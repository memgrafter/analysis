# SMKC: Sketch Based Kernel Correlation Images for Variable Cardinality Time Series Anomaly Detection

## Quick Facts
- **arXiv ID:** 2601.21050
- **Source URL:** https://arxiv.org/abs/2601.21050
- **Reference count:** 25
- **Primary result:** A training-free detector using random projection and k-NN on the SMKC representation achieves competitive AUPRC (e.g., 0.555) with fully trained neural baselines on variable-cardinality time series anomaly detection.

## Executive Summary
SMKC is a framework for anomaly detection in multivariate time series where the number of observed variables (sensors) changes across time windows. It decouples the challenge of handling dynamic, unordered variable sets from the detection task. First, it uses permutation-invariant feature hashing to convert each variable-cardinality input window into a fixed-width sequence. Second, it constructs a hybrid kernel correlation image from this sequence and its derivatives to capture global temporal structure. A simple, training-free scorer—random projection followed by k-nearest neighbors on this representation—performs competitively with gradient-trained models, especially under distribution shifts in variable cardinality. Key findings show that robust, magnitude-sensitive kernel channels are essential, while efficient linear-scaling variants maintain performance with far less compute.

## Method Summary
The SMKC pipeline operates on input windows `(X, M)` where `X` are values and `M` is a missingness mask, with varying variable count `C`. **Stage 1** transforms the unordered set of observed variables at each timestep into a fixed-size, permutation-invariant state vector `g_t` using deterministic signed feature hashing (hashing variable IDs into `m` buckets for values and presence) and normalizing by the square root of observed variables at that timestep `√n_t`. **Stage 2** builds a "kernel image" by computing pairwise cosine similarity and robust log-distance for `g`, its first difference `Δg`, and absolute difference `|Δg|`, stacking six `L×L` channels. For scalability, band-diagonal or anchor-based features approximate this full image. **Stage 3** (training-free) flattens the image, applies a fixed random projection to 256 dimensions, and scores a test window by its average cosine distance to the `K=20` nearest neighbors among normal reference windows. An optional full encoder with masked reconstruction and teacher-student prediction can be added for modest gains but requires training.

## Key Results
- Training-free `RandProj-kNN(SMKC)` achieves AUPRC 0.555 under `holdout-C` (unseen cardinalities), comparable to the trained `SMKC-ENS(HYB)` (0.549) and beating many neural baselines.
- Robust log-distance kernel channels provide the dominant discriminative signal; cosine-only variants collapse (AUPRC ~0.12).
- Efficient `bandfeat` variants reduce compute by 16× with maintained or improved AUPRC (0.578).

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** The framework handles variable sensor cardinality and missingness by converting unordered, dynamic sets of variables into a fixed-width, permutation-invariant sequence.
- **Mechanism:** Signed feature hashing aggregates per-time-step variable values and presence indicators into a fixed number of hash buckets. The aggregation sum is normalized by the square root of the number of observed variables at that timestep (`√nt`), decoupling the representation magnitude from the variable count `C`. Deterministic hashing of variable identifiers ensures reproducibility and supports unseen variable IDs.
- **Core assumption:** Information loss from hash collisions is tolerable and does not bottleneck detection performance; per-time normalization sufficiently controls for count-dependent magnitude biases.
- **Evidence anchors:** [abstract] states permutation-invariant feature hashing; [section 3.2.1] details equations (1)-(2) and implementation; internal evaluations show weak direct support but analogous techniques exist in other domains.

### Mechanism 2
- **Claim:** A hybrid kernel image built from the hashed sequence and its derivatives captures global temporal structure robustly, even when built from a sketch.
- **Mechanism:** For sequences `g`, `Δg`, and `|Δg|`, compute two pairwise channels per sequence: (i) cosine similarity (ℓ2-normalized) and (ii) robust log-distance using a median-estimated bandwidth. Stacking yields a 6×L×L "image" where each channel encodes directional smoothness vs. magnitude deviations of temporal relationships.
- **Core assumption:** Pairwise comparisons over the hashed sequence `g` preserve sufficient signal about the underlying latent dynamics for anomaly detection, despite initial dimensionality reduction via hashing.
- **Evidence anchors:** [abstract] describes hybrid kernel image; [section 3.2.2] defines channels and shows visualizations; [section 5.5] ablation shows cosine-only collapse, confirming reliance on magnitude-sensitive log-distance.

### Mechanism 3
- **Claim:** A strong anomaly detector can be built from the SMKC representation without gradient-based training, using random projection and k-nearest neighbors.
- **Mechanism:** Flatten the SMKC kernel image, apply a fixed random Johnson–Lindenstrauss projection to 256 dimensions, and score a test window by its average cosine distance to the K=20 nearest neighbors among normal reference windows.
- **Core assumption:** The SMKC kernel image geometry yields a relatively dense, low-dimensional manifold for normal windows in projected space, with anomalies as outliers.
- **Evidence anchors:** [abstract] promotes training-free competitiveness; [section 3.4.4] describes kNN scoring; [section 5.1 & Table 3] shows `RandProj-kNN` AUPRC 0.555 vs. trained baselines ~0.55.

## Foundational Learning

### Concept: Signed Feature Hashing
- **Why needed:** To create a fixed-size `(L, 2m)` representation from variable-cardinality inputs in a permutation-invariant way, supporting unseen variable IDs without retraining.
- **Quick check:** If you double the hash width `m` while keeping `L` fixed, what happens to (a) expected collision rate and (b) computational cost? (Answer: (a) decreases, (b) increases linearly with `m`.)

### Concept: Robust Kernel Distance Scaling
- **Why needed:** To make pairwise distance comparisons insensitive to overall signal magnitude shifts (e.g., due to different numbers of observed variables) while remaining sensitive to local structural deviations.
- **Quick check:** Why might cosine similarity alone fail to detect an anomaly that is a short-segment amplitude scaling? (Answer: Cosine is invariant to positive scaling after ℓ2-normalization, so magnitude changes are suppressed.)

### Concept: Permutation-Invariant Set Processing
- **Why needed:** The variable order is meaningless and can change; the model must treat `{var1, var2}` and `{var2, var1}` identically.
- **Quick check:** What architectural property must a model have to process `(X, M)` with varying `C` and no fixed variable ordering? (Answer: The forward pass must commute with any permutation of the variable dimension, e.g., via summing over a learned embedding after permutation-equivariant variable encoding.)

## Architecture Onboarding

### Component map
Input (X,M) -> Hashed Sequence Builder -> Kernel Image Constructor -> (Optional: Scalable Variants bandfeat/anchorfeat) -> (Optional: Encoder) -> Flatten -> Random Projection -> kNN Scoring

### Critical path
The minimal, training-free pipeline: `(X,M) → g_{1:L} → kernel image (or bandfeat/anchorfeat) → flatten → random projection → kNN`. The core innovation is that steps 2–3 create a representation where this simple kNN works well.

### Design tradeoffs
- **Hash width `m`**: Larger `m` reduces collisions (better fidelity) but increases `d=2m` and kernel compute (`O(L²d)`). Performance saturates by `m=128`.
- **Kernel channels**: Log-distance channels are dominant; cosine-only collapses. Using only log-dist for `g`, `Δg`, `|Δg|` is a strong, simpler variant.
- **Scalability**: `bandfeat` reduces compute 16× vs. full image with maintained/improved AUPRC. Tradeoff: loses long-range off-diagonal structure.
- **Training vs. cold-start**: `RandProj-kNN` gives competitive zero-training performance. Full `SMKC-ENS` with encoder and fusion gives modest gains but requires labeled validation and compute.

### Failure signatures
1. **Very low cardinality (`C<4`)**: Performance drops across all methods because insufficient variables provide structured evidence; SMKC degrades less than sequence-only methods.
2. **Cosine-only kernel**: AUPRC collapses to ~0.12. Symptom: kernel images appear visually smooth with low contrast.
3. **No `√nt` normalization**: Increased variance and slight performance drop. Symptom: anomaly scores correlate with observed count `nt` rather than pattern.
4. **Extreme hash compression (`m<64`)**: Potential collision-induced signal loss, though resilience down to `m=32` is shown in this benchmark.

### First 3 experiments
1. **Validate training-free baseline**: Implement `RandProj-kNN(SMKC)` with `m=128`, `L=64`, full HYB image. Replicate holdout-C result: AUPRC should be ~0.555, competitive with trained baselines. This confirms the representation's intrinsic discriminativity.
2. **Ablate kernel channels**: Re-run with `cos only` and `log only` variants. Expect `cos only` AUPRC ~0.12 (collapse) and `log only` AUPRC > baseline (+0.03). This verifies the dominant role of robust log-distance.
3. **Sweep hash width `m`**: For `RandProj-kNN`, sweep `m ∈ {32,64,128,256,512}`. Expect AUPRC to plateau by `m=128` with collision rate ~1%, confirming collision tolerance and guiding practical `m` selection.

## Open Questions the Paper Calls Out
- **How does the presence stream impact anomaly detection when missingness is correlated with anomalies?** The authors noted that removing the presence stream slightly improved performance in their synthetic benchmark where missingness is independent of anomalies. They expect it to become more informative when missingness is structured or correlated with abnormal events, but this was not experimentally tested. *Unknown:* Whether the presence bitstream adds signal or noise under realistic missingness patterns.
- **How does SMKC scale to very high variable cardinalities (e.g., hundreds of variables), and what are the implications of hash collisions on detection accuracy?** The paper evaluates hash widths up to 512 and cardinalities up to 16, finding performance saturation. However, the method's reliance on feature hashing implies that collisions increase with the number of observed variables `C`, potentially degrading representations when `C` is much larger than `m`. This scalability is not addressed. *Assumption:* Collision rate remains manageable if `m` is scaled with `C`, but this is not validated.
- **Does the training‑free RandProj‑kNN detector remain effective under non‑stationary normal behavior or concept drift in real‑world deployments?** The authors promote RandProj‑kNN as a cold‑start solution, but all evaluations are on stationary synthetic datasets. Robustness to distribution shifts is unknown; in practice normal behavior may change, potentially requiring adaptive updates. *Open problem:* Developing a version with bounded reference set updates or adaptive projection.

## Limitations
- Synthetic data generation specifics are undocumented; exact anomaly injection and cardinality distribution are unknown, limiting external validation and reproducibility of the benchmark.
- The break condition for hash collisions at very small `m` is described but not systematically validated across diverse data regimes (e.g., varying variable correlations or anomaly types).
- Real-world applicability is uncertain; SMKC addresses a niche (variable-cardinality MTS) with few direct predecessors in the citation corpus, so comparative advantage on real-world variable-cardinality datasets is unproven.
- Claims about scalable variants (`bandfeat` 16× speedup) lack independent timing measurements and testing on longer sequences (`L>64`), so computational benefits are inferred rather than measured.
- The analysis does not explore sensitivity to the random projection matrix or `k` in kNN; results may vary with different random seeds or `K` choices.

## Confidence
- **Representation mechanism (hashing + kernel):** Medium. Supported by internal ablations (cos-only collapse, log-dominant channels, hash width sweeps), but external validation pending and theoretical collision bounds not established.
- **Training-free detector competitiveness:** Medium-High. Results are internally consistent and show strong holdout-C performance; however, dependence on reference set size and `k` is not fully explored, and all tests are on synthetic stationary data.
- **Scalable variants (bandfeat/anchorfeat):** Low-Medium. Claimed speedup with maintained AUPRC needs independent verification on varied sequence lengths and real-world cardinality distributions.
