# BTZSC: A Benchmark for Zero-Shot Text Classification Across Cross-Encoders, Embedding Models, Rerankers and LLMs

## Quick Facts
- **ArXiv ID:** 2603.11991  
- **Source URL:** https://arxiv.org/abs/2603.11991  
- **Reference count:** 38  
- **Primary result:** Rerankers (e.g., Qwen3‑Reranker‑8B) achieve state‑of‑the‑art zero‑shot classification macro F1=0.72 on BTZSC, outperforming embedding models, instruction‑tuned LLMs, and NLI cross‑encoders.

## Executive Summary
BTZSC is a new benchmark for zero‑shot text classification comprising 22 diverse datasets spanning sentiment, topic, intent, and emotion. It addresses the lack of unified, truly zero‑shot evaluation across model families by implementing a consistent protocol: models compare input text to verbalized label descriptions via NLI entailment, embedding similarity, reranking, or instruction‑based prompting. The authors evaluate 38 models and find that modern rerankers, exemplified by Qwen3‑Reranker‑8B, set a new state‑of‑the‑art with macro F1 of 0.72. Strong embedding models like GTE‑large‑en‑v1.5 offer a compelling accuracy‑latency trade‑off (macro F1=0.62), while instruction‑tuned LLMs of 4–12B parameters reach up to 0.67 but generally trail rerankers. NLI cross‑encoders plateau at 0.60 even with larger backbones, and scaling benefits rerankers and LLMs far more than embedding models. The benchmark and code are publicly released.

## Method Summary
BTZSC standardizes zero‑shot evaluation across four model families. Each dataset provides a fixed set of labels verbalized via templates (e.g., “The overall sentiment is {label}”). For inference:
- NLI cross‑encoders treat the input as premise and verbalized label as hypothesis, extracting the entailment logit.
- Embedding models encode input and label separately with instruction prompts (e.g., “query: {text}”) and compute cosine similarity.
- Rerankers use a cross‑encoder architecture to score the relevance of the input (query) against the verbalized label (document); for models like Qwen3‑Reranker, a yes/no scoring head is used.
- Instruction‑tuned LLMs are prompted with a multiple‑choice format and probabilities for option tokens are compared.
Models are evaluated on official test splits without any task‑specific training. Primary metric is macro‑averaged F1; additionally micro accuracy, macro recall, and precision are reported. Dataset‑level scores are aggregated by unweighted mean within each task family.

## Key Results
- Rerankers achieve SOTA: Qwen3‑Reranker‑8B reaches macro F1=0.72, and even the 0.6B variant outperforms all NLI cross‑encoders.
- Embedding models like GTE‑large‑en‑v1.5 (macro F1=0.62) provide the best trade‑off between accuracy and latency, dominating the high‑accuracy low‑latency quadrant.
- Instruction‑tuned LLMs (4–12B) achieve up to 0.67 macro F1, excelling on topic classification but still trailing rerankers; NLI cross‑encoders plateau at 0.60 despite scaling.

## Why This Works (Mechanism)
**Mechanism 1: Rerankers achieve SOTA through cross‑encoder architecture and large‑scale relevance training**  
Rerankers process input–label pairs with full attention, and their training on massive relevance data (e.g., MS MARCO) directly transfers to zero‑shot classification. The core assumption is that relevance data distribution is sufficiently diverse; evidence includes the abstract and Section 5 showing Qwen3‑Reranker‑8B’s 0.72 macro F1 and the 0.6B variant beating all NLI cross‑encoders. Break conditions: if training data is domain‑narrow, performance may degrade; computational cost scales with number of labels.

**Mechanism 2: Embedding models offer best accuracy‑latency trade‑off via bi‑encoder design**  
Independent encoding of inputs and labels enables precomputation of label embeddings and fast similarity search. Contrastive training on large datasets aligns the embedding space so semantically similar texts are nearby, sustaining accuracy despite lacking cross‑attention. Evidence: abstract mentions GTE’s strong performance with best trade‑off; Figure 3(a) shows embedding models in the high‑accuracy low‑latency quadrant. Break condition: poor alignment (e.g., dataset bias) reduces accuracy; tasks requiring deep interaction (like NLI) may suffer.

**Mechanism 3: NLI cross‑encoders plateau with scale due to limited supervision**  
The three‑way NLI objective (entailment/contradiction/neutral) saturates quickly; larger models cannot extract additional benefit. The core assumption is that task complexity is insufficient to utilize larger capacity. Evidence: abstract states plateau at 0.60; Section 5 notes only +3.5 F1 from base to large; Figure 2(b) shows a flat scaling curve compared to rerankers and LLMs. Improvement may require enhancing the objective (e.g., contrastive) or using instruction‑tuned LLMs for NLI.

## Foundational Learning
- **Zero‑shot classification via label verbalization**  
  *Why needed:* BTZSC evaluates models without task‑specific training; models must connect input text to natural language descriptions of labels.  
  *Quick check:* For a sentiment task with labels “positive”, “negative”, “neutral”, how would you construct verbalizations for an NLI model (premise‑hypothesis)? How would that differ for an embedding model (instruction prompts)?

- **Cross‑encoder vs. bi‑encoder architectures**  
  *Why needed:* Performance differences among model families largely stem from whether they use cross‑attention between input and label (cross‑encoder) or independent encoding (bi‑encoder), which underlies accuracy‑latency trade‑offs.  
  *Quick check:* For a classification task with 50 candidate labels, what is the computational complexity (forward passes) for a cross‑encoder versus a bi‑encoder? How does that impact total inference time?

- **Scaling laws and family‑specific behaviors**  
  *Why needed:* The paper reveals that scaling model size benefits rerankers and LLMs much more than embedding models or NLI cross‑encoders, a pattern critical for future model development.  
  *Quick check:* If you can train a 10B parameter model, which family (reranker or LLM) would likely yield the largest gain over its smaller variant based on BTZSC findings? Why?

## Architecture Onboarding
- *Component map:* Data Module -> Verbalization Module -> Model Interface -> Prediction Module -> Evaluation Module
- *Critical path:* To run a minimal example: install transformers, datasets, torch; load a dataset (e.g., amazon_polarity) and a model (e.g., facebook/bart-large-mnli); for NLI, create hypotheses using the verbalizer, get entailment logits, compute accuracy (~0.84 expected).
- *Design tradeoffs:*  
  - Accuracy vs. latency: cross‑encoders/rerankers slower but more accurate; embedding models and small LLMs faster but less accurate.  
  - Model size: larger models generally better but increase memory/latency; scaling benefits differ by family.  
  - Verbalization: use fixed templates from the paper; altering them may affect results.  
  - Batch processing: cross‑encoders require O(L) passes for L labels; embedding models can precompute label embeddings.  
  - Precision: use bfloat16 to reduce memory and speed up inference.
- *Failure signatures:*  
  - Low accuracy: check model suitability for zero‑shot and correct verbalizer templates.  
  - High variance: set random seeds; ensure model.eval().  
  - Out‑of‑memory: reduce batch size; process one label at a time for cross‑encoders.  
  - Task‑specific failure: may indicate domain mismatch; inspect training data.  
  - Embedding similarities near zero: verify L2 normalization.  
  - LLMs not outputting option letters: check prompt format, that options are single tokens, and model is instruction‑tuned.
- *First 3 experiments:*  
  1. Baseline replication: Run BART‑Large‑MNLI on Amazon Polarity; expect macro F1 ~0.84.  
  2. Efficiency comparison: Measure inference time per example for BART‑Large‑MNLI, all‑MiniLM‑L6‑v2, ms‑marco‑MiniLM‑L6‑v2, and Llama‑3.2‑3B‑Instruct on 100 examples with 2 labels; verify embedding fastest, LLM slowest.  
  3. Scaling test for rerankers: Compare Qwen3‑Reranker‑0.6B vs. 8B on 5 diverse BTZSC datasets; expect ~5–10 F1 point gain for the larger model.

## Open Questions the Paper Calls Out
1. How do different label verbalizations (e.g., template wording, length, synonym choice) affect zero‑shot classification performance across the four model families?
2. How do the relative performance and accuracy‑latency trade‑offs of the four model families change when evaluated on languages other than English?
3. To what extent do the reported zero‑shot results on BTZSC reflect genuine generalization versus contamination from models’ pretraining corpora?
4. Why do embedding models exhibit diminishing returns from parameter scaling, while rerankers and large language models continue to improve in zero‑shot classification?

## Limitations
- Custom NLI cross‑encoder checkpoints are not publicly available, hindering exact replication.
- Dataset licenses (often non‑commercial) and English‑only coverage limit broader reuse and generalizability.
- Missing explicit instruction templates for embedding models introduce prompt‑engineering variance; fixed verbalizations may bias results toward certain architectures.
