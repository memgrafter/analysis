# Regret Bounds for Competitive Resource Allocation with Endogenous Costs

## Quick Facts
- arXiv ID: 2603.18999
- Source URL: https://arxiv.org/abs/2603.18999
- Reference count: 4
- Primary result: Online resource allocation with endogenous costs defined by interaction matrix W exhibits strict regret separation: uniform Ω(T), gated O(T^{2/3}), competitive O(√(T log N)). Sparse topologies reduce computation with minor regret increase; ring structures minimize the computation-regret product.

## Executive Summary
This paper studies online allocation of a probability distribution over N modules, where module costs are endogenous: the total payoff includes a quadratic interaction term λ∑_{(i,j)∈E} W_{ij} a_i a_j with a known interaction matrix W. The environment's value sequence v_t is adversarial but with bounded variation. Three allocation paradigms are analyzed: uniform (always equal allocation), gated (predict allocation from features before seeing v_t), and competitive (multiplicative weights with interaction-enriched feedback). The authors prove a strict regret separation: uniform suffers linear Ω(T) regret, gated incurs an irreducible O(T^{2/3}), while competitive attains the optimal O(√(T log N)) rate. Furthermore, the sparsity and structure of W govern a fundamental tradeoff between per-step computational cost and regret: sparse graphs (|E|=O(N)) increase regret by at most an additive O(√(log N)) while reducing computation from O(N²) to O(N); ring-like topologies such as Wuxing minimize the product of computation and regret.

## Method Summary
The problem is formalized as online convex optimization with coupled losses. The allocator chooses a_t ∈ Δ^N each round, then receives v_t and accrues payoff P(a_t, v_t; W) = a_t·v_t + λ a_t^⊤ W a_t. The goal is to minimize static regret relative to the best fixed allocation in hindsight. Three algorithms are considered: (1) Uniform ignores W and v_t entirely; (2) Gated maintains a linear map G from features x_t (e.g., past values) to a softmax allocation, and updates G via gradient descent on the observed payoff; (3) Competitive uses a multiplicative weights update where the reward for module i incorporates the endogenous cost effect: r_i(t) = v_{t,i} + λ ∑_j W_{ij} a_{t,j}. The analysis relies on the bounded variation assumption V_T = ∑_{t=2}^T ‖v_t−v_{t-1}‖_∞ ≤ V and concavity ensured by λ ≤ 1/(2N). Regret bounds are derived for each paradigm, separating them by their ability to exploit the interaction feedback.

## Key Results
- **Regret separation**: Uniform suffers Ω(T); gated achieves O(T^{2/3}); competitive attains O(√(T log N)).
- **Sparsity–regret tradeoff**: Using a sparse interaction graph with |E| = O(N) increases regret by at most O(√(log N)) but reduces per-step computation from O(N²) to O(N).
- **Optimal topology**: Ring-structured graphs (e.g., Wuxing with balanced cooperative and competitive edges and edge connectivity κ ≥ 2) minimize the product of computation cost and regret.

## Why This Works (Mechanism)
**Mechanism 1 (Competitive advantage).** Competitive allocation computes an interaction-enriched reward r_i(t) = v_{t,i} + λ Σ_{j:(i,j)∈E} W_{ij}·a_{t,j} using the known W and current allocation a_t. This signal directly captures the marginal contribution of module i, including endogenous cost effects from other modules. With this feedback, multiplicative weights updates efficiently track the optimal allocation, preserving the standard O(√(T log N)) regret bound. The mechanism hinges on W being fixed and known, and the value sequence having bounded variation.

**Mechanism 2 (Gated limitation).** Gated allocation predicts a_t from features x_t via a linear map G before observing v_t. The gradient used to update G evaluates the interaction terms λ Σ_j W_{ij} a_j at the *current* allocation a_t, which itself was produced by G. This circular dependency introduces a bias proportional to the gap between a_t and the optimal a*_t. Under bounded variation, this bias limits the convergence rate to O(T^{2/3}), an irreducible penalty compared to the competitive case.

**Mechanism 3 (Topology tradeoff).** The interaction graph’s density |E| controls the computation–regret tradeoff. Denser graphs provide more interaction information per round (tightening regret bounds via better variance control and connectivity), but increase per-step cost O(|E|). Sparser graphs reduce computation but loosen regret. The product T·(per-step cost)·(regret) is minimized when |E| = Θ(N) and the graph is balanced (both positive and negative edges) with edge connectivity κ ≥ 2; ring-like topologies such as Wuxing achieve this optimum.

## Architecture Onboarding
Component map: Allocator module → outputs a_t → system computes payoff P and feedback → Feedback processor (computes r_i from W and a_t) → Allocator update; Value observer receives v_t.

Critical path (competitive): Compute r_i for all i (O(|E|)) → multiplicative weights update (O(N)) → normalize. Interaction computation dominates for dense W.

Design tradeoffs:
- Topology density: Dense W (|E|=O(N²)) → tighter regret O(√T) but O(N²) per-step cost; Sparse W (|E|=O(N)) → slightly worse regret (additive O(√log N)) but O(N) cost.
- Balance: Must include both positive (cooperation) and negative (competition) edges to avoid positional rent; unbalanced graphs increase regret.
- Connectivity: Edge connectivity κ(G) ≥ 2 required to keep the term λ²(N/κ)√T small (Theorem 6).

Failure signatures:
- Gated: Linear regret if α_t not decaying as t^{-1/3}, missing λ interaction term in gradient, or uninformative features x_t.
- Competitive: Numerical issues if reward bounds violated; always use log-space updates; ensure λ ≤ 1/(2N) to keep |r_i| ≤ 1.5.
- Non-concave payoff: If λ(W+W^⊤) has large positive eigenvalues, the problem becomes non-concave; scale λ down.
- Variation exceeded: After generating v_t, compute V_T; if > V, reduce step size δ.
- Offline optimum: For large N, use projected gradient rather than CVXPY; verify KKT.

First 3 experiments:
1. Paradigm separation test: Run uniform, gated, competitive on a synthetic adversarial sequence with alternating optimal modules. Plot static regret vs. T on log-log scale; expect slopes ≈1, 2/3, 1/2 respectively.
2. Topology sweep: Fix N and T; vary edge count m from Θ(N) to Θ(N²). Compute total cost product C = T·(computation per step)·(regret). Verify minimum near m = Θ(N) and that ring-like topologies (e.g., Wuxing) achieve it.
3. Cost truthfulness validation: In a stationary setting (v_t constant), run competitive MWU and monitor (1/T)∑_i |a_i − μ_i/∑μ| (where μ is offline optimum). Should converge at O(ln T/√T). Test with unbalanced W (e.g., star topology) to see persistent divergence (positional rent).

## Open Questions the Paper Calls Out
1. **Dynamic regret under non-stationarity:** How does endogenous cost structure affect dynamic regret bounds with bounded variation V_T? Static regret is analyzed; dynamic regret for time-varying comparators remains open.
2. **Joint learning of W:** What are the guarantees when the interaction matrix W is unknown and must be learned simultaneously? This introduces coupled, non-stationary estimation.
3. **Higher-order interactions:** Can similar regret separations be achieved for payoff functions with three-way or higher-order interactions? Quadratic concavity assumptions may not hold.
4. **Practical constants and crossover:** At what problem sizes (N, T, λ) does competitive allocation empirically outperform gated? Asymptotic rates may only manifest at large scales; empirical validation on realistic modular systems is needed.

## Limitations
- Gated feature x_t is unspecified; using v_{t-1} is an assumption that may affect the O(T^{2/3}) rate.
- The exact Wuxing topology (directed/undirected, weight signs, connectivity κ) is ambiguous, hindering exact recreation.
- Competitive learning rate η = √(ln N / T) requires known horizon T; for unknown T, a doubling trick is needed but not analyzed.
- Corpus evidence is weak; neighboring papers do not address endogenous interaction feedback, limiting contextual validation.
