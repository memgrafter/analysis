# Mechanistic Interpretability of Cognitive Complexity in LLMs via Linear Probing using Bloom's Taxonomy

## Quick Facts
- **arXiv ID:** 2602.17229
- **Source URL:** https://arxiv.org/abs/2602.17229
- **Reference count:** 40
- **Primary result:** Linear probes on residual stream activations achieve ~95% accuracy in linearly separating prompts by Bloom's Taxonomy cognitive level, with separability emerging by layer ~5 and errors predominantly between adjacent levels.

## Executive Summary
This study investigates whether decoder-only Large Language Models (LLMs) internally represent different cognitive complexity levels as defined by Bloom's Taxonomy. Using linear probes on residual stream activations from four models (Llama-3.1-8B-Instruct, Qwen3-4B-Instruct-2507, gemma-3-4b-it, DeepSeek-R1-Distill-Llama-8B), the authors test if prompts labeled Remember, Understand, Apply, Analyze, Evaluate, and Create are linearly separable. Probe accuracy reaches approximately 95% on average, with high performance consistently achieved by early-to-mid layers (Cognitive Separability Onset around layer 5). Misclassifications occur mainly between adjacent taxonomy levels, preserving the ordinal hierarchy. This indicates that cognitive depth is encoded in a linearly accessible, geometrically structured subspace that emerges early in the forward pass and is not merely a byproduct of shallow lexical features.

## Method Summary
The study uses a balanced dataset of 1,128 educational questions (188 per Bloom level) from two existing sources. For each of four decoder-only LLMs, the residual stream activation at the final token position is extracted after a forward pass for every layer. A separate multinomial logistic regression probe (with ℓ2 regularization) is trained on each layer's activations to classify the Bloom level. Performance is evaluated via per-layer accuracy, confusion matrices, and Euclidean distances between class centroids. The Cognitive Separability Onset (CSO) is defined as the first layer where probe accuracy exceeds 90%. Control baselines include linear probes on TF-IDF and sentence embeddings of the raw questions.

## Key Results
- Linear probes achieve ~95% average accuracy, with a sharp rise in performance by layer ~5 (Cognitive Separability Onset).
- Misclassifications are overwhelmingly between adjacent Bloom levels (e.g., Analyze/Evaluate), preserving the taxonomic order.
- The signal in the residual stream substantially outperforms shallow lexical baselines (TF-IDF: ~73%, sentence embeddings: ~61%).
- The ordinal structure is reflected in monotonically increasing centroid distances between classes with layer depth post-CSO.

## Why This Works (Mechanism)

### Mechanism 1
**Claim:** The model resolves the cognitive depth (Bloom level) of a prompt early in the forward pass, within the first few transformer layers, and this representation is then stably maintained.
**Mechanism:** Probe accuracy rises sharply and plateaus (CSO) by layer ~5 across all models, suggesting the cognitive category is determined and encoded into a linearly accessible subspace early. Stable high accuracy in subsequent layers indicates preservation rather than recomputation.
**Core assumption:** Linear probe success on a layer's residual stream directly reflects that the cognitive complexity information is disentangled and linearly accessible within that layer's computation.
**Evidence anchors:**
- Abstract: "representations become increasingly separable across layers" and "Cognitive Separability Onset around layer 5."
- Section 4: Probe accuracy is low in earliest layers, increases, reaches CSO near layer 5, and remains stable.
- Corpus: Neighboring papers use Bloom's for output evaluation; this paper's CSO mechanism in the residual stream is a novel insight.

### Mechanism 2
**Claim:** The internal representation of cognitive depth respects the ordinal, hierarchical structure of Bloom's Taxonomy; geometrically, representations of adjacent levels are closer than those of distant levels.
**Mechanism:** The linear classifier's confusion matrix shows errors predominantly between adjacent Bloom levels. Euclidean distance between class centroids increases monotonically with layer depth after the CSO, indicating an ordered manifold where cognitive depth is a primary separation axis.
**Core assumption:** The error pattern of a linear probe is a valid proxy for the underlying geometric relationships between class-conditional activation distributions.
**Evidence anchors:**
- Section 4.1: "misclassifications occur predominantly between adjacent Bloom levels" and "E[|ŷ - y|] ≈ 1".
- Section 4.1.1: Figure 5 shows centroid distances are small in early layers and increase monotonically.
- Corpus: Neighbors test Bloom's on outputs; this structured internal error pattern is distinct.

### Mechanism 3
**Claim:** The linearly separable signal is not merely a byproduct of surface-level lexical features but corresponds to a deeper, model-internal construction of cognitive complexity.
**Mechanism:** Control experiments using TF-IDF and sentence embeddings on raw text yield substantially lower accuracy (~73% and 61% vs ~95%) and noisier confusion matrices. This gap suggests the residual stream signal contains information beyond the input text, arising from the model's processing.
**Core assumption:** The residual stream activation at the final token position integrates the model's full contextual processing of the prompt.
**Evidence anchors:**
- Section 4.2: TF-IDF (73%) and sentence embeddings (61%) are substantially lower than probe accuracy (~95%); "shallow lexical features do not fully explain the signal."
- Abstract: The encoding is "neither merely a linguistic artifact."
- Corpus: The specific contrast with shallow baselines for a cognitive taxonomy is unique.

## Foundational Learning
- **Concept: Linear Probing**
  - *Why needed:* Core diagnostic tool. The paper's main inference—that cognitive level is linearly encoded—depends on training a simple classifier on frozen activations and achieving high accuracy.
  - *Quick check:* If a linear probe achieves 95% accuracy on a task, what does that definitively tell you about the geometry of the representations? What does it *not* tell you?
- **Concept: Residual Stream & Final Token Position**
  - *Why needed:* Specific locus of analysis. The final token's activation aggregates information over the entire prompt and is considered the model's "understanding" state before generation.
  - *Quick check:* In a decoder-only model, why is the final token's residual stream activation used as the summary state for the entire prompt?
- **Concept: Bloom's Taxonomy as an Ordinal Hierarchy**
  - *Why needed:* Ground-truth labeling framework. The key result—structured adjacency errors—depends on Bloom's levels having a meaningful, ordered relationship.
  - *Quick check:* If a classifier misclassified "Apply" as "Create" more often than as "Remember," what would that suggest about the internal organization?

## Architecture Onboarding
**Component map:**
Input Question -> Tokenizer -> Token IDs -> Embedding Layer -> Initial Hidden State x_emb -> Transformer Stack (L layers; each: x_{l+1} = x_l + Attn(x_l) + MLP(x_l)) -> Activation Hook (extract x_l at final token for every layer l) -> Probe Dataset (x_l, y) -> Per-Layer Probe Training (logistic regression) -> Evaluation (accuracy, confusion, centroid distances) -> Cross-Model Comparison.

**Critical path:** Dataset preparation (balanced prompts + Bloom labels) -> model forward pass + layer-wise activation extraction -> independent per-layer linear probe training -> analysis of accuracy curves, confusion matrices, and centroid distances.

**Design tradeoffs:**
- Final token vs. mean pooling: Final token is standard for "summary" state but may miss distributed info; mean pooling integrates more positions but could dilute the prompt understanding signal.
- Linear vs. nonlinear probe: Linear is chosen for interpretability and to test *linear* accessibility. A nonlinear probe might achieve higher accuracy but conflates probe capacity with representational quality.
- Layer-specific probes: Training separate probes per layer tests *when* information becomes accessible, not just if it's present in the final layer.

**Failure signatures:**
1. **No CSO:** Probe accuracy remains near random (~16.7%) or rises very late (near final layers).
2. **Random errors:** Confusion matrix has no structure; errors uniformly distributed across non-adjacent levels.
3. **Shallow signal dominance:** Probe accuracy similar to TF-IDF/sentence embedding baselines, with similar error patterns.
4. **Inconsistent cross-model:** CSO layer varies wildly (e.g., layer 1 vs. last layer) or accuracy profiles differ drastically.

**First 3 experiments:**
1. **Baseline sanity check:** Train a probe on the embedding layer activations (pre-transformer). Expect near-random accuracy. If high, dataset may be lexically confounded.
2. **Probe capacity check:** Train a small nonlinear probe (1-hidden-layer MLP) on the CSO layer. If accuracy jumps dramatically (>99%), the linear separability claim is weakened.
3. **Cross-validation of CSO:** For one model, run the full pipeline with 3 different random train/test splits. Compute mean and std of layer-wise accuracy curves. The CSO layer (first layer crossing τ=0.90) should be stable across splits.

## Open Questions the Paper Calls Out
- **Question:** Do the linearly separable cognitive representations identified in the residual stream causally influence the model's generation process, or are they merely epiphenomenal?
  - **Basis:** Authors state "linear separability does not imply causal use" and that "establishing causal relevance through targeted interventions remains an important next step."
  - **Why unresolved:** Study demonstrates correlation via probing but does not manipulate representations to observe downstream effects on generation.
  - **Resolution evidence:** Causal intervention experiments, such as ablating or editing dimensions most predictive of Bloom level, then measuring changes in output quality, cognitive level, or task performance.
- **Question:** Does the linear separability of Bloom levels generalize to LLMs processing non-English prompts and prompts from non-educational domains (e.g., medical, legal)?
  - **Basis:** Authors propose "cross-lingual and cross-domain analysis would establish the universality of the CSO" as future work, noting current limitations to English educational questions.
  - **Why unresolved:** Dataset and models are restricted to English educational contexts.
  - **Resolution evidence:** Replicating the probing pipeline on models and datasets in diverse languages and specialized professional domains.
- **Question:** How do encoder-only and encoder-decoder architectures represent cognitive complexity compared to the decoder-only models studied?
  - **Basis:** Limitations state "generalizability to other architectures (e.g., encoder-only or encoder-decoder models) remains to be established."
  - **Why unresolved:** Study exclusively examined decoder-only transformers.
  - **Resolution evidence:** Applying identical linear probing to residual streams (or analogous hidden states) of encoder-only (e.g., BERT) and encoder-decoder (e.g., T5) models on the same Bloom-annotated dataset.
- **Question:** What is the specific contribution of individual components (attention heads, MLP layers) to the emergence and maintenance of cognitive separability within the residual stream?
  - **Basis:** Authors note "our methodology examines only the residual stream, leaving attention patterns and MLP internals as areas for future investigation."
  - **Why unresolved:** Probing the aggregated residual stream does not isolate subcomponent contributions.
  - **Resolution evidence:** Component-level probing (e.g., on attention output matrices or MLP activation vectors) or activation patching experiments to identify critical heads/layers.

## Limitations
- Dataset construction details (downsampling procedure) are unspecified, risking hidden selection biases beyond the reported non-significant length difference (p=0.053).
- Probe implementation hyperparameters (solver, tolerance) are not fully detailed; the claim of linear accessibility strictly depends on probe capacity.
- The causal evidence gap: the early encoding claim rests on correlational accuracy curves without interventions to test necessity for generation.
- Baseline comparisons (TF-IDF, sentence embeddings) may suffer from methodological mismatches in classification setup.

## Confidence
- **Mechanism 1 (Early Encoding):** Medium confidence. Consistent cross-model accuracy rise and plateau by layer ~5 support the claim, but without causal tests, later layers could still refine the signal.
- **Mechanism 2 (Ordinal Structure):** High confidence. The adjacent confusion pattern and monotonically increasing centroid distances provide direct, robust evidence of an ordered latent geometry.
- **Mechanism 3 (Non-Lexical Signal):** Medium confidence. The substantial accuracy gap suggests deeper processing, but unspecified baseline probe architectures and potential lexical confounds leave alternative explanations possible.

## Next Checks
1. **Causal intervention via activation patching:** Swap the CSO-layer (e.g., layer 5) residual stream activations between prompts of different Bloom levels. If task performance or probe accuracy collapses, it confirms the early signal's necessity.
2. **Ordinal geometry stress test:** Compute pairwise centroid distances for all Bloom level combinations and correlate them with the ordinal gap (|level_i - level_j|) post-CSO. Non-monotonic correlation would challenge the ordered manifold claim.
3. **Baseline probe parity test:** Train a multinomial logistic regression probe *directly* on TF-IDF and sentence embedding features using the identical setup. If these achieve >90% accuracy with adjacent confusion, the residual stream's distinctiveness is undermined.
