# A Graph Meta-Network for Learning on Kolmogorov-Arnold Networks

## Quick Facts
- arXiv ID: 2602.16316
- Source URL: https://arxiv.org/abs/2602.16316
- Reference count: 40
- Primary result: WS-KAN consistently outperforms all baselines across INR classification, accuracy prediction, and equivariant pruning mask prediction.

## Executive Summary
Weight-space learning for Kolmogorov-Arnold Networks (KANs) remained an open problem due to their non-scalar edge-based functions and lack of symmetry-aware design. This paper introduces the KAN-graph, a representation where neurons are nodes and learnable univariate functions are edge features, and proposes WS-KAN, a graph neural network that operates on this graph while respecting permutation symmetries of hidden neurons. Across multiple tasks—INR classification, accuracy prediction, and pruning mask prediction—WS-KAN achieves state-of-the-art results and generalizes to wider unseen KAN architectures.

## Method Summary
The authors represent a trained KAN as a directed graph (KAN-graph): nodes correspond to neurons across layers, and edges carry vectorized parameters of the univariate functions (e.g., spline coefficients). Positional encodings based on layer indices are added to disambiguate nodes. WS-KAN is a multi-layer graph neural network that processes this graph using bidirectional message passing: forward and backward messages are computed from incoming and outgoing edges, aggregated, and used to update node and edge features. This architecture naturally respects the permutation symmetries of KANs. Task-specific readouts (e.g., classification heads) are applied to the final node representations. The approach is evaluated on weight-space learning tasks and shows significant improvements over baselines that flatten weights.

## Key Results
- INR classification: WS-KAN achieves 94.3% on MNIST, 84.6% on Fashion-MNIST, and 42.2% on CIFAR-10, surpassing all baselines by large margins.
- Accuracy prediction: WS-KAN yields the lowest mean squared error and highest R² when predicting test accuracy of KANs.
- Pruning mask prediction: WS-KAN accurately predicts equivariant pruning masks and generalizes to wider KAN architectures not seen during training.

## Why This Works (Mechanism)

### Mechanism 1: Permutation Symmetry in KANs
**Claim:** Kolmogorov–Arnold Networks (KANs) share the same neuron permutation symmetries as MLPs.  
**Mechanism:** Permuting the indices of neurons in any hidden layer leaves the function computed by the KAN unchanged because the univariate functions on edges are recomposed accordingly; this corresponds to a simultaneous row/column permutation of the function matrices per layer. The symmetry is formally proven in Proposition 3.1.

### Mechanism 2: KAN-graph Representation
**Claim:** Representing a KAN as a directed graph (the KAN-graph) with neurons as nodes and univariate functions as edge features naturally encodes its computational structure and permutation symmetries.  
**Mechanism:** Nodes correspond to neurons across layers; edges store vectorized parameters of the univariate functions. Permuting neurons within a hidden layer corresponds to a graph automorphism because it permutes nodes within an isomorphism class and simultaneously permutes incident edges, leaving the feature-augmented graph unchanged.

### Mechanism 3: WS-KAN Architecture
**Claim:** A Graph Neural Network (WS-KAN) operating on the KAN-graph can learn weight-space tasks while respecting permutation symmetries, leading to superior performance over flattening baselines.  
**Mechanism:** Bidirectional message passing updates node and edge features via MLPs and neighbor aggregation. Because the graph representation is invariant to neuron permutations within layers, the GNN’s equivariant operations inherently respect the KAN’s symmetries. Theorem 4.2 proves the GNN’s expressive power suffices to simulate the KAN forward pass.

## Foundational Learning

### Permutation symmetries of neural networks
Neural networks with fully connected layers exhibit symmetry: permuting neurons in a hidden layer does not change the computed function because weight matrices are rearranged accordingly.  
**Why needed:** The entire design of WS-KAN hinges on identifying and respecting these symmetries for KANs; without this insight, architecture design would be ad-hoc.  
**Quick check:** If you permute the order of neurons in a hidden layer of an MLP, does the function change? (Answer: no.)

### Graph Neural Networks (GNNs)
GNNs process graph-structured data by iteratively aggregating information from neighbors; standard message passing is equivariant to permutations of input nodes.  
**Why needed:** WS-KAN uses a GNN to process the KAN-graph; understanding GNN equivariance explains why the approach respects symmetries.  
**Quick check:** In a GNN with sum aggregation, if you permute the input node ordering, what happens to the output node features after one layer? (Answer: they permute accordingly.)

### Kolmogorov–Arnold Networks (KANs)
KANs replace scalar weights on edges with learnable univariate functions (e.g., B-splines). Computation involves evaluating these functions and summing across incoming edges.  
**Why needed:** KANs differ fundamentally from MLPs; their edge-based functions necessitate a new graph representation for weight-space learning.  
**Quick check:** In a KAN, where are the learnable parameters located? (Answer: in the univariate functions on edges.)

### Positional encodings in graph networks
When nodes lack inherent distinguishing features, positional encodings (e.g., based on structural roles) provide information to break unwanted symmetries.  
**Why needed:** The KAN-graph nodes are otherwise indistinguishable beyond layer; positional encodings based on layer index prevent the GNN from being invariant to trivial permutations (e.g., swapping input with output).  
**Quick check:** What risk arises if a graph with no node features is processed by a GNN without positional encodings? (Answer: the network may be invariant to permutations that should change the function.)

## Architecture Onboarding

### Component map
Input KAN → Preprocessor (build KAN-graph) → WS-KAN (GNN) → Task-specific head → Output  
- **Input:** a trained KAN model.  
- **Preprocessor:** extracts architecture and spline parameters; constructs a directed graph with neurons as nodes, edges as connections storing vectorized function parameters; adds positional encodings based on layer indices.  
- **Core model (WS-KAN):** multi-layer GNN with bidirectional message passing: forward messages from incoming edges, backward messages from outgoing edges; node and edge features updated via small MLPs.  
- **Readout:** aggregates final node features (e.g., from output layer nodes) for prediction.  
- **Output:** task-specific prediction (e.g., class label, accuracy score, pruning mask).

### Critical path
1. Take input KAN; extract layer dimensions and spline coefficients.  
2. Build KAN-graph with correct connectivity, edge features (e.g., `[w_b, w_s, c]`), and positional encodings.  
3. Run WS-KAN forward pass; ensure GNN depth matches or exceeds KAN depth for full information propagation.  
4. Apply task-specific readout to produce final prediction.

### Design tradeoffs
- *Bidirectional vs. unidirectional message passing:* Bidirectional improves performance (see ablations) but adds computational cost.  
- *Positional encoding:* Crucial to distinguish nodes beyond permutation orbits; omitting degrades performance, especially on equivariant tasks like pruning.  
- *Edge feature representation:* Using raw spline parameters is simple but may be suboptimal; alternative encodings (e.g., function evaluations) could enhance robustness.  
- *GNN depth:* Deeper GNNs can simulate deeper KANs (per Theorem 4.2) but risk overfitting or slower inference; the paper uses 4 layers.

### Failure signatures
- *Collapsed accuracy:* If WS-KAN performs similarly to MLP baselines, likely the KAN-graph construction or message passing is flawed (e.g., missing edge features, no positional encoding).  
- *Poor OOD generalization to wider KANs:* Training only on narrow KANs limits scalability; performance drops for widths >64 on MNIST.  
- *Pruning task failure:* If pruning mask accuracy is near random (~50%), WS-KAN may not be leveraging graph structure; verify message passing implementation.

### First 3 experiments
1. *Sanity check:* Feed a single KAN through the pipeline; manually permute hidden neuron order and verify that the GNN output remains unchanged for invariant tasks.  
2. *Baseline replication:* Replicate Table 1 for INR classification on MNIST; expect WS-KAN >90% vs. flat MLP ~34%.  
3. *Ablation validation:* Run WS-KAN without positional encoding and without bidirectional passing on accuracy prediction; expect noticeable drop in R² / increase in MSE.

## Open Questions the Paper Calls Out

1. **Generalization to deeper and topologically varied KANs**  
   The paper tested widths up to 96 but kept depth fixed at 3; it remains open whether WS-KAN generalizes to deeper architectures or those with skip connections, pooling, or sparsity.  
   *Basis:* Section 6 explicitly calls for extending to deeper and broader topology variations.  
   *Why unresolved:* Such architectures may introduce new symmetry or expressivity challenges not covered by the current layered full-connectivity assumption.

2. **Conversion between KANs and MLPs**  
   Can we develop practical methods to convert KANs to MLPs (or vice versa) while preserving the underlying function?  
   *Basis:* Section 6 notes the natural invitation due to weight-space models for both families.  
   *Why unresolved:* No conversion algorithms exist; the mismatch between edge-based univariate functions and scalar weights makes both theoretical and practical correspondence non-trivial.

3. **Applicability to other KAN variants (e.g., CNN-KANs)**  
   Does WS-KAN remain effective when applied to KANs with convolutional or graph-based structures?  
   *Basis:* Section 6 suggests evaluating WS-KAN on CNN-KANs.  
   *Why unresolved:* The current KAN-graph assumes fully connected layers; CNN-KANs introduce weight sharing and locality, potentially requiring modified symmetry handling and graph construction.

4. **Improved weighting schemes for KAN alignment**  
   During model-zoo construction, the alignment method treats all channels of univariate functions equally. Can we design smarter weighting (e.g., based on smoothness or magnitude) to improve canonicalization?  
   *Basis:* Section D.1 mentions alternative weighting schemes could yield improved results.  
   *Why unresolved:* Uniform weighting may not capture parameter importance; exploring meaning-based weights is left for future work.

## Limitations
- The permutation symmetry analysis assumes strictly layered, fully-connected KANs; architectures with skip connections, sparsity, or pooling may invalidate the symmetry claims.
- Generalization to wider KANs is limited: performance drops for widths >64 on MNIST, indicating scalability issues.
- Edge features using raw spline parameters may be suboptimal; alternative representations could improve robustness and performance.

## Confidence
- **KANs share MLP permutation symmetries:** High (formal proof in Proposition 3.1).  
- **KAN-graph representation naturally encodes symmetries:** Medium (valid under layered fully-connected topology; break conditions exist).  
- **WS-KAN consistently outperforms baselines:** Medium (strong empirical results across tasks, but OOD generalization not fully established).

## Next Checks
- Test WS-KAN on KANs with residual/skip connections to verify if symmetry preservation and performance hold.
- Expand model zoos to include KANs with widths up to 128 (and deeper) to probe scalability of accuracy prediction and INR classification.
- Ablate edge feature representation: replace spline coefficients with function evaluations or learned embeddings and compare performance on INR tasks.
