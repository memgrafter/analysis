# Quantifying Membership Disclosure Risk for Tabular Synthetic Data Using Kernel Density Estimators

## Quick Facts
- **arXiv ID:** 2603.10937
- **Source URL:** https://arxiv.org/abs/2603.10937
- **Reference count:** 29
- **Primary result:** A KDE-based method for membership inference attacks on tabular synthetic data provides probabilistic risk scores, consistently outperforms prior distance-based baselines in F1 score, and reveals high worst-case leakage via ROC analysis even when average metrics appear benign.

## Executive Summary
This paper introduces a novel, post-hoc framework for quantifying membership inference attack (MIA) risk in tabular synthetic data. It addresses key limitations of existing methods: prior distance-based approaches yield only hard classifications, while shadow-model attacks are computationally expensive. The core innovation uses kernel density estimators (KDEs) to model the distribution of nearest-neighbor distances from real records to synthetic data, enabling probabilistic membership scoring. Two attack variants are proposed: a "True Distribution Attack" using privileged training data labels and a "Realistic Attack" that operates with only auxiliary unlabeled data. Evaluated across four datasets and six generators, the method achieves superior F1 scores and, crucially, ROC curves that expose severe leakage at extremely low false positive rates—risk that average accuracy metrics canmask. The approach requires no shadow models, offering a practical and sensitive tool for synthetic data privacy assessment.

## Method Summary
The method quantifies MIA risk by modeling the distribution of nearest-neighbor distances between records and synthetic data. Given a real training set `R`, an unseen holdout set `U`, and synthetic data `S` generated from `R`, an attack dataset `D_attack = R ∪ U` is created. For each record in `D_attack`, its nearest-neighbor distance `d` to `S` is computed using Gower’s distance (for mixed-type data). In the True Attack, these distances are split by true membership label (member from `R`, non-member from `U`). Separate KDEs are fitted to the member and non-member distance distributions. For a test distance `d`, the membership probability is estimated as `P(member|d) = KDE_member(d) / (KDE_member(d) + KDE_nonmember(d))`. The Realistic Attack replaces true labels with pseudo-labels derived from an auxiliary dataset by thresholding distances. Probabilistic outputs allow ROC curve construction, revealing risk at low false positive rates. The process is: data partition → distance computation → KDE fitting → probability estimation → metric evaluation.

## Key Results
- The KDE-based attack consistently achieves higher F1 scores than the prior distance-based baseline (Method 1) across four datasets and six synthetic data generators.
- ROC analysis uncovers high true positive rates at extremely low false positive rates (e.g., ≤10⁻⁶), even when overall accuracy or AUC appears near random, indicating severe worst-case leakage obscured by average metrics.
- For example, on Texas-100X data synthesized with a Bayesian Network, the True Attack achieves 97.5% accuracy and a 0.975 F1 score, demonstrating near-perfect membership discernibility.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** KDEs enable probabilistic membership inference by modeling the distribution of nearest-neighbor distances for members and non-members separately, replacing hard thresholds with continuous probability estimates.
- **Mechanism:** Compute Gower’s distance between each record in an attack dataset and the synthetic data. Fit two KDEs: one to distances from known training records (members), another to distances from unseen records (non-members). For a query record with distance `d`, estimate membership probability via `P(member|d) = KDE_member(d) / (KDE_member(d) + KDE_nonmember(d))`, derived from Bayes’ Theorem under equal class priors.
- **Core assumption:** The KDEs accurately approximate the true conditional density functions `P(d|member)` and `P(d|non-member)`.
- **Evidence anchors:** Abstract states the approach models distance distributions for probabilistic inference. Section 3.2 (Proposition 3.1) formally derives the estimator. Corpus context from Synth-MIA and MIA-EPT shows prior work on MIA metrics but not this specific KDE mechanism.

### Mechanism 2
- **Claim:** The Realistic Attack variant extends the method to practical adversary scenarios where true membership labels are unavailable, using auxiliary data and distance-based pseudo-labeling.
- **Mechanism:** Using an auxiliary dataset (mixed members/non-members), records are split into "supposed members" (nearest-neighbor distance ≤ threshold τ) and "supposed non-members" (distance > τ). Separate KDEs are fitted to these pseudo-labeled distance sets, and the same probabilistic equation is applied. Label noise is inherent but manageable.
- **Core assumption:** The auxiliary data is drawn from the same underlying population as the original training data, so its distance distribution approximates the true member/non-member mixtures.
- **Evidence anchors:** Abstract mentions the Realistic Attack using auxiliary data without true labels. Section 3.3 details the threshold-based partitioning and label noise trade-off.

### Mechanism 3
- **Claim:** The method provides sharper risk characterization than prior distance-based methods by enabling ROC analysis, revealing high true positive rates at extremely low false positive rates that average metrics (F1, accuracy) can mask.
- **Mechanism:** Probabilistic outputs allow computation of ROC curves by varying the membership probability threshold. This exposes worst-case leakage where a small fraction of records are highly identifiable, even if overall accuracy is near baseline.
- **Core assumption:** ROC curves at low false positive rates (e.g., FPR ≤ 10⁻⁶) are a meaningful measure of worst-case disclosure risk for synthetic data.
- **Evidence anchors:** Abstract states the approach enables robust evaluation via ROC curves, revealing high TPR at low FPR. Section 5.2 provides examples (TV AE on UK Census, DPGAN on Nexoid) where benign accuracy/AUC hides high TPR at FPR=10⁻⁶.

## Foundational Learning
- **Concept: Kernel Density Estimation (KDE)**
  - *Why needed here:* Forms the non-parametric backbone for estimating distance distributions without assuming a fixed functional form, crucial for handling complex, multimodal distance patterns in heterogeneous tabular data.
  - *Quick check question:* How does the bandwidth parameter `h` in KDE control the bias-variance trade-off when estimating member vs. non-member distance densities?
- **Concept: Gower’s Distance**
  - *Why needed here:* Provides a unified similarity measure for mixed-type (numerical + categorical) tabular data, enabling nearest-neighbor searches across diverse datasets.
  - *Quick check question:* Why is Euclidean distance inappropriate for a purely categorical dataset like UK Census, and how does Gower’s distance handle category mismatches?
- **Concept: Membership Inference Attack (MIA) Threat Model**
  - *Why needed here:* Defines the adversarial objective: determining if a specific record was in the training set of a synthetic data generator, which is the core privacy risk being quantified.
  - *Quick check question:* How does membership inference risk differ from an attribute inference attack in the context of synthetic data privacy?

## Architecture Onboarding
- **Component map:** Data partitioner -> Distance engine -> KDE fitter -> Probability calculator -> Evaluator
- **Critical path:** `D_attack` (combined real training + holdout records) -> nearest-neighbor Gower distance computation to synthetic data `S` -> distance-labeled table `D_dists` -> KDE fitting on training split of `D_dists` (by true or pseudo-labels) -> membership probability estimation on test split -> metrics (accuracy, F1) and ROC curve generation.
- **Design tradeoffs:**
  - *Bandwidth selection:* Scott’s rule (default) vs. manual tuning affects KDE smoothness; over-smoothing may blur distribution separation.
  - *Threshold selection (Realistic Attack):* Percentile choice (10th–90th) controls pseudo-label noise; higher thresholds increase TP/FP but may improve F1 if TP growth outpaces FP.
  - *Distance metric:* Gower’s handles mixed types but is computationally heavier than Euclidean; for all-numeric data, Euclidean might suffice but reduces generality.
- **Failure signatures:**
  - KS test p-values > 0.05 between member/non-member distances → indistinguishable distributions.
  - Log-ROC curves show TPR ≈ FPR across all thresholds → no effective separation.
  - Realistic Attack F1 scores collapse at all thresholds → auxiliary data likely mismatched population.
- **First 3 experiments:**
  1. Replicate True Distribution Attack Table 3: For Texas-100X + Bayesian Network, verify 97.5% accuracy and 0.975 F1. Ensure balanced train/test split (70/30) and Scott’s rule bandwidth.
  2. Reproduce Realistic Attack heatmap (Figure 15): For Texas-100X, run across 9 thresholds (10th–90th percentiles). Confirm F1 peaks around 50th–60th percentile and outperforms Method 1 at higher thresholds.
  3. Generate log-ROC for TV AE on UK Census: Verify TPR=10⁻⁴–10⁻³ at FPR=10⁻⁶ despite overall accuracy ~50% (Figure 12). Demonstrates the “benign average, high worst-case” pattern.

## Open Questions the Paper Calls Out
- **How does the method perform under realistic imbalanced membership prevalence?** The current evaluations use balanced attack datasets, while real-world membership proportions are often much smaller; metrics like F1 and TPR at low FPR may behave differently under imbalance. *Evidence needed:* Empirical evaluation across a range of class priors with proper scoring rules (e.g., Brier score) to assess calibration.
- **What theoretical guarantees exist for the KDE-based estimator?** The method relies on approximating conditional densities via KDE without formal justification; statistical properties (consistency, convergence rates) are unknown. *Evidence needed:* Asymptotic theory proving convergence to true conditional probability under sufficient data and appropriate bandwidth, or identifying failure conditions.
- **Can hybrid approaches with shadow modelling or adversarial training improve risk quantification?** It is unclear whether integrating KDE with other techniques (e.g., as features in a meta-classifier or as a regularizer) can improve detection while maintaining computational advantages. *Evidence needed:* Design and evaluation of specific hybrid architectures against both pure KDE and full shadow-model baselines across diverse datasets and generators.

## Limitations
- Gower’s distance implementation details (missing value handling, feature weighting) are unspecified, risking shifted distance distributions in replication.
- KDE kernel choice and bandwidth sensitivity are not fully explored; Scott’s rule may not generalize to all data scales, affecting separability.
- The Realistic Attack’s effectiveness heavily depends on auxiliary data matching the training data distribution, with no robustness analysis to covariate shift.
- ROC findings demonstrating worst-case leakage are shown for select cases; systematic validation across broader scenarios is needed to confirm generalizability.

## Confidence
- **High:** KDE-based probabilistic membership inference mechanism. Formal derivation (Prop 3.1) and consistent empirical gains over baseline support this.
- **Medium:** Realistic Attack with pseudo-labeling. Mechanism is plausible but empirical evidence on auxiliary data quality is limited.
- **Medium:** ROC reveals hidden high-risk leakage. Supported by selected case studies but requires systematic validation.

## Next Checks
1. **Ablation on bandwidth:** Vary KDE bandwidth (0.5×, 1×, 2× Scott’s rule) across all dataset‑generator pairs to measure stability of F1 and ROC shapes.
2. **Auxiliary data shift simulation:** Introduce controlled distributional shifts in auxiliary data (e.g., feature prevalence bias) and quantify impact on Realistic Attack F1.
3. **Gower distance encoding comparison:** Re‑compute distances using alternative categorical encodings (one‑hot vs. integer) and compare resulting KDE separability to assess encoding sensitivity.
