# KTCF: Actionable Recourse in Knowledge Tracing via Counterfactual Explanations for Education

## Quick Facts
- **arXiv ID:** 2601.09156
- **Source URL:** https://arxiv.org/abs/2601.09156
- **Reference count:** 34
- **Primary result:** KTCF generates actionable, minimal counterfactual changes to past incorrect responses, guided by a KC relationship graph, achieving 5.7%–34% relative improvements in validity and sparsity over baselines while guaranteeing 0% unactionable suggestions.

## Executive Summary
Knowledge Tracing (KT) models predict student mastery but often lack interpretable, student‑focused explanations. KTCF addresses this gap by producing counterfactual explanations that specify the smallest set of previously incorrect responses a student should change to turn a wrong prediction into a correct one for a target knowledge concept. The method incorporates a knowledge concept (KC) relationship graph to keep suggestions pedagogically coherent and applies an actionability mask so that only originally incorrect answers can be altered. A post‑processing step then orders the recommended KCs into a low‑burden learning sequence using a path‑optimization algorithm. On the large‑scale XES3G5M dataset, KTCF significantly outperforms standard counterfactual baselines (Wachter, DiCE) on validity and sparsity, eliminates unactionable suggestions entirely, and yields qualitatively better learning paths. Results hold across multiple KT architectures (DKT, DKVMN, SAKT).

## Method Summary
KTCF consists of two stages. First, a counterfactual generator optimizes a binary response matrix \(R_{cf}\) for a given student history \(X_{orig}\) and target KC. The loss combines: (1) a prediction loss (cross‑entropy encouraging the KT model to output a correct prediction), (2) a sparsity loss (Hamming distance to \(X_{orig}\)), and (3) a KC‑coherence loss that penalizes modifications to KCs far from the target in a pre‑defined undirected KC graph \(G_{kc}\). An actionability mask ensures only originally incorrect responses are changed. Optimization proceeds via Adam for 200 iterations. Second, post‑processing takes the set of modified KCs, computes all‑pairs shortest‑path distances in \(G_{kc}\), builds a complete weighted graph, and solves a greedy Hamiltonian path problem starting from the target KC. The reversed path becomes the ordered instruction sequence, minimizing total study burden as approximated by graph distances.

## Key Results
- **Validity & Sparsity:** KTCF achieves 5.7%–34% relative improvements over Wachter and DiCE baselines on validity and sparsity metrics.
- **Actionability:** KTCF guarantees 0% unactionable suggestions; baselines show up to 61.7%.
- **Coherence & Burden:** Qualitative analysis shows KTCF recommends fewer, more topically related KCs with a lower total path distance (26 vs. 66, 79) after post‑processing.

## Why This Works (Mechanism)

### Mechanism 1: KC Graph‑Guided Coherence
- **Claim:** Incorporating a predefined KC relationship graph into the counterfactual optimization improves validity and sparsity by ensuring pedagogical coherence.
- **Mechanism:** A penalty term \(L_{kc}\) sums the shortest path distances in the KC graph between each modified KC and the target KC. This steers the optimization toward changes on KCs that are closely related (shorter path) to the target.
- **Core assumption:** \(G_{kc}\) accurately encodes meaningful prerequisite or dependency relationships, and shortest path distance is a valid proxy for pedagogical relevance.
- **Evidence anchors:** Abstract mentions “guided by a knowledge concept (KC) relationship graph”; Section 3.2 defines \(L_{kc}\); Table 1 shows validity/sparsity gains. The reference corpus lacks KC‑graph‑specific counterfactuals, underscoring novelty.
- **Break condition:** If \(G_{kc}\) is incomplete, incorrect, or missing crucial edges, the penalty may misguide the optimization, reducing validity or coherence.

### Mechanism 2: Strict Actionability Mask
- **Claim:** Enforcing a binary mask that only allows modification of originally incorrect responses eliminates unactionable suggestions, which is critical for educational utility.
- **Mechanism:** A mask \(m\) is defined with \(m_t = 1\) iff the original response \(r_t^{orig}\) was incorrect. During updates, \(R_{cf}\) is multiplied element‑wise by \(m\) and combined with the original correct responses, ensuring no change to originally correct items.
- **Core assumption:** Students should not be told to “un‑learn” a correct skill; recourse must involve fixing previous errors only.
- **Evidence anchors:** Abstract reports 0% unactionable suggestions; Section 3.2 states the mask enforces complete actionability; Table 1 shows zero unactionability for all KTCF variants.
- **Break condition:** If the KT model’s original prediction for a response is wrong but the student actually answered correctly (model error), the mask would incorrectly forbid changing that item, conflating model and student mastery.

### Mechanism 3: Path‑Optimization Post‑Processing
- **Claim:** Ordering the counterfactual KCs via a Traveling Salesman Path Problem (TSPP) yields a low‑burden learning sequence.
- **Mechanism:** After obtaining the set \(V_{CF}\) of KCs to change, a complete subgraph \(G'_{kc}\) is built with edge weights equal to shortest‑path distances in \(G_{kc}\). A greedy Hamiltonian path starting at the target KC is found; its reverse provides the instruction order, minimizing cumulative transition cost (study burden).
- **Core assumption:** Shortest‑path distance in \(G_{kc}\) approximates cognitive effort for transitioning between two KCs, and a Hamiltonian path minimizes total burden for visiting all necessary KCs.
- **Evidence anchors:** Abstract mentions “post‑processing step … orders these KCs into a low‑burden learning sequence via a path‑optimization algorithm”; Algorithm 2 details the TSPP; Table 2 shows KTCF’s total path distance (26) is far lower than baselines (66, 79).
- **Break condition:** The model assumes study burden is additive and pairwise. This may fail if learning interactions are non‑linear (e.g., order effects beyond consecutive pairs) or if the KC graph’s distances do not correlate with actual transition costs.

## Foundational Learning
- **Knowledge Tracing (KT):** A machine learning task that models student knowledge state over time by taking a sequence of (knowledge concept, response) pairs and predicting future performance. *Why needed?* KTCF explains a KT model’s predictions; understanding KT is essential to grasp what is being explained. *Quick check:* Given a history `[(kc1, correct), (kc2, incorrect)]`, what does a KT model output for the probability of correctness on `kc3` at the next timestep?
- **Counterfactual Explanations & Algorithmic Recourse:** These generate minimally altered inputs that change a model’s prediction, supporting actionable advice. *Why needed?* KTCF produces counterfactuals as student recommendations; the core goal is finding \(x'\) such that \(f(x') = y'\) with feasible changes. *Quick check:* How does a counterfactual explanation differ from a feature importance explanation (e.g., SHAP) when advising a student?
- **Graph‑based Pathfinding (Dijkstra, TSP):* Algorithms for computing shortest paths and ordering visits across nodes. *Why needed?* KTCF uses a KC graph to enforce coherence (via shortest‑path distances) and to order recommendations (via Hamiltonian path). *Quick check:* If you must visit KCs {A, B, C} starting from target T, what problem are you solving to minimize total graph distance?

## Architecture Onboarding
- **Component map:**  
  Trained KT Model (f) → Counterfactual Generator → Post-processor → Ordered Learning Sequence  
  KC Relationship Graph \(G_{kc}\) → (used by) Counterfactual Generator & Post-processor  
  Student History \(X_{orig}\) & Target KC → Counterfactual Generator  
  (Generator outputs modified response matrix \(R_{cf}\) and set of KCs to change)

- **Critical path:** From a student history and a selected target KC (incorrect, low predicted mastery), the Counterfactual Generator produces a set of KCs to correct (minimal changes). The Post‑processor then converts this set into an ordered instruction sequence optimized for low study burden.

- **Design tradeoffs:**  
  - **Sparsity vs. Validity:** Increasing \(\lambda_{spar}\) promotes fewer changes but may lower validity.  
  - **KC Coherence vs. Sparsity:** Larger \(\lambda_{kc}\) enforces stronger pedagogical coherence but may increase the number of suggested changes.  
  - **Computational cost:** TSPP scales as \(O(|V_{CF}|^2 (|V_{kc}|+|E|)\log|V_{kc}|)\), but remains feasible because \(|V_{CF}|\) is kept small by sparsity objectives.

- **Failure signatures:**  
  - **High Actionability Rate (>0):** Mask implementation flawed or optimization pushes changes to originally correct responses.  
  - **Low Validity (<0.8):** Optimization failed to flip prediction; check hyperparameters (\(\lambda_{kc}\), \(\lambda_{spar}\)), convergence, or KT model decision boundary.  
  - **Large \(|V_{CF}|\) / High Sparsity:** Indicates \(\lambda_{kc}\) too low or KC graph too dense; review penalty strength.  
  - **Irrelevant KC suggestions:** May stem from inaccurate \(G_{kc}\) or incorrect target KC selection.

## Open Questions the Paper Calls Out
- **Impact on actual learning outcomes:** The paper does not evaluate whether KTCF’s explanations lead to improved knowledge acquisition in real classrooms; a user study is needed.  
- **Role of LLMs in instruction generation:** The current post‑processing uses a graph algorithm, but LLMs might produce more natural, context‑aware educational instructions; this potential is unexplored.  
- **Sensitivity to initialization strategies:** The optimization’s stochastic nature may cause instability across different initialization methods; robust initialization techniques are required.  
- **Dependency on KC graph quality:** The method relies on an external KC relationship graph; the effect of graph completeness and accuracy on explanation quality remains unexamined.

## Limitations
- **Uncertainty about KC graph construction:** The source and exact definition of edges in \(G_{kc}\) are unclear; an inaccurate graph could undermine coherence guarantees.  
- **Heuristic target KC selection:** Using the last incorrect response as the target may miss more critical learning gaps; alternative strategies are unexplored.  
- **TSPP greedy tie‑breaking unspecified:** The post‑processing algorithm’s tie‑breaking rule is not detailed, affecting reproducibility and ordering stability.  
- **Actionability assumes KT predictions are correct:** The mask treats model errors as student mastery, which could be problematic if the KT model is inaccurate.  
- **Evaluation limited to XES3G5M:** Generalizability to other datasets, KT architectures, or educational domains has not been demonstrated.

## Confidence
- **Improved validity/sparsity vs. baselines:** Medium (quantitative support strong but depends on graph quality and baseline replication).  
- **0% unactionable suggestions:** High (the mask enforces this by construction; only implementation errors could break it).  
- **Lower path distance & coherent sequences:** Medium (qualitative evidence promising but based on small samples; the mapping from graph distance to study burden is untested).

## Next Checks
1. **Ablate \(\lambda_{kc}\):** Set \(\lambda_{kc}=0\) to measure the contribution of the KC‑graph coherence term to validity, sparsity, and coherence.  
2. **Disable actionability mask:** Run KTCF without the mask and check whether unactionable suggestions appear, confirming the mask’s necessity.  
3. **Compare TSPP against random Hamiltonian paths:** Generate random orderings of the same KC set and compare total path distances and human ratings of coherence to validate the greedy TSPP benefit.
