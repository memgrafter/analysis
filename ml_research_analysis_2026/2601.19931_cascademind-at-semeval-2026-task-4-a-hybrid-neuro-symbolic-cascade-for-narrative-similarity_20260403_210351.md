# CascadeMind at SemEval-2026 Task 4: A Hybrid Neuro-Symbolic Cascade for Narrative Similarity

## Quick Facts
- **arXiv ID:** 2601.19931
- **Source URL:** https://arxiv.org/abs/2601.19931
- **Reference count:** 15
- **Primary result:** A hybrid neuro-symbolic cascade achieved 72.75% test accuracy (11th of 47 teams) by routing narrative similarity cases based on LLM vote consensus and using a symbolic ensemble only for perfect ties.

## Executive Summary
CascadeMind tackles the SemEval-2026 Task 4 challenge of determining which of two candidate stories is more similar to an anchor narrative. It introduces a confidence-aware cascade that first samples multiple parallel decisions from an LLM. Cases with a strong consensus (a supermajority of ≥7 out of 8 votes) are resolved immediately with high accuracy and low cost. Ambiguous cases receive more computational attention via additional voting rounds. A deterministic, theory-grounded symbolic ensemble acts as a tiebreaker for the small fraction of cases that result in a perfect neural vote tie. On the development set, this approach achieves 81.0% accuracy with an average of 1.78 LLM calls per case. The official test accuracy is 72.75%. Analysis indicates that most performance gains stem from the neural voting escalation strategy rather than the symbolic component, highlighting the effectiveness of adaptive computation for narrative ambiguity.

## Method Summary
CascadeMind processes a triplet (anchor story, story A, story B) through a multi-stage pipeline. First, it uses the Gemini 2.5 Flash model with `candidateCount=8` and temperature 1.0 to generate 8 parallel binary votes ("A" or "B"). A router checks for a supermajority (≥7 votes for one option). If found, that decision is output immediately. Otherwise, the system escalates by performing three more `candidateCount=8` calls, aggregating all 32 votes, and taking a simple majority. If this aggregated vote results in a perfect tie (16-16), a symbolic ensemble is invoked. This ensemble computes five hand-crafted narrative similarity signals (TF-IDF cosine, story grammar alignment, semantic embedding cosine, tension curve correlation, event chain longest common subsequence) with weights pre-optimized via differential evolution on a synthetic training set. The option with the higher weighted sum is selected. The prompt requests a JSON decision with a "decision" field set to "A" or "B".

## Key Results
- On the development set (cascade subset), CascadeMind achieves 81.0% accuracy using an average of 1.78 LLM calls per case.
- Performance varies significantly by pathway: 85% accuracy for the cheap supermajority route (74% of cases), 67% for escalated majority (21% of cases), and 61% for symbolic tie resolution (5% of cases).
- The official SemEval-2026 test set accuracy is 72.75%, ranking 11th among 47 teams.

## Why This Works (Mechanism)
### Mechanism 1
The system treats the distribution of votes from multiple LLM samples as a reliable proxy for case difficulty. It samples 8 initial votes; if one option receives a supermajority (≥7 votes), it is accepted immediately as a confident prediction. Otherwise, the case is escalated with 24 additional votes for a total of 32, and a simple majority decides. This creates a difficulty gradient where high-consensus cases are resolved cheaply and accurately, while low-consensus cases receive more computational attention. The core assumption is that LLM vote entropy correlates with inherent narrative ambiguity and lower expected accuracy. Evidence includes a clear performance gradient: supermajority accuracy (85%) on 74% of cases, escalated majority (67%) on 21%, and symbolic tie (61%) on 5%. The break condition is if vote distributions fail to correlate with accuracy, causing miscalibrated routing.

### Mechanism 2
A symbolic ensemble of five theory-grounded narrative similarity signals acts as an effective tiebreaker for the subset of cases where neural voting produces a perfect tie (16-16 after 32 votes). The signals—lexical overlap, story grammar alignment, semantic embeddings, tension curve correlation, and event chain similarity—are combined with pre-optimized weights. This provides a deterministic, non-LLM fallback based on structured features. The assumption is that these complementary signals break ties more reliably than chance. Evidence: the tiebreaker achieves 61% accuracy on the 5% of development cases that reach a tie, versus a 53% baseline if applied indiscriminately. The break condition is if the signals are uninformative or negatively correlated with true similarity for tie cases, causing performance at chance level.

### Mechanism 3
The cascade's primary performance gain originates from the selective routing and voting escalation strategy rather than the sophistication of the symbolic tiebreaker. The system differentiates case difficulty via the supermajority threshold and applies more computational resources (more votes) only to the uncertain minority. The symbolic component's narrow application (5% of cases) means most accuracy gains (85% on 74% of data) come from the neural pathway's design. Evidence: comparisons show self-consistency (k=8) at 76.5% with 1.0 call versus CascadeMind at 81.0% with 1.78 avg calls, indicating marginal gain from escalation/routing. The break condition is if the cost of additional LLM calls outweighs the marginal accuracy gain over a single well-prompted vote, or if a simpler threshold-based abstention achieves a similar cost-accuracy tradeoff.

## Foundational Learning
- **Concept: Self-Consistency Decoding**  
  **Why needed here:** The entire cascade relies on sampling multiple independent LLM responses and aggregating them. Understanding that diversity in reasoning traces (enabled by temperature=1.0) can be aggregated for a more robust answer than a single sample is foundational.  
  **Quick check question:** If an LLM gives different answers to the same query when run multiple times with temperature > 0, what does a majority vote across samples aim to capture?

- **Concept: Selective Prediction / Abstention**  
  **Why needed here:** The supermajority threshold is a form of selective prediction—the system "opts out" (escalates) when its internal confidence (vote consensus) is low. This is a core design principle for handling uncertainty.  
  **Quick check question:** In a binary classification task, what is the trade-off when a model is allowed to abstain on a fraction of inputs instead of always making a prediction?

- **Concept: Neuro-Symbolic Integration (Cascade Model)**  
  **Why needed here:** The architecture embodies a specific neuro-symbolic pattern: neural components for broad, flexible perception (LLM votes), and symbolic components for focused, deterministic resolution (tiebreaker). This is distinct from tightly integrated neuro-symbolic systems.  
  **Quick check question:** In a cascade system where a neural model defers to a symbolic model only on certain conditions, what is a primary advantage and a primary risk of this "sequential" integration pattern compared to a "tightly coupled" one?

## Architecture Onboarding
- **Component map:**  
  LLM Voter -> Confidence Router -> Escalation Module -> Symbolic Tiebreaker
- **Critical path:**  
  Input (anchor, A, B) -> [Stage 1: 8 votes] -> [Stage 2: Router] -> (if supermajority) Output -> (else) [Stage 3: 24 more votes + majority] -> (if majority) Output -> (if tie) [Stage 4: Symbolic ensemble] -> Output.
- **Design tradeoffs:**  
  Cost vs. Coverage: Supermajority threshold (7/8) is conservative (74% resolved quickly). Lowering it increases cheap coverage but risks incorrect confident predictions.  
  Complexity vs. Interpretability: Adding the symbolic ensemble increases codebase complexity and dependency on external NLP libraries (spaCy, TextBlob), but provides a human-grounded, non-LLM fallback with traceable decisions.  
  Generalization vs. Optimization: Symbolic weights are optimized on synthetic training set (99.5% accuracy) but generalize poorly to real/hard test cases (61% on ties), indicating classic overfitting to source domain.
- **Failure signatures:**  
  High Tie Rate: >5% of escalated cases resulting in 16-16 ties suggests either LLM inconsistency or extremely ambiguous problem set.  
  Asymmetric Class Failure: Confusion matrix showing systematic bias (e.g., lower recall for "A-closer" class) suggests LLM prior or symbolic weight skew.  
  Collapse of Gradient: If escalated majority accuracy (67%) is not significantly lower than supermajority (85%), the confidence routing is not effectively separating easy/hard cases.  
  Synthetic-Real Gap: Large drop from symbolic ensemble's training accuracy (99.5%) to its tie-case accuracy (61%) indicates hand-crafted signals fail to capture true narrative similarity dimensions.
- **First 3 experiments:**  
  1. **Baseline Single Vote:** Run the prompt once (temperature=1.0) on the development subset. Measure accuracy and variance across 5 runs to establish raw LLM capability and stochastic baseline.  
  2. **Self-Consistency Without Routing:** Run 8 votes in parallel (1 API call), take majority. Compare accuracy and cost (1 call) to single vote to isolate the value of basic self-consistency.  
  3. **Symbolic Ensemble Alone:** Compute all 5 signals for every development case and predict using the optimized weights (no LLM). Measure accuracy to characterize standalone utility and confirm usefulness only in high-uncertainty contexts.

## Open Questions the Paper Calls Out
### Open Question 1
Why does the symbolic Multi-Scale Narrative Analysis Ensemble, which achieves 99.5% accuracy on the synthetic training set, perform so poorly (61% accuracy) on the genuinely ambiguous cases (perfect ties) in the development set? The paper highlights this domain mismatch but does not diagnose specific failure modes of the symbolic signals on real-world data. Evidence needed: a fine-grained ablation study on the development-set tie cases, evaluating each signal's standalone accuracy and their combinations, correlated with narrative characteristics.

### Open Question 2
What is the root cause of the asymmetric classification error, specifically the lower recall (68.8%) for the "A-closer" class compared to the "B-closer" class (77.6%)? The paper identifies the symptom but does not investigate its cause, which could stem from the neural voting mechanism, symbolic ensemble weighting, or dataset biases. Evidence needed: a dataset audit for label/narrative imbalances, a controlled study isolating the neural component's raw vote distribution, and testing if the bias persists when the symbolic tiebreaker is disabled.

### Open Question 3
Can the neural confidence estimation (vote distribution) be improved to better correlate with true ambiguity, thereby reducing the 5% of cases that end in perfect ties and require the less accurate symbolic intervention? The paper's premise is that vote consensus tracks difficulty, but the occurrence of ties suggests imperfect calibration. Evidence needed: experiments varying the supermajority threshold and analyzing the accuracy-coverage trade-off, and using alternative uncertainty metrics (e.g., vote entropy) to predict ties and adjust escalation.

### Open Question 4
To what extent does the synthetic SemEval-2026 training data (LLM-generated) contribute to the significant development-to-test generalization gap (81.0% vs. 72.75%), and can data augmentation or fine-tuning on human-labeled data mitigate this? The paper hypothesizes domain mismatch but does not quantify the synthetic data's role. Evidence needed: direct feature distribution comparisons between synthetic and human sets, ablation experiments re-optimizing symbolic weights on a human-labeled dev subset, and fine-tuning the base LLM on human-labeled training stories.

## Limitations
- **Synthetic-Real Domain Gap:** Symbolic weights optimized on synthetic training data (99.5% acc) collapse on real ties (61%), indicating poor generalization of hand-crafted narrative signals.
- **Critical Artifact Missing:** The exact list of 47 narrative action verbs for event chain extraction is unreported, hindering faithful replication of a key symbolic signal.
- **API Volatility:** Gemini 2.5 Flash’s stochastic behavior and potential version drift threaten the stability of vote distributions and routing calibration.

## Confidence
- **High Confidence:** Vote-based confidence routing separates case difficulty (85% vs. 67% accuracy gradient). Evidence is internal and consistent.
- **Medium Confidence:** Symbolic tiebreaker provides marginal utility on ties (61% vs. random baseline). Generalization from synthetic to real data is weakly supported.
- **Medium Confidence:** Primary gains originate from neural escalation, not symbolic sophistication. Ablation shows small incremental benefit from the full cascade over self-consistency.

## Next Checks
1. **Replicate Symbolic Weight Optimization:** Using default differential evolution (pop=50, gens=200) on the provided synthetic training split, verify if recovered weights match reported values (w1=0.49,...). Significant deviation indicates unpublished tuning.
2. **Test Tiebreaker on Real Tie Subset:** Apply the fixed symbolic ensemble to all development cases, then filter to only the 16–16 tie subset. Compare accuracy to paper’s 61%. A result near 50% confirms catastrophic domain overfit.
3. **Ablate Symbolic Component:** Run the full neural voting cascade (32 votes) but replace the symbolic tiebreaker with a random choice for perfect ties. Measure overall accuracy drop. If drop is <0.5%, symbolic contribution is negligible.
