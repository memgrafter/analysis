# Abnormalities and Disease Detection in Gastro-Intestinal Tract Images

## Quick Facts
- **arXiv ID:** 2603.22378
- **Source URL:** https://arxiv.org/abs/2603.22378
- **Reference count:** 0
- **Primary result:** Achieved an F1-score of 0.91 on Kvasir V2 at 41 FPS using a hybrid feature and GA-boosted framework.

## Executive Summary
This research presents a real-time framework for detecting abnormalities in gastrointestinal (GI) endoscopic images. It addresses key challenges like class imbalance, image reflections, and visual similarity between conditions. The core method combines traditional texture features with deep features from MobileNet V2, followed by a neural network classifier. To handle uneven class probability distributions, a Genetic Algorithm optimizes class-specific decision thresholds. The system demonstrates high accuracy (F1-scores up to 0.93) while maintaining sufficient speed (41 FPS) for clinical use, providing a comprehensive pipeline from preprocessing to classification.

## Method Summary
The pipeline begins with preprocessing: reflection removal via the Telea algorithm and data augmentation to mitigate class imbalance. Features are extracted in parallel: a set of manually selected texture descriptors (LBP, GLCM, Tamura, etc.) and a 1280-dimensional vector from MobileNet V2. A Random Forest selects the most discriminative subset from this combined feature set. A three-layer neural network (64-64-Sigmoid) trained with Nadam serves as the core classifier. Finally, a Genetic Algorithm (GA-Boost) learns optimal per-class probability thresholds on a validation set to maximize F1-score. For segmentation tasks, an ensemble of UNet/ResUNet++ models with majority voting is employed.

## Key Results
- F1-score of **0.91** on the Kvasir V2 dataset while processing **41 frames per second**.
- F1-score of **0.93** on the DowPK clinical dataset.
- The hybrid feature approach with GA-Boost thresholding outperformed individual feature sets and fixed thresholds.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Hybrid feature extraction (texture + deep) captures complementary information, improving classification accuracy for GI abnormalities.
- **Mechanism:** Two parallel channels: traditional texture features (LBP, GLCM) capture local patterns and edges, while MobileNet V2 provides hierarchical semantic representations. Features are concatenated before classification.
- **Core assumption:** Single feature types are insufficient for GI image variability; texture features capture fine-grained patterns missed by deep features, especially with limited data.
- **Evidence anchors:** [abstract] describes hybrid combination; [section 4.3] details separate extraction and fusion pipelines; neighbor papers show hybrid effectiveness in medical imaging.
- **Break condition:** If texture and deep features show high correlation (>0.9) across all classes, suggesting redundancy.

### Mechanism 2
- **Claim:** Class-specific threshold optimization via Genetic Algorithm (GA-Boost) adapts decision boundaries for each class, accommodating varying probability distributions.
- **Mechanism:** GA evolves threshold values (0.0-1.0) per class over 20 generations with population 10 and 20% mutation, maximizing F1-score using a Decision Tree classifier on combined features.
- **Core assumption:** A single threshold (e.g., 0.5) cannot optimally separate all classes due to imbalances in feature space density.
- **Evidence anchors:** [abstract] mentions GA-Boost; [section 4.3.6] details GA operators; [Table 5.11] shows varied thresholds (e.g., 0.6 for "retroflex-rectrum" vs. 0.2 for "esophagitis").
- **Break condition:** If all classes converge to near-identical thresholds (within 0.05), indicating uniform distributions.

### Mechanism 3
- **Claim:** Real-time performance is achieved by MobileNet V2’s lightweight architecture and efficient feature engineering, enabling 41 FPS without accuracy loss.
- **Mechanism:** MobileNet V2 uses depthwise separable convolutions to reduce computation. Pre-computed texture features and a small final classifier (3 dense layers) minimize overhead.
- **Core assumption:** Medical real-time applications require >30 FPS; MobileNet V2 meets this on CPU while maintaining accuracy versus heavier models.
- **Evidence anchors:** [abstract] states 41 FPS; [section 4.3.4] confirms MobileNet V2 speed; [section 2.2.6] compares efficiency with ResNet/DenseNet.
- **Break condition:** If computational budget increases or accuracy drops below clinical threshold (F1<0.95), trade-offs may need reevaluation.

## Architecture Onboarding
- **Component map:** Input -> Reflection Removal (Telea) -> Augmentation -> Feature Extraction (Parallel: Texture + MobileNet V2) -> Feature Selection (Random Forest) -> Ensemble Classification (Decision Tree/Random Forest/Extra Trees) -> GA-Boost Thresholding -> Probability Outputs -> Final Class (argmax). For segmentation: UNet/ResUNet++ with attention -> Majority Voting Ensemble.
- **Critical path:** Reflection removal quality directly impacts feature extraction accuracy; poor reflection handling cascades to misclassification.
- **Design tradeoffs:** Accuracy vs Speed (MobileNet V2 vs ResNet); Simplicity vs Robustness (single Decision Tree vs ensemble); Augmentation realism (simple transforms fast, GAN-based slow but realistic).
- **Failure signatures:** Low recall on rare classes -> augmentation ineffective or feature selection removed minority cues; High train but low validation accuracy -> overfitting from too many features; GA thresholds near 0 or 1 -> poor feature separation; Reflection removal artifacts -> over-aggressive Telea smoothing.
- **First 3 experiments:**
  1. Ablation: Compare F1-score with/without reflection removal on Kvasir V2.
  2. Feature ablation: Test performance using only texture or only deep features, especially on minority classes.
  3. Threshold validation: Compare GA-Boost thresholds vs fixed 0.5 threshold across all classes; measure per-class F1 delta.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** How can the proposed methods be adapted to other 2D medical imaging modalities (e.g., X-rays, histopathology slides) and extended to 3D volumetric data (e.g., CT, MRI) while maintaining detection accuracy and computational efficiency?
- **Basis in paper:** Sections 6.2.1 and 6.2.6 outline the need to apply frameworks beyond 2D GI images.
- **Why unresolved:** The thesis only evaluated 2D datasets. Other modalities require architectural changes and validation across diverse clinical scenarios.
- **What evidence would resolve it:** Repurposing the model on at least one non-GI 2D modality (e.g., chest X-rays) and one 3D dataset (e.g., abdominal CT), benchmarked against domain-specific SOTA.

### Open Question 2
- **Question:** What semi-supervised or active learning strategies can most effectively reduce dependence on labeled medical data for the proposed ensemble and deep learning approaches, without compromising abnormality detection performance?
- **Basis in paper:** Section 6.2.2 identifies limited labeled data as a bottleneck and suggests semi-supervised and active learning.
- **Why unresolved:** Current work still requires thousands of labels; optimal fusion of limited labels with unlabeled data for this architecture is unexplored.
- **What evidence would resolve it:** Integrating semi-supervised (pseudo-labeling, consistency) or active learning into training, measuring performance when reducing labeled data by 50-80%, and quantifying annotation cost savings.

### Open Question 3
- **Question:** How can interpretable and clinician-friendly explanations be generated for the decisions made by the proposed complex models, and how do these explanations impact clinical trust and decision-making?
- **Basis in paper:** Section 6.2.3 calls for enhancing model transparency for clinical adoption.
- **Why unresolved:** TreeNet and LiRE-CNN are black boxes; without explanations, clinicians cannot verify or learn from the system.
- **What evidence would resolve it:** Implement explanation methods (e.g., Grad-CAM, LIME) and conduct user studies with endoscopists to evaluate impact on confidence and diagnostic accuracy.

## Limitations
- **Hyperparameter gaps:** Core neural network training details (loss function, learning rate, batch size, regularization) are unspecified, blocking exact replication.
- **Feature extraction ambiguity:** Unclear whether MobileNet V2 was fine-tuned or frozen; precise extraction layer and reported 41 FPS lack hardware/batch context.
- **GA validation leakage risk:** Unknown if GA-Boost thresholds were tuned on held-out validation or test set, risking overfitting and inflated metrics.

## Confidence
- **Hybrid Feature Efficacy:** Medium. Supported by pipeline description and neighbor trends, but break condition (feature correlation check) is unvalidated.
- **GA-Boost Thresholding:** Medium. Mechanism and per-class threshold variance ([Table 5.11]) are clear, but confidence reduced by unknown validation strategy and overfitting risk.
- **Real-Time Performance:** High. 41 FPS claim is explicit and tied to MobileNet V2’s architecture, though hardware specifics are needed for absolute certainty.
