# Long-Term Multi-Session 3D Reconstruction Under Substantial Appearance Change

## Quick Facts
- **arXiv ID:** 2602.20584  
- **Source URL:** https://arxiv.org/abs/2602.20584  
- **Reference count:** 40  
- **Primary result:** Enforcing cross-session correspondences directly in joint SfM, with hybrid SIFT/LightGlue matching and VPR-guided selectivity, achieves a median reprojection error of 3.65 pixels on multi-year coral reef data—improving by over 95% versus post-hoc alignment baselines—and successfully integrates all sessions into a coherent reconstruction where others fail.

## Executive Summary
Reconstructing 3D models across multiple imaging sessions separated by years, such as coral reef monitoring, is hindered by substantial appearance change that breaks standard Structure-from-Motion (SfM) pipelines. This paper presents a method that enforces cross-session correspondences within a single joint SfM optimization, rather than relying on post-hoc alignment of independently reconstructed sessions. It uses handcrafted SIFT features for dense intra-session matching and a learned matcher (LightGlue) for robust cross-session matching, with visual place recognition (VPR) selectively identifying candidate pairs to keep computational cost low. On 2016–2018 reef datasets, the approach reduces median reprojection error by 97.8% compared to ICP and 95.3% compared to BUFFER-X, and uniquely integrates all sessions into one consistent model.

## Method Summary
The pipeline processes multiple discrete imaging sessions by first computing global descriptors for all images using MegaLoc VPR. For each image, VPR retrieves a small set of top candidate images from other sessions likely to share spatial overlap. Within each session, exhaustive SIFT matching builds a reliable local reconstruction. Cross-session matching is then performed only on the VPR-proposed candidate pairs using LightGlue, a learned feature matcher robust to appearance change. All intra- and cross-session matches are combined and fed into a modified COLMAP backend that executes a single joint bundle adjustment, simultaneously optimizing camera poses and 3D points across all sessions. This joint optimization directly couples sessions through explicit cross-session constraints, yielding a unified coordinate frame coherent across years.

## Key Results
- Median reprojection error of 3.65 pixels, a 97.8% improvement over ICP (165.26 pixels) and 95.3% over BUFFER-X (77.11 pixels).
- Successfully integrates all survey sessions into a single coherent 3D reconstruction where baseline methods fail or produce fragmented results.
- VPR-guided selective matching reduces total matching time by 95.5% and yields a tighter error distribution than exhaustive learned matching.

## Why This Works (Mechanism)

### Mechanism 1: Joint SfM with explicit cross-session constraints
Independent per-session SfM optimizes each session in isolation, then post-hoc alignment (e.g., ICP) attempts to merge coordinate frames using only geometric overlap, which fails under large appearance change. By enforcing cross-session 2D-3D and 3D-3D constraints *during* a single joint bundle adjustment, the optimization directly couples all sessions. Shared geometry must explain observations from every visit, aligning sessions within one globally consistent model. This requires sufficient cross-session visual overlap to establish correct correspondences. Evidence: Table II and Figure 6 show dramatic reprojection error reduction when cross-session constraints are included during optimization versus post-hoc alignment.

### Mechanism 2: Hybrid intra-session (SIFT) and cross-session (LightGlue) matching
Within a single survey session, images are captured near-simultaneously, so appearance variation is low. Exhaustive SIFT matching is fast, deterministic, and dense. Across years, coral appearance changes substantially; SIFT matches degrade. Learned matchers like LightGlue are more robust to such change but computationally expensive. Using SIFT for intra-session and LightGlue only for inter-session optimizes the trade-off: fast dense intra-session reconstruction provides a strong local frame, while targeted robust cross-session matching provides the long-term links. Evidence: Figure 9 shows SIFT is fastest per image; adding LightGlue increases time but is necessary for cross-session success. The hybrid approach achieves the best error/time trade-off.

### Mechanism 3: VPR-guided selective matching for efficiency and accuracy
Exhaustively matching all cross-session image pairs with LightGlue scales quadratically and introduces many spurious matches from non-overlapping pairs. VPR (MegaLoc) computes a global descriptor per image and retrieves a small set of top candidates likely to overlap spatially. Learned matching is run only on these candidate pairs. This reduces matching time by ~95.5% and improves accuracy (median error 3.65 vs 6.33 for exhaustive learned matching) because VPR filtering discards many non-overlapping pairs that would add noise to the SfM optimization. Evidence: The ablation in Figure 9 shows VPR filtering both speeds up matching and tightens the error distribution.

## Foundational Learning
- **Structure-from-Motion (SfM) pipeline fundamentals**  
  Standard SfM reconstructs 3D structure from unordered images by matching features and optimizing camera poses and 3D points via bundle adjustment. Understanding this is essential to see how adding cross-session edges alters the optimization.  
  *Quick check:* What happens in incremental SfM if an image has no matches to the existing reconstruction? How does adding a single correct cross-session match affect the global bundle adjustment?

- **Feature matching paradigms (handcrafted vs. learned)**  
  Handcrafted features (SIFT) are fast and deterministic but sensitive to illumination and viewpoint change; learned matchers (LightGlue) generalize better to appearance shift but are slower. The hybrid approach leverages complementary strengths.  
  *Quick check:* Why might SIFT fail to match a coral patch imaged years apart, while LightGlue might succeed? What is the primary computational bottleneck in LightGlue?

- **Visual Place Recognition (VPR) as a retrieval filter**  
  VPR uses global image descriptors to find images with similar overall appearance, providing coarse spatial overlap candidates. It is not a precise geometric match but efficiently filters pairs for expensive learned matching.  
  *Quick check:* What image properties does a VPR global descriptor capture? Why can’t VPR matches replace geometric inliers directly?

## Architecture Onboarding
Component map:  
Multi-session RGB images -> VPR Module (MegaLoc) -> Hybrid Matching Module (intra-session SIFT + cross-session LightGlue on VPR candidates) -> Joint SfM Backend (modified COLMAP) -> Unified 3D point cloud & camera poses

Critical path: VPR computes descriptors and retrieves top-k cross-session candidate pairs per image -> LightGlue matching applied only to those candidate pairs -> All matches (intra-session SIFT + cross-session LightGlue) combined -> Joint bundle adjustment in modified COLMAP produces a single coherent reconstruction.

Design tradeoffs:
- SIFT vs. LightGlue coverage: SIFT is fast and dense but brittle to appearance change; LightGlue is robust but slow. The design assumes intra-session appearance is stable enough for SIFT.
- VPR recall vs. precision: Higher top-k improves recall (more true cross-session pairs) but increases matching cost and potential noise; the paper’s selection balances this.
- Joint vs. independent reconstruction: Joint optimization ensures global consistency but requires holding the entire reconstruction graph in memory, which may limit scalability.

Failure signatures:
- Fragmented reconstruction: Individual sessions remain separate, indicating insufficient cross-session matches to connect the graph.
- High reprojection error on annotated cross-session pairs: Misalignment between sessions visible in error distributions (e.g., Figure 6).
- Coarse but not pixel-accurate alignment: Post-hoc ICP may produce overlapping point clouds, but reprojection errors remain high, revealing geometric misalignment.

First 3 experiments:
1. **Post-hoc vs. Joint:** Reconstruct each session independently with COLMAP, then align via ICP/BUFFER-X. Compare to joint reconstruction with enforced cross-session matches. Measure reprojection error on manually annotated cross-session pairs.
2. **Baseline Joint Methods:** Run standard COLMAP with exhaustive SIFT on all images (joint), and MapAnything (end-to-end learned). Compare to proposed method. Measure reconstruction completeness (all sessions integrated?) and qualitative coherence.
3. **Ablation: VPR Selectivity:** Compare matching time and reprojection error for four configurations: (a) SIFT only, (b) SIFT + exhaustive LightGlue (all pairs), (c) SIFT + LightGlue (only cross-session pairs), (d) SIFT + LightGlue (only VPR-filtered cross-session pairs).

## Limitations
- **Domain specificity:** Evaluation solely on coral reef multi-year surveys; unknown if the approach generalizes to other environments (e.g., urban, indoor, seasonal forests).
- **VPR dependency:** Reconstruction succeeds only if VPR finds sufficient cross-session candidates; sensitivity to recall/precision trade-offs and failure modes are not thoroughly studied.
- **Scalability:** Memory and computational cost of joint bundle adjustment for many sessions are not reported; may become prohibitive as session count grows.

## Confidence

- **Claim B** (Hybrid SIFT+LightGlue matching provides robust and efficient correspondences): Medium  
- **Claim C** (VPR-guided selective matching improves speed and accuracy over exhaustive learned matching): Medium  

## Next Checks
1. **Cross-domain generalization:** Apply the full pipeline to at least two additional multi-session datasets from distinct domains (e.g., indoor home over months, city streets across seasons). Compare to ICP and BUFFER-X baselines using reprojection error to test if the >95% improvement holds beyond reefs.
2. **VPR sensitivity analysis:** Systematically vary the number of top-k VPR candidates (e.g., k = 1, 5, 10, 20, all). Measure reconstruction completeness, median reprojection error on cross-session pairs, and total matching time. Identify the recall threshold below which joint reconstruction fragments or degrades.
3. **Scalability stress test:** Using existing reef data or a synthetic multi-session generator, create collections with increasing session counts (e.g., 5, 10, 20, 30). Monitor peak memory consumption and bundle adjustment time. Determine whether computational growth is linear or super-linear and at which point the approach becomes impractical.
