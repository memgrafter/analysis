# Modality as Heterogeneity: Node Splitting and Graph Rewiring for Multimodal Graph Learning

## Quick Facts

- **arXiv ID**: 2602.00067
- **Source URL**: https://arxiv.org/abs/2602.00067
- **Reference count**: 16
- **Primary result**: NSG-MoE consistently improves node classification accuracy (e.g., +3.33% on MAGB, +1.03% on MM-Graph) and link prediction MRR (e.g., +0.60 on Amazon-Sports with ImageBind) over strong baselines.

## Executive Summary

Multimodal graph learning suffers from *modality confusion* during message passing: standard GNNs treat concatenated multimodal features as a single homogeneous vector, blurring distinct semantic spaces. NSG-MoE addresses this by **splitting each multimodal node into unimodal sub-nodes** and **rewiring the graph** to preserve intra‑modal structure while enabling controlled cross‑modal interactions. A **mixture of heterogeneous graph experts** then processes these distinct relational patterns, adaptively routing sub‑nodes to specialized branches. Theoretical analysis confirms adaptive low‑pass filtering in modality subspaces and a tighter generalization bound. Across three benchmarks (MAGB, MM‑Graph, ABIDE), NSG‑MoE yields consistent gains in node classification and link prediction while maintaining competitive training efficiency.

## Method Summary

**Preprocessing & NSG Construction**  
Given a multimodal graph \(G=(V,E,X)\) with node features spanning \(m\) modalities (e.g., text, image), each node’s feature vector is split into \(m\) unimodal parts and projected to a shared dimension \(d\) via linear layers. The new graph \(G^*=(V^*,E^*)\) is built:
- For each original node \(v\), create \(m\) sub‑nodes \((v,\text{mod}_i)\); connect them fully (intra‑node clique) to capture within‑entity modality correlations.
- For each original edge \((u,v)\), add inter‑node edges between sub‑nodes. Two variants:  
  • *Self‑type*: connects same‑modality sub‑nodes \((u,\text{mod}_i)-(v,\text{mod}_i)\).  
  • *Cross‑type*: connects different‑modality sub‑nodes \((u,\text{mod}_i)-(v,\text{mod}_j)\) for all \(i,j\).
- To control quadratic growth, an approximate minimum spanning tree (MST) sparsification (Algorithm 1) may be applied to intra‑node edges and/or inter‑node connections when \(m>2\).

**Modeling**  
Any heterogeneous GNN (e.g., HGT, HAN) can operate on \(G^*\). NSG‑MoE enhances this with a **Mixture of Experts**:
- Two expert groups: self‑type branch (trained on graphs with only self‑type inter‑node edges) and cross‑type branch (only cross‑type edges). Each expert is an independent heterogeneous GNN.
- A noisy top‑\(k_e\) gating function assigns each sub‑node to a small subset of experts across both groups; auxiliary *importance* and *load* balancing losses encourage diverse utilization.
- Sub‑node embeddings from selected experts are aggregated (weighted sum), then merged per original node by concatenation and a linear projection.
- A task‑specific head (classifier or link predictor) produces predictions.
- Training minimizes task loss plus \(\lambda (L_{\text{importance}} + L_{\text{load}})\) with Adam. Hyperparameters typically include LR \(\{5\text{e-}5,1\text{e-}4,2\text{e-}4\}\), weight decay \(\{0.0,1\text{e-}4\}\), layers \(L\in\{1,2,3,5\}\), hidden dim \(32\!-\!128\), attention heads \(1,2,4,8\), and \(\lambda=1\text{e4}\).

## Key Results

- Node classification accuracy gains: **+3.33%** relative on MAGB, **+1.03%** on MM‑Graph.
- Link prediction MRR gain: **+0.60** on Amazon‑Sports (using ImageBind features).
- Training efficiency remains competitive despite incorporating MoE components.

## Why This Works (Mechanism)

### Mechanism 1: Disentanglement via Splitting and Rewiring

- **Claim**: Node splitting and graph rewiring disentangle modalities by separating them into distinct unimodal nodes and carefully constructing edges that preserve intra‑modal structure while enabling controlled cross‑modal interactions.
- **Mechanism**: Each multimodal node is decomposed into \(m\) unimodal sub‑nodes. Intra‑node edges connect sub‑nodes of the same original node (within‑entity correlations). Inter‑node edges link sub‑nodes of neighboring original nodes; two variants: *self‑type* (same modality) and *cross‑type* (different modalities). This transforms a homogeneous multimodal graph into a heterogeneous unimodal graph, allowing message passing to operate in modality‑specific subspaces.
- **Core assumption**: Modality confusion in standard GNNs arises because concatenated multimodal features are treated as a single homogeneous vector, blurring distinct semantic spaces. By explicitly modeling modalities as separate node types and routing messages through modality‑preserving edges, discriminative signals are maintained.
- **Evidence anchors**: [Abstract]; detailed construction in Section 4; contrast with early‑fusion baselines (e.g., UniGraph2) shows clear architectural departure.
- **Break condition**: If intra‑modal homophily is extremely weak (same‑modality neighbors not semantically related) but cross‑modal relations are strong, self‑type edges may be insufficient. The inclusion of cross‑type edges mitigates this, but performance could suffer if both homophilies are low.

### Mechanism 2: Adaptive Routing with Mixture of Heterogeneous Graph Experts

- **Claim**: A Mixture of Heterogeneous Graph Experts (NSG‑MoE) adaptively routes nodes to specialized experts that process different relational patterns (self‑type vs. cross‑type connectivity), capturing both modality‑specific consistency and cross‑modal enrichment.
- **Mechanism**: Two expert groups operate on the self‑type and cross‑type NSG variants. Each expert is an independent heterogeneous GNN. A noisy top‑\(k\) gating function assigns each sub‑node to a small subset of experts across both groups. Auxiliary losses (importance and load balancing) encourage diverse specialization; the final representation is a weighted sum of expert outputs.
- **Core assumption**: A single GNN cannot optimally handle the diversity of relational structures introduced by node splitting; different nodes or modalities may benefit more from intra‑modal smoothing or cross‑modal contextualization. Expert specialization and adaptive routing overcome this limitation.
- **Evidence anchors**: [Abstract] “A mixture of heterogeneous graph experts then processes these distinct relational patterns.”; Section 6 (dual‑branch design, gating, balancing losses); Figure 5 shows modality‑expert alignment (text‑dominant nodes favor self‑type experts, visual nodes favor cross‑type); conceptual consistency with Graph‑MoE (hop‑based patterns) extended to modality‑induced heterogeneity.
- **Break condition**: If gating is poorly regularized (e.g., \(\lambda\) too low), expert collapse occurs (one expert dominates), reducing the model to a single expert and losing diversity. If \(\lambda\) too high, routing becomes uniform, blurring expert boundaries.

### Mechanism 3: Spectral and Generalization Advantages

- **Claim**: Spectral and information‑theoretic analyses reveal that NSG performs adaptive low‑pass filtering in modality‑specific subspaces and reduces mutual information between training data and parameters, yielding tighter generalization bounds.
- **Mechanism**: The coalesced heterogeneous GNN formulation yields a propagation matrix that diagonalizes into two subspaces:  
  – \(F_1\) capturing features shared across modalities,  
  – \(F_2\) encoding modality discrepancies.  
  The filter response differs: in \(F_1\) the gain increases with cross‑modal coupling \(\beta\); in \(F_2\) it decreases with \(\beta\). Thus the architecture adaptively smooths signals based on modality alignment. Moreover, the parameter space is restricted to block‑diagonal form (\(\Theta_{\text{NSG}} \subseteq \Theta_{\text{GNN}}\)), which by the data‑processing inequality reduces \(I(S;W)\) and therefore generalization error.
- **Core assumption**: The spectral behavior translates to improved representation quality and the parameter restriction strikes a beneficial bias‑variance trade‑off without overly limiting capacity.
- **Evidence anchors**: Section 5.2 (Equations 16–18 show frequency responses and \(\beta\) modulation); Section 5.3 (Markov chain argument and bound comparison); Section 7 empirical improvements over strong GNN baselines; theoretical alignment with recent spectral analyses of heterogeneous GNNs (e.g., Butler et al., 2023).
- **Break condition**: If the two modality subspaces are nearly collinear (modalities highly correlated), the distinction between \(F_1\) and \(F_2\) vanishes, and the adaptive filtering offers little advantage. The parameter restriction may then unnecessarily limit expressivity, causing underfitting.

## Architecture Onboarding

- **Component map**:  
  Original multimodal graph \(G\) with features \(X\) → NSG Construction (split nodes into unimodal sub‑nodes; add intra‑node edges; add inter‑node edges – self‑type and/or cross‑type; optional sparsification via MST) → Unimodal feature embeddings \(E\) (modality‑specific projections) → MoE Module (noisy top‑\(k\) gating routes sub‑nodes to a mix of self‑type and cross‑type experts; each expert is an independent heterogeneous GNN) → Expert outputs aggregated → Node Merging (concatenate sub‑node embeddings per original node, apply linear layer) → Task Readout (e.g., classifier or link predictor) → Predictions.

- **Critical path**: Data flows from \(G\) through NSG construction to \(E\). During training, the gating function selects experts for each batch; experts process \(E\) on their respective edge sets; outputs are combined; merged node embeddings feed the task head; total loss = task loss + \(\lambda(L_{\text{importance}} + L_{\text{load}})\).

- **Design tradeoffs**:
  - *Splitting vs. connectivity*: More modalities increase node/edge count quadratically; sparsification (MST) trades some connectivity for scalability and regularization.
  - *Edge type selection*: Self‑type edges exploit strong intra‑modal homophily; cross‑type edges provide complementary context but may introduce noise; dual‑branch MoE aims to get the best of both.
  - *Number of experts*: More experts increase capacity and specialization risk but also memory/computation; sparse activation (Top‑\(K\)) keeps cost moderate.
  - *Base HGNN choice*: Simpler HGNNs (e.g., SAGE‑h) are faster but less expressive; attention‑based (HGT) captures nuanced relations but needs more tuning.

- **Failure signatures**:
  - **Expert collapse**: Gating probabilities concentrate on one expert (check histogram). Remedy: increase \(\lambda\) or adjust noise scale.
  - **Over‑smoothing**: Sub‑node embeddings become too similar after several layers (high pairwise cosine similarity). Remedy: reduce layers, add residuals, increase intra‑node sparsity.
  - **Training instability**: Large swings in loss or gating entropy. May indicate inappropriate learning rate or \(\lambda\).
  - **Memory blow‑up**: When \(m\) is large and sparsification is disabled, edges grow \(O(m^2)\) leading to OOM. Monitor edge count during preprocessing.

- **First 3 experiments**:
  1. **Ablation of NSG structure**: Train a homogeneous GNN on the original multimodal graph vs. a homogeneous GNN on the NSG (no MoE). The latter should show improved accuracy, demonstrating the benefit of splitting/rewiring.
  2. **Edge configuration study**: Compare three NSG variants using the same HGNN backbone: (i) \(\Phi_{\text{intra}} \cup \Phi_{\text{self}}\), (ii) \(\Phi_{\text{intra}} \cup \Phi_{\text{cross}}\), (iii) \(\Phi_{\text{intra}} \cup \Phi_{\text{full}}\). Expect self‑type strongest, cross‑type sometimes helpful, full often no gain or slight drop – this validates Table 1 insight.
  3. **Gating specialization analysis**: After training NSG‑MoE, compute total gating probability per expert for each modality (sum over all sub‑nodes of that modality). Visualize as a bar plot (similar to Figure 5). Expect self‑type experts to have higher sum for text modality, while cross‑type experts favor visual modality, confirming adaptive routing.

## Open Questions the Paper Calls Out

- **Open Question 1**: How can the expert routing mechanism in NSG‑MoE be extended to handle dynamic graph structures or task‑adaptive settings?  
  **Basis**: Explicitly mentioned in the Conclusion (“Future work may explore extending the expert routing to dynamic or task‑adaptive settings”).  
  **Why unresolved**: Current routing uses a fixed noisy gating mechanism trained on a static task/dataset. Dynamic or task‑adaptive routing would require different gating designs that can respond to changing graph topologies or optimize for diverse downstream objectives.  
  **Resolving evidence**: Propose a dynamic routing architecture (e.g., meta‑learned or recurrent gating), evaluate on graphs with temporal evolution or multiple heterogeneous tasks, and demonstrate improved adaptability versus the fixed gating baseline.

- **Open Question 2**: How does NSG‑MoE perform when nodes have incomplete modality sets (missing modalities), which contradicts the paper’s assumption that all nodes share the same modalities?  
  **Basis**: Inferred from the explicit assumption in Section 3 (“In this work, we assume that all nodes share the same set of modalities”).  
  **Why unresolved**: Real‑world multimodal graphs often have missing modalities for some nodes. The node‑splitting mechanism may break down if certain nodes lack one or more modalities, creating uneven sub‑node structures and complicating message passing.  
  **Resolving evidence**: Extend NSG to handle variable modality sets (e.g., via learnable placeholder vectors or conditional edge construction), test on datasets with synthetic or real missing modalities, and analyze performance degradation patterns.

- **Open Question 3**: What are the scalability limits of NSG‑MoE when the number of modalities grows substantially beyond the 2–4 modalities studied in the experiments?  
  **Basis**: Inferred from the proposal of approximate MST sparsification to handle many modalities; empirical validation limited to a maximum of 4 modalities (ABIDE dataset); complexity analysis suggests \(O(m c_1 \log c_1)\) but remains untested for large \(m\).  
  **Why unresolved**: The performance of the approximate MST algorithm and the dual‑branch MoE design for sparse cross‑modal connections is unclear when modalities number in the tens or hundreds, where inter‑modal relationships become combinatorially complex.  
  **Resolving evidence**: Conduct systematic experiments with synthetic multimodal graphs having varying \(m\) (e.g., 5, 10, 20, 50), measure accuracy, convergence, and runtime, and analyze whether the sparsified structure preserves enough relational information.

- **Open Question 4**: How sensitive is NSG‑MoE to the quality of pre‑trained modality encoders, and can the framework be made more encoder‑agnostic?  
  **Basis**: Inferred from the use of CLIP, ImageBind, and MLLMs as frozen encoders; results vary with encoder choice but systematic study of encoder quality is lacking.  
  **Why unresolved**: The results mix encoder effects with architecture effects. If encoder alignment is poor (modalities in disjoint spaces), node splitting and rewiring might not recover meaningful cross‑modal relationships; this is not systematically studied.  
  **Resolving evidence**: Perform controlled experiments where modality alignment is deliberately degraded (e.g., using randomly initialized encoders or encoders trained on unrelated data), measure how NSG‑MoE’s performance degrades relative to baselines, and possibly design an end‑to‑end fine‑tuning variant.

- **Open Question 5**: How does the spectral behavior of NSG‑MoE change when moving beyond the linearized analysis to full non‑linear GNN operations with activation functions and residual connections?  
  **Basis**: Inferred from the theoretical analysis in Section 5 which uses a simplified linear HGNN to obtain closed‑form spectral results; real implementations use non‑linearities (ReLU), residual connections, and LayerNorms.  
  **Why unresolved**: Non‑linearities and normalization layers alter frequency response properties and may invalidate the neat separation into \(F_1\) (shared) and \(F_2\) (discrepancy) subspaces. Practical implications for modality disentanglement remain uncertain.  
  **Resolving evidence**: Empirical spectral analysis of trained non‑linear NSG‑MoE models (e.g., measuring effective filter shapes across layers), comparison with the linear prediction, and possibly extension of the theory to incorporate common non‑linear components.

## Limitations

- **Reproduction unknowns**: Missing details on training epochs, early stopping policy, batch size, negative sampling ratio for link prediction, and ABIDE feature extraction pipeline raise barriers to exact replication.
- **Scalability**: Node/edge count grows \(O(m^2)\) with modalities; sparsification via approximate MST trades connectivity for memory but may discard informative edges, especially for \(m > 4\).
- **Assumption sensitivity**: Benefits rely on strong intra‑modal homophily, well‑tuned MoE auxiliary losses to avoid expert collapse, and distinct modality subspaces for the spectral advantage; violations could degrade performance.

## Next Checks

1. **Homophily sensitivity test**: Compute intra‑modality homophily scores per dataset (e.g., average cosine similarity of same‑modality neighbors). Train NSG variants (self‑type, cross‑type, full) and correlate performance gaps with homophily levels.
2. **Gating dynamics audit**: Log gating probabilities per expert across training. Visualize distributions per modality; detect collapse (single expert > 90% usage) and adjust \(\lambda\) or noise scale accordingly.
3. **Spectral behavior measurement**: After training, input synthetic signals of controlled frequencies into the first layer; measure amplitude propagation through layers to confirm low‑pass filtering and its modulation by cross‑modal coupling \(\beta\).
