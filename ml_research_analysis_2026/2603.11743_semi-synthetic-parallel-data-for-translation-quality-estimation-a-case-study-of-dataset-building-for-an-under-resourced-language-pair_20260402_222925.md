# Semi-Synthetic Parallel Data for Translation Quality Estimation: A Case Study of Dataset Building for an Under-Resourced Language Pair

## Quick Facts
*   arXiv ID: 2603.11743
*   Source URL: https://arxiv.org/abs/2603.11743
*   Reference count: 0
*   Primary result: Large-scale random sampling (1-4M samples) achieved state-of-the-art Pearson correlation of 0.92 for English-Hebrew sentence-level QE, demonstrating that sheer data volume most effectively overcomes morphological complexity.

## Executive Summary
This study tackles the scarcity of reliable Quality Estimation (QE) data for the morphologically complex, under-resourced English-Hebrew language pair. The authors construct a large semi-synthetic parallel dataset by generating English sentences from learner usage examples via ChatGPT, translating them with multiple MT engines, and filtering for consensus. The core dataset is augmented through controlled error insertion (targeting gender/number agreement), adversarial negative sampling, and word-order perturbation, reaching ~400k segments. Training a LoRA-adapted BERT model reveals that QE performance is driven more by dataset scale than by perfect distribution: a uniformly distributed set (430k) significantly outperformed a normally distributed one (500k), but the best result (0.92 Pearson) came from large-scale random sampling (1-4M samples), highlighting the importance of extensive linguistic coverage for complex pairs.

## Method Summary
The core method is a multi-stage pipeline for semi-synthetic QE dataset construction. First, English source sentences are generated from a seed list of "usage examples" using ChatGPT 3.5. Each source is translated into Hebrew by three commercial MT engines (Google, Yandex, Microsoft). Segment pairs are retained only if all pairwise BLEU scores between the three Hebrew outputs are ≥0.85, and the highest-BLEU pair is selected as the consensus translation. These consensus pairs are manually annotated by proficient Hebrew linguists on a detailed 1-5 scale covering accuracy, linguistic quality, style, and functional equivalence. The final dataset is augmented by: 1) inserting controlled gender/number agreement errors into good translations (with score penalties), 2) creating adversarial mismatched English-Hebrew pairs (score 0), and 3) applying word-order perturbations (swaps, shifts, shuffles). Models are trained on subsets of this pool with different sampling strategies (uniform, normal, random) using a LoRA-adapted `bert-base-multilingual-cased` with a custom classification head, and evaluated via Pearson correlation on a held-out test set.

## Key Results
*   Dataset distribution critically impacts performance: a uniformly distributed training set (430k samples, balanced across scores 0-5) achieved a Pearson correlation of 0.88, vastly outperforming a normally distributed set of similar size (500k samples, 0.65), which suffered from the model's default tendency to predict the mean score.
*   Sheer data volume is the strongest driver: randomly sampling 1 million and 4 million segments from the full augmented pool (preserving natural skew) yielded Pearson scores of 0.92, surpassing the uniformly distributed model.
*   The augmentation strategies—controlled error insertion for morphological robustness, adversarial sampling for untranslatability, and word-order perturbation for syntactic flexibility—were essential to building a large, varied training set where naturally poor translations are scarce.

## Why This Works (Mechanism)

### Mechanism 1
*   **Claim:** Controlled perturbation augmentation improves model robustness to morphological and syntactic errors characteristic of Hebrew.
*   **Mechanism:** The method systematically introduces specific error types (gender/number agreement violations, word-order disruptions) into otherwise correct translations, assigning reduced quality scores. This creates explicit training examples of degradation, forcing the model to learn features correlated with these error classes rather than only incidental patterns from natural MT output.
*   **Core assumption:** That artificially inserted errors are linguistically valid and representative of real MT failure modes for the language pair.
*   **Evidence anchors:**
    *   [section 4.1] Describes using morphological lexicons to insert gender/number agreement errors and score penalty rules.
    *   [section 4.3] Details word-order perturbations (adjacent swaps, forward shifts, shuffles) with corresponding score reductions.
    *   [abstract] Notes augmentation targeted "linguistic challenges, particularly regarding gender and number agreement."
*   **Break condition:** If the inserted error patterns do not align with actual MT system failure distributions, the model may learn spurious correlations or fail to generalize to real errors.

### Mechanism 2
*   **Claim:** A uniformly distributed training set across quality scores yields a more fine-grained and less biased QE model than a naturally (normally) distributed set.
*   **Mechanism:** Balanced exposure to all quality levels prevents the model from developing a strong prior towards the majority class (typically high-quality translations). This encourages it to learn discriminative features for mid and low-quality segments, which are critical for reliable QE.
*   **Core assumption:** That the model's tendency to predict the mean score in imbalanced data is a primary failure mode that uniform distribution mitigates.
*   **Evidence anchors:**
    *   [section 5.2] Reports 0.88 Pearson on a 430k uniformly distributed set vs. 0.65 on a 500k normally distributed set, noting it "reduces the default tendency to the mean score."
    *   [section 4] Initial dataset had a "skewed distribution of quality scores, with the vast majority of segments receiving scores of 3 and 5," leading to poor performance.
*   **Break condition:** If the underlying real-world QE task has a fundamentally skewed distribution (e.g., most MT output is high-quality), a uniformly trained model may be miscalibrated for deployment.

### Mechanism 3
*   **Claim:** Large-scale data volume, even with natural skew, is the most effective driver of robust QE performance for this morphologically complex pair.
*   **Mechanism:** Massive data provides extensive exposure to the full spectrum of linguistic variation, MT output idiosyncrasies, and contextual patterns in Hebrew. This overwhelming signal allows the model to internally abstract robust quality indicators, making explicit distribution balancing less critical than sheer coverage.
*   **Core assumption:** That the natural variance in 1-4M semi-synthetic samples is sufficient to cover the relevant feature space for sentence-level QE.
*   **Evidence anchors:**
    *   [section 5.3] Random sampling of 1M and 4M segments achieved 0.92 Pearson, outperforming the uniformly distributed 430k set (0.88).
    *   [abstract] States "sheer data volume, even with natural skew, most effectively improves model robustness."
    *   [section 5.3] Attributes gain to "a broader spectrum of linguistic variation" and "richer training signals."
*   **Break condition:** If the data generation process has fundamental biases or fails to produce certain critical error types, scaling may amplify these gaps rather than fill them.

## Foundational Learning
*   **Concept: Semi-synthetic parallel corpora generation.**
    *   **Why needed here:** The core innovation is building a large QE dataset for an under-resourced pair by generating source sentences (from usage examples via LLM), translating via multi-MT, and manually evaluating/filtering.
    *   **Quick check question:** What are the risks of using an LLM (ChatGPT) to generate source sentences for a QE dataset, and how might they impact model learning?
*   **Concept: Annotation schema for sentence-level MT quality.**
    *   **Why needed here:** The 5-point scale with detailed error categorization (neutral/minor/major) across accuracy, linguistic quality, style, etc., is the ground truth signal. Understanding this schema is essential to interpret the model's target.
    *   **Quick check question:** How would a "major" error in gender/number agreement differ in impact from a "minor" punctuation error for Hebrew MT quality?
*   **Concept: Perturbation-based data augmentation for robustness.**
    *   **Why needed here:** The paper uses error insertion and word-order perturbation to synthesize low-quality examples, addressing the scarcity of naturally bad translations in MT output.
    *   **Quick check question:** Why is word-order perturbation particularly relevant for Hebrew, and how might its effect differ from applying it to a language with fixed word order like English?

## Architecture Onboarding
*   **Component map:**
    Source Select (Usage Examples) -> Generate (ChatGPT) -> Translate (MT APIs) -> Filter (BLEU) -> Annotate (Manual) -> Augment (Error/Perturb) -> Sample (Dataset Split) -> Train (BERT+LoRA+Head) -> Evaluate (Pearson)
*   **Critical path:** The pipeline's success hinges on the manual annotation step providing a reliable quality signal and the augmentation step creating a sufficiently diverse error distribution to train a robust model. A failure in either propagates to the final model.
*   **Design tradeoffs:**
    *   **Synthetic vs. Real:** Using LLM-generated sources and multi-MT translations creates scale but risks domain shift from "typical learner usage" and systematic shared MT biases.
    *   **Distribution vs. Scale:** Uniform distribution (0.88) outperformed Normal (0.65) at ~430k, but Random at 1-4M (0.92) outperformed both. This suggests scale can overcome suboptimal distribution, but uniform is an efficient compromise at smaller scales.
    *   **Error Realism:** Inserting agreement errors via lexicons is controlled but may not capture the contextual and semantic complexity of *actual* MT agreement errors.
*   **Failure signatures:**
    *   Model overwhelmingly predicts a single score (e.g., all 3s) on test set → **Severe dataset skew or insufficient model capacity.**
    *   Model fails on adversarially mismatched pairs (score=0) → **Model not learning sentence correspondence; head may be shortcutting.**
    *   Performance drop when moving from uniform to normal distribution → **Model relying on dataset priors (mean) instead of learning quality discriminant features.**
    *   Low Pearson despite large data → **Augmentation errors not representative; annotation schema inconsistent; or fundamental mismatch between model's representation and quality dimensions.**
*   **First 3 experiments:**
    1.  **Baseline Training:** Train BERT+LoRA on the initial manually ranked set (~14k segments) + basic augmentation (error insertion to 200k). Expected outcome: Poor performance (Pearson ~0.1-0.2) due to small size and extreme skew.
    2.  **Distribution Control:** Train on a uniformly sampled 430k segment set. Expected outcome: Significant jump in Pearson (to ~0.88) as model learns balanced quality cues.
    3.  **Scale Validation:** Train on a randomly sampled 1M+ segment set (preserving natural distribution). Expected outcome: Further performance increase (to ~0.92) demonstrating the overwhelming value of data volume.

## Open Questions the Paper Calls Out
### Open Question 1
*   Question: Does explicitly incorporating idiomatic expressions into the training data improve a QE model's ability to detect and penalize their inaccurate translations?
*   Basis in paper: [explicit] The "Future Work" section states the authors will augment the dataset with English idioms and their correct/erroneous Hebrew equivalents, anticipating this will enhance model performance for evaluating idiom translations.
*   Why unresolved: The paper describes the planned augmentation but provides no experimental results or analysis on whether this targeted approach yields a measurable improvement in QE accuracy for idiom-heavy segments.
*   What evidence would resolve it: Train and test QE models on identical datasets with and without the idiom-augmented subsets, measuring the change in Pearson correlation specifically on a held-out set of idiom-containing sentence pairs.

### Open Question 2
*   Question: What is the underlying mechanism by which a uniformly distributed quality score dataset (430k samples) significantly outperforms a normally distributed one (500k samples) for QE model training?
*   Basis in paper: [inferred] The results show a clear performance gap (0.88 vs. 0.65 Pearson), but the paper attributes this to balanced exposure to all quality levels without explaining the causal linguistic or modeling reason (e.g., mitigation of prediction bias, better gradient signal for mid-range scores).
*   Why unresolved: The paper correlates distribution with performance but does not conduct an ablation or analysis to isolate *why* uniformity helps—whether it's due to reduced model bias toward the mean, improved learning of subtle quality distinctions, or other factors.
*   What evidence would resolve it: Analyze model prediction distributions, gradient updates, or error patterns on datasets with controlled distribution skew. Compare learned representations for mid-quality segments across the two training regimes.

### Open Question 3
*   Question: What is the minimum viable dataset size or a diminishing returns threshold for scaling semi-synthetic QE data for complex language pairs like English-Hebrew?
*   Basis in paper: [inferred] The paper demonstrates a jump from 500k (0.65) to 1M/4M samples (0.92) but tests only these coarse scales. The exact scaling curve and point of saturation are unexplored.
*   Why unresolved: While emphasizing the importance of scale, the experiments lack intermediate data sizes (e.g., 750k, 2M), preventing identification of whether the observed jump is linear, logarithmic, or has a critical mass.
*   What evidence would resolve it: Systematic training runs on datasets of incrementally increasing sizes (e.g., 100k, 250k, 500k, 750k, 1M, 2M) to plot performance vs. size and identify inflection points or saturation.

### Open Question 4
*   Question: Which specific perturbation technique (controlled error insertion, adversarial negative sampling, word-order augmentation) contributes most to model robustness, and do they address complementary failure modes?
*   Basis in paper: [inferred] The final 400k dataset combines all three augmentation strategies, and performance is reported for the combined set. The paper does not ablate or compare the individual contribution of each technique.
*   Why unresolved: It is unclear if one technique (e.g., adversarial negatives for learning "untranslatability") is primarily responsible for the gains, or if their effects are synergistic. The model's failure modes before and after each augmentation step are not characterized.
*   What evidence would resolve it: Train models on datasets where only one augmentation type is applied at a time, comparing performance on targeted test sets (e.g., segments with only gender errors, only mismatched pairs, only word-order issues) and on a diverse held-out set.

## Limitations
*   **Data Source Fidelity:** The exact source of seed "usage examples" and high-quality reference translations is unspecified, risking domain mismatch and limiting replicability.
*   **Error realism:** Artificially inserted errors (gender/number) are controlled but may not capture the full contextual complexity of *actual* MT failure modes for Hebrew.
*   **Test Set Construction:** The held-out test set's composition and size are not detailed, making it hard to assess if results reflect real-world QE deployment scenarios.

## Confidence
*   **Mechanism 1 (Perturbation Robustness):** Medium. Evidence from paper is clear, but break condition (misaligned error distribution) is a significant undemonstrated risk.
*   **Mechanism 2 (Uniform vs. Normal Distribution):** High. Strong empirical result (0.88 vs. 0.65) directly supports the claim about bias reduction.
*   **Mechanism 3 (Scale Over Distribution):** High. Consistent performance gains across 1M and 4M samples strongly support the primacy of data volume.

## Next Checks
1.  **Validate Error Realism:** Create a small, natural test set of real English-Hebrew MT outputs with known errors (not synthetically perturbed). Evaluate the final 0.92 Pearson model on this set to confirm its gains transfer beyond the synthetic error patterns.
2.  **Probe the Distribution Effect:** Conduct an ablation study training models on datasets with systematically varied skew (e.g., 20%, 40%, 60% of samples in the middle score class) at a fixed, intermediate size (e.g., 500k). Measure the change in prediction bias (variance around mean) and granular accuracy for mid/low-quality segments.
3.  **Test Idiom Generalization:** Implement the proposed idiom augmentation on a fixed subset of the training data (e.g., 100k idiom-augmented segments added to a 1M base set). Evaluate on a held-out set of idiom-containing sentences to directly measure any improvement in detecting idiom mistranslations, addressing Open Question 1.
