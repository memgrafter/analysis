# Sparse Additive Model Pruning for Order-Based Causal Structure Learning

## Quick Facts
- **ArXiv ID**: 2602.15306
- **Source URL**: https://arxiv.org/abs/2602.15306
- **Reference count**: 40
- **Primary result**: SARTRE accelerates the pruning step in order-based causal discovery while achieving comparable or better accuracy in SHD and SID, especially in high-dimensional settings.

## Executive Summary
The paper tackles inefficiencies in order-based causal structure learning, specifically the CAM‑pruning step that relies on multiple conditional independence tests. It proposes Sparse Additive Randomized Tree Ensemble (SARTRE), which replaces hypothesis testing with a sparse additive model fitted via group lasso on randomized tree embeddings. This approach directly prunes edges while controlling false positives. Empirical evaluations on synthetic and real datasets show that SARTRE is significantly faster than state‑of‑the‑art methods (SCORE, DAS) and matches or exceeds them in structural Hamming distance (SHD) and structural interventional distance (SID), with notable gains in high‑dimensional regimes.

## Method Summary
SARTRE operates in two main stages. First, for each target variable, it builds a randomized tree ensemble (e.g., random forest) on the data to capture complex relationships and generates intervals that likely contain the true parent effects. Second, it fits a sparse additive model where the response is the target variable and the predictors are basis functions derived from the tree embeddings. Group lasso regularization selects entire groups of basis functions corresponding to each candidate parent, enabling direct identification of the parent set without performing multiple hypothesis tests. The method integrates with any order‑based algorithm by taking the variable ordering and producing a pruned adjacency matrix.

## Key Results
- SARTRE is significantly faster than SCORE and DAS in the pruning step.
- SARTRE achieves comparable or superior accuracy as measured by SHD and SID across various benchmarks.
- In high‑dimensional settings (many variables relative to samples), SARTRE outperforms DAS in both speed and accuracy.

## Why This Works (Mechanism)
SARTRE bypasses the traditional multiple‑testing burden. Instead of conducting many conditional independence tests, it transforms the data using randomized tree ensembles, which approximate nonlinear functions and interactions. By then applying a sparse additive model with group lasso, it jointly selects relevant predictors (parents) in a regularized fashion. The group lasso ensures that all basis functions associated with a given variable are either included or excluded together, naturally controlling the number of false parent selections without the need for per‑test p‑value thresholds. This unified optimization is both computationally efficient (leveraging fast tree ensemble training and coordinate descent for group lasso) and statistically powerful because it borrows strength across the ensemble representation.

## Architecture Onboarding
The architecture of SARTRE can be viewed as a pipeline:

Data + Estimated Order -> Randomized Tree Ensemble -> Intervals/Embeddings -> Group Lasso Regression -> Pruned Adjacency Matrix

**Component map**: Data and an estimated variable ordering serve as input. A randomized tree ensemble (e.g., random forest) is trained per target variable to capture nonlinear relationships. The ensemble outputs intervals or basis expansions that encode potential parent influences. These features feed into a group lasso regression, where each group corresponds to a candidate parent; the regularization drives many groups to zero, selecting the parent set. The final output is a pruned adjacency matrix consistent with the order.

**Critical path**: The most computationally intensive steps are building the tree ensembles and solving the group lasso optimization. Ensemble training per variable can be parallelized. The group lasso uses coordinate descent and benefits from sparsity; its cost scales with the number of features (determined by tree structure).

**Design tradeoffs**:
- Number of trees: More trees improve embedding quality but increase training time and memory.
- Regularization strength λ: Controls sparsity; too high yields overly dense graphs, too low yields false positives. Cross‑validation could tune it.
- Tree depth: Deeper trees capture interactions better but risk overfitting and larger feature groups.
- Tree ensemble vs. kernels: Trees avoid kernel choice but may need many trees for smooth functions; kernels require careful selection.

**Failure signatures**:
- Underfitting: If trees are too shallow or few, the additive model may miss true edges (high false negative rate).
- Overfitting/False positives: If λ is too low, many irrelevant parents are retained; if order is wrong, pruning cannot recover.
- Instability: In high‑noise settings, tree embeddings may vary across runs, leading to inconsistent parent selection.
- Resource exhaustion: Very high dimensionality may cause memory blow‑up due to large feature matrices from tree ensembles.
