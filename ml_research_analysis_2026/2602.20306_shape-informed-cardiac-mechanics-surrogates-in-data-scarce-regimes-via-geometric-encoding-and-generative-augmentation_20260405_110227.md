# Shape-informed cardiac mechanics surrogates in data-scarce regimes via geometric encoding and generative augmentation

## Quick Facts
- arXiv ID: 2602.20306  
- Source URL: https://arxiv.org/abs/2602.20306  
- Reference count: 40  
- Primary result: Augmenting 44 real heart geometries with 976 synthetically generated shapes reduces surrogate model error on unseen patients from 6.7% to 2.4% RMSE.

## Executive Summary
This paper addresses the challenge of building accurate surrogate models for cardiac mechanics that generalize across diverse heart anatomies when high-fidelity simulation data is scarce. It proposes a two-step framework that decouples geometric representation from physics learning. First, a shape model—either PCA-based or DeepSDF-based—learns a compact latent space from point cloud data, enabling synthetic geometry generation for data augmentation. Second, a neural field surrogate, conditioned on this latent code and using universal ventricular coordinates for positional encoding, predicts ventricular displacement fields. Evaluations on idealized and patient-specific datasets show that both shape encoding strategies yield accurate predictions and generalize to unseen geometries. Crucially, the synthetic augmentation dramatically improves performance, reducing error from 6.7% to 2.4% RMSE when moving from real-only to augmented training. The DeepSDF-based approach additionally demonstrates greater robustness to noisy and sparsely sampled inputs.

## Method Summary
The method consists of two sequential components. (1) A shape model trained on point cloud data of ventricles learns a low-dimensional latent space. PCA provides a linear embedding, while DeepSDF offers a nonlinear implicit representation. This latent space allows sampling of new, synthetic cardiac geometries, thereby augmenting the limited real dataset. (2) A neural field surrogate is trained to predict displacement fields. The network takes as input a 3D coordinate (expressed in universal ventricular coordinates—a canonical reference frame aligning anatomical regions across shapes) and the latent code of a specific geometry. It outputs the displacement at that coordinate. During training, the surrogate sees both real and synthetic geometries; at inference, the latent code of a new (unseen) shape is obtained by encoding its point cloud via the trained shape model, after which the neural field predicts displacements anywhere in the volume.

## Key Results
- The framework generalizes to unseen geometries using both PCA and DeepSDF shape encoders, with DeepSDF showing improved robustness.  
- Synthetic augmentation with 976 shapes (from a model trained on 44 real geometries) reduces the surrogate’s RMSE on held‑out patient data from 6.7% to 2.4%.  
- The DeepSDF‑based latent space yields more stable predictions under input noise and reduced point density compared to PCA.

## Why This Works (Mechanism)
The approach works because it cleanly separates the sources of variation: the shape model captures the manifold of plausible cardiac anatomies in a compact latent code, while the neural field learns the physics mapping from coordinates (in a universal frame) to displacements, conditioned on that code. This decoupling allows the surrogate to be trained on a diverse set of geometries without requiring expensive simulations for each one. The synthetic shapes, drawn from the learned latent distribution, effectively expand the training distribution and teach the surrogate to handle anatomical variations. Universal ventricular coordinates provide a consistent spatial reference, further aiding generalization. The DeepSDF encoder’s nonlinearity better captures fine shape details and tolerates imperfect inputs, leading to more reliable conditioning.

## Foundational Learning
- **Latent Space**  
  *Why needed*: To encode complex geometric variations into a low‑dimensional vector that can be sampled for data augmentation and used to condition the surrogate.  
  *Quick check*: Reconstruct point clouds from latent codes and measure Chamfer distance; it should be low for held‑out shapes.

- **Neural Fields**  
  *Why needed*: To represent continuous displacement fields as a function of spatial coordinates, enabling prediction at arbitrary resolution without memory‑intensive grids.  
  *Quick check*: For a neutral (zero‑displacement) shape, the output field should be near zero everywhere.

- **Universal Ventricular Coordinates**  
  *Why needed*: To establish a canonical coordinate system that aligns corresponding anatomical regions across different heart geometries, facilitating consistent conditioning.  
  *Quick check*: Landmarks (e.g., apex, base) should map to similar coordinate values across diverse shapes.

- **Generative Data Augmentation**  
  *Why needed*: To overcome scarcity of high‑fidelity simulation data by synthetically expanding the training set with plausible geometries.  
  *Quick check*: Visual inspection and rudimentary metrics (e.g., surface smoothness, volume ranges) should indicate realistic samples.

- **Surrogate Modeling**  
  *Why needed*: To approximate computationally expensive physics simulations with fast neural models, enabling real‑time analysis.  
  *Quick check*: Compare surrogate predictions against simulation outputs on a validation set; errors should be small and physically plausible.

## Architecture Onboarding
**Component Map (plain text):**  
Point cloud (input) → Shape Encoder (PCA or DeepSDF) → Latent code → Neural Field Surrogate (conditioned on latent code + universal coordinate) → Displacement field.

**Critical Path:**  
1. Input ventricle point cloud is encoded into a latent vector by the trained shape model.  
2. For any query point inside the ventricular volume, its universal ventricular coordinate is computed.  
3. The neural field receives the concatenated (coordinate, latent code) and returns a displacement vector.  
4. Querying a dense set of points yields the full displacement field.

**Design Tradeoffs:**  
- *PCA vs DeepSDF*: PCA is simple, fast, and requires little data but is linear and may miss nonlinear shape variations; DeepSDF is nonlinear and more expressive but needs more training data and longer optimization.  
- *Universal coordinates vs raw spatial coordinates*: Universal coordinates enforce alignment but require a registration step; raw coordinates are simpler but may confuse the network by different orientations/scales.  
- *Synthetic augmentation source*: Using the same shape model trained on limited real data risks sampling shapes that lie in unexplored regions (potentially unrealistic); alternative generative models (e.g., VAEs) might offer better coverage.

**Failure Signatures:**  
- High displacement prediction error on shapes that deviate from the training distribution (e.g., pathological hearts).  
- Synthetic geometries exhibiting topological errors (e.g., self‑intersections) or extreme/unphysical dimensions.  
- Surrogate performance degrades significantly when input point clouds are noisy or sparse, especially for PCA.

**First Experiments (Onboarding):**  
1. Train the shape model on real geometries only; evaluate reconstruction quality (e.g., Chamfer distance) on a held‑out set to verify the latent space captures shape.  
2. Train the neural field surrogate using *only* real data (no augmentation); measure its prediction error on unseen real geometries to establish a baseline.  
3. Add synthetic data generated from the trained shape model to the surrogate’s training set (keeping total data volume comparable to baseline) and re‑evaluate; compare error reduction.

## Limitations
- The training set contains only 44 real geometries, which may not represent the full spectrum of cardiac anatomical variations, including severe pathologies.  
- Synthetic geometries are drawn from a probabilistic shape model trained on the same limited data; unrealistic samples could bias the surrogate.  
- Evaluation on “unseen geometries” likely comes from the same distribution; generalization to truly out‑of‑distribution anatomies remains uncertain.

## Confidence
- Generalization across diverse anatomies: **Medium**  
- Synthetic augmentation improves performance: **Medium**  
- DeepSDF robustness to noise/sparsity: **Medium**

## Next Checks
1. **External validation**: Test the trained surrogate on an independent patient cohort from a different hospital or imaging protocol to assess population and acquisition biases.  
2. **Noise‑sparsity sensitivity analysis**: Systematically vary point cloud noise (e.g., additive Gaussian with increasing σ) and point density (e.g., 10%–90% subsampling) and measure displacement error for both shape encoders.  
3. **Ablation of augmentation source**: Replace the shape‑model‑based synthetic data with alternative augmentation (e.g., affine transforms, VAE‑generated shapes) while fixing total training size, to isolate the contribution of the proposed geometric encoding approach.
