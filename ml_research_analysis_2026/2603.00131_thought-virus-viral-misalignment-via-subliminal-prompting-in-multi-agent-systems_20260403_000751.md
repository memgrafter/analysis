# Thought Virus: Viral Misalignment via Subliminal Prompting in Multi-Agent Systems
## Quick Facts
- **arXiv ID**: 2603.00131
- **Source URL**: https://arxiv.org/abs/2603.00131
- **Reference count**: 29
- **Primary result**: Injecting a single subliminal token into an agent's system prompt biases its outputs and propagates virally through ordinary multi-agent conversations, increasing target response rates up to 437× over baseline and persisting over multiple hops while evading paraphrasing defenses.

## Executive Summary
This paper introduces "Thought Virus," a novel attack where a subliminal token—a semantically unrelated token—is embedded into one agent's system prompt within a multi-agent system (MAS). The token subtly biases that agent's responses, and this bias then spreads to other agents through normal conversational exchanges. experiments in chain and bidirectional chain topologies show the bias propagates significantly, even reaching distant agents, and resists basic paraphrasing-based defenses. The work reveals a stealthy vulnerability: a single compromised agent can misalign an entire MAS without overt malicious prompts.

## Method Summary
The attacker compromises one agent by inserting a target animal name or a "deceitful" token (e.g., "!!!") into its system prompt. Agents then engage in structured conversations (e.g., discussing animal preferences or answering TruthfulQA questions) where each agent's prompt includes prior responses. The researchers measure bias propagation by tracking response rates toward a target animal or truthfulness gaps across agents at increasing hop distances, comparing against baseline and random-token controls. Topologies tested are linear chains and bidirectional chains of up to three agents.

## Key Results
- In animal preference tasks, the target animal's response rate increased by up to **437× over baseline** and **7× over random tokens** at the farthest agent (three hops).
- On TruthfulQA, a **0.4–1.0% accuracy gap** emerged between "truthful" and "deceitful" token conditions after three hops (Mann-Whitney U, p<0.01).
- The bias **weakened with hop distance but persisted**, and **evaded paraphrasing defenses**, demonstrating stealth.

## Why This Works (Mechanism)
Subliminal tokens exploit known LLM sensitivity to irrelevant input tokens, shifting internal representations and biasing outputs. In MAS, agents automatically incorporate previous agents' responses into their prompts. Thus, a biased output from the initial compromised agent becomes part of the next agent's context, indirectly conveying the subliminal influence. This creates a viral spread: each agent's output carries the subtle bias, which influences subsequent agents even without direct token exposure, making theattack both stealthy and socially transmissible across the network.

## Foundational Learning
- **Subliminal Prompting**: Inserting semantically unrelated tokens to manipulate LLM behavior. *Why needed*: Shows attacks need not rely on semantic content. *Quick check*: Does adding a random token (e.g., "xyz") change a model's choice in a multiple-choice task?
- **Token Sensitivity**: LLMs' unexpected responsiveness to specific tokens. *Why needed*: Explains why minimal triggers cause bias. *Quick check*: Measure logit differences when a token is inserted vs. omitted in a neutral prompt.
- **Multi-Agent Systems (MAS)**: Networks of LLM agents that communicate. *Why needed*: Provides environment where biases can propagate between models. *Quick check*: Build a two-agent chain and check if Agent2's output correlates with Agent1's system prompt.
- **Bias Propagation**: Transfer of unintended preferences across agents. *Why needed*: Core phenomenon studied. *Quick check*: Introduce a biased agent in a 3-agent chain and measure bias strength at each hop.
- **Attack Surface in Inter-Agent Trust**: Vulnerability arising from agents assuming benign inputs from peers. *Why needed*: Highlights systemic risk in decentralized deployments. *Quick check*: Simulate a MAS where one agent is adversarial and observe network-wide output changes.
- **Evaluation of Stealth Attacks**: Assessing attacks that avoid detection by content-based filters. *Why needed*: Determines real-world viability. *Quick check*: Run a paraphrasing tool on compromised outputs and test if bias remains.

## Architecture Onboarding
Component map: Agent1 (compromised) -> Agent2 -> Agent3 (chain); or Agent1 <-> Agent2 <-> Agent3 (bidirectional chain). Critical path: The sequence of prompts where each agent's input contains the previous agent's response, allowing the subliminal bias to be implicitly transmitted. Design tradeoffs: Simple topologies (short chains) ensure controlled experiments but limit generalizability; small hop counts manage complexity but miss long-tail attenuation. Failure signatures: Diminishing bias effect over hops, high variance across tasks, or complete neutralization by robust prompt filtering. First experiments: 1) Replicate with Llama 2 and GPT-3.5 using an open-source MAS framework; 2) Extend to 5-hop chains to map decay curve; 3) Apply state-of-the-art prompt sanitization tools and measure residual bias.

## Limitations
- Evaluation restricted to two toy tasks (animal preference, TruthfulQA) and small chain/bidirectional-chain topologies; unknown generalizability to complex, heterogeneous MAS or real deployments.
- Hops limited to 3; attenuation beyond that unmeasured.
- No analysis of propagation mechanisms (e.g., attention patterns); defense evaluation limited to paraphrasing, not advanced monitoring or adversarial training.

## Confidence
- **Subliminal tokens bias individual agents**: High (effect direct, reproducible, aligns with known token sensitivity).
- **Bias propagates through agent conversations**: Medium (supported by simple topologies, but generalizability uncertain).
- **Propagation persists over multiple hops and evades defenses**: Low (evidence limited; evasion robustness unrigorously evaluated).

## Next Checks
1. Replicate experiments across at least three diverse model families (Llama, GPT, Claude) using open-source MAS frameworks to confirm robustness.
2. Measure bias decay in larger networks (5+ hops) and heterogeneous topologies (star, scale-free) to map attenuation function and identify spread thresholds.
3. Conduct adversarial evaluation with state-of-the-art prompt sanitization, paraphrasing defenses, activation monitoring, and human evaluation of output trustworthiness.
