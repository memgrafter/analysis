# WildCat: Near-Linear Attention in Theory and Practice

## Quick Facts
- arXiv ID: 2602.10056
- Source URL: https://arxiv.org/abs/2602.10056
- Reference count: 40
- Primary result: WildCat approximates softmax attention via a small weighted coreset, achieving near-linear O(n^{1+o(1)}) runtime with super-polynomial O(n^{-√log log n}) error decay, and empirical speed-ups up to 11.6× with minimal accuracy loss.

## Executive Summary
WildCat tackles the quadratic cost of attention in transformers by replacing exact attention with a Nyström-based approximation using a small weighted coreset of keys. The coreset is selected via Randomly Pivoted Cholesky (RPC), which provides spectrally accurate sampling in near-linear time. The method includes a temperature-scaling trick to balance low-rank structure and query error, and optimal Nyström reweighting to minimize reconstruction error. Theoretically, under bounded inputs, WildCat enjoys super-polynomial error decay while maintaining O(n^{1+o(1)}) computational complexity—a significant improvement over prior approximate attention methods that either lack guarantees or revert to quadratic cost for high fidelity. Empirically, WildCat delivers substantial speed-ups with negligible accuracy degradation across diverse tasks: image generation (BigGAN), image classification (T2T-ViT), and KV cache compression for language models (Qwen2.5 on LongBench-E).

## Method Summary
WildCat consists of two modular components: COMPRESSKV and WILDATTN. COMPRESSKV preprocesses the key and value tensors to produce a compressed representation. It first recenters the keys, then partitions them into bins, and applies the Randomly Pivoted Cholesky (RPC) algorithm within each bin to select a coreset of keys. The corresponding values are reweighted using the inverse of the coreset kernel matrix (optimal Nyström weighting). The outputs are the selected keys K_S, reweighted values V_S = WV, and normalization weights w = W1_n. In WILDATTN, the attention output is computed as exp(β Q K_S^⊤) scaled by w and clipped to a value range. The whole process is wrapped in the WILDCAT module, which replaces standard attention in a transformer without any retraining. A theoretical temperature parameter τ (derived via Lambert W) rescales queries and keys to improve low-rank approximability while controlling error inflation. The method is inherently data-dependent and operates in a single pass with no additional learning.

## Key Results
- **Image generation (BigGAN)**: 3.71× speed-up, only 1.4% Inception Score degradation, no FID loss.
- **Image classification (T2T-ViT)**: 82.18% Top-1 accuracy (vs. 82.55% exact) with up to 11.6× speed-up on the largest layer.
- **KV cache compression (LongBench-E, 25% compression)**: Average score 47.25, the highest among compared methods, compared to 53.00 for exact attention.

## Why This Works (Mechanism)

### Mechanism 1: Selective key sampling via Randomly Pivoted Cholesky (RPC)
- **Claim:** RPC captures the spectral structure of the kernel matrix with near-linear computational cost.
- **Mechanism:** RPC recursively chooses pivot indices proportional to the diagonal entries of the current residual kernel matrix `h_res(k_l, k_l)`. Each pivot updates the Nyström weights via rank-one corrections, avoiding full matrix factorization. The pivoting rule maximizes the information contributed by each sampled key about the remaining keys under the kernel metric.
- **Core assumption:** The key kernel matrix `H = h(K, K)` is positive definite and can be approximated by a low-rank matrix `T ⪯ H` with bounded residual trace `tr(H - T)`.
- **Evidence anchors:** 
  - Abstract mentions “fast but spectrally-accurate subsampling algorithm – randomly pivoted Cholesky”.
  - Section 2.3: Algorithm 1 and Theorem 1 bound `E∥H - bH_r∥_op` in terms of `rank(T)` and `tr(H - T)`.
- **Break condition:** When residual diagonals become uniformly small, indicating a good low-rank approximation; runtime remains `O(nr² + nrd)` for `r ∈ n^o(1)`.

### Mechanism 2: Optimal Nyström reweighting for attention
- **Claim:** The Nyström weights `W = h(K_S, K_S)^{-1}h(K_S, K)` minimize the reconstruction error of the kernel matrix, preserving the linear structure of attention.
- **Mechanism:** For a selected coreset `K_S`, the weights are the unique minimizers of `∥h(K, K) - h(K, K_S)W∥_F`. Applied to values as `V_S = WV`, the attention output is approximated by `exp(β Q K_S^⊤) V_S`.
- **Core assumption:** The exponential kernel is reproducing and lies in a Hilbert space where the Nyström projection is optimal for squared error.
- **Evidence anchors:** 
  - Section 2.2 states “weight the elements optimally to minimise reconstruction error” and Lemma 2 links `∥A - bA∥_{2,∞}` to `∥h_res(K, K)∥_op`.
  - Section 2.5 describes forming compressed key and value tensors `K_S, V_S = WV`.
- **Break condition:** If `h(K_S, K_S)` is near-singular, weights become unstable; RPC pivoting maintains invertibility (Prop. K.1).

### Mechanism 3: Temperature scaling to balance low-rank structure and query error
- **Claim:** Rescaling keys and queries by a carefully chosen temperature parameter τ improves low-rank approximability without excessively inflating the query error.
- **Mechanism:** Replace `K ← K/τ`, `Q ← τQ` (attention invariant). This adjusts the kernel matrix to `H_τ = h(τ⁻¹K, τ⁻¹K)`. Larger τ makes `H_τ` more low-rank but increases the factor `exp(βτ²R_Q²)` in the error bound (Lemma 2). The optimal τ is given by a closed-form expression (Equation 4) derived from minimizing a bound, using the Lambert W function.
- **Core assumption:** Bounded query/key radii `R_Q = ∥Q∥_{2,∞}`, `R_K = ∥K∥_{2,∞}` and asymptotic alignment of Taylor order `s(ε)` with `log(n)`.
- **Evidence anchors:** 
  - Section 2.4 presents Equation 4 and discusses invariance under rescaling.
- **Break condition:** If the ratio `R_Q/R_K` is extreme, τ may become too large or too small, degrading Nyström quality or causing numerical overflow in exponentials.

## Foundational Learning
- **Kernel methods and Nyström approximation**  
  - *Why needed:* WildCat approximates the softmax kernel `exp(β⟨q_i, k_l⟩)` by projecting it onto the span of a coreset’s kernel features.  
  - *Quick check:* How do Nyström weights `W = h(K_S, K_S)^{-1}h(K_S, K)` arise from an orthogonal projection in the RKHS?

- **Random pivoted Cholesky for matrix approximation**  
  - *Why needed:* RPC enables fast, spectrally accurate selection of a coreset without factorizing the full kernel matrix, crucial for the `O(nr²)` runtime.  
  - *Quick check:* Why does sampling pivots proportional to residual diagonal entries yield near-optimal low-rank approximation for positive semidefinite matrices?

- **Lambert W function and asymptotic trade-offs**  
  - *Why needed:* The optimal temperature τ and the required coreset rank involve the Lambert W function; understanding its growth (`W_0(z) ~ log(1+z)`) is key to super-polynomial error guarantees.  
  - *Quick check:* For `γ = βR_QR_K/log(n) ∈ o(1)`, why does `σ = a + γ / W_0(1/(2ργ)+1/ρ)` determine the coreset rank needed for `n^{-a}` error?

## Architecture Onboarding
- **Component map:** COMPRESSKV → WTDATTN (core operations) with WILDCAT as wrapper. More explicitly:  
  `Input (K,V)` → COMPRESSKV (recentering → binning → RPNYS per bin → concatenate K_S, compute V_S=WV, compute w) → WTDATTN (compute exp(βQK_S^⊤) → scale by w → clip) → Output.

- **Critical path:** The runtime of COMPRESSKV dominates, scaling as `O(nr²/B³ + nrd/B²)` where `B` is the number of bins. Efficient GPU implementation requires batched kernel evaluations and diagonal updates inside the RPC loop.

- **Design tradeoffs:**  
  - Coreset size `r` vs. accuracy: Theory requires `r ∼ n^{σ+δ} log(n)`; `σ` depends on τ and target error exponent `a`. Larger `r` improves accuracy but reduces speed-up.  
  - Binning count `B`: Increases speed (`/B³` factor) but loosens guarantees (use `n/B` in the theoretical bound). Default `B = r/12` for KV cache compression.  
  - Temperature `τ`: Over-scaling leads to uniform sampling; under-scaling hurts low-rank structure. Use Equation (4) with online estimation of `R_K`.

- **Failure signatures:**  
  1. Nyström weights explode → NaNs/Infs. Caused by poorly conditioned `h(K_S, K_S)` (e.g., pivots too similar).  
  2. Low accuracy despite large `r`: τ far from the theoretical value or bins too coarse (`B` too large); check that `ρ = τ²R_Q/R_K` is near `ρ_0 ≈ 3.19`.  
  3. Speed-up lower than expected: GPU launch overhead dominates if `r` or `B` too small; batch size must be sufficiently large (>100) for parallelism.

- **First 3 experiments:**  
  1. **Synthetic low-rank test:** Generate Gaussian keys, compute exact attention, compare WildCat error `∥A - bA∥_max` vs. `r` using computed τ vs. fixed τ=1. Verify super-polynomial decay.  
  2. **Runtime profile:** Time COMPRESSKV on random `K ∈ ℝ^{n×d}` for varying `n`, `r`, `B`. Confirm `O(nr²/B³ + nrd/B²)` scaling and high GPU utilization.  
  3. **KV cache compression sanity:** Load Qwen2.5-7B, compress first `n` KV pairs with `r=0.25n` and `B=r/12`, run one generation step, and check that the output matches exact attention within 1% max-norm on a few tokens.

## Open Questions the Paper Calls Out
- **Open Question 1:** Can WildCat be extended to streaming generation with causal masking while preserving near-linear runtime and error guarantees? (The paper explicitly notes this limitation; causal masking introduces sequential dependencies not handled by the current batch-oriented approach.)
- **Open Question 2:** Can the sequential path dependence in RPNYS be eliminated (e.g., via oversampling or recursive leverage-score methods) without sacrificing the `O(n^{-√log log n})` error decay? (The pivoting is sequential, hindering GPU parallelism; non-adaptive alternatives might improve throughput.)
- **Open Question 3:** Do WildCat’s super-polynomial error guarantees extend to other kernelized attention mechanisms (e.g., RBF, polynomial) or kernel mixtures? (The analysis heavily uses the exponential kernel’s series expansion; other kernels may require new techniques.)
- **Open Question 4:** Can additional structural assumptions (e.g., input smoothness, low-dimensional manifolds) improve the runtime-error trade-off beyond worst-case bounds? (Current bounds are worst-case; natural data often have regularity that could yield stronger guarantees.)

## Limitations
- Theoretical guarantees assume bounded input norms and a positive definite kernel; real-world data may violate these, weakening the error bounds.
- The temperature parameter τ relies on accurate estimation of `R_Q` and `R_K`; poor estimates can distort the low-rank/accuracy trade-off.
- Empirical evaluation is limited to three model families (BigGAN, T2T-ViT, Qwen2.5); generalizability to other architectures remains unproven.
- Hyperparameter choices (coreset size `r`, bin count `B`) are fixed in experiments; sensitivity to these parameters is not thoroughly explored.
- Speed-ups are reported on NVIDIA A100; other hardware may exhibit different scaling due to memory bandwidth and compute characteristics.
- The LongBench-E protocol (prompt formats, generation length, scoring) is not fully specified, making exact replication challenging.
