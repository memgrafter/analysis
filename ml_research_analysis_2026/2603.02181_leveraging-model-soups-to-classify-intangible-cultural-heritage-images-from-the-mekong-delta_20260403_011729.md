# Leveraging Model Soups to Classify Intangible Cultural Heritage Images from the Mekong Delta

## Quick Facts
- **arXiv ID:** 2603.02181
- **Source URL:** https://arxiv.org/abs/2603.02181
- **Reference count:** 17
- **Primary result:** Achieves 72.36% top-1 accuracy on ICH-17 dataset using CoAtNet with model soups, surpassing ResNet-50, DenseNet-121, and ViT.

## Executive Summary
This paper addresses the challenge of classifying Intangible Cultural Heritage (ICH) images from the Mekong Delta, which suffers from limited annotated data, high visual similarity among classes, and domain heterogeneity. The proposed solution integrates the hybrid CoAtNet architecture with model soups—a weight-space ensembling technique that averages diverse checkpoints from a single training trajectory. Two soup strategies, greedy and uniform, are evaluated. On the ICH-17 dataset (7,406 images, 17 classes), the method achieves state-of-the-art results with 72.36% top-1 accuracy and 69.28% macro F1-score. Analysis indicates model soups stabilize predictions by reducing variance while introducing minimal bias, selecting geometrically diverse checkpoints unlike soft voting, all without increasing inference cost.

## Method Summary
The approach involves training a CoAtNet model on the ICH-17 dataset while saving periodic checkpoints. Model soups are then applied by averaging the weights of selected checkpoints using either a greedy strategy (iteratively adding checkpoints that improve validation performance) or a uniform strategy (averaging all checkpoints equally). This weight-space ensembling leverages the optimization trajectory to combine the strengths of multiple snapshots into a single model, enhancing accuracy and robustness. The hybrid CoAtNet architecture merges convolutional layers for local feature extraction and transformer blocks for global context, making it suitable for complex, high-similarity image classification tasks.

## Key Results
- State-of-the-art performance on ICH-17: 72.36% top-1 accuracy and 69.28% macro F1-score.
- Outperforms strong baselines including ResNet-50, DenseNet-121, and Vision Transformer (ViT).
- Model soups reduce prediction variance while maintaining low bias, and select geometrically diverse checkpoints, unlike soft voting methods.

## Why This Works (Mechanism)
Model soups improve performance by averaging weights from diverse points along a single optimization trajectory. This smooths out fluctuations in the loss landscape, reducing model variance (sensitivity to specific training snapshots) without substantially increasing bias (underfitting). The resulting weights retain generalizable features learned across checkpoints while canceling noise or overfitting to particular epochs. The greedy and uniform strategies offer different trade-offs: greedy selection focuses on performance gains but may overfit to the validation set, while uniform averaging provides stability with simpler implementation.

## Architecture Onboarding
- **Component Map:** Data Augmentation → CoAtNet Training → Checkpoint Saving → Soup Selection (Greedy/Uniform) → Weight Averaging → Inference
- **Critical Path:** Train CoAtNet with periodic checkpointing (e.g., every epoch). Select checkpoints based on greedy (validation accuracy) or uniform (all checkpoints) criteria. Average selected weights to form final model for evaluation.
- **Design Tradeoffs:** 
  - *Greedy soup:* Higher potential performance gain but risks overfitting to validation set and depends on checkpoint ordering.
  - *Uniform soup:* Simpler, more stable, but may not capture best-performing regions.
  - Both avoid extra inference cost versus multi-model ensembles.
- **Failure Signatures:** 
  - Minimal performance improvement if selected checkpoints lack geometric diversity (weights are too similar).
  - Greedy soup degradation if validation set is unrepresentative or small.
- **First Experiments:**
  1. Train CoAtNet and evaluate individual checkpoints to establish baseline performance and identify top epochs.
  2. Implement greedy and uniform soup, compare against best single checkpoint and standard baselines (ResNet-50, DenseNet-121, ViT).
  3. Analyze checkpoint diversity using metrics like cosine similarity between weight vectors to validate selection criteria.

## Limitations
- **Dataset Scope & Generalizability:** Results are confined to the ICH-17 dataset from the Mekong Delta; it is unclear if gains extend to other ICH datasets with different visual or cultural characteristics.
- **Trajectory Dependency:** The method relies on a single training run; sensitivity to random seeds, learning rates, or initial weights is unexplored, and benefits may not hold across all optimization paths.
- **Comparative Baseline Gaps:** Lacks explicit comparison to other ensembling or fine-tuning techniques (e.g., stochastic weight averaging, snapshot ensembles, multi-model ensembles), making it hard to isolate the unique contribution of model soups.

## Confidence
- **High:** Reported top-1 accuracy (72.36%) and macro F1-score (69.28%) on ICH-17 test set are concrete empirical results.
- **Medium:** Claim that model soups improve performance without extra inference cost compared to individual checkpoints of the same CoAtNet model, as directly measured.
- **Low:** Broad assertions that model soups offer a "general solution" for ICH classification or that variance reduction is a universal property, given limited experimental scope.

## Next Checks

2. **Rigorous Ensembling Comparison:** Implement and compare against explicit multi-model ensembles (e.g., averaging predictions from independently trained CoAtNet models with different seeds) and other weight-averaging techniques (e.g., SWA) to isolate soup-specific benefits.
