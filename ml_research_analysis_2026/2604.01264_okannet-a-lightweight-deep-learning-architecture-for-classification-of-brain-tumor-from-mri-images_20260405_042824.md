# OkanNet: A Lightweight Deep Learning Architecture for Classification of Brain Tumor from MRI Images

## Quick Facts
- **arXiv ID:** 2604.01264
- **Source URL:** https://arxiv.org/abs/2604.01264
- **Reference count:** 40
- **Primary result:** Transfer learning with ResNet-50 achieved 96.49% accuracy and 0.963 precision, while the custom lightweight OkanNet achieved 88.10% accuracy but trained approximately 3.2 times faster (311 seconds vs. 1000 seconds), illustrating a speed-accuracy trade-off for brain tumor classification from MRI.

## Executive Summary
This study investigates automating brain tumor classification from MRI images to alleviate radiologist workload. It compares two approaches: a custom lightweight convolutional neural network (OkanNet) designed from scratch and a transfer learning model using a pre-trained ResNet-50. Evaluated on a dataset of 7,023 MRI images across four classes (Glioma, Meningioma, Pituitary, No Tumor), ResNet-50 achieved superior classification performance (96.49% accuracy) while OkanNet offered significantly faster training (311 seconds vs. 1000 seconds). The results demonstrate a clear trade‑off between high accuracy and computational efficiency, with implications for deploying models in resource‑constrained environments versus high‑stakes diagnostic settings.

## Method Summary
The study uses a publicly available brain tumor MRI dataset (7,023 images) structured into training and testing folders. Images are preprocessed to 224×224 pixels with grayscale‑to‑RGB conversion. Two models are implemented in MATLAB: (1) **OkanNet**, a custom three‑block CNN with 3×3 convolutions (filter counts 16, 32, 64), batch normalization, ReLU, max pooling, followed by a fully connected layer (128 units), dropout (0.5), and a 4‑class output; and (2) **ResNet‑50**, a pre‑trained ImageNet model where the final 1000‑class layer is replaced with a 4‑class head. Both models are trained for 8 epochs with a mini‑batch size of 32, SGDM optimizer, initial learning rate 1e‑4, and identical data augmentation (random rotation, horizontal flipping, translation). Training time and classification metrics (accuracy, precision, recall, F1‑score) are recorded on a test set.

## Key Results
- **ResNet‑50** achieved 96.49% accuracy and 0.963 precision, with a training time of 1000 seconds.
- **OkanNet** achieved 88.10% accuracy but trained approximately 3.2× faster (311 seconds).
- The confusion matrix shows ResNet‑50 made fewer errors between the challenging Glioma and Meningioma classes compared to OkanNet.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** OkanNet's reduced parameter count and shallow depth enable faster training times compared to deeper architectures.
- **Mechanism:** The architecture uses three convolutional blocks with incrementally increasing filters (16, 32, 64) and simple 3×3 kernels, avoiding residual connections or very deep stacks, minimizing matrix operations per forward/backward pass.
- **Core assumption:** For this specific dataset and task, a shallower hierarchy captures sufficient discriminative features without needing the representational capacity of very deep networks.
- **Evidence anchors:**
  - Abstract states OkanNet has low computational cost and fast training time, with the 3.2× speedup.
  - Section II.B details the three‑block design with 3×3 convolutions, batch normalization, ReLU, and max pooling.
  - Corpus analysis shows related work often uses deeper models (EfficientNet, ResNet variants) for brain tumor classification, suggesting OkanNet's speed is a differentiating factor.
- **Break condition:** If tumor sub‑types exhibit more subtle, hierarchical feature differences (e.g., microcalcifications, infiltration patterns), OkanNet's limited depth may hit an accuracy ceiling, as suggested by its lower performance on the Glioma/Meningioma distinction.

### Mechanism 2
- **Claim:** ResNet‑50's residual blocks mitigate vanishing gradients, enabling effective training of a deep 50‑layer network that captures highly abstract and discriminative features for tumor classification.
- **Mechanism:** Skip connections (y = F(x) + x) allow gradient flow during backpropagation, preventing degradation in very deep networks and permitting learning of complex, non‑linear mappings from MRI pixel patterns to tumor classes.
- **Core assumption:** The hierarchical feature learning (edges → textures → tumor‑specific structures → class distinctions) in a deep network is necessary for high accuracy on this multi‑class problem, especially for fine‑grained distinctions.
- **Evidence anchors:**
  - Section II.C explicitly states ResNet solves the vanishing gradient problem with skip connections and presents the residual block equation.
  - Section III.A shows ResNet‑50 started training from a very high accuracy level (>80%) and converged rapidly, indicating effective knowledge transfer and stable deep learning.
  - Section III.C's confusion matrix shows ResNet‑50 made significantly fewer errors between Glioma and Meningioma compared to OkanNet.
- **Break condition:** If the dataset contains severe domain shift (e.g., MRI sequences/scanners not represented in ImageNet) or very few samples per class, the transferred features may be misaligned, reducing the advantage of depth. The paper's limited 8 epochs suggest this wasn't a major issue here.

### Mechanism 3
- **Claim:** Transfer learning from ImageNet provides a strong, generalizable feature extractor that, even with limited medical data (7,023 images) and few fine‑tuning epochs (8), surpasses a custom architecture trained from scratch.
- **Mechanism:** The pretrained ResNet‑50 weights encode rich, generic visual representations (textures, shapes, patterns). Fine‑tuning the final fully‑connected layer adapts these high‑level features to the specific medical domain (tumor vs. non‑tumor, tumor sub‑types).
- **Core assumption:** Low‑level and mid‑level visual features (edges, blobs, textures) learned on natural images (ImageNet) are transferable to MRI images, which share fundamental spatial structure statistics despite being grayscale and medical.
- **Evidence anchors:**
  - Abstract notes the transfer learning method achieved 96.49% accuracy.
  - Section I states transfer learning allows reaching very high success rates with a limited amount of medical data.
  - Section II.D indicates both models used identical 8 epochs and learning rate, isolating the benefit of pretrained weights.
  - Corpus analysis shows multiple neighboring papers also employ transfer learning for similar tasks, indicating this is a standard, evidence‑supported approach.
- **Break condition:** If the target task (brain MRI) is visually too dissimilar from ImageNet (e.g., different contrast, noise profiles, anatomical focus), frozen or lightly fine‑tuned features may be ineffective, requiring more aggressive fine‑tuning (lower learning rates, unfreezing more layers) which is not explored in this study's fixed 8‑epoch, final‑layer‑only adaptation.

  2. Define `inputSize = [224 224 3]` to match ResNet‑50.
  3. Construct `layersCustom` for OkanNet exactly as coded (3 blocks, filter counts 16/32/64).

  5. Use identical `options` (SGDM, LR=1e‑4, 8 epochs, batch 32) for valid comparison.
  6. Evaluate on `imdsTest` (unaugmented) to get fair metrics.
  7. Generate confusion matrices and time measurements with tic/toc.

- **Design tradeoffs:**
  - **Speed vs. Accuracy:** OkanNet's simplicity wins on speed (311s vs 1000s) but loses accuracy (-8.4%). Choose OkanNet for edge deployment; ResNet‑50 for server‑side high‑stakes diagnosis.
  - **From‑Scratch vs. Transfer:** OkanNet requires no external pretraining data but needs more data to converge well. ResNet‑50 leverages ImageNet knowledge, critical for the limited 7k‑sample medical dataset.
  - **Architectural Simplicity:** OkanNet's 3‑block design is easy to modify. ResNet‑50 is a fixed, complex graph; modification is limited to layer replacement.
  - **Assumption:** The paper assumes the 8‑epoch, final‑layer‑only fine‑tuning is sufficient for ResNet‑50. This may not hold for all medical datasets; more epochs or partial unfreezing could improve results but increase time.

- **Failure signatures:**
  - **OkanNet:** Underfitting (training/test accuracy both low, e.g., <70%) if model capacity is insufficient. Overfitting (train acc >> test acc) if augmentation is insufficient or dropout rate is too low.
  - **ResNet‑50:** Catastrophic forgetting if learning rate is too high (>1e‑3) during fine‑tuning, destroying pretrained weights. Slow convergence if learning rate is too low (<1e‑5) for only 8 epochs.
  - **Both:** Poor generalization if train/test split is not stratified or if patient data leaks between sets (not checked in paper).
  - **Data Pipeline:** `augmentedImageDatastore` forgetting to apply the same resizing/RGB conversion to test set, causing dimension mismatches.

- **First 3 experiments:**
  1. **Baseline Replication:** Run the provided MATLAB code exactly as‑is to confirm the reported results (OkanNet ~88%, ResNet‑50 ~96.5%, time ratio ~3.2×). This validates the environment (MATLAB version, GPU, dataset path).
  2. **Architectural Perturbation (OkanNet):** Add one more convolutional block (filters: 128) or increase filters in existing blocks. Does accuracy improve beyond 88%? Does training time increase linearly or super‑linearly? Tests the "shallow is enough" assumption.
  3. **Transfer Learning Depth:** For ResNet‑50, experiment with unfreezing the last convolutional block (`conv5_x`) in addition to the head, using a lower learning rate (e.g., 1e‑5). Does accuracy improve beyond 96.49% within the same 8 epochs? Tests the "minimal fine‑tuning" assumption.
