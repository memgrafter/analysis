# SSAM: Singular Subspace Alignment for Merging Multimodal Large Language Models

## Quick Facts
*   **arXiv ID:** 2603.21584
*   **Source URL:** https://arxiv.org/abs/2603.21584
*   **Reference Count:** 40
*   **Primary Result:** Training-free merging of independently trained multimodal LLMs via singular subspace alignment achieves state-of-the-art accuracy on four multimodal QA benchmarks while preserving specialist capabilities.

## Executive Summary
SSAM addresses the challenge of merging multiple independently trained specialist Multimodal Large Language Models (MLLMs)—each proficient in a distinct input modality—into a single unified model. Unlike prior work, it requires no retraining and no paired multimodal data. The core insight is to align the language-specific parameter updates from each specialist onto a shared, low-rank subspace identified via SVD, thereby mitigating parameter interference. This projection isolates the consensus "knowledge" common across specialists while combining their unique strengths. Evaluated on four audio-visual and video-text QA benchmarks, SSAM substantially outperforms both training-free and jointly trained baselines. Furthermore, it successfully retains the original specialist models' performance on domain-specific tasks like MMLU and OCRBench, demonstrating effective knowledge consolidation without catastrophic forgetting.

## Method Summary
SSAM is a training-free, post-hoc merging algorithm. Given a set of specialist MLLMs that share a common pre-trained language decoder `W0` and have modality-specific encoders, the method operates solely on the fine-tuned language decoder weights `W_i^t`. For each linear layer `l` in the decoder, it first computes the task-specific updates `∆_i,l = W_i^t,l - W0,l`. To find a shared subspace representing common linguistic adaptations, it constructs two covariance matrices from these updates: `A_l = Σ_i ∆_i,l ∆_i,l^⊤` (output space) and `B_l = Σ_i ∆_i,l^⊤ ∆_i,l` (input space). It then performs singular value decomposition (SVD) on both matrices and selects the top-`k` singular vectors to define orthonormal bases `U_c,l` (for output) and `V_c,l` (for input). Each update `∆_i,l` is projected onto this consensus subspace via `∆_i,l^p = U_c,l U_c,l^⊤ ∆_i,l V_c,l V_c,l^⊤`. The projected updates are averaged and scaled by a coefficient `λ` to form the merged update `∆_merged,l`. Finally, the merged language decoder is reconstructed as `W_merged^t = W0 + ∆_merged`. The modality-specific encoders and projectors from any one specialist are retained unchanged.

## Key Results
*   **MUSIC-AVQA:** Achieves 54.97% average accuracy, exceeding the Proj-Only baseline by 7.98 points.
*   **AVQA:** Reaches 81.29%, a 14-point improvement over Proj-Only.
*   **MCUB-3 & MCUB-4:** Obtains 60.35% and 62.27% respectively, surpassing all training-free and jointly trained baselines.
*   **Specialist Preservation:** Maintains performance on domain-specific tasks (e.g., MMLU, OCRBench) without degradation, indicating successful retention of original capabilities.

## Why This Works (Mechanism)
Independently fine-tuned specialist models develop divergent, task-specific updates to the shared language decoder. Directly averaging these `∆_i` matrices causes interference, where conflicting directions in parameter space degrade performance. SSAM mitigates this by identifying a low-dimensional "consensus subspace" that captures the principal directions of variation common across all specialists' updates. Projecting each `∆_i` onto this subspace discards idiosyncratic, model-specific directions that are likely sources of interference. The subsequent averaging then combines only the shared, compatible knowledge components. This process effectively separates the "what" (common semantic knowledge) from the "how" (modality-specific processing quirks), allowing a single decoder to be steered by multiple modality-specific encoders without mutual disruption. The low-rank constraint (`k=128`) is crucial: it is high enough to preserve essential task knowledge but low enough to suppress noise and conflict.

## Foundational Learning
*   **Multimodal Large Language Models (MLLMs):** Architectures that integrate encoders for non-text modalities (vision, audio) with a language model decoder. *Why needed:* SSAM merges specialist MLLMs; understanding their shared-decoder structure is key. *Quick check:* Verify that all specialists use the same pre-trained LLM (e.g., Vicuna-7B) as their textual decoder.
*   **Parameter Interpolation / Model Merging:** The practice of combining model weights (e.g., via averaging) to create a multi-capable model. *Why needed:* SSAM is a refined merging technique that solves interference. *Quick check:* Confirm that naive weight averaging of specialist models leads to significant performance drop on benchmarks.
*   **Singular Value Decomposition (SVD):** Matrix factorization that reveals principal directions (singular vectors) and their importance (singular values). *Why needed:* The core operation to extract the consensus subspace from covariance matrices `A_l` and `B_l`. *Quick check:* For a matrix `M`, `U, Σ, V^T = svd(M)` satisfies `M = U Σ V^T` with `U` and `V` orthogonal.
*   **Low-Rank Approximation:** Representing a matrix using only its top-`k` singular components. *Why needed:* Defines the dimensionality (`k`) of the consensus subspace to filter interference. *Quick check:* Projecting a matrix `M` onto top-`k` left/right singular vectors yields `U_k U_k^T M V_k V_k^T`, its best rank-`k` approximation in Frobenius norm.
*   **Subspace Alignment:** Finding a common geometric space (subspace) where different sets of vectors can be compared or combined. *Why needed:* Aligns the input/output spaces of different `∆_i` to make their projections commensurate for averaging. *Quick check:* Projecting vectors from different models onto the same `U_c, V_c` bases ensures they are expressed in a shared coordinate system.

## Architecture Onboarding
*   **Component Map:**
    Specialist MLLM 1 (Modality A Encoder + Projector + `W0 + ∆_1`) -> Extraction of `∆_1`
    Specialist MLLM 2 (Modality B Encoder + Projector + `W0 + ∆_2`) -> Extraction of `∆_2`
    ... -> All `∆_i` per layer `l` -> Covariance `A_l, B_l` -> SVD -> `U_c,l, V_c,l` -> Projection of all `∆_i,l` -> `∆_merged,l` -> Reconstructed `W_merged^t = W0 + ∆_merged` -> Unified MLLM (Any Encoder + `W_merged^t`)
*   **Critical Path:**
    1.  **Weight Extraction:** Isolate fine-tuned language decoder weights `W_i^t` and the base `W0` from each specialist checkpoint.
    2.  **Delta Computation:** Calculate `∆_i = W_i^t - W0` for every linear layer in the decoder.
    3.  **Subspace Estimation:** For each layer `l`, compute `A_l` and `B_l` from all `∆_i,l` and perform SVD to get top-`k` vectors `U_c,l`, `V_c,l`.
    4.  **Projection & Merge:** Project each `∆_i,l` onto the consensus subspace and compute the scaled average `∆_merged,l`.
    5.  **Model Assembly:** Construct the final decoder `W_merged^t` and plug it into the architecture of one specialist, keeping its encoders fixed.
*   **Design Tradeoffs:**
    *   **Rank `k`:** Low `k` increases interference suppression but risks underfitting (losing specialist knowledge). High `k` preserves more knowledge but may reintroduce conflict. Paper finds `k=128` optimal.
    *   **Uniform vs. Per-Layer `k`:** Using a fixed `k` across all layers is simple and effective. Optimizing `k` per layer could yield gains but increases complexity and risk of overfitting.
    *   **Scaling Coefficient `λ`:** Controls the magnitude of the merged update relative to `W0`. `λ=1` is a natural choice, but tuning on a validation set can adapt to varying degrees of compatibility between specialists.
*   **Failure Signatures:**
    *   **Catastrophic Performance Drop:** Likely due to merging full model weights instead of only language decoder `∆_i`, or incorrectly modifying modality-specific encoder weights.
    *   **Symmetric Degradation with Increasing `k`:** Suggests incorrect computation of `A_l`/`B_l` (e.g., summing `∆_i` first then computing one SVD, or using wrong matrix dimensions).
    *   **No Improvement over Single Specialist:** Indicates the consensus subspace is too restrictive (`k` too small) or the specialists are fundamentally incompatible.
*   **First Three Experiments:**
    1.  **Delta Shape Verification:** Print shapes of `∆_i,l` for a sample layer. They must be identical across specialists and match `W0,l`'s shape. Check that `A_l` is `[d_out, d_out]` and `B_l` is `[d_in, d_in]`.
    2.  **Consensus Subspace Quality:** For a layer, compute reconstruction error `||∆_i,l - U_c U_c^T ∆_i,l V_c V_c^T||_F` for all `i`. Error should be low and similar across specialists, indicating the subspace captures most variance.
    3.  **Single-Modality Sanity Check:** After merging, evaluate the unified model on a task requiring only one specialist's modality (e.g., image-text QA using only the vision specialist's encoder). Performance should be comparable to that specialist's original standalone performance, confirming preservation of individual capabilities.

## Limitations
*   **Checkpoint Dependency:** Results critically depend on obtaining the exact specialist checkpoints from the DAMC source; minor variations would yield different `∆_i` and subspaces.
*   **Hyperparameter Ambiguity:** The protocol for selecting the scaling coefficient `λ` is vague (e.g., no defined validation set or search range).
*   **Evaluation Scope:** Benchmarking is limited to four QA datasets; generalizability to other multimodal tasks (generation, reasoning) is untested.

## Confidence
*   **Merging without retraining is feasible:** **High** (the projection is a deterministic, well-defined linear algebra operation given the inputs).
*   **SOTA on reported benchmarks:** **Medium** (performance is sensitive to exact checkpoint versions and `λ` choice, which are not fully specified).
*   **Specialist capability preservation:** **Medium** (depends on appropriate `λ` and sufficient `k`; the paper shows results but the validation for preservation could be more extensive).
