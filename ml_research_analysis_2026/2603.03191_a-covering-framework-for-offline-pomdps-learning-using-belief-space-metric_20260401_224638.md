# A Covering Framework for Offline POMDPs Learning using Belief Space Metric

## Quick Facts
- **arXiv ID:** 2603.03191
- **Source URL:** https://arxiv.org/abs/2603.03191
- **Reference count:** 40
- **Primary result:** Introduces a belief-space covering framework that replaces exponential history-based coverage with polynomial bounds under Lipschitz continuity, yielding sample complexity that scales polynomially in horizon and memory for offline policy evaluation in POMDPs.

## Executive Summary
This paper tackles the "curse of horizon" and "curse of memory" in offline policy evaluation (OPE) for partially observable Markov decision processes (POMDPs). Traditional OPE methods suffer error that grows exponentially with the planning horizon or memory length because they rely on covering the raw history space. The authors propose a unified analysis framework that uses the metric structure of the belief space (probability distributions over latent states) to define coverage. By assuming that value-relevant functions (e.g., value functions, policies) are Lipschitz continuous in belief space, they derive error bounds that avoid exponential blow-ups. The framework applies to various OPE algorithms, such as double-sampling Bellman error minimization and future-dependent value functions (FDVF). Key results show that belief-space coverage is never worse than history-based coverage, and under smoothness assumptions, sample complexity becomes polynomial. The analysis also reveals that mitigating the "curse of memory" is easier than the "curse of horizon" because only the policy's memory needs abstraction, not the full POMDP dynamics.

## Method Summary
The proposed method constructs an ε-cover of the belief space encountered in the offline dataset, mapping each belief to a nearby cover point. This induces a finite abstract MDP. An OPE algorithm (e.g., double-sampling or FDVF) is then run on this abstract system. The total error is decomposed into (1) abstraction error, bounded by the Lipschitz constant of the target value function times ε, and (2) estimation error on the abstract MDP, which depends on the covering number and a coverage coefficient measuring how well the behavior policy covers the abstract states. The coverage coefficient replaces the history-based concentrability coefficient. Under assumptions of Lipschitz continuity for the policy and value function, and realizability/Bellman completeness for the function class, the sample complexity scales polynomially with the covering number rather than exponentially with horizon or memory length.

## Key Results
- Belief-space coverage bounds (Theorems 4, 5) are no worse than history-based coverage in the worst case.
- For double-sampling Bellman error minimization, the rate is  
  \[
  O\left( \left(C|S|L_E m R_{\max}^2\right)^{1/4} (1-\gamma)^{-3/2} \left( \frac{1}{n} \log \frac{|F|}{\delta} \right)^{1/8} \right)
  \]
- For future-dependent value functions with fast-forgetting policies, the rate is  
  \[
  O\left( \frac{\max\{\|V\|_\infty, \|\Theta\|_\infty\}}{(1-\gamma)^2} \left( \frac{1}{n} \log \frac{|V||\Theta|}{\delta} \right)^{1/4} \right)
  \]
- The "curse of memory" is milder than the "curse of horizon"; structural assumptions (stability, fast-forgetting) yield tighter guarantees.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** An ε-cover of the belief space reduces the effective state space cardinality from exponential in horizon H to polynomial in covering number, provided value-relevant functions are Lipschitz in belief space.
- **Mechanism:** Construct an abstraction ϕε mapping belief b to its nearest cover point. Run OPE algorithm on abstract MDP (|Cε| states). Bound error between true and abstract value functions using Lipschitz constants L_V, L_π (Theorem 2). The covering number C(|S|, L_E, m) scales polynomially under smoothness (Example 1), replacing exponential |B| = O((|O||A|)^H).
- **Core assumption:** Value function V^π is L_V-Lipschitz w.r.t. L1 belief distance; policy π is L_π-Lipschitz (Assumptions 1–2).
- **Evidence anchors:**  
  [abstract] "By assuming value-relevant functions are Lipschitz continuous in the belief space, we derive error bounds that mitigate exponential blow-ups in horizon and memory length."  
  [section 4] Theorem 2 gives ∥V^π_true - [V^π_ϕ]true∥_∞ ≤ L_ϕ ε with L_ϕ = O(L_V, L_π, R_max, γ^{-1}).  
  [corpus] Neighbors [19990, 125579] address similar OPE curses; this paper’s novelty is belief-metric covering vs. history coverage.
- **Break condition:** Belief space is discrete (one-hot, no smoothness) → L_V, L_π potentially exponential → covering number equals |B| → no improvement.

### Mechanism 2
- **Claim:** Coverage measures based on abstract belief occupancy (e.g., L∞ ‖d^{π_ϕ}_e / d_D‖_∞) are never worse than history-based coverage, due to information-theoretic contraction under coarse σ-algebras.
- **Mechanism:** Define abstraction ϕ_T via truncation (memory window T). Show that for one-hot beliefs, the abstract occupancy ratio is pointwise ≤ history-based ratio (Theorems 4–5). This uses variational representation of χ²-divergence and that partitioning can only reduce divergence.
- **Core assumption:** One-hot belief representation (bijection b(τ_h) ↔ τ_h) and abstraction via ϕ_T.
- **Evidence anchors:**  
  [section 4.2] Theorem 5: ‖d^{π_ϕ}_e / d_D‖_∞ ≤ ‖d^{[π_ϕ]_true} / d_{π_b}‖_∞.  
  [abstract] "Our coverage definition based on the belief space metric yields tighter bounds."  
  [table 1] Direct comparison showing abstract coverage ≤ original coverage in worst-case scaling.
- **Break condition:** If ϕ_T distorts distributions significantly (e.g., non-uniform bins), coverage could degrade; but Theorem 4–5 guarantee non-worsening.

### Mechanism 3
- **Claim:** For memory-based policies (FDVF), the "curse of memory" is easier to mitigate than "curse of horizon" because only policy memory needs abstraction, not full POMDP dynamics.
- **Mechanism:** FDVF works with truncated futures f_h = (o_h,a_h,...,o_H,a_H). Abstract by truncating history to window T (˜ϕ_T). Under fast-forgetting (Assumption 7) and realizability, error bound becomes polynomial in T instead of H (Theorem 10). Simpler pipeline: Abstract only policy, not POMDP → avoid Assumption 6 (fast-forgetting POMDP).
- **Core assumption:** Fast-forgetting policy (π_τ depends only on recent T steps) and Bellman completeness.
- **Evidence anchors:**  
  [section 5.2] Theorem 10: bound ∼ √(H) · coverage_T · n^{-1/4}, with coverage_T polynomial in covering number of T-window belief space.  
  [abstract] "Memory-based policies are easier to handle than horizon-based ones... fast-forgetting properties yield tighter guarantees."  
  [section 5.2] "This shows a significant advantage of FDVF... the 'curse of memory' is much easier to handle than 'the curse of horizon'."
- **Break condition:** Policy has long-term dependencies beyond T (slow forgetting) → L_π grows → covering number reverts to exponential in H.

## Foundational Learning
- **Concept: Belief Space Abstraction**  
  Why needed here: POMDP history space grows exponentially; belief space (distributions over latent states) is a sufficient statistic but still infinite. Abstraction via ε-covers compresses it to finite proxy.  
  Quick check: If two histories yield beliefs b₁, b₂ with ‖b₁−b₂‖₁ ≤ ε, can we guarantee their Q-values differ by ≤ L_Q ε? Why or why not?  
  Answer: Only if Q^π is L_Q-Lipschitz in belief space (Assumption 2). Without Lipschitzness, small belief changes can cause large Q-value changes (e.g., near decision boundaries).

- **Concept: Lipschitz Continuity in Metric Spaces**  
  Why needed here: Enables error propagation through abstraction (Theorem 2). Without Lipschitz V/π, covering number does not control approximation error.  
  Quick check: How does Assumption 2 (value stability) relate to the optimal value function’s Lipschitz constant R_max/(1−γ)?  
  Answer: The optimal Q* is R_max/(1−γ)-Lipschitz in belief (since max over actions of L_Q-Lipschitz functions preserves Lipschitzness). This provides a worst-case bound; L_V may be smaller for specific π.

- **Concept: ε-Covering Number**  
  Why needed here: Quantifies complexity of abstract belief space. Sample complexity scales with covering number, which can be polynomial under smoothness.  
  Quick check: If belief space is a subset of ℝ^{|S|} with bounded coefficients in m basis vectors, how does covering number scale with m, |S|, and smoothness exponent?  
  Answer: For a smooth manifold of dimension m embedded in ℝ^{|S|}, covering number scales as O((1/ε)^m). If beliefs lie in a low-dimensional linear subspace (rank m), then C(ε) = O((|S|/ε)^m). Smoothness exponent appears in the Lipschitz constants, not directly in C(ε).

## Architecture Onboarding
- **Component map:**  
  Offline data loader -> Belief estimator -> Abstraction module -> OPE algorithm runner -> Error estimator.
- **Critical path:** Data -> belief computation -> abstraction -> algorithm -> bound. Key dependency: abstraction quality (ε) must be small enough to satisfy realizability (Assumption 4) and Conditions 1–3.
- **Design tradeoffs:**  
  - ε vs. bias-variance: Smaller ε → lower abstraction error (L_ϕ ε) but larger covering number → higher sample complexity term C_π(ε). Choose ε that minimizes total bound (Corollary 1 formula).  
  - Algorithm choice: Double Sampling needs Bellman completeness? Not strictly, but realizability of Q^π_ϕ in F. FDVF needs Bellman completeness for Θ and fast-forgetting assumptions.  
  - Policy stability: If L_π unknown, cannot set ε; need to estimate or bound Lipschitz constants a priori.
- **Failure signatures:**  
  - High empirical coverage C_π(ε) → bound blows up → likely belief space not smooth (check L_V, L_π).  
  - Violation of Condition 1 (min π_b → 0) → µ term explodes → importance weights unstable.  
  - FDVF: poor performance with long H → likely policy not fast-forgetting; increase T until coverage stabilizes.
- **First 3 experiments:**  
  1. Smoothness validation: Run on synthetic POMDP with known smooth dynamics (e.g., linear-Gaussian). Vary ε; verify bound ∝ ε + C_π(ε)^{1/2} matches empirical error.  
  2. Curse comparison: Compare history-based OPE (exponential in H) vs. belief-space OPE (polynomial) as H increases. Use metrics: error vs. H, coverage ratio (Theorem 5).  
  3. FDVF memory window test: Fix H, vary memory window T in abstraction. Show error decreases until T captures relevant memory, then plateaus. Test Theorem 10’s prediction that coverage scales with T not H.

## Limitations
- Belief space covering construction may be computationally heavy and covering numbers can remain large for complex POMDPs.
- Core assumptions (Lipschitz continuity, known emission model, realizability, fast‑forgetting) are strong and may not hold in practice.
- Sample complexity bounds are loose (e.g., exponents as low as 1/8) and may not reflect real sample efficiency.
- The framework does not address unknown models or continuous state/observation spaces.

## Confidence
- Belief‑space ε‑cover reduces effective complexity (Mechanism 1): High under stated assumptions; Medium for practical polynomial scaling due to smoothness dependencies.
- Belief‑space coverage never exceeds history‑based coverage (Mechanism 2): High for truncation abstractions; Medium for general abstractions.
- Memory‑based policies mitigate curse of memory (Mechanism 3): Medium; relies on fast‑forgetting policy assumption which may be restrictive.
