# Regular Fourier Features for Nonstationary Gaussian Processes

## Quick Facts
- arXiv ID: 2602.23006
- Source URL: https://arxiv.org/abs/2602.23006
- Reference count: 8
- Primary result: Regular Fourier features enable efficient, PSD-preserving kernel approximation for nonstationary GPs by discretizing the spectral representation and factorizing the spectral covariance, avoiding the probability assumption of random Fourier features.

## Executive Summary
The paper addresses the challenge of efficiently simulating Gaussian processes with nonstationary kernels. Existing spectral approaches like random Fourier features (RFF) rely on the spectral density being a probability distribution, a requirement that fails for nonstationary processes. The authors propose **regular Fourier features**, which discretize the spectral representation of harmonizable processes on an equidistant grid, thereby preserving the correlation structure among spectral weights. The spectral covariance matrix \(S_{\Delta\omega}^2\) is factorized to obtain a feature map \(\phi(x)\) such that \(K \approx \phi(x)\phi(x')^\dagger\), guaranteeing a positive semi‑definite approximation. For kernel learning, the spectral density is parametrized as \(s(\omega,\omega') = f(\omega)^\dagger f(\omega') + f(-\omega')^\dagger f(-\omega)\), enabling learning of arbitrary complex‑valued densities without symmetrization. Experiments demonstrate accurate approximations for locally stationary kernels (absolute error \(\sim10^{-3}\)) and harmonizable mixture kernels (\(\sim10^{-5}\)), and in learning the Silverman kernel the method achieves a median relative error of 66.04% versus 99.64% for an RBF baseline, highlighting its ability to handle unsymmetrized and complex spectral densities.

## Method Summary
The core method approximates the stochastic Fourier integral by a Riemann sum on a frequency grid from \(-\omega_m\) to \(\omega_m\) with spacing \(\Delta\omega\). The \(m\) spectral increments have covariance \(S_{\Delta\omega}^2\) where \(S(\omega,\omega') = s(\omega,\omega')\). Factorizing \(S_{\Delta\omega}^2 = CC^\dagger\) (e.g., via Cholesky) yields the feature map \(\phi(x) = \alpha(x)C\), where \(\alpha(x)\) contains complex exponentials for the grid frequencies. The resulting kernel \(K(x,x') \approx \phi(x)\phi(x')^\dagger\) is positive semi‑definite by construction. For learning, the spectral density is expressed via a neural network \(f(\omega;\theta)\) as \(s(\omega,\omega') = f(\omega)^\dagger f(\omega') + f(-\omega')^\dagger f(-\omega)\), which is automatically PSD and Hermitian. The feature matrix for data is built in real form as \(L = \sqrt{2}[\operatorname{Re}(\Phi C)\ \operatorname{Im}(\Phi C)]\), where \(\Phi_{i,k} = \exp(i x_i \omega_k)\). Training optimizes the marginal log‑likelihood of a GP with this kernel via gradient‑based methods. Key hyperparameters are the cutoff \(\omega_m\), grid spacing \(\Delta\omega\), and number of features \(m\), with the constraint \(\Delta\omega < \pi/x_{\text{max}}\) to avoid aliasing.

## Key Results
- Achieves absolute kernel approximation error \(\sim10^{-3}\) for locally stationary kernels and \(\sim10^{-5}\) for harmonizable mixture kernels.
- In learning the Silverman kernel, median relative error is 66.04% (best runs <50%), compared to 99.64% for an RBF baseline.
- Successfully handles unsymmetrized and complex‑valued spectral densities, overcoming limitations of RFF‑based approaches.

## Why This Works (Mechanism)

**Mechanism 1: Discretization preserves spectral correlations.**  
- **Claim:** Discretizing the spectral representation on an equidistant grid preserves the correlation structure among spectral weights, enabling accurate low‑rank approximation for nonstationary kernels without probability assumptions.  
- **Mechanism:** The stochastic integral is approximated by a Riemann sum over a frequency grid, yielding spectral increments \(W_k\) whose covariance matrix \(S_{\Delta\omega}^2\) captures off‑diagonal correlations encoding nonstationarity. This contrasts with RFF’s independence assumption.  
- **Core assumption:** Finite spectral support (band‑limited), so the grid covers all non‑negligible frequencies.  
- **Break condition:** If spectral support is infinite, truncation error occurs; if \(\Delta\omega \ge \pi / x_{\text{max}}\), aliasing distorts the kernel.

**Mechanism 2: Factorization guarantees PSD approximation.**  
- **Claim:** Factorizing the spectral matrix \(S_{\Delta\omega}^2 = CC^\dagger\) ensures the low‑rank kernel approximation \(K \approx \phi(x)\phi(x')^\dagger\) is positive semi‑definite by construction.  
- **Mechanism:** The feature map \(\phi(x) = \alpha(x)C\) yields an outer product whose PSD property follows from linear algebra.  
- **Core assumption:** \(S_{\Delta\omega}^2\) is positive semi‑definite and factorable.  
- **Break condition:** If \(S_{\Delta\omega}^2\) is not PSD or severely ill‑conditioned, factorization fails or requires jitter, potentially distorting the approximation.

**Mechanism 3: Parametrization ensures valid spectral density.**  
- **Claim:** Parametrizing the spectral density as \(s(\omega, \omega') = f(\omega)^\dagger f(\omega') + f(-\omega')^\dagger f(-\omega)\) guarantees a valid real‑valued kernel and enables learning without symmetrization.  
- **Mechanism:** This form is inherently PSD and Hermitian; the second term enforces \(s(\omega, \omega') = s(-\omega, -\omega')\) for real kernels. The function \(f\) (e.g., neural network) is learned via marginal likelihood optimization.  
- **Core assumption:** The true spectral density can be well‑approximated by this factorized form; assumes circular symmetry for complex processes.  
- **Break condition:** If the parametrization is too restrictive, learning error persists; optimization is sensitive to initialization.

## Foundational Learning
- **Spectral representation of harmonizable Gaussian processes**  
  *Why needed:* The method builds on representing GPs via stochastic Fourier integrals; understanding harmonizable processes (which include nonstationary cases) is essential.  
  *Quick check:* How does the spectral density \(s(\omega, \omega')\) differ between stationary and harmonizable processes? (Stationary uses a nonnegative real‑valued power spectrum \(S(\omega)\) with \(s(\omega,\omega')\) diagonal; harmonizable allows complex‑valued cross‑spectra, encoding dependence across frequencies.)

- **Positive semi‑definite (PSD) kernels and feature maps**  
  *Why needed:* The approximation must be PSD to define a valid GP; the feature map construction \(\phi(x)\phi(x')^\dagger\) inherently ensures this.  
  *Quick check:* Why does an outer product of a feature map with its conjugate transpose always yield a PSD matrix? (For any vector \(v\), \(v^\dagger \phi(x)\phi(x')^\dagger v = |\phi(x')^\dagger v|^2 \ge 0\).)

- **Low‑rank approximations and computational trade‑offs**  
  *Why needed:* The method reduces cubic scaling to \(O(nm^2)\) by approximating the kernel with \(m \ll n\) features; balancing accuracy and cost is critical.  
  *Quick check:* How does the number of features \(m\) influence the rank of the approximated kernel matrix and its conditioning? (Increasing \(m\) increases rank, improving approximation fidelity; however, computational cost grows as \(O(m^2)\) per training point, and adding features may worsen conditioning if they are noisy.)

## Architecture Onboarding
- **Component map:** Frequency grid designer → Spectral matrix builder → Factorizer → Feature composer → Learning engine.
- **Critical path:**  
  1. Determine \(\omega_m\) from domain knowledge (e.g., Nyquist: \(\omega_m < \pi / \Delta x\)) or spectral decay.  
  2. Set \(\Delta\omega\) such that \(\Delta\omega < \pi / x_{\text{max}}\) to avoid aliasing, where \(x_{\text{max}} = \max_i |x_i|\).  
  3. Choose number of features \(m\) based on desired accuracy and budget; larger \(m\) reduces error but increases cost.  
  4. If spectral density unknown, initialize \(f(\omega)\) (e.g., random weights) and learn parameters.  
  5. Factorize \(S_{\Delta\omega}^2\) to obtain \(C\); add jitter \(\epsilon I\) if ill‑conditioned.  
  6. Compute feature matrices \(L \in \mathbb{R}^{n \times 4r}\) for training (using real valued form from Eq. 23).  
  7. For learning, optimize using gradient‑based methods on marginal log‑likelihood (Eq. 21).
- **Design tradeoffs:**  
  - \(\omega_m\) vs. truncation: Larger \(\omega_m\) captures more spectral mass but may include unrecoverable frequencies and increases \(m\) for fixed \(\Delta\omega\).  
  - \(m\) vs. efficiency: Higher \(m\) improves approximation but raises \(O(nm^2)\) cost; diminishing returns beyond a threshold.  
  - Factorization method: Cholesky is efficient but requires strict PSD; SVD is more robust but costlier; jitter stabilizes but adds bias.  
  - Learning rank \(r\): Higher \(r\) increases model capacity but risks overfitting and optimization instability; lower \(r\) may underfit complex spectral densities.
- **Failure signatures:**  
  - Non‑PSD kernel matrix during factorization or prediction indicates incorrect spectral density or insufficient \(\omega_m\).  
  - High approximation error suggests \(\omega_m\) too low or \(m\) too small; check spectral decay.  
  - Poor learning performance (high variance in errors) signals optimization issues; monitor marginal likelihood convergence.  
  - Aliasing artifacts: Kernel becomes periodic; validate by checking if \(x_{\text{max}} > \pi/\Delta\omega\).
- **First 3 experiments:**  
  1. **Stationary baseline:** Approximate an RBF kernel using this method; compare with RFF and true kernel. Should match RFF as special case.  
  2. **Locally stationary kernel test:** Use the Silverman kernel with known spectral density; sweep \(m\) and \(\omega_m\) to replicate Figure 4 error trends, verifying sensitivity.  
  3. **Kernel learning validation:** Generate data from a nonstationary kernel (e.g., Silverman with \(a=0.5\)), learn using the factorized parametrization, and compare posterior predictions to true GP (as in Figure 5).

## Open Questions the Paper Calls Out
- **1. Extend regular Fourier features to multi‑dimensional non‑separable kernels?**  
  *Basis in paper:* The conclusion states: "Future work could examine multi‑dimensional settings..."  
  *Why unresolved:* Current method assumes separable product kernels, limiting applicability to non‑separable dependencies.  
  *What evidence would resolve it:* Develop and empirically validate a non‑product factorization (e.g., tensor‑based) for multi‑dimensional spectral densities.

- **2. Design adaptive frequency selection for non‑uniform spectral densities.**  
  *Basis:* "develop adaptive frequency selection schemes".  
  *Why unresolved:* Equidistant grids are inefficient when spectral mass is concentrated or varies across frequencies.  
  *What evidence would resolve it:* An algorithm that refines the frequency grid based on spectral density magnitude, with experiments showing improved efficiency.

- **3. Derive error bounds for the low‑rank kernel approximation in terms of \(m\), \(\omega_m\), and spectral density properties.**  
  *Basis:* "derive error bounds".  
  *Why unresolved:* Only empirical error analysis is provided; no theoretical guidance for hyperparameter selection.  
  *What evidence would resolve it:* Mathematical analysis linking discretization error to \(m\) and \(\omega_m\), validated on various benchmark kernels.

- **4. Integrate Fourier feature approximation with approximate inference methods (e.g., variational GPs) for large‑scale learning.**  
  *Basis:* "combine our approach with approximate inference methods".  
  *Why unresolved:* Direct kernel matrix computation scales quadratically with \(n\), hindering scalability.  
  *What evidence would resolve it:* Combine the method with inducing point variational inference and demonstrate reduced training complexity on large datasets.

## Limitations
- **Neural architecture details unspecified:** Activation functions, output scaling, initialization, and learning rate schedule are not specified, affecting reproducibility.
- **Truncation bias for non‑band‑limited kernels:** Finite \(\omega_m\) introduces error with no guidance on selection; risk of aliasing if \(\Delta\omega \ge \pi/x_{\text{max}}\) not verified.
- **Factorization stability:** \(S_{\Delta\omega}^2\) must be PSD; near‑singular matrices require jitter, adding bias and potentially degrading accuracy.
