# Efficient endometrial carcinoma screening via cross-modal synthesis and gradient distillation

## Quick Facts
- arXiv ID: 2602.19822
- Source URL: https://arxiv.org/abs/2602.19822
- Reference count: 40
- Primary result: Achieved 99.5% sensitivity, 97.2% specificity, and 0.987 AUC at 0.289 GFLOPs for endometrial carcinoma screening.

## Executive Summary
Endometrial carcinoma screening via transvaginal ultrasound faces challenges of severe class imbalance and subtle myometrial invasion features. This paper introduces a two-stage framework: first, a Structure-Guided CycleGAN synthesizes high-fidelity ultrasound from unpaired MRI to augment scarce pathological data; second, a lightweight screening network employs gradient distillation to transfer knowledge from a teacher model and dynamically focus sparse attention on diagnostic regions. Evaluated on a multicenter cohort of 7,951 participants, the system surpasses expert sonographer performance and achieves computationally efficient metrics suitable for real-time deployment in resource-constrained primary care settings.

## Method Summary
Reproduction details are not provided. The proposed framework comprises two stages. Stage 1 uses a Structure-Guided CycleGAN to generate synthetic ultrasound images from MRI scans without paired supervision, preserving anatomical junctions to realistically represent myometrial invasion. Stage 2 trains a computationally lightweight screening network via gradient distillation, where a pre-trained teacher model guides the student to mimic its behavior while the student learns to apply sparse, dynamic attention to regions indicative of carcinoma. This approach addresses data scarcity and computational constraints simultaneously.

## Key Results
- On 7,951 participants: 99.5% sensitivity, 97.2% specificity, 0.987 AUC.
- Extremely low computational cost: 0.289 GFLOPs.
- Performance exceeds that of expert sonographers.
- Enables real-time deployment in primary care settings.

## Why This Works (Mechanism)
Cross-modal synthesis mitigates the scarcity of pathological ultrasound samples by leveraging abundant MRI data to generate high-fidelity, anatomically consistent ultrasound images, thereby enriching the training set for rare positive cases. Gradient distillation allows the efficient student network to inherit the diagnostic patterns of a larger teacher model while dynamically focusing sparse attention on the myometrial invasion features critical for screening, maintaining accuracy without the computational burden of full model complexity.

## Architecture Onboarding
Component map: MRI input -> Structure-Guided CycleGAN -> synthetic ultrasound -> combined with real ultrasound -> train lightweight screening network (with gradient distillation from teacher) -> carcinoma probability output  
Critical path: Data synthesis (CycleGAN) → Dataset augmentation (synthetic + real) → Model training (distillation) → Inference.  
Design tradeoffs: Unpaired synthesis (no paired supervision) vs. fidelity risk (artefacts); Model size (student efficiency) vs. accuracy (teacher knowledge transfer).  
Failure signatures: Synthetic ultrasound with anatomical inconsistencies; Attention mechanism mislocalizing away from invasion zones; Poor generalization to new scanner vendors or protocols.
