# CiQi-Agent: Aligning Vision, Tools and Aesthetics in Multimodal Agent for Cultural Reasoning on Chinese Porcelains

## Quick Facts
- **arXiv ID:** 2603.28474
- **Source URL:** https://arxiv.org/abs/2603.28474
- **Reference count:** 40
- **Primary result:** A 7B-parameter domain-specific multimodal agent achieves state-of-the-art accuracy on Chinese porcelain connoisseurship, outperforming much larger models like GPT-5.

## Executive Summary
Antique Chinese porcelain connoisseurship is a specialized expertise requiring deep knowledge of subtle visual attributes. This paper introduces CiQi-Agent, a multimodal agent designed to democratize this skill. It integrates a vision zoom-in tool and retrieval-augmented generation (RAG) for fine-grained analysis across six key attributes (dynasty, reign period, kiln site, glaze color, decorative motif, vessel shape). The agent is trained on a new large-scale, expert-annotated dataset, CiQi-VQA, using a two-phase pipeline combining supervised fine-tuning and reinforcement learning. On the custom CiQi-Bench benchmark, CiQi-Agent significantly outperforms leading general-purpose models like GPT-5 in both multiple-choice and free-form generation tasks.

## Method Summary
The core method involves training a Qwen2.5-VL-7B-Instruct model to act as a tool-using agent. It is fine-tuned on the CiQi-VQA dataset (29,596 specimens, 557,940 VQA pairs) which provides structured supervision for the six connoisseurship attributes. The agent can autonomously invoke two tools: an `image_zoom_in_tool` to extract high-resolution patches of salient regions, and retrieval tools (`search_image` and `search_text`) to fetch semantically similar records and descriptive text from a curated database. Training proceeds in two phases: Phase I uses reinforcement learning (GRPO) with a reward encouraging tool calls to bootstrap tool-use strategies; Phase II integrates these synthetic trajectories into further supervised fine-tuning and then applies reinforcement learning with an accuracy-weighted reward to align tool invocation with final answer correctness.

## Key Results
- CiQi-Agent (7B) achieves **81.5%** average accuracy on multiple-choice evaluation, surpassing GPT-5's 75.8%.
- In free-form generation, it achieves **66.7%** average attribute similarity, significantly exceeding GPT-5's 48.0%.
- Ablation studies confirm that both the supervised fine-tuning on the expert dataset and the reinforcement learning phases are essential, with tool integration providing substantial additional gains.

## Why This Works (Mechanism)
### Mechanism 1: Tool-Augmented Fine-Grained Reasoning
- **Claim:** Tool use (vision zoom-in + retrieval) enables analysis beyond single-pass perception by grounding judgments in external evidence.
- **Mechanism:** The agent decides when to call tools. The zoom-in tool extracts detailed patches (e.g., for glaze cracks), while retrieval tools fetch similar porcelain records and domain texts. The model must then synthesize this retrieved multimodal evidence into its reasoning, reducing hallucination and improving precision on nuanced attributes like kiln site or motif.
- **Core assumption:** The domain-adapted base model can correctly interpret tool outputs (e.g., match a retrieved "crackle pattern" image to its zoomed-in view) and integrate them.
- **Evidence anchors:** Abstract describes integration of visual/textual evidence; Section 4.1 details tool designs; Section 5.3 (Table 5) shows tools only help when combined with the domain-adapted model, not base models.
- **Break condition:** If the retrieval database lacks relevant exemplars for a rare type, or the model misinterprets tool outputs, noise may be introduced.

### Mechanism 2: Two-Phase Training for Strategic Tool Use
- **Claim:** The SFT → Phase I RL → Phase II SFT → Phase II RL pipeline effectively aligns tool-calling behavior with accuracy, avoiding the inefficiency of pure RL.
- **Mechanism:** Phase I SFT establishes domain knowledge and tool syntax. Phase I RL (GRPO with a tool-count reward) bootstraps the mechanical skill of invoking tools and generates synthetic trajectories. Phase II SFT incorporates these to teach *why* to call tools. Phase II RL uses a reweighted reward (`R_tool = (0.9 + 0.1·m_tool)·R_acc`) to fine-tune strategy, rewarding tool calls only when they contribute to accuracy.
- **Core assumption:** Phase I trajectories are sufficiently high-quality to bootstrap Phase II, and the reweighted reward can distinguish strategic use from spamming.
- **Evidence anchors:** Abstract outlines the pipeline; Section 4.2 states the two-phase goals; Section 5.3 (Table 4) shows RL after SFT yields large gains (e.g., kiln accuracy 67.2%→81.8%).
- **Break condition:** Systematic errors in Phase I trajectories could entrench poor strategies; the accuracy-conditioned reward might not credit tool use with delayed benefits.

### Mechanism 3: Large-Scale Expert Dataset for Domain Adaptation
- **Claim:** The CiQi-VQA dataset provides the high-quality, fine-grained supervision necessary for learning the domain-specific taxonomy and visual feature mappings.
- **Mechanism:** The dataset encodes six attributes with hundreds of sub-categories (e.g., 248 motifs) in standardized nomenclature. SFT on this data teaches the model the domain vocabulary, visual distinctions, and structured output format. Its scale (29k specimens, 557k VQA pairs) and diversity prevent overfitting.
- **Core assumption:** Expert annotations and LLM-assisted cleaning yield consistent labels across the long-tail of varieties; a 7B model can generalize from this data.
- **Evidence anchors:** Abstract provides dataset stats; Section 3.1 details expert curation and VQA generation; Section 5.2 shows the 7B model outperforms 70B+ models; Supplement (Table 6) shows greater category diversity than prior datasets.
- **Break condition:** Hidden label inconsistencies (e.g., ambiguous dynasty assignments) could lead to spurious correlations; under-represented attributes may still suffer.

## Foundational Learning
- **Concept:** Multimodal Reinforcement Learning with Tool Use (e.g., GRPO, reward shaping).
  - **Why needed here:** The agent must learn *when* and *how* to call tools (discrete actions) to improve a downstream accuracy reward, which standard SFT does not optimize for. The two-phase curriculum addresses the exploration problem.
  - **Quick check:** How does the Phase II reward function (`R_tool = (0.9 + 0.1·m_tool)·R_acc`) encourage strategic tool use versus gratuitous invocation?
- **Concept:** Retrieval-Augmented Generation (RAG) for Multimodal Data.
  - **Why needed here:** Connoisseurship requires comparing an input against a vast reference corpus. The agent must retrieve *relevant* multimodal records (images and text) and fuse evidence. The dual-space (CLIP image + text embeddings) retrieval is designed for this multimodal knowledge base.
  - **Quick check:** Why use separate CLIP image and text embeddings for the `search_text` tool instead of a single multimodal encoder?
- **Concept:** Fine-Grained Visual Classification with Domain Taxonomies.
  - **Why needed here:** The six attributes have hundreds of sub-categories (e.g., 248 motifs). The model must learn subtle visual distinctions (e.g., "tendrilled lotus" vs. "peony scroll") and map them to a structured nomenclature, extending generic object recognition.
  - **Quick check:** What visual feature distinguishes a "Guan ware celadon" from a "Longquan celadon"?

## Architecture Onboarding
- **Component map:** Qwen2.5-VL-7B-Instruct (Base Model) -> Tools (`image_zoom_in_tool`, `search_image`, `search_text`) -> Training Pipeline (SFT on CiQi-VQA -> Phase I RL (GRPO, tool-call reward) -> Phase II SFT (with Phase I trajectories) -> Phase II RL (accuracy-weighted tool reward)) -> RAG Database (8,161 images + 49,606 texts) -> Evaluation (CiQi-Bench with LLM-as-Judge)
- **Critical path:** 1) Data Curation (create CiQi-VQA and non-overlapping RAG DB) -> 2) Base Model SFT -> 3) Phase I RL (bootstrap tool use) -> 4) Phase II SFT (align trajectories) -> 5) Phase II RL (optimize for accuracy) -> 6) Evaluation on CiQi-Bench.
- **Design tradeoffs:**
  - **Tool number vs. Efficiency:** Limiting tool calls to 4 per query prevents infinite loops but may cut short needed multi-step reasoning.
  - **Reward shaping:** Phase I's pure tool-count reward promotes exploration but risks spamming; Phase II's accuracy-weighting corrects this but may converge prematurely if accuracy signal is noisy.
  - **Dataset scale vs. Cost:** Building a 29k expert-annotated dataset is expensive but necessary; ablation shows SFT on this data is the largest single boost.
- **Failure signatures:**
  - **Tool misuse:** Calls `search_image` with an already zoomed-in patch, or enters tool-call loops.
  - **Retrieval irrelevant evidence:** Returns superficially similar items (e.g., same color, wrong dynasty) that the agent fails to discriminate.
  - **Format deviation:** Fails to place final answer in `<answer>` tags, causing LLM-as-Judge penalty.
  - **Attribute conflation:** Confuses kiln site with glaze color (e.g., calling "Jingdezhen" a glaze).
- **First 3 experiments:**
  1. **Tool Ablation:** Disable each tool (zoom-in, image retrieval, text retrieval) individually on CiQi-Bench to quantify per-tool contribution.
  2. **Phase Ablation:** Train models with only SFT, or SFT+Phase I RL (no Phase II RL), comparing to full pipeline to isolate Phase II RL's strategic refinement.
  3. **Cross-Dataset Transfer:** Evaluate on a prior porcelain dataset (e.g., Hu et al.) to test generalization beyond CiQi-VQA's taxonomy and database.

## Open Questions the Paper Calls Out
1. Can CiQi-Agent reliably distinguish genuine antique Chinese porcelains from later imitations (authentication)?
2. To what extent does the CiQi-Agent framework generalize to other domains of cultural heritage (e.g., ancient coins, calligraphy, paintings)?
3. What specific visual cues or reasoning patterns trigger tool invocation in CiQi-Agent, and are these optimal for accuracy?
4. Do the model's textual descriptions capture nuanced aesthetic qualities (e.g., artistic style, craftsmanship subtlety) that human experts prioritize, beyond the six factual attributes?

## Limitations
- **Annotation consistency:** No reported inter-annotator agreement; potential label noise could affect learning.
- **Tool dependency:** Retrieval coverage may be incomplete for rare types; model may misinterpret tool outputs without proper supervision.
- **Training transparency:** GRPO hyperparameters and prompt templates are not fully specified, hindering exact replication.
- **Benchmark scope:** Evaluation is solely on CiQi-Bench; performance on other cultural heritage tasks is unknown.

## Next Checks
1. **Cross-dataset transfer:** Test on an independent porcelain collection (e.g., from a different museum) to evaluate generalization beyond CiQi-VQA's taxonomy and retrieval database.
2. **Retrieval robustness:** Corrupt retrieval results with random/distractor items and measure accuracy drop to quantify reliance on retrieval precision.
3. **Tool call necessity:** For correct predictions, remove tool outputs and re-query; if accuracy remains high, tools may be superfluous in many cases.
