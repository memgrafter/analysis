# ShapleyLaw: A Game-Theoretic Approach to Multilingual Scaling Laws

## Quick Facts
- **arXiv ID:** 2603.17945
- **Source URL:** https://arxiv.org/abs/2603.17945
- **Reference count:** 40
- **Primary result:** Uses Shapley values from cooperative game theory to quantify cross-lingual transfer, integrates into a scaling law (ShapleyLaw) that accurately predicts per-language test loss and yields optimized multilingual mixtures.

## Executive Summary
Multilingual pretraining often uses suboptimal language mixtures because existing scaling laws ignore cross-lingual transfer between languages from different families. This paper frames pretraining as a cooperative game where each language is a player; the Shapley value measures each language's marginal contribution to reducing loss on another language, quantifying transfer. This transfer metric is combined with Chinchilla scaling to form ShapleyLaw, which predicts per-language test loss based on model size, data size, and mixture ratios. ShapleyLaw achieves high predictive accuracy (R² up to 0.990) across scales and mixtures, outperforms FamilyLaw, and when used to optimize mixtures, reduces pretraining loss in real experiments. Predicted loss correlates strongly with downstream task accuracy (R² up to 0.996), validating its utility. Monte Carlo approximation makes the approach scalable.

## Method Summary
The method proceeds in three stages. First, compute cross-lingual transfer via Shapley values: treat each language as a player in a cooperative game where the payoff is the reduction in test loss on a target language when training on a subset of languages with uniform mixing. For each target language, the Shapley value ϕ_{i,j} for training language i is the average marginal contribution over all subsets, either computed exactly (for small language sets) or approximated via Monte Carlo sampling. Second, normalize these Shapley values to [0,1] (exponential normalization) to get a transfer matrix ϕ^N. Then define an aggregate transfer metric Θ_j = Σ_i p_i * ϕ^N_{i,j} that summarizes the mixture's effect on target language j. Third, extend the Chinchilla scaling law: L_j(N,D,p) = (E_j + A_j/N^{α_j} + B_j/D^{β_j}) * (Θ_j)^{-γ_j}. Fit parameters (E_j, A_j, B_j, α_j, β_j, γ_j) by regression on observed losses from models trained at various scales and mixtures. For optimization, solve min_p Σ_j w_j L_j(N,D,p) subject to mixture constraints, using a closed-form diagonal approximation with cross-lingual correction and clipping.

## Key Results
- ShapleyLaw accurately predicts held-out test loss across model scales and mixtures, with R² up to 0.990, significantly outperforming FamilyLaw which fails to capture cross-family transfer.
- Optimizing language mixtures using ShapleyLaw yields lower cross-entropy loss than uniform or family-based baselines in actual pretraining experiments.
- Predicted pretraining loss strongly correlates with downstream task accuracy across multiple benchmarks (R² up to 0.996), validating the loss as a proxy for downstream performance.

## Why This Works (Mechanism)
### Mechanism 1: Shapley Value Quantifies Transfer
- **Claim:** The Shapley value fairly quantifies cross-lingual transfer by measuring each training language's marginal contribution to reducing test loss on a target language.
- **Mechanism:** For multilingual pretraining game with language set K, define payoff v_j(S) = loss reduction when training on subset S (uniform mixture). Compute ϕ_{i,j} = Σ_{S⊆K\{i}} [|S|!(K-|S|-1)! / K!] * [v_j(S∪{i}) - v_j(S)]. This weights subsets by their frequency in random permutations, averaging marginal contributions.
- **Core assumption:** Cross-lingual transfer is additive and cooperative; languages jointly contribute to performance gains in a way that can be partitioned fairly via Shapley's axioms (efficiency, symmetry, null player).
- **Evidence anchors:** The paper explicitly frames pretraining as a cooperative game and derives the Shapley formula; it shows existing work ignores cross-family transfer while ShapleyLaw captures it at language level.
- **Break condition:** Violation of efficiency (total payoff not fully allocated) or highly unstable marginal contributions across random seeds, indicating non-cooperative interactions or high variance in utility estimation.

### Mechanism 2: Aggregate Transfer Rescales Chinchilla Law
- **Claim:** The aggregate cross-lingual transfer Θ_j = Σ_i p_i * ϕ^N_{i,j} rescales the standard Chinchilla law to capture mixture effects multiplicatively.
- **Mechanism:** The baseline Chinchilla scaling L_chin_j(N,D) = E_j + A_j/N^{α_j} + B_j/D^{β_j} is multiplied by (Θ_j)^{-γ_j}. Θ_j linearly combines mixture ratios p_i with normalized Shapley values ϕ^N_{i,j} (exponentially normalized to [0,1]).
- **Core assumption:** Test loss depends on a single aggregate metric Θ_j rather than full interaction terms; normalization makes Shapley values comparable across target languages while preserving relative transfer rankings.
- **Evidence anchors:** The paper presents Equation (3) defining L_j(N,D,p) and shows in Figure 1b that Θ_j alone explains most loss variation across mixtures (R²=0.990).
- **Break condition:** If cross-lingual interactions are inherently non-linear in p (e.g., synergy effects where combination matters beyond sum), or if normalization distorts critical magnitude information for some language pairs.

### Mechanism 3: Transferability Across Scales
- **Claim:** Normalized Shapley values computed at a small model/data scale accurately predict loss at much larger scales.
- **Mechanism:** Exponential normalization ϕ^N_{i,j} = exp(ϕ_{i,j} - max_{i'} ϕ_{i',j}) removes absolute scale of contributions, preserving relative transfer rankings and magnitudes hypothesized to be stable across scales. These normalized SVs are then treated as fixed parameters in ShapleyLaw for larger (N,D).
- **Core assumption:** Cross-lingual transfer patterns (which language helps which, and relative strengths) are scale-invariant; i.e., they do not fundamentally change as model capacity or data volume increases.
- **Evidence anchors:** The paper states this as a key finding and demonstrates in Figure 1b that using small-scale (50M,50B) normalized SVs predicts losses at scales up to 1.46B/100B with high R².
- **Break condition:** If transfer hierarchies shift with scale—for example, high-resource languages dominate more at larger scales, or low-resource transfer emerges only with sufficient capacity—then small-scale SVs become uninformative for large-scale optimization.

## Foundational Learning
- **Shapley Value (Cooperative Game Theory):** A solution concept that fairly distributes total payoff among players based on marginal contributions. *Why needed here:* It is the core metric quantifying each language's contribution to target language performance. - **Multilingual Scaling Laws:** Extensions of classic scaling laws (e.g., Chinchilla) that model test loss as a function of model size (N), data size (D), and sometimes mixture ratios. *Why needed here:* The paper integrates cross-lingual transfer into a scaling law to predict per-language loss. *Quick check:* How does FamilyLaw's family-level aggregation differ from ShapleyLaw's language-level Θ_j, and why does that matter for optimization?

- **Cross-lingual Transfer:** The phenomenon where training on one language improves model performance on another, due to shared representations, lexical overlap, or structural similarities. *Why needed here:* The entire premise is that languages transfer knowledge; understanding why transfer occurs and why family-based assumptions are insufficient is key. *Quick check:* Provide an example from the paper where two languages from different families show strong transfer, and hypothesize what linguistic factor might explain it.

## Architecture Onboarding
- **Component map:** SV Computation Module → Normalization Module → Mixture Design Space → ShapleyLaw Fitter → Optimizer → Validation Harness
- **Critical path:**
  1. Choose language set K and collect corpora with token counts.
  2. Compute Shapley values at small scale (N', D') via exact or MC approximation.
  3. Normalize SVs to get transfer matrix.
  4. For target (N, D), design mixture experiments (varying p) and pretrain models to collect (p, L_j) pairs.
  5. Fit ShapleyLaw parameters via non-linear regression.
  6. Optimize p* for desired weights w_j using closed-form solution with clipping.
  7. Validate by pretraining with p* and comparing loss to baselines.

- **Design tradeoffs:**
  - Exact vs MC SV: Exact (2^K -1 models) is ground truth but exponential; MC (T permutations) reduces cost to O(K² log K) but introduces estimation error. Choose T to balance accuracy and compute.
  - Normalization: Exponential normalization preserves ordering smoothly; linear min-max is simpler but may distort relative differences.
  - Mixture constraints: Hard caps p_i ≤ D̄_i/D from corpus limits may make optimization infeasible; requires clipping and redistribution.
  - Fitting regime: Controlled mixtures isolate p variation for clean Θ-L relationship; random mixtures test generalization but may include outliers.

- **Failure signatures:**
  - Poor fit (R² < 0.8): Check monotonicity of Θ_j vs loss; may indicate inadequate normalization or non-linear effects.
  - Extreme p_i (e.g., p_i → 0 for many languages): Could signal overestimated negative transfer or violated corpus constraints; inspect Shapley matrix for unexpectedly low self-transfer.
  - MC approximation divergence: High MAE between approx and exact SVs; increase T or stabilize utility evaluation.
  - Downstream mismatch: High pretraining loss correlation but poor downstream accuracy; suggests test loss is not a perfect proxy for target tasks.

## Open Questions the Paper Calls Out
1. Do Shapley values accurately capture causal cross-lingual transfer, or are they confounded by language correlations and data sparsity? The paper assumes uniform subsets but actual pretraining uses non-uniform mixtures, possibly biasing contributions. No validation against ground-truth transfer mechanisms.
2. How does ShapleyLaw scale to dozens or hundreds of languages, and what sample complexity does Monte Carlo approximation require in high dimensions? Experiments only use K=7; empirical scaling beyond that is untested.
3. Why does the correlation between pretraining loss and downstream accuracy vary across task-language pairs (e.g., R² from 0.675 to 0.996), and does ShapleyLaw remain useful for tasks with weak loss-accuracy correlation? The paper does not analyze deviations or test optimization on such tasks.
4. How should importance weights w_j be determined for mixture optimization in practice, and how sensitive are optimal mixtures to weight choices? The paper uses ad hoc weights without principled justification; operational metrics for weighting are unclear.

## Limitations
- Exact hyperparameters for small-scale Shapley value pretraining (e.g., weight decay, Z-loss parameters) are unspecified, risking replication variance.
- The distribution used to sample "random mixtures" (e.g., Dirichlet concentration) is not detailed, affecting diversity of aggregate transfer Θ_j in fitting.
- Downstream evaluation protocols (prompt templates, dataset versions for XWinograd/XStoryCloze) are omitted, hindering full benchmark replication.

## Confidence
- Shapley value quantification: Medium (cooperative game framing is sound but assumes additive, stable marginal contributions; real interactions may be non-cooperative).
- Scaling law integration (ShapleyLaw): High (held-out R² up to 0.990 strongly supports multiplicative rescaling by Θ_j).
- Transferability across scales: Medium (evidence limited to 4 scales; break condition exists if transfer hierarchies shift with capacity).
- Downstream correlation: High (R² up to 0.996), but task-specific nuances may limit practical utility.

## Next Checks
1. **Scale-invariance stress test:** Compute exact Shapley values at two distinct small scales (e.g., 50M/50B vs 100M/100B). Compare normalized matrices via rank correlation (Kendall τ) per target language. Significant drop (<0.8) would refute transferability.
2. **Normalization sensitivity analysis:** Re-fit ShapleyLaw using linear min-max or no normalization. Compare held-out R² and optimized mixture performance; degradation >0.1 R² would indicate exponential normalization is critical.
3. **Mixture optimization under corpus constraints:** Implement clipping-and-redistribution (Eq. 7). For tight corpus caps, compare optimized p* from ShapleyLaw vs uniform baseline by computing actual feasible weighted loss after constraint enforcement to detect over-optimism.
