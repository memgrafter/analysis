# AgentAssay: Token-Efficient Regression Testing for Non-Deterministic AI Agent Workflows

## Quick Facts
- **arXiv ID**: 2603.02601
- **Source URL**: https://arxiv.org/abs/2603.02601
- **Reference count**: 40
- **Primary result**: A framework for regression testing non-deterministic AI agents using stochastic semantics and behavioral fingerprinting, achieving 78–100% cost reduction while maintaining statistical guarantees.

## Executive Summary
AgentAssay addresses the lack of rigorous regression testing for non-deterministic AI agent workflows, where traditional deterministic pass/fail metrics fail to detect subtle behavioral changes. It introduces a stochastic test semantics with three-valued verdicts (PASS/FAIL/INCONCLUSIVE) grounded in hypothesis testing. Key innovations include behavioral fingerprinting, which compresses execution traces into low-dimensional vectors for sensitive multivariate change detection, and a token-efficient pipeline leveraging trace-first offline analysis, adaptive budgets, and sequential testing. Evaluated across 5 models and 7,605 trials, the system reduces testing costs by up to 100% and increases detection power dramatically compared to univariate pass-rate methods.

## Method Summary
AgentAssay replaces deterministic assertions with statistical hypothesis testing on agent execution outcomes. For each test scenario, it collects a sequence of binary pass/fail trial results. Using Wilson confidence intervals or Sequential Probability Ratio Tests (SPRT), it issues a three-valued verdict (PASS/FAIL/INCONCLUSIVE) with controlled type I (α) and type II (β) errors. To detect regressions that don’t affect pass rates, it extracts a behavioral fingerprint—a compact feature vector from each trace capturing tool usage, reasoning patterns, and costs. A Hotelling’s T² test on these vectors identifies multivariate mean shifts. The framework minimizes token costs by reusing stored traces for offline analysis (coverage, contracts, metamorphic relations), adapting trial budgets based on fingerprint variance, using cheaper proxy models via multi-fidelity combinations, and warm-starting SPRT with prior data.

## Key Results
- Behavioral fingerprinting with Hotelling’s T² achieves 86% statistical power to detect subtle regressions where binary pass-rate testing has 0% power.
- SPRT reduces the number of required live trials by 78% compared to fixed-sample testing while maintaining (α, β) guarantees.
- The full token-efficient pipeline (trace-first + adaptive budgets + multi-fidelity) yields 100% cost savings in CI/CD scenarios with mature trace stores.
- Open-source implementation includes 20,000+ lines of Python, 751 tests, and adapters for 10 major agent frameworks.

## Why This Works (Mechanism)

### Behavioral Fingerprinting
Agent behavior, despite stochastic textual outputs, concentrates on a low-dimensional manifold (effective dimension 3–8). Fingerprints compress raw traces (~20–40 raw features) into these 3–8 dimensions via PCA, capturing tool usage, structural complexity, output characteristics, reasoning patterns, and costs. Hotelling’s T² on these vectors detects distributional shifts invisible to univariate pass-rate metrics. This works because many regressions (e.g., slower tool chains, altered reasoning depth) change the fingerprint without affecting final correctness.

### Trace-First Offline Analysis
Pre-recorded execution traces are stored versioned. For non-regression tests (coverage, contracts, metamorphic relations, mutation evaluation), metrics are computed directly from stored traces at zero marginal token cost. For regression, candidate fingerprints are compared against stored baseline fingerprints without re-executing the baseline. This shifts the cost profile: initial trace generation is amortized, and mature trace stores enable nearly free regression checks.

### Sequential Probability Ratio Test (SPRT)
SPRT treats trial outcomes as i.i.d. Bernoulli draws and sequentially computes the log-likelihood ratio between hypotheses H₀ (pass rate ≥ threshold) and H₁ (pass rate ≤ threshold - δ). It stops as soon as the ratio crosses pre-calculated boundaries corresponding to α and β, avoiding a fixed sample size. This adapts to the observed pass rate: large margins lead to early stopping, while ambiguous cases automatically collect more data. Warm-starting with prior trials further cuts costs.

## Foundational Learning

### Concept: Statistical Hypothesis Testing (α, β, Confidence Intervals)
- **Why needed**: The entire stochastic semantics relies on Neyman-Pearson hypothesis testing to control false alarms (α) and missed detections (β), and on confidence intervals to quantify uncertainty in pass rates.
- **Quick check**: Given 45 passes out of 50 trials at α=0.05, compute the Wilson confidence interval. Does the agent pass at threshold 0.85? What if you had 90 passes out of 100 trials?

### Concept: Multivariate Statistical Testing (Hotelling's T²)
- **Why needed**: Behavioral fingerprinting uses Hotelling’s T² to detect multivariate mean shifts. This requires understanding Mahalanobis distance, PCA for dimensionality reduction, and how sample size scales with effective dimension.
- **Quick check**: If the effective fingerprint dimension is 4 and the Mahalanobis distance between baseline and candidate is 1.5, approximately how many trials are needed for 80% power at α=0.05, compared to a univariate test with Cohen's h=0.5?

### Concept: Software Testing Fundamentals (Coverage, Mutation, Metamorphic)
- **Why needed**: AgentAssay extends traditional coverage (tool/path), mutation (prompt/tool/model), and metamorphic relations to the agent domain. Understanding these classic concepts is prerequisite to grasping agent-specific adaptations and their limitations (e.g., the coupling effect for agent mutations).
- **Quick check**: What is the 'coupling effect' in mutation testing, and why is it particularly challenging to assume for agent mutations like prompt reordering?

## Architecture Onboarding

Component map:
Core Engine -> Token-Efficient Engine (Fingerprinting, Budgets, Trace-first, Multi-fidelity) -> Coverage Analyzer & Mutation & Metamorphic Engine <- Framework Adapters (LangGraph, CrewAI, AutoGen, etc.) -> Infrastructure Layer (CLI, pytest Plugin, Trace Store, Reports)

Critical path for CI/CD regression check with trace store: 1) Load baseline traces. 2) Check for candidate traces; if missing, run adaptive trials (possibly with proxy models). 3) Extract fingerprints from all traces. 4) Apply Hotelling’s T² and/or SPRT. 5) Aggregate verdicts with multiple testing correction. 6) Compute coverage. 7) Apply deployment gate.

Design tradeoffs: Statistical rigor vs. cost (trace store completeness is critical); offline vs. online analysis (stale traces risk); multivariate detection power vs. interpretability; adaptive sampling vs. risk of under-sampling; proxy models vs. required correlation (ρ≥0.6).

Failure signatures: High inconclusive rate (insufficient trials/variance); zero fingerprint power (features non-discriminatory); SPRT not terminating (non-i.i.d. data); low coverage (untested paths); mutation score near 0% (lenient evaluator); trace store misses (incomplete data).

First 3 experiments: 1) Run a simple test with varying trials; observe Wilson interval and verdict changes. 2) Test trace-first: add a trace, run regression (should skip baseline execution), delete trace and rerun (should fall back to live). 3) Create a mutant with identical pass rate; verify univariate test fails (0% power) while fingerprint test detects (high power).

## Open Questions the Paper Calls Out

- **Compositional testing for multi-agent systems**: How to formally derive pipeline-level test guarantees from individual agent results, analogous to type-safe composition.
- **Optimal fingerprint construction**: What features guarantee a low-dimensional manifold and maximize detection power for all regression types?
- **Equivalent mutant problem**: How to address undecidable behavioral equivalence for agent mutations; current heuristic (no difference after *n* trials) may misclassify.
- **Coverage normalization constant λ**: How to set the state-space coverage calibration constant without circular dependency on prior test runs.
- **Multi-fidelity proxy selection**: How to efficiently estimate model correlation ρ and choose proxy models to optimize cost without prohibitive initial testing.

## Limitations
- Fingerprinting's 86% power claim assumes low-dimensional behavioral structure; high-dimensional, uncorrelated traces would nullify gains.
- Trace-first offline analysis requires a complete, fresh trace store; staleness or coverage gaps produce misleading verdicts.
- SPRT assumes i.i.d. trials; non-stationarity (model updates, caching) may inflate type I/II error rates.

## Confidence
- **78–100% cost reduction**: High (empirical across 7,605 trials)
- **SPRT trial reduction (78%)**: High (classical theory + experiments)
- **Fingerprinting power (86% vs 0%)**: Medium (scenario-specific, depends on low-dimensional assumption)
- **Trace-first zero-cost**: Medium (conditional on trace store representativeness)
- **Multi-fidelity savings**: Medium (requires sufficient proxy-target correlation ρ≥0.6)
