# Improved state mixing in higher-order and block diagonal linear recurrent networks

## Quick Facts
- **arXiv ID**: 2602.12021
- **Source URL**: https://arxiv.org/abs/2602.12021
- **Reference count**: 40
- **Primary result**: BD-LRU and H-LRU enhance expressivity-efficiency trade-off via structured state mixing, achieving high accuracy on synthetic tasks and competitive throughput.

## Executive Summary
Linear recurrent networks (LRNNs) typically use diagonal state transitions, limiting expressivity, while dense nonlinear architectures are costly. This paper introduces Higher-order LRUs (H-LRU) and Block-Diagonal LRUs (BD-LRU) to enrich state mixing while preserving linear-time computation. H-LRU employs m-th order recurrence for temporal mixing; BD-LRU partitions the hidden state into blocks for intra-block channel mixing. Both use input-dependent selective gates with per-block L1-normalization for stable scaling. Evaluated on synthetic tasks and language modeling, BD-LRU matches or exceeds baselines like Mamba and LSTM, and H-LRU is highly parameter-efficient. The work demonstrates that the structure of state mixing, not just width, governs the expressivity-efficiency trade-off.

## Method Summary
The authors propose two extensions to linear recurrent units:
- **Higher-order LRU (H-LRU)**: Generalizes first-order recurrence to m-th order, effectively mixing information over longer horizons without increasing hidden dimension.
- **Block-Diagonal LRU (BD-LRU)**: Splits the hidden state into B blocks of size K and applies a dense linear transformation within each block, while inter-block dependencies remain linear (often identity). This yields dense intra-block mixing with O(BK^2) parameters instead of O((BK)^2).

Both variants incorporate *selective gates*: input-dependent coefficients that modulate contributions of the input and previous state. These coefficients are normalized via a softmax applied per block (L1-normalization) to maintain stable scaling. Training uses AdamW with a cosine learning rate schedule; models are evaluated on synthetic algorithmic tasks (compression, selective copying, in-context recall, permutation S3–S5) and language modeling on FineWeb. Parallel scan algorithms (Blelloch) are leveraged to achieve O(L log L) inference for long sequences, ensuring competitive throughput.

## Key Results
- BD-LRU matched or outperformed Mamba, DeltaNet, and LSTM on synthetic tasks, achieving 100% accuracy on the S5 permutation with only 200K parameters.
- H-LRU delivered superior parameter efficiency for compression tasks, often requiring far fewer parameters to reach the same performance.
- Both architectures maintained throughput comparable to existing linear recurrent models, demonstrating that richer mixing does not come at a prohibitive computational cost.

## Why This Works (Mechanism)
Structured state mixing via block diagonal or higher-order matrices introduces nonlinear-like interactions within a linear framework. Selective gates enable the model to dynamically route information based on the input, while per-block L1-normalization prevents runaway growth of activations. Parallel scan efficiently compiles the recurrence into a balanced binary tree, allowing parallel evaluation and thus scalable inference. Together, these mechanisms increase expressive capacity without sacrificing the linear complexity that makes recurrent models attractive for long sequences.

## Foundational Learning
- **Linear Recurrent Networks (LRNN)**: Core recurrence `h_t = W h_{t-1} + U x_t`. Needed as the simple, efficient baseline. Quick check: For random W, U, and short sequence, compare sequential vs vectorized recurrence; they must match exactly.
- **Block Diagonal Matrices**: Sparse structure where dense blocks lie on the diagonal. Needed to increase mixing while limiting parameter count. Quick check: Construct a block diagonal matrix of size (B*K, B*K) with block size K; verify that off-block entries are zero.
- **Higher-Order Recurrence**: Recurrence that depends on m previous states, e.g., `h_t = sum_{i=1}^m A_i h_{t-i} + U x_t`. Needed to capture longer temporal context with fixed hidden size. Quick check: Expand m=2 into a combined state of size 2d and verify that first-order formulation on the combined state yields equivalent dynamics.
- **Selective Gating**: Input-dependent coefficients (often from a linear layer) that modulate mixing. Needed to make the recurrence input-adaptive. Quick check: Pass two different inputs through the gate generator; the coefficients should differ.
- **Parallel Scan**: An associative scan algorithm (e.g., Blelloch) that parallelizes recurrence computation. Needed to achieve O(L log L) time on hardware. Quick check: For random inputs and a simple associative operator (e.g., addition), compare sequential scan with parallel scan output; relative error < 1e-5.
- **L1 Normalization (Softmax over block)**: Normalization that forces coefficients to sum to 1 in absolute value per block. Needed to stabilize training and avoid exploding states. Quick check: For a batch of gate logits, apply softmax along block dimension; verify that the sum of absolute values per block equals 1.

## Architecture Onboarding
**Component Map**:  
Input -> Selective Gate Generator (linear layer) -> Per-block L1 Normalization (softmax) -> Recurrent Core (Block-Diagonal or Higher-Order Matrix) -> Parallel Scan -> Hidden State -> (optional) Output Layer

**Critical Path**:  
1. For each timestep t, the input `x_t` is projected to produce mixing coefficients (α_t for input, β_t for state).  
2. Coefficients are normalized block-wise to sum to 1.  
3. The recurrence `h_t = α_t ⊙ (U x_t) + β_t ⊙ (W h_{t-1})` (or its higher-order/block-diagonal equivalent) is applied.  
4. The entire sequence is computed in parallel via a scan that exploits the associative property of the recurrence.  
5. The final hidden state(s) are used for prediction.

**Design Tradeoffs**  
- *Block size*: Smaller blocks increase number of blocks → more parameters but also more mixing; larger blocks reduce parameters but may limit intra-block diversity.  
- *Normalization*: Softmax provides stability but introduces nonlinearity; sigmoid might be simpler but less numerically bounded.  
- *Parallel scan*: Efficient for long sequences but introduces logarithmic constant overhead and requires the recurrence to be associative.  
- *Higher order*: Increases the effective memory span with fixed hidden dimension but grows the effective state size and may complicate parallelization.

**Failure Signatures**  
- Diverging loss: likely incorrect normalization (sums not equal to 1) or unstable gate values.  
- Parallel scan mismatch with sequential: associative operator implementation error or misordered combine operation.  
- Low accuracy (<70% on simple synthetic tasks): insufficient hidden dimension, block size too small, or gates not becoming selective (i.e., close to constant).  
- No benefit from increasing block size: verify gates are actually input-dependent; replace gates with averages to confirm.

**First Experiments**  
1. Implement parallel scan for block diagonal recurrence and validate against sequential computation on 32-step random sequences; require relative error < 1e-5.  
2. Train BD-LRU on the MAD compression task (vocab 16, seq_len 64, hidden_dim 1024, block size 3, softmax L1-normalization) for 50k steps using AdamW (lr=0.001, cosine to 1e-5). Expect test accuracy >75% (paper reports 76.2% with larger model).  
3. Perform gate ablation: replace selective gates with constant (average) normalization; retrain on compression and at least one other task. Expect accuracy drop >10%, confirming the necessity of input-dependent mixing.

## Limitations
- The exact training steps and early stopping criteria for synthetic tasks are not detailed; only learning rate ranges are given.
- The MAD data generation code is not provided, so reimplementation may introduce subtle differences in tokenization or dataset construction.
- Language modeling experiments lack specifics such as context length, batch size, and exact step counts per token budget, making exact replication difficult.
- Throughput measurements' experimental conditions (batch size, sequence length, compilation flags) are ambiguous, limiting reproducibility of speed claims.
