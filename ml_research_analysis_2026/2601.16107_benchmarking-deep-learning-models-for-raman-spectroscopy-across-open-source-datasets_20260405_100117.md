# Benchmarking Deep Learning Models for Raman Spectroscopy Across Open-Source Datasets

## Quick Facts
- **arXiv ID:** 2601.16107
- **Source URL:** https://arxiv.org/abs/2601.16107

## Executive Summary
This study benchmarks five deep learning architectures (Deep CNN, SANet, RamanNet, Transformer, RamanFormer) on three open-source Raman spectroscopy datasets (MLROD, Bacteria-ID, API) under a unified training protocol with minimal preprocessing. SANet emerges as the top performer on clean API and MLROD subsets. However, all models exhibit severe brittleness when tested on MLROD’s dusty subsets, experiencing 20–30% accuracy drops. Transformers consistently underperform CNN-based approaches across datasets. Macro-F1 scores reveal particularly poor performance on minority classes under domain shift, underscoring the need for more robust models tailored to Raman data.

## Method Summary
The authors trained and evaluated five architectures on standardized train/test splits from MLROD, Bacteria-ID, and API datasets. A minimal preprocessing pipeline (normalization only) and consistent training hyperparameters were applied to all models to ensure a fair comparison. Performance was measured via test accuracy and Macro-F1. No domain-specific preprocessing (e.g., cosmic ray removal, baseline correction) was employed, and the study did not explore architectural modifications or advanced data augmentation.

## Key Results
- SANet achieves the highest test accuracy on the API dataset (99.57%) and clean MLROD subsets (91.13%).
- All models suffer severe performance degradation (20–30% accuracy loss) on MLROD’s dusty test subsets, indicating high sensitivity to distribution shift.
- Transformers consistently underperform CNN-based models across all datasets; Macro-F1 scores closely match accuracy on Bacteria-ID and API but are significantly lower on MLROD, highlighting poor minority-class robustness under domain shift.

## Limitations
- **Dataset scope:** Benchmark limited to three specific datasets (MLROD, Bacteria-ID, API), restricting generalizability to other Raman application domains.
- **Preprocessing impact:** Use of minimal preprocessing may advantage or disadvantage certain architectures; the effect of domain-standard preprocessing (e.g., baseline correction, smoothing) remains unknown.
- **Brittleness cause:** The severe drop on dusty MLROD subsets is demonstrated, but the study cannot isolate whether the failure stems from model architecture, feature extraction, or dataset-specific noise characteristics.
