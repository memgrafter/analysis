# Agentic Flow Steering and Parallel Rollout Search for Spatially Grounded Text-to-Image Generation
## Quick Facts
- arXiv ID: 2603.18627
- Source URL: https://arxiv.org/abs/2603.18627
- Reference count: 40
- Primary result: AFS-Search-Pro improves average T2I-CompBench performance by 7.86% over FLUX.1-dev, achieving state-of-the-art with significant gains in object relationships and complex tasks; AFS-Search-Fast improves by 2.57% while being faster.

## Executive Summary
Spatially grounded text-to-image generation is hindered by static text encoder limitations and irreversible error accumulation during open-loop sampling. This paper introduces AFS-Search, a training-free closed-loop framework that treats generation as a sequential decision-making process. It employs a Vision-Language Model as a semantic critic to diagnose intermediate latents and dynamically steer the flow model’s velocity field via spatial grounding (Agentic Flow Steering), while using parallel rollout search to explore and select optimal latent trajectories. On T2I-CompBench and R2I-Bench, AFS-Search-Pro achieves state-of-the-art results, with ablations confirming the necessity of both steering and search components.

## Method Summary
AFS-Search reformulates T2I generation as a navigable decision process. At a bifurcation point (`t_split`), a VLM critic evaluates the intermediate latent and outputs a diagnosis: a spatial mask (derived via SAM3 from a targeted bounding box) and a scalar reward. The system then simulates three parallel short-horizon trajectories—Baseline (standard continuation), Steer (applies Agentic Flow Steering by modulating the velocity field within the mask using CLIP contrastive gradients), and Explore (adds noise for diversity). After a fixed number of steps, the VLM rescues each preview and selects the optimal branch. The chosen trajectory continues to completion. A global feedback loop monitors final adherence, triggering prompt redesign if scores are low.

## Key Results
- AFS-Search-Pro improves average T2I-CompBench performance by 7.86% over FLUX.1-dev, with gains of +15.2% in object relationships and +12.4% in complex tasks.
- AFS-Search-Fast maintains a 2.57% improvement while generating faster.
- On R2I-Bench, AFS-Search-Pro achieves the highest average score (0.48) among evaluated models.
- Ablations show removing parallel rollout search severely harms relationship performance, and removing self-correction (AFS) degrades attribute binding, confirming both components are critical.

## Why This Works (Mechanism)
**Mechanism 1: Closed-loop feedback with lookahead search**
- **Claim:** Closed-loop feedback with lookahead search corrects irreversible error accumulation in open-loop flow matching.
- **Mechanism:** At `t_split`, the system diagnoses intermediate latents via VLM, then simulates multiple short-horizon trajectories (Baseline, Corrective via AFS, Exploration). The optimal path is selected based on VLM reward scores, actively navigating the latent space rather than following a single deterministic ODE.
- **Core assumption:** The pre-trained flow model possesses latent capability to satisfy complex spatial constraints if guided onto the correct trajectory; the challenge is finding that trajectory among many plausible but incorrect ones.
- **Evidence anchors:** [abstract] "formulate T2I generation as a sequential decision-making process, exploring multiple trajectories..." ; [section 3.3] "reformulates generation as a navigable decision-making process..." ; [corpus] Weak/No Direct Anchor: Neighboring papers explore tree search in diffusion but not closed-loop VLM-guided rollout for spatial grounding.
- **Break condition:** If VLM rewards are uncorrelated with human-judged compliance in short-horizon previews, selection collapses to random.

**Mechanism 2: Agentic Flow Steering (AFS)**
- **Claim:** AFS dynamically warps the flow model’s velocity field via spatial masking to rectify semantic drift without destabilizing the ODE integration history.
- **Mechanism:** Using a predicted clean latent `ẑ0` from linear trajectory projection, a contrastive CLIP energy `E(ẑ0)` is defined. The gradient `∇vtE` is mapped back to the velocity field `vt`, scaled by `t`, and applied only within the SAM3-provided spatial mask `M` (`v_corrected_t = v_t + ηt * ∇ẑ0E ⊙ M`).
- **Core assumption:** The flow model’s near-linear transport property (`z_t = t * v_t + z0`) allows accurate back-projection to `ẑ0`, and modulating `vt` is more stable than directly modifying `z_t`.
- **Evidence anchors:** [abstract] "dynamically steer the velocity field via precise spatial grounding leveraging SAM3" ; [section 3.4] "z_t can be rewritten as z_t = t*u_t + z0… gradient descent update on the velocity field is confined by the spatial mask M" ; [corpus] Weak/No Direct Anchor: "Not All Latent Spaces Are Flat" discusses hyperbolic control but not flow velocity modulation.
- **Break condition:** If the linear projection assumption fails significantly (i.e., `v_t` poorly approximates `u_t`), `ẑ0` is semantically meaningless, causing destructive warping.

**Mechanism 3: VLM as semantic critic**
- **Claim:** A VLM, acting as a semantic critic with a structured multi-dimensional scoring rubric, provides a reliable reward signal for branch selection and global recovery, compensating for the static text encoder’s relational reasoning limits.
- **Mechanism:** The VLM diagnoses intermediate decoded images against the refined prompt, outputting JSON with defect localization (`segmentation_keyword`, `target_bbox`) for AFS, and a scalar score (-10 to +10) based on Prompt Adherence (50%), Relational Logic (30%), and Visual Integrity (20%) with strict penalties.
- **Core assumption:** A sufficiently capable VLM (e.g., Qwen-VL-MAX) can perform human-like compositional critique and assign scores that correlate with spatial compliance better than the base model’s internal likelihood.
- **Evidence anchors:** [abstract] "leverages a Vision-Language Model (VLM) as a semantic critic..." ; [section 3.3 & Fig. 5] Detailed scoring rubric and JSON output format ; [corpus] Weak Anchor: "Structured Information for Improving Spatial Relationships" uses VLM for prompt structuring but not as an online critic for trajectory selection.
- **Break condition:** If VLM scoring exhibits high variance on semantically equivalent images or systematically penalizes valid variations, selection becomes unstable or biased.

## Foundational Learning
- **Flow Matching / Rectified Flow ODEs**
  - **Why needed:** Understanding that generation solves `dx_t = v_t(x_t, t, y)dt` and that `v_t` approximates constant-velocity linear transport (`z_t = t*v_t + z0`) is fundamental to why AFS can project to `ẑ0` and modulate `v_t` stably.
  - **Quick check:** Why is modulating the velocity field `v_t` theoretically more stable for guiding a flow model than directly adding noise to the latent `z_t` at an intermediate step?
- **Contrastive Guidance in CLIP Space**
  - **Why needed:** AFS’s energy function `E(ẑ0) = cos(CLIP(ẑ0), e_neg) - cos(CLIP(ẑ0), e_pos)` relies on CLIP’s embedding space to define a semantic direction for correction. Understanding that this space supports directional arithmetic for concepts is key.
  - **Quick check:** How does a contrastive loss between positive and negative text embeddings in CLIP space encourage moving the image toward the target attribute (e.g., "blue dog") and away from the defect (e.g., "red dog")?
- **Test-Time Compute / Search Paradigm**
  - **Why needed:** The core innovation is using computation at inference to explore trajectories instead of training. This requires understanding trade-offs: more simulated branches increase success probability but linearly increase latency.
  - **Quick check:** What is the primary computational cost added by the Parallel Rollout Search compared to standard open-loop sampling, and what parameter most directly controls this cost?

## Architecture Onboarding
**Component map:** VLM Prompt Optimizer → FLUX.1-dev → VLM Critic → SAM3 → AFS Module → Search Controller → (parallel branches: Baseline, Steer, Explore via FLUX.1-dev) → VLM Scoring → Selection → FLUX.1-dev (full generation) → Global Feedback Loop.

**Critical path:**
1. Refine prompt with VLM Prompt Optimizer.
2. Run initial denoising with FLUX.1-dev until `t_split`.
3. VLM Critic diagnoses intermediate latent, outputs JSON with `segmentation_keyword`, `target_bbox`, and preliminary score.
4. SAM3 converts `target_bbox` to spatial mask `M`.
5. Search Controller launches three parallel branches: Baseline (standard continuation), Steer (apply AFS correction using `M` and CLIP gradients), Explore (noise perturbation).
6. Each branch runs for Δt steps, then VLM Critic scores the preview images.
7. Search Controller selects the branch with highest VLM reward.
8. Continue generation from the selected branch’s state to `t=0` using FLUX.1-dev.
9. Final VLM score computed; if below threshold τ, Global Feedback triggers prompt redesign and restart from step 1.

**Design tradeoffs:**
- **AFS-Search-Pro vs. Fast:** Pro uses stronger VLM (Qwen-VL-MAX) and more/longer branches for max accuracy; Fast uses smaller VLM (Qwen2.5-VL-7B) and shorter simulation for speed.
- **`t_split` timing:** Branching earlier (e.g., `t=0.8`) better for global layout/spatial relationships; later (`t=0.4`) better for fine attributes/color. Multi-stage branching improves robustness but adds latency.
- **Simulation horizon (`Δt` steps):** Longer lookahead gives more reliable VLM scores but increases compute linearly per branch.

**Failure signatures:**
- VLM diagnosis returns `needs_correction: false` on a visibly defective image → final output fails due to missed error.
- Corrective branch score << Baseline/Exploration → likely SAM3 mask error or VLM misdiagnosis; system should auto-prune.
- Global redesign loop triggered repeatedly → prompt is ambiguous or conflicts with model prior; system may be stuck.

**First 3 experiments:**
1. Ablation: w/o Parallel Rollout Search – Run only Base branch (greedy). Expect significant drop in Object Relationship and Complex scores (~15-20% as in Table 3).
2. Ablation: w/o Self-Correction (AFS) – Disable Steer branch, keep Base and Explore. Expect drop in Attribute Binding scores, showing AFS’s role.
3. Hyperparameter: Search Timing (`t_split`) – Compare branching at `t=0.8` (early) vs `t=0.4` (late). Expect early to improve Spatial scores, late to improve Color/Texture.

## Limitations
- VLM critic reliability: Selection depends on VLM scoring consistency; low inter-rater agreement destabilizes search.
- Linear projection validity: AFS assumes near-linear `z_t = t*v_t + z0`; deviation in non-rectified flows breaks `ẑ0` estimation.
- Search scalability: Computational cost scales linearly with branches; unclear if gains justify added latency for real-time applications.

## Confidence
- Overall gains on T2I-CompBench/R2I-Bench: High (validated on benchmarks).
- Core mechanisms (closed-loop search, AFS, VLM critic): Medium (plausible but hinge on unverified assumptions).
- VLM critic reliability: Medium.
- Linear projection assumption: Medium/Model-dependent.
- Search cost-effectiveness: Medium.
