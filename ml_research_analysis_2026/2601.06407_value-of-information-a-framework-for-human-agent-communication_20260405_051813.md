# Value of Information: A Framework for Human-Agent Communication

## Quick Facts
- arXiv ID: 2601.06407
- Source URL: https://arxiv.org/abs/2601.06407
- Reference count: 37
- Primary result: VoI matches or exceeds best manually-tuned baselines in 18/20 conditions, achieving up to +1.36 utility in high-cost settings without hyperparameter tuning.

## Executive Summary
LLM agents often face ambiguous user requests and must decide whether to act immediately or seek clarification, balancing potential gains against user interruption costs. This paper introduces a decision-theoretic framework based on Value of Information (VoI), which dynamically computes the expected utility gain from asking a question minus the user's cognitive cost. The method operates at inference time, requiring no additional training or tuning. Across four domains—20 Questions, medical diagnosis, flight booking, and e-commerce—VoI consistently matches or outperforms the best baseline strategies in 18 of 20 experimental conditions, demonstrating its ability to automatically adapt the information-cost trade-off to context-specific stakes.

## Method Summary
The VoI framework formalizes the clarification decision as an economic trade-off. For each candidate question, the agent estimates the expected reduction in uncertainty about the task objective using the LLM's probabilistic outputs. This expected information gain is converted into an expected utility improvement, which is then compared against a modeled cognitive cost of interrupting the user. The agent asks a question only if the net expected value is positive. The approach leverages the LLM's own probability estimates over possible interpretations or outcomes, making it applicable at inference time without model fine-tuning or hand-crafted thresholds. It explicitly accounts for the stakes of the task by incorporating a utility function, allowing adaptation across different contexts.

## Key Results
- VoI matches or exceeds the best manually-tuned baseline in 18 out of 20 experimental conditions across four domains.
- In high-cost settings (where interruptions are particularly burdensome), VoI achieves up to 1.36 utility points higher than baselines.
- The framework automatically identifies the optimal trade-off between information gain and communication burden without domain-specific hyperparameter adjustments.

## Why This Works (Mechanism)
VoI works by applying rigorous decision theory to the interruption problem. It transforms the vague notion of "confidence" into a concrete expected value calculation: the agent asks a question only when the anticipated benefit (in terms of improved task utility) outweighs the certain cost (user cognitive burden). This prevents both premature action on ambiguous requests and excessive pestering for trivial clarifications. By grounding decisions in probability estimates from the LLM and an explicit cost model, the agent makes rational, context-sensitive choices that adapt to the stakes of the interaction. The method's strength lies in its normative foundation—it prescribes the economically optimal action given the agent's beliefs and cost assumptions.

## Foundational Learning
- **Value of Information (VoI)**: A decision-theoretic concept quantifying the expected increase in utility from acquiring additional information. *Why needed*: Provides a formal, quantitative criterion for whether a clarification question is worth asking. *Quick check*: Can the agent compute a real-valued VoI score for each candidate question?
- **Utility Theory**: The framework for representing and maximizing task-specific rewards or preferences. *Why needed*: Defines the objective the agent is trying to achieve, allowing VoI to be scaled to stakes. *Quick check*: Is the utility function aligned with the user's true goals?
- **Cognitive Cost Modeling**: Assigning a numerical burden to user interruptions (e.g., time, mental effort). *Why needed*: Prevents the agent from over-querying by making the cost of asking explicit. *Quick check*: Is the cost parameterization consistent with observed user behavior?
- **Probabilistic Inference with LLMs**: Treating the LLM's output distributions as estimates of underlying probabilities. *Why needed*: Supplies the uncertain beliefs about user intent or world state that VoI calculations require. *Quick check*: Are the LLM's probability estimates sufficiently calibrated for the domain?
- **Decision-Making Under Uncertainty**: The general paradigm of choosing actions with imperfect knowledge. *Why needed*: Captures the core challenge of ambiguous requests; VoI is a specific instantiation. *Quick check*: Does the agent consider all plausible outcomes and their utilities?

## Architecture Onboarding
Component map: User Request -> LLM Probability Estimator -> VoI Calculator (with Cost Model) -> Clarification Decision -> [If Ask: Generate Question -> User Response -> Update Beliefs -> Action] / [If Act: Direct Action]
Critical path: An ambiguous request triggers probability estimation over interpretations/outcomes; candidate questions are evaluated via VoI; the highest positive-VoI question (if any) is posed; upon response, beliefs update and a final action is taken.
Design tradeoffs: Accuracy of cost modeling versus generalizability; computational overhead of enumerating and evaluating candidate questions versus response latency; reliance on LLM probability calibration versus robustness to miscalibration.
Failure signatures: Sharp utility drop if cognitive cost is significantly underestimated (leading to excessive interruptions) or overestimated (leading to critical omissions); degraded performance if LLM probabilities are highly miscalibrated; brittleness if the set of candidate questions is poorly defined.
First experiments: 1) Validate VoI logic in a controlled game like 20 Questions where utilities and costs are easily specified. 2) Test in a high-stakes simulated domain like medical diagnosis with a tunable cost parameter to observe the trade-off curve. 3) Deploy in a practical transactional domain (e.g., flight booking) to assess performance against a rule-based baseline.

## Open Questions the Paper Calls Out
The paper's discussion of limitations points to several open research questions:
- How can the accuracy of task utility and user cognitive cost models be improved for real-world deployments, perhaps through learning from user interactions?
- To what extent does the VoI framework generalize to open-domain conversational agents beyond the four evaluated domains?
- Can cognitive cost be modeled beyond a scalar parameter to capture social, emotional, and contextual nuances of interruptions?
- How robust is the approach to miscalibration in LLM probability estimates, and can methods be developed to mitigate such issues?

## Limitations
- Framework performance depends on accurate models of task utility and user cognitive cost; errors in these models may lead to suboptimal interruption decisions in real deployments.
- Evaluation is confined to simulated or controlled tasks; generalizability to open-domain conversational agents remains uncertain.
- Cognitive cost is simplified to a scalar parameter; real interruptions involve social, emotional, and contextual factors not captured.
- No hyperparameter tuning is required, but the method relies on well-calibrated probability estimates from the LLM, which may not hold in practice.

## Confidence
- **Information-cost trade-off**: Medium (theoretically sound, but empirical validation of cost modeling is limited to simplified settings).
- **Domain adaptability**: High within the four tested domains; Low for unseen domains without re-estimating the cost or utility models.
- **Performance advantage**: High in the specific reported experimental conditions (18/20), but sample size is modest and independent replication is needed.

## Next Checks
1. Conduct a user study with a live conversational agent to validate the assumed cognitive cost model and measure real interruption burden across different question types.
2. Test VoI on a broader range of domains (e.g., technical support, creative collaboration, customer service) to assess generalization beyond the four initially reported.
3. Compare VoI against state-of-the-art LLM prompting strategies (e.g., chain-of-thought, self-critique) in a unified benchmark to isolate the contribution of the decision-theoretic computation.
