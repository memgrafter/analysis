# VQQA: An Agentic Approach for Video Evaluation and Quality Improvement

## Quick Facts
- arXiv ID: 2603.12310
- Source URL: https://arxiv.org/abs/2603.12310
- Reference count: 40
- Primary result: VQQA achieves absolute improvements of +11.57% on T2V-CompBench and +8.43% on VBench2 over vanilla generation.

## Executive Summary
Video generation often fails to capture complex user intent due to visual artifacts and misalignments. Existing test-time methods are either computationally expensive or require model internals. VQQA introduces a unified, model-agnostic multi-agent framework that dynamically generates visual questions, uses Vision-Language Model critiques as semantic gradients, and iteratively refines prompts via a black-box interface. Across text-to-video and image-to-video tasks, VQQA significantly outperforms state-of-the-art baselines with only a few iterations, demonstrating a practical approach to improving video quality without retraining.

## Method Summary
VQQA operates as an iterative loop involving three specialized agents: a Question Generation (QG) agent creates context-specific questions about the video; a Question Answering (QA) agent scores the video on these questions; and a Prompt Refinement (PR) agent uses low-scoring QA pairs to revise the prompt. Each iteration generates a new video, and a Global VLM Rater selects the best video against the original prompt to prevent semantic drift. The process stops when a global score threshold is met or improvements plateau. This design is model-agnostic, requiring only a black-box video generator and VLM access.

## Key Results
- +11.57% absolute improvement on T2V-CompBench over vanilla generation.
- +8.43% absolute improvement on VBench2.
- Significant outperformance of state-of-the-art baselines with just a few iterations.

## Why This Works (Mechanism)

**Mechanism 1:** VLM critiques as semantic gradients. The QA agent produces scores on dynamically generated questions that pinpoint specific flaws (e.g., "how clearly does the bud bloom?" scoring low). The PR agent uses these low-scoring QA pairs to revise the prompt, directly targeting identified weaknesses. Evidence shows that VQQA's questions achieve 82.08% E2E-Recall in capturing ground-truth visual flaws, validating that the generated questions effectively identify problems. Break condition: if VLM critiques become noisy or hallucinated, the semantic gradient may misdirect refinement, degrading quality or causing prompt drift.

**Mechanism 2:** Global selection prevents semantic drift. After each refinement iteration, a Global VLM Rater scores all generated videos against the original user prompt (not intermediate prompts). The highest global score video is selected as final output, ensuring alignment with initial intent despite localized optimizations. Evidence: Ablation shows that using last-iter selection or average-QA selection drops performance by 1.02%–1.86%, confirming the global selection's necessity. Break condition: if the global rater VLM is biased or inconsistent, the selected video may diverge from true user intent despite high granular QA scores.

**Mechanism 3:** Dynamic question generation enables task-agnostic evaluation. The QG agent creates 5–10 questions per video, tailored to the prompt and task (T2V vs. I2V), covering Video-Prompt Alignment, Visual Quality, and Condition Fidelity. This avoids static rubrics that may miss instance-specific artifacts. Evidence: VQQA achieves 96.55% Q-Recall and 82.08% E2E-Recall, outperforming VLM Direct Analysis (70.18% E2E-Recall) in capturing ground-truth flaws. Break condition: if QG generates overly generic or irrelevant questions due to prompt ambiguity, feedback may not isolate actual flaws.

## Architecture Onboarding
Component map: User Prompt p0 -> Iterative Loop: [Video Generator M -> QG Agent -> QA Agent -> PR Agent] -> Global VLM Rater -> Selected Video.

Critical path (one iteration):
1. Generate video v_t = M(p_t, C).
2. QG generates questions Q_t from (v_t, p_t, C).
3. QA answers Q_t on v_t → scores and rationale.
4. PR uses (p0, p_t, QA pairs, history) to produce p_{t+1}.
5. Update t and repeat until convergence.
6. Global Rater scores all v_t → select v* = argmax GS(v_t, p0, C).

Design tradeoffs:
- Black-box vs. white-box: Chose black-box to support any video generator, sacrificing efficiency from gradient-based methods.
- Global selection decoupling: Uses original prompt p0 to avoid drift, but adds VLM inference cost; ablation confirms necessity.
- Dynamic stopping: Uses simple thresholds (k, ε) to balance quality and compute; complex adaptive schemes may improve efficiency but add hyperparameters.
- Question count (5–10): Fixed range balances feedback granularity with VLM call cost.

Failure signatures:
- Semantic drift: Prompts evolve away from original intent; detect by embedding similarity drop or global score decreasing while QA scores rise.
- VLM hallucination in critique: QA gives high scores to obvious flaws; detect via human audit or cross-VLM check.
- Non-convergence: Global score keeps improving after many iterations; may indicate too high ε/k or generator limitations.
- High iteration variance: Some prompts require many iterations; may indicate inconsistent VLM reliability or prompt complexity.
- I2V reference identity loss: VBench-I2V consistency scores drop; PR over-prioritizes motion/quality over fidelity.

First 3 experiments:
1. Baseline sanity check: Run VQQA on simple T2V prompt (e.g., "a cat sleeping on a mat") with CogVideoX-5B. Verify global score increases, questions relevant by inspection, and final video visibly improves.
2. Global selection ablation: Compare three selection strategies (global rater, last-iter, average-QA) on 20 samples; quantify benchmark score differences.
3. Convergence sensitivity: Vary k (patience window: 1,3,5) and ε (saturation threshold: 0.5,1.0,2.0) on fixed prompt subset; plot average iterations vs. final quality to identify optimal defaults.

## Open Questions the Paper Calls Out
**Open Question 1:** How does VQQA generalize to diverse video generation architectures (e.g., autoregressive) and to videos with longer durations or higher resolutions beyond those tested? Basis: Experiments limited to CogVideoX (diffusion) and Veo 3.1, max 49 frames. Unresolved: No evaluation across model families or scaled video settings; assumptions about prompt sensitivity and VQA coverage may not hold. Evidence needed: Systematic benchmark across various generation models and a wide range of resolutions/frame counts.

**Open Question 2:** What is the robustness of VQQA to errors and biases in the VLM-based QA agent, and can the framework tolerate or correct for such noise during iterative refinement? Basis: Limitations acknowledge "noisy semantic gradients from VLM hallucinations" but provide no robustness analysis; precision is high (>99%) yet occasional hallucinations admitted. Unresolved: Impact of occasional erroneous QA scores on refinement trajectory unknown; a single misleading flaw could derail updates. Evidence needed: Controlled experiments injecting noise (random perturbations, systematic bias) into QA agent, measuring effects on convergence, final quality, failure rate.

**Open Question 3:** Under what conditions does the dynamic stopping criterion fail to detect semantic drift or premature stagnation, and could a more sophisticated heuristic improve the compute-quality trade-off? Basis: Stopping relies on fixed patience window and threshold tuned on T2V-CompBench; sensitivity analysis shows parameter dependence but no failure-case investigation. Unresolved: Heuristic may halt before global optimum or continue despite drift, especially if global score plateaus due to noise. Evidence needed: Detailed analysis of optimization trajectories where final selected video underperforms earlier candidates; development and evaluation of adaptive stopping rules using additional signals (QA score trends, diversity metrics).

**Open Question 4:** Is the decoupling of granular QA feedback from global selection universally beneficial, or are there scenarios where incorporating global score into refinement could accelerate convergence without sacrificing fidelity? Basis: Ablation shows adding global score to refinement context ("GS-in-the-loop") degrades average performance, leading to conclusion that decoupling yields best results. Unresolved: Average masks per-category or per-flaw-type effects; some failures (e.g., gross misalignment) might benefit from global feedback. Evidence needed: Per-dimension breakdown of GS-in-the-loop vs. standard across many samples; identification of conditions where global feedback aids convergence.

## Limitations
- Replication gaps: exact convergence threshold ε, Global VLM Rater prompt format, and historical context serialization for PR agent.
- Dependence on VLM reliability (hallucinations, bias) and compute cost from repeated VLM calls (5–10 questions × iterations).
- Potential semantic drift if PR agent overfits to narrow QA feedback.

## Confidence
- Semantic gradient from VLM critiques: Medium (supported by E2E-Recall 82.08%, but vulnerable to VLM noise).
- Global selection prevents drift: High (ablation shows 1.02%–1.86% drop without it, strong evidence).
- Dynamic QA adaptability: Medium (96.55% Q-Recall, but question count ranges unspecified).
- Overall cross-task gains: Medium (results promising, but replication unknowns remain).
