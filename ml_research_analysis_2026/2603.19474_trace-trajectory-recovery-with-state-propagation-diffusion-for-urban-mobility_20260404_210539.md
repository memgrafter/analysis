# TRACE: Trajectory Recovery with State Propagation Diffusion for Urban Mobility

## Quick Facts
- **arXiv ID:** 2603.19474
- **Source URL:** https://arxiv.org/abs/2603.19474
- **Reference count:** 33
- **Primary result:** Over 26% accuracy improvement and MSE reduction from 0.326 to 0.010 on Xi'an dataset.

## Executive Summary
Recovering dense, continuous trajectories from sparse and irregular GPS data is a key challenge in urban mobility analysis. Existing methods often fail to handle the irregularities and missing segments effectively.

TRACE introduces a State Propagation Diffusion Model (SPDM) with a memory mechanism that retains and reuses intermediate features across denoising steps, enabling robust reconstruction of difficult segments. On real‑world datasets, TRACE achieves more than 26% accuracy improvement over state‑of‑the‑art methods, reducing MSE from 0.326 (DT+RP) to 0.010 on Xi'an. It also shows robustness to spatio‑temporal irregularities; when combined with DDIM acceleration, recovery quality improves by 26.65% with only a 12% parameter increase and minimal overhead.

## Method Summary
TRACE employs a diffusion-based approach for trajectory recovery, termed the State Propagation Diffusion Model (SPDM). The model treats trajectory reconstruction as a denoising process where a noisy version of the trajectory is iteratively refined. A key innovation is the inclusion of a memory mechanism that stores intermediate feature representations from each denoising step and propagates them forward. This memory allows the model to retain contextual information about missing or irregular segments throughout the diffusion chain, thereby improving reconstruction quality over standard diffusion models.

## Key Results
- Accuracy improvement of over 26% compared to SOTA methods.
- MSE reduced from 0.326 (DT+RP) to 0.010 on the Xi'an dataset.
- With DDIM, recovery quality improves by 26.65% with only 12% additional parameters and minimal overhead.

## Why This Works (Mechanism)
The diffusion process in TRACE gradually removes noise from a corrupted trajectory estimate. The memory module retains salient features (e.g., spatial patterns, temporal dynamics) extracted at each step and re-injects them into subsequent steps. This state propagation prevents the loss of information that typically occurs in deep denoising chains, especially when dealing with long gaps or irregular sampling. By preserving and reusing these intermediate representations, the model maintains a consistent internal state that guides the recovery toward more accurate and coherent trajectories.

## Foundational Learning
TRACE builds upon Denoising Diffusion Probabilistic Models (DDPM) and adapts them to the trajectory recovery domain. It incorporates concepts from sequence modeling, such as memory or attention mechanisms, to handle temporal dependencies. The method also relates to state-space models where the system state is propagated over time. While the paper does not delve into extensive foundational theory, the integration of diffusion with a memory mechanism represents a hybrid approach that leverages the generative strength of diffusion and the stability of state propagation.

## Architecture Onboarding
- **Component map:**  
  1. *Trajectory Encoder*: Embeds sparse GPS points into a latent representation.  
  2. *Diffusion Denoiser*: A neural network (e.g., U-Net) that iteratively denoises a trajectory estimate.  
  3. *Memory Module*: Stores intermediate features from each denoising step and feeds them back to the denoiser.  
  4. *Trajectory Decoder*: Maps the latent denoised representation back to the output space.

- **Critical path:**  
  1. Preprocess raw GPS data to handle irregular timestamps.  
  2. Encode sparse observations into the latent space.  
  3. Run the diffusion process with memory augmentation.  
  4. Decode the final denoised trajectory and evaluate metrics.

- **Design tradeoffs:**  
  - Memory module adds ~12% parameters but significantly improves robustness.  
  - Using DDIM acceleration reduces inference steps with negligible loss in accuracy (reported improvement of 26.65% in recovery quality vs. baseline).  
  - Increased model complexity may affect training time but the paper reports minimal overhead at inference.

- **Failure signatures:**  
  - Performance degradation when gap lengths exceed typical patterns seen in training.  
  - Potential instability if memory is not properly regularized.  
  - No explicit evaluation under extreme missing rates; robustness claims are based on real‑world irregularities.

- **First experiments:**  
  1. Comparison of TRACE against SOTA methods (e.g., DT+RP, DiffMove) on the Xi'an dataset, showing MSE reduction from 0.326 to 0.010.  
  2. Ablation study evaluating the contribution of the memory mechanism.  
  3. Evaluation of DDIM acceleration: quality improvement of 26.65% with only 12% parameter increase.
