# Children's Intelligence Tests Pose Challenges for MLLMs? KidGym: A 2D Grid-Based Reasoning Benchmark for MLLMs

## Quick Facts
- **arXiv ID:** 2603.20209  
- **Source URL:** https://arxiv.org/abs/2603.20209  
- **Reference count:** 40  
- **Primary result:** KidGym reveals that state-of-the-art MLLMs achieve near-perfect scores on simple tasks but exhibit sharp performance drops on composite tasks (some Planning rates below 30%), with persistent weaknesses in abstract visual reasoning, quantity insensitivity, multi-rule coordination, and Perception Reasoning/Planning.  

## Executive Summary
This paper introduces KidGym, a novel 2D grid-based benchmark inspired by the Wechsler Intelligence Scales to evaluate multimodal LLMs across five core cognitive capabilities: Execution, Perception Reasoning, Learning, Memory, and Planning. The benchmark comprises 12 tasks with random layouts and three difficulty levels, designed to isolate dominant abilities while minimizing confounds. Comprehensive evaluation of nine leading MLLMs shows that while models excel at straightforward tasks (e.g., Classification >95%), performance degrades significantly on tasks requiring abstract reasoning, exact counting, or integration of multiple rules. The study identifies four key limitations—difficulty with non-semantic visual structure, insensitivity to quantity, struggles with multi-rule interactions, and overall weakness in Perception Reasoning and Planning—and publicly releases the benchmark and code to facilitate future research.  

## Method Summary
KidGym implements a Gym-like environment with a 5×5 interactive grid rendered as a 576×576 pixel image. Each episode randomizes item positions, semantic scene (e.g., supermarket), and goal while ensuring solvability. Models are presented with a single image, a text goal, and a list of high-level actions (e.g., "pick up apple"). They respond with a textual action choice, which is decoded via fuzzy matching to one of the valid options. The agent then executes the action, and the environment updates state. Success is binary (goal achieved within optimal steps). Each task-level combination is evaluated over 100 episodes, with scores weighted by difficulty (L1:0.2, L2:0.3, L3:0.5). The design deliberately avoids static image–answer pairs, instead requiring sequential decision-making to assess memory, planning, and learning.  

## Key Results
- Top closed-source models (e.g., o3, GPT-5) score >95% on simple Execution tasks but see composites drop below 30% (e.g., Memory Maze Advanced).  
- Abstract visual reasoning (Puzzle) consistently underperforms semantic filling (Filling), with GPT-5 achieving only 0.30 on Puzzle L1 vs. higher on Filling.  
- Counting (CO) accuracy improves dramatically with input resolution for some models, whereas humans maintain near-perfect performance at native 64px/cell resolution.  

## Why This Works (Mechanism)
KidGym’s design isolates intended causal mechanisms by engineering away confounds irrelevant to MLLMs.

**Abstract visual reasoning gap** – The Puzzle (PU) task removes semantic anchors compared to Figurative Filling (FI). Both require assembling a picture, but PU uses arbitrary block patterns. Performance drop (PU < FI) directly measures reliance on semantic priors vs. pure spatial reasoning. Evidence: Across all models, PU success is consistently worse than FI. Break condition: Future models achieve near parity between FI and PU at L1 with higher resolution alone.

**Quantity insensitivity** – Counting (CO) requires exact numeric answers. Models improve with resolution (e.g., Claude-3.7: 0.14→0.79 from 32→96px), implying they treat “two items” as a localized pixel pattern rather than abstract cardinality. Humans succeed without enhanced clarity. Break condition: Models achieve >0.90 on CO at native 64px/cell resolution.

**Capacity interference** – Composite tasks (e.g., Memory Maze = Maze + Memory) show significantly lower success than single-capacity constituents (MA). This additive cost suggests that coordinating multiple abilities linearly degrades performance rather than operating independently. Break condition: Composite tasks show no statistically significant decrement vs. corresponding single-capacity tasks.  

## Foundational Learning
**Task impurity and dominant-ability design**  
*Why needed:* KidGym assumes each task isolates one dominant ability; misinterpreting scores as pure measurements invalidates the benchmark.  
*Quick check:* If a model is weak on Placement (Learning + Perception), is the drop due to rule acquisition or spatial orientation? How would you isolate the two?

**Dynamic vs. static evaluation**  
*Why needed:* KidGym’s sequential interaction is essential for measuring Memory/Planning; static versions would collapse to snapshot reasoning.  
*Quick check:* Why would a static version of Memory Maze (showing all steps in one image) fail to measure Memory?

**High-level action abstraction**  
*Why needed:* Macro-actions (e.g., “pick up apple”) simplify Execution but shape what is measured (instruction following vs. motor control).  
*Quick check:* If you gave only “move north/south/east/west” actions, how would that change what the Classification task measures?  

## Architecture Onboarding
**Component map**  
Environment Engine -> Action Generator -> Prompt Formatter -> Model API -> Answer Decoder -> Metric Logger

**Critical path**  
1. `env.reset(seed)`: Randomize layout, scene, items.  
2. `prompt = env.render()`: Fetch image + text prompt.  
3. `action_text = model.chat(prompt)`: Call model.  
4. `action_idx = decode(action_text, env.action_list)`: Map text to action index.  
5. `obs, reward, done = env.step(action_idx)`: Update state; repeat until done or max steps.

**Design tradeoffs**  
- Randomness vs. reproducibility: Seeds ensure debug reproducibility but infinite state space prevents overfitting; complicates cross-model exact scene comparison.  
- High-level actions vs. control granularity: Simpler for MLLMs but hides sub-policy reasoning (e.g., pathfinding).  
- Composite vs. single-capacity tasks: Ecologically richer but scores conflate multiple abilities; radar chart partially disentangles.

**Failure signatures**  
- Violates rules (e.g., “put” without “pick up”) → Execution weakness.  
- Chooses wrong cluster in CO → Quantity insensitivity.  
- Fails PU but succeeds FI → Abstract visual reasoning deficit.  
- Collapses on DMA/MMA but not SO → Multi-rule coordination bottleneck.

**First 3 experiments**  
1. **Baseline sanity check:** Run CL-L1 on all models; expect ≥0.95 for top closed-source, >0.0 for random. Validates Execution and decoding pipeline.  
2. **Resolution sensitivity test:** Run CO-L1 at 32/64/96 pixels per cell; verify accuracy improves with resolution for affected models (e.g., Claude-3.7).  
3. **Zero-shot vs. CoT toggle:** For DMA-L1, compare zero-shot and CoT; CoT should boost models like Gemini-Flash but not o3.  

## Open Questions the Paper Calls Out
1. What architectural changes or training data improvements are needed for robust quantity sensitivity, given MLLMs rely on high-resolution inputs while humans succeed at low resolution?  
2. Are abstract visual reasoning weaknesses (Puzzle task) fundamental to current MLLM architecture or a gap in pre-training data diversity?  
3. Do composite task failures indicate a fundamental working memory bottleneck or merely coordination overhead reducible by better prompting?  
4. Is ICL underperformance on memory tasks due to randomized layouts causing overfitting to superficial patterns?  
5. Can the Wechsler-inspired five-capability framework remain valid as MLLMs become more general, or will new dimensions emerge?  

## Limitations
- **Task impurity:** The dominant-ability design assumption is unverified; composite failures could stem from unmeasured secondary bottlenecks.  
- **Generative details:** Exact procedural generation algorithms (solvability constraints, item/scene distribution) are undisclosed, hindering replication and risking hidden biases.  
- **Ecological validity:** High-level action abstraction simplifies Execution but may obscure lower-level planning or motor deficits; link to child intelligence tests is conceptual, not psychometrically validated.  
- **Benchmark saturation:** With only 12 tasks and static layouts despite randomization, risk of dataset overfitting limits long-term utility.  

## Confidence
- **High Confidence:** Empirical performance findings (consistent model failures on PU, CO, composites).  
- **Medium Confidence:** Causal mechanisms (representational deficit explanations).  
- **High Confidence:** Systemic weakness conclusion (aggregate Perception Reasoning/Planning deficits).  

## Next Checks
1. **FI vs. PU isolation:** Replicate the Puzzle vs. Filling gap using identical seeds and resolutions; expect significant performance difference (p<0.01) across models.  
2. **Resolution-controlled counting:** Run CO tasks at native (64px) and elevated (96px+) resolution; replicate accuracy jumps for specific models while verifying human ceiling at 64px.  
3. **Composite cost quantification:** For a target model, compute product of single-capacity success rates (e.g., MA × SO) vs. observed composite (e.g., MMA); expect significant decrement (>20% relative risk reduction) supporting capacity interference.
