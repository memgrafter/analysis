# Bridging Discrete Marks and Continuous Dynamics: Dual-Path Cross-Interaction for Marked Temporal Point Processes

## Quick Facts
*   **arXiv ID:** 2603.11462
*   **Source URL:** https://arxiv.org/abs/2603.11462
*   **Reference Count:** 34
*   **Primary Result:** Proposes NEXTPP, a dual-channel framework fusing discrete event marks (via self-attention) and continuous dynamics (via Neural ODEs) through cross-attention, achieving state-of-the-art performance on five real-world marked temporal point process datasets.

## Executive Summary
Marked Temporal Point Processes (MTPPs) model sequences of events with both timestamps and discrete types. A key challenge is effectively unifying the discrete, semantic relationships between event marks with the continuous, fine-grained temporal dynamics. NEXTPP addresses this gap with a novel dual-channel architecture. One channel uses self-attention to encode dependencies among event marks, while a second channel employs a Neural ODE to model continuous latent state evolution between events. A cross-attention module fuses these two parallel representations, enabling bidirectional interaction where historical marks condition the temporal dynamics and temporal context refines mark representations. This fused representation drives a neural Hawkes intensity function for event prediction and generation. On five benchmark datasets, NEXTPP significantly outperforms prior state-of-the-art methods, reducing temporal prediction error (RMSE) and event-type misclassification rates while improving log-likelihood.

## Method Summary
NEXTPP processes an input event sequence in three parallel stages. First, an embedding layer projects event marks and timestamps into dense vectors. Second, a **Discrete Encoder** applies self-attention to these embeddings, capturing semantic dependencies among the event types (output `A_i`). Concurrently, a **Continuous Encoder** (termed Neural Evolution) encodes the initial event embedding into a latent distribution, samples an initial state `z(0)_i`, evolves it via a Neural ODE solver over the inter-event interval `[t_i, t_{i+1}]` to `z(1)_i`, and decodes it to a continuous representation `O_i`. Third, a **Fusion (X-Interaction)** module uses cross-attention, with `O_i` as the Query and `A_i` as the Key/Value, to produce a fused context vector `C_i` that integrates both streams. This `C_i` parameterizes a neural Hawkes conditional intensity function `λ(t,m)`. Future events are generated using an iterative thinning sampler that proposes candidate times from an upper-bound Poisson process and accepts them stochastically based on the ratio of true to bound intensity. Training minimizes a composite loss: negative log-likelihood of observed events, a KL divergence regularizing the latent initial state distribution, and a continuity loss encouraging smooth state transitions.

## Key Results
*   NEXTPP achieves state-of-the-art performance across five datasets (Taxi, Amazon, Stack Overflow, Earthquake, Retweet), consistently reducing temporal RMSE (e.g., Amazon: 0.461 → 0.377; Stack Overflow: 1.331 → 1.152) and event-type error rates.
*   It significantly improves data log-likelihood (e.g., Amazon: -2.258 → -1.246), indicating a better fit to the empirical event distribution.
*   Ablation studies confirm the critical contributions of both the Neural Evolution (continuous) stream and the Cross-Attention fusion module, with event-granular ODE evolution proving optimal.

## Why This Works (Mechanism)

### Mechanism 1
*   **Claim:** A dual-channel parallel architecture disentangles the modeling of discrete event marks and continuous-time dynamics, allowing each stream to specialize without interference.
*   **Mechanism:** The discrete stream processes event sequences via self-attention to capture semantic dependencies among marks. Concurrently, the continuous stream evolves a latent state between observed events using a Neural ODE, modeling fine-grained temporal dynamics. The two streams proceed in parallel from the same initial embedding.
*   **Core assumption:** Discrete mark relationships and continuous temporal evolution are distinct but interdependent signals that can be processed separately before fusion, and that event-granular (one ODE step per inter-event interval) evolution is optimal for representing abrupt changes.
*   **Evidence anchors:**
    *   [abstract] "dual-channel framework that unifies discrete and continuous representations via Event-granular Neural Evolution with Cross-Interaction"
    *   [section 3.1] "Our NEXTPP pipeline proceeds in three stages: (1) ... (2) a dual parallel Encoder via Self-Attention and Neural ODEs ..."
    *   [section 4.4] Ablation shows replacing event-granular Neural Evolution with coarse-grained RNNs or chunked ODE steps monotonically degrades temporal RMSE and log-likelihood.
*   **Break condition:** If the event-granular evolution is replaced by coarse-grained chunking (as in ablation "NE→GRU/LSTM" or block-wise tests), temporal precision (RMSE) and distribution fit (log-likelihood) degrade monotonically, indicating the specialized, per-event continuous modeling is compromised.

### Mechanism 2
*   **Claim:** A cross-attention fusion module enables bidirectional semantic alignment, allowing historical event marks to condition temporal dynamics and temporal context to refine mark predictions.
*   **Mechanism:** The reconstructed continuous representation from the Neural ODE (Query) attends to the self-attention output of discrete events (Key/Value). This directs the continuous state to be influenced by relevant past marks, while the discrete representation is implicitly updated with temporal context from the evolved state within the attention mechanism's output.
*   **Core assumption:** The influence between discrete marks and continuous dynamics is not unidirectional; optimal forecasting requires mutual conditioning where marks affect future timing and timing context affects mark generation.
*   **Evidence anchors:**
    *   [abstract] "fused through a cross-attention module to enable explicit bidirectional interaction between continuous and discrete representations"
    *   [section 3.1] "Cross-Attention module then establishes bidirectional interaction ... enabling explicit information flow where historical event marks influence temporal dynamics while temporal context refines mark predictions"
    *   [section 4.5] Heatmap visualizations show cross-attention weights concentrate on causally relevant past events during training, unlike diffuse self-attention patterns.
*   **Break condition:** Removing the cross-attention module (ablation "w/o CA") leads to a significant increase in event-type error rate (e.g., +4.6% on Amazon) and log-likelihood drop, demonstrating the fusion's critical role in integrating the two streams.

### Mechanism 3
*   **Claim:** A neural Hawkes intensity function, parameterized by the fused representation, combined with iterative thinning, generates event sequences that respect both learned continuous dynamics and discrete mark distributions.
*   **Mechanism:** The fused sequence representation `C_i` drives a Hawkes-style intensity `λ(t,m)` that includes a learnable triggering kernel `α_m` and a history-dependent bias via `W_m^⊤ C_i`. Iterative thinning samples candidate times from an upper-bound Poisson process, accepting events where a uniform random variable is below the ratio of true to bound intensity.
*   **Core assumption:** The conditional intensity formulation can be effectively parameterized by a neural network using the fused representation, and the thinning sampler remains tractable for this parameterization.
*   **Evidence anchors:**
    *   [abstract] "The fused representations drive the conditional intensity function of the neural Hawkes process, while an iterative thinning sampler is employed to generate future events."
    *   [section 3.1] Equation (11) defines `λ_i(t,m) = Act(α_m(t−t_i) + W_m^⊤ C_i + b_m + β_m)`.
    *   [section 3.3] Details the thinning algorithm steps.
    *   [section 4.2] Superior log-likelihood scores across datasets indicate the intensity parameterization fits empirical distributions better than baselines.
*   **Break condition:** If the intensity function becomes poorly conditioned (e.g., explosive or flat) due to training instability, the thinning sampler's acceptance rate collapses, degrading both temporal and mark prediction accuracy as seen in unstable baseline comparisons (e.g., SAHP's high variance in Table 3).

## Foundational Learning
*   **Concept: Marked Temporal Point Processes (MTPPs)**
    *   *Why needed here:* NEXTPP models events as (time, mark) pairs; understanding the conditional intensity `λ(t,m|H_t)` as the core object to estimate is prerequisite. The paper builds on this foundation to propose a new intensity parameterization.
    *   *Quick check question:* What does the conditional intensity `λ(t,m)` represent in an MTPP, and why is it central to prediction and likelihood calculation?
*   **Concept: Neural Ordinary Differential Equations (Neural ODEs)**
    *   *Why needed here:* The continuous stream uses a Neural ODE to evolve latent states between discrete events. Grasping the ODE formulation `dz/dt = f_θ(z,t)` and the adjoint method for memory-efficient backpropagation is key to understanding the "Neural Evolution" module's operation and advantages over discrete RNN steps.
    *   *Quick check question:* How does a Neural ODE model continuous-time evolution differently from a discrete RNN, and what is the role of the adjoint sensitivity method?
*   **Concept: Self-Attention and Cross-Attention**
    *   *Why needed here:* Self-attention processes the discrete event sequence; cross-attention fuses it with the continuous stream. Understanding attention as a mechanism for weighted aggregation of a set of vectors (queries, keys, values) is essential to follow the information flow design.
    *   *Quick check question:* In the cross-attention module of NEXTPP, what serves as the Query, Key, and Value, and what does this design choice enable?

## Architecture Onboarding
*   **Component map:** Embedding Layer -> Discrete Encoder (Self-Attention) -> A_i; Embedding Layer -> Continuous Encoder (Neural Evolution: Encoder -> ODESolve -> Decoder) -> O_i; A_i & O_i -> Fusion (Cross-Attention) -> C_i; C_i -> Intensity Head -> λ(t,m) -> Sampler (Iterative Thinning) -> Generated Events.
*   **Critical path:** Input event sequence is embedded. The embeddings branch into two parallel paths: (1) Self-Attention produces `A_i` capturing discrete mark dependencies. (2) A Neural ODE evolves a latent state per inter-event interval to produce `O_i` capturing continuous dynamics. `O_i` (as Query) and `A_i` (as Key/Value) enter Cross-Attention to produce the fused context `C_i`. `C_i` parameterizes the neural Hawkes intensity, which is used by the thinning sampler to generate the output event sequence.
*   **Design tradeoffs:**
    *   **Memory vs. Temporal Precision:** A low-dimensional latent space (`d << D`) in the Neural ODE reduces memory cost but risks information loss; the paper shows it maintains performance.
    *   **Granularity vs. Stability:** Event-granular ODE steps (one solve per interval) capture fine dynamics but require more solver invocations; coarse steps (chunking multiple intervals) are computationally cheaper but harm accuracy (Figure 3).
    *   **Fusion Complexity:** Cross-attention adds parameters and computational overhead versus simpler fusion (e.g., concatenation), but ablation proves it is necessary for achieving high mark-type accuracy.
*   **Failure signatures:**
    *   **Poor Log-Likelihood:** Indicates intensity mis-specification or unstable latent dynamics (check convergence of continuity loss `L_cont` and variance `τ` in Figure 6a).
    *   **High Error Rate:** Suggests mark-type information is not properly integrated, likely due to cross-attention failure or insufficient capacity in the discrete encoder.
    *   **Diverging Training / NaNs:** Often stems from ODE solver instability due to poor initialization, aggressive learning rates, or unnormalized timestamps. Check solver tolerances and gradient norms.
*   **First 3 experiments:**
    1.  **Reproduce Table 2 & 3:** Train and evaluate NEXTPP on the Amazon dataset, verifying it matches or exceeds reported RMSE, error rate, and log-likelihood to confirm implementation correctness.
    2.  **Run Ablation "w/o CA":** Remove the cross-attention fusion module, retrain, and compare metrics. Expect a significant absolute increase in event-type error rate (~5%) and a drop in log-likelihood to confirm the fusion's critical role.
    3.  **Conduct Event-Granularity Test:** Modify the code to perform ODE evolution over blocks of `α` events (α=2,4,8) instead of per-event. Plot NLL and RMSE against `α`. Expect a monotonic worsening as `α` increases, validating the paper's claim about event-granular optimality.

## Open Questions the Paper Calls Out
*   **Open Question 1:** What is the theoretical relationship between event-granularity evolution step size and a dataset's inherent temporal dynamics (e.g., rate of intensity change, inter-event variability), and can we derive a data-driven principle for optimal granularity? *Basis:* Section 4.4 empirically shows single-event granularity (α=1) is optimal but provides no formal justification or link to dataset properties.
*   **Open Question 2:** How does the cross-attention module's learned interaction *causally* shape the neural Hawkes intensity function, and can attention weights be interpreted as quantitative measures of mark-driven temporal influence? *Basis:* Section 4.5 shows cross-attention concentrates on relevant events, but no direct mapping from attention weights to the triggering kernel `α_m` or baseline `β_m` is established.
*   **Open Question 3:** What specific properties of the Neural ODE-based continuous channel enable robust performance under limited training data, where Transformer-based discrete models struggle? Is this benefit primarily due to smoother latent trajectories or explicit ODE inductive bias? *Basis:* Section 4.6 shows NEXTPP scales better with data size than Transformer baselines, but the ablation comparing to RNNs is inconclusive about the ODE's specific advantage.
*   **Open Question 4:** Does the variational posterior over initial latent states `q(z_i^(0)|t_i, m_i)` capture meaningful uncertainty that correlates with prediction error, and can its learned variance `τ` be calibrated as a confidence measure? *Basis:* The model includes a KL term and Figure 6a tracks `τ` convergence, but no uncertainty calibration metrics (e.g., reliability diagrams) are reported.

## Limitations
*   **Implementation Gaps:** Critical hyperparameters like exact ODE solver tolerances (`rtol`/`atol`), the specific form of the variational prior `p(z0)`, and full data splitting/normalization details are not specified, potentially hindering exact replication.
*   **Scalability Concerns:** The event-granular Neural ODE requires solving an ODE for every observed inter-event interval, incurring significant computational overhead for very long sequences; no efficiency analysis is provided.
*   **Generalization Scope:** Evaluation is limited to five datasets with moderate mark cardinality and sequence lengths. Performance on high-cardinality mark spaces or extremely sparse/irregular event streams remains untested.

## Confidence
*   **Dual-channel disentanglement:** **Medium**. Ablation (Table 4) shows both streams contribute, but the universal optimality of event-granularity relies on a limited sweep (α=1,2,4,8) across a small set of datasets.
*   **Cross-attention fusion:** **High**. Ablation removing it causes large, consistent performance drops (Table 4), and attention visualizations (Figure 4) provide clear qualitative evidence of learned, focused interaction.
*   **Neural Hawkes intensity parameterization:** **Medium**. Strong log-likelihood improvements suggest an effective fit, but the theoretical properties (e.g., identifiability, stability) of this specific neural network parameterization are not analyzed.
