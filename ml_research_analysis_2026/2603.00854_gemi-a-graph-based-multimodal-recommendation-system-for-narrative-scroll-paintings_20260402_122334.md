# GeMi: A Graph-based, Multimodal Recommendation System for Narrative Scroll Paintings

## Quick Facts
- **arXiv ID:** 2603.00854
- **Source URL:** https://arxiv.org/abs/2603.00854
- **Reference Count:** 24
- **Primary Result:** GeMi achieves a peak Precision@5 of 0.78 on mythology concepts using VGAE, outperforming state-of-the-art recommenders on a novel, sparse dataset of 189 narrative scroll panels.

## Executive Summary
GeMi is the first recommendation system designed for endangered Eastern Indian narrative scroll paintings, addressing cold-start and data sparsity in a domain with only 189 panels. It combines multimodal content (images and Bengali song text) with user preferences. The system employs an LLM (TinyLlama) to canonicalize noisy text, extracts complementary embeddings from a discriminative model (SigCLIP) and a generative multimodal VAE, and propagates this information through item-item graphs built via kNN similarity. Graph neural networks (GCN, GAE, VGAE) are used for learning panel representations. Transductive training, which leverages the full graph during training, consistently outperforms inductive learning. The work demonstrates that LLM-enhanced multimodal features and graph-based transductive learning effectively model the relational structure of this culturally specific art form.

## Method Summary
The core pipeline first processes raw panel data: Bengali song descriptions are rewritten into canonical form using TinyLlama. Two distinct multimodal embeddings are then generated—one from a fine-tuned SigCLIP model and another from a VAE that fuses image and text via a Product-of-Experts. A symmetric k-nearest-neighbor graph is constructed from these features, with an optional augmentation adding edges between panels sharing tree labels. This graph feeds into one of three graph encoders (GCN, GAE, or VGAE) to produce node embeddings supervised by sparse panel concept labels (Animal, Tree, Mythology) and, for autoencoder variants, by adjacency matrix reconstruction. For recommendation, synthetic user profiles are created by sampling panels; a user's embedding is the mean of their liked panel vectors, and panels are ranked by cosine similarity to this user vector. The system is evaluated on Precision@5 per concept.

## Key Results
- GeMi (VGAE with LLM+VAE features) achieves **Precision@5 = 0.78** on the mythology concept, significantly outperforming homogeneous and heterogeneous graph-based baselines.
- **Transductive training** consistently beats inductive learning across all concepts and graph encoders.
- **LLM-based text canonicalization** provides a substantial performance lift, particularly for abstract narrative concepts like mythology.

## Why This Works (Mechanism)
### Mechanism 1: LLM-Based Text Canonicalization
TinyLlama rewrites raw, colloquial Bengali song descriptions into a normalized, concept-focused format. This deterministic pre-processing reduces lexical variance and noise, creating a textual representation that aligns more reliably with visual motifs for downstream vision-language models. The improved semantic alignment is evidenced by significant performance gains in ablations (e.g., Mythology P@5 rising from ~0.58 to ~0.65). The approach risks over-normalization, potentially losing culturally specific dialectal terms or poetic metaphors.

### Mechanism 2: Complementary Multimodal Embeddings
GeMi uses two distinct embedding pipelines: SigCLIP (contrastive) provides a robust, aligned joint space, while the VAE (generative, with PoE fusion) models per-modality uncertainty. Feeding these separate embeddings (`e_sigclip`, `e_vae`) into different graph encoders allows the system to leverage both confident alignment and probabilistic fusion. Ablation results confirm their complementary utility: LLM+VAE excels on narrative/abstract concepts (Mythology), while LLM+SigCLIP is stronger on visually distinct ones (Animal).

### Mechanism 3: Transductive Graph Structure Learning
The item-item graph is built from multimodal features and trained in a transductive manner using VGAE/GAE. These models jointly optimize for adjacency reconstruction and label prediction, allowing them to exploit the full graph's connectivity—including unlabeled test nodes—during training. This propagates label information through the graph, smoothing the latent structure and mitigating sparsity. On the small, noisy dataset, transductive methods show large margins over inductive counterparts (e.g., 0.78 vs. 0.61 P@5 on Mythology).

## Foundational Learning
- **Concept: Variational Autoencoder (VAE)**
  - **Why needed:** To fuse image and text while modeling uncertainty, crucial for handling missing/noisy modalities common in Phase 2 scroll data.
  - **Quick check:** How does Product-of-Experts (PoE) fusion combine the precision (inverse variance) of the image and text encoder distributions?
- **Concept: Graph Convolutional Network (GCN)**
  - **Why needed:** To propagate label and feature information across the panel similarity graph, allowing a panel to borrow strength from semantically similar neighbors when its own label is rare.
  - **Quick check:** In a one-layer GCN, how does the symmetric normalized adjacency matrix `˜A = D^{-1/2} A D^{-1/2}` affect neighbor feature aggregation?
- **Concept: Contrastive Learning (SigCLIP)**
  - **Why needed:** To align image and canonicalized text into a shared space where matching pairs are close, providing a discriminative signal complementary to the VAE's generative approach and helping distinguish visually similar but narratively different panels.
  - **Quick check:** What is the primary difference between the standard softmax-based CLIP loss and the sigmoid-based SigCLIP loss used in fine-tuning?

## Architecture Onboarding
- **Component map:** Raw Panel (Image + Bengali Text) -> LLaMA (Canonical Text) -> [SigCLIP Encoder -> e_sigclip] & [Multimodal VAE (PoE) -> e_vae] -> Graph Builder (kNN + Tree-aug) -> Adjacency Matrix A -> [GCN/AE/VGAE Encoder on A with e_sigclip/e_vae] -> Node Embeddings -> Multi-label Classifier (Animal/Tree/Mythology) + User Preference Simulator -> User Embedding (mean of liked panels) -> Recommendation Engine (cosine similarity ranking).
- **Critical path:** LLM Canonicalization -> Multimodal Embedding -> Graph Construction -> Graph Encoding. The multimodal embedding and graph encoding stages are co-dependent and empirically most pivotal.
- **Design tradeoffs:**
  - **Transductive vs. Inductive:** Transductive uses full graph during training (better for static collection); inductive isolates test nodes (for streaming). Paper shows transductive superior.
  - **Graph Encoder:** GCN (simple supervised), GAE (+ unsupervised reconstruction), VGAE (+ uncertainty). VGAE/GAE often win; GCN can be sparser-label robust.
  - **Feature Pipeline:** LLM+SigCLIP excels on visual concepts; LLM+VAE excels on narrative ones. An ensemble is recommended.
- **Failure signatures:**
  - **Mythology P@5 collapses (<0.40):** Likely LLM over-normalization or VAE KL collapse. Inspect LLM outputs.
  - **Tree P@5 ~0:** Graph kNN failing to capture background tree relations; check `--tree_aug` and k value.
  - **Inductive > Transductive:** Suspected data leakage or graph construction bug; transductive should dominate.
- **First 3 experiments:**
  1. Replicate GeMi-GCN with Llama-VAE features; verify Mythology P@5 ~0.65, Tree ~0.36.
  2. Ablate LLM: Compare Base-VAE+GCN vs. Llama-VAE+GCN; expect ~0.58 -> 0.65 rise on Mythology.
  3. Ablate graph structure: Test with/without `--tree_aug` to confirm it lifts Tree precision.

## Open Questions the Paper Calls Out
- **Alternative LLMs:** How do other LLMs (BLOOM, Gemma2, Qwen) for text canonicalization impact performance vs. TinyLlama?
- **Generative AI for Content Creation:** Can diffusion models generate missing modalities (e.g., images from text) to improve recommendations and personalization where multimodal data is misaligned?
- **Dynamic Pricing:** How can dynamic pricing mechanisms be integrated to improve artist livelihoods, and what strategies balance revenue and user adoption?
- **Synthetic vs. Real User Preferences:** To what extent do Monte Carlo-sampled synthetic preferences reflect real user behavior, and how does model performance transfer to a real-world setting?
- **Cold-Start Generalization:** How does GeMi handle truly new users/panels (e.g., unseen visual/textual patterns) under inductive settings, and what modifications enable robust zero-shot generalization?

## Limitations
- **Tiny dataset:** Only 189 panels limits statistical power and generalizability beyond this highly specific cultural domain.
- **Synthetic evaluation:** User preferences are algorithmically simulated, not based on real human interactions, which may not capture actual aesthetic or cultural engagement.
- **Reproducibility gaps:** Exact train/test split, random seeds, LLM prompt wording, and fine-tuning details are not fully specified, relying on provided scripts/files.
