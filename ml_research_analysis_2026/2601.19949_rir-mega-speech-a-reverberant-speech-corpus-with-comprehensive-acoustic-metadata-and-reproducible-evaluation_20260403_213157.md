# RIR-Mega-Speech: A Reverberant Speech Corpus with Comprehensive Acoustic Metadata and Reproducible Evaluation

## Quick Facts
- **arXiv ID:** 2601.19949  
- **Source URL:** https://arxiv.org/abs/2601.19949  
- **Reference count:** 0  
- **Primary result:** Paired evaluation with Whisper small shows reverberant WER increase of +2.50 pp (95% CI 2.06–2.98), a 48% relative rise, with monotonic trends vs RT60/DRR.

## Executive Summary
This paper introduces RIR-Mega-Speech, a large-scale reverberant speech corpus created by deterministically convolving LibriSpeech clean utterances with approximately 5,000 simulated room impulse responses (RIRs) from the RIR-Mega collection. Each generated audio file is accompanied by pre-computed acoustic metadata (RT60, direct-to-reverberant ratio [DRR], clarity index C50) and universal split assignments. The resource emphasizes reproducibility via provided rebuild scripts and a paired evaluation protocol using Whisper small on 1,500 clean/reverberant utterance pairs. Results confirm expected acoustic trends: WER increases with reverberation time (RT60) and decreases with direct-to-reverberant ratio (DRR), all quantified with bootstrap confidence intervals.

## Method Summary
The corpus construction follows a deterministic signal-processing pipeline. Clean LibriSpeech utterances are convolved in the time domain with randomly sampled RIRs (up to ten per clean utterance), excluding cases that cause clipping. The RIRs originate from the simulated RIR-Mega collection. For every RIR (and thus every output file), acoustic parameters are computed using standardized methods: RT60 via Schroeder backward integration (−5 to −35 dB fit), DRR as the ratio of energy in the first 2.5 ms to the remainder (in dB), and C50 as the energy ratio between the first 50 ms and the later part (in dB). All file paths, acoustic metrics, speaker IDs, and train/dev/test splits are stored in a universal CSV metadata file. Evaluation employs a paired design: a fixed set of 1,500 utterances is used, each tested in both its clean and one reverberant variant. Word error rates (WER) are computed, and the per-utterance difference is bootstrapped (B=2000) to derive a 95% confidence interval for the mean paired ΔWER. The entire process, from data acquisition to final plots, is scripted with fixed random seeds to ensure exact replicability.

## Key Results
- Clean WER: 5.20% (95% CI 4.69–5.78); Reverberant WER: 7.70% (7.04–8.35).
- Paired WER increase: +2.50 percentage points (95% CI 2.06–2.98), corresponding to a 48% relative degradation.
- WER increases monotonically with RT60 and decreases with DRR across binned analyses, confirming known acoustic relationships with quantified statistical confidence.

## Why This Works (Mechanism)
The approach succeeds through three interrelated mechanisms. First, simulated RIR convolution creates a large, acoustically diverse reverberant corpus with known ground-truth conditions. By convolving clean speech with a pool of ~5,000 simulated RIRs and pre-computing standardized acoustic metrics (RT60, DRR, C50), the corpus enables systematic, controlled study of ASR performance across a wide range of reverberant environments. Second, per-file acoustic metadata enables post-hoc analysis and filtering by specific, quantified acoustic conditions without re-processing audio. The universal CSV associates every audio file with its source RIR's parameters, allowing researchers to group, bin, or subset the test set by RT60, DRR, etc., facilitating the investigation of performance trends as a function of these continuous variables. Third, the paired utterance evaluation design with bootstrap confidence intervals provides a statistically robust measure of reverberation's impact. By testing the same clean utterance in both clean and reverberant forms, the paired analysis isolates the effect of the acoustic transformation from inherent utterance difficulty. Nonparametric bootstrapping of the paired differences then yields a distribution from which a precise confidence interval for the mean degradation is derived, controlling for variability across utterances.

## Architecture Onboarding
- **Component map:** Sources (LibriSpeech WAVs/transcripts, RIR-Mega RIR WAVs) -> Build Pipeline (convolve.py, compute_metrics.py) -> Outputs (reverberant WAVs, metadata.csv) -> Evaluation (evaluate_wer.py, bootstrap_ci.py, plot_trends.py) -> Configuration (config.yaml).
- **Critical path:** RIR selection -> Convolution -> Acoustic Metric Computation -> Metadata CSV -> Paired Test Set Selection -> Whisper Inference -> Paired WER Difference Calculation -> Bootstrap CI.
- **Design tradeoffs:**
  - Simulation vs. Reality: Simulated RIRs offer perfect parameter control and reproducibility but may lack complex real-world scattering/diffraction; real RIRs offer validity but are sparse and hard to redistribute.
  - Metadata Fidelity vs. Perceptual Relevance: Using a 2.5 ms direct-only window for DRR isolates the true direct path but may produce values misaligned with perceptual models that include early reflections (up to 50 ms).
  - Coverage vs. Sampling: Non-stratified sampling from RIR-Mega led to uneven RT60-DRR coverage; a stratified approach would improve balance but require a larger/targeted RIR pool.
- **Failure signatures:**
  - Missing/incorrect metadata: `metadata.csv` entries with NaN or impossible values (e.g., RT60 ~ 0 for a long decay RIR). Check: run `python scripts/compute_metrics.py --verify`.
  - Splits leakage: A speaker appearing in both train and test splits. Check: `grep "speaker_id" metadata.csv | sort | uniq -d`.
  - Rebuild failure: `make all` completes but output file count or duration mismatches Table 1 (53,230 files, ~117.7 h). Check: `wc -l outputs/rirmega_speech_out/*.wav`.
  - Evaluation mismatch: Replicated WER falls outside reported 95% CI. Likely cause: different Whisper version, beam search settings, or text normalization.
- **First 3 experiments:**
  1. **Metadata Integrity Spot-Check:** Randomly select 10 files from `metadata.csv`. Manually compute RT60/DRR from the source RIR using the paper’s formulas and compare to CSV entries.
  2. **Replicate Core WER Result:** Run the provided evaluation on the 1,500-paired test set using `openai/whisper-small` with beam size 5. Verify computed mean WER and 95% CIs match the paper’s intervals.
  3. **Trend Validation:** Using evaluation outputs, replicate the binned WER vs. RT60 plot (Figure 7). Ensure monotonic increase holds with your bootstrap resampling; check bin definitions and file counts per bin.

## Open Questions the Paper Calls Out
1. **Does the 2.5 ms direct-only window DRR definition correlate with human speech intelligibility or ASR difficulty?**  
   *Basis:* Section 3.3 acknowledges the definition differs from perceptual models that include early reflections.  
   *Why unresolved:* Its perceptual validity for predicting ASR errors is untested; only monotonic trends are shown.  
   *Resolving evidence:* Conduct listening tests for a subset of RIRs and correlate with multiple DRR definitions; or re-analyze existing WER data with alternative DRR computations.

2. **Can acoustic parameter coverage be made more uniform through stratified sampling, and does this change observed WER trends?**  
   *Basis:* Section 3.4 admits random (non-stratified) sampling led to uneven RT60–DRR coverage (Figure 3).  
   *Why unresolved:* Sparse regions (e.g., high RT60 + very low DRR) limit confidence in trends there.  
   *Resolving evidence:* Generate an augmented corpus using stratified design over RT60/DRR, re-run Whisper evaluation, and compare trend lines/confidence intervals.

3. **Do degradation patterns generalize to real-world reverberant corpora with measured RIRs and ambient noise?**  
   *Basis:* Section 7.2 notes simulated RIRs may not capture real complexities; Section 7.3 recommends supplementing with corpora like REVERB or CHiME.  
   *Why unresolved:* Evaluation was only on simulated data; interaction with real-world factors (noise, room asymmetry) is unknown.  
   *Resolving evidence:* Evaluate Whisper small on a standardized subset of REVERB/CHiME with estimated RT60/DRR, comparing trend slopes to those from RIR-Mega-Speech.

4. **How do state-of-the-art robust ASR models and dereverberation front-ends perform, and do they show the same acoustic sensitivity trends?**  
   *Basis:* Section 5.1 states Whisper small is not claimed best; Section 7.4 lists evaluating more models as future work.  
   *Why unresolved:* Only one relatively small model was tested; trends for larger architectures or with dereverberation are unknown.  
   *Resolving evidence:* Evaluate models like Whisper large, WavLM, and pipelines with WPE on the same paired test set; compare WER trends across RT60/DRR bins.

5. **Which specific phonemic or linguistic features are most vulnerable to reverberation, and does this interact with utterance duration?**  
   *Basis:* Section 6.4 notes anecdotal patterns (e.g., consonant substitutions, function word deletion) but no systematic phonetic analysis.  
   *Why unresolved:* No forced-aligned phoneme-level error rates are provided; vulnerability across phoneme classes remains unclear.  
   *Resolving evidence:* Perform forced alignment on the evaluation set, compute phoneme error rates (PER) by class/manner/voicing, and correlate PER with RT60/DRR and duration.

## Limitations
- **Simulation validity:** RIRs are simulated; may lack real-world diffraction, moving sources, and non-linear room effects, limiting ecological generalizability.
- **Metadata definition sensitivity:** DRR uses a fixed 2.5 ms direct window; its correlation with perceptual clarity/ASR difficulty across diverse RIRs is unvalidated.
- **Coverage imbalance:** RIR sampling was random (non-stratified), leading to uneven RT60–DRR distribution; trends may be skewed by sparse regions.
- **Model scope:** Evaluation uses only Whisper‑small; trends with other architectures (e.g., Conformer, Wav2Vec2) or dereverberation methods are unknown.

## Confidence
- Corpus reproducibility: **High** (scripts, seeds, formats provided; rebuilding is deterministic).
- Reported WER deltas: **Medium** (paired bootstrap robust, but depends on fixed test split, Whisper config, and text normalization).
- Acoustic trend claims (monotonicity): **Low–Medium** (trends shown, but per-bin confidence intervals are wide; DRR definition may not generalize).
