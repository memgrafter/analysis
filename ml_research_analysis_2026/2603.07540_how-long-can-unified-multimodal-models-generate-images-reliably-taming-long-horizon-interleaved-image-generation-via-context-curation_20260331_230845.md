# How Long Can Unified Multimodal Models Generate Images Reliably? Taming Long-Horizon Interleaved Image Generation via Context Curation

## Quick Facts
- **arXiv ID:** 2603.07540
- **Source:** https://arxiv.org/abs/2603.07540
- **References:** 26
- **Primary Result:** A training-free inference policy reduces quality collapse in long-horizon interleaved generation by evicting irrelevant historical context, improving image quality (HPS v3 ↑7.57) and consistency (DINOv2 ↑0.4272) while cutting memory and speeding up inference ~11×.

## Executive Summary
Unified multimodal models that interleave text and image generation suffer rapid quality degradation over long horizons. The root cause is identified as "active pollution": dense historical visual tokens dominate attention via heavy-tailed outlier matches, corrupting new image synthesis. The paper proposes UniLongGen, a training-free inference strategy that curates context. It performs a one-shot attention probe to score historical text and image blocks using model-internal relevance signals from layer-specialized depths, then evicts low-score tokens from the KV cache during generation. On a 40-image benchmark, this stabilizes generation, significantly boosting per-image quality and cross-image consistency while reducing memory use and improving speed.

## Method Summary
UniLongGen is applied at inference time to a unified model (BAGEL) without retraining. For each new image generation step conditioned on cumulative history:
1.  **One-shot Probe:** Run a single forward pass over the full history (all prior text blocks and image VAE token blocks) to capture per-layer attention keys (K) and queries (Q).
2.  **Dual-Depth Scoring:** Compute a relevance score for each historical block. Text blocks are scored at an early layer (ℓgrd=1) using VAE-derived queries. VAE image blocks are scored at a late layer (ℓsyn=15) using the same current-image VAE query mean. The score is the head-averaged, pre-softmax Q·K similarity.
3.  **Layer-Split KV Eviction:** During all subsequent denoising steps for the current image, the KV cache is masked. For layers < ℓsyn, only Turn 1 and the top-Kgrd text blocks are visible. For layers ≥ ℓsyn, only Turn 1 and the top-Kimg image blocks are visible. All other tokens are permanently evicted from consideration.

## Key Results
- On a 40-image narrative benchmark, UniLongGen improves image quality (HPS v3) from 3.17 to 7.57 over a dense-KV baseline.
- Cross-image consistency (DINOv2) improves from 0.3164 to 0.4272.
- The approach reduces memory footprint and achieves up to ~11× inference speedup.
- Ablations confirm that eviction at the image-block (event) level, not token-level pruning/compression, is essential for stable long-horizon generation.

## Why This Works (Mechanism)
The failure in long-horizon generation stems from "active pollution." The model's KV cache, filled with dense visual tokens from prior images, creates a heavy-tailed distribution of attention matches. A small number of these historical tokens can form extremely strong (outlier) matches with the current generation queries, hijacking attention and corrupting the output. UniLongGen directly attacks this by using the model's own attention probes to identify and evict the specific historical visual tokens most likely to cause these disruptive matches. The dual-depth scoring exploits functional specialization: early layers (grounding) need text context, while late layers (synthesis) need only the most relevant visual priors. By permanently evicting low-score blocks at the correct layer depth, it removes the source of pollution without discarding necessary grounding information.

## Foundational Learning
- **Long-Horizon Interleaved Generation:** The task of generating a sequence of alternating text and images (e.g., a storyboard). *Why needed:* The paper's core problem domain; standard short-context generation fails here. *Quick check:* Can the model maintain character and style consistency across dozens of generated images?
- **KV Cache & Attention:** The key-value cache stores past activations for autoregressive generation. Attention computes relevance between current queries and cached keys. *Why needed:* The cache is where pollution accumulates; attention weights determine token influence. *Quick check:* Does pruning the KV cache affect output coherence?
- **Transformer Layer Specialization:** Different layers in a model learn different functions (e.g., early layers for linguistic/semantic grounding, late layers for high-level feature composition). *Why needed:* UniLongGen's scoring uses different depths for text vs. image relevance, assuming this split. *Quick check:* Do attention maps vary systematically by layer depth for multimodal inputs?
- **Pre-softmax vs. Post-softmax Attention:** Pre-softmax QK scores represent raw compatibility; post-softmax weights are normalized. *Why needed:* UniLongGen uses pre-softmax scores to avoid recency/normalization biases that would misrepresent true relevance. *Quick check:* Does using post-softmax weights for scoring degrade performance?
- **Event-Level vs. Token-Level Granularity:** Grouping tokens into semantic units (e.g., an image's VAE tokens as one block). *Why needed:* The mechanism relies on evicting whole competing visual events; token-level pruning leaves partial pollutant tails. *Quick check:* Does evicting individual tokens within an image block still cause collapse?
- **Heavy-Tailed Attention Distributions:** A few key-value pairs can receive disproportionately large attention mass. *Why needed:* Explains why even a few irrelevant visual tokens can dominate. *Quick check:* Does the attention weight distribution have extreme outliers in long sequences?

## Architecture Onboarding
**Component Map:**
Input Sequence (Text1, Img1_Tokens, Text2, Img2_Tokens, ...) -> BAGEL Model (Transformer Layers) -> Per-Layer Attention (Q, K, V) -> KV Cache -> Generation Head (Text/Image Decoders)
UniLongGen adds: Attention Probe (reads Q,K) -> Dual-Depth Scoring (Layer1 for Text Blocks, Layer15 for Img Blocks) -> Top-K Selection -> KV Cache Pruning (Layer-Specific Masks)

**Critical Path:** 1) Serialize interleaved history into token blocks. 2) For current step, run full-history forward pass to collect Q/K per layer. 3) Compute block scores at ℓgrd (text) and ℓsyn (images). 4) Determine top-K sets. 5) During generation, apply layer-specific masks to the KV cache, evicting all non-selected tokens.

**Design Tradeoffs:**
- *Training-Free vs. Performance:* Avoids costly retraining but is tied to a specific model's attention patterns.
- *Memory vs. Quality:* Evicting more tokens saves memory/improves speed but risks discarding necessary context.
- *Granularity:* Block-level eviction is coarse but essential; token-level is finer but ineffective against pollution.
- *Layer-Split Policy:* Complexity vs. efficacy; a single uniform policy across layers harms either grounding or synthesis.

**Failure Signatures:**
- Quality collapse still occurs after applying UniLongGen.
- Inconsistent character/style across images in the narrative.
- Degraded text grounding or incoherent image-text alignment.
- No speed/memory gain observed.
- Metrics degrade if using post-softmax scores or token-level pruning.

**First Three Experiments:**

Verify the reported HPS v3 and DINOv2 improvements over a no-eviction baseline.
2.  **Eviction Granularity Ablation:** Implement three variants: a) Block-level eviction (paper method), b) Token-level pruning (evict individual low-score tokens), c) Block-level compression (approximate low-score blocks). Compare all on quality and consistency metrics to confirm block-level necessity.
3.  **Probing Layer Sensitivity:** Sweep the scoring layers (ℓgrd and ℓsyn) across the model's depth (e.g., early, middle, late layers). Plot metric performance (HPS v3, DINOv2) as a heatmap to validate the chosen depths (1 and 15) are optimal or near-optimal for the target model architecture.

## Limitations
- **Implementation Gaps:** Critical details of BAGEL (exact tokenization, block boundaries, layer count) are undisclosed, forcing assumptions that may affect replication.
- **Benchmark Inaccessibility:** The exact 50 narrative templates used for evaluation are not public, necessitating a substitute benchmark that may not align perfectly with the paper's test distribution.
- **Generalizability Concern:** The method is tightly coupled to the specific attention patterns and modality competition within the BAGEL architecture; performance on other unified models (e.g., SDXL-based) is an open question.

## Confidence
- **Quality/Consistency Gains (HPS v3 ↑7.57, DINOv2 ↑0.4272):** Medium. Results are specific to the paper's exact setup (model, benchmark, hyperparameters); replication with different choices may yield different magnitudes.
- **Efficiency Improvements (Memory Reduction, ~11× Speedup):** Medium-High. The eviction logic directly reduces KV cache size and attention compute; quantitative speedup depends on implementation and hardware.
- **Criticality of Event-Level Eviction:** High. The provided ablations strongly support this claim, though independent confirmation on a different model would strengthen it.
- **Mechanism (Active Pollution via Heavy-Tailed Attention):** Medium. The explanation is coherent and supported by analysis, but direct causal proof (e.g., intervening on specific tokens) is not shown.

## Next Checks
1.  **Cross-Model Validation:** Reimplement UniLongGen on a different open-source unified multimodal model (e.g., a variant of Stable Diffusion 3 or Emu3) with a consistent 40-image narrative benchmark to test if the quality/consistency gains generalize.
2.  **Granularity Ablation Study:** Conduct a controlled comparison between the proposed block-level eviction, token-level pruning, and block-level approximation/compression, measuring the impact on both per-image metrics (HPS v3, PickScore) and cross-image consistency (DINOv2) to quantify the claimed necessity of event-level eviction.
3.  **Probing Layer Sweep:** Systematically vary the relevance scoring layers (ℓgrd for text, ℓsyn for images) across the model's depth and measure the robustness of the final metrics to identify the optimal or most robust layer pair, verifying the paper's chosen depths.
