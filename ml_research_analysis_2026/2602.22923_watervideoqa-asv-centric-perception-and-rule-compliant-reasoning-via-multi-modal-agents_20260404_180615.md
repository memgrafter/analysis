# WaterVideoQA: ASV-Centric Perception and Rule-Compliant Reasoning via Multi-Modal Agents

## Quick Facts
- **arXiv ID**: 2602.22923
- **Source URL**: https://arxiv.org/abs/2602.22923
- **Reference count**: 37
- **Primary result**: NaviMind achieves state-of-the-art on WaterVideoQA with a finetuned 21B variant (GPT-Score 0.602, CIDEr 0.948) and generalizes to LingoQA (CIDEr 93.77), while maintaining efficient inference (9.74s for 11B variant).

## Executive Summary
This paper introduces WaterVideoQA, the first large-scale VideoQA benchmark for all-waterway environments, containing 3,029 videos and 3,673 QA pairs across five hierarchical cognitive levels. It also presents NaviMind, a multi-agent neuro-symbolic system designed to bridge the gap between passive visual perception and knowledge-driven, regulation-compliant reasoning for autonomous surface vessels (ASVs). NaviMind integrates Adaptive Semantic Routing, Situation-Aware Hierarchical Reasoning with RAG, and Autonomous Self-Reflective Verification. Experimental results demonstrate state-of-the-art performance on WaterVideoQA, efficient inference, strong cross-domain generalization to the LingoQA driving benchmark, and robust ablation-validated component contributions.

## Method Summary
NaviMind orchestrates five specialized agents—Router, Captioner, Reasoner, Grader, and Summary—built on multi-modal LLMs. The Adaptive Semantic Routing (ASR) classifies user queries into three pathways (Fast Vision, Fast RAG, Complex Reasoning) to minimize latency. For complex queries, the Situation-Aware Hierarchical Reasoning (SAHR) pipeline applies Adaptive Temporal Standardization to sample key video frames, generates a global scene description via a Captioner, retrieves relevant maritime regulations using RAG, and performs chain-of-thought reasoning to produce rule-compliant answers. An Autonomous Self-Reflective Verification loop employs a Grader agent to score answers against retrieved context; if confidence is low, retrieval scope expands and regeneration occurs. The system is fine-tuned on WaterVideoQA with standard hyperparameters (AdamW, lr=4e-5, batch size 8) and shows efficiency gains and generalization beyond the maritime domain.

## Key Results
- **State-of-the-art on WaterVideoQA**: Finetuned 21B-parameter variant attains GPT-Score 0.602 and CIDEr 0.948.
- **Efficient inference**: 11B variant processes a query in ~9.74 seconds; ASR reduces latency without accuracy loss.
- **Cross-domain generalization**: Achieves CIDEr 93.77 on the LingoQA driving benchmark.
- **Ablation insights**: SAHR is essential (largest GPT-Score drop when removed); ASR significantly cuts latency with negligible performance change.

## Why This Works (Mechanism)

### Mechanism 1: Adaptive Semantic Routing (ASR)
- **Claim**: ASR optimizes computational efficiency by dynamically directing user queries to the most appropriate processing pathway (fast vision, fast RAG, or complex reasoning) based on semantic intent, thereby reducing latency without sacrificing accuracy.
- **Mechanism**: A lightweight Router Agent classifies the query into one of three categories (perceptual, knowledge-driven, or complex causal). Conditional execution then bypasses unnecessary components: simple perceptual queries skip knowledge retrieval, explicit knowledge queries skip video processing, and complex tasks activate the full SAHR pipeline.
- **Core assumption**: Query intents can be reliably distinguished by a small model, and different intents benefit from different computational pathways—simple queries do not require heavy reasoning, while complex ones require full multimodal synthesis.
- **Evidence anchors**: Ablation (Section V) shows removing ASR causes a massive latency surge with negligible performance gain, indicating misrouting primarily harms efficiency rather than accuracy when the full pipeline remains available.
- **Break condition**: Misclassification by the Router Agent could send a complex causal query to a fast path (yielding incorrect answers) or a simple perceptual query to the complex path (wasting resources). The paper’s ablation suggests accuracy is preserved but efficiency drops.

### Mechanism 2: Situation-Aware Hierarchical Reasoning (SAHR)
- **Claim**: SAHR bridges the gap between raw visual perception and regulation-compliant reasoning by explicitly aligning video observations with maritime rules through hierarchical, chain-of-thought deduction.
- **Mechanism**: Adaptive Temporal Standardization (ATS) normalizes variable-length videos into a fixed set of key frames. A Captioner Agent generates a global scene description. A Reasoner Agent then synthesizes visual tokens, the user query, the caption, and retrieved regulations (via RAG) into a coherent answer, explicitly conditioning generation on rule chunks.
- **Core assumption**: Generic MLLMs lack domain-specific maritime knowledge; by injecting regulatory constraints via RAG and structuring reasoning hierarchically, the system can produce logically sound, rule-grounded outcomes.
- **Evidence anchors**: Ablation (Section V) demonstrates that removing SAHR causes the steepest drop in GPT-Score, confirming its necessity.
- **Break condition**: Failure could arise if ATS selects uninformative frames (e.g., due to occlusion or blur), if the Captioner misses key scene elements, or if RAG retrieves irrelevant/outdated regulations.

### Mechanism 3: Autonomous Self-Reflective Verification
- **Claim**: The verification loop mitigates hallucinations by iteratively assessing answer consistency against retrieved regulations and forcing regeneration when confidence is low, ensuring outputs are strictly rule-compliant and visually grounded.
- **Mechanism**: A Grader Agent scores the initial Reasoner output against the retrieved context. If the score falls below a threshold τ, the system expands the retrieval scope and regenerates the answer, repeating up to N times. This closed-loop feedback corrects potential errors before final delivery.
- **Core assumption**: Hallucinations can be detected by measuring factual and logical alignment with authoritative maritime rules; iterative refinement with expanded retrieval can resolve inconsistencies.
- **Evidence anchors**: Ablation (Section V) shows the verification acts as a precise safety net with minimal latency impact; the retry distribution indicates a high first-pass accuracy (>70% across categories).
- **Break condition**: If the Grader Agent is poorly calibrated (e.g., threshold τ set too low or high), it may reject valid answers or accept invalid ones. Additionally, if the knowledge base lacks coverage for edge cases, expanded retrieval may not provide corrective evidence.

## Architecture Onboarding
- **Component map**: User Query -> Router Agent -> {Fast Vision: Captioner Agent -> Answer; Fast RAG: RAG -> Reasoner Agent -> Answer; Complex Reasoning: ATS -> Captioner Agent -> RAG -> Reasoner Agent -> Grader Agent (optional retry) -> Summary Agent -> Answer}
- **Critical path (for a complex knowledge-based query)**:
  1. Router classifies query as `p_reason`.
  2. ATS samples K frames from the input video.
  3. Captioner processes sampled frames to produce a scene description `C_cap`.
  4. RAG fuses query and `C_cap` to retrieve top-K regulation chunks `R_kn`.
  5. Reasoner combines visual tokens `v`, query `q`, caption `C_cap`, and rules `R_kn` to generate an answer via CoT.
  6. Grader scores the answer against `R_kn`; if score >= τ, proceed; else, expand retrieval and regenerate (up to N retries).
  7. Summary Agent formats the final answer into actionable guidance.
- **Design tradeoffs**:
  - Router size vs. accuracy: A 1B router is fast but may misclassify; scaling improves routing but adds latency.
  - ATS frame count K: More frames preserve temporal detail but increase compute; too few may lose critical motion cues.
  - Verification thoroughness: Higher retry limit N improves safety but increases response time; the paper sets N=1 for efficiency.
  - Offline capability: Using a local Captioner ensures operation without Wi-Fi but limits its capacity compared to cloud models.
- **Failure signatures**:
  - Router sends a causal query to `p_vis`: Answer ignores temporal dynamics, leading to oversimplified guidance.
  - ATS selects frames with motion blur or occlusion: Visual tokens miss key objects (e.g., buoys, vessels), degrading grounding.
  - Captioner hallucinates objects not present: Injects false premises into reasoning chain.
  - RAG retrieves irrelevant rules: For example, pulling inland regulations for a sea scenario, causing non-compliance.
  - Grader accepts a hallucination (false negative): Output passes verification despite factual errors.
  - Reasoner ignores retrieved rules: Generates plausible but non-compliant maneuvers.
- **First 3 experiments**:
  1. **Router validation**: Sample 200 queries from WaterVideoQA with known intent labels. Measure routing accuracy and latency distribution. Expected: >90% accuracy, with `p_reason` queries showing higher latency.
  2. **SAHR necessity**: Ablate the RAG component (set `R_kn = ∅`) on knowledge-based questions. Measure drop in GPT-Score and CIDEr. Expected: significant decline, confirming RAG’s role.
  3. **Verification loop**: Introduce synthetic errors (e.g., alter video to remove a buoy) and check if Grader triggers retries. Measure retry rate and final accuracy. Expected: high retry rate on corrupted inputs, with corrected answers aligning with ground truth.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question**: How does the incorporation of multi-sensor fusion (e.g., 4D radar, LiDAR) with visible-spectrum video quantitatively improve NaviMind's robustness and reasoning accuracy under severe visual degradation conditions (e.g., dense fog, nighttime glare) compared to the current video-only paradigm?
- **Basis**: The first limitation states that "relying exclusively on visible-spectrum video exposes the framework to severe degradation under extreme maritime conditions" and future work plans to "evolve WaterVideoQA into a multi-sensor benchmark by fusing 4D millimeter-wave radar and LiDAR."
- **Why unresolved**: The current NaviMind architecture and WaterVideoQA benchmark are evaluated solely on RGB video inputs. The impact of complementary sensor modalities on the core neuro-symbolic reasoning pipeline, particularly the Situation-Aware Hierarchical Reasoning (SAHR) and verification mechanisms, remains untested and unquantified.
- **What evidence would resolve it**: A new multi-sensor variant of the WaterVideoQA dataset and a corresponding NaviMind model that processes fused sensor streams. Controlled experiments under synthetically degraded (e.g., fog, low-light) and real-world adverse-weather video clips, measuring performance delta (GPT-Score, CIDEr) against the video-only baseline, along with failure mode analysis of the visual tokenization and reasoning stages.

### Open Question 2
- **Question**: Can integrating a dedicated Spatial-Grounding Agent that outputs dense trajectory coordinates or instance-level masks significantly enhance the safety and executability of NaviMind's navigational guidance, and what is the trade-off in inference latency?
- **Basis**: The second limitation identifies that "NaviMind lacks fine-grained spatial grounding" and "cannot explicitly output dense trajectory coordinates or instance-level masks," with a planned "Spatial-Grounding Agent to map textual deductions directly onto pixel-level navigable space."
- **Why unresolved**: The current system produces high-level linguistic guidance but stops short of providing the low-level, executable motion primitives required for direct integration with a vessel's control system. The feasibility of this mapping, its impact on reducing the reality gap between reasoning and action, and the associated computational cost are unknown.
- **What evidence would resolve it**: Development and integration of a spatial grounding module (e.g., a segmentation or occupancy prediction head) within the NaviMind agent suite. Evaluation would require a new metric for spatial accuracy (e.g., IoU of suggested safe passages against ground-truth navigable regions) and a practical assessment in a high-fidelity maritime simulator, measuring collision rates and control smoothness before and after integration.

### Open Question 3
- **Question**: To what extent can a multi-agent reinforcement learning (MARL) framework, which explicitly models counterfactual trajectory planning, outperform NaviMind's current auto-regressive reasoning in resolving complex, long-horizon multi-vessel collision avoidance scenarios involving more than two vessels?
- **Basis**: The third limitation states that "resolving multi-vessel game-theoretic interactions remains challenging" as "complex topological conflicts... strain purely auto-regressive decoding," and proposes exploring "multi-agent reinforcement learning to simulate counterfactual trajectory planning."
- **Why unresolved**: NaviMind's reasoning is fundamentally sequential and document-based (via RAG), which may not capture the strategic, recursive nature of multi-agent interactions governed by COLREGs. The MARL approach would require a fundamentally different training paradigm and environment, and its efficacy for open-ended reasoning (beyond the VideoQA format) is an open research problem.
- **What evidence would resolve it**: Construction of a multi-vessel maritime simulation environment (e.g., extending the USVTrack or WaterVideoQA scenarios) with formalized game-theoretic rewards. Training a policy network with MARL and comparing its success rate, safety margin, and regulatory compliance against NaviMind's deductive outputs in held-out complex multi-ship encounter tests, with analysis of policy generalizability to unseen waterway topologies.

### Open Question 4
- **Question**: Does the Adaptive Semantic Routing (ASR) mechanism maintain its efficiency gains and accuracy preservation when confronted with a significantly different distribution of query intents (e.g., a higher proportion of ambiguous or multi-faceted queries) compared to the WaterVideoQA benchmark?
- **Basis**: The paper demonstrates ASR's effectiveness via the "Route Strategy Distribution" (Fig. 6), which shows the router correctly classifying queries from the test set. However, the distribution of the five cognitive levels in WaterVideoQA may not reflect real-time, open-vocabulary user queries from a human-ASV interface, where intent ambiguity could be higher.
- **Why unresolved**: The router's classifier is trained and validated on the curated, well-defined WaterVideoQA intent taxonomy. Its robustness to out-of-distribution or semantically hybrid queries (e.g., a question that implicitly requires both perception and rule-retrieval) is not evaluated. Misrouting such queries could either trigger unnecessary heavyweight pathways (hurting efficiency) or bypass necessary components (hurting correctness).
- **What evidence would resolve it**: A stress test using a held-out set of "adversarial" or "edge-case" queries crafted to probe the router's boundaries (e.g., questions with fused intents, vague spatial references). Analysis would track the divergence between the router's chosen path and a "gold-standard" oracle path determined by human experts, measuring the drop in end-to-end accuracy and latency increase when the router is forced to use its decision versus the oracle path.

### Open Question 5
- **Question**: Are the five hierarchical cognitive levels (Perception, Scene Understanding, Action/Interaction, Causal & Predictive, Knowledge-Driven) in the WaterVideoQA taxonomy strictly orthogonal and sequentially dependent, or do real-world maritime reasoning tasks often require non-linear, recursive application of multiple levels simultaneously?
- **Basis**: The dataset is structured on a "five-tier hierarchical cognitive framework" and the SAHR mechanism models a "hierarchical reasoning capability" with two levels. The design implies a progression from basic to advanced reasoning. However, the qualitative examples (Fig. 7) suggest tasks like collision avoidance simultaneously involve perception, causal prediction, and rule-based knowledge.
- **Why unresolved**: The benchmark treats question-answer pairs as belonging to a single primary category. This may obscure the fact that solving a complex "Knowledge-Driven" query might first fail if its underlying "Causal" or "Perception" sub-components are flawed. The architecture assumes a discrete path selection (ASR), but the cognitive process might be more fluid.
- **What evidence would resolve it**: A fine-grained error analysis of NaviMind's failures on each question category, specifically checking if incorrect answers for "higher-level" questions are preceded by detectable errors in the "lower-level" perceptual or descriptive steps (e.g., flawed captioning leading to wrong rule retrieval). Alternatively, designing hybrid questions explicitly requiring two+ levels and measuring if the system's routing and reasoning modules can seamlessly integrate them without cascading errors.

## Limitations
- Exact model specifications for each agent’s MLLM (e.g., which InternVL3 variant corresponds to 1B/2B/4B/8B/14B) are not disclosed, hindering reproducibility.
- Details of the maritime knowledge base K (source documents, chunking strategy, exact text encoder) are unknown, preventing proper evaluation of rule retrieval.
- Implementation details such as Captioner prompts, ATS’s “adaptive” frame selection logic, and router training data/thresholds are missing, limiting full mechanistic understanding.

- Adaptive Semantic Routing: Medium
- Situation-Aware Hierarchical Reasoning: Medium
- Autonomous Self-Reflective Verification: Medium
