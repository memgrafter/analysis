# Hybrid Neural-LLM Pipeline for Morphological Glossing in Endangered Language Documentation: A Case Study of Jungar Tuvan

## Quick Facts
- **arXiv ID**: 2603.00923  
- **Source URL**: https://arxiv.org/abs/2603.00923  
- **Reference count**: 25  
- **Primary result**: A hybrid BiLSTM-CRF + LLM pipeline with retrieval-augmented prompting (RAG) achieves 0.698 token accuracy on Jungar Tuvan morphological glossing, substantially outperforming pure neural (0.474) and pure LLM baselines.

## Executive Summary
This paper tackles the annotation bottleneck for interlinear glossed text (IGT) in low-resource, morphologically complex endangered languages, using Jungar Tuvan as a case study. The proposed hybrid pipeline first applies a BiLSTM-CRF model to generate an initial gloss prediction, then refines it using a large language model (LLM) with retrieval-augmented prompting (RAG). Systematic evaluation shows that RAG dramatically improves over random example selection, and the two-stage hybrid approach consistently beats both standalone components. Notably, including morpheme dictionaries in prompts generally harms performance, and accuracy plateaus around 10–15 retrieved examples. Gains are strongest for infrequent morphemes, demonstrating how structured prediction and contextual LLM reasoning can complement each other to reduce annotator workload.

## Method Summary
The task is token-level morphological glossing (predicting gloss labels for gold-segmented morphemes). The baseline is a BiLSTM-CRF with character embeddings and two BiLSTM layers. For LLM-based methods, four models are prompted using a system message defining a linguistic expert role and a user message containing optional morpheme dictionaries, few-shot examples retrieved via TF-IDF cosine similarity, and the test sentence. The hybrid pipeline feeds the BiLSTM output as a “rough initial attempt” into the same LLM prompt (without dictionary). Evaluation uses exact-match token accuracy. Key unknowns include the unreleased Tuvan corpus specifics, BiLSTM hyperparameters, TF-IDF settings, and precise LLM versions/prompt formatting.

## Key Results
- The best hybrid model (deepseek-v3.2-exp) reaches 0.698 accuracy, surpassing the BiLSTM baseline (0.474) and pure RAG LLM generation.
- RAG provides a large absolute gain over random example selection (+0.388 for deepseek-v3.2-exp).
- Adding morpheme dictionaries (any size or type) to prompts reduces performance compared to no dictionary.
- Accuracy scales logarithmically with the number of few-shot examples, plateauing around 10–15.
- Hybrid gains are most pronounced for infrequent lexical morphemes.

## Why This Works (Mechanism)
Retrieval-augmented prompting (RAG) supplies the LLM with contextually relevant in-context examples from the training corpus, significantly improving its predictions over random or no examples. The BiLSTM-CRF provides a structured, data-efficient initial guess that captures local sequential dependencies. The LLM then corrects residual errors—especially on infrequent or ambiguous morphemes—using its broader linguistic knowledge and the retrieved examples. The hybrid design leverages the BiLSTM’s strength in modeling sequence structure and the LLM’s strength in contextual reasoning and pattern generalization. The failure of dictionary inclusion suggests that the tested prompt format introduced noise or distraction, overwhelming any potential lexical lookup benefit.

## Foundational Learning
- **Morphological Glossing**: Assigning grammatical labels (e.g., `PST`, `1SG`) to individual morphemes in a segmented word. *Why needed*: Foundational for linguistic analysis of morphology in endangered languages. *Quick check*: For Tuvan “ev-ler-im-den” (house-PL-1SG.ABL), glosses are `house-PL-1SG.ABL`.
- **BiLSTM-CRF**: A neural architecture for sequence labeling, combining bidirectional LSTMs with a Conditional Random Field layer. *Why needed*: Models context-sensitive dependencies between adjacent morphemes, improving label consistency. *Quick check*: Predicts a gloss for each morpheme using prefix/suffix context.
- **Retrieval-Augmented Generation (RAG)**: augmenting LLM prompts with retrieved examples from a knowledge source. *Why needed*: Mitigates LLM limitations in low-resource settings by providing task-specific demonstrations. *Quick check*: For a test sentence, find the most similar training sentences by TF-IDF and prepend them to the prompt.
- **Token-level Accuracy**: Exact match between predicted and gold gloss per morpheme. *Why needed*: Standard automatic metric for IGT, though it ignores morphological consistency across forms. *Quick check*: If predicted gloss sequence `[CAT, PL]` matches gold `[CAT, PL]` exactly, count as correct.
- **Agglutinative Morphology**: Word formation by concatenating clear morpheme boundaries (typical in Turkic languages). *Why needed*: Common in many endangered languages; segmentation is often straightforward but glossing is complex. *Quick check*: “gitti” (Tuvan “went”) = “git-ti” (go-PST).
- **Hybrid Pipeline**: Combining a neural model with an LLM in a sequential refinement loop. *Why needed*: Balances data efficiency (BiLSTM) with contextual reasoning (LLM). *Quick check*: BiLSTM predicts → LLM corrects using same input + BiLSTM output.

## Architecture Onboarding
- **Component Map**: Segmented Tuvan Sentence → BiLSTM-CRF → Initial Gloss → (Retrieval: TF-IDF similarity → Few-shot examples) → LLM Prompt → Refined Gloss  
- **Critical Path**: The core flow moves from fixed segmentation to BiLSTM prediction, then through retrieval (parallel) to LLM refinement. RAG is computed per test sentence; the BiLSTM output is injected into the LLM user message.
- **Design Tradeoffs**:  
  - *BiLSTM vs LLM*: BiLSTM is fast, trainable on small data, but limited by training distribution; LLM is flexible and knowledgeable but prone to distraction and hallucinations.  
  - *RAG vs Random*: RAG provides relevant context but depends on retrieval quality; random is simpler but ineffective.  
  - *Dictionary Inclusion*: Intended to aid lexical lookup but in practice introduces noise due to formatting or irrelevant entries.
- **Failure Signatures**:  
  - Dictionary presence consistently lowers accuracy.  
  - Random retrieval underperforms RAG significantly.  
  - Prompt non-compliance (missing `###` delimiters) breaks extraction.  
  - Accuracy plateaus or drops beyond ~15-shot, likely due to irrelevant examples crowding context.  
  - Hybrid gains diminish for frequent morphemes, indicating BiLSTM already handles them well.
- **First Experiments**:  
  1. Train and evaluate the BiLSTM-CRF baseline on gold-segmented Tuvan-like data; record token accuracy.  
  2. Implement TF-IDF character-level retrieval; test pure LLM generation with 3-shot RAG vs random examples.  
  3. Build the hybrid: feed BiLSTM output into the LLM prompt (no dictionary); compare accuracy against pure LLM and BiLSTM across multiple k.

## Open Questions the Paper Calls Out
- **Cross-linguistic generalization**: Do the hybrid design principles (RAG, BiLSTM-LLM synergy) work for non-Turkic morphological systems (e.g., polysynthetic, templatic)? *Basis*: Future directions explicitly call for diverse typological evaluation.
- **Joint segmentation and glossing**: Can the pipeline handle raw text (no gold boundaries), and does joint modeling improve accuracy? *Basis*: Limitations state the assumption of gold boundaries is unrealistic.
- **Effective dictionary integration**: What prompt engineering strategies (e.g., structured formatting, placement) can make morpheme dictionaries helpful rather than harmful? *Basis*: Discussion notes the tested format was ineffective; systematic studies needed.
- **Real-world annotator impact**: Does the pipeline actually reduce fieldwork time and cognitive load, and at what accuracy do linguists adopt it? *Basis*: Conclusion admits no user study; practical utility is speculative.
- **Paradigm-level consistency**: Do LLM corrections improve coherence of glosses across inflectional paradigms, and could explicit paradigm constraints boost performance? *Basis*: Future directions mention paradigm-level evaluation beyond token accuracy.

## Limitations
- The exact Tuvan corpus, train/test splits, and sentence boundaries are unreleased, preventing exact replication.
- Critical BiLSTM-CRF hyperparameters (learning rate, batch size, validation split) and TF-IDF retrieval settings (n-grams, max features) are unspecified.
- LLM identifiers (“deepseek-v3.2-exp”, “qwen3-max”) may refer to internal/unreleased versions; prompt formatting details (whitespace, ordering) are ambiguous.

## Confidence
- **Hybrid pipeline superiority**: High (consistent across models and k, clear ablation contrasts)  
- **RAG > random retrieval**: High (large, statistically significant gain)  
- **Dictionary generally hurts**: Medium (ablation shown but cause not deeply diagnosed; may be corpus-specific)  
- **Logarithmic scaling with k, plateau at 10–15**: Medium (trends plotted but model variability and retrieval exhaustion could explain plateaus)  
- **Gains concentrated on infrequent morphemes**: Medium (frequency stratification reported but statistical details lacking)

## Next Checks
1. **Retrieval diversity diagnostic**: On a public IGT dataset (e.g., SIGMORPHON 2023 Task 2), compute distribution of retrieval similarity scores and correlate with per-instance LLM accuracy. A weak correlation would suggest retrieval quality is not the primary driver of gains.
2. **Dictionary effect replication with controlled gloss sets**: Construct two dictionary conditions: (a) only canonical gloss forms, (b) including common paraphrases. Compare LLM accuracy to “no dictionary” on a held-out test set of morphemes to isolate format vs. presence effects.
3. **Hybrid failure mode analysis**: Stratify hybrid errors by (a) BiLSTM confidence scores (CRF marginals), (b) morpheme frequency, and (c) grammatical vs. lexical category. High overlap with low-confidence BiLSTM predictions would confirm LLM acts primarily as a corrector for uncertain base guesses.
