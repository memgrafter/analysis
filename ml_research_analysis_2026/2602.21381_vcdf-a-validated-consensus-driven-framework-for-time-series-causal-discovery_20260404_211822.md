# VCDF: A Validated Consensus-Driven Framework for Time Series Causal Discovery
## Quick Facts
- **arXiv ID:** 2602.21381
- **Source URL:** https://arxiv.org/abs/2602.21381
- **Reference count:** 27
- **Primary result:** VCDF improves stability of time-series causal discovery under noise and non-stationarity, achieving summary F1 gains of 0.08–0.12 (e.g., VAR-LiNGAM linear: 0.69→0.80) and up to 0.18 for sequences ≥1000.

## Executive Summary
Time-series causal discovery is often unstable under noisy conditions and non-stationarity. VCDF addresses this by introducing a validation layer that checks edge stability across blocked temporal partitions using directional consistency and variability metrics, filtering out unstable edges. The framework can be applied to existing causal discovery algorithms (e.g., VAR-LiNGAM, PCMCI) without modifying their internals. On synthetic data, VCDF yields substantial improvements in summary F1 (0.08–0.12) and window F1, with gains up to 0.18 for longer sequences. Benefits are also observed on real-world fMRI and IT monitoring datasets, albeit with limited evaluation. The overhead is linear in the number of folds and described as moderate.

## Method Summary
VCDF operates as a post-processing wrapper around a base causal discovery algorithm. First, the input time series is partitioned into K temporal blocks (e.g., via folding). The base algorithm is run independently on each block, producing K edge sets with associated effect sizes. For each directed edge candidate, two metrics are computed: directional consistency (the proportion of blocks where the edge appears in that direction) and variability (e.g., the standard deviation of effect sizes across blocks). Edges that fail to meet user-defined thresholds on these metrics are pruned, and the remaining edges form the final causal graph. The approach is agnostic to the base algorithm and requires no internal modifications.

## Key Results
- On synthetic data, VCDF improves summary F1 by 0.08–0.12 (e.g., VAR-LiNGAM linear: 0.69→0.80) and yields comparable gains in window F1; for sequences ≥1000, improvements reach up to 0.18.
- The framework enhances robustness on real-world datasets (fMRI brain connectivity, IT system monitoring).
- Runtime overhead is linear in the number of temporal folds and described as moderate.

## Why This Works (Mechanism)
VCDF leverages the insight that true causal relationships are expected to be consistent across different temporal segments of the data, even when the underlying distribution shifts. By requiring an edge to appear in the same direction with stable effect sizes across partitions, the method filters out spurious edges that arise from noise, local fluctuations, or algorithm-specific quirks. This consensus-driven filtering reduces the impact of non-stationarity and leads to more reliable causal graphs. The combination of directional consistency and variability balances sensitivity (catching true edges that may occasionally be missed) and specificity (rejecting edges that appear erratically).

## Architecture Onboarding
- **Component map:** `Time Series Data -> Partitioning -> Base Causal Discovery (per partition) -> Edge Aggregation -> Stability Metrics -> Filtering -> Final Graph`
- **Critical path:**  
  1. Divide the time series into K temporal blocks.  
  2. Run the base causal discovery algorithm on each block independently.  
  3. For each directed edge (i→j), compute directional consistency (fraction of blocks where i→j appears) and variability (e.g., standard deviation of effect size across blocks).  
  4. Apply predefined thresholds; retain edges that satisfy both criteria.  
  5. Output the filtered causal graph.
- **Design tradeoffs:**  
  - Number of folds (K): Larger K offers finer-grained stability assessment but increases computational cost; too small K may miss non-stationarity patterns.  
  - Thresholds: Stricter consistency/variability thresholds improve precision but risk losing true edges; looser thresholds retain more edges but may include false positives.  
  - Algorithm agnosticism: Enables use with any base method but inherits its biases and limitations.  
  - Overhead vs. robustness: Running the base algorithm multiple times adds overhead, but scaling is linear with K, keeping it manageable for moderate K.
- **Failure signatures:**  
  - Excessive edge filtering leading to an empty or overly sparse graph, indicating thresholds are too strict or partitions too small.  
  - No improvement over the base method on synthetic data with known ground truth, suggesting instability metrics are ineffective for the algorithm/data.  
  - Low directional consistency for most edges even for simple relationships, possibly due to insufficient data per partition or overly noisy data.
- **First experiments:**  
  1. Baseline comparison: Apply VAR-LiNGAM and PCMCI on a simple synthetic dataset (e.g., two variables with a known linear lagged causal link) with and without VCDF; compare F1 scores and edge stability metrics.  
  2. Sensitivity to folds: Vary the number of folds (K = 2, 5, 10) on a fixed synthetic dataset; measure summary F1, computational time, and average directional consistency to identify a suitable default.  
  3. Threshold calibration: Systematically vary the consistency threshold (e.g., 0.3, 0.5, 0.7) while keeping variability fixed, and vice versa; plot precision-recall trade-offs to understand their impact.

## Limitations
- Evaluation relies on only two real-world datasets (fMRI, IT monitoring), raising generalizability concerns for other domains.
- Hyperparameters (fold count, block size, consistency thresholds) lack systematic sensitivity analysis; optimal values may vary across datasets.
- Runtime overhead is described only qualitatively; no absolute timing or scaling experiments are provided.

## Confidence
- Synthetic performance gains (F1 +0.08–0.12): Medium
- Robustness on real datasets: Low
- Linear runtime overhead: Medium
