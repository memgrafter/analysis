# Tell Me What To Learn: Generalizing Neural Memory to be Controllable in Natural Language

## Quick Facts
- **arXiv ID:** 2602.23201  
- **Source URL:** https://arxiv.org/abs/2602.23201  
- **Reference count:** 40  
- **Primary result:** GNM achieves 84.1 overall score on a synthetic continual-learning benchmark, surpassing RAG-FT (70.5) and ICL-FT (67.3), with superior fact selectivity (77.4% vs. 61.8%, 51.5%) and format generalization (67.4% vs. 0–4.4%).

## Executive Summary
Neural memory systems typically use a fixed, predefined objective for updating their external memory, preventing users from specifying *what* to learn from incoming documents. This paper introduces Generalized Neural Memory (GNM), which conditions memory updates on natural language instructions. Given an instruction and a document, a learnable update rule modifies an external memory bank; this memory then influences model predictions. Training optimizes a sequence loss over query probes that test both content that should be learned and content that should be ignored. On a synthetic benchmark extending CounterFact with fact, format, and refusal tasks, GNM significantly outperforms fine-tuned in-context learning (ICL-FT), retrieval-augmented fine-tuning (RAG-FT), and the prior MemoryLLM approach. It demonstrates strong generalization to unseen categories, formatting styles, and compositional instructions, while scaling efficiently with the number of documents.

## Method Summary
GNM extends the MemoryLLM architecture by making the memory update rule conditional on an instruction. The core component is an update function \( U_\psi \) that takes the current memory bank \( M_{t-1} \), a learning instruction \( I_t \), and a new document \( D_t \), then produces an updated memory \( M_t \). During training, after each update the model is probed with queries designed to evaluate whether it correctly learned the instructed content *and* correctly ignored non-instructed content. The total loss combines cross-entropy on all these probe responses, forcing \( U_\psi \) to learn selective encoding—storing only instruction-relevant information. At inference, given a query, the model attends to the current memory (prepended as special tokens per layer) to generate a response. This decouples *what* to store from the document's raw content, enabling fine-grained user control.

## Key Results
- GNM achieves an overall score of **84.1** on the test benchmark, substantially higher than RAG-FT (70.5) and ICL-FT (67.3).
- **Fact selectivity** (ability to ignore non-target facts) reaches **77.4%**, compared to 61.8% (RAG-FT) and 51.5% (ICL-FT).
- On **format generalization** to unseen markup styles, GNM attains **67.4%** accuracy, while all baselines score ≤4.4%.
- Ablation removing gradients from the memory update step severely degrades selectivity, confirming that selectivity is learned during the write operation.
- Memory analysis shows GNM's updates align with target facts, not merely filtering at query time, and its inference cost scales O(1) with the number of documents.

## Why This Works (Mechanism)
GNM enables controllable memory updates by conditioning the write operation on natural language instructions, decoupling *what* to store from the document content. The update rule \( U_\psi \) ingests the instruction and document, allowing selective compression so that only instruction-relevant information from \( D_t \) is encoded into the fixed-size memory bank. This relies on grounding the instruction to a representation that reliably modulates encoding. Evidence includes the formalization of \( U_\psi \) and its implementation as a modification to MemoryLLM's learning step.

Training with probes for both targeted and ignored content forces selectivity at the memory write stage, not just at query time. The sequence loss includes queries testing learned facts and facts that should remain unchanged; gradients flow through the entire update trajectory, teaching \( U_\psi \) to suppress disallowed information during encoding. The high fact selectivity scores and the dramatic drop when update-step gradients are removed confirm this mechanism.

A two-stage representation process appears to underlie selectivity: early layers parse the instruction, while later layers use that representation to route only relevant information into memory. Layer-wise intervention shows disrupting middle layers (5–14) harms selectivity without affecting accuracy. Memory analysis reveals increasing alignment between updates and target facts starting in these middle layers, suggesting the instruction representation is built first and then biases the write operation. This relies on the base transformer having separable sub-circuits for instruction understanding and content routing.

- **Instruction Following / Grounding:** The framework depends on mapping a natural language instruction to a precise update rule. Without reliable grounding, the "what to learn" control is ineffective. *Quick check:* How does the training data ensure the model learns to distinguish between "learn facts about X" and "ignore facts about Y"?
- **Selective Learning Objectives (Fact/Format/Refusal):** The benchmark defines multiple orthogonal learning goals to test the generality of control. Each requires a different kind of information to be stored or suppressed. *Quick check:* Why is format accuracy a harder test of generalization than fact accuracy?
- **Continual Learning & Catastrophic Forgetting:** The setting involves a continual stream of documents; the memory must accumulate new information without overwriting previously stored, still-relevant content. GNM aims to mitigate this via external memory. *Quick check:* Why does fine-tuning a base LLM on new documents fail in this setting, even with instructions?

## Architecture Onboarding
- **Component map:** Base model (Llama-3) -> Memory module (MemoryLLM-style token embeddings bank) -> Instruction encoder -> Update rule \( U_\psi \) -> Probe evaluator.
- **Critical path:** 1) Receive \( (I_t, D_t) \). 2) **Learning pass:** Run model with instruction+document, extract last-256 embeddings per layer → write to memory bank (overwrite/replace). 3) **Inference pass:** Given a query \( q \), run model with query and current memory (memory embeddings prepended to each layer). 4) Compute loss on probe responses (for training) or generate output (for testing).
- **Design tradeoffs:** Memory capacity vs. interference (fixed-size bank risks overwriting); instruction complexity vs. generalization (more diverse instructions improve generalization but complicate training); update frequency vs. stability (writing after every document can cause rapid overwriting).
- **Failure signatures:** Low fact selectivity → update rule failing to suppress irrelevant content; poor format generalization on unseen styles → instruction representations not abstracting format concept; retention decay over long sequences (>20 steps) → memory bank saturation without eviction/consolidation.
- **First 3 experiments:** 1) **Fact-only continual learning** tests basic ability to learn/ignore facts using unseen categories/instructions; validates core selectivity. 2) **Mixed knowledge, style, behavior** adds format adoption and refusal behaviors; tests generalization to unseen formatting styles. 3) **Compositional generalization** tests simultaneous fact+refusal instructions (never seen together); shows GNM doubles RAG-FT and >10× ICL-FT on selectivity.

## Open Questions the Paper Calls Out
1. How does GNM perform on real-world, heterogeneous data streams compared to the synthetic CounterFact-based benchmark?
2. Can neural memory avoid exponential retention degradation over long sequences without increasing memory capacity?
3. How should GNM handle contradictory information across time while following instructions about update semantics?
4. Does GNM generalize to free-form natural language instructions that deviate from the templated training distribution?
5. What is the computational overhead of the learned update rule \( U_\psi \) at scale, and does it offset the O(1) inference advantage?

## Limitations
- Key architectural details (exact Uψ implementation, memory bank parameters, query sampling protocol) are unspecified, blocking faithful replication without code.
- Evaluation uses a synthetic benchmark that may not capture the noise, ambiguity, and interdependencies of real domains like healthcare.
- Mechanistic claims (e.g., separable sub-circuits) rely on limited interventions; long-sequence retention behavior is unproven beyond ~20 steps.
- Generalization to truly open-ended natural language instructions and contradictory information streams remains unresolved.

## Confidence
- **Selectivity gains over baselines:** High (consistent metrics, ablations).
- **Two-stage mechanism (instruction parsing then routing):** Medium (layer-wise evidence supportive but not conclusive).
- **Scalability O(1) with documents:** Medium (theoretically plausible, unsupported by large-scale experiments).
- **Generalization to unseen natural instructions/domains:** Low (tested only on held-out CounterFact categories and format styles).
