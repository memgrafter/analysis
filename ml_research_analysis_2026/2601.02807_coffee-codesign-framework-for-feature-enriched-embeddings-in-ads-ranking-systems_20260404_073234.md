# COFFEE: COdesign Framework for Feature Enriched Embeddings in Ads-Ranking Systems

## Quick Facts
- **arXiv ID:** 2601.02807
- **Source URL:** https://arxiv.org/abs/2601.02807
- **Reference count:** 8
- **Primary result:** Enriches event-based feature sequences via diverse sources, longer histories, and multi-modal attributes; achieves +0.56% CTR AUC gain at sequence length 200; ad-impression enrichment yields AUC 0.758 and scaling slope 7.12 vs organic AUC 0.235/slope 2.37.

## Executive Summary
COFFEE is a framework designed to enhance ads-ranking systems by enriching user event sequences along three dimensions: incorporating diverse event sources (organic, ad-impression, video-view), extending user history length, and adding multi-modal attribute embeddings. The core modification replaces static user features with a sequence of event-based features processed by a transformer-based learner. In experiments, the enriched ad-impression model improves CTR prediction AUC by 0.56% over a baseline at sequence length 200, and demonstrates superior scalability with a scaling slope of 7.12 compared to organic sources' slope of 2.37. These gains indicate that richer, longer, and semantically augmented event sequences significantly improve user intent modeling for ad ranking.

## Method Summary
The authors extend a production ads-ranking sparse neural network into a sequence learning model. Input events (organic impressions, ad impressions, video views) are aggregated per user into timestamped sequences of Event-Based Features (EBFs). Each event’s attributes (up to 10, including content-id, dwell-time, semantic IDs) are linearly compressed into a dense embedding, combined with a timestamp encoding, and optionally enriched with multi-modal content features (e.g., k-NN from pre-trained vision-language embeddings). The sequence of event embeddings is fed to a transformer-based Sequence Learner to predict click-through rate. The framework allows independent scaling of three axes: EBF source type, sequence length (r), and attribute enrichment. Training and evaluation are performed on billions of user samples, measuring Normalized Entropy (NE) gains and training-capacity scaling curves (AUC vs. training capacity) to assess long-term ROI. The modified architecture introduces no additional complexity during online serving; enrichment is precomputed offline.

## Key Results
- At sequence length 200, enriched ad-impression EBF improves CTR prediction AUC by 0.56% over the baseline production model.
- For ad-impression sources with enrichment, the scaling curve yields AUC 0.758 and slope 7.12, while organic impression (without enrichment) achieves AUC 0.235 and slope 2.37—a 1.56–2× ROI advantage for ad-impression sources even at short sequences (100–10K events).
- NE gains saturate beyond ~1000 events, indicating diminishing returns from extremely long histories.

## Why This Works (Mechanism)
### Mechanism 1: Diverse Event Sources
- **Claim:** Combining diverse event sources (organic, ad-impression, video-view) improves user intent modeling by capturing complementary signals across user engagement surfaces.
- **Mechanism:** The framework aggregates timestamped events from multiple verticals into unified EBF sequences. Each event’s attributes are linearly compressed into a single embedding, allowing the sequence model to learn from varied interaction contexts.
- **Core assumption:** Different event sources provide non-redundant information about user preferences; ad-impressions directly indicate commercial interest, while organic views reflect broader content affinities.
- **Evidence anchors:** The abstract states that diverse and enriched data sources are essential to accurately assess user interest both before and after engagement. Section 2.2 notes that scaling with diverse signals by varying EBFₙ provides a more holistic view of user intent.
- **Break condition:** Sources become noisy or redundant (e.g., organic and ad signals correlate too highly), causing diminishing returns or AUC degradation.

### Mechanism 2: Longer User Histories
- **Claim:** Increasing sequence length (r) enables deeper modeling of long-term user interest evolution, up to a saturation point.
- **Mechanism:** The system extends the number of timestamped events per user within a fixed aggregation window (e.g., 30 days). The transformer-based sequence learner processes longer histories to capture trends, seasonality, and drifting preferences.
- **Core assumption:** Past engagement sequences contain predictive signals for future ad clicks; more events provide better contextual memory.
- **Evidence anchors:** The abstract mentions longer user histories improve the prediction of user interests. Section 3.1 reports that NE gain curves tend to saturate for longer sequences, with the rate of increase diminishing beyond sequence length 1000.
- **Break condition:** Saturation where additional events add noise or exceed model capacity, evident in diminishing NE gains after ~1000 events (Fig. 3).

### Mechanism 3: Multi-Modal Attribute Enrichment
- **Claim:** Enriching events with multi-modal attributes (e.g., content embeddings, k-NN semantic IDs) boosts representation quality by adding nuanced semantic signals.
- **Mechanism:** For each event, additional attributes (text, image, temporal context) are encoded via pre-trained models (e.g., vision-language) and pooled/concatenated with base embeddings. This creates denser, context-aware event vectors.
- **Core assumption:** Raw event metadata (e.g., content-id) is insufficient; multi-modal features capture latent content properties better aligned with user intent.
- **Evidence anchors:** The abstract discusses enriching data with additional event attributes and multi-modal embeddings. Section 2.2 details encoding, concatenating and pooling multi-modal event attributes. Section 3.1 (Table 1) shows ad-impression with enrichment achieves AUC 0.758 vs. 0.486 without, and slope 7.12 vs. 4.69.
- **Break condition:** Attribute noise overwhelms signal (e.g., irrelevant visual features), or vector quantization introduces distortion, causing AUC drop.

- **Why needed:** Replaces static, aggregated user features with dynamic, timestamped sequences that model behavior evolution. This is the core input representation for COFFEE’s sequence learner.

## Architecture Onboarding
**Component map:** EBF Data Pipeline -> Event Module -> Sequence Scaling Modules -> Sequence Learner -> Evaluation Layer

**Critical path:** Raw event -> attribute aggregation -> timestamp encoding -> event embedding -> sequence assembly -> transformer inference -> CTR score. Enrichment steps insert between attribute aggregation and event embedding.

**Design tradeoffs:**
- Sequence length (r) vs. cost: Longer sequences improve AUC but increase training/inference memory and latency.
- Source diversity vs. noise: More EBF types can add signal but may introduce conflicting patterns requiring careful curation.
- Enrichment complexity vs. gain: Multi-modal attributes (e.g., VL embeddings) boost AUC but add preprocessing overhead and potential attribute noise.

**Failure signatures:**
- AUC drop when scaling sequence length beyond saturation point (Fig. 3: NE gains diminish after ~1000 events).
- Shallow scaling slope (e.g., organic sources ~2.37) indicating poor long-term ROI.
- High cross-attention noise (uniform weights) suggesting enriched attributes failed to capture semantic relevance.

**First 3 experiments:**
1. Baseline Comparison: Cap all EBF sources to sequence length 200; compare enriched ad-impression vs. baseline production model (expect +0.56% AUC).
2. Scaling Curve Construction: For each EBF source (with/without enrichment), vary sequence lengths (200–2000), plot NE vs. training capacity, compute AUC and slope (expect ad-impression enrichment: AUC ~0.758, slope ~7.12).
3. Cross-Attention Sanity Check: For a sample of clicked ads, extract top-attended events from organic-impression vs. historic engagement sequences; manually verify topical relevance (expect organic impressions to align better with new ads).

## Open Questions the Paper Calls Out
1. **Why do ad-impression EBFs demonstrate 1.56–2× higher ROI compared to organic-impression and video-view sources?** The paper briefly states ad-impressions are better indicators of future interest, but does not rigorously validate this across user demographics, ad formats, or contextual scenarios. The underlying reasons (e.g., immediate commercial intent, richer metadata) remain unclear. Controlled experiments isolating variables or cohort studies would clarify universality.
2. **What specific enriched features contribute most to the CTR gain for ad-impression EBFs, and why do similar enrichments have significantly smaller impact on organic-impression and video-view sources?** The framework enriches all EBFs with multi-modal attributes, yet the differential impact is not analyzed. Ablation studies systematically removing enriched feature types and feature importance analysis are needed.
3. **Can COFFEE maintain CTR gains and scaling benefits when sequence lengths are extended to ~1e6 without increasing real-time inference latency?** The paper claims offline scalability but lacks online A/B test results for very long sequences. Serving-time optimizations (e.g., cached representations, hierarchical attention) are not described, leaving latency concerns unaddressed.

## Limitations
- Exact model hyperparameters and transformer architecture details are unspecified, hindering precise replication.
- The multi-modal enrichment protocol (e.g., choice of pre-trained model, k-NN size, integration strategy) is vague, making it difficult to assess sensitivity or noise effects.
- The definition and computation of “training capacity” for scaling curves are not detailed, complicating reproduction of reported metrics.
- Lack of ablation studies on attribute noise and overfitting, leaving potential failure modes under-investigated.

## Confidence
- Diverse event sources improve intent modeling: **Medium confidence** (internal experiments show gains, but external validation weak).
- Longer sequences capture long-term preferences: **Medium confidence** (saturation beyond 1000 events reported, but optimal cost trade‑offs unclear).
- Multi-modal attribute enrichment boosts representation: **Low confidence** (results strong but rely on poorly defined components; sensitivity high).
