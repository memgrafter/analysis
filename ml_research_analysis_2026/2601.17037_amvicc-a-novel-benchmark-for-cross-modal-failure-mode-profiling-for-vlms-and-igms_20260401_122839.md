# AMVICC: A Novel Benchmark for Cross-Modal Failure Mode Profiling for VLMs and IGMs
## Quick Facts
- **arXiv ID:** 2601.17037  
- **Source URL:** https://arxiv.org/abs/2601.17037  
- **Reference count:** 21  
- **Primary result:** AMVICC reveals shared failure modes (Quantity/Count, Viewpoint) between multimodal LLMs and image generation models, but also modality-specific weaknesses: IGMs struggle with fine-grained control in explicit prompts, while MLLMs fail more on Positional Relations and Counting; pair accuracy is consistently lower than individual accuracy.

## Executive Summary
This paper introduces AMVICC, a novel benchmark designed to profile failure modes in both multimodal large language models (MLLMs) and image generation models (IGMs) by evaluating them on the same set of visual reasoning concepts. By adapting the MMVP dataset's multiple-choice questions into a set of implicit and explicit text-to-image prompts, the study enables a direct cross-modal comparison. Evaluation of 11 MLLMs and 3 IGMs uncovers that while certain elementary visual reasoning failures (e.g., with quantity and viewpoint) are common across modalities, other weaknesses are specific to the model type. Crucially, IGMs show a significant drop in accuracy on explicit prompts requiring precise attribute manipulation, and all models suffer a performance penalty on paired questions that test consistency under minimal visual variation. The work highlights that robust visual understanding requires consistency across both interpretation and generation.

## Method Summary
AMVICC adapts the 300 image-question pairs from the MMVP benchmark. For MLLMs, the original MMVP evaluation protocol is used: both images and a question are provided, and the model's free-text answer is graded (via GPT-4o) against the correct multiple-choice option. For IGMs, each MMVP question is translated into two text-to-image prompts: an *implicit* prompt describing the general scene, and an *explicit* prompt that adds the specific visual element distinguishing the correct answer. Three IGMs generate images for all 600 prompts. Human evaluators, using a detailed rubric, score each generated image for correctness relative to its prompt. Performance is measured via individual accuracy per category and *pair accuracy* (for MLLMs: both questions in a pair correct; for IGMs: both the implicit and explicit images for a question correct). Nine reasoning categories (e.g., Quantity and Count, Positional and Relational Context) structure the failure analysis.

## Key Results
- Shared failure modes appear in **Quantity/Count** and **Viewpoint/Perspective** categories for both MLLMs and IGMs.
- IGMs exhibit **modality-specific weakness** in fine-grained control: average explicit accuracy is 59.16%, with a notable drop from implicit to explicit prompts.
- **Pair accuracy** is systematically lower than individual accuracy for all models, indicating compounded challenges in maintaining consistency across minimally varying visual conditions.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Shared failure modes between MLLMs and IGMs indicate common underlying limitations in elementary visual representation, while modality-specific failures point to differences in representation or training objectives.
- **Mechanism:** By using the same MMVP visual concepts in both image-to-text (MLLM) and text-to-image (IGM) tasks, the benchmark isolates whether difficulty with a concept (e.g., quantity) is inherent to the concept's representation or specific to the modality's processing bottleneck. A shared failure suggests a gap in the model's internal visual concept representation; divergence suggests a modality-specific issue (e.g., fine-grained control in IGMs, relational reasoning in MLLMs).
- **Core assumption:** Visual concept difficulty should manifest similarly in both directions if the model's internal representation is robust.
- **Evidence anchors:** Paper states failures are "often shared between models and modalities, but certain failures are model-specific and modality-specific." Results show IGMs perform better in positional contexts while MLLMs excel with text, supporting divergent bottlenecks. Neighbor papers on VLM limitations support consistent elementary gaps but do not test cross-modal alignment.
- **Break condition:** If a category shows no statistical correlation in failure rates across modalities (e.g., MLLMs excel while IGMs uniformly fail, or vice versa), the shared representation hypothesis would be falsified.

### Mechanism 2
- **Claim:** IGMs exhibit poorer control over fine-grained visual attributes in explicit prompts compared to implicit prompts, revealing a limitation in precise instruction following for compositional edits.
- **Mechanism:** Implicit prompts ("dog in grass") test basic scene generation. Explicit prompts ("dog in grass looking to the right") add a specific modifying clause. The accuracy drop from implicit to explicit isolates the model's ability to execute precise, incremental visual changes without disrupting the base scene.
- **Core assumption:** The accuracy gap between explicit and implicit prompts measures fine-grained attribute manipulation capacity, independent of basic scene generation competence.
- **Evidence anchors:** Prompt design definition in Section 2.1; results in Section 3.2 show IGMs "consistently struggled to manipulate specific visual components," with Stable Diffusion 3.5 dropping below failure thresholds in all explicit pair categories; Section 3.4.1 ablation shows reworded explicit prompts did not improve accuracy, pointing to conceptual control issues.
- **Break condition:** If explicit and implicit prompt accuracies are statistically indistinguishable across IGMs and categories, the fine-grained control loss mechanism would not hold.

### Mechanism 3
- **Claim:** Pair accuracy (requiring both images/answers in a comparison pair to be correct) is systematically lower than individual accuracy, indicating compounded failure modes where models struggle with consistency across minimally varying visual conditions.
- **Mechanism:** Each MMVP question pair tests a subtle visual distinction (e.g., orientation left vs. right). For MLLMs, answering both correctly requires discerning the difference; for IGMs, generating both images correctly requires controlling that difference. The pair accuracy penalty reflects fragility in the model's internal representation of the discriminating feature under near-identical contexts.
- **Core assumption:** The pair task measures consistency in visual reasoning/generation under perturbation, exposing sensitivity to small changes.
- **Evidence anchors:** Abstract notes pair accuracy is "consistently lower than individual accuracy." Tables 2 (MLLMs) and 4 (IGMs) show pair accuracies generally lower than individual accuracies across models and categories.
- **Break condition:** If pair accuracy equals or exceeds individual accuracy across models and categories, the "compounded challenge" effect would not exist, suggesting models handle comparative reasoning as well as single-instance reasoning.

## Foundational Learning
- **Concept: Benchmark Adaptation & Prompt Engineering**
  - *Why needed here:* AMVICC's validity hinges on converting MMVP's multiple-choice questions into generation prompts that test the same visual concept. Understanding how prompt phrasing (implicit vs. explicit) affects IGM behavior is critical to interpret results.
  - *Quick check:* If an MMVP question asks "Which animal is facing left?" with two images, what would be the corresponding implicit and explicit prompts for an IGM, and what visual concept does each test?
- **Concept: Modality-Specific Evaluation Metrics**
  - *Why needed here:* The paper uses different evaluation methods for MLLMs (AI-graded multiple-choice) and IGMs (human-judged image correctness). Grasping why human evaluators are necessary for IGMs (due to VLMs' own spatial reasoning failures) prevents misinterpreting IGM results.
  - *Quick check:* Why would using an MLLM (like GPT-4o) to judge an IGM’s output for "hidden Z key" introduce bias, and how does the human rubric mitigate this?
- **Concept: Failure Mode Taxonomy**
  - *Why needed here:* The nine categories (Quantity, Viewpoint, etc.) structure all results. Recognizing what each category tests (e.g., "Positional and Relational Context" = spatial relationships between objects) allows mapping successes/failures to specific cognitive visual skills.
  - *Quick check:* For a prompt "Generate a cup on the table with a lemon inside the cup," which AMVICC category is primarily being tested, and would an IGM failing this indicate a problem with object counting, containment relations, or both?
- **Concept: Cross-Modal Alignment**
  - *Why needed here:* The core goal is to compare generation and interpretation failures. Understanding that the same visual concept is probed in both directions (image→text vs. text→image) is key to interpreting shared vs. divergent failure patterns.
  - *Quick check:* If an MLLM fails a "Quantity and Count" question but an IGM successfully generates an image with the correct count for the corresponding prompt, what does that suggest about the model's visual representation?
- **Concept: Human-in-the-Loop Evaluation**
  - *Why needed here:* IGM evaluation relies on human annotators because automated metrics (e.g., using VLMs as judges) can be biased by the very failures being studied. The human rubric provides a more objective ground truth for fine-grained visual attributes.
  - *Quick check:* What are the risks of using a VLM with known poor "Positional and Relational Context" skills to judge an IGM's output for a prompt testing that same category?

## Architecture Onboarding
### Component Map
MMVP Question Pool -> Prompt Translation Module -> IGM Prompts (Implicit/Explicit) -> Model Inference Layer (MLLMs & IGMs) -> Evaluation Engine (GPT-4o for MLLMs, Human Rubric for IGMs) -> Failure Aggregator (Individual/Pair Accuracies per Category) -> Cross-Modal Comparison

### Critical Path
The essential path for IGM evaluation is: MMVP questions → rule-based conversion to 600 prompts (300 implicit + 300 explicit) → IGM generation → human scoring against rubric → category-wise accuracy computation → comparison with MLLM failure patterns. Prompt alignment is critical to ensure the IGM task tests the same concept as the original MLLM task.

### Design Tradeoffs
- **Prompt design bias vs. consistency:** Using a strict template for prompt conversion ensures comparability but may lack natural language variation. Trade-off: controlled stimulus vs. ecological validity.
- **Human evaluation vs. scalability:** Human scoring for IGMs reduces AI-judge bias but limits dataset size and reproducibility. Trade-off: accuracy of ground truth vs. throughput.
- **Model selection breadth:** 11 MLLMs vs. 3 IGMs. Trade-off: wider architectural insight for MLLMs vs. potentially unrepresentative IGM sampling due to API access constraints.

### Failure Signatures
- **IGM explicit prompt failure:** Accuracy drop from implicit to explicit, especially in "Quantity and Count" and "Text" categories.
- **MLLM pair failure:** Pair accuracy significantly lower than individual, notably in "Positional and Relational Context" and "Quantity and Count."
- **Model-specific outliers:** e.g., Llama 3.2 90B Vision-Instruct excels in pairs; Stable Diffusion 3.5 fails all explicit pair categories.

### First 3 Experiments
1. **VLM Baseline:** Run all 11 MLLMs on the 300 MMVP questions. Record individual and pair accuracies per category. Identify common failure categories and best/worst models.
2. **IGM Prompting & Scoring:** For each of the 600 AMVICC prompts, generate images with 3 IGMs. Have human annotators score each image against the rubric. Compute implicit/explicit individual and pair accuracies per model per category.
3. **Cross-Modal Alignment Check:** For each of the 9 categories, compare MLLM failure rates with IGM failure rates. Use correlation analysis to test the hypothesis that failures are shared. Perform t-tests to see if differences (e.g., IGMs worse at explicit prompts) are significant.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** Why do failure modes diverge across specific visual reasoning categories between IGMs and MLLMs (e.g., IGMs performing relatively better in Positional and Relational Context while MLLMs excel in Text recognition)?
- **Basis in paper:** Results show "each model type perform[ed] better in different category-specific tasks," but the discussion does not isolate causes.
- **Why unresolved:** The study compares models with many confounding differences (architecture, training data, objectives). No causal analysis isolates whether divergence stems from training losses, data composition, or architectural biases.
- **What evidence would resolve it:** Controlled studies comparing models with matched architectures but different training regimes, or probing internal representations during tasks from divergent categories (e.g., attention maps for positional reasoning vs. OCR-head activations for text).

### Open Question 2
- **Question:** To what extent are failure modes for a given visual concept (e.g., counting, orientation) correlated across modalities? If a VLM fails to count objects, does an IGM also fail to generate the correct count?
- **Basis in paper:** The framework probes whether "generation and interpretation failures stem from shared limitations," but analysis aggregates by category, not by individual concept.
- **Why unresolved:** The benchmark maps MMVP questions to separate IGM prompts, but evaluation does not directly pair the success/failure of a specific concept across modalities. The paper reports category-level trends, not concept-level alignment.
- **What evidence would resolve it:** Fine-grained analysis linking each of the 300 original MMVP concepts to its corresponding explicit/implicit IGM prompts, measuring concordance of success/failure per concept across all model pairs (e.g., Cohen's kappa).

### Open Question 3
- **Question:** What specific architectural or training choices explain the outlier performance of models like Llama 3.2 90B Vision-Instruct (top MLLM) and Gemini 2.5 Flash Image (top IGM)?
- **Basis in paper:** Results highlight these as top performers; discussion speculates on factors (two-stage vision encoder for Llama, sparse MoE for Gemini) but provides no causal analysis.
- **Why unresolved:** The study compares models with numerous confounding differences (size, training data, API access). Ablations tested prompt wording and stochasticity but not architectural components (e.g., vision encoder type, modality fusion point).
- **What evidence would resolve it:** Targeted ablations on the top-performing models (e.g., replacing vision encoders, modifying MoE routing, or retraining components on controlled datasets) to measure impact on failure-prone categories.

## Limitations
- **Unknown prompt specifics:** The exact 600 AMVICC prompts and human evaluation rubrics are not in the paper; only a GitHub link is provided, risking implementation drift.
- **IGM sample bias:** Only 3 IGMs were tested (DALL·E 3, SD3.5, Imagen3), limiting generalizability across generation architectures.
- **Human evaluation variability:** Subjective scoring nuances for "correctness" could affect IGM accuracy numbers despite inter-annotator agreement checks.

## Confidence
- **High:** Benchmark design validity (systematic prompt adaptation from MMVP; controlled cross-modal comparison).
- **Medium:** Shared failure modes (Quantity/Count, Viewpoint) – evidence from a single study; external validation needed.
- **Low:** IGM explicit-prompt control limitation – ablation suggests conceptual (not linguistic) control issues, but small IGM set weakens the claim.
