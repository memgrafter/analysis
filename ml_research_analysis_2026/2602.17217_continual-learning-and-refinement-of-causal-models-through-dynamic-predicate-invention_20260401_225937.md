# Continual learning and refinement of causal models through dynamic predicate invention
## Quick Facts
- **arXiv ID:** 2602.17217
- **Source URL:** https://arxiv.org/abs/2602.17217
- **Reference count:** 34
- **Primary result:** The system learns a correct symbolic model within dozens of timesteps, achieving first success in episode 2 vs ~128 for PPO, and generalizes zero-shot to larger grids.

## Executive Summary
The paper presents an approach for continual learning and refinement of causal world models via dynamic predicate invention. By integrating Meta-Interpretive Learning (MIL) with a Predict-Verify-Refine loop, an agent incrementally builds hierarchical, reusable abstractions from experience. Evaluated on MiniHack Lava Crossing, the method learns a correct symbolic model within dozens of timesteps, achieving first success in the second episode—over two orders of magnitude more sample-efficient than a PPO baseline. The learned model exhibits zero-shot scale invariance, generalizing to larger grid sizes, and its size stabilizes rapidly by step 23, demonstrating effective online repair.

## Method Summary
The system operates on fully observable states represented as sets of ground atoms. Background knowledge provides static predicates (e.g., adjacent/3). The agent maintains a hypothesis H consisting of abstractions (Abs), dynamic rules (Dyn), and constraints (Con). At each timestep, H predicts state changes via lifted forward chaining; mismatches between predicted and observed changes yield false positives (FPs) and false negatives (FNs). FPs trigger pruning of over-general clauses; FNs trigger metarule-guided abduction to invent new predicates and rules recursively. The Global Predicate Registry canonicalizes invented abstractions to enable reuse. A classical planner uses H to select actions, closing the loop. This online, self-supervised process yields sample-efficient model acquisition and scale invariance.

## Key Results
- Learns a correct symbolic model within dozens of timesteps; first success in episode 2 vs ~128 for PPO (over 100× sample efficiency).
- Model generalizes zero-shot to larger grid sizes (scale invariance).
- Model size stabilizes rapidly (by step 23) through targeted generalization and specialization.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** The system continuously repairs its causal model online via a self-supervised Predict-Verify-Refine loop.
- **Mechanism:** For each state transition, the current hypothesis `H` predicts effects. Mismatches (False Positives/Negatives) trigger localized MIL search: FPs prune over-general clauses; FNs abduce new clauses via metarules. This lattice traversal (Fig 3) incrementally updates `H` without retraining.
- **Core assumption:** Environment dynamics are deterministic and fully observable; prediction failures are attributable to hypothesis incompleteness/incorrectness, not stochasticity.
- **Evidence anchors:**
  - [abstract] "...continuous model learning and repair into the agent’s decision loop... Predict-Verify-Refine loop."
  - [section 2.2] Describes error signals (FP/FN) and specialization/generalization operators.
  - [corpus] Strong thematic alignment with "continual learning" and "refinement" neighbors; direct mechanism not duplicated but conceptually reinforced.
- **Break condition:** Non-stationary environment changes faster than loop can converge, or combinatorial explosion in `D_max`/metarules prevents timely abduction.

### Mechanism 2
- **Claim:** Lifted inference with predicate invention ensures computational cost depends on logical complexity (`D_max`), not state-space size (scale invariance).
- **Mechanism:** Rules operate on relational predicates (e.g., `adjacent/3`) with intensional semantics via procedural attachment. Canonicalization and the Global Predicate Registry (`Ω`) cache/ reuse invented abstractions, converting tree search to DAG construction.
- **Core assumption:** Domain dynamics are expressible via first-order logic with a finite set of metarules; type system sufficiently constrains search.
- **Evidence anchors:**
  - [abstract] "...lifted inference approach scales to domains with complex relational dynamics, where propositional methods suffer from combinatorial explosion... scale invariant."
  - [section 2.3] Formalizes complexity as `O(|M|·|P_typed|^k·D_max)` and describes canonicalization/DAG conversion.
  - [corpus] Consistent with "scale invariance" in title and "relational" focus of neighbors; no direct complexity proof anchor.
- **Break condition:** Required metarule set `M` is inadequate to express target dynamics, forcing exhaustive search; registry collisions from poor canonicalization cause duplicate invention.

### Mechanism 3
- **Claim:** Dynamic predicate invention creates disentangled, reusable hierarchical abstractions that improve interpretability and generalization.
- **Mechanism:** Recursive abduction (Algorithm 1) invents predicates (e.g., `p2` for "moving towards") by applying abstraction metarules to unresolved literals. Invented predicates are typed and reused across rules (e.g., `p2` in both movement and death rules, Fig 1), compressing the theory.
- **Core assumption:** Useful abstractions are compositional and can be built from bottom-up via metarule-guided synthesis; type signatures correctly propagate semantic constraints.
- **Evidence anchors:**
  - [abstract] "...predicate invention to find semantically meaningful and reusable abstractions, allowing an agent to construct a hierarchy of disentangled, high-quality concepts."
  - [section 2.2] Details recursive abduction, depth limit `D_max`, and type inheritance for invented predicates.
  - [corpus] Strong alignment with "predicate invention" neighbors; no direct evidence of "disentanglement" metric beyond interpretability claim.
- **Break condition:** `D_max` too shallow to capture necessary abstractions; type system mis-specified, allowing semantically incoherent inventions; noise in observations leads to spurious abstractions.

## Foundational Learning
- **Concept: Inductive Logic Programming (ILP) / Meta-Interpretive Learning (MIL)**
  - **Why needed here:** The entire framework is a variant of MIL; understanding clause construction, metarules, and Abecedarian (top program) is prerequisite to following the refinement loop.
  - **Quick check question:** How does restricting clause generation to metarule instantiations (vs. arbitrary Horn clauses) change the bias-variance trade-off of the learner?
- **Concept: First-Order Logic (FOL) & Logical Entailment**
  - **Why needed here:** States, rules, and predicates are represented as FOL. The model's correctness hinges on `H ∪ S_t ∪ B |= S_{t+1}`; errors are set differences. One must interpret `add(P)←Body` as a derivative of transition rules.
  - **Quick check question:** Why is the transition function defined via `A = {h | H_Dyn ∪ S_t ∪ B |= h}` rather than directly learning a mapping `S_t × A → S_{t+1}`?
- **Concept: Lifted vs. Grounded Reasoning**
  - **Why needed here:** The claimed scalability ("scale invariance") explicitly comes from reasoning about objects/relations (lifted) rather than enumerating all ground atoms (grounded). Critical to understand why `adjacent/3` is procedural, not a lookup table.
  - **Quick check question:** What would happen to the computational complexity if all predicates (including `adjacent`) were grounded into propositional features?

## Architecture Onboarding
**Component map:**  
Perception → Hypothesis Manager (H) → Predict-Verify-Refine Loop → Metarule Engine ↔ Global Predicate Registry → H (updated)

The critical path is: S_t → E+/E- → Compare with H's prediction → (if error) MetaruleInduction(FN) / Prune(FP) → Update H → CompressAndGC → next timestep.

**Design tradeoffs:**  
- **Symbolic vs. Neural:** Gains: interpretability, sample efficiency, zero-shot scale invariance. Costs: assumes deterministic, fully observable worlds; brittleness to perceptual noise.  
- **Online vs. Batch:** Gains: immediate adaptation, no replay buffer. Costs: cannot leverage hindsight across many episodes; may overfit to transient noise (pruning FPs acts as regularizer).  
- **Fixed Metarules vs. Learning Metarules:** Assumes user-provided `M` is sufficient. Inadequate `M` ceiling on expressivity.

**Failure signatures:**  
1. **Model instability:** `|H|` oscillates without converging (Sec 3.1: "Spikes... sharp drops"). Indicates conflicting evidence or insufficient type constraints.  
2. **Abstraction explosion:** `Abs` grows unbounded. Failure of `Ω` canonicalization or `D_max` too high.  
3. **Prediction blind spot:** Persistent FNs on a specific transition (e.g., never predicts `dead`). Likely missing metarule or inadequate background knowledge `B`.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** How can active model refinement be enforced, where the agent proactively tests rule validity rather than only reacting to prediction errors?
- **Basis in paper:** [explicit] "A promising research direction is to enforce active model refinement, in which the agent sets the rule body as a goal and tests whether the rule is valid."
- **Why unresolved:** The current Predict-Verify-Refine loop only revises the model when errors occur; it lacks a mechanism for deliberate hypothesis testing, which could uncover hidden inconsistencies and accelerate learning.
- **What evidence would resolve it:** Implement an experimental design module that generates targeted queries to falsify rules, and measure improvements in model convergence speed and robustness on benchmark tasks.

### Open Question 2
- **Question:** Can the framework be extended to probabilistic logic to handle stochastic transitions and uncertainty?
- **Basis in paper:** [explicit] "Other promising avenues of research include moving towards probabilistic logic..."
- **Why unresolved:** The system assumes deterministic dynamics; real-world environments often exhibit stochasticity that deterministic logic cannot capture.
- **What evidence would resolve it:** Integrate probabilistic logic programming (e.g., ProbLog) into the MIL engine, evaluate performance on stochastic variants of MiniHack, and compare in terms of sample efficiency and model accuracy.

### Open Question 3
- **Question:** How can neural predicates replace hand-engineered primary predicates to enable autonomous learning of state representations?
- **Basis in paper:** [explicit] "...use of neural predicates... would allow a transition from hand-engineered domain encoding to a more autonomous learning framework in which primary predicates are also learnt."
- **Why unresolved:** The reliance on manually defined background knowledge limits scalability to new domains; neural predicates could learn perceptual features directly.
- **What evidence would resolve it:** Couple the logic engine with differentiable perception modules (e.g., CNNs) to map raw observations to predicate truth values, test on vision-based tasks, and assess generalization.

### Open Question 4
- **Question:** How can the symbolic world model be combined with neural policies to leverage both sample efficiency and robust decision-making?
- **Basis in paper:** [explicit] "Combining this method with a neural policy could enable the agent to plan and react efficiently and robustly."
- **Why unresolved:** The paper focuses on model learning only; a neural policy could handle continuous action spaces or provide fallback strategies when planning fails.
- **What evidence would resolve it:** Develop a hybrid agent where the symbolic model supplies a high-level planner and a neural network supplies low-level policy, evaluate on complex tasks like noisy or large-scale environments.

## Limitations
- Unknown specifics: exact MiniHack task configuration, complete metarules `M`, type signatures, planner identity, hyperparameters (`D_max`, beam widths), and PPO baseline details.
- Strong environmental assumptions: fully observable states, deterministic dynamics, and sufficient user-provided metarules; performance may degrade in stochastic or partially observable settings.
- Predicate invention quality depends critically on initial metarule set and type system.
