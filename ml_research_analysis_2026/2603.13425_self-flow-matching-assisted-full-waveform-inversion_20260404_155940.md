# Self-Flow-Matching assisted Full Waveform Inversion

## Quick Facts
- arXiv ID: 2603.13425
- Source URL: https://arxiv.org/abs/2603.13425
- Reference count: 16
- Primary result: SFM-FWI achieves higher accuracy (lower relative L2, higher SSIM) and robustness than conventional FWI, TV-regularized FWI, and DIP-FWI on multiple benchmarks without offline pretraining, Gaussian initialization, or fixed noise schedules.

## Executive Summary
Full-waveform inversion (FWI) is a powerful technique for subsurface imaging but often suffers from cycle skipping and sensitivity to noise, particularly when starting from a poor initial model. Diffusion-based regularization can mitigate these issues but requires expensive offline training, assumptions of Gaussian priors, and a predefined noise schedule, introducing ambiguities in mapping model states to noise levels.

This paper introduces Self-Flow-Matching assisted FWI (SFM-FWI), which leverages flow matching to learn a deterministic transport field that directly uses the current FWI iterate as the source, thereby eliminating the need for Gaussian initialization and fixed schedules. The flow network is trained online using the FWI data-misfit gradient as self-supervision, and the method alternates between constructing interpolated models and applying flow updates. Extensive benchmarks on Marmousi, Overthrust, and Salt synthetic models demonstrate that SFM-FWI yields superior reconstruction accuracy (lower relative L2 error, higher SSIM) and robustness to poor initialization, noise, and sparse shots, while automatically evolving from coarse to fine structures without handcrafted multi-scale scheduling.

## Method Summary
SFM-FWI incorporates a time-conditioned flow network \(v_\theta\) into the FWI loop. Starting from an initial velocity model \(m_0\), the algorithm runs for \(T\) outer steps. At outer step \(s\), a time \(t = s/(T-1)\) is set, and an interpolated model \(m_t = (1-t)m_0 + t \hat{m}_1\) is computed using the current proposal \(\hat{m}_1\) (initially set to \(m_0\)). Then an inner loop of \(K\) iterations updates the network parameters \(\theta\): the network predicts an update \(v_\theta(m_t, t)\); a candidate model \(\hat{m}_{\text{prop}} = m_t + (1-t)v_\theta\) is evaluated in a differentiable wave solver \(F\) to compute the data-misfit loss \(L = \frac{1}{2}\|F(\hat{m}_{\text{prop}}) - d_{\text{obs}}\|^2\); and \(\theta\) is adjusted via backpropagation through the solver. After the inner loop, \(\hat{m}_1\) is refreshed to \(m_t + (1-t)v_\theta(m_t, t)\) (without gradient). This alternating procedure trains the flow online to propose physics-consistent model updates while gradually refining the model. An optional warm-start phase, minimizing \(\|v_\theta(m_0,0) - m_0\|^2\) for a few iterations, stabilizes early steps without significant overhead.

The method requires no offline training data, no Gaussian prior, and no fixed noise schedule. The linear interpolation path implicitly biases the flow to add low-wavenumber corrections early (small \(t\)) and finer details later, achieving an automatic multi-scale inversion. All components—wave solver, flow network, and optimization—are implemented in PyTorch with automatic differentiation (e.g., via Deepwave), and the total number of forward physics evaluations is \(T \times K\), comparable to conventional FWI.

## Key Results
- On the Marmousi sub-region, SFM-FWI attains relative error 0.0130 and SSIM 0.907, beating DIP-FWI (0.0177/0.866) and conventional FWI (0.0213/0.853).
- It maintains stable convergence under adverse conditions: poor initial models, high noise levels, and sparse shot geometries, where baseline methods degrade significantly.
- The inversion automatically progresses from coarse to fine structures without handcrafted frequency continuation, as evidenced by a slower, monotonic increase in model rank across iterations.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Flow matching eliminates the need for Gaussian initialization and a fixed noise schedule, allowing the current FWI iterate to serve directly as the source distribution for transport.
- **Mechanism:** Instead of reversing a diffusion process from random noise, SFM-FWI learns a deterministic velocity field `v_θ(m_t, t)` via flow matching. This field transports an intermediate model `m_t` (linearly interpolated between the initial model `m0` and current target `m̂1`) toward a refined proposal `m̂1,k = m_t + (1-t)v_θ`. The transport path is defined by the user-chosen interpolation (Eq. 8), not a predefined stochastic differential equation, so `m0` can be any arbitrary starting model.
- **Core assumption:** The initial FWI model `m0` is a valid starting point for the transport dynamics, and the linear interpolation path provides a meaningful corridor for the flow field to operate within.
- **Evidence anchors:** [abstract] "...flow matching to learn a transport field without assuming Gaussian initialization or a predefined noise schedule, so the initial model can be used directly as the starting point of the dynamics." [section 2.2] "Flow matching does not require a specific assumption on the source distribution. Therefore, the current inversion model can be directly treated as the starting point of the transport dynamics..."
- **Break condition:** If the initial model `m0` is so far from the target distribution that the linear interpolation path `m_t` never enters a region where the learned flow field `v_θ` is well-defined or provides a useful gradient, the transport may fail to converge.

### Mechanism 2
- **Claim:** The flow network is trained online using self-supervision derived from the FWI data-misfit gradient, avoiding the need for paired velocity datasets.
- **Mechanism:** At each outer step `s` (with time `t`), the flow network parameters `θ` are updated for `K` inner steps. Each inner step proposes a candidate model `m̂1,k`, evaluates the FWI data-misfit `L_t,k(θ)`, and backpropagates the gradient `∇_θ L_t,k` through the flow update (Eq. 9). This signal `(∂m̂1,k/∂θ)^T ∇_{m̂1,k} Φ` directly ties the flow's output to the physics-based misfit reduction.
- **Core assumption:** Short FWI refinements (the inner `K` steps) from the interpolated state `m_t` generate a sufficiently informative and stable training signal for the flow field. The flow network's update `v_θ(m_t, t)` is meant to *predict* a direction that reduces misfit, not merely fit a static dataset.
- **Evidence anchors:** [abstract] "...trains a single flow network online using the governing physics and observed data... providing self-supervision without external training pairs." [section 2.3] "We use the data-misfit objective to generate self-supervised supervision by minimizing Eq. 10..." [section 2.3] "Across outer steps, the interpolation in Eq. 8 provides a smooth progression... and the shared network v_θ(·, t) learns a time-dependent update rule that consistently decreases the data misfit."
- **Break condition:** If the inner-loop FWI steps `K` are too few, the candidate models `m̂1,k` may not move meaningfully in model space, leading to a high-variance or uninformative gradient signal for `θ`. Conversely, if `K` is too large relative to outer progression, the method may behave like conventional FWI with a slowly changing auxiliary network.

### Mechanism 3
- **Claim:** The alternating outer sampling and inner FWI updates induce an automatic, stable coarse-to-fine (multi-scale) inversion trajectory.
- **Mechanism:** The interpolation `m_t = (1-t)m0 + t m̂1` ensures that early outer steps (small `t`) present the flow network with inputs dominated by the smooth initial model `m0`. The network, trained to propose updates that reduce misfit, thus learns to add primarily low-wavenumber corrections first. As `t` increases, the input `m_t` already contains more refined structures from previous `m̂1` updates, so the flow field naturally introduces progressively higher wavenumbers.
- **Core assumption:** Linear interpolation between a smooth `m0` and a progressively refined `m̂1` provides a natural bias toward low-wavenumber content in early `m_t` samples, and the flow network's learned update `v_θ(m_t, t)` is smooth enough in `t` to not inject high-wavenumbers prematurely.
- **Evidence anchors:** [abstract] "...automatically evolves from coarse to fine structures..." [section 4.1] "SFM-FWI exhibits a noticeably slower and more monotone increase of rank across iterations... realizing an automatic multi-scale inversion schedule without handcrafted frequency continuation." [section 4.2] "SFM-FWI exhibits a clear layer-stripping behavior... emerges automatically without any handcrafted design."
- **Break condition:** If the outer progression is too aggressive (e.g., few outer steps `T` with large `t` increments), early `m_t` may already contain problematic high-wavenumber artifacts from previous updates, causing the flow to reinforce or amplify errors instead of building a stable coarse foundation.

## Foundational Learning
### Flow Matching for Continuous Transport
**Why needed here:** It provides a deterministic alternative to diffusion models, removing the requirement to map a deterministic FWI model to a stochastic diffusion time step and noise level. This resolves the "noise-level alignment ambiguity" described in the paper.  
**Quick check question:** "What is the key mathematical difference between the transport path in flow matching (Eq. 6) and the reverse diffusion process in score-based models?"

### Adjoint-State Method for PDE-Constrained Gradients
**Why needed here:** It is the engine for computing `∇_{m̂1,k} Φ` efficiently within the inner loop. The paper uses automatic differentiation via Deepwave, but the underlying principle is adjoint-state, avoiding the need for repeated forward solves when differentiating the wave-equation solver's output.  
**Quick check question:** "Why is the adjoint-state method necessary for FWI, and how does its cost compare to a single forward simulation?"

### Implicit Regularization via Deep Image Prior (DIP)
**Why needed here:** SFM-FWI is contrasted with DIP-FWI as a pretraining-free implicit regularizer. Understanding DIP (optimizing network parameters `φ` with a fixed random input `z`) helps clarify SFM-FWI's novelty: it uses a *time-conditioned* network trained *online* with a self-supervised signal, rather than a fixed-parameter inductive bias.  
**Quick check question:** "How does the role of the fixed input `z` in DIP differ from the role of the interpolated model `m_t` in SFM-FWI?"

## Architecture Onboarding
### Component map
The system comprises the following interconnected components:
- **Flow Network \(v_\theta\)**: A U-Net that takes a model \(m_t\) and a time scalar \(t\) and outputs a velocity-field update.
- **Interpolator**: Computes \(m_t = (1-t)m_0 + t \hat{m}_1\) from the current initial model \(m_0\) and proposal \(\hat{m}_1\).
- **Inner FWI Loop**: For \(k = 1 \dots K\), uses \(v_\theta\) to generate a candidate \(\hat{m}_{\text{prop},k}\), computes the data-misfit loss via the forward solver \(F\), and updates \(\theta\) by backpropagation.
- **Outer Update**: After the inner loop, sets \(\hat{m}_1 \leftarrow m_t + (1-t)v_\theta(m_t, t)\) (detached) for the next outer step.
- **FWI Solver \(F\)**: A differentiable wave-equation solver (e.g., Deepwave) that computes synthetic data and provides gradients.

Data flows sequentially: \(m_0, \hat{m}_1 \rightarrow \text{Interpolator} \rightarrow m_t \rightarrow v_\theta \rightarrow \hat{m}_{\text{prop}} \rightarrow F \rightarrow \text{loss} \rightarrow \nabla_\theta\). The outer loop governs time \(t\) and the state \(\hat{m}_1\).

### Critical path
The algorithm alternates between outer and inner loops:
1. Outer step \(s\) (from 0 to \(T-1\)): set \(t = s/(T-1)\).
2. Compute \(m_t = (1-t)m_0 + t \hat{m}_1\).
3. Inner loop for \(K\) iterations:
   a. Compute \(v = v_\theta(m_t, t)\).
   b. Form candidate \(\hat{m} = m_t + (1-t) v\).
   c. Evaluate loss \(L = \frac{1}{2}\|F(\hat{m}) - d_{\text{obs}}\|^2\).
   d. Update \(\theta \leftarrow \theta - \eta \nabla_\theta L\).
4. After inner loop, update \(\hat{m}_1 = m_t + (1-t) v_\theta(m_t, t)\) (no gradient).
5. Repeat with next \(s\).

This is fully sequential; \(\hat{m}_1\) from step \(s\) becomes input for step \(s+1\).

### Design tradeoffs
- **Outer/inner allocation**: With a fixed total number of physics evaluations (e.g., 3000), increasing \(T\) (outer steps) yields a finer progression of \(t\) and more stable coarse-to-fine evolution but fewer inner updates to train the flow network at each \(t\). Decreasing \(T\) (larger \(K\)) provides more training per \(t\) but risks overfitting and premature injection of high-wavenumber details.
- **Network capacity**: Larger U-Nets (more channels, residual blocks) capture complex updates but may overfit during short inner loops, especially under sparse shots. The authors reduce the number of residual blocks for sparse-shot scenarios.
- **Warm-start**: An optional phase minimizing \(\|v_\theta(m_0,0) - m_0\|^2\) for ~100 iterations stabilizes early updates at negligible extra cost.

### Failure signatures
- **Diverging data misfit**: During inner iterations, the loss \(\frac{1}{2}\|F(\hat{m}) - d_{\text{obs}}\|^2\) increases rather than decreases, indicating the flow update moves the model away from data-consistent states.
- **Rank explosion**: The singular value rank of \(\hat{m}_1\) grows too rapidly, suggesting premature high-wavenumber artifacts (see Section 4.1).
- **Oversmoothing**: The final model exhibits unnaturally low rank or SSIM, implying the flow updates are too conservative, possibly due to insufficient inner steps or overly strong bias from \(m_0\).
- **Stagnation**: Data misfit or model error plateaus at a high value, suggesting the flow network fails to learn meaningful updates; may require increasing \(K\) or adjusting network size.

### First three experiments
1. **Warm-start sanity check**: Run the first outer step with \(K=0\) (no inner updates). Verify that applying \(v_\theta(m_0,0)\) does not drastically alter \(m_0\) (i.e., \(\hat{m}_1\) remains close to \(m_0\)).
2. **\(T/K\) sensitivity sweep**: Fix total physics steps = 3000. Test pairs \((T,K)\): (10,300), (30,100), (100,30). Plot convergence curves (data loss, relative error, SSIM). Expect best performance for moderate \(T\) (around 20–200) as shown in the paper.
3. **Baseline replication under clean data**: On the Marmousi sub-region, implement conventional FWI, TV-regularized FWI, and DIP-FWI with identical total evaluations (3000) and learning rates. Reproduce Table 1 metrics; confirm SFM-FWI outperforms them.

## Open Questions the Paper Calls Out
### Extension to 3D elastic/anisotropic physics
**Basis in paper:** Section 4.8 explicitly states that extending SFM-FWI to elastic/anisotropic physics and 3D acquisition is an important next step, as current experiments are limited to 2D acoustic constant-density.  
**Why unresolved:** Real-world seismic imaging often requires elastic or anisotropic wave equations to capture shear waves and directional velocity variations. The flow network architecture and self-supervision scheme may need adaptation to higher-dimensional, more complex physics.  
**What evidence would resolve it:** Implementation and validation on 3D elastic/anisotropic synthetic benchmarks (e.g., 3D versions of Marmousi or SEG/EAGE models) with realistic acquisition geometries, comparing reconstruction quality, convergence stability, and computational cost against 3D baseline FWI methods.

### Robustness to full-field data challenges
**Basis in paper:** Section 4.8 notes that tests on full-field data are absent, and modeling errors from source signature uncertainty, attenuation, and anisotropy may further challenge inversion.  
**Why unresolved:** The current evaluations use synthetic data with perfect forward modeling and clean recordings. Field data introduces mismatches that could degrade the online flow learning, which relies on accurate gradient computations via adjoint-state or automatic differentiation.  
**What evidence would resolve it:** Application to real seismic datasets with known geological constraints (e.g., well logs), incorporating source estimation and Q-compensation in the forward solver, and rigorously assessing inversion results against independent validation data.

### General hyperparameter guidance across diverse settings
**Basis in paper:** Section 4.6 shows sensitivity to \(T\) and \(K\) on one benchmark (Marmousi sub-region) under a fixed budget, but notes "moderate changes" in \(T\) yield similar performance. This implies generalizability across other models and noise conditions is untested.  
**Why unresolved:** Optimal trade-offs between coarse-to-fine progression (\(T\)) and flow training stability (\(K\)) likely depend on model complexity, illumination, and noise level. No systematic study across benchmarks exists.  
**What evidence would resolve it:** Broad ablation studies varying \(T\) and \(K\) across all tested benchmarks (Marmousi, Overthrust, Salt) and robustness tests (poor init, noise, sparse shots), identifying patterns or deriving adaptive heuristics (e.g., based on initial model smoothness or data SNR).

### Integration with pretrained generative priors
**Basis in paper:** Section 4.5 proposes a hybrid approach but provides no experiments. Section 4.7 shows a pretrained diffusion prior underperforms on Overthrust due to distribution shift, while SFM-FWI adapts online—suggesting complementary strengths.  
**Why unresolved:** It is unclear how pretrained weights (e.g., from OpenFWI) would interact with the online flow updates: would they accelerate convergence, provide better initialization, or introduce biases that hinder physics-driven adaptation?  
**What evidence would resolve it:** Comparative experiments where SFM-FWI initializes or regularizes with pretrained flow/diffusion models, tested on distribution-shifted targets (e.g., training on layered models, inverting salt), measuring metrics like convergence speed, final error, and qualitative prior utilization (e.g., spectral content, structural fidelity).

## Limitations
- **Warm-start procedure underspecified**: The number of warm-start iterations is not given; the objective \(\|v_\theta(m_0,0) - m_0\|^2\) may be erroneous and could cause instability if misinterpreted.
- **Architecture details ambiguous**: The exact mechanism for injecting the time conditioning (likely AdaGN) and the potential use of attention layers are not confirmed; parameter counts suggest no attention but not explicit.
- **Physical bound enforcement not mentioned**: The paper does not state whether velocity values are clipped to physical ranges during updates, risking unphysical models (e.g., negative velocities).
