# Structure-Aware Robust Counterfactual Explanations via Conditional Gaussian Network Classifiers

## Quick Facts
- arXiv ID: 2602.08021
- Source URL: https://arxiv.org/abs/2602.08021
- Reference count: 0
- Primary result: CGNC-based robust counterfactual generation achieves high (98–99%) uncertainty set coverage with global optimality via MILP, but runtime grows sharply with DAG density; QCQP is faster but lacks guarantees.

## Executive Summary
This paper introduces a framework for generating counterfactual explanations that are both robust to input perturbations and structurally coherent with feature dependencies. The core model, a Conditional Gaussian Network Classifier (CGNC), encodes continuous features and their conditional relationships in a directed acyclic graph (DAG), extending Bayesian network classifiers to continuous domains. Robustness is enforced through a semi-infinite optimization problem that requires the counterfactual to be classified as the target class under any perturbation within a Mahalanobis-ℓ∞ uncertainty set. A cutting-set iterative method approximates this problem by alternating between a master problem (over a finite scenario set) and an adversarial problem (finding the worst-case perturbation). The nonconvex quadratic constraints arising from the CGNC decision function are addressed via two solvers: (1) a mixed-integer linear program (MILP) obtained by piecewise McCormick relaxations, which provides global optimality, and (2) a direct quadratically constrained quadratic program (QCQP) solved with a nonconvex solver, which is faster but without guarantees. Experiments on three binary classification datasets show the MILP approach achieves very high empirical coverage of the uncertainty set (98–99%), confirming robustness, but its runtime increases dramatically with DAG density—e.g., on Pima, going from a sparser to denser BAN structure raises runtime from 0.24 s to 853 s. The QCQP is orders of magnitude faster (~0.05 s) but may produce locally optimal solutions, sometimes with nonzero robustness violation, and times out on higher-dimensional data like Ionosphere.

## Method Summary
The proposed counterfactual pipeline consists of training, optimization, and solution extraction. First, a CGNC is fitted to the training data, learning a DAG structure (naïve Bayes, TAN, or BAN) and class-conditional linear Gaussian parameters (mean as an affine function of parents, conditional variances). For a factual instance `x_fac` of class 0, the goal is to find a counterfactual `x` that minimizes the Mahalanobis-ℓ∞ distance (using the Cholesky factor of class‑0 covariance) while guaranteeing that for all perturbations `δ` with `∥δ∥_{p,Σ_0^{-1/2}} ≤ γ`, the posterior probability `P(Y=1|X=x+δ)` exceeds a threshold `τ'`. This robust requirement leads to a semi‑infinite program. A cutting‑set procedure solves it iteratively: start with `S = {0}`; solve a Master Problem (MP) to minimize distance subject to `H(x+δ) ≥ τ'` for all `δ ∈ S`; then solve an Adversarial Problem (AP) to maximize the violation `τ' - H(x+δ)` over `U_γ`; add the worst‑case perturbation to `S` and repeat until the violation `φ ≤ ε`. Both MP and AP are nonconvex QCQPs because the CGNC decision function `H(x)` contains quadratic terms from the Gaussian log‑likelihood. Two solving approaches are compared: (i) reformulating the QCQPs into a MILP by applying piecewise McCormick relaxations to every bilinear term (using uniform partitioning and iterative bound tightening to tighten the relaxation), thereby enabling global optimality certificates; (ii) solving the original QCQP directly with Gurobi’s nonconvex solver, which is faster but may not find the global optimum and can time out on large or dense instances. The method is evaluated on three continuous binary‑classification datasets, varying the CGNC structure density and robustness budget `γ`.

## Key Results
- The MILP‑based method achieves empirical coverage of 98–99% of the uncertainty set radius, indicating strong robustness.
- MILP runtime explodes as the learned DAG becomes denser; e.g., on the Pima dataset, denser BAN structures increase runtime from 0.24 s to 853 s. On high‑dimensional Ionosphere, MILP frequently times out (>3600 s).
- The QCQP alternative is two orders of magnitude faster (≈0.05 s on average) but provides no global optimality guarantee and may also time out on high‑dimensional data; moreover, it sometimes terminates with a nonzero violation `φ > ε`, implying only partial robustness.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Embedding feature dependencies via CGNC's DAG-structured generative model produces structurally coherent counterfactuals that respect the data‑generating process.
- **Mechanism:** The CGNC encodes conditional Gaussian dependencies among features through a directed acyclic graph (DAG), where each feature's conditional distribution depends on its parents. This structure directly integrates into the counterfactual optimization objective and constraints, eliminating the need for post‑hoc constraints to enforce plausibility.
- **Core assumption:** The learned DAG structure accurately captures true conditional dependencies among features, and counterfactuals generated under this model remain within the support of the class‑conditional distribution.
- **Evidence anchors:**
  - [abstract]: "CGNC has a generative structure that encodes conditional dependencies and potential causal relations among features through a directed acyclic graph (DAG). This structure naturally embeds feature relationships into the search process, eliminating the need for additional constraints to ensure consistency with the model’s structural assumptions."
  - [section 1.3–1.4]: Details how CGNC extends BNCs to continuous features via linear Gaussian conditionals, and how the DAG structure enables factorization of joint distributions.
  - [corpus]: Weak—neighbors focus on graph neural networks and diffusion models; no direct evidence on CGNC-specific mechanisms.
- **Break condition:** If the learned DAG is incorrect (e.g., due to limited data or structure learning errors), counterfactuals may violate true feature dependencies, reducing plausibility.

### Mechanism 2
- **Claim:** The cutting‑set adversarial framework guarantees convergence to solutions robust against perturbations within a defined uncertainty set.
- **Mechanism:** The semi‑infinite robust optimization problem is approximated by iteratively solving a master problem (MP) over a finite scenario set S and an adversarial problem (AP) that finds worst‑case violating perturbations. Each iteration adds the most violating perturbation to S, progressively tightening the constraint approximation.
- **Core assumption:** The decision function H(x) is Lipschitz continuous over a compact domain X, ensuring finite termination of the cutting‑set procedure.
- **Evidence anchors:**
  - [abstract]: "We adopt a convergence‑guaranteed cutting‑set procedure as an adversarial optimization framework, which iteratively approximates solutions that satisfy global robustness conditions."
  - [section 3.1]: Theorem 1 formally proves finite termination under Lipschitz continuity and compactness, with explicit Lipschitz constant derivation for CGNCs.
  - [corpus]: Weak—no direct citations on cutting‑set robustness for counterfactuals; related work in robust optimization [3] is cited but not evaluated.
- **Break condition:** Non‑Lipschitz behavior (e.g., discontinuities from poorly estimated variances) or unbounded search space X could violate convergence guarantees; also, early stops with `φ ∈ (0, ε]` indicate incomplete robustness coverage.

### Mechanism 3
- **Claim:** Piecewise McCormick relaxation reformulates the nonconvex QCQP into a MILP, enabling global optimality via branch‑and‑bound.
- **Mechanism:** Bilinear terms `x_j x_k` (and `δ_j δ_k`) are relaxed using piecewise McCormick envelopes within variable subintervals, converting quadratic constraints to linear ones. Binary variables activate appropriate linear bounds per segment, yielding a MILP solvable to global optimality with a gap tolerance.
- **Core assumption:** Variable bounds are sufficiently tight and partitions sufficiently fine to approximate the original nonconvex feasible region accurately; bound tightening across iterations progressively refines this approximation.
- **Evidence anchors:**
  - [abstract]: "To address the nonconvex quadratic structure induced by feature dependencies, we apply piecewise McCormick relaxation to reformulate the problem as a mixed‑integer linear program (MILP), ensuring global optimality."
  - [section 3.2]: Equations (33)–(34) show the full MILP formulation with binary variables `λ^r_j`, partition bounds, and McCormick inequalities; Section 3.2 also describes bound tightening with contraction factor `ν`.
  - [corpus]: Weak—McCormick relaxations are standard in process optimization [34] but not previously applied to CGNC‑based counterfactuals.
- **Break condition:** Loose initial bounds or too few partitions (`m`) yield overly relaxed feasible regions, admitting infeasible points; excessive partitions cause combinatorial explosion, leading to timeouts or memory exhaustion.

- **Why needed here:** The robustness requirement turns the counterfactual search into a semi‑infinite program. The cutting‑set procedure is the core algorithm that makes this tractable by iteratively refining a finite scenario set S. Without this, enforcing robustness over a continuum of perturbations would be intractable.

### Mixed‑Integer Programming and McCormick Relaxations
- **Why needed here:** The nonconvex QCQP arising from CGNC's quadratic decision function cannot be solved to global optimality directly. McCormick relaxations provide a way to encode bilinear terms with linear constraints and binary variables, enabling MILP solvers to provide optimality certificates.

## Architecture Onboarding
### Component map
1. **CGNC Trainer**: Learns DAG structure (NB/TAN/BAN) and fits class‑conditional linear Gaussian parameters (w^c_ij, b^c_i, σ²_i|c). Input: dataset; Output: CGNC model.
2. **Whitening Module**: Computes class‑0 covariance Σ₀ and its Cholesky factor for Mahalanobis‑ℓ_p distance; used only in metric, not in model transformation.
3. **Optimization Engine**: Implements cutting‑set loop:
   - Master Problem (MP): MILP/QCQP minimizing d(x_fac, x) subject to H(x+δ) ≥ τ' ∀ δ ∈ S.
   - Adversarial Problem (AP): Maximizes violation τ' − H(ˆx+δ) over U_γ; for ℓ_∞, reduces to QCQP.
4. **Relaxation Handler**: Generates piecewise McCormick constraints for all bilinear terms (x_j x_k in MP; δ_j δ_k in AP), manages binary variables λ^r_j, and performs bound tightening per iteration.
5. **Main Controller**: Orchestrates initialization (S = {0}), MP→AP iteration, termination check (φ ≤ ε), and final solution return.

### Critical path
CGNC training → whitening → first MP (S={0}) → AP → if φ>ε: add ˆδ to S → repeat MP/AP → terminate when φ≤ε. The MP's MILP formulation size depends on (n, |Q|, m) where Q is the set of bilinear index pairs (Equation 32) and m is partitions per variable. For high n or dense DAGs, |Q| grows quickly, making MILP expensive; QCQP alternative avoids binaries but lacks global guarantees.

### Design tradeoffs
- **MILP vs QCQP**: MILP ensures global optimality but scales poorly with graph density (e.g., BAN on Pima: 853s vs 0.05s for QCQP). QCQP is stable in runtime but may converge to local optima and times out on high‑dimensional data (Ionosphere).
- **Partition count m**: Larger m yields tighter relaxation (better feasibility) but increases MILP size combinatorially. The bound tightening (ν) reduces search bounds over iterations, but too aggressive contraction (ν << 1) may exclude feasible regions.
- **Norm choice**: ℓ_∞ yields linear uncertainty set U_γ (box), simplifying AP to QCQP; ℓ_2 would require second‑order cone constraints.

### Failure signatures
- **MILP timeouts**: Occur on dense BAN structures or high‑dimensional data (Ionosphere) due to explosive binary variable count. Symptom: Gurobi hits 3600s limit without closing gap.
- **Early stops with φ ∈ (0, ε]**: Indicates solution is only γ_eff = γ − √(φ/Lipschitz) robust; paper reports 98–99% coverage but not 100%. Check AP objective value after termination.
- **QCQP instability**: On some runs, QCQP may return locally optimal solutions with higher distance or violate robustness; monitor iteration count—excessive iterations (>10) may indicate slow convergence.
- **Infeasible MP**: Rare, but if initial factural x_fac is already on decision boundary, no feasible counterfactual exists; or tight bounds from whitening may cut off feasible region.

### First 3 experiments
1. **Scalability test**: For each dataset, train NB, TAN, BAN CGNCs; run MILP‑based robust counterfactual search with γ=0.05; record runtime and iteration count vs. number of edges in DAG. Expect runtime exponential in edge count (see Table 1: Pima BAN 12 edges → 297s; 18 edges → 853s).
2. **Robustness coverage validation**: For solutions from (1), compute empirical robustness: sample 1000 perturbations δ ∼ Uniform over U_γ and check if H(ˆx+δ) ≥ τ'. Report failure rate; expect ≤ 2% given 98–99% coverage claim.
3. **MILP vs QCQP comparison**: On same factual instances, solve both formulations; compute (a) objective d(x_fac, x), (b) runtime, (c) AP violation φ at termination. Expect similar distances (Figure 5) but QCQP faster; MILP should have φ ≤ ε (global optimal), QCQP may have φ > 0.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** Can difference‑of‑convex (DC) programming or hybrid continuous‑discrete optimization methods provide a scalable alternative to MILP for CGNC‑based counterfactual search while preserving global optimality or strong approximation guarantees?
- **Basis in paper:** [explicit] The authors state that the decision function naturally forms a DC structure and suggest future work explore DC optimization or hybrid methods to address theoretical limitations arising from nonconvexity.
- **Why unresolved:** The paper relies on MILP (via piecewise McCormick) for global optimality but suffers from combinatorial blowup with dense dependencies, while the QCQP alternative lacks global guarantees. DC methods could offer a middle ground but are not implemented or analyzed.
- **What evidence would resolve it:** Implement a DC algorithm (e.g., DC programming with convex‑concave procedure) for the CGNC counterfactual problem, compare it to MILP/QCQP on runtime, solution quality, and optimality gaps across varying graph densities and dimensions.

### Open Question 2
- **Question:** How can the CGNC framework be adapted to handle mixed discrete and continuous features, and what conditional distributions (e.g., discrete parents with continuous children) would maintain tractable inference and optimization?
- **Basis in paper:** [explicit] The authors note the framework currently assumes all features are continuous and propose extending to mixed discrete–continuous datasets as a future direction to broaden applicability.
- **Why unresolved:** CGNCs are defined for continuous features conditioned on a discrete class, but real‑world datasets often include discrete attributes. Extending the model requires redefining conditional distributions (e.g., using logistic regression for discrete parents) and may break the linear‑Gaussian assumptions that enable tractable likelihood computation.
- **What evidence would resolve it:** Develop a hybrid CGNC variant that supports discrete parent nodes (e.g., by integrating conditional exponential families), derive the corresponding log‑likelihood expansions, and evaluate counterfactual generation on mixed‑type benchmarks.

### Open Question 3
- **Question:** What user‑centered evaluation metrics and study designs can effectively measure the perceived plausibility, actionability, and trust in CGNC‑generated counterfactuals compared to black‑box or independence‑assuming methods?
- **Basis in paper:** [explicit] The authors call for assessing interpretability and plausibility from a user perspective and incorporating human‑in‑the‑loop evaluations to gauge practical utility.
- **Why unresolved:** The paper evaluates robustness and structural coherence quantitatively (e.g., distance, coverage) but does not involve end‑users or domain experts. Plausibility is inferred from feature dependencies, but human judgment may differ due to context, causality, or social factors.
- **What evidence would resolve it:** Conduct controlled user studies with relevant stakeholders (e.g., loan officers, clinicians) comparing CGNC counterfactuals against baselines on criteria like realism, understandability, and willingness to act, possibly using Likert scales or qualitative interviews.

### Open Question 4
- **Question:** How can causal identification methods (e.g., do‑calculus, instrumental variables) be integrated into CGNC‑based counterfactual search to ensure that suggested changes correspond to feasible interventions within the causal graph?
- **Basis in paper:** [explicit] The authors state that causal validity of counterfactuals needs empirical verification and that integrating causal identification methods is necessary, though the current work focuses on structural dependencies (DAGs) rather than intervention‑based causality.
- **Why unresolved:** CGNCs encode conditional dependencies via a DAG but do not inherently support causal interventions (e.g., do(x)=x). Counterfactuals generated under the model may violate causal constraints if the DAG is misinterpreted as a causal structure without proper identification of actionable variables.
- **What evidence would resolve it:** Incorporate causal constraints (e.g., forbidding changes to descendants of the class or requiring interventions on root causes) into the optimization, test on synthetic datasets with known causal ground truth, and measure whether counterfactuals align with valid interventions.

### Open Question 5
- **Question:** How can the CGNC‑based counterfactual search be modified to avoid generating out‑of‑distribution counterfactuals that fall into low‑density regions when class‑conditional distributions are well‑separated, while still satisfying feature dependencies and robustness requirements?
- **Basis in paper:** [explicit] The authors identify a trade‑off: when class‑conditional distributions are well separated, counterfactuals may lie in low‑density regions, making them infeasible despite meeting classification constraints. They call this a central unresolved challenge.
- **Why unresolved:** The current method optimizes distance and robustness under CGNC likelihood but does not explicitly account for data density or distributional plausibility. Solutions may be statistically valid generationally but unrealistic in practice.
- **What evidence would resolve it:** Introduce density regularization (e.g., penalizing deviation from high‑density regions estimated via kernel density or a generative model) or incorporate constraints based on the training data support, then evaluate plausibility using metrics like nearest‑neighbor density or domain expert assessment.

## Limitations
- Missing implementation specifics for TAN/BAN structure learning (e.g., discretization bins, NOTEARS settings) and optimization hyperparameters (`m_init=20`, `ν=0.5`) block exact replication.
- MILP runtime degrades sharply with graph density, e.g., on Pima BAN reaching 853 s, limiting scalability to high‑dimensional or densely connected feature sets.
- Reported 98–99% uncertainty set coverage stems from an early‑stop criterion (`φ ≤ ε=0.001`), which does not certify full robustness; small residual violations may persist.

- **Cutting‑set adversarial robustness**: High
