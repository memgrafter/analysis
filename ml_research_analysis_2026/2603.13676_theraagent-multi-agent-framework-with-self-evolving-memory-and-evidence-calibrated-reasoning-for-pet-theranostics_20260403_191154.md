# TheraAgent: Multi-Agent Framework with Self-Evolving Memory and Evidence-Calibrated Reasoning for PET Theranostics

## Quick Facts
- **arXiv ID:** 2603.13676  
- **Source URL:** https://arxiv.org/abs/2603.13676  
- **Reference Count:** 20  
- **Primary Result:** Achieves 75.7% accuracy on real patient data (35 cases) and 87.0% on synthetic data (400 cases), outperforming state-of-the-art medical agents by 13–20%, with strong performance on clinically misleading cases.

## Executive Summary
TheraAgent is a multi-agent system designed to predict treatment response for 177Lu-PSMA radioligand therapy in metastatic prostate cancer. It addresses data scarcity, heterogeneous clinical inputs, and the need for evidence-grounded reasoning. The framework combines three specialized LLM experts for extracting features from PET/CT reports, lab tests, and clinical notes; a self-evolving memory module (SEA-Mem) that learns prognostic patterns from accumulated cases; and a reasoning module that calibrates predictions against curated trial evidence from VISION/TheraP. Evaluated on 35 real patients and 400 synthetic cases, TheraAgent demonstrates superior accuracy and robustness compared to existing medical agents.

## Method Summary
TheraAgent processes heterogeneous pre-treatment documents through a pipeline: a parsing stage routes inputs to three modality-specific expert agents (Radiologist, Biochemist, Oncologist) that extract structured features with confidence scores. An Integrator agent fuses these outputs into a unified patient profile. In parallel, a self-evolving memory (SEA-Mem) retrieves similar historical cases and learned prognostic patterns, while a retrieval-augmented generation (RAG) module fetches relevant passages from a curated knowledge base of 23 trial publications. The Reasoning Module synthesizes the patient profile, case-based evidence, and trial evidence, explicitly citing sources to produce a prediction (PSA response and overall survival >12 months). The memory updates asynchronously when new outcomes become available, enabling continuous improvement.

## Key Results
- Overall accuracy: 75.7% on real data, 87.0% on synthetic data.
- Outperforms MDAgents and MedAgent-Pro by 13–20% absolute accuracy.
- Ablation studies confirm each component contributes; the multi-expert design yields the largest gain.
- Particularly strong on clinically misleading cases where surface features are deceptive.

## Why This Works (Mechanism)

### Mechanism 1: Specialized Parallel Experts
**Claim:** Domain-tailored experts extract structured features from heterogeneous medical inputs more reliably than a single generalist LLM.  
**Mechanism:** Three LLM-based experts (Radiologist, Biochemist, Oncologist) process distinct data types (PET reports, lab values, clinical notes) using modality-specific prompts and output JSON with confidence. An Integrator synthesizes these with confidence-weighted consensus.  
**Break condition:** If input formats deviate from expected templates (e.g., novel lab nomenclature), expert confidence drops, leading to integration failures.

### Mechanism 2: Self-Evolving Memory (SEA-Mem)
**Claim:** SEA-Mem mitigates data scarcity by learning and reusing prognostic patterns from accumulated institutional cases, enabling case-based reasoning.  
**Mechanism:** Memory stores (feature profile, outcome) pairs. For subgroups with ≥3 cases sharing key features (e.g., "high PSMA + no liver mets"), it computes empirical outcome rates. New queries retrieve top-k similar cases and matching patterns; memory updates when outcomes become available.  
**Break condition:** If the feature space is too sparse (<3 similar cases), pattern learning fails and retrieval defaults to noisy nearest-neighbor matches without statistical significance.

### Mechanism 3: Evidence-Calibrated Reasoning
**Claim:** Reasoning explicitly calibrated against curated trial evidence (VISION/TheraP) prevents hallucinations and anchors predictions in established clinical knowledge.  
**Mechanism:** A domain-specific knowledge base (23 publications) is queried using patient features. The Reasoning module synthesizes three sources—patient profile, SEA-Mem case evidence, and retrieved trial passages—requiring explicit citation of each.  
**Break condition:** If retrieved trial passages are irrelevant or conflict with SEA-Mem patterns, the module lacks a principled resolution mechanism, risking synthesis errors.

## Foundational Learning

**LLM-based Agentic Workflows**  
*Why needed:* TheraAgent orchestrates specialized agents rather than a single monolithic prompt, requiring understanding of decomposition, inter-agent communication, and state passing.  
*Quick check:* What are the risks of using a single LLM prompt for multi-modal extraction versus a multi-agent decomposition, and how does confidence weighting mitigate integration errors?

**Memory-Augmented Systems & Case-Based Reasoning**  
*Why needed:* SEA-Mem is the core innovation for data scarcity, relying on memory structures, similarity metrics, and pattern induction from sparse data.  
*Quick check:* How does SEA-Mem’s pattern learning (requiring ≥3 cases) differ from simple k-NN retrieval, and what are the statistical risks of its empirical rate estimation?

**Retrieval-Augmented Generation (RAG) with Domain KBs**  
*Why needed:* Evidence calibration depends on semantic retrieval from a curated, small-scale knowledge base, demanding grasp of chunking, embedding, and medical literature retrieval challenges.  
*Quick check:* In a medical RAG system, what makes a “good” query formulation from a patient profile, and how might query design impact the relevance of retrieved VISION/TheraP evidence?

## Architecture Onboarding

**Component map:**  
Input Parser → Expert Agents (Radiologist, Biochemist, Oncologist) → Integrator → {SEA-Mem Retriever, KB Retriever} → Reasoning Module → Output.  
Memory Updater (asynchronous) adds new (profile, outcome) to SEA-Mem.

**Critical path:** Raw input → expert extraction → integration → parallel retrieval (case memory & trial knowledge) → reasoning → prediction.

**Design tradeoffs:**  
- SEA-Mem update latency vs. pattern stability: threshold of ≥3 cases balances volatility and staleness.  
- KB curation cost vs. evidence reliability: 23-source KB required physician guidance; larger automated KB risks lower quality.  
- Expert specialization vs. integration overhead: three experts improve extraction but increase latency and prompt engineering effort.

**Failure signatures:**  
- Low expert confidence (<0.5) → vague unified profile.  
- SEA-Mem returns few similar cases → prediction relies heavily on trial evidence alone.  
- KB retrieval returns low-similarity passages → reasoning may cite irrelevant evidence.  
- Reasoning output lacks explicit citations → evidence calibration failed.

**First 3 experiments:**  
1. Test Multi-Expert Extraction: Run 35 real patient inputs through each expert separately. Measure per-expert JSON validity rate and confidence distribution.  
2. Validate SEA-Mem Pattern Learning: Simulate memory with increasing synthetic case batches (e.g., 50, 100, 200). Track number of stable patterns (≥3 cases) and their outcome rate variance.  
3. Probe Evidence Calibration: Feed a known “misleading case” (e.g., high tumor burden but favorable PSMA/liver profile). Audit retrieval: Are trial passages on PSMA/liver factors retrieved and weighted appropriately?

## Open Questions the Paper Calls Out
- **Generalization across centers:** How does performance hold with data from multiple medical centers? Current evaluation is single-institution; multi-center studies are needed.  
- **Reinforcement learning from feedback:** Can RL from clinical feedback improve accuracy over the simple memory accumulation?  
- **Prospective validation:** Does TheraAgent maintain accuracy and reliability when deployed in a real clinical workflow before treatment?

## Limitations
- **Reproducibility gaps:** Exact prompts, confidence thresholds, and feature weighting schemes are undisclosed.  
- **KB composition unknown:** The 23 curated publications and their retrieval parameters (embedding model, chunk size, query generation) are not specified.  
- **Small real dataset:** Evaluation on only 35 real patients raises concerns about statistical power and overfitting to synthetic data.

1. **Extraction Audit:** Manually annotate 10 real patient documents. Compare expert JSON outputs against ground truth; measure per-expert accuracy and confidence calibration.
