# Provably Explaining Neural Additive Models

## Quick Facts
- **arXiv ID:** 2602.17530
- **Source URL:** https://arxiv.org/abs/2602.17530
- **Reference Count:** 40
- **Primary Result:** A model-specific algorithm for Neural Additive Models (NAMs) computes provably minimal sufficient explanations with logarithmic query complexity, yielding significantly smaller and faster explanations with 100% sufficiency guarantees compared to prior methods.

## Executive Summary
Providing interpretable explanations for neural networks with formal guarantees is notoriously difficult, often requiring a number of verification queries that scale exponentially with the number of input features. This paper tackles this challenge for Neural Additive Models (NAMs), a class of models that sum univariate functions, one per feature. The authors introduce a specialized algorithm that first uses parallel verification to bound the contribution of each feature's component function and then performs a binary search over features to identify a minimal subset sufficient for the model's prediction. This approach reduces the number of required verification queries from exponential or linear to logarithmic in the number of features. Evaluated on four tabular datasets, the method produces explanations that are substantially smaller than those from prior subset-minimal techniques (e.g., average size 4 vs. 16 on Breast Cancer) while often being faster and providing absolute (100%) sufficiency guarantees, in stark contrast to sampling-based approaches that could only verify sufficiency for 31% of cases. The work demonstrates that tailored algorithms for structured model families can achieve scalable, certifiable interpretability.

## Method Summary
The algorithm addresses the problem of finding a smallest set of features whose associated univariate component functions in a ReLU-based NAM can be combined to replicate the model's output on a given input, a "cardinally-minimal sufficient explanation." The method operates in two distinct phases. The first phase, a parallel verification step, determines a precision bound for each univariate component function. It computes, for each feature, the maximum possible change in that feature's component output over the input's valid perturbation region, using a verifier like ERAN. This yields a value representing that feature's maximum possible influence on the final sum. The second phase exploits the additive structure: since the NAM output is a sum of these components, features can be sorted by their computed influence bounds in descending order. The algorithm then performs a binary search over this sorted list to find the smallest prefix of features whose summed maximum influences meet or exceed the difference between the model's output at the input and its output at the baseline (e.g., all-zeros). This prefix constitutes the provably minimal sufficient explanation. The binary search is the key efficiency gain, requiring only O(log n) verification queries to confirm sufficiency for a candidate subset size, in contrast to checking all subsets.

## Key Results
- Explanations are significantly smaller: e.g., average size of 4 for Breast Cancer dataset vs. 16 for prior subset-minimal method.
- Method often runs faster than baseline approaches while providing 100% provable sufficiency guarantees.
- Sampling-based baselines failed to provide any guarantee for 69% of instances (only 31% verified sufficiency), highlighting the value of formal verification.

## Why This Works (Mechanism)
The algorithm's efficiency and correctness stem from two critical insights specific to the NAM architecture's additive, feature-wise decomposition. First, the additive structure means the overall output's maximum possible variation due to a feature is solely determined by the maximum variation of that feature's *own* univariate subnetwork, independent of others. This decouples the verification problem into n independent, smaller verification tasks (one per feature's function) instead of one large, intractable task over all features. Second, this decoupling produces scalar "influence bounds" that are monotonically related to feature importance for constructing a minimal sufficient set. A feature's bound represents an upper limit on how much it can contribute to changing the output; thus, a minimal sufficient set must include the features with the largest bounds until their combined upper limit covers the required output shift. This property justifies a greedy-like sorting and enables the use of binary search over the sorted list to find the minimal prefix, avoiding the exponential combinatorial search. The provable guarantee comes from the completeness of the verifier used in the first phase: if it certifies a bound, that bound is mathematically sound.

## Foundational Learning
*   **Neural Additive Model (NAM):** A neural network architecture where the final output is a sum of separate, single-input feedforward networks (one per feature). **Why needed:** This structure is the core property the algorithm exploits; it enables independent verification per feature and a meaningful sorting by influence. **Quick check:** If the model were a standard MLP with interactions, could we still bound each feature's contribution independently? (No.)
*   **Provable Verification / Formal Verification:** Using methods like SMT or branch-and-bound (e.g., ERAN) to compute sound bounds on a neural network's output over an input region. **Why needed:** Provides the mathematically rigorous "maximum influence" values for each feature's component function. **Quick check:** What does it mean for a verification result to be "sound"? (It over-approximates all possible outputs; no false negatives.)
*   **Additive Decomposition & Sufficiency:** The explanation problem is framed as finding a smallest subset S of features such that the sum of *only their* component functions equals the full model's output for the specific input. **Why needed:** Defines the formal goal (cardinally-minimal sufficient explanation) that the algorithm solves optimally. **Quick check:** Is a subset sufficient if its component functions' values at the input sum to the model's output? (Yes, by definition of NAM.)
*   **Binary Search over Features:** Searching for the minimal *k* such that the top-k features (by influence bound) are sufficient. **Why needed:** Drastically reduces the number of expensive sufficiency checks from O(2^n) or O(n) to O(log n). **Quick check:** Why does binary search work here? (Because if the top-k features are sufficient, then top-(k+1) are trivially sufficient; a monotonic predicate.)
*   **Parallel Verification:** Running the independent verification queries for each feature's component function concurrently. **Why needed:** The first phase has n independent tasks, making it embarrassingly parallel and reducing wall-clock time. **Quick check:** Are these n verification tasks truly independent? (Yes, because each involves only one feature's function and the input interval for that feature.)

## Architecture Onboarding
*   **Component Map:** Input x -> For each feature i: Bound_i = Verify( f_i, x_i ± ε ) -> Sort features by Bound_i descending -> Binary Search over sorted list to find minimal prefix k s.t. sum(Bound_1...k) ≥ |f(x) - f(baseline)| -> Explanation = features in prefix.
*   **Critical Path:** 1. Independent verification for each univariate subnetwork to compute its maximum possible contribution (Bound_i). 2. Global sort of features by these bounds. 3. Sufficiency checks (using a verifier) for candidate prefixes determined by binary search.
*   **Design Tradeoffs:** The algorithm trades general applicability (it only works for additive models) for massive query complexity reduction. It trades the cost of *n* smaller verifications in phase one for avoiding combinatorial explosion in phase two. The guarantee quality depends entirely on the underlying verifier's completeness and soundness.
*   **Failure Signatures:** 1. Phase 1 timeout/Inconclusive: Verifier cannot compute a bound for some feature's function within resource limits. 2. Numerical tolerance issues: The soundness of the computed bounds is compromised by floating-point approximations in the verifier. 3. Non-monotonic activation break: For non-ReLU activations, the sorting by maximum influence may not correctly predict the minimal sufficient set, breaking the binary search logic.
*   **First 3 Experiments:** 1. **Scalability Test:** Apply the algorithm to a synthetic NAM with 50-100 features to measure wall-clock time and query count against the predicted O(n log n) scaling. 2. **Actation Sensitivity Test:** Replace ReLU with tanh in a NAM and evaluate the size and validity of explanations produced by the same algorithm (which assumes ReLU properties). 3. **Verifier Dependency Test:** Compare explanations and performance using two different complete verifiers (e.g., ERAN vs. a MILP-based solver) to quantify sensitivity to verifier implementation and tolerance settings.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** How can we systematically design neural network architectures that guarantee both high accuracy and efficient, provably minimal explanations?
- **Basis in paper:** [explicit] The introduction explicitly states: "A central challenge ahead is to design models that balance high expressivity and accuracy with efficient provable explanations."
- **Why unresolved:** NAMs provide one example, but a general framework for creating such models from first principles remains open.
- **What evidence would resolve it:** A theoretical characterization or design principles linking architecture choices to explanation complexity, validated on multiple model families.

### Open Question 2
- **Question:** How can neural network verifiers be made more robust and scalable to eliminate numeric tolerances and reduce timeouts in practice?
- **Basis in paper:** [explicit] Section 7 notes: "Our approach relies on a complete verifier, which often come with numeric tolerances and timeout restrictions."
- **Why unresolved:** These verifier limitations bound the scalability of any provable explanation method, including ours.
- **What evidence would resolve it:** Verifiers with sound floating-point handling and formal complexity guarantees for larger architectures.

### Open Question 3
- **Question:** Can the logarithmic-complexity algorithm for NAMs be adapted to other interpretable structured models, such as monotonic neural networks or graph neural additive models?
- **Basis in paper:** [inferred] The conclusion suggests the work "opens the door to extending them across other interpretable neural network families."
- **Why unresolved:** The proof crucially relies on NAMs' additive decomposition; other structures lack this property.
- **What evidence would resolve it:** New algorithmic reductions or complexity analyses showing similar efficiency gains for other architectures.

### Open Question 4
- **Question:** How does the explanation algorithm generalize to non-ReLU activations (e.g., sigmoid, tanh) and more complex output tasks beyond binary classification?
- **Basis in paper:** [inferred] The paper uses ReLU NAMs and briefly mentions regression and multi-class extensions; non-ReLU cases are not explored.
- **Why unresolved:** The sorting procedure depends on ReLU monotonicity and linearity properties; other activations break these assumptions.
- **What evidence would resolve it:** Theoretical adaptation of the importance sorting and binary search steps, supported by empirical validation on diverse activation functions.

## Limitations
*   **Architecture-Specific:** The algorithm's efficiency and correctness are tightly bound to the additive, feature-wise decomposition of NAMs. It does not extend to standard multi-layer perceptrons (MLPs) with feature interactions.
*   **Verifier Dependence:** All provable guarantees rely on the underlying verifier being complete and sound; in practice, verifiers have numeric tolerances, may timeout, and can be computationally expensive for deep ReLU networks.
*   **Empirical Scope:** Experimental validation is limited to four relatively small, tabular datasets. Performance on high-dimensional data, non-tabular data (e.g., images), or with different baseline definitions is not established.

## Confidence
- **Algorithmic correctness and provable minimality for NAMs:** **High** (theoretical derivation based on sound verification and additive structure).
- **Query complexity reduction to logarithmic:** **High** (binary search argument is straightforward under the sorting assumption).
- **Empirical superiority (smaller explanations, faster, 100% sufficiency):** **Medium** (results are strong but based on a limited set of 4 datasets and comparisons with a small number of specific baselines; constant factors in query reduction not deeply analyzed).

## Next Checks
1.  **Scale Evaluation:** Test the algorithm on datasets with >100 features to measure practical scalability, constant factors in the O(n log n) query count, and wall-clock time dominated by verification.
2.  **Boundary Test for Generalizability:** Attempt to adapt the method to a simple non-additive architecture (e.g., a 2-layer MLP with a bottleneck) to identify precisely which architectural properties are necessary for the logarithmic complexity guarantee.
3.  **Verifier Robustness Sensitivity Analysis:** Quantify how small changes in verification tolerance parameters (e.g., ε for soundness) or different verifier backends affect the computed influence bounds and, consequently, the size and validity of the final explanations.
