# On the use of Aggregation Operators to improve Human Identification using Dental Records

## Quick Facts
* **arXiv ID:** 2603.23003
* **Source URL:** https://arxiv.org/abs/2603.23003
* **Reference count:** 40
* **Primary result:** White-box ML (Symbolic Regression avg rank 2.02, Linear Regression 2.21) significantly outperforms state-of-the-art (3.91) while maintaining interpretability.

## Executive Summary
Accurate and explainable aggregation of dental comparison criteria is critical for forensic human identification. The paper evaluates methods to combine seven Simplified Coding System (SCS) criteria into a similarity score for ranking antemortem records. Three families of approaches are tested on 215 forensic cases: (1) a data‑driven reordering of lexicographic criteria, (2) fuzzy aggregation operators (OWA, OWHM, Choquet, Sugeno), and (3) machine‑learning models (Linear Regression, Symbolic Regression, Multilayer Perceptron). Results show that white‑box machine‑learning techniques achieve substantially better rankings (Symbolic Regression average 2.02, Linear Regression 2.21) than the state‑of‑the‑art lexicographic method (3.91), while preserving interpretability. Some fuzzy operators (e.g., OWA‑Linear) also improve performance (2.86) but are less consistent. The best models reduce the 95th percentile ranking from 30 to as low as 4, greatly easing expert review without sacrificing transparency.

## Method Summary
The study uses the Simplified Coding System (SCS), which encodes pairwise comparisons of antemortem (AM) and postmortem (PM) odontograms into seven criteria: counts and percentages of matches, mismatches, possible matches, and an exact group discretization. The aggregation task is to combine these criteria into a single score that ranks AM records correctly for a given PM query.

Three aggregation strategies are evaluated:

1. **Lexicographic ordering (LO)**: criteria are applied sequentially to break ties. Instead of the fixed Adams & Aschheim order, the authors exhaustively test all 5040 permutations on validation data to find the data‑driven best order.
2. **Fuzzy aggregation operators**: Ordered Weighted Averaging (OWA) with various weight vectors (Maximum, Minimum, Average, Linear), OWA‑based harmonic mean (OWHM), Choquet integral, and Sugeno integral. Fuzzy measures are derived from solo‑criterion average rankings on the training set.
3. **Machine‑learning aggregators**: Linear Regression (optimized via genetic algorithm), Symbolic Regression (genetic programming to evolve a mathematical expression), and a Multilayer Perceptron (also GA‑trained). All minimize the average ranking position.

Experiments use 215 cases (Israel/Chile) with 5‑fold cross‑validation and a held‑out test set. Performance metrics include average rank, maximum rank, and percentiles (P95, P99) of the true match position, plus cumulative match curves (CMC).

## Key Results
- Symbolic Regression achieves the best average ranking (2.02), Linear Regression 2.21, while the state‑of‑the‑art lexicographic method scores 3.91. The Multilayer Perceptron slightly outperforms (1.94) but is less interpretable.
- Among fuzzy operators, OWA with linear weights improves to 2.86; other operators (OWHM, Choquet, Sugeno) underperform the baseline.
- The 95th percentile ranking drops from 30 (SOTA) to as low as 4 (Symbolic Regression), meaning that 95% of queries place the correct match within the top‑4 candidates.

## Why This Works (Mechanism)

### Mechanism 1: Data‑driven reordering of lexicographic criteria
- **Claim:** Exhaustively searching for the optimal criterion sequence improves ranking over the fixed state‑of‑the‑art order.
- **Mechanism:** For each permutation of the seven criteria, the system computes the average ranking on validation data and selects the sequence that minimizes it. The discovered order (e.g., % Mismatch → % Match → # Mismatch → ...) tailors the tie‑breaking hierarchy to the dataset.
- **Core assumption:** The relative importance of matches, mismatches, and possible matches is data‑dependent; a fixed universal ordering discards valuable information from lower‑priority criteria.
- **Evidence:** The abstract reports improvement from 3.91 to 2.14; Section 4.2 details the permutation search and optimal sequence.
- **Break condition:** Performance degrades if the learned order does not generalize to new populations or if the training set lacks diversity.

### Mechanism 2: Fuzzy aggregation operators (e.g., OWA‑Linear)
- **Claim:** Ordered Weighted Averaging and similar operators can aggregate all criteria simultaneously and more effectively than lexicographic ordering by weighting the most supporting evidence in each comparison.
- **Mechanism:** OWA sorts the seven criterion values in descending order and applies a weight vector (e.g., linearly increasing weights) to these ordered values before summation. This emphasizes the highest‑supported criteria within a given comparison, rather than following a rigid priority.
- **Core assumption:** The strongest signals (largest match counts, smallest mismatch counts) within a single comparison are more discriminative than any predefined hierarchy.
- **Evidence:** The abstract notes OWA‑Linear reaches average ranking 2.86; Section 4.3.1 shows improved tail coverage (P95) over the baseline.
- **Break condition:** Underperformance occurs if the weight vector is poorly chosen (e.g., maximum‑only weights yield worse results) or if the operator is too conservative (as seen with OWHM).

### Mechanism 3: White‑box machine learning models
- **Claim:** Linear Regression and Symbolic Regression, trained to directly predict a similarity score from all seven criteria, outperform hand‑crafted aggregation by learning data‑optimal combinations.
- **Mechanism:** Models are optimized via genetic algorithms to minimize average ranking. Linear Regression learns a weighted sum; Symbolic Regression evolves a concise mathematical expression (e.g., `(x1‑x6)/(x5*x6)`). The resulting score is used to rank comparisons.
- **Core assumption:** A functional mapping exists from the seven criteria to ground‑truth similarity that is more complex than simple lexicographic or fuzzy rules, and this mapping can be learned even from limited forensic data.
- **Evidence:** The abstract states Symbolic Regression avg rank 2.02 and Linear Regression 2.21, both significantly beating SOTA (3.91); Section 4.4 provides the learned equations and shows CMC improvements.
- **Break condition:** High risk of overfitting on the small, population‑specific dataset; performance may collapse if the symbolic expression becomes too complex (though the paper’s expressions remain simple).

## Foundational Learning

**Concept: Simplified Coding System (SCS)**
- **Why needed:** SCS provides the seven criteria that serve as input features for aggregation. Understanding what each criterion measures (matches, mismatches, possible matches, exact group) and its inherent uncertainty (e.g., the "possible" code) is essential to interpret model behavior.
- **Quick check:** How does the 'P' (possible) code introduce uncertainty, and why might this affect aggregation differently than a 'match' or 'mismatch'?

**Concept: Lexicographical Ordering**
- **Why needed:** This is the state‑of‑the‑art baseline (Adams & Aschheim). It illustrates a fundamental limitation: when criteria are applied sequentially, lower‑priority criteria are ignored once a tie‑break is decided, discarding potentially useful information.
- **Quick check:** Provide a concrete example of two AM‑PM comparisons where lexicographic ordering (using exact group then number of matches) would rank them incorrectly despite one having strictly fewer mismatches.

**Concept: Aggregation Operator**
- **Why needed:** The core task is to combine seven heterogeneous criteria into a single similarity score. Operators define *how* this combination occurs—whether by ordered weights (OWA), fuzzy measures (Choquet, Sugeno), or learned coefficients (LR, SR).
- **Quick check:** Why might a simple weighted average be insufficient for this problem, and how does an OWA operator attempt to address that?

## Architecture Onboarding

**Component map:**  
Input: Pairwise AM‑PM odontogram comparisons encoded via SCS → Output: Seven criteria per comparison → Aggregation Module (LO/OWA/ML model) → Score per comparison → Ranking module → Output: Ordered list of AM cases for a given PM case.

**Critical path:**
1. Preprocess raw dental records (X‑rays, notes) into SCS codes.
2. For a query PM record, compute all seven criteria against every AM record in the database.
3. Pass the vector of seven criteria for each comparison to the trained aggregation model.
4. Sort all comparisons by the model’s output score (descending).
5. Present the ranked list to a forensic expert for final verification.

**Design tradeoffs:**
- *Interpretability vs. Performance*: Symbolic Regression and Linear Regression produce equations that experts can validate; the Multilayer Perceptron gives a marginal performance boost but acts as a black box.
- *Training cost vs. Flexibility*: Lexicographic order and fixed fuzzy operators require no training but are rigid; ML approaches need a representative training set and careful cross‑validation to avoid overfitting.
- *Generality vs. Specificity*: Models trained on Israel/Chile data may not generalize to other populations; SCS simplifies reality and might lose nuance compared to finer‑grained codifications.

**Failure signatures:**
- **Model brittleness**: Sudden drop in ranking metrics on a new test population not seen during training/validation.
- **Overfitting indicators**: Training average rank much better than validation rank during CV (e.g., 0.004 vs. 0.007), suggesting memorization of training folds.
- **Interpretability collapse**: Symbolic Regression produces an overly complex expression (many nested operations) that domain experts cannot validate.

**First 3 experiments:**
1. **Baseline replication**: Implement Adams & Aschheim’s exact lexicographical order (Exact Group → # Matches → % Mismatch → % Possible) and confirm average ranking ~3.91 on the provided test split.
2. **Lexicographical search**: Systematically test all 5040 permutations of the seven criteria; for each permutation, compute rankings via 5‑fold CV. Identify the top‑performing order and verify it significantly improves over baseline on the held‑out test set.
3. **OWA weight sweep**: For OWA, test weight vectors: Maximum, Minimum, Average, Linear. Evaluate on validation folds, select the best (Linear), and compare its test‑set CMC curve to baseline and the best lexicographical order. Record why OWHM and Sugeno integral underperform (e.g., conservatism).

## Limitations
- The study relies on a single non‑public dataset (215 cases from Israel/Chile); results may not generalize to other populations or coding practices.
- Key parameters for fuzzy operators (e.g., how Sugeno λ measure is derived from solo‑criterion rankings) are ambiguously described, hindering exact replication.
- Machine‑learning models risk overfitting on the small dataset; implementation details (MLP activation functions, Symbolic Regression bloat control) are under‑specified, introducing variability in reproductions.

## Confidence
- **White‑box ML superiority (Symbolic Regression, Linear Regression):** High – Clear metrics, consistent CMC improvements, and explicit equations provided.
- **Fuzzy operator efficacy (OWA‑Linear):** Medium – Improvement documented but mixed across operators; parameter uncertainty weakens evidence.
- **Lexicographical reordering benefit:** Medium‑High – Exhaustive permutation test supports claim, but transferability to unseen data remains unproven.

## Next Checks
1. **Cross‑population validation:** Apply the best models (Symbolic Regression, OWA‑Linear) to an external forensic dataset or a held‑out subset from a different demographic to measure generalization performance.
2. **Parameter sensitivity analysis for fuzzy operators:** Explicitly derive Sugeno λ using both cardinality and λ measures with step‑by‑step normalization; recompute rankings to isolate the impact of parameter choices.
3. **Nested cross‑validation for overfitting diagnosis:** Perform 5×5 nested CV to separate model selection from evaluation; report mean and variance of test ranks across outer folds to assess stability on small data.
