# Contract And Conquer: How to Provably Compute Adversarial Examples for a Black-Box Model?
## Quick Facts
- **arXiv ID:** 2603.10689
- **Source URL:** https://arxiv.org/abs/2603.10689
- **Reference count:** 29
- **Primary result:** Introduces a black-box attack with a provable convergence guarantee, achieving 100% success on ResNet-50 and ViT-B for ImageNet and CIFAR-10 with lower ℓ∞ perturbations.

## Executive Summary
The paper addresses a fundamental gap in adversarial machine learning: the absence of success guarantees for black-box attacks. It proposes **Contract And Conquer (CAC)**, a novel algorithm that iteratively distills the target black-box model into a surrogate and performs white-box attacks within a contracting search space. Under mild assumptions—including bounded surrogate gradients and the ability to train the surrogate to a specified confidence margin—CAC provably returns an adversarial example within a fixed number of queries. Empirical evaluations on standard benchmarks show near-perfect success rates and competitive query efficiency, demonstrating that provable guarantees are achievable in practice for common model families.

## Method Summary
CAC operates in alternating iterations. First, it trains a surrogate model via knowledge distillation on an expanding dataset of labeled queries to the target. The distillation set is initialized with the target point *x* and its *m−1* nearest neighbors from a hold-out set. Second, a white-box attack (MI-FGSM) is run on the surrogate within the current feasible region, an ℓ∞ ball around *x* that contracts after each iteration. If the resulting example *z_j* does not transfer to the target, it is added to the distillation set, and the feasible region is shrunk by intersecting it with an ℓ∞ ball around *z_j*. The contraction rate depends on the distance between consecutive examples. The total query budget accounts for initial distillation queries and one query per iteration to test transferability. The theoretical guarantee bounds the number of iterations required before the contracted region forces transferability.

## Key Results
- Achieves **100% attack success** in both hard-label and soft-label settings against ResNet-50 and ViT-B on ImageNet and CIFAR-10.
- Produces adversarial examples with **lower ℓ∞ perturbations** compared to state-of-the-art black-box attacks.
- Maintains **comparable or better query efficiency** than prior methods while providing a provable convergence guarantee.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** CAC iteratively narrows the adversarial search space while improving surrogate fidelity.
- **Mechanism:** Each alternation trains a new surrogate via knowledge distillation on an expanding dataset including the latest adversarial example, then performs a white-box attack on the surrogate within the current search space. If the example doesn't transfer, the search space contracts around the new example via `Uδ(x)_j = Uδ(x) ∩ Uρ_j(z_j)`, where ρ_j depends on the step between successive examples.
- **Core assumption:** The surrogate can be trained to match the target's predictions on the current distillation set with a confidence margin ε (Eq. 4).
- **Evidence anchors:**  
  - [abstract] "the method is based on knowledge distillation of the target model on an expanding distillation dataset and precise contraction of the adversarial example search space."  
  - [section 3.2] Full description of the two-step alternation and contraction formula (Eq. 6,7).  
  - [corpus] Alignment with "Model Mimic Attack" on using distillation for transferability, but CAC uniquely adds contraction.
- **Break condition:** Surrogate fails to learn the target's decision boundary on the current distillation set to required confidence ε.

### Mechanism 2
- **Claim:** The contraction guarantees that after bounded iterations, a surrogate adversarial example will be close enough to a target decision boundary to ensure transfer.
- **Mechanism:** The theoretical bound (Lemma 3.4) shows that if the surrogate's gradients are bounded (γ) and the confidence condition holds, the distance between consecutive adversarial examples shrinks geometrically (ρ_j ≤ τ^(j-1)δ). Once ρ_j < ε/γ, the surrogate's prediction at z_j matches that at z_{j-1} (a point on the target's decision boundary), forcing transfer.
- **Core assumption:** Surrogate is differentiable with bounded gradients in Uδ(x); white-box attack succeeds each iteration.
- **Evidence anchors:**  
  - [section 3.3] Formal statement of Lemma 3.4 and its proof derive the iteration bound (j-1) ln τ ≤ ln ε - ln δ - ln γ.  
  - [abstract] "we prove that the method yields an adversarial example for the black-box model within a fixed number of algorithm iterations."  
  - [corpus] Neighboring papers focus on improving transferability empirically, not on iterative convergence guarantees.
- **Break condition:** Any assumption fails—e.g., surrogate gradients unbounded, white-box attack fails on some iteration, or contraction parameter τ ≥ 1.

### Mechanism 3
- **Claim:** Query budget is strategically partitioned between initial distillation set construction and iterative transfer checks.
- **Mechanism:** Initially, *m* queries build the seed distillation set (including target point). Each subsequent iteration spends 1 query to test transferability of the new surrogate adversarial example (z_j). If it fails, that query also adds (z_j, T(z_j)) to the distillation set. The total number of iterations is bounded by the remaining query budget *N* after initialization.
- **Core assumption:** The total query budget *N* is finite and known.
- **Evidence anchors:**  
  - [section 3.2.1] "the distillation dataset for the surrogate model, D(S), consists of pairs (x_k, T(x_k))... We use N_init = 10000 and m = 300."  
  - [Algorithm 1] Explicit query accounting: `N ← N - m` in line 2 and `N ← N - 1` in line 16.  
  - [section 4.1.4] "we fix the maximum number of queries to the target model... and evaluate the efficiency... by computing its attack success rate."
- **Break condition:** Query budget exhausted before meeting transferability condition ρ_j < ε/γ.

## Foundational Learning
- **Concept:** Black-box adversarial attacks (score-based/decision-based vs. transfer-based)  
  - *Why needed:* CAC is a *transfer-based* attack; understanding the query-efficiency trade-offs of other black-box methods contextualizes CAC's design.  
  - *Quick check:* What is the fundamental difference in information access between a score-based attack and a transfer-based attack like CAC?
- **Concept:** Knowledge distillation  
  - *Why needed:* CAC's surrogate is trained via distillation; the quality of this imitation directly impacts transferability.  
  - *Quick check:* Why does distilling on a small, locally-focused dataset (nearest neighbors to *x*) help the surrogate learn the target's behavior *near x* better than a random subset?
- **Concept:** Adversarial transferability phenomenon  
  - *Why needed:* CAC's entire guarantee hinges on the assumption that an adversarial example for a close surrogate will transfer to the target.  
  - *Quick check:* Under what conditions might an adversarial example crafted for a surrogate model *fail* to transfer to the target model, even if the surrogate is highly accurate on the benign data?
- **Concept:** Bounded gradient assumption in adversarial robustness analysis  
  - *Why needed:* The theoretical bound (Lemma 3.4) depends on a bound γ for the surrogate's gradient norm within the search region.  
  - *Quick check:* How does the Lipschitz continuity of a neural network's output relate to the boundedness of its gradients?
- **Concept:** Convergence guarantees for iterative algorithms  
  - *Why needed:* CAC provides a fixed iteration upper bound; understanding worst-case versus empirical iteration counts is key.  
  - *Quick check:* What is the difference between a *worst-case* convergence bound and an *expected* or *empirical* convergence rate?

## Architecture Onboarding
Component map:  
Target Model T -> Hold-out Dataset -> Distillation Dataset D(S)_j -> Surrogate S_j -> White-box Attacker (MI-FGSM) -> Search Space Manager -> Query Budget Tracker

Critical path:  
1. Initialize D(S) with *m* nearest neighbors from hold-out + (x, T(x)).  
2. Train S on D(S).  
3. Run MI-FGSM on S within current Uδ(x)_{j-1} to get z_j.  
4. Query T(z_j). If argmax S(z_j) == T(z_j), return z_j.  
5. Else: add (z_j, T(z_j)) to D(S), compute ρ_j = τ·∥z_j−z_{j−1}∥∞, shrink region to Uδ(x) ∩ U_{ρ_j}(z_j), set α = ρ_j/M, loop.

Design tradeoffs:  
- Surrogate capacity vs. speed: Larger S (e.g., ResNet-18) may learn T better but is slower to train; smaller S may violate the learning assumption (Eq. 4).  
- Contraction rate (τ): Too aggressive (small τ) risks overshooting the decision boundary before surrogate improves; too slow (τ ~ 1) increases iterations needed.  
- Initial δ: Larger δ gives more room but may require more iterations; smaller δ may miss adversarial region.

Failure signatures:  
- Surrogate training loss stagnates above zero, violating Eq. 4 confidence condition.  
- MI-FGSM fails to find any adversarial example for S within Uδ(x)_j.  
- Transferability rate stays near 0% across many iterations despite surrogate accuracy.  
- Feasible region becomes empty after contraction update.

First 3 experiments:  
1. **Surrogate fidelity check:** After training S_j, evaluate accuracy and *margin* (Eq. 4) on the *held-out* nearest-neighbor subset. Must satisfy min margin > ε.  
2. **White-box attack sanity check:** On a known vulnerable surrogate (e.g., same architecture as T, trained on same data), confirm MI-FGSM with current δ and α finds adversarial examples with >99% success.  
3. **Initial transferability test:** With j=1, after first surrogate attack, check if z_1 transfers to T. If not, inspect: (a) is S_1 actually misclassifying z_1? (b) does T(z_1) match S_1(x) or S_1(z_1)? This isolates whether failure is due to poor surrogate or non-transferable region.

## Open Questions the Paper Calls Out
1. Under what conditions does the assumption that a white-box attack succeeds on *every* alternation iteration fail in practice, and can the convergence guarantee be extended to cases with occasional surrogate attack failures?
2. How sensitive is the theoretical convergence bound to the choice of the contraction parameter τ, and can an adaptive τ schedule significantly reduce the worst-case iteration count?
3. Does CAC’s guarantee extend to threat models beyond ℓ∞ perturbations (e.g., ℓ2, ℓ0, or spatial transformations), and what modifications to the contraction mechanism would be necessary for other norms?
4. For a given target model, can the theoretical iteration upper bound be empirically tightened, and what factors (e.g., model architecture, dataset, distillation quality) most influence the actual number of iterations needed?
5. How does the quality of the initial distillation dataset (size *m*, selection of nearest neighbors) affect the trade-off between query efficiency and the risk of failing the assumption in Eq. 4 (surrogate confidence ε)?

## Limitations
- Theoretical guarantees rely on strong assumptions: bounded surrogate gradients, perfect distillation (margin ε), and successful white-box attack each iteration; real-world training may violate these.
- Practical hyperparameters (initial δ, contraction τ, MI-FGSM steps *M*) are chosen heuristically; their optimal values likely vary by target model.
- The guarantee holds only within the contracted ℓ∞ ball; if the true decision boundary is non-linear or has small ℓ∞ radius, CAC may fail to find an example.

## Confidence
- **Provable convergence** (Mechanism 2): **Medium**. Proof exists but assumptions may not hold in practice.
- **High empirical success** (Mechanism 1 & 3): **High** for reported settings (ResNet-50/ViT-B on ImageNet/CIFAR-10), but unknown for other architectures or robust models.
- **Query efficiency** (Mechanism 3): **Medium**. Algorithmic query accounting is clear, but efficiency depends on hyperparameters and surrogate quality.

## Next Checks
1. **Surrogate margin stress test:** Vary surrogate capacity (ResNet-18 vs. ResNet-50) and training epochs; record frequency of margin violation (Eq.4) and its impact on final attack success.
2. **Contraction dynamics tracking:** Monitor ρ_j decay across runs with different τ; verify geometric decay and compare to theoretical bound (ln τ ≤ ln ε - ln δ - ln γ).
3. **Cross-robustness transfer:** Evaluate CAC against adversarially trained targets (e.g., ResNet-50 with ℓ∞ robustness) to test the assumption that surrogate decision boundary approximates target locally.
