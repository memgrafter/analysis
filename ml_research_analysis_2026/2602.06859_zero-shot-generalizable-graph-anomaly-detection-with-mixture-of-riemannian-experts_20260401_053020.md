# Zero-shot Generalizable Graph Anomaly Detection with Mixture of Riemannian Experts

## Quick Facts
- **arXiv ID:** 2602.06859  
- **Source URL:** https://arxiv.org/abs/2602.06859  
- **Reference count:** 40  
- **Primary result:** GAD-MoRE achieves an average AUROC of 82.09% and AUPRC of 36.96% in zero-shot graph anomaly detection, significantly surpassing state-of-the-art zero-shot methods and even outperforming few-shot fine-tuned models.

## Executive Summary
Graph anomaly detection (GAD) models often fail to generalize across unseen domains due to geometric heterogeneity in anomaly patterns and the distortion caused by fixed-curvature Riemannian spaces. This paper introduces GAD-MoRE, a mixture of Riemannian experts framework designed for zero-shot generalizable GAD. It combines an anomaly-aware multi-curvature feature alignment module that projects raw node attributes into several Riemannian manifolds, a scorer with specialized experts each operating in a distinct curvature space, and a memory-based dynamic router that assigns nodes to experts based on historical reconstruction quality. Evaluated on 11 benchmark datasets in a zero-shot setting, GAD-MoRE sets a new state-of-the-art, demonstrating that explicitly modeling geometric diversity is crucial for cross-domain anomaly detection.

## Method Summary
GAD-MoRE operates in three stages. First, the anomaly-aware multi-curvature feature alignment (MCFA) module processes raw node features \(X_0\) by projecting them into multiple constant-curvature manifolds (hyperbolic, Euclidean, spherical). For each curvature, PCA extracts high-variance components followed by Laplacian score-based feature selection; the selected subsets are concatenated into a unified geometry-aware matrix \(X\) of dimension \(D\). Second, a GNN backbone (4 layers, 2-hop) propagates \(X\) over the graph to produce residual node embeddings \(h_v\). Third, a mixture of Riemannian experts (MoE) scorer uses \(K=5\) experts, each with a distinct fixed curvature \(\kappa_i\). Each expert reconstructs \(h_v\) via manifold-aware operations (exponential/logarithmic maps). A sparse top-\(k\) router, informed by memory banks \(B_i\) storing high-quality past reconstructions, computes gating weights. The final reconstructed embedding \(\hat{h}_v\) is a weighted sum of selected experts’ outputs. Training uses a composite loss (embedding, feature, structure, contrastive, gate entropy) without target labels. At inference, anomaly score \(S(v) = \|h_v - \hat{h}_v\|^2\) ranks nodes.

## Key Results
- GAD-MoRE achieves average zero-shot AUROC 82.09% and AUPRC 36.96% across 11 datasets, outperforming IA-GGAD (77.00% AUROC) and few-shot fine-tuned models like ARC and AnomalyGFM.
- Ablation studies show removing MCFA, MoE, or the memory router each causes significant performance drops (e.g., w/o MoE: AUROC 75.32%), confirming each component’s necessity.
- Hyperparameter sensitivity analysis identifies optimal settings: embedding dimension \(D=32\), number of experts \(K=5\).

## Why This Works (Mechanism)
### Mechanism 1: Anomaly-aware Multi-curvature Feature Alignment
- **Claim:** The MCFA module enriches raw, geometry-agnostic node attributes by projecting them into multiple Riemannian spaces, capturing diverse geometric characteristics that help separate anomalies.
- **Mechanism:** For each target curvature, raw features are first mapped to the tangent space at the manifold origin. PCA extracts high-variance components, and a Laplacian score selects features smooth with respect to graph topology. The subsets are concatenated into a unified feature matrix.
- **Core assumption:** Anomalous patterns across graphs exhibit geometric heterogeneity; some are more separable in hyperbolic space (hierarchical), others in spherical (cyclical), etc. Multi-curvature features increase the chance of a discriminative representation.
- **Evidence anchors:** The module is described in Section IV.A; the ablation “w/o MCFA” (single Euclidean space) yields lower performance, supporting its role.

### Mechanism 2: Mixture of Riemannian Experts Scorer
- **Claim:** The MoE scorer assigns each node to a small set of curvature-specialized expert networks, allowing reconstruction in the geometry best suited to that node’s anomaly pattern.
- **Mechanism:** Each expert \(E_i\) lifts the node embedding into its manifold via exponential map, transforms it through manifold-aware layers, and maps back with logarithmic map. A gating network computes logits; a sparse top-\(k\) selection yields a weighted combination of expert outputs.
- **Core assumption:** No single Riemannian space optimally captures all anomaly patterns; per-node expert selection provides adaptability without committing to a global geometry.
- **Evidence anchors:** Experts are defined in Section IV.B; the “w/o MoE” ablation drop (Section V.B) demonstrates the mixture’s importance.

### Mechanism 3: Memory-based Dynamic Router
- **Claim:** The memory-based router directs nodes to experts based on historical reconstruction quality, aligning routing directly with the anomaly detection objective (low reconstruction error for normal patterns).
- **Mechanism:** Each expert maintains a memory bank \(B_i\) of embeddings it reconstructed well. After a cold-start period, nodes assigned to an expert receive a quality score \(q(v,i)\) based on normalized reconstruction error; only samples exceeding a progressively tightening threshold \(\tau_q(e)\) are added to the bank.
- **Core assumption:** An expert that has previously reconstructed similar nodes with high fidelity is likely the best choice for future nodes of that type.
- **Evidence anchors:** The router and bank update rules are in Section IV.C; the “w/o MDR” ablation (replacing with a linear router) shows performance degradation.

## Architecture Onboarding
- **Component map:** Raw features \(X_0\) -> MCFA -> unified feature matrix \(X\) -> GNN backbone -> node embeddings \(h_v\) -> Router logits (via memory banks) -> top-\(k\) expert selection -> expert reconstruction \(\hat{h}_v\) -> anomaly score \(S(v)\).
- **Critical path:** MCFA alignment, GNN propagation, memory-informed routing, expert reconstruction, loss computation, memory update (post cold-start). Inference requires only steps up to reconstruction.
- **Design tradeoffs:**  
  - Number of experts \(K\): More experts increase curvature coverage but risk collapse; paper finds \(K=5\) optimal.  
  - Embedding dimension \(D\): Larger \(D\) enriches representation but may overfit; \(D=32\) chosen.  
  - Memory bank size & threshold: Larger banks provide stable prototypes but consume memory; threshold \(\tau_q(e)\) trades quality vs. quantity.  
  - Loss weights \(\lambda_j\): Balance reconstruction vs. regularization; improper weighting causes routing collapse or ignores geometry.
- **Failure signatures:**  
  - Low gating entropy: all nodes routed to few experts → loss of geometric diversity.  
  - Memory corruption early (cold-start too short): router consistently selects suboptimal experts.  
  - Experts’ curvatures not diverging: effectively single-geometry approach.  
  - Poor MCFA selection (e.g., Laplacian filtering removes key attributes): downstream performance drop, especially on datasets like Facebook.
- **First 3 experiments:**  
  1. **Overall performance (RQ1):** Zero-shot evaluation on seven target datasets yields avg AUROC 82.09%, AUPRC 36.96%, surpassing baselines including few-shot fine-tuned models.  
  2. **Ablation study (RQ2):** Removing MCFA, MoE, or memory router each causes clear performance drops (e.g., w/o MoE: AUROC 75.32%), confirming necessity.  
  3. **Hyperparameter sensitivity (RQ3):** Varying \(D\) and \(K\) shows \(D=32\), \(K=5\) optimal; performance plateaus beyond.

## Open Questions the Paper Calls Out
- How can GAD-MoRE be effectively extended to dynamic graphs where the structure and node attributes evolve over time?
- Does the memory-based dynamic router remain reliable when the target graph exhibits normality patterns that are significantly different from those in the source graphs?
- Can a hierarchical Mixture-of-Experts architecture better capture multi-scale geometric heterogeneity than the current flat set of curvature experts?
- Would an end-to-end learnable manifold projection replace the heuristic PCA/Laplacian feature alignment to further improve zero-shot generalization?

## Limitations
- **Architectural underspecification:** Exact expert MLP depth, router network structure, memory bank capacity, and dynamic threshold schedule (\(\tau_q(e)\) parameters) are not provided, hindering faithful reproduction.
- **Curvature selection rationale:** Why the specific set \(\kappa = \{0.0, -0.5, -1.0, 0.5, 1.0\}\)? Sensitivity to different graph types (hierarchical vs. community) is not analyzed.
- **Heuristic MCFA:** The PCA+Laplacian alignment is not trained end-to-end; its feature selection behavior (e.g., variance thresholds) is unquantified, and alternative alignments are unexplored.

## Confidence
- **Overall zero-shot performance claim** (avg AUROC 82.09%): *Medium* – supported by reported results on 11 datasets, but no public code for verification; baseline comparisons rely on cited numbers.
- **MCFA mechanism** (multi-curvature alignment): *Medium* – described in Section IV.A, but actual feature selection (e.g., retained components) is not quantified; ablation shows benefit but not isolated PCA vs. Laplacian contributions.
- **MoE mechanism** (curvature-specialized experts): *Medium* – “w/o MoE” ablation confirms importance, but no diagnostics on expert collapse (gating entropy distribution) are reported.
- **Memory router mechanism** (historical quality-based routing): *Low* – update logic described mathematically, but crucial hyperparameters (cold-start epochs, threshold schedule, bank size) are omitted; “w/o MDR” uses a linear router, but memory component’s standalone necessity is unvalidated.
