# BiGain: Unified Token Compression for Joint Generation and Classification

## Quick Facts
- arXiv ID: 2603.12240
- Source URL: https://arxiv.org/abs/2603.12240
- Reference count: 40
- Primary result: Training-free token compression that simultaneously boosts classification accuracy (+7.15% on ImageNet-1K vs ToMe) and improves generation fidelity (FID -0.34) while reducing FLOPs.

## Executive Summary
BiGain introduces a training-free, plug-and-play token compression framework for diffusion models that jointly optimizes for generative fidelity and discriminative utility. It employs frequency separation to protect high-frequency details during merging. Two core operators—Laplacian-gated token merging and Interpolate-Extrapolate KV downsampling—enable efficient token reduction with controllable preservation of edges and textures. Evaluated on ImageNet-1K with Stable Diffusion 2.0, BiGain outperforms prior work ToMe in both classification accuracy and FID, and shows robust performance across DiT and U-Net backbones and on the Oxford-IIIT Pets dataset.

## Method Summary
BiGain operates within the attention layers of diffusion model backbones (U-Net or DiT). It first computes a Laplacian-based frequency measure for each token. Tokens with low-frequency content (smooth regions) are merged using a gating mechanism that prevents merging of high-frequency tokens, thereby preserving edges and fine textures. For the attention computation, keys and values are downsampled via a weighted combination of nearest and average pooling (Interpolate-Extrapolate), reducing the cost while maintaining query integrity. The process is training-free, requiring only a single pass through the model to identify merge decisions, and can be toggled on or off without re-training.

## Key Results
- On ImageNet-1K with Stable Diffusion 2.0 at 70% merge ratio, BiGain improves classification accuracy by 7.15% and FID by 0.34 compared to the previous method ToMe.
- On Oxford-IIIT Pets with ~10% FLOPs reduction, BiGain incurs only a 2.65% accuracy drop versus 8.07% for ToMe.
- Across DiT and U-Net backbones, BiGain consistently enhances the speed-accuracy trade-off for diffusion-based classification while matching or improving generation fidelity.

## Why This Works (Mechanism)
The paper leverages the principle that salient image details (edges, textures) correspond to high-frequency components. By separating tokens into smooth (low-frequency) and rough (high-frequency) via Laplacian filtering, BiGain selectively merges only those tokens that are unlikely to contain critical information for downstream classification or generation. The interpolation-extrapolation downsampling of keys/values reduces the computational burden of attention while maintaining the representation capacity by preserving queries. This dual strategy ensures that the compression does not degrade either the generative quality (FID) or the discriminative performance (classification accuracy). The training-free nature simplifies adoption, as the same gating thresholds can be applied to new datasets without adaptation.

## Architecture Onboarding
BiGain integrates into existing diffusion models at the attention layers.

- **Component Map**: Input latent tokens -> Frequency analysis (Laplacian computation) -> Laplacian-gated merging -> KV downsampling (Interpolate-Extrapolate) -> Attention (with reduced K/V) -> Output tokens -> Decoder (for generation) or Classifier head (for classification).
  Plain text: Latent tokens -> Laplacian gate -> Merge operator -> KV downsample -> Attention -> Output

- **Critical Path**: The token merging decision is made early per layer, based on the current token features. The gating threshold and merge ratio are hyperparameters that must be tuned per model. The quality of the Laplacian estimate directly impacts preservation of details. The downsampling of K/V must be synchronized across layers to maintain consistency in attention computation.

- **Design Tradeoffs**: Higher merge ratios yield greater FLOPs reduction but risk losing high-frequency information; the Laplacian gate sensitivity controls this balance. The mix of nearest vs average pooling in KV downsampling influences how much context is retained: nearest preserves sharpness but may be noisy; average smooths. The framework is training-free, so it avoids costly retraining but may not reach the optimal compression achievable by learnable methods.

- **Failure Signatures**: Blurred edges or loss of fine textures in generated images; classification accuracy drops on datasets with many high-frequency details; visible grid artifacts from aggressive merging; attention maps becoming overly sparse or uniform, indicating loss of token diversity.

- **First Three Experiments**:
  1. **Merge Ratio Sweep**: Vary the token merge ratio (e.g., 30%, 50%, 70%) on ImageNet-1K with SD 2.0, record classification accuracy and FID to find the Pareto frontier.
  2. **Cross-Architecture Generalization**: Apply BiGain to DiT and U-Net backbones on a different dataset (e.g., Oxford-IIIT Pets) to test robustness and measure accuracy drop vs FLOPs saved.
  3. **Ablation of Frequency Thresholds**: Systematically vary the Laplacian gating threshold to quantify its effect on edge preservation (e.g., using edge detection metrics) and downstream performance.

## Limitations
- Corpus signals indicate very low citation count (~0.0 average) and a Field Marginalized Rate (FMR) of ~0.47, suggesting limited peer recognition or early-stage validation.
- Claims are based on a narrow set of benchmarks (ImageNet-1K, SD 2.0, Pets) without evidence of generalization to other domains (e.g., medical, satellite) or newer diffusion models (e.g., SDXL, DiT-XL/2).
- Speed metrics are derived from FLOPs calculations; actual wall-clock runtime and memory consumption are not measured, and the training-free approach may underperform learnable compression methods under optimal tuning.
