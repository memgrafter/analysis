# JAL-Turn: Joint Acoustic-Linguistic Modeling for Real-Time and Robust Turn-Taking Detection in Full-Duplex Spoken Dialogue Systems

## Quick Facts
- **arXiv ID:** 2603.26515
- **Source URL:** https://arxiv.org/abs/2603.26515
- **Reference count:** 0
- **Primary result:** Achieves state-of-the-art accuracy (93.27%) and F1 (0.934) on STurn-v3 with 36 ms latency by jointly modeling acoustic and linguistic cues for zero-added-latency turn-taking detection.

## Executive Summary
JAL-Turn introduces a real-time turn-taking detection system for full-duplex voice AI. It fuses acoustic features from a frozen CPC encoder and linguistic features from a frozen SenseVoice encoder (shared with ASR) via cross-attention, processed by a causal Transformer. This design enables parallel computation with ASR, adding no latency. Training uses an automated pipeline that derives Hold/Shift labels from stereo conversations. The model outperforms audio-only and LLM-based baselines on multiple benchmarks while meeting strict latency constraints.

## Method Summary
The system processes raw audio waveforms. Acoustic features come from a frozen CPC encoder, linguistic features from a frozen SenseVoice-Small encoder (also used by the ASR component). These features are projected and fused through a two-layer cross-attention module (SenseVoice as query, CPC as key/value). A causal Transformer with ALiBi positional bias then models the fused sequence. An attention-based temporal pooling layer aggregates frame-level outputs into an utterance representation, followed by a binary classifier. Labels are automatically generated via a VAD-based future-window strategy on stereo audio, with context windows normalized to 10 seconds. The model is trained end-to-end with binary cross-entropy, and the shared SenseVoice encoder allows inference to run concurrently with ASR without extra delay.

## Key Results
- 93.27% accuracy and 0.934 F1 on STurn-v3 with 36 ms latency.
- 92.03% accuracy and 0.925 F1 on a Japanese corpus with 38 ms latency.
- Surpasses audio-only and LLM-based baselines in both accuracy and latency.

## Why This Works (Mechanism)
Joint acoustic-linguistic modeling captures complementary cues: acoustic patterns (e.g., breath, pause) and linguistic context (word identities, syntax). The cross-attention fuse allows dynamic weighting of both modalities. Causal Transformer with ALiBi handles streaming inputs without future context. Temporal pooling provides robust utterance-level decisions. Crucially, sharing the SenseVoice encoder with ASR enables parallel processing: the same linguistic features serve both tasks, eliminating sequential dependency and achieving zero added latency.

**Critical Path:** The frozen SenseVoice encoder is shared with ASR. During inference, ASR and turn-taking use the same linguistic features simultaneously, avoiding serialization and achieving zero added latency.

**Design Tradeoffs:**  
- *Frozen encoders:* Stability vs. flexibility; prevents catastrophic forgetting but limits adaptation to turn-taking data.  
- *Cross-attention fusion:* Dynamic integration vs. complexity; adds parameters but allows modality balancing.  
- *Causal processing:* Real-time constraint vs. modeling power; cannot use future context, may miss long-range dependencies.

**Failure Signatures:**  
- Degraded accuracy if CPC/SenseVoice feature spaces mismatch.  
- Noisy labels from VAD pipeline cause training instability.  
- Latency exceeds budget if cross-attention or Transformer not optimized for streaming.

**First Three Experiments:**  
1. Verify frozen encoder output dimensions and distributions match expectations (CPC: 256-d, SenseVoice: 512-d).  
2. Implement VAD labeling on a small public stereo corpus (e.g., Switchboard) and manually audit label quality.  
3. Measure end-to-end inference latency on GPU (e.g., H100) with streaming input to confirm ~36 ms per frame.
