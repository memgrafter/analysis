# DocSplit: A Comprehensive Benchmark Dataset and Evaluation Approach for Document Packet Recognition and Splitting

## Quick Facts
- **arXiv ID**: 2602.15958
- **Source URL**: https://arxiv.org/abs/2602.15958
- **Reference count**: 22
- **Primary result**: Qwen 3 achieves the highest Packet scores (0.9238–0.9492) across five DocSplit datasets, with ordering performance consistently exceeding 0.97.

## Executive Summary
This paper introduces DocSplit, the first dedicated benchmark for document packet splitting—the task of separating heterogeneous multi-page packets into their constituent documents. It comprises five datasets with sequential, shuffled, and interleaved page arrangements, addressing a real-world need unserved by existing benchmarks. The authors propose a novel evaluation framework that unifies clustering metrics (Rand Index, V-measure) and ordering metrics (Kendall's Tau) into a continuous "Packet score," overcoming limitations of prior binary or cascading scoring systems. Testing five multimodal LLMs (Claude, DeepSeek, Gemma, Qwen), Qwen 3 performs best, while analysis reveals boundary detection as the primary bottleneck, especially on shuffled/interleaved data. The benchmark highlights significant performance gaps, underscoring the need for specialized solutions.

## Method Summary
DocSplit provides five datasets simulating real-world packet scenarios: sequential documents, within-document shuffling, and interleaved multi-document packets. The evaluation framework computes a Packet score by combining clustering metrics (which assess whether pages are correctly grouped into documents) and ordering metrics (which evaluate the correct sequence within each group). This approach allows continuous, partial-credit scoring, avoiding the harsh penalties of all-or-nothing or error-cascade evaluations. The framework is model-agnostic, requiring only predicted page groupings and orderings as input.

## Key Results
- Qwen 3 attains the highest Packet scores, ranging from 0.9238 to 0.9492 across datasets.
- Ordering performance is uniformly strong (>0.97 Kendall's Tau), indicating models reliably sequence pages once grouped.
- Clustering performance varies widely (0.56–0.90), identifying boundary detection—distinguishing where one document ends and another begins—as the core challenge.
- The continuous Packet score effectively discriminates between models and dataset difficulties, validated through edge-case analyses.

## Why This Works (Mechanism)
The continuous, metric-based evaluation overcomes prior scoring limitations by awarding partial credit for near-accurate splits. This avoids cascading penalties where a single early error ruins all subsequent scores and captures nuanced performance differences. The combination of clustering and ordering metrics ensures both grouping and sequencing are assessed, aligning with real-world requirements where both aspects matter. Edge-case analysis confirms the metrics behave as intended for partial matches and common error patterns.

## Foundational Learning
- **Document Packet Recognition**: Separating mixed multi-page packets into original documents; needed because real-world archives (e.g., scanned filings) often contain interleaved materials; quick check: test if standard document segmentation tools handle heterogeneous multi-document inputs.
- **Clustering Evaluation (Rand Index, V-measure)**: Quantifies agreement between predicted and ground-truth page groupings; needed to measure grouping accuracy without order consideration; quick check: apply to toy examples with swapped pages between documents.
- **Ordering Evaluation (Kendall's Tau)**: Measures rank correlation of page sequences within documents; needed because documents have intrinsic linear order; quick check: compute on a perfectly ordered vs. reversed document sequence.
- **Multimodal LLMs**: Models processing both textual and spatial/layout features; needed to interpret document structure beyond plain text; quick check: evaluate on a single-page form extraction task to isolate layout understanding.
- **Benchmark Curation**: Constructing datasets with controlled perturbations (shuffling, interleaving); needed to isolate failure modes and simulate production scenarios; quick check: analyze dataset statistics for page count distribution and interleaving depth.
- **Continuous Scoring**: Using real-valued metrics instead of binary correct/incorrect; needed for fine-grained model comparison and partial-credit fairness; quick check: manually score a few edge-case splits to see if metric aligns with intuitive accuracy.

## Architecture Onboarding
**Component Map**:  
Input Pages -> Multimodal Feature Extraction -> Page Embedding/Representation -> Clustering (group assignment) -> Ordering (sequence prediction) -> Metric Computation (Rand Index, V-measure, Kendall's Tau) -> Packet Score Aggregation

**Critical Path**:  
Pages are first processed by a multimodal LLM to extract representations. These feed into a clustering step to assign pages to document groups. Within each group, an ordering step determines the sequence. Finally, metrics compare predictions against ground truth.

**Design Tradeoffs**:  
- **Metric weighting**: Balancing clustering vs. ordering contributions in the Packet score; over-weighting ordering may mask poor grouping.
- **Dataset diversity**: Including sequential, shuffled, and interleaved cases increases realism but complicates error analysis.
- **Model-agnosticism**: The framework evaluates any grouping/ordering output but does not prescribe how to generate them, shifting complexity to the model.

**Failure Signatures**:  
- **Low clustering score**: Model fails to detect document boundaries (e.g., grouping pages from different documents together).
- **High ordering but low clustering**: Model sequences pages correctly within wrong groups, suggesting boundary detection is the bottleneck.
- **Dataset-specific drops**: Sharp performance decline on shuffled/interleaved sets indicates sensitivity to arrangement perturbations.

**First Three Experiments**:  
1. **Baseline on sequential dataset**: Establish a performance ceiling with the easiest arrangement; expect high Packet scores.
2. **Shuffled within-document test**: Introduce intra-document shuffling; measure clustering robustness; expect ordering to remain high if grouping is correct.
3. **Interleaved multi-document challenge**: Test worst-case; assess how well models disentangle multiple documents; expect both clustering and ordering to degrade.

## Limitations
- Novelty claim of first dedicated packet-splitting benchmark has medium confidence; related work may exist under different terminology (document segmentation, page grouping).
- Evaluation framework's edge-case validation is described but details are sparse, limiting confidence in metric robustness.
- Generalizability is low; only multimodal LLMs are evaluated, with no traditional (non-LLM) baselines tested, making it unclear if the benchmark discriminates broadly.

## Confidence
- **Benchmark novelty**: Medium
- **Evaluation framework**: Medium
- **Performance results (Qwen 3 scores, ordering/clustering ranges)**: High
- **Generalizability (need for specialized approaches)**: Low
