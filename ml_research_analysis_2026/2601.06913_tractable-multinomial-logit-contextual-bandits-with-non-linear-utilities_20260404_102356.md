# Tractable Multinomial Logit Contextual Bandits with Non-Linear Utilities

## Quick Facts
- **arXiv ID**: 2601.06913
- **Source URL**: https://arxiv.org/abs/2601.06913
- **Reference count**: 40
- **Primary result**: ONL-MNL achieves a Õ(√T) cumulative regret bound for non-linear MNL contextual bandits, the first such sharp and tractable guarantee, with regret independent of the number of items N.

## Executive Summary
The multinomial logit (MNL) model is widely used to model user choice in recommendation and assortment optimization. Contextual bandits with MNL rewards and linear utility functions have been studied, but non-linear utilities pose significant challenges: prior work either assumes linearity or incurs suboptimal regret or computational intractability. This paper introduces ONL-MNL, a novel algorithm that handles non-linear utility functions while achieving a near-optimal Õ(√T) regret with no dependence on the number of items N. ONL-MNL operates in two phases: an initial uniform exploration phase to collect pilot data, followed by an optimistic phase that uses a linearized model and regularized likelihood to construct confidence sets. A key technical contribution is a generalized geometric condition that allows the analysis to go beyond linear utilities and accommodate neural network function classes without relying on neural tangent kernel (NTK) approximations. Theoretical guarantees hold under standard assumptions, and experiments on synthetic and real data demonstrate superior robustness and scalability compared to existing baselines.

## Method Summary
ONL-MNL proceeds in two phases. Phase I explores uniformly at random for the first t0 rounds, selecting assortments independently of contexts. After observing choices, the algorithm computes a pilot estimate ŵ0 by minimizing the negative log-likelihood over the collected dataset. Phase II then runs for the remaining rounds. In each round t, the algorithm first updates the estimate ŵt by minimizing a regularized negative log-likelihood that linearizes the MNL model around ŵ0 and incorporates the history via a design matrix Vt. Specifically, the loss uses a first-order Taylor expansion of the utility function f_w around ŵ0, i.e., f_{ŵ0}(x) + ∇f_{ŵ0}(x)^⊤(w - ŵ0). The regularization is (λ/2)||w - ŵ0||^2. The confidence set Ct is defined as { w : ||w - ŵt||_{Vt} ≤ βt }, where Vt = λI + ∑_{s=t0}^{t-1} ∑_{i∈S_s} ∇f_{ŵ_s}(x_{si})∇f_{ŵ_s}(x_{si})^⊤. The optimistic utility for item i at time t is zti = f_{ŵt}(x_{ti}) + √(βt ||∇f_{ŵt}(x_{ti})||_{Vt^{-1}}) + βt Ch/λ, where Ch bounds the Hessian norm of f. The algorithm then selects the assortment St that maximizes the optimistic MNL expected reward: \tilde{R}_t(S) = (∑_{i∈S} exp(zti) r_{ti}) / (1 + ∑_{j∈S} exp(ztj)). After observing the user's choice, Vt is updated with the gradients of the selected items.

The regret analysis hinges on three pillars: (i) the pilot error converges as O(1/t0) due to a geometric condition on the expected squared loss (Assumption 4) and uniform convergence; (ii) the confidence set Ct contains the true utility equivalence set W* throughout Phase II with high probability, thanks to a self-concordant-like property of the linearized loss and a tailored concentration inequality; (iii) the per-round regret is bounded by the optimism bonus, whose sum over T is Õ(√T) via the elliptical potential lemma and careful balancing of λ and βt. Crucially, the bound depends on the parameter dimension dw rather than the number of items N, enabling scalability to large catalogs.

## Key Results
- First tractable algorithm for non-linear MNL contextual bandits with a sharp Õ(√T) cumulative regret bound.
- Regret scaling independent of the number of items N, overcoming polynomial dependence in prior methods.
- Bound explicitly incorporates problem-specific constants: κ (minimum choice probability), dw (parameter dimension), and geometric condition parameters (μ, τ).

## Why This Works (Mechanism)

### Mechanism 1: Uniform Exploration Yields Pilot Estimate
Uniform sampling in Phase I produces a dataset such that the empirical risk minimizer ŵ0 over the Lipschitz function class converges to the true utility equivalence set W* at rate O(1/t0) with high probability. This follows from uniform convergence of the negative log-likelihood (generalization error) and a reverse Lipschitz property of the MNL model, which translates log-loss error to squared error. The key enabler is the generalized geometric condition (Assumption 4), which ensures the expected squared loss is locally strongly convex near W*. If this convergence fails (e.g., due to violation of the geometric condition or insufficient t0), the pilot may be too inaccurate, causing the confidence set in Phase II to miss the true parameter and leading to linear regret.

### Mechanism 2: Confidence Set via Linearized Model
In Phase II, the algorithm constructs a confidence set Ct that provably contains W* for all rounds. This is achieved by minimizing a regularized loss that linearizes the MNL model around the current estimate ŵt. The design matrix Vt accumulates gradient outer products from selected items. A new concentration argument yields a confidence radius βt = Õ(μ^{-2} κ^{-4} dw) that grows slowly (essentially constant). By induction, leveraging the pilot convergence (Mechanism 1) and a self-concordant-like property of the linearized loss (which relates parameter distance to gradient distance), the true parameter ẽw ∈ W* is shown to satisfy ||ẽw - ŵt||_{Vt} ≤ βt with high probability. If βt is too small (e.g., due to mis-specified λ or t0), or if the self-concordant property fails, the confidence set may exclude ẽw, causing optimism to break down.

### Mechanism 3: Optimistic Utility Drives Low Regret
For each item i, the optimistic utility zti adds two bonuses to the current estimate f_{ŵt}(x_{ti}): a standard linear UCB term √(βt ||∇f_{ŵt}(x_{ti})||_{Vt^{-1}}) and a constant correction βt Ch/λ that accounts for linearization error. Setting λ = Õ(√T) makes the sum of the constant terms over T be Õ(√T). The sum of the sqrt terms is bounded by O(√T) via the elliptical potential lemma, provided gradients are bounded (Cg) and βt = Θ(1). Optimism holds: zti ≥ f_{w*}(x_{ti}). The per-round regret is at most the maximum bonus over the chosen assortment, and summing yields total regret Õ(κ^{-2} μ^{-1} dw √T). The dependence on dw (parameter dimension) rather than N (number of items) arises because the confidence set lives in parameter space, and the bonus depends on gradient norms, not directly on N. Failures include large Hessian (Ch) leading to inflated constant term, or unbounded gradients breaking the potential lemma.

## Foundational Learning

### Multinomial Logit (MNL) Choice Model
- **Why needed**: The MNL model defines the probability that a user selects an item from an assortment, forming the basis of the reward distribution. The algorithm's updates (log-likelihood, gradient computations) and analysis (reverse Lipschitz) rely on its specific probabilistic structure and properties like the outside option.
- **Quick check**: In the MNL model, p(i|X, S, w) = exp(f_w(x_i)) / (1 + ∑_{j∈S} exp(f_w(x_j))) for i∈S, and p(0|X, S, w) = 1 / (1 + ∑_{j∈S} exp(f_w(x_j))). What is the outside option probability?

### Upper Confidence Bound (UCB) for Bandits
- **Why needed**: ONL-MNL builds optimistic estimates by adding a confidence bonus to current utility predictions, a hallmark of UCB. The bonus arises from a confidence set in parameter space and depends on feature gradients and the design matrix. Understanding the classic linear UCB explains how the algorithm generalizes to non-linear f via gradients.
- **Quick check**: In a linear bandit, UCB = x^⊤ θ̂ + √(β ||x||_{V^{-1}}). How does ONL-MNL replace x with something else? (Answer: It uses the gradient vector ∇f_{ŵt}(x) as the feature in the linearized model.)

### Self-concordant-like functions
- **Why needed**: The loss function in Phase II, after linearization, exhibits a self-concordant-like property that links the distance between parameters to the distance between their gradients. This property is used to argue that if the gradient at ŵt is small relative to Vt, then ŵt is close to the true parameter ẽw, thereby justifying the confidence set.
- **Quick check**: A function ℓ is M-self-concordant-like if its Hessian satisfies ∇^2 ℓ(w1) ⪰ exp(-M||w2-w1||^2) ∇^2 ℓ(w2). How is this used to bound ||w1 - w2||_{∇^2 ℓ(w1)}? (Answer: It allows controlling the local norm of the difference via gradient norms.)

## Architecture Onboarding

### Component Map
ONL-MNL consists of the following interacting components:
- Uniform exploration in Phase I produces pilot data.
- Regression oracle computes pilot estimate ŵ0 from Phase I data.
- In Phase II, per-round: (1) optimize ŵt using regularized linearized loss; (2) compute gradients for all items; (3) compute optimistic utilities zti; (4) maximize \tilde{R}_t(S) to pick St; (5) update Vt with gradients from St.
- Confidence radius βt and matrices Vt flow from updates; βt depends on t, dw, κ, μ; Vt scales with λ and cumulative gradient outer products.
- The final output is the sequence of assortments St.

### Critical Path
The most critical and computationally intensive step in each Phase II round is the optimization of ŵt, which involves minimizing a potentially non-convex regularized loss over parameter space w. This step's complexity is O(t) per round if using gradient-based methods, and it must be completed before computing gradients and bonuses. Delays here directly impact overall runtime. Secondary critical steps include gradient computation for all N items (O(N dw)) and assortment optimization (O(N) for top-K, but could be heavier for general K).

### Design Tradeoffs
- **Phase I length t0**: Larger t0 yields a more accurate pilot ŵ0 but consumes more exploration rounds, increasing regret. The paper sets t0 = ⌈κ^{-3/2} dw √T⌉ to balance.
- **Regularization λ**: Larger λ reduces the linearization error term (βt Ch/λ) but increases the condition number of Vt, enlarging the sqrt bonus term. The optimal scaling is λ = Õ(√T).
- **Confidence radius βt**: Must be large enough to cover estimation error but small enough to keep bonuses modest. It scales as Õ(1) but depends on μ^{-2} κ^{-4} dw; if κ is small, βt grows, potentially inflating regret.
- **Linearity vs optimism**: For linear utilities (Ch=0), the constant correction disappears, making bonuses tighter. For non-linear f, the trade-off between λ and Ch becomes delicate.
- **Assortment optimization**: Efficient algorithms exist for MNL-based reward maximization (e.g., dynamic programming for nested logit, greedy for submodularity). However, with large N, even O(N) evaluations may be costly; approximations or pre-selection heuristics might be needed.

### Failure Signatures
- **Pilot estimate failure**: Monitor min_{ẽw∈W*} ||ŵ0 - ẽw||^2. If it does not decay as 1/t0, the geometric condition may be violated or t0 too small. This likely causes the confidence set to lose coverage later.
- **Confidence set under-coverage**: Track min_{ẽw∈W*} ||ŵt - ẽw||_{Vt}. If it exceeds βt at any t, the induction breaks; possibly λ too small or t0 insufficient.
- **Excessive linearization error**: Compute the term βt Ch/λ; if it remains large (e.g., > 1/sqrt(t)), the constant bonus may dominate, causing linear regret. Adjust λ upward if possible.
- **Gradient explosion**: If gradients ||∇f_{ŵt}(x_{ti})|| exceed the assumed bound Cg, the elliptical potential argument fails; monitor max gradient norm.
- **Non-convex convergence failure**: If the loss minimization for ŵt does not converge to a stationary point within a reasonable tolerance, the estimates may be unreliable; consider more iterations or better initialization.

### First 3 Experiments
1. **Realizability (Gaussian)**  
   Setup: True utility from a two-layer neural network with sigmoid activations; contexts i.i.d. Gaussian; N=500; T=1000.  
   Result: ONL-MNL cumulative regret ≈30, while linear baselines (UCB-MNL, TS-MNL, OFU-MNL+) exceed 50. Demonstrates ability to capture nonlinearities.
2. **Misspecification (Gaussian)**  
   Setup: True utility f_{w*}(x) = cos(2π(x^⊤ w*)) - 0.5 x^⊤ w*; estimator uses neural network class.  
   Result: ONL-MNL still achieves low regret ≈40, while linear baselines fail (regret >80). Shows robustness to model mismatch.
3. **Scalability in N**  
   Setup: Vary N ∈ {100, 200, 400, 800}; Gaussian contexts; realizable setting; T=500.  
   Result: ONL-MNL regret increases modestly (30 → 38), whereas ε-greedy baseline from [41] shows steep increase (50 → 90). Confirms theoretical N-independence.

## Open Questions the Paper Calls Out

1. **Reducing dependence on κ**  
   - **Question**: How can the instance-specific constant κ be eliminated or reduced in the regret bound?  
   - **Basis**: Concluding section identifies κ-dependence as a key limitation.  
   - **Why unresolved**: Current analysis tightly couples the bound with κ via geometric conditions and confidence radius; new techniques may be required.  
   - **Evidence to resolve**: Develop a novel analysis that decouples κ, or a lower bound proving its necessity.

2. **Extension to MNL MDPs**  
   - **Question**: Can ONL-MNL be extended to infinite-horizon MDPs with MNL transition kernels and non-linear utilities?  
   - **Basis**: Paper suggests this as a promising direction.  
   - **Why unresolved**: MDPs introduce sequential decision-making, unknown transitions, and long-term credit assignment, complicating the bandit-style analysis and algorithm design.  
   - **Evidence to resolve**: A provably efficient algorithm with Õ(√T) or similar regret for non-linear MNL MDPs.

3. **Theoretical guarantees under misspecification**  
   - **Question**: What are the regret bounds when the true utility lies outside the assumed function class?  
   - **Basis**: Experiments show robustness, but theory assumes realizability (Assumption 1).  
   - **Why unresolved**: Misspecification invalidates the equivalence set and the geometric condition; errors may accumulate differently.  
   - **Evidence to resolve**: A refined analysis that bounds regret in terms of the best-in-class approximation error and shows robustness to small distribution shifts.

## Limitations
- Theoretical guarantees rely on strong assumptions (realizability, boundedness, stochastic Phase I contexts, and a generalized geometric condition). Violations in real-world data could significantly degrade performance.
- The problem-specific constants (κ, μ, τ) are not explicitly bounded and may be very small or large, making the theoretical Õ(√T) bound loose in practice.
- The algorithm requires solving a non-convex optimization for ŵt in each round; while the theory assumes convergence to the global optimum, practical implementations may get stuck in local minima, especially with complex neural network utilities.

2. **Test λ and t0 sensitivity**: Vary λ around the recommended Õ(√T) scaling and the Phase I length t0. Monitor the size of the constant term βt Ch/λ and the cumulative regret to validate the theoretical choices.
3. **Assess robustness under non-i.i.d. Phase I**: Introduce covariate shift or adversarial contexts during Phase I. Track the pilot estimation error and overall regret to evaluate the necessity of the i.i.d. context assumption (Assumption 3).
