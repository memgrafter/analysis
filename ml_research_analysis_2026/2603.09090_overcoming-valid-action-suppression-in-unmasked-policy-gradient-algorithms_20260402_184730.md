# Overcoming Valid Action Suppression in Unmasked Policy Gradient Algorithms

## Quick Facts
- **ArXiv ID:** 2603.09090
- **Source URL:** https://arxiv.org/abs/2603.09090
- **Reference count:** 40
- **Primary result:** Feasibility classification with KL-balanced loss enables deployment without oracle masks with only ~2% performance loss (e.g., 43.2 vs 43.9 return).

## Executive Summary
In discrete-action reinforcement learning with state-dependent validity (e.g., certain actions are illegal in particular states), standard unmasked policy gradient training suffers from *valid action suppression*. Gradients that reduce the probability of invalid actions at visited states propagate through shared network parameters to unvisited states where those same actions are valid, causing an exponential decay in their probabilities. Oracle masking (zeroing invalid actions during training) prevents this but entangles the state representation, making the policy depend on the oracle at deployment. This paper introduces *feasibility classification*: an auxiliary task that predicts action validity using a KL-balanced classification loss. This loss weights each state-action pair by the KL divergence between the oracle-masked policy and a policy using predicted masks, prioritizing errors that most affect the current policy distribution. Training still uses oracle masks for stability; at deployment, the learned predictor replaces the oracle. Across Craftax, Craftax-Classic, and MiniHack, the method reduces the feature correlation between valid and invalid states from ~0.8 to ~0.4, prevents suppression, and achieves near-oracle performance with only a ~2% drop, doubling the performance of prior focal-loss approaches.

## Method Summary
The method augments a PPO agent with per-action binary classifiers on top of a shared encoder. During training, the policy uses ground-truth validity masks (oracle masking) to avoid invalid actions. The classifiers predict validity ν̂(s,a) from the encoder output ϕ(s). A KL-balanced classification loss weights each example by w_a(s) = π(a|s)·|log π_oracle(a|s) − log π_pred(a,s)|, which measures how much the policy distribution would change if that action's validity were mispredicted. This focuses the classifier on state-action pairs critical to the current policy. After training, the policy is deployed using the predicted masks (thresholded at 0.5) instead of the oracle, removing the dependency on ground-truth validity functions. Key hyperparameters: auxiliary loss weight λ=10, focal modulation γ=2.0.

## Key Results
- Suppression is proven for linear softmax policies under a feature alignment condition; empirical measurements confirm deep networks exhibit this condition (correlation ~0.8).
- Oracle masking prevents suppression but maintains high feature correlation (~0.8), causing catastrophic failure when the oracle is removed at deployment.
- Feasibility classification with KL-balanced loss reduces correlation to ~0.4, enabling deployment with only ~2% performance loss versus oracle-masked training and outperforming focal loss by 2×.

## Why This Works (Mechanism)
**Mechanism 1: Valid Action Suppression via Parameter Sharing**  
Gradients that decrease the probability of an invalid action at visited states propagate through shared network parameters (e.g., encoder) to unvisited states where that action is valid. Under linear softmax policies, the per-step decay rate of π(a|s*) is proportional to the feature correlation ϕ(s*)ᵀ·E[c(s)ϕ(s)], where c(s) is advantage-weighted. Cumulative suppression yields an exponential bound π(a|s*) ≤ e^{-KT}/n. This requires (i) a dominance gap (invalid actions are suboptimal at visited states) and (ii) feature alignment (ϕ(s*) correlates with the gradient direction). Empirical feature correlation of ~0.8 confirms alignment, explaining observed suppression.

**Mechanism 2: Masking-Induced Representational Entanglement**  
Oracle masking excludes invalid actions from policy updates, so the encoder receives no gradient signal that would force it to distinguish states where an action is valid from those where it is invalid. Consequently, states with similar raw observations but different validity (e.g., a corridor vs. a staircase) map to nearby feature vectors. This entanglement preserves high feature correlation (~0.8) throughout training, so when the oracle is removed at deployment, suppression resumes because the shared representation still conflates valid and invalid cases.

**Mechanism 3: KL-Balanced Classification for Validity-Aware Representations**  
The auxiliary classifiers are trained with a loss weighted by the KL divergence between the oracle-masked policy and the policy using predicted masks. This weight prioritizes classification errors on state-action pairs that would most distort the policy distribution if mispredicted. The resulting gradient signal explicitly encourages the encoder to produce features that separate valid from invalid states, reducing their correlation to ~0.4. At deployment, the accurate classifiers cleanly substitute the oracle, avoiding suppression and maintaining performance.

## Architecture Onboarding
Encoder -> Policy Head, Value Head, Classification Heads. The shared encoder ϕ(s) (e.g., Transformer-XL+S5, GRU, or MLP) outputs a feature vector. This feeds into: (1) linear policy logits per action, (2) value head, and (3) one linear classifier per action (with sigmoid) predicting ν̂(s,a). During training, the policy uses oracle masks: softmax(exp(logit)·ν_oracle). The KL-balanced classification loss uses predictions from the classifiers. At deployment, predicted masks (ν̂ > 0.5) replace oracles.

Critical path: State s -> encoder ϕ(s) -> produces policy logits (masked by oracle) and validity predictions. KL weights computed from oracle and predicted policies scale the classification loss.

Design tradeoffs: Compute overhead is modest (O(|A|·d) parameters). Stability: Oracle masks during training ensure correct gradients; classifier accuracy is critical for deployment. Loss weighting: λ controls auxiliary strength; high λ may conflict with policy gradients.

Failure signatures: High feature correlation (~0.8) between valid/invalid states indicates ineffective classifier; low validation accuracy on rare actions (<95%) predicts poor deployment; suppression curve matching unmasked baseline shows classifier not mitigating interference.

First 3 experiments:  
1. Suppression measurement: Train unmasked PPO; track π(rare_action | valid_state) over frames; expect exponential decay to near zero.  
2. Feature correlation: For a target action, compute Pearson r between encoder representations on states where it is valid vs invalid; compare Masked vs Masked+KL; expect reduction from ~0.8 to ~0.4.  
3. Deployment test: After Masked or Masked+KL training, evaluate with predicted masks; Masked alone should collapse (return ~−0.9), Masked+KL should match oracle-masked (~43 vs 44); Focal loss should underperform.

## Open Questions the Paper Calls Out
- How does joint optimization of the state representation ϕ(s) and policy parameters affect the exponential suppression bound derived under fixed features?
- Can we eliminate the train-deploy distribution shift by training the policy entirely with predicted masks, thereby achieving performance comparable to oracle-masked training while remaining deployable without an oracle?
- How robust is feasibility classification to noise or incompleteness in the ground-truth validity labels used during training?
- Does valid action suppression occur in continuous action spaces or with raw pixel observations, and can feasibility classification be adapted to these settings?

## Limitations
- Theoretical analysis assumes linear softmax policies and fixed features; joint feature-policy dynamics may alter suppression behavior.
- Hyperparameter choices (λ=10, γ=2) lack comprehensive sensitivity analysis; robustness to different values is uncertain.
- Evaluation restricted to symbolic-observation domains with moderate action counts (11–43); scalability to high-dimensional visual inputs or huge action spaces remains unproven.
- Requires very high classifier accuracy (~99%) for successful deployment; performance under distribution shift or sparse state coverage is unexplored.

## Confidence
- Suppression mechanism & exponential decay: **High** (formal proof provided; strong empirical correlation ~0.8 matches condition).
- Masking-induced entanglement: **Medium** (high correlation observed, but causal link to encoder gradients is inferred).
- KL-balanced classification effectiveness: **Medium** (consistent gains across domains, but limited ablations on loss weighting and potential overfitting).
