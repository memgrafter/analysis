# Assessing Deanonymization Risks with Stylometry-Assisted LLM Agent

## Quick Facts
- arXiv ID: 2602.23079
- Source URL: https://arxiv.org/abs/2602.23079
- Reference count: 33
- Primary result: SALA (stylometry-assisted LLM agent) achieves F1-score 0.827 in targeted attacks and top-3 prediction rate 0.224 in open-world attacks; guided recomposition reduces attack success to 0.561 (targeted) and 0.012 (open-world).

## Executive Summary
This paper examines deanonymization risks posed by LLM-based authorship inference in news articles. It introduces SALA, an agent framework that combines quantitative stylometric features with LLM reasoning to perform robust and interpretable authorship attribution. The system incorporates a database module for candidate aggregation and embedding-based search, boosting accuracy. On targeted attacks (500 samples per candidate), SALA attains an F1-score of 0.827; in open-world settings, it yields a top-3 prediction rate of 0.224. The authors also propose a guided recomposition defense, which uses the agent's reflection on influential stylistic features to rewrite texts, slashing attack success to 0.561 (targeted) and 0.012 (open-world) while preserving semantic meaning.

## Method Summary
The authors evaluate an LLM agent for authorship attribution and anonymization on English news datasets (All the News 2.0, CrossNews). The pipeline comprises four stages: (1) Information Extraction (LLM extracts article metadata), (2) Candidate Search (via web search or a pre-populated database using embedding/keyword similarity), (3) Candidate Matching—SALA—where stylometric features (lexical, syntactic, readability, semantic, style) are extracted from target and candidate texts and fed to an LLM for pairwise similarity judgment, and (4) Result Reflection, where the LLM identifies the most influential features for attribution. A Database Module stores aggregated author profiles, and an Anonymization Enhancer generates rewrite prompts based on reflection to produce anonymized text. The system uses GPT‑4.1; success is measured by F1-score (targeted) and top‑3 prediction rate (open-world). Defense effectiveness is quantified by reduction in these metrics after guided recomposition.

## Key Results
- SALA with database augmentation: F1‑score 0.827 (targeted attacks, 500 samples per candidate).
- SALA open‑world performance: top‑3 prediction rate 0.224.
- Guided recomposition mitigation: reduces attack success from 0.827 to 0.561 (targeted) and from 0.156 to 0.012 (open-world).

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** SALA improves authorship inference accuracy by grounding LLM reasoning in quantitative stylometric features, reducing hallucination and increasing precision compared to pure LLM-based or embedding similarity analysis.
- **Mechanism:** The system extracts a predefined set of stylometric features (lexical, syntactic, readability, semantic, style) from both target and candidate texts using deterministic tools (e.g., NLTK) and LLM queries. These numerical and qualitative descriptors are structured into a prompt that guides the LLM's pairwise comparison, forcing the model to base its judgment on explicit, interpretable metrics rather than ungrounded style impressions.
- **Core assumption:** The selected stylometric features capture discriminative authorial signals that are stable across an author's texts and that the LLM can synthesize logically when provided with concrete data points.
- **Evidence anchors:**
  - [abstract] "integrates quantitative stylometric features with LLM reasoning for robust and transparent authorship attribution."
  - [section 3.3] "This structured prompting strategy grounds the model’s reasoning in explicit, interpretable metrics while retaining its ability to synthesize qualitative insights."
  - [corpus] Weak direct anchor; neighboring papers discuss stylometry and LLMs but do not evaluate this specific hybrid integration. Assumption: the feature set is sufficiently expressive for news article domains.
- **Break condition:** If the target domain produces highly homogeneous stylometric distributions across authors (e.g., all texts adhere to a rigid house style), the features lose discriminative power, and the LLM's reasoning may still default to hallucination or bias despite the grounding.

### Mechanism 2
- **Claim:** Database augmentation significantly boosts candidate search coverage and matching robustness by pre-aggregating author profiles from multiple samples, enabling efficient similarity search and stable feature representation.
- **Mechanism:** A warm-up phase populates a database with candidate authors and their pre-processed writing samples. Candidate search then uses embedding and keyword similarity within this database instead of costly, unreliable web searches. For matching, stylometric features are aggregated across all stored samples for each author, creating a consolidated profile that is compared against the target article, reducing noise from single-sample variability.
- **Core assumption:** An author's stylistic profile stabilizes with a moderate number of samples (the paper suggests ~300), and a pre-populated database with embedding-based retrieval can accurately surface relevant candidates without full web search.
- **Evidence anchors:**
  - [abstract] "SALA, particularly when augmented with a database module, achieves high inference accuracy."
  - [section 3.5] "the search stage is much more efficient... Finding related authors is also much more accurate with keyword and embedding similarity search within the database."
  - [section 4.3] Table 2 shows candidate inclusion rates jumping from 1.2% (20 candidates, zero-shot) to 78.1% (DB-augmented).
- **Break condition:** If the initial database is severely skewed (missing whole sub-genres or author demographics) or if an author's style varies drastically across contexts not represented in the stored samples, the aggregated profile becomes unrepresentative, and search recall suffers.

### Mechanism 3
- **Claim:** Guided recomposition, informed by the agent's result reflection on influential features, effectively reduces authorship identifiability by prompting targeted text modifications that obscure style while preserving semantics.
- **Mechanism:** The Result Reflection stage identifies the stylometric features most indicative of the inferred author (e.g., high lexical hapax legomenon ratio, specific syntactic patterns). The Anonymization Enhancer converts these insights into concrete rewriting instructions (e.g., "diversify sentence length," "replace domain-specific jargon"). An LLM then rewrites the original text following these prompts, aiming to alter the identified signals.
- **Core assumption:** The agent's attribution reasoning correctly pinpoints the features that are genuinely responsible for its own correct identification, and modifying those features will disrupt the author's stable fingerprint without altering the core meaning.
- **Evidence anchors:**
  - [abstract] "guided recomposition strategy... effectively reducing authorship identifiability while preserving textual meaning."
  - [section 3.6] "recommend targeted modifications designed to reduce re-identifiability... The module can directly provide a guided recompose."
  - [section 5] Table 8 shows attack success dropping from 0.827 to 0.561 (targeted) and 0.156 to 0.012 (open-world) after guided recomposition.
- **Break condition:** If the reflection process misattributes the source of identifiability (e.g., focuses on irrelevant features), the rewrite will be ineffective. Furthermore, aggressive stylistic changes may degrade semantic utility or introduce unnatural text, violating the preservation goal.

## Foundational Learning
- **Concept: Stylometry**
  - **Why needed here:** SALA's core innovation is the integration of quantitative stylometric features (e.g., type-token ratio, average sentence length) into LLM prompting. Understanding what these metrics measure and why they can be author-specific is fundamental to grasping the agent's inference mechanism.
  - **Quick check question:** What does a high hapax legomenon ratio typically indicate about an author's vocabulary usage?
- **Concept: LLM Agent Architecture (Core, Planning, Tools, Memory)**
  - **Why needed here:** The paper's system is explicitly framed as an LLM agent using tool execution (web search, Python feature extraction) and a memory module (database). The pipeline stages (extraction, search, matching, reflection) map onto this architecture.
  - **Quick check question:** In this agent, what component corresponds to the "Database Module" and what role does it play?
- **Concept: Authorship Attribution Attack Scenarios (Targeted vs. Open-World)**
  - **Why needed here:** The evaluation framework defines two fundamentally different threats. Understanding the distinction (known suspect list vs. open pool) is critical for interpreting the reported performance metrics and the real-world risk assessment.
  - **Quick check question:** Why is open-world attack intrinsically harder than targeted attack, even with a perfect matching method?

## Architecture Onboarding
- **Component map:** Information Extraction -> Candidate Search (Web or Database) -> SALA Candidate Matching (per candidate) -> Result Reflection -> Anonymization Enhancer -> Guided Recompose. Parallel: Database Module (stores author profiles, serves search & matching). Tools: Web search, NLTK for feature extraction, LLM for reasoning.
- **Critical path:** Metadata from target article -> populate candidate list (via DB or web) -> for each candidate, extract target features and candidate aggregated features -> SALA pairwise comparison LLM prompt -> aggregate pairwise scores -> top-1 selection -> result reflection identifies influential features -> anonymization enhancer formulates rewrite instructions -> LLM rewrites article.
- **Design tradeoffs:** 
  - Database size vs. bias: Larger DB improves coverage but may embed representational skew.
  - Feature richness vs. cost: More stylometric features enhance discriminative power but increase extraction and prompt complexity.
  - Rewrite intensity vs. utility: Stronger anonymization may distort meaning or readability.
- **Failure signatures:**
  - Low candidate inclusion rate (<50% with 20 candidates) indicates poor search coverage.
  - SALA yields near-random F1 (~0.5) with few samples per author, suggesting insufficient profile aggregation or ineffective feature set.
  - Guided recomposition produces low semantic similarity to original (utility loss) or fails to lower attack success (ineffective anonymization).
- **First 3 experiments:**
  1. **SALA Ablation:** Compare targeted attack accuracy of SALA against embedding similarity (ES) and LDA baselines, varying sample count per candidate; expect SALA to outperform.
  2. **DB Warm-up Impact:** Measure candidate inclusion rate as database size grows; expect sharp initial rise then plateau.
  3. **Mitigation Efficacy:** Run attacks on original vs. paraphrased (baseline) vs. guided recomposed text; compare attack success reductions to validate reflection-to-action loop.

## Open Questions the Paper Calls Out
- **Generalization across languages and genres:** The evaluation is limited to English news articles. Performance on social media, academic writing, and multilingual corpora remains unknown.
- **Quality of guided recomposition:** The current rewrite strategy may degrade stylistic nuance and overall text quality. Adaptive prompting or human-in-the-loop refinement could improve the trade-off between anonymity and preservation.
- **Database bias and fairness:** Uneven sample counts per author in the database may introduce bias. Techniques for balancing or dynamically updating profiles are needed to ensure equitable inference accuracy.

## Limitations
- Key implementation details (prompts, database schema, embedding model) are not disclosed, impeding exact replication.
- The approach’s reliance on GPT‑4.1 and the assumption of stable stylometric signals limit applicability to other LLMs or domains with homogenized styles.
- Guided recomposition’s semantic fidelity is not thoroughly evaluated, and residual attack success (0.561 targeted) indicates incomplete mitigation.

## Confidence
- **Mechanism 1 (SALA grounding):** Medium – relies on chosen features and LLM synthesis; evidence is indirect.
- **Mechanism 2 (Database augmentation):** High – empirical candidate inclusion jump (1.2% → 78.1%) strongly confirms benefit.
- **Mechanism 3 (Guided recomposition):** Medium – reduction is clear, but semantic preservation remains unverified.

## Next Checks
- Conduct prompt variation studies to test SALA's sensitivity to alternative phrasings and ensure robustness.
- Perform database diversity ablations (e.g., by author demographics or topics) to quantify bias and establish minimal representational requirements.
- Evaluate semantic integrity of rewritten texts via embedding similarity metrics (e.g., BERTScore) and human assessment to validate guided recomposition's utility preservation.
