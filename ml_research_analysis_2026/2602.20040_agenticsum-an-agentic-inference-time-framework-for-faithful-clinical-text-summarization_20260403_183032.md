# AgenticSum: An Agentic Inference-Time Framework for Faithful Clinical Text Summarization
## Quick Facts
- arXiv ID: 2602.20040
- Source URL: https://arxiv.org/abs/2602.20040
- Reference count: 40
- Primary result: AgenticSum significantly reduces hallucination in clinical summarization; with Llama-3.2-3B, BLEU-2 improved from 7.17 to 12.61 and BERTScore from 81.90 to 84.50 vs. vanilla LLM; human evaluation showed mean severity drop from ~3.9 to ~2.0.

## Executive Summary
AgenticSum is an inference-time framework that addresses factual hallucination in clinical text summarization by decomposing the task into coordinated stages: context compression, draft generation, grounding analysis, and supervised targeted correction. It leverages an attention-based signal (AURA) to detect unsupported content and a supervisory agent to control iterative revision. Evaluated on MIMIC-IV discharge summaries using Llama-3.2-3B, AgenticSum improved lexical similarity (BLEU-2 from 7.17 to 12.61) and semantic similarity (BERTScore from 81.90 to 84.50) over a vanilla LLM baseline. LLM-as-a-judge and human evaluations confirmed a substantial reduction in hallucination severity, with mean scores dropping from ~3.9 to ~2.0 and effect sizes exceeding 0.80. Ablation studies identified post-generation correction and supervisory refinement as critical components.

## Method Summary
AgenticSum operates at inference time using a frozen pretrained language model (e.g., Llama-3.2-3B) without any fine‑tuning. The framework consists of five agents orchestrated in a loop: (1) FocusAgent compresses the input clinical document by selecting the top‑k sentences based on aggregated decoder self‑attention scores (β_j), retaining a configurable proportion r of the original text. (2) DraftAgent generates an initial summary from the compressed input via zero‑shot instruction. (3) HallucinationDetectorAgent identifies potentially unsupported spans: it computes token‑level AURA scores (the proportion of attention weight directed to source tokens) and aggregates them to span‑level a_j; simultaneously, an LLM‑based entailment prompt yields binary labels h_j. Spans with a_j below a threshold τ or h_j = 1 are flagged. (4) FixAgent rewrites only the flagged spans, preserving the rest of the summary. (5) ClinicalSupervisorAgent monitors the mean span‑level AURA (¯A) and the set of hallucinated spans H; it halts the iteration when the change in ¯A falls below tolerance ϵ, when H stabilizes (H(t) \ H(t‑1) = ∅), or when a maximum step count T_max is reached. This agentic decomposition isolates factual verification and correction, enabling the base LLM to produce faithful summaries without altering its parameters.

## Key Results
- Relative to vanilla LLM, AgenticSum (Llama-3.2-3B) increased BLEU‑2 (7.17 → 12.61) and BERTScore (81.90 → 84.50) on MIMIC‑IV‑Ext‑BHC discharge summaries.
- LLM‑as‑a‑judge hallucination scores decreased (2.11±0.67 → 1.88±0.42); human evaluation across three domains showed mean hallucination severity dropping from ~3.9 to ~2.0 (rank‑biserial effect size >0.80).
- Ablation studies demonstrated that removing either the FixAgent (post‑generation correction) or the ClinicalSupervisorAgent (iterative supervision) significantly degraded performance, confirming their essential roles.

## Why This Works (Mechanism)
**Mechanism 1: Staged Decomposition**  
Claim: Decomposing summarization into separate, coordinated stages (context compression, draft generation, verification, targeted correction) reduces hallucination by isolating and correcting unsupported content without altering the base model.  
Mechanism: FocusAgent compresses input to task‑relevant sentences, reducing noise. DraftAgent generates an initial summary without fidelity constraints. HallucinationDetectorAgent identifies weakly supported spans using semantic entailment and attention‑based grounding (AURA). FixAgent revises only flagged spans. ClinicalSupervisorAgent governs termination based on grounding stability and span set changes.  
Core assumption: Hallucinated content can be reliably identified post‑generation via combined signals and corrected in isolation without degrading overall summary fluency or necessitating model retraining.  
Evidence: Framework specification in the paper and ablation results showing staged design contributes to performance.

**Mechanism 2: Attention‑Based Grounding (AURA)**  
Claim: The AURA signal, aggregating decoder self‑attention to source tokens, provides a lightweight, token‑level indicator of factual grounding that helps localize hallucinated spans for targeted correction.  
Mechanism: For each generated token, AURA computes the proportion of attention weights allocated to source document positions. Span‑level scores are averaged over tokens in a summary sentence. Low scores indicate weak source reliance, flagging the span for revision.  
Core assumption: Decoder self‑attention distributions correlate with the model’s reliance on source content during generation; deviations (low source attention) predict unsupported statements.  
Evidence: Formal definition in Section 3.3; combined with entailment, it contributes to improved BERTScore and reduced hallucination scores in Section 4.5.

**Mechanism 3: Supervised Iterative Refinement**  
Claim: Supervised iterative refinement, governed by the ClinicalSupervisorAgent, prevents unconstrained self‑correction and ensures termination only when grounding stabilizes or no new hallucinations appear, balancing correction effort with diminishing returns.  
Mechanism: At each iteration, the supervisor computes mean span‑level AURA (¯A) and compares it to the previous step (tolerance ϵ). It also checks if the set of flagged spans (H) has changed. Refinement halts if |Δ¯A| < ϵ, or if H stabilizes, or upon reaching a max step budget.  
Core assumption: Aggregate grounding metrics converge as hallucinations are corrected; further iteration yields negligible improvement or risks over‑correction.  
Evidence: Ablation showing the supervisor’s critical role; the paper’s termination logic in Section 3.4.

## Architecture Onboarding
**Component map**  
FocusAgent → DraftAgent → [HallucinationDetectorAgent → FixAgent → ClinicalSupervisorAgent] → (loop until halt) → Output

**Critical path**  
1. FocusAgent compresses the input document.  
2. DraftAgent generates an initial summary.  
3. HallucinationDetectorAgent flags unsupported spans (using AURA and entailment).  
4. FixAgent revises the flagged spans.  
5. ClinicalSupervisorAgent decides whether to continue iteration or halt.  
6. Loop returns to step 3 or outputs the final summary.

**Design tradeoffs**  
- Fixed LLM vs. fine‑tuning: Uses pretrained model without task‑specific adaptation for deployment simplicity and generality, but may underutilize domain knowledge.  
- Sentence‑level (FOCUS) vs. token‑level filtering: Sentences preserve clinical semantics (negation, context) but may retain irrelevant sentences; token‑level could be more precise but risk breaking clinical meaning.  
- Attention‑based (AURA) vs. pure entailment: AURA is lightweight and token‑level but correlates imperfectly with factuality; entailment is precise but slower and may be binary/coarse. Hybrid aims to balance.  
- Supervised loop vs. single correction: Iteration improves correction but adds latency; supervisor prevents infinite loops.

**Failure signatures**  
- High hallucination in final output despite FixAgent: AURA threshold τ mis‑set, entailment prompt ineffective, or FixAgent not correcting properly.  
- Supervisor halting too early: ϵ too large or H(t) stabilizing prematurely (e.g., AURA scores plateau but factual errors remain).  
- FOCUS removing critical context: Salience scoring (β_j) overlooks clinically key sentences (e.g., due to low decoder self‑attention on templated but vital sections).  
- Fluency degradation after FixAgent: Overly aggressive rewriting of flagged spans disrupts coherence.

**First 3 experiments**  
1. **Ablation study**: Systematically remove FOCUS, then FixAgent, then supervisor (as in Appendix D) to quantify each component's contribution to BLEU/BERTScore and LLM‑as‑a‑judge hallucination scores.  
2. **AURA threshold sweep**: Vary τ (e.g., 0.1 to 0.9) on a validation set to find the optimal balance between false positive (over‑correction) and false negative (missed hallucination) flags.  
3. **Supervision condition test**: Compare full supervisor logic against fixed‑iteration baselines (e.g., always 3 revisions) to validate the convergence criteria (Δ¯A, H‑set stability) in reducing unnecessary revisions.

## Open Questions the Paper Calls Out
1. How does the AURA attention‑based grounding signal perform on detecting hallucinations that do not manifest as attention dispersion or reduced source reliance, such as subtle semantic inconsistencies or omitted critical negations? The paper acknowledges this limitation but does not analyze individual failure modes of AURA. Resolution would require a fine‑grained error analysis categorizing hallucination types and measuring detection recall of AURA alone versus the combined system.
2. Are the heuristic termination criteria for the ClinicalSupervisorAgent (based on mean AURA score change ϵ and set stability H(t) \ H(t‑1) = ∅) optimal, or could a learned or adaptive stopping rule improve the trade‑off between correction efficacy and inference latency? The termination thresholds are set values, not learned or systematically optimized. Resolution would involve a systematic parameter sweep and perhaps a learned policy.
3. Does the AgenticSum framework's effectiveness generalize to larger, more capable LLMs (e.g., >7B parameters) and to other specialized clinical document types beyond discharge summaries and SOAP notes (e.g., operative reports, progress notes, radiology reports)? Experiments focused on small and mid‑sized models and two document types; generalizability is untested. Resolution requires re‑running experiments with larger models (e.g., Llama 3.1 70B) and additional annotated datasets.
4. To what extent does the performance gain from AgenticSum depend on the quality and prompt‑engineering of the underlying LLM used for the DraftAgent, HallucinationDetectorAgent (entailment), and FixAgent? Is there a point of diminishing returns where a sufficiently strong base LLM reduces the marginal benefit of the agentic structure? The framework uses a single frozen LLM for all roles, but the interaction between base model capability and framework utility is unexplored. Resolution requires scaling base model size while keeping prompts constant.
5. How does the sentence‑level input compression performed by FOCUS affect the factual completeness of the final summary, particularly for information conveyed across multiple non‑consecutive sentences or in temporally complex narratives? Compression retains top‑k sentences independently, which may discard linking information needed for multi‑sentence facts. Resolution would involve analysis of omitted or distorted multi‑sentence facts, perhaps using a test set with known multi‑hop clinical facts.

## Limitations
- Missing hyperparameter values: exact settings for retention ratio *r*, AURA threshold τ, convergence tolerance ϵ, and max iterations *T_max* are not reported, requiring empirical tuning.
- Undetailed LLM choice for HallucinationDetectorAgent’s entailment step; it may differ from the base LLM, affecting reproducibility and performance.
- Generalizability is limited: evaluations are restricted to MIMIC‑IV discharge summaries and a SOAP dataset; performance on other clinical document types (e.g., operative reports, radiology) or larger LLMs remains unknown.

## Confidence
- Efficacy on MIMIC‑IV (BLEU/BERTScore/hallucination reduction): High
- Decomposition into coordinated stages reduces hallucination: Medium
- AURA as effective grounding signal: Medium
