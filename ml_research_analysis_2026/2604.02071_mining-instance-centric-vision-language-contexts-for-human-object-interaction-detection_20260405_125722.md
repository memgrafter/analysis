# Mining Instance-Centric Vision-Language Contexts for Human-Object Interaction Detection

## Quick Facts
- **arXiv ID:** 2604.02071  
- **Source URL:** https://arxiv.org/abs/2604.02071  
- **Reference count:** 40  
- **Primary result:** InCoM-Net achieves SOTA on HICO-DET (43.96 mAP Full, 45.61 mAP Rare) and V-COCO (73.6/75.4 AP_role), with improvements up to 3.8 AP_role, and sets a new zero-shot benchmark.

## Executive Summary
Human-Object Interaction (HOI) detection aims to identify interactive relationships between humans and objects in images. Recent advances leverage Vision-Language Models (VLMs) for their rich semantic knowledge, but effectively integrating diverse contextual cues remains challenging.

This paper introduces InCoM-Net, an Instance-centric Context Mining framework that extracts multi-granular contexts (intra-instance, inter-instance, global) from VLM features using adaptive masks. These contexts are progressively aggregated with detector features via a Transformer module, complemented by masked feature training to balance contributions. Evaluated on HICO-DET and V-COCO, InCoM-Net surpasses prior state-of-the-art by notable margins and establishes a new zero-shot benchmark, demonstrating the effectiveness of instance-centric context mining.

## Method Summary
InCoM-Net addresses HOI detection by mining instance-specific contexts from VLM features. It employs adaptive masks to extract three types of contexts: intra-instance (within a single human/object), inter-instance (between instances), and global (entire scene). These multi-context features are then aggregated with standard detector features using a Transformer-based module in a progressive manner. Additionally, masked feature training is introduced to prevent over-reliance on any single feature source, encouraging balanced utilization. The framework seamlessly integrates with existing HOI detectors, enhancing their performance without altering the base architecture.

## Key Results
- HICO-DET: 43.96 mAP (Full) and 45.61 mAP (Rare), improving SOTA by 1.03 mAP.
- V-COCO: 73.6 AP_role (Scenario 1) and 75.4 AP_role (Scenario 2), up to 3.8 AP_role improvement.
- Sets new zero-shot benchmark for HOI detection.

## Why This Works (Mechanism)
InCoM-Net succeeds because it explicitly models context at multiple granularities tailored to each instance. Intra-instance context captures fine-grained details within a single human or object, inter-instance context captures relationships between different instances, and global context provides overall scene understanding. By adaptively masking VLM features, the method selects relevant regions for each context type, avoiding noise from irrelevant areas. The progressive aggregation via Transformer allows gradual fusion of these contexts with detector features, preserving spatial and semantic alignment. Masked feature training further ensures that the model does not overly depend on any one context source, leading to robust representations that generalize well, especially to rare interactions.

## Architecture Onboarding
**Component map:** Detection backbone -> Adaptive mask generation -> Context extraction (intra, inter, global) -> Feature aggregation (Transformer) -> Masked training -> HOI classification.

**Critical path:** The detector produces instance proposals; adaptive masks are generated from these proposals; VLM features are masked accordingly to extract contexts; contexts are aggregated with detector features; the combined features are used for final HOI prediction.

**Design tradeoffs:**  
- Adaptive masks rely on detector accuracy; poor detections degrade context quality.  
- Extracting three contexts increases computational cost but yields richer information.  
- Masked training may slow convergence but improves robustness.

**Failure signatures:**  
- Significant performance drop when detector fails (e.g., missing objects, occlusion).  
- Over-reliance on global context leading to false positives in cluttered scenes.  
- Degradation on rare interactions if contexts are not discriminative enough.
