# VQPP: Video Query Performance Prediction Benchmark

## Quick Facts
- arXiv ID: 2602.17814
- Source URL: https://arxiv.org/abs/2602.17814
- Reference count: 40
- Primary result: VQPP introduces a benchmark for video query performance prediction with 56K queries and 51K videos; fine-tuned BERT predictor achieves top correlation (ρ up to 0.41) and, as a reward model in DPO, improves GRAM's Recall@10 by 0.34%.

## Executive Summary
This paper addresses the underexplored task of query performance prediction (QPP) for content-based video retrieval, where no standardized benchmarks or robust methods existed. The authors introduce **VQPP**, a benchmark built from two popular video-text datasets (MSR-VTT and VATEX) totaling 56K text queries and 51K videos. VQPP provides pre-computed retrieval results from two systems (GRAM and VAST) for all queries, along with ground-truth performance scores (Reciprocal Rank and Recall@10) for 112K query–model pairs. This release decouples the expensive retrieval step from predictor development, enabling reproducible evaluation. The empirical study shows that **pre-retrieval predictors**, especially a fine-tuned BERT model, consistently outperform more complex post-retrieval baselines, achieving up to 0.41 Pearson correlation on MSR-VTT/GRAM. Additionally, using the best predictor as a reward model in direct preference optimization (DPO) to steer an LLM toward better query reformulations yields a modest but positive improvement in GRAM’s Recall@10 on MSR-VTT (from 47.28% to 47.62%).

## Method Summary
VQPP is constructed by selecting the MSR-VTT (32,732 queries) and VATEX (18,055 queries) datasets. For each dataset, the authors run two video retrieval systems—GRAM and VAST—to generate text-to-video rankings. They compute standard performance metrics (Reciprocal Rank, Recall@10) and release the top-100 retrieved videos together with the scores. Official training, validation, and test splits are provided for both datasets. The benchmark supports two predictor families: **pre-retrieval** (query-only features, e.g., linguistic cues, fine-tuned BERT, few-shot Llama-3.1) and **post-retrieval** (using top-ranked results, e.g., fine-tuned CLIP/CLIP4Clip, correlation CNN). Performance is measured by Pearson (ρ) and Kendall (τ) correlation between predicted and true scores. The best pre-retrieval predictor (fine-tuned BERT) is then used as a reward model in a DPO pipeline to fine-tune Phi‑4‑mini for query reformulation, with the goal of improving downstream retrieval metrics.

## Key Results
- Fine-tuned BERT predictor achieved the highest correlation (Pearson ρ up to 0.41 on MSR-VTT/GRAM for RR), outperforming all post-retrieval baselines across all four dataset–system combinations.
- Post-retrieval predictors underperformed, which the authors attribute to the one-to-one query-video mapping in the datasets limiting the signal from ranking statistics.
- Using the BERT predictor as a DPO reward model to guide LLM query reformulation improved GRAM’s Recall@10 on MSR-VTT by 0.34% absolute (47.28% → 47.62%).

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** The VQPP benchmark enables reproducible comparison of QPP methods for video retrieval by providing standardized, pre-computed retrieval results and performance annotations.
- **Mechanism:** It decouples the expensive video retrieval step from predictor development by releasing top-100 results and ground-truth performance scores (RR, Recall@K) for 112K query-model pairs across two datasets and two systems. This allows researchers to extract features or train models without re-running retrieval.
- **Core assumption:** The performance of a predictor evaluated on this fixed set of retrieval results generalizes to the underlying video retrieval task.
- **Evidence anchors:**
  - [abstract] "VQPP contains a total of 56K text queries and 51K videos... comes with official training, validation and test splits... release the top-100 retrieval results for all 112K query-model pairs."
  - [section 3.4] "By providing pre-computed retrieval results and performance scores, we enable the development and evaluation of QPP estimators without having to run the heavy retrieval systems."

### Mechanism 2
- **Claim:** Pre-retrieval predictors, particularly fine-tuned BERT, can achieve competitive QPP performance in video retrieval without accessing retrieved results, due to strong semantic cues in natural language queries.
- **Mechanism:** A BERT model fine-tuned on query-to-performance regression learns to map textual query features to expected retrieval scores. It leverages contextual embeddings to capture query complexity, specificity, or concreteness that correlate with system performance.
- **Core assumption:** The difficulty of a video retrieval query is sufficiently encoded in the query text itself, independent of the retrieved video ranking.
- **Evidence anchors:**
  - [section 5.1] "deep pre-retrieval methods demonstrate superior performance... fine-tuned BERT predictor consistently outperforming more complex post-retrieval models."
  - [Table 2] Fine-tuned BERT achieves the highest Pearson/Kendall correlations across all four evaluation scenarios (e.g., 0.40/0.33 on MSR-VTT/GRAM RR).

### Mechanism 3
- **Claim:** A QPP predictor can serve as an effective reward model for query reformulation via preference learning, improving retrieval performance by steering an LLM toward higher-performing queries.
- **Mechanism:** The fine-tuned BERT predictor scores candidate reformulations. In a DPO setup, pairwise preferences (higher-scoring vs. lower-scoring reformulations) are used to update the LLM’s policy, optimizing it to generate queries that the predictor estimates will retrieve better.
- **Core assumption:** The predictor’s estimated performance score is a reliable proxy for actual retrieval improvement when used as a reward signal.
- **Evidence anchors:**
  - [abstract] "employing the best performing pre-retrieval predictor as reward model... via direct preference optimization (DPO)... improved GRAM’s Recall@10 on MSR-VTT from 47.28% to 47.62%."
  - [section 6] Table 5 shows a 0.34% absolute gain in Recall@10, and Figure 3 illustrates reformulations becoming more descriptive.

## Foundational Learning

#### Query Performance Prediction (QPP)
- **Why needed here:** The entire paper revolves around predicting the effectiveness of a retrieval system for a given query without relevance judgments. Understanding QPP’s goal (estimating metrics like RR/Recall) and its pre/post-retrieval distinction is fundamental.
- **Quick check question:** What is the key difference between pre-retrieval and post-retrieval QPP methods in terms of required inputs?

#### Pre-retrieval vs. Post-retrieval Predictors
- **Why needed here:** The paper’s core finding is that pre-retrieval methods (using only the query) outperformed post-retrieval ones (using ranked results) in VQPP. Grasping this dichotomy explains the result analysis and design choices.
- **Quick check question:** Why might post-retrieval predictors underperform on datasets with a one-to-one query-video mapping?

#### Evaluation Metrics for QPP (Pearson & Kendall)
- **Why needed here:** The paper evaluates predictors using correlation coefficients. Understanding that Pearson measures linear relationship magnitude and Kendall measures rank ordering is crucial to interpreting Table 2.
- **Quick check question:** If a predictor has a high Kendall τ but low Pearson ρ, what does that imply about its predictions?

## Architecture Onboarding
Datasets → Retrieval Systems → Pre‑computed results → Predictors → Evaluation; Best predictor → Reward model → DPO → Policy model → Query reformulation → Retrieval check.

1. **Critical path:**
   - Run GRAM/VAST on all queries → retrieve results & compute RR/Recall@10 (ground truth).
   - Split queries into train/val/test.
   - For each predictor: extract features (query-only or from top-25 results) → train model → predict scores on test → compute correlation with ground truth.
   - Use best predictor to generate (winning, losing) query pairs → fine‑tune Phi‑4‑mini with DPO → evaluate retrieval performance on original queries.

2. **Design tradeoffs:**
   - *Pre‑vs. post‑retrieval:* Pre‑retrieval is efficient (no retrieval call) but may lack system‑specific signals; post‑retrieval can model ranking behavior but is computationally heavy and, in VQPP, hampered by one‑to‑one mapping.
   - *Dataset choice:* MSR‑VTT has more descriptive queries; VATEX has shorter, potentially more ambiguous queries, affecting predictor performance.
   - *Reward model selection:* Using the best predictor (BERT) as reward assumes its scoring function aligns with true retrieval gains. A miscalibrated predictor would misguide DPO.

3. **Failure signatures:**
   - Low correlation (ρ, τ < 0.2) on test splits, especially for top‑performing methods like Fine‑tuned BERT.
   - Post‑retrieval predictors performing near random or worse than linguistic baselines.
   - Query reformulation via DPO leading to decreased Recall@10, indicating reward model failure.
   - Significant performance drop from validation to test set, indicating overfitting or split mismatch.

4. **First 3 experiments:**
   - **Benchmark Validation:** Compute baseline correlations for all predictors on the provided test splits (as in Table 2). Confirm pre‑retrieval BERT superiority and post‑retrieval underperformance.
   - **Ablation – Few-shot Shots (k):** For Llama‑3.1‑8B, vary k in {4,8,16} (Table 3). Verify performance scales with more in‑context examples.
   - **Application – DPO Impact:** Train Phi‑4‑mini with DPO using BERT rewards. Compare Recall@10 of GRAM on MSR‑VTT test set before vs. after reformulation (Table 5). Check if gain is statistically significant.

## Open Questions the Paper Calls Out
1. Why do post-retrieval predictors underperform in video QPP with one-to-one query-video mappings, and how can they be redesigned for such settings?
2. How do query linguistic properties (e.g., conciseness, descriptiveness) affect QPP generalizability across diverse video datasets?
3. Does the decoupled benchmark design (pre-computed retrieval results) limit exploration of interactive QPP-retrieval systems?
4. What mechanisms within fine-tuned BERT enable it to outperform post-retrieval and other pre-retrieval predictors in video QPP without access to retrieval results?

## Limitations
- Exact predictor architectures and hyperparameters (BERT regression head, CLIP/CLIP4Clip MLP, correlation CNN) are unreported, hindering exact replication.
- Few-shot Llama‑3.1 implementation details (embedding model, k‑NN prompt, LLM variant) are missing, making results sensitive to design choices.
- The one‑to‑one query‑video mapping in MSR‑VTT/VATEX likely suppresses post‑retrieval signals and limits generalizability to multi‑relevant‑video scenarios.

## Confidence
- Mechanism 1 (Benchmark reproducibility): High
- Mechanism 2 (Pre‑retrieval superiority): Medium
- Mechanism 3 (Predictor as DPO reward): Low
