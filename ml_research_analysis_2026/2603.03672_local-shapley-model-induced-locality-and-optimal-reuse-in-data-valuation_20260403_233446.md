# Local Shapley: Model-Induced Locality and Optimal Reuse in Data Valuation

## Quick Facts
- **arXiv ID:** 2603.03672
- **Source URL:** https://arxiv.org/abs/2603.03672
- **Reference count:** 40
- **Primary result:** Introduces model-induced locality and LSMR/LSMR-A to reduce exact Shapley computations from exponential to near-linear in practice, achieving over 1000× speedup while preserving fidelity to global Shapley values.

## Executive Summary
Data valuation via Shapley values is computationally prohibitive due to exponential coalition enumeration. This paper exploits model-induced locality, where each test instance's prediction depends only on a small support set of training points. By projecting Shapley computation onto these supports, the coalition space collapses dramatically. The authors then propose LSMR, an exact algorithm that canonically reuses model trainings across test points via a bipartite support-mapping graph and pivot scheduling, achieving an information-theoretic lower bound on retraining. For larger supports, LSMR-A extends to Monte Carlo estimation with reuse, remaining unbiased and concentrating exponentially. Empirical results across various models (KNN, trees, kernel SVMs, GNNs) show orders-of-magnitude speedups (e.g., 1,126M to 0.9M trainings) while maintaining high correlation with global Shapley values (up to 0.84 Pearson) and strong downstream data selection accuracy. The work demonstrates that treating Shapley computation as a structured reuse problem yields both theoretical optimality and practical scalability.

## Method Summary
The method consists of three key steps. First, it defines a *support set* \(N(t)\) for each test point \(t\) based on the model's computational pathway (e.g., nearest neighbors for KNN, same-parent leaves for trees, kernel threshold for RBF-SVM, receptive field for GNN). Under exact locality, the utility \(v_t(S)\) depends only on \(S \cap N(t)\), reducing the effective coalition space from all training points to \(N(t)\). Second, it reformulates the Shapley value using a subset-centric expression (Lemma 2), which reduces per-test-point cost from \(|N(t)| \cdot 2^{|N(t)|}\) to \(2^{|N(t)|}\) by evaluating each subset once and updating contributions for all players via deterministic weights. Third, it introduces a *pivot scheduling* mechanism to globally avoid redundant model trainings: for each distinct subset \(S\) that appears across test points, the algorithm trains the model exactly once at the earliest test point \(t^*(S)\) (according to a fixed ordering) and reuses the utility evaluations \(v_t(S)\) for all other \(t\) that also include \(S\) in their support. This is orchestrated via a bipartite graph linking training points and test points through the supports. For exact computation, LSMR enumerates all subsets; for larger supports, LSMR‑A samples subsets via random permutations while maintaining unbiasedness and exponential concentration. The overall complexity is determined by the number of distinct subsets \(|S|\), which in practice is far smaller than the sum of \(2^{|N(t)|}\) due to extensive reuse.

## Key Results
- **Massive computational reduction:** On WKNN, LSMR‑A reduces the number of model trainings from 1,126 million to 0.9 million, a speedup exceeding 1,000×.
- **High fidelity:** Local Shapley values correlate strongly with global Shapley estimates (Pearson \(r\) up to 0.84, Spearman \(\rho\) up to 0.86) and achieve comparable test accuracy in data selection tasks.
- **Scalability across models:** Similar gains observed for decision trees, RBF‑SVMs, and GNNs, with LSMR‑A maintaining unbiasedness and concentration guarantees.

## Why This Works (Mechanism)
### Model-Induced Locality
For a given test instance \(t\), the model's prediction pathway structurally limits influence to a small support set \(N(t)\) (e.g., \(K\) nearest neighbors). This yields exact locality: \(v_t(S) = v_t(S \cap N(t))\), collapsing the coalition space from \(2^{|D|}\) to \(2^{|N(t)|}\). The assumption holds for models with sparse, localized computational graphs (KNN, trees, GNNs). If the model exhibits global parameter coupling (e.g., deep fully‑connected networks), the support may omit influential points, degrading fidelity (Proposition 1).

### Subset-Centric Reformulation
Instead of computing marginal contributions per player, the Shapley value can be expressed as a weighted sum over subsets \(S \subseteq N(t)\) (Lemma 2). Evaluating \(v_t(S)\) once updates contributions for all \(z \in N(t)\) via deterministic weights \(\frac{|S|! (|N(t)| - |S| - 1)!}{|N(t)|!}\) (or their equivalents). This reduces per‑test‑point cost by a factor of \(|N(t)|\), eliminating intra‑support redundancy.

### Pivot‑Based Global Reuse
Across test points, many subsets \(S\) recur. A bipartite support‑mapping graph connects training points \(z\) and test points \(t\) via \(N(t)\) and its reverse \(R(z)=\{t: z\in N(t)\}\). For each \(S\), define its pivot \(t^*(S)\) as the earliest test point (in a fixed order \(\Pi_T\)) whose support contains \(S\). Training \(\theta(S)\) at \(t^*(S)\) and reusing \(v_{t'}(S)\) for all other \(t'\in R_S\) ensures each distinct subset is trained exactly once. This canonicalization attains the information‑theoretic lower bound on retraining (Theorem 1), yielding optimal reuse. LSMR‑A extends this by sampling permutations and conditionally accepting \(S\) only when the current test point is its pivot, preserving unbiasedness and exponential concentration (Theorems 2–3).

## Foundational Learning
- **Concept: Shapley value axioms and permutation interpretation**  
  *Why needed:* The subset‑centric reformulation (Lemma 2) and the unbiasedness of LSMR‑A (Theorem 2) rely on the Shapley value’s definition as the average marginal contribution over all permutations. The weight formula depends on the symmetry and additivity axioms.  
  *Quick check:* For a player set \(N\), what is the Shapley weight for a subset \(S\) of size \(k\)? How does it ensure symmetry among players not in \(S\)?

- **Concept: #P‑hardness of coalition enumeration**  
  *Why needed:* The baseline cost of exact Shapley computation is \(|T|\cdot|D|\cdot2^{|D|}\) because each coalition must be evaluated. Understanding this exponential baseline motivates the entire reduction strategy.  
  *Quick check:* Why does exact Shapley require evaluating \(2^{|D|}\) subsets? How does the training cost per subset factor into the total complexity?

- **Concept: Sampling subsets via random permutations**  
  *Why needed:* LSMR‑A approximates Shapley values by sampling subsets according to the distribution induced by random permutations of \(N(t)\cup\{t\}\). The convergence and variance bounds (Theorems 3, 5) depend on this specific distribution.  
  *Quick check:* When sampling a random permutation of \(N(t)\cup\{t\}\), what is the probability that the sampled subset \(S\) equals a particular subset of size \(k\)?

## Architecture Onboarding
### Component Map
Support Set Constructor -> Bipartite Mapping Builder -> Subset Enumerator -> Pivot Scheduler -> Model Trainer & Utility Evaluator -> Shapley Accumulator

### Critical Path
1. Construct support sets \(N(t)\) for all test points \(t\).
2. Build reverse mapping \(R(z)=\{t: z\in N(t)\}\).
3. Iterate test points \(t\) in fixed order \(\Pi_T\).
4. For each \(t\), enumerate subsets \(S\subseteq N(t)\).
5. For each \(S\), compute \(R_S = \bigcap_{z\in S} R(z)\) and determine pivot \(t^*(S)=\arg\min_{t'\in R_S}\Pi_T(t')\).
6. If \(t = t^*(S)\), train model \(\theta(S)\) and evaluate \(v_{t'}(S)\) for all \(t'\in R_S\); propagate contributions to Shapley accumulators for each \(z\in N(t')\) using Lemma 2 weights.
7. After processing all \(t\), output Shapley values.

### Design Tradeoffs
- **Support size vs. fidelity:** Larger support sets increase \(2^{|N(t)|}\) subsets and distinct subsets \(|S|\), raising computational cost, but reduce approximation error (Proposition 1). Calibration needed.
- **Exact vs. approximate:** LSMR is feasible only for very small supports (e.g., \(K\le 10\)). LSMR‑A scales to larger supports via Monte Carlo sampling but introduces variance.
- **Pivot ordering:** The choice of \(\Pi_T\) affects *which* test point incurs the training cost for each \(S\), but not the final Shapley values. Round‑robin or load‑balancing orders can improve parallel efficiency.

### Failure Signatures
- **Misaligned support:** If \(N(t)\) is constructed from a different model than used for utility evaluation, fidelity drops because true influences are omitted or irrelevant points included (RQ5). Diagnostic: cross‑model support correlation.
- **Low subset reuse:** If supports \(N(t)\) have minimal overlap across test points, the number of distinct subsets \(|S|\) approaches \(\sum_t 2^{|N(t)|}\), eroding reuse gains. Diagnostic: measure average \(|R_S|\) or reuse ratio.
- **Memory overflow:** Storing \(R(z)\) adjacency lists and intermediate utilities for large \(T\) can exhaust memory. Diagnostic: monitor memory usage; consider streaming or batching.
- **LSMR infeasibility:** For \(|N(t)| > 15\), exact enumeration becomes prohibitive. Diagnostic: switch to LSMR‑A.

### First 3 Experiments
1. **Fidelity validation (RQ1):** Compare Local Shapley (LSMR‑A) against global Monte Carlo Shapley on WKNN with exact locality; expect high Pearson \(r\) (≥ 0.8) and tight scatter.
2. **Scaling test (RQ3):** Vary training set size \(|D|\) for WKNN and decision trees; plot LSMR‑A number of trainings and runtime vs. baselines. LSMR‑A should remain nearly constant while global methods grow exponentially.
3. **Support size sweep (RQ4):** For WKNN, vary \(K\) (support size). Measure correlation with global Shapley and number of trainings. Expect correlation to plateau after moderate \(K\) while trainings grow sublinearly due to reuse.

## Open Questions the Paper Calls Out
- **Dynamic/federated extension:** How can LSMR be adapted to settings where data and supports evolve over time (e.g., streaming or federated learning)? The current algorithm assumes a static dataset and fixed supports.
- **Support construction for black‑box models:** For models without inherent locality (e.g., deep fully‑connected networks), how can one construct compact, accurate support sets to enable Local Shapley? The paper only covers models with clear structural locality.
- **Tightening approximation error bounds:** Proposition 1’s error bound depends on potentially loose constants \(\ell_{t,z}(u)\). Can model‑specific analyses yield tighter bounds that better reflect empirical behavior?

## Limitations
- **Fidelity relies on locality assumption:** Models with strong global coupling may violate exact locality, leading to significant approximation error.
- **Support set construction underspecified:** Hyperparameters for support sets (e.g., kernel thresholds, tree depth) are not fully detailed; misconfiguration can break locality or enlarge supports unnecessarily.
- **LSMR‑A’s variance and constant‑time training assumption:** The Monte Carlo variant’s practical variance and the assumption that training cost is constant per subset are not thoroughly validated across diverse models.
