# Conformal Graph Prediction with Z-Gromov Wasserstein Distances

## Quick Facts
- arXiv ID: 2603.02460
- Source URL: https://arxiv.org/abs/2603.02460
- Reference count: 12
- Primary result: A conformal prediction framework using Z-Gromov-Wasserstein distances achieves 90% marginal coverage with a 98.9% median reduction in candidate graph set size on a synthetic image-to-graph task.

## Executive Summary
This paper tackles uncertainty quantification in supervised graph prediction by developing a conformal prediction framework. The core method employs permutation-invariant Z-Gromov-Wasserstein distances, instantiated as Fused Gromov-Wasserstein (FGW), as a nonconformity score to compare predicted graphs against candidate graphs from a library. To handle input-dependent uncertainty, the authors propose Score Conformalized Quantile Regression (SCQR), which adapts the conformal threshold based on features like the size of the candidate set. The approach guarantees marginal coverage on the quotient space of graphs. On a synthetic Coloring dataset, both standard and adaptive versions attain empirical coverage around 90% (90.2% and 90.3%) while shrinking candidate sets by a median of 98.9%.

## Method Summary
The task is to predict a graph from an input image and provide a conformal set of plausible graphs with coverage guarantees. The base predictor is ANY2GRAPH, trained on 100k samples with a permutation-invariant PMFGW loss, achieving ~82% test accuracy. For conformal prediction, candidate sets L(x) are constructed from test graphs sharing the same node color counts as the ground truth, ensuring the true graph is included. The nonconformity score is the Fused Gromov-Wasserstein distance between the predicted graph and each candidate, using adjacency matrix cost and one-hot node features, with Feature Diffusion initialization. In standard CP, a global 90% quantile of calibration scores determines a fixed threshold. In SCQR, the threshold is conditioned on ω(x)=|L(x)|: a linear quantile regressor predicts calibration scores from |L(x)|, and the residual quantile plus this prediction yields an adaptive threshold. During testing, for an input x, candidates with FGW distance ≤ threshold are returned as the conformal set.

## Key Results
- Marginal coverage on test set: 90.2% (CP) and 90.3% (SCQR), matching the nominal 90%.
- Median reduction in candidate set size: 98.9% relative to the full candidate library L(x).
- Both methods achieved low empty-set rates, ensuring practical utility.

## Why This Works (Mechanism)
The Z-Gromov-Wasserstein framework provides a metric on graphs that is invariant to node permutations, aligning with the notion that graphs represent equivalence classes under relabeling. By using FGW—which blends structural (adjacency) and feature (node color) information—the nonconformity score faithfully reflects graph similarity in the task’s relevant aspects. This permutation invariance is crucial for valid exchangeability in conformal prediction. SCQR further tailors the conformal threshold to each input: larger candidate sets often indicate higher uncertainty, and modeling the conditional distribution of scores allows the method to tighten thresholds when appropriate, thereby reducing set size without sacrificing coverage. The theoretical guarantee holds under the assumption that data are exchangeable and candidate sets are complete (the true graph always belongs to L(X)), translating marginal coverage from the calibration distribution to the test distribution on the graph quotient space.

## Foundational Learning
1. **Conformal Prediction** – distribution-free uncertainty quantification with finite-sample coverage guarantees. *Why needed*: Ensures the true graph lies in the output set with probability at least 1-α. *Quick check*: For exchangeable samples, the calibration p-values are uniform, leading to a valid quantile threshold.
2. **Gromov-Wasserstein Distance** – compares metric spaces by aligning pairwise distances, robust to label permutations. *Why needed*: Graphs are naturally represented as metric spaces (via adjacency or shortest paths). *Quick check*: GW distance between two isomorphic graphs with different node orderings is zero.
3. **Fused Gromov-Wasserstein** – extends GW by incorporating node features via a convex combination. *Why needed*: Captures both structure and attributes, essential for graphs with colored nodes. *Quick check*: Vary the feature weight β; distance should smoothly transition between pure GW (β=0) and feature-only Wasserstein (β=1).
4. **Permutation Invariance** – property that a distance metric does not change under node relabeling. *Why needed*: Graphs are defined up to isomorphism; a valid similarity measure must ignore arbitrary node ordering. *Quick check*: Randomly permute the nodes of a graph and recompute its distance to a fixed other graph; the value should be identical.
5. **Quantile Regression** – models the conditional quantiles of a response variable. *Why needed*: In SCQR, predicts the α-quantile of the nonconformity score given a conditioning feature ω(x). *Quick check*: Train a linear QR model; residuals should have zero median and be uncorrelated with ω(x).
6. **Marginal Coverage** – guarantee that P(Y ∈ C(X)) ≥ 1-α over the joint distribution of calibration and test data. *Why needed*: The primary validity requirement for conformal prediction. *Quick check*: On a held-out test set, the empirical coverage should be at least 1-α with high confidence (Clopper-Pearson interval).

## Architecture Onboarding
Component map:
ANY2GRAPH (trained on PMFGW loss) → predicted graph → FGW scorer (adjacency + one-hot features, Feature Diffusion init) → similarity scores to all candidates in L(x) → calibration module (global quantile calculator OR SCQR: linear quantile regressor using |L(x)|) → threshold function ψ(·) + residual quantile → conformal set = {g ∈ L(x) : FGW(pred, g) ≤ threshold}.

Critical path:
1. Train base predictor on training split.
2. For calibration samples: compute FGW scores between predictions and true graphs; store scores and candidate set sizes |L(x)|.
3. Fit global quantile (CP) or train linear quantile regressor on (|L(x)|, score) to obtain ψ(|L(x)|); compute residuals and their 90% quantile.
4. For each test input: build L(x) from test graphs with matching color counts, compute FGW distances to all candidates, apply threshold to select set.

Design tradeoffs:
- **FGW computation**: exact entropic solver is O(n^3) but can be approximated; tradeoff between accuracy and speed. For larger graphs, approximations or alternative Z-GW instantiations may be necessary.
- **Candidate set construction**: Using color counts yields manageable sets but may include many irrelevant graphs; completeness is assumed for coverage.
- **SCQR conditioning**: Using a simple linear model on |L(x)| keeps calibration tractable but may not fully capture heteroscedasticity; richer ω(x) (e.g., graph embeddings) could improve adaptivity at the cost of overfitting.

Failure signatures:
- FGW distance changes after node permutation → indicates non-permutation-invariant implementation.
- Ground truth absent from some L(x) → empirical coverage will fall below nominal regardless of calibration.
- Residuals from SCQR’s linear regression show strong dependence on |L(x)| → threshold mis-specified, leading to under- or over-coverage.
- Mismatch in FGW hyperparameters (β, γ, q) between calibration and test → score distribution shift and invalid thresholds.

First experiments:
1. Permutation invariance test – Implement or obtain the FGW distance, compute it for a random graph and its node‑permuted copies; confirm identical values to validate the permutation‑invariant property.
2. Full pipeline replication – Train ANY2GRAPH on 100k Coloring samples (PMFGW loss), calibrate with 10k, and evaluate test coverage and set‑size reduction using default FGW parameters (β=0.5, γ=0, q=1); check if results match the reported 90.2%/90.3% coverage and 98.9% median reduction.
3. SCQR robustness assessment – Replace the linear quantile regressor with a flexible non‑parametric model (e.g., gradient boosting for quantiles) and examine empirical coverage binned by |L(x)|; any discrepancy would indicate the linear ω(x) assumption may be insufficient.

## Open Questions the Paper Calls Out
**Open Question 1**: How does the computational cost of Z-GW distances scale with graph size, and does the framework remain practical for graphs larger than those used in the experiments? *Basis*: The paper uses ANY2GRAPH restricted to small graphs and evaluates only synthetic graphs without runtime reports on larger graphs. *Why unresolved*: Complexity of Z-GW optimization grows with graph size; no empirical scaling analysis is provided for graphs with >50 nodes. *What evidence would resolve*: Empirical scaling analysis on diverse graph datasets with varying node counts, measuring time and memory for distance calculations and overall conformal set construction while maintaining coverage guarantees.

**Open Question 2**: To what extent does the assumption of complete candidate sets (P(Y ∈ L(X)) = 1) affect the marginal coverage guarantee in real-world applications? *Basis*: The paper acknowledges in Remark 4.9 that coverage degrades by P(Y ∉ L(X)) if candidate sets are incomplete, but assumes completeness in experiments. *Why unresolved*: Real candidate libraries (e.g., metabolite databases) are often incomplete; trade-off between coverage loss and reduction efficiency under incompleteness is not quantified. *What evidence would resolve*: Controlled experiments with artificially incomplete candidate sets, systematically varying the miss probability and measuring actual coverage and set size reduction.

**Open Question 3**: Which instantiation of the Z-GW distance (via choice of Z-space and ω encoding) optimizes the trade-off between conformal set informativity (size) and computational feasibility? *Basis*: The paper uses Fused Gromov-Wasserstein with adjacency and feature diffusion but does not compare other Z-GW variants. *Why unresolved*: The framework allows flexible Z-network definitions, but practical guidance on selecting ω and d_Z for graph tasks is absent; different choices may yield different nonconformity score distributions and thus set sizes. *What evidence would resolve*: Benchmark multiple Z-GW instantiations (e.g., varying edge feature inclusion, distance metrics) on graph prediction tasks, comparing empirical coverage, median set size, and solver runtime.

**Open Question 4**: Can SCQR’s adaptivity be improved by automatically learning the conditioning features ω(x) from data rather than using handcrafted ones like |L(x)| or fixed embeddings? *Basis*: SCQR is evaluated only with ω(x) = |L(x)| or precomputed DREAMS embeddings; the framework permits arbitrary ω but no learning of ω is explored. *Why unresolved*: Handcrafted ω may not fully capture heteroscedasticity in complex graph prediction; learned features could better tailor thresholds to input difficulty. *What evidence would resolve*: Integrate SCQR with representation learning (e.g., train a neural network to predict nonconformity scores directly from input X or predicted graph fθ(X)), and compare set size efficiency against handcrafted ω while preserving coverage.

**Open Question 5**: Does the proposed conformal framework maintain validity and efficiency on real-world graph prediction tasks (e.g., molecular identification from mass spectra) beyond synthetic benchmarks? *Basis*: The introduction mentions molecular identification applications and MassSpecGym, but experiments are limited to a synthetic image-to-graph task (Coloring) without real-world validation. *Why unresolved*: Synthetic tasks may not capture noise, heterogeneity, and candidate set characteristics of real applications; coverage and set size behavior could differ. *What evidence would resolve*: Apply the method to real datasets like MassSpecGym or other molecule identification benchmarks, compare against baseline conformal methods, and report empirical coverage, reduction, and empty-set rates.

## Limitations
- Exact FGW hyperparameters (β, γ, q) and Feature Diffusion initialization are unspecified, which may critically affect distance values and nonconformity scores.
- Node feature encoding (likely one‑hot) and candidate‑set construction details are not fully described; risk of omitting the ground truth or mis‑scoring.
- Validation is limited to a single synthetic dataset; no code release, hindering independent verification; theoretical assumptions (graph exchangeability, quotient space) are unstated.
