# AcTTA: Rethinking Test-Time Adaptation via Dynamic Activation

## Quick Facts
- **arXiv ID:** 2603.26096  
- **Source URL:** https://arxiv.org/abs/2603.26096  
- **Reference count:** 40  
- **Primary result:** AcTTA lowers error rates on CIFAR10‑C, CIFAR100‑C, and ImageNet‑C compared to SOTA TTA methods (e.g., CIFAR10‑C WRN‑28 error 17.03% vs TENT 18.51%; ImageNet‑C ViT‑B/16 51.79% vs 53.85%).

## Executive Summary
Test‑time adaptation (TTA) methods typically adjust only affine parameters of normalization layers, overlooking the crucial role of activation functions in shaping representations under distribution shift. AcTTA addresses this by reparameterizing conventional activations (ReLU, GELU) into a learnable form with channel‑wise parameters: a shift `c` and asymmetric slopes `λpos`, `λneg`. This allows dynamic adjustment of activation thresholds and gradient sensitivity during inference without altering pretrained weights or requiring source data. The approach is objective‑agnostic, integrating with any TTA loss (e.g., entropy minimization), and initializes identically to the base activation. Across CIFAR‑C, ImageNet‑C, and architectures including WRN, ResNeXt, ResNet50 (BN/GN) and ViT‑B/16, AcTTA consistently improves accuracy, shows stable optimization with large learning rates, remains effective under small batch sizes, and reduces continual forgetting during long‑horizon adaptation.

## Method Summary
AcTTA transforms a standard activation function `f` (e.g., ReLU) into a parameterized version:  
`f_A(x) = λpos · max(0, x - c) + λneg · min(0, x - c) + c`  
where `c`, `λpos`, `λneg` are learnable per‑channel parameters. For ReLU, initialization sets `c=0`, `λpos=1`, `λneg=0`; for GELU, analogous values restore the original function. During test‑time adaptation, only these activation parameters are updated via a chosen TTA loss (e.g., entropy minimization), while all pretrained weights remain frozen. The channel‑wise granularity offers a balance between expressiveness and stability: it is finer than layer‑wise yet avoids the optimization difficulties of pixel‑wise updates. AcTTA can be seamlessly combined with existing TTA strategies and does not depend on specific normalization layers.

## Key Results
- CIFAR10‑C (WRN‑28): error reduced from **18.51%** (TENT) to **17.03%** (AcTTA).  
- ImageNet‑C (ViT‑B/16): error reduced from **53.85%** (TENT) to **51.79%** (AcTTA).  
- AcTTA exhibits stable optimization with large learning rates, works with batch size 1, and mitigates continual forgetting in extended adaptation streams.

## Why This Works (Mechanism)
AcTTA’s channel‑wise shift `c` re‑centers pre‑activation features to match target‑domain statistics, while asymmetric slopes `λpos` and `λneg` adjust gradient flow asymmetrically, allowing the model to amplify or suppress positive and negative inputs differently. This fine‑grained control corrects distribution shifts at the level of individual channels without perturbing the core weights, preserving the representational geometry learned on the source domain. The channel‑wise granularity provides sufficient adaptability without overfitting, as evidenced by poorer performance with coarser (layer‑wise) or finer (pixel‑wise) parameterizations. Moreover, by limiting updates to activation space, AcTTA avoids the catastrophic interference that often occurs when both normalization and activation parameters are adapted simultaneously on CNNs. The identity initialization ensures no perturbation until beneficial updates are learned, contributing to robust optimization even under aggressive learning rates.

## Foundational Learning
- **Test‑Time Adaptation (TTA)**  
  *Why needed*: Enables models to handle distribution shifts during inference without accessing source data.  
  *Quick check*: Apply entropy minimization on a corrupted dataset (e.g., CIFAR10‑C) and compare error to the source model.

- **Activation Functions**  
  *Why needed*: Introduce non‑linearities that shape feature representations; AcTTA modifies them to adapt to target statistics.  
  *Quick check*: Replace ReLU with PReLU in a fixed model and observe changes in gradient magnitudes under TTA.

- **Channel‑wise Parameterization**  
  *Why needed*: Provides a balance between flexibility and stability; channel‑wise updates performed best in AcTTA.  
  *Quick check*: Compare layer‑wise, channel‑wise, and pixel‑wise adaptation on a simple corruption (e.g., salt‑and‑pepper noise) and record error.

- **Normalization Layers (BN/GN/LN)**  
  *Why needed*: Commonly adapted in TTA; AcTTA offers an alternative or complementary adaptation mechanism.  
  *Quick check*: Freeze all normalization parameters and only adapt activations; measure performance gain.

- **Objective‑agnostic TTA**  
  *Why needed*: AcTTA can be used with any TTA loss, increasing its applicability.  
  *Quick check*: Combine AcTTA with entropy loss and with a contrastive loss on the same backbone; compare both results.

- **Continual Forgetting in TTA**  
  *Why needed*: Long‑term adaptation may overwrite source knowledge; AcTTA mitigates this by limiting parameter scope.  
  *Quick check*: Run sequential adaptation on multiple corruptions and evaluate source‑domain accuracy over time.

## Architecture Onboarding
**Component map**  
Input → Backbone (e.g., ResNet block: Conv → BN → AcTTA → Conv → BN → skip connection → AcTTA) or ViT block: Patch Embedding → LN → Attention → LN → MLP(Linear → AcTTA → Linear) → residual add → Output (Global Pool → Classifier). AcTTA replaces the conventional activation (ReLU/GELU) in each block.

**Critical path**  
During inference, a sample passes through the frozen backbone; only the AcTTA parameters (`c`, `λpos`, `λneg`) in the activation layers are updated via the TTA loss gradient. No weight updates occur, preserving the source representation.

**Design tradeoffs**  
- *Granularity*: Channel‑wise is optimal; layer‑wise under‑fits, pixel‑wise over‑fits and becomes unstable.  
- *Layer selection*: Adapting roughly the middle 50% of layers works best; shallow layers may already capture low‑level features, deep layers are more sensitive.  
- *Normalization interaction*: On CNNs with BN, freezing BN while adapting AcTTA avoids forgetting; on ViTs with LN, updating LN alongside AcTTA can be beneficial.  
- *Learning rate*: AcTTA tolerates larger learning rates than BN adaptation due to bounded gradients from the reparameterization.  
- *Batch size*: Since AcTTA does not rely on batch statistics, it remains effective even with batch 1.

**Failure signatures**  
- Pixel‑wise parameterization leads to catastrophic error increase.  
- Jointly updating BN and AcTTA on CNNs degrades accuracy (catastrophic forgetting).  
- Using large learning rates on many layers simultaneously may cause divergence.  
- No improvement when applied to architectures without activations (e.g., linear models).  

**First experiments**  
1. **Baseline replication** – Apply channel‑wise AcTTA with entropy minimization to WRN‑28 on CIFAR10‑C; compare error against TENT and source model.  
2. **Granularity ablation** – Train models with layer‑wise, channel‑wise, and pixel‑wise AcTTA on a single corruption (e.g., Gaussian noise); report error to confirm channel‑wise superiority.  
3. **Normalization interaction** – On ResNet50 (BN) and ViT‑B/16 (LN), test three settings: (a) only AcTTA, (b) only BN/LN, (c) both; measure error and forgetting over 100 adaptation steps to diagnose interference.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** How can the optimal configuration choices for AcTTA (i.e., which network layers to adapt, choice of base activation, and adaptation depth) be determined systematically rather than through heuristic or architecture‑specific tuning?
- **Basis in paper:** [explicit] The conclusion explicitly states AcTTA has a "clear limitation: its effectiveness depends on design choices such as backbone architecture, activation type, and adaptation depth, and these factors are not yet determined in a fully principled manner."
- **Why unresolved:** The paper provides empirical observations (e.g., best to freeze BN on CNNs but update LN on ViTs, mid‑depth ~50% as a compromise) but offers no generalizable framework or theory to predict these choices for new architectures or corruption types.
- **What evidence would resolve it:** A comprehensive study across a wider array of architectures (e.g., different normalization layers, MLP‑Mixers) and corruption types, analyzing the relationship between feature statistics shift magnitude per layer and the corresponding optimal AcTTA parameter allocation, potentially leading to a predictive heuristic or learning‑based selector.

### Open Question 2
- **Question:** What is the precise mechanistic reason why channel‑wise parameterization of AcTTA (λ_pos, λ_neg, c per channel) significantly outperforms both coarser (layer‑wise) and finer (pixel‑wise) granularities for test‑time adaptation?
- **Basis in paper:** [inferred] Appendix C shows channel‑wise achieves lowest error, while layer‑wise and pixel‑wise perform worse or catastrophically fail. The paper notes channel‑wise provides a "balanced level of parameterization and expressiveness" but does not explain the underlying cause.
- **Why unresolved:** The result is presented as an empirical finding without analysis of the statistical properties of corrupted features per channel or the optimization dynamics (e.g., gradient noise, overfitting) that make channel‑wise uniquely suitable.
- **What evidence would resolve it:** Analyzing the distribution of activation inputs (x‑c) per channel across corruptions; measuring per‑channel gradient norms and stability during adaptation for different granularities; or theoretically modeling the bias‑variance trade‑off introduced by the parameter count at each granularity in the TTA setting.

### Open Question 3
- **Question:** Why do learnable activation functions designed for training‑time use (e.g., PReLU, PAU) often fail or become highly unstable under test‑time adaptation, while AcTTA’s specific parameterization (shift + asymmetric slopes) remains robust?
- **Basis in paper:** [inferred] Tables 3 and 11 show PReLU/PGU/PAU yield higher errors than even the base activation, whereas AcTTA improves. The paper suggests this is due to a "mismatch between conventional training and TTA" but does not formally characterize the failure modes.
- **Why unresolved:** The paper hypothesizes that TTA’s "unstable online adaptation regime" is incompatible with activations optimized for stable, full‑dataset training, but lacks ablation on the specific properties (e.g., gradient bounds, parameter sensitivity) that cause instability.
- **What evidence would resolve it:** A controlled analysis comparing gradient distributions, eigenvalue spectra of the loss Hessian w.r.t. activation parameters, and sensitivity to learning rate and batch size for each activation type under TTA conditions. Identifying whether AcTTA’s formulation inherently bounds gradients or provides a smoother optimization landscape would clarify the principle.

### Open Question 4
- **Question:** Does AcTTA’s superior performance in continual test‑time adaptation (reduced forgetting) stem primarily from the narrower scope of parameter updates (activation only vs. normalization affine parameters), from the specific functional form (shift + slopes), or from a combination? Can this be quantified?
- **Basis in paper:** [inferred] Section 4.8 claims AcTTA mitigates "continual forgetting" by limiting adaptation to activation space, preserving "core representational geometry." However, ablation in Table 2 (CNN) shows updating BN (γ,β) alongside AcTTA slightly degrades accuracy, while on ViT (LN) joint update helps. This suggests the interaction with normalization type is crucial and not fully understood.
- **Why unresolved:** The paper posits activation adaptation provides a "more localized" correction without perturbing weights, but does not measure representational drift (e.g., feature covariance, weight norm changes) or disentangle the effect of parameter scope from the functional form.
- **What evidence would resolve it:** Measuring source‑domain performance retention over time while ablating: (a) updating only AcTTA vs. only BN vs. both, across architectures; (b) comparing feature space metrics (e.g., CKA similarity to source model) for each configuration; (c) analyzing the magnitude and direction of parameter updates (activation vs. BN affine) throughout continual adaptation.

### Open Question 5
- **Question:** How does the learned shift parameter c in AcTTA correlate with the statistical moments (particularly mean) of corrupted features at different layers, and does it effectively re‑center activations to match source‑domain statistics?
- **Basis in paper:** [inferred] Figure 2 and Section 4.9 show c shifts noticeably and differs by layer (early layers larger shifts). The paper states this "recenters the nonlinear response to match the target‑domain feature statistics" but provides no quantitative validation linking c values to measured feature distribution shifts.
- **Why unresolved:** The visual evidence is suggestive but lacks statistical correlation analysis. It is unclear if c directly tracks the corruption‑induced mean shift or if it captures other distributional aspects (e.g., variance, higher moments). The assumption that re‑centering is the primary mechanism remains untested.
- **What evidence would resolve it:** For a set of corruptions, compute the per‑channel mean of pre‑activation features (before AcTTA) at each layer. Correlate these means with the learned c values across channels and layers. A strong positive correlation would support the re‑centering hypothesis. Additionally, intervening by manually setting c to the measured mean shift (instead of learning it) and comparing performance could isolate its contribution.

## Limitations
- Evaluation restricted to synthetic corruptions (CIFAR‑C, ImageNet‑C); performance on natural distribution shifts (e.g., ImageNet‑R, domain adaptation benchmarks) is unknown.  
- No computational overhead analysis; channel‑wise parameters increase memory and computation, especially for large models or high‑channel count layers.  
- Scope limited to image classification on a handful of architectures (CNNs, ViT); applicability to other tasks (detection, segmentation) or activation functions (e.g., SiLU) remains unexplored.
