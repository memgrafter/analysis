# Sequential Regression for Continuous Value Prediction using Residual Quantization

## Quick Facts
- arXiv ID: 2602.23012
- Source URL: https://arxiv.org/abs/2602.23012
- Reference count: 37
- Primary result: Outperforms SOTA on continuous value prediction tasks; e.g., on KuaiRec watch-time, MAE 3.190 and XAUC 0.615; online A/B test on Kuaishou GMV shows ΔAUC +0.12% and ADVV +4.19%.

## Executive Summary
The paper introduces RQ-Reg, a framework for continuous value prediction in recommendation systems, particularly effective for long‑tailed distributions. RQ-Reg decomposes the target value into an ordered sequence of residual quantization codes, predicted recursively from coarse to fine using an LSTM. A representation learning objective (Rank‑N‑Contrast) aligns the embedding space of these code sequences with the ordinal structure of target values, while scheduled sampling mitigates exposure bias. The method achieves state‑of‑the‑art results on multiple public benchmarks and demonstrates significant gains in a large‑scale online A/B test on Kuaishou for GMV prediction.

## Method Summary
RQ‑Reg first builds a hierarchical residual quantization (RQ) codebook via K‑means across L levels, each with K centroids. For a target y, iterative quantization yields a code sequence q₁…q_L with diminishing residuals. An MLP encodes user‑item features into an initial LSTM state. The LSTM predicts codes autoregressively: at step l it receives the embedding of the previous code (or its expected embedding during scheduled sampling) and updates its state. A predictor MLP outputs logits over the level‑l codes, and a regressor MLP maps these logits to a scalar ŷ_l. The final prediction ŷ is the sum of all ŷ_l. The total loss combines: (i) generative NLL for code predictions, (ii) Huber regression loss on each ŷ_l and the final ŷ, and (iii) Rank‑N‑Contrast loss that forces the sequence embedding (a weighted sum of code embeddings) to respect target‑value ordering. Scheduled sampling, with inverse sigmoid decay, gradually replaces ground‑truth code embeddings with the model’s own predictions during training.

## Key Results
- KuaiRec watch‑time prediction: MAE 3.190, XAUC 0.615, surpassing prior SOTA.
- Public benchmarks (Criteo‑SSC, Kaggle LTV, CIKM16) show consistent improvement on ranking metrics like Norm‑Gini and Spearman’s ρ.
- Online Kuaishou GMV A/B test: ΔAUC +0.12%, ADVV +4.19% improvement.

## Why This Works (Mechanism)

### Mechanism 1: Coarse‑to‑Fine Residual Quantization
- **Claim:** Decomposing the continuous target into an ordered sequence of RQ codes enables recursive coarse‑to‑fine prediction, reducing quantization error relative to single‑step discretization.
- **Mechanism:** RQ builds L levels of centroids via hierarchical K‑means. Starting with r₀ = y, each level l quantizes the residual r₋₁ to its nearest centroid in 𝒞ₗ, producing code qₗ and new residual rₗ = r₋₁ – qₗ. The target is approximated by the sum of codes. An LSTM predicts the code sequence autoregressively: p(q₁,…,q_L|x)=∏ p(qₗ|x,q_{<l}).
- **Core assumption:** Hierarchical residuals allow each level to focus on a different granularity, cumulatively minimizing error; single‑level K‑means must balance bucket widths and suffers from imbalanced bucket occupancy in long‑tailed data.
- **Evidence anchors:** Abstract states “ordered quantization codes, predicted recursively from coarse to fine granularity with diminishing quantization errors.” Section 3.2 details Algorithm 1 and y = Σ qₗ + r_L. Neighboring papers on residual quantization (FMR ~0.5) indicate relevance.
- **Break condition:** If hierarchical K‑means does not sufficiently reduce residual variance (e.g., poor initialization, cluster overlap), the benefit collapses, making performance similar to single‑level K‑means (see Table 6 reconstruction error).

### Mechanism 2: Ordinal Structure via Rank‑N‑Contrast
- **Claim:** A representation learning objective (Rank‑N‑Contrast loss) aligns the embedding space of predicted code sequences with the ordinal structure of target values, capturing continuous relationships beyond discrete code predictions.
- **Mechanism:** For each level l, the model’s predicted distribution over codes is used to compute an expected embedding Ẽ_l = Σ_c p(q=c|x,q_{<l}) e(c). The full sequence embedding Ẽ = [Ẽ₁;…;Ẽ_L] is trained with RnC loss: for each anchor i, a positive j (with |y_i – y_j| small) and negative k (with |y_i – y_k| larger) are contrasted, encouraging embeddings of samples with closer targets to be more similar.
- **Core assumption:** The ordinal ranking of target values is reflected in the geometry of a well‑structured embedding space; enforcing this via contrastive learning yields smoother latent representations and improves regression.
- **Evidence anchors:** Abstract mentions “representation learning objective that aligns RQ code embedding space with the ordinal structure of target values.” Section 3.4.3 defines ℒ_rnc (Eq. 15) and states its ordering goal. Figure 3 t‑SNE shows full model embeddings preserving value order, while w/o ℒ_rnc they are scattered.
- **Break condition:** If the contrastive objective overly perturbs the embedding space (e.g., causing collapse or reducing code distinguishability), it may harm code prediction accuracy; indeed, ablation w/o ℒ_rnc degrades performance (Table 3).

### Mechanism 3: Scheduled Sampling to Mitigate Exposure Bias
- **Claim:** Autoregressive prediction with scheduled sampling bridges the gap between training (teacher forcing) and inference (model‑generated inputs), stabilizing training and preventing error accumulation.
- **Mechanism:** During training, at step l, with probability p(t) (inverse sigmoid decay) the ground‑truth code embedding e(q_{l-1}) is used; otherwise, the model’s own predicted embedding Ẽ_{l-1} (from Eq. 14) is fed. This gradually increases exposure to the model’s predictions.
- **Core assumption:** A train‑inference mismatch (always ground‑truth vs. always model predictions) leads to exposure bias; scheduled sampling eases this transition, making the model robust to its own errors.
- **Evidence anchors:** Section 3.5.1 describes scheduled sampling and its purpose. Table 3 shows that extreme cases (always teacher forcing p=1 or always model p=0) both underperform the balanced schedule (full model MAE 3.190 vs. 3.206 and 3.240), confirming the need for a gradual mix.
- **Break condition:** If decay is too rapid (small t₀), early training receives noisy model inputs, causing instability; if too slow (large t₀/k), exposure bias persists, harming inference performance (seen in both ablations).

## Foundational Learning

### Residual Quantization (RQ)
- **Why needed here:** RQ replaces rigid fixed discretization (classification) or inflexible parametric assumptions (e.g., Gaussian) with a flexible hierarchical decomposition that minimizes cumulative quantization error, crucial for complex long‑tailed continuous targets.
- **Quick check:** How does RQ’s hierarchical residual approach reduce the trade‑off between bucket width (classification error) and data sparsity (imbalance) compared to a single‑level K‑means discretization?

### Ordinal Structure in Embedding Space
- **Why needed here:** Standard classification treats quantization codes as independent categories, ignoring that codes with similar target magnitudes (e.g., adjacent levels) should have close embeddings. The Rank‑N‑Contrast loss explicitly encodes this ordinal prior, yielding a smoother, continuous latent space for regression.
- **Quick check:** Why is minimizing cross‑entropy on code prediction insufficient to ensure that the embedding space reflects the continuous ordering of the original target values?

### Scheduled Sampling for Autoregressive Models
- **Why needed here:** Autoregressive prediction of RQ codes suffers from exposure bias when teacher forcing is used during training; the model never learns to recover from its own mistakes. Scheduled sampling gradually mixes ground‑truth and model‑predicted inputs, closing the train‑inference gap.
- **Quick check:** What is the specific failure mode (observed in the w/o SS ablations) that scheduled sampling is designed to prevent in this architecture?

## Architecture Onboarding

### Component Map
Input features x → f_enc (MLP) → [h₀,c₀] → LSTM (loop over L levels: input = e(q_{l-1}) or Ẽ_{l-1}) → hₗ → f_pred (MLP) → logits over level‑l codes → f_reg (MLP) → ŷₗ → Output Aggregator: ŷ = Σ ŷₗ. Supporting: Embedding Table E mapping codes to vectors; Loss Modules: ℒ_gen (code NLL), ℒ_reg (Huber on ŷ and ŷₗ), ℒ_rnc (on Ẽ = Σ p e).

### Critical Path
x → f_enc → initial LSTM state → for l=1..L: (LSTM consumes previous code embedding) → hₗ → f_pred → zₗ (logits) → f_reg → ŷₗ → accumulate → ŷ = Σ ŷₗ. Losses: ℒ_gen on code predictions, ℒ_reg on ŷ and each ŷₗ, ℒ_rnc on sequence embedding Ẽ from predicted distributions.

### Design Tradeoffs
- **RQ codebook size (K) vs. levels (L):** Larger K reduces per‑level error but increases vocabulary and sequence length; more L reduces residual error but lengthens sequence, raising error propagation risk.
- **Scheduled sampling decay (k, t₀):** Aggressive decay (small t₀) destabilizes early training; sluggish decay (large t₀) leaves exposure bias, harming inference performance.
- **Loss weighting (λ₁, λ₂):** Imbalance may neglect either code prediction fidelity (λ₁) or ordinal embedding structure (λ₂), degrading overall regression accuracy.

### Failure Signatures
- **Degraded long‑tail performance:** Significant MAE increase on high‑value samples, especially when ℒ_rnc or scheduled sampling are ablated.
- **Embedding collapse/disorder:** t‑SNE visualizations show non‑monotonic embedding layout; indicates ℒ_rnc failed.
- **High reconstruction error:** RQ K‑means yields large residuals r_L, meaning codebook inadequately captures distribution; predictions will be biased.
- **Training instability:** Loss spikes or NaNs early in training, often due to overly aggressive scheduled sampling or un‑tuned ℒ_rnc λ₂.

### First 3 Experiments
1. **Ablation study (Table 3):** Systematically remove ℒ_gen, ℒ_rnc, f_reg, and scheduled sampling (both extremes p=1 and p=0) to quantify contributions on KuaiRec/CIKM16; full model expected best, with w/o ℒ_rnc and w/o SS showing notable regression.

## Limitations
- Missing implementation details (feature preprocessing, codebook separation, MLP sizes, sampling schedule) hinder exact replication.
- RQ hyperparameters (L, K) are not tuned; optimal values likely depend on dataset characteristics.
- Evaluation relies heavily on a single online A/B test (Kuaishou GMV), with limited validation of ordinal embedding structure (only t‑SNE) and possible oversight of recent residual quantization works.
