# What Makes a Good Doctor Response? An Analysis on a Romanian Telemedicine Platform

## Quick Facts
- **arXiv ID:** 2602.17194
- **Source URL:** https://arxiv.org/abs/2602.17194
- **Reference count:** 0
- **Primary result:** Metadata (patient/clinician history) dominates feedback prediction; polite and hedged doctor responses further increase thumbs-up, yielding ROC-AUC 0.836 on high-confidence instances.

## Executive Summary
This study analyzes 77,334 text-based telemedicine consultations from a Romanian platform to identify which characteristics of doctor responses correlate with patient thumbs-up feedback. Using interpretable, largely language-agnostic features (length, structure, readability proxies) alongside Romanian LIWC and politeness markers, a CatBoost classifier was trained with a time-based split. SHAP analysis revealed that patient and clinician history metadata act as strong priors, while response text features provide a smaller but actionable signal: politeness and hedging consistently correlate with positive feedback, and lexical diversity correlates negatively. Specialty-specific patterns emerge (e.g., numeric content in endocrinology). Model performance reached ROC-AUC 0.836 on high-confidence instances, suggesting that satisfaction is driven more by communication clarity and empathy than by clinical accuracy.

## Method Summary
The task is binary classification of patient feedback (thumbs-up vs. thumbs-down/missing) for Romanian text-based consultations. Inputs include 77,334 anonymized patient question–doctor response pairs, with features from four sources: (i) patient group information (new/returning, prior feedback), (ii) doctor public profile & activity (workplace, education, historical feedback rate), (iii) question metadata (specialty, daytime, day of week), and (iv) doctor response text (length, structure, readability proxies, Ro-LIWC psycholinguistic features, politeness/hedging markers). The patient question text itself is not used. A CatBoost classifier is trained on an 80:20 time-based split to avoid temporal leakage. Performance is measured via ROC-AUC, PR-AUC, F1, precision, recall, and model interpretability is achieved through SHAP global and local explanations. Subgroup analyses are performed by question type, patient/doctor gender, and medical specialty.

## Key Results
- SHAP global importance: patient and clinician history metadata are the top predictors of feedback.
- Text features: politeness and hedging markers show positive correlations with thumbs-up; lexical diversity shows a negative correlation.
- Specialty-specific patterns observed, e.g., numeric content in endocrinology responses correlates with higher satisfaction.
- Model performance: ROC-AUC 0.72 on the full validation set, rising to 0.836 on a high-confidence subset.

## Why This Works (Mechanism)
Metadata priors (e.g., doctor’s historical feedback rate, patient’s previous ratings) capture established reputation and loyalty, which are strong indicators of future satisfaction. The time-based split ensures these priors are computed only from pre-consultation data, preventing leakage and reflecting real-world deployment. Text features add incremental predictive power because polite language and hedging (e.g., “may I suggest”) convey empathy and cautious advice, which patients appreciate. Lexical diversity may signal overly complex or jargon-heavy responses, reducing satisfaction. Specialty-specific patterns likely arise because different clinical domains have distinct communicative expectations (e.g., numeric details in endocrinology). The combination of robust baselines (metadata) and subtle communication cues yields high discriminative ability, especially on high-confidence cases where the feedback signal is clear.

## Foundational Learning
- **CatBoost**: Gradient boosting that natively handles categorical features. *Why needed*: Efficiently models mixed data types without extensive preprocessing. *Quick check*: Train on a small subset; inspect that categorical features are automatically processed and feature importance is computed.
- **SHAP (TreeSHAP)**: Game-theoretic interpretability method for tree models. *Why needed*: Quantifies each feature’s contribution to individual predictions and global importance. *Quick check*: Compute SHAP values for a trained model and verify that the sum of SHAP values plus the base value equals the predicted log-odds.
- **LIWC (Romanian)**: Psycholinguistic dictionary mapping words to categories (e.g., emotion, cognitive processes). *Why needed*: Provides language-agnostic psychological signals from text. *Quick check*: Apply the Ro-LIWC2015 lexicon to a sample response; ensure reasonable category counts and coverage.
- **Politeness/Hedging markers**: Romanian lexical cues for courteous and tentative language. *Why needed*: Capture empathy and uncertainty, which are hypothesised to affect satisfaction. *Quick check*: Manually count occurrences in a few responses; confirm that markers align with expected phrases (e.g., “vă rog”, “poate”).

## Architecture Onboarding
Component map: Raw logs -> MetadataExtraction -> TextFeatureExtraction -> FeatureVectorAssembly -> CatBoostTrainer -> Predictor -> SHAPAnalyzer

Critical path:
1. Collect consultation records with timestamps.
2. Compute patient/doctor historical features using only prior data.
3. Extract response text features (length, punctuation, LIWC, politeness/hedging counts).
4. Combine all features into a fixed-length vector per consultation.
5. Split data temporally (train before test).
6. Train CatBoost model on training set.
7. Evaluate on test set (ROC-AUC, etc.).
8. Compute SHAP values for global and local interpretability.

Design tradeoffs:
- Interpretability vs. performance: Simple, hand-crafted features enable clear explanations but may underperform vs. deep NLP models.
- Language-specific resources: Ro-LIWC and politeness lexicons improve accuracy for Romanian but limit cross-lingual transfer.
- Temporal split: Reduces training data size and may omit recent trends, but is essential to avoid leakage and simulate production.

Failure signatures:
- SHAP indicates text features dominate → possible leakage (history features incorrectly include post-consultation data).
- ROC-AUC on test set << 0.70 after careful split → feature extraction mismatch or data quality issues.
- Calibration error > 2% → model probabilities not reliable for decision-making.

First three experiments:
1. **Metadata-only baseline**: Train CatBoost using only history features. Expect lower ROC-AUC than full model, quantifying text feature contribution.
2. **Politeness/hedging ablation**: Remove these features and re-train; measure change in performance and SHAP rankings of related proxies.
3. **Temporal integrity check**: Verify that all consultations in the test set have timestamps later than the latest timestamp used in any history feature for that instance.

## Open Questions the Paper Calls Out
1. **Higher-level semantic features**: What semantic attributes (e.g., response clarity, adequacy of explanations) correlate with satisfaction, and how can they be automatically discovered using modern NLP methods? The current study uses surface-level features; future work should employ pretrained language models or feature discovery.
2. **Subgroup variations**: Do satisfaction correlates differ across patient and clinician subgroups beyond gender and new/returning status (e.g., age groups, specific conditions, doctor experience)? Limited metadata granularity prevented exploration.
3. **Accuracy vs. communication**: To what extent does patient feedback reflect clinical accuracy versus communication quality, and can this be disentangled? The study lacks ground-truth accuracy labels and may confound reputation with actual care quality.
4. **Specialty-specific communicative demands**: What are the specific communicative demands of each medical specialty that drive patterns like numeric content in endocrinology, and how can they be operationalized for doctor training? The analysis is correlational and does not investigate why certain features are preferred.

## Limitations
- Undisclosed Romanian lexicons for politeness and hedging hinder exact replication of these key textual features.
- Missing implementation details for metadata engineering (time windows, smoothing, binning) and the definition of the high-confidence subset.
- Specialty-specific findings are observational and not systematically validated, limiting generalizability.

## Confidence
- **Metadata priors dominate prediction**: High
- **Text features (politeness/hedging) positive correlation; lexical diversity negative**: Medium
- **Specialty-specific patterns (e.g., digits in endocrinology)**: Low

## Next Checks
- **Temporal leakage audit**: Confirm that test-set consultations occur after the train cut-off and that all history features use only pre-consultation data.
- **Politeness/hedging lexicon ground truth**: Source or construct a Romanian politeness/hedging lexicon, recompute features, and rerun SHAP to verify their importance and direction.
- **Subgroup stability on high-confidence instances**: Using a reasonable proxy (e.g., predictions near 0 or 1), repeat the subgroup correlation analyses separately; compare to full test set to see if text-feature effects are driven by ambiguous cases.
