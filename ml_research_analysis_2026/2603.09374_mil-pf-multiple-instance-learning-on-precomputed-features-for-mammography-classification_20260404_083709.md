# MIL-PF: Multiple Instance Learning on Precomputed Features for Mammography Classification

## Quick Facts
- arXiv ID: 2603.09374
- Source URL: https://arxiv.org/abs/2603.09374
- Reference count: 22
- Primary result: Achieves AUC 0.916, balanced accuracy 0.850, and specificity 0.762 at 0.9 sensitivity on the EMBED dataset (0.5M images), outperforming state-of-the-art baselines.

## Executive Summary
MIL-PF introduces a highly efficient framework for breast-level mammography classification that decouples expensive visual representation learning from task-specific aggregation. By precomputing features using frozen foundation encoders (e.g., DINOv2), it avoids retraining large backbones and instead trains only a lightweight (~40k-parameter) attention-based multiple instance learning (MIL) head. This head aggregates both global view embeddings and local tile embeddings to capture complementary tissue context and sparse lesion signals. On the large-scale EMBED dataset (0.5M images), MIL-PF achieves state-of-the-art performance (AUC 0.916, balanced accuracy 0.850) while drastically reducing training time (~5–7 minutes on an A100 GPU) and computational cost (2M FLOPS per forward pass). The approach demonstrates that high-quality medical image analysis can be accomplished with minimal trainable parameters by leveraging pretrained representations.

## Method Summary
MIL-PF operates in two stages. First, high-resolution mammograms are processed by a frozen foundation encoder to extract two types of embeddings: a global embedding per image view and multiple local embeddings from a grid of tiles covering breast tissue. These embeddings are stored in a dataset grouped by breast (a "bag" containing all views of that breast). Second, a lightweight MIL head is trained on these precomputed embeddings. The head consists of a global aggregator (AG) that pools view-level embeddings via a small MLP and permutation-invariant pooling (max or mean), and a local aggregator (AT) that uses a Perceiver-style cross-attention mechanism with a single learned latent query to weight tile embeddings. The aggregated global and local vectors are concatenated and passed through a final linear layer to produce a breast-level cancer prediction. The entire head contains only ~40k trainable parameters and is trained with binary cross-entropy, using full-batch optimization on a single GPU due to the small memory footprint.

## Key Results
- On the EMBED dataset (500k images), MIL-PF achieves AUC 0.916, balanced accuracy 0.850, and specificity 0.762 at 0.9 sensitivity.
- It outperforms prior state-of-the-art baselines across these metrics.
- Training the MIL head takes only 5–7 minutes on an A100 GPU with 2M FLOPS per forward pass, demonstrating extreme efficiency.

## Why This Works (Mechanism)

### Mechanism 1: Efficient Representation via Frozen Encoders
- **Claim:** Precomputing features with frozen foundation encoders drastically reduces training computational cost while retaining expressive representations for mammography.
- **Mechanism:** High-resolution mammograms are passed once through a large pretrained vision encoder (e.g., DINOv2) to generate fixed embeddings, which are stored and reused. Only a ~40k-parameter attention-based aggregator is trained, eliminating the need to recompute encoder gradients.
- **Core assumption:** The foundation encoder's representations are sufficiently semantically aligned with the mammography classification task without adaptation.
- **Evidence:** [abstract] "By precomputing the semantic representations... Training complexity is drastically reduced..."; [section 2] "We assume the existence of an encoder, F, that is pretrained..."; [table 4] DINOv2 (518×518) achieves AUC 0.897 on EMBED.
- **Break condition:** The frozen encoder's representation space is misaligned with the target task, leading to poor performance that cannot be corrected by the lightweight head. Evidence: Table 4 shows DINOv3's poor performance.

### Mechanism 2: MIL Formulation for Weakly-Labeled, Multi-View Data
- **Claim:** Framing breast-level classification as Multiple Instance Learning (MIL) with a bag of views/tiles correctly models the weak supervision (breast-level labels) and hierarchical structure (views containing sparse lesions).
- **Mechanism:** A "bag" is defined as all views of a single breast. The MIL head aggregates variable numbers of global view embeddings and local tile embeddings into a single breast-level prediction, respecting the clinical reporting unit and avoiding forced per-image labels.
- **Core assumption:** The bag-level label is consistent across all instances in the bag, and clinically relevant signals are distributed across views and sparse high-resolution tiles.
- **Evidence:** [section 2] "We study a special case of MIL, which includes: 1. Nested hierarchy... 2. Complementary streams..."; [section 3.1] "A bag Si is defined as a set of all views of a single breast..."; [table 4] Ablation shows full MIL-PF (max + attn) outperforms single-instance learning (SIL) on global views only by up to 5% AUC.
- **Break condition:** The bag-level label is extremely noisy or inconsistent, or the sparse lesion signal is too diluted even within a breast bag, making aggregation unreliable. The paper uses a BI-RADS thresholding strategy to mitigate label noise; extreme noise could break this.

### Mechanism 3: Perceiver-Style Cross-Attention for Sparse Lesion Aggregation
- **Claim:** A Perceiver-style cross-attention aggregator for local tile embeddings effectively attends to sparse, clinically relevant lesions without quadratic complexity.
- **Mechanism:** A single trainable latent query vector attends to all tile embeddings via cross-attention, producing a weighted summary. This design is parameter-efficient (~40k total parameters) and focuses capacity on learning to attend, not modeling tile-tile dependencies.
- **Core assumption:** A single latent query is sufficient to capture the presence/absence of relevant lesions; multiple distinct lesions can be summarized by one attention vector.
- **Evidence:** [section 2] "We employ a Perceiver-style cross-attention mechanism... We found that using a single latent query was sufficient..."; [section 3.3] MIL-PF with attention (vs. max pooling) achieves higher Spec@Sens=0.9 on EMBED (0.762 vs. 0.703); [section 3.4] Qualitative attention maps show localization on masses/calcifications, though small lesion detection mAP is low.
- **Break condition:** Multiple distinct, spatially separated lesions require separate attention queries to be properly captured; the single-query design aggregates them into a less informative summary. The paper notes low mAP for small lesions, possibly due to large tile size.

## Foundational Learning
- **Concept:** Multiple Instance Learning (MIL)
  - **Why needed:** Mammography labels exist at the breast level, not per image or tile. MIL provides a formalism to learn from bags of instances (views/tiles) with only a bag-level label.
  - **Quick check:** If you have a bag of 4 mammogram views (CC, MLO for each breast) and only one "cancer" label for the entire left breast bag, how would you design a loss function that doesn't force you to guess which view(s) caused the label?
- **Concept:** Frozen Encoder / Feature Precomputation
  - **Why needed:** End-to-end training on 0.5M high-res images is computationally prohibitive. Precomputation decouples expensive visual representation learning from cheap task-specific aggregation.
  - **Quick check:** What are the two main risks of using a frozen encoder that was not trained on mammography data (e.g., DINOv2 trained on natural images)?
- **Concept:** Cross-Attention for Aggregation
  - **Why needed:** Local lesion signals are sparse among thousands of background tiles. Mean/max pooling either dilutes or ignores multiple relevant tiles. Cross-attention learns to weight tiles by relevance to the prediction.
  - **Quick check:** How does cross-attention (query-key-value) differ from self-attention in the context of aggregating a set of tile embeddings toward a single bag prediction?

## Architecture Onboarding
- **Component map:**
  1. Embeddings Dataset (E): Precomputed tuples (G_i, T_i, y_i) where G_i are global view embeddings, T_i are concatenated tile embeddings, y_i is breast label.
  2. Global Aggregator (AG_ψ): MLP (embed dim → 16 → 8) + permutation-invariant pooling (mean or max) over G_i → global summary.
  3. Local Aggregator (AT_ω): Perceiver-style cross-attention with a single learned latent query; tile embeddings first passed through MLP → local summary.
  4. Final Head (h_θ): Concatenates global & local summaries, MLP → scalar logit.
- **Critical path:**
  1. Precompute stage: For each image, extract global and tile embeddings using frozen F; group by breast to form bags; store E.
  2. Head training stage: Load E; freeze F; initialize AG, AT, h; train with binary cross-entropy using full-batch on a single GPU.
- **Design tradeoffs:**
  - Tile size vs. resolution: larger tiles reduce count but may miss small lesions; overlapping tiles at inference helps but increases compute.
  - Global vs. Local stream: Late fusion (concat) is simple; early/interaction fusion could model cross-stream dependencies but adds parameters.
  - Single vs. multi-query attention: single query is efficient; multiple latents may capture multiple lesions but were found unhelpful.
- **Failure signatures:**
  - High variance across runs: unstable optimization with different seeds or learning rates.
  - Poor small lesion detection: mAP_s near 0 indicates tile resolution or attention mechanism may not localize tiny calcifications.
  - Encoder mismatch: using a poorly performing encoder yields low AUC regardless of head design.
  - Data leakage: patient IDs appearing in both train and test splits inflate metrics.
- **First 3 experiments:**
  1. Encoder validation: Train MIL-PF head with different frozen encoders on a small subset; expect DINOv2/MedSigLIP to outperform others quickly (Table 4).
  2. Aggregator ablation: Test AG/AT with mean, max, and attention pooling, with and without both streams; expect max+attn combination to perform best.
  3. Multiple-seed stability: Run full training 5–10 times with same hyperparameters; check validation AUC variance should be <1–2% if implementation is correct.

## Open Questions the Paper Calls Out
- How can inductive biases from prior patient exams and contralateral breast asymmetry be effectively incorporated into the MIL-PF framework? The current framework processes each breast exam in isolation without leveraging longitudinal or bilateral contextual signals.
- To what extent does the frozen encoder approach generalize to other high-resolution, weakly-labeled medical imaging domains beyond mammography? The paper only evaluates mammography; domain-specific characteristics may affect transferability.
- How can the tiling strategy be optimized to improve small lesion detection without sacrificing classification performance? The uniform grid with fixed-size tiles (448×518) leads to low mAP for small lesions; multi-scale or adaptive tiling could help.
- Would fine-tuning the foundation encoder on the mammography dataset yield performance gains, or does the frozen encoder already capture optimal features? The paper uses frozen encoders for efficiency, but task-specific fine-tuning might adapt to medical nuances.

## Limitations
- **Preprocessing & implementation gaps:** Exact tiling heuristics, normalization for each encoder, and MIL head details (activations, LayerNorm) are unspecified, risking feature misalignment.
- **Data leakage risk:** No explicit patient-level split protocol; common leakage sources (multiple exams per patient) could inflate reported metrics.
- **Lesion size sensitivity:** mAP for small lesions is near zero, indicating the tile resolution (448×518) or single-query attention may fail on subtle calcifications.

## Confidence
- Computational efficiency claim: High
- MIL formulation benefit: Medium
- Attention localization efficacy: Medium

## Next Checks
1. **Preprocessing audit:** Recompute embeddings using inferred pipelines; validate with linear probe on a balanced subset. Degraded accuracy (<0.6 AUC) indicates normalization/tiling errors.
2. **Data leakage test:** Hash all patient IDs across train/val/test splits; any overlap invalidates reported generalization.
3. **Lesion resolution stress test:** Reduce tile size (e.g., 224×224) with overlapping grids; if small-lesion mAP remains near zero, the bottleneck is architectural (single-query attention) rather than tile resolution.
