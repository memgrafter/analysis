# When Stability Fails: Hidden Failure Modes Of LLMS in Data-Constrained Scientific Decision-Making
## Quick Facts
- arXiv ID: 2603.15840
- Source URL: https://arxiv.org/abs/2603.15840
- Reference count: 18
- Primary result: LLMs can exhibit near-perfect run-to-run stability while diverging severely from statistical ground truth, showing high prompt sensitivity and systematic hallucination, indicating that stability alone is insufficient as a correctness proxy in data-constrained scientific decision-making.

## Executive Summary
The paper critically examines the common practice of equating internal stability with correctness when using large language models (LLMs) for scientific decisions under data constraints. It proposes a controlled evaluation framework that separates four dimensions: run-to-run stability, correctness against a deterministic statistical ground truth, prompt sensitivity, and output validity. Using a fixed DESeq2 differential expression table and gene prioritization prompts across three state-of-the-art LLMs (ChatGPT, Gemini, Claude), the study reveals that models achieve near-perfect stability (pairwise Jaccard ≈1.00) but suffer serious correctness failures, with Claude recovering no differentially expressed genes under strict thresholds (Jaccard=0.00) and ChatGPT only 0.14 on borderline rankings. Minor prompt wording changes cause drastic shifts in gene selections (Jaccard as low as 0.08), and Claude repeatedly outputs invalid gene identifiers (~20 per run). The findings demonstrate that high stability does not guarantee correct or valid reasoning, urging explicit ground-truth validation and output checks in scientific LLM workflows.

## Method Summary
The authors built a deterministic evaluation framework around a single RNA‑seq differential expression dataset (GEO GSE239514) processed with DESeq2. This yields a fixed table containing gene statistics (log2FoldChange, pvalue, padj, etc.). A suite of prompts was designed to ask the LLM to prioritize genes under various statistical regimes: strict (FDR ≤ 0.05), relaxed (0.05 < FDR ≤ 0.10), borderline top‑20, and minimal wording variants (P7a/P7b). Three LLMs (ChatGPT GPT‑5.2, Gemini 3, Claude Opus 4.5) were queried via API with temperature=0, producing 10 independent runs per model‑prompt combination. Outputs were parsed (JSON) into gene sets. Correctness was measured by Jaccard similarity between the model’s set and a reference set derived deterministically from the same DESeq2 table (e.g., genes meeting padj thresholds). Prompt sensitivity was assessed by Jaccard between outputs from different prompt variants. Validity was checked by counting identifiers absent from the input table. The same metrics (Jaccard, overlap coefficient) were used across stability, correctness, and sensitivity dimensions.

## Key Results
- All models exhibit near-perfect run-to-run stability (mean pairwise Jaccard ≈1.00) within each prompt condition.
- Correctness diverges sharply: Claude fails to recover any true DE genes under strict thresholds (Jaccard=0.00), while ChatGPT achieves only 0.14 on borderline ranking; both models show low agreement with DESeq2 reference sets.
- Prompt sensitivity is extreme: minimal wording changes between P7a and P7b yield very low Jaccard scores (e.g., Gemini 0.08, ChatGPT 0.74), indicating that phrasing acts as an implicit decision variable.
- Claude systematically outputs invalid gene identifiers (≈20 per run) for ranking prompts, while all other models produce only identifiers present in the input table.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** High run-to-run stability does not imply agreement with statistical ground truth.
- **Mechanism:** LLMs can produce internally consistent (deterministic) outputs that systematically diverge from a fixed statistical reference because stability measures reproducibility across random seeds, not correctness against an external standard. The model's internal decision logic may consistently apply a flawed heuristic or misalignment with the statistical objective.
- **Core assumption:** Users conflate internal consistency (stability) with task accuracy (correctness).
- **Evidence anchors:** [abstract] "LLMs can exhibit near-perfect run-to-run stability while systematically diverging from statistical ground truth"; [section 3.1] "models achieve maximal within-LLM stability while exhibiting substantial variation in agreement with the reference... Claude fails to recover DE genes (Jaccard=0.00) under strict threshold".
- **Break condition:** When a deterministic statistical reference is available and model output is compared against it; stability metrics will show high similarity while correctness metrics show low or zero agreement.

### Mechanism 2
- **Claim:** Minor prompt wording changes induce large shifts in prioritization outcomes, even under identical inputs and high internal stability.
- **Mechanism:** Prompts act as implicit decision variables. Small linguistic variations (e.g., emphasis on "effect size" vs. "statistical significance") alter the model's internal objective function or interpretation of prioritization criteria, leading to substantively different gene selections. This sensitivity is orthogonal to stochastic run-to-run variation.
- **Core assumption:** Semantically equivalent prompts should yield equivalent outputs for a deterministic task.
- **Evidence anchors:** [abstract] "minor prompt wording changes drastically alter outputs (Jaccard as low as 0.08 between variants)"; [section 3.2] "small wording changes can lead to substantial differences in selected gene sets for some models... this decoupling between internal stability and cross-prompt consistency suggests that prompt phrasing may function as an implicit decision variable"; [section A.4] Prompts P7a vs. P7b differ only in emphasis wording yet yield low Jaccard (0.08 for Gemini).
- **Break condition:** When comparing outputs from two semantically aligned prompts that differ only in emphasis; the Jaccard/overlap coefficient between their outputs will be low, indicating sensitivity.

### Mechanism 3
- **Claim:** Models can produce syntactically plausible but invalid identifiers (hallucinations) while maintaining high internal stability.
- **Mechanism:** The model's generation process, constrained only by format (e.g., JSON), can output entities that are grammatically correct but absent from the input domain. This reflects a failure to strictly adhere to the "use only provided table" constraint, possibly due to overgeneralization from training on gene-like identifiers. Stability is preserved because the same invalid pattern recurs across runs.
- **Core assumption:** Stable outputs grounded in a provided table will contain only identifiers present in that table.
- **Evidence anchors:** [abstract] "Claude systematically hallucinates 20 invalid gene identifiers per run"; [section 3.4] "Claude systematically produces invalid gene IDs (20 invalid genes/run)... invalid identifiers recur across repeated runs and take the form of syntactically well-formed, gene-like tokens absent from the input table"; [figure 5] "Claude frequently outputs ranked lists composed largely of identifiers absent from the input table".
- **Break condition:** When performing output validity checks by set difference against the input table; a high count of invalid identifiers will be detected despite identical outputs across runs.

## Foundational Learning
- **Concept: Set Similarity Metrics (Jaccard, Overlap Coefficient)**  
  *Why needed:* To disentangle stability (within-run set similarity) from correctness (similarity to ground truth) and prompt sensitivity (between-prompt set similarity). Jaccard penalizes set size differences; overlap coefficient captures containment.  
  *Quick check:* If Model A always returns 5 genes and the ground truth has 10, a Jaccard of 0.33 vs. an overlap of 0.5 conveys what different information?

- **Concept: Deterministic Statistical Ground Truth Construction**  
  *Why needed:* To isolate model behavior from data variability. The DESeq2 reference is fixed, enabling controlled comparison. The paper treats this as a "statistical ground truth" for evaluation, not absolute biological truth.  
  *Quick check:* Why is it critical that the ground truth is derived from the *same* input table provided to the LLM?

- **Concept: Prompt Sensitivity vs. Stochastic Variability**  
  *Why needed:* To distinguish failure modes: high stability + high prompt sensitivity means the model is consistently wrong in different ways depending on wording, not just noisy.  
  *Quick check:* If two prompts yield Jaccard=0.9 within each prompt's 10 runs but Jaccard=0.2 between prompts, what does that imply?

## Architecture Onboarding
Input Engine -> LLM Client -> Output Parser -> Ground Truth Comparator -> Validity Checker -> Metric Aggregator
**Critical path:** Fixed DE table → Prompt injection → Repeated LLM queries → Parse outputs → Compare to regime-specific reference → Compute stability/correctness metrics → Validate gene IDs against input table.
**Design tradeoffs:**  
- Deterministic decoding (temperature=0) trades off creative sampling for stability measurement; may mask sampling-based failures.  
- Single dataset trades off generalizability for controlled isolation; findings may not transfer to other DE tables.  
- Fixed thresholds (FDR ≤ 0.05) vs. borderline regimes (0.05 < FDR ≤ 0.15) capture different failure modes (complete vs. partial failure).
**Failure signatures:**  
- High within-LLM stability (pairwise Jaccard ≈1.00) + low correctness (Jaccard ≈0.00) → Stable misalignment.  
- Low between-prompt similarity (Jaccard < 0.3) despite high within-prompt stability → Prompt sensitivity.  
- Non-zero count of invalid gene IDs → Hallucination under constraint.
**First 3 experiments:**  
1. Stability Baseline: For each model/prompt (e.g., P1), run 10 times with identical input. Compute mean pairwise Jaccard. Expect ≈1.00 for all.  
2. Correctness Check: For each model/prompt, compare output set to DESeq2 reference set for that regime (e.g., genes with padj ≤ 0.05 for P1). Compute mean Jaccard. Expect divergence from stability values (e.g., Claude = 0.00).  
3. Prompt Sensitivity Test: For P7a vs P7b, run 10 times each. Compute mean Jaccard between the two prompt outputs. Expect low values (e.g., Gemini = 0.08) despite high within-prompt stability.

## Open Questions the Paper Calls Out
- **Generalization:** To what extent do the observed failure modes generalize beyond differential expression analysis to other data-constrained scientific decision-making tasks and different LLM architectures? *Basis:* The authors note the evaluation focuses on a single dataset and statistical paradigm; extending to additional datasets and paradigms is an important future direction. *Evidence needed:* Replication across diverse scientific tasks, data types, and a wider range of models.
- **Underlying mechanisms:** What architectural, training-related, or prompt-processing mechanisms cause LLMs to exhibit near-perfect stability while simultaneously producing outputs that diverge from statistical ground truth or violate input-domain constraints? *Basis:* The study documents decoupling but does not investigate *why* models lock into consistent but incorrect reasoning paths or hallucinate deterministically. *Evidence needed:* Controlled probing (layer-wise ablation, adversarial prompts), internal representation analysis, comparisons across model families.
- **Robust proxy for correctness:** Can a more robust proxy for correctness be identified that is computationally cheaper than full ground-truth validation but more predictive than internal stability for high-stakes, data-constrained scientific decisions? *Basis:* The paper critiques stability as a proxy but does not propose or test alternative lightweight heuristics. *Evidence needed:* Empirical studies correlating various cheap metrics (e.g., entropy, consistency across diverse prompts, constraint adherence) with correctness on held-out tasks.
- **Prompt wording aspects:** What specific aspects of prompt wording (lexical, syntactic, semantic framing) are most likely to trigger large shifts in LLM prioritization outputs for borderline statistical items, and can this sensitivity be systematically reduced? *Basis:* The paper shows dramatic Jaccard drops for semantically similar prompts but does not characterize responsible features or test mitigation. *Evidence needed:* Large-scale systematic prompt variation to identify high-sensitivity features; interventions like explicit decision rules or fine-tuning.
- **Model-specific failure modes:** Why do different LLMs exhibit qualitatively distinct failure modes (e.g., Claude's systematic hallucination vs. ChatGPT/Gemini's prompt sensitivity) under identical, constrained data inputs, and are these differences stable across diverse scientific domains? *Basis:* The paper documents stark differences but cannot explain them. *Evidence needed:* Correlational analysis between observed failure modes and known model characteristics (training data, RLHF objectives); cross-domain tests with same prompt structures.

## Limitations
- The evaluation relies on a single DESeq2 differential expression table, limiting generalizability to other datasets or scientific tasks.
- Deterministic decoding (temperature=0) may conceal failures that appear under stochastic sampling.
- Key methodological details are unspecified: aggregation method for prompt sensitivity, tie-breaking rules for ranking ground truth, and exact gene identifier normalization.
