# Standard Transformers Achieve the Minimax Rate in Nonparametric Regression with $C^{s,λ}$ Targets
## Quick Facts
- **arXiv ID:** 2602.20555
- **Source URL:** https://arxiv.org/abs/2602.20555
- **Reference count:** 40
- **Primary result:** Standard Transformers attain the minimax optimal rate for nonparametric regression with Hölder smooth functions $C^{s,λ}$.

## Executive Summary
The paper establishes a landmark theoretical result: standard Transformer architectures, without any architectural modifications, are capable of achieving the minimax optimal rate for nonparametric regression when the target function belongs to a Hölder smoothness class $C^{s,λ}$. By constructing an explicit Transformer estimator that approximates smooth functions arbitrarily well and deriving an excess risk bound that matches the classical minimax rate up to poly‑logarithmic factors, the authors prove that Transformers possess the statistical capacity required for nonparametric learning. This bridges the gap between practical deep learning models and classical nonparametric theory, showing that the empirical success of Transformers is not merely coincidental but theoretically justified.

The core of the work is a constructive approximation scheme that decomposes the problem into four Transformer‑implementable modules: a grid‑rounding step that maps inputs to anchor points, a memorisation branch that retrieves pre‑stored Taylor coefficients, a monomial branch that approximates the Taylor remainder, and a parallel aggregation that combines all terms. The grid resolution $K$ governs the trade‑off between approximation accuracy and network size. With $\gamma = s+\lambda$, the approximation error scales as $K^{-\gamma}$, and the resulting estimator under Gaussian noise attains the minimax risk $\Theta(m^{-2\gamma/(2\gamma+dn)})$, where $m$ is the sample size and $dn$ the total input dimension. Thus, standard Transformers are statistically optimal for a wide range of smoothness levels.

## Method Summary
The proposed estimator begins by discretising the domain $[0,1]^{d \times n}$ into a grid of spacing $1/K$. An initial feedforward block rounds each input token down to the anchor of its containing cube. Two parallel branches then operate: (i) a memorisation branch uses attention with a fixed positional encoding to assign each anchor a unique identifier, which is transformed into the memorised Taylor coefficients of the target function at that grid point; (ii) a monomial branch approximates the displacement from the anchor raised to multi‑indices using ReLU subnetworks, with exact multiplication by the coefficients approximated by small feedforward modules. A parallelisation trick (Lemma 3) enables all products and their sum to be computed in a single feedforward block, effectively building the truncated Taylor polynomial. The grid size is chosen as $K = \Theta(\varepsilon^{-1/\gamma})$ to achieve a target approximation error $\varepsilon$. The resulting deterministic approximator serves as the regression function, and its risk under additive Gaussian noise is bounded by covering‑number arguments that leverage the Transformer’s size tuple and dimension vector. The final excess risk matches the classical minimax rate $\Theta(m^{-2\gamma/(2\gamma+dn)})$, confirming that standard Transformers are adaptively optimal for Hölder smooth regression.

## Key Results
- Achieves minimax optimal nonparametric regression rates for Hölder smooth functions $C^{s,λ}$.
- Provides both $L^t$ (arbitrary precision) and $L^\infty$ (larger cost) approximation guarantees with rate $\varepsilon \sim K^{-\gamma}$.
- Excess risk bound under Gaussian noise matches the classical minimax rate $\Theta(m^{-2\gamma/(2\gamma+dn)})$.

## Why This Works (Mechanism)
### Mechanism 1
The input space is partitioned into axis‑aligned cubes of side $1/K$. An embedding layer adds a constant offset, and a depth‑3 ReLU feedforward block (Lemma 6) rounds each coordinate down to the nearest multiple of $1/K$. Inside a cube $\Omega_j$ the output equals the grid anchor $X^{(j)}$; on a boundary layer of width $\delta$ it varies linearly. The Hölder smoothness $f\in C^{s,λ}$ implies that the Taylor remainder on any cube is bounded by $C K^{-\gamma}$ with $\gamma=s+\lambda$. Choosing $K=\Theta(\varepsilon^{-1/\gamma})$ ensures interior error at most $\varepsilon$, while $\delta=\Theta(\varepsilon^{(7dn+\gamma+2)/\gamma})$ controls boundary contributions. Failing to set $K$ or $\delta$ appropriately leads to larger approximation error.

### Mechanism 2
The memorisation branch leverages contextual mapping to store Taylor coefficients $\{c_{i,j}\}$ for each grid point. The anchor $X^{(j)}$ is combined with a fixed positional encoding matrix $E$ and processed by a special Transformer layer $T^{\text{mmr}}$ that assigns a unique numeric identifier to each token, exploiting the separation $r>\rho$ among grid points. A subsequent feedforward network (Lemma 15) decodes these identifiers into the stored coefficient vectors. The construction requires head count $H_1$ and head size $S_1$ scaling as $\Theta(K^{dn})$ to avoid collisions; otherwise distinct grid points would retrieve identical IDs, breaking memorisation.

### Mechanism 3
The monomial branch builds the Taylor remainder $ \sum_i c_{i,j} (x - X^{(j)})^{\alpha_i} $. For each multi‑index $\alpha$, a ReLU feedforward network approximates the monomial $x^\alpha$ on $[0,1]^{dn}$ to error $\varepsilon_1$ (Lemma 9), and a small network approximates the product $c \cdot x^\alpha$ to $\varepsilon_2$ (Lemma 10). Parallelisation (Lemma 3) aggregates all such products in one feedforward block, yielding the full Taylor polynomial. The errors $\varepsilon_1, \varepsilon_2$ are budgeted as $O(\varepsilon/(C d n))$; the required depth scales as $O(\log 1/\varepsilon)$ while width scales polynomially in $1/\varepsilon$. If the monomial approximators are too shallow or narrow, the total approximation error exceeds $\varepsilon$.

## Architecture Onboarding
- **Component map:** 
  Embedding layer $(W^{EB}, B^{EB})$ → Feedforward block FF₀ (grid rounding) → Parallel branches:
    - Memorisation branch: anchor $+$ positional encoding $E$ → $T^{\text{mmr}}$ → coefficient vectors $c_{i,j}$.
    - Monomial branch: displacement $(x - \text{anchor})$ → $T^{\text{mnm}}$ → approximated monomials $x^\alpha$ → multiplication networks $\cdot c$ → aggregation via $F^{\text{prl‑mtp}}$ → Taylor polynomial.
  Final feedforward block FF$_K$ → scalar output (via selecting the $(1,1)$ entry of $E_{11}$).
- **Critical path:**
  1. Input $X \in \mathbb{R}^{d \times n}$ passes through embedding to produce token matrix $Y_0$.
  2. FF₀ maps each token to the anchor of its containing grid cube.
  3. Two branches process the anchor and the displacement in parallel:
     - Memorisation branch: anchor $+$ fixed $E$ → $T^{\text{mmr}}$ (contextual mapping) → decode IDs to Taylor coefficients.
     - Monomial branch: displacement → $T^{\text{mnm}}$ (ReLU subnetworks) → approximate each monomial and multiply by the corresponding coefficient.
  4. Parallel aggregation (Lemma 3) sums all products to form the full Taylor polynomial.
  5. FF$_K$ refines the polynomial and produces the final scalar estimate.
- **Design tradeoffs:**
  - Grid size $K$: $\varepsilon \approx K^{-\gamma}$, but memorisation width $H_1 \propto K^{d n}$ and weight bounds grow polynomially in $K$.
  - $L^\infty$ vs $L^t$: $L^\infty$ approximation requires a horizontal shift construction (Lemma 2), which multiplies the number of parallel Transformer copies by $3^{d n}$ and inflates $H_1, S_1$.
  - Width‑depth balance: Monomial depth $L_n = O(\log 1/\varepsilon)$, width $W_n = O(\varepsilon^{-d n/\gamma})$; in high dimensions width dominates.
  - Weight bounds: $B_{\text{FF}}$ scales as $\varepsilon^{-\max\{(6dn+2)/\gamma, 1/\lambda\}}$; large values may hinder optimisation and loosen covering‑number bounds.
- **Failure signatures:**
  - Interior error too high → $K$ too small (check $K$ vs. $\varepsilon$).
  - Coefficient collisions → memorisation branch outputs identical for distinct grid points; inspect $H_1, S_1$ and the positional encoding $E$.
  - Monomial mismatch → monomial branch error exceeds $\varepsilon_1$; increase depth/width of the underlying FNNs.
  - Boundary blow‑up → output magnitude $\propto \varepsilon^{-(7dn+2)/\gamma}$ on the boundary layer $\Omega^{\text{flaw}}$; ensure $\delta$ is properly tuned or avoid boundary regions.
- **First 3 experiments:**
  1. **Approximation sanity:** Set $d=n=1$, $s=2$, $\lambda=0.5$, target $f(x)=x^3$. Build the Transformer per Theorem 1 with $\varepsilon=0.1$. Verify $\max_{x\in[0,1]} |T(x)-f(x)| \le \varepsilon$.
  2. **Memorisation test:** Use only the memorisation branch with $K=5$ (125 grid points). Feed all grid anchors, check that the output exactly equals the pre‑computed Taylor coefficients. Increase $K$ until failure to confirm the required scaling of $H_1$.
  3. **Monomial validation:** Test the monomial branch (Lemmas 8‑10) for various multi‑indices $\alpha$. Compare $f_{\text{mnm}}(x)$ to $x^\alpha$ on a fine mesh and vary the depth to confirm empirical error follows the predicted logarithmic scaling.

## Limitations
- Parameter explosion: The memorisation branch requires $H_1, S_1 \propto K^{d n}$ and weight bounds grow as $\varepsilon^{-(7dn+2)/\gamma}$, becoming astronomically large for moderate $d n$ or small $\varepsilon$.
- Memorisation separation: The distinct‑ID mechanism relies on exponential head dimensions; it is unclear whether standard self‑attention without explicit identifiers can achieve the necessary separation.
- Training gap: The risk bound is proved for the exact constructed estimator; there is no guarantee that gradient‑based training of a Transformer converges to this estimator, leaving a significant gap between theory and practice.
