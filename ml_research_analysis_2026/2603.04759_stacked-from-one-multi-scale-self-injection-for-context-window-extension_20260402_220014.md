# Stacked from One: Multi-Scale Self-Injection for Context Window Extension

## Quick Facts
- **arXiv ID:** 2603.04759
- **Source URL:** https://arxiv.org/abs/2603.04759
- **Reference count:** 23
- **Primary result:** SHAREDLLM extrapolates to 128K+ tokens despite 8K training, yielding 2× inference speedup and lower memory than baselines.

## Executive Summary
Large language models face a critical context window limit, and extending it via continual pretraining is computationally expensive. This paper introduces SHAREDLLM, a hierarchical framework that stacks two LLMs derived from the same base model: a compressor that encodes long inputs into a multi-granular context tree of compressed key-value states, and a decoder that attends to this tree via cross-attention in its early layers. This design enables query-aware information selection, parallel processing, and minimal additional memory overhead. Evaluations show that SHAREDLLM extrapolates to sequences over 128K tokens—far beyond its 8K training length—while achieving lower perplexity on academic long-document benchmarks (Arxiv, PG19, ProofPile) and competitive scores on LongBench and InfiniBench. It also reduces memory footprint and provides significant inference speedups relative to streaming and encoder-decoder alternatives.

## Method Summary
SHAREDLLM employs two stacked models initialized from the same base LLM. The lower model (compressor) processes long input sequences sequentially, constructing a hierarchical context tree where each node stores compressed KV states at a different granularity. The upper model (decoder) integrates this tree through cross-attention mechanisms applied only in its early layers, allowing it to dynamically select relevant compressed context per query. This separation avoids the quadratic cost of full self-attention on long sequences. The self-injection approach—using identical weights for compressor and decoder—minimizes training overhead and ensures representation consistency. The multi-scale tree enables parallel encoding and efficient, query-driven retrieval without scanning the entire context.

## Key Results
- Despite training on only 8K-token sequences, SHAREDLLM generalizes to 128K+ tokens, outperforming positional encoding methods (YaRN) and relative position approaches (CEPE) on language modeling perplexity across Arxiv, PG19, and ProofPile.
- Achieves comparable or superior scores on LongBench and InfiniBench for long-context tasks.
- Reduces memory usage and delivers 2× faster inference than streaming methods and 3× faster than encoder-decoder architectures under comparable settings.

## Why This Works (Mechanism)
The hierarchical decomposition shifts the computational burden: the compressor sequentially builds a compact, multi-resolution representation, while the decoder attends to this summary in parallel. Self-injection aligns the feature spaces of both models, avoiding mismatch. The tree structure supports query-aware selection because cross-attention can route to different granularities (e.g., fine-grained for specific details, coarse-grained for broad context) based on the decoder’s current state. This mimics human skimming strategies and avoids the uniformity penalty of single-scale compression. Parallel tree construction and selective cross-attention also sidestep the sequential bottleneck of standard attention, yielding speed gains.

## Architecture Onboarding
**Component map:** Base Model → Compressor (lower layers) → Multi-Granular Context Tree → Decoder (upper layers with cross-attention to tree) → Output

**Critical path:** Input sequence → Compressor processes sequentially to populate tree nodes (each node aggregates a segment) → Tree stored in memory → Decoder’s early layers apply cross-attention to tree nodes → Decoder generates tokens autoregressively.

**Design tradeoffs:** 
- Compression ratio vs. information retention: Higher compression reduces memory but risks losing details.
- Tree depth/branching vs. lookup cost: Deeper trees offer finer granularity but increase cross-attention complexity.
- Shared weights vs. specialization: Self-injection cuts training cost but may limit adaptability to distinct compression/decoding roles.

**Failure signatures:** 
- Perplexity spikes on documents >32K tokens despite 128K extrapolation claims.
- Cross-attention heads apprend uniform patterns, indicating poor query-driven selection.
- Memory savings diminish as tree depth increases due to overhead from node pointers.

**First experiments:**
1. Validate tree fidelity: Compress a document, then reconstruct it from the tree using a separate decoder; compute token-level accuracy.
2. Test self-injection necessity: Train with separate compressor and decoder initializations; compare final perplexity and training stability.
3. Measure scaling limits: Incrementally increase input length from 8K to 200K tokens during inference; plot perplexity curve to identify breakdown point.

## Open Questions the Paper Calls Out
The paper does not explicitly list open questions. Potential undiscussed directions include extending to non-transformer architectures (e.g., MoE), theoretical analysis of tree optimality, and robustness to noisy or poorly structured long texts.

## Limitations
- Training exposure only up to 8K tokens; robustness to vastly longer contexts without in-training data remains uncertain.
- Baselines may omit recent efficient context methods (e.g., StreamingLLM, FlashAttention-2), possibly narrowing comparative advantage.
- Zero average citations suggest very recent publication or limited peer recognition; independent validation is pending.
- Self-injection ties performance to a single base model; generalizability across diverse model families is unproven.

## Confidence
- **Context extension efficacy (128K+):** Medium — Validated on three academic datasets but task diversity is limited (primarily language modeling).
- **Efficiency gains (memory/speed):** Medium — Claims based on reported benchmarks; independent hardware profiling required.
- **Query-aware selection via tree:** Low — Mechanism analyzed qualitatively; no ablation isolating hierarchical tree utility against naive KV compression.
