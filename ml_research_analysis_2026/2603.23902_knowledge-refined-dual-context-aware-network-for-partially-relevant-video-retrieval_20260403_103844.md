# Knowledge-Refined Dual Context-Aware Network for Partially Relevant Video Retrieval

## Quick Facts
- **arXiv ID:** 2603.23902
- **Source URL:** https://arxiv.org/abs/2603.23902
- **Reference count:** 33
- **Primary result:** Achieves new state-of-the-art on TVR (SumR 184.9%, R@1=15.4%) and ActivityNet Captions, with particularly robust performance on low moment-to-video ratios.

## Executive Summary
KDC-Net is a novel framework for partially relevant video retrieval (PRVR) that tackles two key challenges: the mismatch in information density between text queries and video content, and the difficulty of modeling temporal structure in untrimmed videos. It introduces three synergistic modules—Hierarchical Semantic Aggregation (HSA) to enrich query semantics with multi-scale phrase cues, Dynamic Temporal Attention (DTA) to highlight coherent events via relative positional encoding and adaptive windows, and Knowledge Refinement Distillation (KRD) to denoise CLIP-based supervision using temporal continuity priors. Evaluated on TVR and ActivityNet Captions, KDC-Net sets new state-of-the-art results and demonstrates strong performance on retrievals with sparse relevance, confirming the effectiveness of its design.

## Method Summary
KDC-Net employs a dual-branch student architecture that inherits knowledge from a frozen CLIP teacher while exploring refined representations. The text encoder processes the query with HSA, which extracts phrase-level features at multiple scales via sliding windows and adaptively fuses them to produce enriched word representations. The video encoder processes frame features through multiple DTA layers, where each attention head includes a relative position bias, a dynamic local window mask, and Purification Normalization to reduce redundancy. The teacher CLIP model generates frame-query similarity distributions that are refined by KRD using adaptive thresholds and a temporal continuity prior; the student then distills this cleaned distribution via KL loss alongside standard ranking losses. Training combines exploration (ranking-based) and inheritance (distillation-based) objectives, and inference fuses the two branch scores with a weighting factor.

## Key Results
- New state-of-the-art on TVR (SumR 184.9%, R@1=15.4%) and ActivityNet Captions.
- Robust performance on low moment-to-video ratio intervals, demonstrating effective handling of sparse relevance.
- Ablation studies confirm each of the three proposed components (HSA, DTA, KRD) is essential for full performance.

## Why This Works (Mechanism)

### Mechanism 1: Hierarchical Semantic Aggregation (HSA)
- **Claim:** HSA resolves the text-video information density mismatch by explicitly modeling multi-scale textual phrases, enriching query semantics beyond word-level tokens.
- **Mechanism:** Sliding windows generate phrase-level features via self-attention and pooling. A learnable fusion aggregates these multi-scale context vectors back into word features, yielding a compositionally structured query representation.
- **Core assumption:** Natural language queries possess an inherent hierarchical compositional structure (phrases of varying granularity) critical for fine-grained alignment with video events.
- **Evidence anchors:** abstract statement; equations for multi-scale phrase extraction (Eq. 1) and adaptive fusion (Eq. 2); similar recognition in related work but adaptive fusion is novel.
- **Break condition:** If adaptive fusion weights β(m) fail to learn meaningful scale importance (e.g., uniformly distributed), the hierarchical enrichment collapses to flat aggregation.

### Mechanism 2: Dynamic Temporal Attention (DTA)
- **Claim:** DTA enables robust temporal modeling by injecting relative positional priors and adaptive local windows, focusing computation on coherent events while suppressing irrelevant frames.
- **Mechanism:** Adds learnable relative position bias (b_i,j) to attention scores and a dynamic window mask (m_i,j) that restricts attention to a local neighborhood of radius U. Purification Normalization (PN) further reduces feature redundancy.
- **Core assumption:** Relevant video segments exhibit local temporal coherence, and modeling dependencies within adaptive windows is more effective than global uniform attention.
- **Evidence anchors:** abstract statement; DTA score formulation (Eq. 3), window mask definition (Eq. 4), and PN redundancy subtraction (Eq. 5); related work often uses fixed windows.
- **Break condition:** If performance degrades when relative position bias is removed or when window size U is fixed globally (shown in DTA parameter ablation), confirming the necessity of dynamic, position-aware local attention.

### Mechanism 3: Knowledge Refinement Distillation (KRD)
- **Claim:** KRD denoises CLIP's supervision by leveraging temporal continuity priors, producing a cleaner similarity distribution for student training.
- **Mechanism:** Dynamically thresholds teacher confidence scores (τ_high, τ_low) based on batch statistics. A sliding window enhances/suppresses scores based on local consistency, modulating adjustment strength α via mean and dispersion. Student learns via KL divergence to this refined distribution.
- **Core assumption:** Genuine relevant moments in video exhibit temporal continuity, leading to locally consistent high-confidence scores in the teacher's (noisy) output.
- **Evidence anchors:** abstract statement; adaptive threshold equations (Eq. 7), local window adjustment with indicator I(i) and α (Eq. 8), KL loss (Eq. 9); prior distillation methods use raw CLIP scores.
- **Break condition:** If refined distribution ˜s_t_i correlates poorly with ground-truth relevance compared to raw teacher scores S_t, the continuity prior is invalid for the data distribution.

## Foundational Learning

### Multi-Scale Feature Aggregation
- **Why needed:** HSA requires understanding how to extract and combine representations at different granularities (word, phrase, sentence).
- **Quick check:** "How would you design a sliding window mechanism to capture phrases of lengths 2, 3, and 4 tokens, and what problem might arise from overlapping windows?"

### Relative Positional Encoding in Attention
- **Why needed:** DTA replaces absolute or no position encoding with learnable relative biases to model temporal order without permutation invariance.
- **Quick check:** "Why is standard self-attention permutation-invariant, and how does adding a bias based on (j-i) help capture temporal structure in videos?"

### Knowledge Distillation with Signal Refinement
- **Why needed:** KRD assumes teacher outputs (CLIP) are noisy and require preprocessing; standard distillation treats teacher output as ground truth.
- **Quick check:** "What is the risk of using CLIP's frame-text similarity scores directly for video segment retrieval, and how does temporal continuity help identify noise?"

## Architecture Onboarding

### Component Map
- Text Encoder (Student): Input tokens → HSA module → enhanced word features → pooled query embedding.
- Video Encoder (Student): Frame features → DTA blocks (with relative bias, dynamic window mask, PN) → segment embedding.
- Teacher (CLIP): Frozen image & text encoders → frame-wise and global query embeddings → raw similarity distribution S_t.
- KRD Module: Applies temporal-continuity-based refinement to S_t → ˜S_t.
- Dual-Branch Learning: Inheritance branch (matches teacher via L_I + KRD), Exploration branch (L_E). Inference fuses both branches with weight δ.

### Critical Path
Training: (Q, V) → Student text/video branches → dual embeddings → similarity scores → L_E, L_I + w·L_KRD. KRD runs in parallel: (Q, V) → Teacher → S_t → refine → ˜S_t → L_KRD target. Inference: Only student branches, similarity fusion.

### Design Tradeoffs
- DTA window size U: Larger U captures long-term dependencies but increases computation and noise; smaller U focuses on local events but misses global context. Optimal found at U=20 (with relative position up to 30) on TVR.
- KRD window size: Small (k=2) limits context; large (k≥6) introduces irrelevant frames. Optimal k=3 balances local coherence.
- PN λ: Under-regularization (λ<0.1) leaves redundancy; over-regularization (λ>0.1) loses discriminative info. Sharp performance drop beyond λ=0.1.
- Branch weight δ: δ=0.1 (heavier on inheritance branch) works best; δ=0 (exploration only) or δ=1 (inheritance only) underperform, showing dual-branch synergy.

### Failure Signatures
- Degraded performance on low M/V ratio intervals (e.g., (0, 0.2] in Table I) if HSA fails to capture fine-grained phrases or DTA windows are too large/noisy.
- Ablation: Removing KRD causes larger drop on datasets with noisier CLIP signals, indicating distillation quality sensitivity.
- Training instability: If α in KRD is not modulated by µ_s and σ_s, thresholding becomes too aggressive/lenient, causing KL divergence spikes.

### First 3 Experiments
1. **Ablation:** Remove one module at a time (Table II). Compare full model vs. -HSA, -DTA, -KRD on R@1/SumR to confirm necessity.
2. **DTA hyperparameter sweep:** Vary max relative position (10, 20, 30, 40) and window size U (10, 15, 20, 25) jointly. Expect optimal ratio ~1.5 (position range / window size).
3. **KRD window size sensitivity:** Test k ∈ {2,3,4,5,6} on TVR validation. Expect peak at k=3; performance drop for k≥5 due to noise inclusion.

## Limitations
- Feature extraction details (MS-SL backbone, preprocessing) are not fully specified, risking replication fidelity.
- The mechanism for DTA’s “dynamic multi-scale temporal windows” is ambiguous; it is unclear whether windows are truly adaptive or fixed.
- KRD’s adaptive thresholding may be unstable with small batch sizes, and the distillation weight decay schedule is not provided.

## Confidence
- HSA: Medium (non-uniform fusion weights need verification)
- DTA: High (strong ablation evidence and consistent gains)
- KRD: Medium (relies on temporal continuity prior without explicit correlation analysis)
