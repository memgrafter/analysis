# BlackMirror: Black-Box Backdoor Detection for Text-to-Image Models via Instruction-Response Deviation

## Quick Facts
- arXiv ID: 2603.05921
- Source URL: https://arxiv.org/abs/2603.05921
- Reference count: 40
- Primary result: Training-free black-box detector achieving 89.46% average F1 and 15.09% FPR across diverse backdoor attacks, matching white-box methods.

## Executive Summary
BlackMirror introduces a novel two-stage framework for detecting backdoor attacks in text-to-image (T2I) models under black-box settings. Unlike prior methods that rely on global image-text similarity and fail against localized attacks, BlackMirror identifies fine-grained semantic deviations between the input prompt and generated image using a vision-language model (VLM). It then verifies the stability of these deviations across prompt variations to distinguish true backdoor behavior from natural model biases. The approach is training-free, plug-and-play, and effective across object replacement, patch insertion, and style manipulation attacks, outperforming the black-box baseline UFID significantly.

## Method Summary
BlackMirror operates in two stages: MirrorMatch and MirrorVerify. In MirrorMatch, it extracts visual patterns from the prompt (via an LLM) and the generated image (via a VLM with majority voting). It computes deviations: objects appearing in the image but not the prompt (`O_new`) and objects in the prompt missing from the image (`O_lost`). Parallel branches handle patch and style deviations via binary VLM queries. In MirrorVerify, for each suspicious pattern, it generates multiple prompt variations by removing "safe" aligned patterns from the original prompt. New images are synthesized for these variants, and the VLM is queried to measure the stability (consistency) of the deviation pattern across generations. If the maximum stability score exceeds a high threshold (τ=0.999), the model is flagged as backdoored. The process requires no training and only a few VLM queries per sample.

## Key Results
- Achieves average F1 score of 89.46% and false positive rate (FPR) of 15.09% across object, patch, and style backdoor attacks.
- Outperforms black-box baseline UFID (F1 72.29%, FPR 48.78%) and matches white-box methods.
- Effective even when only partial semantics are manipulated, where global similarity detectors fail.

## Why This Works (Mechanism)
### Mechanism 1: Fine-Grained Deviation Detection via MirrorMatch
Backdoor attacks often manipulate only localized visual patterns (e.g., a specific object or patch) while the rest of the image aligns with the prompt. MirrorMatch uses a VLM to extract object sets from both prompt (`O_ins`) and image (`O_res`), then identifies new objects (`O_new = O_res - O_ins`) and lost objects (`O_lost = O_ins - O_res`). This fine-grained mismatch captures partial semantic deviations that global image-text similarity misses. Evidence includes the paper's observation that "only partial semantic patterns within the generated image are steadily manipulated" and the described extraction process.

### Mechanism 2: Stability Verification via Pattern Masking
Backdoor-induced deviations are stable across prompt variations that preserve the trigger, whereas benign model biases or VLM noise tend to be unstable. MirrorVerify creates prompt variants by randomly removing "safe" patterns (those aligned between prompt and image). For each variant, it generates an image and queries the VLM to check if the suspicious pattern persists. The stability score is the average presence/absence probability (or binary consistency) over N variations. A high score indicates the deviation is likely caused by a backdoor, not incidental bias. Evidence includes abstract statement about evaluating stability and results in Fig. 5 showing backdoor deviations persist while bias-induced ones vanish.

### Mechanism 3: Multi-Attack Generalization via Parallel Branches
Different attack types (object replacement, patch insertion, style manipulation) manifest as different kinds of pattern deviations. BlackMirror runs three parallel detection branches, each tailored to extract and verify a specific deviation type using customized VLM prompts. A backdoor is flagged if any branch yields a stability score above threshold. This allows the framework to handle diverse attacks without prior knowledge of which one is present. Evidence includes the three-fold detection process (section 3.3.3) and evaluation across multiple attack types (Table 1).

## Architecture Onboarding
- **Component map**: Original prompt x and image I -> LLM extracts O_ins and style/patch flags; VLM (K=5 majority votes) extracts O_res -> Compute deviations O_new, O_lost, O_safe -> Prompt variation generator (remove random O_safe, N=5) -> For each variation, generate image and query VLM for pattern presence -> Compute stability scores s_new, s_lost, s_style, s_patch -> If max(s_final) > τ (0.999) flag backdoor. Parallel branches for object, patch, style run identical pipelines with different VLM queries.

- **Critical path**: Prompt variation generation → image synthesis → VLM verification queries. The number of VLM queries per sample is m (average ~3.14) after pattern filtering, much lower than UFID's O(N²) pairwise comparisons.

- **Design tradeoffs**:  
  - *VLM dependence*: Accuracy tied to VLM grounding; poor VLM increases false positives/negatives.  
  - *Computation vs. robustness*: More generations (N>5) improves stability estimation but increases cost; N=5 chosen as sweet spot.  
  - *Threshold τ*: High τ (0.999) reduces FPR but may miss subtle backdoors; chosen empirically for F1/FPR balance.

- **Failure signatures**:  
  - High FPR: If O_safe extraction is noisy, benign deviations appear stable. Mitigated by majority voting and N=5.  
  - False negatives on global attacks: FixImgAtt may not produce O_new/O_lost; reliance on style/patch branches or global similarity.  
  - VLM misinterpretation: If VLM misses subtle patch/style, branch fails.

- **First 3 experiments**:  
  1. Replicate UFID and CLIPD on a known ObjRepAtt (e.g., BadT2I) to confirm their low F1/high FPR.  
  2. Ablate MirrorVerify (use only MirrorMatch) to observe FPR near 100%, proving stability check necessity.  
  3. Sweep N (1→5) and τ (e.g., 0.5→0.9999) on a PatchAtt to see FPR decrease and F1 plateau, selecting robust defaults.

## Open Questions the Paper Calls Out
### Open Question 1
How does BlackMirror generalize to novel or hybrid backdoor attacks beyond the three predefined types (object, patch, style)? The framework assumes awareness of possible attack types; unknown or combined manipulations may evade detection. Evidence needed: evaluation on synthesized hybrid attacks to measure failure rates.

### Open Question 2
To what extent does performance depend on the specific VLM used, and can reliance on VLMs be reduced without sacrificing accuracy? The conclusion notes VLM evolution will improve BlackMirror, but alternative grounding methods (e.g., object detectors) are unexplored. Evidence needed: ablation with diverse VLMs across attack types.

### Open Question 3
Is the fixed stability threshold τ=0.999 universally optimal, or does it require per-attack/model calibration? The threshold was chosen empirically on SDv1.5; its robustness to distribution shifts is unknown. Evidence needed: threshold sweeps across multiple T2I models and prompt sets.

### Open Question 4
How resilient is BlackMirror to adaptive attacks that explicitly target its two-stage logic? Evaluation uses non-adaptive attacks; adversaries could optimize backdoors to produce unstable deviations or align with prompt semantics. Evidence needed: design and test adaptive attack variants.

## Limitations
- Masking method for safe pattern removal is unspecified, affecting variation semantics.
- Detection is limited to predefined deviation types (object, patch, style); novel attacks may evade.
- Performance depends critically on VLM grounding accuracy; biases or errors in VLM cause false detections.
- Fixed threshold τ may not generalize to all models/attacks without calibration.

## Confidence
- **MirrorMatch fine-grained deviation detection**: Medium. Supported by ablations and visuals, but relies on VLM extraction quality and partial manipulation assumption; global attacks weaken it.
- **MirrorVerify stability discrimination**: Medium. Stability check distinguishes backdoor vs bias, but prompt variation design and safe pattern identification are critical; trigger masking risks false negatives.
- **Generalization across attack types**: Medium. Strong results on four attacks, but only known categories; novel attacks untested.
