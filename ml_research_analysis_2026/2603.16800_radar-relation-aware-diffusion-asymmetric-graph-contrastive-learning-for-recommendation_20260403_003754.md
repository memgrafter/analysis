# RaDAR: Relation-aware Diffusion-Asymmetric Graph Contrastive Learning for Recommendation

## Quick Facts
- **arXiv ID:** 2603.16800
- **Source URL:** https://arxiv.org/abs/2603.16800
- **Reference count:** 40
- **Primary result:** RaDAR achieves state-of-the-art performance on three binary-edge recommendation benchmarks, improving Recall@20 by up to 4.65% and NDCG@20 by up to 4.76% over the previous best (AdaGCL) with statistically significant gains (p < 0.001).

## Executive Summary
RaDAR is a novel graph contrastive learning framework for recommendation systems that tackles two critical challenges: structural signal distortion caused by random edge perturbations and limited signal propagation due to data sparsity. It introduces a dual-view approach combining a graph generative model that captures global structure and a relation-aware denoising model that refines noisy edges. Key innovations include asymmetric contrastive learning with global negatives, diffusion-guided progressive noise/denoising, and dynamic edge reweighting based on node semantics. Evaluated on three binary-edge datasets (Last.FM, Yelp, BeerAdvocate), RaDAR consistently outperforms state-of-the-art baselines, yielding substantial improvements in Recall@20 and NDCG@20. The method also demonstrates strong robustness under injected noise and extreme sparsity conditions.

## Method Summary
RaDAR employs a dual-view architecture. The first view uses a graph generative model to learn a global structure representation, often by reconstructing the adjacency matrix or node embeddings. The second view applies a relation-aware denoising model that progressively removes or corrects noisy edges guided by a diffusion process. During training, the two views are aligned via asymmetric contrastive learning, where one view provides positive pairs and the other supplies negatives that include both local and global negatives. Edge weights are dynamically adjusted based on node semantics to emphasize reliable connections. This design mitigates distortions from random edge perturbations and enhances signal propagation in sparse graphs.

## Key Results
- Outperforms SOTA on three binary-edge datasets: Recall@20 +4.65%, NDCG@20 +4.76% over AdaGCL (p < 0.001).
- Demonstrates superior robustness under injected noise and extreme sparsity.
- Achieves consistent gains across Last.FM, Yelp, and BeerAdvocate benchmarks.

## Why This Works (Mechanism)
RaDAR's effectiveness stems from its dual-view design. The generative model captures global graph structure, providing a robust representation that is less sensitive to local noise. The relation-aware denoising model uses a diffusion process to progressively refine edges, correcting distortions from random perturbations. Asymmetric contrastive learning leverages global negatives, which enrich the supervisory signal and prevent alignment collapse. Dynamic edge reweighting focuses learning on semantically important connections, further improving robustness. Together, these components mitigate structural distortion and enhance signal propagation in sparse graphs.

## Architecture Onboarding
**Component map:**  
Interaction Graph -> Generative Model -> Global View  
Interaction Graph -> Denoising Model -> Denoised View  
Global View + Denoised View + Global Negative Bank -> Asymmetric Contrastive Learning -> Contrastive Loss  
Node Semantics -> Dynamic Edge Reweighting (feeds into Denoising Model and Contrastive Loss)

**Critical path:** Input graph is processed in parallel by the generative model (producing a global view) and the relation-aware denoising model (producing a refined view). These two views are then fed into the asymmetric contrastive learner with a set of global negatives to compute the loss. Dynamic edge reweighting, driven by node semantics, continuously adjusts edge importance during training, influencing both the denoising and contrastive stages.

**Design tradeoffs:** The dual-view design increases computational overhead but significantly improves robustness and representation quality. Asymmetric contrastive learning reduces the noise from false negative pairs but requires careful temperature tuning. Diffusion-guided progressive denoising balances noise removal with signal preservation, albeit adding complexity to the training schedule. Dynamic edge reweighting adds overhead but adapts the model to semantic relevance.

**Failure signatures:** If the generative model underfits, the global view may be too coarse, limiting alignment quality. The denoising model could over-smooth edges, removing useful connections. A poorly set temperature in asymmetric contrast may cause misalignment or collapse. Edge reweighting might downweight genuinely informative edges if node semantics are not properly captured.
