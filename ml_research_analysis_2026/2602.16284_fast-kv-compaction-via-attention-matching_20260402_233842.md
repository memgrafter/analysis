# Fast KV Compaction via Attention Matching

## Quick Facts
- **arXiv ID:** 2602.16284  
- **Source URL:** https://arxiv.org/abs/2602.16284  
- **Reference count:** 40  
- **Primary result:** Achieves up to 50× KV cache compaction on a single H100 in seconds while matching the quality of gradient-based Cartridges but 100× faster, and reaches ~65% accuracy on QuALITY with AM-OMP at 50× ratio.

## Executive Summary
Long-context transformer models face scalability bottlenecks due to the size of the KV cache. Existing solutions either sacrifice accuracy (e.g., summarization) or incur high computational cost (e.g., gradient-based Cartridges). This paper introduces Attention Matching, a novel compaction method that constructs a compact KV cache in latent space by matching both the locally normalized attention outputs and the unnormalized attention mass under reference queries. The problem decomposes into closed-form subproblems: selecting a subset of original keys (via highest-attention or OMP), fitting per‑token biases via nonnegative least squares, and computing compact values via ordinary least squares. Attention Matching thus avoids end‑to‑end gradient descent, achieving orders of magnitude speedup. Additional ingredients—nonuniform head budgeting based on sensitivity analysis and chunking for long contexts—further improve quality. Evaluated on QuALITY with Qwen3‑4B, the method achieves up to 50× compaction in seconds on a single H100, matching the accuracy of Cartridges but 100× faster. Ablations confirm that every component (biases, learned values, nonuniform budgets) is essential; self-study reference queries and nonuniform budgeting yield additional gains. The approach also extends to hybrid summarization (200×) and online compaction.

## Method Summary
Given a precomputed KV cache (K, V) for a context and a set of reference queries Qref, Attention Matching produces a compacted KV block that preserves the model’s attention behavior. For each attention head, it first selects a subset of original keys Ck using either a fast highest-attention heuristic or orthogonal matching pursuit (OMP). Then it solves for per‑token biases β via nonnegative least squares to match the total attention mass from Qref. Finally, it fits compact values Cv by ordinary least squares to match the attention outputs. The method relies on Qref being representative of future queries; otherwise, generalisation may suffer. Optional enhancements include nonuniform per‑head budget allocation based on precomputed sensitivity curves and chunking for long sequences. The entire pipeline uses closed‑form solutions and runs in seconds on a single GPU.

## Key Results
- Up to 50× KV cache compaction on a single H100 in seconds, matching Cartridges quality but 100× faster.
- On QuALITY (Qwen3‑4B), AM‑OMP achieves ~65% accuracy at 50× ratio, outperforming token‑selection baselines.
- Ablations confirm that biases, learned values, and nonuniform head budgets are all necessary; self‑study queries and nonuniform budgeting provide additional gains, and the method extends to hybrid summarization (200×) and online compaction.

## Why This Works (Mechanism)

### Mechanism 1: Matching outputs and mass ensures concatenation equivalence
**Claim:** A compact KV block (Ck, β, Cv) that matches the locally normalized attention output and the unnormalized attention mass relative to reference queries exactly reproduces the original attention when future KV blocks are appended.  
**How:** Attention over a concatenation of blocks decomposes into a mixture weighted by each block’s attention mass. By preserving both mass and output locally, the compacted block contributes identically to any concatenated sequence under arbitrary future queries (Appendix A.2).  
**Assumption:** The reference query set Qref adequately covers the distribution of queries that will arise when the compacted prefix is used.  
**Evidence:** Theoretical derivation in Section 2, Equations (1)–(5); decomposability argument (Eq. 5).  
**Break condition:** If Qref is unrepresentative (e.g., random vectors or narrow distribution), the compacted cache may not generalize to actual downstream queries, causing performance drops.

### Mechanism 2: Decomposition into subproblems enables closed‑form solutions
**Claim:** The attention‑matching objective naturally separates into three tractable subproblems—key subset selection, bias fitting via nonnegative least squares (NNLS), and value fitting via ordinary least squares—thus avoiding gradient descent at compaction time.  
**How:** After choosing a subset S of keys (Ck = K_S), β is determined by solving min\_{w≥0} ||Φ\_S w – m||² (NNLS) to match mass, where w = exp(β). Then Cv is found by a linear least squares to match outputs: X Cv = Y. The main computational challenge is selecting S; heuristics include highest‑attention (fast) and OMP (more accurate).  
**Assumption:** Restricting Ck to be a subset of original keys is sufficient; sequential solution yields a good local optimum.  
**Evidence:** Abstract mentions natural decomposition; Section 3 details Algorithms 1 (OMP) and 3 (NNLS/OLS). Ablations (Section 4.5) show that removing either β or learned values harms performance, validating the two‑stage fitting.  
**Break condition:** At extreme compaction ratios (<1%), the best compact keys may require linear combinations not present in any subset, making subset selection suboptimal relative to gradient‑based latent optimization.

### Mechanism 3: Nonuniform head budgeting via sensitivity analysis improves quality
**Claim:** Allocating compaction budgets nonuniformly across attention heads, based on each head’s sensitivity to KV loss, significantly improves quality compared to uniform allocation.  
**How:** For a given model, the loss change when varying a single head’s compaction ratio defines a sensitivity curve J_h(ρ). A greedy algorithm (Algorithm 4) uses these curves to redistribute a fixed total KV budget across heads to minimize predicted loss. The per‑head proportions are precomputed and remain stable across contexts.  
**Assumption:** Per‑head sensitivity is largely independent and stable across different input distributions, so a single schedule suffices.  
**Evidence:** Section 3.4 introduces the method; Appendix E shows stability (Figure 6) and provides sensitivity curves for different models (Figures 2, 7). Ablations (Section 4.5) report that removing nonuniform budgets (“No Head Budget”) causes the largest performance drop among ablated components.  
**Break condition:** If head sensitivity varies widely across domains or tasks, a fixed schedule may become suboptimal; the assumption of separable effects could fail under reallocation.

## Foundational Learning
**Attention mechanisms and KV caching in transformers**  
*Why needed:* Attention Matching directly manipulates the KV cache to preserve attention outputs; understanding the linear‑algebraic form of attention (softmax(QKᵀ/√d)V) and the role of KV caching in autoregressive decoding is essential.  
*Quick check:* Given a query q and a KV block (K,V), how does the attention output change when replaced by a compacted block (Ck, Cv) with per‑token bias β? (Answer: It is determined by matching the locally normalized attention output and the unnormalized mass as per Eqs. (1)–(2).)

**Nonnegative least squares (NNLS) and convex optimization**  
*Why needed:* The bias β is derived by solving min\_{w≥0} ||Aw – m||² with w = exp(β); this is an NNLS problem, where non‑negativity constraints ensure biases are real‑valued.  
*Quick check:* If the unconstrained least‑squares solution for w has a negative component, what does the NNLS solution do? (Answer: It projects onto the nonnegative orthant, setting negative components to zero (or a small epsilon).)

**Orthogonal matching pursuit (OMP) for sparse approximation**  
*Why needed:* OMP greedily selects the subset of keys S that best explains the mass vector m, minimizing ||Φ\_S w – m||². It refits weights w via NNLS after each selection, ensuring stepwise improvement.  
*Quick check:* In OMP, after a new key index j is added to the support S, why is w refit via NNLS on the current S? (Answer: To update the weight vector to best explain the residual mass given the currently selected keys, guaranteeing the objective improves at each iteration.)

## Architecture Onboarding
**Component map:**  
Reference Query Generator → Key Selector → Bias Fitter → Value Fitter → RoPE Phase Adjuster.  
Supporting components: Nonuniform Budget Allocator (precomputes per‑head budgets) and Chunker (splits contexts for independent compaction).

**Critical path:** For each layer and head: (a) generate reference queries (repeat‑prefill, self‑study, or on‑policy as needed); (b) select a subset of keys S of size t using highest‑attention or OMP; (c) fit β via NNLS to match attention mass on Qref; (d) fit Cv via least squares to match attention outputs. If using nonuniform budgets, the per‑head t is determined beforehand by the budget allocator. For long contexts, the original KV cache is first chunked (by tokens or by precomputed KV) and each chunk is compacted independently; compacted chunks are then concatenated. Finally, the RoPE Phase Adjuster aligns the positional embeddings of the compacted keys to their original global positions.

**Design tradeoffs:**
- **Speed vs Quality:** AM‑OMP‑fast (OMP with k=4, τ=2) is much faster but less accurate than full AM‑OMP at extreme ratios.
- **Query source:** Self‑study + repeat‑prefill yields higher quality but incurs generation cost; context‑prefill is faster but may under‑cover query distribution.
- **Uniform vs Nonuniform:** Nonuniform budgets significantly improve quality (especially at high compaction ratios) but require precomputation and per‑head handling.
- **Chunking:** KV‑based chunking (slicing cached KV) preserves cross‑chunk context better but requires full prefill; text‑based chunking avoids full prefill but introduces approximations and RoPE alignment challenges.

**Failure signatures:**
- **OMP instability:** Residual does not decrease, or solution becomes ill‑conditioned; mitigate by using OMP‑fast (k=4, τ=2), clamping inputs, adding regularization.
- **Extreme β values:** exp(qCk⊤+β) overflows/NaNs; bound β (e.g., β∈[−3,3] for highest‑attention) or use clipping during NNLS.
- **High perplexity despite good QA:** Indicates overfitting to task‑specific queries; ensure reference queries are diverse and representative.
- **Chunking artifacts:** Mismatched RoPE phases cause performance drops; verify positional offsets, especially for sliding‑window layers (e.g., Gemma).

**First 3 experiments:**
1. **Query Generation Comparison:** Compress with random vectors, context‑prefill, repeat‑prefill, and self‑study queries at a fixed compaction ratio (e.g., 0.05). Measure log‑perplexity on original‑cache generations. Expect ranking: self‑study ≈ repeat‑prefill > context‑prefill > random.
2. **Key Selection Ablation:** Compare highest‑attention vs OMP vs OMP‑fast (k=4, τ=2) in terms of runtime and downstream quality. Expect full OMP best quality, OMP‑fast fastest, highest‑attention intermediate.
3. **Nonuniform Budget Validation:** Compare uniform vs precomputed nonuniform budgets across multiple compaction ratios. Expect nonuniform to significantly lower loss/higher accuracy at high ratios (>0.1), and head proportions to remain stable across different contexts.

## Open Questions the Paper Calls Out
1. **Direct optimization of compact keys:** Can we avoid subset selection and directly optimize Ck in latent space? The paper suggests future work on moving away from subset selection to expand solution space.
2. **Extreme compaction (∼100×):** How can fast methods achieve quality comparable to gradient‑based approaches (Cartridges) at very high compaction rates? The paper notes Cartridges still outperforms at ∼100×.
3. **Native compaction primitives:** What architectures or training procedures natively support KV compaction as a simple primitive, avoiding post‑hoc distribution shift?
4. **Sufficiency of matching outputs and mass:** Is preserving attention outputs and mass enough for all downstream tasks (e.g., generation, reasoning)? The paper only validates on QA.

## Limitations
- **Reference query representativeness:** The method assumes the reference queries capture the future query distribution; mismatch can cause unseen degradation.
- **Subset selection limitation:** Optimal compact keys might require linear combinations beyond original cache tokens, especially at extreme compaction ratios (<1%).
- **Head sensitivity stability:** Nonuniform budgeting assumes per‑head sensitivity curves are stable across contexts; this stability is only partially validated across diverse domains.

## Confidence
- **Attention matching correctness** (given representative Qref): Medium – proof exists, but practical representation is an empirical assumption.
- **Decomposition speed** (no gradient descent): High – algorithmic description and ablations confirm drastic speedup.
- **Nonuniform head budget gains:** Medium – ablations show strong improvements, but sensitivity stability across distributions is only partly evidenced.

## Next Checks
1. **Query distribution robustness:** Systematically vary Qref sources (random, context‑prefill, self‑study) on held‑out datasets and measure performance gaps; large gaps would confirm the representativeness issue.
2. **Head sensitivity stability:** Re‑estimate sensitivity curves across multiple domains (news, scientific, dialogue) and compare resulting budget allocations; test if a single schedule maintains quality per‑domain.
3. **Extreme‑ratio subset limitation:** Directly compare AM‑OMP against gradient‑based Cartridges at ratios below 0.01; a significant performance cliff would confirm that subset selection is insufficient at extreme compaction.
