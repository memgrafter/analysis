# S-VoCAL: A Dataset and Evaluation Framework for Inferring Speaking Voice Character Attributes in Literature

## Quick Facts
*   **arXiv ID:** 2603.00958
*   **Source URL:** https://arxiv.org/abs/2603.00958
*   **Reference count:** 0
*   **Primary result:** Introduces S-VoCAL, a dataset of 952 character-book pairs with 8 voice-relevant attributes, and a RAG pipeline achieving high F1 for Gender/Age but lower scores for Origin/Physical Health.

## Executive Summary
This paper addresses the challenge of assigning plausible voices to fictional characters for synthetic audiobooks. It introduces S-VoCAL, a dataset of 952 character-book pairs from 192 novels, annotated with eight voice-relevant attributes (e.g., Age, Gender, Origin) grounded in sociophonetics. The authors propose an evaluation framework using weighted F1 for categorical attributes and a novel Qwen-3 embedding-based similarity metric for open-class attributes, which better aligns with human judgments than BERTScore. A simple Retrieval-Augmented Generation (RAG) pipeline is evaluated, showing strong performance on closed attributes but notable difficulty on open, sparse, or ambiguous ones like Physical Health. The work highlights the promise and current limits of inferring voice traits from text alone.

## Method Summary
The core method is a RAG pipeline for attribute inference. For a given character in a novel, the system first identifies all name mentions using regular expressions. Around each mention, it extracts a 200-word context window. These windows and attribute-specific queries (e.g., "Is {character} a child?") are encoded with the E5-large embedding model. The top-10 most similar windows per query are retrieved. All retrieved passages and the full set of attribute queries are fed to an LLM (Qwen3-8B or Phi-4-14B) to generate a JSON output of predicted attributes. The raw output undergoes cleaning to remove reasoning traces and fix formatting. Evaluation compares these predictions to gold labels from the dataset using weighted F1 for closed/semi-closed attributes and Qwen-3 embedding similarity (mapped to a Human-Aligned Score) for open attributes.

## Key Results
*   The RAG pipeline achieves near-perfect weighted F1 for **Gender** (0.993–0.997) and strong scores for **Age** (0.783–0.800).
*   Performance drops significantly for open-class attributes, with a mean Human-Aligned Score of only ~0.42 for **Origin** and ~0.15 for **Physical Health**.
*   The proposed Qwen-3 embedding similarity metric correlates better with human judgments than BERTScore, especially for attributes like Origin.

## Why This Works (Mechanism)
### Mechanism 1: Sociophonetic Attribute Selection
*   **Claim:** Grounding the dataset in sociophonetic studies ensures the selected attributes directly correlate with acoustic voice properties needed for TTS synthesis.
*   **Mechanism:** The authors identified eight voice-related attributes from literature on voice indexicality, mapping them to structured Wikidata properties and manually annotating Age where sparse.
*   **Core Assumption:** These voice-relevant attributes are inferable from narrative text and sufficient for designing plausible synthetic voices.
*   **Evidence Anchors:** Abstract mentions attributes "grounded in sociophonetic studies"; Section 3 and Table 1 detail the attribute-voice links.
*   **Break Condition:** If sociophonetic links are too coarse or the attribute set is incomplete for high-fidelity voice generation.

### Mechanism 2: Retrieval-Augmented Generation for Scattered Information
*   **Claim:** The RAG pipeline effectively extracts scattered character information from long novels, enabling attribute inference despite implicit and distant mentions.
*   **Mechanism:** Character occurrences are located; 200-word windows are embedded with E5-large; for each attribute, a query computes similarity to passages; top-10 are fed to an LLM with prompts.
*   **Core Assumption:** Relevant cues are captured within a local context window and retrievable by semantic similarity.
*   **Evidence Anchors:** Abstract describes the "simple RAG pipeline"; Section 6 details the steps with E5-large and Qwen3/Phi-4.
*   **Break Condition:** If key attributes are only revealed through long-range narrative arcs not in 200-word windows, or if LLMs rely on memorized book knowledge.

### Mechanism 3: Attribute-Specific Evaluation Framework
*   **Claim:** The attribute-specific evaluation (Qwen-3 embedding similarity) provides a more human-aligned assessment than generic metrics, enabling fair benchmarking.
*   **Mechanism:** Closed attributes use weighted/soft F1. For open attributes, Qwen-3 embeddings conditioned on attribute-specific instructions compute cosine similarity; an isotonic regression maps scores to a Human-Aligned Score (HAS) using human judgments.
*   **Core Assumption:** Instruction-aware embeddings capture semantic equivalence better than BERTScore, and human-derived mapping yields interpretable scores.
*   **Evidence Anchors:** Abstract notes the novel metric "correlates better with human judgments"; Section 5.2 describes the Qwen-3 metric and HAS calibration.
*   **Break Condition:** If the embedding model is biased/fails on nuances, or if the isotonic regression overfits the limited human sample.

## Architecture Onboarding
Component map: Book Selection -> Character Extraction & Annotation -> Mention Detection -> Context Window Extraction -> Embedding & Retrieval (E5-large) -> LLM Inference (Qwen3/Phi-4) -> Output Cleaning -> Evaluation (Weighted F1 / Qwen-3 similarity -> HAS)

Critical path:
1.  Curate book list from Project Gutenberg with Wikidata entries.
2.  Extract and normalize character attributes; manually annotate missing Age.
3.  For each character: identify all name mentions, extract 200-word windows, compute embeddings.
4.  For each attribute: rank passages by query similarity, select top-10.
5.  Build a prompt with all attribute queries, invoke the LLM.
6.  Clean and parse LLM output into a structured attribute prediction.
7.  Evaluate predictions against gold labels using appropriate metrics.
8.  Aggregate results and run statistical comparisons.

Design tradeoffs:
*   **Wikidata vs. manual curation:** Wikidata offers scale but sparse values (e.g., Age initially 4.1% coverage); manual annotation improves Age but is labor-intensive.
*   **Retrieval window size (200 words):** Balances context richness and cost; larger windows may include more cues but increase noise and LLM input length.
*   **LLM size:** Phi-4 14B yields slightly higher scores than Qwen3-8B but requires more memory; 4-bit quantization mitigates cost.
*   **Open-class metric:** Qwen-3 embedding similarity correlates better with humans but needs a calibration set of human judgments for HAS mapping, adding evaluation overhead.

Failure signatures:
*   Closed-class F1 near majority baseline (e.g., Gender ≈ 0.561) → retrieval or LLM not capturing signals; inspect retrieved passages.
*   Open-class mHAS < 0.3 → predictions likely unrelated; check query relevance, LLM instruction following, and cleaning.
*   High discrepancy between Qwen3 and Phi-4 outputs on same inputs → model-specific memorization/bias; consider ensembling.
*   Many post-processing errors (malformed JSON) → cleaning rules insufficient; add robust parsing and fallbacks.

First 3 experiments:
1.  **Baseline replication:** Run the full RAG pipeline with default parameters (E5-large, Qwen3-8B, window=200) on the S-VoCAL test set; verify reported weighted F1 and mHAS values (Tables 5–6) are reproducible within ±2%.
2.  **Ablation on retrieval:** Replace retrieval with whole-book chunking (e.g., 2000-word chunks) or random passage selection; expect performance drops, especially for attributes needing distant information (Physical Health, Origin); quantify per-attribute impact.
3.  **Prompt variation for Physical Health:** Test alternative query phrasings to assess sensitivity; aim to improve the low mHAS (~0.15) by finding more effective prompts.

## Open Questions the Paper Calls Out
*   **Open Question 1:** To what extent does performance on S-VoCAL generalize to modern, non-Project Gutenberg books that LLMs have not memorized? The paper explicitly notes the corpus is likely memorized, so reported performance may not reflect reasoning on unseen books. Resolution requires evaluation on a new, contemporary dataset with no pre-training overlap.
*   **Open Question 2:** How can the dynamic evolution of attributes (Age, Health, Languages) throughout a narrative be reliably modeled and evaluated? The dataset provides static snapshots, but attributes often change over a story. Resolution requires a new annotation protocol labeling attributes at multiple timepoints and an evaluation framework for trajectory accuracy.
*   **Open Question 3:** What are the primary factors—data sparsity, attribute ambiguity, or contextual reasoning—causing lower performance on open-class attributes like Physical Health and Origin? The paper hypothesizes but lacks error analysis to disentangle whether poor results stem from sparse examples (e.g., Physical Health 4.1% coverage), ambiguous gold labels, or failure to aggregate dispersed evidence.
*   **Open Question 4:** Does the Qwen-3 embedding-based metric reliably evaluate semantic equivalence for complex attributes like Occupation? Its validation shows lower correlation (ρ=0.66) and annotator agreement for such attributes, suggesting the "gold" truth is noisy and the metric may optimize on a weak signal. Resolution requires a larger-scale human study to establish more robust reference standards.

## Limitations
*   **Sparse Wikidata coverage:** Attributes like Origin and Physical Health have low coverage in Wikidata; manual annotation was only done for Age, limiting dataset completeness.
*   **Fixed RAG context window:** The 200-word window may miss long-range narrative cues crucial for some attributes (e.g., gradual health decline), but the paper does not analyze this granularly.
*   **Evaluation calibration dependency:** The Human-Aligned Score requires a fitted isotonic regression on human judgments; without published coefficients, exact open-attribute score reproduction is blocked.

## Confidence
*   **Sociophonetic grounding:** Medium. The attribute selection is theoretically sound but may not capture all voice-relevant traits; acoustic applicability is assumed but not directly validated.
*   **RAG pipeline effectiveness:** Medium. The pipeline is fully described, but performance drops on Origin/Physical Health suggest retrieval or reasoning may be insufficient for complex, implicit attributes.
*   **Embedding-based metric:** High. Correlation with human judgments is demonstrated, but the metric's dependence on Qwen-3 and the isotonic mapping introduces model-specific bias risks.
