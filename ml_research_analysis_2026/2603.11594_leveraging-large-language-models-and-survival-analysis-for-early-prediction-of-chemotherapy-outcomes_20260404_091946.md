# Leveraging Large Language Models and Survival Analysis for Early Prediction of Chemotherapy Outcomes

## Quick Facts
- **arXiv ID:** 2603.11594
- **Source URL:** https://arxiv.org/abs/2603.11594
- **Reference count:** 16
- **Primary result:** For breast cancer (n=3409), the model achieves a C-index of 0.731 and, as a classifier at 431 days, an accuracy of 0.723 and F1-score of 0.724. Extraction precision ranges from 79.5% to 86.2%.

## Executive Summary
This study addresses early prediction of chemotherapy failure (progression, toxicity, death) by automatically extracting phenotypes and outcome labels from unstructured oncological notes using a retrieval-augmented generation (RAG) system with a critic agent to minimize hallucinations. These structured features, combined with electronic medical record data, feed a Random Survival Forest model. Evaluated on a breast cancer cohort (n=3409), the model achieves a C-index of 0.731 and, when converted to a classifier at the optimal time point (431 days), an accuracy of 0.723 and F1-score of 0.724. The approach generalizes to four other cancer types with consistent performance, and extraction precision ranges from 79.5% to 86.2%.

## Method Summary
The method involves two stages. First, an LLM-based RAG pipeline extracts phenotypes (e.g., TNM, stage, ER/PR/HER2) and outcomes (progression, toxicity, death) from unstructured notes. Notes are chunked (≤2500 tokens), and hybrid retrieval (semantic via cosine similarity and lexical via BM25, top k=10) fetches relevant chunks. An LLM (LLLaMA-3 8B or Mistral v0.2) processes these in a K-shot prompt with a JSON schema. A critic agent validates the output (schema compliance and substring match against chunks) and triggers re-extraction if invalid. Second, extracted chemotherapy regimens are filtered by patient support (≥20) to retain robust features, then combined with other clinical features (vitals, demographics, labs, comorbidities, staging, biomarkers, performance scores). A Random Survival Forest (RSF) is trained on time-to-failure with censoring. The survival function is converted to a classifier at the time point maximizing accuracy and F1, and calibration curves assess probability reliability.

## Key Results
- Breast cancer cohort (n=3409): RSF C-index = 0.731; at 431 days, accuracy = 0.723, F1-score = 0.724.
- Phenotype extraction precision: 79.5%–86.2%.
- Approach generalizes to four other cancer types with consistent performance.

## Why This Works (Mechanism)
The RAG system with a critic agent grounds LLM extraction in retrieved note chunks and enforces output validity, reducing hallucinations and yielding high-precision structured features. These features capture critical clinical signals (e.g., regimens, phenotypes) that complement traditional EMR data. The Random Survival Forest effectively models time-to-event data with censoring, leveraging both extracted and structured features to stratify patients by risk of early chemotherapy failure.

## Foundational Learning
- **Retrieval-Augmented Generation (RAG):** Provides context from source documents to LLMs to improve accuracy and reduce hallucinations. *Why needed:* Ensures extraction is grounded in patient-specific notes. *Quick check:* Verify retrieved chunks have high similarity to query and contain relevant information.
- **Critic Agent:** Validates LLM outputs (schema compliance, consistency with source) and triggers re-extraction if invalid. *Why needed:* Catches extraction errors post-hoc. *Quick check:* Implement simple heuristics (e.g., substring match) and measure reduction in invalid outputs.
- **Random Survival Forest (RSF):** Ensemble of survival trees handling right-censored data and providing survival probability estimates. *Why needed:* Models time-to-failure while accommodating non-linear relationships. *Quick check:* Compare with Cox PH model on same features to assess non-linear gains.
- **Hybrid Retrieval (Semantic + Lexical):** Combines dense vector similarity (cosine) with sparse lexical matching (BM25). *Why needed:* Balances semantic understanding with exact keyword matching. *Quick check:* Ablate each component on a validation set to measure impact on extraction precision.
- **K-shot Prompting:** Uses a few examples in the prompt to guide LLM extraction. *Why needed:* Improves extraction consistency without fine-tuning. *Quick check:* Vary number of shots (e.g., 1 vs 5) on a small annotated set to find optimal tradeoff.
- **Survival Analysis C-index:** Measures discriminative ability of risk scores. *Why needed:* Primary metric for survival model performance. *Quick check:* Plot Kaplan-Meier curves for high- vs. low-risk groups to visually confirm separation.

## Architecture Onboarding
Component map: Raw notes -> Chunking -> Embedding index (FAISS) + BM25 index -> Hybrid retrieval -> LLM extraction with K-shot prompt -> Critic agent (validate/re-prompt) -> Structured phenotypes/outcomes -> Feature engineering (regimen filtering, one-hot) + Structured EMR -> Concatenated features -> Random Survival Forest -> Survival function -> Classification at optimal time.

Critical path: The extraction pipeline (chunking, retrieval, LLM, critic) is most complex and failure-prone; its precision directly impacts downstream model performance.

Design tradeoffs:
- Chunk size: Larger chunks provide more context but risk exceeding LLM context limits; smaller chunks may fragment relevant information. Paper uses ≤2500 tokens.
- Retrieval k: Top k=10 balances coverage and noise; increasing k may introduce irrelevant chunks.
- LLM choice: LLaMA-3 8B offers a cost-accuracy tradeoff; smaller models may be faster but less accurate.
- Critic agent rigor: Simple substring check is fast but may miss paraphrased content; advanced checks (e.g., NLI) are computationally costly.
- Regimen support threshold: ≥20 patients retains frequent regimens; too low yields sparse features, too high loses rare but informative regimens. Adjust based on cohort size.

Failure signatures:
- Extraction precision <80%: indicates poor retrieval, inadequate prompt, or overly permissive critic.
- Overfitting (high train C-index, low test C-index): likely due to high-dimensional sparse regimen features; increase support threshold or regularize RSF.
- Poor probability calibration: survival probabilities may be overconfident; check calibration curve and consider recalibration.

Three first experiments:
1. Isolate extraction pipeline: run on a small annotated set (n=50) and compute precision/recall for phenotypes/outcomes. Iteratively refine prompt and critic.
2. Train baseline RSF with only structured EMR features (no extracted phenotypes/regimens) to quantify added value of LLM-extracted features.
3. Ablate hybrid retrieval: compare semantic-only, lexical-only, and hybrid retrieval on extraction precision to tune the retrieval component.

## Limitations
- Extraction pipeline specifics (embedding model, prompt details, critic validation logic) are unreported, hindering reproducibility.
- Random Survival Forest hyperparameters are not specified, potentially affecting performance consistency.
- Generalization to other cancers lacks detail on cohort-specific adjustments, limiting confidence in cross-cancer claims.
