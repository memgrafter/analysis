# Embedding Inversion via Conditional Masked Diffusion Language Models

## Quick Facts
- **arXiv ID:** 2602.11047
- **Source URL:** https://arxiv.org/abs/2602.11047
- **Reference count:** 15
- **Primary result:** Achieves up to 81.3% token accuracy on embedding inversion using only 8 forward passes, without requiring access to the target embedding model at inference.

## Executive Summary
The paper tackles embedding inversion—recovering original text from embedding vectors—in a black-box setting where the target embedding model is inaccessible during inference. It reformulates the task as conditional masked diffusion: a diffusion model, conditioned on the target embedding via adaptive layer normalization (AdaLN), iteratively denoises a fully masked sequence in parallel across all token positions. This avoids the error accumulation of sequential autoregressive generation and eliminates the need for iterative re-embedding loops. On 32-token sequences across three embedding models (Qwen3-Embedding, EmbeddingGemma, jina-embeddings-v3), the method attains token accuracies of 81.3%, 78.8%, and 76.0% with only 8 forward passes. Average cosine similarity across 10 languages reaches 0.715 for jina-embeddings-v3 using sequential greedy decoding. The approach is encoder-agnostic and requires no architecture-specific alignment or correction loops.

## Method Summary
The method frames embedding inversion as a conditional masked diffusion problem. A transformer-based diffusion model is conditioned on the target embedding vector through AdaLN, which modulates layer activations at every depth. During training, tokens are progressively masked according to a log-linear noise schedule, and the model learns to predict the original tokens at masked positions using a Rao-Blackwellized ELBO loss weighted by 1/t. The model is initialized from a pretrained multilingual BERT (frozen or fine-tuned) and uses a large vocabulary (~256K) with weight tying. At inference, starting from an all-mask sequence, the model performs iterative denoising (e.g., Euler sampling) for a fixed number of steps (e.g., 8) to recover all tokens in parallel, optionally employing remasking or sequential greedy decoding. No re-embedding or encoder access is needed.

## Key Results
- **High token accuracy:** 81.3% (Qwen3-Embedding), 78.8% (EmbeddingGemma), 76.0% (jina-embeddings-v3) on 32-token sequences.
- **Strong semantic similarity:** Average cosine similarity up to 0.715 (jina-embeddings-v3) with sequential greedy decoding.
- **Efficient inference:** Only 8 forward passes required, enabling parallel reconstruction without iterative re-embedding.

## Why This Works (Mechanism)
### Mechanism 1
**Claim:** Parallel iterative denoising avoids error accumulation inherent in sequential autoregressive generation.  
**Mechanism:** The diffusion model starts from a fully masked sequence and, at each timestep, predicts all currently masked positions simultaneously. Predictions are conditioned on the target embedding (via AdaLN) and the context of already revealed tokens. By updating all positions in parallel, each token is informed by the global context, preventing early errors from propagating downstream.  
**Core assumption:** The embedding vector contains sufficient information to guide the denoising process toward the original token sequence, and parallel updates can converge to a consistent reconstruction without iterative re-embedding.  
**Evidence anchors:**  
- Abstract: "recovering all tokens in parallel through iterative denoising rather than sequential autoregressive generation."  
- Section 1: "Starting from a fully masked sequence, a denoising model iteratively reveals tokens at all positions in parallel, conditioned on the target embedding vector via adaptive layer normalization. Correction is built into the diffusion process itself: each step refines all positions simultaneously using global context, without ever reembedding the current hypothesis."  
- Corpus: Neighbor papers on masked diffusion (e.g., "Auto-Regressive Masked Diffusion Models", "Activation Steering for Masked Diffusion Language Models") demonstrate the viability of parallel decoding, providing indirect support.  
**Break condition:** If the embedding is too low-dimensional or the text is out-of-distribution, the conditioning signal may be insufficient for parallel disambiguation, causing accuracy to drop. Underparameterized models may also fail to capture the conditional mapping.

### Mechanism 2
**Claim:** Adaptive layer normalization (AdaLN) enables effective encoder-agnostic conditioning by fine-grained modulation of transformer activations.  
**Mechanism:** The target embedding *e* is projected to a conditioning vector *c* via a two-layer MLP. For each transformer layer ℓ, separate MLPs compute scale (γ) and shift (β) parameters from *c* (and timestep *t*). These modulate the layer-normalized activations: *h' = γ ⊙ (h - μ)/σ + β*. This allows the embedding to exert layer-specific influence.  
**Core assumption:** The linear AdaLN modulation can translate continuous embedding semantics into appropriate discrete token distributions without requiring task-specific alignment or encoder access during inference.  
**Evidence anchors:**  
- Section 3.3: "Following DiT [Peebles and Xie, 2023], we condition each transformer layer on both the timestep *t* and the embedding vector *c* via adaptive layer normalization... This formulation allows the conditioning signal and timestep to independently modulate the layer normalization at each depth, providing fine-grained control over feature representations."  
- Section 1: "The embedding vector enters only through AdaLN modulation, making the approach encoder agnostic: the same architecture applies to any embedding model without alignment training."  
- Corpus: AdaLN is established in vision diffusion transformers; corpus includes related steering work, but direct evidence is primarily from the paper's experiments.  
**Break condition:** If the projection MLP is too small or hidden dimension *D_h* insufficient, conditioning information may be lost. Highly non-linear embedding spaces might require more expressive conditioning.

### Mechanism 3
**Claim:** The log-linear noise schedule (α_t = e^{-λt}) provides a curriculum that stabilizes training and improves reconstruction quality by gradually increasing masking difficulty.  
**Mechanism:** During training, for sampled timestep *t*, each token is masked independently with probability 1-α_t. The log-linear schedule ensures low *t* has mostly unmasked tokens (easy denoising) and high *t* has mostly masked (hard denoising). The loss is weighted by 1/t, emphasizing accurate prediction when few tokens are masked. This curriculum helps the model first learn to use abundant context, then adapt to sparser context.  
**Core assumption:** A dynamic difficulty progression yields better learning efficiency and final performance than fixed high mask ratios.  
**Evidence anchors:**  
- Section 3.2: "We use the log-linear schedule α_t = e^{-λt} with λ=5.0, which concentrates masking in later timesteps while preserving structure in early denoising stages."  
- Appendix A: Table 4 compares fixed mask ratios (10%, 20%, 40%, 80%, 100%) using a different decoder architecture. Higher fixed mask ratios achieve lower validation loss, but the log-linear schedule outperforms all fixed ratios, indicating dynamic schedule benefits.  
- Corpus: The masked diffusion language model (MDLM) baseline introduced the log-linear schedule; subsequent corpus papers adopt or extend it, confirming acceptance in the field.  
**Break condition:** If λ is poorly chosen, the curriculum may not match the model's learning stage, slowing convergence or reducing accuracy. For sequences much longer than training length (32 tokens), the schedule may need retuning.

## Architecture Onboarding
### Component Map
Target embedding *e* → Projection MLP → Conditioning vector *c* → Transformer backbone (with AdaLN modulation) → Logits (vocabulary-sized) → Token sampling.

### Critical Path (Inference)
1. Obtain target embedding *e* (black-box, no encoder access).
2. Compute *c = Proj(e)* using the trained projection MLP.
3. Initialize sequence *x* with all `[MASK]` tokens of length *n* (e.g., 32).
4. For diffusion step from *t*=1 down to *t*=0 (using fixed steps, e.g., 8):
   a. Compute timestep embedding.
   b. Pass (*x*, *t*, *c*) through transformer (with AdaLN) to get logits for all positions.
   c. Apply decoding strategy (e.g., Euler: sample all; sequential: unmask leftmost).
   d. Update *x*; optionally remask low-confidence tokens.
5. Return final *x* as recovered text.

### Design Tradeoffs
- **Model depth:** Deeper models (22 layers) offer higher capacity but slower inference; shallow models (2-8 layers) are faster but less accurate.
- **Parameter freezing:** Freezing pretrained backbone (e.g., mmBERT) leverages general language knowledge with fewer trainable parameters, but may limit task adaptation; training all parameters can boost accuracy at higher compute cost.
- **Decoding strategy:** Sequential greedy yields best token accuracy but loses parallelism; Euler sampling is fully parallel but lags; two-stage and remasking aim to bridge the gap.
- **Vocabulary size:** Large vocabulary (256K) with weight tying reduces parameters but may cause sparsity; smaller vocabularies (e.g., GPT-2's 50K) might be easier but require tokenizer alignment.
- **Training data:** Multilingual mC4 improves cross-lingual robustness but may dilute single-language performance; monolingual C4 could enhance English accuracy.
- **Noise schedule:** Log-linear schedule is effective but *λ* requires tuning; fixed schedules are simpler but underperform.

### Failure Signatures
- **Low training token accuracy (<50%):** Likely underfitting; increase model size, unfreeze backbone, or extend training.
- **High BLEU but low exact match:** Model generates fluent text but fails to reconstruct original; may indicate weak conditioning or bias toward high-probability text; try stronger conditioning or adjust decoding.
- **Validation loss plateau:** Check learning rate, batch size, or data preprocessing; consider longer training or schedule adjustment.
- **Poor cross-encoder generalization:** Overfitting to a specific encoder's distribution; train on multiple encoders or diversify data.
- **Slow convergence in early steps:** Inappropriate initial mask ratio or *λ*; retune schedule.
- **Memory overflow:** Large vocabulary or deep models exceed GPU memory; reduce batch size or depth.

Record token accuracy and validation loss for each encoder (Qwen3, EmbeddingGemma, jina). This should reproduce reported baselines (81.3%, 78.8%, 76.0%).
2. **Decoding strategy ablation:** For each encoder, evaluate all five decoding strategies on the same trained model (or train separate models). Compare token accuracy, cosine similarity, and BLEU. Identify which strategy gives best similarity (e.g., sequential greedy for jina and EmbeddingGemma, two-stage for Qwen3) and verify remasking effect (τ=0.05).
3. **Mask schedule validation:** Train models with fixed mask percentages (10%, 20%, 40%, 80%, 100%) using an 8-layer transformer from scratch. Compare validation loss and training accuracy against the log-linear schedule. Confirm dynamic masking superiority, supporting the curriculum hypothesis.

## Open Questions the Paper Calls Out
1. **Classifier-free guidance** – Can it improve embedding inversion without encoder access? Proposed but not evaluated; effectiveness uncertain.
2. **Hybrid diffusion + correction** – Does combining diffusion initialization with a lightweight distilled encoder close the gap with autoregressive methods? No implementation; current method lacks correction loops.
3. **Dynamic mask schedule benefits** – Why do log-linear schedules outperform fixed mask ratios? Ablation shows improvement but no analysis of curriculum learning dynamics.
4. **Generalization to other encoders** – How well does the approach generalize beyond the three evaluated encoders? Encoder-agnosticism assumed but not broadly validated.
5. **Scaling to longer sequences** – Can hierarchical diffusion handle >32 tokens? Identified as future work; current implementation limited to 32-token sequences.

## Limitations
- Vocabulary and tokenization details are incompletely described (256K vs. mBERT's ~110K), which may affect reproducibility.
- Decoding hyperparameters for some strategies (e.g., confidence-based, two-stage) are unspecified, hindering exact recreation.
- Evaluation is restricted to fixed 32-token sequences; performance on variable or longer texts remains unknown.

## Confidence
- *Parallel denoising avoids error accumulation:* Medium (strong results but lacking controlled autoregressive baseline; support from masked diffusion literature is indirect).
- *AdaLN enables encoder-agnostic conditioning:* Medium (AdaLN is established, but no ablation confirms necessity; improvements could stem from other factors).
- *Log-linear noise schedule provides a beneficial curriculum:* High (Appendix A shows consistent improvement over fixed masks, aligning with prior diffusion work).
