# A Multimodal Deep Learning Framework for Edema Classification Using HCT and Clinical Data

## Quick Facts
- **arXiv ID:** 2603.26726
- **Source URL:** https://arxiv.org/abs/2603.26726
- **Reference count:** 10
- **Primary result:** AttentionMixer achieves 87.32% accuracy, 92.10% precision, 85.37% F1‑score, and 94.14% AUC on a 205‑patient cohort, outperforming HCT‑only, metadata‑only, and prior multimodal baselines.

## Executive Summary
The paper introduces AttentionMixer, a novel multimodal framework for automated brain edema detection from head CT scans and clinical data. It leverages a self‑supervised Vision Transformer (ViT‑AE++) to extract robust imaging features, a cross‑attention module to dynamically fuse clinical metadata, and a lightweight MLP‑Mixer for post‑fusion refinement. Evaluated via five‑fold cross‑validation on 205 patients with expert labels, AttentionMixer achieves superior performance (Accuracy 87.32%, Precision 92.10%, F1‑score 85.37%, AUC 94.14%). Ablation studies confirm the contributions of both cross‑attention and the MLP‑Mixer. The work demonstrates the value of intermediate fusion and fine‑grained modulation in medical multimodal learning, while acknowledging limitations of single‑center data and lack of calibration/fairness analysis.

## Method Summary
Processing begins with two parallel inputs: a 3D HCT volume and a vector of tabular clinical metadata. The imaging branch uses a self‑supervised ViT autoencoder (ViT‑AE++) pretrained on masked volume reconstruction to produce a feature token that summarizes the scan. The metadata branch applies k‑NN imputation for feature‑level missingness; if an entire record is missing, a learned embedding substitutes. Both branches are projected to a shared dimension. Fusion occurs via a cross‑attention layer where the HCT token serves as query and the metadata token as key and value, allowing the model to dynamically re‑weight imaging features based on clinical context. The fused token then passes through a lightweight MLP‑Mixer block to capture channel‑wise interactions before a single‑layer classifier outputs a probability for edema. The model is trained end‑to‑end with binary cross‑entropy loss using the Adamax optimizer (learning rate 1e‑3) and early stopping on validation AUC.

## Key Results
- AttentionMixer reaches 87.32% accuracy, 92.10% precision, 85.37% F1‑score, and 94.14% AUC on the held‑out test folds.
- Ablation shows that removing cross‑attention reduces AUC to 92.66% (~1.5% drop), while removing the MLP‑Mixer lowers accuracy to 85.85% and F1 to 84.04%.
- The framework consistently outperforms unimodal baselines (HCT‑only, metadata‑only) and prior multimodal fusion approaches across all metrics.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** A self‑supervised ViT encoder extracts robust, high‑level spatial features from 3D HCT volumes, reducing overfitting in small labeled cohorts.
- **Mechanism:** The ViT‑AE++ (Section 3.3) partitions the HCT volume into patches, applies transformer blocks, and reconstructs masked inputs during pretraining. This forces the encoder to learn rich contextual representations without voxel‑level labels. The encoded feature volume is flattened and projected to a fixed‑dimensional token for fusion.
- **Core assumption:** Masked image modeling on unlabeled HCT scans yields representations that transfer effectively to the downstream edema classification task, even with limited expert labels.
- **Evidence anchors:**  
  [abstract] "HCT volumes are first encoded using a self‑supervised Vision Transformer Autoencoder (ViT‑AE++), without requiring large labeled datasets."  
  [section 3.3] Details the ViT‑AE++ encoder, patch processing, and linear projection to a token.  
  [corpus] Self‑supervised ViTs and MAEs are noted in Related Work (Section 2) as improving data efficiency in medical imaging.
- **Break condition:** If the unlabeled HCT pretraining data is grossly mismatched to the target edema distribution (e.g., different scanners, protocols, or patient populations), the learned representations may not transfer, degrading performance.

### Mechanism 2
- **Claim:** Cross‑attention fusion dynamically modulates HCT features using patient‑specific clinical metadata, enabling fine‑grained, interpretable multimodal integration.
- **Mechanism:** The HCT token serves as Query (Q), while metadata embeddings are Key (K) and Value (V) (Section 3.5). Attention weights compute similarity between the global HCT context and each metadata feature, allowing the network to re‑weight and contextualize imaging features based on clinical variables (e.g., age, lab values). This is a form of intermediate fusion.
- **Core assumption:** The relationship between edema presence and imaging patterns is conditional on clinical context (e.g., same HCT finding may be edema in an elderly stroke patient but not in a young trauma patient). The cross‑attention mechanism can learn these conditional dependencies.
- **Evidence anchors:**  
  [abstract] "Clinical metadata are mapped into the same feature space and used as keys and values in a cross‑attention module, where HCT‑derived feature vector serves as queries… allows the network to dynamically modulate imaging features based on patient‑specific context."  
  [section 3.5] Formal equations (6‑11) define the multi‑head cross‑attention.  
  [section 4.3] Ablation shows removing cross‑attention (w/o CA) drops AUC from 94.14% to 92.66%, supporting its contribution.  
  [corpus] The "Cross‑Attention is Not Enough" paper (neighbor) highlights challenges in multimodal affect recognition, indirectly supporting that a principled attention design is critical but not sufficient alone, aligning with Authors' addition of MLP‑Mixer.
- **Break condition:** If the metadata vector is completely uninformative or contains systematic errors (e.g., all patients have the same value for a key variable), the modulation may introduce noise. The mechanism assumes metadata contains signal relevant to edema.

### Mechanism 3
- **Claim:** A lightweight MLP‑Mixer refines the cross‑attention fused token, capturing channel‑wise interactions with minimal parameter overhead, enhancing discriminative power.
- **Mechanism:** After cross‑attention produces a fused token, the MLP‑Mixer (Section 3.6) applies alternating channel‑mixing MLPs (Eq 12) to model non‑linear interactions across the feature channels of this single token. This provides global dependency modeling within the fused representation without stacking expensive attention layers.
- **Core assumption:** The fused representation from cross‑attention benefits from further non‑linear transformation of channel‑wise features to sharpen edema‑relevant signals before classification. Parameter efficiency is prioritized for clinical deployment.
- **Evidence anchors:**  
  [abstract] "A lightweight MLP‑Mixer then refines the fused representation… enabling global dependency modeling with substantially reduced parameter overhead."  
  [section 3.6] Describes the MLP‑Mixer block applied to the fused token.  
  [section 4.3] Ablation shows removing the MLP‑Mixer (w/o MLP‑Mixer) drops accuracy (87.32% → 85.85%) and F1‑score (85.37% → 84.04%), though AUC remains high (93.35%), indicating complementary value.  
  [corpus] MLP‑Mixer is cited (Tolstikhin et al., 2021) as a parameter‑efficient alternative to transformers. Corpus neighbors show MLP‑Mixer used in medical segmentation (Yang et al., 2025), supporting its applicability.
- **Break condition:** If the cross‑attention fusion already produces a linearly separable representation, the additional non‑linearity may be unnecessary or could introduce overfitting on small datasets. The benefit is contingent on the fusion output needing deeper channel interaction.

## Architecture Onboarding
- **Component map:**  
  1. **Input:** 3D HCT volume (D×H×W) and tabular clinical metadata vector (`d_m`).  
  2. **HCT Path:** 3D patches → ViT‑AE++ encoder → 3D feature volume (`C×D'×H'×W'`) → Flatten → Linear projection → HCT token (`1×d_f`).  
  3. **Metadata Path:** Preprocessed/one‑hot encoded → Feature‑level k‑NN imputation → If entire record missing, replace with `e_m` → Linear embedding → Metadata token(s) (`L×d_f`, L=1).  
  4. **Fusion:** Cross‑attention (HCT token as Q, metadata token as K/V) → Fused token (`1×d_f`).  
  5. **Refinement:** MLP‑Mixer blocks (channel‑mixing MLPs) → Refined token (`1×d_f`).  
  6. **Classification:** Global average pool (trivial for single token) → FC layer → Sigmoid → Edema probability.

- **Critical path:** HCT volume → ViT encoder → Cross‑attention with metadata → MLP‑Mixer → Classifier. Metadata path is parallel but critical for modulating the HCT path at the cross‑attention step.

- **Design tradeoffs:**  
  - *Cross‑attention vs. Concatenation:* Cross‑attention provides interpretable, dynamic weighting but adds parameters and computation. Early fusion (concatenation) is simpler but may not model interactions well (Section 4.3 ablation).  
  - *ViT‑AE++ vs. 3D CNN:* ViT offers global context but may need more data/pretraining; 3D CNNs are parameter‑efficient for local features but may miss long‑range dependencies (Section 4.2 shows vanilla ViT underperforms without proper pretraining/fusion).  
  - *MLP‑Mixer vs. extra transformer layers:* MLP‑Mixer adds refinement with fewer parameters, but may be less expressive than full attention for certain interactions.  
  - *Missing data handling:* Learnable token is robust but may learn a suboptimal “default” if many patients have missing metadata; k‑NN imputation handles feature‑level missingness but not whole‑record absence.

- **Failure signatures:**  
  - Poor performance on metadata‑only baseline? If the metadata MLP (Table 1, 84.88% AUC) performs close to or better than the full model, the fusion or HCT encoder may be failing to leverage imaging.  
  - High variance across CV folds? Indicates instability, possibly from small dataset (N=205) or poor generalization of ViT pretraining.  
  - Model confident but wrong on certain subgroups? Suggests issues with calibration or fairness (Section 5 limitation), possibly due to unrepresentative training data.  
  - AUC drops significantly when permuting a metadata feature? Expected for important features; if *no* feature drops AUC, cross‑attention may not be learning meaningful interactions.

- **First 3 experiments:**  
  1. Verify unimodal baselines: Train and evaluate the HCT‑only ViT‑AE++ encoder + classifier and the metadata‑only MLP to establish performance ceilings (Table 1).  
  2. Test cross‑attention necessity: Train `AttentionMixer (w/o CA)` (Table 2) to confirm that cross‑attention fusion provides a gain over simple concatenation or other fusion‑less combination.  
  3. Validate missing data handling: Artificially create a test set with entirely missing metadata for some patients. Compare performance of the full model (with `e_m`) against a variant that discards such patients or uses zero/mean imputation for the whole vector.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** How well does AttentionMixer generalize to diverse external datasets from multiple medical centers with varying CT scanners and acquisition protocols?
- **Basis in paper:** The authors identify the use of a "single‑center, retrospective cohort" as a key limitation, noting that differences in HCT sequences, vendor reconstruction, and patient populations could affect performance. They explicitly call for "multi‑center, multi‑scanner external validation and domain adaptation strategies" as future work (Page 10, Section 5).
- **Why unresolved:** The model's reported performance (87.32% accuracy, 94.14% AUC) is based on five‑fold cross‑validation of a single institution's data. Real‑world deployment across different hospitals would encounter distribution shifts in imaging appearance and clinical variable distributions, potentially degrading model reliability without adaptation.
- **What evidence would resolve it:** A prospective study evaluating AttentionMixer on completely held‑out datasets from at least three different medical centers, reporting standardized metrics and analyzing performance drops. Additionally, testing domain adaptation techniques (e.g., style transfer, adversarial training) would quantify robustness and inform mitigation strategies.

### Open Question 2
- **Question:** Can the AttentionMixer framework be extended to predict fine‑grained edema characteristics such as volumetric burden, spatial extent, or subtype (e.g., vasogenic vs. cytotoxic)?
- **Basis in paper:** The authors state that their binary classification (presence/absence) does not provide the "quantitative measurements needed for detailed treatment planning" and propose extending the model by coupling it with "a segmentation head or regression module that predicts edema burden and progression over time" as a direct future direction (Page 10, Section 5).
- **Why unresolved:** A patient‑level binary label is insufficient for clinical decisions requiring precise edema quantification (e.g., monitoring response to therapy, surgical planning). Without volume or subtype prediction, the model's utility remains limited to screening rather than detailed assessment.
- **What evidence would resolve it:** Architecturally modifying AttentionMixer to include a decoder branch for 3D edema segmentation or a regression head for volume estimation, then evaluating against expert segmentations or volumetric ground truth on a cohort with such annotations. Performance would be measured by segmentation metrics (Dice score) and regression errors.

### Open Question 3
- **Question:** How robust is AttentionMixer to partial or complete unavailability of specific clinical metadata fields at inference, and how can its multimodal fusion be adapted for scenarios with additional imaging sequences (e.g., perfusion CT, MRI)?
- **Basis in paper:** The authors acknowledge a "limited modality and sequence diversity," focusing only on structural HCT and a fixed set of tabular variables. They explicitly identify extending to "heterogeneous multi‑sequence inputs" and operating "robustly under partial modality availability (e.g., missing sequences at test time)" as a natural next step (Page 10–11, Section 5). The current learnable embedding handles entirely missing metadata vectors but not missing individual features within an otherwise available vector.
- **Why unresolved:** Real‑world clinical data often have missing individual lab values or vital signs, not just entirely absent records. Furthermore, many neurologic cases involve multiple imaging sequences, and the model's cross‑attention design may not naively scale to more than two modalities without architectural changes.
- **What evidence would resolve it:** Systematic experiments where individual metadata features are masked or where additional imaging sequences (e.g., perfusion maps) are either included or withheld. Performance degradation curves would quantify robustness, and architectural variants (e.g., hierarchical cross‑attention for >2 modalities) could be proposed and tested.

### Open Question 4
- **Question:** Are the predicted edema probabilities from AttentionMixer well‑calibrated, and does the model exhibit equitable performance across demographic subgroups (e.g., age, sex, race)?
- **Basis in paper:** The authors admit they did not "comprehensively assess probability calibration or fairness across demographic subgroups" and list "calibration analysis, subgroup performance evaluation" as necessary future work for clinical deployment (Page 11, Section 5).
- **Why unresolved:** Discrimination metrics (AUC, F1‑score) do not guarantee that a predicted probability of 0.8 corresponds to an 80% chance of edema (calibration). Furthermore, without subgroup analysis, the model might perform poorly for underrepresented populations, risking biased clinical decisions. Both are critical for trustworthy AI in healthcare.
- **What evidence would resolve it:** Computing calibration metrics (e.g., reliability diagrams, Brier score) on a held‑out set. For fairness, stratifying performance metrics (AUC, sensitivity, specificity) by key demographic variables and testing for statistically significant disparities using fairness‑aware evaluation frameworks. If issues are found, techniques like post‑hoc calibration or fairness constraints should be applied and re‑evaluated.

## Limitations
- Small cohort size (N=205) may lead to high variance in performance estimates and limited generalizability.
- Study uses single‑center data; no external validation across different hospitals or scanner vendors.
- No assessment of probability calibration or fairness across demographic subgroups, which are essential for trustworthy clinical deployment.

## Confidence
- **[Medium]** Self‑supervised ViT encoder yields robust, high‑level spatial features (transferability depends on pretraining data match).
- **[High]** Cross‑attention fusion dynamically modulates HCT features using clinical context (strong ablation support).
- **[Medium]** MLP‑Mixer refinement enhances discriminative power (modest but consistent gains).
- **[Medium]** Reported performance metrics (87.32% accuracy, 94.14% AUC) – five‑fold CV on a modest cohort may have high variance, no external validation.
