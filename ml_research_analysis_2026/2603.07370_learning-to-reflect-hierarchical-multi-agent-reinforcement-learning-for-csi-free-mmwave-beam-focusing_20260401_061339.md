# Learning to Reflect: Hierarchical Multi-Agent Reinforcement Learning for CSI-Free mmWave Beam-Focusing
## Quick Facts
*   **arXiv ID:** 2603.07370
*   **Source URL:** https://arxiv.org/abs/2603.07370
*   **Reference count:** 40
*   **Primary result:** A hierarchical multi-agent RL framework using user localization instead of channel estimation achieves 2.81–7.94 dB RSSI gains over centralized baselines and scales efficiently with user density.

## Executive Summary
This paper tackles the channel state information (CSI) estimation overhead in reconfigurable intelligent surface (RIS)-aided millimeter-wave systems. It proposes a Hierarchical Multi-Agent Reinforcement Learning (HMARL) framework that operates without explicit CSI by leveraging user localization data. The control problem is decomposed into a high-level centralized allocator that assigns users to reflector segments and low-level decentralized controllers that optimize focal points for beam steering. Evaluated in a ray-tracing simulator, the framework demonstrates significant RSSI improvements, strong scalability with user count, and robustness to reflector size and moderate localization errors.

## Method Summary
The system model features a base station (AP) and two mechanically reconfigurable reflector arrays aiding multiple users. Instead of estimating channels, the system uses 3D user positions and reflector geometries. The HMARL policy has two levels: a high-level allocator runs every *T* steps to assign each user to a unique reflector segment, and low-level controllers (one per segment) adjust the segment's 3D focal point at each step to maximize RSSI for their assigned user. A geometric compatibility matrix, derived from user-reflector distances and reflection angles, biases the high-level sampler during training. Both levels are trained using Centralized Training with Decentralized Execution (CTDE) via MAPPO, with global and local critics respectively.

## Key Results
*   The proposed HMARL framework achieves 2.81–7.94 dB higher deployment RSSI compared to centralized single-agent RL baselines.
*   It exhibits strong scalability: doubling the number of users (from 2 to 4) results in only a 1.39 dB per-user RSSI degradation while the total system RSSI remains stable.
*   The system is robust across reflector sizes (45 to 99 tiles) and tolerates user localization errors up to 0.5 m with graceful performance loss.

## Why This Works (Mechanism)
### Mechanism 1: Hierarchical Decomposition for Scalability
*   **Claim:** Splitting control into a high-level user-to-reflector allocator and low-level focal point optimizers reduces effective action space dimensionality and enables efficient coordination as system size grows.
*   **Mechanism:** The high-level controller makes discrete assignment decisions every *T* timesteps (temporal abstraction), while each low-level controller independently optimizes continuous focal point coordinates for its assigned user. This exploits locality: a reflector primarily affects its assigned user's RSSI.
*   **Core assumption:** Under effective user assignment, cross-reflector interference/coverage overlap is minimal, allowing independent focal point optimization without centralized coordination at each step.
*   **Evidence anchors:**
    *   [abstract] "decomposes control into a high-level centralized allocator for user-to-reflector assignment and decentralized low-level controllers for focal point optimization."
    *   [section III-A] "Observation space reduction... from R³ᴷ⁺⁶ᴸ to R⁹ at the low level" and Eq. (13) showing dimensionality reduction factor η > 5 for typical parameters.
    *   [section V-C] Performance gap between hierarchical and centralized baselines widens from 2.81 dB (2 users) to 7.94 dB (4 users), demonstrating scalability.
*   **Break condition:** If users are densely packed or reflector segments are large/numerous (L large), assignment locality breaks down; focal point adjustments for one user may significantly impact others, violating the independent optimization assumption and requiring more frequent high-level reassignment.

### Mechanism 2: CSI-Free Operation via Geometric Priors
*   **Claim:** Replacing pilot-based channel estimation with user localization data eliminates the CSI acquisition bottleneck while maintaining high-fidelity beam focusing.
*   **Mechanism:** The system uses 3D user positions *uₖ(t)* and reflector centroids *rₗ* to compute a geometric compatibility score *Cₖₗ* (Eq. 36), which biases the high-level allocator toward assignments where the reflector can geometrically redirect the AP signal toward the user. The low-level controllers then refine focal points based on local RSSI feedback.
*   **Core assumption:** In mmWave NLOS indoor environments, user position strongly correlates with channel path gain/angle-of-arrival, such that geometric alignment (distance, reflection angles) is a reliable proxy for channel quality without explicit CSI.
*   **Evidence anchors:**
    *   [abstract] "substitutes pilot-based channel estimation with readily available user localization data."
    *   [section IV-C] Compatibility matrix definition: *Cₖₗ = exp(−‖uₖ−rₗ‖/d₀)·cos(θₖₗ)*, encoding distance and reflection geometry.
    *   [section V-G] System tolerates localization errors up to 0.5 m with graceful degradation (<13 dB loss), confirming the approximation is robust to small inaccuracies.
*   **Break condition:** If localization error exceeds ~1 m (per V-G) or the propagation environment changes drastically (e.g., furniture moved, new obstacles), the geometric prior becomes misaligned with actual channels, causing allocation failures and RSSI collapse.

### Mechanism 3: Inductive Bias via Compatibility Matrix for Sparse Reward Learning
*   **Claim:** Embedding a domain-specific compatibility matrix into the high-level policy’s action sampling accelerates convergence in the exponentially large combinatorial assignment space and yields higher final performance.
*   **Mechanism:** During early training, the high-level controller samples assignments proportional to *Q(sᴴ,b) + α(t)∑ₖ Cₖ,ᵦₖ*, where *Q* is learned and *C* is the geometric prior. This biases exploration toward geometrically feasible user-reflector pairs, avoiding the need for exhaustive random search in a Kᴸ-action space.
*   **Core assumption:** The discrete assignment optimization suffers from extremely sparse rewards; random exploration is insufficient to discover good allocations within training budget. Geometric priors provide a coarse but correct signal to guide early learning.
*   **Evidence anchors:**
    *   [section IV-C] "compatibility matrix serves as a critical inductive bias... accelerates early convergence by approximately 200-300 episodes."
    *   [section V-B] Allocator (with matrix) reaches ~67 cumulative reward vs. No compat’s ~42 in 2UE (37% gap), showing both faster convergence and superior final performance.
    *   [corpus] Limited direct evidence; neighboring papers (e.g., HCPO, MAIDCRL) discuss hierarchical MARL exploration challenges but do not validate this specific geometric bias mechanism.
*   **Break condition:** If the reflector geometry or AP location is highly asymmetric such that simple Euclidean distance/angle heuristics are misleading (e.g., obstructed direct paths), the static compatibility matrix may repeatedly propose suboptimal assignments, stalling learning or converging to a poor local optimum.

## Foundational Learning
*   **Concept: Centralized Training with Decentralized Execution (CTDE)**
    *   **Why needed here:** The high-level allocator needs global state to make informed user-reflector assignments, but low-level controllers must execute with only local observations (user position, own reflector state) for scalability and no inter-agent communication during deployment. CTDE reconciles this by training a global critic with full state while policies use partial observations.
    *   **Quick check:** How does a global critic during training address the non-stationarity problem when multiple low-level agents learn concurrently?
*   **Concept: Focal Point Abstraction**
    *   **Why needed here:** Directly controlling 2*Nᵣ*N꜀ tile orientations per reflector is combinatorially explosive. The focal point abstraction reduces the parameter space from 2N² to 3L continuous coordinates per segment, while Eq. (2) maps focal points to tile orientations via geometric reflection laws.
    *   **Quick check:** What physical constraint (Eq. 5) must be satisfied by a focal point *fₗ* to ensure all tiles in segment *l* remain within mechanical angle limits?
*   **Concept: Temporal Abstraction in Hierarchical RL**
    *   **Why needed here:** The high-level allocator operates on a longer timescale (*T* steps) to allow low-level focal point controllers time to converge before reassignment. This prevents high-level decisions from disrupting low-level learning stability.
    *   **Quick check:** In Fig. 2, what would likely happen if the high-level controller changed assignments every timestep instead of every *T* steps?

## Architecture Onboarding
*   **Component map:** Compatibility Matrix → High-Level Allocator → Assignment Vector → Low-Level Controllers (per segment) → Focal Point Updates → Ray-tracing Environment → Rewards
*   **Critical path:**
    1.  Get user localization.
    2.  High-level sample assignment *b* every *T* steps using global state & compatibility matrix.
    3.  For each reflector *l*, low-level observes masked local state (assigned user *u*, own reflector *rₗ*, own focal point *fₗ*).
    4.  Execute continuous displacement action *aₗ,t*.
    5.  Update *fₗ* and enforce mechanical constraints.
    6.  Ray-tracing compute new per-user RSSI.
    7.  Every *T* steps, global reward updates high-level policy; every step, per-agent reward updates low-level policies.
*   **Design tradeoffs:**
    *   **Hierarchical vs. Centralized:** Hierarchical reduces dimensionality but may suffer from suboptimal assignments if high-level is poorly trained. Centralized has full observability but scales poorly (O(K·L) action space) and has credit assignment issues.
    *   **Compatibility matrix:** Provides essential exploration bias but requires geometric knowledge (AP/reflector positions). If environment changes (e.g., new walls), matrix may become obsolete; retraining needed.
    *   **Temporal abstraction period *T*:** Small *T* allows more responsive reassignment but destabilizes low-level learning. Large *T* stabilizes low-level but may cause poor allocation in dynamic user mobility. Paper uses *T*=? (implied but not explicitly stated in excerpt).
*   **Failure signatures:**
    *   **High variance in RSSI during deployment:** Likely cause: low-level focal point policies not fully converged before high-level reassignment (if *T* too small) or poor initial assignments (high-level exploration failure).
    *   **RSSI collapse when users move:** Indicates high-level allocator overfits to static user positions; test with dynamic mobility (as in V-C) to detect.
    *   **Sensitivity to localization error > 0.5 m:** Per V-G, error > 1 m causes steep degradation; monitor RSSI vs. injected positioning error.
*   **First 3 experiments:**
    1.  **Ablation: Train Allocator (with matrix) vs. No compat vs. No allocator (centralized) vs. Random.** Validate hierarchical gains and matrix contribution (V-B).
    2.  **Robustness: Evaluate with increasing Gaussian noise on user positions (σₑᵣᵣₒᵣ = 0.1→3.0 m).** Verify graceful degradation up to 0.5 m (V-G).
    3.  **Scalability: Double user count from 2 to 4.** Check per-user RSSI degradation (should be ~1.39 dB, not 3 dB) and total system RSSI stability (V-D).

## Open Questions the Paper Calls Out
### Open Question 1
*   **Question:** How does the HMARL framework perform under high-mobility conditions with user speeds significantly exceeding 1 m/s and fast time-varying channels, and what modifications to the temporal abstraction (e.g., variable T) are needed to maintain stability?
*   **Basis in paper:** [explicit] The conclusion states: "Future research will extend this paradigm to high-mobility scenarios with time-varying channels."
*   **Why unresolved:** The current evaluation uses a fixed mobility speed of 1 m/s and deterministic ray-tracing channels. High mobility introduces rapid user movement and channel fluctuations that may exceed the fixed allocation interval T, causing stale user-reflector assignments and performance collapse.
*   **What evidence would resolve it:** Simulations with diverse mobility models (e.g., vehicular speeds up to 10 m/s) and channel coherence times shorter than T, measuring RSSI degradation and convergence while testing adaptive T schedules or predictive allocation mechanisms.

### Open Question 2
*   **Question:** What are the performance gains and complexity trade-offs when jointly optimizing AP beamforming and reflector configurations in a unified HMARL framework, compared to the current sequential approach where reflector control is isolated?
*   **Basis in paper:** [explicit] The conclusion identifies "investigate joint AP-reflector beam-coordination" as a key future direction.
*   **Why unresolved:** The paper assumes AP beamforming is ideal or separate, focusing solely on reflector optimization. Joint control could exploit additional degrees of freedom (e.g., AP precoder, reflector focal points) but may explode the action space and require new hierarchical decompositions or credit assignment methods.
*   **What evidence would resolve it:** Extend the system model to include AP beamforming variables, design a joint HMARL policy (e.g., high-level for both, low-level for focal points), and compare RSSI, training stability, and computational overhead against the baseline in ray-tracing simulations.

### Open Question 3
*   **Question:** What practical mechanical limitations (e.g., actuation latency, precision errors, power consumption) of reconfigurable reflectors invalidate the ideal simulation assumptions, and how can policy learning be made resilient to these hardware constraints?
*   **Basis in paper:** [explicit] The conclusion calls for "validating the mechanical dynamics through physical prototyping."
*   **Why unresolved:** Simulations assume perfect, instantaneous focal point adjustments, but real reflectors have servo-induced delays, backlash, and positioning errors that may destabilize learned policies or reduce beam-focusing accuracy during deployment.
*   **What evidence would resolve it:** Construct a laboratory prototype with mechanically adjustable tiles, characterize its dynamic response (latency, error bounds), and test trained policies in controlled wireless environments, quantifying performance drops and identifying necessary policy robustness techniques (e.g., smooth actions, safety layers).

### Open Question 4
*   **Question:** Can the HMARL framework maintain robust RSSI performance under user localization errors exceeding 0.5 meters without retraining for each error level, and what algorithmic enhancements (e.g., domain randomization, robust RL) can achieve this?
*   **Basis in paper:** [inferred] Section V.G shows systematic RSSI degradation beyond 0.5m localization error, and the current solution trains policies with error-matched statistics.
*   **Why unresolved:** Training with specific error distributions requires prior knowledge of the localization system’s accuracy, which may be unknown or variable in practice. A policy robust to a range of errors would eliminate the need for per-deployment retraining and improve adaptability.
*   **What evidence would resolve it:** Implement domain randomization during training by sampling localization errors from a broad distribution (e.g., Gaussian with varying variances), evaluate held-out error levels up to several meters, and compare reward stability against error-matched training to demonstrate generalization.

## Limitations
*   The exact ray-tracing implementation details (Sionna/Blender specifics, tile reflection coefficients, modeling of `h_other,k`) are unspecified, hindering precise replication of RSSI calculations.
*   The annealing schedule for the compatibility matrix influence (α(t) threshold) is not detailed, creating uncertainty about high-level policy convergence stability.
*   Performance under rapidly time-varying channels or user speeds significantly beyond 1 m/s is not evaluated, leaving the framework's adaptability to dynamic environments questionable.

## Confidence
*   **Scalability & hierarchical decomposition:** High (directly supported by quantitative results showing widening gaps vs. centralized baselines as users increase).
*   **CSI-free viability via localization:** High (strongly evidenced by measured tolerance to up to 0.5 m localization error and consistent geometric prior use).
*   **Compatibility matrix as essential inductive bias:** Medium (ablation shows benefit, but acceleration claim lacks convergence curves; neighboring literature supports exploration challenges but not this specific bias).
*   **Total system power stability under density changes:** Medium (stated outcome based on aggregated RSSI reward, but per-user fairness implications need verification).
