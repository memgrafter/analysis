# Active perception and disentangled representations allow continual, episodic zero and few-shot learning

## Quick Facts
- **arXiv ID:** 2602.19355  
- **Source URL:** https://arxiv.org/abs/2602.19355  
- **Reference count:** 15  
- **Primary result:** The proposed Complementary Learning System achieves few-shot learning without catastrophic forgetting, true zero-shot transfer to unseen classes, and stable streaming reinforcement learning with batch size 1.

## Executive Summary
Continual reinforcement learning suffers from catastrophic interference, where learning new classes erases previously acquired knowledge. This paper introduces a bio-inspired Complementary Learning System: a fast, disentangled Short-Term Memory (STM) that stores experiences using sparse, nearly orthogonal codes and forgoes generalization, and a slow, statistical Long-Term Memory (LTM) that provides generalized perceptual descriptors via active perception. The STM learns by querying the LTM, which maps novel stimuli to familiar tokens, enabling zero-shot reasoning. Evaluated in a simulated garden environment, the disentangled STM maintains performance on original classes while rapidly acquiring new ones, generalizes to withheld bird-of-prey classes without direct experience, and operates effectively in an online streaming regime (batch size 1).

## Method Summary
The system consists of a frozen LLM (Mistral 7B) as LTM and two STM architectures: a disentangled STM based on sparse distributed memory (SDM) and an entangled baseline (feed‑forward network). The environment is defined by LLM‑generated dynamics: objects belong to 24 classes, and the agent (a mouse) receives a broad class observation and can issue 10 predefined perceptual queries (e.g., “Is it red?”) to the LTM, which returns single‑token answers. The STM processes the last six tokens with a recurrent encoder, stores Q‑values in an associative SDM, and selects either a perceptual query or one of four external actions. Training uses Q‑learning with ε‑greedy exploration. The disentangled STM updates only a small random subset of its memory cells per step, enabling interference‑free online learning. The entangled baseline requires minibatches and suffers from forgetting.

## Key Results
- **Few‑shot learning:** Disentangled STM preserves optimal mean reward (~0.1) on original classes while rapidly learning new classes; entangled baseline degrades to ~0.6 due to forgetting.  
- **Zero‑shot learning:** Disentangled STM attains optimal policy (mean reward 0.5) on withheld bird‑of‑prey classes (e.g., eagles, falcons) after training only on hawks, demonstrating true zero‑shot transfer.  
- **Streaming RL:** Disentangled STM matches performance with batch size 16 when learning with batch size 1 (online, no replay), confirming robustness to single‑threaded experience.

## Why This Works (Mechanism)

### Mechanism 1: Sparse disentangled STM prevents interference
- **Claim:** A sparse, disentangled STM representation enables rapid, interference‑free learning of new classes while preserving performance on previously learned classes.  
- **Mechanism:** The STM uses Sparse Distributed Memory (SDM) with a fixed random projection matrix *P* and top‑*k* activation. Only *k* active “clique” elements are updated per experience, creating orthogonal memory traces. New episodes modify isolated memory subsets, preventing overwriting even with high learning rate (η=0.1).  
- **Core assumption:** Sparsity (k=32 out of m=10000) induces sufficient orthogonality to avoid catastrophic interference regardless of decision boundary complexity.  
- **Evidence anchors:** [abstract] “fast, disentangled Short‑Term Memory (STM) foregoes generalization entirely, using sparse non‑interfering representations”; [section 2.2.2] Equations 1–5 detail sparse coding and local updates; [section 3.1] disentangled STM maintains ~0.1 reward on original data during 1280+ steps of new‑class exposure while entangled degrades to ~0.6.  
- **Break condition:** If the task requires more than *k* co‑active features for discrimination, or environmental noise yields inconsistent sparse codes, orthogonality fails and interference emerges.

### Mechanism 2: Active perception enables zero‑shot reasoning
- **Claim:** Zero‑shot learning of novel classes emerges from the STM’s ability to query the LTM for stable, generalized perceptual descriptors that remain consistent across unseen instances.  
- **Mechanism:** The STM selects perception‑actions (predefined questions) that query the LTM’s generalized knowledge. The frozen LLM maps any stimulus to a sequence of attribute tokens (e.g., “bird‑of‑prey” features). The STM learns policies conditioned on these tokens; when novel stimuli produce tokens matching dangerous patterns, it executes correct avoidance without direct experience.  
- **Core assumption:** The LTM’s statistical generalization reliably maps unseen class instances to a finite, task‑relevant vocabulary of perceptual tokens that the STM can interpret.  
- **Evidence anchors:** [abstract] “contextual bias provided by the fast learner induces the slow learner to encode novel stimuli in familiar, generalized terms, enabling zero‑shot reasoning”; [section 2.1.3] lists 10 fixed perceptual queries; [section 3.2] shows optimal policy (reward 0.5) on withheld eagles/falcons after training on hawks.  
- **Break condition:** If novel classes lack overlap with training classes on the predefined query set, or if the LTM’s responses are inconsistent/incorrect for novel stimuli, the STM receives unreliable tokens and fails.

### Mechanism 3: Streaming RL stability via local sparse updates
- **Claim:** Streaming RL with batch size 1 is feasible because STM updates are inherently stable and the LTM is frozen, eliminating the need for replay or mini‑batch gradient averaging.  
- **Mechanism:** Each step updates only a small, random subset of memory cells (k=32) with learning rate η=0.1, without backpropagation through time or cross‑step gradients. The frozen LTM ensures perception tokens are deterministic given input, avoiding catastrophic shifts. This enables true online, single‑threaded learning.  
- **Core assumption:** Memory capacity (m=10000) and sparsity (k=32) are sufficient that each update’s footprint is negligible relative to total memory, making gradient variance from single examples irrelevant.  
- **Evidence anchors:** [abstract] “The system learns effectively with batch size 1 (online, no replay), matching performance with batch size 16”; [section 3.3] Figure 7b shows overlapping reward trajectories for batch=1 and batch=16; [section 2.2.2] notes “can learn in streaming, online mode”.  
- **Break condition:** If the task requires long‑temporal credit assignment beyond the context window (n=6), or if sparse updates accumulate bias without mini‑batch averaging, performance may degrade.

## Foundational Learning
- **Sparse Distributed Representations**: Understanding how a fixed random projection + top‑k activation yields nearly orthogonal codes explains why interference is minimized. *Quick check:* If two memories activate 80% overlapping sparse codes, what happens to their mutual interference?  
- **Complementary Learning Systems (CLS)**: The architecture reverses the usual STM→LTM consolidation direction; grasping the biological inspiration (hippocampus vs. neocortex) clarifies why STM forgoes generalization. *Quick check:* In standard CLS, which system generalizes and which memorizes? How does this paper flip that?  
- **Active Perception**: The STM’s “disentanglement” is not about extracting raw features but about selecting which generalized features to request from LTM. *Quick check:* If STM cannot process raw pixels, how does it get information about a novel object it has never seen?

## Architecture Onboarding

**Component map:**  
LTM (frozen LLM, Mistral 7B) → STM (sparse recurrent encoder + associative SDM) → Environment (simulated garden with 24 classes, LLM‑generated dynamics).  
Control loop: STM emits a perceptual query → LTM returns a token → STM updates its context window → STM selects an external action → Environment returns reward → STM updates SDM.

**Critical path:**  
An episode begins with an initial broad class token from LTM. For up to 10 steps, the STM (a) issues a perceptual query to the LTM (receiving a token and appending it to the last six tokens) or (b) executes an external action. After an external action, the environment returns a reward (0 or ±1) based on LLM‑generated rules, and the STM updates its Q‑value for the (state, action) pair using sparse SDM rules. Episodes terminate on terminal actions or step limit.

**Design tradeoffs:**  
- Pre‑defined vs. learned perceptual queries: The fixed set of 10 questions is simple but limits adaptability; learning queries in LTM latent space could improve efficiency at the cost of complexity.  
- Frozen vs. trainable LTM: Freezing the LLM simplifies analysis and prevents interference, but may not optimally serve the agent’s task; an end‑to‑end trainable LTM would integrate learning but risks destabilizing the memory system.  
- Sparse vs. dense STM: Sparse SDM guarantees non‑interference but has limited pattern‑completion ability; the associative variant adds sampling at the price of extra memory.

**Failure signatures:**  
- STM overwrites old memories: Mean reward on pre‑training classes declines during new‑class learning, indicating sparse coding is insufficient (check *k*, *m*, or feature overlap).  
- Zero‑shot failure: STM performs at chance on withheld classes despite consistent LTM tokens, suggesting the perceptual query set lacks discriminative features for those classes.  
- Streaming instability: Variance in mean reward across runs increases dramatically with batch size 1, implying the learning rate is too high relative to sparsity/update frequency.

**First 3 experiments:**  
1. **Orthogonality check:** Compute pairwise cosine similarity between active memory cliques for random episodes; expect near zero given large *m* and small *k*.  
2. **Ablation – perceptual query necessity:** Disable STM’s ability to query LTM (only use broad class token); catastrophic forgetting should return and zero‑shot should fail.  
3. **Capacity scaling:** Vary memory size *m* while keeping *k/m* constant; performance should remain stable until capacity is exhausted, then degrade sharply.

## Open Questions the Paper Calls Out

### Open Question 1: Can the disentangled STM scale to high-dimensional, realistic environments?
- **Basis in paper:** [explicit] “Further work is needed to discover how to scale up these techniques to more complex and realistic high‑dimensional environments.”  
- **Why unresolved:** The current evaluation uses a simple text‑based environment; scaling to high‑D sensory inputs (e.g., images) may challenge the assumptions of disentanglement and active perception.  
- **What evidence would resolve it:** Apply the architecture to vision‑based RL tasks (e.g., Atari pixels, robotic control) while maintaining stable non‑interference and zero‑shot transfer.

### Open Question 2: How can the STM automatically discover useful perceptual queries from the LTM’s latent space?
- **Basis in paper:** [explicit] “In a more sophisticated version of this architecture, the STM should automatically discover useful perceptual frames and queries in the latent space of the LTM.”  
- **Why unresolved:** The perceptual action space is manually specified, which limits adaptability to new domains and may require hand‑engineering for each task.  
- **What evidence would resolve it:** Learn a parameterized query generator that maps STM internal states to LTM queries, trained end‑to‑end via reinforcement learning signals.

### Open Question 3: Does the associative SDM enable effective world models for zero/few‑shot learning through imagined rollouts?
- **Basis in paper:** [explicit] “The associative SDM supports pattern completion… this variant can be used to build fast‑learning world‑models… potentially another mechanism for zero or few‑shot learning.”  
- **Why unresolved:** Pattern completion in the associative SDM has not been tested as a dynamics model; it is unclear whether imagined rollouts are accurate enough for learning.  
- **What evidence would resolve it:** Integrate the associative SDM as a learned dynamics model, generate rollouts for policy or value updates, and evaluate sample efficiency and zero‑shot performance on continuous control tasks.

### Open Question 4: Can the disentangled STM generate suitable replay sequences for consolidation into the LTM?
- **Basis in paper:** [explicit] “It would be desirable to demonstrate specifically that the disentangled STM can generate suitable sequences for replay and consolidation.”  
- **Why unresolved:** The STM currently operates as an online learner without replay; its ability to select experiences that facilitate long‑term retention and generalization remains unknown.  
- **What evidence would resolve it:** Use the STM to select past episodes for replay, train the LTM with these sequences, and measure forgetting reduction and transfer to novel classes over extended learning periods.

## Limitations
- Reliance on a frozen LLM (Mistral 7B) introduces non‑determinism and reproducibility challenges; exact prompt templates and decoding strategies for perceptual queries are unspecified.  
- Critical hyperparameters for the SDM (memory size *m*, sparsity *k*, projection initialization) and the recurrent encoder architecture (hidden size, cell type) are not fully detailed, hindering faithful replication.  
- Evaluation is confined to a simple text‑based environment; scalability to high‑dimensional perceptual inputs (e.g., images) remains untested.

## Confidence
- **Sparse STM prevents interference** → Medium confidence (theoretically plausible but depends on undisclosed hyperparameters).  
- **Zero‑shot learning via LTM token generalization** → Low confidence (depends on arbitrary LLM outputs consistency and adequacy of fixed query set).  
- **Streaming RL robustness** → High confidence (empirical result directly tests claim and mechanism is well‑specified).

## Next Checks
1. **Orthogonality Stress Test:** For 1000 random episodes, compute average Jaccard similarity between active memory index sets; it must remain <0.05 under varying learning rates (0.01–0.5).  
2. **Perceptual Query Ablation for Zero‑Shot:** Disable all 10 predefined perceptual queries, allowing only the initial broad class token; zero‑shot performance on withheld bird‑of‑prey classes should drop to chance, confirming dependence on active perception.  
3. **Capacity Scaling Boundary:** Systematically reduce memory capacity *m* while keeping sparsity ratio *k/m* constant; identify the capacity where both few‑shot retention (<0.08 reward on old classes) and zero‑shot transfer fall below 50% of optimal.
