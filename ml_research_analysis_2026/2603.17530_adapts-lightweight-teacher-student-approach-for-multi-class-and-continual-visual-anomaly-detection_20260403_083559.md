# AdapTS: Lightweight Teacher-Student Approach for Multi-Class and Continual Visual Anomaly Detection

## Quick Facts
- **arXiv ID:** 2603.17530  
- **Source URL:** https://arxiv.org/abs/2603.17530  
- **Reference Count:** 22  
- **Primary Result:** AdapTS unifies multi-class and continual visual anomaly detection with SOTA-level image AUROC while adding only 8 MB (13–149× less than comparators) and achieving 99% dynamic task identification accuracy.

## Executive Summary
AdapTS proposes a unified teacher-student framework for visual anomaly detection that efficiently handles multiple object classes and continual learning scenarios. It freezes a pretrained backbone to serve as both teacher and student, and injects lightweight adapter modules into the student pathway, allowing task-specific adaptation without catastrophic forgetting. Training is enhanced with segmentation-guided objectives and synthetic Perlin noise to improve anomaly discrimination. At inference, a prototype-based mechanism selects the appropriate adapter with 99% accuracy. Evaluations on MVTec AD and VisA show that AdapTS matches state-of-the-art teacher-student methods in image-level AUROC across single, multi-class, and continual settings, while its smallest variant uses dramatically less additional memory, enabling deployment on resource-constrained edge devices.

## Method Summary
AdapTS employs a single pretrained backbone network (e.g., ImageNet-trained CNN) that remains frozen throughout training and inference. The backbone is used in two ways: as a teacher that processes normal reference images, and as a student that is augmented with small, trainable adapter modules placed at strategic layers. adapters modify the student’s feature extraction to adapt to each anomaly detection task. The training loss combines a feature-matching discrepancy between teacher and student features and a segmentation-guided loss that focuses on pixel-level differences using ground-truth masks. To augment normal training samples, synthetic anomalies are generated by overlaying Perlin noise, which mimics texture variations. Each task’s normal features are distilled into class-specific prototypes. At inference, an input image is compared to stored prototypes to identify the task, and the corresponding adapter is selected to process the image through the student. The anomaly score is derived from the discrepancy between student and teacher features.

## Key Results
- Matches SOTA teacher-student methods (STFPM, RD4AD, DeSTSeg) in image AUROC on MVTec AD and VisA across single, multi-class, and continual settings.
- Lightest variant, AdapTS-S, adds only 8 MB of memory—13× to 149× less than comparable methods—while maintaining competitive performance.
- Prototype-based task identification achieves 99% accuracy on benchmark splits.

## Why This Works (Mechanism)
The frozen backbone provides a rich, stable feature representation, acting as a consistent teacher that normalizes the student’s learning. Adapters enable efficient, modular adaptation: only a few parameters are updated per task, preventing forgetting and reducing computational overhead. Segmentation-guided loss directs the model to focus on anomalous regions, sharpening pixel-level discrimination, while Perlin noise introduces diverse synthetic defects that regularize the model and reduce overfitting to spurious patterns. The prototype-based task identification captures the typical feature distribution of each class; during inference, the input’s features are compared against these prototypes, allowing a simple nearest-neighbor selection that is both accurate and low-cost. Together, these mechanisms yield a unified, scalable solution for multi-class and continual anomaly detection.

## Architecture Onboarding
**Component Map:**  
Pretrained Backbone → (Teacher pathway & Student pathway with Adapters) → Anomaly Score; Segmentation Masks → Loss; Perlin Noise → Training Augmentation; Stored Prototypes → Task ID → Adapter Selection.

**Critical Path:**  
1. For each new task, train adapters using normal images (with and without Perlin noise) and segmentation-guided loss, while keeping backbone frozen.  
2. After training, compute and store prototypes from the normal images’ student features.  
3. At inference, compute features of input, compare to all stored prototypes, select the nearest (highest confidence), activate corresponding adapter, and compute anomaly score from student-teacher discrepancy.

**Design Tradeoffs:**  
- *Memory vs. Performance:* Adapters are tiny, but the frozen backbone dominates memory; total footprint may still be large for edge deployment.  
- *Flexibility vs. Scalability:* One adapter per task prevents forgetting but adapters accumulate linearly, eventually reaching capacity limits.  
- *Synthetic vs. Real Anomalies:* Perlin noise is easy to generate but may not capture all real defect modalities, risking a domain gap.  
- *Task ID Simplicity vs. Robustness:* Prototype-based selection is lightweight but assumes tasks are separable; ambiguous or overlapping tasks could misroute.

**Failure Signatures:**  
- Task identification accuracy drops sharply on mixtures of classes or under domain shift.  
- Anomaly detection performance declines for tasks with many synthetic Perlin patterns not representing real defects.  
- Memory usage grows linearly with tasks, exceeding hardware limits after many tasks.

**Three First Experiments:**  
1. Reproduce reported AUROC results on MVTec AD and VisA for single, multi-class, and continual settings, comparing against STFPM, RD4AD, DeSTSeg.  
2. Measure actual on-device memory consumption (including backbone) and inference latency for AdapTS-S on a representative edge platform (e.g., Raspberry Pi or Jetson Nano).  
3. Stress-test task identification by feeding inputs containing mixed anomalies from multiple classes or from unseen classes, and record misrouting rate.

## Limitations
- Adapter-only memory count ignores large frozen backbone; total footprint may exceed edge constraints.  
- Prototype-based task identification may fail on ambiguous or overlapping tasks.  
- Evaluation limited to image AUROC; localization quality and generalization to diverse real-world anomalies remain unverified.
