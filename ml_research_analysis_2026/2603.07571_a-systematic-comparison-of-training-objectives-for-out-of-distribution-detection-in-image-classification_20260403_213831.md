# A Systematic Comparison of Training Objectives for Out-of-Distribution Detection in Image Classification

## Quick Facts
- **arXiv ID:** 2603.07571
- **Source URL:** https://arxiv.org/abs/2603.07571
- **Reference count:** 40
- **Primary result:** Cross-Entropy loss yields the most robust OOD detection across datasets (near ~83.5%, far ~91.2% AUROC on ImageNet-200) while maintaining ID accuracy on par with other objectives.

## Executive Summary
This paper presents a systematic study of how training objectives influence out-of-distribution (OOD) detection performance in image classification. The authors evaluate four loss functions—Cross-Entropy (CE), Prototype, Triplet, and Average Precision (AP)—on CIFAR-10/100 and ImageNet-200 under standardized OpenOOD protocols, using each objective’s natural inference and OOD scoring method. CE consistently achieves the best balance of in-distribution (ID) accuracy and OOD separability across both near and far OOD benchmarks. Prototype loss often attains the highest ID accuracy but yields inconsistent OOD detection. Triplet loss leads to substantial ID accuracy drops on class-rich datasets while showing mixed OOD results, though it excels at far-OOD on CIFAR-10. AP loss demonstrates strong far-OOD detection on CIFAR-10 but underperforms on larger datasets. The work establishes CE as a reliable default and highlights inherent trade-offs between ID classification and OOD detection when varying training objectives.

## Method Summary
The study trains ResNet-18 models on three ID datasets (CIFAR-10, CIFAR-100, ImageNet-200) using four distinct training objectives. For CE, Prototype, and AP, the network outputs class logits; for Triplet and Prototype, the final layer produces an embedding vector. Each objective employs a dataset-specific OOD scoring rule: entropy or maximum softmax probability (MSP) for probabilistic objectives, and nearest-neighbor distance for metric objectives. Hyperparameters (learning rate, embedding dimension, loss-specific parameters) are selected via validation ID accuracy. Models are evaluated using the OpenOOD v1.5 framework, reporting ID classification accuracy and AUROC for near-OOD (semantically similar) and far-OOD (dissimilar) benchmarks. Five independent runs per setting provide statistical robustness.

## Key Results
- Cross-Entropy loss delivers the most consistent OOD detection, achieving near-OOD AUROC ~83.5% and far-OOD AUROC ~91.2% on ImageNet-200 while maintaining ID accuracy of ~86–95% across datasets.
- Prototype loss yields the highest ID accuracy (95.1% on CIFAR-10, 78.2% on CIFAR-100) but exhibits inconsistent OOD performance, particularly on near-OOD benchmarks.
- Triplet loss causes significant ID accuracy degradation on class-rich datasets (69.0% on CIFAR-100, 68.1% on ImageNet-200) and shows mixed OOD results, though it attains the best far-OOD AUROC (92.3%) on CIFAR-10.
- Average Precision loss provides strong far-OOD detection on CIFAR-10 (92.3%) but weaker performance on CIFAR-100 (77.7%) and ImageNet-200 (90.5%).

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Cross-Entropy (CE) loss yields the most consistent OOD detection because its softmax probabilities naturally produce low confidence (high entropy or low max probability) for samples that do not align well with any in-distribution (ID) class.
- **Mechanism:** CE optimizes a probabilistic classifier over logits. During inference, the softmax output reflects relative alignment with ID class prototypes implicitly learned in the final layer. OOD samples typically fail to strongly match any class, leading to dispersed probabilities (high entropy) or a low maximum probability (MSP), both effective for OOD scoring.
- **Core assumption:** OOD data lies in regions of the feature space where the classifier is uncertain, not just wrong; this uncertainty is captured by the softmax distribution.
- **Evidence anchors:**  
  [abstract] "Cross-Entropy Loss provides the most consistent near- and far-OOD performance overall."  
  [section 3.2.1] Details how MSP and entropy are derived from softmax probabilities for OOD scoring.  
  [corpus] Neighbor papers (e.g., [215936] on ranking for OOD) corroborate that score-based separation relies on predictive distributions.
- **Break condition:** If ID classes are highly correlated or OOD data is *near*-OOD with features overlapping ID clusters, softmax may remain confidently incorrect, reducing separability.

### Mechanism 2
- **Claim:** Prototype Loss improves ID accuracy by enforcing compact class clusters around learned prototypes, but OOD detection is inconsistent because separation depends on prototype positioning relative to OOD data.
- **Mechanism:** Prototype Loss (via GCPL) combines distance-based cross-entropy with a center loss, explicitly minimizing embedding distance to class-specific prototypes. This sharpens intra-class clustering. For OOD, distance-to-prototype scores are converted to probabilities via temperature-scaled softmax; OOD detection then uses MSP or entropy on these probabilities.
- **Core assumption:** Class prototypes adequately represent the mode of each ID class distribution; OOD samples are far from all prototypes.
- **Evidence anchors:**  
  [abstract] "Prototype Loss often yields the highest ID accuracy (95.1% CIFAR-10, 78.2% CIFAR-100)."  
  [section 3.2.3] Formulation of prototype-based probabilities and OOD scoring rules.  
  [corpus] [2305.14696] explores ranking-based OOD detection, indirectly supporting that structured embeddings can aid separation.
- **Break condition:** When OOD data lies near class boundaries or between prototypes, or when class count is very high (e.g., ImageNet-200), prototypes may not be well-separated, leading to ambiguous distances and poor OOD AUROC.

### Mechanism 3
- **Claim:** Triplet Loss enhances far-OOD detection by forcing inter-class separation in the embedding space, but ID accuracy suffers on class-rich datasets due to ineffective triplet sampling and embedding distortion.
- **Mechanism:** Triplet Loss minimizes distance between anchor-positive pairs and maximizes anchor-negative distance with a margin. The embedding space becomes metric, and OOD scoring uses nearest-neighbor distance to training embeddings. Far-OOD samples tend to be far from all training points, yielding high OOD scores.
- **Core assumption:** Meaningful triplets (with informative negatives) exist and can be sampled for all classes; the embedding space remains linearly separable for classification via nearest neighbor.
- **Evidence anchors:**  
  [abstract] "Triplet causes significant ID accuracy drops on class-rich datasets (69.0% CIFAR-100, 68.1% ImageNet-200)."  
  [section 3.2.2] Triplet mining strategies (Random for CIFAR-10, Semi-hard for CIFAR-100/ImageNet-200) and nearest-neighbor inference.  
  [corpus] [2312.08894] uses triplet-style learning for OOD in radar sensing, showing domain-specific viability but not addressing class-scalability issues.
- **Break condition:** With many classes, semi-hard negatives become too hard or too easy, leading to poor gradients; nearest-neighbor classification becomes noisy due to embedding collapse or fragmentation, causing ID accuracy collapse.

## Foundational Learning
- **Concept: OOD evaluation taxonomy (near vs. far AUROC)**  
  *Why needed:* The paper’s results compare near- and far-OOD AUROC; understanding that near-OOD (e.g., CIFAR-100 for CIFAR-10) is semantically harder to detect than far-OOD (e.g., MNIST) is crucial for interpreting trade-offs.  
  *Quick check:* Why might a method perform well on far-OOD but poorly on near-OOD?

- **Concept: Training objective families and natural inference alignment**  
  *Why needed:* Each loss (CE, Prototype, Triplet, AP) has a standard OOD scoring rule (MSP/entropy, distance-based) that is not interchangeable; misalignment invalidates comparisons.  
  *Quick check:* For Prototype Loss, how does the temperature parameter τ affect OOD scoring via softmax?

- **Concept: Hyperparameter sensitivity per objective**  
  *Why needed:* Appendix A shows learning rates, embedding dimensions, and loss-specific parameters (λ, τ) vary across datasets; poor tuning could explain performance differences.  
  *Quick check:* Why does Triplet Loss require a significantly smaller learning rate than CE on CIFAR-100?

## Architecture Onboarding
**Component map:**  
Input (ID images + OOD benchmarks) -> Backbone (ResNet-18) -> Output head (FC for CE/AP; embedding head for Triplet/Prototype) -> Loss module (CE / Triplet with mining / Prototype with GCPL / AP with ranking) -> OOD scoring module (entropy/MSP for probabilistic; min distance for metric) -> Evaluation (OpenOOD computes ID accuracy, near/far AUROC)

**Critical path:**
1. Select dataset and training objective.
2. Tune hyperparameters on validation set (ID accuracy as primary guideline).
3. Choose OOD scoring rule by validating AUROC (if multiple candidates like MSP/entropy).
4. Train final model, evaluate on OpenOOD test splits.
5. Repeat for 5 independent runs for statistical significance.

**Design tradeoffs:**
- ID vs. OOD: Prototype prioritizes ID accuracy; Triplet may boost far-OOD at severe ID cost.
- Scalability: CE and Prototype scale to many classes; Triplet degrades due to sampling; AP is moderate.
- Computational: Triplet has high memory/compute (triplet mining); AP has ranking overhead; CE/Prototype are standard.
- Inference-time: Triplet requires storing/querying training embeddings for nearest-neighbor; others are feedforward.

**Failure signatures:**
- Triplet: ID accuracy <70% on CIFAR-100/ImageNet-200; far-OOD AUROC drop if embedding collapses.
- Prototype: Near-OOD AUROC close to random (e.g., <80% on CIFAR-100) if prototypes not discriminative.
- AP: Far-OOD AUROC plummets on mid-complexity datasets (CIFAR-100: 77.7% vs. CE 80.5%).
- CE: Inconsistent near-OOD if ID classes have nuisance correlations.

**First 3 experiments:**
1. **Baseline CE on CIFAR-10:** Verify ID accuracy ~95%, far-OOD AUROC ~91%; test both MSP and entropy scoring to confirm selected rule (entropy from Appendix A).
2. **Prototype vs. CE on CIFAR-100:** Expect Prototype higher ID (78.2% vs. 77.1%), but check near-OOD AUROC drop (79.95% vs. 80.94%).
3. **Triplet mining switch:** Run Triplet on CIFAR-10 with Random mining (expected far-OOD ~92.3%) and on ImageNet-200 with Semi-hard (expected ID ~68%); confirm mining strategy matches paper.

## Open Questions the Paper Calls Out
- **Question 1:** Do self-supervised pretraining objectives improve OOD detection relative to the supervised objectives studied?  
  *Basis:* Future work includes "contrastive or self-supervised pretraining objectives."  
  *Why unresolved:* The study only considered supervised losses; self-supervised methods may produce distinct representations.  
  *What evidence would resolve it:* Systematically evaluate self-supervised models (e.g., contrastive) on OpenOOD benchmarks with the same backbone.

- **Question 2:** Are the paper's key findings (e.g., CE robustness, Triplet's limitations) generalizable to architectures other than ResNet-18?  
  *Basis:* Future work proposes "testing whether the observed trends hold under different backbones."  
  *Why unresolved:* All experiments used ResNet-18; other architectures might yield different trade-offs.  
  *What evidence would resolve it:* Replicate the study with diverse architectures (e.g., ViT) under identical OpenOOD protocols.

- **Question 3:** Can hybrid objectives combining probabilistic and metric-based losses achieve better ID-OOD trade-offs than single objectives?  
  *Basis:* Future work mentions "hybrid objectives that combine probabilistic and metric-based supervision."  
  *Why unresolved:* Single objectives show specific trade-offs; hybrids might integrate benefits but are untested.  
  *What evidence would resolve it:* Implement combined losses (e.g., CE + Triplet), tune hyperparameters, and compare performance on all datasets.

- **Question 4:** Does the natural pairing of objectives with scoring methods bias the results, and would a fully crossed design change the relative rankings?  
  *Basis:* Limitation: "the training objective and OOD scoring rule are not fully factorized; a fully crossed comparison... remains important future work."  
  *Why unresolved:* Each objective was evaluated with its standard scoring rule; alternative pairings might alter conclusions.  
  *What evidence would resolve it:* For each objective, compute OOD scores using multiple methods (MSP, entropy, nearest-neighbor) and analyze the full cross-product.

## Limitations
- The precise algorithm and gradient computation for Average Precision (AP) Loss, including the “three-step ranking-loss formulation” and “identity/error-driven update,” are not fully specified, hindering replication.
- The hyperparameter search space, validation set size, and exact criterion (ID accuracy vs. OOD AUROC) for selecting learning rates, embedding dimensions, and loss-specific parameters (λ, τ) are not detailed.
- The exact OpenOOD v1.5 dataset splits, preprocessing, and ImageNet-200 subset construction are not documented, risking evaluation mismatches.

## Confidence
- **Cross-Entropy robustness:** High – consistent across three datasets and both near/far OOD benchmarks using standard scoring.
- **Prototype OOD inconsistency:** Medium – performance hinges on prototype positioning and temperature scaling; break conditions not thoroughly examined.
- **Triplet ID drop:** Medium – sensitive to mining strategy and class cardinality; embedding distortion may explain poor scalability.
- **AP loss trade-offs:** Low – implementation is opaque; reported far-OOD superiority on CIFAR-10 cannot be independently verified without reproducing the referenced ranking-loss approach.
