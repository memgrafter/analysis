# Learning Unified Distance Metric for Heterogeneous Attribute Data Clustering

## Quick Facts
- **arXiv ID:** 2603.04458
- **Source URL:** https://arxiv.org/abs/2603.04458
- **Reference count:** 40
- **Primary result:** HARR learns a unified metric for mixed-type clustering, with HARR-M significantly outperforming 10 SOTA methods on 14 datasets without hyperparameters.

## Executive Summary
Clustering datasets with numerical and categorical attributes is challenging due to incompatible distance structures. The Heterogeneous Attribute Reconstruction and Representation (HARR) paradigm addresses this by projecting categorical values into multiple one-dimensional Euclidean-like spaces using a base distance derived from conditional probability differences. This homogenizes all attribute representations into a common metric space. HARR then jointly optimizes cluster partitions and attribute weights—either globally (HARR-V) or per-cluster (HARR-M). On 14 benchmark datasets, HARR-M achieves significant improvements in Adjusted Rand Index and Clustering Accuracy over 10 state-of-the-art methods. HARR-V remains highly competitive. The approach converges quickly (within 15 iterations), scales linearly, and ablation studies confirm the contribution of each component.

## Method Summary
HARR introduces a two-stage learning paradigm. First, each categorical attribute’s values are embedded into multiple one-dimensional Euclidean-like spaces. The embedding uses a base distance computed from conditional probability differences, capturing semantic relationships between categories and the target clustering structure. Second, a joint optimization framework alternately updates cluster assignments and attribute weights. HARR-V learns a single global weight vector for all clusters, while HARR-M allows cluster-specific weights, adding flexibility. The process requires no manual hyperparameter tuning and produces a unified distance metric applicable to any mixed-type dataset.

## Key Results
- HARR-M significantly outperforms 10 state-of-the-art clustering methods in Adjusted Rand Index and Clustering Accuracy across 14 datasets; HARR-V is very competitive.
- Ablation studies confirm the effectiveness of the conditional probability-based distance, multi-projection mechanism, and weighting strategies.
- HARR converges rapidly (≤15 iterations), scales linearly with data size, and t-SNE visualizations show markedly improved cluster separation using the learned metric.

## Why This Works (Mechanism)
HARR succeeds by transforming categorical data into a form compatible with Euclidean distance. The conditional probability difference base distance measures how likely two category values belong to the same cluster, embedding domain semantics directly into geometry. Projecting into multiple 1D spaces provides enough flexibility to model complex relationships without high-dimensional overhead. Jointly optimizing weights and clusters ensures the metric adapts to the actual data distribution: important attributes (or attribute-cluster pairs) receive higher weight, while noisy ones are downweighted. This avoids arbitrary distance choices for categorical attributes (e.g., simple matching) that often degrade mixed-type clustering.

## Foundational Learning
- **Distance Metric Learning:** Unifies heterogeneous data under a single similarity measure. *Why needed:* Clustering quality hinges on distance definition. *Quick check:* Verify learned metric satisfies symmetry and non-negativity on a validation set.
- **Categorical Data Embedding:** Maps unordered categories to numeric space. *Why needed:* Standard distances (e.g., Euclidean) fail on pure categorical values. *Quick check:* Similar categories (e.g., “car” and “vehicle”) should have smaller Euclidean distances after projection.
- **Conditional Probability Distance:** Uses $|P(\text{cluster}|A=x) - P(\text{cluster}|A=y)|$ as dissimilarity. *Why needed:* Captures attribute-cluster dependency directly. *Quick check:* Correlate base distance with true cluster labels on a held-out set.
- **Multi-Projection per Attribute:** Each categorical attribute is mapped to $K$ 1D spaces. *Why needed:* Single projection may not preserve all discriminative information. *Quick check:* Sweep $K$; performance should plateau after a small $K$ (e.g., 3–5).
- **Joint Optimization of Weights and Clusters:** Alternates between updating cluster assignments (e.g., k-means) and attribute weights. *Why needed:* Attribute relevance is data-dependent and potentially cluster-specific. *Quick check:* Ablate weighting; clustering performance should degrade notably.
- **Heterogeneous Data Clustering:** Integrates numerical (directly used) and categorical (projected) attributes. *Why needed:* Real-world datasets are rarely pure. *Quick check:* Apply to purely numerical or categorical benchmarks; HARR should remain competitive with specialized methods.

## Architecture Onboarding
Component map:  
Categorical Attributes → Projection Module (multi-1D spaces) → Euclidean-like Representations → Weighted Distance Computation → Joint Optimization (Cluster Assignments ↔ Attribute Weights) → Final Clusters

Critical path:  
1. For each categorical attribute, learn projection matrices mapping values to $K$ 1D spaces using conditional probability differences.  
2. Combine with numerical attributes into a unified feature space.  
3. Initialize cluster centroids and attribute weights (global or per-cluster).  
4. Iterate: (a) Assign points to nearest centroid using weighted distance; (b) Update weights to maximize cluster separation (closed-form solution).  
5. Stop upon assignment stability or max iterations.

Design tradeoffs:  
- **HARR-M vs. HARR-V:** HARR-M models cluster-specific attribute relevance, potentially capturing nuanced patterns but increasing parameters and risk of overfitting on small clusters. HARR-V is simpler and more robust when attribute importance is uniform.  
- **Projection dimensionality ($K$):** Larger $K$ increases representation capacity but adds computational cost and may overfit. The paper claims $K$ is fixed (no tuning), but in practice it may need adjustment for very high-cardinality categories.  
- **Base distance choice:** Conditional probability difference is intuitive and parameter-free, but may be less stable with sparse data compared to learned embeddings.

Failure signatures:  
- **Diverging weights:** Some weights explode or vanish, indicating poor initialization or extreme imbalance in attribute distributions.  
- **Oscillating assignments:** Cluster labels flip between iterations, suggesting the weighting update is too aggressive or the base distance is uninformative.  
- **Degenerate projections:** All categorical values map near zero in all 1D spaces, implying the conditional probability estimates are uniform (e.g., due to severe data sparsity).

First three experiments:  
1. **Sanity check on synthetic mixed data:** Generate a dataset with 2 clusters, 1 numerical and 1 categorical attribute (3 categories). Verify HARR recovers true clusters and that weights reflect known attribute importance.  
2. **Projection dimension ablation:** On a mid-sized benchmark (e.g., “Acute Inflammations”), run HARR with $K \in \{1,3,5,10\}$. Plot ARI vs. $K$ to confirm performance stabilizes quickly.  
3. **Global vs. per-cluster weighting comparison:** On a dataset with intuitive subgroup differences (e.g., “Zoo” where animal types may value features differently), compare HARR-V and HARR-M statistical significance via paired t-test over 20 random seeds.

## Limitations
- **Benchmark scope:** Evaluation on only 14 datasets may not capture diversity in size, dimensionality, or domain; lacks large-scale or high-dimensional heterogeneous benchmarks.
- **Baseline coverage:** No comparison with recent deep learning or LLM-based methods for categorical clustering, which could represent stronger contemporary baselines.
- **Validation rigor:** Performance differences are not supported by statistical significance tests; the “no hyperparameters” claim is not systematically validated (e.g., projection count $K$ may implicitly act as one).

## Next Checks
- **Expand benchmarks:** Test HARR on recent heterogeneous clustering methods (including deep/LLM-based) and on large, high-dimensional datasets with missing values.
- **Statistical testing:** Report paired t-test p-values across multiple random seeds for all primary metrics (ARI, CA) to assess significance of improvements.
- **Sensitivity analysis:** Systematically vary the number of projection dimensions $K$ and convergence tolerance to quantify impact on clustering quality and identify any hidden hyperparameters.
