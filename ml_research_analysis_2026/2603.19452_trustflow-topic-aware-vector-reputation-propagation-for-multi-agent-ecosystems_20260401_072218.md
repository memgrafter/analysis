# TrustFlow: Topic-Aware Vector Reputation Propagation for Multi-Agent Ecosystems

## Quick Facts
- **arXiv ID:** 2603.19452
- **Source URL:** https://arxiv.org/abs/2603.19452
- **Reference count:** 0
- **Primary result:** Solves multi-domain reputation with topic-gated vector propagation, achieving up to 98% Precision@5 on dense graphs and structural resistance to sybil attacks (≤4pp impact).

## Executive Summary
TrustFlow addresses fundamental flaws in scalar reputation systems (e.g., PageRank) for multi-agent ecosystems where agents possess varied expertise and interactions can be adversarial. It replaces a single trust score with a multi-dimensional reputation vector in the same semantic space as content. Trust propagates via a topic-gated transfer operator that modulates each edge by its content embedding, allowing cross-domain trust to flow only when semantically aligned. The system guarantees convergence to a unique fixed point and enables direct dot-product retrieval at query time, eliminating separate ranking infrastructure.

## Method Summary
The core method defines an iterative update: `R_new[j] = α Σ_i w(i→j) f(R[i], e_ij) + (1-α)T[j] + C[j]`. Here, `R[i]` is the sender's vector reputation, `e_ij` is the interaction content embedding, `w(i→j)` are row-normalized edge weights, `T[j]` is a teleportation prior (agent's own profile), and `C[j]` is exogenous authority. The transfer operator `f` (e.g., projection, squared gating) is Lipschitz-1, making the entire mapping a contraction with factor `α`. This ensures linear convergence from any initialization. For "blind" edges lacking content, a proxy like `avg(profile_i, profile_j)` is used. At query time, agents are ranked by dot-product `R[j]·q` against the query embedding.

## Key Results
- Achieves up to **98% multi-label Precision@5** on dense interaction graphs (156+ edges) and **78% on sparse graphs** (70 edges).
- **Structurally resists attacks**: cross-domain sybil rings and vote rings cause at most a 4 percentage point drop in P@5; same-domain sybils are mitigable via flags.
- Enables **direct dot-product retrieval** without a separate ranking layer, thanks to vector reputation in query embedding space.

## Why This Works (Mechanism)

### Mechanism 1: Convergence to a Unique Fixed Point
- **Claim:** The iterative update converges to a unique reputation vector from any initialization.
- **Mechanism:** The update rule forms a contraction mapping with factor `α` when `f` is Lipschitz-1 (`∥f(R1,e) - f(R2,e)∥ ≤ ∥R1-R2∥`) and edge weights are row-normalized (`∑_i w(i→j)=1`). By the Banach fixed-point theorem, a unique fixed point exists and is reached linearly.
- **Core assumption:** All chosen operators `f` satisfy the Lipschitz-1 condition.
- **Evidence anchors:** [abstract] convergence guarantee via contraction mapping; [section 3.5] full proof showing `∥F(R1)-F(R2)∥ ≤ α∥R1-R2∥`.
- **Break condition:** If `f` is unbounded (e.g., scaling >1) or row-normalization is skipped, contraction fails, risking divergence or multiple fixed points.

### Mechanism 2: Cross-Domain Trust Isolation
- **Claim:** Reputation leaks across domains only when interaction content semantically aligns with both agents' expertise.
- **Mechanism:** Each edge's transfer is modulated by its content embedding `e_ij`. Operators like **projection** (`σ(R·e)·e`) restrict output to the interaction's direction; **squared gating** (`R⊙e²`) applies per-dimension filters; **KL-divergence gating** penalizes transfers where sender profile `R[i]` misaligns with interaction topic distribution.
- **Core assumption:** `e_ij` accurately captures the interaction's topic. For blind edges, the proxy `avg(p_i,p_j)` assumes the topic lies between agents' declared expertise.
- **Evidence anchors:** [section 3.3] topic-gating ensures alignment; [table 2] projection achieves maximum cross-domain isolation; [table 7] KL-gating improves self-alignment by 24.5%.
- **Break condition:** Poor `e_ij` proxies (e.g., adversarial content) can inhibit legitimate transfer or fail to block malicious cross-domain flow. Mean-centering of embeddings is required for reliable cosine alignment.

### Mechanism 3: Structural Attack Resistance
- **Claim:** The system bounds sybil attack impact and prevents reputation laundering/vote rings.
- **Mechanism:** (1) **Teleportation ceiling** limits total sybil cluster reputation by `T_total + C_total/(1-α)`. (2) **Row normalization** dilutes per-edge weight as attackers add outgoing edges. (3) **Topic-gating** prevents cross-domain sybil amplification. (4) **α-damping** geometrically attenuates cyclic vote rings (`α^k` per cycle). Negative edges via flags provide active defense.
- **Core assumption:** Attackers cannot generate abundant high-quality, topic-aligned edges with strong economic delegation.
- **Evidence anchors:** [section 6.1] lists teleportation ceiling, normalization dilution, delegation asymmetry; [section 5.5] empirical: cross-domain sybil P@5 unchanged (78.0%), vote rings bounded by contraction.
- **Break condition:** If attackers produce many topic-aligned edges with high delegation weight (e.g., via compromised payments) and evade ownership detection, they could exceed the teleportation ceiling. Flag efficacy depends on timely, accurate reporting.

## Foundational Learning
- **Concept: PageRank and Topic-Sensitive PageRank (TSPR)**
  - **Why needed:** TrustFlow generalizes PageRank's `r = αMᵀr + (1-α)v`. TSPR uses topic-biased teleportation but still scalar. TrustFlow's key advance is per-edge topic modulation via `f(R[i],e_ij)` and vector output.
  - **Quick check:** How does TSPR's single transition matrix `M` for all topics limit multi-domain agent reputation, and how does TrustFlow's topic-gated transfer overcome this?

- **Concept: Contraction Mapping Theorem**
  - **Why needed:** The convergence proof hinges on showing the operator `F(R)` is a contraction (`∥F(R1)-F(R2)∥ ≤ α∥R1-R2∥` with `α<1`). This requires Lipschitz continuity and the Banach fixed-point theorem.
  - **Quick check:** Why is row-normalization of edge weights (`∑_j w(i→j)=1`) critical for the contraction proof?

- **Concept: Embedding Anisotropy and Mean-Centering**
  - **Why needed:** Dense LM embeddings (e.g., E5) cluster in a narrow cone, yielding high inter-domain cosine (0.87–0.93). This destroys topical discrimination. Mean-centering (`ṽ = v - mean(v)`) is mandatory to achieve meaningful alignment (0.25–0.60).
  - **Quick check:** What retrieval failure occurs without mean-centering, and why does the cone clustering cause it?

## Architecture Onboarding
- **Component map:** Interaction Graph Builder -> Embedding Pipeline -> Transfer Operator Selector -> Convergence Engine -> Reputation Store -> Retrieval Module
- **Critical path:** Graph construction -> Embedding & mean-centering -> Operator/gate selection -> Convergence loop -> Persist vectors -> Query-time dot-product retrieval.
- **Design tradeoffs:**
  - **Operator choice:** Projection for max cross-domain isolation (best on combined graph); squared gating for blind-edge preservation and fast convergence; scalar-gated for dense labeled graphs. Hybrid per-edge selection is complex but flexible.
  - **Continuous vs. discrete:** Continuous embedding space necessary for sparse, content-varied graphs; discrete domains fail on blind edges and cross-domain specialists.
  - **Magnitude usage:** Use raw dot-product (`R[j]·q`) if embeddings isotropic (post mean-centering). Add magnitude (`log(∥R[j]∥)`) as reranker if anisotropy risks remain.
- **Failure signatures:**
  - **Slow/no convergence:** Check Lipschitz-1 of `f`; ensure row-normalization; verify `α<1`.
  - **Low cross-domain P@5:** Likely missing mean-centering; or using projection on graphs with many blind edges.
  - **Sybils ranking high:** Check exogenous `C` signals; verify row-normalization; ensure blind-edge discount applied.
  - **Magnitude-dominated results:** Uncentered embeddings causing hub agents to have spuriously high cosine with all queries.
- **First 3 experiments:**
  1. **Operator & density sweep:** Run all 5 operators on sparse (~70 edges) vs. dense (156+) graphs. Expect: scalar-gated peaks on dense; projection on combined; squared gating fastest. Validate P@5 improvements with density.
  2. **Attack resistance stress test:** Inject cross-domain/same-domain sybil rings, vote rings, laundering chains. Measure P@5 delta. Expect ≤4pp impact for all except same-domain sybils (~4pp), mitigable by flags.
  3. **Embedding preprocessing A/B:** Compare with/without mean-centering. Expect catastrophic P@5 drop (~58pp) without centering; inter-domain cosine should drop from 0.87–0.93 to 0.25–0.60.

## Open Questions the Paper Calls Out
- **Blind edge proxy improvement:** How to learn better proxies for content-free edges using caller-callee features and context, beyond simple averaging?
- **Operator selection at scale:** Under which graph conditions (density, label ratio, domain diversity) does each operator (or an adaptive hybrid) perform optimally?
- **Economic trust scaling:** Should payment delegation edges use linear multipliers (e.g., 3×) or logarithmic scaling to balance legitimate high-value signals against capital-backed sybil attacks?
- **Temporal dynamics:** How to incorporate decay (`ω(τ)=e−λτ`) to prevent stale interactions from dominating and reflect evolving agent competence?

## Limitations
- Proprietary 50-agent benchmark dataset (8 domains, 682 edges, 10 queries) is unreleased, blocking exact replication.
- Hybrid operator selection logic and composable gate parameters (e.g., KL weighting) are unspecified.
- Exact construction of teleportation prior `T` (from agent content with engagement weights) and exogenous signals `C` (from six signal classes) is not detailed.

## Confidence
- **Convergence guarantee:** High. Proof based on contraction mapping is rigorous with clear Lipschitz-1 and row-normalization conditions.
- **Cross-domain isolation:** Medium. Relies on embedding quality and mean-centering; operator choice significantly impacts performance; blind edges introduce uncertainty.
- **Attack resistance:** Medium. Structural defenses (teleportation ceiling, normalization) are sound, but efficacy may degrade under adversarial edge generation (e.g., topic-aligned sybils via compromised delegation).

## Next Checks
