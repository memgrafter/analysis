# Conformal Cross-Modal Active Learning

## Quick Facts
- **arXiv ID**: 2603.23159
- **Source URL**: https://arxiv.org/abs/2603.23159
- **Reference count**: 40
- **Primary result**: CCMA outperforms SOTA AL baselines on multiple datasets (e.g., CIFAR100 91.6% vs BADGE 91.3%) with superior label efficiency, especially in low-budget regimes.

## Executive Summary
Active learning (AL) for vision foundation models has remained vision-only, overlooking the rich multimodal knowledge in vision-language models (VLMs). This work introduces Conformal Cross-Modal Acquisition (CCMA), which uses a frozen VLM teacher to provide calibrated, semantically grounded uncertainty via conformal prediction sets. These sets guide a vision-only student model through a teacher-student disagreement score combining Jensen-Shannon divergence and student entropy, with diversity ensured via a selective subpool and uncertainty-weighted coverage. CCMA consistently achieves higher test accuracy than SOTA AL baselines on CIFAR100, Food101, and DomainNet-Real, and reaches target accuracies with fewer annotations. Ablations confirm the necessity of both calibrated cross-modal scoring and the two-stage diversity selection.

## Method Summary
CCMA is a pool-based active learning method for image classification that leverages a frozen vision-language model (VLM) teacher to guide a trainable vision-only student. Each AL round proceeds as follows: (1) Precompute CLIP image embeddings for the unlabeled pool and cluster them to form a selective subpool of candidates, reducing computational cost. (2) For each candidate, compute teacher (CLIP) and student (DINOv2-based linear classifier) probabilities. (3) Apply split-conformal calibration on a held-out calibration set to obtain distribution-free uncertainty sets Γ_T and Γ_S with target sizes (e.g., 3 and 5). (4) Compute a per-sample disagreement score δ(x) by comparing teacher and student distributions over the union of their sets, adaptively weighted by a confidence gate, and blending with student entropy. (5) Select a batch by first taking the top-κB uncertain candidates and then maximizing an uncertainty-weighted coverage objective to ensure diversity. The student model is retrained from scratch each round on the expanded labeled set.

## Key Results
- CCMA achieves state-of-the-art active learning accuracy on CIFAR100 (91.6%), Food101 (90.8%), and DomainNet-Real (85.5%), surpassing BADGE and other baselines.
- It demonstrates superior label efficiency, reaching target accuracies with fewer annotations, particularly in low-budget regimes.
- Ablations confirm the necessity of both conformal calibration and the two-stage diversity selection for full performance.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Conformal calibration transforms miscalibrated VLM probabilities into distribution-free, per-sample uncertainty sets (`Γ_T(x)`) that are robust for guiding a vision-only student.
- **Mechanism:** Split-conformal calibration uses a held-out calibration set to compute nonconformity scores (`a_m(x,c) = -log p_m(c|x)`) and thresholds (`q_m`) that control the expected set size (e.g., `s_T=3`, `s_S=5`). This yields set-valued predictors `Γ_m(x) = {c: a_m(x,c) ≤ q_m}` with marginal coverage guarantees, independent of model miscalibration or domain shift.
- **Break condition:** If the conformal sets become too large (low `q_m`) or too small (high `q_m`) consistently across the calibration split, the target set size `s_m` cannot be met, invalidating the informativeness of the sets.

### Mechanism 2
- **Claim:** A teacher-student disagreement score, adaptively weighted by a confidence gate, identifies samples where the VLM's semantic guidance materially differs from the student's current belief, indicating high learning value.
- **Mechanism:** For each sample `x`, renormalize teacher/student posteriors over the union set `Ω(x)=Γ_S(x)∪Γ_T(x)`. Compute Jensen-Shannon (JS) divergence between these distributions. Blend with student entropy `H_S(y|x)` using weight `w_js(x) = conf_T/(conf_T+conf_S)`. This yields a final score `δ(x) = w_js*JS + (1-w_js)*H_S`.
- **Break condition:** When teacher-student overlap (`|Γ_T ∩ Γ_S|`) saturates early and top-1 disagreement (`d_top-1`) collapses to near zero, the teacher provides no new semantic information. The score degenerates to pure student entropy, losing the cross-modal advantage.

### Mechanism 3
- **Claim:** A two-stage diversity selection—(1) a CLIP-space clustering-based selective subpool, followed by (2) an uncertainty-weighted coverage maximization—converts the per-sample uncertainty scores `δ(x)` into a batch that is both informative and distributionally representative.
- **Mechanism:** (1) Cluster VLM image embeddings `ϕ(x)` (e.g., k-Means) and sample representatives to form a small candidate subpool `C` (vs. random or full pool). (2) From the top-`κB` uncertain samples in `C`, select the final batch `S` of size `B` by maximizing `F(S) = (1/|U|) Σ_{u∈U} δ(u) * max_{s∈S} k_σ(ϕ(u),ϕ(s))`, which encourages covering high-uncertainty regions of the unlabeled pool.
- **Break condition:** If the CLIP-space clustering fails to capture the true class structure (e.g., due to domain shift), the selective subpool `C` may omit critical semantic regions. The coverage objective then cannot compensate, leading to degraded final accuracy.

## Foundational Learning

- **Concept: Conformal Prediction (CP)**
  - **Why needed:** Provides distribution-free, finite-sample guarantees for uncertainty sets, making VLM uncertainty usable despite miscalibration. It is the core mechanism for converting softmax probabilities into valid, comparable uncertainty estimates.
  - **Quick check:** Given a calibration set of `(x,y)` pairs and nonconformity scores `a(x,c) = -log p(c|x)`, how do you compute the threshold `q` for a target expected set size `s`?

- **Concept: Teacher-Student Framework for Knowledge Transfer**
  - **Why needed:** Allows a frozen, semantically rich VLM (teacher) to guide a trainable, modality-specific student without backpropagation through the teacher. The disagreement space (`Γ_T vs Γ_S`) is the source of acquisition signal.
  - **Quick check:** In this setup, which model(s) are updated during active learning rounds? What is frozen and why?

- **Concept: Diversity-Aware Acquisition (Coverage vs. Uncertainty)**
  - **Why needed:** Pure uncertainty acquisition leads to redundant batches. The coverage objective (`F(S)`) and selective subpool ensure the batch represents the unlabeled distribution, especially crucial for low-budget AL.
  - **Quick check:** What is the computational complexity difference between scoring all `|U|` samples vs. using a selective subpool `|C|`? What is the potential risk of a too-small `|C|`?

## Architecture Onboarding

- **Component map:**
  Unlabeled pool U -> Subpool Selector (clusters CLIP embeddings) -> Candidate set C -> [Frozen Teacher (VLM) computes p_T, Frozen Student Backbone extracts z(x), Student Classifier Head computes p_S] -> Conformal Calibrators (produce Γ_T, Γ_S) -> Disagreement Scorer (computes δ) -> Batch Optimizer (selects S via coverage) -> Selected batch S

- **Critical path (per AL round):**
  1. Cluster precomputed CLIP embeddings of unlabeled pool to form candidate subpool C.
  2. For each x in C, compute teacher probabilities p_T(x) and student probabilities p_S(x) (student: extract z(x) with frozen backbone, then linear head).
  3. Apply per-round split-conformal calibration on held-out calibration set to obtain thresholds q_T, q_S; compute uncertainty sets Γ_T(x), Γ_S(x).
  4. Compute disagreement score δ(x) using JS divergence over union set and confidence gate.
  5. Take top-κB samples in C by δ rank.
  6. From this oversampled set, select a batch of size B by maximizing uncertainty-weighted coverage objective (e.g., greedy).
  7. Add selected batch to labeled set; retrain student from scratch.

- **Design tradeoffs:**
  - Subpool size |C| vs. accuracy: larger |C| preserves accuracy but increases scoring cost O(|C|B).
  - Oversampling factor κ: larger κ improves coverage but slows optimization; dataset-dependent sweet spot.
  - Target set sizes s_T, s_S: smaller s_T yields sharper teacher sets; larger s_S encourages student exploration.
  - Teacher temperature τ: lower τ sharpens logits but risks overconfidence.

- **Failure signatures:**
  - Teacher-Student Collapse: Early saturation of overlap and top-1 disagreement; CCMA degrades to uncertainty-only methods.
  - Subpool Coverage Loss: Clustering discards critical semantic regions; accuracy drops vs. full-pool baseline.
  - Conformal Instability: High variance in thresholds q_T, q_S across calibration splits leads to erratic set sizes.
  - Diversity Optimization Bottleneck: Query time spikes with large κ.

- **First 3 experiments:**
  1. Conformal Calibration Sanity Check: Verify empirical coverage and average set size for Γ_T/Γ_S on held-out calibration set; expect ~3 and ~5.
  2. Disagreement Scoring Diagnostic: Plot δ(x) vs. student entropy and JS divergence; verify confidence gate increases when teacher more confident.
  3. Ablation of Diversity Stages: Run V1-V5 variants on a small dataset (e.g., CIFAR100, budget=2K); expect V1 (full) > V3 (random subpool) > V2 (full pool) > V4 (no diversity) > V5 (neither).

## Limitations
- Teacher-student semantic mismatch can cause early collapse of the disagreement signal, reducing effectiveness on certain datasets (e.g., Caltech).
- Selective subpooling may omit critical semantic regions if CLIP-space clustering fails to capture true class structure, harming coverage.
- Conformal thresholds can be unstable with small or non-representative calibration sets, leading to erratic set sizes and scoring noise.
- Query-time overhead from large oversampling factor κ may be prohibitive for very large unlabeled pools.

## Confidence
- **Claim: CCMA outperforms SOTA AL baselines.** Confidence: High (consistent results across three datasets with multiple seeds and thorough ablations).
- **Claim: Conformal calibration provides robust cross-modal uncertainty.** Confidence: Medium (theoretical foundation solid, but cross-modal application is novel; robustness to distribution shift untested).
- **Claim: Teacher-student disagreement score identifies high-value samples.** Confidence: Medium (diagnostics show correlation with learning value, but degrades when teacher-student overlap saturates early).
- **Claim: Two-stage diversity selection ensures batch representativeness.** Confidence: Medium (ablations confirm benefit, but selective subpool design risks omitting clusters if clustering fails).

## Next Checks
1. **Conformal coverage sanity**: On a held-out calibration set, compute empirical coverage (fraction true labels in Γ_T/Γ_S) and average set size; verify sizes ≈3 (teacher) and ≈5 (student); check threshold stability across random splits.
2. **Selective subpool impact**: Compare full-pool vs. selective subpool across varying |C| and cluster count k; visualize cluster coverage to ensure all classes represented; measure AULC differences.
3. **Mismatch monitoring**: Track per-round |Γ_T ∩ Γ_S|, top-1 disagreement d_top-1, and JS divergence. If early drop (e.g., by round 5), test sharper teacher sets (lower s_T) or fallback to coverage-only acquisition.
