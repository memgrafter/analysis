# Temporal Memory for Resource-Constrained Agents: Continual Learning via Stochastic Compress-Add-Smooth

## Quick Facts
- **arXiv**: 2604.00067  
- **Source URL**: https://arxiv.org/abs/2604.00067  
- **Reference count**: 35  
- **Primary result**: Memory as a stochastic process (Bridge Diffusion) with a three‑step Compress–Add–Smooth recursion; forgetting arises from lossy temporal compression; retention half‑life scales linearly with segment budget ($a_{1/2} \approx c L$, $c\approx2.4$), outperforming FIFO by $\sim2.4\times$.

## Executive Summary
This paper tackles continual learning for resource‑constrained agents that must incorporate new experiences without forgetting old ones under a fixed memory budget. Instead of storing a parameter vector or raw data, the agent maintains a stochastic process—a Bridge Diffusion defined on a fixed replay interval [0,1]. New experiences are integrated via a Compress–Add–Smooth (CAS) recursion within a parameterized density class (Gaussian mixtures). The key insight is that forgetting originates not from parameter interference but from lossy temporal compression during the smoothing step, where a finer grid is re‑approximated on a coarser one. This yields a linear scaling law: the retention half‑life $a_{1/2}$ grows proportionally to the segment budget $L$, with a constant $c>1$ (empirically $\approx2.4$) that demonstrates a storage efficiency advantage over naive FIFO buffers. The method operates with $O(LKd^2)$ flops per day, requires no backpropagation, stored data, or neural networks, and can generate temporally coherent “movie” replays via Fokker‑Planck drift reconstruction. Extensive experiments validate the mechanism and scaling across dimensions, mixture complexities, and curriculum changes.

## Method Summary
The proposed framework represents memory as a piecewise‑linear density path $p_t(x)$ on $[0,1]$, encoded by Gaussian mixture (GM) parameters at $L+1$ uniform time nodes. Each day, the agent performs three deterministic operations:

1. **Compress**: The time axis is rescaled by $L/(L+1)$, shrinking the domain to $[0, L/(L+1)]$; all stored readout times are multiplied by the same factor. This step is lossless (just a relabeling).
2. **Add**: The new day’s target GM $q^{(new)}$ is appended at $t=1$. Linear interpolation between the last old node and the new node fills the newly created segment of width $1/(L+1)$.
3. **Smooth**: The $(L+1)$‑segment protocol is re‑binned back to the original $L$‑segment uniform grid by evaluating the piecewise‑linear interpolant at times $j/L$ ($j=0,\dots,L$). This is a lossy compression step that replaces finer temporal resolution with coarser, effectively blurring older memories.

The readout times for past memories decay geometrically: $t_{m|n} = (L/(L+1))^{\,n-m}$. The entire update costs $O(LKd^2)$ flops and involves no gradient computation or raw data storage. Optionally, the Fokker‑Planck equation can be inverted to reconstruct an SDE drift that reproduces the prescribed density path, enabling the generation of temporally coherent sample trajectories for replay.

## Key Results
- **Linear retention scaling**: The retention half‑life $a_{1/2}$ scales linearly with segment budget $L$: $a_{1/2} \approx 2.4\,L$ for default drift, a $\sim2.4\times$ improvement over a FIFO buffer ($a_{1/2}=L$). This holds across mixture complexities ($K\le8$), ambient dimensions ($d\le30$), crowding, and curriculum changes.
- **Forgetting mechanism localized**: Forgetting is confined to the smoothing (re‑binning) step where lossy temporal compression occurs; there is no parameter interference because no gradient updates are performed.
- **Efficient and expressive**: The method achieves $O(LKd^2)$ daily flops, requires no backprop or stored data, and produces temporally coherent “movie” replays validated on MNIST latent space.

## Why This Works (Mechanism)
**Mechanism 1: Forgetting as Lossy Temporal Compression**  
Forgetting arises not from parameter interference but from the smoothing step of the CAS recursion. After each day, the protocol is compressed in time (multiplying all timestamps by $L/(L+1)$) and a new experience is appended at $t=1$. The resulting $(L+1)$‑segment piecewise‑linear density is then re‑approximated on the original $L$‑segment uniform grid via linear interpolation. This rebinning averages adjacent node states, blurring older memories. Since a memory’s readout time decays geometrically with age, older memories undergo more rebinning cycles, accumulating distortion. Evidence: The paper explicitly states this mechanism (abstract, Section 3) and contrasts it with parameter‑interference baselines; numerical experiments show that forgetting correlates with the number of compression steps.

**Mechanism 2: Linear Retention Scaling from Geometric Decay**  
Each CAS cycle multiplies readout times by $L/(L+1)$, so after $a$ days, $t_{m|n} \approx (L/(L+1))^a \approx \exp(-a/L)$. Forgetting occurs when $t_{m|n}$ drops below a threshold $t^*$ where compression distortion exceeds a criterion (e.g., normalized error 0.5). Solving $a \approx L\ln(1/t^*)$ yields $a_{1/2} \approx cL$ with $c=\ln(1/t^*)$. Empirically, $t^*\approx0.09$ gives $c\approx2.4$. This scaling is confirmed empirically across a wide range of $L$, $K$, $d$, crowding, and curricula, and it outperforms FIFO ($a_{1/2}=L$).

**Mechanism 3: Stochastic Process Representation Enables Closed‑Form Updates**  
Memory is represented as a Bridge Diffusion process, whose density path is piecewise‑linear and encoded by GM parameters. The GM class is closed under linear interpolation, allowing all CAS steps to be performed via simple linear algebra on parameters (weights, means, covariances). This avoids backpropagation and stored raw data, reducing per‑day cost to $O(LKd^2)$. The reconstructed SDE drift (via the Fokker‑Planck equation) can generate temporally coherent trajectories, providing a “movie” replay of compressed histories (validated on MNIST latent space).

## Foundational Learning
**Concept: Fokker‑Planck equation and drift reconstruction**  
*Why needed here:* The CAS framework optionally reconstructs an SDE drift from the prescribed density path to generate temporally coherent sample trajectories (the “movie replay”). This uses the Fokker‑Planck equation to solve for the drift that yields the desired marginals.  
*Quick check:* Given a time‑dependent density $p_t(x)$, write the Fokker‑Planck equation and derive the formula for the drift $s_t(x)$ in terms of $\nabla\log p_t$ and a current term. How does the current term simplify for constant Gaussian mixture weights?

**Concept: Gaussian mixture linear interpolation**  
*Why needed here:* The entire CAS recursion works by linearly interpolating GM parameters (weights, means, covariances) between nodes. The validity of the interpolated density as a Gaussian mixture is essential for closed‑form operations.  
*Quick check:* Given two Gaussian mixtures with parameters $(\pi_1, m_1, \Sigma_1)$ and $(\pi_2, m_2, \Sigma_2)$, show that for $\alpha\in[0,1]$, the interpolated parameters $\pi=(1-\alpha)\pi_1+\alpha\pi_2$, $m=(1-\alpha)m_1+\alpha m_2$, $\Sigma=(1-\alpha)\Sigma_1+\alpha\Sigma_2$ define a valid Gaussian mixture. Why are the covariances guaranteed positive definite?

**Concept: Catastrophic forgetting via parameter interference**  
*Why needed here:* The paper contrasts its forgetting‑by‑compression mechanism with standard catastrophic forgetting in neural networks, where gradient updates on new tasks overwrite weights important for old tasks. Understanding this baseline is crucial to appreciate the novelty.  
*Quick check:* Explain how weight regularization (e.g., EWC) or replay buffers mitigate parameter‑interference forgetting. How does the CAS framework avoid gradient updates altogether?

## Architecture Onboarding
- **Component map**: `PriorDistribution` provides initial GM → `ProtocolGrid` stores $L+1$ GM nodes on a uniform time grid; `ReadoutTimeDict` tracks readout times $t_{m|n}$; `GaussianMixture` objects hold parameters and support linear interpolation; `ForgetMetrics` computes forgetting from original and replay densities; optional `DriftReconstructor` solves Fokker‑Planck for SDE drift to generate movie replay.

- **Critical path for daily update**:
  1. **Compress**: Multiply all stored readout times by $L/(L+1)$; relabel node times to $j/(L+1)$ (no parameter change).
  2. **Add**: Append the new day’s GM at $t=1$; linearly interpolate between the last old node and the new node to fill the new last segment (width $1/(L+1)$).
  3. **Smooth**: For each target grid time $j/L$ ($j=0,\dots,L$), locate the enclosing $(L+1)$‑segment and linearly interpolate between its endpoints to obtain the new node; this uses a precomputed sparse matrix $W$ (rows sum to 1).
  4. Record the new day’s readout time as 1.

- **Design tradeoffs**:
  - **L vs retention/storage**: Larger $L$ increases half‑life linearly but also storage $O(LKd^2)$; CAS is $\sim2.4\times$ more storage‑efficient than FIFO.
  - **Grid uniformity**: Uniform grid simplifies analysis and implementation; non‑uniform (e.g., logarithmic) could allocate resolution to recent memories, potentially boosting the constant $c$.
  - **Interpolation type**: Linear interpolation preserves GM structure but may distort geometry; Wasserstein barycenters could be more faithful but require optimization.
  - **Density family**: Gaussian mixtures enable closed‑form $O(Kd^2)$ operations; richer families (e.g., normalizing flows) increase expressiveness but complicate interpolation and moment computation.

- **Failure signatures**:
  1. **Confusion regime** ($\bar{F}>1$): Replay means are pulled toward recent eras instead of reverting to prior; indicates over‑smoothing of old nodes.
  2. **Half‑life far below $cL$**: Suggests excessive drift speed or numerical instability (e.g., covariances becoming near‑singular during rebinning).
  3. **Component collapse** (for $K>1$): Components merge or weights equalize prematurely, detectable via decomposed forgetting (weight error spikes).
  4. **Decoded movie degradation**: In latent‑space visuals (MNIST), digit identities vanish early; indicates the protocol is too coarse to preserve semantic structure.

- **First 3 experiments**:
  1. **Single‑Gaussian baseline** (Section 5): Vary $L$ to confirm linear scaling of half‑life; observe the two‑regime forgetting curve and confusion regime; establish $c\approx2.4$.
  2. **Mixture complexity sweep** (Section 6): Fix $L=10$, vary $K\in\{1,2,3,5,8\}$; show half‑life independence on $K$ and that forgetting is dominated by mean errors for drifting means.
  3. **Crowding experiment** (Section 7.1): For $K=3$, $L=10$, vary inter‑component radius $r$ (crowding ratio $\chi$); half‑life remains flat for moderate crowding ($\chi\lesssim1.5$) and declines slightly for extreme separation, confirming limited effect of state‑space geometry.

## Open Questions the Paper Calls Out
- **What is the theoretical maximum retention constant $c_\text{opt}$ under the CAS framework, and how does it depend on the source drift rate $v$?**  
  Basis: Section 9.1 conjectures $a_{1/2}\le c_\text{opt}(v)\cdot L$ and notes the current uniform‑grid scheme achieves $c\approx2.4$, but $c_\text{opt}$ remains undefined. Why unresolved: No analytical bound exists; dependence on drift speed is only empirical (e.g., $c$ varies from $\sim2.0$ to $\sim3.6$ across periods). What would resolve: A rigorous rate‑distortion analysis of the CAS compression process; empirical evaluation of non‑uniform grids or variational rebinning across drift regimes to bound $c_\text{opt}$.

- **Can the CAS framework be extended to flexible neural density families (e.g., normalizing flows) while preserving the linear scaling law $a_{1/2}\propto L$?**  
  Basis: The approach is claimed generic (Sections 2, 10) but experiments are limited to Gaussian mixtures; extending to neural estimators is suggested as future work. Why unresolved: Interpolation of neural parameters may not yield valid densities; computational cost and forgetting behavior are unknown. What would resolve: Implement CAS with a flow‑based density, perform an $L$‑sweep, and compare the retention constant $c$ to the Gaussian baseline.

- **Does replacing piecewise‑linear interpolation with a nonlinear alternative (e.g., Wasserstein geodesic) increase the retention constant $c$?**  
  Basis: Section 9.1 lists non‑linear interpolation (e.g., Wasserstein geodesics) as a concrete optimization avenue. Why unresolved: No experiments have tested this; Wasserstein interpolation is geometrically faithful but computationally heavier, and its effect on $c$ is unknown. What would resolve: Implement rebinning using Wasserstein barycenters between Gaussian mixtures, run an $L$‑sweep, and measure $c$ relative to the linear case.

- **Does the temporally coherent SDE replay improve downstream continual learning performance compared to marginal‑only recall?**  
  Basis: Section 9.2 describes SDE replay as producing correlated trajectories analogous to hippocampal sleep replay, but task performance was not evaluated. Why unresolved: It is unknown whether trajectory coherence translates to better accuracy or reduced forgetting in CL tasks. What would resolve: Integrate CAS memory into a CL agent (e.g., class‑incremental learner) and compare marginal sampling versus full SDE trajectory replay on standard benchmarks (e.g., Split MNIST).

## Limitations
- **Generalization uncertainty**: Scaling results ($a_{1/2}\propto L$) were verified only up to moderate mixture complexities ($K\le8$) and ambient dimensions ($d\le30$); performance on larger, high‑dimensional real‑world data remains uncertain.
- **Movie replay validation limited**: The temporally coherent SDE replay was validated solely on MNIST latent space; its applicability to raw sensory data or more complex distributions is untested.
- **Numerical stability**: The linear interpolation of covariances may yield near‑singular matrices under extreme parameter regimes; the paper does not extensively explore failure modes of the Gaussian‑mixture closure.

## Confidence
- **High confidence**:  
  - Forgetting originates from lossy temporal compression during the smoothing step, not parameter interference.  
  - The retention half‑life scales linearly with segment budget: $a_{1/2} \approx 2.4\,L$ for the default drift setting.

- **Medium confidence**:  
  - The linear scaling holds across a wide range of mixture complexities ($K\le8$), ambient dimensions ($d\le30$), crowding levels, and curriculum changes.  
  - The SDE reconstruction yields coherent movie‑like replays (validated on MNIST latent space).

- **Low confidence**:  
  - Extending CAS to flexible neural density families (e.g., normalizing flows) will preserve the linear scaling law and constant $c$.
