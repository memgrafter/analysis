# NeuroMambaLLM: Dynamic Graph Learning of fMRI Functional Connectivity in Autistic Brains Using Mamba and Language Model Reasoning

## Quick Facts
- **arXiv ID:** 2602.13770
- **Source URL:** https://arxiv.org/abs/2602.13770
- **Reference count:** 40
- **Primary result:** Achieves 72.12% test accuracy on ABIDE for ASD classification, with generated reports showing neurobiological consistency.

## Executive Summary
NeuroMambaLLM introduces an end-to-end framework that dynamically learns functional connectivity graphs from raw fMRI BOLD signals to address the limitations of static connectivity analysis in autism spectrum disorder (ASD). The system uses a graph encoder to produce time-resolved latent adjacency matrices, processes these with a state-space model (Mamba) for efficient long-range temporal modeling, and aligns the output with a frozen LLaMA-3-8B language model via LoRA adaptation. This enables both classification and interpretable clinical report generation. On the ABIDE dataset, the method outperforms recent static and non-LLM approaches, demonstrating the value of dynamic graph representations and LLM reasoning for neuroimaging.

## Method Summary
The pipeline begins with ROI-wise BOLD time series. A dynamic graph encoder applies a 1D convolution and self-attention per time point to generate latent node embeddings; these are used to compute an adjacency matrix via inner product, and the graph filters the original BOLD signals. The resulting time series is fed into a Mamba block, which selectively evolves a state sequence in linear time. A structured pooling compresses the state sequence into a fixed number of "brain-summary" tokens, which are projected into the embedding space of a frozen LLaMA-3-8B. LoRA adapters are added to the LLM’s attention layers, and the model is trained end-to-end on classification with a cross-entropy loss. The LLM also generates descriptive text conditioned on the brain tokens using a constrained prompt.

## Key Results
- Test accuracy 72.12%, precision 80.22%, recall 61.02%, F1-score 0.6931 on ABIDE.
- Outperforms static graph and non-LLM baselines in ablation studies.
- Generated connectivity patterns align with known ASD alterations in temporal and fronto-occipital regions.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Dynamic latent graph inference captures time-varying functional interactions that static correlation matrices miss, improving ASD classification by modeling transient neural states.
- **Core assumption:** The latent similarity space meaningfully represents time-varying functional coupling, and transient patterns are predictive of ASD.
- **Break condition:** If learned latent graphs do not correlate with known dFC biomarkers or static replacement severely degrades performance. The paper reports such degradation (Static MambaLLM: 0.6650 vs 0.7212 accuracy), supporting the design.

### Mechanism 2
- **Claim:** The Mamba selective state-space model efficiently captures long-range temporal dependencies in fMRI sequences while adaptively filtering noise/motion artifacts, enabling linear-complexity modeling of full scans.
- **Core assumption:** fMRI dynamics benefit from input-dependent gating of state transitions, and the linear SSM structure can represent relevant neural processes without attention.
- **Break condition:** If performance plateaus with longer sequences or selective gating fails to correlate with artifact metrics. The paper does not test sequence-length scaling.

### Mechanism 3
- **Claim:** Aligning compressed dynamic brain representations with a frozen LLM via LoRA enables high-level semantic reasoning and interpretable report generation, adding clinical utility beyond black-box classification.
- **Core assumption:** The LLM’s pretrained knowledge can interpret the projected brain token semantics, and LoRA adaptation suffices to align domains without catastrophic forgetting.
- **Break condition:** If generated reports show low clinical validity (e.g., high hallucination rates) or LoRA fails to align domains. The paper acknowledges hallucination risk and uses a predefined schema to constrain output.

## Foundational Learning
- **Concept: Dynamic Functional Connectivity (dFC)**  
  *Why needed:* Static FC averages temporal variability, missing transient states relevant to ASD. dFC models time-varying interactions.  
  *Quick check:* What are two neurobiological reasons static FC is insufficient for ASD, and how does a time-varying graph address them?
- **Concept: Selective State-Space Models (Mamba)**  
  *Why needed:* Mamba provides linear-time sequence modeling with input-dependent filtering, crucial for long fMRI recordings.  
  *Quick check:* How does Mamba’s selective parameterization (`A_t, B_t` as functions of input) differ from a standard SSM, and why is this important for noisy fMRI data?
- **Concept: Parameter-Efficient Fine-Tuning (LoRA)**  
  *Why needed:* LoRA adapts a frozen LLM to a new modality with minimal parameters, avoiding overfitting on limited neuroimaging data.  
  *Quick check:* What is the intuition behind LoRA’s low-rank weight update decomposition, and why does it preserve pretrained knowledge better than full fine-tuning?

## Architecture Onboarding
Input: BOLD signals (B, T, N) → Dynamic graph encoder (per-timestep latent graph) → Graph-filtered series ˜X → Mamba block (state sequence S) → Compression to K brain-summary tokens → Linear projection to LLM space → Frozen LLaMA-3-8B + LoRA → Classification logits & generated text.

Critical path: raw BOLD → latent dynamic graphs (per time) → Mamba aggregation (full sequence) → compressed tokens → LLM reasoning.

Design tradeoffs:
- Dynamic vs Static Graph: dynamic captures transient states but adds per-timestep cost; static is cheaper but loses temporal resolution.
- Mamba vs Transformer: Mamba avoids quadratic memory, enabling full-sequence; Transformers may capture finer cross-time patterns at higher compute.
- Frozen LLM + LoRA vs Full FT: LoRA is parameter-efficient and less overfit-prone; may underfit if domain gap is large.
- Latent graph vs Precomputed dFC: learned graphs are adaptive but less neurobiologically interpretable; precomputed dFC (e.g., sliding windows) aligns with known biomarkers but is heuristic.

Failure signatures:
- Poor generalization across sites (ABIDE multi-site): large train-test gap suggests overfitting to site artifacts.
- Degraded LLM output: reports become generic, hallucinate biomarkers, or contradict input tokens.
- Mamba state collapse: uninformative state norms, possible NaNs during update.
- Graph sparsity/degeneracy: learned adjacency nearly diagonal or uniformly dense, indicating failed graph learning.

First 3 experiments:
1. Baseline replication: Train the pipeline without LLM (classifier on Mamba states). Expect ~70%+ accuracy to validate core representation.
2. Ablation: Replace dynamic graph encoder with static PCC-based adjacency. Expect significant drop (as in paper) confirming dynamic graphs’ contribution.
3. LLM alignment sanity check: Feed known ASD/Control brain tokens into trained LLM; generate 100 reports. Qualitatively assess consistency (e.g., ASD reports mention temporal regions) and check for hallucinations.

## Limitations
- Exact preprocessing details (atlas, exclusion criteria) are unspecified, risking site-variance confounds.
- No direct validation of learned dynamic graphs against established dFC biomarkers (e.g., state variability).
- LLM-generated reports lack clinical validation; hallucination risk remains despite constrained prompt.

## Confidence
- Dynamic graph mechanism: Medium confidence (supported by ablation, but no biomarker correlation).
- Mamba efficiency & filtering: Medium confidence (outperforms baselines, but no length-scaling tests).
- LLM alignment & report generation: Low-Medium confidence (LoRA improves over frozen, but no clinical review of outputs).

## Next Checks
1. Neurobiological validity: Correlate dynamic adjacency matrices (e.g., variability, state transitions) with known ASD dFC biomarkers from literature.
2. Robustness to sequence length and noise: Compare Mamba vs. windowed Transformer on truncated vs. full-length sequences; correlate selective parameters with motion artifact metrics.
3. Clinical sanity of LLM outputs: Conduct masked clinician review of generated reports for consistency with ASD phenotypes and absence of contradictions/hallucinations.
