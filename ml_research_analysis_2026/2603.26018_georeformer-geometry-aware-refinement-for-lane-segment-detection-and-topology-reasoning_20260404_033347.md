# GeoReFormer: Geometry-Aware Refinement for Lane Segment Detection and Topology Reasoning

## Quick Facts
- arXiv ID: 2603.26018
- Source URL: https://arxiv.org/abs/2603.26018
- Reference count: 26
- Primary result: State-of-the-art on OpenLane-V2 with 34.5% mAP, using only 48M parameters.

## Executive Summary
GeoReFormer introduces geometry-aware refinements into a DETR-style decoder to tackle the inherent graph structure of lane segments. By integrating spatial priors via stratified k-medoids, bounded coordinate updates, and a gated topology aggregation module, it achieves superior detection and topology reasoning on the OpenLane-V2 benchmark while maintaining a compact model size.

## Method Summary
The method processes surround-view images through a ResNet-50+FPN backbone and a BEVFormer encoder to obtain a BEV feature map. A transformer decoder with 200 queries then iteratively refines lane segment polylines. Queries are initialized with geometric priors derived from k-medoids clustering on normalized training polylines, spatially stratified to cover the BEV grid. Each decoder layer performs self-attention, deformable cross-attention (Lane Attention) using current reference points, and a TopoFFN that aggregates relational context via a gated graph convolution. Bounded refinement stabilizes updates: r_l = r_{l-1} + 0.25·tanh(Δ_l). Training uses Hungarian matching, deep supervision on all layers, and a topology loss. The model achieves 48M parameters and 34.5% mAP on OpenLane-V2.

## Key Results
- Overall mAP 34.5% (SOTA) on OpenLane-V2, improving lane segment detection (AP_ls 33.9%) and pedestrian crossing detection (AP_ped 35.0%).
- Topology consistency TOP_lsls 28.9%, surpassing prior work.
- Parameter-efficient design at only 48M parameters.

## Why This Works (Mechanism)
GeoReFormer bridges the gap between generic transformers and the continuous, graph-structured nature of lane segments by embedding geometric inductive biases directly into the decoder. The stratified k-medoids provide data-driven query initialization that covers typical lane spatial distributions, reducing the need for the model to learn positions from scratch. Bounded refinement with tanh scaling ensures that updates remain localized and numerically stable, preventing coordinate explosion. The TopoFFN selectively integrates relational information via per-query gating, allowing each query to decide how much neighbor context to incorporate, which is crucial for modeling connectivity and topology. Together, these mechanisms align the transformer’s learned representations with the underlying geometry and graph structure of the task.

## Architecture Onboarding
Component map:  
Input Images -> ResNet-50 -> FPN -> BEVFormer Encoder -> Transformer Decoder (L layers) -> Output Heads (class, polyline)

Critical path: The backbone extracts multi-scale features, FPN aggregates them, BEVFormer lifts to a 200×200 BEV grid, the decoder queries generate and refine polylines, and the heads predict classes and coordinates.

Design tradeoffs:  
- Geometric priors reduce training time but are fixed;  
- Bounded refinement trades expressivity for stability;  
- TopoFFN adds relational capacity but increases per-query computation;  
- Parameter budget (48M) forces compact BEV and decoder sizes.

Failure signatures:
- Coordinate scale mismatch: initial reference points outside BEV range.
- TopoFFN gate saturation: g_q ≈ 0 or 1 for most queries.
- Unstable refinement: large Δ_l causing coordinate jumps.
- Hungarian matching degeneracy: mismatched object counts or duplicate assignments.
- Deep supervision failure: early layer losses not decreasing.

First three experiments:
1. Visualize initialized k-medoids on the BEV grid to confirm proper coverage and scale.
2. Log per-query gate mean during first 5 epochs; should start near 0.05 (due to bias -3) and rise gradually.
3. Compute average matched lane segments per image and class distribution on validation; should match dataset statistics (≈4–5 segments/image).
