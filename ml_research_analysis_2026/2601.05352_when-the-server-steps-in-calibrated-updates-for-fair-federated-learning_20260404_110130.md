# When the Server Steps In: Calibrated Updates for Fair Federated Learning

## Quick Facts
- **arXiv ID:** 2601.05352
- **Source URL:** https://arxiv.org/abs/2601.05352
- **Reference Count:** 40
- **Primary Result:** Server‑side debiasing via calibrated updates yields substantial fairness gains (e.g., +45.1% equalized odds on Income‑Sex) with negligible accuracy loss across multiple datasets and aggregation rules.

## Executive Summary
Federated learning (FL) often suffers from biased models due to heterogeneous client data. Existing fair FL methods typically require client‑side modifications or are tied to specific aggregation rules. This paper presents EquFL, a novel server‑side debiasing approach. The server stores early global model checkpoints, synthesizes a proxy dataset that approximates client learning dynamics, and in each round produces a calibrated update—a gradient that reduces a fairness loss on the synthetic data. This calibrated update is then combined with any client aggregation, preserving accuracy while mitigating bias. Theoretically, EquFL converges to the same optimal model as FedAvg and monotonically reduces the fairness loss. Empirically, on six structured and image datasets, EquFL significantly outperforms six baselines on equalized odds, demographic parity, calibration, and consistency, with improvements up to 82.5% and negligible accuracy loss. The method remains robust under various aggregation rules, non‑IID splits, and numbers of clients.

## Method Summary
EquFL introduces a server‑level calibration step that decouples fairness correction from client updates. The server maintains an archive of early global model checkpoints. From these checkpoints, it synthesizes a proxy dataset intended to mimic the distribution of client updates across the FL population. In each communication round, after receiving client updates, the server computes a calibrated gradient by minimizing a fairness loss (e.g., equalized odds) on the proxy dataset. This gradient is then combined with the aggregated client updates—e.g., added or scaled—before updating the global model. The approach is agnostic to the underlying aggregation rule (FedAvg, FedProx, etc.) and requires no changes to client behavior. Theoretical analysis under convexity and smoothness assumptions shows that EquFL converges to FedAvg’s optimal solution and that the fairness loss decreases monotonically. The empirical evaluation covers six datasets (e.g., Income, COMPAS, CIFAR‑10) and demonstrates consistent fairness gains with minimal impact on task accuracy.

## Key Results
- **+45.1% equalized odds** on Income (Sex) compared to baselines.
- **+55.8% demographic parity** improvement on CIFAR‑10.
- **+82.5% improvement** in calibration and consistency on CIFAR‑10.
- **Negligible accuracy drop** across all datasets.
- **Broad robustness:** effectiveness holds across different aggregation rules, non‑IID splits, and varying client counts.

## Why This Works (Mechanism)
EquFL works by shifting the global model’s trajectory toward fairness without disrupting the learning dynamics of the clients. Early checkpoints capture the model before severe bias accrues; the proxy dataset generated from these checkpoints approximates the true distribution of client data and their gradient contributions. By computing a gradient that directly minimizes a fairness loss on this synthetic data, the server produces an update that corrects systematic biases present in the aggregated client updates. Since this calibrated gradient is applied at the server, it is independent of the specific aggregation method, ensuring broad compatibility. Moreover, the theoretical guarantee shows that the calibrated update does not deviate the model from the FedAvg optimum in terms of accuracy; instead, it reorients the model along a fairness‑improving direction while staying within the same convergence region. The monotonic reduction of fairness loss is ensured because each calibrated gradient is derived from the current global model and moves it toward a point with lower fairness loss on the proxy, which bounds the true fairness loss.

## Architecture Onboarding
### Component Map
Checkpoint Manager -> Proxy Dataset Generator -> Calibrated Gradient Computer -> Aggregation Orchestrator -> Global Model

### Critical Path
1. Server stores early global model checkpoints at predefined intervals.
2. Proxy Dataset Generator creates synthetic data mimicking client update distributions using the checkpoints.
3. Calibrated Gradient Computer computes a gradient that minimizes a fairness loss on the proxy dataset.
4. Aggregation Orchestrator receives client updates and combines them with the calibrated gradient (e.g., weighted average) to produce an updated global model.

### Design Tradeoffs
- **Fidelity vs. Efficiency:** More elaborate proxy synthesis (e.g., generative models) may better approximate client data but increases server compute and memory; EquFL uses a simpler approach for scalability.
- **Calibration Strength:** The magnitude of the calibrated gradient must balance fairness improvement and task accuracy; overly strong correction may harm model performance.
- **Checkpoint Selection:** Early checkpoints reduce bias but may be less representative of later data distributions; the choice of which round to store involves a trade‑off.

### Failure Signatures
- **Fairness gains plateau or reverse:** Indicates proxy dataset quality is insufficient (e.g., fails to capture client heterogeneity).
- **Significant accuracy drop:** Suggests calibration gradient is too large or misaligned with the true objective.
- **High server memory usage:** Could arise from storing too many checkpoints or large proxy datasets, compromising scalability.

### First Experiments
1. **Baseline Comparison:** Apply EquFL to the Income dataset and compare equalized odds against FedAvg and three representative fair FL methods.
2. **Aggregation Compatibility Test:** Swap FedAvg with FedProx and SCAFFOLD to verify that EquFL retains fairness improvements across aggregation rules.
3. **Non‑IID Robustness:** Vary label skew (e.g., Dirichlet α) on CIFAR‑10 and measure changes in demographic parity and accuracy.

## Limitations
- Reliance on a synthetic proxy dataset that may not fully capture client data heterogeneity.
- Theoretical convergence proof assumes convexity and smoothness, which may not hold for real neural networks.
- Evaluation limited to six datasets; broader evaluation across more domains is needed.
