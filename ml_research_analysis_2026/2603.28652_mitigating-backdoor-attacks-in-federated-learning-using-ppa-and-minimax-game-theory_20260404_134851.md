# Mitigating Backdoor Attacks in Federated Learning Using PPA and MiniMax Game Theory

## Quick Facts
- arXiv ID: 2603.28652
- Source URL: https://arxiv.org/abs/2603.28652
- Reference count: 22
- Primary result: FedBBA reduces backdoor attack success rates to 1.1%–11% while maintaining 95%–98% normal task accuracy.

## Executive Summary
Federated learning (FL) is vulnerable to backdoor attacks where malicious clients poison the global model. This paper proposes FedBBA, a defense framework combining Projection Pursuit Analysis (PPA) with kurtosis-based anomaly detection, a dynamic reputation system, and a MiniMax game theory model. The server uses PPA to compute anomaly scores for client updates, clusters them with DBSCAN to identify suspicious clients, and updates a reputation score that tracks historical behavior and gradient stability. Weights for aggregation are derived from a MiniMax game where the server chooses a defense sensitivity parameter and the adversary responds with a poisoning ratio. Extensive simulations on GTSRB and BTSC datasets demonstrate that FedBBA suppresses backdoor success to 1–11% across various attack scenarios while preserving high normal accuracy, outperforming RDFL and RoPE.

## Method Summary
FedBBA intercepts the FL aggregation step to dynamically assess and weight client contributions. Upon receiving updates from a subset of clients, the server computes a multivariate kurtosis projection pursuit score for each update, identifying outliers that likely stem from poisoning. DBSCAN clustering on these scores groups updates; clients in the outlier cluster are penalized. A reputation metric $R_i(t) = \alpha H_i(t) + \beta G_i(t)$ combines historical correctness $H_i$ and gradient stability $G_i$, updated via reward and penalty factors. The server then determines aggregation weights using $w_i = (R_i + \theta - \lambda s_i)/\sum_j (R_j + \theta - \lambda s_j)$, where $s_i$ is the PPA score and $\lambda$ is a defense sensitivity set by solving a MiniMax game against a rational adversary. The game yields an adversary best-response poisoning ratio $\rho_i^* = \min\{(R_i+\theta)/(2\lambda),1\}$, and the server optimally chooses $\lambda = \lambda_{\max}$. This integrated system allows the server to down-weight malicious updates without sacrificing benign contributions.

## Key Results
- Backdoor attack success reduced to 1.1%–11% across one-to-one, one-to-many, and N-to-one scenarios.
- Normal task accuracy maintained at 95%–98%.
- Outperforms RDFL (23%–76% success) and RoPE in both defense and utility.

## Why This Works (Mechanism)

### Mechanism 1: PPA with Kurtosis Detection
- **Claim:** Projection Pursuit Analysis (PPA) with kurtosis identifies malicious model updates by detecting non-Gaussian, heavy-tailed deviations in the high-dimensional update space that benign heterogeneity typically does not produce.
- **Mechanism:** The server collects client updates into a data matrix **X**. PPA searches for a projection vector **w** that maximizes the kurtosis of the projected data **wᵀX**. High kurtosis indicates an outlier projection, flagging an anomalous client update. Combined with DBSCAN clustering, suspicious groups are isolated.
- **Core assumption:** Malicious updates introduce statistical artifacts (e.g., extreme values in specific weight dimensions) that manifest as high kurtosis in some projection, whereas benign updates from heterogeneous data follow a more Gaussian-like distribution.
- **Break condition:** If benign data has naturally heavy tails (e.g., skewed sensor data), false positives may occur; mitigated by the reputation system.

### Mechanism 2: Dynamic Reputation System
- **Claim:** A reputation system tracking client behavior over time (historical correctness & gradient stability) distinguishes persistent malicious actors from benign clients with occasional anomalies.
- **Mechanism:** For client *i* at round *t*, reputation $R_i(t) = \alpha H_i(t) + \beta G_i(t)$, where $H_i$ is the ratio of correct actions (not flagged) and $G_i$ measures gradient variation consistency. Reputation is adjusted via reward ($\gamma$) and penalty ($\delta$) after each round's assessment.
- **Core assumption:** Honest clients exhibit stable, consistent gradient updates over time, while malicious clients exhibit a pattern of suspicious behavior that degrades their reputation cumulatively.
- **Break condition:** A sophisticated attacker could slowly poison updates to keep individual suspicion low, evading cumulative penalization.

### Mechanism 3: MiniMax Game Theoretic Weighting
- **Claim:** Modeling server–malicious client interaction as a non-cooperative MiniMax game yields a saddle-point equilibrium where the server's optimal defense sensitivity forces adversaries' best-response poisoning ratio below an effective level.
- **Mechanism:** The server chooses $\lambda \in [\lambda_{\min}, \lambda_{\max}]$; the adversary chooses poisoning ratio $\rho_i$. Aggregation weight $w_i(\rho_i,\lambda) = (R_i + \theta - \lambda \rho_i)/\sum_j (R_j + \theta - \lambda \rho_j)$. The server minimizes $J(\lambda,\rho)=\sum_{i\in I'} w_i(\rho_i,\lambda)\cdot\rho_i$, the adversary maximizes it. Equilibrium gives $\rho_i^*(\lambda) = \min\{(R_i+\theta)/(2\lambda),1\}$ and server sets $\lambda^* = \lambda_{\max}$ (if $\lambda_{\max} \ge (R_{\max}+\theta)/2$).
- **Core assumption:** Adversaries are rational and utility-maximizing, and the server knows the best-response function.
- **Break condition:** If adversaries are irrational or server misestimates $R_{\max}$, equilibrium may fail to suppress malicious weights.

## Architecture Onboarding

- **Component map:**  
  Client Update Generator (local training) → Server: collects updates → PPA Anomaly Scorer → DBSCAN Clusterer → Reputation Tracker → Weight Calculator → Global Aggregator → New global model → Clients

- **Critical path:**  
  Client uploads → PPA Scoring → DBSCAN Clustering → Reputation Update → Weight Calculation → Weighted Aggregation

- **Design tradeoffs:**
  - Detection sensitivity (λ) vs. False Positives: Higher λ penalizes anomalies more but risks down-weighting benign clients.
  - Reputation inertia (γ, δ) vs. Adaptivity: Larger γ/δ yields faster response but may over-punish transient anomalies.
  - Computational cost: PPA’s iterative SVD on high-dimensional updates can be expensive for large models.

- **Failure signatures:**
  - High backdoor success + normal accuracy: PPA/DBSCAN fail to separate malicious updates (attack too subtle or benign data non-Gaussian).
  - Degraded normal accuracy: λ too high or reputation too punitive, down-weighting honest clients.
  - Reputation scores saturate at extremes: γ/δ poorly set, causing rigidity and slow recovery.

- **First 3 experiments:**
  1. Sensitivity analysis of α/β: Vary the weighting between historical correctness and gradient stability in reputation (e.g., α, β = 0.2,0.8; 0.5,0.5; 0.8,0.2) and measure trade-off between clean accuracy and backdoor success rate.
  2. PPA vs. PCA visualization: Generate synthetic client updates (e.g., 30 clients, 10 malicious) and project updates using PPA scores and PCA components. Visualize separation to confirm PPA's outlier detection advantage.
  3. Attack scenario evaluation: Train FedBBA on GTSRB for 100 rounds under one-to-one, one-to-many, N-to-one attacks. Plot accuracy and backdoor success rate trajectories and compare against Vanilla FL, RDFL, and RoPE, expecting >95% normal accuracy and <12% backdoor success.

3. How resilient is FedBBA against sophisticated adaptive attacks where malicious clients dynamically alter poisoning ratios or triggers in response to server defenses?

## Limitations

- The paper omits exact CNN architecture details, optimizer settings, and learning rates, making exact replication difficult.
- Key hyperparameters for PPA (guess, maxcount, convergence threshold) and reputation (γ, δ, θ, n) are unspecified.
- The assumption that benign updates are near-Gaussian may fail on naturally heavy-tailed data, increasing false positives.
- The MiniMax equilibrium assumes rational adversaries with known strategy spaces, which may not hold in practice.
- Computational cost of PPA’s iterative SVD on high-dimensional updates is not analyzed.

## Confidence

- PPA + kurtosis detection: Medium (experimental evidence but dataset-specific)
- Reputation system: Medium (novel, limited theoretical guarantees)
- MiniMax game model: Medium (theoretically sound but strong assumptions)
- Overall effectiveness (1–11% backdoor success, 95–98% normal accuracy): High (consistent across scenarios and baselines)
