# Future-Interactions-Aware Trajectory Prediction via Braid Theory
## Quick Facts
- arXiv ID: 2603.22035
- Source URL: https://arxiv.org/abs/2603.22035
- Reference count: 18
- Primary result: On Waymo, MinJointFDE reduces by 5% and MinJointADE by 5% relative to baseline; Braid Similarity improves by up to 1% with negligible overhead.

## Executive Summary
Multi-agent trajectory prediction for autonomous vehicles demands accurate modeling of social interactions, yet existing methods rely on heuristics or incur high computational cost. This work introduces *braid prediction*, an auxiliary task that classifies crossing types (over, under, no crossing) between agent pairs using braid theory, and shares mode embeddings with the trajectory predictor to infuse future interaction awareness. Evaluated on Interaction, Argoverse 2, and Waymo datasets, the approach yields consistent improvements in joint prediction metrics—e.g., 5% reduction in MinJointFDE and MinJointADE on Waymo—and a new Braid Similarity metric shows up to 1% higher adherence to correct multi-agent behavior, all with negligible added training or inference complexity.

## Method Summary
The method extends the QCNet/QCNeXt architecture. Mode embeddings—learnable vectors representing diverse behavioral modes—are refined via cross‑ and self‑attention and then used in parallel for two tasks: (1) trajectory decoding (regressing future positions) and (2) braid prediction. For the latter, an edge is created between every pair of agents within a distance δ (50 m). Each edge feature combines the mode embeddings of the two agents with a relative vector. A shallow MLP classifies the crossing type for that pair under that mode. The braid loss (cross‑entropy) is applied **only** to the mode *k*⁺ that minimizes the sum of joint displacement errors for that pair, preserving multi‑modality. The total loss combines trajectory losses (regression + classification) with λ·braid loss (λ=1). At inference the braid head can be detached, yielding zero overhead.

## Key Results
- Consistent joint metric gains across three datasets: on Waymo, MinJointFDE↓5% and MinJointADE↓5%.

## Why This Works (Mechanism)
- **Explicit Interaction Reasoning**. Classifying crossing types forces the model to reason explicitly about pairwise interactions; gradients from the braid loss shape the shared mode embeddings to capture interaction‑relevant features. *Core assumption*: crossing labels are a sufficient proxy for social dynamics (e.g., yielding, overtaking). *Evidence*: abstract and Section IV‑B.
- **Shared Mode Embeddings**. Using the same final embeddings for both tasks aligns the representation spaces; the embeddings must encode information useful for both regression and classification, naturally infusing interaction awareness into predicted trajectories. *Core assumption*: embeddings are expressive enough for individual and relational patterns. *Evidence*: abstract and Section IV‑B.
- **Selective Loss on Best Joint Mode**. Applying the braid loss only to the mode *k*⁺ that yields minimal joint error strongly conditions a single coherent joint behavior while preserving diversity across other modes. *Core assumption*: the best joint mode is the most plausible. *Evidence*: Section IV‑B and Table V (agent‑encoding ablation).

Needed to represent how agent strands cross; crossing direction (over/under) encodes relative priority. *Quick check*: Given two trajectories projected onto the (x,t) plane, how does the sign of the y‑coordinate difference at the crossing point determine the label?

## Architecture Onboarding
Input encoding -> Mode embedding generator (initial K random vectors) -> Cross‑attention (scene‑aware agent‑specific embeddings) -> Self‑attention (encourages multi‑modality) -> Final mode embeddings -> (Trajectory decoder + Braid prediction head). Edges are formed by linking agents within δ=50 m, with a neighbor cap.

- **Critical path**: The flow from input through mode embeddings to both heads during training; at inference the braid head is detached.
- **Design tradeoffs**:
  - Mode embeddings vs. agent encodings: embeddings give stronger conditioning but require DETR‑style decoder; encodings are more flexible but yield smaller gains.
  - Distance threshold δ: larger δ includes more interactions but adds noise; fixed at 50 m.
  - Loss weight λ=1 balances tasks robustly; higher λ may reduce diversity.
  - Neighbor limit needed to avoid quadratic complexity.
- **Failure signatures**:
  - Marginal metrics degrade while joint metrics improve → λ likely too high.
  - Low Braid Similarity despite joint gains → model not truly capturing interactions; try increasing λ or improving edge labeling.
  - High braid accuracy but poor trajectories → misalignment; adjust k* selection or add regularizers.
- **First 3 experiments**:
  1. Train baseline QCNet (no braid task); record joint metrics.
  2. Add braid prediction with λ=1; verify consistent improvements in joint metrics and BrSim.
  3. Replace mode embeddings with agent encodings (Eq. 8); observe performance drop confirming importance of shared mode embeddings.

## Open Questions the Paper Calls Out
1. **Temporal integration of crossing times**. The current braid prediction omits exact crossing timestamps, limiting its correspondence to full braid words. How can timestamps be encoded into edge features or loss to capture yielding sequences or gap acceptance?
2. **Interactions with static map elements**. Braid prediction considers only agent‑agent edges; incorporating crossings with lanes or traffic signs could enhance rule compliance. How can map primitives be added to the interaction graph with appropriate crossing labels?
3. **Higher‑order multi‑agent interactions**. The pairwise representation may miss global braid topology and coordinated maneuvers. Does a full braid word provide a better supervisory signal? Evidence could come from comparing pairwise BrSim with full‑braid metrics and designing triplet/group losses.
4. **Applicability beyond DETR‑like models**. The reliance on shared mode embeddings restricts use to specific architectures. Can a modular braid component work with GNNs or autoregressive decoders? Demonstration across diverse model families would resolve this.

## Limitations
- Implementation details (QCNeXt variant, braid label pipeline) are incompletely specified; the provided codebase is essential for faithful reproduction.
- Crossing labels (over/under/no crossing) may be too simplistic to model nuanced social interactions like cooperatives or implicit yielding.
- Fixed distance threshold δ=50 m and neighbor limits are heuristics that may not generalize to all scene densities.
- Selective application of braid loss on *k*⁺ risks early training instability if mode selection is noisy.

## Next Checks
- **Braid label verification**: Visualize crossing labels in local agent frames across diverse scenarios (e.g., intersections, merges); confirm class distribution and edge correctness.
- **Hyperparameter sensitivity**: Vary δ (30–70 m) and λ (0.5–2.0); measure effects on joint metrics, BrSim, and marginal accuracy; identify robust ranges.
- **k* selection stability**: Monitor alignment between ground‑truth best joint mode and the mode receiving braid loss during early training; if alignment <80%, introduce a curriculum delay for the braid loss.
