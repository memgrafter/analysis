# Conformal Signal Temporal Logic for Robust Reinforcement Learning Control: A Case Study

## Quick Facts
- **arXiv ID**: 2602.14322  
- **Source URL**: https://arxiv.org/abs/2602.14322  
- **Reference count**: 0  
- **Primary result**: A conformal STL shield achieved 95% STL satisfaction under severe stress, compared to 60% for unshielded PPO and 75% for a rule-based shield.

## Executive Summary
The paper tackles safe reinforcement learning for F-16 engine throttle control. It introduces a conformal shield that filters actions from a PPO agent using online conformal prediction to enforce a Signal Temporal Logic (STL) airspeed tracking constraint. Under combined stress conditions—including model mismatch, actuator limits, noise, and setpoint jumps—the conformal shield maintained high constraint satisfaction (95%) while providing formal robustness guarantees and negligible computational overhead.

## Method Summary
The method trains a PPO agent in an AeroBench F-16 simulator with a reward penalizing airspeed tracking error. At runtime, a shield intercepts the agent’s throttle actions. The shield uses a linear one-step predictor for airspeed, calibrated via split conformal prediction to obtain uncertainty quantiles. For each candidate throttle within a slew bound, it propagates worst-case STL robustness over a 6-step horizon using interval arithmetic. The action yielding the maximum minimum robustness (preferably positive) is executed, ensuring the STL constraint holds with a guaranteed miscoverage rate.

## Key Results
- Conformal shield achieved **95%** STL satisfaction in the hardest stress scenario (S3), versus 60% (unshielded PPO) and 75% (rule-based shield).
- The shield provided **formal robustness guarantees** with negligible computational overhead.
- Near-baseline performance was maintained on the nominal task.

## Why This Works (Mechanism)
The shield combines distribution-free uncertainty quantification (conformal prediction) with worst-case STL robustness propagation. The linear predictor, calibrated on nominal data, yields intervals that cover the true next airspeed with probability 1–δ. By simulating the worst-case trajectory within these intervals over a finite horizon, the shield selects actions that preserve a positive robustness margin for the STL specification, even under disturbances. The linear model and limited lookahead keep computation lightweight.

## Architecture Onboarding
**Component map**:  
PPO Agent → Shield (Conformal Predictor + STL Propagator) → Action → F16 Environment  
Calibration Data → Conformal Predictor (offline)  
Environment States → Conformal Predictor (online)

**Critical path**: At each timestep, the shield receives current state and previous action, generates candidate actions within slew bound, for each candidate uses the linear predictor with conformal uncertainty to simulate worst-case airspeed over K=6 steps, computes STL robustness for the final window, and selects the action with maximum minimum robustness (positive if possible).

**Design tradeoffs**:  
- Prediction horizon K: longer lookahead increases cost and conservatism; shorter may miss violations.  
- Slew bound s: larger s increases flexibility but worsens worst-case propagation.  
- Miscoverage δ: lower δ yields tighter intervals but risks under-cover under stress.

**Failure signatures**:  
- Empirical coverage < 1–δ on calibration set → predictor miscalibration.  
- Shield often returns no safe action (all candidates negative min robustness) → fallback leads to task failure.  
- STL robustness yields NaN → numerical issues in propagation.

**First experiments**:  
1. Train PPO on nominal environment until tracking error <5%.  
2. Calibrate conformal predictor: collect 10k transitions, fit linear model, compute 70th percentile residual.  
3. Evaluate shielded PPO on stress scenario S0 and verify STL satisfaction.
