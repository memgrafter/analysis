# Certified Circuits: Stability Guarantees for Mechanistic Circuits
## Quick Facts
- arXiv ID: 2602.22968
- Source URL: https://arxiv.org/abs/2602.22968
- Reference count: 16
- Primary result: Certified Circuits provides provable stability guarantees for mechanistic circuits, achieving up to 45% fewer neurons and up to 91% higher accuracy on OOD benchmarks compared to baselines.

## Executive Summary
Mechanistic interpretability aims to identify subnetworks ("circuits") in neural networks that implement specific concepts. Existing discovery methods are unstable: small changes to the concept dataset yield different circuits, and these circuits fail to generalize under distribution shifts. This paper introduces Certified Circuits, a framework that wraps any black-box circuit discovery algorithm with randomized data subsampling. By leveraging dataset deletion smoothing and Clopper-Pearson confidence bounds, it produces circuits with provable invariance to bounded dataset edits and abstains from unstable components. Experiments on ImageNet and multiple out-of-distribution benchmarks show that certified circuits are both more compact (using up to 45% fewer neurons) and more accurate (up to 91% higher) than baseline circuits, while exhibiting robust generalization.

## Method Summary
The Certified Circuits framework treats circuit discovery as a stability certification task. Given a neural network model, a concept dataset (images for a target class), and a base discovery algorithm A (e.g., top-K selection by activation), the method repeatedly samples subsampled datasets via deletion masks (each example kept with probability 1−p_del). For each subsample, A produces a binary mask indicating selected vertices (feature channels). The inclusion frequency of each vertex across subsamples is treated as a binomial proportion. Using Clopper-Pearson lower confidence bounds at confidence level 1−α, vertices are certified as "in" if their lower bound exceeds a threshold τ, "out" if the upper bound is below 1−τ, and otherwise abstained. The certified circuit consists of all "in" vertices. This yields a provable guarantee: any vertex certified as "in" will be included by A on any dataset within a certified edit distance r, where r = ⌊log(1.5−τ)/log(p_del)⌋. For typical parameters (p_del=0.6, τ=0.95), r=1. The framework is agnostic to the choice of A and can be applied to any black-box discovery method.

## Key Results
- Certified circuits are provably stable under dataset edits of bounded size and achieve up to 45% fewer neurons and up to 91% higher class accuracy on OOD benchmarks compared to baselines.
- On ImageNet-A, certified circuits reach 94% class accuracy at a circuit size fraction of 0.33, while the baseline achieves only 62% at 0.60.
- They generalize robustly to distribution shifts and exhibit higher structural stability (IoU) when re-discovered on OOD data.

## Why This Works (Mechanism)
The core mechanism is randomized smoothing applied to the dataset rather than the model. By repeatedly perturbing the input dataset through deletions and observing the base algorithm's selections, the method estimates the robustness of each vertex's inclusion. The Clopper-Pearson bound provides a conservative confidence interval for the true inclusion probability. Thresholding on the lower bound ensures that only vertices that are consistently selected across diverse subsamples are certified. This yields a set of vertices that are invariant to any dataset perturbation within the certified radius, because the probability that such a perturbation could flip a certified vertex's inclusion is below the chosen significance level. Abstentions identify vertices whose inclusion is data-dependent, thus avoiding unstable components. The guarantee is independent of the base algorithm's internal behavior, making the framework widely applicable.

## Foundational Learning
- **Mechanistic Circuit**: A subset of neurons/features that causally implement a specific concept. *Why needed*: The target of discovery. *Quick check*: Can you identify a small set of neurons that, when ablated, destroys a specific class prediction?
- **Dataset Deletion Smoothing**: A technique that samples perturbed datasets by randomly deleting examples, used to certify robustness to dataset edits. *Why needed*: Enables provable stability guarantees without modifying the discovery algorithm. *Quick check*: If you delete 60% of examples, does the base algorithm's selection change drastically? The smoothing aggregates over many such deletions.
- **Clopper-Pearson Bounds**: Conservative confidence intervals for binomial proportions. *Why needed*: To compute rigorous lower/upper bounds on inclusion probability from finite samples, enabling certification with statistical guarantees. *Quick check*: Given 90 successes in 100 trials, what is the 95% lower bound? (Answer: ~0.829)
- **Edit Distance**: The number of example-level changes (insertions/deletions) between two datasets. *Why needed*: Quantifies the size of dataset perturbations; the certified radius is defined in terms of this metric. *Quick check*: If dataset D has 100 examples and you remove 2, what is the edit distance to the original? (Answer: 2)

## Architecture Onboarding
Component map: Concept Dataset -> Deletion Sampler -> Subsampled Datasets -> Base Discovery Algorithm A -> Selection Masks -> Aggregator -> Inclusion Counts -> Clopper-Pearson Bounds -> Certifier -> Certified Circuit

Critical path: The algorithm must run base discovery A on many subsamples (n=1000) and compute statistical bounds. This is the bottleneck.

Design tradeoffs:
- n (number of subsamples): larger n reduces Monte Carlo noise but increases compute.
- p_del (deletion probability): higher p_del yields larger certified radius r but may make subsamples too small, hurting base algorithm reliability.
- τ (inclusion threshold): higher τ yields more conservative circuits (fewer vertices, stronger guarantee) but may cause many abstentions.
- Choice of A: more stable base algorithms may yield better certified circuits, but framework is agnostic.

Failure signatures:
- High abstention rate (many vertices neither in nor out) indicates insufficient statistical power; increase n or adjust τ.
- Degenerate certified circuit (empty or too tiny) suggests p_del too high or base algorithm too unstable on small data.
- Low cACC on in-distribution data indicates that certification is discarding critical vertices; may need to relax τ or ensure base algorithm is well-suited.

First experiments:
1. Sanity check: Set p_del=0 and n=1; the certified circuit should exactly match the base algorithm's output on the full dataset.
2. Stability verification: For a certified vertex, generate 100 random single-deletion perturbations of the concept dataset and confirm that the base algorithm includes the vertex in all cases (within statistical tolerance).
3. Performance comparison: For a single ImageNet class, plot cACC vs. circuit size for both baseline (target K sweep) and certified (effective K) to reproduce the typical tradeoff curve and observe the gains.

## Limitations
- The concept dataset size and composition per class are unspecified, which may affect reproducibility and scaling to 100 classes.
- Evaluation on ImageNet-O relies on model predictions as pseudo-labels, introducing potential bias; the exact protocol is unclear.
- Absolute performance numbers depend on hyperparameters (τ, p_del, n) and the choice of base algorithm; the paper uses specific values that may not be optimal.

## Confidence
- Provable stability: **High** (the framework combines well-established statistical techniques with a clear guarantee).
- Efficiency & accuracy gains: **Medium** (quantitative improvements depend on faithful execution and hyperparameter choices; some uncertainties could shift absolute numbers).
- OOD generalization robustness: **Low–Medium** (lack of precise evaluation protocol, especially for ImageNet-O, makes it hard to assess reproducibility of robustness claims).

## Next Checks
1. **Concept dataset size sensitivity**: Vary the number of images per class (e.g., 20, 50, 100) and measure effects on certified radius and circuit sparsity.
2. **Full-scale replication**: Run certified discovery on all 100 ImageNet classes with identical hyperparameters to reproduce the cACC vs. compactness curves reported in the paper.
3. **OOD protocol audit**: For ImageNet-O, compare model-predicted pseudo-labels against any available ground truth to quantify impact on class accuracy; clarify severity levels for other OOD benchmarks.
