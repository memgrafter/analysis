# On the Expressive Power of Transformers for Maxout Networks and Continuous Piecewise Linear Functions
## Quick Facts
- arXiv ID: 2603.03084
- Source URL: https://arxiv.org/abs/2603.03084
- Reference count: 40
- Primary result: Transformers can approximate maxout networks (and thus ReLU/CPWL functions) with comparable complexity, and their expressive power (measured by linear region count) grows exponentially with depth.

## Executive Summary
This paper studies the theoretical expressive power of Transformer architectures. The authors construct Transformer models that can approximate maxout networks to arbitrary accuracy while maintaining comparable model complexity, thereby inheriting universal approximation capabilities for ReLU networks. They develop a framework for analyzing the approximation of continuous piecewise linear (CPWL) functions, quantifying expressivity by the number of linear regions. The analysis reveals that self‑attention layers implement max‑type operations, while feedforward layers perform token‑wise affine transformations when combined with positional embeddings and residual connections. A lower bound shows that the number of linear regions realizable by Transformers grows exponentially with network depth. The work bridges approximation theory for standard feedforward neural networks and Transformer architectures.

## Method Summary
The paper establishes a constructive approximation: a Transformer with L = 3D blocks can represent any D‑layer maxout network with width mT and rank p. The construction uses positional embeddings to shift each token into a distinct hyperrectangle, enabling a feedforward layer to compute token‑wise affine transformations (realized by a one‑hidden‑layer ReLU network that selects appropriate affine pieces). Self‑attention, with scaled softmax (or hardmax), aggregates these token‑specific values to approximate the max operation; multiple heads handle the multiple components. Stacking such blocks yields deep maxout networks. For generic CPWL functions, the Transformer outputs the difference of two such stacks. Approximation errors for softmax scale exponentially with the inverse temperature λ and linearly with dimension d, whereas hardmax gives exact representation. The method mirrors standard feedforward approximations but adapts to the Transformer structure.

## Key Results
- Transformers can approximate any maxout network with arbitrary L∞ accuracy using at most L = 3D blocks, preserving comparable parameter complexity.
- Self‑attention computes max‑type operations; feedforward layers with token‑wise shifts realize distinct affine maps per token.
- The number of linear regions of the functions representable by a Transformer grows exponentially with depth L; a lower bound is provided in Theorem 4.4.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Self‑attention layers implement max‑type operations, enabling the aggregation of token‑specific affine computations into a maxout‑like structure.
- **Mechanism:** The scaled softmax (or hardmax) attention weights compute a weighted sum over token values. With appropriate weight configurations (large scaling parameter λ for softmax), the output can approximate the maximum of the selected token values (`x⊤σλ_S(x) ≈ max(x)` for large λ).
- **Core assumption:** The number of maxout components `p` does not exceed the sequence length `T`; otherwise, the max approximation requires deeper stacking (see Remarks 3.2, 3.4).
- **Evidence anchors:**  
  [abstract]: "self‑attention layers implement max‑type operations"  
  [section 2.2, eq. 2.1 & definitions]: Formal definitions of hardmax `σ_H` and scaled softmax `σλ_S`.  
  [section 3, Proof Sketch of Theorem 3.1, Step 2]: Explicit construction showing self‑attention computes `max(W_i X Vec + b_i)` via appropriate `W_K, W_Q, W_V`.  
  [Lemma A.3]: Bound on `|x⊤σλ_S(x) - max(x)| ≤ d e^{-λ}`.
- **Break condition:** If `p > T`, a single self‑attention layer cannot directly approximate a maxout unit; the paper resorts to approximating a deep `p`‑maxout network with a shallower `s`‑maxout intermediate network (Theorem 3.4).

### Mechanism 2
- **Claim:** Feedforward layers realize token‑wise affine transformations, and repeated token‑wise shifts (via positional embeddings and residual connections) across depth enable distinct computation per token, mitigating parameter sharing limitations.
- **Mechanism:** Positional embedding `E(X)=AX+B` maps each token `x_t` to a distinct domain `[a,b]^n + offset_t`. A feedforward layer with ReLU (Lemma A.2) then implements a piecewise linear function that is affine on each distinct token region `I_t`. Stacking these layers with shifts allows each token to follow its own affine path, necessary for representing general CPWL functions.
- **Core assumption:** The input domain is compact and can be partitioned into `T+1` disjoint hyperrectangles `I_t` via linear shifts. The lemma A.2 construction requires pairwise disjoint regions.
- **Evidence anchors:**  
  [abstract]: "feedforward layers realize token‑wise affine transformations"  
  [section 1.3]: "To mitigate the limitations induced by parameter sharing across tokens in the feedforward layers... we introduce a token‑wise shift..."  
  [section 3, Proof Sketch of Theorem 3.1, Step 1]: Use of positional embedding to create disjoint regions, and Lemma A.2 to build token‑wise affine pieces.  
  [Lemma A.2]: Construction of a one‑hidden‑layer ReLU network that implements a different affine map on each of `T+1` disjoint hyperrectangles.
- **Break condition:** Without enough depth or without the positional shifts (`δ` too small), regions from different tokens may overlap, causing interference and failing to realize the intended piecewise function. The construction requires `0 < δ < (b-a)/(T+1)`.

### Mechanism 3
- **Claim:** The number of linear regions realizable by Transformer architectures grows exponentially with network depth `L` (or the depth `D` of the approximated maxout network), as shown by the lower bound in Theorem 4.4.
- **Mechanism:** By Theorem 3.5, a Transformer with `L=3D` layers can approximate a `D`‑layer maxout network. The expressive power (number of linear regions `N(N)`) of a `D`‑layer maxout network with width `mT` and rank `p` has a known lower bound from Lemma 4.3 that is exponential in `D` when `mT` and `p` are sufficiently large relative to input dimension `nT`. This bound transfers to the Transformer class.
- **Core assumption:** The maxout network width `n_ℓ` and input dimension satisfy conditions in Lemma 4.3 (e.g., `n_ℓ / n` even). The Transformer construction requires `p ≤ T` (or uses depth reduction for `p > T`).
- **Evidence anchors:**  
  [abstract]: "the number of linear regions grows exponentially with network depth"  
  [section 4, Theorem 4.4]: Explicit lower bound `N(F) ≥ [mT/(q(T-1)+1)]^{q(⌊D/3⌋-1)} * Σ_{j=0}^{mT} (mT choose j)(T-1)^j` for suitable `q`.  
  [section 4, preceding Theorem 4.4]: Connection to maxout network region bounds via Lemma 4.3.  
  [corpus]: Multiple papers (e.g., [26, 27, 42] on maxout/ReLU region counts) provide foundational evidence that depth yields exponential region growth in standard FNNs.
- **Break condition:** The exponential lower bound relies on large enough width `mT` and suitable `q` (e.g., `q ≤ min(nT, mT/2)`). For very narrow Transformers (small `m` or `d`), the bound may not be tight or may not reflect actual achievable regions.

## Architecture Onboarding

### Component map
Input `X ∈ ℝ^{n×T}` → Positional embedding `E(X)=AX+B` → repeated Transformer blocks (self‑attention → token‑wise feedforward) → linear readout `C` (output). An auxiliary constant token is appended at position `T+1` to absorb residual shifts.

### Critical path
1. Positional embedding shifts each token into a distinct hyperrectangle.
2. For each target maxout component: a feedforward layer computes token‑wise inner products `x_t^⊤ V_{i,j}` on its region.
3. Self‑attention layer (multiple heads) aggregates these per‑token inner products via a weighted sum that approximates `max` (using large `λ` for softmax).
4. A second self‑attention layer computes the final max over the `p` components.
5. Steps 1‑4 are repeated in blocks (total `L=3D`) to realize a `D`‑layer maxout network.
6. Linear readout subtracts two such stacks to represent a CPWL function (`g−h`).

### Design tradeoffs
- **Depth vs. Width:** Deeper Transformers (`L` larger) can represent exponentially more linear regions. The construction requires `H = Θ(mT)` heads and embedding dimension `d ≥ Θ(mT)`.
- **Softmax vs. Hardmax:** Hardmax gives exact max but is non‑differentiable; softmax approximates with error `O(1/λ)`, needing large `λ` for high accuracy.
- **Sequence Length `T`:** Parameter count scales at least linearly with `T` because of head count `H = Θ(mT)`. Longer contexts increase resource requirements.
- **Rank `p` of maxout:** If `p ≤ T`, use `L=3D` blocks; if `p > T`, a preliminary depth reduction (Theorem 3.4) is needed, increasing `L`.

### Failure signatures
- **Token interference:** Overlapping token regions due to insufficient shift `δ` or too small embedding dimension `d` cause feedforward layers to mix affine maps. Diagnose by checking per‑token outputs on separable inputs.
- **Softmax saturation:** If `λ` is too small, `x⊤σλ_S(x)` deviates from `max(x)`. Monitor the gap `max(x) - x⊤σλ_S(x)` on worst‑case token values; increase `λ`.
- **Boundary errors:** Near hyperrectangle boundaries, the piecewise affine selector (Lemma A.2) may fail if hidden width is insufficient. Ensure hidden width ≥ `4(n+1)(T+2)` per the lemma.

### First 3 experiments
1. **Unit test max approximation:** For `T=2`, vary `λ` and verify `|x⊤σλ_S(x) - max{x}|` matches the theoretical `O(d e^{-λ})` decay.
2. **Reconstruct a rank‑2 maxout layer:** Build a Transformer with three blocks to implement `f(X)=max(W₁XVec+b₁, W₂XVec+b₂)`. Compare outputs on a grid and confirm error decreases as `λ` increases.
3. **Measure linear region growth:** Construct Transformers of increasing depth `D` (via Theorem 3.5) and empirically count distinct affine pieces in the output over a fine grid in `ℝ^{n×T}` for small `n,T`. Verify super‑linear growth consistent with the lower bound when width is sufficient.

## Open Questions the Paper Calls Out

### Open Question 1
- **Question:** How can refined approximation rates for feedforward networks (e.g., on Hölder, Sobolev, or Barron spaces) be transferred to Transformer architectures via the maxout/ReLU connection?
- **Basis in paper:** The conclusion states: "One direction is to transfer refined approximation results for feedforward neural networks—such as approximation rates on specific function spaces and techniques for alleviating the curse of dimensionality—to Transformer models via their systematic approximation of maxout and ReLU networks."
- **Why unresolved:** The analysis is confined to CPWL functions; extending to smooth function classes would require handling continuous softmax and adapting depth/width trade‑offs.
- **What evidence would resolve it:** Derive explicit approximation rate bounds (e.g., in Lp norms, entropy numbers) for Transformers on smooth function classes by translating feedforward results through the maxout approximation.

### Open Question 2
- **Question:** Can a pure self‑attention‑only architecture (without token‑wise feedforward layers) efficiently emulate standard feedforward networks, i.e., achieve comparable parameter complexity?
- **Basis in paper:** The conclusion asks: "whether pure self‑attention architectures can efficiently emulate standard feedforward networks."
- **Why unresolved:** The paper attributes token‑wise affine transformations to feedforward layers; removing them may break the ability to realize arbitrary token‑wise maps. No impossibility or constructive proof exists.
- **What evidence would resolve it:** Provide either a constructive proof that self‑attention alone can approximate any feedforward network with similar depth/width and explicit parameter scaling, or a hardness result showing that such emulation necessarily incurs super‑polynomial overhead.

### Open Question 3
- **Question:** Do Transformers or self‑attention‑only models surpass standard feedforward networks in expressive power, for instance by realizing a higher growth rate of linear regions with depth?
- **Basis in paper:** The conclusion: "whether Transformers or self‑attention‑only models can surpass feedforward networks in expressive power, for instance as measured by the growth of linear regions."
- **Why unresolved:** Transformers inherit exponential depth dependence from maxout networks, but known lower bounds for maxout/ReLU already achieve exponential growth. It is unknown whether Transformers can achieve an even faster growth (e.g., doubly exponential) within the same parameter budget.
- **What evidence would resolve it:** Either a tighter lower bound on the linear regions of Transformers that strictly exceeds the best known bound for comparably sized feedforward networks, or a proof that Transformer expressivity cannot surpass the feedforward ceiling.

## Limitations
- Lemma A.2 provides only an existence proof for token‑wise affine selectors; explicit weight matrices are missing, complicating direct implementation.
- Asymptotic bounds (e.g., `λ = O(1/ε)`) lack concrete constants, leaving ambiguity in setting `λ` for a target approximation error.
- The exponential lower bound on linear regions assumes sufficiently large width; for narrow Transformers the bound may be loose, and parameter scaling grows linearly with sequence length `T`.
