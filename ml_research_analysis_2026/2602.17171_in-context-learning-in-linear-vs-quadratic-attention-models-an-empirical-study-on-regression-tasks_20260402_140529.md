# In-Context Learning in Linear vs. Quadratic Attention Models: An Empirical Study on Regression Tasks
## Quick Facts
- arXiv ID: 2602.17171
- Source URL: https://arxiv.org/abs/2602.17171
- Reference count: 16
- Primary result: Linear attention with a squared‑ReLU kernel matches quadratic softmax attention’s final test MSE on a linear regression ICL benchmark, converges faster, and shows comparable robustness to anisotropic inputs.

## Executive Summary
This paper investigates in‑context learning (ICL) on a linear regression benchmark using decoder‑only transformers with either standard quadratic (softmax) attention or linear attention parameterized by a squared‑ReLU feature map. Models with 1, 3, and 6 layers are trained to predict a query label from ten context examples. Key findings reveal that both architectures achieve similarly low normalized MSE (≈0.03) at six layers, but linear attention converges substantially faster—requiring roughly half the number of training samples to reach 90% of its final performance. Depth is a critical factor: one‑layer models fail (MSE >0.7), while three and six layers show dramatic improvement. Both generalize to an anisotropic input distribution with modest degradation, though quadratic attention is slightly more robust at three layers. The results suggest that linear attention is a computationally efficient alternative for ICL on simple regression tasks without sacrificing accuracy.

## Method Summary
The authors train decoder‑only transformers on the Garg et al. linear regression benchmark. The task: given a context of ten (x, y) pairs with x∈ℝ^5 and y = wᵀx where w∼N(0,I), and a query x, predict the corresponding y without weight updates. Models are compared across two attention mechanisms—quadratic softmax and linear with squared‑ReLU kernel—and three depths (1,3,6 layers). Architecture details: d_model=256, 4 attention heads, MLP hidden size 1024, causal masking, and residual connections. Training uses Adam with gradient clipping 1.0. Hyperparameters differ: quadratic (lr=1e‑4, batch=32, up to 30k steps) and linear (lr=3e‑4, batch=64, depth‑specific steps: 1‑layer 7500, 3‑layer 8000, 6‑layer 10000). Evaluation metrics: normalized test MSE (divided by d_x), samples to reach 90% of final MSE reduction, and robustness to an anisotropic input distribution (diagonal covariance with increasing variances). All experiments are run with five random seeds.

## Key Results
- At six layers both mechanisms achieve comparable final accuracy: quadratic attention test MSE 0.0365±0.0041 vs. linear attention 0.0302±0.0034.
- Linear attention converges significantly faster: to 90% of its final MSE it requires 256k samples for 3‑layer and 480k for 6‑layer, whereas quadratic needs 688k and 800k respectively.
- Depth dramatically improves performance for both; one‑layer models fail (MSE >0.7), while three and six layers yield low error and similar generalization to anisotropic data (<13% degradation).

## Why This Works (Mechanism)
The paper proposes three interrelated mechanisms to explain ICL in the studied models.

1. **Quadratic attention simulates gradient descent.** Each self‑attention layer can implement one step of a meta‑learning algorithm (e.g., ridge regression) on the in‑context examples. Deeper stacks perform multiple sequential updates, approximating iterative optimization. This is supported by prior theoretical work and the observed depth‑performance relationship. The mechanism breaks when depth is insufficient (1‑layer models fail).

2. **Linear attention’s capability is kernel‑constrained.** Linear attention factorizes the attention matrix via a feature map ϕ. The choice of squared‑ReLU enables non‑negative aggregation and sharper weights, crucial for stable ICL on regression. Different kernels yield different learning algorithms; the identity map fails completely. Depth helps overcome expressivity limits by stacking linear transformations in the feature space.

3. **Depth is the primary scaling factor.** Both architectures require a minimum number of computational steps to process the context and synthesize a query prediction. The gap between 1‑layer and deeper models indicates a threshold effect: at least three layers are needed to reach the least‑squares solution for k=10 examples.

## Architecture Onboarding
**Component map:** Input Tokens -> Input Embedding -> [Attention -> MLP] repeated L times -> Output Head

**Critical path:**
1. Tokenization: Each (x_i, y_i) pair and the query x are converted into tokens; x is a d_x=5 vector, y is a scalar.
2. Embedding: All tokens projected to d_model=256.
3. Sequential processing: For each position t in the causal sequence, compute attention output o_t using either quadratic softmax or linear recurrence (with squared‑ReLU feature map).
4. MLP: After each attention, a feed‑forward block (expand to 1024, nonlinearity) is applied. Residual connections add the block input to its output.
5. Prediction: The representation at the final query position (after the last MLP) is fed to an output head that produces a scalar prediction.
6. Loss: Mean squared error between prediction and true y_query, normalized by d_x, is minimized during training.

**Design tradeoffs:**
- Quadratic attention offers higher expressivity via softmax but incurs O(T²) compute/memory; it converges slower but reaches similar final accuracy.
- Linear attention runs in O(Td²) and has far fewer parameters; it converges faster but performance is sensitive to the choice of feature map ϕ.
- Depth is the dominant factor for both; increasing layers dramatically reduces error and enables both mechanisms to approximate the least‑squares solution.
- At 6 layers, linear attention achieves parity with quadratic despite having only ~0.8M–4.75M parameters vs. quadratic’s 13.7M–17.6M.

**Failure signatures:**
- One‑layer models yield high MSE (>0.7) regardless of attention type, indicating insufficient depth for iterative refinement.
- Linear attention with an inappropriate feature map (e.g., identity ϕ(x)=x) fails almost completely (MSE≈1).
- Excessive learning rates cause divergence, especially for quadratic attention (>1e‑3) and linear (>3e‑4).
- Anisotropic data can cause moderate performance drops; the 3‑layer linear model shows a larger degradation (12.6%) than its quadratic counterpart (4.7%).

**First 3 experiments:**
1. **Replicate Garg et al. baseline:** Train a 6‑layer quadratic transformer with the original hyperparameters (12 layers, 8 heads, d_x=20) to confirm the task is solvable, then scale to the paper’s setup (d_x=5, 4 heads, 6 layers).
2. **Kernel sensitivity test for linear attention:** With fixed 6‑layer linear model, train runs using feature maps ϕ(x)=x (identity), ϕ(x)=ReLU(x), and ϕ(x)=ReLU(x)². Measure final MSE and convergence speed; expect squared‑ReLU to be superior.
3. **Depth scaling comparison:** Train both architectures at depths 1, 3, and 6 under identical optimal hyperparameters. Plot test MSE vs. depth and samples‑to‑90%‑convergence vs. depth; expect both to improve with depth, with linear converging faster at each depth.

## Open Questions the Paper Calls Out
The authors identify three unresolved questions:

1. **Does linear attention generalize its faster convergence to more complex function classes?** The study only examined linear regression; evaluating on polynomial regression, decision trees, or MLPs would determine if the advantage extends.
2. **How do quadratic and linear attention differ mechanistically in implementing ICL?** No internal analysis (e.g., attention pattern probing) was performed; such studies could reveal the exact algorithms each mechanism learns.
3. **Which architectural components are essential for ICL?** Only depth and attention type were varied; systematic ablations on width, head count, normalization, and feature map are needed to separate essential from beneficial design choices.

## Limitations
- Architectural details such as exact layer‑norm placement and residual connection implementation are not fully specified, hindering exact replication.
- The data generation pipeline (batching strategy, number of distinct tasks per batch, train/test splits) is underscribed.
- The scope is limited to linear regression; it remains unclear whether results transfer to non‑linear or more realistic tasks.

## Confidence
- Final accuracy parity at 6 layers: **High** (low‑variance empirical results across seeds).
- Faster convergence of linear attention: **Medium** (clearly shown but depends on precise convergence metric).
- Depth‑scaling improvement: **High** (consistent performance jump from 1→3→6 layers).
- Robustness to anisotropic data: **Medium** (modest degradation observed, but exact invariance unclear).
- Mechanistic interpretations (gradient descent simulation, kernel constraints): **Low/Medium** (correlative, not rigorously proven).
