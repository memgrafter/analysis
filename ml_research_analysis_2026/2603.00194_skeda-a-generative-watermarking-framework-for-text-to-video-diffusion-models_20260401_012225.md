# SKeDA: A Generative Watermarking Framework for Text-to-video Diffusion Models

## Quick Facts
- arXiv ID: 2603.00194
- Source URL: https://arxiv.org/abs/2603.00194
- Reference count: 40
- Primary result: Achieves 96.87% bit accuracy under H.264 compression (CRF=30), a 10.75% absolute improvement over best baseline, while preserving video quality (FVD=361.3, CLIP-score=0.3345).

## Executive Summary
SKeDA introduces a training-free generative watermarking framework for text-to-video diffusion models. It addresses the vulnerability of existing watermarking methods to temporal distortions like frame reordering and compression. By combining Shuffle-Key Sampling (SKe) for frame-level encryption and Differential Attention (DA) for robust message aggregation, SKeDA achieves state-of-the-art robustness without compromising video quality.

## Method Summary
The framework operates in two phases: embedding and extraction. During embedding, a binary watermark is mapped to Gaussian noise via a spatial block configuration. SKe applies a frame-specific permutation derived from a base pseudo-random sequence to encrypt the watermark per frame. This permuted noise initializes a diffusion sampler (DPMSolver) with a text-to-video model (Stable Diffusion v1.5 + AnimateDiff) to generate the watermarked video. For extraction, the watermarked video is encoded to latent space, inverted via DDIM, and reverse-sampled to obtain per-frame encrypted messages. DA computes inter-frame cosine similarities to derive attention weights, aggregating messages across frames. After decrypting with the same shuffle key, spatial blocks are aggregated and thresholded to recover the original bits.

## Key Results
- Under H.264 compression (CRF=30), SKeDA achieves 96.87% bit accuracy, improving over the best baseline by 10.75% absolute.
- Across common distortions, average bit accuracy improves by 1.15% relative to baselines.
- Watermarked video quality remains high (FVD=361.3, CLIP-score=0.3345), comparable to non-watermarked generation.

## Why This Works (Mechanism)
SKeDA’s robustness stems from two synergistic designs. Shuffle-Key Sampling (SKe) encrypts the watermark per frame using a shared base sequence and frame-level permutations, ensuring that temporal misalignments (e.g., frame reordering, loss) do not desynchronize extraction as long as the set of frames is preserved. Differential Attention (DA) compensates for residual distortions by weighting each frame’s extracted message according to its similarity to a reference frame (typically the first frame). Frames with higher similarity (less distorted) contribute more to the final bit decision, while outlier frames are downweighted. This dynamic aggregation makes the system tolerant to compression artifacts and partial frame corruption.

- **Attention-Based Aggregation**: Using learned attention weights to combine per-frame messages. *Why needed*: Adapts to varying frame quality/distortion. *Quick check*: Do weights correlate with frame similarity metrics?

## Architecture Onboarding
Component map: Text Prompt -> Embedding (SKe module + Gaussian mapping) -> DPMSolver Sampling (with SD v1.5 + AnimateDiff) -> Watermarked Video. Extraction: Watermarked Video -> Latent Encoder -> DDIM Inversion -> Reverse Sampling -> DA Module (cosine similarity + attention weights) -> Message Aggregation -> Shuffle-Key Decryption -> Spatial Block Aggregation -> Thresholding -> Recovered Bits.

Critical path: The embedding pipeline must align with the extraction inversion path to ensure latent consistency. SKe and DA are the core innovations that handle temporal variations.

Design tradeoffs:
- Robustness vs. quality: Stronger watermarking may degrade video fidelity; SKeDA balances by operating in latent space and using DA to avoid overfitting to distortions.
- Capacity vs. robustness: More bits require more spatial blocks, potentially reducing redundancy; SKeDA uses block aggregation to mitigate.
- Computational cost: Full reverse sampling per frame is expensive; however, the method is training-free, avoiding model fine-tuning.

Failure signatures:
- Low bit accuracy on clean videos indicates embedding/extraction misalignment (e.g., incorrect Gaussian mapping or spatial block config).
- Poor robustness under compression suggests DA weights are not responding to distortion (e.g., invalid cosine similarity computation).
- Failure under frame reordering implies SKe permutation is not correctly applied or decrypted.

3. **Compression stress test**: Apply H.264 with varying CRF; evaluate accuracy and compare with baselines.
