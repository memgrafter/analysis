# Near-optimal Swap Regret Minimization for Convex Losses

## Quick Facts
- arXiv ID: 2602.08862  
- Source URL: https://arxiv.org/abs/2602.08862  
- Reference count: 37  
- Primary result: Achieves Õ(√T log T) expected swap regret for 1‑Lipschitz convex losses, matching the lower bound up to log factors, and yields the first Õ(√T) calibration error for median/quantile without Lipschitzness assumption.

## Executive Summary
The paper addresses online swap regret minimization against an adaptive adversary using Lipschitz convex loss functions over [0,1]. Prior best bounds were Õ(T^{2/3}). The core idea is multi‑scale binning: discretize the interval into bins at multiple granularity scales simultaneously and make randomized predictions across scales to balance rounding and sampling errors. Efficiency is achieved via a multi‑objective learning reduction using the MsMwC expert algorithm. The authors provide an explicit randomized predictor guaranteeing Õ(√T log T) expected swap regret (near‑optimal) and running in polynomial time. As a corollary, they obtain the first Õ(√T) calibration error bound for median and quantile without assuming Lipschitzness of the identification function.

## Method Summary
The algorithm operates in rounds. Before play, compute γ = √(ln T·ln(1/δ)/T) and define scales R = {γ·2^k} ∩ [0,1] and bins B_r = {0, r, 2r, …} ∩ [0,1]; let Θ = ⋃_{r∈R} {r}×B_r. Each round: (1) Query MsMwC for mixing distribution w^{(t)} over constraint indices Ξ = Θ×{−2,−1,+1,+2}. (2) Form convex combination ¯h_t of constraint functions h_{r,b,ξ} using w^{(t)}. (3) Solve a linear program to obtain distribution κ_t over Θ such that Σ_{r,b} κ_t(r,b)·¯h_t(r,b,v) ≤ 0 for all v in a finite set V. (4) Sample (r_t,b_t)~κ_t and predict p_t = b_t. (5) Observe loss ℓ_t; compute its V‑shaped distribution φ_t via subgradient integration. (6) For each (r,b,ξ) compute reward u^{(t)}_{r,b,ξ} = E_{v∼φ_t}[h_{r,b,ξ}(r,b,v)]. (7) Feed rewards to MsMwC to update weights for next round. The γ‑width of the average loss distribution guides the effective scale selection implicitly through the LP constraints.

## Key Results
- An explicit randomized predictor guaranteeing Õ(√T log T) expected swap regret (matching the Ω(√T) lower bound up to log factors) and running in polynomial time.
- First Õ(√T) calibration error bound for median and quantile without assuming Lipschitzness of the identification function.

## Why This Works (Mechanism)

### Mechanism 1: Multi‑Scale Binning
Discretize [0,1] into bins at multiple scales r ∈ R = {γ,2γ,4γ,…} with γ = Θ(1/√T). In each round the predictor selects a bin b_t from some scale r_t. The scale r_t is determined by the γ‑width of the loss distribution π_t; this width balances rounding errors (coarse discretization) and sampling errors (insufficient data per bin). Small width favors fine scales (small r) to reduce rounding error; large width favors coarse scales (large r) to ensure enough expected samples per bin, reducing sampling error. Total swap regret sums contributions over all bins, each controlled by this balance.

- **Evidence anchors**: [Abstract] identifies multi‑scale binning; [Section 3.2] details the truthful predictor; [Section 1.2] explains failure of fixed binning and solution.
- **Break condition**: If γ‑width fails to reflect effective variability of the loss (e.g., disjoint modes), rounding and sampling errors may not cancel optimally. The V‑shaped decomposition (Lemma 2.1) is essential; for non‑convex or non‑Lipschitz losses the mechanism breaks.

### Mechanism 2: Truthful Predictor for Order‑Reversed Game
In an order‑reversed game where the adversary reveals π_t before prediction, choosing p_t as a bin that minimizes expected loss at the scale given by the γ‑width of π_t yields O(√T log T) expected swap regret. Compute average distribution φ̄_t from π_t, determine its γ‑width w_t and interval [α_t,β_t] (quantiles), pick r_t such that w_t ∈ [r_t,2r_t) and choose b_t ∈ B_{r_t} ∩ [α_t,β_t]. This makes b_t an approximate median of φ̄_t, so rounding error is O(r_t). Sampling error between empirical and expected losses is controlled by concentration (Azuma/Freedman) with rate depending on 1/√|T_{r,b}| and γ/r. Summing over all (r,b) and balancing r_t with expected bin occupancy gives the final bound.

- **Evidence anchors**: [Section 3.2] describes predictor and analysis; [Lemma 3.4] gives O(√T log T) bound; [Abstract] highlights multi‑scale binning.
- **Break condition**: If γ‑width is extremely small, r_t≈γ leads to many light bins, increasing sampling error; if width is large, r_t large and rounding error may dominate. The width definition is crafted to balance these, but pathological distributions with disjoint modes could cause the interval [α_t,β_t] to miss the true minimizer.

### Mechanism 3: Efficient Reduction via Multi‑Objective Learning
The non‑constructive truthful predictor is implemented efficiently by reducing to a multi‑objective learning task. The swap regret bound requires holding inequalities (14)–(17) for all (r,b) pairs; these are linear in expectations of functions h_{r,b,ξ}. In each round, MsMwC produces a convex combination ¯h_t of these functions. By Lemma 4.1 there exists κ_t over Θ such that E_{(r,b)∼κ_t}[¯h_t(r,b,v)] ≤ 0 for all v. Sampling (r_t,b_t)~κ_t ensures martingale differences are controlled. MsMwC minimizes external regret on convex combinations, which implies all constraints are satisfied in hindsight via standard multi‑objective arguments. The LP to compute κ_t is polynomial in |Θ| = O(1/γ)=O(√T), and MsMwC runs in poly(T,|Θ|), yielding overall poly(T) algorithm.

- **Evidence anchors**: [Section 4] presents efficient algorithm and analysis; [Lemma 4.1] shows LP feasibility; [Lemma 4.3] proves O(√T log T) bound and poly(T) runtime; [Abstract] mentions reduction and MsMwC.
- **Break condition**: If γ is too small, |Θ| becomes large (O(1/γ)), making LP and MsMwC slower though still polynomial. The analysis relies on specific form of h functions and V‑shaped representation; for non‑convex/non‑Lipschitz losses the decomposition may not exist. MsMwC’s guarantee (25) is critical; if squared rewards are not bounded by 1, the bound worsens.

## Architecture Onboarding

Component map:  
Inputs (T,δ) -> Compute γ, Scales R, Bins B_r, Set Θ -> MsMwC (maintains weights w^{(t)}_{r,b,ξ}), LP solver (computes κ_t from ¯h_t), Loss decomposer (computes φ_t from ℓ_t), Reward computer (computes u^{(t)}_{r,b,ξ}), Sampler (draws (r_t,b_t)~κ_t) -> Output p_t. After observing ℓ_t, rewards are fed back to MsMwC for next round.

Critical path per round t:
1. Query MsMwC for current mixing distribution w^{(t)}.
2. Form convex combination ¯h_t = Σ w^{(t)}_{r,b,ξ} · h_{r,b,ξ}.
3. Solve LP: unknowns κ_t(r,b)≥0, Σκ_t=1; for each v∈V, Σ κ_t(r,b)·¯h_t(r,b,v) ≤ 0. Output feasible κ_t.
4. Sample (r_t,b_t)∼κ_t; set p_t = b_t.
5. Observe loss ℓ_t; compute its V‑shaped distribution φ_t via subgradient integration.
6. For each (r,b,ξ) compute reward u^{(t)}_{r,b,ξ} = E_{v∼φ_t}[h_{r,b,ξ}(r,b,v)].
7. Feed reward vector to MsMwC; it updates weights for round t+1.

Design tradeoffs:
- γ selection: γ = √(ln T ln(1/δ)/T) minimizes bound; smaller γ increases |Θ| (LP size) but worsens asymptotic bound linearly; larger γ reduces |Θ| but increases rounding error.
- LP size: |Θ| = O(1/γ) = O(√T); LP has O(|Θ|) variables and constraints; manageable for large T (e.g., T=10^6 → |Θ|~1000).
- MsMwC vs MW: MsMwC’s √(∑ squares) guarantee (Eq. 25) is crucial for √T bound; simpler multiplicative weights would add √(log|Θ|) factor, possibly worsening to T^{2/3}.
- Lipschitz convexity: V‑shaped decomposition (Lemma 2.1) requires 1‑Lipschitz convex; non‑Lipschitz/non‑convex losses break analysis.

Failure signatures:
- Empirical swap regret >> O(√T log T) indicates concentration/balancing failure.
- LP infeasibility (numerical or due to incomplete breakpoint set V) may cause constraint violations.
- MsMwC divergence or incorrect implementation (e.g., using standard Hedge) degrades regret to O(√T·√log|Ξ|).
- Time/memory blowup if γ is set too small (|Θ| grows as 1/γ, exceeding poly(T) in practice).

First 3 experiments:
1. Deterministic V‑shaped loss: ℓ_t(p)=|p−v| for fixed v; T=10^4. Verify bins concentrate around v at scale ≈γ; empirical swap regret scales like √T log T. Compare against fixed binning with O(√T) bins (constant rounding error).
2. Mixture of two separated V‑shaped losses: π_t uniform over {|p−v|, |p−(v+0.5)|}. Expect coarse bins (r~0.5) and sampling error dominance; check swap regret still O(√T log T).
3. Quadratic convex loss: ℓ_t(p)=(p−μ_t)^2 with adversarially chosen μ_t. Algorithm should achieve O(√T log T); confirm bound holds and note it is not tighter than specialized O(T^{1/3}) algorithm, illustrating generality.

## Limitations
- Requires a subgradient oracle for each loss; without efficient left/right derivative computation the reward construction fails.
- Efficient implementation hinges on the MsMwC expert algorithm; any deviation from its variance‑adjusted guarantee could degrade the √T bound.
- The V‑shaped decomposition only holds for 1‑Lipschitz convex losses; non‑Lipschitz or non‑convex losses are not covered.
- Solving an LP each round must be numerically exact; small constraint violations may break the concentration argument.

## Confidence
- Near‑optimal swap regret bound (Õ(√T log T)): High
- Polynomial‑time implementability: Medium
- Calibration error Õ(√T) for median/quantile: Medium
