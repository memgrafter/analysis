# SYNAPSE: Framework for Neuron Analysis and Perturbation in Sequence Encoding

## Quick Facts
- **arXiv ID:** 2603.08424
- **Source URL:** https://arxiv.org/abs/2603.08424
- **Reference count:** 37
- **Primary result:** SYNAPSE reveals that while task-relevant information is broadly distributed across neurons (ensuring functional stability), class-specific neuron asymmetries create heterogeneous vulnerabilities: targeted per-class silencing can collapse individual labels, and weight-space attacks can redirect up to 76% of predictions.

## Executive Summary
SYNAPSE is a training‑free framework for neuron‑level interpretability and robustness testing in Transformer models. It extracts per‑layer [CLS] representations, trains a lightweight linear probe to assign importance scores to neurons (both globally and per class), and applies reversible interventions at inference time using forward hooks. Evaluated on malware detection and emotion classification across multiple Transformer architectures, the framework uncovers a dual pattern: task‑relevant information is distributed across overlapping neuron subsets, making models surprisingly robust to large‑scale random silencing; yet class‑specific asymmetries mean that silencing neurons important for a particular class can cause its performance to collapse entirely. Moreover, small structured manipulations in weight or logit space (e.g., balanced push attacks) can flip the majority of predictions to a target class. These findings highlight complementary robustness weaknesses beyond standard adversarial perturbations and provide a systematic tool for model auditing.

## Method Summary
The SYNAPSE pipeline comprises three stages. First, the **Explainability Block** processes a held‑out dataset to extract [CLS] token activations after each Transformer layer, then trains a linear classifier (probe) on these frozen representations. The resulting weight tensor (classes × hidden size × layers) encodes each neuron’s contribution to each class. Second, the **Analysis Block** derives global neuron rankings by summing absolute weights across all classes, and per‑class rankings by taking the absolute weight for the class; top‑k neurons are selected according to a given silencing fraction. Third, the **Adversarial Block** registers PyTorch forward hooks on specified layers to modify the [CLS] vector during inference—e.g., zeroing out selected neurons, adding Gaussian noise, or perturbing the classification head weights. After each intervention, model performance (weighted F1‑score) is measured on a clean test set, and hooks are removed to restore original behavior. The framework supports both multi‑layer and last‑layer‑only scopes and includes a range of attacks (undirected silencing, per‑class silencing, logit bias, embedding‑space FGSM).

## Key Results
- Global undirected silencing of top‑ranked neurons degrades performance gradually; on Longformer, F1 drops from 0.852 to 0.079 when 95% of top neurons are silenced.
- Targeted per‑class silencing can collapse specific labels entirely; silencing BigBird neurons important for Class‑2 (TheTick) reduces its F1 to 0.000.
- Structured weight‑space attacks cause large prediction redirection; a balanced push attack on BigBird results in 76% of samples flipping to a target class.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Neuron importance for classification can be approximated without retraining via a lightweight linear probe trained on frozen [CLS] representations.
- **Mechanism:** Extract per‑layer [CLS] token activations from a held‑out dataset. Train a separate linear classifier (probe) on these representations to predict labels. The learned weight matrix (C classes × H hidden size × L layers) assigns each neuron a contribution score per class.
- **Core assumption:** Class‑relevant information in the model’s internal representations is approximately linearly separable at the [CLS] token, and probe weights reflect each neuron’s causal role in the decision.
- **Evidence anchors:**
  - [abstract] "extracts per-layer [CLS] representations, trains a lightweight linear probe to obtain global and per-class neuron rankings"
  - [section 4.1] "Linear Probe Training... is trained to be applied on top of the frozen [CLS] representations... Probe accuracy is a direct measure of how effectively the network has distilled input information into linearly separable patterns"
  - [corpus] Weak direct evidence; neighboring papers (e.g., "Sparse Neurons Carry Strong Signals...") use linear probing for neuron analysis but not in a unified, training‑free intervention framework. SYNAPSE’s specific integration with forward hooks is novel.
- **Break condition:** If the [CLS] representations are not linearly separable for the task (probe accuracy near random), the weight‑based rankings become unreliable for identifying functionally important neurons.

### Mechanism 2
- **Claim:** A single scalar importance score per neuron (global or class‑specific) can be derived from probe weights to rank neurons for targeted silencing.
- **Mechanism:** For **global ranking**, sum absolute weights across all classes for each neuron. For **class‑specific ranking**, take the absolute weight for that class. Top‑k neurons are selected based on these scores.
- **Core assumption:** Summing absolute weights (global) or taking per‑class absolute values yields a monotonic signal of a neuron’s functional contribution, and silencing neurons according to this order isolates degradation effects.
- **Evidence anchors:**
  - [section 4.2] "Global ranking: The importance of a neuron is defined as the sum of the absolute values of its weights across all classes... Class‑conditional ranking: The importance is defined by the absolute value of the weight assigned to a specific class c"
  - [section 6.1.1] Performance degradation curves (e.g., Figure 2, Table 5) show gradual drops as top‑k neurons are silenced, supporting that the ranking order correlates with functional importance.
  - [corpus] Assumption: Neighboring work (e.g., "What Language(s) Does Aya‑23 Think In?") uses similar absolute‑weight heuristics but does not validate their causal sufficiency for robustness prediction.
- **Break condition:** If neurons have opposing, cancelling contributions across classes (e.g., a neuron strongly positively weights class A but negatively weights class B), the absolute sum may misrepresent its net effect on overall accuracy. Class‑specific rankings remain valid for that class but may not generalize.

### Mechanism 3
- **Claim:** Inference‑time, reversible interventions on specific neurons can be applied non‑destructively across Transformer architectures via forward hooks, enabling controlled robustness evaluation.
- **Mechanism:** Register PyTorch forward hooks on targeted layers. During the forward pass, intercept the [CLS] activation tensor and set selected neuron dimensions (indices from rankings) to zero. Hooks are removed post‑inference, restoring original behavior without weight changes.
- **Core assumption:** Silencing a neuron’s activation at the [CLS] vector isolates its contribution to the final classification, and this effect is comparable across layers and models when scoped consistently (e.g., last‑layer only vs. all layers).
- **Evidence anchors:**
  - [abstract] "applies reversible, inference‑time interventions via forward hooks"
  - [section 4.3] "Silencing sets the activations of selected dimensions to zero in the encoder output during the forward pass. This process is non‑destructive and training‑free... hooks are used to silence targeted neurons"
  - [section 6] Empirical results show performance degradation proportional to silencing fraction (e.g., Table 5, Figure 3), confirming the intervention’s causal effect.
  - [corpus] Neighboring attack papers (e.g., "Model tampering attacks...") manipulate weights/logits but not via neuron‑level hooks; SYNAPSE’s hook‑based approach is presented as architecture‑agnostic.
- **Break condition:** If neurons exhibit high co‑activation or compensatory dynamics, silencing a ranked neuron might not reduce performance as expected because other neurons rapidly adapt within the same forward pass. Also, hooking different Transformer implementations (e.g., custom attention variants) may require adaptation.

## Foundational Learning
- **Concept: Transformer [CLS] token semantics**
  - Why needed here: SYNAPSE exclusively uses [CLS] token activations from each layer as a compressed, sequence‑level summary for neuron ranking and intervention. Understanding that [CLS] aggregates contextual information is key to why this reduction is feasible.
  - Quick check question: After each Transformer layer, what does the [CLS] hidden state represent about the input sequence, and why is it suitable for classification?
- **Concept: Linear probing as an attribution method**
  - Why needed here: The entire ranking pipeline assumes a linear probe’s weights can serve as a proxy for neuron importance. This requires understanding that probing tests for linear separability of concepts in representations.
  - Quick check question: If a linear probe trained on [CLS] activations achieves high accuracy, what does that imply about the information encoded in those representations?
- **Concept: PyTorch forward hooks for runtime modification**
  - Why needed here: All interventions (silencing, noise, weight edits) rely on registering hooks that modify tensors during the forward pass without altering model parameters. This is the technical enabling mechanism for training‑free analysis.
  - Quick check question: How does a forward hook registered on a specific module allow you to zero out particular dimensions of the [CLS] activation tensor during inference?

## Architecture Onboarding
### Component map
Explainability Block (activations extraction + probe training) -> Analysis Block (global/per-class ranking) -> Adversarial Block (forward hook intervention) -> Evaluation (metric computation) -> Cleanup (hook removal)

### Critical path
Activation extraction → probe training → ranking → intervention via hooks → evaluation → cleanup. The probe must be trained on a held‑out set (not test) to avoid ranking leakage.

### Design tradeoffs
- **[CLS]-only vs. token‑level:** [CLS] drastically reduces dimensionality and compute but discards token‑specific information. Token‑level analysis would capture finer‑grained patterns but be costly.
- **Linear probe vs. complex attribution:** Linear probe is fast, architecture‑agnostic, and interpretable, but may miss nonlinear neuron interactions. More complex probes (e.g., MLP) could improve ranking quality at the cost of training time and overfitting risk.
- **All‑layers vs. last‑layer only silencing:** All‑layer interventions test distributed robustness; last‑layer only isolates the final decision layer’s redundancy. The paper uses both (Eq. 1).

### Failure signatures
- Probe accuracy << baseline model accuracy → rankings are noise; interventions will not yield interpretable degradation curves.
- Global silencing causes near‑instant collapse (e.g., 5% silencing → F1≈0) → indicates extreme over‑specialization or ranking flaw (maybe probe overfitted).
- Per‑class silencing improves performance → suggests the probe misidentified “important” neurons that are actually suppressing other classes (possible if weights have opposite signs).
- Hooks do not trigger → intervention metrics identical to baseline → check hook registration logic and layer targeting.

### First 3 experiments
1. **Baseline recovery check:** Run full pipeline without any silencing. After all hooks are removed, re‑evaluate test set. F1 must match original model baseline exactly (within stochastic variation). This verifies no permanent state change.
2. **Global undirected silencing sweep:** Select top 5%, 10%, … 95% of globally ranked neurons. Silence them across all layers. Plot weighted F1 vs. silencing fraction. Expect gradual degradation if information is distributed (per paper’s main claim).
3. **Per‑class silencing on a known fragile class:** From Table 6 (malware), BigBird Class‑2 (TheTick) collapses to 0.000. Specifically: rank neurons for Class‑2, silence top 40% (as in Figure 3c). Verify that Class‑2 F1→0 while other classes remain stable. This confirms class‑specific vulnerability.

## Open Questions the Paper Calls Out
- **Question 1:** What is the role of token‑level neuron activations and attention mechanisms in the interpretability and robustness of Transformer models, beyond the [CLS]‑based analysis?
- **Question 2:** How do alternative neuron attribution methods (e.g., non‑linear probes, gradient‑based techniques) influence the importance rankings and the derived robustness conclusions in Transformer models?
- **Question 3:** Can neuron importance rankings from SYNAPSE be leveraged to create effective defense mechanisms that detect or mitigate targeted neuron‑level manipulations in real‑world deployments?
- **Question 4:** Does the observed pattern of distributed task‑relevant information and class‑specific neuron asymmetries generalize to multimodal Transformer architectures, such as vision‑language models?

## Limitations
- Probe training hyperparameters (solver, regularization, per‑layer vs. concatenated) are unspecified, making rankings sensitive and potentially unstable.
- Global neuron indexing and weight‑space attack details are ambiguous, hindering exact replication of neuron selection and attack implementation.
- The exclusive reliance on [CLS] token and linear probing may overlook nonlinear contributions and token‑level dynamics, limiting the framework’s generalizability to all tasks and architectures.

## Confidence
- **Mechanism 1** (linear probe as importance proxy): Medium.
- **Mechanism 2** (scalar ranking from absolute weights): Medium‑Low.
- **Mechanism 3** (forward hooks enable reversible intervention): High.

## Next Checks
1. **Probe hyperparameter sensitivity:** Train probes with multiple solvers and regularization strengths; compute rank correlation (Spearman’s ρ) between global rankings. Low correlation would indicate Mechanism 1 is brittle to unspecified details.
2. **Synthetic control test:** Build a small Transformer with a known set of task‑critical neurons. Run SYNAPSE and verify that silencing top‑ranked neurons (global and per‑class) causes predicted performance drops, confirming causal assumptions.
3. **Hook isolation test:** For a baseline model, install a hook that zeroes all [CLS] neurons except one random dimension. The model’s predictions should then be entirely determined by that neuron. Baseline must be fully recoverable after hook removal; failure indicates hook misplacement or leakage.
