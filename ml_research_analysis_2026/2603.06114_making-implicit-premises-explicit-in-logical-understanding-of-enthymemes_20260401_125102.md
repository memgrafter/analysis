# Making Implicit Premises Explicit in Logical Understanding of Enthymemes

## Quick Facts
- **arXiv ID:** 2603.06114  
- **Source URL:** https://arxiv.org/abs/2603.06114  
- **Reference count:** 40  
- **Primary result:** A neuro-symbolic pipeline that generates multi-step implicit premises via an LLM, translates text to propositional logic using AMR with neuro-relaxation, and uses a SAT solver to decode enthymemes, improving accuracy from 0.53 to 0.73 on ANLI and 0.29 to 0.56 on ARCT as steps increase.

## Executive Summary
The paper tackles the lack of a systematic method for translating textual enthymemes—arguments with missing premises—into logical form to assess entailment. It proposes a neuro-symbolic pipeline that first uses a large language model (LLM) to generate one to three intermediate implicit premises connecting an explicit premise to a claim. All text is then converted into propositional logic formulas via Abstract Meaning Representation (AMR) parsing. To handle semantic variability, word embeddings and a Natural Language Inference model provide a “neuro-relaxation” step that approximates logical equivalence and contradiction between atomic formulas. A SAT-based reasoner finally checks for entailment or contradiction. Evaluated on the ARCT and ANLI datasets, the approach shows clear improvements with more generated implicit steps, demonstrating the value of multi-step reasoning for enthymeme interpretation.

## Method Summary
The pipeline operates in sequence: given a (premise, claim) pair, an LLM (DeepSeek v3.2) is prompted to output `k` (1, 2, or 3) natural language statements that logically bridge the explicit premise and the claim. All texts—the explicit premise, generated implicit premises, and claim—are parsed into AMR graphs using the IBM Transition parser. Each AMR is translated into a grounded propositional formula (e.g., `arg0(want,boy)`) via an extended Bos algorithm, where existentially quantified variables are grounded to constants derived from node concepts. A relaxation engine then computes two relations over the atomic formulas: *neuro-matching* (`≃`) using embedding cosine similarity (BGE model) above a threshold `τ_m`, and *neuro-contradiction* (`⊥`) using NLI labels (mDeBERTa) and score threshold `τ_c`. These relations define a mapping `g` that merges matching atoms into the same propositional variable and maps contradictory atoms to complementary literals. The formulas are transformed via `g` into abstract CNF formulas, and a SAT solver (PySAT) checks entailment via unsatisfiability of `premises ∧ ¬claim` or contradiction via `premises ∧ claim`. No models are trained; the system uses frozen pretrained components and threshold tuning.

## Key Results
- Best F1-scores: ~0.75 on ANLI (3-step) and ~0.59 on ARCT (3-step) for the entailment class.
- Accuracy improves steadily with more implicit premise steps: from 0.53 to 0.73 on ANLI and from 0.29 to 0.56 on ARCT.
- Performance is highly sensitive to neuro-relaxation thresholds (`τ_m`, `τ_c`), with optimal values differing between datasets (e.g., `τ_m` ≈ 0.55 for ANLI vs. 0.65 for ARCT).

## Why This Works (Mechanism)
### Mechanism 1: Multi-step Implicit Premise Generation
Generating intermediate implicit premises via an LLM improves logical decoding by constructing a reasoning chain that bridges the explicit premise and claim. The LLM (DeepSeek v3.2) is prompted to produce one, two, or three helpful statements. The core assumption is that the LLM can generate premises that are *relevant* and *sufficient* to support the claim when combined with the explicit premise. Evidence: The pipeline design explicitly includes this step; experiments show accuracy increases with more steps. Break condition: If the LLM generates irrelevant, factually incorrect, or contradictory premises, the reasoning chain fails.

### Mechanism 2: Neuro-relaxed Logical Translation
Translating natural language to AMR graphs and then to propositional logic provides a formal representation. To overcome strict syntactic matching, neuro-relaxation uses word embeddings (BGE) to define a `≃` relation (similarity > `τ_m`) and an NLI model (mDeBERTa) to define a `⊥` relation (contradiction with score ≥ `τ_c`). These relations are used to construct a mapping `g` that merges or negates atoms across formulas. Core assumption: Semantic similarity and textual entailment/contradiction reliably indicate logical equivalence or negation for the purpose of entailment checking. Evidence: Section 3.3-3.4 defines these relations; threshold tuning experiments (Table 3, Figures 3-10) show their critical role. Break condition: If embeddings miss polysemy or NLI misjudges, the mapping `g` becomes unsound.

### Mechanism 3: SAT-based Decision on Relaxed Formulas
After applying mapping `g`, the abstract propositional formulas are converted to CNF. Entailment is checked by verifying unsatisfiability of `ϕ ∧ ¬ψ`; contradiction by `ϕ ∧ ψ`. Core assumption: The neuro-relaxed formula is a sound approximation of the original argument’s logical intent—if the relaxed formulas entail/contradict, the natural language argument should too. Evidence: Section 3.5 describes the SAT procedure; accuracy improvements with tuned thresholds support the approximation’s effectiveness on benchmark datasets. Break condition: Over- or under-aggressive relaxation thresholds cause false positives/negatives; the SAT solver is sound only for the given CNF representation.

## Foundational Learning
- **Concept: Abstract Meaning Representation (AMR)**  
  *Why needed:* AMR converts unstructured text into a semantic graph that can be deterministically translated into logical formulas. It captures predicate-argument structures but omits tense and articles, affecting grounding.  
  *Quick check:* Why might the AMR for “The boy does not want to go” contain nested negation, and how does this impact the final propositional formula?

- **Concept: Propositional Logic and SAT Solving**  
  *Why needed:* The final reasoning step reduces to checking satisfiability of a CNF formula. Understanding entailment as `ϕ ⊢ ψ` iff `ϕ ∧ ¬ψ` is unsatisfiable is fundamental.  
  *Quick check:* Given premises `P1 ∧ P2` and claim `C`, what exact CNF(s) would you pass to the SAT solver to test for entailment and for contradiction?

- **Concept: Neuro-Symbolic Relaxation**  
  *Why needed:* Pure exact matching of logical atoms is too brittle for natural language. This concept explains how embedding similarity (`≃`) and NLI (`⊥`) are used to create approximate logical identities and negations, enabling formula simplification.  
  *Quick check:* Given AMR atoms `arg0(walk,tiger)` and `arg0(move,tiger)`, what evidence from embeddings and NLI would cause them to be mapped to the same propositional variable under `g`?

## Architecture Onboarding
- **Component map:**  
  Input → LLM (DeepSeek v3.2) → AMR Parser (IBM Transition) → Translator (Extended Bos) → Relaxation Engine (Embeddings BGE + NLI mDeBERTa, with τ_m, τ_c) → Formula Translator (SymPy CNF) → SAT Reasoner (PySAT) → Output

- **Critical path:** The sequence from input through LLM generation, AMR parsing, translation, relaxation engine (thresholds critical), SAT solving.

- **Design tradeoffs:**  
  - **LLM cost vs. accuracy:** DeepSeek is effective but adds latency; simpler heuristics may be faster but less accurate.  
  - **Threshold tuning:** Optimal `τ_m`/`τ_c` vary by dataset; lower `τ_m` increases recall but risks false positives; lower `τ_c` increases contradiction sensitivity.  
  - **AMR parsing errors:** A single mis‑parse introduces incorrect atoms, cascading without validation.  
  - **Propositional grounding:** Grounding existentials to constants loses quantifier structure, an acknowledged simplification.

- **Failure signatures:**  
  - High sensitivity to `τ_m` (Figures 3,5-10).  
  - Large performance gap between ANLI (baseline 0.53) and ARCT (baseline 0.29), indicating ARCT’s implicit warrants are harder.  
  - Diminishing gains from 2 to 3 implicit steps, suggesting a practical limit to useful LLM‑generated steps.  
  - LLM may generate unhelpful chains, especially for formal enthymemes.

- **First 3 experiments:**  
  1. **AMR Parsing Sanity Check:** Manually verify core predicate-argument structures in 50 random (premise, claim) AMR pairs; error rate >15% would limit downstream performance.  
  2. **Neuro-Matching Calibration:** On a 100‑example dev set, sweep `τ_m` (with fixed `τ_c`=90) to find accuracy peak, then sweep `τ_c` at optimal `τ_m`. Reproduce reported optimal ranges (ANLI: `τ_m`≈0.55, `τ_c`=90; ARCT: `τ_m`≈0.65, `τ_c`=90).  
  3. **Implicit Premise Utility Ablation:** Compare accuracy across four conditions: (a) explicit only, (b) explicit + dataset’s original helpful premise, (c) explicit + LLM 1‑step, (d) explicit + LLM 3‑step. Isolate marginal gain from LLM generation beyond provided warrants.

## Open Questions the Paper Calls Out
- **Syntactic sugar for formula presentation:** How can syntactic sugar be integrated to make abstract propositional formulas more interpretable for non‑experts? (Section 6)  
- **Extended logical analyses:** What additional analyses (e.g., support types, relevance, similarity) can be automated using the neuro‑symbolic reasoner? (Section 6)  
- **Generalization to informal enthymemes:** How well does the pipeline perform on real‑world, informal enthymemes from social media or spoken dialogues? (Inferred from evaluation on curated datasets)  
- **Grounding existential quantifiers:** Does grounding AMR existential variables to specific constants compromise logical fidelity, and can alternative strategies improve accuracy? (Inferred from Section 2.2’s simplification)

## Limitations
- **Grounding ambiguity:** The exact mapping from AMR to propositional constants is underspecified; examples suggest deriving constants from argument concepts, but description is unclear.  
- **Template incompleteness:** Only a fragment of the 29 instantiation templates is provided; missing templates may weaken neuro‑relaxation.  
- **Threshold fragility:** Optimal thresholds are dataset‑specific; performance degrades sharply outside narrow ranges.  
- **LLM premise quality:** Generated implicit premises may be irrelevant or contradictory, especially for formal enthymemes (lower ARCT baseline).

## Confidence
- **Pipeline efficacy:** Medium – strong on ANLI, modest on ARCT; highly sensitive to hyperparameters and parser quality.  
- **Multi-step benefit:** Medium – clear improvement with steps, but diminishing returns and dataset dependency limit generalization.  
- **Neuro‑relaxation soundness:** Medium – embedding/NLI heuristics approximate logical equivalence/negation but lack formal guarantees; tuning is critical.
