# Multi-Level Embedding Conformer Framework for Bengali Automatic Speech Recognition

## Executive Summary
This paper tackles the challenge of building high-accuracy ASR for Bengali, a morphologically rich, low-resource language. The authors propose an end-to-end Conformer-CTC model enhanced with a multi-level embedding fusion mechanism. This mechanism integrates linguistic representations at the phoneme, syllable, and wordpiece levels directly into the acoustic encoder’s processing path. The model is trained on the 181-hour OpenSLR Bengali corpus with standard preprocessing and SpecAugment, significantly outperforming prior RNN and CNN-based systems.

## Method Summary
The framework uses a split Conformer encoder. The early encoder (12 blocks) processes acoustic features. Its output is fed in parallel into three separate branches—each designed to generate embeddings for one linguistic level (phoneme, syllable, wordpiece). These embeddings are fused (via element-wise sum) and then passed through a late Conformer encoder (24 blocks). The final encoder output feeds a CTC decoder. Training uses CTC loss, Adam optimizer (lr=1e-4), batch size 32, dropout 0.1, gradient clipping 5.0, and weight decay 1e-5 on an 80/10/10 train/validation/test split. ## Key Results
- Achieved 10.01% Word Error Rate (WER) and 5.03% Character Error Rate (CER) on full-sentence Bengali ASR.
- Demonstrated significant improvement over prior RNN and CNN-based approaches.
- Performance establishes a new state-of-the-art for Bengali ASR on the OpenSLR benchmark.

## Why This Works (Mechanism)
The core innovation is injecting multi-level linguistic structure (phonetic, syllabic, lexical) into the acoustic encoder. This allows the model to simultaneously capture fine-grained phonetic cues (crucial for Bengali’s phoneme inventory), morpho-syllabic patterns (addressing its agglutinative nature), and contextual word-level semantics. The fusion operation merges these complementary representations, enriching the encoder’s feature space. This approach is intended to counter the data scarcity and morphological complexity that typically degrade end-to-end ASR performance for Bengali.

## Architecture Onboarding
- **Component map:** Audio (Log-Mel) -> Early Conformer Encoder (12 blocks) -> Parallel [Phoneme Embedding Branch, Syllable Embedding Branch, Wordpiece Embedding Branch] -> Fusion (Element-wise Sum) -> Late Conformer Encoder (24 blocks) -> CTC Decoder -> Transcriptions
- **Critical path:** The acoustic features must pass through the early encoder before branching. The fusion must align all three embedding outputs dimensionally before summation. The fused vector then drives the late encoder’s contextual refinement.
- **Design tradeoffs:** Fusion simplicity (sum) vs. potential information loss; parallel branches increase parameter count but enable specialized linguistic processing; splitting the encoder adds depth but may increase training instability.
- **Failure signatures:** Shape mismatch errors at fusion (output dims from branches ≠ encoder dim); diverging training/validation loss indicating overfitting (check augmentation strength, dropout); poor token coverage from unsupervised BPE (verify vocabulary vs. train set OOV rate).
