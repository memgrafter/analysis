# Identifying Evidence-Based Nudges in Biomedical Literature with Large Language Models

## Quick Facts
- **arXiv ID:** 2602.10345
- **Source URL:** https://arxiv.org/abs/2602.10345
- **Reference count:** 40
- **Primary result:** A two-stage pipeline identifies evidence-based behavioral nudges from PubMed with 67.0% F1 and 72.0% recall (Title/Abstract/Intro), and achieves 100% precision at 12% recall via self-consistency.

## Executive Summary
The paper tackles the challenge of scaling the identification of evidence-based behavioral nudges in biomedical literature by introducing a hybrid filtering and large language model pipeline. The system first narrows PubMed’s 8+ million articles to ~81,000 candidates using lexical and semantic techniques. A fine-tuned LLM then classifies and extracts structured nudge metadata in a single pass. Evaluated on a 197-article test set, the approach achieves 67.0% F1 for discovery recall, with an optional high-precision mode trading recall for perfect accuracy. This infrastructure aims to ground AI-generated behavioral interventions (e.g., Agile Nudge+) in peer-reviewed evidence.

## Method Summary
The method uses a two-stage pipeline. Stage 1 applies hybrid filtering: candidate articles are scored via TF-IDF vectorization (unigrams/bigrams/trigrams) and cosine similarity against a reference vector built from behavioral science keyword lists, plus a heuristic "nudge-term bonus" that upweights documents containing key terms like "choice architecture." A threshold (0.12) reduces the corpus to ~81,000 candidates. Stage 2 uses OpenScholar (a LLaMA 3.1 8B variant fine-tuned on scientific text) to jointly classify nudge relevance and extract structured JSON metadata (e.g., nudge type, cognitive bias) from the title, abstract, and introduction. An optional self-consistency mechanism runs multiple high-temperature passes and aggregates by majority vote to boost precision.

## Key Results
- Best configuration (Title/Abstract/Intro input) achieves 67.0% F1 and 72.0% recall on the test set.
- Self-consistency (7 passes) yields 100% precision at 12% recall, enabling a high-trust mode.
- The system processes PubMed efficiently and is being integrated into the Agile Nudge+ platform.

## Why This Works (Mechanism)

**Mechanism 1: Hybrid filtering maintains broad recall while efficiently narrowing the corpus.**  
- **Claim:** The composite scoring (TF-IDF cosine similarity + nudge-term bonus) reduces 8M+ articles to ~81,000 candidates without losing most nudge-relevant literature.  
- **Mechanism:** Sparse lexical matching identifies semantic overlap with a behavioral science reference vector; the bonus explicitly upweights documents containing curated high-value terms (e.g., "default option") to compensate for TF-IDF’s term dilution.  
- **Core assumption:** Nudge-related articles, even if implicitly described, share lexical features with the keyword-derived reference vector.  
- **Evidence anchors:** Abstract and Section "Hybrid Filtering Stage" detail the TF-IDF parameters (`ngram_range=(1,3)`, `min_df=2`, `max_df=0.85`), bonus formula `bonus(d) = min(|Td|×0.1, 0.3)`, and threshold 0.12.  
- **Break condition:** Articles using highly novel or non-standard terminology not in the keyword lists may be missed; the bonus cap (0.3) might be insufficient for implicitly described nudges.

**Mechanism 2: A single-pass, instruction-tuned LLM accurately classifies and extracts structured nudge metadata.**  
- **Claim:** OpenScholar, prompted with strict inclusion/exclusion criteria, can interpret nuanced nudge definitions and output constrained JSON, achieving 67% F1 on truncated inputs.  
- **Mechanism:** The model is fine-tuned on scientific text and generates structured outputs in one forward pass, acting as a semantic reranker on the high-recall candidate set.  
- **Core assumption:** The model reliably distinguishes non-coercive choice-architecture interventions and maps them to a fixed taxonomy, despite inconsistent terminology.  
- **Evidence anchors:** Abstract and Section "LLM-Based Classification and Extraction" describe the prompt, criteria, and JSON schema; Section "Results" reports 67.0% F1 (Title/Abstract/Intro).  
- **Break condition:** Performance degrades with full-text input (recall drops to 51%) due to noise; the model hallucinates reasoning for false positives (e.g., misclassifying reviews) and fails on unconventional framings.

**Mechanism 3: Self-consistency voting trades recall for perfect precision.**  
- **Claim:** Sampling the LLM seven times per document and majority-voting suppresses random errors, yielding 100% precision at 12% recall.  
- **Mechanism:** Stochastic decodings assume consensus indicates correctness; inconsistent outputs are filtered out.  
- **Core assumption:** Incorrect labels are more likely to vary across high-temperature passes than correct ones.  
- **Evidence anchors:** Abstract and Section "Model Configurations" define self-consistency (`T=0.8`, 7 passes); Section "Results" Table 1 shows (Precision=1.00, Recall=0.12).  
- **Break condition:** Computationally expensive (7× cost); may still miss valid borderline cases that consistently misclassify; does not fix systematic biases.

## Foundational Learning
- **Concept: TF-IDF Vectorization and Cosine Similarity**  
  *Why needed here:* Enables semantic matching in Stage 1 against a behavioral science reference vector. Understanding `ngram_range`, `min_df`/`max_df`, and cosine similarity is key to grasping candidate scoring.  
  *Quick check:* Increasing `max_df` from 0.85 to 0.95 would likely **decrease** recall, as it excludes more frequent n-grams that might include important but common nudge-related terms (e.g., "intervention", "effect").

- **Concept: Instruction Tuning and Constrained JSON Generation**  
  *Why needed here:* The LLM must follow complex inclusion/exclusion rules and output a strict schema. Requires prompt engineering for structured outputs and validation (e.g., JSON parsing with retries).  
  *Quick check:* If `"nudge_types": []` is output for articles mentioning "default", potential causes are: (1) prompt examples omit "default" as a nudge type, or (2) the JSON schema’s allowed values list does not include "default".

- **Concept: Precision-Recall Trade-off in Information Retrieval**  
  *Why needed here:* The system’s value lies in tuning this curve via Stage 1 threshold and self-consistency. Discovery favors recall; high-trust applications favor precision.  
  *Quick check:* 100% precision at 12% recall is useful for constructing a gold-standard corpus because **false positives are extremely costly** in training downstream models, even if many relevant papers are missed.

## Architecture Onboarding
- **Component map:**  
  PubMed Open Access Corpus -> Stage 1 Filter (TF-IDF + cosine + bonus) -> Stage 2 Classifier (OpenScholar LLM) -> Post-Processor (self-consistency/orchestrator) -> Structured Output (Agile Nudge+ integration)

- **Critical path:**  
  Load article JSON → Compute hybrid score → If score ≥ 0.12, format prompt with title/abstract/intro → Run OpenScholar → Validate JSON → (Optional: 7 self-consistency passes + majority vote) → Store result.

- **Design tradeoffs:**  
  - Recall vs. Precision: Controlled by Stage 1 threshold (0.12) and self-consistency use. Lower threshold increases candidates and Stage 2 compute.  
  - Speed vs. Accuracy: Truncated inputs (Title/Abstract/Intro) are faster and higher recall than full-text; self-consistency multiplies latency by 7.  
  - Open-source vs. API: LLaMA 3.1 8B offers control/cost but lower performance than proprietary models (e.g., Gemini 2.5 Pro).

- **Failure signatures:**  
  - **High false positives:** Threshold too low; model misclassifies reviews or theoretical papers (see Appendix D errors).  
  - **High false negatives:** Keyword lists/bonus missing domain-specific terms (e.g., digital nudges like "gamification"); unusual phrasing.  
  - **JSON parse errors:** Malformed outputs exceeding retry limit; may need prompt tuning or parsing relaxation.

- **First 3 experiments:**  
  1. **Reproduce baseline:** Run Title/Abstract/Intro pipeline on 100-doc development set (from Appendix D examples) to verify ~67% F1 and ~81K candidate count.  
  2. **Input ablation:** Compare performance of Title-only, Title+Abstract, Title+Abstract+Intro, and Full Text on test set to confirm recall advantage of truncated context.  
  3. **Self-consistency cost/benefit:** Run `k=7` on 200 random positives; measure precision/recall gain vs. 7× compute time; check if voting eliminates review-article false positives.

## Open Questions the Paper Calls Out
1. **Full-text degradation causes:** Which sections (methods, discussion, etc.) in full-text articles introduce noise that reduces classification performance compared to truncated inputs?
2. **Refining inclusion criteria:** How can criteria be adjusted to capture nudges with non-standard terminology or embedded in broader interventions, without increasing false positives from reviews/theoretical papers?
3. **Optimal trade-off for RAG:** What precision-recall balance best populates a retrieval-augmented generation knowledge base for nudge design, and how do classifier errors propagate to LLM-generated nudge quality?
4. **Nudge-term bonus bias:** Does the heuristic bonus create terminological bias that excludes nudges described with novel or domain-agnostic language, and can this be mitigated cost-effectively?

## Limitations
- Exact PubMed subset version, TF-IDF implementation details (e.g., `max_features`, sparse matrix ops), and precise threshold tuning are unreported.
- OpenScholar fine-tuning dataset, hyperparameters, and deployment optimizations (e.g., batching) are undisclosed, hindering replication.
- Test set (N=197) is unreleased, preventing independent verification.
- Documented failure modes include false positives on review/system papers and false negatives on digital/niche nudges.

## Confidence
- **Hybrid filtering recall/efficiency:** Medium – mechanism clear, but missing parameters directly impact candidate yield.
- **LLM classification F1/recall (67.0%/72.0%):** High – results on labeled test set, though generalizability beyond biomedical text unclear.
- **Self-consistency precision-recall (100% precision @12% recall):** High – empirical numbers provided and mechanism straightforward.
