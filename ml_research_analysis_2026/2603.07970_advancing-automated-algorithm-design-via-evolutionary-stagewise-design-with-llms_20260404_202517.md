# Advancing Automated Algorithm Design via Evolutionary Stagewise Design with LLMs
## Quick Facts
- arXiv ID: 2603.07970
- Source URL: https://arxiv.org/abs/2603.07970
- Reference count: 40
- Primary result: EvoStage achieved SOTA half-perimeter wire-length on open-source chip placement benchmarks within 25 evaluations and improved commercial 3D chip tool metrics by 9.24% HPWL reduction.

## Executive Summary
EvoStage introduces a stagewise evolutionary framework leveraging LLMs to automate algorithm design, overcoming black-box limitations through sequential stages with real-time feedback and a multi-agent system for search space reduction. Applied to chip placement and Bayesian optimization, it demonstrates significant improvements over baselines with remarkably few evaluations, though reproducibility and generalizability remain open.

## Method Summary
The method decomposes algorithm design into discrete stages where an LLM-based multi-agent system generates candidate solutions evaluated in real-time. Feedback from each stage refines subsequent stages, while a global-local balancing mechanism mitigates local optima. This structured approach reduces the design space and guides evolution efficiently.

## Key Results
- SOTA HPWL results on all open-source chip placement benchmarks with only 25 evaluations.
- Commercial 3D chip tool: 9.24% HPWL improvement and 52.21% reduction in optimization iterations.
- Bayesian optimization acquisition functions: designs with significantly lower optimal gaps and up to 100% pass rate, surpassing experts and other LLM methods.

## Why This Works (Mechanism)
EvoStage overcomes LLM black-box limitations by introducing stagewise decomposition, which allows intermediate feedback to steer the design process. The multi-agent system narrows the search space by exploring diverse solutions, while the global-local balance ensures both exploration and refinement, preventing convergence to suboptimal designs.

## Architecture Onboarding
Component map: Stage Manager → Multi-Agent Generator → Evaluator → Feedback → Stage Manager (next stage) → Final Design
Critical path: Initialize stages → For each stage: agents generate candidates → evaluate → provide feedback → update stage → until termination.
Design tradeoffs: More stages increase granularity but cost; agent diversity improves coverage but increases evaluations; feedback richness guides better but may cause overfitting.
Failure signatures: Stagnant improvement across stages, inconsistent agent outputs, feedback ignored in subsequent stages.
First experiments: 1) Compare single-stage vs. multi-stage performance; 2) Ablate multi-agent to use single LLM; 3) Vary feedback frequency (every eval vs. per stage).

## Open Questions the Paper Calls Out
- **Reproducibility**: The paper does not release code or hyperparameter details, making replication challenging.
- **Generalizability**: It remains unclear whether EvoStage can be effectively applied to problem domains beyond chip placement and Bayesian optimization.
- **Robustness**: Results are based on a single run with only 25 evaluations; stability across different random seeds and evaluation budgets is an open question.
- **Independent Verification**: The commercial tool improvements are claimed but not independently verified.
- **Scalability**: How does the method perform as problem size or algorithm space complexity increases?

## Limitations
- Lack of code and hyperparameter details hinders reproducibility.
- Results based on single runs with only 25 evaluations may not be robust.
- Generalizability beyond chip placement and Bayesian optimization is unclear; commercial tool improvements not independently verifiable.
