# Map of Encoders -- Mapping Sentence Encoders using Quantum Relative Entropy
## Quick Facts
- **arXiv ID:** 2602.08740  
- **Source URL:** https://arxiv.org/abs/2602.08740  
- **Reference count:** 40  
- **Primary result:** A method using Quantum Relative Entropy (QRE) on PIP matrices creates feature vectors for 1101 sentence encoders, enabling a 2D t-SNE map that clusters by architecture/task/size and predicts downstream MTEB performance with Spearman correlation >0.8.

## Executive Summary
This paper introduces a universal framework to compare and map diverse sentence encoders by representing each with a fixed-size feature vector derived from Quantum Relative Entropy (QRE). The representation is built from Pairwise Inner Product (PIP) matrices computed on a shared sentence set, making it invariant to embedding dimensionality. Projecting these vectors via t-SNE reveals clusters corresponding to encoder architectures, training objectives, and parameter counts. Critically, the feature vectors strongly correlate with downstream task performance on the Massive Text Embedding Benchmark (MTEB), suggesting the map captures functionally relevant geometric properties of embedding spaces.

## Method Summary
For each of 1101 sentence encoders, a fixed set of 10,000 English sentences is embedded to form matrix **A**. From **A**, the PIP matrix **G** = **A** **A**ᵀ is computed efficiently via SVD, capturing pairwise cosine similarities. **G** is normalized to a density matrix **ρ**. A synthetic "unit base encoder" **ρ**⁰ = (1/**N**) **I** serves as a common reference. QRE between **ρ**⁰ and **ρ** approximates their divergence using Theorem 1 (adding a tiny noise ε to null spaces) and yields an **N**-dimensional feature vector **ϕ** per encoder. These vectors are compared with ℓ₁ distance for t-SNE visualization and nearest-neighbor search, and after PCA reduction, predict MTEB scores via ElasticNetCV.

## Key Results
- Mapped 1101 sentence encoders in a single 2D t-SNE space, showing clear grouping by architecture (e.g., Transformer variants), training task (e.g., contrastive vs. masked), and parameter scale.
- Feature vectors predict MTEB retrieval and clustering task scores with Spearman correlation >0.8, validating that the QRE-based representation encodes downstream utility.
- Nearest-neighbor analysis confirms that fine-tuned versions of the same model cluster together, and synthetic experiments demonstrate sensitivity to embedding space geometry.

## Why This Works (Mechanism)
### Mechanism 1: Pairwise Inner Product (PIP) Matrices as Dimensionality-Free Geometry
- **Claim:** PIP matrices provide a representation of an encoder's embedding space geometry that is independent of output dimensionality.
- **Mechanism:** For a fixed sentence set, the embedding matrix **A** yields **G** = **A** **A**ᵀ. Its eigenspace (squared singular values of **A**) encodes all pairwise relationships. Since **G** is always **N**×**N**, it allows comparison across encoders with different **d**.
- **Core assumption:** The fixed sentence set **S** is sufficiently semantically diverse to elicit each encoder's full relational structure.
- **Evidence anchors:** 
  - Abstract states PIP matrices represent all encoders in the same **N**×**N** space.
  - Section 3.1 formalizes the invariance.
- **Break condition:** An unrepresentative or too-small **S** yields a PIP matrix that does not capture the encoder's true geometry.

### Mechanism 2: Quantum Relative Entropy as Invariant Divergence
- **Claim:** QRE between density matrices derived from PIP matrices offers a scale, rotation, and translation-invariant measure for comparing encoders.
- **Mechanism:** Normalized PIP **ρ** is a density matrix. QRE S(**ρ**⁰∥**ρ**) = Tr(**ρ** ln **ρ**)−Tr(**ρ** ln **ρ**⁰) compares eigenspaces. Theorem 1 approximates QRE when eigenspaces misalign by injecting noise ε into the null space of **ρ**, making the divergence finite and differentiable.
- **Core assumption:** The spectral decomposition captures semantic relational structure, and the chosen ε (e⁻¹²) adequately approximates information loss.
- **Evidence anchors:**
  - Abstract and Section 3.2 derive QRE and Theorem 1.
  - Corpus: theoretical support from quantum information theory and quantum NLP literature.
- **Break condition:** Drastically different eigenspaces (e.g., syntax vs. semantics focus) may cause the approximation to overestimate divergence or require ε tuning.

### Mechanism 3: Unit Base Encoder as Unbiased Reference
- **Claim:** A synthetic isotropic base encoder **ρ**⁰ = (1/**N**) **I** provides a uniform coordinate system to project all target encoders into a common feature space.
- **Mechanism:** Each encoder's QRE S(**ρ**⁰∥**ρ**ᵐ) is decomposed into an **N**-dimensional vector **ϕ**ᵐ, where each dimension corresponds to a basis direction of **ρ**⁰. This yields a fixed reference frame.
- **Core assumption:** The isotropic eigenspace is complete and orthonormal, so no existing encoder biases the projection.
- **Evidence anchors:**
  - Section 3.3 defines **ρ**⁰ and derives **ϕ**.
  - This is an original design choice; no direct prior evidence.
- **Break condition:** If **N** is small, the base encoder's eigenspace may be too coarse, losing nuances in the projection.

## Foundational Learning
- **Linear Algebra (Eigendecomposition, PSD Matrices)**  
  *Why needed here:* PIP and density matrices are positive semi-definite; their eigenvalues/eigenvectors define geometric structure. QRE requires spectral decomposition.  
  *Quick check question:* Given PSD **G** = **A** **A**ᵀ, what is the relationship between its non-zero eigenvalues and the singular values of **A**?

- **Information Theory (Relative Entropy, Von Neumann Entropy)**  
  *Why needed here:* QRE generalizes KL divergence to density matrices, quantifying information loss when one encoder’s geometry approximates another’s.  
  *Quick check question:* How does von Neumann entropy −Tr(**ρ** ln **ρ**) differ from Shannon entropy for a probability distribution?

- **Manifold Learning (t-SNE)**  
  *Why needed here:* High-dimensional **ϕ** vectors (size **N**=10,000) are projected to 2D for visualization while preserving local and global structure.  
  *Quick check question:* What does t-SNE minimize to embed high-dimensional data into low dimensions?

## Architecture Onboarding
**Component map**  
Sentence Set → Embedding Extraction → PIP Matrix → Density Matrix → Unit Base Encoder → Feature Vector → Projection (t-SNE/nearest neighbors)

**Critical path**  
1. Fix sentence set **S** (10,000 English sentences).  
2. For each encoder, encode **S** → **A** (**N**×**d**) and compute SVD to obtain **G**’s eigenspace implicitly.  
3. Normalize **G** → **ρ** and compute QRE w.r.t. **ρ**⁰ using Theorem 1 with noise ε.  
4. Derive **ϕ** (size **N**) and use ℓ₁ distances for downstream mapping.

**Design tradeoffs**  
- *Sentence set size **N**:* Larger **N** improves representativeness but increases SVD cost (∝ **N** **d**). Paper shows **N**=2,500 saturates MTEB correlation.  
- *Noise parameter ε:* Too large washes out signal; too small causes numerical instability. Fixed to e⁻¹² empirically.  
- *Dimensionality reduction:* PCA to 50D before ElasticNetCV avoids overfitting with **N**=10,000 features vs. only 112 labeled encoders.

**Failure signatures**  
- Encoders with similar architectures appear far apart → PIP miscomputation (check SVD tolerance) or inadequate sentence set.  
- Low MTEB prediction correlation (<0.8) → feature vectors may not capture task-relevant geometry; verify QRE calculation and ε.  
- t-SNE shows no known attribute clustering → revisit sentence diversity or feature normalization.

**First 3 experiments**  
1. Synthetic validation: generate embeddings with controlled noise; map should separate low-noise from high-noise groups.  
2. Nearest neighbor inspection: for each encoder, top-ℓ₁ neighbors should include its fine-tuned variants.  
3. MTEB correlation: ElasticNetCV (5-fold) on PCA-reduced **ϕ** predicts retrieval/clustering scores; expect Spearman >0.8.

## Open Questions the Paper Calls Out
- How does using a multilingual sentence set instead of an English-only set affect the map’s accuracy and groupings for multilingual encoders? The current English set may distort relationships for non-English models.
- How would incorporating encoders for low-resource languages change the map’s structure and attribute correlations? Selection based on popularity likely excludes many low-resource models, introducing bias.
- Can the QRE-based method be adapted to map cross-encoders (which require sentence pairs), and how would they integrate with single-sentence encoders? The method currently assumes single-sentence inputs.

## Limitations
- The exact 10,000-sentence set is undisclosed; random sampling may alter PIP matrices and map stability.
- MTEB scores are not provided; leaderboard values drift over time and model checkpoints are unpinned, hindering exact replication.
- Critical hyperparameters (t-SNE perplexity/learning rate, SVD tolerance, ElasticNetCV α grid) are unspecified, requiring empirical tuning.
- Computational cost of SVD for 1,101 encoders with **N**=10,000 and **d** up to 4,096 is substantial (~500 MiB/encoder), limiting accessibility.

## Confidence
- **QRE feature vector dimensionality-independent representation:** Medium (theoretically solid but sensitive to ε and sentence coverage).  
- **t-SNE map clusters encoders by architecture/task/size:** Medium (empirical evidence shown, but depends on unstated t-SNE settings and sentence set).  
- **Feature vectors predict downstream performance (Spearman >0.8):** Medium (cross-validated results strong, but lack of raw scores and leaderboard variability introduce uncertainty).

## Next Checks
1. **Sentence set stability:** Sample an alternative 10k set from the same corpus, recompute the full map (PIP, QRE, t-SNE), and quantify cluster consistency (e.g., adjusted Rand index) versus the original.
2. **MTEB prediction replication:** Archive current MTEB scores for the 112 models (e.g., via Hugging Face snapshot) and rerun the ElasticNetCV (PCA‑50, 5‑fold) pipeline to confirm Spearman >0.8 on retrieval/clustering tasks.
3. **Ablation of ε and N:** For a representative encoder subset, vary ε (1e‑6, 1e‑12, 1e‑18) and **N** (2,500, 5,000, 10,000); assess impacts on feature vector ℓ₁ distances and downstream prediction correlation to establish robustness boundaries.
