# Datasets for Verb Alternations across Languages: BLM Templates and Data Augmentation Strategies

## Quick Facts
- arXiv ID: 2603.15295
- Source URL: https://arxiv.org/abs/2603.15295
- Reference count: 0
- Primary result: Curated BLM datasets enable diagnostic evaluation of cross-sentence verb alternation knowledge across four languages, revealing that models learn sequential patterns but struggle with syntax-semantic role mappings.

## Executive Summary
This paper introduces the Blackbird Language Matrices (BLM) datasets to probe how language models understand verb alternations across English, Italian, German, and Hebrew. The BLM task presents structured sentence sequences where models must identify the correct continuation based on underlying alternation patterns. Three template types of increasing complexity test different aspects of linguistic generalization: peripheral cues, linguistic diagnostics, and mixed patterns. The study also compares synthetic data generation (masking, prompting) with natural corpus extraction. Baseline evaluations using a feed-forward network with Electra embeddings show English performs best, while German is sensitive to case marking and Hebrew monolingual models excel on natural data. Error analysis reveals models generally learn the sequential structure but frequently commit syntax-semantic role mapping errors.

## Method Summary
The authors create BLM datasets for four languages, each containing template instances with context sentences and an answer set. Templates are categorized into three types: Type A uses peripheral cues (like temporal phrases) to signal pattern continuation; Type B employs linguistic diagnostics (e.g., relative clauses) to highlight thematic role mappings; Type C mixes both. Data is collected via three augmentation strategies: masking (synthetic), LLM prompting (synthetic), and extraction from Universal Dependencies treebanks (natural). The evaluation uses a baseline architecture: sentences are encoded using a frozen Electra model, context embeddings are stacked, and a feed-forward neural network with max-margin loss learns to select the correct answer by cosine similarity. Performance is measured by F1 score, and errors are classified as either sequence errors (wrong pattern order) or grammar errors (incorrect syntax-semantic mapping).

## Key Results
- English consistently achieves the highest F1 scores (up to 0.983), while Italian, German, and Hebrew show lower performance, with German sensitive to case marking ambiguities.
- Models primarily commit grammar errors involving syntax-semantic mismatches, such as misinterpreting intransitive subjects as agents for change-of-state verbs.
- For Hebrew, the monolingual model outperforms the multilingual model on natural data but performs similarly on synthetic data, indicating an interaction between data naturalness and model linguistic specialization.

## Why This Works (Mechanism)
1. **Peripheral Cues Enable Superficial Pattern Learning**: Type A templates include extraneous but predictable elements (e.g., temporal phrases). Models exploit these surface regularities to select the correct continuation without understanding the alternation itself. Evidence: High sequence error rates and the fact that models learn the "Sequence pattern of the BLM" (section 5). Break condition: Removing the cue should drop performance.
2. **Linguistic Diagnostics Force Abstract Role Mapping**: Type B templates use constructions like relative clauses to explicitly encode thematic roles. The model must then preserve the correct mapping between syntactic positions and semantic roles as dictated by the alternation rule. Evidence: The dominant error type is syntax-semantic mismatches, suggesting difficulty with this mapping (section 5). Break condition: Replacing diagnostics with neutral structures should degrade performance to Type A levels.
3. **Data Modality Affects Cross-Linguistic Transfer**: Synthetic data (masking, prompting) provides clean control but may introduce biases; natural corpus data offers authentic usage but is limited. The interaction with model type (monolingual vs. multilingual) determines generalization. Evidence: Hebrew monolingual model outperforms multilingual on natural data but not synthetic. Break condition: Swapping data sources would invert performance hierarchy.

## Foundational Learning
- **Paradigmatic Generalization**: The BLM requires recognizing a pattern across a paradigm of verb forms (e.g., transitive/intransitive pairs). Quick check: Given "The vase broke" and "The artist broke the vase," what missing variant completes the change-of-state alternation?
- **Syntax-Semantic Interface Mapping**: Alternations govern how thematic roles (Agent, Patient) map to syntactic positions (Subject, Object). Quick check: In "The vase broke," what is the thematic role of "The vase" and its syntactic position?
- **Morphological Bootstrapping**: For case-marked languages like German, case morphology disambiguates syntactic roles. Quick check: How does case marking help distinguish the subject in "Der Becher zerbrach" vs. "Der Künstler zerbrach den Becher"?

## Architecture Onboarding
- **Component map**: BLM Template Instance -> Sentence Encoder (Electra/AlephBERT) -> Context Stacking -> Feed-Forward Neural Network -> Scoring & Selection -> Prediction.
- **Critical path**: Data Preparation -> Template Instantiation -> Sentence Embedding Extraction -> FFNN Training -> Evaluation -> Error Analysis.
- **Design tradeoffs**: The FFNN simplicity vs. expressiveness; static embeddings isolate encoded knowledge but limit peak performance; synthetic vs. natural data tradeoff.
- **Failure signatures**: High Sequence Error Rate indicates failure to learn templatic ordering; High Grammar Error Rate (syntax-semantic) indicates failure at core rule; Language-specific collapse (German Mix vs Case); Synthetic vs Natural divergence (Hebrew).
- **First 3 experiments**:
  1. Establish baseline F1 on a single dataset (e.g., En-COS+MinLex) to show task learnability.
  2. Error analysis breakdown on the same test set, categorizing errors into Sequence and Grammar sub-types.
  3. Cross-linguistic comparison across comparable datasets (En, It, De) to demonstrate impact of morphology.

## Open Questions the Paper Calls Out
1. How do modern large language models (e.g., GPT-4, LLaMA) perform on BLM datasets compared to the baseline feed-forward network?
2. How does the performance of monolingual versus multilingual models on BLM tasks vary across languages, given the divergent results observed for Hebrew?
3. How do the three BLM template types (A, B, C) differentially require analogical, abductive, or systematic reasoning from models, and what do performance differences across them reveal about the nature of linguistic generalization in LLMs?
4. Why do models primarily commit syntax-semantic interface errors (e.g., misinterpreting the subject of an intransitive as an agent rather than a patient), and what architectural or training modifications could mitigate these errors?

## Limitations
- The paper's conclusions rely on mechanisms that were not fully tested via break conditions (e.g., cue ablation, diagnostic neutralization, data source swap).
- All claims are based on a static FFNN probe with frozen embeddings, which may not generalize to modern LLMs with different architectures.
- The Hebrew monolingual vs. multilingual comparison is correlational and limited to one language pair.

## Confidence
- Mechanism 1 (Peripheral Cues): Medium. Supported by error patterns but untested ablation.
- Mechanism 2 (Linguistic Diagnostics): Medium. Grammar errors align but confounded with cue presence.
- Mechanism 3 (Data Modality): Low. Hebrew comparison correlational, causal inference weak.

## Next Checks
1. Perform cue ablation on Type A templates by removing or randomizing the peripheral temporal phrase to test reliance on superficial cues.
2. Neutralize diagnostics in Type B templates by replacing relative clauses with syntactically equivalent but thematically neutral structures to confirm necessity for abstract mapping.
3. Conduct data modality swap for Hebrew: train monolingual and multilingual models exclusively on either synthetic or natural BLM data and cross-evaluate to establish causality.
