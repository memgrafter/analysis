# Local Urysohn Width: A Topological Complexity Measure for Classification
## Quick Facts
- **ArXiv ID:** 2603.15412
- **Source URL:** https://arxiv.org/abs/2603.15412
- **Reference count:** 40
- **Primary result:** Introduces local Urysohn width, a topological‑geometric complexity measure for classification tasks, proving a strict hierarchy, a scaling law, a two‑way separation from VC dimension, and a sample complexity lower bound.

## Executive Summary
The paper introduces the *local Urysohn width*, a new complexity measure for classification problems defined on metric spaces. Unlike VC dimension, which quantifies the expressive power of a hypothesis class, local Urysohn width captures the intrinsic topological‑geometric complexity of the problem itself: it is the minimum number of connected, diameter‑bounded “local experts” required to correctly classify a margin‑safe region. The authors establish four core results: a strict hierarchy theorem showing that on a bouquet of circles the width equals the first Betti number; a scaling law factorizing width into a topological factor (β₁) and a geometric factor (L/D₀); a two‑way separation from VC dimension; and an Ω(w log w) sample complexity lower bound independent of VC. These findings suggest that the effective “width” of a classifier must grow with the topological complexity of the data manifold, providing a fresh perspective on neural network design and continual learning.

## Method Summary
The local Urysohn width \( uw_{D_0}(P,\gamma) \) is defined for a margin‑γ classification problem on a metric space. A \((\gamma,D_0)\)‑Urysohn covering consists of local Urysohn triples \((S,U,f)\) where \(S\) is connected, \(\text{diam}(S)\le D_0\), \(U\supseteq S\) is open, and \(f:U\to\{0,1\}\) is continuous and correctly classifies all points in a safe ball (a ball where the true label is constant and separated from the opposite class by at least γ). The width is the smallest number of such triples that cover the entire safe region. The authors prove their main results by constructing explicit families of spaces (e.g., bouquets of circles, interval unions) and analyzing combinatorial covering constraints. For a bouquet of \(w\) circles, they show that with suitable parameters each safe ball lies on a distinct loop, forcing at least \(w\) patches; the safe balls themselves form a valid covering, yielding equality. For multiple safe regions per loop, spacing arguments produce a lower bound scaling as \(w\cdot L/D_0\). The separation from VC dimension is achieved by tailoring hypothesis classes where either the topological layout forces many patches (high width, low VC) or a single complex region forces many labelings (high VC, low width). The sample complexity lower bound follows via a coupon‑collector argument.

## Key Results
- **Strict hierarchy:** On a bouquet of \(w\) circles (\(\beta_1 = w\)), \(uw_{D_0} = w\) for \(3\gamma/2 \le D_0 < L/2 - 3\gamma/4\).
- **Scaling law:** width \(\ge \Omega(w \cdot L/D_0)\), factorizing topological loops and geometric resolution.
- **Separation from VC:** Families exist where width grows while VC is bounded, and vice versa.
- **Sample complexity:** Any algorithm learning a width‑\(w\) problem needs \(\Omega(w \log w)\) samples.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** The local Urysohn width scales with the first Betti number (β₁) of the input space, meaning topological complexity (number of independent loops) forces a minimum number of local experts.
- **Mechanism:** On a connected space with non‑trivial topology (e.g., a bouquet of circles), each margin‑safe region anchored to a distinct topological loop (antipodal safe ball) is separated from others by a distance larger than the locality scale \(D_0\). This metric confinement ensures any connected patch of diameter ≤ \(D_0\) can intersect at most one safe region, necessitating at least one expert per loop.
- **Core assumption:** The locality scale \(D_0\) is smaller than the minimal separation between safe regions on different loops, which requires the loops to be “macroscopic” relative to the margin (\(L > 9\gamma/2\)).
- **Evidence anchors:**
  - [abstract] “strict hierarchy theorem… on a bouquet of circles… width is exactly w = β₁”
  - [section 4] Theorem 4.1 proof: distance from safe ball to wedge point forces patch confinement to single loop
  - [corpus] Neighbor “Leveraging the Urysohn Lemma…” uses Urysohn for separation but does not address width; weak direct support for mechanism.
- **Break condition:** If \(D_0 \ge L/2 - 3\gamma/4\), a single patch could cover safe regions on multiple loops, collapsing width to 1. Topology becomes invisible at coarse resolution.

### Mechanism 2
- **Claim:** Local Urysohn width factorizes multiplicatively into a topological factor (β₁) and a geometric resolution factor (\(\times L/D_0\)), meaning both topology and metric scale independently determine complexity.
- **Mechanism:** Within each topologically independent loop, multiple safe regions may exist. If safe regions on the same loop are spaced farther apart than \(D_0\), each requires a distinct patch. The number of patches per loop scales with loop circumference divided by \(D_0\). Since loops are independent (different loops require different patches), total width multiplies: (number of loops) × (patches per loop).
- **Core assumption:** Safe regions are placed with sufficient spacing along each loop (\(L/m > 3\gamma\)) and patches are constrained by diameter ≤ \(D_0\).
- **Evidence anchors:**
  - [abstract] “topology × geometry scaling law: width scales as Ω(w·L/D₀)”
  - [section 5.1] Corollary 5.1 proof for \(P_{w,m}\): spacing between safe regions on same loop > \(D_0\), and separation between loops > \(D_0\) → wm distinct patches needed.
  - [corpus] Neighbor “Dimensionality reduction and width…” links topological dimension to network width but does not establish this multiplicative factorization; weak support.
- **Break condition:** If \(D_0\) is so large that a single patch can cover multiple safe regions on the same loop (\(D_0 \ge L/(2m) - 3\gamma/2\)), the geometric factor collapses. The factorization requires \(D_0\) to be finer than the safe region spacing.

### Mechanism 3
- **Claim:** Urysohn width and VC dimension measure orthogonal aspects of classification difficulty; neither implies the other.
- **Mechanism:** VC dimension measures the expressive power of a hypothesis class (how many labelings it can realize). Urysohn width measures the structural coverage needed on the problem space itself. The Urysohn‑Brouwer (Tietze) extension theorem implies that, for continuous function classes, any locally consistent labeling extends globally, so expressiveness is not the bottleneck. The bottleneck is how many disconnected‑by‑locality regions must be covered, which VC dimension does not see.
- **Core assumption:** The hypothesis class considered is rich enough to extend locally correct labelings (e.g., all continuous functions, or patchwise‑constant functions with sufficient patches). The separation constructions exploit that VC can be high on a single complex region (low width) or low across many simple disjoint regions (high width).
- **Evidence anchors:**
  - [abstract] “two‑way separation from VC dimension”
  - [section 6] Theorem 6.1: Part (a) bouquet family has width \(w\) but VC(\(O(w \log w)\)) for a natural patchwise‑constant class; Part (b) interval unions have VC \(2n\) but width 1.
  - [section 6] Discussion of Urysohn‑Brouwer lemma making global expressiveness trivial.
- **Break condition:** If the hypothesis class is severely restricted (e.g., only linear classifiers), both VC and width may be low simultaneously, but the separation is about the existence of families where they diverge. The mechanism relies on the ability to define problem families where topology creates many contexts but local classification is trivial (bouquet), or one context is complex but single (interval unions).

## Foundational Learning
- **Concept: Margin‑safe region (\(A^{\gamma/2}_k\))**
  - **Why needed here:** The Urysohn width is defined only over the margin‑safe region, a subset where classification must be correct and classes are separated by at least \(\gamma\). This excludes boundary regions and makes the problem well‑posed.
  - **Quick check question:** How does increasing \(\gamma\) affect the size of \(\text{Safe}(P,\gamma)\) and potentially the required width?

- **Concept: Local Urysohn triple \((S, U, f)\)**
  - **Why needed here:** This is the primitive unit of the Urysohn Machine. The constraints—connected support \(S\), diameter ≤ \(D_0\), continuous separator \(f\)—enforce locality and prevent a single global separator from collapsing width to 1.
  - **Quick check question:** Why would removing the connectedness or diameter constraint make \(uw_{D_0}(P,\gamma) = 1\) for any margin‑\(\gamma\) problem?

- **Concept: First Betti number (\(\beta_1\))**
  - **Why needed here:** \(\beta_1\) counts independent 1‑dimensional cycles (loops). The hierarchy theorem shows \(uw = \beta_1\) on bouquets, linking topological complexity directly to classifier complexity.
  - **Quick check question:** What does \(\beta_1 = 0\) imply about the connectivity structure of \(X\), and what might that mean for potential width?

- **Concept: Urysohn Machine (UM)**
  - **Why needed here:** The UM provides the computational model that motivates width as a resource measure (library size). Its operations (Evaluate, Detect, Construct) map to metric classification and topological indexing.
  - **Quick check question:** What UM operation corresponds to discovering a new topological context, and how does width relate to the frequency of that operation?

- **Concept: Metric‑Topology Factorization**
  - **Why needed here:** The scaling law \(uw \ge \Omega(\beta_1 \cdot L/D_0)\) suggests optimal classifiers should decouple topological routing (\(\beta_1\) contexts) from metric classification (\(L/D_0\) patches per context). This is an architectural principle for complex spaces.
  - **Quick check question:** If \(\beta_1\) doubles while \(L/D_0\) halves, what happens to the width, and what does that say about the relative difficulty of the two factors?

## Architecture Onboarding
- **Component map:**
  - **Metric Library (M):** Finite set of local Urysohn triples \(\{(S_i, U, f_i)\}\). Each triple is a frozen local expert.
  - **Detect (D):** Given input \(x\), checks if \(x \in \bigcup_i S_i\). If not, raises alarm → triggers Construct.
  - **Evaluate (E):** If \(x \in S_i\), apply \(f_i(x)\) to get label.
  - **Construct (T):** When alarm fires, create a new triple for the novel region (new \(S\), \(U\), \(f\)) and add to \(M\). Never modify existing triples.

- **Critical path:**
  1. **Detect phase:** Determine if input is covered by existing library. This is topological indexing: which context (loop/region) does \(x\) belong to?
  2. **Evaluate phase:** Apply the local separator for that context. This is metric classification within the identified patch.
  3. **Construct phase:** If uncovered, allocate a new expert and freeze it. This increases library size (width) monotonically.

- **Design tradeoffs:**
  - **\(D_0\) selection:** Smaller \(D_0\) increases potential width but ensures finer geometric resolution. Larger \(D_0\) risks merging topologically distinct regions. Must satisfy \(3\gamma/2 \le D_0 < L/2 - 3\gamma/4\) for bouquet to achieve \(uw = \beta_1\).
  - **Library growth:** In continual learning, new contexts require new experts (width increases). Reusing or modifying old experts causes catastrophic interference (routing drift).
  - **Indexing mechanism:** The Detect operator must be gradient‑free and based on topological features (e.g., homotopy class, systole distance). End‑to‑end differentiable routing fails because gradients from new contexts corrupt old routing decisions.

- **Failure signatures:**
  - **Under‑coverage:** Library size \(< uw_{D_0}(P,\gamma)\). Some points in \(\text{Safe}(P,\gamma)\) are never classified correctly (alarm always fires on them).
  - **Routing error:** Detect misroutes an input to the wrong expert (e.g., \(x\) on loop A gets expert from loop B). Leads to misclassification even if library size is sufficient.
  - **Overlap conflict:** If two triples overlap and assign different labels to the same point, continuity of \(f_i\) is violated locally, but UM’s local correctness only requires agreement on the intersection with safe balls. Overlap outside safe balls is allowed but may cause inconsistency if not handled.

- **First 3 experiments:**
  1. **Validate Theorem 4.1:** Construct the bouquet space \(X_w\) (\(w\) circles glued at a point) with circumferences \(L = 1\). Set \(\gamma = 0.05\), choose \(D_0 = 0.15\) (satisfies \(3\gamma/2=0.075 \le D_0 < L/2 - 3\gamma/4 = 0.325\)). Place \(w\) safe balls (radius \(\gamma/4=0.0125\)) at antipodes. Run an exhaustive search or greedy covering algorithm to find minimal \((\gamma,D_0)\)‑Urysohn covering. Confirm \(uw = w\).
  2. **Test scaling law (Corollary 5.1):** On the same bouquet, but place \(m\) safe balls equally spaced on the semicircle opposite the wedge point on each loop, with \(L/m > 3\gamma\). Vary \(m\) and measure minimal covering size. Confirm \(uw \ge w\cdot m\) and observe \(uw \approx w\cdot \lfloor L/(2D_0) \rfloor\) for small \(D_0\).
  3. **Verify VC separation:** For the bouquet family, construct the patchwise‑constant hypothesis class \(H_w\) (constant on each of the \(w\) safe arcs, arbitrary outside). Compute or bound VC(\(H_w\)) by counting distinct labelings. Should be \(O(w \log w)\). Conversely, for interval unions on \([0,1]\) with gaps ≥ \(\gamma\) and \(D_0 \ge 1\), show a single interval‑connected patch suffices (\(uw=1\)) while VC(interval unions) = \(2n\).

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** Does local Urysohn width satisfy \(uw_{D_0}(P,\gamma) \ge c\cdot \beta_1(X)\) without assuming bounded nerve adjacency? (Conjecture 8.9)
- **Basis in paper:** Conjecture 8.9 states the conjecture under conditions (i)‑(iii) alone, without the adjacency condition (iv).
- **Why unresolved:** The existing lower bound (Theorem 8.5) requires bounded adjacency; without it the nerve can have \(O(w^2)\) edges, weakening the bound to \(\Omega(\sqrt{\beta_1})\). Proving a linear bound is challenging because optimal coverings might have arbitrarily many pairwise intersections.
- **What evidence would resolve it:** A proof that any \((\gamma,D_0)\)‑Urysohn covering automatically satisfies bounded adjacency under (i)‑(iii), or a homological argument bypassing adjacency. A counterexample showing sublinear width would refute the conjecture.

### Open Question 2
- **Question:** Do higher Betti numbers \(\beta_k\) (\(k\ge 2\)) yield lower bounds on local Urysohn width? (Conjecture 8.12)
- **Basis in paper:** The text asks: “Whether \(\beta_k\) for \(k\ge 2\) provides further lower bounds on width in higher‑dimensional settings is a natural next question.” Conjecture 8.12 proposes \(uw_{D_0} \ge c \sum_{k\ge 1} \beta_k(X)\).
- **Why unresolved:** The paper’s methods focus on \(\beta_1\) via loop counting. Higher‑dimensional cycles (voids, shells) have not been analyzed; interactions between multiple homology groups are unknown.
- **What evidence would resolve it:** Exact width computations on families of spaces with known \(\beta_k\) (e.g., wedges of \(k\)-spheres, products of manifolds). Alternatively, extending the nerve‑based proof to higher homology via generalized Nerve Lemma or spectral sequences.

### Open Question 3
- **Question:** Can we design online algorithms that provably adapt the Metric Library size to match the unknown topological width of the data manifold?
- **Basis in paper:** The conclusion: “Most ambitiously, one would like to develop online algorithms that adaptively grow the Metric Library to match the unknown topological width of the data manifold.”
- **Why unresolved:** No existing algorithm has theoretical guarantees for structural allocation in continual learning. Mixture‑of‑Experts and related methods entangle topological indexing with metric classification, causing catastrophic interference.
- **What evidence would resolve it:** A constructive online algorithm with analysis showing that, under mild distributional assumptions (e.g., each topological context has minimum probability mass), the library size after \(n\) samples concentrates around the true width and classification error vanishes. Empirical validation on synthetic manifolds (e.g., Bouquet of circles with latent permutations) would demonstrate feasibility.

## Limitations
- Results are confined to 1‑D bouquets and interval unions; behavior on higher‑dimensional manifolds is unknown.  
- Scaling law provides only a lower bound; the absence of an upper bound leaves tightness uncertain.  
- No algorithmic approach to compute width; the covering problem is combinatorially hard in general.
