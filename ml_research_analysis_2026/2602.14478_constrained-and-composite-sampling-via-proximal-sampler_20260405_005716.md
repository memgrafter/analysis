# Constrained and Composite Sampling via Proximal Sampler
## Quick Facts
- arXiv ID: 2602.14478
- Source URL: https://arxiv.org/abs/2602.14478
- Reference count: 40
- Primary result: Transforms constrained/composite log-concave sampling into uniform sampling over lifted convex sets and solves via proximal sampler with RGO implemented by cutting-plane and rejection sampling, achieving dimension-polynomial mixing times.

## Executive Summary
This paper tackles the challenges of sampling from log-concave distributions under constraints or with composite structures. It introduces a unified framework that lifts the original problem to a higher-dimensional space where the target distribution becomes nearly uniform over a convex set. A proximal sampler is then applied, requiring only a Restricted Gaussian Oracle (RGO). The RGO is implemented using a separation oracle for the lifted set and proximal/subgradient oracles for the involved functions, avoiding expensive projections or barrier constructions. The approach yields theoretical guarantees with polynomial dependence on dimension and provides unbiased samplers with minimal oracle access.

## Method Summary
The method proceeds by lifting the constrained sampling problem via single epigraph lifting and the composite sampling problem via double epigraph lifting. This transformation converts the original sampling task into drawing approximately uniform samples from a lifted convex set. The proximal sampler algorithm is employed, which at each step requires the ability to sample from a Gaussian distribution restricted to the lifted set (the RGO). The RGO is realized through a cutting-plane method that iteratively refines a polyhedral approximation of the set, combined with rejection sampling to correct biases. Crucially, the algorithm only needs a separation oracle for the lifted set and first-order (subgradient) or proximal oracles for the functions \(f\) and \(h\), not projections or log-barriers. This makes the method applicable to a broad class of problems with implicit set descriptions.

## Key Results
- For constrained sampling, mixing time is \(O(d^2 \log d \log(1/\epsilon))\) in Rényi/\(\chi^2\) divergence, with per-iteration oracle complexity \(O(d \log d \cdot \gamma/\alpha)\) where \(\gamma = R/\text{minwidth}(K)\).
- Proposal complexity is \(O(1)\) under standard Lipschitz assumptions.
- For composite sampling, similar dimension-polynomial bounds hold; notably, the oracle complexity remains \(O(d \log d)\) in high probability.

## Why This Works (Mechanism)
The epigraph lifting converts the original non-uniform target distribution into a nearly uniform one over a convex body because the density becomes constant on the lifted set when augmented with an auxiliary variable representing the function value. The proximal sampler, which is designed for uniform sampling over convex sets, can then be applied. The RGO, which is the only subroutine needed, is approximated by a polynomial-time algorithm that uses a separation oracle to build an inner polyhedral approximation and rejection sampling to account for the curvature of the set. The analysis shows that the total variation mixing time scales polynomially in dimension and depends on geometric parameters like the radius-to-width ratio \(\gamma\). The rejection step’s acceptance probability is bounded away from zero under Lipschitz assumptions, ensuring constant expected number of proposals. Thus, the combination of lifting and proximal sampling yields an efficient and theoretically sound method for both constrained and composite log-concave sampling.

## Foundational Learning
- **Log-concave sampling**: Sampling from densities proportional to \(\exp(-f(x))\) on convex sets. *Why needed*: The paper targets this fundamental problem. *Quick check*: Verify that the target distribution is log-concave if \(f\) is convex.
- **Proximal sampler**: A Markov chain that uses Gaussian proposals restricted to the convex set. *Why needed*: It provides a framework with simple RGO requirement. *Quick check*: Understand the transition operator: propose from Gaussian, reject if outside, else accept with probability proportional to target density ratio.
- **Separation oracle**: A black-box that, given a point, returns whether it is inside the set and a separating hyperplane if not. *Why needed*: Enables handling of implicit convex sets without projections. *Quick check*: Implement for a polytope by checking constraints.
- **Epigraph lifting**: Adding an auxiliary variable \(t\) to represent \(f(x) \le t\) (single) or \(f(x)+h(x) \le t\) (double). *Why needed*: Transforms non-uniform distribution into uniform over the lifted set. *Quick check*: Show that the Jacobian of the lifting yields constant density.
- **Rényi/\(\chi^2\) divergence**: Divergence measures used for mixing time analysis. *Why needed*: They allow cleaner analysis for the proximal sampler. *Quick check*: Know that \(\chi^2\) divergence contracts under the transition kernel.
- **Restricted Gaussian Oracle (RGO)**: Ability to sample from a Gaussian conditioned on lying in a convex set. *Why needed*: Core subroutine of proximal sampler. *Quick check*: For an ellipsoid, RGO is exact via affine transformation.

## Architecture Onboarding
Component map:
Separation oracle (for lifted set) + Proximal/subgradient oracles (for f, h) -> Cutting-plane polyhedral approximation -> Rejection sampling -> RGO -> Proximal sampler -> Target samples

Critical path: The RGO is the bottleneck; its implementation determines overall efficiency. The cutting-plane method builds an inner approximation of the lifted set; rejection sampling corrects the difference.

Design tradeoffs: Single vs double lifting: double lifting introduces an extra dimension but handles composite structure directly. Using separation oracles avoids expensive projections but may require many cutting-plane iterations. Rejection sampling efficiency vs accuracy of polyhedral approximation.

Failure signatures: Large \(\gamma = R/\text{minwidth}(K)\) leads to poor mixing. Low acceptance probability in rejection step (e.g., due to poor polyhedral approximation or high curvature) increases runtime. Ill-conditioned lifted sets cause cutting-plane to converge slowly.

First three experiments:
1. Implement for sampling from a uniform distribution over a simple polytope (constrained case) and verify mixing time scaling with dimension.
2. Apply to composite logistic regression with L2 regularization; compare effective sample size to MCMC benchmarks.
3. Measure rejection sampling acceptance rate as a function of dimension and condition number for ellipsoidal sets to validate O(1) proposal complexity claim.

## Limitations
- The method relies on separation oracles and proximal/subgradient oracles, which may be computationally expensive depending on the problem.
- The bound involves \(\gamma = R/\text{minwidth}(K)\), which can be arbitrarily large for thin sets, leading to worse theoretical guarantees.
- Mixing time analysis is in Rényi/\(\chi^2\) divergence, which is weaker than total variation; also, no experimental validation of practical performance is provided.

## Confidence
- Theoretical soundness of lifting+proximal sampler framework, unbiasedness, and proven mixing time/complexity bounds: **High**
- Practical performance and constant factors: **Medium**
- None: **Low**
