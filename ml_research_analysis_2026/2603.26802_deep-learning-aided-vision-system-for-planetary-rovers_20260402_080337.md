# Deep Learning Aided Vision System for Planetary Rovers

## Quick Facts
- **arXiv ID:** 2603.26802  
- **Source URL:** https://arxiv.org/abs/2603.26802  
- **Reference count:** 27  
- **Primary result:** Dual-pipeline vision system achieves 2.26 cm median depth error (1-10 m) and real-time obstacle detection on Chandrayaan-3 NavCam.

## Executive Summary
This paper presents a computationally efficient vision system for autonomous planetary rovers, combining real-time obstacle detection with high-resolution terrain mapping under strict resource constraints. The system employs a dual-pipeline architecture: a real-time module that uses CLAHE-enhanced stereo imagery, the lightweight YOLOv11n object detector, and a neural network for metric depth estimation; and an offline module that leverages the Depth Anything V2 monocular depth model with Open3D to produce dense 3D reconstructions. Evaluated on imagery from the Chandrayaan-3 rover’s navigation camera, the depth estimator achieves a median error of 2.26 cm in the critical 1–10 meter range, while YOLOv11n maintains a balanced precision-recall trade-off on grayscale lunar scenes. The results demonstrate the system’s potential for safe, autonomous operation in planetary exploration.

## Method Summary
The core method is a dual-pipeline vision architecture. The real-time pipeline processes stereo images: first, Contrast Limited Adaptive Histogram Equalization (CLAHE) enhances local contrast; then YOLOv11n detects obstacles; and a separate shallow neural network estimates metric depth from the stereo pair to provide distance estimates. The offline pipeline takes one of the stereo images, feeds it into the Depth Anything V2 monocular depth model, and uses Open3D to fuse the resulting depth maps into a dense 3D reconstruction. The two pipelines operate independently, allowing the rover to react immediately to hazards while building a more complete map for later planning.

## Key Results
- Neural network depth estimator yields median error of 2.26 cm in the critical 1–10 m range on Chandrayaan-3 data.
- YOLOv11n detector provides balanced precision-recall on grayscale lunar scenes, suitable for real-time deployment.
- System integrates a real-time obstacle detection pipeline with an offline dense 3D reconstruction module, addressing both immediate safety and high-resolution mapping needs.

## Why This Works (Mechanism)
The system's effectiveness stems from its tailored handling of lunar imaging conditions and resource constraints. CLAHE compensates for the Moon's uniform albedo and harsh lighting by adaptively enhancing local contrast, which improves feature visibility for both detection and depth networks. YOLOv11n, being one of the fastest YOLO variants, provides a favorable speed-accuracy balance, enabling high frame rates on limited hardware. The metric depth network directly regresses distance from stereo pairs, leveraging geometric cues to maintain accuracy within the key 1–10 m range. Meanwhile, the offline pipeline uses a state-of-the-art monocular depth model (Depth Anything V2) that, despite potential scale ambiguity, can generate dense depth maps from a single image, which are then integrated by Open3D into a coherent 3D model for path planning. By separating real-time and offline processes, the system guarantees low-latency hazard avoidance without sacrificing the long-term mapping quality.

## Architecture Onboarding
**Component Map:**  
Stereo Camera -> CLAHE -> {YOLOv11n -> Obstacle Map, Depth Estimation Network -> Sparse Depth}  
Stereo Camera -> Depth Anything V2 -> Open3D -> Dense 3D Map

**Critical Path:**  
Image capture → CLAHE enhancement → Object detection → Depth estimation → Obstacle fusion → Control decision.

**Design Tradeoffs:**  
- Real-time performance vs detection/depth accuracy.
- Sparse real-time depth vs dense offline reconstruction.
- Lightweight model (YOLOv11n) vs higher mAP models.
- Stereo-based metric depth (robust) vs monocular depth (dense but may drift).

**Failure Signatures:**  
- High latency in real-time pipeline leads to missed obstacles.
- Depth estimation error > threshold causes false negatives/positives.
- Offline reconstruction fails due to insufficient texture or lighting.
- CLAHE over-enhancement introduces noise in detection.

## Limitations
- Generalizability of the reported 2.26 cm depth error to other planetary surfaces remains unvalidated; evaluation limited to Chandrayaan-3 NavCam.
- Computational footprint (FPS, memory, power) of the real-time module is not quantified, undermining claims of resource efficiency.
- Offline reconstruction quality (accuracy, completeness) and robustness to challenging conditions (dust, glare) are not reported.

## Confidence
- Depth estimation accuracy: Medium
- Object detection reliability: Medium
- Overall system suitability for resource-constrained rovers: Low
