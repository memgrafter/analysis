# Enhancing Debunking Effectiveness through LLM-based Personality Adaptation
## Quick Facts
- arXiv ID: 2603.09533
- Source URL: https://arxiv.org/abs/2603.09533
- Reference count: 40
- Primary result: Tailored debunking verdicts aligned with binarized Big Five personalities were significantly more persuasive than generic ones (p<0.05).

## Executive Summary
This study investigates whether tailoring fake news debunking messages to individual personality traits increases persuasiveness. Using Qwen3-32B, generic debunking verdicts from FullFact were rewritten into 32 versions corresponding to binary Big Five profiles. Three LLM personas (Llama3, Qwen3-8B, Qwen3-32B) evaluated persuasiveness on a 1-7 scale. Results showed tailored verdicts were significantly more persuasive than generic (p<0.05). Qwen3-8B identified the exact-profile verdict as most persuasive with 88.64% accuracy, rising to 96.39% when allowing one-trait differences. Qualitative analysis revealed higher Openness correlated with increased persuadability while higher Neuroticism lowered it, with evaluator model choice heavily influencing scores.

## Method Summary
The authors used a subset of 933 false claims from FullFact UK fact-checking articles. For each claim, a generic verdict was transformed into 32 versions aligned with binary Big Five profiles (high/low for each of the five traits) via role-play prompting with Qwen3-32B (temperature=0.7). The generation used the full article as factual context and instructed the model to adjust tone and emphasis while avoiding explicit trait mentions and factual distortions. Persuasiveness was evaluated by three LLMs (Llama3-8B-Instruct, Qwen3-8B, Qwen3-32B) each simulating all 32 profiles using persona-based system prompts (temperature=0). Each judge scored all 33 verdicts (32 tailored + generic) on a 1-7 Likert scale. Primary metrics compared matched tailored verdicts against generic and mismatched ones using paired t-tests, exact-profile accuracy (`Accuracy_p`), and closed-neighbor accuracy (`Accuracy_cn`).

**Assumption:** The binarization (median split) of continuous Big Five scores is applied uniformly across all claims and profiles, though specific threshold details are not elaborated.

## Key Results
- Tailored verdicts were significantly more persuasive than generic verdicts (p<0.05).
- Qwen3-8B evaluator achieved 88.64% exact-profile accuracy and 96.39% when considering profiles differing by one trait.
- Higher Openness correlated with higher persuadability; higher Neuroticism correlated with lower persuadability; evaluator model choice substantially influenced scores.

**Unknown:** Effect sizes for the persuasiveness improvement are not reported; statistical power for the correlation findings is unspecified.

## Why This Works (Mechanism)
The system uses role-play prompting to prime an LLM (Qwen3-32B) as a communication strategist for a target binary Big Five profile. Given a claim, context, and generic verdict, the model rewrites the verdict to resonate with the psychological tendencies (e.g., values, communication style) associated with the profile while maintaining factual consistency. The core assumption is that LLMs can internalize the descriptive semantics of a personality profile and apply them as coherent stylistic constraints. Evidence comes from the paper's generation outputs and qualitative analysis (Section 5.2). The transformation fails if factual fidelity is compromised, leading to hallucinations or distortion.

**Assumption:** The stylistic adjustments reflect genuine personality-based persuasion principles rather than superficial lexical changes.

## Foundational Learning
- **Big Five Personality Traits (OCEAN)**: Provides a psychologically grounded, dimensional framework for personalization; binary simplification reduces complexity. Quick check: Can you map a 5-bit string correctly to E, A, C, N, O?
- **Role-Play Prompting**: Enables LLMs to adopt stylistic patterns of a target profile without explicit trait mention. Quick check: Does the system prompt assign a clear role and traits to the LLM?
- **LLM-as-Judge**: Offers scalable, controllable evaluation across many profiles; reduces human variability. Quick check: Are judge models given a system prompt defining the personality profile and a consistent scoring task?
- **Binarized Personality Profiles**: Creates a finite set of 32 personas for systematic testing. Quick check: Are trait thresholds (e.g., median split) defined and consistently applied?
- **Fact-Checking Verdicts**: Ensure factual accuracy; only presentation changes. Quick check: Does the generation prompt include the original context and claim?
- **Persuasion Metrics**: Quantify persuasiveness; accuracy measures assess profile matching. Quick check: Is the evaluation task to score on a 1-7 scale and compute ranks?

## Architecture Onboarding
- **Component map**: Dataset (FullFact) -> Generation (Qwen3-32B with role-play) -> 32 Tailored Verdicts -> Evaluation (3 LLM-judges × 32 profiles) -> Scores -> Accuracy_p, Accuracy_cn, Statistical tests
- **Critical path**: Generation (32×933 calls) is resource-intensive; evaluation (3×32×933 calls) is heavier but parallelizable; dataset preprocessing is prerequisite.
- **Design tradeoffs**:
  - *Binary vs. continuous traits*: Binarization simplifies to 32 personas but loses nuance; continuous traits would require more prompts/parameters.
  - *LLM-as-judge vs. human*: LLM judges are cheap and scalable but may not reflect human psychology; human evaluation is gold standard but costly.
  - *Temperature settings*: Generation uses 0.7 for diversity; evaluation uses 0 for consistency. Changing these affects output variability and score reliability.
- **Failure signatures**:
  - Low `Accuracy_p` (near random ~3%) indicates generation not aligning with profile semantics or judges not recognizing alignment.
  - High variance or uniformly high scores in judge outputs suggest poor discrimination ability.
  - Inconsistency across evaluator models (e.g., Llama3 shows no preference for matched verdicts while Qwen models do) signals model-specific biases.
- **Three first experiments**:
  1. Trait-order verification: Generate for profile `11000` (E↑, A↑, C↓, N↓, O↓) and check output matches Appendix A's action-oriented, cooperative tone.
  2. Neighbor metric implementation: Compute `Accuracy_cn` using Hamming distance=1; validate against reported 96.39% for Qwen3-8B.
  3. Judge consistency check: For each judge model, compare score distributions for matched vs. generic verdicts; expect matched higher for Qwen models but not necessarily for Llama3.

## Limitations
- Core mechanism validity: LLM's ability to reliably map binarized Big Five to stylistic shifts lacks independent validation.
- Evaluator circularity: Persuasiveness judged by LLM personas may create a validation loop favoring superficial alignment.
- Dataset scope: Findings limited to 933 UK false claims; generalizability to other topics, cultures, or claim types is unknown.

## Confidence
- Tailored verdicts are more persuasive than generic. -> Medium (based on p<0.05; effect size unknown)
- LLMs can apply personality traits as stylistic constraints. -> Low-Medium (based on accuracy metrics; may reflect judge bias)
- Higher Openness increases persuadability; higher Neuroticism decreases it. -> Low (correlational; no causal claim; possible confounding)
