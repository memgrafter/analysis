# An Empirical Study on Knowledge Transfer under Domain and Label Shifts in 3D LiDAR Point Clouds

## Quick Facts
- **arXiv ID:** 2601.07855
- **Source URL:** https://arxiv.org/abs/2601.07855
- **Reference Count:** 40
- **Primary Result:** Zero-shot transfer fails for cyclists (0.6-5.9% acc), label split/insertion cripples linear probing, and neural collapse pretraining induces severe forgetting in continual learning (BWT as low as -59.6%).

## Executive Summary
This study investigates transfer learning for 3D LiDAR object classification when both the sensor domain (e.g., Waymo to nuScenes) and the set of class labels evolve simultaneously—a scenario common in autonomous driving. The authors introduce the **RoAD** benchmark, which systematically couples domain shifts with specific label space changes (split, insertion, expansion) and evaluates three adaptation protocols: zero-shot transfer, linear probing, and memory-free continual learning. Using diverse pretraining objectives (supervised, self-supervised, hybrid) and two backbone architectures (PointNet++, Point Transformer), they reveal critical failure modes: zero-shot transfer is ineffective for classes with label expansion (e.g., cyclist), linear probing collapses for novel subclasses or inserted classes, and pretraining objectives that induce neural collapse (e.g., dot regression) catastrophically harm continual learning despite strong zero-shot performance. Counter-intuitively, supervised pretraining, while weaker in zero-shot/linear probing, proves most robust for continual learning under non-stationary distributions.

## Method Summary
The **RoAD** benchmark defines a source dataset (Waymo) with three coarse classes (`vehicle`, `pedestrian`, `cyclist`) and two target datasets (nuScenes, Argoverse2) with richer, divergent label sets. The core evaluation couples a **domain shift** (sensor/environment change) with a **label shift** operation applied to the source classes: *split* (e.g., `vehicle`→`car`/`truck`), *insertion* (entirely new classes like `barrier`), or *expansion* (e.g., `cyclist`→`bicycle`+`rider`). Three adaptation paradigms are tested:
1.  **Zero-Shot (ZS):** Frozen source model applied to target data; predictions are remapped according to the label shift (split→superclass, expansion→original class, insertion→ignored).
2.  **Linear Probing (LP):** Source backbone frozen; only the final classification layer is trained on the target dataset.
3.  **Continual Learning (CL):** Full model fine-tuned on the target dataset under a *memory-free* constraint, using either **LwF** (knowledge distillation to preserve source head outputs) or **EWC** (Fisher-based regularization on source-important weights). Performance is measured by class-averaged accuracy (ZS/LP on target classes only; CL as average of source and target accuracy) and **Backward Transfer (BWT)** to quantify catastrophic forgetting of source knowledge. Pretraining objectives include standard cross-entropy (CE), neural collapse-inducing dot regression (DR), supervised contrastive (SupCon), self-supervised (InfoNCE, VICReg), and their hybrids.

## Key Results
- Zero-shot transfer fails dramatically for the `cyclist` class under label expansion (e.g., 0.6% in W→A) and is also broken by pure domain shift, indicating over-specialization to source-specific cues.
- Linear probing accuracy drops sharply for classes undergoing label split (poor fine-grained separation) or insertion (<40% accuracy), as the frozen feature space lacks discriminative structure for novel subclasses or categories.
- Pretraining objectives that induce **neural collapse** (e.g., DR, where features converge to class prototypes with cosine similarity >0.99) lead to severe catastrophic forgetting during CL (BWT as low as -59.6%). Supervised CE pretraining, despite inferior ZS/LP, yields the best CL performance.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Zero-shot transfer fails for the cyclist class under coupled domain and label shifts.
- **Mechanism:** Models pretrained on Waymo's coarse `cyclist` class over-specialize to features correlated with human riders (e.g., bounding box size, point distribution including a rider). These cues do not transfer to target datasets where the class definition differs (nuScenes `bicycle` includes rider-less bicycles) or the domain shift removes these cues (Argoverse2 `bicyclist` with different sensor characteristics).
- **Core assumption:** Features learned for a coarse class are not sufficiently invariant to semantic sub-variations or domain-specific appearance.
- **Evidence anchors:**
  - [abstract] "Zero-shot transfer fails for cyclists (0.6-5.9% acc), due to label expansion and domain shift;"
  - [section 4.1] "In W→N, the failure is mainly induced by label expansion... The failure also persists in W→A, despite Argoverse2 bicyclist maintaining the Waymo cyclist definition... indicating that domain shift alone can be sufficient to break zero-shot transfer for this class."
- **Break condition:** If source pretraining data explicitly includes the full semantic spectrum of the target class definition (e.g., rider-less bicycles) or produces features invariant to rider presence.

### Mechanism 2
- **Claim:** Linear probing performance degrades sharply for classes undergoing label split or insertion compared to maintained or expanded classes.
- **Mechanism:** The frozen pretrained feature space lacks discriminative structure for fine-grained subclasses (from split) or entirely novel classes (from insertion). Linear probing can only learn a linear classifier on fixed features, so it cannot create new separation boundaries required for these classes.
- **Core assumption:** Pretraining objectives like supervised cross-entropy encourage maximal separation of coarse classes but insufficient intra-class variation preservation or novelty detection.
- **Evidence anchors:**
  - [abstract] "Label split and insertion cripple linear probing (inserted classes <40% acc), while split classes show poor fine-grained separation;"
  - [section 4.2] "Classes affected by label split and insertion consistently attain lower accuracy... ZS performs well on coarse superclasses, but accuracy drops sharply when predicting the corresponding fine-grained subclasses. This gap suggests insufficient separation of fine-grained classes... consistent with the entangled clusters observed in the t-SNE visualizations."
- **Break condition:** If the pretraining objective explicitly encourages feature diversity within coarse classes (e.g., via self-supervised methods) or if the split/insertion classes are already semantically close to existing classes in the source feature space.

### Mechanism 3
- **Claim:** Neural collapse-inducing pretraining (e.g., dot regression) accelerates catastrophic forgetting during continual learning.
- **Mechanism:** Such pretraining collapses features of all instances of a class to a single prototype point, discarding intra-class variance. When fine-tuning on a shifted target domain, updates to the shared feature extractor easily overwrite this collapsed source representation, causing severe forgetting. Regularization like EWC that constrains parameter updates across layers mitigates this by protecting the entire collapsed structure.
- **Core assumption:** Forgetting is driven by the overwriting of source feature space geometry; a collapsed space is less robust to distribution shifts during target adaptation than a dispersed one.
- **Evidence anchors:**
  - [abstract] "Neural collapse pretraining induces feature collapse (high cosine similarity >0.99) leading to severe forgetting in CL (BWT as low as -59.6%);"
  - [section 4.3] "DR exhibits the most severe catastrophic forgetting... We attribute this failure to DR’s strong tendency to collapse features toward class prototypes... As a result, when target fine-tuning shifts the feature space, the source information is easily overwritten... DR exhibits the highest overlap among different pretraining objectives, characterized by the highest cosine similarity... This weakness is largely mitigated under EWC: whereas LwF primarily enforces prototype alignment, EWC constrains parameter updates across layers..."
- **Break condition:** If source and target domains are highly dissimilar (minimal feature overlap), the collapsed prototype may lie in a low-update region. Or if CL uses strong regularization (high λ EWC) that protects the entire feature extractor path.

## Foundational Learning
- **Concept: Domain Shift & Label Shift Taxonomy**
  - *Why needed here:* The entire study hinges on distinguishing and coupling two sources of dataset shift: covariate shift (sensor, environment) and label space evolution (split, insertion, expansion). Misidentifying these leads to incorrect evaluation design.
  - *Quick check:* Given Waymo→nuScenes transfer, is the change from `vehicle` to `car`/`truck` a domain shift, label shift, or both? (Answer: Primarily label split, but co-occurs with domain shift.)
- **Concept: Neural Collapse**
  - *Why needed here:* It is the hypothesized mechanism for catastrophic forgetting in the DR pretraining experiments. Understanding that features collapse to class means on the last layer is key to interpreting the results.
  - *Quick check:* What would you expect to see in a t-SNE plot of features from a neural collapse-induced model? (Answer: Tight, well-separated clusters per class with low intra-class variance.)
- **Concept: Continual Learning Regularization (LwF vs. EWC)**
  - *Why needed here:* The benchmark compares two fundamental, memory-free CL strategies. LwF (knowledge distillation) preserves output logits; EWC (regularization) constrains parameter updates based on importance. Their different failure modes are central findings.
  - *Quick check:* Why might LwF be less effective than EWC when source features are collapsed? (Answer: LwF only aligns final layer logits/prototypes, but if all source class features are at a single point, target updates can move that point easily. EWC penalizes changes to weights that were important for the source task, protecting the entire mapping.)

## Architecture Onboarding
- **Component map:**
  Raw Point Cloud -> Backbone (PointNet++ / Point Transformer) -> Penultimate Feature -> Classification Head (MLP)
  Pretraining Loss (CE / DR / SupCon / NCE / VICReg / Hybrids) applied to Head outputs.
  Adaptation: Zero-Shot (no change), Linear Probing (freeze Backbone, retrain Head), Continual Learning (fine-tune Backbone+Head with LwF/EWC).
- **Critical path:**
  1.  Source Pretraining: Train Backbone+Head on Waymo (3 classes) with chosen pretraining objective.
  2.  Zero-Shot Evaluation: Apply frozen model to target data; map predictions via label shift rules (split→superclass, expansion→original class, ignore inserted).
  3.  Linear Probing: Freeze Backbone; reset and train Head on target dataset.
  4.  Continual Learning: Fine-tune entire model on target with LwF (dual heads, distillation loss) or EWC (Fisher penalty on source-important weights).
- **Design tradeoffs:**
  - **Backbone:** PointNet++ is simpler/faster; Point Transformer captures longer dependencies but shows instability with EWC.
  - **Pretraining Objective:** Supervised CE yields strongest CL performance. Self-supervised/hybrid improve ZS/LP on *maintained* classes but may introduce domain shortcuts that harm CL. Neural collapse (DR) is stable for ZS but catastrophic for CL.
  - **CL Method:** LwF generally more stable and higher ACC than EWC on these backbones. EWC's Fisher estimates become unstable for attention/convolutional layers.
- **Failure signatures:**
  - **Zero-Shot:** Very low accuracy (<10%) on `cyclist`/`bicycle` and all inserted classes.
  - **Linear Probing:** Large accuracy gap between `vehicle` (maintained/expanded) and fine-grained `car`/`truck` (split); near 0% on inserted classes like `barrier`.
  - **Continual Learning:** Negative BWT (forgetting) below -30% with DR or high SSL coefficient; EWC runs may diverge or show high variance.
- **First 3 experiments:**
  1.  **Reproduce Zero-Shot Failure:** Train CE+PointNet++ on Waymo. Evaluate zero-shot on nuScenes. Confirm `vehicle`~95%, `pedestrian`~98%, but `bicycle` (cyclist expansion) only ~62%.
  2.  **t-SNE Visualization of Split:** Using a Waymo-pretrained model, extract penultimate features for nuScenes `car` and `truck`. Plot t-SNE. Expect overlapping clusters, confirming insufficient separation for label split.
  3.  **CL Catastrophic Forgetting with DR:** Pretrain with DR on Waymo. Do LwF CL to nuScenes. Expect ACC ~70% and BWT ~-45%. Contrast with same CL using CE pretraining (ACC ~82%, BWT ~-17%).

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** How do longer-tailed and open-set label shifts—beyond the current closed-set split/insert/expansion taxonomy—affect robustness in 3D LiDAR transfer under domain shift?
- **Basis in paper:** [explicit] The conclusion states that future work will explore “richer shift taxonomies (e.g., long-tail and open-set label shifts).”
- **Why unresolved:** RoAD currently covers only balanced, closed-set label evolutions; real-world deployments may suffer from severe class imbalance and previously unseen classes, which could exacerbate failure modes.
- **What evidence would resolve it:** Extend the benchmark with long-tailed source/target distributions and open-set evaluation protocols; systematically compare pretraining objectives and CL methods on metrics like open-set recognition rate and per-class accuracy under varying imbalance levels.

### Open Question 2
- **Question:** Can the RoAD benchmark and findings be successfully transferred to more complex perception tasks such as 3D object detection and motion forecasting?
- **Basis in paper:** [explicit] The conclusion explicitly mentions extending RoAD to “more challenging tasks such as 3D object detection and motion forecasting.”
- **Why unresolved:** The current study isolates classification, ignoring localization and forecasting components; detection/forecasting architectures and loss functions may interact with domain and label shifts differently.
- **What evidence would resolve it:** Re-implement the RoAD protocol using state-of-the-art detection/forecasting models on large autonomous driving datasets; report performance degradation patterns and compare to classification results.

### Open Question 3
- **Question:** Why do self-supervised pretraining objectives, despite strong zero-shot and linear probing performance, become suboptimal for continual learning under domain shift, and how can SSL be adapted for non-stationary settings?
- **Basis in paper:** [explicit] The authors observe that “supervised pretraining outperforms self-supervised ones in continual learning” and hypothesize that SSL encourages “domain shortcuts” that are suppressed during target fine-tuning.
- **Why unresolved:** The domain shortcut hypothesis is plausible but not directly measured; the exact properties of SSL representations that make them vulnerable to forgetting under domain shift are unknown.
- **What evidence would resolve it:** Analyze SSL feature spaces (e.g., domain separation metrics, saliency maps) and correlate with forgetting intensity; explore SSL objectives that explicitly enforce domain invariance.

### Open Question 4
- **Question:** How can regularization-based continual learning (e.g., EWC) be stabilized for point cloud networks like PointNet++ and Point Transformer, given their sensitivity to the regularization weight and worse performance compared to LwF?
- **Basis in paper:** [explicit] “EWC is more sensitive to λ, showing larger accuracy variance and consistently lower performance than LwF. Mitigating these stability issues for such backbones likely requires additional stabilization strategies.”
- **Why unresolved:** EWC’s Fisher-based importance estimation yields disproportionately high scores for core layers in point cloud backbones, causing optimization instability.
- **What evidence would resolve it:** Investigate alternative importance metrics (e.g., per-layer scaling, damping, or gradient-based importance), or architecture-aware regularization designs; evaluate on RoAD’s CL scenarios to demonstrate improved stability.

## Limitations
- Details of DR and ARPL losses are missing, hindering exact reproduction of the neural collapse effect.
- Optimal hyperparameters (λ for LwF/EWC) are given only as search ranges; reported numbers may not represent the best possible performance.
- Preprocessing assumptions (e.g., point count resampling, normalization specifics) are not fully explicit.
- Evaluation is restricted to three autonomous driving datasets; broader generalizability is unknown.
- No explanation for Point Transformer's instability with EWC.
