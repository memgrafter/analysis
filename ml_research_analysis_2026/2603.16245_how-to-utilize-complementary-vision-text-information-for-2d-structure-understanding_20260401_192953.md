# How to Utilize Complementary Vision-Text Information for 2D Structure Understanding
## Quick Facts
- arXiv ID: 2603.16245
- Source URL: https://arxiv.org/abs/2603.16245
- Reference count: 39
- Primary result: DiVA-Former achieves average improvements of 23.9% over text-only baseline, 22.5% over direct concatenation, and outperforms fusion methods by 8.6%–35.8% on 13 table benchmarks.
## Executive Summary
Large language models (LLMs) face difficulty in understanding 2D tables because serializing tables into a 1D token sequence discards spatial relationships. DiVA-Former addresses this by introducing a lightweight cross-attention resampler that uses visual tokens from a frozen image encoder as dynamic queries to condense the lengthy linearized table text into a compact set of structurally informed digest vectors. An identity-preserving gating mechanism stabilizes training and retains the spatial prior encoded in the visual queries. Evaluated on 13 table benchmarks covering question answering, fact verification, text generation, and structure understanding, DiVA-Former achieves average gains of 23.9% over pure-text baselines, 22.5% over direct concatenation, and outperforms prior fusion methods by 8.6%–35.8%, demonstrating effective cross-modal synergy without interference. The method’s success highlights the value of leveraging complementary visual and textual information for 2D structure understanding while keeping the LLM frozen, making it parameter‑efficient and adaptable.
## Method Summary
DiVA-Former processes a table image and its serialized textual representation through two frozen encoders: a visual encoder (e.g., Qwen3‑VL) yields visual token embeddings V, while the LLM’s embedding layer converts the linearized text tokens into context matrix C. A trainable cross‑attention resampler Rθ then takes V as initial query tokens Q⁰. Each transformer layer performs gated cross‑attention where queries attend to a combined memory M comprising C and the previous queries, followed by a gated feed‑forward network. The output digest D = Qᴺ is a shorter sequence (n×d) that preserves the dimensionality of the visual tokens but aggregates relevant textual evidence. The frozen LLM Φ finally consumes the concatenation of D and the user prompt p to generate the output y. Only the parameters of Rθ are optimized, preserving the LLM’s knowledge and reducing computational cost.

The core innovation lies in using visual tokens as queries, which naturally encode the table’s 2D layout (row/column adjacency, cell bounding boxes). This guides the resampler to extract spatially coherent information from the text, avoiding the noise and misalignment that arise from naive concatenation. The identity‑preserving gates (near‑zero initialization) ensure each transformer block behaves like an identity at the start of training, preventing catastrophic forgetting of the spatial prior and stabilizing optimization.
## Key Results
- Over pure‑text baseline: +23.9% average improvement across 13 benchmarks.
- Over direct concatenation: +22.5% average improvement.
- Outperforms adapter‑ and resampler‑based fusion methods by 8.6% to 35.8% in average score, with particularly large gains on structure‑centric tasks (e.g., TCR, TCE, RCE).
## Why This Works (Mechanism)
### Mechanism 1: Visual tokens as structure‑anchored queries
- **Claim:** Visual tokens serve as dynamic, structure‑anchored queries to distill textual context into compact digest vectors that preserve 2D spatial priors.
- **Mechanism:** Visual embeddings from a frozen encoder initialize the query sequence for a lightweight cross‑attention resampler. These queries attend over the long, linearized table text tokens (Keys/Values), aggregating relevant textual evidence while retaining the spatial layout encoded in the visual features. The output digest sequence is shorter than the text, reducing LLM burden.
- **Core assumption:** Visual tokens effectively encode coarse 2D layout (row/column adjacency, cell bounding boxes) that is lost during text linearization, and these spatial priors can guide meaningful text selection.
- **Evidence anchors:** [abstract] “DiVA-Former introduces a lightweight cross‑attention resampler that uses visual tokens as dynamic queries to distill lengthy text sequences into compact, structurally informed digest vectors.” [section 3.2] “Unlike prior query resamplers… DiVA‑Former derives its queries directly from the visual embeddings… the representation is typically much shorter than the original textual context.”
- **Break condition:** If the visual encoder fails to capture meaningful spatial structure (e.g., due to poor OCR or distorted layout), the query initialization provides a poor prior, leading to ineffective text aggregation.

### Mechanism 2: Mitigating cross‑modal interference through query‑driven fusion
- **Claim:** Direct concatenation of vision and text inputs introduces cross‑modal interference and redundant context; DiVA‑Former’s query‑driven fusion mitigates this by allowing visual anchors to selectively extract complementary textual evidence.
- **Mechanism:** Direct concatenation forces the LLM to perform cross‑modal alignment over a long, redundant sequence, where irrelevant or conflicting signals from one modality can distract from the other. DiVA‑Former’s cross‑attention resampler performs explicit, early fusion within a small, dedicated module, where visual queries actively retrieve text tokens most relevant to the spatial structure they represent.
- **Core assumption:** The complementarity between modalities is not automatically leveraged by the LLM’s self‑attention in a long concatenated sequence; a dedicated alignment module is needed to prevent interference.
- **Evidence anchors:** [abstract] “direct concatenation and other fusion methods yield limited gains and frequently introduce cross‑modal interference.” [section 4.4] Figure 3 and Table 2 show DiVA‑Former recovers many examples where both unimodal and concatenation baselines fail, indicating effective synergy rather than simple modality selection.
- **Break condition:** If modalities are highly redundant rather than complementary (e.g., perfect OCR text from the image), the fusion mechanism provides little benefit and may add unnecessary complexity.

### Mechanism 3: Identity‑preserving gating for training stability
- **Claim:** The identity‑preserving gating mechanism stabilizes training and prevents catastrophic forgetting of the initial visual spatial priors during optimization of the resampler.
- **Mechanism:** Scalar gates (g_attn, g_ffn) initialized near zero make each transformer block behave approximately as an identity mapping at the start of training. This allows the digest vectors to begin as pure visual tokens, with textual information incorporated gradually through small residual updates. It prevents the queries from drifting into semantic collapse or forgetting layout information.
- **Core assumption:** Training a query resampler from scratch on a new modality (text) causes unstable optimization and loss of the beneficial prior from the initialized queries (visual tokens).
- **Evidence anchors:** [section 3.2] “With near‑zero initialization, the attention and FFN branches contribute only minimally at the beginning of training, making the block behave approximately like an identity mapping… stabilizes optimization.” [section 4.5] Ablation shows removing gates causes dramatic performance drop, especially on precise answer extraction tasks.
- **Break condition:** If gate initialization is too large (e.g., g₀=1), the residual branches dominate early, the identity property is lost, and training becomes unstable or forgets visual priors.

## Architecture Onboarding
### Component map
- **Inputs:** (1) Serialized table text tokens → frozen LLM embedding layer → C (m×d). (2) Table image → frozen visual encoder → V (n×d). (3) User prompt p.
- **DiVA-Former (Rθ):** N-layer cross-attention resampler. Input: V (initial queries Q⁰), C (context). Each layer: CrossAttn(Q^{ℓ-1}, M_ℓ, M_ℓ) where M_ℓ = [C; Q^{ℓ-1}], then FFN, both gated. Output: D = Qᴺ (n×d).
- **LLM (Φ):** Frozen. Takes sequence [D; p] → generates output y. Only Rθ is trained.

### Critical path
1. Visual encoder processes table image → V.
2. DiVA-Former: Initialize Q⁰ = V. For each layer: compute M = [C; Q^{prev}]; apply gated cross-attention & FFN to Q.
3. Output digest D replaces original verbose text context.
4. Concatenate D with prompt p, feed to frozen LLM.
5. Compute NLL loss on target y, backpropagate through Rθ only.

### Design tradeoffs
- **Query initialization:** Visual tokens (adaptive, structure-rich) vs. learned queries (flexible but prone to collapse) vs. text tokens (lexically anchored, less optimizable). Tradeoff: quality of spatial prior vs. adaptability.
- **Gate initialization g₀:** Very small (e.g., 1e-3) → stable, gradual fusion but slower start. Larger (e.g., 1e-1) → faster but risk of instability. g₀=1 → unstable.
- **Resampler depth:** Shallow (1-3 layers) sufficient; deeper (6) hurts—likely due to over-transformation away from visual prior.

### Failure signatures
- **Training instability:** Loss spikes early if g₀ too large. Visualizations would show query representations diverging from V.
- **No synergy:** Performance on "both-wrong" subset (Table 2) remains low, similar to direct concat. Digest vectors fail to extract complementary info.
- **Spatial forgetting:** Poor performance on structure tasks (TCE, RCE, TCR) despite good QA scores—digest lost table coordinates.
- **Query collapse:** Multiple digest vectors become near‑identical (check cosine similarity among D rows).

### First 3 experiments
1. **Ablation on query source:** Compare Vision-init vs. Text-init queries (Table 3, row 1 vs 2). Expect Vision-init to outperform significantly, especially on structure tasks.
2. **Gate ablation:** Remove gating (set g_attn=g_ffn=1) under Vision-query/Text-context setting. Expect large drop, particularly on exact-answer datasets (WTQ, TabMWP, TCR).
3. **Modality order test:** Evaluate Vision+Text vs. Text+Vision input sequence to LLM (Table 5). Expect Vision-first to perform slightly better per paper’s observation.
## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** Why does initializing the query tokens from the visual modality (instead of the text modality) yield superior performance for the DiVA-Former architecture, and is this an artifact of the specific frozen LLM backbone or a more general principle for cross-modal fusion in structured tasks?
- **Basis in paper:** [inferred] The ablation study in Table 3 and related text (Section 4.5) demonstrate that using visual tokens as queries significantly outperforms using text embeddings as queries. The authors posit that text representations are "tightly anchored to discrete lexical tokens" and thus less suitable for learnable query optimization, but they do not provide a deeper theoretical or empirical analysis to generalize this finding beyond their specific experimental setting.
- **Why unresolved:** The paper strongly correlates performance with query initialization choice but does not isolate *why* visual features serve as better anchors. Is it due to their continuous nature, their inherent 2D spatial encoding, or an interaction with the frozen LLM's pre-training? This limits the design principles for future multimodal fusion architectures.
- **What evidence would resolve it:** A controlled study varying the *type* of visual encoder (e.g., one trained with explicit spatial objectives vs. one trained for classification) and measuring the quality of the learned "digest vectors." Additionally, testing the same query initialization paradigm on multiple, architecturally diverse backbone LLMs would determine if the observed superiority is backbone-specific or general.

### Open Question 2
- **Question:** To what extent are the performance gains of DiVA-Former on fact verification and structure understanding tasks (e.g., TabFact, TCR) specifically due to improved cross-modal alignment for *spatial reasoning* versus simply reducing input length and mitigating the "lost-in-the-middle" problem for the frozen LLM?
- **Basis in paper:** [inferred] The paper claims DiVA-Former exploits "complementary vision-text information" and shows large recovery rates on "both-wrong" cases (Table 2, Figure 3). However, the Direct concatenation baseline also shortens context length somewhat by using two separate modalities, yet performs poorly. This suggests the gains are not *solely* from compression. The strong performance on TCR, a task designed to isolate structural understanding, points to spatial reasoning, but the paper lacks a fine-grained breakdown of error types (e.g., spatial vs. semantic vs. numerical) to confirm this.
- **Why unresolved:** Without a detailed error analysis categorizing failure modes, we cannot confirm the primary driver of improvement. The complementary information could be as simple as the visual modality providing a more reliable row/column count, which the text-only linearization might lose.
- **What evidence would resolve it:** An error taxonomy analysis on TCR and TabFact, where examples are manually or automatically labeled based on the nature of the required reasoning (pure spatial coordination, symbol matching, numerical computation, multi‑hop). Correlating DiVA-Former's success rate on each subtype with unimodal model performance would clarify which complementary aspects are most critical.

### Open Question 3
- **Question:** Does the identity-preserving gating mechanism in DiVA-Former primarily function to prevent catastrophic forgetting of the initial visual spatial prior during early training, or does it also implicitly regularize the model to perform a more conservative, "cross‑validation" style fusion that avoids hallucination?
- **Basis in paper:** [explicit] The authors introduce the gates (Section 3.2) and state they are "to preserve the original visual information and avoid catastrophic forgetting." The ablation in Table 3 (removing gates) shows a dramatic performance drop, especially on tasks requiring precise answers (WTQ, HiTab, TCR). The text suggests the gates "enable textual information to be incorporated gradually" and help the model "selectively determine whether the text contains useful fine‑grained information or complementary evidence for cross‑validation."
- **Why unresolved:** While catastrophic forgetting is the stated motivation, the "cross‑validation" description hints at a more nuanced role. The gates are scalar and learnable, so their final values could indicate a learned strategy beyond simple identity preservation. We do not know if the mechanism primarily stabilizes training or actively shapes the fusion strategy toward evidence reconciliation.
- **What evidence would resolve it:** Analyzing the learned gate values (g_attn, g_ffn) across layers and datasets. Are they consistently small (near the initial ϵ), indicating persistent identity preservation? Or do they grow on certain datasets/tasks, suggesting the model learns to trust textual updates more? Correlating gate magnitude with task type (e.g., fact verification vs. cell retrieval) could reveal if the mechanism adapts its fusion strategy.

### Open Question 4
- **Question:** Given DiVA-Former's success, what are the fundamental limits of its design paradigm? Specifically, can it effectively handle tables with extremely complex 2D structures (e.g., multi‑level headers, massive merged cells, non‑rectangular layouts) that significantly deviate from the "simple grid" assumption implicit in standard linearization and visual rendering?
- **Basis in paper:** [inferred] The paper evaluates on standard benchmarks (WTQ, HiTab, etc.) where tables are mostly rectangular with standard headers. HiTab includes hierarchical tables, but the method processes the rendered image and linearized text without explicit structural parsing. The success implies the visual encoder captures some structural cues. However, the paper's own Related Work section notes that "purely vision‑based approaches… struggle to preserve fine‑grained textual content," and DiVA-Former relies on text for fidelity. For extremely complex layouts, the visual spatial prior might become noisy or ambiguous, and the simple linearized text might completely lose structural relationships.
- **Why unresolved:** The paper establishes effectiveness on a broad but conventional set of tables. It does not stress‑test the architecture on tables with pathological layouts where the standard linearization (e.g., HTML‑like or markdown) is known to be highly ambiguous. The method's robustness to such distribution shifts is an open question critical for real‑world deployment.
- **What evidence would resolve it:** Evaluation on a dataset specifically constructed with complex, non‑standard table layouts (e.g., from scanned documents with irregular formatting). Comparing DiVA-Former's performance degradation to that of unimodal text and vision baselines on this challenging subset would show if the complementary fusion is robust or if one modality becomes dominantly unreliable.

### Open Question 5
- **Question:** Is the observed performance gain from DiVA-Former primarily due to its *cross‑modal fusion* architecture, or could similar gains be achieved by a simpler, unimodal enhancement that improves the quality of the visual tokens (e.g., a visual encoder pre‑trained with specific table‑structured objectives) or the text representation (e.g., a better linearization format)?
- **Basis in paper:** [inferred] The paper compares DiVA-Former against strong unimodal baselines (Direct Vision, Direct Text) and multimodal baselines (Direct Concat, Adapter, Resampler). DiVA-Former significantly outperforms the Vision‑only Direct baseline (+23.9% average over pure‑text, +22.5% over direct concat). However, the Direct Vision baseline itself underperforms Direct Text on many tasks (Table 1). This suggests the visual tokens from the standard Qwen3‑VL encoder are not optimally informative for table structure on their own. DiVA-Former's success might partly stem from "rescuing" a suboptimal visual representation by anchoring it to high‑fidelity text, rather than from an optimal fusion design per se.
- **Why unresolved:** The contribution is presented as a novel fusion architecture. But if the core issue is that the off‑the‑shelf visual encoder is weak for tables, then the "complementarity" might be lopsided (strong text, weak vision). The paper doesn't ablate the quality of the input modalities. A stronger unimodal visual backbone might close the gap, reducing the marginal benefit of DiVA-Former's specific fusion.
- **What evidence would resolve it:** A study where the quality of the visual input is controlled: (1) use a visual encoder explicitly pre‑trained on table structure recognition tasks (e.g., PubTabNet), (2) use the same Qwen3‑VL encoder but with additional table‑specific language. Compare the performance of the simple Direct Vision baseline and DiVA-Former with these enhanced visual features. If DiVA-Former's relative gain diminishes with a stronger visual encoder, it suggests its primary role is compensating for weak visual features. If the gain remains large, it validates the fusion design itself.
## Limitations
- Visual tokens may fail to encode 2D layout reliably under poor OCR or distorted tables.
- The interference caused by direct concatenation is inferred from performance gaps, not directly measured (e.g., via attention analysis).
- Identity‑preserving gates are validated only on table benchmarks; generalization to other 2D structures is unknown.
## Confidence
- **Vision‑init query resampling:** Medium
- **Concatenation interference mitigation:** Medium
- **Gating for training stability:** High
