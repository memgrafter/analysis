# RILEC: Detection and Generation of L1 Russian Interference Errors in English Learner Texts

## Quick Facts
- **arXiv ID:** 2603.07366
- **Source URL:** https://arxiv.org/abs/2603.07366
- **Reference count:** 0
- **Primary result:** Models fine-tuned on the RILEC dataset achieve an average F1-score of 73.95% on the test set, substantially outperforming a baseline trained only on REALEC-L1 (55.66% F1).

## Executive Summary
The paper introduces RILEC, a large-scale dataset for detecting L1 Russian interference errors in English learner texts. It combines expert-annotated REALEC data with synthetically generated examples using rule-based, PPO-optimized neural, and LLM-prompted augmentation. The authors demonstrate that training a RoBERTa-based span classifier on RILEC yields strong detection performance (average F1 73.95%), with particularly high scores on transliteration (96.55%), word form transmission (90.48%), and tense semantics (80.00%). The augmentation pipeline, especially PPO-based generation, is key to overcoming data scarcity and class imbalance.

## Method Summary
The researchers built the RILEC corpus by expanding the REALEC-L1 dataset (3,882 sentences) through three augmentation strategies: (1) PPO-optimized DistilGPT2 generation for three error types, using reward classifiers to encourage target errors; (2) rule-based injection using GECToR’s dictionary approach plus specific tense and transliteration rules; (3) prompt-based generation with Claude 2 and automatic annotation via Mistral. After merging and deduplication, the final dataset contains 18,830 sentences with a roughly balanced distribution across five L1 interference error tags. A RoBERTa-base model fine-tuned with a SpaCy span classification pipeline on the training split (12,652 sentences) is evaluated on the held-out REALEC-L1 test set (2,204 sentences) and two external test sets (Test100, REALEC70). Hyperparameters include batch size 128 and 10 epochs.

## Key Results
- RILEC-trained model achieves **73.95% average F1**, outperforming the REALEC-L1 baseline (55.66% F1) by 18.29 percentage points.
- Best per-tag performance: **Transliteration 96.55%**, **Word Form Transmission 90.48%**, **Tense Semantics 80.00%**.
- The PPO-based augmentation alone yields 71.81% F1, demonstrating the quality of neural synthetic errors.

## Why This Works (Mechanism)
### Mechanism 1: Synthetic augmentation mitigates data scarcity
- **Claim:** Adding synthetic examples for each error type enlarges and balances the training set, improving generalization.
- **Mechanism:** The augmentation pipeline generates thousands of labeled sentences, increasing the REALEC-L1 training set from 3,882 to 12,652 examples and achieving roughly 4,000 per class.
- **Core assumption:** Synthetic errors closely resemble real L1-motivated errors in context and characteristics.
- **Evidence anchors:** Abstract and Section 2 highlight the use of synthetic data to scale corpora; Table 3 and Figure 2 show the expanded, balanced dataset.
- **Break condition:** If synthetic data are linguistically implausible or mislabeled, the model may learn spurious correlations. The authors note GPT2 resisted generating some error types, requiring fallback to rule-based methods.

### Mechanism 2: PPO-optimized generation yields high-quality errors
- **Claim:** PPO enables controlled generation of diverse, fluent sentences containing specific L1 errors.
- **Mechanism:** A DistilGPT2 model fine-tuned on REALEC is further optimized with PPO using a binary classifier (reward model) that scores the presence of the target error. This direct optimization produces on-topic erroneous sentences.
- **Core assumption:** The reward model reliably identifies the target error.
- **Evidence anchors:** Section 4.1 describes the PPO setup; Section 5.2 shows GPT-based augmentation achieves 71.81% F1, second only to the full RILEC; the corpus statistics list 4,583 GPT-based training sentences.
- **Break condition:** PPO failed for Tense Semantics and Transliteration, limiting its application to error types where the base LM can be guided effectively.

### Mechanism 3: Hybrid combination captures complementary patterns
- **Claim:** Combining PPO, rule-based, and LLM-based generations leverages the strengths of each, leading to the best detection performance.
- **Mechanism:** PPO provides diversity for three tags, rule-based reliably injects errors that are hard for neural models (tense, transliteration), and LLM prompting yields naturalistic contexts. Their union (RILEC) covers all five tags with high diversity.
- **Core assumption:** Errors from different sources are consistent with the annotation schema and represent the true error distribution.
- **Evidence anchors:** Abstract and Section 5.2 report that the full RILEC (average F1 73.95%) outperforms individual augmentation subsets (71.81% GPT, 71.16% LLM, 65.98% rule). Table 3 shows the composition of the final dataset.
- **Break condition:** Poor integration (e.g., one method introduces systematic noise) could harm performance; however, the paper observed positive synergy.

## Architecture Onboarding
### Component map
REALEC data & REALEC-L1 annotations -> Augmentation Pipeline -> RILEC dataset -> RoBERTa span classification (SpaCy) -> Evaluation

### Critical path
1. Acquire REALEC and REALEC-L1 annotations.
2. For each error type, select augmentation method: PPO (Copying Expression, Synonyms, Word Form Transmission), rule-based (Tense Semantics, Transliteration), LLM (optional diversity).
3. Generate synthetic sentences with quality filters, deduplicate.
4. Combine with real data to form RILEC, ensuring no train/test leakage.
5. Fine-tune RoBERTa on the training split (batch size 128, 10 epochs).
6. Evaluate on REALEC-L1 test and external sets; analyze per-tag performance.
7. If results are unsatisfactory, adjust augmentation mix or PPO hyperparameters.

### Design tradeoffs
- **Synthetic data quality vs. quantity:** Rule-based generates many examples but may be less diverse; PPO yields fewer but more diverse errors; LLM adds natural contexts.
- **Computational cost:** PPO and LLM prompting are expensive; rule-based is cheap.
- **Annotation consistency:** Using Mistral to auto-annotate LLM-generated data risks propagated errors; manual checks were performed on samples.
- **Model choice:** DistilGPT2 used for PPO for efficiency; it fine‑tuned better than GPT2.

### Failure signatures
- Low inter‑annotator agreement (kappa < 0.7) on REALEC-L1.
- PPO reward model fails to improve or generates off‑target errors.
- Synthetic data have high Self‑BLEU (>20) or low MAUVE (<0.4) relative to REALEC-L1.
- Overfitting: large gap between train and test F1 (e.g., rule‑based train 78.53 vs test 65.98).
- LLM generation low success rate (e.g., GPT‑3.5 failed completely).

### First 3 experiments
1. **Baseline:** Train RoBERTa on REALEC-L1 only → expected F1 ~55.66%.
2. **Single‑augmentation ablation:** Train separate models on each synthetic subset (GPT‑based, rule‑based, LLM‑based) → compare F1s (GPT ~71.81%, rule ~65.98%, LLM ~71.16%).
3. **Combined augmentation:** Train on full RILEC → expected F1 ~73.95%.

## Open Questions the Paper Calls Out
1. **Extending RILEC to other L1 backgrounds**  
   *Basis:* Future work aims to include diverse L1s using resources like ICNALE.  
   *Why unresolved:* Current tags and generation are Russian‑specific; cross‑linguistic differences may require new categories.  
   *What evidence would resolve:* Multi‑L1 annotated corpora, transfer learning evaluations, comparative analysis of interference patterns.

2. **Improving neural generation for all five error types**  
   *Basis:* GPT2‑based PPO failed for Tense Semantics and Transliteration.  
   *Why unresolved:* The model resists generating these ungrammatical/natural constructions.  
   *What evidence would resolve:* Systematic comparison of alternative models (T5, BART), modified RL rewards, or hybrid generation.

3. **Low detection scores for semantic/ collocational errors**  
   *Basis:* Copying Expression (33.33% F1) and Synonyms (69.39% F1) lag behind other tags.  
   *Why unresolved:* These errors require nuanced L1‑L2 mappings beyond surface patterns.  
   *What evidence would resolve:* Error analysis, ablation with linguistic features (syntax, semantics), expanding the annotation scheme.

4. **Distributional shift between synthetic and real data**  
   *Basis:* Synthetic data differ from REALEC‑L1; performance on REALEC70 varies.  
   *Why unresolved:* Synthetic data may introduce artificial patterns or lack complexity of genuine errors.  
   *What evidence would resolve:* Controlled experiments comparing different augmentation mixes on multiple out‑of‑domain corpora, with detailed error analysis.

## Limitations
- **Synthetic fidelity:** Limited human evaluation; plausibility and L1 authenticity of generated errors remain partly unverified.
- **PPO applicability:** PPO fails for two error types (Tense Semantics, Transliteration), restricting neural augmentation.
- **Reproducibility:** Missing hyperparameters and prompts; proprietary API usage hinders exact replication.

## Confidence
- **Augmentation improves detection (F1 +18.29 pp):** High
- **PPO generates high‑quality errors (F1 up to 90.48% on Word Form Transmission):** High
- **Hybrid combination yields best performance (73.95% F1):** High
