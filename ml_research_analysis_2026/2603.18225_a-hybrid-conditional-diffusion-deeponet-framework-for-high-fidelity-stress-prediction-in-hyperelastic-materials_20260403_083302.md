# A Hybrid Conditional Diffusion-DeepONet Framework for High-Fidelity Stress Prediction in Hyperelastic Materials

## Quick Facts
- **arXiv ID:** 2603.18225  
- **Source URL:** https://arxiv.org/abs/2603.18225  
- **Reference count:** 40  
- **Primary result:** Hybrid cDDPM-DeepONet reduces mean absolute error by 86–99% compared to UNet and standalone diffusion baselines, achieves relative MAE below 1%, and accurately recovers peak stresses with errors around 2%, while demonstrating superior spectral fidelity across all wavenumbers.

## Executive Summary
This paper tackles the problem of predicting full-field von Mises stress in hyperelastic materials with complex microstructures (e.g., polygonal voids). Traditional surrogates like UNet oversmooth sharp stress gradients near voids, while DeepONet suffers from spectral bias, failing to capture high-frequency components. The authors propose a hybrid framework, cDDPM-DeepONet, that decouples the prediction of stress field morphology (spatial pattern) from its global magnitude scale. A conditional denoising diffusion probabilistic model (cDDPM) generates normalized stress fields conditioned on geometry and loading, preserving fine details. A DeepONet separately predicts the global minimum and maximum stress values used to linearly rescale the normalized field. Evaluated on synthetic finite element simulations of single- and multiple-void specimens, the hybrid model significantly outperforms baselines in accuracy, peak stress prediction, and spectral fidelity.

## Method Summary
The method involves three main steps. First, a dataset of stress fields is generated via FEniCS finite element simulations on 2D domains with random polygonal voids, using a compressible Neo-Hookean hyperelastic model under tensile loading. Stress fields are computed on a uniform grid (e.g., 128×128). Second, two neural networks are trained independently: (1) a conditional DDPM with a UNet backbone learns to denoise and generate *normalized* von Mises stress fields, conditioned on a 2-channel input (geometry mask and loading magnitude) via a CNN encoder embedding. (2) A DeepONet, with a branch network processing the same 2-channel input and a trunk network processing coordinate queries, is trained to predict the global minimum and maximum stress values. Third, at inference, the diffusion model produces a normalized stress field, the DeepONet outputs the scaling parameters, and final stress is obtained via linear rescaling: `σ_vM = σ_norm * (max_pred - min_pred) + min_pred`. Both networks use L1 loss.

## Key Results
- The hybrid model reduces mean absolute error (MAE) by 86–99% compared to UNet and standalone diffusion baselines across single- and multiple-void datasets.
- It achieves relative MAE (RelMAE) below 1% and peak absolute error (PAE) around 2%, accurately capturing localized stress concentrations.
- Spectral analysis via 1D isotropic energy spectra shows Area-between-curves (Ac) metric ~4.42 for the hybrid model versus ~5.26 for UNet, confirming superior preservation of high-frequency components.

## Why This Works (Mechanism)
The hybrid framework succeeds by strategically decoupling two distinct aspects of stress prediction: spatial morphology (the pattern of stress concentrations) and global magnitude scaling (the range of stress values). The conditional diffusion model (cDDPM) excels at generating realistic, high-frequency morphological patterns because it operates on normalized fields where the scale is removed, allowing it to focus purely on spatial structure without being constrained by magnitude. This avoids the oversmoothing tendency of deterministic surrogates like UNet. Conversely, the DeepONet specializes in learning the mapping from geometry and loading to the global min/max stress values, a low-dimensional, global quantity that is less susceptible to the spectral bias that plagues operator networks when approximating high-frequency functions. By recombining these two specialized predictions, the system achieves both detailed morphological fidelity and accurate magnitude scaling.

## Architecture Onboarding
**Component Map**  
Geometry + Loading -> CNN Encoder -> ζ_emb -> Conditional DDPM (UNet + Timestep) -> σ_norm  
Geometry + Loading -> DeepONet Branch (UNet encoder) + Trunk (MLP) -> [min_pred, max_pred]  
σ_norm + [min_pred, max_pred] -> Linear Rescaling -> σ_vM (final stress)

**Critical Path**  
1. Dataset generation via FEM (FEniCS) with varied void geometries and loads.  
2. Train cDDPM: noisy normalized stress + ζ_emb -> denoised normalized stress.  
3. Train DeepONet: geometry+load embedding -> min/max scalars.  
4. Inference: sample normalized field from cDDPM, get scalars from DeepONet, rescale.

**Design Tradeoffs**  
- *Decoupling vs Complexity:* Separating morphology and scale simplifies each sub-task but requires careful normalization and introduces two training stages.  
- *Diffusion Sampling Cost:* cDDPM requires multiple reverse diffusion steps (e.g., T=100), increasing inference time versus a single-pass UNet.  
- *UNet Capacity:* cDDPM's UNet must be sufficiently deep/wide with attention to capture fine details; too small loses high-frequency content.  
- *DeepONet Branch Design:* Using a UNet encoder for the branch extracts geometric features effectively but may overfit if not regularized.

**Failure Signatures**  
- cDDPM produces noise or incorrect patterns (e.g., missing void-induced concentrations) if conditioning embedding is weak or UNet too shallow. *Diagnostic:* High L1 loss on normalized fields; visual inspection of samples.  
- DeepONet min/max predictions are inaccurate (large deviation from FEM extrema), causing overall rescaling error. *Diagnostic:* Scatter plot of predicted vs true min/max; high PAE in final output.  
- Spectral Ac metric remains high (close to UNet baseline), indicating high-frequency content lost. *Diagnostic:* Compare 1D spectra; missing high-k tail suggests cDDPM undersmoothing or normalization error.

**First 3 Experiments**  
1. **Normalization Verification:** Compute per-sample mean and standard deviation of normalized stress fields from cDDPM; confirm they are approximately 0 and 1 respectively.  
2. **Conditioning Ablation:** Train cDDPM without ζ_emb (or with random ζ_emb). Expected failure: outputs become independent of geometry/load, yielding random-like fields.  
3. **Scaling Isolation Test:** Evaluate cDDPM using *true* FEM min/max for rescaling (oracle). If MAE drops significantly compared to using predicted min/max, confirms DeepONet is the bottleneck.
