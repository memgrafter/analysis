# ES-Merging: Biological MLLM Merging via Embedding Space Signals

## Quick Facts
- arXiv ID: 2603.14405
- Source URL: https://arxiv.org/abs/2603.14405
- Reference count: 40
- Primary result: ES-Merging achieves state-of-the-art cross-modal reasoning on biological benchmarks (e.g., 65.7% accuracy on molecule-protein, 87.4% on molecule-cell), outperforming existing merging methods and fine-tuned models.

## Executive Summary
Biological multimodal large language models (MLLMs) are typically trained for specific modalities (molecule, protein, cell), limiting their ability to perform cross-modal reasoning. Existing model merging approaches rely on input-agnostic parameter heuristics (e.g., magnitude, sign) that fail to capture nuanced modality-specific expertise. ES-Merging addresses this by deriving merging coefficients directly from embedding-space signals. A multi-modality probe input is forwarded through both a base LLM and specialized MLLMs to extract layer-wise token embeddings. Coarse-grained layer coefficients are computed via sliced Wasserstein distance between embedding distributions, while fine-grained element coefficients come from gradient sensitivity to embedding discrepancies. These signals are combined and used to merge LoRA parameters without additional training. On interactive effect prediction and CYP inhibition benchmarks, ES-Merging surpasses prior merging methods and even matches or exceeds task-specific fine-tuning, demonstrating that embedding-space analysis can effectively preserve and combine modality-specific knowledge.

## Method Summary
ES-Merging constructs a probe input by sampling raw data from each modality, encoding it via modality-specific encoders into token embeddings, and concatenating these with text prefixes. This probe is forwarded through a base LLM and each specialized MLLM to extract embeddings for each modality’s tokens at every transformer layer. For layer-wise coefficients, mean-pooled embeddings per layer and model are compared using sliced Wasserstein distance (SWD); the incremental change in SWD across layers indicates each layer’s contribution to modality-specific processing. For element-wise coefficients, the Frobenius norm distance between fine-grained embeddings (base vs. specialized) is computed per sample, and the absolute gradient of this distance w.r.t. each LoRA parameter element is accumulated. After normalization, layer and element coefficients are multiplied and renormalized across modalities to produce final merging weights. These weights are applied to linearly combine LoRA parameters from all specialists into a unified model.

## Key Results
- On instance-varying cross-modal tasks (molecule-protein, molecule-cell), ES-Merging reaches average accuracy 65.7% and 87.4%, surpassing task-specific fine-tuned models (60.5%, 87.5%) and other merging baselines.
- It achieves strong performance on CYP inhibition/substrate tasks, consistently matching or exceeding fine-tuned models and parameter-heuristic merging.
- Ablations confirm that combining coarse-grained (layer-wise) and fine-grained (element-wise) signals yields the best results, validating the multi-granularity design.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: Modality-specific specialization is encoded in the input-aware embedding space, not solely in parameter magnitudes or signs.
- **Mechanism**: A probe input containing tokens from all modalities is forwarded through the base LLM and each modality-specialized MLLM. Layer-wise token embeddings are extracted. Differences in these embedding distributions between base and specialized models reflect the degree of modality-specific adaptation.
- **Core assumption**: The way a model transforms modality tokens in its hidden layers reveals its expertise for that modality, and this signal is richer than static parameter statistics.
- **Evidence anchors**: [abstract] “embedding distribution distance between the base LLM and each specialized MLLM under specialized and non-specialized token inputs”; [section 4.1] “By forwarding this input through each MLLM and the base LLM, we obtain layer-wise embeddings that reflect modality-specific representation changes.”
- **Break condition**: If the probe input fails to activate modality-specific pathways (e.g., tokens are not meaningful to the specialized encoders), the embedding shifts will not correlate with true specialization, leading to poor coefficient estimation.

### Mechanism 2
- **Claim**: Coarse-grained, layer-level importance for merging can be derived from the magnitude of embedding distribution shifts across layers.
- **Mechanism**: For each modality, mean-pooled embeddings across probe samples are computed per layer for base and specialized models. Sliced Wasserstein Distance (SWD) between these distributions is calculated. The layer-wise change in SWD (ΔSWD) indicates how much new modality-specific transformation is introduced at that layer. After Z-score normalization across layers, these scores are aggregated over modalities and softmax-normalized into a layer-wise merging coefficient.
- **Core assumption**: A layer that induces a larger incremental shift in the coarse embedding distribution (from base to specialized) is more critical for that modality’s processing.
- **Evidence anchors**: [section 4.2] “We quantify their representational gap using the embedding distribution distance with sliced Wasserstein distance (SWD)... A larger value indicates that θmj induces a stronger layer-wise shift.”
- **Break condition**: If SWD is an unreliable estimator for high-dimensional embeddings or modality specialization is distributed evenly across layers, the ΔSWD signal will be noisy and layer coefficients will not meaningfully differentiate importance.

### Mechanism 3
- **Claim**: Fine-grained, element-level importance for merging can be derived from the sensitivity of fine-grained embedding distances to individual parameter elements.
- **Mechanism**: The Frobenius norm distance between full token embedding tensors (base vs. specialized) is computed per probe sample. The absolute gradient of this distance w.r.t. each parameter element is accumulated over all modalities and samples. Larger gradient magnitudes indicate stronger influence on the embedding discrepancy. After Z-score normalization per layer, these are softmax-normalized into element-wise merging coefficients.
- **Core assumption**: Parameters that, when perturbed, cause larger changes in the embedding-distance metric are more critical for maintaining the specialized model’s representation behavior.
- **Evidence anchors**: [section 4.3] “We estimate the importance of each parameter element by measuring how sensitive this distance is to that element... A larger score indicates that the parameter element is more sensitive.”
- **Break condition**: If the embedding distance metric is not smooth or well-behaved w.r.t. parameters (e.g., due to activation saturation), the gradient signal will be uninformative or vanish.

## Foundational Learning
- **Token Embedding Space and Cross-Modal Interface**: In MLLMs, modality-specific encoders project raw data (SMILES, sequences) into token embeddings that are processed by a shared LLM backbone. Expertise resides in how these embeddings are transformed across layers. *Why needed here*: ES-Merging’s premise is that modality-specific knowledge is reflected in embedding-space differences. *Quick check*: “If a molecule encoder projects a SMILES string to vectors, where does ‘molecular’ expertise primarily manifest—in the token embeddings themselves or in how subsequent layers transform them?”
- **Distributional Distance Metric (Sliced Wasserstein Distance)**: SWD measures the distance between two distributions by projecting them onto random 1D lines and computing Wasserstein distances. It is more robust for high-dimensional data than simple mean differences. *Why needed here*: SWD quantifies coarse-grained embedding distribution shifts between base and specialized models. *Quick check*: “Why might Euclidean distance between mean-pooled embeddings be insufficient for capturing representational shift, and how does projecting onto random lines help?”
- **Gradient-based Sensitivity Analysis**: The gradient of a output metric w.r.t. parameters indicates their influence. Larger absolute gradients suggest higher importance. *Why needed here*: Element-wise coefficients rely on ∂(embedding distance)/∂(parameter) to identify sensitive LoRA elements. *Quick check*: “In ∂r/∂θ, if a small change in θ leads to a large change in embedding distance r, what does that imply about θ’s role?”

## Architecture Onboarding

**Component map**:
Probe Constructor -> Embedding Extractor -> Layer Coefficient Calculator (Coarse) -> Element Coefficient Calculator (Fine) -> Coefficient Integrator -> Merger

**Critical path**: Probe Input -> Embedding Extraction (for all models) -> Layer Coefficient Path (Mean-pool -> SWD -> ΔSWD -> α) AND Element Coefficient Path (Per-sample distance -> Gradient accumulation -> β) -> Integration (α × β renormalized) -> Final Merged LoRA Weights.

**Design tradeoffs**:
- SWD projection size vs. cost: Larger projection sizes (e.g., 1024) improve distribution estimates but increase compute.
- Probe sample count vs. signal stability: More samples (110/modality used) stabilize SWD and gradient estimates but add forward/backward cost.
- Granularity vs. robustness: Element-wise coefficients are precise but potentially noisier; layer-wise are robust but coarse. Multiplication amplifies high-confidence regions but could suppress important elements if one signal is weak.

**Failure signatures**:
- Uniform α/β: If coefficients become nearly uniform after normalization, embedding signals are not discriminative—likely due to uninformative probe input or overly similar models.
- Degraded single-modality performance: While paper focuses on cross-modal tasks, loss of specialist performance on native modalities would indicate over-merging or incorrect coefficients.
- High computational cost: Element-wise path requires backward passes; memory/time constraints make this a bottleneck despite being cheaper than some baselines.

## Open Questions the Paper Calls Out
- Can ES-Merging generalize to non-biological multi-modal domains like video, image, and audio? (Limitation: not explored due to lack of cross-modal benchmarks.)
- Does ES-Merging preserve or degrade performance on individual single-modality tasks after merging? (Limitation: preservation on native modalities remains unevaluated.)
- How sensitive are the estimated merging coefficients to the design of the probe input? (Inferred: probe construction details lack ablation on sample size, token order, etc.)
- Can ES-Merging scale to many modalities or highly heterogeneous modality domains? (Inferred: Experiments merge only three related biomodalities; behavior with more modalities or larger domain gaps unknown.)

## Limitations
- Probe input construction details are underspecified (e.g., exact test sets, stratification, concatenation template), risking inconsistent coefficient estimation.
- SWD implementation specifics (number of projections, handling variable token lengths) are missing; SWD may fail to capture subtle shifts if specialization is distributed.
- Gradient-based element coefficient stability is uncertain; embeddings may yield vanishing/noisy gradients, especially with small LoRA magnitudes. Batch processing details are unclear.

## Confidence
- Modality-specific expertise resides in embedding space: Medium
- Layer-wise ΔSWD captures coarse-grained importance: Medium
- Element-wise gradient sensitivity captures fine-grained importance: Medium
- Overall performance superiority over baselines: Medium

## Next Checks
1. Probe sensitivity analysis: Vary probe sample size (10, 50, 110, 200) and measure variance of α/β coefficients and downstream accuracy to ensure robustness.
2. Distance metric ablation: Replace SWD with MMD (Gaussian kernel) and compare layer-wise coefficients and final performance; a significant drop would indicate SWD is critical.
3. Parameter intervention test: Intentionally zero out LoRA parameters in specific layers/modules of a specialized model and confirm that β coefficients for those parameters decrease substantially, validating gradient sensitivity.
