# Can Embedding Similarity Predict Cross-Lingual Transfer? A Systematic Study on African Languages
## Quick Facts
- **arXiv ID:** 2601.03168
- **Source URL:** https://arxiv.org/abs/2601.03168
- **Reference count:** 19
- **Primary result:** Embedding similarity metrics (e.g., cosine gap) reliably predict zero-shot cross-lingual transfer for African languages on NER and POS tasks, but pooling across models leads to Simpson’s Paradox; embedding metrics perform comparably to URIEL linguistic distances.

## Executive Summary
This study tackles the problem of selecting an optimal source language for zero-shot cross-lingual transfer to African languages, where linguistic diversity often leads to unreliable choices. The authors evaluate five embedding similarity metrics—cosine gap, P@1, CSLS, CKA, and cosine mean—by computing them on parallel FLORES-200 sentences and correlating them with actual downstream task performance across 816 experiments (12 languages, 3 models, 3 tasks). Strong correlations (Spearman ρ = 0.4–0.6) are found for cosine gap, P@1, and CSLS on named entity recognition (NER) and part-of-speech (POS) tagging, while CKA shows negligible predictive power. A critical warning emerges: pooling results across models reverses correlation signs (Simpson’s Paradox), mandating model-specific analysis. Embedding-based predictors match the performance of traditional URIEL linguistic distances. In a practical highlight, cosine gap identifies the best source language for AfriBERTa NER 50% of the time, far exceeding the 9% random baseline.

## Method Summary
The study uses parallel sentences from the FLORES-200 devtest set (1,012 sentences per language) to extract mean-pooled, L2-normalized embeddings from the final layer of three African‑centric multilingual models: AfriBERTa, AfroXLM‑R, and Serengeti. Five similarity metrics are computed for each language pair. Zero‑shot transfer experiments are then conducted: for every source language, the model is fine‑tuned on the training data of a downstream task (MasakhaNER 2.0, MasakhaPOS, or AfriSenti) and evaluated on all target languages’ test sets. This yields 816 unique model‑task‑source‑target combinations. Spearman’s rank correlation (ρ) between each metric and the observed downstream performance (F1 for NER and sentiment, accuracy for POS) is calculated. The authors compare these correlations against those obtained using URIEL linguistic distances and emphasize the need to stratify analysis by model to avoid Simpson’s Paradox.

## Key Results
- Cosine gap, P@1, and CSLS show moderate to strong correlation (ρ = 0.4–0.6) with transfer performance for NER and POS tasks.
- CKA exhibits negligible predictive power (ρ ≈ 0.1) across all tasks.
- Pooling results across models reverses correlation signs (Simpson’s Paradox); per‑model analysis is essential.
- Embedding similarity metrics achieve predictive power comparable to URIEL linguistic distances.
- For AfriBERTa NER, cosine gap selects the best source language in 50% of top‑1 trials versus a 9% random baseline.

## Why This Works
Embedding similarity metrics capture the alignment between language representations in a multilingual model. When source and target languages occupy similar regions in the embedding space, knowledge transferred from the source fine‑tunes more effectively, leading to higher downstream performance. Cosine gap and CSLS are particularly robust because they mitigate the hubness problem and focus on relative neighbourhood density. The breakdown of CKA suggests that linear kernel-based HSIC may be insensitive to the subtle sentence‑level alignment captured by functional tasks. Simpson’s Paradox arises because each model internalizes cross‑lingual correspondence differently; aggregating them obscures the true relationship between similarity and transfer. By analysing per model, the study reveals that embedding similarities are indeed predictive, aligning with the theoretical expectation that a well‑aligned multilingual space should facilitate zero‑shot transfer.

## Architecture Onboarding
### Component Map
FLORES‑200 dataset → Multilingual model (AfriBERTa/AfroXLM‑R/Serengeti) → Embedding extraction (mean‑pooled, L2‑normalized final layer) → Similarity metric computation (cosine_mean, cosine_gap, P@1, CSLS, CKA) → Zero‑shot transfer pipeline (fine‑tune on source task data, evaluate on target) → Correlation analysis (Spearman ρ) → Comparison with URIEL distances.

### Critical Path
1. Compute embeddings for all language pairs on FLORES‑200.
2. Compute each similarity metric for every pair.
3. For each model‑task combination, run zero‑shot fine‑tuning for every source language and evaluate on every target language.
4. Correlate metric scores with performance scores separately per model‑task.
5. Identify predictive metrics and compare their correlation strength to URIEL linguistic distances.

### Design Tradeoffs
- **Domain mismatch**: FLORES‑200 (formal translation) vs. downstream user‑generated data (e.g., Twitter in AfriSenti) may reduce the relevance of embedding similarities.
- **Single‑run evaluation**: Each configuration is run once; no seed averaging, which risks inflated or unstable correlations.
- **Per‑model stratification**: Necessary to avoid Simpson’s Paradox but limits cross‑model generalization; the study prioritizes internal validity over broad applicability.
- **Metric diversity**: Testing five metrics provides breadth; however, some (e.g., CKA) may be inherently less suited to sentence‑level alignment.

### Failure Signatures
- Correlation sign flips when aggregating across models (Simpson’s Paradox).
- CKA correlations remain near zero across all tasks, suggesting implementation issues or insensitivity.
- High variance in reported ρ across different random seeds if not averaged.
- Inconsistent tokenization or label mapping between FLORES‑200 and task datasets leading to misaligned embeddings.

### First Experiments
1. Replicate embedding metric computation for the AfriBERTa‑NER combination; verify that the reported Spearman ρ for cosine_gap falls within the range 0.4–0.6.
2. Compute both per‑model and pooled correlations for the NER task; confirm that pooled correlations become negative or near zero while per‑model remain positive.
3. Use cosine_gap to select the top source language for AfriBERTa NER on a held‑out target language; check that the top‑1 accuracy is at least 50%, compared to a 9% random baseline.

## Limitations
- Domain mismatch: FLORES‑200 formal text may not reflect the linguistic characteristics of MasakhaPOS or AfriSenti (user‑generated/Twitter), potentially weakening embedding‑based predictions.
- Implementation variance: Single runs per configuration without seed averaging could overestimate the reliability of observed correlations.
- CKA’s null result remains unexplained; it may reflect estimator insensitivity to sentence‑level semantics or task‑specific factors.

## Confidence
- **Embedding metrics predict transfer (NER/POS)**: Medium
- **Simpson’s Paradox reversal**: High
- **Equivalence to URIEL distances**: Medium
