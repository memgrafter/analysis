# LARFT: Closing the Cognition-Action Gap for Length Instruction Following in Large Language Models

## Quick Facts
- **arXiv ID:** 2603.19255
- **Source URL:** https://arxiv.org/abs/2603.19255
- **Reference count:** 40
- **Primary result:** LARFT improves length instruction following by an average of +20.92 points over untuned models and +4.59 over the strongest RL baseline, with a marginal -1.45 point drop on general capability benchmarks.

## Executive Summary
Large language models (LLMs) lack intrinsic cognition of output length, creating a gap between user length constraints and generated text. LARFT addresses this via Length-Aware Reinforcement Fine-Tuning. It combines Group Relative Policy Optimization (GRPO) with a verifiable word-count reward and a hindsight self-awareness mechanism where models are trained to count their own generated text. This aligns an internal length representation with the generation policy. Across four base models and three length benchmarks, LARFT significantly enhances precise length control while preserving most general capabilities.

## Method Summary
LARFT fine-tunes on a curated dataset of 8,732 English/Chinese prompts with explicit word/character count targets (10–4,000). Training interleaves two objectives: (1) a reinforcement learning loss (GRPO) that rewards rollouts based on the deviation between their detokenized word count and the target; (2) a supervised hindsight awareness loss that forces the model to predict the actual length of its own rollout. A cosine-annealed weight λt prioritizes the awareness loss early (to build a length representation) and the RL loss late (to refine generation policy). The unified loss L_unified = L_GRPO + λ_t * L_aware is optimized end-to-end.

## Key Results
- **Superior length following:** Average improvement of +20.92 Length Score points over untuned baselines.
- **Beats strong RL:** +4.59 point gain over the best RL-only baseline across benchmarks.
- **Minimal capability degradation:** Only -1.45 average point drop on four general benchmarks (MMLU, GSM8K, IFEval, GPQA).

## Why This Works (Mechanism)

### Mechanism 1: Length-Oriented Reinforcement Learning with Verifiable Reward
The model generates multiple candidate sequences per prompt. A piecewise-linear reward R_len(τ, c) = max(0, 1 - |L(τ)-c|/c) is computed from the detokenized word count L(τ). Group Relative Policy Optimization (GRPO) uses the mean and standard deviation of rewards within each rollout group to normalize advantages, providing a stable learning signal. This directly optimizes the generation policy for length adherence. Break condition: If all rollouts in a group have similarly poor lengths, the advantage signal becomes uninformative and training stalls.

### Mechanism 2: Hindsight Length Awareness
On-policy rollouts are repurposed into a supervised self-counting task. Each generated text τ is concatenated with a prompt "Count how many words are in the text above?" to form input x_aware, with the label being the actual length L(τ) in XML format. The model is trained to predict this label, forcing the network to activate and refine pathways dedicated to an explicit length representation, separate from semantic generation. Break condition: If linear probing (Fig. 4) does not show improved length decodability in hidden states, especially in shallow layers, the mechanism fails to induce a usable internal signal.

### Mechanism 3: Unified Optimization with Curriculum Scheduling
The total loss combines GRPO and awareness losses with a cosine-annealed weight λt = (λ_max/2)*(1 + cos(tπ/T)). Early training (high λt) emphasizes building the length representation via the awareness loss; later training (low λt) shifts focus to policy refinement via RL rewards. This curriculum prevents the RL signal from overwhelming or the awareness task from interfering with semantic quality. Break condition: If ablating the schedule (using fixed λ) does not cause a significant performance drop, the dynamic balance is unnecessary.

## Foundational Learning
- **Reinforcement Learning from Verifiable Feedback (RLVR):** LARFT uses GRPO, a policy gradient algorithm, with a scalar reward rather than token-level cross-entropy. Understanding that RL operates on on-policy rollouts and updates via advantages is crucial. *Quick check:* Why might pure RL (GRPO with only R_len) still fail to achieve precise length control despite a well-designed reward?
- **Tokenization vs. Word Count Discrepancy:** The reward is defined on *word count* after detokenization (D(τ)), but the model generates *tokens*. This misalignment between the model’s internal token-length sense and the user’s word-length intent is part of the cognition gap. *Quick check:* If a model generates 100 tokens that detokenize to 80 words, what is the reward’s target? What does this imply for a model without a robust token-to-word mapping?
- **Autoregressive Decoding & Length Bias:** LLMs generate text token-by-token with inherent biases (e.g., premature EOS emission or verbosity). The "action" in the cognition-action gap is this autoregressive policy. *Quick check:* How does the autoregressive nature, where each token depends only on previous tokens, make guaranteeing an exact final word count difficult?
