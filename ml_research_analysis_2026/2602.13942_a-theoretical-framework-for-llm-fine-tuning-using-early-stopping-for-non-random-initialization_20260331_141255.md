# A Theoretical Framework for LLM Fine-tuning Using Early Stopping for Non-random Initialization

## Quick Facts
- **arXiv ID**: 2602.13942
- **Source URL**: https://arxiv.org/abs/2602.13942
- **Reference count**: 40
- **Primary result**: Convergence guarantee $\|f_{\text{bTop}} - f_{\text{tgt}}\|_2^2 \le O(N^{-1/2}_2)$ for fine-tuning with pretrained initialization

## Executive Summary
This paper develops a theoretical framework explaining why fine-tuning large language models (LLMs) with few epochs suffices. By combining early stopping theory with the attention-based Neural Tangent Kernel (NTK), the authors prove that pretrained models linearize around the target function and that convergence rate depends on the eigenvalue decay of the empirical NTK matrix. The framework explains empirical observations about task arithmetic and provides convergence guarantees for regression and classification tasks on GPT-Neo.

## Method Summary
The framework extends the NTK framework to non-random (pretrained) transformer decoders, proving that fine-tuned networks linearize around pretrained models. The core insight is that convergence rate depends on the eigenvalue decay rate of the empirical NTK matrix. Early stopping is theoretically justified as optimal when the target function lies within the span of the NTK's top eigenspace. The authors derive convergence guarantees showing error bounds that decay as $O(N^{-1/2}_2)$ where $N_2$ is the number of samples.

## Key Results
- Convergence guarantee $\|f_{\text{bTop}} - f_{\text{tgt}}\|_2^2 \le O(N^{-1/2}_2)$ for fine-tuning with pretrained initialization
- Tasks with faster eigenvalue decay (estimated $\beta$) achieve better performance with fewer samples
- Task arithmetic (negation/addition) explained via weight disentanglement; successful multi-task model construction when task vectors are nearly orthogonal

## Why This Works (Mechanism)
The framework leverages the linearization property of neural networks around pretrained models. When fine-tuning, the network remains close to the pretrained initialization due to the NTK's spectral properties. The eigenvalue decay of the empirical NTK matrix determines how well the target function can be approximated within the model's effective hypothesis space. Early stopping prevents overfitting beyond the point where the linear approximation breaks down.

## Foundational Learning
- **Neural Tangent Kernel (NTK)**: Needed to analyze the linearized dynamics of neural networks around initialization; quick check: verify the NTK matrix is positive semi-definite
- **Eigenvalue Decay Analysis**: Required to characterize the effective capacity of the model's function space; quick check: plot eigenvalue spectrum on log scale
- **Early Stopping Theory**: Provides theoretical justification for stopping criteria; quick check: verify validation loss minimum aligns with theoretical bounds
- **Transformer Decoder Architecture**: Essential for understanding attention mechanisms in the NTK; quick check: confirm attention weights remain stable during fine-tuning
- **Weight Disentanglement**: Explains task arithmetic phenomena; quick check: measure cosine similarity between task weight vectors
- **Function Approximation Theory**: Underpins the convergence guarantees; quick check: verify target function smoothness conditions

## Architecture Onboarding
**Component Map**: Pretrained Model -> NTK Linearization -> Early Stopping Criterion -> Task Weight Space
**Critical Path**: Model initialization → NTK matrix computation → Eigenvalue decomposition → Convergence analysis → Early stopping
**Design Tradeoffs**: Linearization accuracy vs. fine-tuning duration; eigenvalue decay vs. model capacity; orthogonality vs. interference in task arithmetic
**Failure Signatures**: Poor eigenvalue decay indicates insufficient model capacity; non-orthogonal task vectors suggest interference; early stopping too late indicates overfitting
**First Experiments**: 1) Compute NTK eigenvalue spectrum for your target task; 2) Measure cosine similarity between task weight vectors for arithmetic operations; 3) Plot validation loss vs. iteration to identify early stopping point

## Limitations
- Reliance on eigenvalue decay assumptions that may not hold for all tasks or architectures
- Linearization approximation becomes less accurate beyond early stopping
- Theory assumes target function lies within NTK's top eigenspace span
- Limited empirical validation to GPT-Neo on specific regression/classification tasks

## Confidence
**High Confidence**: Linearization property around pretrained models and NTK eigenvalue decay dependence are mathematically well-established
**Medium Confidence**: Empirical validation on GPT-Neo supports theory but sample size of tasks is limited
**Low Confidence**: Task arithmetic explanations lack rigorous theoretical justification for weight orthogonality leading to additive composition
