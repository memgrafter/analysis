# Learning with Boolean threshold functions
## Quick Facts
- arXiv ID: 2602.17493
- Source URL: https://arxiv.org/abs/2602.17493
- Reference count: 0
- Primary result: Constraint-based RRR training yields exact solutions on synthetic Boolean tasks (e.g., multipliers, cellular automata) and strong generalization on analog data like MNIST with sparse interpretable weights.

## Executive Summary
This paper introduces a constraint-based training framework for neural networks using Boolean threshold functions (BTFs) with strict ±1 activations and weights. The method reformulates learning as satisfying two constraints—local BTF consistency (with a margin bound) and architectural concurrence—via the reflect-reflect-relax (RRR) projection algorithm. A margin hyperparameter σ enforces sparsity, producing networks equivalent to simple logic gates. On tasks including multiplier circuit discovery, binary autoencoding, logic network inference, and cellular automata learning, the approach achieves exact solutions or strong generalization where gradient-based methods fail. For 5-layer random logic circuits (32-bit inputs), it reaches 100% test accuracy with at least 256 training examples, while gradient descent remains below 100% even with more data. The method also extends to analog data like MNIST, yielding interpretable sparse weights and competitive classification accuracy.

## Method Summary
Training is cast as a constrained optimization problem solved by the RRR algorithm, which iteratively projects weights onto two constraint sets: (1) local BTF consistency, ensuring each neuron's output aligns with a thresholded linear form with a margin σ, and (2) architectural concurrence, maintaining the prescribed network connectivity. Unlike gradient-based methods that optimize a continuous loss, RRR directly enforces discrete BTF properties through alternating projections, guaranteeing exact satisfaction of constraints at convergence. The margin σ controls sparsity by driving weights toward ±1, enabling the learned networks to mimic logic gates. This projection-based approach avoids local minima common in non-convex loss landscapes and achieves sample-efficient learning on Boolean functions.

## Key Results
- Achieves 100% test accuracy on multiplier circuit discovery, rule-30 cellular automata (one-step), and 5-layer random logic circuits (with ≥256 training examples), while gradient descent fails to reach 100% even with more data.
- On MNIST, produces sparse ±1 weights with 98.5% test accuracy, demonstrating interpretability and good generalization despite modest performance versus state-of-the-art.
- The constraint gap (violation measure) vanishes at solutions, confirming exact satisfaction of the BTF and architectural constraints.

## Why This Works (Mechanism)
The RRR algorithm's projection-based optimization directly enforces the discrete structure of BTFs, bypassing the continuous relaxations that plague gradient-based binary network training. By alternating between reflecting violated local BTF constraints (per-neuron threshold agreement) and relaxing architectural concurrence (weight connectivity), the method systematically reduces constraint violations without getting trapped in local minima. The margin σ acts as a sparsity regularizer, pushing weights to extreme values (±1) that correspond to simple logic operations. This constraint satisfaction paradigm ensures that the final network precisely implements the target Boolean function with minimal connectivity, yielding exact solutions on synthetic tasks and interpretable sparse representations on analog data.

## Foundational Learning
- **Boolean Threshold Functions (BTFs):** Neurons with sign activations and ±1 weights. *Why needed:* Enforces discrete, interpretable logic operations and eliminates non-binary weight values. *Quick check:* Verify each neuron's output equals sign(Σw_i x_i) with a margin.
- **Margin Hyperparameter σ:** Minimum separation required between positive and negative class scores. *Why needed:* Drives weights to ±1, enabling logic gate equivalence and controlling sparsity. *Quick check:* Inspect weight histogram for concentration at ±1 values.
- **Reflect-Reflect-Relax (RRR) Algorithm:** Iterative projection onto constraint sets via reflection and relaxation steps. *Why needed:* Solves constrained optimization without gradients, guaranteeing convergence for convex sets. *Quick check:* Monitor monotonic decrease in constraint gap per iteration.
- **Local BTF Consistency:** Per-neuron constraint ensuring output matches thresholded linear combination. *Why needed:* Guarantees each unit behaves as a valid BTF. *Quick check:* Compute per-neuron accuracy on a held-out Boolean sample.
- **Architectural Concurrence:** Constraint aligning weight matrix with network connectivity pattern. *Why needed:* Prevents degenerate solutions and maintains intended sparse architecture. *Quick check:* Compare weight sparsity pattern to adjacency matrix of network topology.
- **Projection onto Convex Sets:** Each constraint defines a convex feasible region. *Why needed:* Convergence of alternating projections is assured for convex sets. *Quick check:* individually project random weight vectors onto each constraint and verify feasibility.

## Architecture Onboarding
- **Component Map:** Training data -> Local BTF constraint projection -> Architectural concurrence projection -> Updated weights (iterative RRR loop) -> Converged BTF network.
- **Critical Path:** The RRR loop iterates: (1) reflect local BTF violations by projecting weights to satisfy per-neuron threshold margins, (2) relax architectural concurrence by projecting onto the weight support defined by network connectivity, repeating until both constraints are met.
- **Design Tradeoffs:** Higher σ increases sparsity but may reduce accuracy; more projection iterations improve constraint satisfaction but increase compute time; strict ±1 weights favor interpretability but may limit representation capacity for noisy analog data.
- **Failure Signatures:** Constraint gap plateaus above zero; test accuracy drops significantly below training accuracy; weights fail to concentrate at ±1; algorithm exceeds maximum iterations without convergence.
- **First Three Experiments:** 1) 2-bit multiplier circuit discovery to validate exact Boolean learning. 2) Rule-30 cellular automata (one-step prediction) to test sample-efficient generalization. 3) Binary autoencoder on MNIST to assess analog extension and weight sparsity.

## Limitations
- σ hyperparameter lacks systematic study; its impact on sparsity-accuracy trade-offs is unclear.
- Benchmarks are restricted to synthetic Boolean tasks and MNIST; performance on larger, noisier, or more complex datasets is unevaluated.
- Computational runtime and memory usage of RRR versus gradient-based methods, especially for deeper networks, are not reported.

## Confidence
- Exact Boolean learning (multipliers, CA, logic): **High** (100% test accuracy, vanishing constraint gap across multiple tasks).
- Scalability to 5-layer random circuits: **Medium** (success with ≥256 examples, but only one circuit size/depth examined).
- Analog extension (MNIST) and interpretability: **Low** (modest accuracy vs. baselines, interpretability claims qualitative).
