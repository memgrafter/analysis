# Unifying Formal Explanations: A Complexity-Theoretic Perspective
## Quick Facts
- **arXiv ID:** 2602.18160
- **Source URL:** https://arxiv.org/abs/2602.18160
- **Reference count:** 40
- **Primary result:** Formal explanations unify as minimizing a single probabilistic value function; global explanations are tractable (polynomial/constant-approx), while local ones are NP-hard and inapproximable under standard assumptions.

## Executive Summary
This paper presents a unified complexity-theoretic framework for formal explanations in machine learning. It introduces a single probabilistic value function that captures both sufficient (why an input was classified a certain way) and contrastive (why not another class) explanations, spanning local (instance-specific) and global (distributional) settings. The core finding is a sharp complexity separation: global value functions are monotonic and (super/sub)modular under feature independence, enabling polynomial-time computation and constant-factor approximation algorithms for subset- and cardinal-minimal explanations. In contrast, local value functions lack these properties, leading to NP-hardness and inapproximability even for simple models like decision trees. This establishes that global explainability is fundamentally more tractable than local explainability.

## Method Summary
The method centers on defining unified value functions \(v_\ell\) (local) and \(v_g\) (global) for four explanation types. For a model \(f\), distribution \(D\), and feature subset \(S\), \(v_g(S) = \mathbb{E}_{x\sim D}[ \Pr_{z\sim D}[\text{condition holds} \mid x_S] ]\) aggregates local probabilities over the distribution. The global expectation induces monotonicity and, under feature independence, (super/sub)modularity—key properties for efficient subset search. Algorithms exploit these: a greedy removal procedure (Algorithm 1) finds subset-minimal global explanations exactly; a greedy addition procedure (Algorithm 2) yields constant-factor approximations for cardinal-minimal ones. Local explanations lack these structural guarantees, proving intractable via reductions from classic NP-hard problems.

## Key Results
- Global sufficient/contrastive explanations are polynomially computable (subset-minimal) for neural networks, decision trees, and ensembles with empirical distributions.
- Local sufficient/contrastive explanations are NP-hard even for decision trees and admit no bounded-factor approximation for cardinal-minimal versions.
- Global value functions are monotonic and (super/sub)modular under feature independence; local ones are neither. This structural difference explains the complexity separation.
- For global contrastive reasons, a \(O(\ln|D|)\)-approximation exists; for global sufficient reasons, a constant-factor approximation holds under bounded curvature.

## Why This Works (Mechanism)
### Mechanism 1
**Claim:** Global probabilistic sufficient/contrastive reasons are efficiently computable because their value functions are monotonic and (super/sub)modular under feature independence.  
**Mechanism:** Monotonicity ensures adding features never decreases the value; supermodularity (sufficient) or submodularity (contrastive) ensures diminishing marginal returns. A monotonic submodular function allows a greedy algorithm to achieve a constant-factor approximation for the minimum set cover problem, which maps to finding a cardinally minimal explanation. The core assumption is feature independence (for modularity) and an empirical distribution (for tractable evaluation).  
**Evidence anchors:**  
- Abstract: "global value functions are monotonic and (super/sub)modular under feature independence... subset-minimal global explanations can be computed polynomially."  
- Section 6: Proposition 2 proves monotonicity; Proposition 3 shows `vg_suff` supermodular; Proposition 4 shows `vg_con` submodular under independence.  
- Corpus: Neighboring work linking explanations to modular optimization supports the structural link.  
**Break condition:** Feature dependence breaks modularity; non-empirical distributions may make evaluation intractable for complex models.

### Mechanism 2
**Claim:** Local probabilistic sufficient/contrastive reasons are NP-hard because their value functions are non-monotonic and lack combinatorial structure.  
**Mechanism:** Non-monotonicity means adding a feature can lower the value, invalidating greedy search guarantees. This prevents polynomial-time subset-minimal computation and leads to inapproximability (no bounded ratio) for cardinally minimal versions.  
**Evidence anchors:**  
- Section 6: Proposition 2 states local value functions are non-monotonic.  
- Section 7.1: Cites (Arenas et al., 2022) showing NP-hardness for local δ-sufficient reasons in decision trees.  
- Section 7.2: Theorems 3 and 4 show no bounded approximation for local cardinally minimal explanations.  
**Break condition:** If the model or distribution yields a monotonic local value function (rare), tractability could improve.

### Mechanism 3
**Claim:** Unification under a single value function `v` explains why global/local versions differ: the expectation over `x ∼ D` in `vg` induces monotonicity and super/submodularity, absent in `vℓ`.  
**Mechanism:** The global value `vg(S) = E_x[ Pr_z(... ) ]` averages local probabilities over all inputs, smoothing out non-monotonicities and enabling submodularity under independence. This structural difference maps global explanation tasks to classic combinatorial optimization (submodular set cover/supermodular cover) with known approximations.  
**Evidence anchors:**  
- Section 5: Defines unified value functions `vℓ`/`vg`.  
- Section 6: Props 2–4 prove monotonicity and modularity only for global `vg` under independence.  
- Section 7: Uses these to derive polynomial-time subset-minimal (Prop 6) and constant-approx (Thms 3,4) results for global.

## Foundational Learning
- **Concept:** Submodularity and Supermodularity  
  **Why needed:** They determine whether greedy algorithms give guarantees for minimization problems. Submodular -> constant-factor approx for set cover; supermodular -> approx only with bounded curvature.  
  **Quick check:** Given a value function `v`, how would you test if adding feature `t` has diminishing returns when `S ⊆ S'`? Write the inequality for submodularity: `v(S ∪ {t}) - v(S) ≥ v(S' ∪ {t}) - v(S')`.

- **Concept:** Monotonic (Non-decreasing) Value Functions  
  **Why needed:** Guarantees that greedy removal/addition steps preserve feasibility (`v(S) ≥ δ`) and ensures Algorithm 1 finds a subset-minimal solution.  
  **Quick check:** If `v(S ∪ {i}) < v(S)` for some `i ∉ S`, why can't a top-down greedy algorithm (Algorithm 1) be trusted to find minimal `S`? Because removing features might increase `v`, so a feature deemed "unnecessary" early could later be required to meet the threshold.

- **Concept:** Empirical Distributions in XAI  
  **Why needed:** They make `vg` evaluation polynomial (by iterating over dataset pairs) and anchor approximation bounds (`min_i v({i}) ≥ 1/|D|²`).  
  **Quick check:** How does replacing a true `D` with an empirical `D̂` change the computational cost of computing `vg(S)`? What is the lower bound on `vg({i})`? Cost becomes `O(|D|²)` pairwise evaluations; lower bound is `1/|D|²` because for any feature `i`, there exists at least one pair `(x,z)` where flipping `i` changes the label.

- **Concept:** Submodular Set Cover  
  **Why needed:** The global contrastive explanation problem reduces to minimizing `|S|` subject to `vg(S) ≥ δ` with `vg` submodular and monotonic, which is a submodular set cover.  
  **Quick check:** What classic greedy algorithm applies to submodular set cover, and what is its approximation factor? Greedy addition of features with largest marginal gain per unit cost; factor `O(ln(f(S*)/δ))` or `O(ln|D|)` in this setting.

- **Concept:** Supermodular Cover with Bounded Curvature  
  **Why needed:** Global sufficient reasons yield a supermodular `vg_suff`; minimization requires handling supermodularity via bounded curvature to get constant-factor approximations.  
  **Quick check:** If `vg_suff` is supermodular, why does a simple greedy algorithm fail? Because marginal gains increase with set size, so greedy may pick large sets early; bounded curvature limits this increase to enable constant-factor approx.

## Architecture Onboarding
- **Component map:**  
  Value function evaluator -> Monotonicity checker -> Modularity tester -> Greedy searcher -> (Optionally) Redundant feature remover  
  The evaluator computes `v(S)`; the checker and tester decide which algorithm to use; the searcher runs the appropriate greedy; the remover preprocesses to ensure finite `min v({i})`.

- **Critical path:**  
  1. Input: model `f` (NN/DT/ensemble), distribution `D` (empirical recommended), explanation type (global/local, sufficient/contrastive), threshold `δ`.  
  2. If global and `D` independent, expect monotonic+modular → use greedy with approx guarantees.  
  3. Compute `v({i})` for all `i`; remove zero-contribution features (if empirical) to keep bounds finite.  
  4. Run Algorithm 1 for exact subset-minimal global; run Algorithm 2 for cardinal-minimal global with approx guarantee.  
  5. For local, warn NP-hard; fall back to heuristics (not covered here).

- **Design tradeoffs:**  
  - Exact vs approx: Subset-minimal global (Alg 1) is exact but may yield larger `S`; cardinal-minimal (Alg 2) gives smaller `S` with provable approx factor.  
  - Distribution choice: Empirical enables polynomial `v` eval but approx factor ~ `O(ln|D|)`; independent allows analytic `v` but independence may be unrealistic.  
  - Model class: NN/ensembles need empirical `D` for polynomial `v`; decision trees handle independent `D` symbolically.

- **Failure signatures:**  
  - `v(S)` non-monotonic (e.g., local case) → greedy (Alg 1) may return non-minimal `S`.  
  - `min_i v({i}) ≈ 0` without preprocessing → approx factor blows up (→∞).  
  - Feature dependence → super/submodularity fails; approx guarantees void.

- **First 3 experiments:**  
  1. Monotonicity sanity check: For a small global model (e.g., DT) with independent `D`, compute `v(S)` for all `S` and verify `S⊆S' ⇒ v(S)≤v(S')`. Fails for local.  
  2. Global vs local runtime: On a mid-size NN (e.g., Fashion-MNIST subset), measure time for subset-minimal global (Alg 1) vs local (exhaustive search for small n, MIP for larger). Expect polynomial vs exponential.  
  3. Approximation validation: Construct a global sufficient reason instance via reduction from set cover; run Alg 2, compare `|S|` to optimal (solved via MIP for small n). Check ratio ≈ `O(ln|U|/δ)` or `O(1/(1-k_f) + ln|D|)`.

## Open Questions the Paper Calls Out
### Open Question 1
- Question: Can the tractable global explainability results be tightened to achieve exact polynomial-time computation for simpler model classes (e.g., decision trees, linear models) or tighter constant-factor approximation bounds under empirical distributions?
- Basis in paper: explicit
- Why unresolved: The paper shows global explanations are polynomial-time computable under empirical distributions but leaves open whether better complexity bounds exist for specific model families.
- What evidence would resolve it: New algorithms proving exact polynomial-time solvability for a given model class, or matching hardness results showing existing bounds are tight.

### Open Question 2
- Question: What approximation algorithms can compute global contrastive/sufficient reasons while maintaining minimality guarantees when exact expectation computation is infeasible, and what error tolerance levels still preserve provable approximation factors?
- Basis in paper: explicit
- Why unresolved: The paper assumes exact expectation computation over empirical distributions; practical settings often require sampling-based approximations, but the impact on minimality guarantees is unknown.
- What evidence would resolve it: Formal analysis showing that sampling with bounded error still yields the same approximation factor, or FPRAS schemes preserving the submodular/supermodular structure.

### Open Question 3
- Question: Do other feature importance measures (e.g., KL divergence-based, LIME-style) exhibit similar monotonicity, submodularity, or supermodularity properties when transitioning from local to global settings, enabling similar complexity separations?
- Basis in paper: explicit
- Why unresolved: The unified framework focuses on sufficient and contrastive reasons; its extension to alternative importance measures remains unexplored.
- What evidence would resolve it: Proofs that another measure (e.g., SHAP) shows analogous monotonicity/submodularity globally but not locally, or hardness results showing the separation is unique to the considered measures.

### Open Question 4
- Question: How robust are the global value functions' monotonicity and (sub/super)modularity properties to violations of feature independence? Can mild dependence conditions (e.g., weak correlation, Markovian structure) still guarantee these properties or weaker variants enabling approximation?
- Basis in paper: implicit (the feature independence assumption is necessary for submodularity/supermodularity per Propositions 3–4)
- Why unresolved: The paper proves that global sufficient reasons are supermodular only under independence; independence is strong and unrealistic for many real-world data, yet the boundary of tractability under dependence is unclear.
- What evidence would resolve it: Characterization of dependence classes (e.g., graphical models) where monotonicity still holds, or hardness results ruling out such guarantees under general dependencies.

### Open Question 5
- Question: Do the complexity separations between local and global explanations extend to other prediction tasks (e.g., regression, structured prediction) and to non-binary or continuous feature representations?
- Basis in paper: implicit (focuses on binary classification)
- Why unresolved: The paper’s model definitions and proofs assume binary/classification settings; regression outputs or multi-valued features may alter the value function properties and complexity landscapes.
- What evidence would resolve it: Generalizations of the definitions to regression with analogous monotonicity/submodularity proofs, or counterexamples showing the separation collapses for certain task/feature types.

## Limitations
- The tractability guarantees for global explanations critically depend on feature independence; real-world dependencies likely break super/submodularity and void approximation bounds.
- The NP-hardness of local explanations is worst-case; practical instances may sometimes be easier, but the framework provides no guide to identify such cases.
- Results assume empirical or independent distributions and binary classification; extension to continuous outcomes or non-tabular data (e.g., images, text) is not addressed.

## Confidence
- **High:** Global explanations are polynomially computable (subset-minimal) and admit constant-factor approximations due to monotonicity and super/submodularity under independence.
- **Medium:** Local explanations are NP-hard and inapproximable in general, based on cited complexity results and lack of structural guarantees.
- **Medium:** The unified value function framework correctly captures both sufficient and contrastive explanation types, given the formal definitions provided.
