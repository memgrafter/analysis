# An Automatic Text Classification Method Based on Hierarchical Taxonomies, Neural Networks and Document Embedding: The NETHIC Tool

## Quick Facts
*   **arXiv ID:** 2603.11770
*   **Source URL:** https://arxiv.org/abs/2603.11770
*   **Reference Count:** 35
*   **Primary Result:** Combining bag-of-words (BOW) with Doc2Vec document embeddings improved classification accuracy by ~2% on a large Wikipedia corpus, correctly classifying approximately 60 more documents than a BOW-only system.

## Executive Summary
NETHIC is a method for large-scale automatic text classification that uses a hierarchical taxonomy to structure a tiered system of specialized neural networks. Each network in the hierarchy is trained only on documents from its specific subtree, which reduces semantic noise from unrelated concepts. The core extension integrates a pre-trained Doc2Vec document embedding with the traditional bag-of-words (BOW) feature representation. Experiments on a 57,304-document Wikipedia corpus demonstrated that this combined feature set yielded a measurable accuracy gain over using BOW alone, with the most significant reductions in confusion observed between semantically close categories like Science, Art and Entertainment, Society, and Health and fitness.

## Method Summary
The method constructs a dataset by semantically mapping a predefined RDF taxonomy to Wikipedia's category graph, retrieving documents along shortest paths to create a balanced, hierarchical folder structure. For classification, it employs a separate multi-layer perceptron (MLP) neural network for every non-leaf node in the taxonomy. An input document is first transformed into a composite feature vector: a BOW vector built from a dictionary specific to the current taxonomy path, concatenated with a fixed 300-dimensional Doc2Vec embedding. The document then traverses the hierarchy starting at the root network; at each node, if the network's confidence score is below a threshold (0.7), the document is passed to the child network with the highest score, building a classification path until a leaf is reached. This path-based approach outputs the top three probable leaf categories.

## Key Results
*   The combined BOW+Doc2Vec model improved overall classification accuracy by approximately 2% compared to the original BOW-only system on a validation set of 2,843 documents.
*   This corresponded to roughly 60 additional documents being correctly classified.
*   Confusion matrix analysis showed reduced misclassification between semantically adjacent classes (e.g., Health and fitness vs. Society) when using the combined feature set.

## Why This Works (Mechanism)

### Mechanism 1: Hierarchical Neural Network Alignment
Aligning specialized neural networks with each non-leaf node in a taxonomy reduces semantic noise by training on contextually relevant sub-corpora. For every intermediate taxonomy category (e.g., "Sports"), a separate neural network is trained using documents only from its descendant leaves. Dictionaries are built per network, with upper levels using generic terms and deeper levels using specific terms, isolating decision boundaries. The core assumption is that hierarchical decomposition prevents interference from semantically distant concepts. Evidence includes the abstract's statement on reducing noise and Section 4.2's description of vocabulary granularity. Confusion matrix analysis (Section 5.1) showing reduced confusion between close classes supports this. A break condition is ambiguous or overlapping parent-child relationships in the taxonomy.

### Mechanism 2: Combined BOW and Doc2Vec Feature Representation
Concatenating bag-of-words (BOW) frequencies with Doc2Vec embeddings improves classification accuracy by leveraging both lexical precision and semantic context. Input documents are transformed into composite vectors: BOW captures word occurrence patterns via dictionaries specific to each taxonomy path, while Doc2Vec adds a fixed 300-dimensional semantic vector from a pre-trained model. The core assumption is that BOW alone misses latent semantic relationships, while Doc2Vec alone lacks discriminative keyword signals; their combination mitigates individual weaknesses. Evidence is the abstract's description of the core extension and Section 4.4/4.5 showing BOW+Doc2Vec models achieved ~2% higher accuracy. Doc2Vec alone performed worst, indicating its insufficiency for this fine-grained, multi-class task without lexical cues.

### Mechanism 3: Taxonomy-Guided Corpus Construction from Wikipedia
Mapping a predefined RDF taxonomy to Wikipedia's category graph enables scalable, balanced dataset creation that mirrors hierarchical structure. Starting from leaf categories, SKOS mappings link to Wikipedia categories. Documents are recursively retrieved via APIs along shortest semantic paths, then stored in folder hierarchies that reflect the taxonomy, ensuring balanced representation per leaf. The core assumption is that Wikipedia's vast, categorized content, when semantically aligned via vector-based edge weighting, provides a general-purpose corpus preserving hierarchical relationships. Evidence is Section 3.3 outlining the construction of a 1.5 million-node graph and collection of 57,304 documents into balanced folders. A break condition is poor coverage or inconsistent mappings in Wikipedia's category graph for specific domains.

## Architecture Onboarding
*   **Component map:**
    Input Document -> Tokenization (NLTK) & Feature Extraction (BOW + Doc2Vec) -> Hierarchical Neural Networks (one MLP per non-leaf taxonomy node, using node-specific dictionary) -> Path-building with confidence threshold (0.7) -> Top 3 Leaf Output.
    Taxonomy (RDF-based depth-2 tree) and Data (Wikipedia corpus: Corpus-A training, Corpus-B validation) are supporting structures.
*   **Critical path:**
    1.  Receive raw text document.
    2.  Tokenize and generate BOW vector using root network's dictionary; generate static Doc2Vec embedding.
    3.  Classify with root network. If max confidence < 0.7, pass document to child network with highest score.
    4.  At each subsequent node, rebuild BOW vector using *that node's* dictionary, concatenate with same Doc2Vec embedding, classify with child network, and repeat threshold check.
    5.  Continue descent until a leaf category is reached or no child exceeds threshold. Output the highest-scoring path(s).
*   **Design tradeoffs:**
    *   Hierarchical vs. flat: Hierarchy reduces noise and complexity but adds latency and risk of top-level error propagation.
    *   BOW vs. Doc2Vec: BOW is interpretable and precise for keywords; Doc2Vec adds semantics but is less discriminative for fine classes; combination increases dimensionality but improves accuracy.
    *   Pre-trained vs. custom Doc2Vec: Using Wikipedia-trained Doc2Vec leverages general semantics but may not domain-adapt optimally.
*   **Failure signatures:**
    *   High confusion between semantically adjacent leaves (e.g., "Science" vs. "Health") indicates insufficient feature discrimination.
    *   Low scores at the root network suggest the document is too generic or outside the taxonomy's scope.
    *   Memory spikes during validation due to the large size of the concatenated BOW+Doc2Vec feature matrices.
*   **First 3 experiments:**
    1.  Train individual networks on BOW-only datasets; evaluate per-category accuracy to establish a baseline.
    2.  Train networks on Doc2Vec-only datasets; confirm poor overall performance to justify the combined approach.
    3.  Train networks on combined BOW+Doc2Vec datasets; compare confusion matrices and overall accuracy gain (~60 documents) against the BOW-only baseline.

## Open Questions the Paper Calls Out
*   **Question:** Can BERT-based contextual embeddings replace or enhance NETHIC's current BOW+Doc2Vec approach to achieve higher accuracy in hierarchical text classification?
    *   **Basis:** The conclusion states that future work may explore integrating BERT.
    *   **Why unresolved:** NETHIC-2 uses static Doc2Vec; BERT's attention mechanisms might better capture contextual nuances for semantically close leaf categories, but this is untested.
    *   **Resolution evidence:** Train NETHIC models with BERT embeddings on the Wikipedia corpus, compare per-category precision/recall/F1-scores against BOW+Doc2Vec using statistical tests; analyze confusion matrices for reduced misclassification.
*   **Question:** What specific limitations of standalone Doc2Vec embeddings cause their poor performance in NETHIC's hierarchical neural networks, and are these due to the embedding algorithm's inability to capture fine-grained distinctions or the hierarchical architecture's requirements?
    *   **Basis:** Section 4.5 reports Doc2Vec-only models had the worst accuracy but provides no diagnostic analysis.
    *   **Why unresolved:** The paper speculates lexical features are needed for fine-grained distinction but does not verify if Doc2Vec vectors lack discriminatory power or if the network training is mismatched.
    *   **Resolution evidence:** Perform embedding space analysis (e.g., t-SNE, intra-/inter-class cosine similarity) for Doc2Vec vectors of leaf categories; compare hierarchical vs. flat classification performance using only Doc2Vec.
*   **Question:** To what extent does the structure of the hierarchical taxonomy (e.g., depth, number of leaf nodes per branch) influence the magnitude of improvement from combining BOW and Doc2Vec features?
    *   **Basis:** The taxonomy has fixed depth (2) and 117 leaves, but the paper reports only overall accuracy gains without per-node breakdown.
    *   **Why unresolved:** Error propagation in deeper hierarchies might benefit more from semantic embeddings, but the paper does not analyze if gains are uniform or concentrated in certain branches.
    *   **Resolution evidence:** Compute accuracy metrics for each taxonomy node in NETHIC-2; correlate improvements with node depth and branching factor; simulate modified taxonomies (e.g., increased depth) to test robustness.

## Limitations
*   The observed ~2% accuracy gain (60/2,843 documents) is modest and lacks reported statistical significance testing; it could be due to chance variation.
*   Experiments rely solely on a Wikipedia-derived corpus; generalizability to other domains or different taxonomy structures is unproven.
*   Memory constraints were observed during validation, indicating potential scalability bottlenecks for larger taxonomies or datasets without optimization.

## Confidence
*   **Hierarchical decomposition reduces semantic noise:** Medium (supported by confusion matrix reduction but no direct hierarchical ablation study).
*   **BOW + Doc2Vec feature fusion improves accuracy:** High (consistent gains across categories in reported experiments).
*   **The approach scales to large taxonomies:** Low (memory constraints observed and untested beyond the 117-class Wikipedia experiment).
