# A Firefly Algorithm for Mixed-Variable Optimization Based on Hybrid Distance Modeling

## Quick Facts
- arXiv ID: `2603.26792`
- Source URL: https://arxiv.org/abs/2603.26792
- References: 40
- Primary result: FAmv (especially FAmvH) outperformed state-of-the-art on the CEC2013 mixed-variable benchmark and achieved the lowest error on most real engineering problems.

## Executive Summary
The paper tackles mixed-variable optimization problems (MVOPs) with continuous, integer, and categorical decision variables. It introduces **FAmv**, an adaptation of the Firefly Algorithm that employs a **hybrid distance model** (Euclidean-Hamming or Gower) to unify attractiveness computation across variable types. Coupled with type-specific movement mechanisms and adaptive parameters, FAmv effectively navigates heterogeneous search spaces. Empirical results on the CEC2013 mixed-variable benchmark (28 functions, 100k function evaluations) and three engineering design problems (10k FEs) demonstrate that FAmvH (Hamming variant) is superior or competitive against leading methods such as DEmv, GA, and PSOmv.

## Method Summary
FAmv maintains a population of fireflies. For each firefly *i*, it examines all other fireflies *j*; if *j* is brighter (lower objective), it computes a **mixed distance** `r_ij` using a hybrid metric – Euclidean for continuous dimensions and Hamming (or Gower) for discrete ones. Attractiveness `β = exp(-γ r²)` determines the strength of attraction. Movement is then **type‑specific**:
- Continuous variables: `x_i^c = x_i^c + β (x_j^c - x_i^c) + α (rand - 0.5)` (clamped to bounds).
- Discrete (integer/categorical): a **β‑step** probabilistically exchanges components that differ between *i* and *j*; an **α‑step** adjusts integers by `x = INT(x + α ε)` (ε uniform in an unspecified interval) or replaces categorical values randomly with probability `p_α`.  
Parameters `α` (randomness) and `γ` (distance scaling) decay adaptively based on the fraction of used function evaluations. If no brighter firefly is found, a random walk (without β) occurs. The algorithm respects variable types throughout and uses simple clamping for bound handling.

## Key Results
- **CEC2013 benchmark**: FAmvH (Hamming) achieved the best mean absolute error on 7 of 28 functions and was statistically equivalent to the best on 13 functions, consistently outperforming DEmv, GA, and PSOmv.
- **Engineering problems** (10k FEs): FAmv variants obtained the lowest error on the BEAM and Vessel problems and were statistically tied for best on the CSD problem.
- The hybrid distance model combined with decoupled movement mechanisms enables robust search across mixed‑variable spaces.

## Why This Works (Mechanism)
The core mechanism unifies heterogeneous variables via a **hybrid distance** that aggregates Euclidean (continuous) and Hamming/Gower (discrete) contributions. This allows the firefly’s attractiveness to be computed in a single scalar, preserving the original FA’s attraction dynamics while respecting variable semantics. **Type‑specific moves** then apply appropriate operations: a continuous differential‑like step for real‑valued dimensions, and for discrete dimensions a probabilistic swap of mismatched components (β‑step) followed by a localized random perturbation (α‑step). **Adaptive parameter decay** gradually shifts the search from exploration (high α, low γ) to exploitation (low α, high γ). The combination yields an algorithm that efficiently explores mixed‑type search spaces without violating variable constraints.

## Architecture Onboarding
### Component Map
InitPopulation -> Evaluate -> OuterLoop(i) -> InnerLoop(j) -> BrighterCheck -> ComputeDistance -> ComputeBeta -> Move(i) -> Evaluate -> UpdateBest -> EndInner -> IfNoBrighter -> RandomWalk -> DecayParams -> Next i -> CheckFEBudget -> Termination

### Critical Path
The algorithm’s runtime is dominated by the **pairwise distance computation** and attractiveness evaluation in the inner loop (`O(N²)` per iteration). All other operations (movement, evaluation, updates) are linear per interaction but are overshadowed by the distance calculations for large populations.

### Design Tradeoffs
- **Distance choice**: Hamming is computationally cheaper but ignores ordinal relationships; Gower provides a more nuanced measure at a slight cost.
- **Parameter adaptation**: Fixed parameters simplify implementation but may not adapt to problem hardness; adaptive decay adds minimal overhead and generally improves performance.
- **Decoupled movement**: Respecting variable types increases code complexity and requires careful tuning of `ε` and categorical probability `k`, but avoids invalid solutions and leads to better search.

### Failure Signatures
- **Distance mismatch**: Incorrect hybrid distance (e.g., forgetting to normalize Gower) yields misleading attractiveness and poor convergence.
- **Type violation**: Discrete variables becoming non‑integer or out‑of‑category after a move.
- **FE counting error**: Extra evaluations (e.g., evaluating after both move and random walk) exceed budget, artificially granting more resources.
- **Penalty mis‑specification**: Engineering constraints not penalized adequately lead to infeasible solutions dominating the population.
- **Parameter decay bug**: Missing or incorrect decay results in stagnant late‑phase search or excessive randomness throughout.
