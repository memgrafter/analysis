# Agent Primitives: Reusable Latent Building Blocks for Multi-Agent Systems

## Quick Facts
- arXiv ID: 2602.03695  
- Source URL: https://arxiv.org/abs/2602.03695  
- Reference count: 28  
- Primary result: Agent Primitives improve average accuracy by 12.0–16.5% over single-agent baselines while reducing token usage and latency by 3–4×.

## Executive Summary
Existing multi-agent systems (MAS) suffer from task-specific designs and error-prone natural language communication, leading to complexity and instability. This work introduces Agent Primitives—three reusable latent building blocks (Review, Voting and Selection, Planning and Execution)—that decompose MAS into recurring patterns. Primitives communicate internally via key-value cache, mitigating information degradation. An LLM-based Organizer automatically composes primitives using a knowledge pool. Across eight benchmarks and five LLMs, the primitives-based approach yields accuracy gains of 12.0–16.5% over single-agent baselines, reduces token usage and latency by 3–4× compared to text-based MAS, and incurs only 1.3–1.6× overhead relative to single-agent inference, with more stable performance across model backbones.

## Method Summary
The method defines three Agent Primitives: Review (iterative critique loop), Voting & Selection (parallel solvers with a selector), and Planning & Execution (plan-then-execute). Agents within a primitive exchange reasoning states by directly concatenating their key-value (KV) caches, applying Rotary Positional Encoding offsets to preserve positional integrity. This latent communication avoids semantic drift from repeated text decoding. An LLM Organizer maps a user query to a composition of primitives by retrieving relevant configurations from a Knowledge Pool storing successful past MAS structures. The composed graph executes with internal KV cache hops and presents a unified external interface, providing modularity and robustness.

## Key Results
- Accuracy gains of 12.0–16.5% over single-agent baselines.  
- Token usage and latency reduced by 3–4× versus text-based multi-agent systems.  
- Computational overhead only 1.3–1.6× relative to single-agent inference; stable across model backbones.

## Why This Works (Mechanism)

1. **Recurring Pattern Decomposition** – Many existing MAS architectures can be abstracted into a small set of fundamental structural units (Review, Voting & Selection, Planning & Execution). This reduces design complexity by enabling task-agnostic modular reuse instead of handcrafting agent roles per problem. Evidence: The authors manually decompose diverse MAS and show that their primitives encapsulate common interaction patterns.

2. **Latent KV Cache Communication** – Passing KV caches directly (with RoPE positional offset) between agents preserves the decoder’s output distribution while avoiding repeated text decoding, which causes information degradation. This yields robustness to context length and noise. Evidence: Injecting auxiliary tasks and noise causes accuracy drops >20% for text-based communication, but KV cache remains stable. Ablation on LLaMA models confirms that disabling RoPE re-encoding leads to severe performance collapse.

3. **LLM-based Organizer with Knowledge Pool** – An Organizer LLM retrieves successful past MAS structures from a Knowledge Pool and abstracts them into primitive compositions for new queries, automating MAS construction. Evidence: Ablations show that removing the Knowledge Pool or using random selection harms performance by 5–12%, demonstrating the pool’s crucial role.

## Architecture Onboarding
- **Component Map**: User Query -> Organizer (with Knowledge Pool) -> Primitive Graph (Review/Voting/Planning) -> KV Cache Internal Hops -> Final Output.  
- **Critical Path**: The system receives a query, the Organizer retrieves relevant configurations from the Knowledge Pool, composes a primitive graph, executes the primitives with agents exchanging KV caches, and returns the final answer.  
- **Design Tradeoffs**:
  - KV cache communication is robust and efficient but requires identical model architecture and positional encoding, and sacrifices interpretability.
  - Organizer automation reduces design overhead but depends on Knowledge Pool coverage and the Organizer’s abstraction fidelity.
  - A fixed primitive set simplifies the system but may not express all possible interaction patterns.
- **Failure Signatures**:
  - Severe accuracy drop on LLaMA models when RoPE re-encoding is disabled (Table 7).
  - Performance degrades by 5–12% if the Knowledge Pool is ablated (Table 6).
  - Text-based MAS baselines show high variance across tasks, while primitive-based systems remain stable (Tables 3, 4).
- **First 3 Experiments**:
  1. Stress-test communication: Validate KV cache advantage by injecting auxiliary tasks/noise into long contexts.
  2. Baseline comparison: Measure accuracy, token usage, and latency against single-agent, TextMAS, and LatentMAS across 8 benchmarks.
  3. Ablation study: Isolate contributions of Organizer (LLM vs. random), Knowledge Pool, and KV RoPE.

## Open Questions the Paper Calls Out
- **Open Question 1**: How generally does the KV cache communication assumption hold across different LLM architectures, model sizes, and training objectives? The assumption that conditioning on KV cache approximates conditioning on the full token sequence is fundamental but validated only on same-model agents; sensitivity shown in ablations suggests limitations.
- **Open Question 2**: What is the minimal set of primitives needed to capture all effective MAS computation patterns, and can primitives be automatically discovered from data? The three proposed primitives are based on empirical observation of existing MAS, but completeness and automatic discovery remain open.
- **Open Question 3**: How does the size, diversity, and representation of the Knowledge Pool influence the Organizer’s composition effectiveness for novel tasks? The current pool is a manually curated set of 45 structures; its impact on generalization is not studied.
- **Open Question 4**: Can a theoretical model explain why KV cache communication mitigates information degradation in long-context MAS compared to natural language? The paper provides empirical evidence but no formal analysis.

## Limitations
- The primitive set may be incomplete; tasks requiring dynamic role switching or emergent communication may not fit any primitive.
- KV-cache communication assumes identical model architecture and positional encoding, limiting heterogeneity and potentially failing with mixed-model agents.
- The Organizer’s performance depends heavily on Knowledge Pool coverage; it may degrade on queries far from the pool’s distribution.

## Confidence
- Decomposition into reusable primitives: Medium  
- KV-cache internal communication: High  
- LLM-based Organizer with Knowledge Pool: Medium
