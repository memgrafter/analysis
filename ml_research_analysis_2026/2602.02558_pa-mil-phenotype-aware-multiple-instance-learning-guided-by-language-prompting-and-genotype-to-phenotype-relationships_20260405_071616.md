# PA-MIL: Phenotype-Aware Multiple Instance Learning Guided by Language Prompting and Genotype-to-Phenotype Relationships

## Quick Facts
- arXiv ID: 2602.02558
- Source URL: https://arxiv.org/abs/2602.02558
- Reference count: 40
- Primary result: PA-MIL achieves competitive classification (e.g., 94.68% accuracy on NSCLC) while providing ante-hoc interpretability via phenotype saliency scores.

## Executive Summary
PA-MIL addresses the critical gap in ante-hoc interpretability for whole-slide image (WSI) analysis in computational pathology. Existing deep learning methods often rely on post-hoc saliency maps that lack reliability. PA-MIL introduces a phenotype-aware multiple instance learning framework that explicitly identifies cancer-related phenotypes. It constructs a knowledge base linking morphological phenotype descriptions to associated genes, uses language prompting to aggregate phenotype-relevant patch features, and employs a Genotype-to-Phenotype Neural Network (GP-NN) trained on transcriptomics to provide multi-level guidance. Evaluated on NSCLC and RCC subtyping tasks using TCGA data, PA-MIL attains performance competitive with state-of-the-art MIL methods (e.g., up to 94.68% accuracy and 98.42% AUC on NSCLC) while delivering interpretable phenotype saliency scores directly from the model. However, the approach’s reliance on a curated knowledge base and transcriptomics data, along with limited external validation, leaves questions about generalizability and robustness.

## Method Summary
PA-MIL is a multiple instance learning (MIL) system for whole-slide image classification that integrates domain knowledge about cancer phenotypes. The method builds a phenotype knowledge base containing textual morphological descriptions and associated gene sets. For a given WSI, patches are extracted and encoded into feature vectors. Using language prompting (e.g., a pre-trained text encoder), phenotype descriptions are encoded, and the similarity between patch features and phenotype text embeddings guides an attention mechanism to weight patches according to their relevance to each phenotype. Additionally, a Genotype-to-Phenotype Neural Network (GP-NN), trained on transcriptomics data, predicts phenotype-related gene expression patterns, providing molecular guidance that further modulates the attention or aggregation process. The weighted patch features are pooled to produce a slide-level prediction. The attention weights serve as phenotype saliency scores, offering inherent interpretability without post-hoc procedures.

## Key Results
- Achieved test accuracy up to 94.68% and AUC 98.42% on TCGA-NSCLC subtyping, comparable to state-of-the-art MIL methods.
- Demonstrated competitive performance on RCC subtyping as well, indicating broad applicability across cancer types.
- Provided ante-hoc interpretability through phenotype saliency scores that highlight morphologically relevant regions, potentially enhancing clinical trust.

## Why This Works (Mechanism)
PA-MIL’s ante-hoc interpretability stems from its explicit phenotype-driven design. The language prompting module aligns visual patch features with textual phenotype descriptions, creating a natural interface for pathologists to understand which morphological patterns the model associates with each phenotype. The GP-NN, trained on transcriptomics, injects biological priors by linking gene expression patterns to phenotypes, guiding the MIL aggregator to focus on patches that reflect underlying molecular characteristics. This multi-level guidance ensures that the model’s attention is grounded in both morphological and molecular evidence, yielding saliency scores that are directly derived from the prediction process rather than computed after the fact. Consequently, the explanations are more reliable and aligned with the model’s decision-making.

## Architecture Onboarding
**Component Map**: WSI → Patch Extractor → Patch Encoder → Phenotype Attention (via Language Prompting) → GP-NN Modulation (using transcriptomics) → Weighted Aggregation → MIL Classifier → (Slide Label, Phenotype Saliency)

**Critical Path**: The essential data flow for a prediction begins with WSI patch extraction, followed by encoding each patch into a feature vector. Language prompting computes attention weights for each phenotype by comparing patch features to encoded phenotype descriptions. The GP-NN processes transcriptomics (if available) to generate phenotype probabilities, which adjust the attention weights. Weighted aggregation of patch features then yields a slide-level representation, which is classified. The final phenotype saliency scores are derived from the attention weights.

**Design Tradeoffs**:
- *Knowledge Base Dependency*: Relying on a curated phenotype knowledge base enhances interpretability but limits the model to known phenotypes and introduces potential bias from the selection process.
- *Multi-Omodality Requirement*: The GP-NN necessitates transcriptomics data alongside WSIs, reducing applicability to datasets lacking molecular profiling and raising integration challenges.
- *Language Model Bias*: Using a pre-trained language model for prompting may inherit biases from its training corpus and suffer from domain mismatch when encoding specialized medical terminology.

**Failure Signatures**:
- *Incomplete Knowledge Base*: Missing key phenotypes could cause the model to overlook important morphological patterns, degrading performance on certain cancer subtypes.
- *Misaligned Embeddings*: Poor alignment between visual patch features and text embeddings (e.g., due to domain shift) would produce noisy attention weights, leading to erroneous focus and reduced accuracy.
- *GP-NN Malfunction*: Noisy or mismatched transcriptomics data can cause the GP-NN to provide misleading guidance, corrupting the attention modulation and harming both performance and interpretability.

**First Experiments**:
1. **Baseline MIL Comparison**: Train and evaluate PA-MIL alongside standard MIL methods (e.g., Attention-MIL, CLAM) on NSCLC and RCC subtyping to quantify classification performance.
2. **Ablation Study**: Remove the GP-NN component and/or the language prompting module to measure their individual contributions to accuracy and interpretability (e.g., via saliency map quality).
3. **Qualitative Saliency Validation**: Visualize phenotype saliency maps for test WSIs and have pathologists assess whether highlighted regions correspond to expected morphological features, providing initial evidence for interpretability.

## Limitations
- Phenotype knowledge base construction is not detailed and may be incomplete or biased, affecting model coverage.
- Interpretability claims lack quantitative assessment by domain experts (e.g., pathologist evaluation) and comparison with ground-truth phenotype annotations.
- Performance evaluation lacks statistical rigor (confidence intervals, significance tests) and cross-dataset validation, raising concerns about overfitting and generalizability.
