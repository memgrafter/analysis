# Feature Recalibration Based Olfactory-Visual Multimodal Model for Enhanced Rice Deterioration Detection

## Quick Facts
- **arXiv ID:** 2602.14408
- **Source URL:** https://arxiv.org/abs/2602.14408
- **Reference count:** 32
- **Primary result:** Proposed method achieves 99.89% offline accuracy and 93.33% online detection accuracy, improving classification by 8.67% over state-of-the-art SS-Net and averaging 11.51% over traditional baselines while using a standard RGB camera instead of costly hyperspectral devices.

## Executive Summary
This paper tackles the challenges of limited fine-grained feature extraction and high equipment costs in multimodal rice deterioration detection. Traditional approaches rely on expensive hyperspectral cameras and mass spectrometers. The authors propose a feature recalibration-based olfactory-visual model that introduces a Fine-grained Deterioration Embedding Constructor (FDEC) to reorganize heterogeneous olfactory and visual data into a unified embedding structure, and a Fine-grained Deterioration Recalibration Attention Network (FDRA-Net) that uses Squeeze-and-Excitation (SE) blocks for olfactory channel recalibration and Convolutional Block Attention Modules (CBAM) for visual spatial emphasis. The framework achieves high accuracy (99.89% offline, 93.33% online) with a standard RGB camera, significantly outperforming baselines.

## Method Summary
The method comprises two main modules. First, FDEC preprocesses raw multimodal data: for olfactory e-nose signals, it extracts a stable response phase and applies a Periodic Linear ReLU (PLR) embedding to map temporal sequences into a feature space highlighting critical variations; for visual RGB frames, it partitions the image into local patches and uses a convolutional embedder (PLCE) to capture micro-scale mold textures. These modality-specific embeddings are structured into a unified dataset `X = {O, V}`. Second, FDRA-Net processes these embeddings through stacked FDRA layers. Each layer applies an SE block to olfactory features to dynamically weight informative gas sensor channels, and a residual path with CBAM to visual features to emphasize salient local mold patterns. After `M` layers, features from both modalities are vectorized, linearly projected, concatenated, and classified. Training uses Adam optimizer with cross-entropy loss.

## Key Results
- Proposed method achieves **99.89% offline accuracy** and **93.33% online accuracy** on rice deterioration detection.
- Improves classification accuracy by **8.67%** over state-of-the-art SS-Net and averages **11.51%** improvement over other traditional baselines.
- Replaces costly hyperspectral cameras with a standard RGB camera while maintaining superior performance.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** FDEC enhances sample representation by standardizing and reorganizing heterogeneous olfactory and visual data into a unified embedding structure prior to network processing.
- **Mechanism:** For olfactory data, FDEC extracts a stable response phase from raw e-nose signals and applies a Periodic Linear ReLU (PLR) embedding to map temporal sequences into a feature space that emphasizes critical variation patterns. For visual data, it partitions the RGB image into local patches and applies a convolutional embedder (PLCE) to capture micro-scale mold textures. These modality-specific embeddings are then structured into a single multimodal dataset (`X = {O, V}`) that reduces noise and improves accessibility for subsequent branches.
- **Core assumption:** Directly feeding raw, heterogeneous signals (spatial images, temporal sensor responses) into a multimodal network causes inconsistent representations and redundant information; modality-specific preprocessing that preserves granular details while reducing noise leads to more stable and discriminative joint feature extraction.
- **Evidence anchors:**
  - [abstract] "The fine-grained deterioration embedding constructor (FDEC) is proposed to reconstruct the labeled multimodal embedded-feature dataset, enhancing sample representation."
  - [section II.B] Detailed description of PLR for olfactory signals and PLCE for visual patches, culminating in structured dataset `X`.
  - [corpus] Neighboring papers focus on fine-grained visual disease detection or generic multimodal fusion but do not address structured preprocessing of heterogeneous agricultural sensor data; the evidence for this specific mechanism is primarily anchored in the proposed paper itself.
- **Break condition:** If the stable response phase extraction for olfactory data fails (e.g., due to sensor drift or inconsistent sampling), the PLR embedding will operate on noisy/irrelevant signal segments, degrading the quality of the olfactory embedding `O` and undermining the unified dataset's utility.

### Mechanism 2
- **Claim:** The FDRA module within FDRA-Net improves sensitivity to fine-grained deterioration by performing modality-aware feature recalibration: SE blocks dynamically weight olfactory channels to highlight informative gas responses, while CBAM blocks emphasize spatial regions in visual features corresponding to sparse, irregular mold patterns.
- **Mechanism:** For olfactory features `x_o` at each FDRA layer, a global average pooling followed by a two-layer MLP and sigmoid generates channel-wise scaling coefficients `a_o`. These are applied via element-wise multiplication (`a_o ⊙ x_o`) to amplify relevant sensor channels and suppress noisy/uninformative ones. For visual features `x_v`, CBAM sequentially applies channel and spatial attention to produce a refined feature map `CBAM(r_v)`, which is added to a residual shortcut `D(x_v)` to enhance salient local textures without losing spatial context.
- **Core assumption:** In rice deterioration, the most discriminative cues are fine-grained and modality-specific: olfactory cues manifest as subtle inter-channel differences in gas sensor responses to volatile metabolites, while visual cues are localized, small-scale mold spots. A shared backbone with modality-specific recalibration units can better isolate these cues than a generic multimodal fusion approach.
- **Evidence anchors:**
  - [abstract] "FDRA-Net uses Squeeze-and-Excitation for olfactory channel recalibration and Convolutional Block Attention Module for visual spatial emphasis."
  - [section II.C, Fig. 3] Equations (6)-(11) and architectural diagram explicitly define the SE and CBAM pathways within a single FDRA layer.
  - [corpus] Neighboring works (e.g., [12], [13]) use attention for multimodal fusion but do not specify modality-differentiated recalibration; this design choice is novel to the proposed framework as per paper claims.
- **Break condition:** If the e-nose sensor array exhibits extreme drift or the visual mold patterns are too faint/sparse relative to background noise, the learned attention weights (from SE or CBAM) may incorrectly suppress truly discriminative features or amplify noise, leading to degraded classification—particularly for the "expired" class as seen in baseline model weaknesses.

### Mechanism 3
- **Claim:** The overall multimodal framework achieves higher accuracy and robustness by enabling complementary interaction between olfactory and visual streams, where each modality compensates for the other's limitations (e.g., olfactory sensitivity to chemical changes vs. visual direct surface texture).
- **Mechanism:** FDEC provides modality-specific embeddings already enhanced for fine-grained patterns. FDRA-Net then processes these in parallel branches with dedicated attention (SE/CBAM), producing recalibrated features `h_o` and `h_v`. These are vectorized, linearly projected, and concatenated (`[z_v ∥ z_o]`) before final classification. The training process (via cross-entropy loss) implicitly learns to weight the two modalities' contributions based on their discriminative power for each sample.
- **Core assumption:** Rice deterioration manifests both chemically (volatile metabolites detectable by e-nose) and physically (surface mold/texture changes detectable by RGB). A model that separately optimizes each modality's feature representation and then fuses their *recalibrated* outputs will be more robust than early-fusion or single-modality approaches, especially under variable conditions (e.g., mild degradation).
- **Evidence anchors:**
  - [abstract] "The olfactory modality reflects variations in volatile components, whereas the visual modality provides a direct and intuitive representation of surface texture changes... multimodal methods generally achieve more stable and discriminative deterioration detection results."
  - [section I] Discussion of limitations of single-modality olfactory (susceptible to sensor drift) and visual (hyperspectral cost) methods, motivating fusion.
  - [section III.C, Table III] Ablation results show that removing both SE and CBAM (i.e., disabling modality-specific recalibration) causes a larger accuracy drop (-9.22%) than removing either alone, supporting complementary interaction.
- **Break condition:** If one modality is severely corrupted (e.g., e-nose failure or occluded visual sample), the framework may still attempt to fuse low-quality features from that branch, potentially degrading performance compared to a fallback single-modality model. The paper does not propose a modality confidence mechanism to handle such failures.

## Architecture Onboarding

Component map:  
Data Acquisition (RGB camera + e-nose) -> FDEC (Olfactory: stable phase extraction -> PLR embedding; Visual: image patch partition -> PLCE embedding) -> Structured Multimodal Embedding Set X -> FDRA-Net (Stacked FDRA layers: Olfactory path = SE recalibration; Visual path = Residual + CBAM) -> Feature Vectorization & Linear Projection -> Concatenation -> Classification Head

Critical path: Raw data undergoes modality-specific embedding in FDEC to produce `X`, which feeds into FDRA-Net. Stacked FDRA layers apply attention-based recalibration separately to each modality. Final features are concatenated and classified.

Design tradeoffs:
- Accuracy vs. Complexity: FDRA-Net (48.73 MB, 9.483 ms) outperforms baselines but is larger and slower; trade-off justified by gains.
- Sensor cost vs. Performance: Using standard RGB instead of hyperspectral reduces cost but relies on model to extract fine-grained cues.
- Modality balance: Fixed concatenation fusion assumes both modalities contribute; if one is noisy, performance may degrade without adaptive down-weighting.

Failure signatures:
- Class-specific: Poor recall on "expired" class (subtle cues) in baselines without FDRA.
- Distribution shift: Offline (99.89%) to online (93.33%) drop indicates sensitivity to real-world noise.
- Ablation impact: Removing FDEC causes largest accuracy drop (-14.45%), SE/CBAM removal causes smaller but significant drops.

First 3 experiments:
1. **Baseline replication:** Implement SS-Net and other baselines using identical day-based data splits and same raw data preprocessing as FDEC. Validate accuracy matches Table I.
2. **FDEC isolation test:** Train FDRA-Net with FDEC but without FDRA layers (i.e., replace with plain linear layers). Expect accuracy near "FDEC removed" row (~85%).
3. **Modality ablation:** Train FDRA-Net with only one modality branch active (e.g., disable olfactory branch). Test model's reliance on each modality and compensation ability, especially for "expired" class.

## Open Questions the Paper Calls Out
- **Optimization for edge deployment:** How can FDRA-Net be optimized for real-time deployment on resource-constrained edge devices without sacrificing detection accuracy? Current model size (48.73 MB) and latency (9.483 ms) may not suit all embedded platforms; trade-offs between compression (pruning, quantization, distillation) and accuracy need investigation.
- **Sensor drift and domain adaptation:** What strategies are most effective for compensating sensor drift and adapting FDRA-Net to distribution shifts across different granary environments over long-term operation? Longitudinal studies with data from multiple granaries and methods like unlabeled data alignment, online calibration, or few-shot updates are needed.
- **Interpretability and transferability:** How can the interpretability of FDRA-Net's multimodal decisions be improved to increase auditability in practical quality inspection, and how transferable is the model to other agrifood deterioration detection tasks? Current interpretability (Grad-CAM) covers only visual branch; transfer to other products (wheat, corn) remains unexplored.

## Limitations
- FDEC implementation details are missing: PLR hyperparameters (`k`, `σ`), stable response phase extraction method, and PLCE architecture specifications hinder faithful reproduction.
- FDRA-Net architecture is incompletely specified: channel dimensions, exact layer count `M`, and projection sizes are not provided.
- Significant performance drop from offline (99.89%) to online (93.33%) testing indicates limited robustness to real-world variability.
