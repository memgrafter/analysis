# Inheritance Between Feedforward and Convolutional Networks via Model Projection

## Quick Facts
- **arXiv ID:** 2602.06245
- **Source URL:** https://arxiv.org/abs/2602.06245

## Executive Summary
Feedforward networks (FFNs) and convolutional networks (CNNs) have historically been studied in isolation, with little explicit connection between them. This paper establishes a rigorous link by introducing a unified tensor-level formalization that proves generalized FFNs are a strict subset of generalized CNNs. Building on this insight, the authors propose "model projection": a technique that freezes the spatial filters of a pretrained convolutional layer and learns a single scalar gate for each (output, input) channel pair. This reparameterization turns the convolutional operation into an FFN-like module, reducing the number of trainable parameters from O(d_out·d_in·k²) to O(d_out·d_in). Consequently, one can directly apply the rich suite of parameter-efficient methods developed for FFNs to CNNs. Empirical evaluations on several ImageNet-pretrained backbones across seven downstream datasets demonstrate that projection consistently outperforms both logistic regression and full fine-tuning under simple training protocols. For example, on CIFAR-10 with ResNet50, projection combined with full fine-tuning achieves 96.95% accuracy compared to 90.74% for standard full fine-tuning. In parameter-efficient fine-tuning benchmarks, projection-based variants rank at the top, offering dramatic parameter savings without sacrificing accuracy.

## Method Summary
Model projection reparameterizes a standard convolutional layer by decomposing its weight tensor into two parts: the spatial filters (the convolutional kernel) and a set of scalar gates for each output-input channel pair. The pretrained spatial filters are frozen, preserving the learned feature extractor. For each output channel and each input channel, a single scalar (the gate) is learned and applied multiplicatively to the corresponding feature maps before summation. This effectively turns the convolutional operation into a per-channel linear combination (like an FFN) while maintaining the spatial aggregation via the frozen filters. The number of trainable parameters per projected layer reduces from O(d_out·d_in·k²) to O(d_out·d_in). The projected layer can then be treated as an FFN node, allowing the use of FFN-specific optimization and regularization techniques. The authors also extend projection to residual blocks and dense blocks by freezing spatial filters and projecting the channel interaction pathways.

## Key Results
- Parameter reduction: Projection cuts trainable parameters by up to two orders of magnitude (e.g., from 1.2M to 10k per layer).
- Accuracy gains: Projection consistently outperforms logistic regression and full fine-tuning across multiple backbones (VGG16, ResNet50, DenseNet121) and seven downstream datasets; e.g., on CIFAR-10 with ResNet50, projection+full-fine-tuning yields 96.95% vs 90.74% for full fine-tuning.
- PEFT benchmark success: Projection-based variants rank top in parameter-efficient fine-tuning benchmarks.

## Why This Works (Mechanism)
Model projection works by decoupling spatial feature extraction from channel interaction. The frozen spatial filters retain the pretrained representation of visual patterns, which are broadly useful across tasks. The introduced scalar gates, one per (output, input) channel pair, efficiently modulate the contribution of each frozen filter to each output channel. This reduces the parameter count because channel interactions are captured by O(d_out·d_in) scalars instead of full d_out·d_in spatial kernels. Theoretically, generalized FFNs are a strict subset of generalized CNNs, so projected convolutional nodes (which become FFN-like) can still approximate a wide range of functions while being far more parameter-efficient. Empirically, this approach often yields better performance than full fine-tuning or linear probing, likely because it prevents overfitting on small downstream datasets while allowing adaptive channel mixing.

## Architecture Onboarding
**Component Map:** Input -> Convolution (spatial filters frozen) -> Scalar Gate (per output-input channel) -> Activation -> Next layer. In residual blocks, the gated path is combined with the skip connection.  
**Critical Path:** The projection step decomposes the convolutional weight tensor: W_{o,i,h,w} = g_{o,i} * F_{o,i,h,w}, where F are frozen spatial filters and g_{o,i} are trainable scalars. This yields an FFN-like operation: y = (X * F) (spatial) then per-channel weighted sum via gates.  
**Design Tradeoffs:** Freezing filters preserves strong pretrained features but limits adaptation to new spatial patterns; scalar gates are cheap but may be too restrictive for tasks requiring new spatial invariances. The method trades off expressivity for parameter efficiency, which is beneficial on small datasets but may underfit on large ones.  
**Failure Signatures:** (1) Gates collapse to near-zero or uniform values, indicating no adaptation. (2) Significant accuracy drop compared to full fine-tuning on large target datasets. (3) Training instability because gates are not bounded; adding a normalization (e.g., softmax across input channels) may be needed.
