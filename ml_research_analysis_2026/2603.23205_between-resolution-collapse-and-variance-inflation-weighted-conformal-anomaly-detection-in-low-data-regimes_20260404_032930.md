# Between Resolution Collapse and Variance Inflation: Weighted Conformal Anomaly Detection in Low-Data Regimes
## Quick Facts
- arXiv ID: 2603.23205
- Source URL: https://arxiv.org/abs/2603.23205
- Reference count: 40
- Primary result: Weighted KDE for continuous p-values resolves the resolution-variance dilemma in low-data weighted conformal anomaly detection, achieving valid FDR control and higher power than discrete baselines.

## Executive Summary
In low-data regimes with covariate shift, weighted conformal anomaly detection suffers from a fundamental trade-off: deterministic p-values based on the empirical distribution function develop a lower bound (resolution collapse) that prevents rejecting even extreme anomalies when importance weights concentrate; randomized smoothing removes the bound but introduces conditional variance (variance inflation) that can mask anomalies. This paper proposes using weighted kernel density estimation (KDE) to construct continuous p-values, thereby decoupling adaptation from tail resolution. The method eliminates both the discrete floor and Monte Carlo noise, restoring detection power while maintaining marginal FDR control at the nominal level (0.1) on benchmark datasets.

## Method Summary
The approach begins by estimating importance weights via a probabilistic classifier (Random Forest) trained on pooled calibration and test data, stabilized with bagging and winsorization. Then, instead of relying on rank-based p-values, it fits a weighted kernel density estimator to the calibrated anomaly scores, selecting bandwidth via leave-one-out cross-validation. The p-value for a test point is the upper tail probability under this smoothed density. Multiple testing is handled by Weighted Conformalized Selection (WCS) for weighted p-values. This continuous inference avoids the resolution collapse of deterministic weighted EDF and the variance inflation of randomized methods.

## Key Results
- Reconciled the resolution-variance dilemma via continuous KDE-based p-values.
- In low-data regimes (N << 1000), restored detection where discrete weighted EDF yielded zero discoveries and improved power over randomized methods.
- Achieved valid marginal FDR control at α = 0.1 on ADBench benchmarks.

## Why This Works (Mechanism)
### Mechanism 1: Resolution collapse in deterministic weighted EDF
- Claim: Deterministic p-values based on the weighted empirical distribution function have a non-zero lower bound when importance weights concentrate, preventing rejection of extreme anomalies.
- Mechanism: For a test score more extreme than all calibration scores, p-value = w_j/(W_cal + w_j). As weights localize under covariate shift, w_j/W_total grows, creating a discrete floor that can exceed the BH cutoff.
- Break condition: When w_j/W_total > (r/m)·α for a putative rejection count r, no rejection is possible regardless of extremity.

### Mechanism 2: Variance inflation in randomized smoothed EDF
- Claim: Randomized p-values remove the discrete floor but introduce conditional variance that can mask anomalies, especially with concentrated weights.
- Mechanism: The randomized p-value in the extreme tail is uniform on [0, w_j/W_total]; interval width scales with test weight fraction. This leads to conditional variance = (width)^2/12, which can cause an anomaly’s p-value to exceed the threshold due to an unlucky uniform draw.
- Break condition: Low effective sample size (high weight concentration) makes width_j large, increasing variance and risk of false negatives.

### Mechanism 3: Continuous KDE decouples adaptation from tail resolution
- Claim: Weighted KDE produces continuous p-values that avoid both the discrete floor and Monte Carlo noise.
- Mechanism: Instead of weighted ranks, it estimates the weighted score distribution f_w(s) via KDE. The tail p-value p_KDE(s_j) = ∫_{s_j}^∞ f_w(t) dt is a smooth function of s_j, not directly tied to w_j/W_total.
- Assumptions: Weighted null distribution is continuous; KDE consistent (bandwidth → 0, N h_N / log N → ∞). Bandwidth selection via LOO-CV balances bias-variance.
- Break condition: Poor bandwidth choice (oversmoothing masks tails; undersmoothing high variance) or extremely noisy weight estimates can invalidate asymptotic approximation and lead to FDR inflation.

## Architecture Onboarding
### Component map
Calibration data (scores s_i) + test features -> Weight Estimator (Random Forest classifier with balanced bootstrap bagging and winsorization) -> importance weights w_i for calibration points -> KDE Fitter (bandwidth selection via weighted LOO-CV) -> weighted density f̂_w(s) -> p-value Computer (tail integral) -> Weighted Conformalized Selection (homogeneous pruning) -> anomaly rejections.

### Critical path
1. Load D_cal (scores s_i) and Z_test.
2. Estimate w(z) using classifier, clip via winsorization (γ=0.05).
3. Compute calibration weights w_i = w(z_i).
4. Select KDE bandwidth h via weighted LOO-CV.
5. Build weighted KDE f̂_w(s) = (1/h) Σ (w_i/Σw_i) K((s - s_i)/h).
6. For each test score s_j, compute p_KDE(s_j) = 1 - Σ (w_i/Σw_i) Φ_K((s_j - s_i)/h).
7. Apply WCS at α=0.1 to obtain rejections.

### Design tradeoffs
- Asymptotic vs. finite-sample validity: KDE gives asymptotic validity but loses finite-sample super-uniformity guarantees of discrete conformal p-values.
- Bias-variance in tail: Bandwidth choice trades tail resolution (small h) for variance (large h); LOO-CV seeks balance.
- Weight estimation stability: Winsorization reduces variance but introduces bias; extreme weight estimates can distort KDE.

### Failure signatures
- High weight variance: Inspect distribution of w_i; heavy tails suggest poor overlap between P and Q supports → invalid KDE.
- Constant p-values: All p_KDE nearly identical indicates oversmoothing (h too large).
- FDR inflation: Consistently observed FDR > α indicates possible tail underestimation or breakdown of WCS assumptions.

### First 3 experiments
1. **Resolution collapse replication**: Run deterministic weighted EDF on a low-N dataset with induced covariate shift. Verify zero discoveries because min p_discrete > BH cutoff for all test points.
2. **KDE vs. EDF tail behavior**: For fixed w_i and calibration scores, plot p(s) vs s for EDF (step function with floor) and KDE (smooth decay). Show KDE yields p-values below the floor for extreme s_j.
3. **FDR validation**: Run full pipeline (weighted KDE + WCS) across 20 seeds on a benchmark. Check mean FDR ≤ 0.1 + margin. If violated, investigate weight distribution and bandwidth choices.

## Limitations
- Asymptotic KDE consistency may fail in very small calibration sets (N < 50).
- Noise in importance weight estimates can severely distort the weighted density, especially with limited support overlap.
- Evaluation mostly on ADBench; applicability to high-dimensional scores or other shift types remains open.
