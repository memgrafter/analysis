# Clifford Kolmogorov-Arnold Networks

## Quick Facts
- **arXiv ID:** 2602.05977
- **Source URL:** https://arxiv.org/abs/2602.05977
- **Reference count:** 38
- **Primary result:** Extends KANs to arbitrary Clifford algebras, using Sobol sequences to mitigate the curse of dimensionality and achieving comparable or better performance with 2–6% of the parameters.

## Executive Summary
This paper introduces Clifford Kolmogorov-Arnold Networks (ClKAN), a neural architecture that generalizes the Kolmogorov-Arnold representation to arbitrary Clifford algebras. The core innovation replaces exponentially scaling uniform grids with Randomized Quasi Monte Carlo (RQMC) scrambled Sobol sequences for placing radial basis functions. This drastically reduces parameters while maintaining approximation quality. New batch normalization strategies are essential for stabilizing training, especially with non-uniform grids. The method successfully operates in high-dimensional Clifford spaces (e.g., 4D) and matches prior complex-valued results.

## Method Summary
ClKAN models a Clifford algebra-valued function on each network edge using radial basis functions (RBFs) centered on a grid within the algebra. Inputs and weights operate under the geometric product of a chosen Clifford algebra Cl(p,q,r). Instead of a full uniform grid (which scales exponentially with algebra dimension D), the grid points are sampled from a low-discrepancy Sobol sequence, turning the weighted RBF sum into a quasi-Monte Carlo estimator. The paper proposes three batch normalization strategies (dimension-, node-, component-wise) to keep pre-activations within the bounded grid range (e.g., [-2,2]^D), which is critical for non-uniform grids. Training uses the ClSiLU activation and an Adam optimizer with a higher learning rate (0.1) for stability.

## Key Results
- Achieves comparable or better test MSE than full-grid models on synthetic datasets while using only 2–6% of the parameters via Sobol grids.
- Demonstrates successful function approximation in 4D Clifford algebras (e.g., Cl(1,0,1)).
- Batch normalization is necessary; omitting it leads to catastrophic failure (MSE ~51 vs. ~0.02 with normalization).
- Matches CVKAN performance on complex-valued tasks, validating the Clifford extension.

## Why This Works (Mechanism)

**Mechanism 1: Clifford Algebra Generalization**  
The network replaces complex numbers with an arbitrary Clifford algebra Cl(p,q,r), allowing it to represent functions on high-dimensional geometric algebras. Each edge learns a map Cl → Cl using RBFs evaluated in the same algebra, relying on the geometric product. This extends the KAN philosophy of edge-centric univariate functions to hypercomplex domains.  
*Evidence:* [abstract] states the extension to arbitrary Clifford algebras; [section IV] describes learning per-edge functions; assumes the Kolmogorov-Arnold theorem generalizes structurally.  
*Break condition:* Mismatch between target function's structure and the chosen algebra's grade/product rules.

**Mechanism 2: Sobol Grids for Parameter Efficiency**  
Full uniform grids scale as N_g^D (D = algebra dimension), causing exponential growth. Using a scrambled Sobol sequence (a low-discrepancy (t,m,d)-net) with N_g points per dimension yields O(n⁻¹) variance for smooth functions under the RBF convolution estimator, where n ≈ N_g·D. This quasi-Monte Carlo approach provides even space coverage with far fewer points.  
*Evidence:* [abstract] and [section IV-C] introduce RQMC Sobol grids; [section IV-D, Lemma IV.2 & Property IV.1] give the variance bound for smooth f.  
*Break condition:* Target function is highly discontinuous or the RBF is not smooth enough, violating the f_x ∈ L^{1+ϵ} assumption.

**Mechanism 3: Normalization for Grid Alignment**  
Batch normalization (applied as dimension-, node-, or component-wise) rescales Clifford-valued pre-activations (treated as D-dimensional real vectors) to match the grid range [-2,2]^D. This prevents activations from straying far from RBF centers, avoiding near-zero kernel responses.  
*Evidence:* [section IV-E] describes the strategies; [section V-B & Table III] ablation shows no-normalization fails catastrophically while all three variants succeed.  
*Break condition:* Data has heavy tails or outliers that push normalized outputs outside [-2,2]^D despite batch norm.

## Architecture Onboarding
**Component map:**  
Input Clifford element -> Batch Normalization (dim/node/component-wise) -> Edge RBF Evaluation (grid G) -> Weighted Sum per node -> ClSiLU Activation -> (repeat hidden layers) -> Output layer (scalar or Clifford)

**Critical path:** Input → BatchNorm → (for each edge: compute RBFs on grid G, apply weight, sum to target node) → ClSiLU → next hidden layer → Output.

**Design tradeoffs:**  
- *Grid type:* Full grid (stable, many parameters) vs. Sobol grid (fewer parameters, potential coverage gaps).  
- *RBF type:* Naive (ϕ: Cl→R, loses direction) vs. Clifford (ϕ: Cl→Cl, preserves geometry, costlier).  
- *Batch norm:* Node-wise (original KAN style) vs. dimension/component-wise (may stabilize some algebras).  
- *Learning rate:* Original CVKAN used 0.01; ClKAN requires ~0.1 for stability.

**Failure signatures:**  
- No batch norm: Training loss remains very high (MSE >> 1), gradients vanish.  
- Too few Sobol points (e.g., Ng=2 in 4D): Inability to approximate, high MSE and variance across folds.  
- Grid range mismatch: Outputs consistently outside [-2,2]^D after batch norm → RBFs near zero → dead network.  
- Instability: High standard deviation across CV folds despite lr=0.1.

**First 3 experiments:**  
1. Replicate Table I: Train on complex-valued `square` dataset with full grid (Ng=8), node-wise norm, architecture [1,1]. Expect test MSE ~0.001.  
2. Sobol efficacy: On Cl(1,0,1), compare full grid (Ng=8) vs. Sobol grid (Ng=4). Verify ~75% parameter reduction and non-inferior MSE.  
3. Batch norm ablation: On holography dataset with large architecture [3,10,5,3,1], train four models (no-norm, dim-wise, node-wise, comp-wise). Confirm no-norm fails (MSE >>1) and others succeed (MSE ~0.02–0.03).

## Limitations
- Implementation specifics (scrambling algorithm, exact batch norm formulas) are not detailed in the text and require code consultation.
- Theoretical Sobol variance bound assumes smooth functions; real-world data may violate conditions.
- Experiments only validate up to 4D Clifford algebras; higher dimensions remain untested.

## Confidence
- **Clifford extension:** Medium. Empirical validation limited to ≤4D synthetic tasks; theoretical generalization plausible but not proven for arbitrary algebras.
- **Sobol grid efficiency:** Medium. Theory holds for smooth f; empirical support only on synthetic datasets; risk for discontinuous functions.
- **Batch normalization necessity:** High. Ablation shows catastrophic failure without it; multiple strategies succeed, indicating robust stabilization.
