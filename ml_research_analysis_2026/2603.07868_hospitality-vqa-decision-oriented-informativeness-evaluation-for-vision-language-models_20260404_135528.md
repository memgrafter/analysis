# Hospitality-VQA: Decision-Oriented Informativeness Evaluation for Vision-Language Models

## Quick Facts
- **arXiv ID:** 2603.07868
- **Source URL:** https://arxiv.org/abs/2603.07868
- **Reference count:** 15
- **Primary result:** General VLMs achieve >90% accuracy on coarse facility classification but fall below 30% on fine-grained decision-oriented axes; LoRA fine-tuning yields gains up to +61.29%.

## Executive Summary
Vision-Language Models (VLMs) are increasingly used for multimodal reasoning, but existing benchmarks focus on factual correctness rather than decision-relevant information, particularly in specialized domains like hospitality. The authors introduce "Informativeness," a formal framework quantifying decision-oriented visual cues across four axes—Spatial Legibility, Activity Affordance, Contextual Openness, and Geometric Completeness—and release Hospitality-VQA, a dataset of 5,000 hotel images with 19,729 question-answer pairs aligned to these axes. Evaluation on eight VLMs reveals that while general-purpose models excel at coarse facility classification (e.g., >90% accuracy), they struggle significantly on the finer-grained informativeness tasks, often scoring below 30%. However, lightweight domain adaptation via LoRA fine-tuning on Qwen2.5-VL models leads to substantial improvements, with absolute gains up to +53.24% on Spatial Legibility and +61.29% on room type prediction. The results demonstrate that achieving reliable decision-aware reasoning in hospitality requires only modest domain-specific training.

## Method Summary
The paper evaluates general-purpose VLMs on a new decision-oriented VQA benchmark, Hospitality-VQA. The dataset comprises 5,000 hotel/facility images annotated with hierarchical facility labels (main/sub-category) and four informativeness axes. All tasks are formulated as classification, with fixed templates generating question-answer pairs. The primary evaluation metric is exact-match accuracy on six classification tasks (main type, main+sub type, and four axes) and two auxiliary attributes. Baseline zero-shot performance is measured on eight VLMs (including GPT-4o, Gemini, LLaVA-NeXT, Qwen2.5-VL). The core intervention is domain adaptation via LoRA fine-tuning on Qwen2.5-VL-3B/7B models for 2 epochs using AdamW (LR 2e-5, rank r=16, α=32), with direct answer supervision (no chain-of-thought). Reproduction requires access to the dataset and exact template wording; fine-tuning can be done on a single RTX 4090 using the unsloth framework.

## Key Results
- Zero-shot VLMs achieve >90% accuracy on coarse main facility classification but drop sharply on axis-level tasks, with Activity Affordance and Geometric Completeness often below 30%.
- LoRA fine-tuning on Qwen2.5-VL yields large absolute improvements: up to +53.24% on Spatial Legibility and +61.29% on room type prediction.
- Lightweight domain adaptation (2 epochs, 4.7k training images) suffices to close most of the performance gap, highlighting the representational gap in general VLMs.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Domain-specific fine-tuning aligns VLM outputs with decision-relevant visual affordances.
- **Mechanism:** LoRA adapters update a small subset of model parameters on the Hospitality-VQA dataset, which is explicitly structured around the four informativeness axes. This supervised signal forces the model to map visual patterns to the defined decision-oriented attributes rather than generic scene descriptions.
- **Core assumption:** General VLMs pre-trained on web data lack representations for hospitality-specific functional and spatial cues.
- **Evidence anchors:**
  - [abstract] "reliable informativeness reasoning emerges only after modest domain-specific finetuning."
  - [section 5.2.3] Table 3 shows consistent absolute gains (e.g., +53.24% on SL for 7B model) from LoRA fine-tuning.
  - [corpus] Weak corpus support; neighbor papers focus on medical/general VQA, not hospitality fine-tuning effects.
- **Break condition:** If the fine-tuning distribution diverges significantly from the target deployment imagery (e.g., different hotel chains or photography styles), gains may not transfer.

### Mechanism 2
- **Claim:** General VLMs default to high-accuracy coarse scene classification but fail on fine-grained, decision-oriented axes.
- **Mechanism:** Pre-training objectives (e.g., captioning, object detection) optimize for recognizing "what is present" rather than "how it supports decision-making." This leads to a capability gap where models can identify a room interior but cannot reliably assess spatial legibility or activity affordance.
- **Core assumption:** Decision-relevant cues (e.g., visible planar surfaces for spatial legibility) are not salient in standard VLM pre-training data.
- **Evidence anchors:**
  - [section 5.2.1] "main facility classification transfers well... >90% accuracy" while "axis-level tasks exhibit a sharper drop."
  - [section 2.3] Existing benchmarks "focus on factual correctness... rarely capture what information users actually find useful."
  - [corpus] Neighbors confirm VLM brittleness in specialized contexts (e.g., medical VQA), but hospitality-specific failure modes are not directly evidenced.
- **Break condition:** If prompts are engineered to explicitly request evaluations based on the four axes (without fine-tuning), performance might improve, suggesting the issue is partly representational and partly prompting.

### Mechanism 3
- **Claim:** The hierarchical annotation schema (facility type + axis labels) provides a structured learning signal that decomposes complex visual affordances into learnable classification tasks.
- **Mechanism:** By mapping images to discrete, interpretable labels (e.g., "Spatial Legibility: count of distinct planar surfaces"), the dataset creates a curriculum that first grounds facility context and then refines into domain-grounded utility metrics. This structure may help models disentangle scene type from functional quality.
- **Core assumption:** Human annotators can consistently operationalize "informativeness" via the four axes, and this operationalization aligns with user decision criteria.
- **Evidence anchors:**
  - [section 3.1] Table 1 maps facility types to applicable axes, imposing a structured schema.
  - [section 4.2] "strict consensus protocol" and "fixed templates" enforce consistency.
  - [corpus] No direct evidence; corpus neighbors do not address this specific annotation methodology.
- **Break condition:** If the axis definitions are ambiguous or culturally biased (e.g., "Geometric Completeness" favoring certain architectural styles), the learned signal may not generalize to diverse hospitality settings.

## Foundational Learning
- **Concept:** Visual Question Answering (VQA)
  - *Why needed:* The paper frames all tasks as VQA to align with practical deployment scenarios where systems answer specific user queries. Understanding standard VQA (e.g., VQA v2) is prerequisite to seeing how Hospitality-VQA diverges by focusing on decision utility rather than factual existence.
  - *Quick check:* How does a "How many sleeping areas does this room support?" query differ in required reasoning from "What color is the sofa?" in a standard VQA dataset?
- **Concept:** Parameter-Efficient Fine-Tuning (LoRA)
  - *Why needed:* The core experimental intervention uses LoRA to adapt large VLMs with minimal overhead. Knowing how LoRA works (low-rank matrix updates) explains why gains are achieved without full model retraining and why results might vary with rank/dropout settings.
  - *Quick check:* Why might updating only attention projections and MLP layers via LoRA be sufficient for capturing new visual affordance concepts, while freezing the vision encoder?
- **Concept:** Evaluation via Classification Accuracy
  - *Why needed:* The paper deliberately formulates all tasks as categorical prediction (exact-match) to mimic real-world attribute extraction systems. This contrasts with generative VQA evaluation and impacts how model performance is interpreted—failure modes are discrete misclassifications, not vague hallucinations.
  - *Quick check:* Why is exact-match accuracy a stricter—and perhaps more practical—metric for a hospitality booking platform than BLEU or ROUGE for free-form answers?

## Architecture Onboarding
- **Component map:** Image Encoder -> Projection Layer -> Language Decoder (LLM) with LoRA Adapters inserted in attention and MLP layers. Offline Annotation Pipeline: Image collection -> Hierarchical labeling (facility type, axes) -> Template-based QA pair generation.
- **Critical path:**
  1. Start with a pre-trained VLM (e.g., Qwen2.5-VL-3B).
  2. Prepare training data: For each image, format a prompt (from fixed template) and a categorical label.
  3. Apply LoRA: freeze base model, train only adapters on image-prompt-label pairs.
  4. At inference, run image through encoder + adapters, feed with prompt to decoder, decode greedily (temp=0).
  5. Parse output to match one of the fixed label sets; compute exact-match accuracy.
- **Design tradeoffs:**
  - Fixed templates vs. free-form QA: Templates ensure controlled, repeatable evaluation but may not capture linguistic diversity; free-form could test robustness but complicates metric computation.
  - Classification formulation: Enables clean metrics but discards nuanced reasoning chains; the paper's Appendix D shows CoT fine-tuning can hurt performance under this strict evaluation.
  - Dataset scale (5k images): Manageable for research but may under-cover long-tail facility types or photographic variations; risk of overfitting to template phrasing.
- **Failure signatures:**
  - Axis collapse: Model predicts same high/low value for an axis across diverse images (e.g., always "high spatial legibility"), indicating it hasn't learned the axis concept.
  - Facility-type leakage: Model uses facility type as a shortcut for axis prediction (e.g., all "Room Interior" images get high Activity Affordance), failing to assess actual visual content.
  - Template overfitting: Model performs well on training template phrasing but fails with paraphrased prompts at test time.
- **First 3 experiments:**
  1. Zero-shot baseline: Run all eight VLMs on the 300-eval set with provided templates. Verify the core claim: high main facility accuracy but low axis accuracy.
  2. LoRA fine-tuning replication: On Qwen2.5-VL-3B/7B, reproduce Table 2 fine-tuned results. Confirm gains are consistent across random seeds and learning rates.
  3. Ablation: Axis-specific training: Fine-tune separate models per informativeness axis (SL-only, AA-only, etc.) to diagnose whether gains are from general representational shift or axis-specific adaptation. Check for interference effects.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** How can VLMs learn representations that explicitly encode hospitality-specific visual cues (e.g., spatial legibility) to enhance decision-oriented reasoning?
- **Basis in paper:** Future Directions list "domain-aware representation learning" as a research direction for advancing hospitality-aware multimodal intelligence.
- **Why unresolved:** The paper only evaluated LoRA fine-tuning; it did not explore fundamental changes to representation learning (e.g., pre-training objectives, architectural modifications) that might yield more robust and transferable improvements.
- **What evidence would resolve it:** Comparative experiments on Hospitality-VQA with different representation learning approaches (e.g., contrastive objectives, multimodal mixture-of-experts), measuring cross-facility generalization and sample efficiency.

### Open Question 2
- **Question:** What prompt engineering techniques (e.g., instruction phrasing, exemplars, chain-of-thought) most effectively elicit decision-relevant reasoning from general-purpose VLMs on hospitality VQA tasks?
- **Basis in paper:** Future Directions explicitly mention "prompt optimization" as a research direction.
- **Why unresolved:** The study used fixed templates for evaluation; the impact of prompt design on activating decision-oriented knowledge in VLMs remains unexplored.
- **What evidence would resolve it:** Systematic evaluation of diverse prompt variations (with/without CoT, with attribute definitions, with few-shot examples) across multiple VLMs, reporting accuracy on the informativeness axes.

### Open Question 3
- **Question:** Can test-time reasoning strategies (e.g., iterative refinement, visual backtracking) improve VLMs' accuracy on fine-grained hospitality informativeness without additional fine-tuning?
- **Basis in paper:** Future Directions cite "test-time reasoning strategies" as a promising extension.
- **Why unresolved:** The paper assessed only standard classification prompts and fine-tuned models; it did not test whether reasoning techniques applied at inference can boost performance on challenging axes like Geometric Completeness.
- **What evidence would resolve it:** Implementation and evaluation of test-time reasoning methods (e.g., CoT, self-consistency, multi-step visual analysis) on the benchmark, comparing results to zero-shot and fine-tuned baselines.

### Open Question 4
- **Question:** How can VLMs be trained to predict human-preferred accommodation attractiveness, and how does this correlate with the proposed informativeness dimensions (e.g., Spatial Legibility, Activity Affordance)?
- **Basis in paper:** Future Directions highlight "modeling human-preferred accommodation attractiveness" as a particularly promising extension with practical B2C and B2B applications.
- **Why unresolved:** The current framework quantifies objective visual cues but does not address subjective aesthetic appeal; the relationship between informativeness and perceived attractiveness is unknown.
- **What evidence would resolve it:** Collecting human preference ratings (e.g., booking likelihood) for images, training VLMs to predict these ratings, and conducting correlation analysis with informativeness axis scores.

## Limitations
- Dataset accessibility unknown; without public release of the 5,000 annotated images and exact test/train splits, exact replication is impossible.
- Generalization scope limited; gains from LoRA fine-tuning on hotel images from a single source (nol.yanolja.com) may not transfer to other hospitality settings (e.g., different regions, hotel chains, photography styles); no cross-dataset validation provided.
- Annotation schema validity not externally validated; there is no evidence that high axis scores actually correlate with better real-world decision-making (e.g., booking choices).
