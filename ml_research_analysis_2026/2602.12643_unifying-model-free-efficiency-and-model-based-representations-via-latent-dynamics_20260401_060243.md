# Unifying Model-Free Efficiency and Model-Based Representations via Latent Dynamics

## Quick Facts
- **arXiv ID:** 2602.12643
- **Source URL:** https://arxiv.org/abs/2602.12643
- **Reference Count:** 40
- **Primary Result:** A single algorithm (ULD) achieves strong, domain-specialist-level performance across 80 diverse environments (Gym locomotion, DMC proprioceptive/visual, Atari) with minimal hyperparameter tuning.

## Executive Summary
This paper introduces Unified Latent Dynamics (ULD), a reinforcement learning algorithm that bridges model-free and model-based paradigms. ULD learns a latent state-action representation where the value function is approximately linear, enabling efficient model-free learning. It uses short-horizon predictive auxiliary losses and reward-scale normalization to stabilize training across extremely diverse domains—from continuous control to pixel-based Atari games—without requiring planning. Theoretically, ULD's embedding-based TD fixed points match those of linear model-based value expansion. Empirically, it achieves TD3-normalized scores of 0.97, 0.96, 0.92 and human-normalized 0.94, matching or exceeding specialized baselines with a fraction of the parameters.

## Method Summary
ULD learns a state encoder ϕ_s and state-action encoder ϕ_sa to embed observations and actions into a latent space. A linear environment model m is trained via auxiliary predictive losses: it unrolls for a short horizon H_enc to predict the next state's embedding (using a slow target encoder ϕ'_s as a label), reward (via a categorical two-hot cross-entropy head), and termination. Critics Q_θ estimate value in this latent space using multi-step TD errors, with targets normalized by a running average of absolute rewards ¯r. The policy π is updated via deterministic policy gradient. All components (encoders, model, critics, policy) are updated synchronously per batch, with target networks slowly tracking the online networks. This design avoids explicit planning; the learned model only shapes the representation.

## Key Results
- ULD achieves TD3-normalized scores of **0.97 (Gym), 0.96 (DMC-proprioceptive), 0.92 (DMC-visual)** and **0.94 (Atari human-normalized)**, matching or outperforming domain-specific algorithms.
- It uses a **single, minimal hyperparameter setting** across all 80 tested environments, demonstrating remarkable cross-domain robustness.
- The approach requires **significantly fewer parameters** than many state-of-the-art model-based or model-free methods while maintaining comparable performance.

## Why This Works (Mechanism)

### Mechanism 1: Latent Space Linearization
ULD’s core hypothesis is that there exists a representation where the true value function Q^π is approximately linear in the state-action embedding z_sa. The algorithm encourages this by aligning the TD learning objective with a predictive objective that uses state-only targets, which decouples representation from the current policy. Theoretically, if the encoder can find such a linearizing representation, the TD fixed point will match that of a linear model-based value expansion, inheriting its sample efficiency. Practically, a non-linear Q-network on top of these embeddings can compensate for residual non-linearity. Evidence for this mechanism is primarily theoretical (Theorem 4.2/4.3) and empirical: strong performance across diverse MDPs suggests the learned embeddings effectively linearize value for the tasks.

### Mechanism 2: Auxiliary Predictive Losses for Stable Representation
Short-horizon auxiliary losses (reward, next-state embedding, termination) provide dense, self-supervised signals that shape the latent space to be predictive and temporally consistent. Predicting the immediate future forces the encoder to capture features relevant for both dynamics and long-term return. Crucially, dynamics targets use the slow target encoder ϕ'_s(s')—a state-only representation—which breaks the lockstep between representation learning and the current exploratory policy, preventing the representation from collapsing under a constantly shifting policy distribution. This combination (linear model + state-only targets) stabilizes representation learning across policies.

### Mechanism 3: Reward Normalization and Synchronized Updates
ULD employs a running average ¯r of absolute rewards to scale TD targets and losses. This ensures gradient magnitudes remain consistent across environments with wildly different reward scales (e.g., dense vs. sparse, Atari points vs. locomotion speed), preventing any single domain from dominating optimization. Furthermore, all networks (encoder, model, critics, policy) are updated on every batch using the same data snapshot, while target networks are slowly updated. This synchronization prevents one component (e.g., the encoder) from diverging due to stale inputs from another (e.g., outdated critics), maintaining a coherent learning signal across all modules.

## Architecture Onboarding
**Component map:**
Raw observation s -> ϕ_s (state encoder) -> z_s
z_s + a -> ϕ_sa (state-action encoder) -> z_sa
z_sa -> m (linear model) -> (predicted z_s', predicted reward distribution, predicted termination)
z_sa -> Q_θ1, Q_θ2 (critics) -> scalar value
z_s -> π (policy) -> action distribution a
Target networks: ϕ'_s, Q'_θ1, Q'_θ2, π' (slow EMA updates)
Replay buffer D stores (s, a, r, done, s')
Running statistic ¯r scales losses

**Critical path (per update iteration):**
1. Sample trajectory segments of length H_enc + H_Q + 1 from replay buffer D.
2. Initialize z_s^(0) = ϕ_s(s^(0)). For t=0 to H_enc-1: z_sa^(t) = ϕ_sa(z_s^(t), a^(t)); then (z_s_pred^(t+1), r_pred^(t+1), d_pred^(t+1)) = m(z_sa^(t)).
3. Compute L_rep: sum over t of λ_r * CrossEntropy(r_pred^(t+1), TwoHot(r^(t+1))) + λ_d * ||z_s_pred^(t+1) - ϕ'_s(s^(t+1))||² + λ_t * (d_pred^(t+1) - done^(t+1))².
4. For each step t in the segment: current Q(z_sa^(t)); target = (r^(t) + γ^{H_Q} * min_j Q'_θj(z_sa^(t+H_Q)) if not done else 0) * (1/¯r); L_value = Huber(current Q, target).
5. Policy loss: L_policy = -mean(min_j Q_θj(z_sa^π)) + λ_pre * ||pre-activation||², where a^π = π(z_s) (deterministic for gradient).
6. Backpropagate total loss L_rep + L_value + L_policy to update ϕ_s, ϕ_sa, m, Q_θ, π.
7. Every T_target steps: soft-update target networks (ϕ'_s ← ϕ_s, etc.) and update ¯r with batch's |r|.

**Design tradeoffs:**
- Linear environment model: Simplicity and speed vs. limited expressiveness; non-linear critics compensate.
- State-only dynamics targets: Decouples representation from current policy, improving stability, but assumes state embeddings alone suffice for prediction under any policy.
- Two-hot reward encoding: Handles diverse scales but adds hyperparameters (atoms, spacing) and may be less sample-efficient than MSE for dense rewards.
- Synchronized updates: Prevents module divergence but risks mutual interference; target networks mitigate this.

**Failure signatures:**
- Latent collapse: L_dynamics very low but L_value remains high → embeddings lose discriminative information (check pairwise z_s distances).
- Reward scaling instability: ¯r → 0 or explodes → gradients vanish or explode; monitor ¯r trajectory.
- TD error divergence: L_value returns NaN or huge values → unstable value learning, often from scaling mismatch or initialization.
- Policy saturation: Continuous actions saturate at bounds |a|≈1 → poor exploration; adjust noise or regularization.
- Auxiliary loss dominance: L_rep >> L_value in magnitude → representation overfits to prediction; adjust λ coefficients.

**First 3 experiments:**
1. **HalfCheetah (Gym)**: Validate basic continuous control learning. Expect TD3-normalized score >1.0, all losses decreasing, ¯r stable.
2. **Cartpole swingup sparse (DMC proprioceptive)**: Test sparse reward adaptation. Confirm ULD learns swing-up; check ¯r adapts to occasional large positive rewards.

## Open Questions the Paper Calls Out
### Open Question 1
How can ULD be extended to effectively handle tasks requiring long-horizon reasoning, hard exploration, or non-Markovian dependencies, which are explicitly identified as current limitations?

### Open Question 2
Does ULD's cross-domain competence observed on standard benchmarks transfer to truly out-of-distribution real-world scenarios, such as multi-agent coordination, robotic manipulation with diverse dynamics, or language-conditioned control?

### Open Question 3
What specific properties of ULD's architecture and training objectives enable its cross-domain generalization, and can these be formally characterized beyond empirical benchmark performance?

### Open Question 4
How tight are the theoretical error bounds (Theorem 4.2) in practice for complex, high-dimensional MDPs like Atari, and do they predict empirical performance degradation in environments with stochastic dynamics or extremely sparse rewards?

### Open Question 5
How does the prediction horizon `H_enc` for representation learning (typically 3-5 steps) trade off against representation quality and final performance across different domain types (continuous control vs. discrete Atari)?

## Limitations
- **Reproducibility gaps:** Key hyperparameters (learning rates, loss weights λ, architectures) are undisclosed, blocking exact replication.
- **Theoretical assumptions:** The linear value approximation claim relies on the existence of a suitable latent space; its viability under complex, high-dimensional tasks is empirically supported but not theoretically guaranteed.
- **Auxiliary loss design:** The impact of state-only dynamics targets and two-hot reward encoding across diverse domains is not ablated; break conditions (e.g., H_enc too long) are asserted but not systematically tested.

## Confidence
- *Unified performance across 80 environments:* Medium – strong empirical results, but undisclosed tuning may hide domain-specific adjustments.
- *Linear embedding for value function:* Medium – theoretical fixed-point equivalence is proven, but practical linearity in latent space is inferred from losses, not directly measured.
- *Auxiliary predictive losses shape useful representations:* Medium – supported by representation learning literature and ULD’s losses, but causal link to final performance is indirect.
- *Theoretical bounds tightness in complex MDPs:* Low – bounds derived for linear approximations may not capture non-linear compensations or high-dimensional stochasticity.
- *Cross-domain stability heuristics (reward normalization, sync updates):* Low – practical stabilizers whose interaction under abrupt shifts lacks analysis.
