# A Neuropsychologically Grounded Evaluation of LLM Cognitive Abilities

## Quick Facts
- **ArXiv ID:** 2603.02540  
- **Source URL:** https://arxiv.org/abs/2603.02540  
- **Reference count:** 40  
- **Primary result:** LLM benchmarks miss core cognitive abilities; NeuroCognition reveals gaps via neuropsychological tests, showing text superiority over images, mixed ablation effects, and a distinct factor structure despite positive correlations with standard benchmarks.

## Executive Summary
This paper introduces NeuroCognition, a multimodal benchmark adapting three neuropsychological tests—Raven’s Progressive Matrices (abstract reasoning), Spatial Working Memory (state tracking), and Wisconsin Card Sorting (cognitive flexibility)—to evaluate foundational cognitive abilities in LLMs. Testing 10 state-of-the-art models reveals consistent advantages on text-based inputs versus images, steep performance drops with increased complexity, and contradictory effects from reasoning control and scaffolding. Factor analysis across 156 models shows a dominant general factor (75% variance) in standard benchmarks, but NeuroCognition scores correlate positively while measuring distinct abilities (e.g., RAPM image correlates r=0.87 with ARC-AGI2). The work argues that current LLM benchmarks overemphasize knowledge and pattern matching, overlooking core processes, and that NeuroCognition can guide targeted cognitive improvements.

## Method Summary
The authors built NeuroCognition by adapting three neuropsychological tests: Raven’s Progressive Matrices (RAPM) for abstract reasoning, Spatial Working Memory (SWM) for state tracking, and Wisconsin Card Sorting (WCST) for cognitive flexibility. Each test was implemented in text (synthetic data for control) and image modalities (using the RAVEN dataset for RAPM; synthetic grids for SWM/WCST). Ten LLMs were evaluated under baseline conditions and ablations (reasoning on/off, pattern hints, note-taking). Performance was measured via task-specific metrics (S_rapm, S_swm, S_wcst) and error counts. Additionally, factor analysis was conducted on scores from 156 models across 10 standard benchmarks and NeuroCognition to assess distinctiveness. The methodology prioritizes controlled cognitive operations over domain knowledge.

## Key Results
- LLMs show strong text performance but degrade sharply on image inputs and with higher complexity (e.g., more tokens, ambiguous rules).
- Disabling reasoning improves RAPM multiple-choice text accuracy; enabling complex reasoning is not consistently beneficial.
- Pattern hints have minimal impact; note-taking consistently benefits WCST but not SWM.
- Factor analysis reveals a dominant general factor (75% variance) in standard benchmarks; NeuroCognition correlates positively but loads on distinct factors, with specific tests correlating with related benchmarks (e.g., RAPM image with ARC-AGI2, r=0.87).

## Why This Works (Mechanism)

**Mechanism 1: General Factor vs. Distinct Abilities**  
The dominant general factor in standard benchmarks (75% variance) reflects shared methodological biases like knowledge recall and surface pattern matching. NeuroCognition’s tasks minimize knowledge demands and target foundational processes (relational reasoning, cognitive flexibility), leading to positive but distinct correlations. Evidence: Factor analysis in Section 6.1; correlation matrix in Section 6.2 (e.g., RAPM Image MC vs ARC-AGI2 r=0.87). Break condition: If NeuroCognition scores become nearly perfectly predicted (r≥0.95) by the first principal component of standard benchmarks, the test would collapse into the general factor.

**Mechanism 2: Modality-Specific Processing Bottleneck**  
LLMs’ text advantage indicates that cognitive abilities like abstract reasoning are not robustly transferred to the visual domain. Text provides discrete tokens aligning with transformer architecture, while images require spatial grounding and larger contexts. Consistent underperformance on images and complex variants suggests limitations in vision-language integration or internal representation. Evidence: Abstract and Section 4.1 show text > image even with combined modalities; Section 4.2 details error patterns (hallucination, no-box errors). Break condition: If models achieve <5% performance gap between text and image on equivalent relational tasks (e.g., RAPM MC), the bottleneck is resolved.

**Mechanism 3: Representational Rigidity vs. Memory Capacity**  
Note-taking helps WCST (tracking rule hypotheses) but not SWM (spatial state updates), suggesting SWM deficits stem from representational rigidity rather than pure working memory capacity. External notes aid hypothesis management but cannot compensate if the model fails to integrate spatial layout. Evidence: Abstract and Section 5.3 show WCST improvements from notes but null effect in SWM. Break condition: If note-taking yields significant improvements in both SWM and WCST across models, deficits would be reinterpreted as memory capacity limitations.

## Foundational Learning

- **General Factor (g) in Psychometrics**  
  *Why needed:* To interpret factor analysis showing standard benchmarks share a common latent variable.  
  *Quick check:* What does a single factor explaining 75% of variance indicate? (Answer: A general ability like intelligence drives performance, obscuring task-specific skills.)

- **Cognitive Offloading**  
  *Why needed:* To understand why external notes help some tasks but not others, revealing the nature of LLM limitations.  
  *Quick check:* If notes help WCST but not SWM, what does that suggest about SWM bottlenecks? (Answer: The issue is likely spatial representational rigidity, not memory capacity.)

- **Measurement Invariance in Neuropsychological Testing**  
  *Why needed:* Because adapting human tests to LLMs requires verifying they measure the same construct.  
  *Quick check:* Why is measurement invariance critical before claiming LLMs have cognitive deficits? (Answer: Without it, performance differences could be due to test artifacts, not true cognitive differences.)

## Architecture Onboarding

**Component Map**  
Data Generators -> Task Executors -> Assistant Modules (hints/notes) -> Metrics Calculators -> Analysis Toolkit  
Model API Handler interfaces with Task Executors and Assistant Modules.

**Critical Path**  
1. Configure API credentials and install dependencies.  
2. Validate each test with deterministic examples.  
3. Run baseline on a reference model (e.g., GPT-5) in text mode.  
4. Extend to image modality; integrate visual data.  
5. Implement ablations (reasoning on/off, hints/notes).  
6. Scale to full test sets and all models; collect outputs.  
7. Perform factor analysis (need ≥100 models; may use public scores).

**Design Tradeoffs**  
- Synthetic vs real data: RAPM text uses synthetic for control; RAPM image uses RAVEN for ecological validity but limited samples.  
- MC vs generative: MC scores easily; generative requires validation and may reject valid responses.  
- Sample size: Paper uses ~200 text and 140 image items; for iteration, 20–50 per condition may suffice.  
- Reasoning control: Not all models support fine-grained toggles; prompt tweaks may be needed.

**Failure Signatures**  
- RAPM: hallucinations, semantic over-interpretation.  
- SWM: high illegal/repeat counts, high no-box rates.  
- WCST: high perseverative response (PR) and failure-to-maintain-set (FMS), especially after switches.  
- Infrastructure: API timeouts, image loading errors, response parsing failures.

**First 3 Experiments**  
1. Sanity baseline: Evaluate GPT-5 on RAPM-MC (text, 10 items), SWM-Easy (text), WCST-Easy (text). Expect S_rapm ≥0.5, S_swm=1.0, S_wcst ≥0.8.  
2. Modality gap: Run RAPM-MC on same model for text vs image; confirm image accuracy ≥20% lower.  
3. Ablation – reasoning: For Gemini 2.5 Pro, compare RAPM-MC text with reasoning on vs off; expect Δ≥+0.15 for no-reasoning.

## Open Questions the Paper Calls Out
1. Do NeuroCognition tests measure the same cognitive abilities in LLMs as in humans? Without measurement invariance, performance gaps may reflect test artifacts.
2. Can training on synthetic NeuroCognition data improve LLM cognitive abilities, and does it generalize? Unclear if LLMs can acquire such abilities via targeted data.
3. Why does note-taking improve WCST but not SWM, and how might note-taking be adapted for spatial working memory? Textual notes may be ill-suited for spatial states.

## Limitations
- **Measurement invariance:** NeuroCognition adapted from human tests; validity for LLMs unverified.
- **Limited image samples:** RAVEN-based tasks use only 140 items, risking low reliability.
- **Note-taking implementation:** Only one summarization format tested; other scaffolds could differ.

## Confidence
- **Dominant general factor (75% variance):** High (large N=156, replicates prior work).
- **NeuroCognition distinctiveness:** Medium (positive correlations but separate factors; depends on benchmark selection).
- **Modality bottleneck (text > image, complexity drop):** High (consistent across tests and models).
- **Note-taking differential (WCST benefit, SWM no benefit):** Medium (WCST gains significant; SWM null may reflect true limits or power).

## Next Checks
1. **Factor robustness expansion:** Replicate factor analysis with 30+ diverse standard benchmarks; if NeuroCognition remains distinct, its incremental validity is secured.
2. **Vision-specialist model test:** Evaluate a vision-only model (e.g., ViT-based) on RAPM-image and SWM-image; smaller text-image gap would confirm bottleneck in vision-language integration.
3. **Memory scaffold variation:** Compare structured note-taking against raw conversation history in SWM and WCST; if notes help WCST but not SWM across formats, it strengthens the claim about SWM’s spatial representational rigidity.
