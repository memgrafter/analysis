# Invariant Transformation and Resampling based Epistemic-Uncertainty Reduction

## Quick Facts
- **arXiv ID**: 2602.23315  
- **Source URL**: https://arxiv.org/abs/2602.23315  
- **Reference Count**: 30  
- **Primary Result**: A resampling method with invariant transformations reduces epistemic uncertainty in AI-based MIMO detection, achieving up to 0.7 dB BLER improvement at 10% BLER and 0.5 dB gain at 1% uncoded BER for an 8×8 256QAM system with LDPC coding.

## Executive Summary
The paper tackles inference errors arising from epistemic uncertainty in AI models. By applying invariant transformations (e.g., negations, permutations, complex conjugates) to the input and combining the multiple outputs, the variance of estimation errors is reduced. The method is demonstrated on a Transformer-based MIMO detector, where combining four resampled outputs yields significant gains in BLER and BER over a single-sample baseline. Theoretical analysis via a linear combination theorem predicts the error correlation reduction, which matches empirical observations.

## Method Summary
The approach consists of two phases: (1) training a Transformer-based MIMO detector on synthetic data generated from received signals and channel matrices; and (2) at inference, generating several transformed versions of the input (e.g., `(y, H)`, `(-y, -H)`, `(y, HP)`, `(y*, 1j·H*)`), feeding each through the trained model, and linearly combining the outputs (averaging or weighted per Theorem 1). The combination reduces the variance of errors due to epistemic uncertainty, leading to improved detection performance. The method is evaluated using LDPC coding and metrics such as BLER and uncoded BER.

## Key Results
- **BLER improvement**: Up to 0.7 dB gain at 10% BLER for 8×8 MIMO with 256QAM and LDPC.
- **BER improvement**: Up to 0.5 dB gain at 1% uncoded BER.
- **Error correlation**: Measured reduction in error correlation aligns with the predictions of the derived linear combination theorem.

## Why This Works (Mechanism)
Epistemic uncertainty stems from the model's limited training data or capacity, causing its predictions to vary across plausible inputs. The invariant transformations produce inputs that are mathematically equivalent for the underlying detection problem, so the true signal remains unchanged. However, the model's predictions may differ due to epistemic effects. By combining predictions across these transformed samples (e.g., averaging), the independent components of the estimation error cancel out, reducing the overall variance. Theorem 1 provides the optimal linear weights given the error covariance among the resampled outputs, further minimizing the mean-squared error. This mechanism effectively converts some epistemic uncertainty into a reducible variance via ensembling over symmetry.

## Architecture Onboarding
### Component Map
Input (y,H) -> Transformation Module (M versions) -> AI Detector (Transformer) -> Output Combiner (weighted sum) -> Decision (symbol/LLR)

### Critical Path
- **Training phase**: Generate synthetic MIMO data (Rayleigh H, QAM s, AWGN n), train Transformer to map (y,H) to symbol probabilities or LLRs.
- **Inference phase**: For each test sample, create M invariant transformations; run the detector on each; combine outputs using average or weights from Theorem 1; produce final decision.

### Design Tradeoffs
- **Number of resamples (M)**: More samples reduce variance but increase latency linearly.
- **Transformation choice**: Must preserve invariance; limited to transformations that maintain detection equivalence for the real-valued model.
- **Averaging vs weighted**: Weighting requires estimating error correlations on validation data; averaging is simpler but suboptimal.
- **Transformer capacity**: Larger models improve baseline accuracy but increase computational cost.

### Failure Signatures
- No performance gain after resampling: indicates high correlation among transformed errors (ρ≈1) or incorrect transformations breaking invariance.
- Baseline underperformance relative to conventional methods: suggests insufficient model capacity or poor training.
- Inconsistent results across random permutations: permutation implementation may be flawed.

### First Experiments
1. **Validate Invariance**: For a batch of inputs, apply each transformation and confirm that symbol error rates are identical (within statistical noise). Also verify that transformed inputs can be inverted to original.
2. **Measure Error Correlation**: Compute pairwise error (e.g., symbol difference) correlation across resampled outputs on a validation set; estimate ρ for use in Theorem 1.
3. **Compare Combination Strategies**: Evaluate uniform averaging and optimal weighting (using estimated ρ) against single-sample baseline; assess gain and confirm theoretical predictions of variance reduction.

## Limitations
- Missing training hyperparameters (learning rate, batch size, optimizer, epochs) hinders exact replication.
- LDPC configuration (block length, rate 12/13, iterations) not fully specified, affecting BLER comparison.
- ETU-70Hz channel model details (delay profile, Doppler) are incomplete.
- Ambiguity in the complex conjugate transformation `(y*, 1j·H*)` may cause implementation errors.
- Results are evaluated only for 8×8 MIMO with 256QAM; generalizability to other configurations is uncertain.
