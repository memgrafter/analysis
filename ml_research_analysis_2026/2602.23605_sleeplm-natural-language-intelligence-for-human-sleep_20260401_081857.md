# SleepLM: Natural-Language Intelligence for Human Sleep

## Quick Facts
- **ArXiv ID:** 2602.23605  
- **Source URL:** https://arxiv.org/abs/2602.23605  
- **Reference count:** 40  
- **Primary result:** SleepLM significantly outperforms state-of-the-art LLMs and VLMs in zero‑shot sleep analysis tasks, achieving 85.4% AUC for staging, 30.4% IoU for event localization, and >94% Recall@1 for cross‑modal retrieval.

## Executive Summary
Existing sleep analysis systems are limited to predefined label spaces and cannot describe, query, or generalize to novel sleep phenomena. SleepLM introduces a multimodal foundation model that aligns polysomnography (PSG) signals with natural language. It creates the first large‑scale sleep‑text dataset (>100K hours, >10K individuals) via a multilevel captioning pipeline and proposes ReCoCa, a unified pretraining objective combining contrastive alignment, caption generation, and signal reconstruction. The model enables zero‑shot sleep staging, event localization, cross‑modal retrieval, and generalization to unseen clinical events, demonstrating robust performance across multiple tasks without task‑specific fine‑tuning.

## Method Summary
SleepLM’s training data is derived from public cohorts (SHHS, MrOS, CCSHS) with multimodal PSG (12 channels at 64 Hz) segmented into 30‑second epochs. Three caption levels are generated: channel‑specific statistics, local event descriptions (arousals, apneas, desaturations), and global summaries. The ReCoCa objective jointly optimizes: (1) contrastive loss (InfoNCE) for cross‑modal alignment, (2) autoregressive captioning loss to generate text from PSG, and (3) reconstruction loss (MSE) to recover input signals from encoder latents. The architecture uses channel‑specific sleep encoders with interleaved temporal and channel attention, separate text encoder/decoder, and modality tokens ([Brain]/[Respiratory]/[Cardiac]/[Somatic]) to condition generation. Training uses AdamW (lr=1e‑4, batch=384) for 15 epochs with subject‑level splits.

## Key Results
- Zero‑shot sleep staging: **85.4% AUC**  
- Event localization (temporal): **30.4% IoU**  
- Cross‑modal retrieval: **>94% Recall@1**  
- Generalization to unseen clinical events: **~80% F1**

## Why This Works (Mechanism)
ReCoCa’s multimodal pretraining aligns PSG embeddings with natural language via contrastive learning, while the captioning objective forces fine‑grained semantic understanding of sleep events and patterns. Reconstruction preserves low‑level signal fidelity. The multilevel captions provide hierarchical supervision—from raw statistics to global narratives—enabling the model to learn both localized events and overarching sleep architecture. This combination allows the model to map novel PSG patterns to language descriptions without retraining, achieving zero‑shot generalization.

## Foundational Learning
1. **Multimodal alignment** – Why needed: To bridge continuous physiological signals and discrete language tokens for bidirectional retrieval and generation.  
   Quick check: Validate with high Recall@1 on cross‑modal search tasks.

2. **Zero‑shot generalization** – Why needed: Sleep research encounters rare or newly defined events; a foundation model must adapt without labeled data.  
   Quick check: Evaluate performance on held‑out event categories using presence/absence templates.

3. **Hierarchical captioning** – Why needed: Sleep analysis requires understanding at multiple scales (channel metrics, event timing, nightly summaries).  
   Quick check: Audit caption granularity distribution; ensure coverage of all PSG channels and event types.

4. **Contrastive pretraining** – Why needed: Learns a shared embedding space where similar PSG and text are proximate.  
   Quick check: Tune temperature τ and enforce strong in‑batch negatives; monitor validation retrieval.

5. **Signal reconstruction** – Why needed: Prevents encoder from discarding low‑level details useful for precise localization (e.g., waveform morphology).  
   Quick check: Track reconstruction MSE; ensure it does not dominate total loss (λ_rec=0.1).

## Architecture Onboarding
**Component map:**  
Raw PSG (12 channels) -> Sleep Encoder (per‑channel patches) -> Multimodal embeddings -> [Modality token] -> Text Decoder (for captioning) / Sleep Decoder (for reconstruction). Text Encoder processes captions independently; embeddings compared via contrastive loss.

**Critical path:**  
PSG input → Patch embedding (1 s patches) → Stacked layers (temporal self‑attention with RoPE, channel attention with learnable RoPE) → CLS token → Projection to text space → Contrastive loss.

**Design tradeoffs:**  
- Patch length: Smaller patches capture finer temporal details but increase sequence length and compute.  
- Loss weighting (λ_con, λ_cap, λ_rec): Imbalance risks misalignment (λ_rec too high) or poor signal fidelity (λ_cap too low).  
- Modality tokens: Separate tokens for each PSG subsystem enable targeted generation but require careful caption annotation.

**Failure signatures:**  
- Retrieval Recall@1 <70% → contrastive loss misconfiguration (temperature, batch size).  
- Localization IoU <20% → insufficient local caption diversity or patch size mismatch.  
- Reconstruction MSE near zero but main metrics degrade → λ_rec overweighted, encoder prioritizing low‑level reconstruction over semantics.

**First three experiments:**  
1. Ablate patch length (0.5 s, 1 s, 2 s) and measure staging AUC and localization IoU to identify optimal temporal resolution.  
2. Audit text tokenization: reconstruct vocabulary size (~10 k) and OOV rates on caption corpus; compare convergence with/without pretrained tokenizer.  
3. Validate caption generation rules: implement local event detection with described thresholds; compute Jensen‑Shannon divergence against (if obtainable) original event distributions.

## Limitations
- **Data curation ambiguity:** Exact thresholds for local captions (e.g., apnea severity, desaturation slope) are unspecified, risking dataset shift.  
- **Architecture underspecification:** Patch size (temporal length) not stated; assumed 1 s but could affect temporal receptive field.  
- **Tokenization/initialization uncertainty:** Vocabulary details and whether text modules use pretrained weights are unclear, impacting multimodal alignment.

## Confidence
- **Dataset scale (100K+ hours, 10K+ individuals):** High – aligns with public cohort statistics.  
- **Zero‑shot performance (85.4% AUC staging, 30.4% IoU):** Medium – metrics reported but reproducibility depends on unresolved hyperparameters and caption distribution.  
- **Generalization to unseen events (~80% F1):** Medium – concept of “unseen” defined, but event definitions and few‑shot protocol details sparse.

## Next Checks
1. **Patch size verification:** Query authors or infer from model code; train ablations with 0.5 s/1 s/2 s patches and report staging AUC stability.  
2. **Tokenization audit:** Recover BPE merges and vocabulary from training logs; compute caption token length distribution and OOV rates vs. claimed ~10 k vocab.  
3. **Caption replication:** Implement local caption extraction using identical rules; measure distribution overlap (e.g., J‑S divergence) with any available original caption corpus.
