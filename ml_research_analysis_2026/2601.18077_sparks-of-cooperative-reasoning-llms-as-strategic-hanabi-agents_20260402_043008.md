# Sparks of Cooperative Reasoning: LLMs as Strategic Hanabi Agents

## Quick Facts
- **arXiv ID:** 2601.18077  
- **Source URL:** https://arxiv.org/abs/2601.18077  
- **Reference count:** 40  
- **Primary result:** Top reasoning models reach up to 18/25 in Hanabi; fine‑tuned 4B model surpasses GPT‑4.1 by 52% and generalizes to other cooperative tasks.

## Executive Summary
This paper evaluates large language models (LLMs) as cooperative agents in the imperfect‑information card game Hanabi, which demands theory‑of‑mind and strategic communication. The authors introduce three prompt scaffolds—Watson (minimal context), Sherlock (Bayesian‑motivated deductions), and Mycroft (implicit multi‑turn state tracking)—and benchmark 17 LLMs across 2–5 player settings. While top reasoning models achieve up to 18/25 points, they still trail human experts and specialized agents. To foster future research, the authors release HanabiLogs (1,520 annotated trajectories) and HanabiRewards (560 games with move‑level utilities). Supervised and reinforcement learning fine‑tuning of a 4B model on these datasets boosts performance by 21–156%, brings it within ~3 points of o4‑mini, surpasses GPT‑4.1 by 52%, and yields improvements on several out‑of‑distribution cooperative and reasoning benchmarks.

## Method Summary
The study systematically evaluates LLMs in Hanabi using the Hanabi Learning Environment (HLE). Three prompt templates provide varying reasoning depth: Watson supplies only the current observation; Sherlock adds Bayesian‑style probability updates; Mycroft incorporates multi‑turn deduction blocks to implicitly track belief states. Seventeen models (4B–600B+ parameters) are tested with fixed seeds and standard decoding settings for 10 games per seed. Two new datasets are introduced: HanabiLogs (human‑like trajectories with JSON‑formatted actions and deduction blocks) and HanabiRewards (move‑level utility scores rated by an LLM judge). A 4B model (Qwen3‑4B‑Instruct) is first fine‑tuned via supervised learning on HanabiLogs (LoRA, 3 epochs) and then via reinforcement learning (GRPO) on HanabiRewards. Generalization is assessed on Group Guessing Game, EventQA, IFBench, and AIME2025.

## Key Results
- Top reasoning models (e.g., o3, Grok‑3‑mini) achieve up to 18/25 points in Hanabi, still below human experts (>20/25).  
- Cross‑play performance smoothly interpolates between self‑play scores as model strength varies, indicating scalable cooperation.  
- Fine‑tuned 4B model improves Hanabi performance by 21–156%, surpasses GPT‑4.1 by 52%, and generalizes to other benchmarks (+11% Group Guessing, +6.4% EventQA, +1.7% IFBench) while retaining AIME2025 math scores.

## Why This Works (Mechanism)
The gains arise from two complementary factors. First, the prompt scaffolds gradually increase reasoning overhead: Watson provides a clean baseline; Sherlock introduces probabilistic inference that helps disambiguate teammates’ knowledge; Mycroft maintains a running belief state that supports long‑horizon consistency. Second, fine‑tuning on annotated trajectories teaches the model the conventions and action sequences typical of skilled play, while RL on move‑level rewards shapes strategic decision‑making beyond mimicry. The combination of structured reasoning and targeted learning allows even a small model to approach the performance of much larger baseline LLMs.

## Foundational Learning
- **Theory of Mind** – Models must infer what teammates know from limited clues; essential for coordination in partially observable settings.  
  *Quick check:* Predict the probability distribution of another player’s hand given a clue; compare to ground truth in simulation.  
- **Prompt Engineering** – Careful scaffolding (Watson, Sherlock, Mycroft) guides LLMs through necessary reasoning steps without changing model weights.  
  *Quick check:* Run ablation with/without Bayesian deduction to isolate its contribution to score.  
- **Dense Reward Annotation** – Move‑level utilities from an LLM judge provide a training signal for reinforcement learning, enabling fine‑grained strategy improvement.  
  *Quick check:* Verify correlation between judge scores and expert‑rated move quality on a held‑out sample.  
- **Cross‑Play Evaluation** – Testing heterogeneous teams reveals how model capability translates to cooperative performance; smooth interpolation suggests scalability.  
  *Quick check:* Pair a weak and a strong model; measure score relative to each model’s self‑play.  
- **Implicit State Tracking** – Maintaining a belief state across many turns is critical for long‑term consistency; Mycroft’s deduction blocks are an attempt to achieve this.  
  *Quick check:* Use an LLM‑as‑judge to evaluate consistency of deduction blocks over the course of a game.

## Architecture Onboarding
- **Component map:** Game State → Prompt Template (Watson/Sherlock/Mycroft) → LLM → JSON Action → HLE Step → New Game State → Score.  
  Additionally: LLM (as judge) → Move Rating → Reward Dataset; HanabiLogs/HanabiRewards → SFT/RL → Fine‑tuned LLM.  
- **Critical path:** For evaluation: initialize HLE with seed → observe state → format prompt → query LLM → parse JSON → apply action → repeat until game end → compute score. For fine‑tuning: collect trajectories → annotate actions and rewards → SFT on (state, action) pairs → RL optimization using move‑level rewards.  
- **Design tradeoffs:**  
  - Prompt complexity vs. legality/decode errors: richer prompts improve reasoning but increase parsing failures.  
  - SFT vs. RL data efficiency: SFT learns static patterns; RL adapts to long‑term outcomes but is sensitive to reward noise.  
  - Model size vs. inference cost: larger models benefit from reasoning but are slower; fine‑tuning small models offers a pragmatic tradeoff.  
- **Failure signatures:** Frequent JSON parse errors or markdown fences; illegal actions (e.g., playing out of turn); deduction blocks becoming inconsistent after ~60 turns; high variance in cross‑play scores for non‑reasoning models; collapse of policy during RL if KL penalty or batch size is mis‑set.  
- **First experiments:**  
  1. Baseline evaluation of all 17 models with Watson prompt across 2–5 players; record scores and failure rates.  
  2. Introduce Sherlock and Mycroft prompts; compare incremental gains and error statistics.  
  3. Fine‑tune Qwen3‑4B‑Instruct on HanabiLogs (SFT) then HanabiRewards (RL); evaluate on Hanabi and the four generalization benchmarks.

## Open Questions the Paper Calls Out
1. How can dense reward annotations for cooperative games like Hanabi be automatically generated using LLM oracles with full game state access?  
2. What techniques can ensure strategy convergence and convention alignment among heterogeneous LLM agents cooperating under partial information?  
3. How does cross‑play performance systematically interpolate across the full spectrum of LLM capabilities, player counts, and cooperative task structures?  
4. How can LLMs be explicitly trained to incorporate theory‑of‑mind reasoning and belief‑state tracking for robust long‑horizon cooperation?

## Limitations
- Inference parameters (temperature, top‑k) for many models are unspecified, potentially affecting score reproducibility.  
- RL fine‑tuning details (KL coefficient, reward normalization, optimizer settings) are omitted, limiting precise recreation.  
- Released datasets are relatively small (1,520 trajectories, 560 games); gains may be sensitive to distributional quirks.  
- Human baseline collection method and filtering criteria are not described, making expert comparisons ambiguous.
