# NeuronScope: A Multi-Agent Framework for Explaining Polysemantic Neurons in Language Models

## Quick Facts
- **ArXiv ID**: 2601.03671
- **Source URL**: https://arxiv.org/abs/2601.03671
- **Reference count**: 40
- **Primary result**: Iterative multi-agent refinement improves activation prediction Score by 0.05–0.10 without altering the number of semantic concepts, converging in ~5 iterations.

## Executive Summary
NeuronScope introduces a multi-agent framework to interpret polysemantic neurons—individual neurons that activate on multiple distinct concepts—in large language models. Reinterpreting neuron interpretation as an iterative, activation-guided process, the system employs four sequential agents: a Hypothesis Agent generates raw explanations from high-activation examples; a Decomposition Agent breaks these into atomic components; a Clustering Agent groups them into distinct semantic modes; and a Refinement Agent iteratively optimizes explanations using activation feedback to maximize predictive correlation. Experiments across three models (Llama-3.1-8B, Gemma-2-2B, Qwen3-4B) show that adding the Refinement Agent consistently boosts the activation prediction Score metric by 0.05–0.10 across all layers while preserving the count of semantic concepts. The refinement converges within about five iterations, yielding more faithful and precise neuron explanations that reveal hidden polysemanticity.

The framework demonstrates that precise, faithful interpretations of polysemantic neurons can be achieved without sacrificing coverage, offering a scalable path toward mechanistic understanding of LLMs.

## Method Summary
NeuronScope’s core method reformulates neuron interpretation as an iterative process guided by activation patterns. It operates through a pipeline of four specialized agents. First, the Hypothesis Agent analyzes a set of high-activation examples to produce broad, natural language explanations for the neuron’s behavior. Next, the Decomposition Agent disassembles these explanations into atomic semantic components. The Clustering Agent then groups these components based on embedding similarity to identify distinct semantic modes—i.e., the different concepts the neuron responds to. Finally, the Refinement Agent enters an iterative loop where it adjusts the explanations (by modifying or combining components) to maximize the activation prediction Score, which measures how well the explanation predicts actual neuron activations on a held-out set. The process stops when the Score stabilizes, typically within five iterations, yielding a refined set of explanations that faithfully capture the neuron’s polysemantic nature.

## Key Results
- Adding the Refinement Agent improves activation prediction Score by 0.05–0.10 consistently across all tested models and layers.
- The number of distinct semantic concepts (Number) remains unchanged by refinement, indicating that polysemanticity detection is preserved.
- The iterative refinement converges rapidly, within approximately five iterations, demonstrating efficient optimization.

## Why This Works (Mechanism)
The multi-agent approach works because it explicitly separates hypothesis generation, decomposition, and mode discovery, while the Refinement Agent closes the loop by using activation feedback to fine-tune explanations into a form that strongly correlates with actual neuron behavior. By iterating, the framework gradually reduces explanation error, moving from coarse hypotheses to precise, predictive descriptions. The clustering step ensures that multiple semantic modes are identified without merging distinct concepts, and the refinement process systematically adjusts explanations to maximize the Score, effectively aligning them with the underlying activation patterns. This guided, iterative optimization yields explanations that are both faithful (high Score) and comprehensive (preserving the count of concepts).

## Foundational Learning
- **Polysemantic Neurons**: Single neurons that activate for multiple, semantically distinct concepts, complicating mechanistic interpretation. Why needed: The target phenomenon NeuronScope aims to explain. Quick check: Find a neuron in a small transformer that fires for both “king” and “queen” as well as “apple” and “orange” in different contexts.
- **Activation Prediction Score**: Metric quantifying the correlation between a neuron's actual activations and those predicted by its explanation (e.g., via linear regression). Why needed: Provides a numeric measure of explanation faithfulness. Quick check: Given a list of explanations and corresponding activation values, compute the R² score.
- **Multi-agent Framework**: A modular system where independent LLM-based agents perform specialized tasks (hypothesis generation, decomposition, clustering, refinement). Why needed: Enables focused processing and iterative improvement without overloading a single model. Quick check: Draw the data flow between agents and identify inputs/outputs of each.
- **Clustering for Semantic Modes**: Using algorithms like HDBSCAN on embedding vectors of explanation fragments to group them into distinct semantic concepts. Why needed: Discovers the separate meanings a polysemantic neuron encodes. Quick check: Cluster short text phrases using cosine similarity and interpret cluster labels.
- **Iterative Refinement**: Repeatedly adjusting explanations based on activation feedback to maximize a target metric. Why needed: Allows the system to converge on a locally optimal explanation set. Quick check: Implement a simple loop that updates explanations to improve a score over 5 iterations.

## Architecture Onboarding
**Component Map**: Hypothesis Agent → Decomposition Agent → Clustering Agent → Refinement Agent (iterative)

**Critical Path**: The pipeline starts with a curated set of high-activation examples for a given neuron. The Hypothesis Agent produces initial natural language explanations. The Decomposition Agent splits these into atomic semantic units. The Clustering Agent groups these units into semantic modes. The Refinement Agent then enters a loop: in each iteration, it evaluates the current set of explanations (or clusters) against activation data to compute the Score, then modifies explanations to increase the Score. The loop terminates when the Score change falls below a threshold or after a fixed number of steps, yielding the final explanation.

**Design Tradeoffs**:
- *Modularity vs. Overhead*: Separating concerns into agents improves interpretability and debuggability but introduces latency and LLM API costs.
- *Iteration Depth vs. Efficiency*: More refinement iterations can improve Score but increase computational load; the paper finds ~5 iterations sufficient for convergence.
- *Clustering Granularity*: HDBSCAN with minimum cluster size=2 balances sensitivity to small modes with noise rejection, but may miss subtle polysemanticity if the threshold is too high.
- *LLM Agent Reliability*: The quality of explanations depends on the prompt engineering and capabilities of the underlying LLM; poor prompts lead to incoherent outputs.

**Failure Signatures**:
- Refinement Agent fails to increase Score after the first iteration, suggesting the initial explanations are already optimal or the feedback signal is noisy.
- Clustering Agent collapses all components into a single cluster, indicating either insufficient diversity in the decomposition or inappropriate clustering parameters.
- Decomposition Agent produces overly broad or compound components that do not reflect atomic concepts, leading to ambiguous clusters.

**First Experiments**:
1. **Baseline Comparison**: Run the full pipeline on a handful of neurons from Llama-3.1-8B and compare the final Score with and without the Refinement Agent to verify the reported 0.05–0.10 improvement.
2. **Clustering Sensitivity**: Vary the minimum cluster size in HDBSCAN (e.g., 2 vs. 5) and measure the resulting Number of semantic concepts and Score stability to understand robustness.
3. **Intermediate Audit**: For a sample neuron, manually inspect the outputs of each agent (hypotheses, decomposed components, clusters) to ensure they are coherent and semantically meaningful, catching any propagation of errors.

## Open Questions the Paper Calls Out
### Open Question 1
- Question: How can NeuronScope be effectively extended to interpret neurons in task-specific benchmarks or multimodal models beyond general text corpora?
- Basis in paper: [explicit] "extending NeuronScope to more task-specific benchmarks or other modalities remains an open direction for future work."
- Why unresolved: The study evaluates only on general-purpose LLMs using LMSYS-Chat-1M and Fineweb datasets; no experiments on specialized tasks (e.g., code generation, math reasoning) or multimodal architectures (e.g., vision-language models).
- What evidence would resolve it: Apply NeuronScope to models fine-tuned on specific domains (e.g., CodeLlama for programming) or multimodal models (e.g., GPT-4V), using relevant datasets and metrics to assess explanation faithfulness and polysemanticity detection.

### Open Question 2
- Question: What is the quantitative computational overhead of NeuronScope's multi-agent iterative refinement, and what optimizations can maintain performance while improving scalability?
- Basis in paper: [explicit] "the iterative, multi-agent refinement process introduces additional computational overhead compared to single-pass interpretation methods, which may limit scalability to very large models or exhaustive neuron-level analysis."
- Why unresolved: The paper mentions overhead qualitatively but provides no empirical measurements of runtime, memory usage, or cost across model scales; scalability to larger models or full neuron coverage is untested.
- What evidence would resolve it: Benchmark NeuronScope's resource consumption (e.g., GPU time, API calls) on varying model sizes (e.g., 70B+ parameters) and neuron counts; test efficiency gains via agent model distillation, parallelization, or adaptive iteration limits.

### Open Question 3
- Question: How sensitive is NeuronScope's clustering-based decomposition to the diversity of activation samples and the choice of clustering parameters, and can this affect polysemanticity detection?
- Basis in paper: [explicit] "NeuronScope relies on activation-based clustering to identify semantic modes, and its performance may be sensitive to the quality and diversity of the activation samples used."
- Why unresolved: The framework uses fixed corpora (LMSYS-Chat-1M, Fineweb) and HDBSCAN with a minimum cluster size of 2; no ablations on sample source diversity, sample size, or alternative clustering algorithms (e.g., k-means, spectral clustering) are reported.
- What evidence would resolve it: Perform sensitivity analyses by varying activation corpus diversity (e.g., domain-specific vs. mixed), sample sizes, embedding models, and clustering hyperparameters; measure stability in Number of semantic concepts and Score consistency across runs.

## Limitations
- **Methodological opacity**: The multi-agent workflow (hypothesis generation, decomposition, clustering, optimization) lacks low-level implementation details (exact LLM prompts, clustering thresholds, objective function), hindering exact replication.
- **Evaluation scope**: Experiments are limited to three relatively small models (Llama-3.1-8B, Gemma-2-2B, Qwen3-4B); no evidence of effectiveness on larger models or older architectures like GPT-2.
- **Downstream impact unknown**: While refinement improves activation prediction Score, the paper does not demonstrate that these explanations lead to better model editing, interpretability, or downstream task performance.

## Confidence
- **Framework design**: Low – described conceptually without pseudocode or open-sourced implementation.
- **Cross-model improvement**: Medium – consistent Score gains across three models are reported, but without statistical significance testing or variance across random seeds.
- **Convergence behavior**: High – clear iteration plots show stabilization within ~5 steps.
