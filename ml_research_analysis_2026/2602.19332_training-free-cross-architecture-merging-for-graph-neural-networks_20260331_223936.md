# Training-Free Cross-Architecture Merging for Graph Neural Networks
## Quick Facts
- arXiv ID: 2602.19332
- Source URL: https://arxiv.org/abs/2602.19332
- Reference count: 40
- Primary result: H-GRAMA merges heterogeneous GNNs with high specialist retention (min(Ret)≥0.80 in most same-depth cases) and 1.2×–1.9× speedup over ensembles; all baselines fail or score <0.25 retention.

## Executive Summary
The paper introduces H-GRAMA, a training-free method for merging two pretrained Graph Neural Networks (GNNs) with different architectures (e.g., GCN and GAT) into a single model. Unlike prior merging approaches that rely on architectural similarity, H-GRAMA lifts the merging problem into a shared operator space using a Universal Message Passing Mixture (UMPM). It aligns layers across depths via CKA-based monotone matching, transports parameters using semi-orthogonal Procrustes maps, fuses operators via closed-form gate regression and confidence-weighted mixing, and stabilizes outputs with label-free message-statistics calibration (LFNorm). Experiments show H-GRAMA significantly outperforms baselines on standard benchmarks, achieving high retention and substantial inference speedups.

## Method Summary
H-GRAMA consists of five phases:
1. **UMPM Canonicalization**: Each parent layer is expressed as a weighted sum over a fixed set of basis message-passing operators (self, GCN, sum, mean, attention). This canonical form allows heterogeneous architectures to be compared.
2. **Layer Alignment**: Pre-activations from both parents are compared using linear CKA to produce a similarity matrix. Dynamic programming with anchor layers (input/output) and a gap penalty finds a monotone correspondence between layers of differing depths.
3. **Parameter Transport**: For each matched layer pair, a semi-orthogonal rectangular Procrustes map is computed from the CKA-aligned activations. This map transports parameters from one parent into the other’s coordinate system, handling width mismatches.
4. **Operator Fusion**: A shared design state (e.g., average of transported activations) is constructed. UMPM gate coefficients are regressed in closed form. Parameters are mixed convexly with mixing coefficient α selected without labels using a confidence-weighted heuristic.
5. **LFNorm Calibration**: To correct distribution shifts in edge messages, child messages are streamed to compute per-destination first and second moments. Parent statistics are mixed and applied as an affine transform in a memory-efficient folded form.

## Key Results
- High specialist retention: min(Ret_A, Ret_B) ≥ 0.80 in most same-depth heterogeneous settings (e.g., 0.89±0.17 for GCN–GAT on Cora).
- Inference speedups of 1.2×–1.9× over two-parent ensembles.
- All baseline methods fail or yield <0.25 retention in cross-architecture merging; H-GRAMA is the only successful approach.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Lifting merging from parameter space to a shared operator space via a Universal Message Passing Mixture (UMPM) enables cross-architecture fusion.
- **Mechanism:** H-GRAMA expresses each heterogeneous GNN layer as a weighted sum over a fixed basis of message-passing operators (e.g., self, GCN, sum, mean, attention). This canonicalizes different architectures into a common functional language, making their parameters transportable and fusible.
- **Core assumption:** Any standard GNN layer's message-passing operation can be sufficiently approximated by a linear combination of a small, fixed set of basis operators.
- **Evidence anchors:**
  - [abstract] "We formalize Universal Message Passing Mixture (UMPM), a shared operator family that expresses heterogeneous GNN layers in a common functional language."
  - [section 3.1] Detailed UMPM formulation: `U^ℓ = Σ_{b∈B} g^ℓ_b P^ℓ_b(H^{ℓ-1}) + β^ℓ`.
  - [section 5.1] High retention in same-depth heterogeneous pairs (e.g., GCN–GAT ≥0.90 on Actor) validates that operator-space alignment bridges architectural gaps.
- **Break condition:** A parent layer's functional behavior cannot be reconstructed by the UMPM basis (e.g., a novel non-message-passing operation), causing reconstruction error after conversion to exceed a tolerance `ε` (Algorithm 1, line 4).

### Mechanism 2
- **Claim:** CKA-based monotone matching followed by semi-orthogonal Procrustes transport aligns heterogeneous layers' parameters into a shared coordinate system.
- **Mechanism:** Pre-activation representations `U` from both parents are compared via linear CKA to find a monotone, depth-warped correspondence. For each matched layer pair, a rectangular Procrustes map (`R = UV^⊤` from SVD) is computed to transport one parent's parameters into the other's coordinate space, respecting width mismatches via semi-orthogonality.
- **Core assumption:** Similar pre-activation geometries (as measured by CKA) indicate that the corresponding layers are performing analogous transformations and can be aligned by a simple linear map. Permutation and scaling symmetries in neural networks allow for such linear transport without losing functional equivalence.
- **Evidence anchors:**
  - [section 3.2] "We use linear Centered Kernel Alignment (CKA) to identify transport-safe correspondences... and then compute orthogonal (or semi-orthogonal) rectangular Procrustes maps."
  - [section 3.3] Explicit transport equations for linear (`fW = R_in^⊤ W R_out`) and attention layers.
  - [table 1] Width asymmetry (64-128, 128-64) has limited impact on retention, suggesting rectangular Procrustes handles dimension mismatches effectively.
- **Break condition:** CKA similarity matrix `S` has poor structure (e.g., no clear monotonic path), or the Procrustes solution yields a map with high reconstruction error `∥U_A R - U_B∥_F`, indicating the matched layers are not linearly related.

### Mechanism 3
- **Claim:** Label-free confidence-weighted coefficient selection and LFNorm message-statistics calibration prevent distribution shift in the merged child's edge messages.
- **Mechanism:** Layer-wise mixing coefficients `α^ℓ` are chosen based on node-wise prediction confidence (top-1 vs. top-2 margin) to weight transported pre-activation discrepancies, avoiding label use. Then, LFNorm applies a destination-conditioned affine transform to edge messages, mixing parent moments (`μ, σ²`) to match target statistics, implemented via a folded, memory-efficient streaming form.
- **Core assumption:** (1) A parent's prediction confidence on unlabeled nodes correlates with the reliability of its layer's representations for the merge. (2) Post-fusion performance degradation is primarily caused by a shift in the distribution of aggregated edge messages, which can be corrected by matching low-order moments.
- **Evidence anchors:**
  - [section 3.4] "Confidence-weighted mixing... α^ℓ is set proportional to the aggregated scores."
  - [section 3.5] Full LFNorm pipeline: extracting edge messages, computing destination-conditioned moments, mixing parents, and applying the affine transform (equation 6). Folded form in equation 8.
  - [figure 6] PCA visualization shows centroid alignment improves after LFNorm. [figure 5] Label-free `α_auto` tracks true minimum of loss landscape.
  - [section 6] Ablation shows each phase, especially calibration, contributes to monotonic retention gain.
- **Break condition:** (1) Confidence scores are uncorrelated with layer reliability (e.g., both parents are equally confident/wrong). (2) Message distribution shift is not correctable by first- and second-order moment matching (e.g., higher-order statistics or topology-induced non-linearities dominate).

## Foundational Learning
- **Concept: Message Passing as an Operator**
  - **Why needed here:** H-GRAMA's core innovation is operator-space merging. Understanding that a GNN layer is a function `P(H^{ℓ-1})` that aggregates neighbor information, not just a weight matrix, is foundational. The UMPM basis operators (`self`, `gcn`, `sum`, `mean`, `att`) are instantiations of this.
  - **Quick check question:** Why can't we directly average weight matrices `W_A` and `W_B` from a GCN layer and a GAT layer? What fundamental property of the operators makes this invalid?

- **Concept: Representation Similarity (CKA) for Layer Alignment**
  - **Why needed here:** CKA is the tool used to find which layer in Parent A corresponds to which layer in Parent B when depths differ. It measures linear similarity between activation matrices `U_i^A` and `U_j^B` across all nodes, providing a similarity matrix `S` for dynamic programming alignment.
  - **Quick check question:** If two GNN layers produce activations `U_A` and `U_B` with the same dimensions, what does a high CKA score between them suggest about the relationship between the two layers' functions?

- **Concept: Procrustes Analysis for Neuron Transport**
  - **Why needed here:** After finding layer correspondences, parameters must be moved into a shared coordinate system. The (semi-)orthogonal Procrustes map `R` solves `min ||U_A R - U_B||_F` to find the best linear transform aligning the *representations*, which is then used to transform the *parameters* (`W, b`). This handles permutation symmetries and width mismatches.
  - **Quick check question:** In the rectangular Procrustes problem, what does the semi-orthogonality constraint (`R^⊤R = I` or `RR^⊤ = I`) enforce about the transformation, and why is it necessary for transport?

## Architecture Onboarding
- **Component map:** Two pretrained specialist GNNs → UMPM Canonicalization → CKA-based Layer Alignment → Procrustes Transport → Operator Fusion → LFNorm Calibration → Merged child model.
- **Critical path:** Phases 1 (UMPM) → 2 (Alignment) → 3 (Transport) → 4 (Fusion). Phase 5 (LFNorm) is critical for robust performance but technically optional; ablations show it provides a substantial lift. Skipping confidence-weighted α (using fixed 0.5) degrades performance.
- **Design tradeoffs:**
  - UMPM basis size vs. expressivity: A larger basis can represent more architectures but complicates gate regression and risks overfitting. The paper uses a compact `{self, gcn, sum, mean, att}` basis.
  - CKA vs. other alignment metrics: Linear CKA is fast and effective but may fail for highly non-linear transformations. Non-linear kernel CKA would be more expensive and could overfit.
  - Label-free α vs. oracle α: The confidence-risk heuristic is cheap and near-optimal but is a heuristic; oracle α would require labels.
  - Folded LFNorm vs. per-edge materialization: Folded form reduces memory from `O(|E|d)` to `O(|V|d)` but assumes per-destination affine transforms, which holds for message-passing GNNs but may not for edge-centric models.
- **Failure signatures:**
  1. **Low min-retention (<0.70) in same-depth configs:** Likely indicates poor UMPM reconstruction, bad CKA alignment, or transport error. Check reconstruction error, CKA matrix structure, and Procrustes reconstruction loss.
  2. **Degradation with depth mismatch (2-3 vs 2-2):** Expected; may be due to misaligned monotone path (adjust gap penalty γ) or difficulty aligning GIN's MLP-heavy updates with linear Procrustes.
  3. **High variance across seeds:** Suggests instability in CKA-Procrustes due to stochastic training or graph noise; increase CKA sample size or average over multiple alignment runs.
- **First 3 experiments:**
  1. **UMPM Reconstruction Sanity Check:** Convert each parent layer to UMPM and compute max absolute error in pre-activations; should be ≤ 1e-4.
  2. **Alignment Quality Inspection:** Visualize CKA matrix S as heatmap; optimal monotone path should be a bright diagonal. Compute average CKA along matched pairs; <0.8 suggests representational divergence.
  3. **Fusion Coefficient (α) Sensitivity Sweep:** Manually vary α for a fused layer and evaluate child accuracy; auto-selected α_auto should lie within 0.05 of the optimal α.

## Limitations
- Missing hyperparameter values (e.g., gap penalty γ, ridge penalty λ, LFNorm ε) require manual tuning or grid search.
- Handling of depth/width mismatches (layer padding, α adjustment) is underspecified, leading to implementation variability.
- Linear Procrustes transport may fail for non-linear layers (e.g., GIN MLPs), limiting applicability.
- Confidence-weighted α assumes prediction margins correlate with layer reliability; this may fail under systematic bias.
- LFNorm corrects only first- and second-order message statistics; higher-order shifts remain unaddressed.

- CKA monotone matching & Procrustes: High
