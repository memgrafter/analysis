# A Unified Multimodal Framework for Dataset Construction and Model-Based Diagnosis of Ameloblastoma

## Quick Facts
- **arXiv ID**: 2602.05515
- **Source URL**: https://arxiv.org/abs/2602.05515
- **Reference count**: 37
- **Primary result**: Developed a multimodal dataset (152 cases, 1,152 annotated images, structured text) and a multi-task DenseNet121 model achieving 65.9% variant classification accuracy and 90.3% abnormal tissue detection F1-score after preprocessing.

## Executive Summary
Ameloblastoma, a rare jaw tumor, lacks structured multimodal datasets for AI research. This work addresses that gap by curating a dataset of 152 patient cases including radiological, histopathological, and clinical images (total 1,152) and extracting structured text from case reports via a Gemini API-based NLP pipeline. Using this resource, a multi-task DenseNet121 model was trained, showing substantial improvements after data preprocessing: variant classification accuracy increased from 46.2% to 65.9% and abnormal tissue detection F1-score surged from 43.0% to 90.3%. Additionally, a case-based retrieval system using Sentence-BERT and FAISS was implemented to support clinical decision-making.

## Method Summary
The research comprises two integrated phases: dataset construction and model development. In the dataset phase, case reports were processed with a Gemini NLP pipeline to extract clinical variables, while images were manually annotated for tumor variants and tissue abnormalities and underwent standardization (normalization, augmentation). In the modeling phase, a multi-task DenseNet121 was trained to jointly predict variant type and detect abnormal tissue from the multimodal inputs. A complementary retrieval system encodes both text and image features with Sentence-BERT and indexes them via FAISS to find similar historical cases for new queries.

## Key Results
- Novel multimodal dataset: 152 cases, 1,152 annotated images, plus structured clinical text.
- Performance gains: variant classification accuracy improved ~20% and abnormal tissue detection F1-score ~47% after preprocessing.
- Case-based retrieval system enabling similarity search for clinical support.

## Why This Works (Mechanism)
The framework leverages complementary information from multiple data modalities (radiology, histopathology, clinical text) to capture a holistic view of ameloblastoma. Preprocessing reduces heterogeneity in image quality, which is critical for the DenseNet121 backbone. Multi-task learning promotes shared representation learning between variant classification and abnormality detection, improving generalization despite limited data. The retrieval system adds interpretability by surfacing analogous past cases, aligning with clinical reasoning patterns.

## Architecture Onboarding
**Component Map**  
Case Reports -> Gemini NLP -> Structured Text  
Medical Images -> Preprocessing & Annotation -> Labeled Images  
Structured Text + Labeled Images -> Multi-task DenseNet121 Training -> Trained Model  
New Case -> Preprocess -> DenseNet121 Prediction + SBERT/FAISS Retrieval -> Output

**Critical Path**  
1. Collect case reports and images.  
2. Extract structured text via Gemini NLP.  
3. Annotate images for variant and abnormality.  
4. Preprocess images.  
5. Train multi-task DenseNet121.  
6. Build SBERT+FAISS retrieval index.  
7. Deploy inference pipeline.

**Design Tradeoffs**  
- Dataset size vs. model complexity: Limited cases (152) restrict deep models; mitigated by transfer learning and multi-task training.  
- Multimodal fusion: Late fusion (used) is simpler but may miss early cross-modal interactions.  
- Retrieval speed vs. accuracy: FAISS enables fast search but may trade off fine-grained similarity.  
- Automation vs. accuracy: NLP scales but introduces potential extraction errors; manual annotation is precise but labor-intensive.

**Failure Signatures**  
- Low model confidence scores or cross-modal inconsistencies (e.g., image-text disagreement).  
- Retrieved cases that are clinically irrelevant despite high similarity.  
- Performance drop on images from new scanners/staining protocols (domain shift).  
- NLP extraction misses key entities or produces malformed structured data.

**First Experiments**  
1. Single-modality baselines: Train image-only and text-only models to quantify multimodal benefit.  
2. Preprocessing ablation: Evaluate raw vs. preprocessed data to isolate each preprocessing step's impact.  
3. Retrieval relevance study: Manually judge top-k results for a query set to compute precision@k and identify failure patterns.

## Limitations
- Small dataset size (152 cases) hinders generalizability to other populations or institutions.  
- No reported inter-annotator agreement or NLP extraction accuracy audit, risking hidden label/text noise.  
- Performance gains attributed to preprocessing lack ablation and statistical significance testing.
