# Efficient Dilated Sququeeze and Excitation Neural Operator for Differential Equations

## Quick Facts
- arXiv ID: 2601.17407
- Source URL: https://arxiv.org/abs/2601.17407
- Reference count: 23
- Primary result: D-SENO achieves up to ~20× faster training than transformer-based models while matching or surpassing accuracy on four PDE benchmarks.

## Executive Summary
D-SENO is a lightweight fully convolutional neural operator designed to solve partial differential equations efficiently. It replaces global operations (Fourier transforms, self-attention) with dataset-specific dilated convolution blocks and Squeeze-and-Excitation modules, achieving linear computational complexity. Across four PDE benchmarks, D-SENO attains training speeds up to 20 times faster than state-of-the-art transformer-based models (e.g., Transolver) while achieving lower or comparable relative L2 errors.

## Method Summary
D-SENO follows a three-stage fully convolutional architecture: (1) a pointwise lifting layer expands input channels to a high-dimensional latent space; (2) a sequence of Dilated-Squeeze (DS) blocks processes features; each DS block comprises a dilated convolution block (two stacked k×k convolutions with dataset-specific dilation rates) followed by a Squeeze-and-Excitation (SE) module (global average pooling, two 1×1 convolutions with reduction ratio r, GELU/sigmoid) and a residual connection with GELU activation; (3) a pointwise projection layer maps back to the output field. All operations preserve spatial resolution and avoid global mixing, yielding O(N) complexity. Training uses Adam (lr=1e-3, batch=20, weight decay=0.5e-4) for 500 epochs with step decay at epoch 100.

## Key Results
- Training speed: up to ~20× faster than Transolver (e.g., Airfoil: 1.99s vs 28.03s per epoch).
- Accuracy: lower relative L2 errors than Transolver on Airfoil (0.0052 vs 0.0053), Pipe (0.0030 vs 0.0033), Darcy (0.0048 vs 0.0057).
- Limitation: FNO+ outperforms D-SENO on the periodic Navier-Stokes benchmark.

## Why This Works (Mechanism)
### Dilated Convolution Blocks
Dilated convolutions insert gaps between kernel elements, exponentially expanding the receptive field per layer without downsampling or extra parameters. In D-SENO, each block uses dataset-specific, non-uniform dilation rates along x and y axes, allowing anisotropic context aggregation tailored to the PDE geometry (e.g., elongated flows). Stacked with residuals, cumulative receptive field grows linearly with depth and input size, enabling multiscale spatial dependency capture using strictly local operations.

### Squeeze-and-Excitation (SE) Modules
SE blocks adaptively recalibrate channel-wise feature importance using global context. After a dilated convolution block, the SE module performs global average pooling to obtain channel descriptors, which pass through two 1×1 convolutions (with reduction ratio r) and GELU/sigmoid activations to produce scaling weights. These weights multiply the original features, amplifying informative channels and suppressing irrelevant ones. This introduces minimal parameters while enhancing the network’s ability to emphasize dynamically relevant feature scales.

### Fully Convolutional, Local-Only Design
By avoiding global Fourier transforms or self-attention, all operations remain spatially local or channel-wise, preserving resolution and achieving O(N) computational complexity. This design leverages highly optimized GPU convolution kernels, enabling large speedups. The approach assumes that long-range physical dependencies in the tested PDEs (Airfoil, Pipe, Darcy) can be modeled via hierarchically aggregated local contexts rather than all-to-all interactions, which holds true for these datasets but fails for the periodic Navier-Stokes where global spectral coupling matters.

## Foundational Learning
- **Dilated Convolutions**: Needed to expand receptive field exponentially without increasing parameters or losing resolution. *Quick check*: With a 3×3 kernel and dilation rate 2, the effective coverage spans a 5×5 input region (since gaps of 1 pixel between kernel elements).
- **Squeeze-and-Excitation (SE)**: Needed for cheap channel-wise attention via global context. *Quick check*: The reduction ratio r controls bottleneck size; smaller r increases SE parameters and capacity but adds overhead.
- **Neural Operator Learning**: Needed to frame the problem as learning mappings between function spaces (input/output functions) rather than fixed discretizations. *Quick check*: Unlike a U-Net that maps one discretized grid to another, a neural operator aims to discretization-invariant solution operators, often using strategies like Fourier lifting or integration with fixed grids.

## Architecture Onboarding
### Component Map
Input -> Lifting (pointwise conv) -> [DS Block (dilated conv block + SE) x n] -> Projection (pointwise conv) -> Output.

### Critical Path
Data flows sequentially: input tensor a is lifted to high-dimensional features, then processed through n DS blocks. Each DS block applies two dilated convolutions (with dataset-specific dilation rates) followed by SE recalibration; the result is added to the block input via residual connection and activated with GELU. Spatial dimensions remain constant throughout. Finally, a pointwise convolution produces the output field.

### Design Tradeoffs
- **Dilation schedule**: Fixed per dataset (non-uniform) vs. learned; more blocks/larger dilation increase receptive field but also parameters and computation.
- **SE reduction ratio r**: Balances SE parameter count and recalibration capacity; lower r gives more expressive SE at cost of parameters.
- **Local vs. global**: Strict locality ensures speed and robustness but may miss critical global couplings (as seen in Navier-Stokes).

### Failure Signatures
- **Navier-Stokes benchmark**: D-SENO underperforms relative to FNO+, indicating failure to capture periodic global dynamics.
- **Ablation without SE**: Significant error increase across datasets, confirming SE’s importance.
- **Resolution sensitivity**: Extreme resolution changes may require retuning dilation rates; the paper shows some robustness but not invariance.

### First 3 Experiments
1. **SE Ablation**: Train D-SENO without SE modules; expect consistent error increase, especially on Airfoil and Pipe where channel recalibration is critical.
2. **Depth Sweep**: Vary number of DS blocks (e.g., 3–9) to plot error vs. training time/parameters; identify efficiency elbow and validate chosen depth.
3. **Dilation Robustness**: Replace dataset-specific dilation rates with a uniform/exponential schedule; assess accuracy drop to determine how hand-tuned rates contribute to performance.

## Open Questions the Paper Calls Out
1. **Unstructured Meshes**: How to extend D-SENO to handle unstructured grids and complex geometries? Current design relies on Cartesian convolutions.
2. **Automatic Dilation Learning**: Can dilation rates be learned automatically during training to improve robustness and reduce per-dataset tuning?
3. **Long-Range Dependencies**: How to enhance D-SENO to capture global interactions more effectively for multiscale time-dependent PDEs like Navier-Stokes? Proposed integration of efficient attention.
4. **Physics-Informed Priors**: Can incorporating physical constraints (e.g., conservation laws) improve generalization and sample efficiency?
5. **Theoretical Analysis**: What are the approximation, stability, and generalization guarantees of D-SENO for learning PDE operators?

## Limitations
- Exact reproduction is hindered by unspecified parameters (SE reduction ratio, residual details, data normalization).
- D-SENO underperforms on PDEs with strong global spectral coupling (e.g., periodic Navier-Stokes).
- Manual dilation schedule selection may not generalize to all PDE types or extreme resolutions.
- No evaluation on out-of-distribution data or very high-resolution grids.

## Confidence
- Dilated Convolution Blocks: Medium (effective on three datasets but fails on Navier-Stokes; no direct ablation).
- Squeeze-and-Excitation Modules: High (consistent gains in ablations across benchmarks).
- Fully Convolutional, Local-Only Design: High (measured 20× speedup vs. Transolver verified).

## Next Checks
1. **SE Ablation**: Remove SE blocks entirely; expect error increase across all datasets.
2. **Depth Scaling**: Sweep number of DS blocks (3–9) to map error-time trade-off and validate chosen depth.
3. **Dilation Robustness**: Replace dataset-specific dilation schedules with uniform/exponential alternatives; measure accuracy change.
