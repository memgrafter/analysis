# Extending Czech Aspect-Based Sentiment Analysis with Opinion Terms: Dataset and LLM Benchmarks

## Quick Facts
- ArXiv ID: 2602.22730
- Source URL: https://arxiv.org/abs/2602.22730
- Reference count: 0
- Primary result: Manual annotation of 6,984 Czech restaurant reviews with quadruplets yields state-of-the-art monolingual ABSA (mT5: 70.74 F1 ASTE) and demonstrates an LLM-based cross-lingual transfer method that narrows but does not close the performance gap.

## Executive Summary
This paper addresses the absence of Czech datasets for complex aspect-based sentiment analysis (ABSA) involving opinion terms. The core contribution is a manually annotated Czech restaurant dataset (6,984 quadruplets) supporting three tasks: ASTE, ASQP, and ACOS. Extensive experiments evaluate fine-tuned Transformer models (mT5) and various LLMs in monolingual, cross-lingual, and multilingual settings. Fine-tuned mT5 achieves substantial gains over zero/few-shot LLMs (15-25% absolute). An LLM-based translation and label alignment method improves cross-lingual transfer from English to Czech but leaves a 15-20% performance gap, largely due to differences in opinion term annotation. Error analysis highlights opinion term extraction as the primary challenge across all models.

## Method Summary
The authors extended an existing Czech triplet-based dataset (CsRest-M) by annotating opinion terms and adjusting sentiment polarities for conflicts, creating quadruplet annotations that include aspect, category, polarity, and opinion. Modifiers (e.g., "velmi rychlá") were retained in opinion spans, and a NULL token represented implicit terms. For modeling, mT5 was fine-tuned in a sequence-to-sequence setup to generate a token sequence of special tags representing each quadruplet. LLMs were evaluated via zero/few-shot prompting and adapted with QLoRA for efficiency. Cross-lingual transfer leveraged English SemEval-2016 data; GPT-4o mini translated English sentences and simultaneously adjusted Czech labels to match the annotation scheme, with filtering to ensure consistency. Results were aggregated across monolingual (Czech-only), cross-lingual (English→Czech), and multilingual (combined) splits.

## Key Results
- Fine-tuned mT5 achieves state-of-the-art monolingual results: ASTE 70.74 F1, ASQP 64.09 F1, ACOS 58.06 F1.
- Cross-lingual transfer from English to Czech without alignment lags 15-20% behind monolingual mT5; adding LLM-translated Czech data with label alignment yields consistent improvements but does not close the gap entirely.
- Across all models, opinion term extraction is the most error-prone component, especially for ACOS which requires handling implicit opinions; mT5 fine-tuning eliminates formatting errors seen in zero-shot LLMs.

## Why This Works (Mechanism)
### Mechanism 1: Dataset Creation Enables Complex ABSA
The manually annotated Czech quadruplet dataset allows models to learn the joint extraction of aspects, categories, sentiment polarities, and opinion terms, which is essential for tasks like ASTE, ASQP, and ACOS. Annotators extended existing triplet annotations by adding opinion term spans and adjusting polarities for conflicting opinions, introducing special handling for implicit terms (NULL) and including modifiers to capture sentiment intensity. This annotation scheme mirrors English ACOS/ASQP datasets but with the added nuance of modifiers, which may complicate cross-lingual transfer. The inter-annotator agreement of 85% supports the reliability of the dataset, though subjectivity in implicit labels remains a concern.

### Mechanism 2: LLM-Based Translation with Label Alignment
The proposed cross-lingual transfer method uses GPT-4o mini to translate English review sentences and simultaneously adjust quadruplet labels to the Czech annotation scheme. The prompt instructs the LLM to preserve category and polarity while extracting aspect and opinion terms from the translated Czech text. A filtering step discards outputs with mismatched tuple counts or categories, yielding a clean augmented Czech dataset. This approach maintains structural consistency between source text and target labels, leading to consistent F1 improvements over using English-only training data. However, about 10% of translations suffer from label misalignment, and the inclusion of modifiers in Czech (absent in English) limits full parity.

### Mechanism 3: Fine-Tuned mT5 Outperforms LLMs
Fine-tuning mT5 end-to-end on the Czech dataset yields superior performance compared to zero-shot and few-shot LLMs (even after QLoRA adaptation). The model learns the task-specific output format (special token sequence) and Czech linguistic patterns directly from the moderately sized training set (~3k sentences). The sequence-to-seq architecture naturally handles variable-length quadruplet generation without formatting errors. In contrast, LLMs, despite their scale, require careful prompting and suffer from hallucinations and format inconsistencies, especially in zero-shot settings. The performance gap (15-25% absolute) underscores the value of in-domain fine-tuning over prompting for structured extraction tasks in low-resource languages.

## Architecture Onboarding
**Component map:**  
Input text (Czech review) → mT5 encoder → mT5 decoder → special token sequence (e.g., `<aspect>...<opinion>...<category>...<polarity>...<ssep>`) → tuple extraction (split by `<ssep>`) → (aspect, category, opinion, polarity) quadruplets.

**Critical path:** Tokenization of Czech sentence → encoder contextualization → autoregressive decoder generation of label tokens (excluding prompt) → parsing generated sequence into quadruplets → micro F1 evaluation (exact match on all four elements).

**Design tradeoffs:**  
- mT5 (seq2seq) vs. LLM (decoder-only): mT5 fine-tuning gives higher accuracy and no format errors; LLMs offer multilingual priors but need careful prompting and may hallucinate.  
- Modifier inclusion: Annotating modifiers improves expressivity but creates mismatch with English datasets that omit them, harming cross-lingual transfer.  
- Task granularity: ACOS (with implicit opinions) is hardest; ASTE (simpler) yields highest scores. Models must handle variable numbers of quadruplets per sentence.

**Failure signatures:**  
- Opinion term extraction errors: missing spans, merging multiple opinions, or predicting non-existent terms (most frequent).  
- Implicit term handling: failure to predict NULL for implicit opinions/aspects, especially in ACOS.  
- Category confusion: mixing fine-grained categories or failing on rare ones.  
- Formatting errors: missing `<ssep>` or incorrect token order (rare in fine-tuned mT5, more common in zero-shot LLMs).

**First 3 experiments:**  
1. Monolingual fine-tuning: Fine-tune mT5 on Czech training set for ASTE/ASQP/ACOS; expect ~70 F1 (ASTE), ~64 (ASQP), ~58 (ACOS).  
2. Cross-lingual transfer: Fine-tune on English SemEval-2016 only; expect 15-20% lower F1 than monolingual.  
3. Translation-alignment augmentation: Fine-tune on English + GPT-4o mini translated Czech with aligned labels; expect improvement over English-only but still below monolingual.

## Open Questions the Paper Calls Out
1. How can Czech ABSA models more accurately extract opinion terms that include modifiers (e.g., "velmi rychlá")? The current models struggle with modifier-inclusive opinion terms, and the annotation choice to include them is not yet optimized for model performance.
2. Why does cross-lingual transfer for ABSA (English→Czech) remain 15–20% below monolingual performance, and how can this gap be closed? The modifier mismatch between English (excludes) and Czech (includes) is a suspected factor, but no systematic harmonization has been tested.
3. How can the annotation of implicit opinion terms be standardized to reduce subjectivity and improve model performance on ACOS? Low inter-annotator agreement on implicit labels leads to noisy training data and model errors; clearer guidelines or re-annotation are needed.

## Limitations
- The anonymized GitHub repository is inaccessible, preventing verification of data splits, preprocessing, and evaluation code.
- Incomplete documentation of prompt templates and translation alignment details (e.g., filtering thresholds) hinders exact replication.
- The inclusion of modifiers in the Czech annotation scheme, while linguistically motivated, creates a structural mismatch with existing English datasets that likely caps cross-lingual transfer performance.

## Confidence
- Dataset contribution: High – well-documented with IAA 85%.
- Cross-lingual method efficacy: Medium – shows consistent improvements but limited by 10% label error rate and modifier mismatch.
- mT5 monolingual superiority: High – robustly demonstrated across tasks and models, backed by error analysis.
