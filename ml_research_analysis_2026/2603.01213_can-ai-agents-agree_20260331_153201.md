# Can AI Agents Agree?

## Quick Facts
- **arXiv ID:** 2603.01213  
- **Source URL:** https://arxiv.org/abs/2603.01213  
- **Reference Count:** 24  
- **Primary Result:** LLM-agent groups fail to achieve reliable Byzantine consensus, with liveness loss dominating failures and a single Byzantine agent collapsing valid consensus to near zero even in small groups.

## Executive Summary
This paper examines whether large language model (LLM) agents can achieve Byzantine consensus on scalar values in a no-stake setting. Using a synchronous all-to-all simulation with Qwen3-8B/14B models across group sizes (N=4,8,16), the study finds that valid consensus is fragile even without adversaries (59.1%–75.4% success). Performance degrades with group size and is extremely sensitive to prompt wording—especially when adversaries are mentioned. Crucially, introducing just one Byzantine agent reduces valid consensus to nearly 0%, with failures primarily due to timeouts and stalled convergence rather than corrupted outcomes. The results indicate that current LLM-agent collectives lack dependable agreement capabilities, even under benign conditions.

## Method Summary
The experiment uses a synchronous all-to-all simulation (A2A-Sim) where N agents repeatedly propose integer values in [0,50] and vote to terminate. Each round, agents receive a history summary, query the LLM (via fixed prompt templates) for a proposal and public reasoning, then broadcast. After proposals are collected, agents vote using a separate prompt; termination requires ≥66% of *all* agents (including Byzantine) to vote "stop." Valid consensus is achieved only if all honest agents eventually agree on one of their initial proposals. The study varies N (4,8,16), Byzantine fraction (f ≤ 1/3), model size (Qwen3-8B/14B), and prompt variants (with/without mention of possible adversaries). Outcomes are measured after 25–100 runs: valid consensus, invalid consensus, and no consensus (timeout at Tmax=50 rounds).

## Key Results
- **Benign consensus is fragile:** For Qwen3-14B with no adversaries, valid consensus ranges from 59.1% to 75.4% depending on prompt phrasing and drops to 33.3% at N=16.
- **Byzantine fragility is extreme:** A single Byzantine agent (f=1/9) in an 8-agent group reduces valid consensus to near 0%, with almost all runs ending in timeout.
- **Liveness dominates failure:** Invalid consensus remains rare; failures are overwhelmingly due to stalled convergence or reaching the round limit, not agreement on a corrupted value.

## Why This Works (Mechanism)
### Mechanism 1
**Claim:** LLM-agent groups fail primarily due to *liveness loss* (timeouts, stalled convergence) rather than *safety loss* (agreement on an invalid value).  
**Mechanism:** The termination condition requires a supermajority (≥66%) of *all* agents to vote "stop." Honest agents, conditioned by prompts to believe they must detect universal agreement among all honest peers, adopt overly cautious voting. Without stakes, they withhold "stop" votes until absolute certainty—a bar rarely met in stochastic interactions—leading to round exhaustion.  
**Evidence anchors:** Abstract states failures "dominated by loss of liveness"; Section 4.2 notes Byzantine agents "primarily harm liveness"; prompt templates (Figures 10,13,14) explicitly tie "stop" to perception that *all honest agents* propose the same value.

### Mechanism 2
**Claim:** Consensus performance is highly sensitive to *psycholinguistic framing* in the prompt and degrades predictably with increasing group size.  
**Mechanism:** Prompt wording shapes the agent's threat model. When informed that Byzantine agents "may exist," honest agents incorporate adversarial suspicion, becoming more conservative and reinterpreting convergent proposals as potential attacks. Larger groups increase cognitive load for tracking peers within context limits, causing semantic drift and inconsistent interpretation of the consensus condition.  
**Evidence anchors:** Section 4.1 shows removing adversary mentions improves Qwen3-14B performance from 59.1% to 75.4% and halves convergence time; valid consensus drops from 46.6% at N=4 to 33.3% at N=16.

### Mechanism 3
**Claim:** The system exhibits *extreme fragility to Byzantine presence*; one adversarial agent collapses valid consensus to near-zero.  
**Mechanism:** A single Byzantine agent sending a persistent outlier value splits honest agents' convergence attempts. Honest agents' private strategy (e.g., proposing the mode) may divide attention between the modal honest value and the outlier, preventing any value from achieving a persistent supermajority and causing perpetual voting deadlock.  
**Evidence anchors:** Section 4.2 reports one Byzantine near-zero valid consensus; Figure 3 shows collapse from ~67% to 0% for N=8; Section 4.2 emphasizes liveness failure over value corruption.

## Foundational Learning
- **Concept:** Byzantine Fault Tolerance (BFT)  
  **Why needed:** The experiment measures performance against classical BFT thresholds (f < 1/3) and reveals LLM agents fail to achieve dependable agreement even in simplified settings.  
  **Quick check:** What is the difference between *validity* and *liveness* in classical Byzantine consensus, and which fails here?
  
- **Concept:** No-Stake Agreement  
  **Why needed:** The design decouples the consensus goal from external rewards, isolating pure coordination capability and avoiding confounding incentives.  
  **Quick check:** How does removing stakes for the agreed value change the problem compared to a cooperative game with direct rewards?
  
- **Concept:** LLM Agent Coordination via Prompt-Based Protocol  
  **Why needed:** Agents follow a static prompt template; success hinges on the LLM's ability to execute a multi-step, socially-aware protocol across rounds without training.  
  **Quick check:** What are the key components of the round-based prompt (Figures 9, 10) an agent must interpret correctly?

## Architecture Onboarding
- **Component map:**  
  Simulator -> Agent State Module -> LLM Inference Engine -> History Summarizer  
  Simulator -> Byzantine Policy Module -> (overrides LLM output)  
  All agents broadcast to Simulator, which aggregates votes and checks termination.

- **Critical path:** (1) Simulator signals new round → (2) Agent retrieves `history_summary` → (3) Agent constructs round prompt (e.g., Figure 9) → (4) LLM generates `(value, reasoning)` → (5) Byzantine module may corrupt output → (6) Agent broadcasts → (7) Simulator collects all messages → (8) Agent forms `current_round_summary` → (9) Agent constructs vote prompt (Figure 10/14) → (10) LLM generates `decision` → (11) Simulator aggregates votes → (12) If ≥2/3 stop, check validity; else loop.

- **Design tradeoffs:**  
  - **Termination threshold (66%) vs. deadlock risk:** Fixed threshold from classic BFT for small f, but may be too high for stochastic LLMs without incentives.  
  - **History compression:** Summarization trades detail for context length; poor summaries cause "forgetting" of convergence, worsening liveness.  
  - **Prompt rigidity:** Fixed prompts control variables but limit adaptability to dynamic threat landscapes.

- **Failure signatures:**  
  1. **Timeout signature:** Majority consistently vote "continue" beyond round 30.  
  2. **Value fragmentation signature:** Proposals split between two+ distinct values without one gaining supermajority.  
  3. **Invalid consensus signature:** Termination with >1 distinct honest value (rare).

- **First 3 experiments:**  
  1. **Replicate benign baseline:** B=0, N=8, Qwen3-14B, no-adversary prompt. Expect ~75% valid consensus, mean rounds ~10.  
  2. **Introduce one Byzantine:** B=1, N=8, Qwen3-14B, may-exist prompt. Expect valid consensus → 0%, timeout → ~100%.  
  3. **Prompt sensitivity test:** B=0, N=8, Qwen3-14B. Swap prompt variants only; expect may-exist prompt to lower consensus and increase rounds.

## Open Questions the Paper Calls Out
- **OQ1:** How do diverse Byzantine strategies (beyond the single adaptive one tested) affect consensus success rates and failure modes?
- **OQ2:** What are the scalability limits of LLM-agent consensus in terms of group size and network topology (e.g., beyond all-to-all, larger N)?
- **OQ3:** Do consensus capabilities generalize across different LLM architectures and training methods beyond the Qwen3 family?
- **OQ4:** How does relaxing the restricted Byzantine model (e.g., allowing equivocation, message suppression) impact consensus robustness?

## Limitations
- **Prompt/implementation gaps:** Exact `history_summary` template, justification truncation heuristics, and LLM decoding parameters are unreported, risking reproduction variance.
- **Reasoning opacity:** Agents' internal logic for voting and proposal generation is inferred from prompt text but not formally verified; emergent heuristics may differ.
- **Generalizability:** Findings are constrained to Qwen3 models in a narrow scalar consensus game; transfer to other architectures, tasks, or open-ended domains is unknown.

## Confidence
- **Mechanism 1 (Liveness-dominant failure):** High. Strongly supported by outcome statistics and failure mode categorization; aligns with BFT expectations.
- **Mechanism 2 (Prompt/group-size sensitivity):** High. Direct experimental comparisons show large, reproducible swings in consensus rates and convergence time.
- **Mechanism 3 (Extreme Byzantine fragility):** Medium. Data shows collapse with one Byzantine, but causal link to honest aggregation strategy is indirect; may vary with adversarial tactics or model scaling.

## Next Checks
1. **Baseline replication:** Run the paper's "no-adversary" configuration (N=8, Qwen3-14B) with ≥25 seeds. Expect ~75% valid consensus and mean rounds ~10.
2. **Prompt isolation test:** With N=8, B=0 fixed, swap only the prompt variant (Figures 11 vs. 12). Quantify delta in valid consensus and convergence time.
3. **Byzantine strategy probe:** With N=8, B=1, test two adversarial policies: (a) constant outlier value vs. (b) random values each round. Measure if valid consensus remains near-zero in both.
