# Online Learning of Kalman Filtering: From Output to State Estimation

## Quick Facts
- **arXiv ID:** 2603.27159  
- **Source URL:** https://arxiv.org/abs/2603.27159  
- **Reference count:** 40  
- **Primary result:** Proposes online gradient descent algorithms with adaptive querying that achieve O(log⁴ T) regret for output estimation and O(τ log⁴ T log(T/τ) + √T log² T) for state estimation in partially observed linear systems.

## Executive Summary
The paper addresses online learning of Kalman filters for linear dynamical systems with unknown parameters. For predicting measurements (output estimation), the loss is conditionally strongly convex, enabling an online gradient descent (OGD) algorithm with a truncation trick that yields O(log⁴ T) regret. For predicting the internal state, the authors first prove that any algorithm relying solely on output observations suffers linear Ω(T) regret—a fundamental limitation. To circumvent this, they introduce a random query mechanism that, at τ‑spaced intervals, obtains a noisy direct state measurement. Combining this with OGD on a truncated finite‑impulse response filter, they achieve sublinear regret O(τ log⁴ T log(T/τ) + √T log² T), revealing a trade‑off between query frequency and estimation accuracy. The approach requires only coarse bounds on system parameters and noise covariances. Numerical experiments on a Boeing 747 longitudinal control model confirm the √T scaling for state estimation.

## Method Summary
The system is x_{t+1}=A x_t + w_t, y_t=C x_t + v_t with unknown A, C and Gaussian noise covariances W, V. Regret is defined relative to the optimal Kalman filter that knows the true parameters. For output estimation, OGD is applied to a FIR filter \hat{y}_t = Σ_{s=1}^{h} N_{t,s} y_{t-s}. The truncation length h grows like O(log T); the step size η_t = 2/(α₀ (log T)² t) (α₀ = min eigenvalue of W or V) and projection onto a ball of radius R_N = √p ψ κ_F²/(1−γ_F) (with ψ = ∥C∥, κ_F = √(σ̄/α₀), γ_F = 1−α₀/(2σ̄), σ̄ = ∥Σ∥, Σ solves the Riccati equation) keep iterates well‑behaved. Conditional strong convexity of the loss yields O(log⁴ T) regret. For state estimation, a lower bound shows any output‑only algorithm has linear regret. The random query mechanism draws b ∼ Uniform{0,…,τ−1} each interval of length τ and at time t = iτ + b returns a noisy state measurement \tilde{x}_t = x_t + \tilde{v}_t. The same OGD scheme is then used on a truncated FIR state estimator \hat{x}_t = Σ_{s=1}^{h} M_{t,s} y_{t-s}, but updates occur only at query times. The resulting regret combines an online term τ log⁴ T log(T/τ) and a statistical error term √T log² T. The algorithms need only rough bounds on α₀, ψ, σ̄ to set step sizes and projection radii.

## Key Results
- **Output estimation:** O(log⁴ T) regret via OGD on truncated linear filters.
- **State estimation (no queries):** Any algorithm incurs linear Ω(T) regret.
- **State estimation (random queries every τ steps):** Regret O(τ log⁴ T log(T/τ) + √T log² T), illustrating a query‑accuracy trade‑off.

## Why This Works (Mechanism)
The output estimator’s success relies on the conditional strong convexity of the squared error loss under the Gauss‑Markov model; this property holds uniformly with high probability and allows OGD to make steady progress. The truncation length h = ⌊log T / log(1/γ_F)⌋ captures the effective memory of the optimal linear predictor; the tail beyond h decays geometrically like γ_F^t, making the approximation error negligible. The step size schedule 2/(α₀ (log T)² t) balances the strong convexity constant and stochastic gradient variance, while projection onto a ball of radius R_N = √p ψ κ_F²/(1−γ_F) prevents divergence and encloses the optimal filter parameters. For state estimation, the impossibility result follows because the state process is hidden; without explicit state observations, any estimator based only on outputs cannot recover the initial state, leading to persistent error. The random query scheme injects just enough information to learn the steady‑state Kalman gain online: each query provides a direct (noisy) state snapshot, enabling an unbiased gradient estimate for the filter parameters. The lower update frequency (once per τ steps) increases the online component by a factor τ but still yields sublinear total regret when τ = o(T). The √T term originates from the inherent statistical uncertainty in estimating the steady‑state Kalman parameters from a limited number of samples—an unavoidable consequence of stochastic approximation.

## Foundational Learning
- **Conditional Strong Convexity**  
  *Why needed:* Guarantees a uniform lower bound on the curvature of the expected loss, enabling OGD to achieve logarithmic regret.  
  *Quick check:* From simulated y_{t−s}, compute the sample covariance Z_t Z_t^T and verify its smallest eigenvalue is bounded below by α₀ with high probability.

- **Truncation of Infinite‑Impulse Response**  
  *Why needed:* The optimal linear estimator is infinite‑dimensional; truncation yields a finite‑parameter problem suitable for OGD.  
  *Quick check:* Obtain the steady‑state Kalman filter’s FIR coefficients; sum the squared tail beyond h and confirm it decays like γ_F^h.

- **Feasible Set Projection**  
  *Why needed:* Keeps iterates within a region containing the optimal filter and respects the analysis’s norm bounds.  
  *Quick check:* Compute the optimal FIR representation of the steady‑state Kalman filter; its Frobenius norm should be ≤ R_N (or R_M).

- **Step Size Scheduling**  
  *Why needed:* The factor α₀ in the denominator scales with strong convexity; (log T)² t controls variance accumulation.  
  *Quick check:* Track Σ_{t=1}^{T} η_t ∥∇f_t∥²; it should remain O(log⁴ T).

- **Random Query Mechanism**  
  *Why needed:* Provides fresh state information to overcome the lower bound for state estimation.  
  *Quick check:* Count Algorithm 2 updates; it should equal the number of queries (≈⌊T/τ⌋). Query times should be uniformly distributed modulo τ.

- **Kalman Filter Benchmark**  
  *Why needed:* Regret is defined against the optimal predictor; accurate benchmark is essential.  
  *Quick check:* Implement the Kalman filter recursion and verify that the error covariance converges to the Riccati solution Σ.

## Architecture Onboarding
**Component map**  
y_t (and optional ˜x_t) → Truncated FIR Estimator → Compute estimate (ŷ_t or x̂_t) → Compare to target → Compute gradient → Projected GD update → Parameters (N_t / M_t). For state estimation, the update branch is gated by the Query Scheduler.

**Critical path**  
Initialize parameters → For t = 0,…,T−1:  
  • Generate estimate using last h outputs  
  • If (output estimation) always: compute loss ∇f_t, update  
     (If state estimation and query) compute loss ∇f̃_t, update  
     (Else keep parameters)  

**Design tradeoffs**  
- *Truncation length h*: Larger h reduces approximation error but increases memory/computation; must satisfy h ≤ τ for state estimation.  
- *Step size*: Too large → instability; too small → slow convergence. Schedule depends on α₀ and (log T)².  
- *Projection radius*: Too tight → excludes optimal filter, causing bias; too loose → slower convergence.  
- *Query frequency τ*: Smaller τ improves online regret O(τ log⁴ T log(T/τ)) but requires more state measurements; larger τ reduces query cost but increases that term.

**Failure signatures**  
- Regret grows polynomially (e.g., √T) rather than logarithmically: likely step‑size or truncation issue.  
- State estimation regret linear: queries missing/too sparse or projection set too small.  
- Frequent gradient clipping: increase projection radius or reassess σ̄.  
- Gradient norm not decreasing: check sign and step size.  
- Benchmark discrepancy: verify Kalman filter by comparing its error covariance to the Riccati solution.

**Three first experiments**  
1. **Output estimation on a random stable system**: Generate spectral radius 0.9, run Algorithm 1 for T = 200, 500, 1000, 2000; plot R_y(T) on log‑log to confirm sub‑polynomial growth.  
2. **Truncation error validation**: Compute offline the optimal FIR filter (by projecting the infinite‑dimensional steady‑state Kalman filter) with the chosen h; compare its cumulative loss to the full Kalman filter; ensure the difference is o(T).  
3. **State estimation with random queries**: Run Algorithm 2 with τ = ⌊√T⌋, T = 3000 across many seeds; plot R_x(T) and R_x(T)/√T; also vary τ (e.g., T^{1/4}, T^{1/2}) to observe the predicted trade‑off.

## Open Questions the Paper Calls Out
- **Nonlinear extension:** Can the framework be extended to extended Kalman filters or other nonlinear estimators? The authors identify moving beyond linear systems as future work.  
- **Non‑stochastic noise:** Is sublinear regret for state estimation achievable without queries under adversarial noise? The current analysis relies on Gaussian noise for conditional strong convexity; non‑stochastic settings remain open.  
- **Optimal query trade‑off:** Is the achieved bound O(τ log⁴ T log(T/τ) + √T log² T) optimal, or can adaptive querying improve the dependence? The paper presents a uniform random query scheme but no lower bound.  
- **Eliminating coarse prior bounds:** Can the dependence on known bounds (α₀, ψ, σ̄) be removed or relaxed, perhaps via parameter‑free methods? This is left as an open question.

## Limitations
- Requires prior coarse bounds (α₀, ψ, σ̄) to set projection radii and step sizes; inappropriate bounds can degrade regret.  
- Truncation length h must be chosen as O(log T) and satisfy h ≤ τ; choosing h too small introduces linear approximation error.  
- The Boeing 747 experiment depends on finding a stabilizing output feedback gain K, which is not provided and may require heuristic tuning.  
- Analysis assumes linear dynamics and Gaussian noise; applicability to non‑linear or non‑Gaussian settings is unclear.

## Confidence
- **Output estimation O(log⁴ T)**: Medium (step size and truncation must be tuned correctly)  
- **State estimation lower bound Ω(T)**: High (rigorous information‑theoretic argument)  
- **State estimation with queries O(τ log⁴ T log(T/τ)+√T log² T)**: Medium (relies on exact query schedule and parameter bounds)  
- **Empirical √T scaling on Boeing model**: Medium (controller parameters unknown, may affect constants)

## Next Checks
1. **Feasibility of parameter bounds** – Compute steady‑state Kalman FIR parameters N* and M* and verify ∥N*∥_F ≤ R_N, ∥M*∥_F ≤ R_M; if violated, increase σ̄ to enlarge radii.  
2. **Truncation error magnitude** – For a moderate T (e.g., 1000), compare cumulative loss of the truncated optimal FIR filter to the full Kalman filter; ensure the difference grows sublinearly (ideally O(log T)). Increase h if needed.  
3. **Query‑schedule adherence** – Instrument Algorithm 2 to log each update; confirm updates occur exactly once per interval of length τ at uniformly random offsets, with total updates = ⌊T/τ⌋ (plus possibly one in the final partial interval).
