# The Median is Easier than it Looks: Approximation with a Constant-Depth, Linear-Width ReLU Network
## Quick Facts
*   **arXiv ID:** 2602.07219
*   **Source URL:** https://arxiv.org/abs/2602.07219
*   **Reference count:** 40
*   **Primary result:** A constant-depth (46 hidden layers), linear-width ReLU network approximates the median of uniform hypercube inputs with exponentially small L2 error, breaking a known depth barrier.

## Executive Summary
This paper resolves a major open question in the complexity of neural network approximation by constructing a ReLU network that computes an approximate median with constant depth and linear width. Prior work suggested a logarithmic depth barrier for this accuracy regime. The authors' breakthrough comes from a two-stage pipeline: first, a deterministic sparsification process that iteratively shrinks the input while provably preserving a candidate set containing the true median; second, a deterministic hashing scheme that reduces the dimensionality of this sparse set to enable final extraction via all-pairs comparisons. The work also establishes a reduction proving that approximating the median is at least as hard as approximating the maximum, thereby transferring known lower bounds and clarifying the relationship between exact and approximate computation thresholds.

## Method Summary
The construction proceeds in two main phases after an initial assumption of δ-separated inputs (all pairwise gaps ≥ δ). First, a four-iteration sparsification algorithm repeatedly samples random subsets of the current candidate set, computes central ranks using a prior max-approximation network, and thresholds to zero out non-central elements. This geometrically reduces the number of non-zero entries from O(d) to O(d^0.16) while maintaining the median with high probability. Second, the sparse vector is hashed using a universal family of binary-weight linear transforms. By applying all hash functions in the family, the network identifies a hash output with zero collisions (guaranteed by a combinatorial lemma). The top O(d^0.16) entries of this collision-free block are then extracted, and the median is isolated using an all-pairs rank-computation subnetwork that leverages the remaining δ-separation. The entire pipeline composes into a single ReLU network with constant depth and linear width.

## Key Results
*   **Constant-depth, linear-width construction:** Achieves L2 error exp(-Ω(d)) for uniform inputs using a 46-hidden-layer network with O(d) neurons per layer.
*   **Reduction of hardness:** Proves that any ReLU network approximating the median can be converted into one approximating the maximum with similar resources, establishing median approximation as at least as hard as maximum approximation.
*   **Separation of regimes:** Demonstrates a clear complexity gap between exact median computation (which requires super-linear width or depth) and approximate computation (achievable with constant depth and linear width).

## Why This Works (Mechanism)
### Mechanism 1: Iterative Sparsification
*   **Claim:** Repeatedly sampling subsets and thresholding shrinks the candidate set while preserving the true median.
*   **Mechanism:** Algorithm 5 performs four iterations. In each, it samples a non-zero subset, computes their "central" ranks via a previous max-approximation network, and zeros out entries outside an interval [e⁻ᵢ, e⁺ᵢ] defined by those ranks. Sample size shrinks geometrically, leaving O(d^0.16) non-zeros containing the median with high probability.
*   **Core assumption:** Inputs are i.i.d. uniform on [0,1] and δ-separated (all pairwise gaps ≥ δ). This ensures random samples approximate global rank proportions via concentration.
*   **Evidence anchors:** [abstract] "iteratively eliminates non-central elements"; [section D.1] Algorithm 5 and Proposition D.2.
*   **Break condition:** If the median's rank deviates beyond the sampled interval due to low-probability sampling error, it gets eliminated. Non-δ-separation also breaks later deterministic comparisons.

### Mechanism 2: Deterministic Hashing for Dimensionality Reduction
*   **Claim:** Universal hashing maps the sparse vector to a lower dimension without collisions, enabling linear-width median extraction.
*   **Mechanism:** Algorithm 7 applies every hash function from a universal family ℋ_{d,2ε+γ} (binary-weight linear maps). A "block extraction" network finds the first hash output with exactly s non-zeros (guaranteed collision-free by Lemma F.9). The top d^ε entries of that output are selected by a rank-selection network.
*   **Core assumption:** The input is (d,ε)-sparse (≤ d^ε non-zeros). The universal family's δ-near-universal property (δ ≤ ⌈1/(2ε+γ)⌉ / d^{2ε+γ}) ensures a collision-free hash exists for sufficiently large d.
*   **Evidence anchors:** [abstract] "deterministic hashing scheme"; [section D.2] Algorithm 7, Proposition D.4, Lemma F.9.
*   **Break condition:** If sparsity exceeds d^0.16, collisions may occur for all hashes; if d is too small relative to ε,γ, the combinatorial guarantee fails.

### Mechanism 3: All-Pairs Rank Selection
*   **Claim:** Pairwise comparisons on a small, δ-separated set compute exact ranks, allowing extraction of the element at the median rank.
*   **Mechanism:** The rank-selection network ℕ_{RS}^δ (Definition G.12) computes each element's rank y_k = 1 + Σ_j ℕ_C^δ(x_k, x_j), where ℕ_C^δ is a comparison network tolerant to δ. For desired rank r, it outputs Σ_k x_k · 1{y_k = r} using an indicator-product subnetwork.
*   **Core assumption:** After sparsification/hashing, the remaining set is δ-separated and small enough (O(d^0.16)) that the quadratic width in this reduced dimension does not blow up the overall linear width claim (since earlier layers dominate width).
*   **Evidence anchors:** [section G.7] Definition G.12, Lemma G.13; [section 3.1] depth-3 quadratic-width precursor.
*   **Break condition:** Non-δ-separation makes ℕ_C^δ outputs ambiguous, corrupting rank tallies. If the set size grows beyond O(d^0.16), the quadratic subnetwork would use super-linear width in d.

## Architecture Onboarding
*   **Component map:** Input x → ℕ_{NZES} (non-zero shortlisting) → ℕ_{RC} (rank computing) → ℕ_{RSC} (rank scaling) → ℕ_{CEI} (ceiling) → ℕ_{MAX} / ℕ_{RS} (central interval) → ℕ_{F} (filter) → (repeat 4×) → ℕ_{H} (hashing for all h) → ℕ_{BE} (block extraction) → ℕ_{RS} (top-s selection) → ℕ_{RS} (median extraction) → Clipping to [0,1]
*   **Critical path:** The sparsification phase (Algorithm 6) uses ~33 layers over four iterations (each iteration ~8-10 sublayers). The hashing phase (Algorithm 7) uses ~6 layers (1 for all hashes, 3 for block extraction, 2 for selection). Final extraction uses ~5 layers. Total depth ≈ 45 + 1 (final clipping) = 46 hidden layers. Width is dominated by the initial layers that operate on dimension d, keeping it O(d).
*   **Design tradeoffs:** The pipeline trades depth (multiple iterative rounds) for width reduction. The construction is probabilistic over the uniform input distribution (success probability 1 - e^{-Ω(d)}) but deterministic once the network is fixed. Weight magnitudes scale as O(1/δ) = O(poly(d)), which is large but polynomial.
*   **Failure signatures:** (1) Sparsification failure: median zeroed out → output error Ω(1). (2) Hash collision: ℕ_{BE} fails to find collision-free block → median missing from final set. (3) Rank error: non-δ-separation breaks ℕ_C^δ → incorrect rank tally.
*   **First 3 experiments:** (1) Test δ-separation: for d=100,1000, sample x~U([0,1]^d), compute min gap; verify it exceeds δ=Ω(1/d²) with high probability. (2) Hash collision test: for a (d,0.16)-sparse vector at small d (e.g., 30), exhaustively check ℋ_{d,2ε+γ} for a collision-free hash; should exist per Lemma F.9. (3) Rank selection validation: construct δ-separated vector of size d'=d^{0.5} with known ranks; feed to ℕ_{RS}^δ with median rank; output should match true median within δ.

## Open Questions the Paper Calls Out
*   **Minimal depth for linear-width median approximation:** The achieved constant 46 is not optimized; the precise minimal depth remains unknown.
*   **Lower bounds for median without reduction from maximum:** Current lower bounds for median are inherited from maximum via reduction. Direct lower bounds specific to median, potentially stronger, are open.
*   **Constant-depth, linear-width networks and arbitrary accuracy:** It is unknown whether such networks can achieve arbitrarily high accuracy solely via weight scaling, or if there is a fundamental accuracy barrier in this regime.

## Limitations
*   **Distribution specificity:** Results assume i.i.d. uniform inputs on the unit hypercube; behavior on non-uniform or dependent data is unanalyzed.
*   **δ-separation prerequisite:** Requires minimum pairwise gap Ω(1/d²); while this holds with high probability for uniform inputs, it is not universally guaranteed.
*   **Network constants:** Depth 46 and polynomial weight magnitudes may be prohibitive for practical use despite theoretical linear width.

## Confidence
*   **Existence of constant-depth, linear-width network achieving exp(-Ω(d)) L2 error:** Medium (depends on layered probabilistic arguments holding simultaneously).
*   **Reduction: median approximation ≥ maximum approximation hardness:** High (reduction is straightforward and rigorous).
*   **Separation between exact and approximate regimes:** High (proven via explicit construction vs. lower bound).
*   **Breaking the Ω(log log d) depth barrier for linear width:** High (under the stated uniform, δ-separated assumptions).
