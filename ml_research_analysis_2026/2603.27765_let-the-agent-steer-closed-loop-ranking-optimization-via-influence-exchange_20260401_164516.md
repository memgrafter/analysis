# Let the Agent Steer: Closed-Loop Ranking Optimization via Influence Exchange

## Quick Facts
- arXiv ID: 2603.27765
- Source URL: https://arxiv.org/abs/2603.27765
- Reference count: 9
- Primary result: Closed-loop LLM-driven agent Sortify reduces offline-online transfer gap, yielding up to +9.2% GMV uplift (Country A) and +4.15% GMV/UU (Country B) in production A/B tests.

## Executive Summary
Sortify tackles the persistent offline-online transfer gap in ranking optimization by autonomously calibrating both the transfer model and constraint penalties. It is grounded in Savage’s Subjective Expected Utility theory, which mandates separating belief (world model) from preference (utility). The system uses a dual-channel framework: a Belief channel (LMS regression + LLM intercept updates) corrects the offline-to-online mapping, while a Preference channel applies asymmetric multiplicative updates to constraint penalties. An LLM meta‑controller observes multi‑round patterns and adjusts framework‑level parameters, and a persistent relational Memory DB enables cross‑round learning and warm‑starts. Production experiments in two countries show significant and stable GMV improvements (up to +9.2% in warm‑start and +4.15% in cold‑start), with the LLM’s calibration effort converging over time.

## Method Summary
Sortify orchestrates a continuous loop beginning with a parameter push to Redis, followed by a 3.5‑hour A/b traffic accumulation, report retrieval, and a 10‑step pipeline. The core dual‑channel framework maintains separate calibration pathways. The Belief channel employs a linear model (LMS regression with fixed learning rate η=0.2) to map offline Influence Share metrics to online uplifts; intercepts are further refined by an LLM meta‑controller (±0.1 range). The Preference channel monitors constraint violation pressure and updates penalty multipliers via asymmetric rules (tightening δ_up=0.25, relaxation δ_down=−0.08). The LLM ingests the 20 most recent episodes and 30 update records to propose framework‑level adjustments, all bounded by safety clamps. The search engine (Optuna TPE) then maximizes a quadratic‑penalty objective—10× GMV Influence relative uplift minus squared constraint violations—across a 7‑dimensional sorting parameter space. Results and calibration state are persisted in a SQLite Memory DB, which seeds subsequent rounds and supports warm‑starts. The YOLO Runner manages the entire cycle, handling retries and crash recovery.

## Key Results
- Warm‑start Country A: GMV uplift improved from −3.6% to +9.2% over 7 rounds, with peak orders +12.5%.
- Cold‑start Country B: +4.15% GMV per user and +3.58% Ads Revenue in a 7‑day A/B test, leading to full rollout.
- LLM calibration effort decreased from 5 to 2 correction items per round, indicating convergence.

## Why This Works (Mechanism)
### Mechanism 1
Sortify decouples offline‑online transfer calibration (Belief channel) from constraint penalty adjustment (Preference channel) based on Savage’s SEU theory. The Belief channel uses LMS regression with LLM intercept jumps to model the mapping from offline Influence Share to online outcomes; the Preference channel asynchronously updates penalty multipliers via asymmetric multiplicative rules. The core assumption is that attribution errors split cleanly into either a misestimated transfer function (world model error) or a mis‑scaled constraint penalty (utility error), requiring exclusive corrections. Evidence: the abstract explicitly mentions the decoupling; Section 2.1 warns against cognitive biases if not forced apart; Sections 2.3.4 and 2.4.3 provide the mathematical updates. Break condition: simultaneous transfer drift and constraint tolerance change may require multiple rounds to disentangle, slowing convergence.

### Mechanism 2
An LLM meta‑controller operates at the framework level (transfer intercepts, penalty multipliers) to correct residuals left by slow LMS updates. It ingests context containing the 20 most recent episodes and 30 prior update records, then proposes discrete adjustments (Δβ ∈ [−0.1, +0.1], multiplier m ∈ [0.5, 2.0]) after LMS runs. A seven‑layer safety pipeline (clamping, whitelist, fallback) bounds its influence. Core assumption: multi‑round pattern recognition (e.g., persistent optimism) is a distinct capability from single‑round gradient descent and can be delegated to a bounded LLM. Evidence: Abstract describes LLM meta‑controller operating on framework‑level parameters; Section 2.5.2 states it adjusts the search framework not the 7‑dimensional vector directly; Section 4.6.1 shows LLM correction effort converging from 5 to 2 items per round. Break condition: in sustained high‑noise environments with low signal‑to‑noise in the 20‑round history, the LLM may frequently return empty proposals, slowing recovery if LMS is conservative.

### Mechanism 3
A persistent relational Memory DB (SQLite) with 7 append‑only tables stores episodes, observations, relations, and update histories, enabling cross‑round learning, warm‑starts, and audit trails. Each round reads from this state to initialize LMS slopes/intercepts, LLM context, and writes new results. This turns independent rounds into cumulative intelligence, supporting warm‑start (Exp‑401838) and cross‑market generalization (Exp‑437160). Core assumption: calibration meta‑knowledge (e.g., “GMV transfer has been 5‑8% optimistic”) is transferable across distributions, whereas raw parameters are ephemeral; thus persistence is necessary. Evidence: Abstract mentions Memory DB for cross‑round learning; Section 2.6.2 details schema and idempotency; Sections 4.5 & 4.8 show warm‑start and cold‑start experiments reusing the schema. Break condition: fundamental changes to business metric definitions or scoring formula would require schema migration or cold reset, losing accumulated state.

## Foundational Learning
- **Subjective Expected Utility (SEU) Theory (Savage, 1954)**
  - *Why needed:* Provides formal Bayesian decision‑theoretic justification for separating the problem into belief and preference channels—a derived requirement for rationality.
  - *Quick check:* If the offline‑to‑online transfer model is perfectly calibrated but a constraint violation still causes business harm, which channel must be adjusted and why?
- **LMS Adaptive Filtering**
  - *Why needed:* Implements the slow‑tempo continuous calibration of the Belief channel via incremental updates; small fixed learning rate prevents overreaction but necessitates an external mechanism for structural breaks.
  - *Quick check:* Why would a larger LMS learning rate (e.g., η=0.5) be problematic in a low‑traffic observation window?
- **Quadratic Penalty Formulation for Constraints**
  - *Why needed:* Converts constraint satisfaction into differentiable loss with squared violations, creating steep gradients near boundaries and biasing toward mild satisfaction, critical for industrial red‑line enforcement.
  - *Quick check:* Why is a linear penalty (λ_j * v_j) insufficient for preventing large constraint violations in this context?

## Architecture Onboarding
### Component Map
Memory DB -> Belief Channel (LMS regression) -> Preference Channel (asymmetric penalty updates) -> LLM Meta‑Controller (framework adjustments) -> Optuna TPE (parameter search) -> Orchestrator (YOLO Runner) -> Redis (parameter push) -> Online A/B test -> Observation collection -> Memory DB (episode recording)

### Critical Path
The cycle starts with pushing parameters to Redis, then a mandatory 3.5‑hour observation window for A/B traffic accumulation. After waiting (snapped to 15‑minute boundaries), the A/B report is fetched (with ≥3 lines validation), the 10‑step pipeline runs, the best parameters are published back to Redis, and the Memory DB is updated with the new episode. The 3.5‑hour wait dominates cycle time; compute (5,000 Optuna trials across 25 workers) and search fit within that window.

### Design Tradeoffs
- **Freeze mechanism:** If a Belief channel update magnitude exceeds a threshold, the Preference channel freezes for one round to isolate causal impact and avoid confounding simultaneous adjustments.
- **LLM safety bounds:** Absolute intercept change limited to ≤0.1; penalty multiplier constrained to [0.5, 2.0]; relation keys whitelisted; prevents a single erroneous LLM judgment from destabilizing the framework.
- **Penalty asymmetry:** Tightening (δ_up=0.25) proceeds three times faster than relaxation (δ_down=0.08), encoding the industrial preference that false negatives (constraint violation) are costlier than false positives (overly tight constraint).

### Failure Signatures
- **Residual pendulum effect:** Extreme oscillation in a single parameter (e.g., ps_ads_wo varying by a factor of 4.5) across rounds indicates the multi‑objective trade‑off (ads vs. organic) is being forced into a single‑penalty saddle rather than explicitly modeled as a Pareto frontier.
- **Statistical underpower:** The strongest round‑level results (e.g., +9.2% GMV) occurring in a low‑traffic window (<20K impressions) may regress in subsequent rounds due to high variance.
- **LLM proposal emptiness:** The LLM returns no adjustments for multiple consecutive rounds, which could mean the system is well‑calibrated or that persistent low signal‑to‑noise in the 20‑round history hampers pattern recognition.

### First 3 Experiments
1. **Cold Start (Country B V1, Round 1):** Began with default priors. The first round identified a market‑specific direction (e.g., ps_org_wc +271%) but parameters remained unstable, validating the system’s ability to produce a directional signal in a new market.
2. **Warm‑start Convergence (Country A Exp‑401838, Rounds 2‑7):** Inherited the existing Memory DB state. Observed a clear GMV uplift trajectory (−3.6% → +9.2%), the LLM correction item count decreased (5 → 2), and parameter oscillation was contained (max 4.5× range). Validated inner‑loop continuous improvement with accumulated calibration state.
3. **Deployment Lifecycle Completion (Country B V3, R7 freeze → 7d A/B → Rollout):** After identifying a Pareto‑optimal parameter set in Round 7, the system froze, ran a 7‑day static A/B test, and achieved consistent positive lifts (GMV/UU +4.15%, Ads Rev +3.58%). A human operator approved full rollout, validating the outer governance loop—the system can produce a deployable policy, not just promising round signals.

## Open Questions the Paper Calls Out
- **How can residual parameter oscillation (pendulum effect) be eliminated?** The paper identifies that the single‑objective‑with‑penalties formulation cannot resolve the fundamental ads‑organic trade‑off, causing ps_ads_wo to oscillate. A multi‑objective Pareto frontier approach is needed to achieve stable convergence.
- **How can the system maintain accurate calibration during low‑traffic observation windows?** Statistical uncertainty in low‑traffic windows (e.g., ~12K impressions) can lead to over‑correction. A confidence‑weighted transfer model (e.g., inverse variance weighting or Bayesian posterior variance) that modulates update step sizes could improve stability.
- **Does the LLM meta‑controller effectively handle extreme structural breaks?** Existing evidence only covers warm‑start and cold‑start under relatively stable conditions; no experiments test abrupt distribution shifts (e.g., flash sales, competitor actions). Controlled studies comparing LMS‑only vs. LLM+LMS recovery times are required.

## Limitations
- Exact initial parameter ranges (7‑dimensional θ) and constraint penalty weights (λ_j) are unspecified, hindering warm‑start reproducibility.
- LLM meta‑controller’s full system prompt, evidence validation logic, and model version are omitted, making its reasoning process opaque.
- Break conditions such as simultaneous transfer drift and legitimate constraint tolerance shifts remain untested; sustained low‑signal environments may impair LLM pattern recognition.

## Confidence
- Dual‑channel SEU‑grounded separation: High
- Persistent Memory DB architecture: High
- LLM meta‑controller convergence effect: Medium
- Orthogonal decomposition always preventing diagnostic entanglement: Low

## Next Checks
- **Reproduce LMS dynamics:** Implement the LMS update (η=0.2) with synthetic drift patterns; measure recovery speed from structural breaks vs. LLM correction frequency.
- **Stress‑test freeze mechanism:** Inject correlated shocks (simultaneous transfer shift and constraint relaxation) in simulation; validate whether the freeze rule isolates causal effects without stalling convergence.
- **LLM pattern‑recognition benchmark:** Construct a 20‑round history with known multi‑round patterns (e.g., persistent optimism); audit if LLM proposals match ground‑truth adjustments within bounded outputs.
