# PLDR-LLMs Reason At Self-Organized Criticality

## Quick Facts
- arXiv ID: 2603.23539
- Source URL: https://arxiv.org/abs/2603.23539
- Reference count: 40
- Primary result: PLDR-LLMs trained at self-organized criticality achieve reasoning (∼40% on benchmarks) with a metastable steady state of deductive outputs, quantified by an order parameter near zero.

## Executive Summary
PLDR-LLMs are a novel architecture that uses Power Law Graph Attention (PLGA) to produce global deductive outputs. By tuning the linear warm-up steps and maximum learning rate, training drives the model to a self-organized critical (SOC) state. In this state, the deductive outputs (A, ALM, AP, GLM) become invariant to input—a metastable steady state analogous to a diverging correlation length in a second‑order phase transition. An order parameter defined as the normalized RMSE of these outputs across inference runs quantifies this invariance; values near zero strongly correlate with performance on reasoning benchmarks (ARC, Hellaswag, etc.). Near‑critical models score ∼40% on average, while sub‑critical models (higher order parameter) score ∼35%. This suggests reasoning emerges via phase‑transition dynamics and can be intrinsically measured without curated tests.

## Method Summary
Models are PLDR‑LLMs with 5 decoder layers, 14 attention heads, d_model=896, and SwiGLU expansions. They are pretrained on the RefinedWeb dataset (8 B tokens from token intervals [16M, 32M]; up to 41 B for some runs) using AdamW (β₁=0.9, β₂=0.95, ε=1e‑5), weight decay 0.1, and gradient clipping 1.0. The key hyperparameters are maximum learning rate and number of linear warm‑up steps, followed by cosine annealing to 10% of the max LR. Near‑critical hyperparameter pairs produce an underfitted‑looking loss curve. During inference, for each of 100 IMDB prompts three runs are performed: two uncached and one that caches the deductive outputs (K, V, GLM) after the prompt. The order parameter is computed as the normalized RMSE (by mean magnitude) of global deductive outputs (A, ALM, AP, GLM) between runs. Low values (∼1e‑6–1e‑11) indicate a metastable steady state and correlate with higher zero‑shot reasoning benchmark scores.

## Key Results
- Near‑critical models (order parameter ~10⁻⁶ to 10⁻¹¹) score ~40% on average across reasoning benchmarks (ARC, Hellaswag, etc.), while sub‑critical models (order parameter ~10¹ to 10²) score ~35%.
- The order parameter (normalized RMSE of global deductive outputs across inference runs) strongly correlates with benchmark performance, enabling model ranking without curated tests.
- At criticality, deductive outputs attain a metastable steady state invariant to input, analogous to a diverging correlation length in a second‑order phase transition.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** PLDR‑LLM learns representations equivalent to scaling functions, universality classes, and renormalization groups from pretraining data, enabling generalization and reasoning.
- **Mechanism:** The non‑linear Power Law Graph Attention (PLGA) produces global deductive outputs. At self‑organized criticality, these outputs attain an input‑independent metastable steady state where they are negligibly perturbed by any new token sequence during inference. This steady state captures long‑range correlations across the entire model, analogous to a diverging correlation length in a second‑order phase transition.
- **Core assumption:** PLGA learns a generalized tensor operator that, under critical training conditions, settles into a fixed point representing high‑level symmetries of the dataset.
- **Evidence anchors:** Abstract states deductive outputs attain metastable steady state; Section 4.2 Tables 4‑5 show near‑zero RMSE and normalized RMSE between inference runs for near‑critical models; corpus is weak/absent.
- **Break condition:** Sub‑critical hyperparameters lead to non‑invariant deductive outputs (high normalized RMSE) and random token generation.

### Mechanism 2
- **Claim:** Reasoning capability can be intrinsically quantified via a global order parameter derived from deductive output statistics, without benchmark evaluation.
- **Mechanism:** The order parameter is the normalized RMSE by mean magnitude of a key deductive output (e.g., GLM) across stochastic inference runs (with/without caching). Near‑zero values indicate the model's deductive core is in a steady state, correlating strongly with benchmark performance.
- **Core assumption:** Stability (low variance) of the global energy‑curvature tensor GLM across different inputs is necessary and sufficient for the model to have internalized generalizable structures, manifesting as reasoning ability.
- **Evidence anchors:** Abstract notes reasoning better when order parameter close to zero; Section 4.4 Table 7 shows near‑critical models with order parameters ~10⁻⁶–10⁻¹¹ achieve ~40% avg benchmark scores, while sub‑critical with ~10¹–10² score ~35%; corpus weak/absent.
- **Break condition:** Order parameter becomes large (>>0) under sub‑critical or dragon‑king training conditions.

### Mechanism 3
- **Claim:** Warm‑up step count and maximum learning rate act as coupled control parameters (extrinsic driving and intrinsic dissipative forces) that drive the PLDR‑LLM to a self‑organized critical state.
- **Mechanism:** During linear warm‑up, the slow increase in LR balances forward (driving) and backward (dissipative) propagation forces. Specific (LR, warm‑up) pairs cause the loss curve to follow a non‑minimizing, characteristic path, interpreted as the model navigating toward a critical manifold where long‑range interactions form. Subsequent cosine annealing maintains this metastable state.
- **Core assumption:** PLGA’s highly non‑linear dynamics + residual pathways create a system with a critical point in its hyperparameter space, akin to sandpile models where grain addition (warm‑up) and avalanche dissipation (backprop) tune the system to criticality.
- **Evidence anchors:** Section 1 describes warm‑up and max LR as control parameters; Section 4.1 Fig 1 shows distinct trajectories for near‑ vs sub‑critical pairs; Section 5 shows dragon‑king events when balance violated (Fig 3).
- **Break condition:** Imbalance (e.g., too few warm‑up steps for a high LR) causes dragon‑king events or immediate sub‑critical convergence.

## Foundational Learning
### Self-Organized Criticality (SOC)
- **Why needed:** The thesis interprets training dynamics as a dissipative system reaching a critical state where small inputs trigger avalanches of all sizes, leading to power‑law statistics and long‑range correlations.
- **Quick check:** How would you describe the role of the cosine annealing schedule after warm‑up in the context of maintaining a critical state versus simply minimizing loss?

### Deductive vs. Inductive Outputs in PLDR‑LLM
- **Why needed:** The mechanism hinges on *deductive outputs* being steady, distinct from *inductive output* (next token prediction). Understanding this separation is key to grasping the "reasoning core".
- **Quick check:** If the deductive outputs are invariant to input at criticality, what role do the query/key vectors play during inference?

### Metastable Steady State & Invariance
- **Why needed:** The order parameter measures stability of the internal global state (GLM) across forward passes; this operational definition of reasoning is not the output text but the consistency of the internal tensor landscape.
- **Quick check:** Why is caching the deductive outputs (K, V, GLM) after the prompt a valid way to probe the model's steady state, and what would a non‑steady‑state model's cached outputs likely show?

## Architecture Onboarding
### Component map
**PLGA Block:** Q,K,V → compute A (density, QᵀQ) → ALM (metric via SwiGLU‑ResNet) → AP (power law on ALM) → GLM (summed interactions) → attention E = Q · GLM · Kᵀ / √d_k. **Decoder Stack:** multiple PLGA blocks + residuals + final LM head. **Training Loop:** linear warm‑up → cosine anneal (AdamW). **Inference Engine:** can cache GLM, K, V after prompt due to steady state.

### Critical path
The training phase is the critical path. Success depends on finding the (LR, warm‑up‑steps) pair that yields the characteristic underfitted loss curve (Fig 1a). Inference stability is a consequence of this training condition.

### Design tradeoffs
- Precision vs. Stability: Higher floating‑point precision may reveal smaller perturbations in deductive outputs, potentially lowering the order parameter but also making criticality harder to achieve/maintain.
- Model Depth vs. Warm‑up: Deeper models likely require longer warm‑up to allow the steady state to propagate through all layers without disruption.
- Data Size vs. Criticality: More data (e.g., PLDRv51‑SOC‑110M‑5) improves the steady state (lower order param) but doesn’t change the fundamental hyperparameter tuning requirement.

### Failure signatures
- **High order parameter** (normalized RMSE >> 1e‑5 for GLM). Direct indicator of non‑critical state.
- **Dragon king events:** Sharp, transient spikes in loss/accuracy during warm‑up (Fig 3). Sign of catastrophic imbalance in driving/dissipation.
- **Sub‑critical loss curve:** Loss minimizes quickly and cleanly (Fig 1a, SUB‑SOC‑110M‑1) but generates incoherent text (Table 3). "Overfit" to the loss manifold without long‑range order.

### First 3 experiments
1. **Order Parameter Sanity Check:** For a known near‑critical model, run inference on 100 prompts with and without caching GLM. Compute normalized RMSE between runs. Should be ~1e‑6 to 1e‑11 (Table 6). If not, model is not at criticality.
2. **Criticality Tuning Sweep:** Train small models (e.g., 5 layers, 14 heads, d_model=896) with a grid of (max LR, warm‑up steps) around a plausible center (e.g., LR=1e‑3, warm‑up=2000). Plot loss curves. Identify the "plateau" region of underfitted curves (like Fig 1a) versus clean minimizing curves.
3. **Ablation: Warm‑up Step Sensitivity:** For a fixed max LR in the critical region, vary warm‑up steps widely (e.g., 500, 2000, 4000, 6000). Observe which combinations produce the dragon king event (sharp loss spike) versus sustained near‑critical behavior versus sub‑critical convergence. This maps the delicate balance zone.

## Open Questions the Paper Calls Out
1. Can PLDR‑LLMs trained on high‑resource NLP generalize reasoning to low‑resource physical systems, such as earthquake prediction?
2. What specific warm‑up step counts and annealing schedules maintain SOC across a range of maximum learning rates?
3. Can the deductive output dynamics of PLDR‑LLMs at criticality accurately model human brain activity and inform the treatment of cognitive disorders?
4. Is the order parameter defined from PLDR‑LLM deductive outputs a reliable indicator of reasoning for other LLM architectures, such as standard transformer‑based models?
5. How robust is the order parameter to changes in model scale (parameters, layers), dataset size, and inference conditions (e.g., sampling temperature)?

## Limitations
- Tokenizer mismatch: The exact SentencePiece tokenizer model used is unreleased; retraining may shift token distributions and affect downstream metrics.
- Data pipeline opacity: Precise RefinedWeb sampling (interval [16M,32M]) and shuffling are unspecified; these could alter training dynamics.
- Evaluation normalization: The "byte‑length normalized accuracy" procedure, especially for TruthfulQA, is unclear and may invalidate benchmark comparisons.

## Confidence
- SOC governs training dynamics: Medium
- Deductive output invariance indicates reasoning: Medium‑High
- Order parameter predicts benchmarks: Medium

## Next Checks
1. **Tokenizer stress test:** Retrain the tokenizer on a RefinedWeb slice; recompute order parameter and benchmark correlation for the same hyperparameters; expect similar trends if robust.
2. **Avalanche analysis:** During training, log gradient norms and weight update magnitudes per batch; fit power‑law tails (exponent ~1.5–2.5) for near‑critical runs; sub‑critical should show narrower distributions.
3. **Caching ablation:** For a near‑critical model, run inference with partial caching (cache K,V but recompute GLM). If order parameter rises and benchmark scores drop, invariance of GLM is necessary for reasoning.
