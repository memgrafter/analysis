# Common Belief Revisited

## Quick Facts
- **arXiv ID:** 2602.15403  
- **Source URL:** https://arxiv.org/abs/2602.15403  
- **Reference count:** 15  
- **Primary result:** The paper gives a complete axiomatization of common belief under KD45 individual belief: for n ≥ 2 agents the logic CBₙ = KD4 + Cc + Cn is sound and complete with respect to all KD45ₙ models, and the extra axiom Cn (a counting formula) is necessary — the logic varies with the number of agents.

## Executive Summary
The paper tackles the long‑standing open problem of axiomatizing common belief when each agent’s belief satisfies the modal axioms KD45. Contrary to the widely held view that common belief is captured simply by KD4 together with the shift‑reflexivity axiom Cc, the author shows that an additional axiom Cn – which depends on the number n of agents – is required. For every n ≥ 2 the logic CBₙ = KD4 + Cc + Cn is proved sound and complete with respect to the class of KD45ₙ models. The core of the proof adapts the canonical uni‑modal model for CBₙ, then systematically relabels transitions to enforce Euclidicity and transitivity while using Cn to keep the branching at the root within bounds. As a by‑product, interpreting common belief as reflexive transitive closure yields an S4 axiomatization. The result is metric‑precise: for two agents the extra axiom is a concrete formula C₂; for general n it is the family of counting formulas Cₙ. The construction demonstrates that the logic of common belief indeed varies with the number of agents, settling the conjecture.

## Method Summary
**Soundness** is established by checking that each axiom of CBₙ holds in any KD45ₙ model. K and Nec follow from normality of the common belief operator C. D (seriality) comes from the seriality of each agent’s accessibility; together with transitive closure this gives Cφ → ¬C¬φ. The axiom 4 (transitivity) is inherited from the transitivity of each Rᵢ applied to the transitive closure. Cc (shift‑reflexivity) is a consequence of Euclidicity of at least one agent’s relation. The new axiom Cn is shown valid by a counting argument: if a state has n + 1 distinct (⋃Rᵢ)*‑witnesses for some common belief subformulas, two of them share a first agent j; Euclidicity then yields a common successor that sees both subformulas, and Cn exactly enforces this condition.

**Completeness** proceeds by constructing, for any CBₙ‑consistent formula φ, a KD45ₙ model that satisfies φ. Starting from a CBₙ‑maximal consistent set w that branches (guaranteed by adding a fresh proposition p with p ∧ Ĉp ∧ Ĉ¬p), the canonical model for CBₙ is built. A proper set cl of subformulas of φ is fixed. The key step defines X₀ as the set of canonical states reachable from w that satisfy certain common belief formulas in cl. Using the first‑order property expressed by Cn, the construction iteratively replaces triples of states to reduce this set to at most n survivors, while preserving that every original X₀ state is one step from some survivor. The survivors are then padded to exactly n distinct R∗‑successors of w, forming the set X. A multi‑agent model M(cl,w) is created: a root w, n branches indexed by X, and a recursive unfolding of the canonical successor relation along each branch. Agents 1 and 2 are given alternating left/right types to reproduce the canonical R∗; the remaining n − 2 agents are assigned the identity relation. The valuation mirrors the truth of atomic formulas in the canonical sets. The model is verified to satisfy KD45 for all agents: within each unfolded cluster the relation is total (Euclidean and transitive), and seriality follows from the seriality of the canonical relation. A bisimulation links the canonical model to M, with the set X ensuring that all common belief formulas in cl are correctly witnessed at the root. Thus φ holds in a KD45ₙ model, establishing completeness. For the reflexive transitive closure variant, the root becomes automatically reflexive; the same construction yields an S4 axiomatization.

## Key Results
- **CBₙ axiomatization:** KD4 + Cc + Cn is sound and complete for common belief over n‑agent KD45 models (n ≥ 2).  
- **Necessity of Cn:** The axiom Cn (a counting formula) is essential; dropping it leaves the logic incomplete.  
- **Dependence on n:** The exact form of Cn varies with n; for two agents it is a specific formula C₂, for general n it is a family Cₙ.  
- **S4 by‑product:** Interpreting common belief as reflexive transitive closure gives a complete axiomatization by S4.

## Why This Works (Mechanism)
The KD45 conditions on individual belief ensure that the union of the agents’ accessibility relations is serial, transitive, and Euclidean. Common belief, defined as the transitive closure of this union, inherits transitivity and, with the shift‑reflexivity axiom Cc (which encodes Euclidicity), also enjoys a form of Euclidicity. The new axiom Cn exploits Euclidean geometry: if a state has more than n distinct (⋃Rᵢ)*‑witnesses, two of those witnesses must share a first step along some agent’s relation, yielding a common successor that sees both associated subformulas. This counting constraint precisely matches the branching bound enforced during the completeness construction. By starting from a canonical uni‑modal model and then relabeling transitions with two alternating non‑trivial agents (and identity agents for the rest), the construction reproduces the canonical relation while guaranteeing that each agent’s relation is KD45. The set X, obtained via the Cn‑driven reduction, ensures that the root has at most n direct children, thereby controlling the branching needed for the Euclidean property to hold globally. Consequently, the constructed model is a KD45ₙ model that bisimulates the canonical model, and the truth lemma follows from the correspondence between X and the required common belief formulas.

## Architecture Onboarding
**Component map**  
CBₙ Axioms (KD4, Cc, Cn) → Logic CBₙ  
Logic CBₙ ↔ Soundness w.r.t. class KD45ₙ  
Consistent formula φ → Maximal consistent set w (branching) → Canonical model for CBₙ → Transform (X₀ definition, Cn reduction, agent labeling) → Multi‑agent model M(cl,w)  
M KD45ₙ + Bisimulation with canonical model → Completeness (w ⊨ φ in M)  
For reflexive transitive closure variant: replace C with closure → axioms T and 4 → S4.

**Critical path**  
1. Start with a CBₙ‑consistent formula φ.  
2. Extend to a maximal consistent set w that forces branching (using fresh p).  
3. Build the canonical uni‑modal model for CBₙ.  
4. Identify the proper set cl of subformulas of φ.  
5. Construct X₀ (successors in canonical model satisfying certain Ĉ‑formulas).  
6. Apply the Cn‑based reduction to obtain a set X of ≤ n survivors covering X₀.  
7. Pad X to exactly n distinct successors.  
8. Define M(cl,w) by recursively unfolding the canonical relation along each branch, assigning agents 1 and 2 alternating patterns and identity to others.  
9. Prove M is KD45ₙ (serial, transitive, Euclidean for each agent).  
10. Establish a bisimulation between the canonical model and M, using the X‑set to satisfy common belief requirements at the root.  
11. Conclude w ⊨ φ in M, so φ is satisfiable in a KD45ₙ model.

**Design tradeoffs**  
- **Two non‑trivial agents:** Using only agents 1 and 2 with alternating left/right patterns simplifies the labeling while still ensuring that the union (R₁∪R₂)* equals the canonical R̂. The remaining n‑2 agents are given the identity relation, which does not affect the union. Tradeoff: restricts the construction to rely on just two agents; but any n can be accommodated by padding identities.  
- **Tree‑like structure:** The model is built as a tree (no cycles). This avoids complications with Euclidicity and transitivity that could arise in cyclic KD45 frames. Tradeoff: the construction may not directly yield all KD45 models, but for completeness it suffices to produce one model.  
- **Exact n branches:** Forcing exactly n children at the root via padding matches the quantification in Cn. If fewer than n are needed, arbitrary distinct successors are added; these use identity agents and therefore do not introduce new paths in the union.

**Failure signatures**  
- **Reduction too large:** After applying the Cn‑based merging, the set X has more than n elements. This indicates the reduction step did not exploit the counting property correctly; the bound in Lemma 4.3 would fail.  
- **Agent relation breaks KD45:** Checking an agent’s relation, e.g., for R₁, finds a state pair without required Euclidean closure. Likely the alternating pattern or cluster universality was mis‑implemented.  
- **Root truth lemma fails:** Some formula Cψ in cl is not witnessed by any x∈X (i.e., no x R̂‑successor satisfies ψ). This means the X set does not correctly cover X₀; revisit the coverage guarantee after reduction.  
- **Unexpected cycles due to identity agents:** If the construction inadvertently creates cycles beyond self‑loops from identity agents, the model may no longer be tree‑like and could violate transitivity or Euclidicity. Verify the unfolding process.

**First three experiments**  
1. **Soundness verification:** For each axiom (D, 4, Cc, Cn) pick a simple KD45ₙ frame and manually check validity. Example: a frame with two agents, each having a universal relation; test Cc and C₂.  
2. **Completeness for n=2:** Take a formula that is valid in all KD45₂ models but not obviously provable in CB₂ (if known). Attempt to model‑check using the construction: start from the canonical CB₂ model, apply reduction, build M. See if the bisimulation holds; if it fails, locate the gap.  
3. **S4 variant test:** Interpret C as reflexive transitive closure. Prove that T (Cφ→φ) and 4 (Cφ→CCφ) are sound. Attempt to derive a complete axiomatization with S4; check on formulas like C(p∧q) ↔ (Cp∧Cq) in simple models.

## Open Questions the Paper Calls Out
1. **Axiomatization for K5 and KB:** What is the complete axiomatization of common belief when individual belief satisfies K5 (and similarly KB)? The paper states this is left for future work.  
2. **K45 case:** The authors claim a corresponding result for K45 – that the logic is K4 + Cc + Cn – but the proof details are omitted, leaving it as a conjecture requiring verification.  
3. **Unrestricted number of agents:** Does the logic of common belief simplify to KD4 + Cc when the class of models includes any finite number of agents or countably infinitely many agents? The paper asserts this without proof.  
4. **One‑agent case (n=1):** What is the axiomatization for a single agent with KD45? The paper notes that the n≥2 construction does not apply and the result for n=1 remains open.

## Limitations
- The reduction using Cn to at most n states is only fully justified for n=2; the general n case requires a rigorous extension.  
- The agent labeling scheme for n>2 (two alternating non‑trivial agents plus identity agents) is asserted without a complete formal proof that the union of relations equals the canonical one and that all agents satisfy KD45.  
- The model construction assumes a tree‑like (branching) structure; potential cycles that could arise in general KD45 frames are not fully addressed.

## Confidence
- **Soundness of CBₙ:** High (direct from KD45 properties).  
- **Completeness of CBₙ:** Medium (construction plausible but gaps remain for n>2).  
- **Exact axiomatization (CBₙ = KD4 + Cc + Cn):** Medium (depends on completeness).  
- **S4 variant for reflexive transitive closure:** High (straightforward adaptation).

## Next Checks
- Prove the reduction algorithm for arbitrary n: demonstrate that the iterative application of the Cn‑based merging always yields a set of ≤ n survivors that collectively cover every original X₀ witness.  
- Formalize the agent labeling for n>2: produce a rigorous argument that the alternating R₁/R₂ pattern together with identity agents for the remaining n‑2 indeed gives (⋃ᵢRᵢ)* equal to the canonical R̂ and that each agent’s relation is KD45.  
- Mechanize the entire construction (canonical model transformation, Cn reduction, agent assignment, KD45 verification, bisimulation) in a proof assistant (e.g., Coq or Isabelle) to eliminate residual doubts about soundness and completeness.
