# Alignment-Aware and Reliability-Gated Multimodal Fusion for Unmanned Aerial Vehicle Detection Across Heterogeneous Thermal-Visual Sensors

## Quick Facts
- **arXiv ID:** 2603.08208  
- **Source URL:** https://arxiv.org/abs/2603.08208  
- **Reference Count:** 0  
- **Primary Result:** RGMAF achieved 98.64% recall, outperforming traditional fusion methods on the MMFW-UAV dataset.

## Executive Summary
This study tackles the challenge of fusing heterogeneous thermal-visual sensor feeds for UAV detection, where mismatched resolutions and perspectives cause misalignment and unreliable integration. The authors propose two strategies: Registration-aware Guided Image Fusion (RGIF), which uses ECC-based affine registration and guided filtering to merge modalities while preserving thermal saliency and structural detail; and Reliability-Gated Modality-Attention Fusion (RGMAF), which adds a reliability-weighted attention mechanism to adaptively combine aligned inputs. Evaluated on the large-scale MMFW-UAV dataset (147,417 frames) with YOLOv10x, RGIF improved the visual-only baseline by 2.13% mAP@50 (97.65%), while RGMAF attained the highest recall (98.64%). Both methods surpass wavelet, Laplacian, and decision-level fusion, demonstrating robust cross-modal integration for real-time UAV detection.

## Method Summary
The core innovation lies in addressing sensor heterogeneity through explicit alignment and adaptive reliability assessment. RGIF first registers thermal and visual frames via Enhanced Correlation Coefficient (ECC) affine transformation, then applies guided filtering to the thermal image using the registered visual as guidance, preserving salient thermal signatures while inheriting structural details. RGMAF extends this by estimating per-modality reliability (e.g., based on sharpness or contrast) and employing a gated attention module to weight the features from each modality before fusion, all integrated with the registration step. The fused outputs are fed to YOLOv10x for detection.

## Key Results
- RGIF raised mAP@50 to 97.65%, a 2.13% gain over the visual-only baseline.
- RGMAF achieved the highest recall at 98.64%, indicating superior sensitivity to UAVs.
- Both strategies consistently outperformed traditional wavelet, Laplacine, and decision-level fusion benchmarks.

## Why This Works (Mechanism)
The methods succeed by directly confronting two failure modes in heterogeneous fusion: geometric misalignment and variable modality quality. ECC registration reduces spatial discrepancies that would otherwise cause ghosting or blur in naive fusion. Guided filtering in RGIF uses the higher-resolution visual guide to structure the thermal saliency map, preventing loss of small thermal targets. RGMAF’s reliability gate dynamically down-weights a modality when it is degraded (e.g., thermal blur or visual occlusion), preventing the fusion from being dominated by noisy inputs. The attention mechanism then learns to combine the most trustworthy features, yielding higher recall. This explicit modeling of alignment and reliability makes the fusion robust to the inherent noise and mismatch in real-world thermal-visual pairs.

## Foundational Learning
- **Multimodal Fusion:** Combines complementary data (thermal for heat signatures, visual for texture) to improve detection. *Why needed:* No single sensor is robust across all conditions; fusion increases coverage. *Quick check:* Does fused output retain distinct advantages of each modality?
- **Image Registration (ECC):** Estimates geometric transformation (affine) between misaligned images. *Why needed:* Heterogeneous sensors have different perspectives/resolutions; alignment is prerequisite for pixel-level fusion. *Quick check:* Measure average registration error on known correspondences.
- **Guided Filtering:** Edge-preserving smoothing that transfers structural details from a guide image to an input. *Why needed:* Thermal images are low-texture; guided filtering injects visual structural context without blurring thermal saliency. *Quick check:* Visually inspect if fused image shows sharp edges from visual modality on thermal targets.
- **Attention Mechanisms:** Learn to weight input features based on learned importance. *Why needed:* Sensor reliability varies per frame (e.g., fog affects visual more than thermal); attention adapts fusion dynamically. *Quick check:* Ablate attention module and measure performance drop under degraded conditions.
- **YOLO Detection:** Real-time object detector. *Why needed:* Provides end-to-end evaluation pipeline; YOLOv10x offers strong baseline for comparison. *Quick check:* Compare detection speed and accuracy on single-modality inputs before fusion.
- **Reliability Estimation:** Computes per-modality confidence (e.g., via gradient magnitude). *Why needed:* Prevents fusion from incorporating low-quality data that could degrade detection. *Quick check:* Correlate reliability scores with human judgment of image quality.

## Architecture Onboarding
**Component Map:**  
Thermal Input -> ECC Affine Registration <- Visual Input -> [RGIF Branch: Guided Filter -> Fusion] OR [RGMAF Branch: Reliability Estimation -> Modality-Attention -> Fusion] -> YOLOv10x -> Detection Output

**Critical Path:**  
1. Input acquisition (thermal & visual)  
2. ECC registration (aligns visual to thermal coordinate space)  
3. Branch-specific fusion (RGIF: guided filtering then pixel fusion; RGMAF: reliability gating then attention-weighted feature fusion)  
4. Detection with YOLOv10x  

**Design Tradeoffs:**  
- *ECC vs. Learning-based Registration:* ECC is fast and deterministic but fails on low-texture thermal images; learning-based methods are more robust but add computational cost and require training data.  
- *Pixel vs. Feature Fusion:* RGIF operates on pixel space (preserves raw information), while RGMAF fuses features (more flexible but loses interpretability).  
- *Reliability Gate Complexity:* Adding reliability estimation increases latency but yields higher recall in challenging conditions.

**Failure Signatures:**  
- Misalignment artifacts (ghosting, double edges) indicate ECC failure.  
- Over-reliance on one modality (e.g., thermal-only output) suggests reliability estimation is broken.  
- Blurred targets after fusion imply guided filtering parameters are mismatched.  
- Drop in FPS below real-time threshold (>30 FPS) if fusion overhead is too high.

**First Three Experiments:**  
1. **Registration Robustness Test:** Run ECC on all MMFW-UAV frames, categorize failures by thermal texture (low/medium/high), and measure detection performance drop in failure cases.  
2. **Component Ablation:** For RGMAF, disable reliability gate, then disable attention, then disable both, and compare mAP/recall to full model to quantify each contribution.  
3. **Latency Measurement:** Integrate RGIF and RGMAF into YOLOv10x inference pipeline, measure wall-clock time per frame on Jetson AGX Orin, and compute FPS relative to visual-only baseline.

## Limitations
- **Dataset Diversity Uncertainty:** The MMFW-UAV dataset size is large but its coverage of environmental conditions (weather, lighting, clutter) and sensor configurations is unspecified; generalization to unseen domains is unproven.
- **Registration Fragility:** Dependence on ECC affine registration risks failure on low-texture thermal images or extreme perspective shifts; failure rates are not reported.
- **Real-Time Claim Unverified:** No latency benchmarks are provided for the fusion modules; computational overhead versus detection speed remains unknown.
