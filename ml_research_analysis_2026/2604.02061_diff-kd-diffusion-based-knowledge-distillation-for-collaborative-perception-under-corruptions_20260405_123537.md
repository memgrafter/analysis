# Diff-KD: Diffusion-based Knowledge Distillation for Collaborative Perception under Corruptions
## Quick Facts
- arXiv ID: 2604.02061
- Source URL: https://arxiv.org/abs/2604.02061
- Reference count: 23
- Primary result: Diff-KD achieves state-of-the-art detection accuracy and robustness under seven corruption types, attaining the lowest mRCE (9.17% on OPV2V, 24.69% on DAIR-V2X) and outperforming prior methods in average AP@0.5/AP@0.7.

## Executive Summary
Collaborative perception systems for autonomous driving rely on sharing sensor data among agents, but they are vulnerable to sensor and communication corruptions. Diff-KD introduces a teacher-student framework that actively restores corrupted local features before fusion. The Progressive Knowledge Distillation (PKD) component uses conditional diffusion to denoise each agent’s corrupted local BEV features toward a teacher’s global view. The Adaptive Gated Fusion (AGF) module dynamically weights neighbor contributions based on the reliability of the ego agent’s perception. Evaluated on OPV2V and DAIR-V2X under seven physically-grounded corruptions, Diff-KD achieves superior detection accuracy and robustness, setting a new state-of-the-art with the lowest mean Relative Calibration Error (mRCE) across all corruptions.

## Method Summary
Diff-KD employs a teacher-student architecture. The teacher model processes early-fused clean point clouds from all agents to produce a global BEV feature \(F^T\), refines it with a Lite Gated Modulation (LGM) block to obtain \(F^{*T}\), and then generates classification and regression outputs \(c^T, r^T\). The student processes each agent’s (potentially corrupted) local point cloud independently to extract a BEV feature \(F^S_i\). Before fusion, \(F^S_i\) conditions a diffusion process that iteratively denoises a noisy version of \(F^T\) (Gaussian noise injected at a random timestep) to produce a refined feature aligned with the teacher’s global view. The refined features from all agents are fused using Adaptive Gated Fusion (AGF), which computes adaptive weights \(\omega_i\) through a lightweight network and applies a shared LGM block. The student’s fused feature \(F^S\) and predictions \(c^S, r^S\) are aligned with the teacher’s outputs via KL divergence losses. The total loss combines the diffusion loss \(L_{\text{diff}}\), post-distillation losses \(L_{\text{post\_kd}}\), and standard detection losses \(L_{\text{cls}}\) and \(L_{\text{reg}}\). Crucially, training uses only clean data; at inference, the student uses only its own corrupted local feature to drive the diffusion module (starting from random noise, no teacher access). Implementation follows OpenCOOD with Adam optimizer, learning rate 1e-3, 40 epochs, batch size 2, and 10 diffusion sampling steps.

## Key Results
- Diff-KD achieves state-of-the-art average precision (AP@0.5 and AP@0.7) on OPV2V and DAIR-V2X under all seven corruption types.
- It attains the lowest mean Relative Calibration Error (mRCE): 9.17% on OPV2V and 24.69% on DAIR-V2X.
- The student model can even outperform the teacher in detection accuracy, demonstrating the effectiveness of dynamic adaptation at inference.

## Why This Works (Mechanism)
Diff-KD works by leveraging a pre-trained teacher’s global, uncorrupted perspective as a target for restoration. The conditional diffusion module, conditioned on the agent’s own corrupted local feature, learns to map corrupted inputs toward clean, teacher-like representations. This effectively recovers semantics lost to corruption. Meanwhile, AGF uses the same local feature to estimate each agent’s reliability, adaptively weighting contributions during fusion so that highly corrupted agents have less influence. The combination ensures that both individual feature refinement and multi-agent aggregation are robust to corruptions, leading to superior detection performance.

## Foundational Learning
- **Diffusion Models**: Generative models that iteratively denoise data from random noise; needed here to perform conditional restoration of corrupted BEV features. Quick check: Can a diffusion model denoise a simple synthetic corrupted image patch when conditioned on a clean reference?
- **Knowledge Distillation**: Transfers knowledge from a larger teacher to a compact student via output/feature alignment; aligns student features with the teacher’s global view to imbue robustness. Quick check: Does KL divergence between student and teacher features decrease during training?
- **Collaborative Perception**: Multiple agents share sensory data to improve scene understanding; requires fusion mechanisms. Quick check: Does early fusion of clean multi-agent data outperform single-agent perception on the same task?
- **BEV Representations**: Bird’s-eye-view feature maps simplify 3D object detection; used as the fusion medium. Quick check: Can a PointPillars-style encoder produce consistent BEV features from varying numbers of points?
- **Adaptive Fusion**: Dynamically weights inputs based on reliability; counters corruption by down-weighting degraded sources. Quick check: Does the weighting network produce diverse weights when presented with inputs of varying quality?
- **Corruption Robustness**: Simulating realistic sensor/communication failures (e.g., fog, beam missing); essential for evaluating real-world viability. Quick check: Do the seven corruptions measurably degrade performance of a standard collaborative detection model?

## Architecture Onboarding
**Component map**  
Local LiDAR point cloud → Student Encoder → \(F^S_i\) → Diffusion Denoiser (conditioned on \(F^S_i\)) → Refined \(F^S_i\) → Adaptive Gated Fusion (AGF, with weighting network \(P(\cdot)\)) → LGM → Fused \(F^S\) → Detection Heads → Output.  
Teacher branch: All-agent clean point clouds → Early Fusion → \(F^T\) → LGM → \(F^{*T}\) →Teacher Detection Heads → Output. Losses: \(L_{\text{diff}}\), KL(\(F^S, F^{*T}\)), KL(predictions), \(L_{\text{cls}}\), \(L_{\text{reg}}\).

**Critical path**  
During inference, a corrupted local point cloud passes through the student encoder; its BEV feature conditions a 10-step diffusion process that starts from Gaussian noise and iteratively refines towards a teacher-like representation. The refined features from all agents are then fused via AGF, modulated by LGM, and fed to detection heads to produce output boxes and classes.

**Design tradeoffs**  
- Diffusion vs. efficiency: The iterative denoising (10 steps) improves robustness but increases inference latency compared to feed-forward refinement.  
- AGF complexity: The weighting network adds parameters and computation but enables per-agent, spatially-aware reliability assessment.  
- Teacher dependency: The teacher provides a high-quality target during training but requires clean multi-agent data for pre-training; the student operates independently at inference.  
- Clean-data training: The method avoids the need for corrupted training samples but relies on the diffusion model to generalize to unseen corruptions.

**Failure signatures**  
- Diffusion module fails to learn if \(L_{\text{diff}}\) does not decrease; check conditioning integration and network capacity.  
- AGF collapse to trivial weights (e.g., always 1 for ego) indicates the weighting network is not learning reliability signals; monitor weight distributions.  
- Large performance gap between reproduced and reported results may stem from mismatched corruption implementation; verify point cloud statistics against paper qualitatively.  
- Training instability (loss spikes, divergence) requires checking gradient norms, teacher detachment, and feature normalization.

**First three experiments**  
1. **Teacher baseline**: Train the teacher model on clean early-fused data and evaluate on both clean and corrupted test sets. This establishes an upper bound for clean conditions and a baseline for robustness.  
2. **PKD-only student**: Disable AGF (use mean pooling) and train the student with only the PKD losses. Isolate the effect of diffusion-based feature restoration on robustness.  
3. **Full Diff-KD with AGF**: Integrate AGF and compare against prior collaborative perception methods. Visualize agent weights to confirm adaptive behavior under different corruptions.

## Open Questions the Paper Calls Out
- **Why does the student outperform the teacher, and when does this happen?** The paper notes that the student can exceed teacher performance due to dynamic adaptation at inference, but does not disentangle whether this is caused by AGF, PKD, or their combination, nor test consistency across corruptions.
- **How can the computational cost of the diffusion process be reduced for real-time operation?** Diffusion models are typically slow; the paper uses 10 inference steps without runtime analysis or exploration of faster alternatives.
- **How does Diff-KD perform under compound or temporal corruptions?** Evaluations only consider seven single-corruption types; real-world scenarios often involve multiple overlapping or evolving corruptions, which remain untested.

## Limitations
- The diffusion architecture specifics (BiFPN-like UNet depth, channel dimensions, FiLM injection points) are not fully detailed, impairing exact replication.
- Corruption simulation parameters from Robo3D [12] are omitted, risking mismatched evaluation datasets.
- Critical training hyperparameters (loss weights, learning rate schedule, weight decay) are unspecified, leaving optimal configuration uncertain.

## Confidence
- PKD restores corrupted features via diffusion: Medium
- AGF enables adaptive, robust fusion: Medium
- SOTA detection accuracy under corruptions (AP@0.5/0.7): Low
- Lowest mean Relative Calibration Error (mRCE): Low

## Next Checks
1. **Corruption replication**: Implement the seven corruption transforms exactly as in Robo3D [12] and verify that key point cloud statistics (e.g., point count reduction for beam missing, noise for echo) match qualitative examples from the paper.
2. **Diffusion architecture ablation**: Train student models with variations in UNet depth (2–4 layers) and conditioning placement to identify configurations that achieve decreasing \(L_{\text{diff}}\) and qualitatively meaningful denoised features.
3. **Loss weighting sensitivity**: Perform a systematic search over weights for \(L_{\text{diff}}\), \(L_{\text{post\_kd}}\), \(L_{\text{cls}}\), and \(L_{\text{reg}}\) to determine whether the reported AP and mRCE are attainable and stable under the described training procedure.
