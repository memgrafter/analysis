# DisenReason: Behavior Disentanglement and Latent Reasoning for Shared-Account Sequential Recommendation

## Quick Facts
- arXiv ID: 2603.03782  
- Source URL: https://arxiv.org/abs/2603.03782  
- Reference count: 3  
- Primary result: DisenReason adaptively infers a dynamic number of latent users behind a shared account, achieving up to 12.56% relative improvement in MRR@5 over state-of-the-art.

## Executive Summary
DisenReason tackles the shared-account sequential recommendation (SSR) problem, where a single account may be used by multiple users with heterogeneous preferences. Unlike prior methods that assume a fixed number of latent users, DisenReason introduces a two-stage framework: first it disentangles the mixed behavior sequence via Fast Fourier Transform to extract frequency-based patterns, then adaptively fuses them into a unified account-level pivot. Second, from this pivot, it performs progressive residual reasoning to iteratively infer latent user representations until semantic similarity indicates termination. Evaluated on four benchmark datasets, DisenReason consistently outperforms state-of-the-art baselines, with relative gains up to 12.56% in MRR@5 and 6.06% in Recall@20, demonstrating the effectiveness of its adaptive modeling approach. The method’s key innovation lies in its frequency-domain disentanglement, which reveals distinct temporal rhythms of latent users, and its residual reasoning loop that uncovers a variable number of users without supervision.

## Method Summary
DisenReason comprises two stages. Stage One leverages LightGCN to incorporate global collaborative signals. The account’s interaction sequence is embedded and transformed into frequency domain via FFT. The frequency spectrum is split into equal-width sub-bands, each inverted back to time domain to yield distinct behavioral patterns representing latent user rhythms. An adaptive fusion mechanism learns to weight these patterns, producing a unified account-level pivot (the last state of the fused sequence). Stage Two initializes a reasoning state with a positional embedding added to the pivot. It then iteratively applies a disentanglement function φ (reusing Stage One’s operations) to extract a candidate user representation, subtracts it from the current state to obtain a residual, and checks cosine similarity between consecutive candidates. When similarity exceeds threshold α, reasoning stops. The final account representation aggregates all inferred user vectors, which are used to score candidate items. Training combines recommendation loss with an auxiliary loss on intermediate user vectors. The approach adaptively determines the number of latent users and handles overlapping behaviors effectively.

## Key Results
- Outperforms state-of-the-art sequential and shared-account recommenders on four datasets, with relative improvements up to 12.56% in MRR@5 and 6.06% in Recall@20.
- Demonstrates robust performance on both real shared-account datasets (HV-E, HV-V) and simulated ones (HA-M, HA-B), confirming its ability to model dynamic latent user counts.

## Why This Works (Mechanism)

### Mechanism 1: Frequency-Domain Behavior Disentanglement
**Claim:** Applying FFT to the shared-account sequence disentangles mixed behaviors into frequency sub-bands, each capturing a distinct behavioral rhythm corresponding to a latent user’s temporal pattern.  
**Mechanism:** FFT converts the time-domain sequence into frequency components. The mixed signal’s energy is distributed across frequencies; slicing the frequency axis into equal-width sub-bands yields relatively independent patterns. Inverse FFT (IFFT) then converts each sub-band back to time-domain representations, each reflecting a specific behavioral rhythm.  
**Core assumption:** Different latent users within a shared account exhibit distinct temporal frequencies (e.g., stable long-term vs. bursty short-term), and these frequencies are separable and non-overlapping in the spectral domain.  
**Evidence anchors:**  
- [abstract] “DisenReason combines behavior disentanglement stage from frequency-domain perspective to create a collective and unified account behavior representation.”  
- [section 5.1] “We posit that different latent users within a shared account also exhibit distinct temporal rhythms… These disentangled components each exhibit concentrated energy within their respective frequency bands, with minimal overlap.”  
**Break condition:** If behavioral patterns of latent users highly overlap in the frequency domain (e.g., similar interaction rhythms), disentanglement fails, leading to fused noise and degraded pivot quality.

### Mechanism 2: Adaptive Fusion for Unified Account Pivot
**Claim:** A Mixture-of-Experts-style adaptive fusion weights the disentangled frequency-based behavioral patterns to construct a unified account-level representation that serves as a reliable pivot for reasoning, rather than using the last item which only reflects one user.  
**Mechanism:** A fully connected layer generates softmax weights for each behavioral pattern. The fused sequence aggregates the patterns with weighted sum; its last hidden state is the pivot.  
**Core assumption:** Not all frequency sub-bands contribute equally to the account’s overall behavioral signal; the model can learn to weight informative patterns higher.  
**Evidence anchors:**  
- [abstract] “adaptively fuse them into a unified account-level pivot.”  
- [section 5.1] “Not all frequency components contribute equally… we learn the relative importance of different behavioral patterns and employ weight sum. yielding a comprehensive multi-behavior account sequential representation.”  
**Break condition:** If the fusion weights mislearn (e.g., over-weight noisy high-frequency patterns), the pivot becomes unrepresentative, harming downstream reasoning.

### Mechanism 3: Progressive Residual Reasoning with Adaptive Termination
**Claim:** Starting from the unified pivot, progressive residual reasoning iteratively infers latent user representations and subtracts each from the current state, terminating when consecutive inferred users are semantically similar, thereby adaptively inferring the actual number of latent users.  
**Mechanism:** Initial reasoning state r⁽⁰⁾ = pivot + positional embedding rᵖ. At step t: u⁽ᵗ⁾ = φ(r⁽ᵗ⁻¹⁾) (reuses disentanglement module), r⁽ᵗ⁾ = r⁽ᵗ⁻¹⁾ – u⁽ᵗ⁾. Terminate when cosine_sim(u⁽ᵗ⁾, u⁽ᵗ⁻¹⁾) > α.  
**Core assumption:** The account-level pivot contains superimposed signals of all latent users; subtracting an inferred user’s representation progressively isolates remaining users. Semantic similarity convergence indicates all users have been uncovered.  
**Evidence anchors:**  
- [abstract] “performing progressive residual reasoning from this pivot to iteratively infer latent users until semantic similarity terminates the process.”  
- [section 5.2] “The residual subtraction removes the identified user from the current state, enabling subsequent steps to focus on the remaining unexplained signals. The reasoning process terminates adaptively when consecutive inferred users become semantically similar, as this indicates that all latent users have been uncovered.”  
**Break condition:** If the reasoning function φ is not sufficiently discriminative, it may extract similar (redundant) user representations repeatedly, causing premature or incorrect termination.

## Architecture Onboarding
**Component map:**  
Embedding & LightGCN -> Sequence Lookup -> FFT Disentanglement -> Adaptive Fusion -> Progressive Reasoning -> Prediction

**Critical path:**  
Account sequence -> embeddings -> FFT -> sub-band IFFT -> fusion -> pivot -> iterative reasoning (residual updates) -> aggregation -> prediction.

**Design tradeoffs:**  
- Fixed bandwidth (B) vs. adaptive decomposition: Equal-width bands simplify but may miss fine-grained boundaries.  
- Single pivot vs. multiple pivots: One fused pivot reduces complexity but may blur user-specific signals; residual reasoning later attempts separation.  
- Shared reasoning function (φ) for both stages: Reuses disentanglement module for efficiency, but could blur objectives; mitigated by positional embedding rᵖ.

**Failure signatures:**  
- Pivot too noisy: if fusion weights poorly learned, reasoning starts from an unrepresentative signal.  
- Early termination: if α too high/stops too low, loop ends prematurely or over-reasons (T=1 or excessive T).  
- Residual collapse: if u⁽ᵗ⁾ extraction is inaccurate, subtraction removes wrong signal, corrupting next step.

**First 3 experiments:**  
1. **Overall performance (RQ1):** Compare against SR (SASRec, FMLP-Rec) and SSR (LightGC2N, DA-GCN) baselines on four datasets. Expected: DisenReason outperforms, especially on real shared-account data (HV-E/V).  
2. **Ablation study (RQ2):** Remove components: w/o LightGCN, w/o Behavior Disentanglement, w/o Adaptive Fusion, w/o Residual Operation. Expected: Disentanglement removal hurts most.  
3. **Hyperparameter sensitivity (RQ3):** Vary B (bandwidth), L (LightGCN layers), α (termination threshold), β (aux loss weight). Expected: optimal B~5, L~3, α~0.4–0.5, β~0.5–1.0.

## Limitations
- Stage Two reasoning function φ(·) applied to a single vector r⁽ᵗ⁻¹⁾ is ambiguous; exact implementation remains unspecified.  
- Fusion mechanism (FC on H_seq) lacks clarity on how it produces Z-dimensional weights (e.g., whether pooling precedes FC).  
- Fixed equal-width frequency bands may not align with actual user rhythms, risking incomplete disentanglement.
