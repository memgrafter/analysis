# Detecting Basic Values in A Noisy Russian Social Media Text Data: A Multi-Stage Classification Framework

## Quick Facts
- **arXiv ID:** 2603.18822  
- **Source URL:** https://arxiv.org/abs/2603.18822  
- **Reference Count:** 40  
- **Primary Result:** Multi-stage framework achieves F1-macro 0.83 and F1 0.71 on held-out test data for detecting Schwartz’s ten basic human values in Russian social media posts.

## Executive Summary
This study presents a scalable multi-stage pipeline for detecting Schwartz’s ten basic human values in noisy Russian social media data from VK. The framework filters spam, selects value-relevant posts using binary classifiers, employs GPT-4 to generate soft labels reflecting annotation agreement, and trains a partially fine-tuned XLM-RoBERTa-large model for multi-label classification. The best model aligns substantially with human expert judgments and demonstrates strong performance while revealing a systematic overestimation of the Openness to Change value domain. All models and code are released publicly.

## Method Summary
The pipeline begins with spam removal via rules and a weakly supervised SVM. Two binary classifiers—one for value-expressive posts (high recall) and another for political posts—are applied to a spam-free corpus, and their union yields a focused dataset (~1.1M posts). For a sample of 24k posts, GPT-4 is queried five times per value to produce soft labels based on agreement levels (1.0 for 4–5 agreements, 0.6 for 3 agreements, 0.0 otherwise). A transformer model (XLM-RoBERTa-large) is then trained with TF-IDF features, partial fine-tuning (top 2 layers unfrozen), and per-class threshold optimization to maximize F1-macro.

## Key Results
- Best multi-label model (XLM-RoBERTa-large) achieves F1-macro 0.83 and F1 0.71 on test data.
- GPT-4 soft labels show moderate-to-strong agreement with human experts (ICC up to 0.86) but systematically overestimate Openness to Change.
- Filtering concentrates value-relevant content: the final 1.1M posts represent 19.9% of Cyrillic texts and 30.8% of spam-free posts.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Using GPT-4 with repeated annotations and soft-label aggregation creates a scalable, uncertainty-aware training signal that aligns with human experts while accommodating annotation ambiguity.
- **Mechanism:** Five independent GPT-4 judgments per value per post are aggregated into soft labels (1.0 for 4–5 agreements, 0.6 for 3 agreements, 0.0 otherwise), preserving confidence gradations and avoiding forced binary ground truth.
- **Core assumption:** Aggregated GPT-4 judgments provide a consistent supervision signal approximating expert interpretation in a scalable manner.
- **Evidence anchors:** Abstract mentions soft labels; Section 3.4 details the protocol; Section 4.1.1 shows almost-unanimous GPT labels (4/5) achieve best F1 vs. expert majority; ICC up to 0.86 supports alignment.
- **Break condition:** If GPT-4 agreement patterns do not correlate with expert consistency (e.g., ICC < 0.5) or soft-label training fails to improve calibration relative to hard labels, the mechanism fails.

### Mechanism 2
- **Claim:** A staged filtering pipeline isolates a value-relevant subset from noisy social media, improving signal-to-noise ratio and efficiency for multi-label classification.
- **Mechanism:** Spam removal → value-expressive classifier (high recall) → political classifier → union. Each stage uses a lightweight classifier to progressively filter noise; the union targets posts where values might be expressed directly or contextually.
- **Core assumption:** Value expressions are sparse in organic social media; pre-filtering reduces false positives and computational cost for the final model.
- **Evidence anchors:** Abstract mentions filtering; Section 3.2 outlines the pipeline; Section 3.3 reports final dataset size (1.1M posts) and binary classifier F1 (value: 0.77, political: 0.82).
- **Break condition:** If the final model’s performance on the full unfiltered corpus is not significantly worse (e.g., F1-macro drop ≤0.1) or if targeted filtering causes high false negative rates, the staging is unnecessary or harmful.

### Mechanism 3
- **Claim:** A partially fine-tuned multilingual transformer (XLM-RoBERTa-large) effectively transfers to Russian social media value detection by balancing adaptation to domain specifics with retention of cross-linguistic semantic knowledge.
- **Mechanism:** XLM-RoBERTa-large’s 100-language pretraining captures cross-linguistic patterns; only the top 2 layers are fine-tuned, allowing adaptation to VK’s slang and informal style without catastrophic forgetting.
- **Core assumption:** Value-relevant linguistic cues share cross-linguistic structures; shallow tuning suffices to match the target genre’s lexical surface forms.
- **Evidence anchors:** Section 4.3.1 shows XLM-RoBERTa-large outperformed language-specific alternatives (e.g., RuRoBERTa-large 0.81 vs. 0.83 F1-macro); partial fine-tuning improved performance; Section 5 notes robustness from multilingual pretraining.
- **Break condition:** If a Russian-specific model with full fine-tuning significantly outperforms XLM-RoBERTa (e.g., F1-macro difference >0.05), the multilingual advantage is invalid. Here, RuRoBERTa-large underperformed.

## Foundational Learning
- **Schwartz’s Theory of Basic Human Values:** Provides the ten-value circumplex typology (e.g., Self-Direction, Conformity) that defines the classification task and guides interpretation of co-occurrence patterns. *Why needed*: Without the theoretical structure, label design, annotation guidelines, and validation (e.g., MDS) would lack coherence. *Quick check*: If a post expresses “pursuing personal freedom” and “seeking exciting experiences,” which adjacent values are likely co-occurring?
- **Multi-label Classification with Imbalanced, Sparse Data:** The task involves predicting up to ten binary labels per post with extreme class imbalance (e.g., Power present in ~8% of posts). *Why needed*: Drives choice of metrics (F1, F1-macro), threshold optimization, and modeling strategies to handle co-occurrence without assuming independence. *Quick check*: Why is F1-macro more appropriate than accuracy for this dataset?
- **Annotation Subjectivity and Soft Labeling:** Value expression is interpretive; expert agreement varies (Fleiss’ κ 0.27–0.75). *Why needed*: Soft labels preserve uncertainty from multiple annotations, preventing loss of information inherent in forced binary consensus. *Quick check*: What is a potential downside of using soft labels (e.g., 0.6) instead of binary labels?

## Architecture Onboarding
- **Component map:** Raw Data -> Spam Filter -> Value-Expressive Classifier -> Political Classifier -> Union Dataset -> Multi-label Annotation (GPT-4) -> Multi-label Model (XLM-RoBERTa-large) -> Validation.
- **Critical path:** Each stage depends on the previous stage’s output; any filtering error propagates to the training set quality and final model performance.
- **Design tradeoffs:**  
  - Recall vs. Precision in binary classifiers: Value-expressive classifier prioritized high recall to avoid missing rare value posts, accepting false positives later refined by the multi-label model.  
  - Soft vs. Hard Labels: Soft labels preserve annotator uncertainty but may blur decision boundaries; chosen to match subjective task nature.  
  - Model Size vs. Efficiency: Larger transformers (XLM-RoBERTa-large) gave best accuracy; smaller models (RuBERT-tiny) used for earlier stages for speed.
- **Failure signatures:**  
  - High false negative rate in value-expressive classifier would exclude many value posts, biasing prevalence estimates.  
  - Systematic GPT-4 bias (e.g., Openness overestimation) would be inherited by the model if uncorrected.  
  - Poor calibration (predictions compressed near 0.5) could reduce utility for thresholded applications.  
  - Low MDS congruence (r_c < 0.9) would indicate violation of Schwartz’s theoretical structure.
- **First 3 experiments:**  
  1. Spam filter validation: manually inspect 100 random spam vs. kept posts; aim for >90% precision on spam removal.  
  2. Binary classifier error analysis: review 100 false negatives and 100 false positives from the value-expressive classifier to identify error patterns.  
  3. Multi-label threshold sweep: plot F1-macro vs. threshold for each value on validation set to determine if per-class tuning is needed.

## Open Questions the Paper Calls Out
1. Why does GPT-4 systematically overestimate Openness to Change? Is it due to bias in training data, cultural framing mismatches, or interpretive differences (aspirational vs. preservative)?
2. Why does the derived value structure place Universalism closer to Conservation (Security/Tradition) rather than Self-Transcendence? Does this reflect a culturally specific Russian expression, an annotation artifact, or platform-specific discourse?
3. How do user engagement metrics (likes, reposts, comments) correlate with predicted value profiles? Could interaction data reveal implicit value norms or amplification effects?
4. To what extent do the personal values of human expert annotators influence their annotations, and could this explain discrepancies with GPT and the model’s systematic biases?
5. How does multimodal content (images, videos) affect value detection accuracy and expression? Can the text-only model be effectively extended to multimodal inputs?

## Limitations
- GPT-4 annotations may carry systematic biases (e.g., Openness overestimation) and rely on a proprietary model subject to change.
- The staged filtering pipeline lacks an ablation study; it might exclude valid value expressions, especially from non-political contexts.
- Performance on rare values (e.g., Power, Conformity) remains unclear due to extreme class imbalance.

## Confidence
- **Mechanism 1 (GPT-4 soft labels):** Medium – Empirical alignment (ICC ≤ 0.86) and improved calibration support it, but bias and model dependence reduce certainty.
- **Mechanism 2 (Staged filtering):** Medium – Binary classifiers show reasonable F1 (0.77–0.82), but no direct ablation leaves impact uncertain.
- **Mechanism 3 (XLM‑RoBERTa‑large):** High – Significantly outperformed alternatives; robust evidence from partial fine‑tuning.

## Next Checks
1. **Filtering ablation:** Train the multi-label model on an equal-sized random sample from the spam-free corpus (no value/political pre-filtering) and compare F1-macro to the published pipeline to quantify filtering contribution.
2. **GPT-4 reliability audit:** Compute ICC among the five GPT-4 runs per post for each value on a held-out set; if any value shows ICC < 0.7, revise prompts and re-annotate.
3. **Per-value performance analysis:** Report F1 scores for all ten Schwartz values on the test set; for values with F1 < 0.6, conduct error analysis to guide class-specific threshold tuning or data augmentation.
