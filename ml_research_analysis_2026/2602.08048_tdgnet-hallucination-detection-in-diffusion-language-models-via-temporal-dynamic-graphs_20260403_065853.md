# TDGNet: Hallucination Detection in Diffusion Language Models via Temporal Dynamic Graphs

## Quick Facts
- **arXiv ID:** 2602.08048
- **Source URL:** https://arxiv.org/abs/2602.08048
- **Reference Count:** 40
- **Primary Result:** TDGNet achieves average AUROC improvements of ~8% (up to 8.5%) over strong baselines for hallucination detection in diffusion LMs, with token-level AUROC reaching 0.87.

## Executive Summary
TDGNet introduces a novel framework for detecting hallucinations in diffusion language models (D-LLMs) by explicitly modeling the temporal evolution of token attention graphs across the denoising trajectory. Instead of analyzing a static final output or a single intermediate state, it constructs a sequence of sparse attention graphs at keyframed steps, maintains a persistent memory for each token updated via graph message passing and GRU cells, and aggregates this temporal memory with learned attention to produce robust per-token and sequence-level hallucination scores. Evaluated on LLaDA-8B and Dream-7B across multiple QA benchmarks, it consistently outperforms output-based, latent-based, and static-graph detectors, demonstrating that factual validity is a trajectory-dependent property best captured by dynamic graph reasoning.

## Method Summary
TDGNet processes the full generation trace of a diffusion LM by extracting per-step attention matrices and hidden states. At each keyframed denoising step, it builds a sparse directed token graph where edges represent significant attention weights. A spatial message-passing network aggregates information from each token’s neighborhood. A GRU-based memory module sequentially updates a persistent token state using these aggregated messages, effectively tracking each token’s evolving relational context. Finally, a temporal attention layer weighs the memory history to produce a final token embedding. These embeddings are pooled for sequence-level classification or used directly for token-level prediction, enabling single-pass inference at test time.

## Key Results
- Achieves consistent AUROC improvements over output-, latent-, and static-graph baselines across multiple QA datasets.
- Average gain of approximately 8% (up to 8.5%) in sequence-level AUROC on LLaDA-8B and Dream-7B.
- Token-level AUROC reaches up to 0.87, demonstrating fine-grained detection capability.
- Incurs only modest computational overhead compared to other single-pass alternatives.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Hallucinations in diffusion language models are dynamic events that unfold across the denoising trajectory, not static errors in the final output.
- **Mechanism:** The detector ingests the full sequence of intermediate attention graphs. Hallucinatory patterns—self-correction, semantic drift, persistence—manifest as specific evolutions in token attention topology over time. A single static snapshot cannot capture these dynamics.
- **Core assumption:** Factual validity is a *trajectory property* influenced by the generative path, not solely the final state.
- **Evidence anchors:**
  - [abstract] "factuality evidence is distributed across the denoising trajectory and may appear, drift, or be self-corrected over time."
  - [section 1] "hallucinations manifest as dynamic events... such as self-correction, late-stage drift, or persistence."
  - [section 4.3, Fig 3] Static models fail to capture strong early validity signals present in the trajectory.
  - [corpus] Adjacent work (TraceDet, DynHD) similarly frames hallucination as a trajectory phenomenon.
- **Break condition:** If a D-LLM’s generation process exhibits no temporal oscillation/drift (all hallucinations fixed at final output), modeling the trajectory provides no benefit over single-state analysis.

### Mechanism 2
- **Claim:** The evolving token-level attention graph is the optimal structural representation for tracking hallucination dynamics.
- **Mechanism:** At each step, a sparse directed graph is built (nodes=tokens, edges=significant attention). Graph structure (clique formation, hub stability, edge weight drift) encodes the model’s grounding. This explicitly captures bidirectional, global context interactions unique to diffusion.
- **Core assumption:** Attention pattern topology and its changes are more predictive of factual coherence than raw hidden states or output text statistics.
- **Evidence anchors:**
  - [section 3.2] Defines directed edge if token *i* attends significantly to token *j*, capturing "underlying structure in intermediate contexts."
  - [section 4.3, Table 4] Ablation removing graph edges (`N(i)=∅`) causes performance collapse to near-random.
  - [section 2, Related Work] Connects to GNNs and self-attention as a dynamic token graph.
- **Break condition:** If a D-LLM’s attention is noise-like or non-informative for factual grounding (weights don’t correlate with valid relationships), the graph representation fails.

### Mechanism 3
- **Claim:** A temporal memory mechanism (GRU-based) that sequentially updates per-token states via message passing is necessary to aggregate weak, distributed hallucination cues.
- **Mechanism:** Each token maintains memory `s_i`. At each keyframe, incoming messages from its sparse neighborhood are aggregated (MPNN) and used to update `s_i` via GRU. This creates a "running belief" integrating evidence across time. Final token embeddings `z_i` are formed by temporally attending over this memory history, weighing informative phases.
- **Core assumption:** The hallucination signal is temporally diffuse and weak at any single step; it requires accumulation and integration.
- **Evidence anchors:**
  - [section 3.3] GRU update: `s(t)_i = GRU(msg(t)_i, s(t+1)_i)`; temporal attention: `z_i = sum alpha(t)_i * Linear(s(t)_i)`.
  - [section 4.3, Table 2] Static single-snapshot graph variants (CHARM) underperform full temporal TDGNet (e.g., 0.661 vs 0.681 avg AUROC on LLaDA).
  - [section 4.3, Fig 3] Static models fail to capture strong early data consistency signals.
- **Break condition:** If all hallucinations manifest as strong, isolated, single-step events, temporal memory integration is unnecessary; a snapshot classifier suffices.

## Foundational Learning

- **Concept: Diffusion Language Model (D-LLM) Generation Process**
  - **Why needed:** TDGNet’s input is the *denoising trajectory*. Understanding iterative, parallel generation with bidirectional attention on a masked sequence is key to grasp why single-pass likelihood is intractable and why temporal dynamics exist.
  - **Quick check:** How does the token sequence state change from step `t` to `t-1` in a diffusion LM, and what role does bidirectional attention play at each step?

- **Concept: Graph Neural Networks (GNNs) & Message Passing**
  - **Why needed:** TDGNet processes each timestep’s attention graph using a Message Passing Neural Network (MPNN). Understanding node feature updates via neighbor aggregation (`Eq. 3`) is essential to model relational structure.
  - **Quick check:** In the MPNN equation `bar m_i = mean(psi(h_j, h_i, e_ji))`, what does each term represent in the context of an attention graph?

- **Concept: Temporal / Dynamic Graph Networks**
  - **Why needed:** The core innovation is treating the graph sequence as temporal, with persistent node memory (`s_i`) updated sequentially. This requires understanding state recurrence (GRU) and temporal attention over snapshots, distinct from static GNNs.
  - **Quick check:** What is the purpose of the GRU update (`Eq. 4`) in TDGNet, and how does it differ from processing each graph snapshot independently?

## Architecture Onboarding

- **Component map:**
  Trace Extractor -> Graph Sparsifier -> Temporal Graph Encoder (Spatial Module + Memory Module + Temporal Readout) -> Task Heads (Sequence-Level / Token-Level)

- **Critical path:**
  1. Run D-LLM generation to completion, saving full decoding trace (attention logs, hidden states) at `T_key = {T, T/2, T/4, 0}`.
  2. For each keyframe `t` in reverse order (`T → 0`):
     - Build sparse graph `G^(t)` from `A^(t,L)` via threshold `τ`.
     - Compute node features `h^(t)_i` (projected hidden state).
     - Perform message passing to get `bar m^(t)_i`.
     - Update GRU memory: `s^(t)_i = GRU(bar m^(t)_i, s^(t+1)_i)`.
  3. After processing all keyframes, for each token `i`: compute temporal attention weights `alpha^(t)_i` over `{s^(t)_i}` to aggregate `z_i`.
  4. Pool `z_i` -> `g` -> predict `hat y` via sequence head. Calculate loss and backpropagate through entire TDGNet encoder and classifier.

- **Design tradeoffs:**
  - **Sparsity Threshold `τ`:** Lower `τ` → denser graphs, more expressive but computationally heavier/noisier. Higher `τ` → sparser, more robust but may lose subtle connections. Paper uses fixed `τ` (not top-K) to allow natural topology evolution.
  - **Keyframe Sampling (`T_key`):** More steps → higher fidelity, captures finer dynamics, but more memory/compute. Fewer steps → efficient, but risks missing critical mid-trajectory events. Paper uses `{T, floor(T/2), floor(T/4), 0}` as compromise.
  - **Feature Dimension:** Projecting large hidden states (4096D) to smaller `d_v` (128D) reduces overhead but risks information loss. Requires search (Table 9).
  - **GRU State Dimension `d_m`:** Larger `d_m` increases memory capacity for long-term token dynamics but raises parameter count and over-smoothing risk.

- **Failure signatures:**
  - **High variance across static graph ablations (Table 2):** Performance varies wildly depending on which single step is used, confirming temporal modeling is essential and detector sensitive to snapshot choice.
  - **Collapse without message passing (Table 4):** AUROC drops to ~0.4-0.5 indicates model not using relational structure; reduced to bag-of-token-confidence classifier.
  - **Poor cross-dataset transfer (Table 5):** Scores fall near random (0.5) on distant target datasets (e.g., Math→Trivia), suggesting learned graph patterns are task-specific artifacts.
  - **Failure on Dream-7B despite success on LLaDA:** If model works on one D-LLM but fails on another with different noise schedules/architectures, it indicates overfitting to dataset-specific attention patterns.

- **First 3 experiments:**
  1. Replicate Core Temporal Benefit: Train TDGNet and static-graph counterpart (single graph from step `T/2`). Evaluate on LLaDA-8B across Math, CSQA, HotpotQA, TriviaQA. Expect TDGNet to outperform static on all, with largest gap on datasets where hallucinations involve drift (e.g., HotpotQA).
  2. Validate Message-Passing Necessity: Ablate by setting `N(i)=∅` (or self-loop only) so `bar m^(t)_i = 0`. Memory updates from `s^(t+1)_i` alone. Expect significant AUROC drop (as in Table 4).
  3. Test Keyframe Efficiency vs. Full Trajectory: Compare TDGNet (`T_key={T, T/2, T/4, 0}`) against variant using *every* step `t∈[0,T]`. Measure AUROC and wall-clock. Expect minimal performance loss (<1-2%) with keyframes.

## Limitations
- Evaluation covers only two D-LLMs (LLaDA-8B, Dream-7B), limiting external validity across architectures and noise schedules.
- Keyframe sampling strategy `{T, T/2, T/4, 0}` may omit critical mid-trajectory events.
- Does not quantify computational overhead relative to full-trajectory models, only stating it is "modest" versus single-pass alternatives.
- Attention graph sparsity threshold `τ` is fixed; optimal values likely vary by model and dataset.
- Token-level labeling process (heuristic based on final answer correctness) may miss subtle hallucinations or introduce noise.
- Field is nascent (neighbor FMR ~0.48, low citation counts), so findings may lack robustness across future D-LLM designs.

## Confidence
- **Mechanism 1 (Hallucination as trajectory property):** High confidence. Supported by multiple paper sections, figures, and corroborating recent work (TraceDet, DynHD).
- **Mechanism 2 (Attention graph as optimal representation):** Medium confidence. Ablation evidence (Table 4) is strong, but break condition—attention being noise-like—is untested and may apply to poorly trained/small D-LLMs.
- **Mechanism 3 (Temporal memory integration necessity):** Medium confidence. Static-vs-temporal ablations (Table 2) show clear gains, but gains are moderate (~2% AUROC avg). Break condition (isolated single-step hallucinations) could occur in some failure modes, reducing advantage.

## Next Checks
1. **Architectural Generalization Test:** Train and evaluate TDGNet on at least two additional D-LLMs with fundamentally different noise schedules (e.g., categorical diffusion vs. continuous-time) and pretraining corpora. Measure AUROC drop relative to LLaDA/Dream to quantify overfitting.
2. **Attention Topology Analysis:** For a held-out set of hallucinated vs. factual generations, compute graph metrics (clique count, hub stability, edge weight drift) per keyframe. Use statistical tests (e.g., t-test) to identify which metrics correlate strongest with hallucination type, validating the core graph assumption.
3. **Keyframe Density Ablation:** Compare TDGNet performance using keyframes at `{T, T/2, T/4, 0}` against (a) using all steps and (b) using only `{T, 0}`. Measure AUROC change and wall-clock inference time to empirically justify the chosen keyframe compromise.
