# Mitigating the Reasoning Tax in Vision-Language Fine-Tuning with Input-Adaptive Depth Aggregation

## Quick Facts
- **ArXiv ID:** 2603.26330
- **Source URL:** https://arxiv.org/abs/2603.26330
- **Reference count:** 40
- **Primary result:** IADA+LoRA improves reasoning by 9.5 points and perception by 3.3 points over LoRA-only with only 0.14M extra parameters on Qwen3-VL-2B.

## Executive Summary
Fine-tuning vision-language models (VLMs) for specific tasks often improves perception capabilities but degrades reasoning performance, a phenomenon termed the "reasoning tax." This work hypothesizes that the tax arises because fine-tuning disrupts the model's access to useful cross-layer representations. To address this, the authors propose Input-Adaptive Depth Aggregation (IADA), a lightweight module inserted between standard transformer blocks. IADA generates input-specific queries to retrieve and aggregate relevant features from earlier layers via a low-rank bottleneck, thereby complementing parameter-efficient fine-tuning (PEFT) methods like LoRA. Experiments on Qwen3-VL-2B show that combining IADA with LoRA substantially recovers reasoning ability while also boosting perception, adding minimal parameters.

## Method Summary
IADA is a plug-and-play module placed between transformer blocks in a VLM. For a given layer, it takes the current hidden states and generates modality-specific queries that are used to retrieve relevant features from all earlier layers. This retrieval operates through a low-rank bottleneck to maintain parameter efficiency. The aggregated cross-layer features are then merged with the original stream of the current layer. IADA is trained alongside a PEFT method like LoRA, allowing the model to adaptively preserve or restore cross-layer information that might be lost during standard fine-tuning. The design is input-adaptive, meaning the aggregation weights vary per input, and modality-specific, treating visual and textual tokens differently.

## Key Results
- IADA combined with LoRA improves the average reasoning score by 9.5 points and perception by 3.3 points over LoRA-only fine-tuning on Qwen3-VL-2B.
- The method adds only 0.14 million trainable parameters, demonstrating high parameter efficiency.
- Even a fixed (non-adaptive) version of cross-depth aggregation recovered most of the reasoning loss, supporting the core hypothesis about disrupted cross-layer access.

## Why This Works (Mechanism)
The core hypothesis is that reasoning in VLMs relies on integrating information across multiple layers (e.g., early visual details with later semantic abstractions). Standard fine-tuning, especially with PEFT, can distort or overwrite these cross-layer pathways, leading to a "reasoning tax." IADA explicitly restores access by allowing each layer to dynamically fetch useful signals from earlier layers based on the current input. The low-rank bottleneck ensures this retrieval is efficient and prevents the module from becoming a source of overfitting. By adaptively aggregating cross-layer features, IADA helps maintain the depth-wise consistency needed for complex reasoning while still allowing task-specific adaptation via LoRA.

## Architecture Onboarding
- **Component map:** Input Tokens -> [Transformer Block 1] -> IADA Module 1 -> [Transformer Block 2] -> IADA Module 2 -> ... -> Output  
- **Critical path:** Visual and textual tokens are processed sequentially through transformer blocks. At each block's output, the IADA module uses the current hidden states to generate queries that attend to all previous layers' hidden states via a low-rank projection. The retrieved context is added back to the current layer's output before passing to the next block.  
- **Design tradeoffs:** The low-rank bottleneck greatly reduces parameters but may limit the complexity of cross-layer mappings. Input-adaptivity adds minimal compute compared to a fixed aggregation. Inserting IADA after every block maximizes potential benefit but increases overhead; the paper likely uses a fixed depth (e.g., after certain layers).  
- **Failure signatures:** If earlier layers contain no useful features for the downstream task, IADA may add noise. An overly restrictive low-rank bottleneck could fail to capture necessary interactions. The module might also interfere with the original training dynamics if not carefully tuned.  
- **First experiments:** 1) Insert IADA at different depths (e.g., after every block vs. only later blocks) to measure optimal placement. 2) Vary the low-rank bottleneck dimension to assess the parameter-accuracy tradeoff. 3) Compare IADA against a non-adaptive version that uses fixed aggregation weights to isolate the benefit of input-adaptivity.

## Limitations
- Results are demonstrated on a single model (Qwen3-VL-2B); it is unclear if IADA generalizes to larger VLMs or different architectures (e.g., decoder-only models).
- Improvements are measured via aggregated benchmark scores; the specific reasoning sub-skills (e.g., mathematical, logical) that benefit most are not analyzed.
- The necessity of the low-rank bottleneck and the adaptive mechanism is not fully ablated; a simpler aggregation might suffice.

## Confidence
- **Core hypothesis** (fine-tuning disrupts cross-layer representations causing reasoning tax): Medium  
- **General efficacy** of IADA across architectures/datasets: Low-to-Medium  
- **Parameter-efficiency claim** (0.14M params for gains): High  

## Next Checks
1. **Cross-model replication:** Test IADA+LoRA on other popular VLMs (e.g., InstructBLIP, InternVL) using standard multimodal reasoning benchmarks (MMMU, ChartQA).
2. **Ablation of adaptive mechanism:** Compare IADA against a non-adaptive (fixed aggregation) variant and a version without the low-rank bottleneck to isolate each design choice's contribution.
3. **Representation analysis:** Probe intermediate layer features (with and without IADA) on a subset of reasoning samples to quantify changes in cross-modal alignment and depth-wise consistency.
