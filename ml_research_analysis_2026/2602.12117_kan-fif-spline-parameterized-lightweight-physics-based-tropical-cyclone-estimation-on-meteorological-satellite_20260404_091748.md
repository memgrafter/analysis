# KAN-FIF: Spline-parameterized Lightweight Physics-based Tropical Cyclone Estimation on Meteorological Satellite

## Quick Facts
- **arXiv ID:** 2602.12117  
- **Source URL:** https://arxiv.org/abs/2602.12117  
- **Reference count:** 40  
- **Primary result:** Spline-parameterized KAN framework reduces parameters by 94.8% and MSW MAE by 32.5% compared to Phy-CoCo, enabling feasible on-orbit inference at 14.41ms on FY-4 satellite processor.

## Executive Summary
KAN-FIF addresses the computational inefficiency of tropical cyclone intensity estimation on edge devices by introducing a spline-parameterized Kolmogorov-Arnold network (KAN) framework. It replaces conventional MLP/CNN layers with KAN layers that use learnable univariate spline functions, enabling high-order polynomial modeling with dramatically fewer parameters. Evaluated on the Tropical Cyclone Multi-Modal Dataset (TCMM), KAN-FIF achieves a 94.8% reduction in model size (0.99MB vs. 19MB), a 68.7% speedup in GPU inference (2.3ms vs. 7.35ms), and a 32.5% lower MAE for Maximum Sustained Wind (3.21 kt vs. 4.76 kt) relative to the physics-guided Phy-CoCo baseline. Offline deployment on a FY-4 satellite processor (Ascend 310 NPU) yields 14.41ms per-sample latency, validating its viability for operational on-orbit tropical cyclone monitoring.

## Method Summary
KAN-FIF is a hybrid architecture that integrates KAN layers into four key modules: (1) a shared encoder with separate temporal (LSTM followed by KAN projection) and spatial (multiscale CNN followed by KAN projection) branches; (2) a KAN-Attention module that encodes radial distances and annular-pooled cloud features for task-specific feature extraction; (3) a physics-guided constraint using bidirectional KAN-based residual corrections between the MSW and RMW prediction pathways; and (4) a KAN-based fusion decoder. For NPU deployment, the LSTM is replaced with an expanded KAN layer to ensure compatibility, and a two-stage pooling strategy is adopted. The model is trained using SGD with early stopping on a temporal split of TCMM (2015–2020 train, 2021–2022 test), leveraging 90° rotational data augmentation.

## Key Results
- Parameter efficiency: 0.99MB vs. 19MB (94.8% reduction)  
- Inference speed: 2.3ms vs. 7.35ms on GPU (68.7% faster)  
- Accuracy: MSW MAE reduced by 32.5% to 3.21 kt; RMW MAE also improved  
- Edge deployment: 14.41ms per-sample latency on FY-4 satellite processor (Ascend 310 NPU)

## Why This Works (Mechanism)
### Mechanism 1: Spline-Parameterized Efficiency
KAN layers replace linear weight matrices with learnable univariate spline functions (e.g., cubic splines with `grid_size=5`), enabling high-order polynomial interactions via Kolmogorov-Arnold decomposition with far fewer parameters. The core assumption is that target functions decompose well into low-degree splines on a coarse grid. Evidence: [abstract], [section 4.1]; ablation shows removing KAN from shared extractor increases MSW MAE by 13.7%. Break condition: if higher-degree polynomials are required, the fixed spline configuration may increase approximation error or parameter count.

### Mechanism 2: Physics-Guided Constraint
Bidirectional residual connections governed by KAN layers model cross-task coupling (e.g., wind-driven radius expansion, radius-modulated wind intensification) as polynomial corrections. The primary task features are preserved while KAN injects physical corrections. Core assumption: cross-task relationships are well-approximated as polynomials of task-specific features. Evidence: [section 4.4], [section 6.5.3] ablation (removing KAN from constraint increases MSW MAE by 17.1%, largest degradation). Break condition: non-polynomial relationships or insufficient spline order may introduce bias.

### Mechanism 3: KAN-Attention for Spatial Encoding
KAN layers replace linear+tanh projections in the attention mechanism, encoding radial distances (keys) and annular-pooled cloud features (queries/values) with spline nonlinearities to capture complex spatial patterns. Core assumption: mappings from spatial location/local features to TC attributes involve high-order interactions. Evidence: [section 4.3], [section 6.5.3] ablation (removing KAN from attention increases MSW MAE by 6.2%, RMW MAE by 1.4%). Break condition: predominantly linear relationships or overly simplistic splines may negate benefits.

## Foundational Learning
- **Kolmogorov-Arnold Theorem:** Justifies decomposition of any continuous multivariate function into compositions of univariate functions, forming the theoretical basis for KAN's parameter efficiency. *Quick check:* "What does the Kolmogorov-Arnold theorem state about representing multivariate functions?"
- **Spline Parameterization:** KAN edges use piecewise polynomial splines; `grid_size` controls intervals, `spline_order` controls polynomial degree, balancing flexibility and parameter count. *Quick check:* "How do `grid_size` and `spline_order` affect a KAN layer’s representation capacity?"
- **Edge-Based vs. Node-Based Activation:** Unlike MLPs (activations on nodes), KANs place learnable functions on edges, changing parameterization and enabling direct modeling of variable interactions. *Quick check:* "Where are the learnable parameters located in a KAN layer compared to an MLP layer?"

## Architecture Onboarding
Component map:  
Inputs (`X_seq`, `X_img`) -> Shared Encoder (Temporal: LSTM -> KAN projection; Spatial: Multiscale Conv -> KAN projection) -> Fusion (concat `F_shared`) -> Task-Specific Branches (Channel-7 image + `F_shared` -> KAN-Attention) -> Physical Constraint (bidirectional KAN residuals) -> Decoders (concat -> KAN) -> Outputs (`Ŷ_MSW`, `Ŷ_RMW`). Deployment variant: LSTM replaced by expanded KAN, static graph, FP16, two-stage pooling.

Critical path:  
1. `X_seq` → temporal feature `F_seq`.  
2. `X_img` → spatial feature `F_img`.  
3. `F_shared = concat(F_seq, F_img)`.  
4. Per-task: channel-7 image + `F_shared` → KAN-Attention → task feature.  
5. Task features → physics constraint → corrected features.  
6. Per-task concatenation (task feature, corrected other task feature, `F_shared`) → KAN decoder → prediction.

Design tradeoffs:  
- Parameter efficiency vs. expressivity: low `spline_order` (3) reduces parameters but limits polynomial degree.  
- Training vs. deployment: LSTM improves temporal modeling but NPU-incompatible; removal incurs ~13% MAE increase.  
- Physical constraints: KAN-based coupling improves accuracy with minimal overhead.  
- Multimodal fusion: shared features reduce redundancy but may lose task nuances; attention mitigates.

Failure signatures:  
- Poor test MAE: spline order too low, insufficient training, missing temporal context.  
- NPU conversion failure: unsupported operators (e.g., LSTM); solved by static graph and operator replacement.  
- Memory overflow: model too large for 8GB LPDDR4; mitigated by compression (KAN-FIF-s: 0.22M params).  
- Overfitting: training loss << validation loss; addressed via early stopping and augmentation.

First three experiments:  
1. **Baseline reproduction:** Train Phy-CoCo and KAN-FIF on TCMM; compare MAE/RMSE and GPU inference time.  
2. **Ablation study:** Train variants with KAN removed from each stage (shared extract, attention, constraint, decoder) to quantify contributions.  
3. **Deployment test:** Convert KAN-FIF to OM format via Huawei CANN, deploy on Qingyun-1000 (Ascend 310 NPU), measure latency and memory.

## Limitations
- Major unknowns: exact KAN hyperparameters (`grid_size`, `spline_order`) per layer; deployment architecture details (LSTM replacement, two-stage pooling); public availability of TCMM dataset and precise preprocessing.  
- Weak external validation: neighboring papers do not support KAN for cyclone estimation; Kolmogorov-Arnold basis for polynomial decomposition lacks external empirical evidence.

## Confidence
- **High:** GPU-based parameter count, inference time, and MAE reduction vs. Phy-CoCo are reproducible with provided code and dataset.  
- **Medium:** Mechanistic role of KAN in physics constraint (ablation shows 17.1% MSW MAE degradation) supported internally but not externally.  
- **Low:** 14.41ms NPU latency claim depends on proprietary hardware/toolchains (Ascend 310, Huawei CANN), infeasible for independent verification.

## Next Checks
1. Reproduce baseline metrics: train full KAN-FIF on TCMM, report test MAE/RMSE, parameter count, GPU inference time to confirm gains over Phy-CoCo.  
2. Verify ablation contributions: re-run partial ablations (removing KAN from shared extractor, attention, constraint, decoder) to validate reported impact, especially constraint's 17.1% on MSW.  
3. Compare deployment variant: implement LSTM-free architecture (flattened sequence → expanded KAN) and measure MAE/inference time against training version to quantify deployment penalty.
