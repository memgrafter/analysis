# NeuroSkill(tm): Proactive Real-Time Agentic System Capable of Modeling Human State of Mind

## Quick Facts
- arXiv ID: 2603.03212
- Source URL: https://arxiv.org/abs/2603.03212
- Reference count: 40
- Primary result: A functional, open-source edge system that models human state of mind from BCI signals to drive proactive, empathetic agent behavior in real-time while preserving privacy.

## Executive Summary
NeuroSkill introduces a real-time agentic system that models a user's state of mind from non-invasive BCI signals and text, enabling proactive adaptation without cloud dependency. The system combines a foundation EXG model (ZUNA) for embedding BCI data, multimodal alignment with text embeddings, and an LLM agent (NeuroLoop) that consults editable SKILL.md policies to trigger context-sensitive actions. Demonstrated in education and gaming use cases, the system operates entirely offline on the edge, ensuring privacy. While functional, key aspects like the EXG model details and alignment parameters remain opaque, limiting full reproducibility.

## Method Summary
The system comprises two main components: the NeuroSkill app and the NeuroLoop harness. NeuroSkill acquires raw EXG/EEG signals from wearable BCI devices (e.g., Muse 2), preprocesses them, and uses the ZUNA foundation model to generate embeddings representing the user's cognitive/affective state. These embeddings, along with optional text input, are made available via a local API/CLI. NeuroLoop runs an LLM agent (e.g., via Ollama) that periodically queries the NeuroSkill API for the current state, consults user-defined SKILL.md policy files (which map state patterns to actions), and decides on tool calls (e.g., TTS, notifications) to proactively engage the user. Multimodal alignment between EXG and text spaces is achieved using UMAP for semantic search/indexing within the Brain Nebula interface. The entire pipeline runs offline on the edge.

## Key Results
- Functional open-source implementation (GPLv3/AI100) demonstrating real-time empathetic engagement, such as detecting sadness from brain data and initiating a calming protocol.
- Validated across use cases including education and gaming.
- Privacy preserved through local, air-gapped operation with no cloud dependency.

## Why This Works (Mechanism)
The system works by creating a closed-loop, real-time feedback mechanism between the user's physiological state and the agent's behavior. The foundation EXG model (ZUNA) provides a dense, learned representation of brain signals that correlates with cognitive and affective states. By aligning these EXG embeddings with a text embedding space (via UMAP), the system can interpret neural states in semantic terms (e.g., "sadness") that are meaningful for policy specification. The NeuroLoop harness continuously polls the state API, matches the current state against conditions in SKILL.md files, and triggers predefined actions when thresholds are met. Operating entirely on the edge eliminates latency and privacy concerns, while the modular CLI/API design allows flexible policy customization without retraining the core models.

## Foundational Learning
- **Foundation EXG Model (ZUNA)**: Converts raw biosignals into latent embeddings capturing neural correlates of state. *Why needed*: Provides a compact, informative representation for downstream tasks. *Quick check*: Apply to a standard EEG dataset (e.g., PhysioNet) and verify separation of known conditions (eyes-open vs. closed) via PCA.
- **Multimodal Alignment (UMAP)**: Maps EXG embeddings into a shared space with text embeddings to enable semantic querying. *Why needed*: Allows policies to reference states using natural language (e.g., "when focused"). *Quick check*: On a paired EEG-text dataset, compute alignment metrics (trustworthiness) and visualize neighbor preservation.
- **Agentic Workflow (NeuroLoop)**: LLM-driven controller that interprets state and executes actions based on SKILL.md. *Why needed*: Provides flexible, proactive decision-making without hard-coded rules. *Quick check*: Simulate a state transition (e.g., high theta) and observe if corresponding tool call (e.g., `say("Relaxed")`) is invoked.
- **Edge LLM (Ollama)**: Local inference engine for the agent. *Why needed*: Ensures privacy, low latency, and offline operation. *Quick check*: Run a simple prompt locally and measure response time; verify no external network calls.
- **Skill Policy Files (SKILL.md)**: Markdown-based rules defining state-action mappings. *Why needed*: Enables end-users to customize agent behavior without programming. *Quick check*: Create a rule with a clear condition (e.g., `if: ...`) and confirm it triggers as expected.

## Architecture Onboarding
- **Component Map**: BCI Device (Muse 2) -> NeuroSkill App (acquisition, preprocessing, ZUNA embedding) -> NeuroSkill API (CLI/HTTP) -> NeuroLoop Harness (LLM agent, SKILL.md parser, tool executor) -> Output Devices (TTS, notifications). Optional: Brain Nebula interface for alignment visualization.
- **Critical Path**: Signal acquisition -> preprocessing -> EXG embedding -> state update -> NeuroLoop poll -> SKILL.md matching -> tool call. Latency-sensitive steps are the embedding inference and polling interval.
- **Design Tradeoffs**: 
  - Edge vs. cloud: Edge ensures privacy and low latency but limits model size and context window.
  - UMAP alignment: Provides efficient search but may introduce non-linear distortions; parameters not tuned.
  - BCI dependency: Signal quality heavily influences reliability; user preparation (electrode contact) is critical.
- **Failure Signatures**:
  - High noise in NeuroSkill UI spectrogram, low SNR values: likely poor electrode contact or movement artifacts.
  - NeuroLoop logs show "no matching rule": state may not meet any SKILL.md condition; check threshold values.
  - Tool calls timeout: may indicate GPU memory exhaustion from large alignment queries; reduce time window size.
- **First Experiments**:
  1. Install NeuroSkill and NeuroLoop, connect a Muse 2, and verify live signal plotting and API status (`neuroskill status`).
  2. Create a SKILL.md with a simple high-confidence trigger (e.g., high alpha power -> `say("Relaxed")`), start NeuroLoop, and induce the state (e.g., close eyes) to confirm tool call.
  3. Measure end-to-end latency from state change to action using a stopwatch or log timestamps; adjust polling interval and embedding window to meet responsiveness goals.

## Limitations
- The foundation EXG model (ZUNA) architecture, preprocessing pipeline, and weights are not disclosed, hindering verification of the core signal representation.
- Multimodal alignment parameters (UMAP settings, text embedding model) and training data are unreported, making the semantic grounding irreproducible.
- Hardware/driver dependencies for BCI devices (e.g., Bluetooth stability) and their impact on real-time performance are not quantified.
- Skill policy scalability for complex, multi-state sequences and conflict resolution is unvalidated.

## Confidence
- System architecture & offline operation: High
- Real-time proactive triggering: Medium
- Empathetic engagement efficacy: Low
- Privacy via local operation: High
