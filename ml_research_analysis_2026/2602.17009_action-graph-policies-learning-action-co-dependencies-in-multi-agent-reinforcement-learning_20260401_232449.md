# Action-Graph Policies: Learning Action Co-dependencies in Multi-Agent Reinforcement Learning
## Quick Facts
- arXiv ID: 2602.17009
- Source URL: https://arxiv.org/abs/2602.17009
- Reference count: 40
- Primary result: Action-Graph Policies (AGP) achieve 80-95% success on canonical coordination tasks, vastly outperforming baselines (10-25%), by modeling action dependencies via a learned graph.

## Executive Summary
The paper addresses the policy-side bottleneck in decentralized multi-agent reinforcement learning (MARL), where independent policies cannot express coordinated joint actions required by many tasks. It proposes Action-Graph Policies (AGP), which model dependencies among all (agent, action) pairs through a learned global action graph. Each agent conditions its policy on a coordination context summarizing global action relationships, enabling compatible joint behavior while preserving decentralized execution. Theoretically, AGP strictly enlarges the expressive joint policy class and yields lower KL divergence to optimal centralized policies compared to independent execution. Empirically, AGP dramatically improves success rates on coordination tasks with partial observability and anti-coordination penalties, demonstrating that embedding action-level coordination resolves fundamental limitations of existing decentralized MARL approaches.

## Method Summary
AGP constructs a graph whose nodes are individual (agent, action) pairs and edges encode coordination-relevant dependencies. Multi-head graph attention propagates information across the graph, updating node embeddings. Each agent then aggregates the embeddings of its own actions via permutation-invariant pooling to produce a coordination context κ_i. The agent’s policy π_i(a_i|o_i, κ_i) selects actions based on its local observation and this context, enabling decentralized execution of globally coordinated behavior. Training integrates with standard MARL frameworks like MADDPG, with the action graph learned centrally to generate contexts.

## Key Results
- AGP achieves 80-95% success on challenging coordination benchmarks (e.g., Top-K selection), while independent policies and other MARL baselines attain only 10-25%.
- Theoretical analysis proves AGP’s joint policy class strictly contains that of independent policies and yields lower KL divergence to optimal centralized policies.
- Across diverse multi-agent particle environments, AGP consistently outperforms baselines, validating the action-graph approach for embedding coordination.

## Why This Works (Mechanism)
AGP works by explicitly modeling dependencies among all (agent, action) choices through a global graph. This graph allows information about how one agent’s action affects others to propagate, producing coordination contexts that summarize global constraints for each agent. Unlike independent policies, AGP’s factorization enables marginal dependence between agents’ actions, capturing coordination patterns like “exactly K agents must activate.” The attention mechanism discovers relevant pairwise interactions from reward signals, and the context pooling provides each agent with a sufficient statistic for compatible decision-making. Theoretical guarantees confirm that this approach expands expressive power and approximates centralized behavior more closely than independent factorization.

## Foundational Learning
- **Independent Policy Factorization**: The standard decentralized approach where each agent acts independently. Needed to contrast AGP’s breakthrough; quick check: independent policies cannot achieve success probability 1 in “exactly K out of N” games due to binomial limitations.
- **Value Decomposition and Greedy Execution**: Centralized training with decentralized execution often suffers from value-policy mismatch. Needed to highlight why policy-side changes are essential; quick check: a perfect centralized Q_tot does not guarantee independent greedy selection recovers the optimal joint action.
- **Graph Neural Networks and Attention**: Foundation for AGP’s action graph. Needed to understand how coordination contexts are learned; quick check: in multi-head attention, coefficients are computed from query-key dot products, exponentiated, and softmax-normalized over neighbors.

## Architecture Onboarding
Component map: Encoder (ϕ) -> Action graph nodes (initial features) -> Message-passing (attention layers) -> Updated node embeddings -> Coordination context pooling (per-agent κ_i) -> Local Q-network -> Action selector.

Critical path:
1. For each agent i and action a, compute x_i^a = ϕ(o_i, a).
2. Assemble global node set V and apply L attention layers to obtain h_i^a.
3. For each agent, mask invalid actions and pool its action embeddings to get κ_i.
4. Each agent computes Q_i(o_i, κ_i) and selects a_i (e.g., ϵ-greedy).
5. Execute joint action a_t.

Design tradeoffs:
- Graph connectivity: Fully connected maximizes dependencies but scales as O(N²|A|²); sparsification reduces compute but may miss long-range signals.
- Attention capacity: More heads/layers increase expressivity but risk overfitting and memory use.
- Pooling operator: Mean pooling is simple but may dilute extreme values; max or attention-based pooling could preserve salient distinctions.
- Encoder sharing: Shared ϕ is parameter-efficient; separate encoders allow specialization at higher cost.
- Recurrence: Adding temporal history (e.g., GRU) helps partial observability but adds sequential complexity.

Failure signatures:
- No improvement over independent baselines: Check attention weights; uniform/diagonal patterns indicate failed cross-agent learning.
- Training instability: Diverging Q-values or high gradient variance may require lower learning rate or gradient clipping.
- Scaling issues: Memory grows quadratically; consider sparsity when N or |A| is large.
- Overfitting to training modes: High training success but low test generalization suggests lack of diversity in κ_i; add dropout or data augmentation.

First experiments:
1. Top-K Selection (N=6, K=2): AGP should exceed 90% success, independent methods ~33%. Validates cardinality constraint handling.
2. Top-K with Anti-Coordination Penalty: Tests robustness to relative overgeneralization; AGP expected ~96% success, baselines collapse.
3. Speaker-Listener (MPE): Continuous-state/action communication task; AGP should achieve higher returns than baselines, proving scalability beyond one-shot games. Ablation: removing cross-agent edges should eliminate gains, confirming action-dependency role.

## Limitations
- Scalability of fully connected action graphs may force sparsification that discards necessary long-range dependencies in large-scale problems.
- Attention-based dependency discovery might fail for coordination requiring higher-order (beyond pairwise) interactions or temporally extended constraints.
- Fixed context pooling (e.g., mean) may be insufficient if coordination requires conditioning on other agents’ actual actions rather than a precomputed summary.
- Theoretical expressivity may not be realized due to optimization challenges like local optima or poor gradient signal for the action graph.
