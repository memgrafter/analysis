# Online Realizable Regression and Applications for ReLU Networks

## Quick Facts
- **arXiv ID:** 2602.19172  
- **Source URL:** https://arxiv.org/abs/2602.19172  
- **Reference count:** 40  
- **Primary result:** For any \(c\)-approximate pseudo-metric loss, the scaled Littlestone dimension of a hypothesis class \(\mathcal{H}\) is bounded by \(O(c)\cdot\Phi(\mathcal{H})\), where \(\Phi(\mathcal{H}) = \int_0^{\operatorname{diam}(\mathcal{H})} \log N(\mathcal{H},\varepsilon)\,d\varepsilon\) is an entropy potential. This yields horizon‑free realizable cumulative loss bounds for classes with polynomial metric entropy. Applications include a sharp phase transition for Lipschitz regression under \(\ell_q\) (finite iff \(q > d\)) and finite bounds for bounded‑norm ReLU networks under squared loss (e.g., \(\widetilde{O}(k^2)\) for width‑\(k\) shallow networks, \(O(1)\) for a single ReLU), while classification with \(0/1\) loss is impossible for two neurons even in one dimension.

## Executive Summary
The paper studies online realizable regression when the loss satisfies an approximate triangle inequality. It introduces an *entropy potential* \(\Phi(\mathcal{H})\) that upper bounds the *scaled Littlestone dimension* \(D_{\text{onl}}(\mathcal{H})\), the latter characterizing the minimax realizable cumulative loss up to constants. The key theorem shows \(D_{\text{onl}}(\mathcal{H}) \le 4c\cdot\Phi(\mathcal{H})\) for any \(c\)-approximate pseudo‑metric loss. Consequently, hypothesis classes with polynomial metric entropy—such as Lipschitz functions on a bounded domain or bounded‑norm ReLU networks—admit horizon‑free loss bounds. The theory reveals a sharp dichotomy for regression of Lipschitz functions under power losses \(\ell_q\): finite bounds when \(q > d\) and infinite otherwise. For bounded ReLU networks, regression under squared loss (appropriately clipped) enjoys nontrivial information‑theoretic bounds (\(\widetilde{O}(k^2)\) for width \(k\), even constant for a single ReLU), whereas classification via \(0/1\) loss already has infinite Littlestone dimension for two hidden units. The work highlights a gap between information‑theoretic feasibility and computational efficiency: generic bounds are non‑constructive, and efficient proper learners are ruled out under Gap‑ETH for certain regimes.

## Method Summary
The core method is an *entropy potential* technique. For a hypothesis class \(\mathcal{H}\) and a loss \(\ell\) that is a \(c\)-approximate pseudo‑metric, define the entropy potential \(\Phi(\mathcal{H}) = \int_0^{\operatorname{diam}(\mathcal{H})} \log N(\mathcal{H},\varepsilon)\,d\varepsilon\), where \(N(\mathcal{H},\varepsilon)\) is the \(\varepsilon\)-covering number under the sup‑pseudo‑metric \(d_\ell(f,g) = \sup_x \ell(f(x),g(x))\). The proof of \(D_{\text{onl}}(\mathcal{H}) \le 4c\Phi(\mathcal{H})\) proceeds by constructing a branch in any realizable scaled Littlestone tree. At a node with gap \(\gamma\), any \(\varepsilon\)-cover must split across the children when \(\varepsilon < \gamma/(2c)\); integrating this splitting requirement over all scales \(\varepsilon\) yields a total gap along the branch bounded by \(4c\Phi(\mathcal{H})\). To apply the framework, one estimates \(\Phi(\mathcal{H})\) via metric entropy bounds. For Lipschitz functions on \([-1,1]^d\) under \(\ell_q\), covering numbers are polynomial in \(1/\varepsilon\) with exponent \(\sim d/q\), so \(\Phi(\mathcal{H})\) converges iff \(q > d\). For bounded ReLU networks, the analysis decomposes the tree into large‑gap nodes (controlled by fat‑shattering dimension) and small‑gap nodes (controlled via the entropy integral and Euclidean covers of the parameter space). The resulting bounds are information‑theoretic; efficient algorithms are known only for special cases (e.g., single ReLU, Lipschitz envelope predictor).

## Key Results
- **Theorem 1.1 (Entropy bound):** For any \(c\)-approximate pseudo‑metric loss, \(D_{\text{onl}}(\mathcal{H}) \le 4c\cdot\Phi(\mathcal{H})\).
- **Corollary 1.2 (Polynomial entropy ⇒ finite bound):** If \(\log N(\mathcal{H},\varepsilon) \le p\log(A/\varepsilon)\) for \(\varepsilon \le 1\), then \(D_{\text{onl}}(\mathcal{H}) = O(c p \log A)\) and there exists a deterministic online algorithm with cumulative loss at most \(D_{\text{onl}}(\mathcal{H}) + \varepsilon\).
- **Theorem 1.3 (Lipschitz regression phase transition):** For \(L\)-Lipschitz \(f:[-1,1]^d\to[0,1]\) under \(\ell_q\), \(D_{\text{onl}}(\mathcal{H}) < \infty\) iff \(q > d\); if \(q>d\) then \(D_{\text{onl}}(\mathcal{H}) = \Theta(L^d)\) and an efficient proper predictor achieves it; if \(q \le d\) then \(D_{\text{onl}}(\mathcal{H}) = \infty\).
- **Theorem 1.5 (Classification impossibility):** For ReLU networks with at least two hidden units, the Littlestone dimension under \(0/1\) loss is infinite already in one dimension.
- **Theorems 1.6, 1.7 (ReLU regression bounds):** For bounded‑norm ReLU networks under squared loss (clipped to be approximate pseudo‑metric), \(D_{\text{onl}}(\mathcal{H}) = \widetilde{O}(k^2)\) for shallow width‑\(k\) networks, and even \(O(1)\) for a single ReLU independent of ambient dimension.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** The entropy potential \(\Phi(\mathcal{H})\) upper bounds the scaled Littlestone dimension \(D_{\text{onl}}(\mathcal{H})\) for any \(c\)-approximate pseudo‑metric loss.
- **Mechanism:** In a realizable scaled Littlestone tree, at each node with gap \(\gamma\), \(\varepsilon\)-covers of the version space must split across children when \(\varepsilon < \gamma/(2c)\) (Lemma 3.2). Integrating the required splits over all \(\varepsilon\) yields a potential drop at least proportional to \(\gamma\) per step; greedy descent then constructs a branch with total gap \(\le 4c\Phi(\mathcal{H})\) (Theorem 3.1).
- **Core assumption:** \(\ell\) is a \(c\)-approximate pseudo‑metric and \(\operatorname{diam}(\mathcal{H}) < \infty\).
- **Evidence anchors:** Theorem 3.1, Lemma 3.2.
- **Break condition:** \(\Phi(\mathcal{H}) = \infty\) (e.g., super‑polynomial covering numbers).

### Mechanism 2
- **Claim:** Polynomial metric entropy—\(\log N(\mathcal{H},\varepsilon) \le p\log(A/\varepsilon)\)—implies \(\Phi(\mathcal{H}) < \infty\) and thus a horizon‑free realizable cumulative‑loss bound.
- **Mechanism:** Substituting the covering bound into \(\Phi(\mathcal{H}) = \int_0^1 \log N(\mathcal{H},\varepsilon)\,d\varepsilon\) gives \(p\int_0^1 \log(A/\varepsilon)\,d\varepsilon = p(\log_2 A + 1/\ln 2) < \infty\) (Corollary F.1). Combined with Theorem 1.1, \(D_{\text{onl}}(\mathcal{H})\) is finite.
- **Core assumption:** Covering numbers are polynomially bounded in \(1/\varepsilon\) for \(\varepsilon \le 1\).
- **Evidence anchors:** Corollary 1.2, Appendix G.
- **Break condition:** If \(\log N(\mathcal{H},\varepsilon)\) grows faster (e.g., \(\asymp \varepsilon^{-p}\) for \(p \ge 1\)), then \(\Phi(\mathcal{H}) = \infty\).

### Mechanism 3
- **Claim:** For bounded‑\(k\) ReLU networks, regression under squared loss admits nontrivial bounds, while classification with \(0/1\) loss is impossible.
- **Mechanism (regression):** Decompose any shattered tree into large‑gap and small‑gap nodes. Large gaps are controlled via sequential fat‑shattering dimension bounds (Lemma C.5, Proposition C.6). Small gaps are scaled and bounded via the entropy potential and Euclidean covers of the parameter space (Lemma C.8, Proposition C.11).  
  **Mechanism (classification):** The Littlestone dimension is infinite because two ReLU neurons can shatter arbitrarily large trees with discrete labels (Theorem 1.5).
- **Core assumption:** For regression, \(\ell\) is an approximate pseudo‑metric (e.g., squared loss with clipping). For classification, \(\ell_{0/1}\) violates the approximate triangle condition.
- **Evidence anchors:** Theorem 1.5 (classification), Theorems 1.6/1.7 (regression), Appendix C.
- **Break condition:** For regression, if depth \(L\) or width \(k\) is unbounded, \(\Phi(\mathcal{H})\) may depend unfavorably (e.g., polynomial in \(kd\)). For classification, the Littlestone dimension is inherently infinite.

## Foundational Learning
- **Concept:** \(c\)-Approximate Pseudo‑Metric Loss  
  **Why needed:** Ensures the triangle inequality holds approximately, which is essential for the potential method to work across scales.  
  **Quick check:** For \(\ell_q(y,y') = |y-y'|^q\), the minimal \(c\) is \(2^{q-1}\).
- **Concept:** Scaled Littlestone Dimension \(D_{\text{onl}}(\mathcal{H})\)  
  **Why needed:** Abstract complexity measure that characterizes the minimax realizable cumulative loss up to constant factors for any \(c\)-approximate loss.  
  **Quick check:** \(D_{\text{onl}}(\mathcal{H}) = \sup_T \inf_{\text{branch}} \sum_{u \in \text{branch}} \gamma_u\), where the supremum is over realizable scaled Littlestone trees \(T\) and \(\gamma_u\) is the gap at node \(u\).
- **Concept:** Entropy Potential \(\Phi(\mathcal{H})\)  
  **Why needed:** Provides a computable, metric‑entropy‑based bound on \(D_{\text{onl}}(\mathcal{H})\), translating geometric complexity into learning guarantees.  
  **Quick check:** \(\Phi(\mathcal{H})\) intuitively measures the integrated log covering number across all scales, akin to Dudley’s integral.
- **Concept:** Metric Entropy (Covering Numbers)  
  **Why needed:** Directly feeds into \(\Phi(\mathcal{H})\); polynomial rates imply finite potential and learnable regimes.  
  **Quick check:** For \(L\)-Lipschitz \(f:[-1,1]^d\to[0,1]\) under \(\ell_q\), \(\log N(\mathcal{H},\varepsilon) \lesssim (L/\varepsilon)^{d/q} \log(1/\varepsilon)\).

## Architecture Onboarding
**Component map:**  
Hypothesis class \(\mathcal{H}\) (e.g., Lipschitz functions, bounded ReLU networks) → Loss \(\ell\) (must be \(c\)-approximate pseudo‑metric) → Induced pseudo‑metric \(d_\ell(f,g)=\sup_x \ell(f(x),g(x))\) → Covering numbers \(N(\mathcal{H},\varepsilon)\) → Entropy potential \(\Phi(\mathcal{H})=\int_0^{\operatorname{diam}(\mathcal{H})} \log N(\mathcal{H},\varepsilon)\,d\varepsilon\) → Online dimension \(D_{\text{onl}}(\mathcal{H})\).

**Critical path to horizon‑free realizable loss bound:**  
1. Verify \(\ell\) is a \(c\)-approximate pseudo‑metric.  
2. Derive a covering number bound for \(\mathcal{H}\) under \(d_\ell\) (e.g., via Lipschitz parameterization).  
3. Compute or upper bound \(\Phi(\mathcal{H})\) (e.g., via Corollary F.1 for polynomial entropy).  
4. Apply Theorem 1.1: \(D_{\text{onl}}(\mathcal{H}) \le 4c\Phi(\mathcal{H})\).  
5. Run a simple online algorithm (e.g., from Theorem 2.4) achieving cumulative loss \(\le D_{\text{onl}}(\mathcal{H}) + \varepsilon\).

**Design tradeoffs:**  
- Approximate vs. true metric: Allows broader losses (e.g., squared with clipping) but introduces factor \(c\) in bound.  
- Constructive vs. existential: The entropy potential proof is non‑constructive; for efficiency one needs tailored algorithms (e.g., Lipschitz envelopes, improper learners), possibly sacrificing properness or efficiency.  
- Parameter dependence: For networks, bounds depend on total scalar parameters \(p\) (e.g., \(\widetilde{O}(p\log d)\) via covering vs. \(\widetilde{O}(k^2)\) via fat‑shattering tradeoff); depth adds further factors.

**Failure signatures:**  
- \(\Phi(\mathcal{H}) = \infty\): Covering numbers grow too fast (e.g., \(\log N \asymp \varepsilon^{-p}, p\ge1\)); horizon‑free bound fails (e.g., Lipschitz regression with \(q \le d\)).  
- Loss not approximate pseudo‑metric: e.g., \(0/1\) classification violates triangle; \(D_{\text{onl}}\) may be infinite (Theorem 1.5).  
- Computationally inefficient: Generic potential method yields no algorithm; need problem‑specific design.

**First 3 experiments:**  
1. **Lipschitz phase transition:** Implement the envelope algorithm (Appendix A.2) for small \(d\) (2,3) and varying \(q\) (1–4). For a realizable \(L\)-Lipschitz target, track cumulative \(\ell_q\) loss over \(T \le 10^4\). Expected: bounded loss for \(q>d\); logarithmic growth for \(q=d\); polynomial growth for \(q<d\).  
2. **Single‑ReLU regression:** Test the online update from Appendix B. For \(d = 10,20,50\), \(T = 10^5\), random \(w^* \in B_2(1)\) and \(x_t \in B_2(1)\), compute total squared loss \(\sum (\hat{y}_t - y_t)^2\). Expected: constant (≤ 4) independent of \(d,T\).  
3. **Bounded \(k\)-ReLU regression (\(k\ge2\)):** No efficient algorithm; instead compute the theoretical entropy‑potential bound using covering number estimates. Check scaling: leading term should be \(\widetilde{O}(k^2)\) (e.g., \(k^2 \log^4 d\) for moderate \(d,k\)). If derived scaling is larger (e.g., exponential in \(k\)), the claim is overstated.

## Open Questions the Paper Calls Out
1. **Upper bound improvement for multi‑ReLU regression:** Can the \(\widetilde{O}(k^2)\) information‑theoretic upper bound for bounded \(k\)-ReLU be improved to \(O(1)\) for any constant \(k>1\), or is a polylog\((d)\) dependence provably necessary?
2. **Optimal \(k\)‑dependence for depth‑\(L\) networks:** For depth‑\(L\) ReLU networks, can the gap between the \(O(k^L)\) upper bound and the \(\Omega(k^{L-1})\) lower bound be closed to achieve optimal dependence on \(k\)?
3. **Extension to near‑realizable setting:** Can the entropy‑potential framework be extended to near‑realizable online regression (best‑in‑class loss ≤ \(L\)) so that cumulative bounds depend essentially linearly on \(L\)?
4. **Efficient improper learning for multi‑ReLU:** Is there an efficient (polynomial‑time) improper online algorithm for bounded \(k\)-ReLU (\(k>1\)) that achieves \(eO(1)\) (or \(O(1)\)) cumulative loss, or do computational lower bounds apply even to improper learners?

## Limitations
- The entropy potential argument is non‑constructive; it guarantees existence but yields no efficient algorithm for general classes like \(k\)-ReLU regression (\(k\ge2\)).
- The \(\widetilde{O}(k^2)\) bound for ReLU regression may be loose in practice; covering‑number based estimates often overestimate complexity, and constants are hidden.
- The phase transition for Lipschitz regression requires \(q > d\), which for high‑dimensional data demands a high‑order loss (e.g., \(\ell_q\) with \(q\) possibly > 10), potentially impractical.
- Classification impossibility relies on \(0/1\) loss violating the approximate triangle condition; other losses (e.g., hinge, exponential) might behave differently but are not covered by the main theorem.
