# Conflict-Free Policy Languages for Probabilistic ML Predicates: A Framework and Case Study with the Semantic Router DSL

## Quick Facts
- **arXiv ID:** 2603.18174  
- **Source URL:** https://arxiv.org/abs/2603.18174  
- **Reference count:** 17  
- **Primary result:** Introduces a decidability hierarchy for probabilistic policy conflicts and a runtime Voronoi normalization via temperature-scaled softmax that eliminates co-firing for embedding signals without model retraining.

## Executive Summary
Policy languages for ML-driven systems (e.g., LLM routers) suffer from silent misrouting when probabilistic signal thresholds cause co-firing of rules intended to be disjoint. This paper formalizes the problem as a three-level decidability hierarchy—crisp (SAT-decidable), geometric embedding (reducible to spherical cap intersection), and classifier (undecidable without distribution)—and provides practical mitigations. For the predominant embedding case, it replaces independent thresholding with a temperature-scaled softmax, partitioning the embedding space into Voronoi regions so at most one signal fires per declared group, eliminating co-firing without retraining. The framework is implemented in the Semantic Router DSL with compiler-level checks and demonstrated on semantic RBAC and API gateway policies.

## Method Summary
The task is to detect and eliminate silent co-firing conflicts in policy languages where rule conditions are probabilistic ML signals (e.g., embedding similarities, domain classifiers). Inputs are Semantic Router DSL configuration files with SIGNAL and ROUTE blocks; objectives include achieving mutually exclusive signal activation per declared group. Methods comprise static analysis (category overlap scanning, guard warnings, TEST blocks), a runtime fix for embedding signals (softmax-based Voronoi normalization within SIGNAL GROUP), and alternative constructions (decision-tree, type-checked composition). Critically, the embedding fix requires no model retraining.

## Key Results
- Formal characterization of three new conflict types: probable, soft shadowing, and calibration.
- Implementation of compiler-level checks (category overlap, guard warnings, SIGNAL GROUP with softmax exclusive semantics, TEST blocks, TIER routing) in the Semantic Router DSL.
- Theoretical guarantee that Voronoi normalization (θ > 1/k, τ → 0) enforces mutual exclusion for embedding signals without retraining.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Probabilistic policy conflicts are decidable in a hierarchy based on signal type (crisp, geometric, classifier), allowing static detection for some conflicts while revealing fundamental undecidability for others.
- **Mechanism:** The framework classifies signal atoms by output space and activation region. Crisp signals (Boolean) reduce to SAT/set algebra. Geometric signals (embedding similarity) have activation regions that are spherical caps, making co-firing reducible to computable spherical cap intersection given centroids. Classifier signals (neural outputs) lack static geometric characterization; detecting calibration conflicts requires knowing input distribution P(x), generally unavailable.
- **Core assumption:** Signal type determines mathematical representation of activation region and feasibility of static conflict analysis.
- **Evidence anchors:** [abstract, section 3.2 Theorem 1] Decidability hierarchy linking spherical cap intersection to embedding signals; classifier conflicts undecidable without P(x).
- **Break condition:** For classifier signals, statically guaranteeing absence of calibration conflict fails without an explicit, learnable model of P(x) or classifier boundaries.

### Mechanism 2
- **Claim:** For embedding signals, replacing independent thresholding with temperature-scaled softmax normalizes scores into a Voronoi partition of the embedding space, guaranteeing mutual exclusion of signal firings within a declared group without model retraining.
- **Mechanism:** For a group G of k embedding signals with centroids {ĉ₁,..., ĉₖ}, runtime computes normalized scores via softmax over cosine similarities with temperature τ. As τ → 0, softmax concentrates all probability mass on the centroid with maximum similarity, partitioning the hypersphere into Voronoi cells where each input x is assigned to exactly one signal. Theorem proves that with group threshold θ > 1/k, at most one signal fires.
- **Core assumption:** Embedding space is a unit hypersphere with cosine similarity; centroids are fixed and provided. Partition correctness relies on softmax and Voronoi properties, not retraining.
- **Evidence anchors:** [abstract, section 4.2 Definition 1 and Theorem 2] Voronoi normalization and conflict elimination proof; [section 4.3] low τ (e.g., 0.1) yields decisive partition.
- **Break condition:** Guarantee fails if τ is too high or θ ≤ 1/k; requires distinct centroids.

### Mechanism 3
- **Claim:** Compiler-level checks (category overlap, guard warnings, SIGNAL GROUP) and declarative constructs (TEST blocks, TIER routing) surface and prevent conflicts at policy-authoring time, integrating safety into workflow without runtime overhead.
- **Mechanism:** DSL compiler extends validation passes: (1) scans domain signals for shared MMLU categories to warn of probable co-firing; (2) detects unguarded overlapping signal references and suggests NOT guards; (3) introduces SIGNAL GROUP block declaring mutual exclusion intent and enforcing softmax-exclusive semantics at runtime; (4) allows TEST blocks to empirically validate routing outcomes; (5) supports TIER routing for explicit evaluation order.
- **Core assumption:** Authors can be guided to write policies with explicit exclusivity groups and guards; TEST blocks catch semantic mismatches static analysis misses.
- **Evidence anchors:** [abstract, section 5] Details of each check and syntax; [section 7.1] Implementation survives round-trips; Table 1 maps techniques to conflict types.
- **Break condition:** Static checks cannot detect calibration or soft shadowing from classifier boundaries; require runtime/TEST monitoring. SIGNAL GROUP misuse (e.g., forgetting group assignment) leaves conflicts undetected.

## Architecture Onboarding
Parser -> Validator -> Compiler -> Signal Engine -> Router Executor; TEST Runner optional.  
Critical path: Author writes DSL → Parser → Validator (conflict checks) → Compiler emits config → Runtime: request → Signal Engine (with group normalization if configured) → Router Executor → Action.  
Design tradeoffs:  
- Static vs dynamic detection: Static checks cheap but incomplete; TEST blocks catch semantic issues but slow.  
- Expressiveness vs safety: Arbitrary Boolean WHEN clauses enable rich policies but create undetectable conflicts; SIGNAL GROUP and DECISION TREE enforce disjointness at flexibility cost.  
- Retraining vs no-retraining: Voronoi normalization works without retraining; coherent classifier heads require retraining but offer stronger guarantees.  
Failure signatures:  
- Co-firing observed in logs: two signals from same group fire; check if group has softmax_exclusive.  
- Validator warning on category overlap: exact MMLU string duplicate; fix by splitting categories or using SIGNAL GROUP.  
- TEST block failure: expected route ≠ actual route; indicates semantic conflict (e.g., calibration).  
- High confidence but wrong route: classic soft shadowing; check priority order or use TIER routing.  
First 3 experiments:  
1. Reproduce co-firing: Use Listing 1 config with query "quantum tunneling probability"; confirm both math and science signals fire independently; observe misrouting by priority.  
2. Apply Voronoi normalization: Wrap math and science signals in SIGNAL GROUP with semantics: softmax_exclusive; temperature: 0.1; rerun query; verify only higher-similarity signal fires; no model change.  
3. Test category overlap check: Add new domain signal with MMLU category "college_physics" overlapping with science; confirm validator emits warning; fix by removing overlap or placing both in SIGNAL GROUP.

## Open Questions the Paper Calls Out
- **Can NetKAT's equational theory be extended to support probabilistic ML predicates while preserving decidability for embedding signals and handling undecidable classifier cases?** Basis: Section 10 discusses extending Probabilistic NetKAT to continuous scores, noting a typed policy algebra could constrain operators by atom type. Why unresolved: Current NetKAT assumes crisp Boolean tests; new semantics and proof system needed. Evidence to resolve: Formal semantics and proof system for "Probabilistic ML-NetKAT" with geometric reasoning for embeddings and conservative approximations for classifiers.
- **Can we design an online monitor that estimates co-firing probability from production traffic to detect calibration conflicts and distribution-shift-induced conflicts that static checks miss?** Basis: Section 10 proposes online detection for post-deployment conflicts. Why unresolved: Static analysis lacks input distribution knowledge. Evidence to resolve: Low-overhead monitoring tool that samples queries, tracks activations, and flags pairs with high joint activation rates.
- **How can conflict-checking be integrated into LLM-based policy synthesis loops so that generated configurations are automatically repaired to be conflict-free?** Basis: Section 10 describes running the conflict checker in the generation loop for "conflict-aware policy synthesis." Why unresolved: DSL supports LLM generation but does not enforce conflict invariants during synthesis. Evidence to resolve: Experimental study where LLM synthesizes policies from natural language specs with conflict checker feedback; high percentage of generated configs passing all checks without human intervention.
- **For classifier-based signals where static analysis is undecidable, can we develop sound geometric approximations of decision boundaries (e.g., using linearized probes or conformal prediction sets) to approximate co-firing regions?** Basis: Theorem 1 states classifier conflicts are undecidable without P(x); paper suggests circumventing via Voronoi normalization or distributional knowledge, but leaves open approximate geometric characterizations. Why unresolved: Classifier boundaries are arbitrary; without distributional assumptions, exact intersection areas cannot be computed. Evidence to resolve: Method to extract a conservative geometric region (e.g., polytope) enclosing a classifier's high-confidence region, such that pairwise region intersections imply possible conflict, with precision/recall studies.
- **Does Voronoi normalization (temperature-scaled softmax) generalize to other geometric representations beyond spherical cosine similarity (e.g., hyperbolic embeddings, learned metrics) while preserving mutual exclusion?** Basis: Inferred from Theorem 2 proof relying on unit hypersphere and cosine similarity; other geometries may not admit same guarantee. Why unresolved: Partition rigidity depends on metric and normalization function; non-Euclidean spaces may allow co-firing. Evidence to resolve: Theoretical analysis extending Theorem 2 to other Riemannian manifolds or a counterexample for common embedding spaces like Poincaré ball.

## Limitations
- Decidability hierarchy leaves classifier conflicts undecidable without distributional knowledge; TEST blocks may not guarantee detection.
- Voronoi normalization requires distinct centroids and low temperature; practical τ=0.1 may still allow co-firing if centroids are too close.
- Compiler checks only catch exact MMLU string overlaps; semantic overlaps and guard warning heuristics lack evaluation.

## Confidence
- **High:** Theoretical hierarchy (Theorem 1) and geometric reduction.
- **Medium:** Voronoi guarantee (Theorem 2) under ideal conditions; compiler checks implemented but unevaluated.
- **Low:** Mitigation for classifier conflicts via TEST blocks; no evidence of reliability.
