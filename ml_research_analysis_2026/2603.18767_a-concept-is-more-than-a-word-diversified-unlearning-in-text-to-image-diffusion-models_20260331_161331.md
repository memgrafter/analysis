# A Concept is More Than a Word: Diversified Unlearning in Text-to-Image Diffusion Models

## Quick Facts
- arXiv ID: 2603.18767
- Source URL: https://arxiv.org/abs/2603.18767
- Reference count: 40
- Primary result: Distributional unlearning using diverse contextual prompts significantly improves erasure robustness and reduces over-forgetting across multiple unlearning methods.

## Executive Summary
Concept unlearning in text-to-image diffusion models is hampered by keyword-based fragility: a single token incompletely captures a multi-dimensional concept, leading to over-forgetting and vulnerability to recovery attacks. This work introduces Diversified Unlearning, a distributional framework that represents a concept through contextually varied prompts rather than an isolated keyword. For output-based methods (e.g., ESD, AP), it proposes Diversified Prompting, which aligns the target concept with a diverse set of contextual anchors. For attention-based methods (e.g., UCE), it adds Diversified Embedding Mixup, interpolating token embeddings with context embeddings to stabilize the unlearning process. Evaluated on five benchmark settings, the approach yields ~50% lower GPT-score on celebrity erasure, reduces attack success rates by 15-40% under Ring-A-Bell and noise-based recovery, and better preserves unrelated concepts via CLIP similarity and GPT-score. The method functions as a lightweight add-on to existing unlearning pipelines.

## Method Summary
Diversified Unlearning reformulates concept unlearning from a point estimate (single keyword) to a distributional objective over contexts. Given a target concept token τₛ, a context set C is constructed (via LLM and verification) to capture natural linguistic variations. For output-based methods, training pairs (c+τₛ, c+τₐ) are generated for each context c, and the model learns to align the noise prediction for the target prompt with that of the anchor prompt across all contexts. For attention-based methods, a Diversified Embedding Mixup replaces the embeddings of target tokens with a high-weight (η≈0.999) interpolation between the original target token embeddings and the average context token embeddings. This token-level mixup retains the target's identity while injecting diversity, mitigating over-forgetting. The framework is agnostic to the underlying unlearning algorithm and requires minimal modifications.

## Key Results
- Diversified variants of ESD, AP, AGE, ACE, and UCE achieve ~50% lower GPT-score on celebrity erasure compared to baselines.
- Attack success rates under Ring-A-Bell and noise-based recovery drop by 15-40%.
- Preservation of unrelated concepts measured by CLIP similarity and GPT-score is improved.
- The method remains effective across single- and multi-concept settings and under varying prompt complexity levels.

## Why This Works (Mechanism)
### Mechanism 1: Distributional Targeting via Contextual Prompting
Unlearning a single keyword covers only a narrow point in the concept's semantic manifold. Using a diverse set of contextual prompts (e.g., "Barack Obama waving", "Barack Obama with a microphone") broadens coverage, forcing the model to suppress the target concept across varied contexts and reducing recovery via rephrasing. The loss becomes an expectation over context distribution C, aligning optimization with the true concept distribution.

### Mechanism 2: Stabilizing Attention-Based Unlearning via Token-Level Mixup
Attention-based unlearning suffers from over-forgetting because the text encoder blends target and context semantics. Diversified Embedding Mixup applies a high-η (≈0.999) interpolation at the token embedding level: η·embed(τₛ)+(1-η)·embed(c). This retains the target's core signature while injecting just enough diversity to regularize optimization, preventing collapse.

### Mechanism 3: Shift from Point to Distributional Unlearning Objective
The core limitation is a formulation mismatch: unlearning objectives target a point estimate, while concepts are distributions. Both Diversified Prompting and Embedding Mixup implement this shift, making the loss an expectation over C. This forces the model to forget the invariant component of the target, making the removal more fundamental and less prone to "concealment".

## Architecture Onboarding
**Component map**:  
Text Encoder (CLIP) -> Cross-Attention Layers (in UNet) -> Denoising UNet  
Context Set Generator (LLM) (external) + Evaluators (CLIP, GPT-Score, Nudenet) (external)

**Critical path**:  
1. Construct context set C via LLM + verification for target concept τₛ.  
2. For output-based: create diversified prompt pairs (c+τₛ, c+τₐ) and fine-tune UNet with loss aligning predictions.  
3. For attention-based: for each target token, mix its embedding with average context embeddings (η≈0.999) and perform closed-form update of attention weights.  
4. Deploy and evaluate across diverse prompts and attacks.

**Design tradeoffs**:  
- Diversity vs. Signal Dilution: Too complex contexts cause over-forgetting; moderate (Level-3) is optimal.  
- Mixup Weight (η): Very high η (0.999) is needed in high-dimensional spaces; lower η harms preservation.  
- Prompt Quantity: ~20 prompts stable; more increases compute with diminishing returns.  
- Architectural Scope: Lightweight add-on; does not alter base loss structure.

**Failure signatures**:  
- Over-forgetting: CLIP-t drop on unrelated concepts → reduce context complexity, increase η, ensure neutral contexts.  
- Incomplete erasure: High GPT-score or attack ASR → increase diversity, verify contexts, extend training steps.  
- Concept confusion: Erasing target also hurts related concepts → contexts not diverse/neutral enough.  
- Training instability: Monitor loss; lower LR, gradient clip; check mixed embedding similarity to original.

**First 3 experiments**:  
1. Baseline replication: Implement Diversified-ESD for a single celebrity (e.g., Henry Cavill) with Level-1 contexts; verify improved erasure/preservation vs original ESD.  
2. Multi-concept stress test: Erase 10 celebrities with Diversified-AP; evaluate across prompt levels (L0-L7) and under noise-based recovery; test scalability and robustness.  
3. Ablation: For Diversified-UCE on 10 celebrities, sweep η (0.9-0.999) and context level (1-4); plot GPT-score vs CLIP-t trade-offs; confirm η≈0.999 optimal.

## Open Questions the Paper Calls Out
- **How can we represent visual concepts beyond single keywords to achieve reliable and robust unlearning?** The paper proposes distributional representation via contexts but notes that the optimal representation for diverse concept types (abstract styles, multi-entity scenes) remains unknown. Systematic comparison of representation strategies (multi-granularity prompts, learned embeddings, concept graphs) would clarify trade-offs.
- **What are effective noise-based embedding mixing strategies for token-level diversification, and how do they trade off erasure strength against preservation?** The paper only briefly compares simple Gaussian noise mixup; the design space (noise distribution, mixing coefficient schedule, token selection) is unexplored. Comprehensive experiments across concepts and baselines, along with gradient/attention analysis, could reveal effective strategies.
- **How can we automatically generate diverse, realistic contextual prompts that accurately reflect a target concept's natural usage, especially for abstract domains like artistic styles?** LLM-generated prompts can be synthetic; real-world context mining (e.g., from annotated artwork corpora) or learning via reinforcement could provide more authentic prompts.
- **What automatic evaluation metrics reliably measure unlearning of abstract concepts in alignment with human judgment?** CLIP-t and LPIPS may not capture subtle style characteristics; a human study and development of style-specific metrics are needed.

## Limitations
- Context set generation details (LLM prompts, verification thresholds) are not fully specified, hindering reproducibility.
- Token alignment for mixup when context token count differs from target token count is unclear.
- Baseline hyperparameters are not provided; must be sourced from original papers.
- The method's reliance on hand-crafted contexts may not generalize to all concept types (e.g., abstract styles).

## Confidence
- Distributional targeting (Mechanism 1): Medium (depends on context set quality).
- Mixup stabilization (Mechanism 2): Medium (η=0.999 empirically effective but may not generalize).
- Distributional objective shift (Mechanism 3): Medium (results strong but hinge on context construction).
