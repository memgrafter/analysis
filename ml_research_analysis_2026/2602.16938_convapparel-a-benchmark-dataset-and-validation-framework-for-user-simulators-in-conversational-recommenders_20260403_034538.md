# ConvApparel: A Benchmark Dataset and Validation Framework for User Simulators in Conversational Recommenders

## Quick Facts
- **arXiv ID**: 2602.16938  
- **Source URL**: https://arxiv.org/abs/2602.16938  
- **Reference count**: 40  
- **Primary result**: All LLM-based user simulators exhibit a significant realism gap (human-likeness ~0) on the ConvApparel benchmark for conversational recommender systems, though data-driven simulators (ICL/SFT) achieve better statistical alignment and counterfactual adaptation than prompted baselines within this domain.

## Executive Summary
This paper tackles the realism gap in LLM-based user simulators for conversational recommender systems (CRS). It introduces ConvApparel, a dataset of 4k human-AI dialogues collected using dual "good" and "bad" recommender agents, enhanced with turn-by-turn first-person satisfaction annotations. A validation framework is proposed combining population-level statistical alignment, a discriminator-based human-likeness score, and counterfactual tests to evaluate generalization to unseen agent behaviors. Experiments reveal a persistent realism gap across all simulator types (prompted, in-context learning, supervised fine-tuning) within the studied apparel domain, with human-likeness scores near zero. However, data-driven simulators (ICL/SFT) show superior statistical alignment and more realistic adaptation in counterfactual scenarios, indicating more robust user modeling despite the overarching gap.

## Method Summary
ConvApparel is built through a dual-agent data collection setup where a "good" recommender (high item acceptance) and a "bad" recommender (low acceptance) interact with crowd-sourced users, yielding diverse dialogue strategies. Each turn is annotated with the user’s satisfaction on a 5-point scale. The validation framework has three pillars: (1) population-level statistical alignment (e.g., utterance length, topic distribution) between simulator and human conversations; (2) a discriminator trained to distinguish human from simulator dialogues, outputting a human-likeness score; (3) counterfactual validation where simulators are exposed to unseen agent behaviors (e.g., a "bad" agent after training on "good" agents) to test adaptive realism. Simulators are implemented via prompting, in-context learning (ICL), and supervised fine-tuning (SFT) on ConvApparel.

## Key Results
- Realism gap persists: all simulator types achieve human-likeness scores near 0.0, indicating poor alignment with genuine human dialogue behavior.  
- Data-driven simulators (ICL/SFT) better match human statistical distributions (e.g., utterance length, satisfaction trajectory) than prompted baselines.  
- In counterfactual tests, SFT simulators adapt more realistically to unseen "bad" agent behaviors, showing greater robustness in satisfaction dynamics.

## Why This Works (Mechanism)
ConvApparel’s dual-agent collection ensures exposure to a spectrum of recommender qualities, eliciting varied user responses (e.g., negotiation, acceptance, rejection). Turn-level satisfaction annotations capture fine-grained user state changes, which are critical for evaluating simulators that must react dynamically. The multi-metric validation framework addresses both static realism (distributional similarity) and dynamic realism (adaptation to novel agent behaviors), going beyond prior aggregate metrics. The discriminator provides an end-to-end human-likeness signal, while counterfactual testing probes generalization beyond the training agent distribution, revealing simulator robustness.

## Architecture Onboarding
**Component map**: Data Collection → Annotation → Discriminator Training → Simulator Training (Prompted/ICL/SFT) → Validation Metrics (Statistical Alignment, Discriminator Score, Counterfactual Adaptation)

**Critical path**:  
1. Gather human-AI dialogues via dual-agent collection.  
2. Annotate each turn with satisfaction labels.  
3. Train discriminator on human vs. simulator (initial) dialogues.  
4. Train simulators using prompted, ICL, or SFT methods on annotated dialogues.  
5. Evaluate simulators via statistical alignment (vs. held-out human data), discriminator score, and counterfactual tests (expose to unseen agent behavior).

**Design tradeoffs**:  
- Domain specificity (apparel) vs. generalizability: Deep domain focus enables fine-grained annotation but limits cross-domain claims.  
- Automated discriminator vs. human evaluation: Discriminator scales but risks overfitting to dataset-specific style.  
- Controlled counterfactual vs. real-world shifts: Counterfactuals test specific behaviors but may not capture complex deployment distribution shifts.

**Failure signatures**:  
- Discriminator score near 1.0 (simulator easily distinguished from human).  
- High statistical divergence (e.g., large difference in utterance length distribution).  
- No adaptation in counterfactual test (simulator satisfaction trajectory remains unchanged when agent behavior shifts).

**First three experiments**:  
1. Train an SFT simulator and compare its utterance length distribution to the human validation set using Jensen-Shannon divergence.  
2. Run the trained discriminator on simulator-generated dialogues and human dialogues; compute human-likeness score (1 - discriminator accuracy).  
3. Expose the SFT simulator to a "bad" agent during counterfactual validation and measure change in per-turn satisfaction variance compared to human responses to the same agent.

## Open Questions the Paper Calls Out
The paper does not explicitly identify open questions; its focus is on presenting the dataset and validation framework. However, the limitations section highlights several areas that could be explored in future work, such as domain generalizability, discriminator bias, and the root causes of the realism gap.

## Limitations
- Domain specificity: ConvApparel is apparel-only, limiting generalizability to other CRS domains (e.g., electronics, movies).  
- Ambiguous agent definitions: The criteria for "good" vs. "bad" recommenders are not detailed, potentially introducing data collection bias.  
- Discriminator overfitting: Human-likeness score likely biased toward ConvApparel’s dialogue style and annotation scheme.  
- Counterfactual scope: Tests adaptation to *specified* unseen behaviors but may not reflect broader real-world distribution shifts.  
- Root cause unknown: Persistent realism gap near 0.0 could stem from LLM architectural constraints or dataset artifacts; unclear.

## Confidence
- **High**: Statistical alignment improvements for ICL/SFT simulators are reproducible within the ConvApparel dataset; data-driven methods consistently outperform prompted baselines on these metrics.  
- **Medium**: Counterfactual validation framework’s ability to predict generalization to *novel* agent behaviors is supported by study experiments but requires external validation on other datasets.  
- **Low**: Claim that realism gap is "persistent across all simulators" is currently confined to this domain and specific implementations; universal applicability across CRS domains and simulator architectures is uncertain.

## Next Checks
1. **Domain replication**: Re-run full validation on a distinct CRS domain (e.g., electronics, movies) using identical simulator architectures to test generalizability of the realism gap.  
2. **Discriminator audit**: Evaluate discriminator bias by (a) testing on out-of-domain human conversations, and (b) measuring agreement with multiple human annotators on a held-out set.  
3. **Longitudinal simulator testing**: Deploy top-performing SFT simulator in a live, small-scale CRS with real users for one week, comparing simulator-predicted satisfaction against actual engagement metrics (e.g., task completion, retention).
