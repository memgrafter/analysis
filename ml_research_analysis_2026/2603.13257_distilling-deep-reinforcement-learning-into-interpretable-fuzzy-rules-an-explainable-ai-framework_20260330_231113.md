# Distilling Deep Reinforcement Learning into Interpretable Fuzzy Rules: An Explainable AI Framework

## Quick Facts
- **arXiv ID:** 2603.13257
- **Source URL:** https://arxiv.org/abs/2603.13257
- **Reference count:** 10
- **Key outcome:** Triangular membership variant achieves 81.48% ± 0.43% action-matching fidelity on Lunar Lander (Continuous), outperforming Decision Trees by 21 percentage points

## Executive Summary
This work addresses the critical challenge of interpreting opaque deep reinforcement learning policies by proposing a Hierarchical Takagi-Sugeno-Kang Fuzzy Classifier System. The approach distills neural policies into human-readable IF-THEN rules using K-Means clustering for state partitioning and Ridge Regression for local action inference. The method achieves 81.48% fidelity on Lunar Lander (Continuous), demonstrating that complex DRL policies can be effectively translated into interpretable fuzzy structures while maintaining strong performance characteristics.

## Method Summary
The framework employs a two-stage distillation process: first, K-Means clustering partitions the state space into interpretable regions, then Ridge Regression fits local linear models to approximate the neural policy's actions within each cluster. This Hierarchical Takagi-Sugeno-Kang Fuzzy Classifier System generates triangular or Gaussian membership functions that capture the policy's decision boundaries in a human-readable format. The approach balances fidelity against interpretability, producing models that maintain high performance while being verifiable and explainable.

## Key Results
- Triangular membership variant achieves 81.48% ± 0.43% action-matching fidelity, outperforming Decision Trees by 21 percentage points
- Superior interpretability with Fuzzy Rule Activation Density (FRAD) of 0.814 vs. 0.723 for Gaussian (p < 0.001)
- Low mean squared error of 0.0053 and Dynamic Time Warping distance of 1.05
- Minimal 4-rule model reaches 97.83% fidelity, demonstrating potential for highly simplified representations

## Why This Works (Mechanism)
The distillation process works by first decomposing the high-dimensional state space into manageable clusters through K-Means, then fitting local linear approximations using Ridge Regression. This hierarchical approach captures both global state transitions and local action nuances. The fuzzy membership functions (triangular or Gaussian) provide smooth interpolation between cluster boundaries, allowing the distilled policy to handle states near cluster edges. The Ridge Regression component ensures stable, interpretable coefficients that directly map to actionable insights about the policy's decision-making.

## Foundational Learning
- **K-Means Clustering:** Required for partitioning state space into interpretable regions; quick check: verify cluster centers capture policy's decision boundaries
- **Ridge Regression:** Provides stable linear approximations for local action inference; quick check: examine coefficient magnitudes for interpretability
- **Fuzzy Logic (Takagi-Sugeno-Kang):** Enables smooth interpolation between discrete state regions; quick check: validate membership function shapes match expected state transitions
- **Hierarchical System Design:** Combines global clustering with local approximation; quick check: ensure cluster hierarchy reflects policy's temporal structure
- **Interpretability Metrics (FRAD):** Quantifies rule activation patterns; quick check: higher FRAD should correlate with better human understanding
- **Fidelity Metrics:** Measures approximation accuracy; quick check: compare action-matching rates against baseline methods

## Architecture Onboarding

**Component Map:** K-Means clustering -> Ridge Regression fitting -> Fuzzy membership generation -> Rule evaluation

**Critical Path:** State clustering → local model fitting → membership function synthesis → policy evaluation

**Design Tradeoffs:** Triangular vs Gaussian membership functions (simplicity vs smoothness), number of clusters vs fidelity (interpretability vs accuracy), Ridge vs other regression methods (stability vs flexibility)

**Failure Signatures:** Poor clustering leads to high variance in local models; insufficient clusters cause oversimplification; inappropriate membership function choice results in sharp, unintuitive boundaries

## Limitations
The 81.48% fidelity was demonstrated only on Lunar Lander (Continuous) with single-run evaluation. Interpretability claims lack human-subject validation despite FRAD metric superiority. The minimal 4-rule model achieving 97.83% fidelity may indicate overfitting rather than generalization. Dynamic Time Warping distance, though low at 1.05, was computed on a single trajectory insufficient for full state-action space representation.
