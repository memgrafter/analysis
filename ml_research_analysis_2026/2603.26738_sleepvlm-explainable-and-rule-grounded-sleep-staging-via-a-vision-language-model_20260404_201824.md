# SleepVLM: Explainable and Rule-Grounded Sleep Staging via a Vision-Language Model

## Quick Facts
- arXiv ID: 2603.26738
- Source URL: https://arxiv.org/abs/2603.26738
- Reference count: 40
- Primary result: SleepVLM achieves Cohen’s kappa 0.767 on held-out data and 0.743 on an external cohort while generating AASM rule-cited rationales, matching state-of-the-art accuracy with explainability.

## Executive Summary
Automated sleep staging typically lacks transparent reasoning, limiting clinical trust. SleepVLM addresses this by adapting a vision-language model to process PSG waveform images and output structured decisions with clinician-readable explanations that explicitly cite AASM rules. The system uses two-phase training: first, waveform-perceptual pre-training to learn fine-grained signal features; second, rule-grounded fine-tuning to tie predictions to standardized guidelines. On held-out and external datasets, SleepVLM reaches competitive staging accuracy (Cohen’s κ ≈ 0.76) and receives high expert ratings (>4/5) for reasoning quality. Post-training quantization further reduces model size by 55% and doubles inference speed with minimal accuracy loss, demonstrating a viable path for deployment.

## Method Summary
SleepVLM builds on the Qwen2.5-VL-3B-Instruct architecture. Inputs are multi-channel PSG waveforms rendered as 448×224 pixel images covering three consecutive 30-second epochs. Training proceeds in two phases. Phase 1 (Waveform-perceptual pre-training) adapts the vision encoder to predict per-second spectral band powers and amplitudes from single-epoch images, using mean squared error loss. Phase 2 (Rule-grounded supervised fine-tuning) freezes the vision encoder and applies LoRA to the language model; the model receives a system prompt containing 15 AASM rules and is trained to output JSON with the sleep stage, applicable rule IDs, and a free-text rationale. Training data includes both coarse (stage+rule IDs) and fine (full rationale) annotations from the MASS-EX corpus. Optional Phase 3 (Reasoning fine-tuning) uses perplexity-gain selection to improve rationale quality from coarse-only samples.

## Key Results
- Cohen’s kappa: 0.767 on MASS-SS1 held-out, 0.743 on external ZUAMHCS
- Expert reasoning scores >4.0/5 for factual accuracy, evidence comprehensiveness, logical coherence
- W4A16 quantization cuts model size 55%, speeds inference 2.2×, with ≤1.6 percentage point κ loss

## Why This Works (Mechanism)
**Mechanism 1:** Waveform-perceptual pre-training (WPT) improves clinical feature extraction from PSG images. The model predicts per-second spectral band powers and amplitudes, forcing the vision encoder to learn fine-grained EEG/EOG/EMG morphology. Accurate perception is prerequisite for correct rule application. Evidence: Ablation removing WPT reduces κ by 3.1 pp and reasoning factual accuracy declines (4.24 → 3.95). Break condition: If pre-training distribution diverges from target recordings (e.g., different montages), features may not transfer, causing perceptual hallucinations.

**Mechanism 2:** Injecting AASM rules into the system prompt and training with rule-annotated data grounds reasoning in clinical standards. The model must cite specific rules, creating an auditable link between observations and guideline criteria. Evidence: Expert scores >4.0; ablation removing rule grounding lowers cross-domain κ by 2.3 pp and reasoning composite by 0.41. Break condition: Incomplete or misaligned rule set (e.g., pediatric rules omitted) leads to misapplication on ambiguous stages.

**Mechanism 3:** The unified vision-language architecture ensures explanations are faithful to the visual evidence used for classification. Classification and rationale are generated concurrently from the same input, avoiding disjoint black-box and post-hoc explainer. Evidence: Qualitative outputs mirror AASM workflow structure. Break condition: If language priors dominate visual conditioning, the model may produce coherent but inaccurate rationales; WPT mitigates this by strengthening visual grounding.

## Architecture Onboarding
- **Component map**: Raw PSG -> preprocessing (filtering, resampling, segmentation) -> rendered multi-channel images -> Qwen2.5-VL-3B-Instruct (vision encoder + LLM with LoRA) -> JSON output {stage, applicable_rules, reasoning_text}
- **Critical path**: 1. Preprocess PSG to generate standardized images. 2. Construct MASS-EX dataset with coarse/fine annotations. 3. Train WPT on single-epoch spectral/amplitude prediction. 4. Freeze vision encoder; perform rule-grounded SFT on three-epoch inputs with LoRA on LLM. 5. Evaluate on held-out and external sets; have experts rate reasoning quality.
- **Design tradeoffs**: 
  - Image rendering vs raw signal: Rasterization loses precision but enables pretrained VLMs; raw signals might recover detail but require training from scratch.
  - Three-epoch context vs longer windows: Three epochs balance local transitions and compute; longer contexts could resolve ambiguity but increase memory.
  - Rule grounding vs flexibility: Strict rule citation aids auditability but may hinder adaptation to non-AASM or new criteria.
  - Coarse annotation scale: Adding coarse labels (stage+rule only) boosts performance; full rationales are expensive but not strictly necessary for SFT.
- **Failure signatures**:
  - Low recall for N1 due to ambiguous electrophysiology, confusion with W/N2.
  - Perceptual hallucinations (e.g., reporting nonexistent spindles) causing rule misapplication.
  - Cross-domain reasoning degradation on ZUAMHCS; factual accuracy drops with more score=1 ratings.
  - Missing multi-epoch rules (e.g., MBM.1, N2.2) if context underused.
  - Channel confusion (e.g., mentioning EMG in EOG trace).
  - Quantization artifacts slightly reducing κ (>1.6 pp) or reasoning clarity.
- **First 3 experiments**:
  1. Zero‑shot baseline (no domain-trained) to confirm need for WPT and SFT.
  2. Ablation study toggling WPT and rule grounding to isolate contributions to classification and reasoning metrics.
  3. Quantization impact test: apply W4A16 and measure throughput vs κ loss to validate deployment feasibility.

## Open Questions the Paper Calls Out
1. How consistent are expert evaluations of SleepVLM's reasoning quality across different sleep clinicians? Current single-rater design cannot capture clinical interpretation variability.
2. Does SleepVLM maintain robust performance and reasoning quality across diverse clinical settings with varying PSG hardware, protocols, and patient demographics? Current evaluation spans only two datasets, limiting generalizability.
3. Can the rule-grounded VLM framework be effectively extended to pediatric sleep staging using age-specific AASM scoring criteria? Pediatric rules differ substantially and are not included.
4. What architectural or training interventions can reduce perceptual hallucinations in VLMs interpreting PSG waveforms, particularly at ambiguous stage boundaries like N1/N2? Current WPT improves fidelity but hallucinations persist.
5. Would incorporating longer temporal context or hybrid signal-image inputs improve SleepVLM's classification and reasoning at transitional sleep stages compared to the current three-epoch window? Richer inputs may help without sacrificing interpretability.

## Limitations
- Unknown annotation pipeline: Exact process for creating MASS-EX rule annotations and rationales is unreported, blocking replication of training data distribution.
- Exact system prompt: Verbatim AASM rules used in fine-tuning are not provided, creating reproducibility ambiguity.
- Validation split composition: Subject IDs for MASS-SS3 fine/coarse/val splits are missing, preventing exact training/checkpoint reproduction.
- Phase 1 target specification: Details of spectral power computation (windowing, channel aggregation, dB scaling) are unspecified.
- Generalization limits: Performance on pediatric or atypical sleep disorders is unknown; rule set may not cover non-AASM variants.

## Confidence
- Performance claims (kappa 0.767/0.743): High (clearly reported with standard errors)
- Reasoning quality (>4.0/5): Medium (single-rater evaluation without inter-rater reliability)
- Full reproducibility: Low (critical details omitted: annotation pipeline, prompt text, splits, Phase 1 specs)
- Deployment viability (quantization impact): High (method and trade-off quantified)
