# Using Vision Language Foundation Models to Generate Plant Simulation Configurations via In-Context Learning

## Quick Facts
- arXiv ID: 2603.08930
- Source URL: https://arxiv.org/abs/2603.08930
- Reference count: 40
- Primary result: Open-source VLMs can generate functional-structural plant model configurations from drone images via in-context learning, but often rely on prompt priors; explicit grounding information (e.g., plant counts, locations) substantially reduces errors, and fine-tuning improves accuracy, though the approach still falls short of human annotation quality.

## Executive Summary
Functional-structural plant models (FSPMs) are essential for agricultural digital twins but scaling them to many fields requires automating the creation of plot-specific configuration files. This paper proposes using vision-language foundation models (VLMs) to generate JSON configuration files directly from drone imagery through in-context learning. The authors evaluate Gemma 3 and Qwen3-VL across five in-context learning setups on a synthetic cowpea dataset (Helios 3D, 1,120 images at multiple growth stages) and real orthophotos. Results show that VLMs can estimate parameters like plant count and sun azimuth, yet frequently default to contextual priors or dataset averages when visual cues are ambiguous. Supplying explicit grounding information (plant counts, locations) significantly improves accuracy across JSON integrity, geometric, and biophysical metrics. A fine-tuned Qwen3-VL model further boosts performance in several contexts. However, a blind baseline (without the image) sometimes outperforms image-inclusive runs, underscoring the models’ tendency to rely on prompt context rather than genuine visual reasoning. The framework offers a scalable path toward digital twins but does not yet match the accuracy of human experts or conventional computer vision pipelines.

## Method Summary
The task is to generate a complete JSON configuration for an FSPM from a single aerial image of a crop plot. Inputs include synthetic cowpea plot images (381×1080 JPEG) generated via Helios 3D at 10, 30, 50, 70, and 90 days after planting (DAP), with randomized physical and biophysical parameters, and real drone orthophotos (10 DAP). Ground-truth JSONs contain plant counts, coordinates, sun angles, and biophysical traits. Evaluation metrics span three areas: (1) JSON integrity (syntax error rate, missing-key rate, BLEU-4), (2) geometric accuracy (DAP MAE, plant count MAE, Chamfer distance for plant locations, sun elevation/azimuth MAE, leaf pitch MAE), and (3) biophysical trait MAE (leaf pigments, water mass, dry matter, leaf structure). The method tests two VLM families (Gemma 3: 4B/12B/27B; Qwen3-VL: 4B/8B/30B) under five in-context learning configurations: zero-shot, with schema, with few-shot JSON examples, with paired image-text examples, and with additional grounding information. In-context prompts are constructed with a fixed 32K context window via the Ollama API. A fine-tuned Qwen3-VL-32B (LoRA, r=16, α=16) is trained on 1,788 synthetic images. A blind baseline omits the image from the prompt to isolate the effect of visual input.

## Key Results
- VLMs estimate plant-level parameters but often fall back on contextual priors or dataset means when visual cues are weak, leading to performance degradation.
- Providing explicit grounding information (plant counts, locations) significantly reduces errors across all metric categories.
- A fine-tuned Qwen3-VL model improves accuracy in several contexts, yet the blind baseline sometimes outperforms image-inclusive evaluations, confirming strong reliance on prompt context over visual reasoning.

## Why This Works (Mechanism)
The approach leverages the in-context learning capabilities of VLMs: by embedding task instructions, JSON schema, few-shot examples, and grounding data within the prompt, the model generates a structured configuration that respects the provided constraints. Grounding information (e.g., known plant counts and locations) dramatically narrows the solution space, steering the model toward consistent geometric and biophysical parameters even when the image is ambiguous. Fine-tuning on synthetic cowpea data adapts the VLM to the domain-specific visual patterns and parameter distributions, further boosting performance. However, the fact that the blind baseline frequently matches or exceeds image-inclusive results indicates that the models often ignore visual content, relying instead on statistical priors extracted from the prompt context. This suggests that current VLMs struggle with robust visual grounding for this fine-grained mapping task, especially when cues are subtle or task complexity high.

## Foundational Learning
- **In-context Learning**: Why needed: Enables VLMs to perform new tasks without weight updates by providing demonstrations in the prompt; quick check: Can the model produce a valid JSON output for a novel image after seeing only a few input-output pairs in the prompt?
- **Vision-Language Models (VLMs)**: Why needed: Integrate image understanding with text generation to transform visual data into structured outputs; quick check: Can the model accurately describe an image and adhere to a specified JSON schema?
- **Functional-Structural Plant Models (FSPMs)**: Why needed: Simulate plant growth and environment interactions; require detailed configuration to mirror real plots; quick check: What are the essential fields (e.g., DAP, plant positions, leaf optics) needed to initialize an FSPM for a cowpea field?
- **Synthetic Data Generation with Helios 3D**: Why needed: Provides scalable, ground-truth-labeled images for training and evaluation; quick check: How does a procedural plant simulator vary canopy architecture across growth stages?
- **Grounding Information**: Why needed: Supplies explicit constraints that anchor model predictions, reducing ambiguity; quick check: How does providing ground-truth plant locations affect the estimated leaf pitch distribution?
- **JSON Configuration Schema**: Why needed: Defines the structured format required by the FSPM; quick check: Validate that a generated JSON includes all mandatory keys and correct data types (e.g., arrays of coordinates, numeric trait values).

## Architecture Onboarding
- **Component map**: Synthetic Data Generation → Dataset Split → In-Context Prompt Construction → VLM Inference (Gemma3/Qwen3-VL) → JSON Parsing → Metrics Computation → Analysis.
- **Critical path**: (1) Prepare dataset (synthetic or real) with images and ground-truth JSONs; (2) Choose in-context configuration and embed grounding info; (3) Send prompt + image to VLM via Ollama API; (4) Parse the model’s JSON response; (5) Compare against ground truth using defined metrics; (6) Iterate on prompt design or fine-tuning.
- **Design tradeoffs**: Larger models (e.g., 30B) may yield higher fidelity but at greater compute cost; zero-shot requires no labeled examples yet is less accurate than few-shot; adding grounding info improves results but consumes prompt context; fine-tuning boosts performance but needs additional labeled data and training infrastructure.
- **Failure signatures**: High JSON syntax error or missing-key rates; Chamfer distance indicating poor plant location alignment; DAP MAE showing stage misclassification; blind baseline performing as well as or better than image-inclusive runs; inconsistent results across random seeds.
- **Three first experiments**: (1) Replicate the zero-shot baseline on the synthetic test set and report JSON integrity and geometric metrics to establish a reference point. (2) Conduct an ablation on grounding information by comparing the baseline with the +grounding configuration to quantify its impact. (3) Fine-tune Qwen3-VL on a small subset of synthetic images and evaluate against the best in-context baseline on a held-out set, verifying improvement and transferability.

## Limitations
- Uncertainties in Helios 3D procedural generation parameters (soil spectra, sun angles, PROSPECT ranges) prevent exact dataset reconstruction.
- Prompt templates and JSON schema are only partially described; subtle wording differences may alter VLM behavior significantly.
- VLMs often default to prompt priors rather than visual reasoning, limiting accuracy; performance remains below human annotation and conventional computer vision methods.

## Confidence
- Synthetic dataset generation: Low (critical parameters missing)
- Prompt template/schema replication: Low (only examples provided)
- In-context learning efficacy claims: Medium (methods described but reproducibility hindered by above)
- Fine-tuned Qwen3-VL improvement: Low (training details sparse)
- Blind baseline outperforming image-inclusive: High (explicitly reported result)
