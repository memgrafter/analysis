# Causality-Driven Disentangled Representation Learning in Multiplex Graphs
## Quick Facts
- arXiv ID: 2603.24105
- Source URL: https://arxiv.org/abs/2603.24105
- Reference count: 40
- Primary result: CaDeM disentangles common and private embeddings in multiplex graphs via three objectives, achieving state-of-the-art Macro-F1 scores (e.g., 0.9287 on ACM for node classification).

## Executive Summary
This paper introduces CaDeM, a causality-driven self-supervised framework for disentangled representation learning on multiplex graphs. The method addresses the entanglement of shared (common) and layer-specific (private) information by combining three complementary objectives: a matching loss using Generalized Procrustes Analysis to align common embeddings across layers; a self-supervised cross-entropy loss that trains private embeddings to predict the layer index; and a causal loss that approximates backdoor adjustment by stratifying and re-pairing common and private embeddings. Theoretical analysis guarantees that at global optima, common embeddings depend solely on shared latent factors while private embeddings depend only on layer-specific factors. Extensive experiments on synthetic and real-world multiplex datasets demonstrate consistent improvements over state-of-the-art baselines in node and graph classification tasks, and qualitative results on brain data reveal that private embeddings capture interpretable functional networks.

## Method Summary
CaDeM processes a multiplex graph with N layers, each having its own adjacency and features. For each layer ℓ, two parallel single-layer GCN encoders produce a common embedding Cℓ and a private embedding Pℓ. The three loss components are: (i) L_matching, which aligns all Cℓ to a consensus orthonormal reference matrix S computed via Generalized Procrustes Analysis (minimizing Frobenius norm discrepancies); (ii) L_self-supervised, where pooled private embeddings are fed to a predictor ϕ to classify the layer index via cross-entropy, thereby maximizing mutual information between private embeddings and the layer; (iii) L_causal, which approximates backdoor adjustment: for each augmented graph’s private embedding h_P, it is paired with common embeddings h_C’ from other augmented graphs, and a second predictor ψ must correctly classify the layer index irrespective of the paired common embedding. This enforces conditional independence L ⊥ C | P, disentangling common from private factors. The final loss is a weighted sum: L_final = L_matching + α L_self-supervised + β L_causal. After training, embeddings from both branches are combined via Multi-Head Attention for downstream tasks.

## Key Results
- On node classification: Macro-F1 scores of 0.9287 (ACM), 0.8497 (DBLP), 0.6667 (IMDB), and 0.6224 (Freebase).
- On graph classification (HCP dataset): Macro-F1 of 0.6628.
- Ablation studies confirm that all three loss components are necessary; removing any degrades performance.
- Qualitative visualizations on brain data show that private embeddings highlight interpretable task-specific functional networks (e.g., default mode network, visual network).

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Aligning common embeddings across layers via Generalized Procrustes Analysis (GPA) captures shared, layer-invariant factors.
- **Mechanism:** For each layer ℓ, common embedding Cℓ is encouraged to match a unified reference matrix S. S is computed as the orthonormal configuration minimizing total squared discrepancy (Frobenius norm) to all Cℓ. This forces Cℓ to converge to a consensus representation across layers. Theoretical analysis (Theorem 1.1) shows that at optimum, common embeddings become a function of the shared latent factor U alone.
- **Core assumption:** Shared factors exist and are stable across layers; aligning embeddings isolates them from layer-specific noise.
- **Evidence anchors:** Abstract mentions aligning shared embeddings; Section III.B states that this promotes a common component that captures invariant information; internal proofs.
- **Break condition:** If no true shared factors exist, forcing alignment may destroy layer-specific signal or yield degenerate embeddings.

### Mechanism 2
- **Claim:** Maximizing mutual information between private embeddings and layer index via self-supervised cross-entropy loss ensures private embeddings encode layer-specific information.
- **Mechanism:** A prediction head ϕ maps pooled private embeddings to a distribution over layer indices. Minimizing cross-entropy loss L_self-supervised encourages the model to use private embeddings to solve the task. Proposition 1 shows this is equivalent (with expressive ϕ) to maximizing I(P_L; L), i.e., private embeddings must contain information sufficient to identify the layer.
- **Core assumption:** The layer index is a measurable function of layer-specific latent factors V_L; i.e., L ↔ V_L.
- **Evidence anchors:** Abstract says private embeddings capture layer-specific signals; Section III.C states private embeddings act as causal features encoding layer-dependent information; limited external evidence.
- **Break condition:** If the layer index is not a sufficient statistic for V_L (e.g., continuous latent factors not captured by discrete L), the loss may not fully recover V_L.

### Mechanism 3
- **Claim:** Causal loss via stratified pairing approximates backdoor adjustment, ensuring common embeddings do not predict layer index after conditioning on private embeddings—i.e., common embeddings are disentangled from layer-specific confounders.
- **Mechanism:** For each augmented graph’s private embedding h_P^i, the loss pairs it with common embeddings h_C^j from other graphs (stratification). The predictor ψ must correctly classify the layer index of the private embedding regardless of which common embedding it is paired with. This enforces conditional independence L ⊥ C_L' | P_L (Proposition 2). Combined with L_matching, this drives common embeddings to depend only on U.
- **Core assumption:** Common embeddings act as confounders between private embeddings and the layer-prediction task; stratification blocks the backdoor path P_L ← {G, X} → C → target.
- **Evidence anchors:** Abstract mentions applying backdoor adjustment to ensure common embeddings capture only global information; Section III.C describes approximating backdoor adjustment via confounder stratification and re-pairing; corpus lacks direct evidence.
- **Break condition:** If the confounder structure is more complex (e.g., C_L not a direct cause of both P_L and target) or if augmentation fails to sample confounder realizations adequately, stratification may not fully block backdoor paths.

## Foundational Learning
- **Concept:** Multiplex Graphs
  - *Why needed here:* The input structure is a set of layers sharing nodes but with different edge types/relations. The method’s entire design (parallel encoders, layer-wise losses) depends on this structure.
  - *Quick check question:* If layers share only partial node sets, how would CaDeM’s alignment objective need modification?
- **Concept:** Disentangled Representations
  - *Why needed here:* The goal is to separate common (U) and private (V_L) factors explicitly. Without disentanglement, common embeddings may leak layer-specific info, hurting generalization and interpretability.
  - *Quick check question:* Why is orthogonality (used in some baselines) insufficient for true disentanglement compared to the causal adjustment in CaDeM?
- **Concept:** Backdoor Adjustment
  - *Why needed here:* To formally remove spurious correlations where common embeddings (as confounders) create false associations between private embeddings and the layer-prediction task.
  - *Quick check question:* In the causal graph P_L ← {G, X} → C_L → target, why is conditioning on C_L sufficient to block the backdoor?
- **Concept:** Generalized Procrustes Analysis (GPA)
  - *Why needed here:* Provides a mathematically grounded way to compute a consensus reference S from multiple common embeddings, enforcing alignment without requiring pairwise matching or explicit correspondence.
  - *Quick check question:* How does the orthonormal constraint (S⊤S = I) and zero-mean constraint (S⊤1 = 0) aid identifiability of shared factors?
- **Concept:** Self-Supervised Learning via Prediction
  - *Why needed here:* The self-supervised loss uses the layer index as a supervisory signal to maximize mutual information with private embeddings, avoiding manual labels.
  - *Quick check question:* What would be the effect of replacing the discrete layer index with a continuous proxy (e.g., layer-level graph statistics) on the disentanglement guarantee?

## Architecture Onboarding
**Component map:** Multiplex input graph -> Parallel GCN encoders (per layer) -> Common embeddings Cℓ and private embeddings Pℓ -> Common reference S via GPA -> Graph augmentation (node subsampling, Gaussian noise) -> Pooling (mean/sum) -> Graph-level h_C, h_P -> Predictor ϕ (layer index from h_P) -> Predictor ψ (layer index from h_P ⊕ h_C’) -> Losses: L_matching (Cℓ vs S), L_self-supervised (ϕ), L_causal (ψ with stratified pairings) -> Combined embeddings via Multi-Head Attention for downstream tasks.

**Critical path:** For each training iteration: (1) Forward pass through both encoders for all layers to obtain Cℓ, Pℓ. (2) Compute consensus S via Generalized Procrustes Analysis on current Cℓ. (3) Apply graph augmentation (node subsampling and noise) to generate N’ augmented single-layer graphs per layer. (4) Pool augmented graphs to obtain h_C, h_P. (5) Compute L_self-supervised by feeding h_P to ϕ and minimizing cross-entropy against true layer index. (6) Compute L_causal by pairing each h_P with h_C’ from other augmented graphs and feeding concatenated (h_P, h_C’) to ψ; minimize cross-entropy. (7) Compute L_matching as Frobenius norm between each Cℓ and S. (8) Combine losses with weights α and β and backpropagate.

**Design tradeoffs:** Loss weighting (α, β) balances the three objectives; high β may force common embeddings to be uninformative, while high α may cause private embeddings to leak shared signal. Graph augmentation parameters (number N’, subsampling ratio r, noise σ) affect memory and the quality of stratification; too much distortion harms layer-specific structure. The orthonormality and zero-mean constraints in GPA ensure identifiability but require centering, which might not suit all downstream tasks.

**Failure signatures:** (1) Private embeddings collapse to nearly identical across layers: L_self-supervised too weak or ϕ not expressive. (2) Common embeddings still predict layer index: L_causal or L_matching weight too low; confounder not removed. (3) Private embeddings leak into common: L_self-supervised dominates, pushing shared factors into private branch. (4) Augmentation distortion: If r too small or σ too large, augmented graphs lose meaningful layer-specific structure, harming L_causal estimation.

**First 3 experiments:** (1) Synthetic dataset Syn1 (distinct structures, shared features) verifies that private embeddings best predict their own layer’s labels while common embeddings capture shared structure. (2) Syn2 varies the trade-off parameter γ (simulated shared factor strength) and plots ARI for common and private embeddings against shared/private community labels, confirming complementary capture. (3) HCP brain data visualization: Inspect top nodes in private embeddings per layer (co-activation vs anti-activation) to check if they highlight known functional networks (e.g., default mode network, visual network) in a task-specific manner.

## Open Questions the Paper Calls Out
- **Temporal extension:** How can CaDeM be extended to dynamic and temporal multiplex graphs where causal and confounding factors evolve over time?
- **Alternative self-supervised targets:** What alternative self-supervised prediction targets could replace the layer index, particularly when layer differences are subtle or continuous?
- **Partial node overlap:** How can CaDeM be adapted for partially overlapping multiplex graphs where node identities are not aligned across layers?
- **Approximation error of backdoor adjustment:** How effective is the stratification approximation of backdoor adjustment, and does it truly remove confounding in practice?

## Limitations
- The exact implementation of stratified pairing (e.g., number of pairings K, concatenation vs. addition) is unreported, which could affect replication and performance.
- The orthonormality constraint in GPA may oversimplify shared factors, potentially harming expressiveness on layers with divergent scales or non-linear relationships.
- The assumption that discrete layer index sufficiently captures continuous layer-specific latent factors V_L lacks validation; L_self-supervised may be inadequate if V_L is high-dimensional or continuous.

## Confidence
- Mechanism 1 (GPA alignment isolates U): High – supported by Theorem 1.1 and internal evidence.
- Mechanism 2 (Private embeddings encode L via self-supervision): Medium – theoretical equivalence holds but limited external validation; relies on layer index as proxy.
- Mechanism 3 (Causal loss disentangles via stratification): Medium – novel operationalization; theoretical justification present but no corpus precedent; approximation error not analyzed.
