# Selective Deficits in LLM Mental Self-Modeling in a Behavior-Based Test of Theory of Mind

## Quick Facts
- arXiv ID: 2603.26089
- Source URL: https://arxiv.org/abs/2603.26089
- Reference count: 23
- Primary result: Nonthinking LLMs show a selective deficit in self-modeling (epistemic ignorance) but reach human-level on other-modeling; thinking LLMs with chain-of-thought achieve near-human performance across all Theory of Mind components.

## Executive Summary
This study investigates whether large language models (LLMs) genuinely represent mental states or merely mimic Theory of Mind (ToM). Researchers designed a behavior-based text game where models act as players, selecting actions (ask/tell/pass) based on dynamic knowledge of self and others. Testing 28 LLMs and humans across four ToM components—self-knowledge, false belief, teammate knowledge, and teammate vs. opponent—they found that nonthinking LLMs (released before mid-2025) failed all tasks. Newer nonthinking LLMs reached human-level accuracy on other-modeling tasks but still failed self-modeling. Thinking LLMs (afforded chain-of-thought reasoning traces) achieved near-human performance across all components. Load experiments showed nonthinkers were impaired by tracking epistemic state transitions but not by additional irrelevant events, suggesting limited working memory. Humans performed uniformly well. The findings indicate LLMs lack robust causal mental models for self-awareness unless provided with external reasoning scaffolds.

## Method Summary
The paradigm positions the LLM as Player A in a first-person text game. The model reads a scenario describing movements of players (A, teammate B, opponents C/D) and manipulations of containers (e.g., box, basket) holding an object (e.g., apple). The scenario updates each player’s knowledge about the object’s location based on their presence/absence during events. The model must then select an action: Ask a specific player, Tell a specific player, or Pass. The correct action depends on the model’s (i.e., Player A’s) own epistemic state and the epistemic states of others, probing four ToM components: self-knowledge (awareness of one’s own ignorance), false belief (recognizing others’ incorrect beliefs), teammate knowledge (tracking teammate’s accurate beliefs), and teammate vs. opponent (strategic deception). Inputs are structured prompts containing game rules and the scenario text. Primary metrics are accuracy per component. The procedure compares two conditions: nonthinking (single forward pass, output constrained to first token action) and thinking (chain-of-thought generation followed by action). Human participants completed the same task via a web interface. Scoring uses a mapping table that defines correct actions for each epistemic state configuration, counting some alternative strategic actions (e.g., lying to opponents) as successes.

## Key Results
- Nonthinking LLMs released before mid-2025 failed all ToM tasks at near-chance levels.
- Newer nonthinking LLMs achieved human-level performance on other-modeling tasks (false belief, teammate knowledge, teammate vs. opponent) but still failed self-modeling, showing a selective deficit.
- Thinking LLMs (with chain-of-thought) achieved near-human performance across all four ToM components.
- Load experiments revealed that nonthinking LLMs’ performance degraded with increased epistemic state transitions (tracking multiple belief updates) but remained robust to increased irrelevant events, indicating a limited-capacity working memory for mental state tracking.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Nonthinking LLMs have a specific, persistent deficit in representing their own epistemic ignorance (self-knowledge ToM).
- **Mechanism:** Models fail to construct or utilize a first-person perspective model that distinguishes between knowledge acquired directly and knowledge that might be outdated due to unobserved events, creating a blind spot for their own potential ignorance.
- **Core assumption:** Success on other-modeling tasks indicates the model can track others’ epistemic states; failure on self-modeling indicates this capability does not generalize to the self.
- **Evidence anchors:** [abstract] "even frontier LLMs fail at our self-modeling task - unless afforded a scratchpad... nonthinking LLMs... still failed self‑modeling." [section 3] "no LLM achieves notably above chance performance... on the self‑modeling task... Self-knowledge stands on stark contrast, correlating with no other task."
- **Break condition:** A release of a capable nonthinking LLM (single forward pass) that achieves >80% accuracy on the self-knowledge task without chain-of-thought.

### Mechanism 2
- **Claim:** Chain-of-thought (CoT) reasoning traces enable models to overcome the self-modeling deficit by externalizing and incrementally updating a world model that includes their own epistemic state.
- **Mechanism:** The generation of intermediate text allows the model to recursively apply rules (e.g., "I left the room, so I don't know what happened after") and maintain a coherent first-person narrative, effectively simulating a mental workspace.
- **Core assumption:** The reasoning trace functionally reconstructs a causal model of the scenario, including the player's knowledge boundaries; success correlates with adopting a first-person ("I") rather than second-person ("you") framing.
- **Evidence anchors:** [abstract] "thinking LLMs (with chain-of-thought) achieved near-human performance across all components." [section 3] "taking the first- rather than second-person perspective is associated with better performance" in self-modeling.
- **Break condition:** A model with strong CoT capability that still fails the self-knowledge task even when traces are explicitly constrained to first-person framing.

### Mechanism 3
- **Claim:** The performance of nonthinking LLMs on other-modeling tasks is constrained by a limited-capacity working memory for tracking epistemic state transitions (ESTs) within a single forward pass.
- **Mechanism:** The model's internal representations can hold a finite number of distinct agent-state mappings (e.g., "B believes X is in Y"). Increasing the number of times these mappings must be updated (ESTs) exceeds this capacity, causing errors, while adding irrelevant descriptive events (event load) does not.
- **Core assumption:** Errors are not due to general scene complexity but specifically to the cognitive load of updating and retaining multiple agents' belief states.
- **Evidence anchors:** [abstract] "nonthinkers were impaired by tracking epistemic state transitions but not by additional irrelevant events, suggesting limited working memory." [section 3] Figure 5 shows load effects for ESTs but not event count.
- **Break condition:** Nonthinking LLMs showing equal robustness to increased EST load and event load in future replications with larger models.

## Foundational Learning
- **Concept:** Theory of Mind (ToM) Components (Self-Knowledge, False Belief, Knowledge vs. Belief, Agent Intent).
  - **Why needed here:** The paradigm isolates these four components; understanding the distinction between *knowing* (direct observation) and *believing* (inferred from past observation, potentially false) is essential to grasp scenario logic and correct actions.
  - **Quick check question:** If you saw an object placed in a box, left the room, and someone moved it while you were gone, do you *know* or *believe* (truly/falsely) what's in the box?

- **Concept:** Action-Based vs. Description-Based Assessment.
  - **Why needed here:** Asking an LLM to *describe* a mental state can be solved by pattern matching. Requiring a strategic *action* (Ask/Tell/Pass) based on that understanding forces online computation and is out-of-distribution.
  - **Quick check question:** Why is selecting "Pass" a more demanding test of ToM than answering "the basket" in a classic false-belief question?

- **Concept:** Chain-of-Thought (CoT) as an External Scratchpad.
  - **Why needed here:** The "thinking" vs. "nonthinking" distinction is fundamental. The mechanism hypothesized is that CoT tokens provide a workspace to build and manipulate the mental model. Understanding this is key to interpreting performance differences.
  - **Quick check question:** If a model must decide in one forward pass (nonthinking), what internal resource becomes critically limiting compared to generating a reasoning trace?

## Architecture Onboarding
- **Component map:** Game Engine & Scenario Generator -> Model Interface -> Scoring & Analysis Module -> Human Baseline Interface.
- **Critical path:** 1. Validate core paradigm: implement basic game loop with canonical scenarios; run on a known thinking model (e.g., GPT-4) to ensure >90% accuracy. 2. Establish nonthinking baseline: run same set on a known weak nonthinking model (e.g., GPT-3.5); expect near-chance, especially on self-knowledge. 3. Reproduce load effect: for a competent nonthinking model on other-modeling, run independent EST_load and event_load sets; verify EST load harms but event load does not.
- **Design tradeoffs:** Scenario complexity vs. parsability: more events/ESTs increase load sensitivity but risk confusing successful models; paper’s approach of simple base scenarios with controlled load batches is sound. Action space restriction: limiting to Ask/Tell/Pass forces discrete scoreable choices but may oversimplify human-like strategy; paper mitigates by allowing private lies in Tell.
- **Failure signatures:** Global failure (all nonthinkers pre-mid-2025): ~25% accuracy (chance). Selective self-modeling failure: >80% on other-modeling, ~50% on self-knowledge. CoT dependency: accuracy jumps from ~50% to >90% on self-knowledge when enabled. Inappropriate tell reflex: nonthinkers frequently select "Tell" when "Pass" is correct.
- **First 3 experiments:** 1. Replicate core asymmetry: run 26-base scenario set on latest nonthinking model; confirm human-level other-modeling, chance self-modeling. 2. Controlled load replication: run independent event_load and EST_load sets; quantify performance delta; verify EST load harms, event load does not. 3. CoT ablation & perspective analysis: for a strong thinking model, force two CoT conditions: (a) standard, (b) prepend "Think in first-person as Player A." Analyze traces for "I" vs. "you" frequency and correlate with self-knowledge accuracy.

## Open Questions the Paper Calls Out
- **Question:** Do the self-modeling deficit in nonthinking LLMs and the benefit of chain-of-thought generalize to other Theory of Mind tasks and game paradigms?
  - **Basis in paper:** [explicit] The authors state in the Discussion: "It would be of interest to evaluate a wider array of ToM tasks... The use of a diverse array of game setups will also help establish the generality of these findings."
  - **Why unresolved:** The study uses a single custom paradigm; it is unclear whether the selective self-modeling failure and CoT remediation are robust across different ToM evaluations.
  - **What evidence would resolve it:** Replicate with established ToM benchmarks (e.g., false-belief variations, social deception tasks) and varied game designs while comparing nonthinking vs. thinking modes. Consistent patterns confirm generality.

- **Question:** What internal representational mechanisms enable chain-of-thought to improve self-modeling performance in LLMs?
  - **Basis in paper:** [explicit] The authors call for identifying "the internal mechanisms underlying LLM performance" and note that "Zhu et al. [2024] offers some evidence that probes can identify belief states."
  - **Why unresolved:** It is unknown whether CoT merely triggers memorized response patterns or facilitates genuine causal modeling of self-knowledge; representational changes during CoT remain uncharacterized.
  - **What evidence would resolve it:** Apply neural probing techniques (e.g., linear probes, representational similarity analysis) to LLM internal states during self-modeling tasks with and without CoT. Finding self-knowledge representations that emerge only during CoT would indicate constructive modeling.

- **Question:** Why is self-knowledge modeling uniquely impaired in nonthinking LLMs (uncorrelated with other ToM components), and why does chain-of-thought specifically remediate this deficit?
  - **Basis in paper:** [inferred] Nonthinking models show self-knowledge performance uncorrelated with any other task, while thinking models show stronger inter-task correlations (Fig. 4). Only thinking models achieve human-level self-modeling (Fig. 3).
  - **Why unresolved:** The cognitive basis for this dissociation is unclear; it may reflect an inability to adopt a first-person perspective without external scaffolding.
  - **What evidence would resolve it:** Analyze CoT traces for linguistic framing (first-person vs. second-person) and correlate with self-modeling success; systematically manipulate prompting to encourage self-referential processing; test if training on self-reflective data improves nonthinking self-modeling.

- **Question:** What is the cognitive bottleneck underlying the sensitivity of other-modeling to epistemic state transition load in nonthinking LLMs?
  - **Basis in paper:** [inferred] Nonthinking LLMs degrade with increased epistemic state transitions but not added irrelevant events (Fig. 5), suggesting a limited-capacity working memory for tracking mental states.
  - **Why unresolved:** The paper speculates about working memory but does not pinpoint whether the limitation stems from context window constraints, lack of iterative updating, or architectural factors; the nature of the "transitions" causing difficulty is not dissected.
  - **What evidence would resolve it:** Design experiments separating the number of state updates from update complexity; measure performance scaling with context length; use mechanistic interpretability to track if models maintain intermediate belief representations across transitions in a single forward pass.

## Limitations
- Model identifiers are not fully specified; only provider series and release timeframe are given.
- The exact algorithmic specification for generating the 26 base scenarios and their load variants is not provided; requires reverse-engineering from examples.
- The exact prompt formatting for "thinking" vs. "nonthinking" conditions (e.g., instruction phrasing) is unspecified.

## Confidence
- Self-modeling deficit in nonthinking LLMs: Medium
- CoT enables near-human performance across ToM components: Medium
- EST vs. event load dissociation (limited working memory): Medium

## Next Checks
- Core asymmetry replication: Run the 26-base scenario set on a current nonthinking model (e.g., Claude Sonnet 3.5 with `max_tokens=1` constraint). Confirm self-knowledge accuracy remains significantly lower than other-modeling.
- Load metric verification: Programmatically count events (actions/entrances/exits) and epistemic state transitions (ESTs) in all generated load variants. Validate that EST load scenarios increase EST count while keeping total events matched to event-load controls.
- CoT perspective analysis: For a strong thinking model (e.g., o1), force two CoT conditions: (a) standard, (b) prepend "Reason in first-person as Player A." Quantify "I" vs. "you" token frequency in traces and correlate with self-knowledge accuracy.
