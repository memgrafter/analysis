# Sparse Auto-Encoders and Holism about Large Language Models

## Quick Facts
- arXiv ID: 2603.26207
- Source URL: https://arxiv.org/abs/2603.26207
- Reference count: 5
- Primary result: SAE features are numerous and exhibit duplication, absorption, and composition, making them implausible as atomic semantic units; instead, they fit a holistic network model provided the meaningful feature space is discrete.

## Executive Summary
The paper investigates whether sparse auto-encoder (SAE) features extracted from large language models (LLMs) support a decompositional view of meaning—where word meanings are built from a finite set of atomic semantic features—or a holistic view—where meaning arises from relational patterns among many expressions. Using SAEs trained on LLM activations, the authors find that SAE features are exceedingly numerous (millions), highly specific, and suffer from artifacts like duplication, absorption, and composition. These properties undermine the notion that SAE features are basic semantic atoms. Instead, they propose treating features as additional nodes in a holistic meaning-similarity network. However, the continuous nature of activation spaces risks an infinite regress of interpolated features; the holistic picture survives only if the set of meaningful features is discrete or countable. The conclusion: LLM semantics are best understood holistically, and discreteness of meaning-bearing features is a necessary condition.

## Method Summary
The authors employ sparse auto-encoders (SAEs) to extract interpretable latent directions from the internal activations of transformer-based LLMs. SAEs consist of a single wide hidden layer with an L1 sparsity penalty, which forces the model to use many distinct features rather than a few reusable ones. Activations from specific layers (e.g., MLP or residual stream) are collected from a text corpus and used as training data. After training, the feature dictionary (the decoder weight columns) represents candidate semantic directions; each feature is interpreted by examining its top-activating examples. The analysis focuses on feature count, specificity, and empirical issues such as duplication (multiple features with similar vectors), absorption (a general feature suppressing activation of a related specific feature), and composition (features that combine multiple concepts). To assess the holistic interpretation, feature vectors are compared to token embeddings to see whether meanings emerge from similarity relations rather than linear combinations of a small set of atoms. Additionally, the continuity of the feature space is probed by generating interpolated directions between known features and evaluating their meaningfulness.

## Key Results
- SAE features are extremely numerous (often millions) and highly specific, contradicting the expectation of a small set of atomic semantic primitives.
- SAE features exhibit duplication, absorption, and composition, indicating that they do not function as clean, independent meaning constituents.
- The continuity of activation spaces implies an infinite regress of interpolated features; however, the holistic network model remains viable if the meaningful feature space is discrete or countable.

## Why This Works (Mechanism)
The paper presents three interconnected mechanisms that explain why SAE features undermine decompositional semantics and support a holistic account.

**Mechanism 1: Feature proliferation undermines atomicity.**  
SAEs, due to the L1 sparsity constraint and a wide hidden layer, learn a large dictionary of feature directions (millions). This proliferation contradicts the idea that meaning can be decomposed into a finite set of basic atoms; if such atoms existed, a sparse representation would likely reuse a small subset across many inputs.

**Mechanism 2: Artifacts reveal non-compositional structure.**  
Optimization pressures lead to duplication (redundant features with similar vectors), absorption (a general feature suppressing activation of a related specific feature), and composition (features that combine multiple concepts, e.g., "red square"). These are not properties of a clean compositional lexicon but reflect the distributed nature of LLM representations, which align with a holistic network where features are interdependent.

**Mechanism 3: Continuity requires discreteness for holism.**  
Because activation spaces are continuous, between any two meaningful feature directions there exist infinitely many interpolated directions. Without a principled discreteness, the set of meaningful features could be uncountable, overwhelming the network model of finite nodes. The authors argue that human-like meaning is discrete; thus, the holistic picture survives if only a countable subset of directions corresponds to genuine semantic distinctions.

## Architecture Onboarding
The pipeline begins with raw text, which is processed by a transformer to produce token and contextual embeddings in the residual stream. SAEs are then applied to activations from specific sublayers (e.g., MLPs or residual blocks) to map each activation pattern to a sparse set of feature activations from a large dictionary. Optionally, cross-layer transcoders can be used to unify features across layers.

Component map: Input text -> LLM (transformer) -> token/contextual embeddings (residual stream) -> SAE(s) on specific layers -> sparse feature activations. Optional: cross-layer transcoders.

**Critical path**: The core workflow is: extract layer activations on a corpus -> train SAE with L1 sparsity -> interpret feature vectors and their activation patterns -> analyze feature properties (count, duplication, absorption, composition) -> relate features to semantic similarity networks.

**Design tradeoffs**:
- Feature granularity: More features increase reconstruction fidelity but risk extreme specificity and artifacts.
- Sparsity strength: Stronger L1 yields fewer active features per input but may omit relevant concepts; weaker L1 leads to polysemantic features.
- Scope: Separate SAEs per layer are simpler but lack cross-layer consistency; cross-layer transcoders improve consistency at the cost of complexity.

**Failure signatures**:
- Excessive duplicate features (high cosine similarity between dictionary vectors).
- Composite features that combine multiple independent concepts (e.g., "red square") indicating over-sparsification.
- Absorption where a general feature consistently activates at the expense of a specific one.
- Interpolated directions between known features that are not semantically meaningful, suggesting continuous noise.

**First 3 experiments**:
1. Train SAEs with varying feature counts (e.g., 4k, 16k, 100k) on a fixed layer and measure reconstruction error vs. interpretability (via automated labeling).
2. Quantify duplication by computing pairwise cosine similarity of feature vectors; measure absorption by correlating activations of general vs. specific features; detect composition by analyzing co-activation patterns of primitive features.
3. Generate interpolated directions between pairs of human-labeled features and evaluate meaningfulness using LLM prompting or clustering.

## Open Questions the Paper Calls Out
1. **Can SAE features serve as basic semantic atoms?** The paper documents duplication, absorption, and composition that undermine their status as independent, atomic constituents.  
2. **Does the continuity of activation spaces force an infinite regress for holistic networks, requiring discreteness?** The authors argue holism requires the meaningful feature set to be discrete or countable; otherwise the network model collapses.  
3. **How to distinguish meaningful SAE features from noise due to polysemanticity and superposition?** Current methods lack robust criteria to separate truly semantic features from incidental byproducts of network training.

## Limitations
- SAE results depend heavily on training hyperparameters and the chosen corpus; no standard evaluation protocols exist for duplication, absorption, or composition.
- The thresholds for what constitutes duplicate or composite features are not rigorously defined, making comparisons across studies difficult.
- The discreteness assumption about meaning is philosophical and lacks direct empirical validation; the paper’s argument rests on intuitions rather than data.

## Confidence
- Numerous specific features: Medium (empirical observations but sensitive to sparsity settings)
- Artifacts (duplication, absorption, composition): Medium (observed in multiple SAE variants, though may be optimization artifacts)
- Discreteness requirement: Low (conceptual argument, not empirically tested)

## Next Checks
1. Perform a systematic hyperparameter sweep for SAE training (sparsity coefficient, expansion factor) on a fixed model and corpus to establish robust feature statistics.
2. Define and validate quantitative metrics for duplication (e.g., cosine similarity > 0.95), absorption (negative activation correlation), and composition (co-activation above baseline) and test them with human judgments on a feature sample.
3. Investigate discreteness by generating many interpolated directions between known semantic features and evaluate whether they correspond to intelligible meanings via LLM-based scoring or human evaluation.
