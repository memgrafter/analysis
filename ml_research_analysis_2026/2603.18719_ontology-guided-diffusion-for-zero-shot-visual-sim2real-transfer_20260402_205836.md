# Ontology-Guided Diffusion for Zero-Shot Visual Sim2Real Transfer

## Quick Facts
- **arXiv ID:** 2603.18719
- **Source URL:** https://arxiv.org/abs/2603.18719
- **Reference count:** 14
- **Primary result:** A neuro-symbolic framework using a realism ontology and graph-based embeddings conditions a diffusion model, achieving state-of-the-art sim2real translation with minimal paired data.

## Executive Summary
Bridging the simulation-to-reality gap for visual domains typically requires extensive paired real data. This paper introduces Ontology-Guided Diffusion (OGD), a zero-shot method that models visual realism as a structured set of interpretable traits (e.g., lighting, materials) organized in a causal knowledge graph. The framework first infers a synthetic image's trait probabilities, propagates them through a Graph Neural Network to produce a coherence-aware embedding, and uses a PDDL planner to generate a consistent, ordered edit plan. Both the graph embedding and the natural-language plan condition an instruction-guided diffusion model to translate the synthetic image toward realism. The approach demonstrates superior performance on multiple sim2real benchmarks, significantly outperforming unstructured prompt-based diffusion methods.

## Method Summary
OGD is a three-stage neuro-symbolic pipeline for zero-shot sim2real image translation. First, a frozen CLIP encoder extracts features from a synthetic image, and lightweight MLP heads (trained on 140 unlabeled images with VLM pseudo-labels) predict probabilities for a predefined set of realism traits. Second, these probabilities initialize nodes in a static, manually defined knowledge graph where edges encode signed causal/perceptual relationships (e.g., "bright sunlight" and "hard shadows" are supportive; "bright sunlight" and "overcast" are opposing). A GraphSAGE GNN propagates information across this graph, trained with a signed similarity loss (to align supportive trait embeddings and separate opposing ones) and a repulsion loss, resulting in a structured embedding `G_s` that captures global realism coherence. Third, the binarized trait vector defines an initial state `b_s`; a target realism state `b_t` (from a reference real image or specification) is combined with `b_s` and fed to a PDDL planner (Fast Downward) using a fixed domain that encodes trait dependencies as action preconditions/effects. The planner outputs a valid sequence of trait-editing actions, which is mapped to a structured natural language prompt. Finally, an InstructPix2Pix diffusion model is modified to condition on both the graph embedding `G_s` (injected as additional cross-attention tokens) and the structured prompt. The model is trained on a small set of paired synthetic-real images using a denoising objective plus an auxiliary loss that aligns the generated image's extracted graph embedding with the target's.

## Key Results
- Graph-based realism embeddings achieve 98.4% accuracy in a meta-classifier task distinguishing real from synthetic images, outperforming embeddings from traits without GNN propagation (97%).
- For sim2real translation, OGD reduces TraitDist to 0.593, LPIPS to 0.275, and increases SSIM to 0.562, substantially surpassing InstructPix2Pix and ControlNet.
- Ablation studies confirm the necessity of both the graph conditioning and the symbolic planning components for achieving the full performance gain.

## Why This Works (Mechanism)

### Mechanism 1
*Claim:* Graph-based realism embeddings capture trait interdependencies, yielding representations that better distinguish real from synthetic imagery than unstructured features.
*Mechanism:* A frozen CLIP encoder extracts visual features, which are mapped to realism trait probabilities via supervised MLP heads. These probabilities initialize nodes in a static knowledge graph (edges encode signed causal/perceptual relations). A GraphSAGE GNN propagates information across the graph, trained with a signed similarity loss (align supportive trait embeddings, separate opposing ones) and a repulsion loss over unconnected nodes. The resulting node-level embeddings retain trait-specific semantics while encoding global coherence.
*Core assumption:* Visual realism is not a monolithic property but emerges from interacting, often constrained, appearance-level cues; explicitly modeling these relationships yields a more discriminative latent.
*Evidence anchors:* [abstract] "graph-based embeddings achieve 98.4% accuracy... outperforming baselines (97% for traits without GNN)." [section 3.2] Details GNN architecture, signed loss, and retention of full node embeddings. [corpus] Weak direct support; neighboring papers focus on other sim2real modalities but do not evaluate graph-based realism embeddings.
*Break condition:* If the fixed ontology's edge signs/weights are systematically incorrect for a given domain, or if trait predictors are highly inaccurate, the propagated embeddings will misrepresent realism structure and lose discriminative power.

### Mechanism 2
*Claim:* Symbolic planning via PDDL generates a minimal, causally consistent sequence of visual edits to transform a synthetic image's realism state toward a target, ensuring perceptual plausibility.
*Mechanism:* Trait probability vectors from an image are binarized (fixed threshold) to define boolean realism states (initial `b_s`, goal `b_t`). A static PDDL domain encodes realism traits as predicates and dependencies as action preconditions/effects. A planner (Fast Downward) computes an action sequence that respects these constraints. This sequence is mapped to a structured natural-language prompt for diffusion conditioning.
*Core assumption:* Realism traits have non-independent, physically/perceptually grounded dependencies; flipping traits arbitrarily yields implausible images. Planning enforces feasibility.
*Evidence anchors:* [abstract] "a PDDL planner generates a consistent sequence of visual edits." [section 3.3] Describes PDDL problem generation, static domain, and planner use; notes that infeasible goal states correctly yield "no valid plan." [corpus] No direct evidence; neighboring works do not integrate symbolic planning for sim2real.
*Break condition:* If the target realism state is infeasible under the ontology or if the PDDL domain's action definitions are incomplete/modelled incorrectly, the planner will fail to produce a valid plan or produce a plan that violates real-world constraints.

### Mechanism 3
*Claim:* Conditioning a diffusion model on both the realism graph embedding (structured latent) and the PDDL-derived prompt (ordered instructions) yields more coherent sim2real translations than either alone or unstructured prompts.
*Mechanism:* The GNN's node embeddings `Z` are linearly projected and added with positional embeddings, then concatenated with text encoder outputs from the structured prompt. These joint tokens attend in the diffusion UNet's cross-attention layers. An auxiliary realism alignment loss (`L_KG`) encourages the generated image's extracted realism embedding to match the target's.
*Core assumption:* The diffusion model can effectively fuse procedural linguistic guidance (what to edit, in order) with structured relational knowledge (how traits cohere) to produce semantically and perceptually consistent edits.
*Evidence anchors:* [abstract] "Both the graph embedding and planned edits condition an instruction-guided diffusion model." [section 3.4] Details injection (Eq. 7), alignment loss (Eq. 9), and training objective (Eq. 10). Ablations show both components contribute (Table 3). [corpus] Neighboring diffusion-based sim2real methods use only prompts or geometric cues; none condition on a jointly learned graph+plan.
*Break condition:* If the graph embedding and textual prompt conflict or if the alignment loss weight `λ_KG` is poorly tuned, the diffusion process may receive contradictory signals, leading to blurry, inconsistent, or semantically distorted outputs.

## Foundational Learning
- **Concept: Diffusion Models (e.g., InstructPix2Pix)**
  - *Why needed here:* OGD builds on an instruction-guided diffusion backbone; understanding denoising, cross-attention conditioning, and text-to-image editing is essential to grasp how graph tokens and prompts modulate generation.
  - *Quick check question:* What is the role of the noise prediction network `ϵ_θ` in the diffusion objective (Eq. 8), and how does conditioning input `c` influence its predictions?
- **Concept: Graph Neural Networks (GraphSAGE)**
  - *Why needed here:* The GNN propagates trait information across the fixed realism ontology, producing embeddings that encode relational constraints. Understanding message passing and inductive biases is key to seeing why graph structure matters.
  - *Quick check question:* How do the signed similarity loss (Eq. 4) and repulsion loss (Eq. 5) jointly shape the geometry of node embeddings in the GNN's output space?
- **Concept: Symbolic Planning (PDDL)**
  - *Why needed here:* OGD formulates realism translation as a planning problem; comprehending predicates, actions, preconditions, and effects is necessary to understand how edit sequences are derived from trait states.
  - *Quick check question:* Given a synthetic image's binarized trait vector `b_s` and a target `b_t`, what does it mean if the PDDL planner returns "no plan"? What would an action's effect look like in terms of trait toggling?
- **Concept: CLIP-based Zero-Shot Classification**
  - *Why needed here:* CLIP provides frozen, high-level visual features for trait prediction; the MLP heads are trained on VLM-annotated data to map these features to realism traits. This bridges generic vision to domain-specific appearance cues.
  - *Quick check question:* Why are the CLIP encoder and trait predictors trained only on a small set of unpaired images (140), yet the approach remains zero-shot at inference for new simulators? What role does the VLM play?

## Architecture Onboarding
- **Component map:** Trait Extractor (CLIP+MLP) -> Realism GNN (GraphSAGE) -> Trait Binarization -> PDDL Planner (Fast Downward) -> Prompt Generator -> Diffusion Model (InstructPix2Pix UNet with modified cross-attention)
- **Critical path:** 
  1. Input synthetic image `x_s` -> CLIP features -> MLP heads -> trait probabilities `p_s`.
  2. `p_s` -> (a) GNN -> realism embedding `G_s`; (b) binarize -> `b_s`.
  3. Target realism (from reference image or spec) -> `p_t`, `b_t`.
  4. `b_s` + `b_t` -> PDDL planner -> action sequence -> structured prompt.
  5. `G_s` + prompt -> condition diffusion -> edit `x_s` to `x'`.
- **Design tradeoffs:**
  - *Fixed ontology vs. adaptable structure:* Ontology is static and manually defined (ensures generalizability, no data-driven overfitting) but may miss domain-specific realism nuances.
  - *Zero-shot inference vs. training data:* Only 140 unpaired images needed for trait/GNN training, but quality depends on VLM annotation accuracy and CLIP's feature generality.
  - *Graph tokens vs. computational cost:* Adding `N` node tokens increases cross-attention memory; tradeoff between richness and efficiency.
  - *Symbolic planning vs. flexibility:* PDDL enforces consistency but can be brittle to thresholding or incomplete domain models.
- **Failure signatures:**
  - **Poor realism discrimination:** Meta-classifier accuracy near random; likely due to inaccurate trait predictors or mis-specified graph edges.
  - **Planner failure:** Returns "no valid plan" for most inputs; check binarization threshold or goal-state feasibility.
  - **Unrealistic outputs:** High LPIPS, low SSIM; examine if graph tokens are being ignored (ablate) or if alignment loss weight is too low.
  - **Semantic drift:** Generated image alters scene layout/objects; possibly because trait predictors are triggered by semantic rather than appearance cues, or prompt is too generic.
- **First 3 experiments:**
  1. **Realism representation evaluation:** Train meta-classifier on GNN embeddings vs. CLIP features/trait probabilities; report accuracy/ROC-AUC (Table 1). Validates graph-based structure capture.
  2. **Sim2real translation benchmarking:** Compare OGD against InstructPix2Pix and ControlNet using TraitDist, LPIPS, SSIM (Table 2). Tests end-to-end utility.
  3. **Ablation study:** Remove realism graph, symbolic planning, or alignment loss (Table 3, Figure 6). Quantifies each component's contribution and shows qualitative degradation patterns.

## Open Questions the Paper Calls Out
- **Open Question 1:** Can the fixed realism ontology be automatically learned and adapted to new visual domains?
  - *Basis in paper:* [inferred] The paper states the ontology is "static and shared across all datasets; no edges, weights, or node definitions are learned from data" (Sec 3.2), making manual design a bottleneck.
  - *Why unresolved:* Manual specification limits scalability and may not capture domain-specific realism cues (e.g., medical, underwater).
  - *What evidence would resolve it:* A method that discovers trait relationships from unpaired image collections while preserving interpretability, and shows improved cross-domain performance.
- **Open Question 2:** How robust is the trait prediction pipeline to noise in VLM-generated pseudo-labels?
  - *Basis in paper:* [inferred] The authors use GPT-4o as an "automatic annotator to provide supervision for training realism trait predictors" (Sec 3.1), but do not evaluate label quality.
  - *Why unresolved:* VLM biases or hallucinations could propagate errors to the realism embeddings and diffusion guidance.
  - *What evidence would resolve it:* Systematic error injection or human annotation studies to measure impact on meta-classifier accuracy and sim2real metrics.
- **Open Question 3:** Can the diffusion model be trained without paired synthetic-real images, using only unpaired data and the ontology?
  - *Basis in paper:* [inferred] The diffusion model requires paired datasets like "Virtual KITTI 2 paired with the real KITTI dataset" (Sec 4.1). While inference is zero-shot, training still needs paired real images.
  - *Why unresolved:* Paired data is scarce; eliminating it would further enhance data efficiency and applicability.
  - *What evidence would resolve it:* A training objective that uses unpaired real images (to extract target realism embeddings) and synthetic images with symbolic planning, achieving comparable results on benchmarks.

## Limitations
- The realism ontology is manually defined and static, which may not capture domain-specific nuances and requires expert knowledge.
- The pipeline depends on accurate VLM-generated pseudo-labels for training trait predictors; noise or bias in these labels is not characterized.
- Key implementation details (VLM annotation protocol, GNN hyperparameters, full PDDL domain, diffusion training specifics) are omitted, hindering exact reproducibility.
- Inference is zero-shot for new simulators, but diffusion model training still requires a small set of paired synthetic-real images.

## Confidence
- **Graph embeddings for realism discrimination:** Medium (98.4% accuracy claim relies on correct graph and loss weighting; details sparse).
- **Symbolic planning for consistent edits:** Medium (PDDL domain not detailed; feasibility hinges on correct preconditions/effects).
- **Joint conditioning improves translation:** Medium (ablations show benefit, but integration specifics vague; risk of contradictory signals).
- **Overall improvement over baselines:** Medium (metrics plausible but reproducibility uncertain due to missing hyperparameters and data splits).
