# LUMINA: Laplacian-Unifying Mechanism for Interpretable Neurodevelopmental Analysis via Quad-Stream GCN

## Quick Facts
- **arXiv ID:** 2603.13329
- **Source URL:** https://arxiv.org/abs/2603.13329
- **Reference count:** 15
- **Primary result:** Achieves 84.66% accuracy (AUC 0.861) on ADHD200 and 88.41% (AUC 0.936) on ABIDE, outperforming standard GCN, GAT, BrainNetCNN, and BrainGNN.

## Executive Summary
LUMINA introduces a Quad-Stream Graph Convolutional Network (GCN) to overcome a key limitation in existing fMRI-based diagnosis models: the loss of contrastive dynamics from standard low-pass smoothing. By decomposing functional connectivity into positive and negative components using bipolar ReLU and processing each with dual Laplacian filters (smoothing and differential), the model preserves both sign information and heterogeneous spatial frequencies. A view attention mechanism dynamically integrates the four resulting streams. Validated on ADHD200 (N=144) and ABIDE (N=579) datasets, LUMINA shows significant gains over baselines and identifies disorder-specific biomarkers in post-hoc analysis.

## Method Summary
The method processes resting-state fMRI data parcellated into 111 ROIs. For each subject, a Pearson correlation matrix R is computed. R is split into strictly positive (A<sub>pos</sub>) and strictly negative (A<sub>neg</sub>) adjacency matrices using bipolar ReLU. For each polarity, two normalized Laplacian operators are constructed: L<sub>smooth</sub> = I + Â (low-pass) and L<sub>diff</sub> = I − Â (high-pass), where Â is the symmetrically normalized adjacency. This yields four spectral filters. Node features are first enriched by a Multi-Scale Regional Mixer applying 1D convolutions with dilations {1,2,5} to the raw ROI time-series. Stacked NeuroGraph Blocks then process features: each block applies the four Laplacian filters in parallel to the node embeddings, producing four view-specific outputs. A View Attention module computes per-node attention weights across views, producing a weighted spatial embedding. Finally, Edge Attention Pooling aggregates node features into a graph-level representation, which an MLP classifier uses for diagnosis.

## Key Results
- ADHD200: 84.66% accuracy (AUC 0.861, F1 0.849); ABIDE: 88.41% accuracy (AUC 0.936, F1 0.885).
- Outperforms GCN, GAT, BrainNetCNN, and BrainGNN by notable margins.
- Ablation studies: Removing bipolar segregation reduces ADHD200 accuracy by ~25% (84.7% → 58.9%); removing the NeuroGraph block structure reduces ABIDE accuracy by 18% (88.4% → 70.4%).

## Why This Works (Mechanism)
**Mechanism 1: Bipolar ReLU segregation preserves sign information.** Standard GCNs often discard negative correlations (e.g., via absolute value or positive thresholding), which represent functionally meaningful inhibitory relationships. LUMINA splits R into A<sub>pos</sub> = ReLU(R) and A<sub>neg</sub> = ReLU(−R) before any spectral filtering, ensuring positive and negative connectivity are processed in separate streams. This prevents blurring of contrastive dynamics that are diagnostically distinct for ADHD/ASD. The large performance drop in ablations without bipolar separation (especially in ADHD200) supports this claim.

**Mechanism 2: Dual Laplacian filters capture heterogeneous spatial frequencies.** By applying both L<sub>smooth</sub> (low-pass) and L<sub>diff</sub> (high-pass) to each polarity, LUMINA separately processes slow-varying global integration patterns and rapid local segregation patterns within both positive and negative networks. Standard GCNs use only a low-pass filter, oversmoothing high-frequency details. The ablation without differential filters shows performance harm, indicating both frequency bands carry unique signals.

**Mechanism 3: View Attention adaptively integrates streams.** The four processed views (positive/negative × smooth/diff) are not equally informative per subject or disorder. A learned attention mechanism scores each view per node, dynamically reweighting their contributions. This allows the model to suppress noisy or uninformative streams (e.g., negative differential if it is mostly noise) while emphasizing predictive ones. The modest but consistent gain over simple concatenation in ablations validates this adaptive fusion.

## Architecture Onboarding
**Component map:** Input Processor (R from X) → Quad-Map Generator (A<sub>pos</sub>, A<sub>neg</sub>; L<sub>smooth</sub>, L<sub>diff</sub>) → Multi-Scale Regional Mixer (1D convs dilations 1,2,5) → NeuroGraphBlock Stack (L layers: per-block parallel GCN streams → View Attention → FFN) → Edge Attention Pooling → MLP Classifier.

**Critical path:** The correlation matrix R is decomposed into four Laplacians. For each NeuroGraph Block, the mixer output H is transformed by each Laplacian (Z<sub>k</sub> = L<sub>k</sub> H W<sub>k</sub>). View Attention computes weights α<sub>k</sub> from Z<sub>k</sub> and produces H<sub>spatial</sub> = Σ α<sub>k</sub> Z<sub>k</sub>. H<sub>spatial</sub> becomes the next block's input. After L blocks, edge attention pools final node features into a graph embedding for classification.

**Design tradeoffs:**
- Bipolar vs. absolute/magnitude: Bipolar preserves sign but doubles streams and may increase noise in one polarity; absolute simplifies but loses sign.
- Dual Laplacian vs. single filter: Dual captures wide frequency band but adds 4× complexity; single is simpler but risks oversmoothing.
- View Attention vs. concatenation: Attention is adaptive but introduces non-linearity and training complexity; concatenation is deterministic but enforces equal weighting.

**Failure signatures:**
- High variance in ADHD200 accuracy (±9.53%) versus ABIDE (±1.57%) suggests instability on smaller N=144 dataset.
- Ablation without bipolar (w/o B/R) in ADHD200 drops ~25% (58.9% vs 84.7%); if reproduced, check if A<sub>neg</sub> contains meaningful signal.
- Ablation without NeuroGraph (w/o N/G) in ABIDE drops 18% (70.4% vs 88.4%); indicates mixer+attention alone insufficient.

3. Dual-Laplacian isolation: Use only L<sub>smooth</sub> streams (both polarities) or only L<sub>diff</sub> streams. Retrain; expect performance drop if either band carries unique signal, consistent with w/o D/L ablations.

## Open Questions the Paper Calls Out
1. Can LUMINA generalize to neurodevelopmental disorders beyond ADHD and ASD? The study only evaluates on these two datasets.
2. Do ADHD and ASD exhibit significantly different View Attention weight distributions across the four Laplacian streams? The paper does not analyze attention weights per disorder.
3. Is bipolar ReLU activation optimal for preserving signed connectivity information, or could alternative sign-aware transformations improve performance? The ablation only compares to absolute values.
4. How sensitive is LUMINA's performance to sample size limitations and demographic heterogeneity given modest cohort sizes (ADHD: N=144, ABIDE: N=579)? External validation on diverse cohorts is lacking.

## Limitations
- Key architectural details missing (Multi-Scale Mixer kernel sizes/padding, Edge Attention Pooling implementation, exact NeuroGraph block composition), forcing assumptions in reproduction.
- Relatively small datasets (ADHD200 N=144) yield high performance variance; generalizability to broader populations is untested.
- Core assumption that negative functional connectivity carries distinct diagnostic signal may not hold universally; if signal resides primarily in magnitude, bipolar segregation could dilute predictive power.
