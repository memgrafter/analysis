# Think First, Diffuse Fast: Improving Diffusion Language Model Reasoning via Autoregressive Plan Conditioning
## Quick Facts
*   **arXiv ID:** 2603.13243
*   **Source URL:** https://arxiv.org/abs/2603.13243
*   **Reference count:** 6
*   **Primary result:** Training-free "plan conditioning" boosts LLaDA-8B accuracy on GSM8K by +11.6pp (75.6%→87.2%), matching a same-size AR model.

## Executive Summary
Diffusion language models (DLMs) like LLaDA generate all tokens in parallel, which disrupts the sequential coherence building critical for multi-step reasoning. This paper introduces "plan conditioning," a training-free method where a short natural-language reasoning plan from a capable autoregressive (AR) model is prepended to the DLM's prompt. The plan acts as a "frozen scaffold"—a globally visible, immutable structure that all token positions can attend to from the first denoising step via bidirectional attention. This scaffold substitutes for the causal dependency chain inherent in AR generation, allowing the DLM's parallel decoding to coordinate around a shared strategic blueprint. On GSM8K and HumanEval, LLaDA-8B sees dramatic gains (+11.6pp and +12.8pp), closing the gap to a same-size AR model (LLaMA 3.1 8B). The approach costs ~$0.002 per problem and reduces inference variance to zero on GSM8K.

## Method Summary
Plan conditioning requires no training of the diffusion model. First, an external AR planner (e.g., Claude Sonnet) generates a ~100-token natural-language reasoning plan for each problem using a benchmark-specific system prompt and a modest temperature (0.3). This plan is then prepended to the problem's prompt in a fixed format (e.g., "Solution Plan:\n{plan}\n\nSolution:"). During diffusion inference, the entire prompt—including the plan tokens—is treated as preserved, non-masked context. The DLM (e.g., LLaDA) starts with the solution tokens fully masked and iteratively denoises them over ~64 steps, maintaining bidirectional attention across the entire sequence. Crucially, the plan tokens remain visible and fixed throughout, serving as a persistent reference for all completion positions. The final output is scored using standard benchmark extraction (e.g., `\boxed{}` for math, unit tests for code).

## Key Results
*   On GSM8K, LLaDA-8B accuracy improves from 75.6% to 87.2% (+11.6 percentage points), matching LLaMA 3.1 8B (87.7%).
*   On HumanEval, LLaDA-8B gains +12.8pp (37.2% → 50.0%).
*   The same Claude Sonnet plans improve LLaMA by only +5.7pp (GSM8K) and +1.3pp (HumanEval)—diffusion models benefit 2–10× more.

## Why This Works (Mechanism)
### Mechanism 1: Frozen Scaffold Coordination
The parallel generation of DLMs suffers from a coordination problem: without sequential dependencies, tokens cannot build on each other's partial states. Prepending a plan creates a "frozen scaffold"—a globally visible, immutable reasoning structure. Because DLMs use bidirectional attention, every solution token position has equal access to all plan tokens from the first denoising step. This provides a shared strategic reference that coordinates the otherwise independent parallel decoding paths, substituting for the sequential chain in AR models. Evidence: Plan tokens receive 1.8× their uniform share of attention at step 0 (fully masked canvas), which declines as solution tokens solidify. Diffusion models benefit 2–10× more from identical plans than AR models.

### Mechanism 2: Strategy-Value Dissociation in Execution
The DLM uses the plan as a procedural template but computes intermediate values independently, rather than copying numbers from the plan. Perturbing numeric values in an otherwise correct plan causes negligible harm (−1.1pp), while providing an incorrect strategic approach causes catastrophic failure (−16.3pp). This indicates the plan's role is to specify the *procedure* (the "what"), not the specific computations (the "what numbers"). The DLM has sufficient execution capability (arithmetic/logic) if guided by a correct strategy, but cannot reliably derive the strategy itself during parallel generation. Error analysis confirms 59% of failures are "execution error (right plan, wrong math)."

### Mechanism 3: Planner Quality Threshold Effect
Plan conditioning exhibits a sharp threshold in planner capability. Plans from models below a certain quality level (roughly Claude Haiku-class) actively harm performance, while plans from above-threshold models provide substantial gains. Bidirectional attention amplifies both signal and noise globally; low-quality plans contain systematic strategic errors that the executor faithfully replicates. The executor lacks an internal mechanism to evaluate plan validity and unconditionally integrates plan content via attention. Evidence: Llama 3.2 3B plans hurt GSM8K by −6.8pp; Haiku plans help (+6.7pp); Sonnet plans help maximally (+11.6pp). All plan conditions (good, bad, random) receive elevated attention at step 0, with magnitude scaling with coherence but not downstream accuracy.

## Foundational Learning
*   **Masked Diffusion Language Models (MDLMs)**
    *   *Why needed:* Understanding the coordination problem requires knowing how MDLMs generate: all tokens are denoised in parallel from a fully masked start using bidirectional attention, unlike AR's sequential generation.
    *   *Quick check:* Describe the forward and reverse process in MDLMs like LLaDA. Why does the reverse process enable parallel decoding?
*   **Autoregressive Decoding & Causal Attention**
    *   *Why needed:* To contrast with diffusion's parallel generation and understand why AR models inherently build coherence sequentially, making them less dependent on external structural scaffolding.
    *   *Quick check:* How does the causal attention mask in AR models enforce a sequential dependency chain between tokens? What information does token *n* have access to at generation time?
*   **Attention as Context Integration Mechanism**
    *   *Why needed:* The "frozen scaffold" mechanism relies on bidirectional attention allowing all completion positions to read plan tokens equally. This is the architectural substrate enabling the coordination fix.
    *   *Quick check:* In a transformer with bidirectional attention, how does a token at position *i* aggregate information from a token at position *j*? How does this differ in a decoder-only (AR) transformer?

## Architecture Onboarding
*   **Component map:**
    Plan Generator (Claude Sonnet) -> Prompt Constructor (prepends plan) -> Diffusion Executor (LLaDA, with plan as preserved context) -> Extraction & Scoring.
*   **Critical path:** Generate plan (one-time, cacheable) -> Construct prompt with preserved plan tokens -> Run diffusion inference with fixed plan context -> Extract answer. The invariant: plan tokens must remain unmasked and globally attendable throughout denoising.
*   **Design tradeoffs:**
    *   **Plan format vs. budget:** Hybrid format best for math; Strategy format best for code. Budget saturates ~100 tokens for GSM8K. More tokens increase planner cost but not executor cost (fixed context length).
    *   **Planner quality vs. harm:** Planners below a sharp threshold (Haiku-class) actively harm. Requires careful capability assessment.
    *   **Latency:** Plan generation adds ~2s latency but is amortizable via caching; diffusion inference cost unchanged.
*   **Failure signatures:**
    *   **Wrong-strategy failure:** Model faithfully follows a strategically incorrect plan (catastrophic drop). Detected via mismatch-plan ablation.
    *   **Premature termination:** Model emits padding tokens before answer (~10% on ARC-C). Diffusion-specific stochastic failure.
    *   **High variance on hard tasks:** Countdown shows higher baseline variance (±1.01pp), indicating sensitivity to remasking schedule without scaffold.
*   **First 3 experiments:**
    1.  Reproduce main lift: Run LLaDA-8B on GSM8K with Sonnet Hybrid plan (100 tokens) vs. bare. Expect ~+11.6pp lift, matching LLaMA 3.1 8B baseline.
    2.  Planner quality sweep: Run LLaDA with plans from Llama 3.2 3B, Llama 3.1 8B, Haiku, Sonnet. Verify sharp threshold: below Haiku, accuracy ≤ baseline; above, monotonic increase.
    3.  Attention verification: Extract attention weights from LLaDA during plan-conditioned generation on a few GSM8K problems. Confirm: (a) plan tokens receive >24% (uniform baseline) attention at step 0, (b) attention to plan declines smoothly over steps, (c) pattern holds across layers.

## Open Questions the Paper Calls Out
*   Can plan distillation replace frontier AR planners with smaller models?
*   How should plan budgets adapt to problem difficulty?
*   Does combining plan conditioning with RL (diffu-GRPO) further boost performance?
*   Are the benefits of plan conditioning reproducible on harder code benchmarks (LiveCodeBench, SWE-Bench)?

## Limitations
*   LLaDA's exact inference details (noise schedule, preserved-token masking) are unspecified, hindering exact replication.
*   Evaluation scripts (answer parsing, splits) are not standardized; minor differences affect reported accuracy.
*   Plan conditioning depends on an external, potentially expensive AR planner, with a sharp quality threshold for benefit.

## Confidence
*   Large gains (+11.6pp GSM8K, +12.8pp HumanEval): **High**
*   Frozen scaffold mechanism (global coordination via attention): **Medium**
*   Strategy-value dissociation (procedure vs. computation): **High**
*   Planner quality threshold effect: **Medium**
*   Diffusion-AR disparity in plan benefit: **High**

## Next Checks
*   Causal attention test: Mask plan tokens at selected denoising steps to measure output change, confirming necessity of early access.
*   Plan length sweep: Vary plan token budget (25–200) on GSM8K/HumanEval to identify optimal length and saturation.
*   Cross-model replication: Test plan conditioning on at least two other MDLMs (e.g., CDCD, DiffuGPT) to assess generalization of gains.
