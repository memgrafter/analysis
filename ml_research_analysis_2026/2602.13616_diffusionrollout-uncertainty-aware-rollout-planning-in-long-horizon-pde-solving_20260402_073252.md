# DiffusionRollout: Uncertainty-Aware Rollout Planning in Long-Horizon PDE Solving

## Quick Facts
- arXiv ID: 2602.13616
- Source URL: https://arxiv.org/abs/2602.13616
- Reference count: 10
- Primary result: Adaptive rollout planning using diffusion model uncertainty reduces error accumulation in long-horizon PDE solving, achieving lower L2 error and higher stability than SOTA baselines.

## Executive Summary
Long-horizon autoregressive prediction of PDEs suffers from error accumulation due to the mismatch between training (teacher forcing) and inference (closed-loop) conditions. DiffusionRollout addresses this by leveraging a pre-trained conditional diffusion model to estimate per-timestep predictive uncertainty from sample variance. It then adaptively selects the rollout step size, only propagating predictions with uncertainty below a threshold, thereby mitigating the compounding effect of inaccurate states.

Evaluated on four PDE benchmarks (Gray-Scott, Turbulent Flow, Cahn-Hilliard, Anisotropic Diffusion), DiffusionRollout achieves state-of-the-art accuracy and stability, reducing relative L2 error by up to 15.37% and extending the duration of high correlation with ground truth. The method is training-free, incurs minimal overhead, and demonstrates the utility of diffusion-based uncertainty for robust physical forecasting.

## Method Summary
DiffusionRollout uses a pre-trained conditional diffusion model (PDE-Refiner) trained with a Diffusion Forcing objective on context-future window pairs. At inference, given a context window, it draws K=2 samples from the model via DDIM (10 steps). For each future timestep, it computes the element-wise standard deviation across samples and takes its Euclidean norm to obtain uncertainty ε̂_t. The rollout step size s is set as the largest t such that ε̂_t < τ, where τ is a dataset-specific threshold. Only the first s predicted states (from a selected sample, typically the mean) are appended to the context, and the process repeats. This adaptively balances network approximation error (when s is small) against condition-induced error (when s is large) without retraining.

## Key Results
- Consistently lower relative L2 error and higher long-term stability (T>0.9) across four PDE benchmarks.
- On Gray-Scott, achieves 15.37% error reduction compared to best fixed-step PDE-Refiner baseline.
- Maintains comparable runtime to fixed-step baselines despite added uncertainty estimation.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** The standard deviation of multiple diffusion samples at a future timestep serves as a reliable, *training-free* surrogate for that timestep's prediction error.
- **Mechanism:** The pre-trained conditional diffusion model $p_\theta(u_F|u_C)$ defines a distribution over plausible future states. Element-wise standard deviation $\hat{\varepsilon}_t$ computed from $K$ samples ($\hat{\varepsilon}_t = \|\sigma(\{u_t^{(k)}\}_K)\|_2$) captures epistemic uncertainty—variability arising from the model's limited context and approximation capacity. A strong positive correlation ($\rho$) between $\hat{\varepsilon}_t$ and true $\|u_t - \hat{u}_t\|_2$ across timesteps implies $\hat{\varepsilon}_t$ is a proxy for confidence.
- **Core assumption:** The dominant predictive uncertainty in deterministic PDE rollouts stems from the model's epistemic limitations (context window, network approximation), not inherent stochasticity in the physics. Aleatoric uncertainty (from numerical discretization) is negligible.
- **Evidence anchors:**
  - [abstract] "statistics computed from multiple samples drawn from a conditional diffusion model...are strongly correlated with prediction errors—supporting their use as a proxy for the model’s predictive confidence."
  - [section 3.3] "Across all four benchmark PDEs...the proposed uncertainty measure $\hat{\varepsilon}_t$ shows a strong correlation ($\rho$) with the actual prediction error."
  - [corpus] No direct corroborating evidence from neighbor papers.
- **Break condition:** If the correlation $\rho$ between $\hat{\varepsilon}_t$ and error falls below a empirically validated threshold (e.g., $\rho < 0.8$) on held-out trajectories, the surrogate becomes unreliable.

### Mechanism 2
- **Claim:** An adaptive rollout step size $s$, selected by rejecting future predictions exceeding an uncertainty threshold $\tau$, mitigates error accumulation by reducing exposure to condition-induced error.
- **Mechanism:** At each autoregressive step, compute $\hat{\varepsilon}_t$ for $t=1..F$. The step size is set to $s = \max(\{t | \hat{\varepsilon}_t < \tau\} \cup \{1\})$. Only the first $s$ predicted states are accepted as new context. This trades off network approximation error (increases with more NFEs/small $s$) against condition-induced error (increases with large $s$ using potentially inaccurate states). The threshold $\tau$ controls conservativeness.
- **Core assumption:** Condition-induced error (from conditioning on inaccurate prior predictions) is the dominant driver of long-horizon instability, not pure network approximation error over many steps. Discarding uncertain states prevents these errors from propagating.
- **Evidence anchors:**
  - [section 3.3] "an ideal way to suppress error accumulation is to identify which type of error...is more dominant and adapt the rollout step size accordingly."
  - [section 4.2] "Our adaptive planning results in 15.37% error reduction compared to the base model’s fixed-step sampling strategy, which advances 6 steps per iteration."
  - [section 4.3] The ablation ("Derivative Threshold") shows an alternative uncertainty proxy (temporal derivative) underperforms, indirectly supporting $\hat{\varepsilon}_t$-based selection.
- **Break condition:** If aggressive discarding ($s$ too small) leads to increased total NFEs causing overall error to rise despite lower per-step condition errors (as hinted for regression baselines in Fig. 7).

### Mechanism 3
- **Claim:** The adaptive step selection mechanism improves long-term stability (measured by $T_{>0.9}$) by preventing the compounding of episodic large errors that would cause correlation with ground truth to collapse.
- **Mechanism:** By only integrating predictions with $\hat{\varepsilon}_t < \tau$ into the context, the rollout avoids committing to states the model is highly uncertain about. This prevents a single large error from corrupting all subsequent predictions, thus extending the duration over which $r(t) \geq 0.9$.
- **Core assumption:** Correlation collapse in long rollouts is primarily triggered by discrete, high-magnitude prediction errors that propagate, rather than a slow, uniform drift.
- **Evidence anchors:**
  - [abstract] "improving long-term prediction reliability by reducing the compounding effect of conditioning on inaccurate prior outputs."
  - [section 4.1] "we quantify long-term stability by measuring the average normalized time up to which the correlation stays above 0.9, denoted as $T_{>0.9}$."
  - [table 1] DiffusionRollout achieves higher $T_{>0.9}$ than PDE-Refiner with fixed $s=6$ on Gray-Scott (0.311 vs. 0.275) and Turbulent Flow (0.926 vs. 0.809), indicating more sustained correlation.
- **Break condition:** If trajectories exist where uncertainty is consistently low early on but errors compound slowly and uniformly, the method may not extend $T_{>0.9}$ significantly.

## Foundational Learning
- **Concept:** Autoregressive Rollout & Exposure Bias
  - *Why needed here:* The entire problem setup ($C$-in, $F$-out chunking, Eq. 2, long-horizon prediction) operates on autoregressive rollouts. Understanding the train/test mismatch (conditioning on ground truth vs. own predictions) is prerequisite to grasping why error accumulation occurs and why adaptive control is needed.
  - *Quick check question:* What is the key difference between training (teacher forcing) and inference (closed-loop) in an autoregressive PDE solver, and why does this difference lead to compounding errors?
- **Concept:** Diffusion Models for Conditional Generation
  - *Why needed here:* The core method builds on a pre-trained conditional diffusion model ($p_\theta(u_F|u_C)$). Understanding the iterative denoising process and how it produces a *distribution* of outputs (not a single point estimate) is essential to see why multiple samples can be drawn for uncertainty estimation.
  - *Quick check question:* In a conditional diffusion model for PDEs, what does the noising/denoising process represent, and how does conditioning on $u_C$ affect the distribution of possible $u_F$?
- **Concept:** Epistemic vs. Aleatoric Uncertainty
  - *Why needed here:* The method interprets sample variance as epistemic uncertainty (due to model/context limitations). Distinguishing this from aleatoric uncertainty (inherent data noise) is critical because only epistemic uncertainty should be reducible with more/better data/modeling and is the relevant signal for the adaptive planning.
  - *Quick check question:* Why is the sample variance from a deterministic PDE-solving diffusion model considered a measure of epistemic rather than aleatoric uncertainty?

## Architecture Onboarding
- **Component map:** Pre-trained Conditional Diffusion Model (DiT backbone) -> Uncertainty Estimator (compute per-timestep stddev) -> Step Selector (choose s) -> Rollout Manager (update context). The backbone is the core; the others are wrappers.
- **Critical path:** `context -> backbone (sample K times) -> uncertainty estimator -> step selector -> new context`. The computational bottleneck is the $K$ parallel passes through the backbone.
- **Design tradeoffs:**
  - **$K$ (sample count):** Larger $K$ yields more robust $\hat{\varepsilon}_t$ but increases compute linearly ($K \times$ backbone cost). Paper shows $K=2$ is often sufficient (Tab. 3).
  - **$\tau$ (uncertainty threshold):** Small $\tau$ makes step selection conservative (small $s$), reducing condition-error but increasing NFEs (approximation error). Large $\tau$ does the opposite. Must be tuned per-dataset (e.g., 1 for Gray-Scott, 0.32 for Anisotropic Diffusion).
  - **$S$ (diffusion timesteps):** More timesteps improve sample quality but increase per-step cost. Paper finds $S=10$ (DDIM) sufficient; more steps slightly increased error (Tab. 4), likely due to more NFEs.
  - **Mean vs. Single Sample for Context:** Paper implies using the first $s$ states from *a* sample (likely the mean or first sample). Using the mean across samples for the new context is a plausible but not explicitly detailed design choice.
- **Failure signatures:**
  - **Weak correlation:** $\hat{\varepsilon}_t$ shows poor correlation ($\rho < 0.7$) with error on validation set → surrogate fails.
  - **Step-size oscillation:** $s$ varies wildly between consecutive steps on a single trajectory → $\tau$ is poorly set or uncertainty signal is noisy.
  - **Divergence with small $s$:** Model predictions diverge to NaN/inf when $s$ is forced to 1 (see FNO in Fig. 7) → backbone is unstable for very long rollouts; adaptive method may still end up with small $s$ if uncertainty is consistently high.
  - **No improvement over fixed $s$:** If the best fixed-$s$ PDE-Refiner baseline already nearly optimally balances errors for a dataset, adaptive selection may not gain much.
- **First 3 experiments:**
  1. **Validation of Uncertainty Proxy:** On a held-out set, for $K=2,3,4,5$, compute per-timestep $\hat{\varepsilon}_t$ and prediction error. Calculate Pearson $\rho$. Confirm $\rho > 0.8$ as in Fig. 2. If not, the core mechanism is unsupported.
  2. **Threshold Sensitivity Sweep:** For a single dataset (Gray-Scott), run full rollouts with $\tau \in \{0.1, 0.5, 1, 3, 5\}$. Plot RelL2 error vs. average $\bar{s}$ (like Fig. 5). Identify the $\tau$ that minimizes error and observe if it selects a non-trivial distribution of $s$ (like Fig. 6). If all $\tau$ give similar performance, the adaptive mechanism provides marginal benefit.
  3. **Ablation: Regression Backbone:** Train the same DiT architecture with MSE loss (Eq. 2) instead of diffusion. Apply the same adaptive rollout logic (using $K=2$ samples from the *non-diffusion* model—but note: a deterministic regression model does not produce multiple samples; this variant would require either: (a) adding noise at inference to create samples, or (b) replacing the backbone with the diffusion-trained one and just changing the training loss). The paper's ablation (Tab. 2) uses a regression-trained diffusion model? Clarify: The "Regression Loss Training" variant likely still uses the diffusion *architecture* but trains with a point-wise MSE loss instead of the diffusion objective, destroying the probabilistic interpretation. Replicate this: train a DiT with pure MSE, then at inference, try to generate multiple samples—this will likely fail as the model is deterministic. A fairer comparison would use an ensemble of regression models. The paper's result (worse performance) supports the necessity of the generative training objective for meaningful uncertainty estimation.
