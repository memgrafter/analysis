# Stability and Sensitivity Analysis of Relative Temporal-Difference Learning: Extended Version

## Quick Facts
- arXiv ID: 2603.27874
- Source URL: https://arxiv.org/abs/2603.27874
- Reference count: 34
- Primary result: Relative TD(λ) with linear function approximation is stable for any non-negative baseline weight and any discount factor when the baseline distribution equals the empirical state-action distribution; asymptotic bias and covariance are uniformly bounded as γ→1.

## Executive Summary
Temporal-difference (TD) learning with linear function approximation suffers from poor conditioning as the discount factor γ approaches 1, leading to slow convergence and high variance. Relative TD learning introduces a baseline subtraction to mitigate this issue. This paper delivers the first rigorous stability analysis for relative TD(λ). The authors prove that stability depends critically on the baseline distribution μ: when μ matches the empirical state-action distribution (ϖ), the algorithm remains stable for any baseline weight δ_r ≥ 0 and any γ ∈ [0,1). Moreover, the asymptotic bias and covariance of the parameter estimates stay uniformly bounded as γ → 1. For small δ_r, exact sensitivity formulas quantify the reduction in these asymptotic statistics. Simulations on a 3-state MDP and a continuous speed-scaling control problem confirm improved conditioning of the mean flow matrix and substantial variance reduction compared to standard TD.

## Method Summary
The work analyzes on-policy TD(λ) with linear function approximation Q_θ(z)=θ^Tψ(z). The relative TD algorithm modifies the TD error by subtracting a baseline: D_{n+1}=r_n+γθ_n^Tψ_{n+1}-θ_n^Tψ_n - δ_r⟨μ, Q_{θ_n}⟩, where δ_r≥0 and μ is a fixed baseline distribution. To realize μ=ϖ (empirical distribution), the algorithm maintains a running average ¯ψ_n of the features via step size β_n, satisfying ∑β_n=∞, ∑β_n^2<∞, and β_n/α_n→∞. Theoretical analysis uses stochastic approximation: the iterates track the ODE dθ/dt = A(θ), where A(θ) is the mean flow matrix. The key result shows that when μ=ϖ, A(θ) is Hurwitz for all δ_r≥0 and γ<1, ensuring stability. Asymptotic bias β_θ and covariance Σ*_Θ are derived via the Poisson equation; for small δ_r, explicit sensitivity formulas are obtained.

## Key Results
- **Stability**: Relative TD(λ) with μ = empirical distribution ϖ is stable for any δ_r ≥ 0 and any γ ∈ [0,1).
- **Uniform boundedness**: As γ → 1, both asymptotic bias β_θ and asymptotic covariance Σ*_Θ remain bounded.
- **Sensitivity**: For δ_r small, exact first-order formulas characterize the reduction in bias and covariance relative to standard TD.
- **Empirical validation**: On a 3-state MDP and a speed-scaling task, relative TD improves condition number of the mean flow matrix and reduces variance.

## Why This Works (Mechanism)
Standard TD becomes unstable near γ=1 because the mean flow matrix develops an eigenvalue near zero, driven by the constant function being an approximate eigenvector. Relative TD subtracts a baseline that, when the baseline distribution equals the empirical distribution, cancels the projection of the update onto the constant direction. This rank‑one correction shifts all eigenvalues of the mean flow matrix into the left half‑plane, guaranteeing Hurwitz stability. The empirical feature mean adapts to the data distribution, preserving the cancellation. The sensitivity analysis further shows that for small δ_r the stabilization incurs only bounded bias increase, while variance reduction scales quadratically with δ_r.

## Foundational Learning
- **Temporal-difference learning**: Bootstrapping method for policy evaluation. *Why needed*: Core algorithm from which relative TD extends. *Quick check*: Derive the TD(0) update from the Bellman equation.
- **Linear function approximation**: Represents value functions as θ^Tψ(z). *Why needed*: Enables tractable learning in large/continuous spaces. *Quick check*: Show that TD with linear FA is stochastic gradient descent on the MSBE.
- **Stochastic approximation**: Theory for iterative stochastic algorithms. *Why needed*: Provides ODE method and Lyapunov arguments to prove stability. *Quick check*: Verify Robbins-Monro step‑size conditions.
- **Mean flow matrix (A)**: Expected outer product of features under the Markov chain; its eigenvalues control stability. *Why needed*: Central object in the stability analysis. *Quick check*: Compute A for a simple Markov chain with given features.
- **Eligibility traces (TD(λ))**: Accumulate past features to approximate λ‑returns. *Why needed*: Generalizes TD(0) and reduces bias; the analysis covers λ∈[0,1]. *Quick check*: Write the eligibility recursion ζ_{n+1}=λγζ_n+ψ_{n+1}.
- **Baseline subtraction**: Variance reduction technique common in reinforcement learning. *Why needed*: In relative TD it also improves conditioning by removing a singular mode. *Quick check*: Prove that adding a constant to all rewards does not change the optimal policy.

## Architecture Onboarding
*Component map*: MDP generates transitions (X_n, U_n, R_n) → feature extractor ψ(Z_n). These feed three parallel components: (1) eligibility trace ζ_{n+1}=λγζ_n+ψ_{n+1}; (2) running average ¯ψ_{n+1}=¯ψ_n+β_{n+1}(ψ_{n+1}-¯ψ_n); (3) baseline computation ⟨μ, Q_θ⟩ (with μ=ϖ_n gives baseline ¯ψ_n^Tθ_n). The TD error D_{n+1} uses reward, γθ_n^Tψ_{n+1}, θ_n^Tψ_n, and the baseline. The parameter update is θ_{n+1}=θ_n+α_{n+1} D_{n+1} ζ_{n+1}. After the run, a Polyak‑Ruppert average over final iterates may be taken.

*Critical path*: Per‑step loop: sample transition → compute ψ_{n+1} → update eligibility → update running average → compute TD error (with baseline) → update θ. Steps must be in order to maintain correctness.

*Design tradeoffs*: Step sizes α_n and β_n must satisfy standard SA conditions and β_n/α_n→∞, respectively. β_n too large increases variance in ¯ψ; too small slows baseline adaptation. Baseline weight δ_r trades off stability (larger δ_r improves conditioning) against bias. λ balances bias‑variance of the return.

*Failure signatures*: Exploding θ indicates instability (A not Hurwitz). Oscillating or diverging ¯ψ suggests β_n/α_n too small. Near‑singular condition number for γ≈1 when δ_r=0. High variance in final estimates may signal insufficient averaging or too large α_n.

*Three first experiments*:
1. **Eigenvalue replication**: For the 3‑state MDP, run standard TD and relative TD (δ_r=0.5) with α_n=min(2, n^{-0.65}), β_n=1/n across γ∈{0.9,0.95,0.99}. Estimate mean flow matrix from steady‑state data, compute condition numbers; verify relative TD maintains bounded condition number while standard TD degrades.
2. **Sensitivity formula validation**: Set δ_r=0.05. Run 200 independent trajectories of length 10^6, discard first 20% as burn‑in, apply Polyak‑Ruppert averaging. Compare empirical bias and covariance to theoretical predictions from Theorem 4.
3. **Baseline schedule robustness**: In the speed‑scaling task, test β_n = n^{-0.9}, n^{-1.0}, n^{-1.1} (keep α_n=min(0.2, n^{-0.6})). Monitor stability (max∥θ_n∥) and variance of final estimates; all should succeed because β_n/α_n→∞.

## Open Questions the Paper Calls Out
1. Can relative TD stabilize Q‑learning with linear function approximation? Q‑learning is off‑policy and known to diverge; the stability of relative Q‑learning remains unknown.
2. What finite‑time error bounds can be derived for the empirical relative TD algorithm? Only asymptotic results exist; non‑asymptotic convergence rates are needed for sample‑complexity guarantees.
3. For which baseline distributions μ is relative TD(λ) guaranteed to be stable for all γ∈[0,1) and all δ_r≥0? The paper gives a condition for small δ_r near γ=1 and proves stability for μ=ϖ; a complete characterization is lacking.
4. Does relative TD with nonlinear function approximation (e.g., deep neural networks) retain the stability and variance reduction properties? The analysis is restricted to linear FA; extending to nonlinear representations is an open challenge.

## Limitations
- Exact step‑size schedules and baseline hyperparameters for all simulation experiments are not fully specified; only asymptotic forms are given.
- Methodology for estimating the mean flow matrix (e.g., number of lags in autocorrelation sum) is omitted, hindering exact replication of eigenvalue plots.
- The assumption Σ(0)≻0 may fail if the basis includes a constant feature or is rank‑deficient, potentially breaking the stability guarantee.
