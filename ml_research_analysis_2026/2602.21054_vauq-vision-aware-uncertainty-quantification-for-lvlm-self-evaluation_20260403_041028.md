# VAUQ: Vision-Aware Uncertainty Quantification for LVLM Self-Evaluation

## Quick Facts
- **arXiv ID**: 2602.21054
- **Source URL**: https://arxiv.org/abs/2602.21054
- **Reference count**: 27
- **Primary result**: VAUQ achieves SOTA self-evaluation for LVLMs, improving AUROC by +13.3% on counterfactual scenarios (ViLP, LLaVA-1.5-7B) to 77.0%.

## Executive Summary
Large Vision-Language Models (LVLMs) often hallucinate, but existing self-evaluation methods derived from LLMs fail for vision-conditioned outputs because they over-rely on language priors. VAUQ addresses this by explicitly measuring the model’s dependence on visual evidence. It introduces an Image-Information Score (IS) that quantifies the reduction in predictive uncertainty attributable to the image. IS is computed by masking core visual regions identified via unsupervised attention aggregation and comparing entropy before and after masking. The final training‑free score combines length‑normalized predictive entropy with the core‑masked IS. Across multiple LVLMs and benchmarks, VAUQ sets a new state‑of‑the‑art, improving AUROC by up to +13.3% (ViLP, LLaVA‑1.5‑7B) while maintaining lower inference overhead than sampling‑based approaches.

## Method Summary
VAUQ is a training‑free self‑evaluation framework for LVLMs. Given an image‑text pair, it first generates a response via greedy decoding. The length‑normalized predictive entropy \(H(y|v,t)\) is computed from the output logits. To quantify how much the image reduces uncertainty, VAUQ identifies the core visual tokens the model attends to when generating \(y\). This is done by aggregating attention weights from a model‑specific range of layers \(l_s\) to \(l_e\) across all heads and generated tokens (Equation 3), then selecting the top \(K\%\) visual tokens as \(v_{\text{top}}\); the remaining tokens are \(v_{\text{masked}}\). The Image‑Information Score is defined as \(\text{IScore} = H(y|v_{\text{masked}},t) - H(y|v,t)\). Since physically removing tokens is difficult, \(H(y|v_{\text{masked}},t)\) is estimated via an attention knockout: during a second forward pass, all attention weights pointing to \(v_{\text{top}}\) are zeroed, forcing the model to rely on diminished visual information. The final VAUQ score is  
\[
sV_{\text{AUQ}} = (1+\alpha)H(y|v,t) - \alpha\cdot H(y|v_{\text{masked}},t),
\]  
where \(\alpha\) and \(K\) are hyper‑parameters tuned on a held‑out validation set. This score effectively captures reliance on visual evidence: lower scores indicate stronger visual dependence, which correlates with more reliable (non‑hallucinated) outputs.

## Key Results
- **SOTA performance** on multiple LVLMs (LLaVA‑1.5‑7B/13B, Qwen2.5‑VL‑7B, InternVL3.5‑8B) and benchmarks (ViLP, MMVet, VisualCoT, CVBench).
- **+13.3% AUROC improvement** on the counterfactual ViLP dataset with LLaVA‑1.5‑7B, reaching **77.0% AUROC** over prior methods.
- **Lower inference overhead** compared to sampling‑based uncertainty techniques (e.g., Semantic Entropy) because VAUQ requires only one extra forward pass with a simple attention modification.

## Why This Works (Mechanism)
Existing LLM‑based self‑evaluation treats the LVLM as a text‑only model and ignores the visual contribution, leading to poor hallucination detection when the output is conditioned on an image. VAUQ overcomes this by directly quantifying how much the image reduces predictive uncertainty. The core insight: if the model truly uses the image, then disabling its most‑attended visual regions (the core evidence) will increase uncertainty. The size of this increase (IScore) measures visual reliance. By combining the original entropy with IScore, VAUQ produces a score that correlates with hallucination risk: outputs that ignore the image (hallucinations) keep high entropy even after masking (small IScore), yielding a higher VAUQ score; outputs grounded in the image show a large IScore, reducing the final score. This mechanism avoids multiple sampled generations and remains faithful to the model’s internal attention dynamics.

## Foundational Learning
- **Uncertainty Quantification**: Measures model confidence; needed to flag potential errors.  
  *Quick check*: Compute entropy of output token distribution; higher values often indicate uncertainty.
- **Attention Mechanisms**: Reveal which input tokens influence generation; used to locate evidence‑bearing image regions.  
  *Quick check*: Visualize attention maps to confirm they highlight semantically meaningful image areas.
- **Vision‑Language Model Architecture**: Understanding multimodal fusion (vision encoder + LLM) is crucial to interpret how image and text interact.  
  *Quick check*: Test model on image‑only, text‑only, and combined inputs to observe dependence patterns.
- **Entropy Calculation**: Predictive entropy quantifies overall uncertainty; it is the backbone of VAUQ’s original component.  
  *Quick check*: Compare entropy values for clear vs. ambiguous prompts; entropy should rise with ambiguity.
- **Ablation via Attention Knockout**: Approximates removal of visual evidence without altering input tokens.  
  *Quick check*: Apply knockout and measure accuracy drop; larger drop suggests stronger reliance on masked tokens.

## Architecture Onboarding
**Component map**:  
Input (image, text) → Vision Encoder & Text Tokenizer → Visual Tokens + Text Tokens → LVLM (Transformer) → Greedy Decoding to produce y + Extraction of Attention Weights → Attention Aggregation (layer range ls‑le) → Attention Scores per Visual Token → Selection of Top K% → Core Visual Tokens (v_top) → Attention Knockout (zero all attention to v_top in a second forward) → Logits → Entropy H(y|v_masked,t) together with H(y|v,t) → Score Fusion with α → VAUQ Score sV_AUQ.

**Critical path**: For each sample:  
1. Run greedy decoding to obtain response y and collect attention from layers ls‑le.  
2. Aggregate attention to each visual token to compute importance; pick top K% as v_top.  
3. Perform a second forward pass with attention knockout (zero all attentive flows to v_top).  
4. Compute length‑normalized predictive entropy from original logits H(y|v,t) and masked logits H(y|v_masked,t).  
5. Combine via sV_AUQ = (1+α)H(y|v,t) − α·H(y|v_masked,t).  

**Design tradeoffs**:  
- **Layer range (ls, le)**: Too narrow may miss high‑level evidence; too wide may include irrelevant signals. Paper provides model‑specific optimal ranges.  
- **Top‑K% (K)**: Small K focuses on most critical tokens but may exclude supporting context; large K dilutes the core signal. Tuned per dataset.  
- **α**: Balances original entropy and IScore; higher α gives more weight to visual reliance. Requires validation tuning.  
- **Knockout vs. token removal**: Knockout is architecture‑agnostic but may not fully sever token influence; full removal risks disrupting sequence modeling. Knockout is a pragmatic compromise.

**Failure signatures**:  
- **Attention misalignment**: Core tokens do not correspond to answer‑relevant image regions (e.g., scattered on background), causing IScore to poorly reflect visual dependence.  
- **Hyperparameter mismatch**: Using default α and K on a new dataset without retuning leads to performance drops; the score may become uninformative.  
- **Model incompatibility**: Applying the preset (ls, le) from one LVLM to another may misalign with the internal hierarchy, yielding noisy attention aggregation.

**First experiments**:  
1. **Visualize core tokens**: Map the selected top‑K% visual tokens back to image space for several samples; confirm they overlap with salient objects or regions relevant to the query.  
2. **Check IScore positivity**: Compute IScore over a validation set; expect a majority positive (masking increases entropy). A substantial negative fraction indicates flawed attention or knockout.  
3. **Score separation**: Compute VAUQ scores for known correct and incorrect responses. Expect higher scores for incorrect (hallucinations). If distributions overlap significantly, the score may not be capturing visual reliance effectively.

## Limitations
- Hyperparameter values (α, K) are tuned on undisclosed held‑out validation splits, making exact replication of reported AUROC gains difficult.  
- The attention knockout procedure lacks full implementation details (e.g., whether only text‑to‑visual or all attention to v_top is zeroed), introducing variability across reproductions.  
- The core‑attention selection may not always align with answer‑critical image regions, especially in complex scenes, limiting the robustness of the Image‑Information Score.
