# InterventionLens: A Multi-Agent Framework for Detecting ASD Intervention Strategies in Parent-Child Shared Reading

## Quick Facts
- **arXiv ID:** 2603.13710
- **Source URL:** https://arxiv.org/abs/2603.13710
- **Reference count:** 35
- **Primary result:** On the ASD-HI dataset, InterventionLens achieves an overall F1 score of 79.44%, with Precision 82.36% and Recall 76.75%, representing a 19.72% absolute improvement over the baseline.

## Executive Summary
**Problem:** Manual annotation of caregiver intervention strategies (Modeling, Mand-Model, Time Delay) in home-based autism spectrum disorder (ASD) shared reading videos is costly and relies on expert clinicians. Automating this analysis is challenging due to noisy home environments, variable child speech, and limited annotated data.

**Proposed solution:** InterventionLens, a multi-agent framework that separates multimodal perception from intervention detection. It uses an Omni-Perception Agent to create time-aligned transcripts, a Book Modeling Agent to incorporate book context, and a two-layer intervention detection pipeline (Candidate Scanner and Strategy-Specific Experts) to perform coarse-to-fine temporal segmentation without any task-specific model training.

**Results:** On the ASD-HI dataset (48 sessions, 239 training / 117 test segments), InterventionLens reaches 79.44% F1 (precision 82.36%, recall 76.75%), improving over the baseline by 19.72 percentage points. Ablation studies show that removing the Book Modeling Agent reduces F1 by 10.47 points, confirming its central role.

## Method Summary
InterventionLens operates in two layers. **Perception Layer:** The Omni-Perception Agent (Gemini for multimodal parsing and Whisper for audio) converts each 15-second video clip into a time-aligned multimodal transcript. The Book Modeling Agent then extracts structured book cues (e.g., recurring sentence patterns, target words) from the transcript. **Intervention Detection Layer:** The Intervention Candidate Scanner Agent scans the transcript and book context to propose candidate intervention segments and assign coarse strategy cues. Each candidate is routed to a dedicated Strategy-Specific Expert (Modeling, Mand-Model, or Time Delay) that verifies the candidate against the book context and fine‑tunes its temporal boundaries using rule‑based reasoning. A Progressive Knowledge Refinement Loop iteratively updates the experts’ rules on the training set to maximize F1, eliminating the need for task‑specific model fine‑tuning.

## Key Results
- Overall F1 score: **79.44%**, Precision: **82.36%**, Recall: **76.75%** on ASD‑HI test set.
- Absolute improvement over baseline: **19.72 percentage points**.
- Ablation study: Removing the Book Modeling Agent lowers overall F1 by **10.47 points**.

## Why This Works (Mechanism)
### Mechanism 1: Decoupling Perception from Detection
- **Claim:** Separating multimodal perception (OPA) from intervention detection (IDS) improves robustness by isolating error‑prone perception tasks.
- **Mechanism:** OPA produces time‑aligned multimodal transcripts and BMA adds book context; IDS uses these structured representations to detect and segment interventions without seeing raw video/audio.
- **Core assumption:** Raw perception (especially child speech ASR) is noisy; higher‑level symbolic summaries are more reliable for reasoning.
- **Evidence anchors:**
  - [abstract] "Without task‑specific model training or fine‑tuning, InterventionLens uses a collaborative multi‑agent architecture to integrate multimodal interaction content..."
  - [section] 4.1: "The Perception Layer first converts the raw shared book reading video into a time‑aligned multimodal transcript and structured book context."
  - [corpus] Neighbor papers (e.g., AgenticAD) use multi‑agent decomposition but for different domains; none explicitly decouple perception from detection for home‑based ASD SBR, suggesting novelty.
- **Break condition:** If OPA or BMA outputs are severely degraded (e.g., misaligned timestamps, irrelevant book cues), downstream performance collapses.

### Mechanism 2: Book Modeling as Triadic Grounding
- **Claim:** Book modeling via BMA is a key contributor, especially for Modeling strategy, as shown by a 19.32 F1 drop when removed.
- **Mechanism:** BMA extracts book‑specific patterns (recurring sentences, target words) from the transcript, providing contextual grounding that helps experts verify if caregiver utterances align with book content.
- **Core assumption:** Caregiver interventions often reference the book; book context disambiguates interventions from casual speech.
- **Evidence anchors:**
  - [abstract] Implied by "fine‑grained strategy analysis" requiring contextual understanding.
  - [section] 4.1: "BMA extracts contextual cues such as recurring sentence patterns and potential target words..." and 5.3: Ablation results show significant performance drop without BMA.
  - [corpus] TaleMate and ContextQ focus on dialogue generation but not book‑content extraction for intervention detection, so BMA's specific function is not paralleled.
- **Break condition:** If the book context does not match the actual book (e.g., due to transcript errors) or the intervention does not involve book references, BMA's contributions diminish.

### Mechanism 3: Coarse‑to‑Fine Candidate Routing with Expert Specialization
- **Claim:** The two‑stage pipeline (ICSA + SSEs) achieves efficient and precise temporal segmentation by reducing search space and leveraging strategy‑specific rules.
- **Mechanism:** ICSA uses heuristic patterns to propose candidate segments with coarse strategy cues; these are routed to dedicated SSEs that verify with detailed rules and refine boundaries.
- **Core assumption:** Intervention strategies have identifiable coarse patterns; dedicated experts can handle fine‑grained nuances better than a monolithic system.
- **Evidence anchors:**
  - [abstract] "It performs coarse‑to‑fine temporal segmentation without task‑specific model training."
  - [section] 4.2: "ICSA extracts two clinically meaningful candidate patterns... and uses it as a routing signal to dispatch each candidate to the corresponding strategy‑specific expert."
  - [corpus] Multi‑agent routing is common (e.g., AgenticAD), but the specific coarse‑to‑fine design for temporal segmentation in ASD interventions appears unique.
- **Break condition:** If ICSA's heuristics miss true interventions (low recall) or misroute candidates, SSEs cannot recover them; also, SSE rules may be insufficient for boundary refinement.

## Foundational Learning
### Concept: Triadic Interaction in Shared Reading
- **Why needed here:** The system's design hinges on the idea that SBR is a three‑way interaction among caregiver, child, and book. Without this, the Book Modeling Agent would be unnecessary.
- **Quick check question:** In a shared reading session, how might a caregiver's "Modeling" intervention implicitly reference the book's content?

### Concept: Multi‑Agent System Decomposition for Complex Tasks
- **Why needed here:** InterventionLens decomposes a hard multimodal problem into specialized agents; understanding this decomposition is key to extending or modifying the framework.
- **Quick check question:** What are the risks of using a single LLM to handle both perception and detection, and how does the multi‑agent approach mitigate them?

### Concept: Rule‑Based Expert Systems with Progressive Refinement
- **Why needed here:** The SSEs are not trained but constructed from domain knowledge and iteratively improved; this data‑efficient approach is central to the paper's claim of working without task‑specific training.
- **Quick check question:** Why might progressive rule refinement on the training set be preferable to fine‑tuning an LLM on the same small dataset?

## Architecture Onboarding
### Component map
OPA (Omni-Perception Agent) produces time‑aligned multimodal transcript and timestamps → BMA (Book Modeling Agent) extracts structured book cues from the transcript → ICSA (Intervention Candidate Scanner Agent) scans transcript and book cues to propose candidate segments with coarse strategy cues → SSEs (Strategy‑Specific Experts) verify candidates, refine boundaries, and output final labeled segments. A Progressive Knowledge Refinement Loop updates SSE rules on the training set to maximize F1.

### Critical path
1. Video → OPA → transcript X and book context B.
2. X → ICSA → candidates C with cues.
3. For each candidate: route to expert → expert uses B → output segment or reject.
4. Collect all accepted segments → final prediction.

### Design tradeoffs
- **Off‑the‑shelf models vs. custom training:** Using Gemini/Whisper avoids large data needs but limits control; custom ASR could improve child speech but requires labeled data.
- **Rule‑based vs. learned experts:** Rules are interpretable and data‑efficient but may not capture all patterns; learned classifiers could generalize better but need more data.
- **Coarse‑to‑fine vs. end‑to‑end segmentation:** Coarse‑to‑fine reduces computation and focuses on plausible regions, but risks missing interventions if ICSA heuristics are too narrow.

### Failure signatures
- **OPA output quality:** Check timestamp alignment between Gemini and Whisper; high mismatch indicates OPA failure.
- **BMA relevance:** Manually inspect BMA‑extracted patterns for a few videos; if they don't match the book content, BMA is broken.
- **ICSA recall:** Measure fraction of ground‑truth interventions that appear as candidates; low recall (<80%) indicates insufficient candidate generation.
- **SSE rejection rate:** If >90% of candidates are rejected, SSE rules may be too strict or ICSA candidates too noisy.

### First 3 experiments
1. **Transcription sanity:** Run OPA on 5 random videos, have a human verify that caregiver and child turns are correctly transcribed and timed. Goal: >90% turn‑level accuracy.
2. **BMA pattern validation:** For the same videos, check if BMA's extracted recurring patterns (e.g., animal names) appear in the actual book text. Goal: >80% pattern match.
3. **ICSA candidate recall:** Run ICSA on the training set, compute what percentage of true intervention segments overlap with at least one candidate. Goal: >95% recall at candidate level.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** How can we build a robust and generalizable automated system for caregiver intervention detection under data scarcity, variable home environments, and child speech challenges?
- **Basis in paper:** [explicit] Introduction: "developing a robust and generalizable automated analysis system under these compounding constraints remains a core open challenge in the field."
- **Why unresolved:** ASD‑HI dataset is small; perception relies on off‑the‑shelf Whisper/Gemini which degrade in noisy home settings; no cross‑dataset validation.
- **What evidence would resolve it:** Evaluate on multiple large‑scale home‑video datasets; develop specialized perception models (child‑ASR, precise temporal grounding); conduct multi‑site benchmarking; ablation isolating each environmental constraint.

### Open Question 2
- **Question:** How can the transferability and robustness of InterventionLens be systematically validated and improved across datasets, family settings, and annotation schemes?
- **Basis in paper:** [explicit] Limitations: "its transferability and robustness across datasets, family settings, and annotation schemes still require more systematic validation."
- **Why unresolved:** The system was only tested on ASD‑HI (3 families); cross‑family variability, differing annotation guidelines, and domain shift remain unexamined.
- **What evidence would resolve it:** Cross‑dataset experiments on independent ASD‑SBR benchmarks; testing on families from diverse socio‑economic/cultural backgrounds; performance comparison under alternative annotation protocols; sensitivity analysis to recording variations.

### Open Question 3
- **Question:** What methodological improvements are needed to detect the Modeling strategy, given its low recall/F1 in the current benchmark?
- **Basis in paper:** [explicit] Error Analysis: "the detection performance of Modeling is substantially lower... influenced by the number of Modeling instances... and inconsistency in labeling criteria between splits."
- **Why unresolved:** Only 16 Modeling instances in test set; labeling inconsistencies create ambiguous boundaries; rule‑based expert may lack discriminative features for Modeling.
- **What evidence would resolve it:** Curate a larger, consistently annotated set of Modeling segments; refine the annotation manual for clearer criteria; data augmentation or few‑shot prompting to capture subtle cues; adaptation of the expert system with learned features.

## Limitations
- **Prompt dependency:** Exact prompts and few‑shot examples are undisclosed, hindering full replication and making performance sensitive to prompt engineering.
- **Generalization unknown:** Evaluation restricted to ASD‑HI (48 home videos); performance in other settings (clinic, different books) or populations is unclear.
- **Perception brittleness:** OPA uses commercial models (Gemini, Whisper); errors in child speech ASR or timestamp alignment may cascade without explicit mitigation.

## Confidence
- Decoupling perception from detection improves robustness: **Medium** confidence.
- Book Modeling Agent is critical: **High** confidence (ablation shows 10.47 F1 drop).
- Coarse‑to‑fine candidate routing with expert specialization: **Medium** confidence.

## Next Checks
1. **Perception robustness test:** Run OPA with alternative ASR (e.g., NVIDIA NeMo) and vision‑language models (e.g., GPT‑4V); measure change in overall F1 to quantify sensitivity to perception quality.
2. **Pipeline ablation:** Replace the two‑stage detection with a single‑step LLM (prompted to directly output segments) using identical inputs; compare F1 and boundary accuracy to isolate benefits of coarse‑to‑fine.
3. **Cross‑dataset evaluation:** Apply InterventionLens to an external shared reading corpus (e.g., CHILDES or a public autism interaction dataset); report F1 change to assess generalization beyond ASD‑HI.
