# Causal Decoding for Hallucination-Resistant Multimodal Large Language Models

## Quick Facts
- **arXiv ID:** 2602.21441
- **Source URL:** https://arxiv.org/abs/2602.21441
- **Reference Count:** 25
- **Primary Result:** COAD reduces object hallucination on CHAIR (I/S), MMHal-Bench, and POPE while maintaining output quality, via causal interventions that block spurious text-object dependencies during decoding.

## Executive Summary
Multimodal large language models (MLLMs) frequently hallucinate objects not present in input images. Existing fixes address symptoms, not the root cause: spurious dependencies between prior generated text and the model's internal object beliefs. This work introduces Causal Object-Aware Decoding (COAD), which applies targeted causal interventions during token generation. COAD first finetunes an MLLM to incorporate explicit object detections. During inference, it fuses outputs from the pretrained and finetuned models using causal inference to block the influence of previous text on object-related states, forcing predictions to rely solely on visual evidence. This yields state-of-the-art faithfulness across captioning and QA benchmarks with modest computational overhead.

## Method Summary
COAD operates in two phases. First, a pretrained MLLM (`Mp`) is finetuned into `Mf` by modifying its architecture to accept an auxiliary object detection vector `z` (from a fixed-category detector like RTMDet) alongside image and text tokens. Second, during autoregressive decoding for a given image `S` and current text history `x`, COAD computes the next-token distribution by fusing: (i) `Mp`'s standard output `P(yp|S,x)`, and (ii) `Mf`'s output conditioned on `z`, `P(yf|S,x,z)`. The fusion formula `(1+α)*E_z[P(yf|S,x,z)] - α*P(yp|S,x)` (implemented in logit space) approximates the interventional distribution `P(y*|S,do(x))` of an oracle model unaffected by spurious text-to-object pathways. The expectation over `z` is approximated by feeding the detector's probability vector `P(z|S)` directly into `Mf`.

## Key Results
- On CHAIR (captioning), achieves SOTA with CHAIRI at 3.4% and CHAIRS at 5.3%, substantially lower than prior work.
- On MMHal-Bench (QA), attains highest average score (2.52) and lowest hallucination rate (0.52).
- On POPE (adversarial QA), achieves best accuracy (79.8) and F1 (81.2), demonstrating robust suppression of false-positive object assertions.
- Ablations confirm the critical role of the object vector `z` and the causal fusion mechanism; removing either causes severe performance collapse.

## Why This Works (Mechanism)

### Mechanism 1: Blocking Spurious Text-Object Pathways via Intervention
- **Claim:** By intervening on the previous text variable `x`, COAD prevents the model's internal object beliefs (`z`) from being corrupted by linguistic priors in the generated text history.
- **Mechanism:** The causal model identifies that in a standard MLLM, the variable `z` (representing object existence beliefs) is confounded by the previously generated tokens `x`. This spurious path `x → z` causes `z` to encode objects not present in the image. COAD applies a `do(x)` intervention, which severs all natural dependencies of `z` on `x`. This forces `z` to depend *only* on the image `S`, ensuring object beliefs are grounded solely in visual evidence.
- **Core assumption:** The vision encoder produces an object-belief representation `z` that is causally downstream of the image `S` and upstream of the next-token prediction `y`. Intervening on `x` blocks the backdoor path `x ← hidden states ← y` that would otherwise influence `z`.
- **Evidence anchors:**
  - [abstract]: "apply[ing] targeted causal interventions... to explicitly block the spurious influence of prior text on object-related hidden states."
  - [section 3.4]: The temporal causal graph in Figure 4 shows that in a standard MLLM, `x(t)` influences `z` indirectly through the autoregressive loop over time. The intervention `do(x)` is applied to break this loop.
  - [section 3.6]: "Component 1: Causal Inference of Objects `z`. To ensure object beliefs reflect only the image content, we explicitly model them as variable `z`... we block this dependency using an intervention `do(x)`."
- **Break condition:** If the vision encoder itself is biased or the image features are already corrupted by spurious correlations present in the training data (e.g., certain textures always co-occurring with objects), the `do(x)` intervention on `x` will not correct the erroneous `z` derived from `S`.

### Mechanism 2: Oracle Token Estimation via a Mixture of Experts
- **Claim:** The finetuned model `Mf` is treated as a probabilistic mixture of the pretrained model `Mp` (capturing linguistic priors) and a hypothetical oracle model `M*` (capturing visually-grounded truth). This allows estimation of the oracle's next-token distribution `P(y*|S,x,z)` from the observable outputs of `Mp` and `Mf`.
- **Mechanism:** Assuming `Mf` was initialized from `Mp` and finetuned to align with ground truth, its output distribution can be decomposed as a mixture: `P(yf|S,x,z) ≈ γ P(y*|S,x,z) + (1-γ) P(yp|S,x)`, where `γ` is a mixing weight. By observing `yf` and `yp`, and knowing the prior over `γ` (Beta distribution), one can solve for `P(y*|S,x,z)`. This estimates what the model *should* predict if it were perfectly grounded.
- **Core assumption:** The finetuning process does not completely overwrite `Mp`'s parameters but instead creates a model that stochastically interpolates between its old behavior (`Mp`) and the desired oracle behavior (`M*`). The mixing proportion `γ` is drawn from a fixed Beta prior.
- **Evidence anchors:**
  - [section 3.5]: "We hypothesize that the finetuned model `Mf` behaves as a mixture of the pretrained model `Mp` and the hypothetical oracle model `M*`... This variable is drawn from a global prior Beta distribution... `yf ≈ Categorical(γ×y* + (1-γ)×yp)`."
  - [section 3.6]: Equation (2) and (3) formally derive `P(y*|S,x,z)` from the mixture assumption. "By rearranging Equation 2, we can rewrite the prediction from `M*` in terms of the predictions `yp` and `yf` from `Mp` and `Mf`."
- **Break condition:** If finetuning causes `Mf` to catastrophically forget `Mp`'s priors (`γ` becomes near 1 always) or if `Mf` diverges from the oracle in a way not captured by the simple mixture (e.g., learns new, systematic biases), the mixture model becomes an inaccurate estimator for `P(y*|S,x,z)`.

### Mechanism 3: Fusing Distributions with Causal Re-weighting
- **Claim:** The final next-token probability is computed by combining the finetuned model's output (conditioned on object `z`) and the pretrained model's output (unconditioned on `z`) with weights derived from the causal intervention, effectively amplifying visually-grounded signals and suppressing text-induced hallucinations.
- **Mechanism:** The interventional objective `P(y*|S, do(x))` is computed (Equation 4) as `(1+α) * E_z[P(yf|S,x,z)] - α * P(yp|S,x)`. This fuses the expectation of the finetuned model's output over object samples `z` (which is causally grounded) with the pretrained model's output. The hyperparameter `α = γb/γa` controls the strength of the correction, pushing the final distribution closer to the finetuned model's object-aware predictions.
- **Core assumption:** The expectation over `z`, `E_z[P(yf|S,x,z)]`, under the `do(x)` intervention, accurately captures the oracle's token distribution that is free from spurious `x` influence. The linear combination is a valid solution to the interventional query given the mixture model.
- **Evidence anchors:**
  - [section 3.6]: "Final Inference Objective... we can then rewrite our final inference objective as a combination of known quantities: `P(y*|S,do(x)) = (1+α) ∑_z [P(z|S)P(yf|S,x,z)] - αP(yp|S,x)`."
  - [section 4.4 Ablation]: The "w/o z" ablation (using no object vector in `Mf`) shows catastrophic performance drop (CHAIRs 18.1 vs. 5.3), proving the fusion of `P(yf|S,x,z)` is critical. The "Mf only" ablation shows the fusion itself (`α` weighting) adds benefit over naive use of `Mf`.
- **Break condition:** If the object detector's distribution `P(z|S)` is highly inaccurate (many false positives/negatives), then sampling `z` from it will cause `E_z[P(yf|S,x,z)]` to average over irrelevant or contradictory object sets, degrading the signal. The method assumes the detector provides a reasonably accurate prior over object presence.

## Foundational Learning
- **Concept:** Causal Inference & `do`-calculus
  - **Why needed:** COAD's core innovation is applying a `do(x)` intervention to break a spurious dependency chain. Understanding backdoor paths, confounding, and the difference between association `P(y|x)` and causation `P(y|do(x))` is essential to grasp why the method works.
  - **Quick check:** In the MLLM graph `S → z ← hidden states → x → y`, what is the confounder creating a spurious link between `x` and `y`, and why does `do(x)` on `z` block it?
- **Concept:** Autoregressive Decoding in MLLMs
  - **Why needed:** The problem is framed within the token-by-token generation loop. One must understand how `x(t)` evolves to see how its influence on `z` (via past computations) can create hallucinations that compound.
  - **Quick check:** In LLaVA's architecture, what part of the hidden state is static and determined only by `S` (our `z`), and what part is dynamic and influenced by the growing `x` (the `h(t)` in Appendix A)?
- **Concept:** Mixture Models & Bayesian Parameter Estimation
  - **Why needed:** The estimation of the unobservable oracle distribution `P(y*|S,x,z)` from observable `Mp` and `Mf` outputs relies entirely on interpreting `Mf` as a mixture and using the known Beta prior on `γ` to solve for the oracle component.
  - **Quick check:** Given `P(yf) = γ P(y*) + (1-γ) P(yp)` and you know `E[γ]` from the Beta prior, how would you algebraically isolate `P(y*)`?

## Architecture Onboarding
- **Component map:**
  Pretrained MLLM (`Mp`) -> Finetuned MLLM (`Mf`) with Object Detector (`D`) input -> Causal Fusion Module -> Output Tokens
  `Mp` and `Mf` run in parallel at each decoding step; `D` runs once per image.

- **Critical path:**
  1.  **Offline:** Finetune `Mf` on a dataset where each sample includes `(image, caption, detector_output_vector)`.
  2.  **Per-Image Inference:**
      a. Run detector `D` on input image `S` -> get `P(z|S)`.
      b. For each token prediction step with current `x`:
          i. Get `P(yp|S,x)` from frozen `Mp`.
          ii. Get `P(yf|S,x, P(z|S))` from finetuned `Mf` (input the probability vector directly).
          iii. Fuse: `P(y) = (1+α) * P(yf) - α * P(yp)`. Apply softmax if fusion was in logit space.
          iv. Sample/select next token `y` from `P(y)`.
          v. Append `y` to `x`, repeat.

- **Design tradeoffs:**
  - **Accuracy vs. Speed:** Using the probability vector `P(z|S)` directly in `Mf` is fast but an approximation. True Monte Carlo sampling over binary `z` vectors is more accurate but slower. The `α` hyperparameter trades off reliance on `Mf` vs. `Mp`.
  - **Detector Quality vs. Generality:** A closed-vocabulary detector (e.g., COCO-trained RTMDet) limits `z`'s scope but is precise. An open-vocabulary detector (e.g., GLIP) increases coverage but may introduce more spurious object probabilities, harming fusion.
  - **Finetuning Cost vs. Plug-and-Play:** Requires a LoRA finetune (~16h on 8 A5000s). A training-free variant (prompt-injection of `z`) is possible but less robust, especially on captioning tasks.

- **Failure signatures:**
  1.  **Domain Shift in Detector:** If test images contain object categories or styles not well-represented in the detector's training data, `P(z|S)` will be misleading, causing `Mf` to condition on wrong objects.
  2.  **Catastrophic Forgetting in `Mf`:** If finetuning overwrites `Mp`'s capabilities (`γ→1`), `Mf` loses general language fluency, and `α`-weighting cannot recover it from `Mp`.
  3.  **Incorrect `α`:** Setting `α` too high over-corrects, making outputs terse and potentially incoherent. Too low leaves hallucinations untouched. The paper uses task-specific `α` (1.5 for generation, 0.1 for POPE).

- **First 3 experiments:**
  1.  **Ablation on CHAIR:** Run full COAD vs. "Mf only" (no fusion) vs. "w/o z" (finetune without detector input). This isolates the contribution of causal fusion and the object vector `z`.
  2.  **Controlled Object Probing (POPE):** Evaluate on the adversarial POPE split where objects are deliberately queried that are *not* in the image. Success here (high accuracy, low "Yes" rate for absent objects) directly demonstrates COAD's ability to suppress text-prior-induced false positives.
  3.  **Visualization of `z` and Probe Hidden States:** As in Appendix B, use a linear probe on LLaVA's hidden states to empirically show that (a) the model forms incorrect object beliefs (`z`) influenced by text, and (b) COAD's use of detector `z` corrects this, leading to non-hallucinated output.

## Open Questions the Paper Calls Out
- **Question 1:** How can COAD's causal modeling framework be effectively extended to other multimodal tasks beyond image captioning and QA, such as video understanding or 3D visual reasoning?
- **Question 2:** Can open-vocabulary detectors (e.g., GLIP) replace fixed-category detectors in COAD to handle a richer object space without compromising hallucination mitigation, and how does detector granularity affect performance?
- **Question 3:** How can temporal and spatial priors be integrated into COAD's causal interventions to improve grounding in dynamic scenes or complex spatial configurations?
- **Question 4:** To what extent can COAD's dependence on task-specific finetuning be reduced—ideally to a training-free or few-shot setup—while retaining state-of-the-art hallucination reduction?
- **Question 5:** How robust is COAD to domain shifts (e.g., medical images, sketches) where the object detector's training distribution diverges from test data, and can domain-adaptive detectors mitigate resulting performance drops?

## Limitations
- **Dataset Specification Ambiguity:** Exact MSCOCO image splits and filtering for finetuning/evaluation are unreported, hindering exact replication.
- **Category Mismatch Risk:** The fixed-category detector's vocabulary may not perfectly align with evaluation benchmarks (e.g., CHAIR/POPE object sets), potentially skewing results.
- **Causal Assumption Sensitivity:** The method's core assumptions (accurate `P(z|S)`, stable finetuning mixture) may not hold under detector failure or catastrophic forgetting, breaking the intervention.

## Confidence
- **Blocking spurious text-object dependencies:** Medium. Ablations strongly support the mechanism, but detector failures would break the intervention's grounding.
- **Oracle estimation via mixture model:** Low. The theoretical Beta-prior assumption for `γ` is not empirically validated; the mixture model is a heuristic.
- **Fusion effectiveness:** High. Table 4 ablations confirm the fusion contributes significant gains over using `Mf` alone.
- **Overall hallucination reduction claim:** High. Results are strong and consistent across multiple diverse benchmarks.
