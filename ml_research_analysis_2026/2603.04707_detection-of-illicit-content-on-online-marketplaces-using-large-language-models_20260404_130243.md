# Detection of Illicit Content on Online Marketplaces using Large Language Models
## Quick Facts
- **arXiv ID**: 2603.04707
- **Source URL**: https://arxiv.org/abs/2603.04707
- **Reference count**: 40
- **Primary result**: Llama 3.2 reaches 0.89 accuracy in binary detection (matching SVM) and 0.74 accuracy with 0.73 weighted F1 in the 40-class task, outperforming all baselines.

## Executive Summary
This work addresses the challenge of detecting and classifying illicit content on online marketplaces, a task that traditional machine learning approaches struggle with due to scalability and semantic complexity. The authors fine-tune two large language models, Llama 3.2 and Gemma 3, using Parameter-Efficient Fine-Tuning (PEFT) and quantization on the multilingual DUTA10K dataset. Both binary (illicit vs. non-illicit) and a fine-grained 40-class classification are evaluated against baselines including SVM, Naive Bayes, and BERT. Results show that for binary classification, Llama 3.2 matches the top baseline (SVM) with 0.89 accuracy. For the more demanding 40-class task, Llama 3.2 significantly outperforms all baselines, achieving 0.74 accuracy and 0.73 weighted F1-score, demonstrating the superiority of LLMs for nuanced content moderation.

## Method Summary
The study utilizes the DUTA10K dataset, containing 4,178 marketplace texts in over 20 languages (85% English), each labeled with a binary illicit flag and one of 40 illicit subcategories. After data cleaning, label concatenation, and UTF-8 normalization, the data is split 80/10/10. For traditional baselines, SVM and Multinomial Naive Bayes are trained on TF-IDF features (top 5,000, multilingual stop-word removal). For neural models, BERT and the instruction-tuned LLMs (Llama 3.2-3B, Gemma 3-4B-Instruct) are fine-tuned via Hugging Face Trainer. To manage computational constraints, PEFT with LoRA (low-rank adapters) and 4-bit quantization (BitsAndBytes) are applied to Llama; Gemma is loaded in bfloat16 for the multi-class task. A class-weighted Cross-Entropy loss addresses the long-tail distribution. Training uses AdamW, mixed precision, early stopping, and evaluation with Accuracy, Precision, Recall, and F1-scores (macro and weighted).

## Key Results
- Llama 3.2 matches SVM’s binary classification accuracy of 0.89.
- Llama 3.2 achieves 0.74 accuracy and 0.73 weighted F1 on the 40-class task, significantly surpassing all baselines.
- PEFT and quantization make large-model fine-tuning feasible on a modest dataset, with Llama 3.2 excelling at fine-grained categorization.

## Why This Works (Mechanism)
LLMs like Llama 3.2 and Gemma 3 excel at capturing contextual and multilingual nuances that traditional bag-of-words or even BERT models may miss. Parameter-Efficient Fine-Tuning (PEFT) via LoRA adapts these massive models by learning low-rank weight updates, drastically reducing the number of trainable parameters and mitigating overfitting on small datasets. Quantification further shrinks memory demands, enabling training on commodity GPUs. The class-weighted loss directs attention to rare illicit categories, improving macro-averaged performance. Combined, these techniques allow the LLMs to interpret subtle semantic signals and hierarchical category structures, explaining their superior multi-class results.

## Foundational Learning
- **PEFT (Parameter-Efficient Fine-Tuning)** – Adapts large models with minimal extra parameters; quick check: base model frozen, only LoRA adapters updated.
- **LoRA (Low-Rank Adaptation)** – Approximates weight changes via low-rank matrices; quick check: set target modules (e.g., q_proj, v_proj) and rank `r`.
- **Quantization (4-bit)** – Reduces memory by lower-precision representation; quick check: use BitsAndBytes with `load_in_4bit=True`.
- **Class-Weighted Cross-Entropy Loss** – Balances influence across imbalanced classes; quick check: compute weights inversely proportional to class frequencies.
- **Evaluation Metrics (Accuracy, Macro/Weighted F1)** – Assess performance on imbalanced tasks; quick check: derive per-class metrics from confusion matrix.
- **TF-IDF Vectorization** – Baseline sparse feature extraction; quick check: apply with max 5,000 features and stop-word removal.

Critical Path: 1) Install dependencies (PyTorch, Transformers, PEFT, BitsAndBytes, scikit-learn). 2) Obtain and preprocess DUTA10K (clean, split 80/10/10). 3) Configure LoRA (rank, alpha) and quantization. 4) Train models with early stopping and class-weighted loss. 5) Evaluate test set using Accuracy, Precision, Recall, F1.

Design Tradeoffs: PEFT vs full fine-tuning (efficiency vs flexibility); 4-bit vs bfloat16 (memory vs accuracy); LoRA rank (capacity vs overfitting); class weighting (balance vs distortion); multilingual stop-word removal (noise reduction vs language info loss).

Failure Signatures: Out-of-memory (reduce batch size/gradient accumulation); divergent loss (learning rate too high); poor macro F1 (imbalance not mitigated); overfitting (train >> val accuracy); data leakage (improper stratification).

## Limitations
- Data accessibility: DUTA10K lacks a public download link, impeding verification.
- Hyperparameter opacity: Exact LoRA settings (rank, alpha, target modules) are unreported, hindering exact replication.
- Quantization ambiguity: The final precision for Gemma 3 in the multi-class experiment (4-bit vs bfloat16) is unclear, affecting result comparability.
- Class imbalance risk: The 40-class task’s long-tail distribution may cause macro F1 to mask poor performance on rare categories.

## Confidence
- Binary task parity (Llama 3.2 vs. SVM): Medium
- Multi-class superiority (Llama 3.2 over baselines): Low
- General setup & baseline definitions: High
