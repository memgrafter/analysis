# Representation-Level Adversarial Regularization for Clinically Aligned Multitask Thyroid Ultrasound Assessment

## Quick Facts
- arXiv ID: 2603.21095
- Source URL: https://arxiv.org/abs/2603.21095
- Reference count: 24
- Primary result: Achieves in-domain classification F1-score 0.6267±0.0115 and improves external recall to 0.4033±0.0208 with RLAR, while reducing training variance.

## Executive Summary
This paper introduces a multitask framework for thyroid ultrasound assessment that jointly performs segmentation and TI-RADS classification, addressing the challenge of inconsistent annotations (annotator variability) that cause competing gradients in a shared encoder. The core contributions are: (1) Representation-Level Adversarial Regularization (RLAR), which penalizes angular alignment between task-specific adversarial directions in the shared latent space to stabilize training; and (2) a clinically guided architecture that distills a compact set of TI-RADS-aligned radiomic features into a dedicated classification subspace, grounding risk prediction in interpretable evidence. Evaluated on the public ThyroidXL dataset and zero-shot on AIMI, the clinically guided model with RLAR attains state-of-the-art in-domain classification F1 (0.6267±0.0115) and significantly improves recall on external data (0.4033±0.0208) while maintaining segmentation quality. RLAR also substantially reduces fold-to-fold variance, demonstrating more robust multitask learning under noisy supervision.

## Method Summary
The method uses a shared encoder (pretrained nnU-Net) that feeds two branches: a segmentation decoder (for pixel-wise nodule masks) and a classification head. The classification head splits the bottleneck representation into two subspaces: a 13-dimensional radiomics-aligned vector (h_tirads) and a deep feature vector (h_deep). During training, radiomic features (2D shape, margin, texture) are computed from ground-truth masks and used to supervise h_tirads via mean squared error. The concatenated h_tirads and h_deep are passed through a linear layer to produce TI-RADS logits. To mitigate gradient competition, Representation-Level Adversarial Regularization (RLAR) is applied. For each task loss (segmentation Dice, classification cross-entropy, radiomics regression), the gradient with respect to the shared bottleneck representation z is computed, normalized per sample, and treated as a directional probe δ_t. RLAR penalizes the absolute cosine similarity between these directional probes across tasks. The total loss is λ_seg*L_seg + λ_cls*L_cls + λ_clin*L_clin + L_RLAR. Training uses AdamW (lr=1e-4), mixed precision, and early stopping based on validation performance, with up to 500 epochs.

## Key Results
- Best in-domain classification F1-score: 0.6267±0.0115 on ThyroidXL (clinically guided + RLAR).
- Zero-shot external recall improvement: RLAR raises recall to 0.4033±0.0208 on AIMI while preserving segmentation (Dice 0.6277±0.0177, HD95 205.78±17.24).
- RLAR reduces training variance: classification F1 standard deviation drops from ±0.011 (vanilla multitask) to ±0.0018.

## Why This Works (Mechanism)
### Representation-Level Adversarial Regularization (RLAR)
**Claim:** RLAR stabilizes multitask learning under annotator variability by preventing destructive interference between task gradients in the shared representation, without hard parameter partitioning.  
**Mechanism:** For each task loss, it computes a normalized adversarial direction (∇zL/∥∇zL∥) in the shared latent space, treating this vector as a geometric probe of task sensitivity. It then penalizes the absolute cosine similarity between these directional probes across tasks. This encourages the tasks to adjust parameters in complementary directions within the representation, rather than opposing ones.  
**Core assumption:** Task gradient alignment in representation space is a leading indicator of negative transfer, and reducing this alignment improves joint optimization stability and generalization.  
**Evidence anchors:** Abstract and Section 2.3 define δt and L_RLAR; Section 3.5 shows best performance when RLAR is applied at the bottleneck (ThyroidXL) or mid-encoder (AIMI); variance reduction is reported.  
**Break condition:** If tasks are inherently aligned in their optimal directions, excessive penalization could suppress beneficial sharing and harm performance.

### Clinically Guided Radiomics Distillation
**Claim:** Guiding part of the classification embedding toward a compact, TI-RADS-aligned radiomics target grounds risk prediction in interpretable clinical cues, improving robustness under label noise.  
**Mechanism:** A training-only branch computes a 13-dimensional radiomics vector from ground-truth masks. This is distilled into a designated subspace (h_tirads) of the classification embedding via L2 loss; the remaining embedding (h_deep) retains data-driven features. Both feed the classifier.  
**Core assumption:** Annotator variability in TI-RADS labels is partially orthogonal to underlying sonographic textural/morphometric evidence; distilling explicit radiomics anchors the model to these evidential features, making it less susceptible to inconsistent categorical labels.  
**Evidence anchors:** Abstract mentions clinical guidance; Section 2.2 details radiomics feature groups; Section 3.5 feature ablation shows external generalization sensitivity to removing specific features (ellipticity, GLCM entropy).  
**Break condition:** If radiomics features are poorly correlated with true clinical outcomes or suffer similar annotation variability, distillation could inject misleading priors.

### Shared Encoder for Coupled Clinical Workflow
**Claim:** A single shared encoder for segmentation and classification mirrors the radiologist's integrated assessment, allowing segmentation cues (contour, margins) to shape the features used for risk stratification.  
**Mechanism:** The encoder's bottleneck representation z is used by both a segmentation decoder and a classification head. This forces z to contain information relevant to both tasks, rather than learning separate representations.  
**Core assumption:** Visual evidence for nodule contouring and for TI-RADS criteria substantially overlaps, making joint representation beneficial.  
**Evidence anchors:** Abstract argues against sequential pipelines; Section 1 motivates integrated workflow; Vanilla Multitask baselines achieve competitive segmentation and classification scores.  
**Break condition:** If tasks are fundamentally orthogonal or shared capacity is insufficient, naive sharing can cause negative transfer.

## Foundational Learning
- **Multitask Learning & Negative Transfer**  
  Why needed: The core problem is competing gradients in a shared encoder due to annotator variability. Understanding how multiple losses interact in shared parameter space is prerequisite to designing RLAR.  
  Quick check: If loss gradients for two tasks point in nearly opposite directions in parameter space, what is the likely outcome for naive joint training, and what are two general strategies to mitigate it?

- **Adversarial Sensitivity Analysis (Feature Space)**  
  Why needed: RLAR's mechanism uses normalized gradients w.r.t. representation as probes of task sensitivity. The engineer must understand that ∇zL/∥∇zL∥ indicates the direction in representation space most sensitive to a task's loss.  
  Quick check: Given a scalar loss L(z) and a representation z, what does the vector ∇zL/∥∇zL∥ represent geometrically in the z-space?

- **Radiomics & TI-RADS Criteria**

## Architecture Onboarding
Component map: Input Image -> Shared Encoder (pretrained nnU-Net) -> Bottleneck z. From z: (a) -> Segmentation Decoder -> Segmentation mask. (b) -> Classification Head: split into h_tirads (13D, supervised by radiomics regression) and h_deep, concatenated -> final linear -> TI-RADS logits. RLAR module computes per-task normalized adversarial gradients from z to generate δ vectors for L_RLAR.

Critical path: The encoder processes input to produce z. Simultaneously, the segmentation decoder and classification head produce outputs to compute L_seg and L_cls. The radiomics features are computed from ground-truth masks (training only) to compute L_clin. The gradients of L_seg, L_cls, L_clin w.r.t. z are normalized to obtain δ_seg, δ_cls, δ_clin. Pairwise absolute cosine similarities among δ vectors form L_RLAR. Total loss L = L_seg + L_cls + L_clin + L_RLAR. Backpropagated to update encoder and heads.

Design tradeoffs:  
- RLAR representation level: Bottleneck yields stable gains in-domain (ThyroidXL); mid-encoder better for external shift (AIMI), reflecting trade-off between abstract vs. mid-level feature interference control.  
- Radiomics dimensionality: 13 features balance clinical alignment vs. risk of overfitting to noisy targets; more features could increase conflict with deep branch.  
- RLAR weight λ_adv: Too high suppresses all gradient alignment; too low fails to mitigate conflict; requires tuning.

Failure signatures:  
- High variance in fold performance (e.g., F1 std±0.011) without RLAR; RLAR reduces variance to ±0.0018.  
- Drop in recall on external dataset (AIMI) for models without RLAR; RLAR maintains higher recall.  
- Ablation shows significant performance drop when removing key radiomics features (ellipticity, GLCM entropy) on AIMI but not ThyroidXL, indicating over-reliance on specific cues that may not generalize.

First 3 experiments:  
1. **Replicate Vanilla Multitask baseline** – Train shared encoder without RLAR or clinical guidance; confirm high fold-to-fold variance in F1 on ThyroidXL and a recall drop on AIMI.  
2. **RLAR layer sensitivity test** – Apply RLAR at bottleneck, mid-encoder, last encoder, and as a mean over three layers; evaluate classification F1 and segmentation Dice on ThyroidXL to find optimal representation level for in-domain stability.  
3. **Radiomics feature ablation on AIMI** – For the clinically guided+RLAR model, zero out each of the 13 radiomics features in h_tirads and measure classification recall; expect significant degradation for ellipticity and GLCM entropy.

## Open Questions the Paper Calls Out
### Open Question 1  
**Question:** Why does applying RLAR at the mid-encoder layer yield the best recall on external AIMI, while bottleneck regularization excels on in-domain ThyroidXL?  
**Basis:** The paper shows these results in ablation tables but speculates it is due to higher intra-case variability and temporal redundancy in AIMI without formal testing.  
**Why unresolved:** Lacks quantitative analysis of feature semantics at different layers under domain shift.  
**What evidence would resolve it:** Visualize or measure task sensitivity directions (δt) at different layers for both datasets, correlated with feature statistics (texture complexity, motion artifacts). Possibly freeze features at specific layers during RLAR to isolate contributions.

### Open Question 2  
**Question:** Under severe annotator variability or distribution shift, does the radiomics distillation target inadvertently encode annotator-specific biases rather than universal TI-RADS criteria?  
**Basis:** The approach assumes radiomics are stable descriptors, but external AIMI results are highly sensitive to specific radiomics features (ellipticity, GLCM entropy), hinting at fragility.  
**Why unresolved:** No analysis of inter-annotator variance in computed radiomics or how target distributions shift across datasets.  
**What evidence would resolve it:** Collect multiple expert masks for a subset and compute radiomics per mask to measure inter-annotator variance. Train models with these alternative targets and compare generalization. Or analyze feature importance shifts between datasets.

### Open Question 3  
**Question:** Does RLAR’s penalty on angular alignment suppress features that are genuinely useful for both tasks but appear to conflict in gradient space?  
**Basis:** RLAR encourages complementary task sensitivities but the paper provides no interpretability of the shared latent space; it only reports task performance metrics.  
**Why unresolved:** No analysis of what latent features are preserved or discarded by RLAR, and whether critical shared cues are lost.  
**What evidence would resolve it:** Apply feature attribution (e.g., Grad-CAM on encoder) or linear probes to measure similarity of task-specific saliency maps with/without RLAR. Compare the predictive power of shared features for both tasks to detect suppression of genuinely shared information.

## Limitations
- Hyperparameter values (λ_adv, λ_seg, λ_cls, λ_clin, ε), regularization strength, checkpoint selection criteria, and class weighting scheme are not fully specified, impeding exact replication.
- Radiomics extraction details (binning strategy, GLCM parameters, standardization) and architecture specifics (classification embedding dimension, hidden layer sizes, exact nnU-Net preprocessing) are missing, risking implementation drift.
- The model shows heavy reliance on a few radiomic features (e.g., ellipticity, GLCM entropy) for external generalization, raising concerns about robustness if these cues are unreliable in new settings.

## Confidence
- RLAR stabilizes multitask training: Medium (evidence from reduced variance and improved recall, but break condition not tested).
- Clinically guided radiomics distillation improves robustness: Medium (feature ablations support utility, but correlation with true malignancy remains an assumption).
- Shared encoder reflects clinical workflow: High (vanilla multitask baselines demonstrate natural coupling).
