# Gated Adaptation for Continual Learning in Human Activity Recognition

## Quick Facts
- **ArXiv ID:** 2603.10046  
- **Source URL:** https://arxiv.org/abs/2603.10046  
- **Reference count:** 40  
- **Primary result:** Gated adaptation reduces catastrophic forgetting in domain-incremental HAR by training less than 2% of parameters, raising final accuracy from 56.7% to 77.7% on PAMAP2.

## Executive Summary
The paper addresses catastrophic forgetting in domain-incremental human activity recognition (HAR), where on-device models must adapt to new subjects without losing performance on prior ones. The proposed method freezes a pretrained CNN backbone and introduces lightweight channel-wise gated modulation, restricting adaptation to diagonal scaling of intermediate features. This design provides theoretical guarantees on bounded representational drift and yields large empirical gains: on PAMAP2, forgetting drops from 39.7% to 16.2% and final accuracy climbs from 56.7% to 77.7%. Across three HAR benchmarks, the approach consistently outperforms replay‑free baselines (EWC, LwF, HAT) while training less than 2% of parameters, demonstrating an effective stability‑plasticity trade‑off without replay buffers or task‑specific regularization.

## Method Summary
A standard CNN backbone is first pretrained on a source dataset (WISDM). For continual learning on a target domain with multiple subjects, the backbone is frozen entirely. After each residual block, a gating module is inserted; each gate computes per‑channel scaling coefficients via global average pooling followed by a two‑layer bottleneck MLP (reduction ratio r = 8) and a sigmoid. During sequential training on each new subject, only the gate parameters and a single shared linear classifier are updated using cross‑entropy loss; the backbone remains untouched. Training employs Adam (lr = 0.001), early stopping, L2 regularization (λ = 0.0001), gradient clipping (max norm = 1.0), and batch size 64. No replay buffers or explicit regularization (e.g., EWC) are used, yielding an extremely parameter‑efficient solution suitable for on‑device deployment.

## Key Results
- On PAMAP2 (8 sequential subjects), the method reduces forgetting from 39.7% to 16.2% and improves final accuracy from 56.7% to 77.7%.
- It consistently outperforms replay‑free baselines (EWC, LwF, HAT) across three HAR benchmarks (PAMAP2, DSA, UCI‑HAR).
- Training involves less than 2% of model parameters, confirming extreme parameter efficiency.

## Why This Works (Mechanism)
1. **Frozen backbone ensures representational stability.** Keeping the pretrained CNN backbone fixed guarantees that intermediate features \(U(x)\) remain identical across tasks, preventing degradation on earlier subjects. Theoretical analysis (Theorem 1) bounds feature drift when the backbone is frozen. Empirically, freezing alone reduces forgetting dramatically (Table IV). The core assumption is that pretrained features capture shared structure across subjects, and subject‑specific variations can be handled downstream.

2. **Channel‑wise gating enables adaptive yet bounded modulation.** Gates apply a diagonal scaling matrix \(D(g)\) to backbone features, updating only per‑channel gains \(g_i \in (0,1)\). This preserves the directional structure of frozen features while allowing subject‑specific adjustments. Assumption 1 posits that cross‑subject variability is approximately channel‑wise, supported by strong diagonal correlations (Figure 4). Theorem 1 shows that for any new task, feature drift satisfies \(\|H' - H\|_F \le \delta(x)\|U\|_F\) with \(\delta(x)=\|g' - g\|_\infty\), thereby constraining forgetting.

3. **Extreme parameter efficiency supports on‑device deployment.** Each gate contains only a two‑layer bottleneck MLP (e.g., 65 536 parameters for 512‑channel layers) and the classifier is shared. Consequently, sequentially training on new subjects updates less than 2% of total parameters, drastically lowering memory and compute costs. Ablations (Table V) reveal that adding more capacity (e.g., dense layers) increases forgetting despite higher parameter counts, highlighting the suitability of diagonal constraints for a favorable stability‑plasticity trade‑off.

## Architecture Onboarding
**Component map:**  
Input -> Per‑subject z‑score normalization -> Embedding layer -> Residual Stack 1 -> Gate 1 -> Residual Stack 2 -> Gate 2 -> Residual Stack 3 -> Gate 3 -> Residual Stack 4 -> Gate 4 -> Global average pooling -> Linear classifier -> Prediction.

**Critical path:**  
1. Pre‑train CNN backbone on WISDM with standard training.  
2. Freeze backbone parameters entirely.  
3. Insert channel‑wise gate modules after each residual block.  
4. For each new subject (random order): train only gate parameters and classifier using that subject’s data, with early stopping; evaluate on all subjects seen so far.  
5. Repeat over multiple permutations to compute Final Accuracy, Forgetting Measure, and Learning Accuracy.

**Design tradeoffs:**  
- **Stability vs. plasticity:** Larger gate bottleneck or task‑specific gates increase adaptation but risk forgetting.  
- **Parameter count vs. adaptability:** Smaller gate hidden size reduces parameters but may underfit subject‑specific patterns.  
- **Task‑free vs. task‑aware:** Shared gates across subjects are memory‑efficient; separate gates per subject improve performance slightly but scale linearly with tasks.

**Failure signatures:**  
- **High forgetting measure (FM):** Indicates over‑adaptation or unintended backbone updates; check gate saturation and backbone update locks.  
- **Low learning accuracy (LA):** Gates lack capacity; inspect gate output distribution (clipped to 0/1) and consider increasing bottleneck size.  
- **Classifier confusion:** If FM is low but final accuracy is poor, the shared classifier may be under‑capacity; consider a larger classifier or per‑task bias.  
- **Gate saturation:** Most gate values near 0 or 1; adjust initialization or learning rate.

**First 3 experiments:**  
1. **Ablation of backbone freezing and gating** (Table IV): Compared (a) trainable backbone, (b) frozen backbone, (c) frozen backbone + gates. Demonstrated that freezing reduces forgetting dramatically, and gates restore plasticity.  
2. **Gating vs. dense layers** (Table V): Replaced gates with fully connected layers of varying depth. Added capacity amplified forgetting despite more parameters, underscoring gating’s stability advantage.  
3. **Knowledge distillation extension** (Table VI): Added KD loss to the gating baseline. Further reduced forgetting at the cost of learning accuracy, validating the drift‑margin relationship.

## Limitations
- **Pre‑training protocol opacity:** The WISDM train/validation split and stratification method are unspecified, risking inconsistent backbone quality.  
- **Gate integration point ambiguity:** The exact placement of gating modules relative to batch normalization layers is unclear, which may affect feature statistics and performance.  
- **Assumption generalizability:** The channel‑wise shift assumption (Assumption 1) is only validated on PAMAP2; its validity on other HAR datasets remains untested.

## Confidence
- Frozen backbone prevents forgetting: **High**  
- Diagonal gating limits representational drift: **Medium**  
- Lightweight gates enable on‑device continual learning: **High**
