# pQuant: Towards Effective Low-Bit Language Models via Decoupled Linear Quantization-Aware Training

## Quick Facts
- **arXiv ID:** 2602.22592
- **Source URL:** https://arxiv.org/abs/2602.22592
- **Reference count:** 40
- **Primary result:** Reduces perplexity by 32.0% over prior 1-bit baselines; matches FP16 model accuracy while delivering over 2× higher throughput; surpasses 2-bit models in accuracy with 18.2% better inference speed.

## Executive Summary
pQuant addresses the parameter democratization problem in 1-bit quantization-aware training (QAT) from scratch, where weight sensitivities become homogenized and limit model expressivity. The method decouples each linear layer into a dominant 1-bit branch and a compact high-precision (8-bit) branch, using feature scaling to explicitly guide sensitive parameters to the high-precision pathway. This branch can further be extended into multiple sparsely-activated experts to scale capacity efficiently under extreme quantization. Experiments demonstrate that pQuant significantly improves over prior 1-bit baselines, achieves accuracy parity with full-precision models, and provides substantial speedups, while scaling more effectively than simply increasing model size.

## Method Summary
pQuant modifies the feed-forward network (FFN) in transformer blocks by splitting each linear transformation into two parallel branches: a 1-bit branch processing the majority of dimensions and an 8-bit branch reserved for a small subset of dimensions (size `r`). The outputs of these branches are multiplied by learnable scalar factors `α` and `β`, with `α` initialized much larger than `β` to prioritize gradient flow to the high-precision branch during early training. To scale the model's capacity for sensitive information without increasing per-token computation, the single 8-bit branch can be replaced by `N` 8-bit experts. A lightweight router selects one expert per token via top‑1 gating, ensuring the total number of active parameters matches that of a standard dense FFN. All other components (e.g., attention projections, layer norms) are quantized to 1‑bit.

## Key Results
- Reduces perplexity by 32.0% compared to previous 1-bit QAT baselines.
- Matches FP16 model accuracy while achieving more than 2× higher throughput.
- Surpasses 2-bit models in accuracy with 18.2% better inference speed.
- Demonstrates superior scalability: the performance gap to FP16 narrows as model size increases.

## Why This Works (Mechanism)
pQuant works through three interconnected mechanisms that counteract parameter democratization and preserve model expressivity under extreme quantization:

1. **Decoupled linear layers** split each weight matrix into a dominant 1‑bit branch and a compact 8‑bit branch. This structural separation prevents the homogenization of weight sensitivity that occurs when all parameters are forced into the same low‑bit regime. The high‑precision branch operates independently, avoiding dynamic range collapse, and provides a dedicated subspace for sensitive weights.

2. **Feature scaling** introduces learnable scalars `α` and `β` multiplied by the 8‑bit and 1‑bit branch outputs, respectively. By initializing `α ≫ β`, the gradient signal to the 8‑bit branch is amplified early in training, explicitly guiding the optimization to allocate the most critical representations to high precision. Ablations confirm that removing this scaling severely harms performance.

3. **Sparse expert scaling** replaces the single 8‑bit branch with `N` parallel 8‑bit experts, selected by a top‑1 router. This increases total high‑precision capacity without raising per‑token FLOPs, allowing the model to scale its sensitive parameter subspace efficiently. Experiments show that performance improves monotonically with `N` and narrows the gap to full‑precision scaling laws.

## Architecture Onboarding
**Component map:**  
Token embeddings → Transformer Block (× L) → Output (LM head).  
Each block: LayerNorm → Multi‑Head Attention (1‑bit Q, K, V, O projections) → residual add → LayerNorm → Feed‑Forward Network (FFN).  
FFN: input splits into two branches:  
  1‑bit branch: 1‑bit linear layer on lower `(D_ffn − r)` dimensions → scaled by `β`.  
  8‑bit branch: either a single 8‑bit linear on top `r` dimensions or a router (linear layer) selects one of `N` 8‑bit experts (each size `r`) → scaled by `α`.  
Scaled outputs summed and added to residual.

**Critical path:** The novel decoupled FFN computation: same input → split → independent 1‑bit and 8‑bit matrix multiplications → learnable scaling → summation. This path is the core innovation that preserves sensitivity.

**Design tradeoffs:**  
- `r` (high‑precision dimension): larger `r` preserves more sensitive information but increases memory/compute of the 8‑bit branch.  
- `N` (number of experts): larger `N` yields more total capacity without per‑token cost, but adds router overhead and stores all expert parameters.  
- Precision choices: 8‑bit for the high‑precision branch balances accuracy and hardware support; 1‑bit maximizes bit efficiency.

**Failure signatures:**  
- Training instability: sudden loss spikes or NaNs, possibly from diverging scaling factors.  
- Sensitivity homogenization persists: if sensitivity analysis (Eq. 2) shows a flat distribution in the 1‑bit branch and no high‑sensitivity peak in the 8‑bit branch, decoupling failed.  
- Router collapse: per‑expert token counts become heavily skewed (one expert > 95% of tokens), wasting capacity.

**First 3 experiments:**  
1. Reproduce sensitivity homogenization: train BitNet‑1B (baseline) and pQuant‑1B (`N=1`); compute Eq. 2 sensitivity for the last FFN layer. Expect uniform log‑sensitivity for baseline and a bi‑modal distribution for pQuant.  
2. Ablate feature scaling: train pQuant‑700M three ways: (a) default `α=2.0, β=0.2`; (b) `α=1.0, β=0.5`; (c) fixed equal weights (no learnable scalars). Compare final perplexity; expect (a) best, (c) worst.  
3. Scale experts: train pQuant‑1.3B with `N=1,2,4,8`. Evaluate perplexity and zero‑shot accuracy, and record router utilization. Expect monotonic improvement with `N`, and utilization roughly uniform across experts.

## Limitations
- Decoupling is applied only to FFN layers; attention projections remain 1‑bit, potentially capping overall accuracy gains.
- Hyperparameters `r` (high‑precision dimension) and `N` (expert count) are chosen heuristically; optimal values across model scales are unknown.
- The router lacks explicit load‑balancing regularization, risking expert collapse under sparse activation.
