# Transformers Can Learn Rules They've Never Seen: Proof of Computation Beyond Interpolation

## Quick Facts
- **arXiv ID:** 2603.17019  
- **Source URL:** https://arxiv.org/abs/2603.17019  
- **Reference count:** 40  
- **Primary result:** A two-layer transformer can recover a hidden XOR rule (absent from training data) via differentiable multi-step constraint propagation, achieving up to 100% accuracy, while similarity-based predictors fail provably (0%).

## Executive Summary
This paper challenges the interpolation-only hypothesis for transformers—the idea that they can only recombine patterns seen during training. Through controlled experiments on synthetic tasks, it demonstrates that transformers can infer rules for input patterns that were never directly supervised. In a cellular automaton task with a pure XOR rule, a specific 3‑bit neighborhood is masked at all timesteps. Despite never seeing the correct output for that pattern, a two‑layer transformer recovers it with high accuracy by propagating constraints across multiple unrolled steps. Circuit extraction confirms the model implements XOR via attention‑based neighbor routing and a ReLU feed‑forward network. A theoretical construction shows a single transformer block can implement any radius‑1 Boolean rule exactly. Together, this provides an existence proof that transformers can compute beyond interpolation.

## Method Summary
The core experiment uses a one‑dimensional cellular automaton with Rule 150 (L ⊕ C ⊕ R). One 3‑bit neighborhood pattern (e.g., `000`) is designated “hidden.” During training, the model never receives a loss signal for any position whose preceding neighborhood matches the hidden pattern, across all timesteps. The model must infer the hidden pattern’s output indirectly by correctly predicting visible positions in subsequent steps—errors on visible positions provide a gradient that indirectly constrains hidden predictions. Training uses **soft unrolling**: the model’s own probabilistic predictions (sigmoid outputs) are fed back as inputs for the next timestep, allowing gradients to flow through multiple steps. A two‑layer post‑LN transformer (embedding dim 64, 4 heads, ReLU FFN dim 128) is trained with Adam (lr 1e‑3) for 220 epochs. Performance is measured by accuracy on all masked positions in a test set. Ablations compare soft unrolling to single‑step prediction, and baselines include kernel ridge regression, k‑NN, and MLPs.

## Key Results
- **Experiment 1 (CA with hidden XOR pattern):** Similarity‑based predictors fail (0%). Two‑layer transformer success rate: 47/60 runs (mean holdout accuracy ∼71.5%). Soft unrolling yields 96.7% vs. 63.1% without unrolling.
- **Experiment 2 (Symbolic operator chains):** Transformer mean holdout accuracy 41.8% vs. kernel ridge regression 4.3% (k‑NN/MLP 0%). Removing intermediate steps degrades performance.
- **Theoretical construction:** A single standard transformer block with learned absolute position embeddings can implement any radius‑1 Boolean rule exactly via attention routing and ReLU FFN.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Transformers can learn rules absent from training data by propagating constraints through multi-step differentiable unrolling.
- **Mechanism:** Hidden pattern predictions are never directly supervised; instead, errors cascade to future visible positions, creating an indirect gradient. Soft unrolling (feeding soft predictions back as input) allows gradients to flow through multiple timesteps, enabling the model to adjust hidden predictions.
- **Core assumption:** The hidden rule is sufficiently constrained by visible positions; i.e., the system of equations linking hidden and visible patterns is solvable when enough steps are unrolled.
- **Evidence anchors:**  
  [abstract] "Performance hinges on differentiable multi-step constraint propagation (96.7% with soft unrolling vs 63.1% without)."  
  [section 4.3] "A GF(2) constraint solver confirms the multi-step rollout uniquely determines hidden outputs... with two timesteps, 100% of samples are uniquely identifiable."
- **Break condition:** If the number of visible constraints is too low (e.g., too many hidden patterns) or unrolling depth is insufficient, the hidden pattern remains underdetermined.

### Mechanism 2
- **Claim:** Self‑attention performs smooth local routing of neighboring bits to the correct positional slots, enabling later rule computation without memorization.
- **Mechanism:** Absolute position embeddings are combined with content‑agnostic queries/keys so that each head attends strongly to a fixed relative offset (e.g., left neighbor, right neighbor). Value vectors carry the actual bit values. The residual stream already contains the center bit.
- **Core assumption:** Position embeddings are learnable and the model can achieve high enough attention mass on the target neighbor.
- **Evidence anchors:**  
  [abstract] "Circuit extraction confirms XOR computation … attention provides smooth local routing."  
  [section A.2, Lemma 10] "Softmax heads can route a fixed relative neighbour with arbitrarily high mass."  
  [section A.2] The explicit construction in Theorem 14 shows a standard block implementing any radius‑1 Boolean rule via attention‑based routing.
- **Break condition:** Without proper positional encoding or if attention mass is split across too many positions, the routed values become a noisy mixture and rule decoding fails.

### Mechanism 3
- **Claim:** The ReLU feed‑forward network provides the necessary non‑affine transformation to compute any Boolean rule from the routed, sign‑margin neighbor values.
- **Mechanism:** After attention and LayerNorm, the three relevant scalars (left, center, right) have sign margins: they are reliably positive when the corresponding bit is 1 and negative when 0. A width‑8 (or more) ReLU network with a high threshold creates separate activated detectors for each of the eight input patterns, exactly one of which fires per pattern. A final linear readout combines these detectors to implement any rule.
- **Core assumption:** The pre‑FFN values have bounded magnitude and a margin relative to the threshold; FFN width is sufficient (≥8 for general radius‑1 rules, 4 for XOR).
- **Evidence anchors:**  
  [section A.2, Lemma 13] “ReLU FFN computes any Boolean rule from sign margins… exactly one hidden unit is positive.”  
  [section 4.4] Polynomial fitting of logits yields large interaction terms (LC, LR, CR, LCR) confirming XOR’s nonlinear structure, not a linear approximation.  
  [section B] Layer ablation shows layer‑1 essential, and logit lens reveals XOR appears only after layer‑1.
- **Break condition:** Insufficient FFN width or lack of sign margin (e.g., attention outputs too noisy) prevents exact rule implementation; the network then defaults to linear or additive approximations.

## Architecture Onboarding
- **Component map:**  
  Token embedding → Position embedding → Self‑attention (aggregate neighbors) → Residual add (center bit) → LayerNorm → ReLU FFN (apply rule) → Multi‑step unroll (feed soft output back) → Output head
- **Critical path:**  
  `Token embedding → Pos.emb → Attention (L+R) → Residual (add C) → LayerNorm → FFN (rule) → Soft unroll`
- **Design tradeoffs:**  
  - **Unrolling:** Soft unrolling (differentiable) vs hard unrolling (discrete) vs none. Soft gives much stronger indirect signal.  
  - **Masking:** Hide outputs at positions where hidden patterns occur in the *true* previous state; mask all timesteps (not just t+1).  
  - **Neighborhood size:** Larger radius provides more visible constraints but increases model capacity needs.
- **Failure signatures:**  
  - Holdout accuracy near chance (∼50%) or stuck at output bias (∼62.5% for some rules).  
  - No clear “grokking” phase transition: holdout never rises after supervised plateau.  
  - Circuit extraction shows linear decoding of XOR from any layer (no interaction terms).
- **First 3 experiments:**  
  1. **Hard‑gap replication.** Train a 2‑layer transformer on Rule 150 with one hidden pattern, soft unrolling. Verify holdout accuracy significantly above 0% and baselines at 0%.  
  2. **Unroll ablation.** Train with same setup but without feeding back predictions (single‑step only). Expected accuracy ∼63%, matching output bias.  
  3. **Circuit probe.** After training, take layer‑1 activations for the three input bits; fit a degree‑3 polynomial. Coefficients of LC, LR, CR, LCR should be large (non‑zero), confirming XOR computation.

## Open Questions the Paper Calls Out
1. **When does constraint propagation activate in LLMs?** Under what specific training conditions (data distribution, scale, architecture variations) do large language models activate the constraint‑propagation mechanism demonstrated in synthetic settings, and how does this interact with natural language's noise and ambiguity? (Basis: explicit; authors note natural language provides denser but noisier constraints.)
2. **What causes bimodal success/failure?** What determines the bimodal outcomes in learning held‑out rules (e.g., Rule 150’s 47/60 successful seeds)? Is it primarily initialization‑dependent phase transitions, optimizer dynamics, or intrinsic properties of the hidden pattern’s position in the rule’s truth table? (Basis: explicit; linked to lottery ticket hypotheses but not isolated.)
3. **Generalization to stochastic/continuous domains.** To what extent can the identified mechanism—differentiable multi‑step constraint propagation—generalize to stochastic or continuous‑valued domains (e.g., learning physical laws from noisy sensor data), where the clean boolean‑causal structure is absent? (Basis: inferred; limitation section notes this remains untested.)
4. **Universal competence threshold.** Is the phase transition at ∼85% supervised accuracy (Figure 3) a universal threshold for beyond‑interpolation generalization across diverse task families, or an artifact of the specific constraint density and supervision pattern? (Basis: explicit; observed in two task families but not broadly validated.)
5. **Nature of internal representations.** When transformers succeed on held‑out rules, what is the nature of the learned internal representation—do they develop truly novel, interpretable subroutines (e.g., a dedicated parity circuit) or approximate the rule via distributed, inscrutable embeddings? (Basis: explicit; circuit analysis is post‑hoc and shows functional but not structural necessity.)

## Limitations
- Masking criterion (true previous state vs model‑predicted state) is unspecified and could affect constraint propagation.
- Theoretical results assume perfect sign margins, exact neighbor routing, and sufficient FFN width; real training may not meet these.
- Soft unrolling is not compared against hard (discrete) unrolling; the necessity of differentiable unrolling is inferred but not isolated.
- Only XOR and a few radius‑1 rules are tested; scalability to larger neighborhoods or more complex rules is unknown.

## Confidence
- **Hidden rule recovery:** High (empirical success 47/60, circuit evidence).
- **Constraint propagation necessity:** Medium (ablation impact, but theoretical gaps).
- **Attention local routing:** Medium (some extraction support, needs broader probing).
- **FFN universal Boolean computation:** Medium‑High (width argument + polynomial fits).

## Next Checks
1. **Mask source comparison:** Train with mask based on true state vs model‑predicted state (thresholded). Holdout accuracy divergence indicates reliance on true‑state information.
2. **Hard unroll vs soft:** Replace soft unroll with discrete rollouts (detach or straight‑through). Compare holdout performance to quantify gradient‑flow benefit.
3. **Attention routing quantification:** For each layer/head, compute attention mass on the correct neighbor offset; correlate with rule accuracy across seeds to confirm routing’s role.
