# From Features to Actions: Explainability in Traditional and Agentic AI Systems

## Quick Facts
- arXiv ID: 2602.06841
- Source URL: https://arxiv.org/abs/2602.06841
- Reference count: 40
- Primary result: Trace-grounded rubrics reliably localize agent failures (state tracking inconsistency 2.7× more prevalent in failed runs) where traditional feature attribution methods (SHAP/LIME) cannot.

## Executive Summary
Traditional explainable AI (XAI) methods are designed for static, single-prediction tasks and rely on feature attribution. Agentic AI systems, however, operate through multi-step trajectories, requiring different diagnostic approaches. This paper shows that while attribution methods provide stable feature rankings in static settings (Spearman ρ=0.86), they fail to pinpoint execution-level failures in agent runs. In contrast, trace-grounded rubrics—behavioral constraints applied to execution logs—consistently identify failure modes. Across benchmarks (TAU-bench Airline, AssistantBench), state tracking inconsistency is 2.7× more common in failed trajectories and correlates with a 49% reduction in success probability. The authors introduce the Minimal Explanation Packet (MEP) framework, bundling explanations with linked evidence and verification signals, to make agent behavior debugging actionable. A bridging experiment confirms that attributions over aggregated rubric features yield global correlations but lack per-run diagnostic power, underscoring the need for trace-based analysis in agentic XAI.

## Method Summary
The study compares traditional attribution methods (SHAP, LIME) against a novel trace-based diagnostic approach. The core methodology involves: (1) collecting execution traces (state, action, observation tuples) from agent runs on static and agentic benchmarks; (2) applying a behavioral rubric (via an LLM judge called Docent) to each trace to produce binary violation flags per constraint; (3) correlating these flags with task outcomes to identify predictive failure modes; and (4) bridging experiment where trajectories are compressed into fixed-length binary feature vectors (rubric violations) to train a surrogate model, whose global SHAP values are compared against direct trace analysis. Additionally, the Minimal Explanation Packet (MEP) is proposed to package explanations with contextual evidence and verification signals, shifting from static narratives to replayable audit logs.

## Key Results
- Attribution methods achieve stable feature rankings in static classification (Spearman ρ=0.86) but cannot reliably localize failures in multi-step agent trajectories.
- Trace-based rubrics consistently identify failures; for example, state tracking inconsistency is 2.7× more prevalent in failed trajectories and reduces success probability by 49%.
- While SHAP/LIME over aggregated rubric features reveal global correlations, only trace-based analysis provides actionable, per-run diagnoses of where and how agent behavior breaks down.

## Why This Works (Mechanism)
### Mechanism 1
Trace-grounded rubrics localize failures by applying behavioral constraints (e.g., state consistency, tool correctness) directly to execution traces. A judge evaluates each step against rules, producing binary violation flags correlated with outcomes. The core assumption is that such constraints are checkable from logs and causally linked to failures. Evidence: state tracking inconsistency appears 2.7× more in failures and reduces success by 49% (Tables 7, 8). Break condition: poorly defined rubrics or incomplete traces cause silent failure.

### Mechanism 2
The Minimal Explanation Packet (MEP) bundles the explanation artifact, linked execution context, and verification signals (e.g., rubric flags, replay consistency) into a replayable audit package. This shifts from static narratives to actionable debugging. Core assumption: Debugging requires full context and trust signals. Evidence: MEP design in [section 3.4] and its diagnostic benefits in [section 6.1]. Break condition: uncalibrated verification signals or missing logs degrade utility.

### Mechanism 3
Applying attribution (SHAP/LIME) to aggregated rubric features yields global importance rankings but cannot diagnose per-run failures because the trajectory compression discards temporal structure. The surrogate model predicts success from binary violation vectors, and SHAP shows feature influence on aggregate outcomes. Evidence: [section 5.3] and Table 10 contrast limited per-run localization for SHAP vs. explicit trace-based. Break condition: insufficient rubric features or misrepresentative surrogate models lead to misleading attributions.

## Foundational Learning
- **Static vs. Agentic Paradigm Distinction**  
  *Why needed:* All explanation methods and evaluation criteria are grounded in this dichotomy. Misapplying static XAI (feature attribution) to agentic settings causes diagnostic failure.  
  *Quick check:* "What is the unit of explanation in each paradigm (single prediction vs. full trajectory), and what evidence grounds it (input features vs. execution trace)?"

- **State-Action-Observation Loop**  
  *Why needed:* Agentic behavior is defined as τ = (s_0, a_0, o_0, ..., s_T). Failures are understood by examining how state (s_t) evolves, how actions (a_t) are chosen, and how observations (o_t) are processed.  
  *Quick check:* "Given a failed run, how would you identify whether the failure was due to a wrong action choice, a state tracking error, or a misinterpreted observation?"

- **Behavioral Rubrics as Diagnostic Primitives**  
  *Why needed:* Rubrics (e.g., State Consistency, Tool Correctness) are the atomic checks applied to traces. They convert raw logs into labeled failure modes.  
  *Quick check:* "For a TAU-bench failure, which rubric violation is most predictive (Table 8), and what concrete trace pattern would trigger it?"

## Architecture Onboarding
**Component map:**  
Agent Execution Layer → Trace Analyzer (Docent) → MEP Assembler → Evaluation Engine  
Bridging Module: Traces → Rubric features → Surrogate → SHAP

**Critical path:**  
1. Collect execution traces (τ) for each run via HAL-Harness.  
2. Run Docent judge on each τ to get rubric flags (f_i,r).  
3. Compute outcome correlations (Tables 7, 8).  
4. For bridging: encode τ → feature vector → logistic regression → SHAP.

**Design tradeoffs:**  
- **Rubric granularity:** Fine-grained rubrics catch more errors but increase judge cost and noise; coarse rubrics are cheaper but may miss subtle failures.  
- **Judge reliance:** Using a fixed LLM judge (GPT-5) ensures consistency but introduces model-specific bias and cost; rule-based checks are cheaper but less flexible.  
- **Trace completeness:** Requires full logging of state, actions, observations; partial logs break localization.

**Failure signatures:**  
- High aggregate SHAP importance but low per-run diagnostic power: indicates bridging captures global correlations but not actionable breakdowns.  
- Rubric flag with P(success|flag) ≈ P(success): that rubric is not predictive; may be irrelevant or noisy.  
- Ratio(prev) = ∞ for a rubric: violation occurs only in failures (e.g., Tool Choice Accuracy in AssistantBench), a hard blocker.

**First 3 experiments:**  
1. **ReplicateStatic Baseline:** Run TF-IDF + Logistic Regression on IT/non-IT classification. Compute SHAP/LIME stability (Spearman ρ) under perturbations. Expected: ρ > 0.85 for linear model.  
2. **Run Agentic Rubric Analysis:** Execute HAL-Harness on TAU-bench Airline with o4-mini. Process traces with Docent using rubrics in Table 3. Compute Tables 7 & 8. Expected: State Tracking Consistency shows Ratio(prev) > 2 and RR < 0.6.  
3. **Bridging Experiment:** Encode each TAU-bench trajectory as 6-dimensional binary vector (rubric flags). Train logistic regression to predict success. Compute global SHAP values. Expected: Intent Alignment and State Consistency have highest |SHAP|, but no per-run failure localization.

## Open Questions the Paper Calls Out
1. **Formalizing faithfulness for agentic XAI**  
   *Question:* How can we formally define and measure the faithfulness of explanations for agentic AI systems, ensuring they accurately reflect the agent's multi‑step decision‑making process?  
   *Basis:* Explicit. The paper states that "open challenges remain in formalizing explanation faithfulness" for agentic systems.  
   *Why unresolved:* Current faithfulness checks (e.g., perturbation stability) are designed for static predictions and do not capture temporal dynamics; no unified framework exists for agentic trajectories.  
   *Resolving evidence:* A theoretical framework and metrics that integrate verification signals (e.g., replay consistency, state invariants) tailored to multi‑step agent explanations, validated on benchmarks with ground‑truth causal structure.

2. **Causal and counterfactual failure analysis**  
   *Question:* What methods can enable causal, counterfactual analysis of agent failures from execution traces, moving beyond correlational diagnostics?  
   *Basis:* Explicit. The authors identify "developing intervention‑based and counterfactual analyses to validate causal hypotheses about agent failures" as a key future direction.  
   *Why unresolved:* Existing trace‑based rubrics only flag violations but do not establish causality; tracing which specific actions cause failure is difficult without manual or automated interventions.  
   *Resolving evidence:* A system that automates generation of counterfactual trajectories (e.g., altering tool calls or state updates) and measures outcome changes, combined with causal inference validation on known failure modes.

3. **Generalization across agent architectures**  
   *Question:* To what extent do the comparative advantages of trace‑based explanations generalize beyond LLM‑based tool agents to other agent architectures (e.g., embodied agents, multi‑agent coordination, online learning with persistent memory)?  
   *Basis:* Inferred. The limitations section notes the evaluation's narrow scope and that findings may not generalize to such architectures.  
   *Why unresolved:* Different agent types exhibit distinct decision‑making dynamics and failure modes, potentially requiring tailored explanation approaches; no empirical evidence covers these settings.  
   *Resolving evidence:* Replication studies applying the same Minimal Explanation Packet (MEP) and rubric framework across diverse agent architectures, measuring diagnostic utility and per‑run failure localization effectiveness.

4. **Improving rubric labeling reliability**  
   *Question:* How can we improve the reliability and reduce subjectivity in rubric‑based labeling of agent traces, especially when using LLM judges?  
   *Basis:* Inferred. The paper highlights that "rubric labels are generated by an LLM judge via Docent, which introduces subjectivity" and relies on complete traces.  
   *Why unresolved:* LLM judge variability and potential bias can affect diagnostic consistency; incomplete logging in real‑world settings may further undermine validity.  
   *Resolving evidence:* Comparative studies of labeling protocols (e.g., human–LLM consensus, rule‑based checks) under varying trace completeness; development of robustness metrics and calibration against expert annotations.

## Limitations
- External validity: The findings are validated on synthetic benchmarks (TAU-bench, AssistantBench); real-world deployments with messy traces and diverse agents may not exhibit the same failure patterns or diagnostic efficacy.
- Judge dependency: Rubric labeling relies on an LLM judge (Docent), which may introduce bias or inconsistency; rule-based alternatives are not explored.
- Rubric completeness: The predefined rubric may miss subtle or emergent failure modes not captured by the current set of constraints.

## Confidence
- **Rubric-based failure localization:** High confidence for internal benchmarks (TAU-bench, AssistantBench) based on strong empirical metrics (e.g., 2.7× prevalence, 49% success reduction); Medium confidence for external generalization.
- **MEP framework utility:** Medium confidence; the bundling concept is well-defined but lacks empirical user studies or adoption evidence beyond the paper's argument; break conditions (judge bias, missing logs) could degrade utility.
- **Attribution method limitations:** High confidence; the bridging experiment clearly demonstrates that SHAP/LIME cannot provide per-run diagnostics in agentic settings, supported by correlations with aggregate outcomes and prior literature on sequential attribution.

## Next Checks
- **Cross-domain replication:** Run the exact rubric analysis on at least two new agentic benchmarks (e.g., WebArena, AgentBench) to test generalizability of the top predictive violations.
- **Rubric design ablation:** Ablate specific rubric constraints (e.g., remove “State Tracking Consistency”) and measure drop in failure localization F1 to quantify each constraint’s unique diagnostic contribution.
- **Human evaluation of MEPs:** Conduct a user study where developers debug failed trajectories using (a) standard SHAP explanations vs. (b) MEPs; compare time-to-diagnosis and accuracy against ground-truth failure causes.
