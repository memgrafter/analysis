# GenState-AI: State-Aware Dataset for Text-to-Video Retrieval on AI-Generated Videos

## Quick Facts
- **arXiv ID**: 2603.14426
- **Source URL**: https://arxiv.org/abs/2603.14426
- **Reference count**: 40
- **Primary result**: MLLMs achieve strong semantic discrimination (Acc_sem up to 0.921) but consistently fail on temporal hard negatives (Acc_temp as low as 0.391), indicating insufficient end-state grounding.

## Executive Summary
Existing text-to-video retrieval benchmarks over-rely on single-frame appearance, leaving temporal reasoning and decisive end-state grounding unevaluated. GenState-AI introduces an AI-generated benchmark of 956 short videos (from Wan2.2-TI2V-5B) where each query has a main video, a temporal hard negative (same objects/motion but incorrect end state), and a semantic hard negative (different objects but similar motion). This design isolates temporal versus semantic confusion. Evaluating two MLLM baselines (VCF-Lik and Qwen3-VL) shows both models achieve reasonable semantic discrimination (Acc_sem up to 0.921) but consistently fail on temporal hard negatives (Acc_temp as low as 0.391). Triplet ordering analysis reveals temporal negatives frequently outrank the main video (e.g., 25–42% of cases per subset), confirming that current models over-prefer temporally plausible yet end-state-incorrect videos, highlighting insufficient grounding on final state evidence.

## Method Summary
GenState-AI comprises 956 videos (720p, 24fps, 5s) generated by the Wan2.2-TI2V-5B model using minimalist prompt templates. For each natural language query, three videos are produced: a main video that exactly matches the described state transition; a temporal hard negative that alters only the decisive end state (e.g., "adds" vs. "removes") while preserving objects, scene, and initial motion; and a semantic hard negative that retains the motion type but substitutes object identity (e.g., "apples" vs. "oranges"). All main videos undergo manual verification to ensure fidelity to the prompt; the negatives are retained as global distractors. Evaluation employs standard Recall@K and custom triplet metrics: Acc_temp (main ranked above temporal negative), Acc_sem (main ranked above semantic negative), Acc_tri (main ranked above both), and relative-order histograms. Candidate pools are constructed per query by adding all videos from the same category as distractors. Two MLLM baselines are tested: VCF-Lik, which scores videos via length-normalized token log-likelihood from VideoChat-Flash-Qwen2-7B_res448; and Qwen3-VL, a two-stage system using Qwen3-VL-Embedding-2B for top-20 retrieval followed by Qwen3-VL-Reranker-2B, with inputs resized to 360×420 and 5 sampled frames.

## Key Results
- Semantic discrimination is strong: Acc_sem reaches 0.921 for VCF-Lik on Home subset; Qwen3-VL achieves 0.803 overall.
- Temporal grounding is weak: Acc_temp as low as 0.391 for Qwen3-VL on Manipulation; VCF-Lik also low (0.558–0.730 across subsets).
- Triplet ordering shows temporal negatives outrank the main video in 25–42% of cases, with the dominant pattern `temp > main > sem` for VCF-Lik, indicating a bias toward motion plausibility over final state.

## Why This Works (Mechanism)
### Mechanism 1: Hard Negatives Enforce End-State Grounding
- **Claim**: Temporal hard negatives force models to discriminate based on final state rather than superficial motion plausibility.
- **Mechanism**: By generating videos with identical objects, scenes, and initial motion trajectories but differing only in the decisive end-state (e.g., object added vs. removed), the benchmark removes appearance-based shortcuts. A model must evaluate the late-frame configuration to succeed.
- **Core assumption**: Without explicit end-state verification, models default to matching global appearance or intermediate motion cues that are shared between the main video and its temporal hard negative.
- **Evidence anchors**:
  - [abstract]: "...temporal hard negative that differs only in the decisive end-state... isolating temporal versus semantic confusion."
  - [section 3.1]: "Temporal hard negatives alter the action dynamics themselves... Such carefully designed hard negatives force models to rely on precise state reasoning rather than superficial cues."
  - [corpus]: Weak direct evidence; neighboring papers (e.g., "Reversed in Time") also emphasize temporal Emphasis but do not specifically address end-state grounding via controlled negatives.
- **Break condition**: If models learn to exploit generator-specific artifacts (e.g., subtle texture differences in objects that correlate with end-state) rather than performing genuine temporal reasoning.

### Mechanism 2: AI Generation Controls Nuisance Variables
- **Claim**: Procedural AI video generation minimizes uncontrolled visual confounders present in real-world footage, making state differences the primary discriminative signal.
- **Mechanism**: Using Wan2.2-TI2V-5B with fixed prompt templates ensures consistent background, lighting, camera stability, and object style across triplet members. Variations are introduced only via controlled prompt edits (object identity or final state), isolating the intended semantic/temporal dimension.
- **Core assumption**: Real-world benchmarks contain myriad nuisance factors (camera motion, editing, background clutter) that allow models to succeed without temporal reasoning.
- **Evidence anchors**:
  - [abstract]: "AI-generated benchmark... providing controllable evaluation conditions for state-aware retrieval."
  - [section 3.2]: "We use... Wan2.2-TI2V-5B... to procedurally create a large collection of short clips... where object states, spatial relations, quantities, and causal outcomes are explicitly manipulated."
- **Break condition**: If the generator itself introduces spurious correlations (e.g., consistently poorer quality for certain edits) that models latch onto instead of the intended state transition.

### Mechanism 3: Triplet Ordering Diagnoses Error Source
- **Claim**: Relative ordering of main, temporal negative, and semantic negative within a triplet reveals whether failures stem from insufficient temporal grounding or semantic insensitivity.
- **Mechanism**: Metrics like `Acc_temp` and `Acc_sem` measure pairwise preferences, while the full 3! ordering histogram exposes systematic biases (e.g., `temp > main > sem` indicates over-reliance on motion plausibility). This disentangles "confused by similar motion" from "confused by similar objects."
- **Core assumption**: Models exhibit non-random, interpretable error patterns that align with the type of misalignment (temporal vs. semantic) in the negatives.
- **Evidence anchors**:
  - [abstract]: "Triplet ordering analysis reveals temporal negatives frequently outrank the main video (e.g., 25–42% of cases per subset)..."
  - [section 4.3]: Defines `Acc_temp`, `Acc_sem`, and relative-order histogram; Figure 3/4 show `temp > main > sem` is the dominant failure pattern for VCF-Lik.
  - [section 5.3]: "the dominant pattern is that the temporal hard negative outranks the main video... cases where the semantic negative outranks the main video are comparatively rare."
- **Break condition**: If ordering distributions become random or do not correlate with human judgments of error type.

## Foundational Learning
### Concept: State-Aware Retrieval
- **Why needed here**: The core task shifts from retrieving any "on-topic" video to retrieving one that matches a specific *outcome* of a state change (e.g., "adds one" vs. "removes one").
- **Quick check question**: Given a query describing a final state (e.g., "two apples" after an action), what visual evidence must a model verify in the video's last frames?

### Concept: Hard Negative Construction for Contrastive Learning
- **Why needed here**: The dataset's diagnostic power relies on *controlled* negatives that differ in exactly one dimension (temporal or semantic), unlike uncontrolled negatives in real datasets.
- **Quick check question**: How does a temporal hard negative differ from the main video *relative to* a semantic hard negative? What is held constant in each case?

### Concept: Triplet-Based Consistency Metrics
- **Why needed here**: Standard Recall@K measures retrieval of the main video against a pool but cannot diagnose *why* a model fails when it retrieves a plausible but incorrect video. Triplet metrics (`Acc_temp`, `Acc_sem`, ordering histograms) explicitly test whether the model respects the fine-grained query constraints relative to specific distractors.
- **Quick check question**: If a model ranks `temp` above `main` but `sem` below `main`, what does `Acc_temp` vs. `Acc_sem` tell us about its failure mode?

## Architecture Onboarding
### Component map:
1. **Prompt Engine**: Generates controlled natural language descriptions (e.g., "On a shelf there are two apples. A hand adds one more.") following a template.
2. **AI Video Generator (Wan2.2-TI2V-5B)**: Takes prompt (and optionally image) to synthesize a 5-second, 720p video. Used to generate main, temporal negative (e.g., "removes one"), and semantic negative (e.g., "adds one orange").
3. **Triplet Builder**: Pairs each main video with its corresponding temporal and semantic hard negatives based on shared prompt roots.
4. **Manual Verification Pipeline**: Human annotators check main video fidelity to prompt and filter invalid clips; negatives can remain as global distractors.
5. **Evaluation Engine**: Computes standard metrics (R@k) and triplet-specific metrics (`Acc_temp`, `Acc_sem`, `Acc_tri`, ordering histograms) for any MLLM-based scorer (likelihood or embedding/reranker).

**Critical path:** Prompt specification → Video generation (3x per query template) → Manual validation → Triplet assembly → Model scoring (on candidate pool containing main + its two negatives + other distractors) → Metric computation.

**Design tradeoffs:**
- *Synthetic control vs. real-world validity*: GenState-AI sacrifices ecological validity for precise isolation of state reasoning; models may overfit to generator style.
- *Prompt simplicity vs. complexity*: Minimalist prompts reduce noise but may not represent natural language complexity of real queries.
- *Triplet integrity vs. pool diversity*: Requiring query-specific triplets limits scale; retaining "global" negatives increases pool challenge but introduces asymmetry.

**Failure signatures:**
- High `Acc_temp` error rate (`Acc_temp` << `Acc_sem`) indicates model ranks temporally plausible but end-state-incorrect videos above the true match.
- Ordering histogram dominated by `temp > main > sem` or `temp > sem > main` patterns.
- Performance drop on "Cartoon" and "Toy" subsets where end-state differences are subtle against stylized backgrounds (Table 3, Figure 4).

**First 3 experiments:**
1. **Replicate baseline evaluation**: Load the provided 956 videos (or a subset), build candidate pools per query, run VCF-Lik and Qwen3-VL pipelines exactly as described in Section 5.2, and reproduce Table 3 and Figure 3 to establish a diagnostic baseline.
2. **Ablate prompt complexity**: Generate additional triplets with longer, more descriptive prompts (deviating from the "minimalist" design) and measure impact on `Acc_temp`/`Acc_sem`. Hypothesis: increased linguistic noise may degrade temporal reasoning further.
3. **Category-wise error analysis**: For the "Manipulation" subset where VCF-Lik shows high `Acc_tri` but Qwen3-VL low (0.826 vs. 0.304), inspect failure cases. Is Qwen3-VL's two-stage pipeline (embedding then reranker) filtering out temporal negatives early? Test by scoring all candidates with the reranker alone.

## Open Questions the Paper Calls Out
1. **Why do MLLM-based text-to-video retrieval models consistently rank temporal hard negatives above the main video?**  
   - **Basis in paper**: [inferred] from triplet ordering analysis showing temporal negatives outrank the main video in 25–42% of queries across subsets, with patterns like `temp > main > sem` dominating failures in Toy and Cartoon groups.  
   - **Why unresolved**: The paper documents this systematic bias but does not investigate model internals (e.g., frame-level attention, state representation) or training objectives to explain why models over-rely on plausible motion trajectories over decisive end-state evidence.  
   - **What evidence would resolve it**: Ablation studies controlling for end-state salience (e.g., blurring final frames), visualization of temporal attention weights across frames, or training with auxiliary losses that explicitly predict final states to see if temporal confusion decreases.

2. **How do artifacts or biases in the Wan2.2-TI2V-5B video generator affect the reliability of GenState-AI for evaluating state-aware retrieval?**  
   - **Basis in paper**: [inferred] because the dataset construction hinges on Wan2.2-TI2V-5B’s ability to produce clean state transitions; while manual filtering removes gross errors, subtle generative biases (e.g., physics inconsistencies, style drift) may inadvertently create spurious cues or remove genuine challenges.  
   - **Why unresolved**: The paper assumes the generator’s controllability yields perfectly isolated state changes, but it does not analyze whether generator-specific failure modes (e.g., difficulty with certain object interactions) might skew the difficulty distribution or create artifacts that models exploit.  
   - **What evidence would resolve it**: Cross-generator validation—regenerating the same prompts with multiple video generators (e.g., Sora, CogVideoX) and measuring consistency of model failure patterns (e.g., Acc_temp, ordering statistics) across generators; or correlating model errors with generator confidence scores/per-frame consistency metrics.

3. **Do conventional non-MLLM video retrieval architectures exhibit the same temporal confusion on GenState-AI?**  
   - **Basis in paper**: [inferred] because evaluation is limited to two MLLM-based baselines; no comparison with pre-MLLM or non-LLM video retrieval systems is provided.  
   - **Why unresolved**: The paper frames the problem as state-aware retrieval generally, but experimental evidence only speaks to MLLM capabilities; it is unclear if older architectures, trained on different objectives (e.g., contrastive learning on real videos), show similar asymmetry.  
   - **What evidence would resolve it**: Benchmarking standard dual-encoder models (e.g., CLIP4Clip, X-CLIP, VideoBERT) on GenState-AI using the same triplet metrics; comparing their error patterns to those of the MLLM baselines to isolate whether temporal confusion correlates with model family or is universal.

4. **Which specific attributes of state transitions are most predictive of temporal confusion errors?**  
   - **Basis in paper**: [inferred] from the subset-wise performance breakdown and mention of transition types (position, quantity, relations), but without correlating error rates with quantitative features.  
   - **Why unresolved**: The paper identifies broad categories where models struggle (e.g., Toy/Cartoon show high temporal confusion) but does not dissect what precise characteristics—such as number of objects, type of spatial relation, or need for causal reasoning—make certain transitions disproportionately hard, limiting targeted model improvements.  
   - **What evidence would resolve it**: Annotating each GenState-AI triplet with fine-grained state-change features (e.g., single-object vs. multi-object motion, explicit vs. implicit end state, number of state variables changed) and performing statistical analysis to identify features that strongly predict `temp > main` ordering or low Acc_temp.

## Limitations
- Synthetic videos may not reflect real-world complexity and could introduce generator-specific artifacts that models exploit.
- Hard negative construction via prompt editing is underspecified; possible unintended visual differences beyond the intended state changes.
- Distractor pool composition (whether to use same subset or all categories) is ambiguous, which may affect triplet metric reliability.

## Confidence
- Isolation via hard negatives: Medium
- MLLMs exhibit temporal grounding failure: Medium
- Triplet ordering diagnoses error source: Medium

## Next Checks
