# Evolution Strategy-Based Calibration for Low-Bit Quantization of Speech Models

## Quick Facts
- **arXiv ID:** 2603.08173
- **Source URL:** https://arxiv.org/abs/2603.08173
- **Reference count:** 0
- **Primary result:** ESC enables lossless INT8 and near-lossless full INT4 quantization for speech models, with only ~1.75% relative accuracy drop on AST at INT4, and ~2.31× speedup for INT8 deployment.

## Executive Summary
Speech models exhibit large activation dynamic ranges that cause severe quantization errors when using conventional calibration methods. This paper introduces ESC, a novel post-training quantization calibration approach that formulates activation scaling as a two-step optimization: per-layer mean squared error (MSE) initialization followed by global refinement using the Covariance Matrix Adaptation Evolution Strategy (CMA-ES) to minimize task error. ESC achieves lossless INT8 quantization across five speech tasks (ASR, speaker recognition, speech enhancement, TTS, audio classification) and is the first method to enable near-lossless full INT4 quantization, with ≤1.75% relative accuracy drop on the AST benchmark. Combining ESC with existing PTQ techniques (e.g., SmoothQuant) further reduces the drop to ~1%. For INT8 deployment, models gain an average 2.31× speedup and substantial memory savings. ESC consistently outperforms all baseline calibration methods by effectively optimizing globally across layers.

## Method Summary
ESC operates in two stages. First, for each layer, a per-layer scaling factor is initialized by minimizing the MSE between original and quantized activations on a small calibration dataset. This provides a fast, heuristic starting point. Second, the scaling factors of all layers are jointly refined using CMA-ES, a gradient-free evolutionary optimizer. CMA-ES treats the vector of scaling factors as a population, iteratively sampling and evaluating candidates by quantizing the model and measuring task error (e.g., word error rate for ASR). The best candidates guide the evolution of the search distribution, converging to near-optimal global scaling factors that account for cross-layer dependencies. The final scaling factors are applied to quantize the model to low bit-widths (INT4/INT8) without any retraining.

## Key Results
- **Lossless INT8**: ESC yields no measurable accuracy degradation on all five evaluated speech tasks.
- **Near-lossless INT4**: Full INT4 quantization incurs at most 1.75% relative accuracy loss on AST; combined with SmoothQuant this drops to ~1%.
- **Efficiency gains**: Quantized INT8 models run 2.31× faster on average with significant memory reduction, and ESC outperforms all baseline calibration methods.

## Why This Works (Mechanism)
- The per-layer MSE initialization supplies a high-quality starting point that respects each layer's activation distribution.
- CMA-ES performs a global, black-box search over the joint scaling factor space, naturally capturing interactions that per-layer heuristics ignore.
- By directly minimizing task error rather than a proxy (e.g., activation MSE), ESC aligns quantization with the ultimate performance metric, preventing accumulated errors that could harm end-to-end model behavior.

## Architecture Onboarding
**Component map:**  
Calibration Data -> Per-Layer MSE Initialization -> CMA-ES Global Refinement -> Scaling Factors -> Quantized Model

**Critical path:**  
1. Gather a representative calibration dataset.  
2. For each layer, compute per-layer scaling factors by minimizing activation MSE.  
3. Assemble the scaling factor vector as the initial population for CMA-ES.  
4. Run CMA-ES: for each candidate, quantize the model, evaluate task error on a validation set, and update the search distribution.  
5. Select the best scaling factors, apply them to quantize the model, and deploy.

**Design tradeoffs:**  
- *Calibration time vs. accuracy*: More CMA-ES iterations improve accuracy but increase overhead.  
- *Bit-width*: Lower bit-width (INT4) yields higher speed and memory savings but is more sensitive to scaling errors.  
- *Memory usage*: Storing activations for per-layer MSE may be memory-intensive for large models.

**Failure signatures:**  
- Large gap between calibration and test accuracy, indicating poor generalization of scaling factors.  
- CMA-ES fails to converge (stagnant best task error) within reasonable iterations.  
- Scaling factors with extreme values (e.g., near zero) causing underflow/overflow during quantization.

**First experiments:**  
1. **Replication**: Implement ESC for a standard speech model (e.g., Whisper) on a small dataset to confirm end-to-end functionality.  
2. **Baseline comparison**: Benchmark ESC against common calibration methods (max, MSE, percentile) on INT8 and INT4 across multiple tasks.  
3. **Ablation study**: Vary CMA-ES population size and iteration count to quantify calibration cost vs. accuracy trade-offs and assess sensitivity to the MSE initialization.

## Limitations
- Generalizability is limited to five speech tasks; performance on other speech/audio models remains unknown.  
- Calibration overhead from CMA-ES is not quantified and may impede real-world deployment.  
- Comparisons omit recent PTQ methods (beyond SmoothQuant) and quantization-aware training baselines, and hardware speedup claims lack detailed profiling.
