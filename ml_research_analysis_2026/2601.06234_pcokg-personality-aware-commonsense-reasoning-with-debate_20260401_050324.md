# PCoKG: Personality-aware Commonsense Reasoning with Debate

## Quick Facts
- **ArXiv ID:** 2601.06234  
- **Source URL:** https://arxiv.org/abs/2601.06234  
- **Reference count:** 4  
- **Primary result:** PCoKGM fine‑tuned model outperforms COMET on word‑overlap metrics (BLEU‑4 up to 14.50, ROUGE‑L up to 31.38) and improves consistency in persona‑based dialogue generation.

## Executive Summary
This paper tackles the neglect of personality traits in commonsense reasoning, aiming to enable personalized AI. The authors present PCoKG, a personality‑aware knowledge graph that extends traditional (event, relation, tail) triples to (event, personality, relation, tail) quadruples using Myers‑Briggs Type Indicator (MBTI) categories. An LLM‑driven pipeline with event filtering and a multi‑agent debate (proponent, opponent, judge) generates and refines 521,316 quadruples. Models fine‑tuned on PCoKG (PCoKGM) achieve significant improvements over the state‑of‑the‑art COMET model on automatic metrics and demonstrate better consistency in persona‑based dialogue. Ablation studies highlight the importance of MBTI integration, careful event selection, and the debate mechanism.

## Method Summary
The method begins by curating a seed set of events, which are filtered to ensure relevance and quality. For each event and each of the 16 MBTI personality types, an LLM‑based pipeline generates candidate quadruples. The pipeline employs three agents: a proponent proposes a quadruple, an opponent critiques it, and a judge decides whether to accept the quadruple. This debate loop iterates until a valid quadruple is produced or a maximum attempt limit is reached. The process yields 521,316 high‑quality quadruples, forming the PCoKG dataset. A base model (e.g., COMET) is then fine‑tuned on this dataset to create PCoKGM, which is evaluated on both standard commonsense reasoning benchmarks and a persona‑based dialogue generation task.

## Key Results
- PCoKGM achieves BLEU‑4 up to 14.50 and ROUGE‑L up to 31.38, substantially outperforming COMET.
- Ablation studies confirm the critical contributions of: (a) MBTI integration, (b) event filtering, and (c) the multi‑agent debate mechanism.
- In persona‑based dialogue generation, PCoKGM improves consistency with reference outputs compared to models relying on generic commonsense knowledge.

## Why This Works (Mechanism)
The quadruple structure explicitly conditions reasoning on personality, allowing the model to capture trait‑specific associations. The debate mechanism reduces hallucinations and improves the diversity and validity of generated quadruples by having agents challenge and refine proposals. Event filtering focuses computational resources on high‑quality events, preventing noise accumulation. Fine‑tuning on the resulting rich, personality‑annotated knowledge graph transfers these benefits to downstream tasks, enabling models to generate outputs consistent with designated personalities.

## Architecture Onboarding
**Component Map:**  
Event Filter → Proponent Agent → Opponent Agent → Judge → Quadruple Storage → Fine‑tuning Module

**Critical Path:**  
1. Filter raw events →  
2. For each event and MBTI type, initiate debate →  
3. Proponent proposes quadruple →  
4. Opponent critiques →  
5. Judge accepts/rejects →  
6. If accepted, store quadruple →  
7. After accumulation, fine‑tune base model.

**Design Tradeoffs:**  
- Using LLMs for generation enables scalability but introduces cost and variability.  
- Debate improves quality but adds computational overhead.  
- MBTI provides a manageable discrete set; however, it may oversimplify compared to continuous trait models (e.g., Big Five).  
- Event filtering balances precision and coverage.

**Failure Signatures:**  
- Extremely low quadruple acceptance rate indicates overly strict judge or poor event selection.  
- Lack of diversity across MBTI types suggests the pipeline is not capturing personality nuances.  
- Fine‑tuned model fails to show personality‑specific improvements → inadequate graph or training regime.

**First Experiments:**  
1. **Replication of quadruple generation:** Re‑run the pipeline with specified LLM versions, measuring yield and filtering success rates.  
2. **Human evaluation of personality consistency:** Conduct pairwise preference tests asking judges whether outputs reflect the intended MBTI type.  
3. **Ablation of debate roles:** Remove opponent and/or judge to quantify their impact on quadruple diversity and validity.
