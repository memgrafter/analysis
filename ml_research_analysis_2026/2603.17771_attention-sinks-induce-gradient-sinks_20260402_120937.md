# Attention Sinks Induce Gradient Sinks

## Quick Facts
- **arXiv ID:** 2603.17771  
- **Source URL:** https://arxiv.org/abs/2603.17771  
- **Reference count:** 37  
- **Primary result:** V-scale preserves attention sinks while suppressing massive activations, supporting gradient sinks as the mediating mechanism.

## Executive Summary
This paper explores the relationship between attention sinks (AS)—the phenomenon where early tokens, especially the first, receive disproportionately high attention—and massive activations (MA), where the same tokens exhibit abnormally large activation norms. The authors introduce gradient sinks (GS), showing theoretically and empirically that under causal masking, AS concentrate gradients on the first token during backpropagation. In pre‑norm Transformers with RMSNorm, MA emerges as an adaptive response: large activations on the sink token amplify RMSNorm’s gradient compression, stabilizing residual flow. To test this, they propose V-scale, a modification that attenuates backpropagated gradients for small‑norm value vectors. Experiments on 0.1B and 0.3B Llama‑like models trained on C4 reveal that V‑scale decouples AS from MA—sink metrics remain strong while MA indicators drop significantly—confirming the GS‑as‑mediator hypothesis.

## Method Summary
The work uses causal language modeling with Llama‑style pre‑norm Transformers (RMSNorm, RoPE, SwiGLU MLPs) on the C4 dataset. Two model sizes (~0.1B and ~0.3B) are trained from scratch with identical hyperparameters (AdamW, sequence length 2048, etc.). The key intervention is **V‑scale**, applied after the V projection: each value vector is radially scaled by ϕ(∥v∥²)=∥v∥²/(∥v∥²+C), with C a learnable parameter (C = (d_head·σ)²·exp(θ), σ=0.02). This scales gradients for small‑norm values while minimally affecting forward pass for large norms. Checkpoints are saved regularly; a fixed validation batch is used to compute:
- **Attention sink strength:** sink mass M_s and thresholded sink rate Sink_ε (ε=0.3, T_ε=64)
- **Massive activation metrics:** norms of residual‑stream output h, MLP output R_mlp, and attention output R_attn at the first token (and other early tokens)
- **Gradient norms** in the Q/K/V pathways.
Baseline models show co‑occurring AS and MA; V‑scale models retain AS but show reduced MA, demonstrating decoupling.

## Key Results
- V‑scale models exhibit comparable attention sink metrics (M_s, Sink_ε) to baselines.
- V‑scale significantly lowers massive activation norms (residual‑stream, MLP, attention outputs) on the first token.
- The decoupling validates that gradient sinks, not just attention patterns, drive MA formation.

## Why This Works (Mechanism)
The paper outlines three interconnected mechanisms:

1. **Gradient Sink Formation**  
   Under causal masking, later tokens attend to the first token. During backpropagation, gradients from those later outputs aggregate onto the first token’s value (and key) vectors. Theorem 1 proves that the expected value‑path gradient norm on the sink token is bounded below by M_s²·∥µ∥², linking sink attention statistics to gradient concentration. Empirically, token‑wise gradient norms for V and K spike at position 0 across layers, while Q gradients remain flat.

2. **Massive Activations as an Adaptive Response**  
   In pre‑norm blocks, RMSNorm precedes the sublayer. Its Jacobian norm scales inversely with the incoming activation norm: larger ∥x∥ yields stronger attenuation. Thus, if the sink token’s activations become large (MA), RMSNorm reduces the backpropagated gradient proportionally, compensating for the initial amplification from the attention branch. This keeps the net change (“Changeattn”) near zero. Scatter plots show a strong negative correlation between gradient compression ratio and activation norm. Theorem 2 formalizes that the RMSNorm Jacobian operator norm ≤ ∥γ∥_∞ / rms(x).

3. **V‑scale Intervention**  
   V‑scale directly attenuates the gradient contribution of small‑norm value vectors (which characterize the sink token). By reducing ∇v_s L, it alleviates the gradient pressure on the sink token’s representation, diminishing the need to develop MA for gradient regulation. Experiments show that V‑scale lowers MA metrics while leaving AS nearly unchanged, confirming that gradient sinks are the primary driver of MA.

## Foundational Learning
- **Pre‑norm Transformer Architecture**  
  The order “normalization → sublayer → residual add” determines how gradients interact with RMSNorm, enabling norm‑dependent compression.

- **Causal Masking in Decoder‑Only Models**  
  The causal mask restricts attention to previous tokens, so later tokens can attend to the first token; this connectivity pattern is essential for gradient aggregation onto the sink.  
  *Quick check:* For sequence length T, which (t, s) pairs have non‑zero attention weight under causal masking?

- **Gradient Flow in Residual Networks**  
  For y = x + f(x), the gradient to x is ∇_x L = ∇_y L + (∂f/∂x)^T ∇_f L. A normalization layer before f(x) scales the second term.  
  *Quick check:* How does a pre‑sublayer normalization affect the magnitude of ∇_x L relative to ∇_y L?

## Architecture Onboarding
**Component map**: Token → RMSNorm → Attention (Q, K, V projections) → RoPE → QK· → Softmax → V‑scale (on V) → Value aggregation (Σ a·v̂) → Residual add → RMSNorm → SwiGLU MLP → Residual add.

**Critical path**:  
1. Causal mask → high attention mass on first token (AS).  
2. Backward pass: gradients from later outputs aggregate onto first token’s V (and K) vectors → gradient sink.  
3. Gradient passes through RMSNorm: large activation norm (MA) on first token → stronger attenuation → residual gradient stabilized (Changeattn ≈ 0).

**Design tradeoffs**:  
V‑scale modifies only the value‑path backward dynamics, assuming the value gradient dominates sink pressure. This minimal intervention preserves the attention weight distribution (AS) but leaves query/key‑path gradients untouched, so gradient sinks are not fully eliminated. The tradeoff is a partial decoupling rather than complete elimination of AS or GS.

**Failure signatures**:
- If the first token’s value norms are not small, V‑scale’s attenuation factor ϕ stays near 1 and MA persists.
- If V‑scale is applied at the wrong location (e.g., before RoPE or after aggregation), forward dynamics are altered and AS degrades.
- If gradient pressure on the sink token is not dominated by the value path (e.g., Q/K gradients major), V‑scale has little effect on MA.
- If RMSNorm is replaced by another normalization (e.g., LayerNorm), the adaptive MA response may fail, and V‑scale might not decouple as expected.

**First 3 experiments**:
1. **Baseline characterization** – Train a 0.1B pre‑norm Llama‑like model on C4. At checkpoints, compute per‑layer AS metrics (M_s, Sink_ε for first token), activation norms (residual, MLP, attention outputs), and gradient norms (Q/K/V). Verify co‑occurrence of AS, MA, and V/K gradient spikes.
2. **V‑scale intervention** – Train an identical model with V‑scale enabled. Apply identical checkpoint analysis. Expected: AS metrics similar to baseline, but MA (activation norms) and V‑gradient norms on first token reduced.
3. **Ablation of compression mechanism** – Replace RMSNorm with LayerNorm in a baseline model. Retrain and measure whether MA still emerges on the first token and whether the inverse relationship between gradient compression and activation norm (Compressattn vs. ∥h∥) breaks. Tests necessity of RMSNorm’s specific behavior.

## Open Questions the Paper Calls Out
- **Generalization to non‑dense architectures?**  
  The study is restricted to dense language models. It remains unclear whether the same GS‑MA mechanism transfers to Mixture‑of‑Experts or multimodal Transformers. Resolution requires extending measurements and V‑scale experiments to those settings.

- **Co‑evolution during training?**  
  The paper explains why MA is useful once GS exists, but not how AS and MA are learned from initialization. Which phenomenon appears first? Does preventing MA with V‑scale affect AS formation? Evidence: monitor metrics from very early training steps and apply V‑scale from step 0.

- **Scalability and downstream impact?**  
  Experiments were limited to 0.1B–0.3B models. Scaling to larger models, deeper networks, and longer contexts may change dynamics. Moreover, suppressing MA could harm capabilities. Evidence: train V‑scale models at 1B, 10B, etc., and evaluate on standard benchmarks (MMLU, GSM8K, long‑context tasks).

- **Alternative gradient modulation?**  
  V‑scale targets only the value path. Other interventions (Q‑scale, K‑scale, learned gating) might achieve cleaner decoupling with fewer side‑effects. The design space is unexplored. Evidence: implement and compare variants, measuring AS/MA metrics, training loss, and downstream performance.

## Limitations
- The analysis is specific to pre‑norm architectures with RMSNorm; applicability to post‑norm or LayerNorm is not proven.
- V‑scale assumes value‑path gradients dominate sink pressure; query/key contributions are not mitigated, leaving residual GS.
- The adaptive‑response claim for MA is supported by correlation and intervention but not by exclusive proof; alternative triggers (e.g., outlier amplification) are not fully ruled out.

## Confidence
- **Gradient sink formation** (theoretical link between AS and V/K gradient concentration): **High**.
- **Massive activations as adaptive response** (MA emerges to regulate gradients via RMSNorm): **Medium**.
- **V‑scale decoupling** (suppresses MA while preserving AS in small models): **Medium** (scaling and downstream effects uncertain).

## Next Checks
1. **Architectural ablation** – Train baseline models with post‑norm blocks (normalization after sublayer) and check if MA still develops on the first token without RMSNorm’s pre‑normalization compression.
2. **Component isolation** – Replace RMSNorm with LayerNorm in a pre‑norm baseline; verify whether MA persists and whether the Compressattn vs. activation norm relationship breaks.
3. **Cross‑family transfer** – Apply V‑scale to a non‑Llama decoder (e.g., GPT‑2 with LayerNorm) and measure AS/MA decoupling.
