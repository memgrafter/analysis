# Revealing Positive and Negative Role Models to Help People Make Good Decisions
## Quick Facts
- arXiv ID: 2603.02495
- Source URL: https://arxiv.org/abs/2603.02495
- Reference count: 40
- Primary result: The planner's disclosure problem on a bipartite social network is addressed; revealing only positive role models yields a submodular welfare function so greedy attains (1-1/e) approximation. Revealing negatives breaks submodularity, but a proxy welfare restores submodularity and, under bounded negative neighbors, proxy-greedy gives a constant-factor approximation. Fairness and learning guarantees are also established, with experiments confirming effectiveness.

## Executive Summary
This paper studies how a social planner can influence individual decisions by revealing information about role models in a bipartite network. The planner chooses which targets (role models) to disclose to agents, aiming to maximize the expected welfare defined as the sum of probabilities that agents emulate a positive target. The core challenge is that revealing negative targets can destroy the submodularity of the welfare function, undermining greedy performance. The authors show that if only positive targets are revealed, the welfare is submodular and a greedy algorithm achieves a (1-1/e)-approximation. When negatives are allowed, they introduce a proxy welfare function that remains submodular and, provided each agent has a bounded number of negative neighbors, proxy-greedy yields a constant-factor approximation to the true optimum. Extensions address fairness among groups, interventions for high-risk agents, coverage radius maximization, and sample complexity for learning from a subset of agents. Experiments on four real datasets validate the theoretical findings and demonstrate the practical benefits of the proposed algorithms.

## Method Summary
The problem is modeled on an unweighted bipartite graph with agents X and targets T; each target has a fixed binary label (positive/negative). The planner selects a subset S of targets to reveal under a budget K. Each agent x chooses among its revealed positive neighbors if any; otherwise it may still be influenced by unrevealed neighbors, with the emulation probability given by Q_S(x). Social welfare F(S) sums Q_S(x) over all agents. The authors prove that when S is restricted to positives only, F is submodular, enabling a simple greedy algorithm with (1-1/e) guarantee. If negatives are allowed, F can become supermodular, so they define a proxy function F_p based on penalizing the first negative reveal per agent. Under the assumption that each agent has at most c negative neighbors, F(S) ≤ c·F_p(S), making proxy-greedy a constant-factor approximation. Additional techniques include a heuristic balancing positive/negative reveals, iterative intervention to assist high-risk agents, a greedy-radius algorithm for spatial coverage, and a PAC learning approach with sample complexity bounds. The overall method involves graph construction from real data, running appropriate greedy variants, and evaluating welfare gains, fairness, coverage, and learning performance.

## Key Results
- Positives-only disclosure yields a submodular welfare function; greedy achieves (1-1/e) approximation.
- Revealing negatives breaks submodularity, but a carefully designed proxy welfare remains submodular; with bounded negative neighbors, proxy-greedy gives a constant-factor approximation to the true welfare.
- For a constant number of demographic groups, allocating the budget per group satisfies all groups under positives-only; with negatives and bounded neighbors, each group’s welfare gain is within a constant of its optimum.
- Sample complexity guarantees that running greedy on a random sample of agents yields near-optimal expected welfare with high probability.
- Experiments on four real datasets (Adult, Student Performance, Garment Workers) confirm the strong performance of greedy, the benefits of interventions, and the effectiveness of coverage radius expansion.

## Why This Works (Mechanism)
The welfare maximization leverages diminishing returns properties. When only positive targets are revealed, each additional positive target can only increase an agent’s emulation probability if the agent previously had no revealed positive neighbor; this creates submodularity. Revealing a negative target, however, can increase the marginal welfare because it reduces the pool of unrevealed targets, thereby increasing the relative influence of any existing positive neighbors—this leads to supermodular behavior in some graphs. The proxy welfare function circumvents this by capping the benefit of negative reveals per agent: only the first negative reveal contributes fully, while subsequent negatives contribute less. This ensures that the proxy’s marginal gains never increase, restoring submodularity. Under the c-bounded condition (each agent has ≤ c negative neighbors), the true welfare is at most a factor c larger than the proxy, so maximizing the proxy close to optimally also nearly maximizes the true objective. The greedy algorithm consistently picks the target with the largest marginal increase in the chosen welfare function (true or proxy), and submodularity guarantees its near-optimality.

## Architecture Onboarding
Component map: Graph input (agents X, targets T, edges E, labels f) -> Agent choice model (Q_S(x)) -> Welfare function F(S) -> Greedy algorithm (iterative target selection). Variants: Proxy welfare F_p -> Proxy-greedy. Group fairness: split budget per group. Interventions: pre/post-reveal edge addition. Coverage radius: greedy radius expansion. Learning: sample agents -> run greedy on sample -> output set.

Critical path: The planner first determines whether only positives are allowed. If yes, run standard greedy (submodular). If negatives allowed, check if agents are c-bounded; if yes, run proxy-greedy for constant-factor; otherwise, fall back to heuristic greedy with no guarantee but empirical performance. For fairness, run the chosen algorithm separately per group with allocated budget.

Design tradeoffs:
- Computation: Brute-force gives optimum but is exponential (O(m^K)); greedy runs in polynomial time (O(K m n δ)).
- Accuracy vs. flexibility: Proxy welfare ensures submodularity but may underestimate true gains by up to factor c; classic greedy has no guarantee with negatives but is simpler.
- Fairness vs. efficiency: Equal budget per group is simple and fair but may waste budget; centralized optimization could improve total welfare but might starve some groups.
- Intervention timing: Pre-reveal (removing high-risk agents before greedy) can sometimes reduce total welfare if those agents contributed positively; post-reveal adds edges after greedy and always improves welfare.

Failure signatures:
- Non-submodular true welfare with negatives -> greedy performance can degrade to O(√n) approximation ratio.
- Large c (many negative neighbors) -> proxy constant factor weakens (larger multiplicative loss).
- Groups with highly uneven connectivity -> equal per-group budget may fail to satisfy all groups (some groups’ optimum may be unattainable).
- High-risk agents already near-optimal -> intervention gains become negligible.

## Open Questions the Paper Calls Out
- **Weighted edges**: How do heterogeneous emulation strengths (weighted edges) affect submodularity and approximation guarantees? The current analysis assumes unweighted graphs; weighting could break submodularity even for positives-only and would require new theoretical foundations.
- **Strategic classification**: Can the model be extended when agents act strategically—emulating positives as improvement and negatives as gaming? This introduces incentives that differ from the uniform-random response, likely altering the welfare objective and optimal disclosure strategies.
- **Stochastic block models**: For random bipartite graphs where target labels and edges follow prescribed probabilities, what sample complexity and performance guarantees does greedy enjoy? The deterministic analysis may not directly apply; new probabilistic tools are needed to bound welfare estimation errors and greedy’s robustness.
