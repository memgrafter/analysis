# Narrative Weaver: Towards Controllable Long-Range Visual Consistency with Multi-Modal Conditioning
## Quick Facts
- **arXiv ID:** 2603.06688
- **Source URL:** https://arxiv.org/abs/2603.06688
- **Reference count:** 40
- **Primary result:** Proposed framework integrates a Multimodal LLM for narrative planning and a fine-grained control module with a dynamic Memory Bank to anchor each generation step, preventing visual drift across extended sequences, achieving state-of-the-art consistency metrics on multiple tasks.

## Executive Summary
Narrative Weaver addresses the fundamental challenge of generating long-range, visually consistent image narratives from multi-modal inputs (text + reference image). Existing diffusion models fail to maintain coherence across extended sequences due to cumulative drift. The solution hybridizes an autoregressive Multimodal Large Language Model (MLLM) for high-level narrative planning with a diffusion transformer (DiT) for image synthesis, linked by a system of learnable queries and a dynamic Memory Bank. The Memory Bank pools geometrically decaying features from prior generated frames to provide bounded, fine-grained conditioning. A progressive, multi-stage training strategy leverages pre-trained models and limited task-specific data, achieving strong performance without massive retraining. The method is evaluated on a new large-scale dataset (EAVSD) and across diverse scenarios, demonstrating superior multi-shot consistency in automated and human assessments.

## Method Summary
The framework operates in a progressive hybrid loop. First, a frozen MLLM (Qwen2.5-VL-3B) processes the initial condition image and user instruction, using a custom dynamic causal attention mask to generate an interleaved sequence of textual shot descriptions and special tokens delimiting "learnable queries." These queries are extracted and projected into the diffusion model's conditioning space. For each subsequent frame generation, the DiT (Flux.1-Dev) is conditioned on a concatenation of: the current learnable query, the VAE features of the initial condition image, and pooled features from a bounded memory buffer containing VAE latents of previously generated frames. After generating a frame, its low-level features are added to the Memory Bank, which applies geometric decay (pooling) to older entries to maintain a fixed total length. Training is staged: Stage 1 trains the MLLM on narrative planning; Stage 2 pre-trains and fine-tunes the learnable query projector on image-text data; Stage 3 fine-tunes the DiT with the full Memory Bank conditioning to enforce fine-grained inter-frame consistency.

## Key Results
- Achieves top GPT-4o scores: Textual Control (7.54), Image-Text Consistency (8.86), Reference-Generated Consistency (8.67), Multi-Shot Style Consistency (7.91), Multi-Shot Content Consistency (7.35).
- Outperforms baselines on automated metrics (CLIP Score, DreamSim) and user studies for long-range consistency and aesthetic quality.
- Demonstrates efficacy across controlled multi-scene generation, autonomous storytelling, and e-commerce advertising tasks.

## Why This Works (Mechanism)
### Mechanism 1: Dynamic Memory Bank for Long-Range Anchoring
- **Claim:** A dynamic Memory Bank with geometrically decaying feature pooling prevents visual drift across long image sequences by efficiently conditioning each generation step on a bounded set of prior frames.
- **Mechanism:** During diffusion generation of the *n*-th frame, the system concatenates the current learnable query, the conditioning image's VAE features, and pooled features from the last *T* generated frames. Pooling reduces each prior frame's feature length by a decay factor λ>1, ensuring total memory length remains bounded while emphasizing recent history.
- **Core assumption:** Visual consistency is best maintained by a transient memory of recent frames, where older frames contribute less contextual weight.
- **Evidence anchors:**
  - [abstract]: "fine-grained control module with a dynamic Memory Bank to anchor each generation step, preventing drift."
  - [section 3.1]: Detailed equations for memory pooling (Eq. 2) and conditioning signal construction (Eq. 3).
  - [corpus]: Weak direct evidence; neighboring papers address consistent generation but not this specific memory decay design (e.g., VinaBench focuses on benchmarks, SSG-Dit on spatial guidance).
- **Break condition:** If λ is poorly tuned (too aggressive decay loses long-range coherence; too conservative increases compute), or if generated frames contain severe artifacts that corrupt memory features.

### Mechanism 2: Progressive Multi-Stage Training for Data-Efficient Alignment
- **Claim:** A three-stage training strategy (narrative planning → semantic coherence → fine-grained consistency) decouples complex multimodal learning, enabling high performance with limited task-specific data.
- **Mechanism:** Stage 1 trains the MLLM on narrative text planning; Stage 2 aligns learnable queries with the diffusion model's semantic space using large public data then small task data; Stage 3 fine-tunes the diffusion model with fine-grained features (memory bank, low-level condition) to enforce inter-frame consistency.
- **Core assumption:** Separating high-level planning from low-level visual control simplifies optimization and prevents catastrophic forgetting.
- **Evidence anchors:**
  - [abstract]: "progressive, multi-stage training strategy that efficiently leverages existing pre-trained models, achieving state-of-the-art performance even with limited training data."
  - [section 3.2]: Explicit loss functions and objectives for each stage (Eq. 4–6) and training data volumes.
  - [corpus]: Indirect support; neighbors like 2K-Characters-10K-Stories address disentangled control but not staged training.
- **Break condition:** Insufficient data in Stage 2.1 (public pre-training) fails to establish query space alignment, causing Stage 3 to overfit small task data without generalizable consistency.

### Mechanism 3: MLLM-Mediated Narrative Planning with Learnable Queries
- **Claim:** A frozen MLLM (with a dynamic causal attention mask) generates textual narrative plans and high-level visual queries, which are then fused with fine-grained features to guide diffusion, enabling autonomous shot planning while maintaining control.
- **Mechanism:** The MLLM ingests the initial image+instruction and predicts a token sequence interleaving shot descriptions (`t_i`) and special tokens bracketing learnable queries (`q_i`). Queries attend to full multimodal context (image, prior text, prior queries), while text tokens are causally masked. Queries are projected to diffuse conditioning.
- **Core assumption:** A large pretrained MLLM contains sufficient cinematic and narrative knowledge to plan coherent multi-shot sequences when prompted appropriately.
- **Evidence anchors:**
  - [abstract]: "Multimodal Large Language Model (MLLM) for high-level narrative planning" and "learnable query module."
  - [section 3.1]: Attention mask design (Fig. 1c) and training objective for next-token prediction with `<img>`/`</img>` tokens.
  - [corpus]: Weak direct evidence; Weaver (writing LLM) and MIM (user behavior) are adjacent but not on MLLM for visual generation.
- **Break condition:** MLLM planning fails for out-of-domain narratives (e.g., highly abstract art) or when attention mask design does not properly freeze textual planning during fine-tuning, causing semantic drift.

## Architecture Onboarding
- **Component map:** Input (condition image + instruction) -> MLLM (AR) -> Interleaved [text plan, <img>queries</img>] -> Learnable Query Projector -> Conditioning Fusion (query + cond_image_features + memory_features) -> Diffusion Model (DiT) -> Generated frame -> Memory Bank update -> Repeat for next frame.
- **Critical path:** Input → MLLM narrative planning & query extraction → Memory bank update (after each generation) → Conditioning fusion → Diffusion generation → Repeat until sequence complete.
- **Design tradeoffs:**
  - *Efficiency vs. Consistency*: Memory bank uses bounded linear memory instead of quadratic self-attention across all frames, but may lose very-long-range details.
  - *Generalization vs. Control*: Freezing MLLM after Stage 1 preserves planning ability but limits adaptation to new narrative styles without full retraining.
  - *Data Efficiency vs. Performance*: Progressive staging allows small-task fine-tuning but requires careful hyperparameter balance between stages.
- **Failure signatures:**
  - Subject drift: Character/apparel changes abruptly after ~3–4 frames (Memory Bank decay misconfigured or Stage 3 omitted).
  - Narrative incoherence: Generated shots contradict earlier plot points (MLLM planning fails, attention mask broken).
  - Style collapse: All frames become near-identical (over-reliance on reference image, insufficient text conditioning).
- **First 3 experiments:**
  1. Ablate Stage 3 (fine-grained training) and measure inter-frame DreamSim/CLIP Score drop to validate necessity of Visual Consistency training.
  2. Vary Memory Bank decay factor λ and plot consistency metrics vs. sequence length to confirm bounded memory efficacy.
  3. Compare against a variant using vanilla DiT self-attention over all prior frames (no queries/memory bank) to measure scalability (TFLOPs) and quality on 12+ frame sequences.

## Open Questions the Paper Calls Out
- **Question 1:** How can Narrative Weaver be extended to generate video with temporal consistency?
  - **Basis in paper:** [explicit] The authors state that extending to video clips is a critical future direction.
  - **Why unresolved:** The current framework only generates images; video introduces motion continuity challenges not addressed.
  - **What evidence would resolve it:** Build a video-capable model and evaluate with temporal consistency metrics and human studies.

- **Question 2:** How can large-scale, diverse datasets for long-range visual consistency be created beyond e-commerce?
  - **Basis in paper:** [explicit] The authors highlight that developing such datasets for broader domains remains a critical need.
  - **Why unresolved:** Existing datasets are short, lack multi-modal conditioning, or provide insufficient consistency annotations.
  - **What evidence would resolve it:** Release multi-domain datasets with (text,image)→multi-frame annotations and standard evaluation protocols.

- **Question 3:** How robust is Narrative Weaver to imperfect reference images (e.g., sketches, multi-subject) and can its input sensitivity be mitigated?
  - **Basis in paper:** [inferred] The paper notes input sensitivity and that the model requires single-subject frontal references.
  - **Why unresolved:** Real-world inputs may be stylized, low-quality, or contain multiple entities; model robustness is unknown.
  - **What evidence would resolve it:** Systematically test on diverse reference types and design preprocessing or adaptation to improve generalization.

## Limitations
- The EAVSD dataset is not publicly released, hindering independent reproduction and benchmark comparison.
- Key implementation details for the dynamic Memory Bank (decay factor λ, window T) and the learnable query projection layer are underspecified.
- Evidence for the MLLM's specific contribution to narrative planning is indirect, lacking direct ablations against alternative planners.

## Confidence
- **Memory Bank effectiveness:** Medium (supported by fine-grained training ablations, but λ/T undisclosed; break conditions noted).
- **Progressive training efficiency:** Medium (staged approach shows benefit, but reliance on proprietary data and stage hyperparameters limits generality).
- **MLLM-mediated planning:** Medium (system-level results imply success, but no direct ablation vs. alternative planners; attention mask details sparse).
