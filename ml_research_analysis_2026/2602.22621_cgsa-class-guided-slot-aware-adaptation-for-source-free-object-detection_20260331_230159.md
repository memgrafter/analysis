# CGSA: Class-Guided Slot-Aware Adaptation for Source-Free Object Detection

## Quick Facts
- **arXiv ID:** 2602.22621
- **Source URL:** https://arxiv.org/abs/2602.22621
- **Reference count:** 9
- **Primary result:** CGSA surpasses prior SF-DAOD methods by up to 15% mAP@50, achieving state-of-the-art results (e.g., 53.2 on Cityscapes→Foggy-Cityscapes, 67.7 on Sim10K→Cityscapes car).

## Executive Summary
Source-Free Domain Adaptive Object Detection (SF-DAOD) adapts detectors to new domains without access to source data, addressing privacy and storage constraints. CGSA introduces Object-Centric Learning to exploit object-level structural cues absent in prior pseudo-label-focused methods. The approach consists of a Hierarchical Slot Awareness (HSA) module that decomposes images into semantically meaningful slots and a Class-Guided Slot Contrast (CGSC) module that aligns these slots with class prototypes via contrastive learning. This yields domain-invariant representations without requiring source data. Experiments on four standard benchmarks (Cityscapes, Foggy-Cityscapes, BDD100K, Sim10K, KITTI) show CGSA outperforms previous SF-DAOD methods by up to 15% in mAP@50, with highlights of 53.2 mAP on Cityscapes→Foggy-Cityscapes and 67.7 on Sim10K→Cityscapes (car). The method also demonstrates robustness across varying conditions and a modest computational overhead (~27% on RT-DETR), validating the slot-aware object-centric approach for privacy-sensitive transfer.

## Method Summary
CGSA augments an RT-DETR detector with a Hierarchical Slot Awareness (HSA) module. HSA uses slot attention to partition an image into a grid of slots (e.g., 5x5=25) that capture local object parts; a reconstruction loss forces slots to retain sufficient information to reconstruct the image, encouraging coherent decompositions. Training proceeds in two phases: first, source domain pretraining combines standard detection loss with the reconstruction loss (λ_rec=1) for 72 epochs; second, target domain adaptation uses a teacher–student framework. The student processes target images, generates pseudo-labels from the teacher (filtered by a dynamic confidence threshold), and optimizes three losses: unsupervised detection from pseudo-labels, contrastive loss between slot prototypes and class prototypes (CGSC, λ_con=0.05), and reconstruction loss (λ_rec=1). The teacher is an exponential moving average (EMA) of the student (decay=0.9993). CGSC matches weighted slots to class prototypes (via Hungarian algorithm) and trains with InfoNCE. At inference, HSA remains active but CGSC is disabled.

## Key Results
- CGSA outperforms prior SF-DAOD methods by up to 15% mAP@50 across four benchmarks.
- Achieves 53.2 mAP on Cityscapes→Foggy-Cityscapes and 67.7 mAP on Sim10K→Cityscapes (car).
- Demonstrates consistent gains with a manageable overhead (~27% extra training time on RT-DETR).

## Why This Works (Mechanism)
CGSA’s strength lies in its shift from image-level pseudo-labels to object-centric slot representations. Slots capture part-whole structure, providing a richer prior that helps align ambiguous target features to source semantics. HSA’s reconstruction objective yields semantically coherent slots, while CGSC’s contrastive alignment ties these slots to class prototypes learned from the source, producing domain-invariant features. The teacher–student scheme with a dynamic confidence threshold yields high-quality pseudo-labels. Together, these components stabilize adaptation without any source data, explaining the significant performance leap.

## Foundational Learning
- **Object-Centric Learning:** Decomposes scenes into object-level components; needed to capture part-whole structure and provide robustness to domain shifts. Quick check: Do slot masks correspond to meaningful object parts in visualizations?
- **Slot Attention:** Iterative attention mechanism grouping features into fixed slots; core of HSA. Needed for unsupervised discovery of object-like entities. Quick check: Are slots diverse and non-overlapping after reconstruction training?
- **Contrastive Learning:** Aligns representations by minimizing distance between positives and maximizing negatives; used in CGSC. Needed to enforce domain-invariant alignment between slots and class prototypes. Quick check: Is the cosine similarity between a slot and its matched class prototype higher than with other classes?
- **Pseudo-Labeling:** Uses model predictions as supervision; supplies detection targets on unlabeled target data. Needed for unsupervised adaptation. Quick check: Does filtering by a confidence threshold improve pseudo-label quality (e.g., higher precision)?
- **Teacher-Student Framework:** Student is trained under supervision of an EMA teacher; stabilizes training. Needed to reduce noise from noisy pseudo-labels. Quick check: Does EMA smoothing lead to more consistent loss curves?
- **Hierarchical Design:** HSA uses two levels (coarse/fine) to capture multi-scale structure; balances granularity and global context. Needed for robust slot decomposition. Quick check: Do coarse slots correspond to object groups and fine slots to object parts?

## Architecture Onboarding
**Component map:**  
Input Image -> RT-DETR Backbone -> Object Queries; Input Image -> HSA -> Coarse slots -> Fine slots (25 total); Slots + Queries -> Fusion Module -> Detection Head; Class Prototypes (EMA) <-> CGSC Contrastive Loss; Student -> Teacher (EMA) -> Pseudo-labels.

**Critical path:** During target adaptation, the student network receives an image, jointly extracts object queries and slot representations. Slots are used for reconstruction and for contrastive alignment with class prototypes. The fused slots and queries produce detection outputs supervised by pseudo-labels from the teacher. The teacher is updated as an EMA of the student's weights. At inference, HSA remains active to provide slots; CGSC is turned off.

**Design tradeoffs:**  
- Slot count (n) vs. compute/memory: more slots (e.g., 5x5=25) capture finer details but increase overhead.  
- λ_con and λ_rec balance: high λ_rec preserves reconstruction quality; high λ_con drives alignment.  
- Dynamic threshold schedule (τ_min, τ_max): controls pseudo-label precision; improper range leads to underfitting or noise.  
- HSA pretraining on COCO vs. source: pretraining on a large generic dataset yields generic slots; skipping may degrade slot quality.  
- Teacher EMA decay: higher decay stabilizes teacher but slows adaptation.

**Failure signatures:**  
- Slot collapse: slot masks become uniform or noisy; check via visualization.  
- No gain from CGSC: contrastive loss does not improve; monitor margin between matched and unmatched pairs.  
- Divergence or OOM: reduce batch size, check gradient clipping (0.1), ensure slot count fits GPU memory.  
- Results far below paper numbers: verify source checkpoint quality, threshold schedule, RT-DETR backbone variant, number of queries.  
- Excessive overhead: profile HSA; consider reducing slot count or using mixed precision.
