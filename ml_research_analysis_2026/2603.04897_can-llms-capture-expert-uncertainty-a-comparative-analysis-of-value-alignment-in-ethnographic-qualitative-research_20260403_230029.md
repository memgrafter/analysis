# Can LLMs Capture Expert Uncertainty? A Comparative Analysis of Value Alignment in Ethnographic Qualitative Research
## Quick Facts
- **arXiv ID**: 2603.04897
- **Source URL**: https://arxiv.org/abs/2603.04897
- **Reference count**: 38
- **Primary result**: LLMs approach human performance on set-based metrics (F1 up to 56.6, Jaccard up to 43.96) but are weaker at ranking (RBO up to 37.1 vs. expert 51.97); Qwen aligns best with expert value distributions and uncertainty patterns; model ensembles improve results by 8–10 points; all models over-assign the Security value.

## Executive Summary
This study investigates whether large language models (LLMs) can replicate expert uncertainty in ethnographic qualitative analysis, specifically in identifying core human values from long interview transcripts. Using 12 translated Chinese interviews and the Schwartz value framework, the authors compare LLM outputs to annotations from six experts, measuring both set overlap and ranking agreement.

The results show that LLMs achieve near-human scores on set-based metrics (F1, Jaccard) but underperform on ranking accuracy (RBO). Qwen models exhibit the strongest alignment with expert value distributions and uncertainty patterns. Ensembles (Majority Vote, Borda Count) boost performance by 8-10 points. Notably, all LLMs systematically over-assign the Security value, indicating a model-induced bias absent from expert judgments.

## Method Summary
The evaluation uses four open-source LLMs (DeepSeek-R1-Distill-Llama-8B, Qwen3-30B-A3B-Instruct, Llama-3.3-70B-Instruct, Mistral-Small-3.2-24B-Instruct) quantized with llama.cpp and run on four Tesla V100 GPUs. For each model, the authors test eight configurations varying by prompting strategy (Baseline, Bias-Constraint, Profile-Enhanced, Bottom-Up) and input granularity (whole transcript vs. ~5k token segments). The task is to output the top-3 Schwartz basic values (from 10) per interview. Performance is measured against a ground truth derived from majority vote of six expert annotators using F1@3, Jaccard@3, and Rank-Biased Overlap (RBO)@3. Additional analyses compare model value distributions to expert distributions via cosine similarity and Spearman's ρ, and assess intra-model variability across prompts as a proxy for uncertainty. Ensembles are created by combining outputs from three-model sets using Majority Vote, Borda Count, and Kemeny-Young.

## Key Results
- LLMs approached the human ceiling on set-based metrics (F1 up to 56.6, Jaccard up to 43.96) but lagged on ranking accuracy (RBO up to 37.1 vs. expert 51.97).
- Qwen demonstrated the best alignment with expert value distributions (cosine similarity 0.833) and uncertainty patterns (Spearman's ρ 0.457), with lower intra-model variability.
- Model ensembles improved F1 and RBO scores by 8–10 points; all four Llama-family models exhibited a systematic over-assignment of the Security value relative to expert frequencies.

## Why This Works (Mechanism)
### Mechanism 1: Set-Based Identification vs. Ranking
The claim is that LLMs can identify a plausible set of top values (presence) but fail to recover the exact ranking (order) as experts. The mechanism is that set-based metrics (F1, Jaccard) reward unordered overlap, which may be achievable by detecting strong value cues, while ranking accuracy (RBO) requires fine-grained discrimination of relative strength, a more nuanced interpretive task where models struggle. The core assumption is that the task's inherent ambiguity makes distinguishing precise value priority harder than identifying relevant values. Evidence includes the abstract’s statement that LLMs approach the human ceiling on set-based metrics but struggle on RBO, and Table 2 showing RBO scores (up to 37.09) substantially below the human ceiling (51.97). A break condition would be if RBO scores approach human ceiling without ensemble methods, suggesting ranking is not inherently harder.

### Mechanism 2: Model Architecture Influences Value-Distribution Alignment
The claim is that model architecture and training affect alignment with expert value distributions and uncertainty patterns. The mechanism is that differences in training data, scale, and instruction-tuning influence how models internalize and express value frameworks like Schwartz’s. Qwen’s superior performance suggests it better captures value co-occurrence and contextual nuance. The core assumption is that value assignment is not purely lexical but requires sociocultural reasoning, and model capabilities vary accordingly. Evidence: Table 5 shows Qwen achieves the highest cosine similarity (0.833) and Spearman’s ρ (0.457) with expert distributions/uncertainty, and Qwen exhibits lower intra-model variability (std ~25.65) compared to DeepSeek (~25.02 but lower mean), indicating more consistent assignments. The break condition: if a different model (e.g., Llama) surpasses Qwen on these metrics with optimized prompting, tuning matters more than base model.

### Mechanism 3: Systematic Security Over-Assignment Indicates Model Bias
The claim is that all models over-assign the Security value, revealing a bias detached from expert disagreement patterns. The mechanism is that LLMs may over-represent certain values due to training data frequency, prompt sensitivity, or an “alignment tax” where safety-focused tuning inflates security-related concepts. The core assumption is the bias arises from model internals or common prompt designs, not the interview content. Evidence: The abstract notes systematic over-assignment of Security, and Figure 1 shows all models’ Security frequency exceeds experts across models. The break condition: if Security over-assignment disappears with debiasing prompts or different model families, confirming it is not task-inherent.

## Foundational Learning
- **Krippendorff’s alpha**: Quantifies inter-expert agreement; here α=0.389 indicates substantial disagreement, establishing the task’s intrinsic ambiguity. *Quick check*: What does an alpha of 0.389 indicate about the value annotation task’s reliability?
- **Schwartz Theory of Basic Values**: Provides the 10 motivational types and 58 subvalues used as annotation targets. *Quick check*: How do the 10 basic motivational types relate to the 58 nuanced values in this study?
- **Rank-Biased Overlap (RBO)**: Measures ranking similarity with top-weighting, essential because the task requires ordering the top‑3 values. *Quick check*: Why might RBO be lower than F1/Jaccard for LLMs even when set overlap is high?

## Architecture Onboarding
**Component map**: Data loader -> Prompt generator -> LLM inference engine -> Response parser -> Ensemble aggregator -> Evaluation module

**Critical path**:
1. Preprocess interviews (ensure token limits, handle segmentation).
2. Implement prompt templates and aggregation logic.
3. Run single-model baselines across all prompt strategies.
4. Compute ensemble outputs from model combinations.
5. Evaluate against expert majority-vote ground truth and expert disagreement distributions.

**Design tradeoffs**:
- Whole vs. split transcripts: Whole preserves context but risks truncation; splits avoid truncation but may fragment value cues.
- Model selection: Larger models (Llama‑70B) may perform better but require more GPU memory; smaller (DeepSeek‑8B) are faster but less accurate.
- Prompt complexity: Profile‑Enhanced (PEP) adds contextual summary but increases prompt engineering effort; Bias‑Constraint (BC) may reduce bias but could over‑constrain.

**Failure signatures**:
- High variance across prompt configurations (std dev > mean) indicates prompt sensitivity.
- Low RBO despite decent F1/Jaccard (e.g., DeepSeek) suggests ranking inability.
- Systematic value skew (e.g., Security over-assignment) indicates bias not mitigated by prompting.

**First 3 experiments**:
1. Baseline replication: Run PEP with whole transcript for Qwen, Llama, Mistral, DeepSeek; compute F1/Jaccard/RBO to confirm paper’s main pattern.
2. Prompt‑strategy sweep: For one model (e.g., Qwen), test all 4 prompt types in whole and split settings; measure performance delta to identify best strategy.
3. Ensemble test: Using top‑3 models from Exp 2, compute Majority Vote and Borda Count ensembles; verify 8‑10 point gain on F1/RBO as in Table 3.

## Open Questions the Paper Calls Out
- **Open Question 1**: Can LLMs' prompt-induced variability in value assignments mirror the inter‑expert disagreement patterns observed in ethnographic analysis?  
  *Basis*: The authors examine whether intra‑model variability across alternative prompt formulations mirrors inter‑expert variability.  
  *Why unresolved*: Only moderate Spearman’s ρ (max 0.457 for Qwen) was found; it remains unclear whether misalignment stems from model limitations or differences in how ambiguity is interpreted.  
  *Resolving evidence*: A larger‑scale study with more interviews and experts, analyzing per‑value variability across models versus humans to identify which Schwartz values consistently show aligned or divergent uncertainty patterns.

- **Open Question 2**: What causes the systematic over‑assignment of the Security value by all LLMs, and does this reflect a training data bias or a fundamental misinterpretation of Schwartz’s framework?  
  *Basis*: The paper notes all models assign Security far more frequently than experts.  
  *Why unresolved*: The root cause—whether corpus frequencies, value connotations, or prompt sensitivity—is not investigated.  
  *Resolving evidence*: Controlled experiments that (a) analyze Security mentions in training corpora, (b) use value‑neutral prompts and context variations, and (c) compare model outputs with human‑annotated evidence for Security inferences.

- **Open Question 3**: How does the limited sample size (12 interviews) affect the generalizability of LLM performance and uncertainty alignment findings in ethnographic value analysis?  
  *Basis*: The conclusion states that a larger set of interview samples would be beneficial for producing more generalizable results.  
  *Why unresolved*: With only 12 interviews from a single cultural context, observed patterns (e.g., Security over‑assignment, Qwen’s superior alignment) could be idiosyncratic.  
  *Resolving evidence*: Replication using a larger, culturally diverse dataset of interviews, testing stability of performance metrics, distribution alignments, and uncertainty correlations across different populations.

- **Open Question 4**: Does preprocessing interview transcripts into structured Q&A pairs using LLMs improve value identification accuracy and uncertainty calibration compared to raw transcripts?  
  *Basis*: The conclusion mentions ongoing work to evaluate an additional preprocessing step that utilizes LLMs to clean transcripts and restructure them into numbered question–answer pairs.  
  *Why unresolved*: The study only tested raw or segmented inputs; potential benefits of structured preprocessing remain unexplored.  
  *Resolving evidence*: An A/B test on the same dataset comparing value identification metrics (F1, RBO) and uncertainty alignment between raw, segmented, and preprocessed (Q&A‑structured) inputs across models.

## Limitations
- The interview transcripts and expert annotations are not publicly available, preventing independent replication.
- The sample size is small (12 interviews) and inter‑expert agreement is low (Krippendorff’s α=0.389), limiting ground‑truth reliability and generalizability.
- Exact experimental details (temperature values, seed‑change policy, segmentation algorithm) are unspecified, introducing reproducibility risks.

## Confidence
- LLMs approximate human set‑based performance but lag in ranking: **Medium**
- Model architecture influences value‑distribution alignment: **Medium**
- Systematic Security over‑assignment reveals model bias (observation): **Medium**; causal attribution: **Low**

## Next Checks
1. **Full data and prompt release**: Obtain the dataset and exact prompt strings from the authors; perform deterministic replications with multiple random seeds to verify reported metrics and quantify configuration variance.
2. **Prompt ablation study**: Systematically modify or remove the objectivity clause (“Be objective”) and the background summary across at least three model families (e.g., Qwen, Llama, Mistral) to isolate the driver of Security over‑assignment and its effect on ranking accuracy.
3. **Cross‑linguistic scale‑up**: Apply the same protocol to ≥50 transcripts in multiple languages (e.g., English, Spanish) and compare LLM uncertainty to the full expert distribution (not just majority vote) to test generalizability of the set/ranking gap and Security bias.
