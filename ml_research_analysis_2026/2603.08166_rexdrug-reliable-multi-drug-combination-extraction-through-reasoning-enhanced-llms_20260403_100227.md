# RexDrug: Reliable Multi-Drug Combination Extraction through Reasoning-Enhanced LLMs

## Quick Facts
- arXiv ID: 2603.08166  
- Source URL: https://arxiv.org/abs/2603.08166  
- Reference count: 21  
- Primary result: RexDrug (Qwen2.5‑7B‑Instruct) achieves SOTA on DrugComb (positive exact F1 = 74.2%, any exact = 81.3%) and on DDI13 (82.7% F1 for relation extraction, 87.6% F1 for classification), a 3.7% gain over the best prior.

## Executive Summary
RexDrug tackles automated extraction of variable‑length n‑ary drug combinations from biomedical literature. The two‑stage framework first distills expert‑like reasoning traces from GPT‑4o/5.1 via a multi‑agent process, then performs supervised fine‑tuning (SFT) with LoRA. Reinforcement learning with Group Relative Policy Optimization (GRPO) and a multi‑dimensional reward (format compliance, coverage, extraction metric) further refines both extraction accuracy and reasoning coherence. On DrugComb and DDI13, RexDrug achieves state‑of‑the‑art F1 scores (e.g., positive exact 74.2% on DrugComb; 82.7% on DDI13) and significantly outperforms baselines. Human and ROSCOE evaluations confirm high reasoning quality, making RexDrug a reliable solution for complex biomedical relation extraction.

## Method Summary
RexDrug employs two training stages. Stage 1: SFT warms up a base LLM (LLaMA3.1‑8B‑Instruct or Qwen2.5‑7B‑Instruct) using high‑quality reasoning traces generated by a multi‑agent Analyst (GPT‑4o) and Reviewer (GPT‑5.1). The traces follow a fixed four‑section template, and the model is fine‑tuned with LoRA. Stage 2: Reinforcement learning applies GRPO to the SFT model, using both the policy and a frozen reference. For each input, *K* responses are sampled and rewarded based on format compliance (`r_format`), combination coverage (`r_comb_cover`), and extraction quality (`r_comb_metric`, weighted 2/3 exact, 1/3 partial). Relative advantages guide policy updates while a KL penalty prevents excessive drift. The final model outputs reasoning inside `<think>` and a JSON answer.

## Key Results
- DrugComb test set: positive exact F1 = 74.2%, positive partial = 76.9%; any exact = 81.3%, any partial = 84.1%. Outperforms Seq2Rel and GPT‑4o by large margins.
- DDI13: 82.7% F1 for relation extraction and 87.6% F1 for relation classification, improving the best prior by 3.7%.
- Reasoning quality: Higher Context Faithfulness and Medical Semantic Consistency than GPT‑4o in human evaluation; ROSCOE scores show better coherence and factual consistency.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim**: Multi‑agent reasoning distillation yields high‑quality traces for SFT.
- **Mechanism**: Analyst (GPT‑4o) produces step‑by‑step reasoning conditioned on gold labels; Reviewer (GPT‑5.1) scores across six criteria; only traces with all ≥4 are kept; rejected traces get feedback for up to three revisions.
- **Core assumption**: The stronger Reviewer can reliably guide the Analyst to emulate expert reasoning, compensating for lack of human‑annotated traces.
- **Evidence**: [abstract] describes multi‑agent collaboration; [section 4.1] reports 80.61% acceptance (1098/1362); [corpus] notes neighboring work differs.
- **Break condition**: If Reviewer is not stronger or scoring inconsistent, trace quality may drop; the 19.39% discard could harm low‑resource scenarios.

### Mechanism 2
- **Claim**: Multi‑dimensional reward effectively guides RL.
- **Mechanism**: Sample *K* responses, compute `r_format` (tag/section + JSON), `r_comb_cover` (mean max overlap minus false empty penalty), `r_comb_metric` (weighted F1); combine with α‑weights; relative advantage within group; update via clipped surrogate + KL penalty.
- **Core assumption**: Decomposition stabilizes learning and preserves constraints.
- **Evidence**: [abstract] mentions multi‑dimensional reward; [section 4.2] gives equations; [section 5.4] ablation confirms each component’s impact.
- **Break condition**: Poor weight calibration can cause suboptimal trade‑offs; fixed weights may not generalize.

### Mechanism 3
- **Claim**: Structured four‑section reasoning aligns model with expert clinical analysis.
- **Mechanism**: Instruction forces `<think>` to contain four numbered sections: clinical scenario, candidate drugs/focus, reasoning/effect, extraction‑oriented summary. This primes a consistent pattern.
- **Core assumption**: Fixed scaffold decomposes the complex n‑ary extraction.
- **Evidence**: [abstract], [section 4.1], [Table 1]; human evaluation ([section 6.2]) attributes improved Context Faithfulness partly to this scaffolding.
- **Break condition**: Forcing this on atypical contexts may produce superficial reasoning and hurt accuracy.

## Architecture Onboarding
- **Component map**: Input (sentence+context) → Multi‑agent trace generator (Analyst+Reviewer) → SFT (LoRA fine‑tune) → RL (GRPO with reward modules) → Output (`<answer>` JSON).
- **Critical path**:  
  1. Preprocess DrugComb dataset into (sentence, context, gold tuples).  
  2. Generate reasoning traces via multi‑agent loop; filter low‑quality ones.  
  3. Perform SFT on base model with traces → warm‑up model.  
  4. Prepare RL data (same inputs, gold combos).  
  5. Run GRPO: per input sample *K* responses, compute `r_format`, `r_comb_cover`, `r_comb_metric`, compute relative advantages, update policy (clipped surrogate + KL penalty).  
  6. Evaluate on test set (Exact/Partial F1) and reasoning quality (ROSCOE, human).
- **Design tradeoffs**:
  - Multi‑agent cost vs trace quality: API usage vs higher reliability.
  - LoRA vs full fine‑tuning: LoRA reduces memory but may limit reasoning capacity.
  - Reward weighting: Fixed α‑weights (0.2, 0.1, 0.7) may need dataset‑specific tuning; over‑weighting metric can harm reasoning.
- **Failure signatures**:
  - Format collapse (missing tags) → check parsing success rate.
  - Reward hacking (empty predictions) → monitor output distribution.
  - Reasoning degradation (declining ROSCOE) → check KL penalty strength.
  - No RL improvement beyond SFT → adjust group size or learning rate.
- **First 3 experiments**:
  1. Reproduce SFT baseline: train Qwen2.5‑7B‑Instruct on 1098 traces; verify format and extraction on 100 held‑out samples.
  2. Ablate rewards: train models without each component separately; compare validation F1.
  3. Pilot human evaluation: blind‑rate 20 samples for Context Faithfulness and Reasoning‑Answer Alignment; compute agreement.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question**: Why does incorporating reasoning traces during SFT degrade extraction performance compared to training without reasoning, and how can this trade‑off be avoided?  
- **Basis**: [inferred] Table 2 shows lower F1 with reasoning (e.g., Qwen Pos‑E: 69.3 vs 72.1).  
- **Why unresolved**: Suggests a conflict between learning to reason and learning to extract; understanding is key for reasoning‑augmented pipelines.  
- **Evidence needed**: Ablation on reasoning complexity; training loss/gradient analysis; curriculum experiments.

### Open Question 2
- **Question**: Which components of the multi‑agent trace generation are essential, and can single‑model self‑refinement achieve similar quality?  
- **Basis**: [inferred] Section 6.1/Fig 2(a) show multi‑agent traces outperform single‑model, but the contribution of specific reviewer criteria or revision rounds is not broken down.  
- **Why unresolved**: Multi‑agent setup is costly and reliant on proprietary LLMs; identifying key factors could enable cheaper alternatives.  
- **Evidence needed**: Ablate each reviewer criterion; vary revision rounds; compare against self‑critique methods (e.g., self‑rewarding) on reasoning and extraction metrics.

### Open Question 3
- **Question**: How to optimize the multi‑dimensional reward weights automatically rather than using fixed heuristics?  
- **Basis**: [inferred] Section 4.2 uses manual weights (α₁=0.2, α₂=0.1, α₃=0.7) without sensitivity analysis.  
- **Why unresolved**: Heuristics may not generalize across datasets or scales; automated tuning could improve robustness and peak performance.  
- **Evidence needed**: Grid/Bayesian search for optimal weights; meta‑learning of weights; comparisons with dynamic weighting strategies.

### Open Question 4
- **Question**: To what extent does RexDrug generalize to other n‑ary biomedical RE tasks (e.g., gene‑disease‑treatment, protein‑complex)?  
- **Basis**: [inferred] Evaluation only on DrugComb (n‑ary) and DDI13 (binary); conclusion mentions broader applications but lacks empirical evidence.  
- **Why unresolved**: Without diverse n‑ary datasets, it is unclear if the architecture is broadly applicable.  
- **Evidence needed**: Apply RexDrug to other n‑ary RE datasets (e.g., Bacteria‑Biotope, chemical‑protein); report performance, error analysis, and necessary adaptations; assess reasoning across domains.

## Limitations
- Incomplete definitions for `r_format` sub‑scores (`st(oi)`, `sa(oi)`) and the Partial F1 metric.
- Missing GRPO hyperparameters, notably the KL penalty coefficient β.
- Ambiguity in how the surrounding context *C* is constructed (e.g., number of sentences).
