# StyleBench: Evaluating Speech Language Models on Conversational Speaking Style Control

## Quick Facts
- arXiv ID: 2603.07599
- Source URL: https://arxiv.org/abs/2603.07599
- Reference count: 0
- Primary result: Kimi-Audio and GLM-4-Voice achieve superior style control, with Kimi-Audio reaching 68.75% VSP on angry emotion and 29.94% SVD on speed.

## Executive Summary
This paper presents StyleBench, a benchmark for evaluating speech language models (SLMs) on speaking style intensity control in multi-turn dialogues. It constructs 14,400 three-turn dialogues across emotion, speed, volume, and pitch dimensions, using fixed text with varying style prompts. Evaluation relies on human-judged Valid Sample Percentage (VSP) for emotion and acoustic-based Style Variation Degree (SVD) for other dimensions. Findings reveal that Kimi-Audio and GLM-4-Voice lead in performance, while models like LLaMA-omni2 significantly lag, with gaps attributed to training data diversity and speech tokenizer design. The work highlights key factors for advancing stylistic speech generation in conversational AI.

## Method Summary
The methodology creates a synthetic benchmark by first generating neutral speech for fixed textual dialogues using CosyVoice2, then augmenting styles via references (e.g., RAVDESS for emotion) or prosodic tools (e.g., FFmpeg for speed/volume/pitch). Models are filtered based on multi-turn semantic coherence (MRD > 40%) using Qwen3-4B to ensure conversational stability before style evaluation. For emotion, human assessors judge whether generated samples match the intended style (VSP); for acoustic dimensions, SVD computes percentage changes in extracted features (speed via Whisper, volume via RMS, pitch via F0). This pipeline isolates style control from semantic drift and quantifies intensity variation.

## Key Results
- Kimi-Audio and GLM-4-Voice outperform other models, with Kimi-Audio achieving 68.75% VSP on angry emotion and 29.94% SVD on speed.
- Models like LLaMA-omni2 show low VSP/SVD, indicating poor prompt responsiveness.
- Performance gaps correlate with training data diversity (e.g., Kimi-Audio's style-enriched data) and tokenizer design (e.g., GLM-4-Voice's custom tokenizer preserving paralinguistic cues).

## Why This Works (Mechanism)
1. **Multi-turn semantic coherence (MRD) as a prerequisite**: Style control requires stable dialogue context; MRD > 40% filters models that lose track, preventing confounds from conversational drift. Evidence includes the benchmark's filtering logic and links to "Style Amnesia" research on turn-based degradation.
2. **Speech tokenizer design critical for style preservation**: Tokenizers must encode paralinguistic cues in discrete tokens; those retaining richer acoustic details (e.g., in GLM-4-Voice) enable finer intensity modulation, as shown by token differences across style variants.
3. **Diverse, style-aware training data as a causal factor**: Exposure to paired linguistic instructions and acoustic variations during pre-training allows models to learn prompt-to-acoustic mappings. Underperformance in omni-models trained on neutral tasks (e.g., ASR) versus Kimi-Audio's style-focused data supports this.

## Foundational Learning
- **Multi-turn dialogue coherence (MRD)**: Ensures style adjustments are applied within a stable context; without it, style metrics may reflect incoherence rather than control. Quick check: If a model's semantic relevance drops from Turn 1 to Turn 3, can its style scores be trusted? No, because drift could mimic or mask style effects.
- **Paralinguistic information in speech tokens**: Token representations must capture non-semantic features like pitch and energy; if collapsed, models cannot actuate prompt-based changes. Quick check: Token sequences for the same sentence spoken angrily vs. calmly should differ in acoustic encodings, implying need for high-fidelity tokenizers.
- **Intensity quantification metrics (SVD, VSP)**: Metrics must measure gradual changes, not just categorical presence; SVD uses percentage shifts in acoustic features, while VSP employs human judgment for emotion saturation. Quick check: Why is a classifier confidence score insufficient? It may not reflect subtle intensity gradations and can saturate, missing incremental variations.

## Architecture Onboarding
The system architecture flows as: Dataset Synthesis Pipeline (textual QA pairs → neutral speech via CosyVoice2 → style augmentation → dialogue assembly) → Evaluation Engine (model inference → semantic scoring with Qwen3-4B → style validity check → SVD/VSP calculation) → Analysis Module (performance aggregation → factor analysis on data/tokenizer). Critical path: text prompt → model speech generation → acoustic feature extraction (e.g., Whisper for speed) → SVD computation → human validation for emotion. Design tradeoffs include synthetic vs. natural data (control vs. validity), automated vs. human metrics (scalability vs. accuracy), and fixed text (isolation vs. ecological validity). Failure signatures: low VSP with high MRD (ignores prompts), high VSP but low SVD (coarse control), declining performance over turns (sustainability issues). First 3 experiments: 1. Replicate MRD filtering on a held-out subset; 2. Compare token distributions across models for style variants; 3. Vary prompt phrasing and measure VSP/SVD changes.

## Limitations
- Synthetic data from CosyVoice2 may not mirror natural human style variability, reducing ecological validity.
- Human evaluation for emotion introduces subjectivity and scalability bottlenecks.
- Fixed three-turn dialogues may not generalize to longer, open-ended conversations.
- The MRD threshold of 40% is empirically chosen without strong theoretical grounding.

## Confidence
- Multi-turn coherence prerequisite (MRD filter): Medium
- Speech tokenizer design importance: High
- Training data diversity as causal factor: Medium

## Next Checks
1. Evaluate alternative MRD thresholds (e.g., 30%, 50%) on StyleBench and external corpora to test robustness.
2. Perform a tokenizer ablation: train identical architectures with different tokenizers on the same style-augmented data to isolate impact on SVD/VSP.
3. Fine-tune a low-performing model (e.g., LLaMA-omni2) on a small, stylistically diverse instruction set and reassess performance to validate the training data hypothesis.
