# LinguDistill: Recovering Linguistic Ability in Vision-Language Models via Selective Cross-Modal Distillation

## Quick Facts
- arXiv ID: 2604.00829
- Source URL: https://arxiv.org/abs/2604.00829
- Reference count: 33
- Primary result: Recovers ~10% of linguistic performance loss (e.g., HellaSwag regression from -19.5% to -2.7%) while preserving vision-heavy task performance (DocVQA degradation only -3.8%) via adapter-free cross-modal distillation.

## Executive Summary
Multimodal fine-tuning of pretrained language models into vision-language models (VLMs) often degrades their native linguistic capabilities, and this loss cannot be reversed by standard fine-tuning. LinguDistill introduces an adapter-free knowledge distillation approach that restores linguistic ability without increasing inference cost. The method uses a frozen text-only language model as a teacher and a multimodal VLM as a student. Key innovations include layer-wise key-value (KV) cache sharing, allowing the teacher to attend to the student's multimodal representations without architectural changes, and a selective distillation objective that applies the teacher's signal only on language-intensive data. Experiments show that LinguDistill recovers approximately 10% of the performance drop on language and knowledge benchmarks—for instance, reducing HellaSwag regression from -19.5% to -2.7%—while maintaining vision-heavy task performance (DocVQA degradation only -3.8% vs -16.8% with uniform distillation). The teacher model is discarded after training, so the final VLM has zero additional inference overhead.

## Method Summary
LinguDistill trains a VLM student on a curated subset of the Cauldron dataset (17 sources, ~600k examples). The student consists of a frozen vision encoder, a trainable multimodal projector, and a trainable decoder. The teacher is a frozen copy of the original language model used to initialize the student. During each training step, the student processes the full multimodal sequence (image tokens + text tokens) and produces KV caches at each decoder layer. The teacher then processes only the text tokens but reuses the student's KV caches at each layer, enabling it to generate outputs conditioned on visual context via attention. The loss combines a KL divergence distillation term (soft targets from the teacher) and a standard cross-entropy term (hard labels), weighted by a source-specific coefficient α. For language-heavy data sources (8 sources), α > 0 applies both losses; for OCR/document sources (9 sources), α = 0 applies only the hard loss. Only the student's projector and decoder are updated; the vision encoder and teacher remain frozen. After training, the teacher is removed, yielding a VLM with restored linguistic capability and no extra parameters.

## Key Results
- HellaSwag regression reduced from -19.5% (standard fine-tuning) to -2.7% with LinguDistill.
- DocVQA degradation limited to -3.8% (vs -16.8% under uniform knowledge distillation).
- No additional parameters required at inference time; the method is adapter-free.

## Why This Works (Mechanism)
LinguDistill’s effectiveness stems from three synergistic mechanisms.

**Mechanism 1: KV-Cache Sharing Enables Vision-Aware Teacher Supervision**  
The student VLM decoder processes the multimodal sequence and caches its key-value states. The frozen teacher decoder reprocesses the text tokens but directly reuses the student's KV caches at each layer. By using its own queries against the student's multimodal KV memory, the teacher generates outputs that are effectively conditioned on visual context without any architectural modification. This requires identical decoder architectures (hidden size, layer count) so that KV shapes match; otherwise sharing fails. The shared KV representations must be meaningful to the teacher—if the student's multimodal features are misaligned, the teacher's outputs become noisy.

**Mechanism 2: Selective Distillation Balances Language Recovery and Visual Grounding**  
A data-dependent weight α(db) modulates the distillation loss component. On language-intensive examples (α>0), both soft (distillation) and hard (next-token) losses are applied; on vision-heavy OCR/document examples (α=0), only the hard loss is used. This prevents the text-only teacher from overwhelming the student's pixel-level visual grounding with linguistic priors that would degrade performance on vision-dependent tasks. The categorization of training sources into two groups is crucial; misclassification can invert the trade-off.

**Mechanism 3: Adapter-Free Transfer Preserves Inference Efficiency**  
The teacher participates only during training; after training it is completely discarded. The student VLM alone executes inference with its original architecture unchanged. This works because the desired linguistic capability is fully transferred through optimization pressure during training, without needing persistent alignment modules.

## Foundational Learning
- **Knowledge Distillation**  
  - *Why needed*: Distillation transfers the teacher's "dark knowledge" (soft probability distributions) to the student, which encodes richer linguistic priors than hard labels alone.  
  - *Quick check*: Why does matching soft target distributions (vs. only hard labels) improve transfer of nuanced capabilities like linguistic commonsense?

- **Transformer KV Cache**  
  - *Why needed*: KV-cache sharing reuses the student's stored key-value tensors across two decoders, enabling the teacher to attend over multimodal context without recomputing visual features.  
  - *Quick check*: In autoregressive decoding, what role do KV caches play, and why are they suitable for sharing between models?

- **Catastrophic Forgetting in Multimodal Adaptation**  
  - *Why needed*: Standard fine-tuning on multimodal data erodes the language model's native linguistic skills; this paper assumes that such forgetting is severe and not self-correcting.  
  - *Quick check*: How does catastrophic forgetting during multimodal fine-tuning differ from typical task-specific forgetting, and why might it be harder to reverse?

## Architecture Onboarding
**Component map**  
Vision Encoder (frozen) → Projector (trainable) → Student Decoder (trainable) → Output Head (trainable)  
Teacher Decoder (frozen) shares KV cache with Student Decoder at every layer; Teacher Output Head frozen

**Critical path**  
1. Image → vision encoder → visual tokens v.  
2. v + text tokens → projector → multimodal sequence X.  
3. Student decoder processes X → KV caches K_l, V_l per layer l.  
4. Teacher decoder processes X's text tokens only; reuses K_l, V_l from student; computes queries Q_l; attends → representations h_l^teacher.  
5. Heads produce logits z_student, z_teacher.  
6. Loss = α(db)·T²·KL(softmax(z_teacher/T) || softmax(z_student/T)) + (1-α(db))·CE(z_student, labels).  
7. Backpropagate through student parameters only (projector + decoder); update; teacher remains frozen.

**Design tradeoffs**  
- KV sharing simplicity vs. architectural constraints: Requires exact decoder architecture match; alternative projection layers would add parameters.  
- Selective routing vs. dataset curation: Requires manual source categorization; mis-categorization leads to suboptimal recovery or vision degradation.  
- Training memory cost: Dual forward passes and KV retention double memory; may limit batch size or sequence length.

**Failure signatures**  
- Language benchmarks show no improvement → KD signal too weak or misrouted.  
- OCR/document benchmarks drop >10% → α not zero for vision-heavy sources or KV misalignment.  
- CE loss high while KD loss drops → teacher supervision contradicts student gradients (architectural mismatch or α error).

**First 3 experiments**  
1. Confirm baseline: fine-tune VLM on all 17 Cauldron sources without KD; expect >15% HellaSwag regression, stable DocVQA.  
2. Uniform KD: apply distillation (α constant >0) to all sources; expect partial language recovery but severe OCR degradation (e.g., OCRBench drop >15%).  
3. Selective KD: set α>0 for 8 language-heavy sources, α=0 for 9 OCR/doc sources; expect HellaSwag regression ~-3% and DocVQA degradation <5%.

## Open Questions the Paper Calls Out
1. **Scaling to multi-image and long-context inputs**  
   The method is evaluated only on single-image, 1024-token data; MMMU regression (-11.6%) is attributed to these constraints. It is unknown whether LinguDistill can be extended to multi-image examples or longer sequences to recover performance on such benchmarks.  
   *Evidence needed*: Train LinguDistill with multi-image or longer-context datasets and evaluate on MMMU.

2. **Why does linguistic recovery plateau at ~10%?**  
   The paper reports only partial recovery of the lost performance, but provides no analysis of the limiting factors.  
   *Evidence needed*: Ablations varying distillation weight, temperature, and data mixture, combined with representation similarity metrics (e.g., CKA) to identify where teacher-student alignment fails.

3. **Does KV-sharing itself subtly harm visual grounding?**  
   Selective distillation mitigates vision degradation, but the contribution of KV-sharing to any residual loss is unclear.  
   *Evidence needed*: Isolate the effect of KV-sharing by comparing a variant without sharing (e.g., using a projection) on vision-heavy benchmarks.

4. **Can selective routing be made data-driven?**  
   Current method requires manual pre-categorization of datasets into language-heavy vs. vision-heavy, which may not generalize.  
   *Evidence needed*: Develop an adaptive α weighting mechanism (e.g., based on image complexity or text length) that does not rely on source labels, and test on mixed datasets.

## Limitations
- KV-cache sharing demands identical teacher/student decoder architecture; any deviation (hidden size, layers) breaks compatibility.
- Selective distillation relies on fixed source-specific α; mis-categorization of task type can invert the reported language-vision trade-off.
- The paper lacks some implementation details (e.g., exact Cauldron filtering, precise α values, temperature schedule), hindering full reproducibility.

## Confidence
- KV-cache sharing enables vision-aware teacher supervision: **Medium** (plausible but not implementation-verified).
- Selective KD recovers linguistic performance while preserving vision-heavy tasks: **High** (consistent empirical gains across benchmarks).
- Adapter-free training yields zero inference overhead: **High** (trivial to confirm by construction).

## Next Checks
1. Replicate KV-cache sharing: implement dual-decoder forward pass, extract teacher attention weights, verify visual tokens are attended, and confirm gradients from KL loss reach student KV tensors.
2. Audit α(db) assignments: if not provided, derive via ablation (e.g., set α=0 per source group and measure performance shifts) and test robustness by swapping α between language-heavy and OCR groups.
3. Cross-architecture transfer: apply LinguDistill to a VLM with a different LM backbone (e.g., LLaVA vs. SmolLM); observe whether KV-sharing fails and whether the language/vision trade-off persists with/without learned KV projections.
