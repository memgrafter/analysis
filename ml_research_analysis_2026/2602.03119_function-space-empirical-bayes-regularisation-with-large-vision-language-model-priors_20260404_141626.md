# Function-Space Empirical Bayes Regularisation with Large Vision-Language Model Priors
## Quick Facts
- **arXiv ID:** 2602.03119
- **Source URL:** https://arxiv.org/abs/2602.03119
- **Reference count:** 20
- **Primary result:** VLM-FS-EB leverages large vision-language models to generate synthetic context and frozen embeddings, consistently improving in-distribution predictive performance and achieving near-perfect OOD detection AUROC across multiple datasets, especially in limited-data regimes.

## Executive Summary
This paper introduces VLM-FS-EB, a function-space empirical Bayes framework for Bayesian deep learning that addresses the challenge of specifying informative, scalable priors. It uses large vision-language models (VLMs) in two key roles: a generative VLM synthesizes semantically coherent context images to condition the functional prior, and a contrastive VLM provides frozen, rich semantic embeddings as a universal feature extractor. The prior is constructed via a stochastic linear model over these embeddings, with posterior inference performed using MC dropout. Evaluations on MNIST, Fashion-MNIST, CIFAR-10, and PathMNIST show significant gains in predictive accuracy, uncertainty calibration, and out-of-distribution detection, particularly under data scarcity, while reducing training time and memory versus prior function-space methods.

## Method Summary
VLM-FS-EB procedurally constructs a functional prior using a large VLM pipeline. First, a generative VLM (e.g., Qwen-VL) synthesizes diverse context images based on reference images and textual prompts. Second, a frozen contrastive VLM (e.g., CLIP variant) maps all images—real and synthetic—to a high-dimensional semantic embedding space. The prior over network functions is defined by a stochastic linear model operating on these context embeddings, yielding a covariance structure that captures semantic relationships. During training, an auxiliary posterior over parameters is induced by the context set, and the main network (a CNN with MC dropout) optimizes an ELBO that combines the data log-likelihood, a context log-likelihood under the linear prior, and an L2 regularization term. At inference, predictions are averaged over multiple MC dropout forward passes.

## Key Results
- VLM-FS-EB improves in-distribution accuracy and negative log-likelihood over strong baselines (e.g., standard dropout, FSVI) on all tested datasets.
- It achieves near-perfect OOD detection AUROC in many scenarios (e.g., 100.0 on MNIST vs. NotMNIST, 99.66 on PathMNIST with 15% training data).
- Under limited-data regimes (e.g., 25% or 15% of training data), VLM-FS-EB substantially outperforms all comparison methods in both in-distribution and OOD metrics.
- Ablation studies confirm that both the VLM-generated context points and the VLM-based embeddings are indispensable for the observed performance gains.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** VLM-generated context points eliminate reliance on scarce task-specific data by synthesizing semantically coherent inputs.
- **Mechanism:** A generative VLM analyzes reference images and textual requirements to produce prompts that yield images preserving target visual style while covering diverse semantic variations. These populate the context set `xc` used to condition the functional prior.
- **Core assumption:** Large VLMs possess sufficient world knowledge to generate samples aligned with the underlying data distribution without fine-tuning.
- **Evidence anchors:** Abstract mentions generating semantically meaningful context images; Section 4.1 details the 4-step pipeline (input specification → multimodal understanding → prompt construction → image synthesis).
- **Break condition:** Generated samples suffer style drift or semantic incoherence, degrading prior quality and hurting OOD detection.

### Mechanism 2
- **Claim:** Frozen VLM embeddings provide expressive, domain-general features that replace costly task-specific pretraining.
- **Mechanism:** A contrastive VLM maps images to a shared semantic embedding space. These embeddings `hL(xc)` are fed into a stochastic linear model to construct a functional prior covariance `KL = τ₁ hL hLᵀ + τ₂ I`, capturing semantic similarities.
- **Core assumption:** The geometry of VLM embedding spaces encodes meaningful relationships that transfer to downstream tasks.
- **Evidence anchors:** Abstract notes providing frozen, rich semantic embeddings; Section 3.1 explains contrastive VLMs produce fixed-dimensional embeddings with semantic alignment; Section 4.2 replaces task-specific extractor with frozen `hL`.
- **Break condition:** Embeddings fail to capture task-relevant variations (e.g., fine-grained medical distinctions), leading to an overly smooth or misaligned prior.

### Mechanism 3
- **Claim:** Function-space empirical Bayes regularization avoids linearization errors and reduces computational overhead compared to linearized FSVI.
- **Mechanism:** FS-EB defines an auxiliary posterior over parameters using context points and a stochastic linear model over embeddings. This yields a well-defined functional prior without requiring Jacobian linearization. MC dropout approximates the posterior tractably.
- **Core assumption:** The stochastic linear model over frozen VLM embeddings adequately approximates the true function-space prior.
- **Evidence anchors:** Abstract describes the prior construction and MC dropout; Section 3.2 derives the auxiliary posterior; Section 5 reports reduced training time and memory vs. FS-EB/GFSVI.
- **Break condition:** Linear model misspecification (true functions highly non-linear relative to embeddings) or MC dropout failing to capture posterior multimodality.

## Architecture Onboarding
- **Component map:**  
  Context generator (qwen-vl-plus) -> synthetic context images -> embedding extractor (tongyi-embedding-vision-plus) -> frozen embeddings hL(xc) -> prior constructor (computes K = τ₁ hL hLᵀ + τ₂ I) -> main network (CNN with MC dropout) -> optimizer (Adam minimizing ELBO)

- **Critical path:**  
  1. Generate 9,000 context images per dataset via qwen-vl-plus prompt pipeline.  
  2. Extract embeddings for all images (real+synthetic) with frozen hL; compute prior covariance from context embeddings.  
  3. During training: for each batch, sample S dropout masks, compute data log-likelihood and context log-likelihood terms, backpropagate ELBO.  
  4. At inference: average predictions over multiple dropout forward passes (e.g., 30).

- **Design tradeoffs:**  
  - Context count: More points improve prior but increase K computation cost; paper uses 9,000 generated but only 32 during training.  
  - VLM selection: Generative quality vs. embedding quality may trade off; using different VLMs for each role is pragmatic but may cause domain mismatch.  
  - Hyperparameters: τ₁, τ₂ control prior scale and noise; λ (weight decay) regularizes main network; dropout rate balances posterior expressivity vs. training stability.  
  - Embedding dimension: High-dimensional embeddings (1152) capture rich semantics but may overparameterize the linear model.

- **Failure signatures:**  
  - Poor OOD detection (AUROC ~0.5): likely due to poor context diversity or τ₁ too small; check context generation quality and increase τ₁ or context set size.  
  - Training instability (ELBO oscillates): probably τ₁/τ₂ poorly tuned or dropout rate too high; monitor loss curves, adjust hyperparameters.  
  - In-distribution degradation (worse than non-Bayesian baseline): prior overly restrictive; reduce τ₁ or increase context diversity.  
  - Memory blowup: Covariance K scales with context count; if using many points, ensure K fits in GPU memory (consider chunking?).

- **First 3 experiments:**  
  1. **Baseline replication:** Train on MNIST full data; expect ~99.2% ACC and ~100% AUROC on NotMNIST (Table 1). Confirms implementation.  
  2. **Component ablation:** Compare VLM-VLM vs. VLM-Rand (Table 5); expect large OOD drop (~5-10 AUROC) when context points are random, confirming semantic context importance.  
  3. **Data-scarce validation:** Train with 25% MNIST; check if VLM-FS-EB maintains >99% ACC and near-perfect OOD AUROC (Table 3,4), demonstrating data efficiency.

## Open Questions the Paper Calls Out
- **Can VLM-FS-EB efficiently scale to high-resolution image datasets and large-scale problems?**  
  Basis: Experiments only on low-resolution datasets (MNIST, Fashion-MNIST, CIFAR-10, PathMNIST) and a fixed 9,000 context points.  
  Why unresolved: Computational burden of generating/embedding high-resolution context images and memory for large covariance matrices may limit applicability; performance in such regimes is unknown.  
  What evidence would resolve: Evaluate on high-resolution benchmarks (e.g., ImageNet, higher medical resolutions) with varying context sizes, reporting accuracy, OOD AUROC, training time, and memory.

- **Does fine-tuning the VLM embedding on the target task improve performance compared to using a frozen generic model?**  
  Basis: The method freezes the embedding to avoid overfitting and leverage general semantics; no fine-tuning experiments were conducted.  
  Why unresolved: Domain-specific datasets (e.g., medical images) might benefit from adaptation; trade-off between generalization and specialization remains unexplored.  
  What evidence would resolve: Compare frozen vs. fine-tuned embeddings on diverse datasets, including domain-shifted ones, using the same VLM-FS-EB pipeline and measuring in-distribution metrics and OOD detection.

- **How sensitive is VLM-FS-EB to the number and diversity of generated context points?**  
  Basis: The paper uses a fixed 9,000 context points without justification; no ablation on quantity or quality is provided.  
  Why unresolved: The empirical Bayes prior depends on these points; too few may inadequately cover input space, while too many increase cost; diversity affects robustness and is untested.  
  What evidence would resolve: Ablate context set size (e.g., 500, 1000, 5000, 9000) and diversity (e.g., by varying VLM prompts or generative models), analyzing effects on ELBO, prediction accuracy, and OOD AUROC.

## Limitations
- Proprietary VLM dependency: exact prompts, reference images, and generation details are undisclosed, hindering faithful reproduction.
- Embedding mismatch: frozen VLM features may not capture fine-grained task variations (e.g., medical images), risking prior misalignment.
- Linear prior assumption: the stochastic linear model over embeddings might be misspecified for highly nonlinear functions; MC dropout may not fully approximate the posterior.
- Computational cost: generating 9k context images per dataset is expensive and may not scale to larger vision tasks.

## Confidence
- **Mechanism 1 (VLM-generated context):** Medium – strong empirical gains, but no systematic validation of semantic coherence or style preservation.
- **Mechanism 2 (Frozen VLM embeddings):** High – well-established by contrastive learning literature; consistent performance gains across diverse datasets.
- **Mechanism 3 (FS-EB linear prior + MC dropout):** Medium – reduces linearization overhead and memory, but relies on embedding quality and may suffer from dropout’s limited expressivity.

## Next Checks
1. **Prompt diversity analysis:** Vary prompts and reference sets; correlate context semantic coverage (e.g., CLIP similarity) with OOD AUROC to verify the need for diverse, coherent contexts.
2. **Embedding model ablation:** Swap the proprietary embedding with an open-source CLIP variant (ViT-B/32) and compare in-distribution NLL/ECE and OOD detection to isolate the impact of embedding quality.
3. **Linear model diagnostics:** Compute the effective rank of the context covariance matrix and evaluate predictive log-likelihood under non-linear kernels (e.g., RBF) to test whether a linear structure suffices.
