# Linked Data Classification using Neurochaos Learning

## Quick Facts
- arXiv ID: 2602.16204
- Source URL: https://arxiv.org/abs/2602.16204
- Reference count: 30
- Primary result: Extends Neurochaos Learning to node classification on knowledge graphs, achieving strong macro F1-scores on homophilic graphs (Cora: 0.844) but poor performance on heterophilic ones.

## Executive Summary
This paper adapts Neurochaos Learning (NL) to node classification on knowledge graphs, a previously unexplored domain for NL. The method aggregates neighboring node features via mean aggregation, transforms all features using chaotic dynamics (ChaosFEX), and classifies with the lightweight ChaosNet using cosine similarity. On homophilic graphs (Cora, Pubmed), mean aggregation with dual loading (original + aggregated features) yields strong results, e.g., Cora test macro F1-score of 0.844. Performance degrades significantly on heterophilic graphs (Actor test F1 0.265, Squirrel 0.34). An alternative H2GNN-based aggregation strategy performed poorly across all tested datasets, indicating that simple mean aggregation is preferable for homophilic graphs but that NL's efficacy is strongly tied to graph homophily.

The study underscores that non-GNN approaches can be effective for graph node classification when structural assumptions match the data. However, the reliance on homophily and the sensitivity to chaotic hyperparameters highlight limitations and open avenues for improving aggregation strategies and direct graph-native chaotic architectures.

## Method Summary
The pipeline loads a knowledge graph using PyTorch Geometric, obtaining node features, edge indices, and labels. For each node, neighbor features are aggregated (mean or H2GNN-based) and concatenated with the node’s original features (dual loading). The combined feature matrix is normalized to [0,1]. Each normalized feature value is processed by a chaotic neuron based on the Generalized Luroth Series map, generating a neural trace from which four chaotic features (firing time, firing rate, energy, entropy) are extracted. This expands each feature dimension fourfold. During training, ChaosNet computes the mean chaotic feature vector per class. For inference, a test sample’s chaotic vector is compared to each class mean via cosine similarity; the highest similarity class is assigned. Hyperparameters (initial activity Q, threshold B, noise ε) are tuned per dataset via 5‑fold cross‑validation on the training set. The approach deliberately avoids deep GNN layers, instead relying on aggregation plus chaotic feature transformation.

## Key Results
- On homophilic graphs (Cora, Pubmed), mean aggregation with dual loading yields strong macro F1-scores (Cora test 0.844, PubMed 0.760).
- Performance degrades significantly on heterophilic graphs (Actor test 0.265, Squirrel 0.340).
- H2GNN-based aggregation performed poorly across all datasets, indicating that simple mean aggregation is preferable for homophilic graphs but that NL's efficacy is strongly tied to graph homophily.

## Why This Works (Mechanism)

### Mechanism 1: Mean Aggregation Enriches Representations on Homophilic Graphs
**Claim:** Mean aggregation of neighboring node features improves classification performance on homophilic graphs by enriching node representations with consistent local structural information.  
**Mechanism:** For each node, the feature vectors of its immediate neighbors are averaged. This aggregated vector is concatenated with the node's original features ("dual loading") before chaotic transformation. The averaging smooths noise while preserving the dominant label signal from same‑class neighbors.  
**Core assumption:** In homophilic graphs, a node's neighbors are likely to share its class label. Therefore, their averaged features provide a reliable estimate of the node's local context.  
**Evidence anchors:**  
- The abstract states: "On homophilic graphs (Cora, Pubmed), mean aggregation with dual loading (original + aggregated features) yields strong results."  
- Table 2 in the paper shows test macro F1‑scores of 0.844 (Cora) and 0.76 (PubMed) using mean aggregation with dual loading.  
- The corpus of related NL work on tabular/time-series data does not directly evidence graph aggregation mechanisms; this mechanism is inferred from the paper's own experimental design and results.  
**Break condition:** The mechanism fails on heterophilic graphs (e.g., Actor F1=0.265, Squirrel F1=0.34) where neighbors often have different labels, causing the aggregated feature to become a noisy or contradictory signal that degrades the discriminative chaotic features.

### Mechanism 2: ChaosFEX Non‑linear Amplification of Subtle Variations
**Claim:** The ChaosFEX chaotic feature extraction pipeline enhances discriminability by non‑linearly amplifying minute, class‑specific variations in the (aggregated) feature vectors that linear methods may miss.  
**Mechanism:** Each normalized input feature (from original or aggregated vectors) is fed into a chaotic neuron (GLS map). The neuron's trajectory—controlled by parameters Q (initial activity), B (threshold), and noise ε—generates a "neural trace." Four features (firing time, firing rate, energy, entropy) are extracted from this trace. The chaotic dynamics ensure small input differences lead to significantly distinct trace dynamics.  
**Core assumption:** Class‑discriminatory information exists in subtle, non‑linear feature interactions within the aggregated representation. The chaotic system's sensitivity to initial conditions acts as a powerful, deterministic feature amplifier for these interactions.  
**Evidence anchors:**  
- Section 3.3 describes: "Chaotic dynamics... generate a non‑linear mapping to aid in accentuating the fine but informative details that are usually neglected by traditional machine learning models."  
- Section 7.6 shows hyperparameter tuning (Q, B, ε) is critical, implying the chaotic transformation's output is highly sensitive to these parameters, which control the "amplification" dynamics.  
- Corpus papers (e.g., "When noise meets chaos: Stochastic resonance in neurochaos learning") establish the foundational principle of using chaotic dynamics and stochastic resonance for feature extraction in NL, though not for graph data.  
**Break condition:** If input features are not properly normalized to [0,1] or if hyperparameters (Q, B, ε) are far from dataset‑specific optima, the chaotic dynamics may enter uninformative regimes (e.g., immediate halt, chaotic explosion) failing to produce discriminative features.

### Mechanism 3: ChaosNet Cosine Classifier Suits Chaotic Feature Space
**Claim:** The ChaosNet cosine similarity classifier is particularly effective for the chaotic feature space in low‑training‑sample regimes by learning a simple, robust class representation from mean chaotic feature vectors.  
**Mechanism:** During training, the mean chaotic feature vector for each class is computed. For a test sample, its chaotic feature vector is compared to each class mean via cosine similarity. The class with the highest similarity is assigned. This avoids complex parametric learning and leverages the presumed high intra‑class similarity of chaotic features.  
**Core assumption:** After ChaosFEX transformation, samples from the same class form a compact cluster in the high‑dimensional chaotic feature space, and the Euclidean/angular structure of this space is meaningful for cosine similarity.  
**Evidence anchors:**  
- Section 3.1: "These learned vectors are then fed... to a simple cosine similarity classifier (ChaosNet)."  
- Section 7.2: On Cora, standalone ChaosNet (0.8437 test F1) outperformed a hybrid ChaosNet+Random Forest (0.8173), suggesting the simple cosine classifier is sufficient and well‑suited to the chaotic feature space.  
- Section 6: "The ultimate goal is to assess... with respect to the macro‑F1 measure... with limited training data." This aligns with ChaosNet's design philosophy from prior NL work.  
**Break condition:** Fails if the chaotic feature space has high intra‑class variance (e.g., due to extreme heterophily corrupting the aggregated input) or if the number of training samples per class is too low to form a stable mean vector, making the centroid representation noisy.

## Foundational Learning

### Graph Homophily and Heterophily
**Why needed:** The paper's central finding is that NL's performance is tightly coupled to this graph property. Understanding it is essential to predict when the presented method will work. Homophily (neighbors share labels) makes mean aggregation beneficial; heterophily (neighbors have different labels) makes it harmful.  
**Quick check:** Given a graph's edge list and node labels, how would you calculate the homophily ratio? What would a value of 0.2 imply about the graph's structure and the suitability of mean aggregation?

### Chaotic Dynamical Systems (GLS Map)
**Why needed:** The core feature extractor (ChaosFEX) is based on the Generalized Luroth Series map. Understanding its basic behavior—piecewise linear, chaotic for certain parameters, sensitive to initial conditions—is key to grasping why it's used and how its parameters (Q, B) influence the output.  
**Quick check:** If you input two nearly identical numeric values (e.g., 0.501 and 0.502) into a GLS map with b=0.6, what property of the chaotic system suggests their output traces will eventually diverge significantly?

### Node Feature Aggregation (Message Passing Prelude)
**Why needed:** This is the bridge between graph‑structured data and NL's tabular‑input architecture. The paper tests two strategies: simple mean and H2GNN‑style decoupling. This concept is fundamental to adapting any non‑GNN model to graphs.  
**Quick check:** What is the fundamental difference in information flow between "mean aggregation" and the "H2GNN‑based aggregation" described, and why might the latter be theoretically better suited for a heterophilic graph?

## Architecture Onboarding

**Component map**  
Data Loader -> Aggregator -> Feature Combiner (Loader Strategy) -> Normalizer -> ChaosFEX Transformer -> ChaosNet Classifier

**Critical path**  
Raw Graph -> Aggregator -> Aggregated Features -> Loader Strategy -> Combined Feature Matrix -> Normalizer -> Normalized Matrix -> ChaosFEX -> Chaotic Feature Matrix -> ChaosNet Training -> Class Means -> ChaosNet Inference -> Predictions

**Design tradeoffs**
- Simplicity vs. Expressiveness: Mean aggregation is computationally trivial but naive. H2GNN is more expressive (separates homo/hetero info) but complex and, in this paper, underperformed, possibly due to implementation overhead or poor parameter interaction with NL.
- Parameter Stability vs. Performance: ChaosNet performance is highly sensitive to (Q, B, ε). The paper shows a stable high‑performance region (e.g., Cora: Q≈0.5, B≈0.75, ε≈0.1), but finding it requires per‑dataset grid search. This is a tradeoff against the "low compute" claim of NL.
- Structure Usage: The method discards edge features and uses only node‑level aggregation. It treats graph structure as a static feature modifier, not as a dynamic process. This limits its ability to capture complex relational patterns compared to message‑passing GNNs.

**Failure signatures**
1. Low Test F1‑Score (<0.5) on a known benchmark: First suspect incorrect homophily assumption. Check dataset's homophily ratio. If highly heterophilic (>0.7 heterophily), mean aggregation is likely the primary culprit.
2. High Variance in Cross‑Validation Scores: Suggests unstable chaotic dynamics. Check if normalized input features are truly in [0,1]. Investigate if the chosen (Q, B, ε) lie in a flat or noisy region of the hyperparameter space (see Fig. 2).
3. Training F1‑Score much higher than Test F1‑Score: Classic overfitting. For NL/ChaosNet, this is less common due to simple classifier, but can occur if chaotic features are not discriminative or if the train/test split is not stratified properly. Verify split code.

**First 3 experiments**
1. **Baseline Reproduction (No Aggregation):**  
   Goal: Establish the performance ceiling using only original node features, ignoring graph structure.  
   Procedure: Set X_final = X_original. Run full pipeline (normalize, ChaosFEX, ChaosNet) with standard hyperparameter ranges. Record test macro F1.  
   Expected Outcome: Decent performance on homophilic datasets (Cora ~0.67 per paper), poor on heterophilic. Confirms graph structure provides useful signal for NL.

2. **Mean Aggregation & Dual Loading:**  
   Goal: Validate the paper's primary claimed mechanism.  
   Procedure: Compute X_agg via mean of neighbor features. Set X_final = concat(X_original, X_agg). Tune (Q, B, ε) via 5‑fold CV on training set. Evaluate on test set.  
   Expected Outcome: Significant boost on homophilic datasets (Cora >0.81, PubMed >0.76). Degradation or minimal change on heterophilic datasets (Actor, Squirrel).

3. **H2GNN‑Based Aggregation Test:**  
   Goal: Test the paper's secondary finding and a more complex alternative.  
   Procedure: Implement H2GNN‑style aggregation (separate homophilic/heterophilic neighbor pools). Generate X_agg_homo and X_agg_hetero, then X_final = concat(X_original, X_agg_homo, X_agg_hetero). Use same CV tuning protocol.  
   Expected Outcome: Replicate paper's finding: poor performance on all datasets, including homophilic ones (e.g., Cora F1=0.23). This suggests the added complexity is detrimental or requires different chaotic parameter tuning, and that simple mean is preferred for NL on these graphs.

## Open Questions the Paper Calls Out

1. **Can chaos‑based feature transformations achieve competitive macro F1‑scores on heterophilic graph node classification without relying on deep GNN architectures?**  
   **Basis in paper:** Section 5 states: "it remains unclear whether chaos‑based features such as firing time, energy, and entropy can provide robustness to heterophily without relying on deep or computationally heavy GNN architectures."  
   **Why unresolved:** The paper reports significant performance degradation on heterophilic datasets (e.g., Actor test F1 0.265, Squirrel 0.34) with mean aggregation, and H2GNN‑based aggregation performed poorly across all tested datasets, indicating current NL approaches lack robustness to heterophily.  
   **What evidence would resolve it:** Systematically evaluate ChaosFEX‑extracted features on a benchmark suite of heterophilic graphs with varying heterophily ratios, compare against state‑of‑the‑art GNNs using macro F1‑score, and conduct ablation studies to isolate which chaotic features (firing time, rate, energy, entropy) fail in heterophilic settings and why.

2. **How can node and edge aggregation algorithms be designed to effectively capture heterophilic neighborhood information for neurochaos learning?**  
   **Basis in paper:** Section 10 calls for "improved node aggregation algorithms that take the actual nature of the heterophily into account, not just the heterophily metric. Here, edge aggregation algorithms that help to integrate edge features, should also be considered to augment the node aggregation algorithms."  
   **Why unresolved:** Simple mean aggregation works for homophilic graphs but harms performance on heterophilic ones, and H2GNN aggregation (designed for heterophily) failed, suggesting existing strategies do not preserve useful heterophilic signals or integrate edge semantics in the NL pipeline.  
   **What evidence would resolve it:** Develop aggregation methods that weight neighbors by label similarity or edge relation types, incorporate edge feature transformations, and validate on heterophilic datasets (e.g., Actor, Squirrel) via macro F1‑score improvements over mean aggregation, with statistical significance tests.

3. **What architectural modifications enable neurochaos learning to directly process graph topology without feature aggregation, preserving structural nuances?**  
   **Basis in paper:** Section 5 notes that existing NL models "lack mechanisms to directly capture graph connectivity and neighborhood information present in linked datasets," relying instead on tabular transformations after aggregation.  
   **Why unresolved:** The current approach uses mean aggregation as a proxy for graph structure, which may oversimplify connectivity and lose topological patterns critical for heterophilic graphs; direct processing could align chaotic dynamics with graph properties.  
   **What evidence would resolve it:** Design graph‑native chaotic networks where neuron parameters (e.g., initial activity Q, threshold B) are initialized based on node centrality or edge weights, test on node classification tasks, and compare performance and feature stability against aggregated baselines using macro F1‑score and sensitivity analysis.

4. **How can chaotic maps be distributed across a knowledge graph's structure to mimic biological chaotic neural oscillators and enhance node classification?**  
   **Basis in paper:** Section 10 proposes "Distribution of NL, in particular, specifically designed chaotic maps, across the structure of the knowledge graph, in a manner similar to the chaotic neural oscillators described in [30]."  
   **Why unresolved:** ChaosNet applies uniform chaotic transformations per feature, ignoring graph topology; distributing maps could synchronize or localize chaotic dynamics with graph communities or paths, potentially improving discriminative power in complex graphs.  
   **What evidence would resolve it:** Implement a graph‑aware ChaosFEX where chaotic map parameters vary by node cluster (e.g., via modularity) or path length, evaluate on homophilic and heterophilic graphs with macro F1‑score, and measure alignment between chaotic feature distributions and graph structural properties (e.g., assortativity).

## Limitations
- The method's applicability is limited to homophilic graphs; performance drops dramatically on heterophilic graphs, indicating a strong dependency on the homophily assumption of mean aggregation.
- ChaosFEX's claimed discriminative amplification lacks direct empirical validation; the role of each chaotic feature and their sensitivity is inferred but not isolated via ablation studies.
- Implementation details for ChaosFEX and H2GNN‑based aggregation are not fully specified, making faithful reproduction difficult and hindering further development.

## Confidence
- Homophily‑dependence of NL: High
- ChaosFEX’s discriminative amplification: Medium
- ChaosNet’s suitability for chaotic feature space: Medium
