# Seeing Like Radiologists: Context- and Gaze-Guided Vision-Language Pretraining for Chest X-rays
## Quick Facts
- **arXiv ID:** 2603.26049
- **Source URL:** https://arxiv.org/abs/2603.26049
- **Reference count:** 40
- **Primary result:** CoGaze achieves state-of-the-art gains: +2.0% CheXbert F1 and +1.2% BLEU2 for report generation, +23.2% AUROC for zero-shot classification, and +12.2% Precision@1 for image-text retrieval, with consistent improvements in classification and segmentation across multiple benchmarks.

## Executive Summary
Chest X-ray interpretation requires integrating clinical context and mimicking radiologists' visual attention. Existing vision-language pretraining methods treat images as context-agnostic and ignore gaze, limiting diagnostic reasoning. CoGaze introduces a framework that explicitly incorporates patient history, symptoms, and radiologists' eye-tracking data. It uses a context-infused vision encoder to fuse clinical context and a soft gaze guidance loss to align transcript patches with radiologists' fixations. Through hybrid-positive contrastive learning, disease-aware classification, and gaze supervision, CoGaze learns richer representations. Extensive experiments show consistent improvements on report generation, zero-shot classification, retrieval, and segmentation tasks, demonstrating the value of context and gaze for medical vision-language modeling.

## Method Summary
CoGaze employs dual encoders: a context-infused vision encoder (Rad-DINO backbone) and a shared language encoder (CXR-BERT). Clinical context (patient history, symptoms) is injected into the vision encoder via a Perceiver module. During pretraining on the MIMIC-CXR dataset (240k images, 150k reports), the model optimizes three losses: hybrid-positive contrastive loss (`L_con`) for global image-report alignment, disease-aware cross-modal classification loss (`L_cls`) using CheXbert labels to inject diagnostic priors, and soft gaze guidance loss (`L_G`) that aligns transcript-patch similarities with radiologists' gaze heatmaps (from EGD and REFLACX) using bidirectional Jensen-Shannon divergence. For downstream tasks, the pretrained backbone is frozen and task-specific heads are attached (e.g., LoRA-tuned LLM for generation, linear classifiers, UNet decoders). The approach is evaluated on 7 datasets covering report generation, classification, segmentation, and retrieval.

## Key Results
- Report generation: +2.0% CheXbert F1, +1.2% BLEU2 over previous SOTA.
- Zero-shot classification: +23.2% AUROC improvement.
- Image-text retrieval: +12.2% Precision@1 gain.
- Consistent gains also in classification and segmentation benchmarks.

## Why This Works (Mechanism)
Integrating clinical context conditions the vision encoder on patient-specific information, mimicking how radiologists use history and symptoms to focus on relevant regions. Gaze data provides fine-grained supervision: radiologists' fixation heatmaps highlight diagnostically salient areas, guiding the model to align textual mentions with image patches via the soft gaze loss. The multi-level supervision combines global alignment (contrastive), explicit disease priors (classification), and local alignment (gaze), covering complementary aspects of medical reasoning. This structured approach yields representations that transfer strongly to diverse tasks.

## Architecture Onboarding
**Component map:**  
Clinical Context -> Perceiver -> Context-Infused Vision Encoder (Rad-DINO)  
Report + Transcript -> Shared Language Encoder (CXR-BERT)  
Gaze Heatmaps -> Soft Gaze Guidance Loss  
Multi-level Supervision (L_con, L_cls, L_G) -> Pretrained Model  

**Critical path:** During pretraining, input: image, report, clinical context, gaze heatmap. Vision encoder processes image with context from Perceiver. Language encoder processes report and context. Compute L_con between image and report embeddings, L_cls from image to disease labels, L_G between gaze heatmap and transcript-patch similarity. Backpropagate sum. For inference/downstream, use frozen vision encoder to extract features, attach task head.

**Design tradeoffs:** Using limited gaze data (~0.7% of MIMIC-CXR) may limit coverage; soft guidance mitigates noise. Context infusion adds complexity but improves relevance. Hybrid-positive contrastive balances false negatives.

**Failure signatures:**  
- Gaze loss stagnant or diverging: likely mismatch between heatmap resolution and patch similarity computation.  
- Context feature extraction fails: check Perceiver output norm and conditioning.  
- Downstream performance far below reported: verify pretrained checkpoint loading and exact downstream splits.
