# A Dual Pipeline Machine Learning Framework for Automated Multi Class Sleep Disorder Screening Using Hybrid Resampling and Ensemble Learning

## Quick Facts
- **arXiv ID**: 2601.05814
- **Source URL**: https://arxiv.org/abs/2601.05814
- **Reference count**: 40
- **Primary result**: Achieved 98.67% classification accuracy using Extra Trees and K-Nearest Neighbors on the Sleep Health and Lifestyle dataset.

## Executive Summary
This research tackles the resource-intensive nature of clinical polysomnography by proposing a Dual Pipeline Machine Learning Framework (DPMLF) for scalable sleep disorder screening. The framework processes data in parallel through a statistical pipeline (Mutual Information + Linear Discriminant Analysis) and a wrapper-based pipeline (Boruta + Autoencoder), combined with hybrid SMOTETomek resampling to address class imbalance. Evaluated on the Sleep Health and Lifestyle dataset, it achieves 98.67% accuracy with inference latency under 400 ms, significantly outperforming recent benchmarks (Wilcoxon Signed Rank Test, p=0.00391). The design enables automated, efficient screening while maintaining high performance.

## Method Summary
The DPMLF employs two parallel feature engineering pipelines applied after preprocessing and stratified train-test splitting. Hybrid SMOTETomek resampling is applied only to the training fold to balance classes. Pipeline 1 uses RobustScaler, Mutual Information (MI) for filter-based selection, and Linear Discriminant Analysis (LDA) for linear dimensionality reduction. Pipeline 2 uses MinMaxScaler, Boruta for wrapper-based all-relevant selection, and an Autoencoder for nonlinear compression. Nine classifiers (e.g., KNN, Extra Trees) are trained on both transformed feature sets, with hyperparameter tuning via RandomizedSearchCV and stratified 8-fold cross-validation, ensuring all transformations fit strictly within each CV fold to prevent data leakage. Performance is evaluated on a held-out test set using accuracy, F1-score, recall, precision, and latency metrics.

## Key Results
- Classification accuracy of 98.67% achieved with KNN (Pipeline 1) and Extra Trees (Pipeline 2).
- Statistically significant improvement over recent baselines (Wilcoxon Signed Rank Test, p=0.00391).
- Inference latency maintained below 400 milliseconds, supporting real-time screening.

## Why This Works (Mechanism)
The framework's superior performance arises from three interconnected mechanisms. First, the dual pipeline architecture separately optimizes linear (statistical) and nonlinear (wrapper-based) feature engineering, allowing classifiers to select the pipeline aligned with their inductive biases—KNN thrives on MI-reduced linear subspaces, while Extra Trees benefits from Boruta's interaction-aware selection. Second, hybrid SMOTETomek resampling effectively handles severe class imbalance: SMOTE synthesizes minority samples to increase representation, while Tomek Links remove ambiguous majority-minority pairs, clarifying decision boundaries and boosting recall for rare disorders like Insomnia and Sleep Apnea. Third, tailoring feature selection to classifier paradigms—using MI (a filter) for distance-sensitive models to reduce noise, and Boruta (a wrapper) for tree ensembles to capture complex interactions—ensures each model receives optimally relevant inputs, as evidenced by ablation studies showing classifier-specific performance peaks.

## Foundational Learning
- **Mutual Information (MI)**: Measures statistical dependence between features and target, used in Pipeline 1 to discard irrelevant dimensions for KNN. *Quick check*: An MI score near zero implies the feature contributes little predictive information for MI-based selection.
- **Linear Discriminant Analysis (LDA)**: Reduces dimensionality by maximizing the ratio of between-class to within-class variance, enhancing linear separability. *Quick check*: LDA optimizes for discriminant projection that maximizes class separation relative to spread.
- **Boruta Feature Selection**: Wrapper method comparing original features against randomized "shadow" copies via Random Forest to identify all-relevant features. *Quick check*: Shadow features provide a randomized baseline; features consistently more important than shadows are deemed significant.
- **Autoencoder**: Neural network that learns compressed latent representations by reconstructing inputs, capturing nonlinear structures. *Quick check*: Minimizes reconstruction loss (e.g., mean squared error), implying the latent space preserves essential data characteristics.
- **SMOTETomek**: Hybrid resampling combining SMOTE (oversampling via synthetic minority samples) and Tomek Links (undersampling by removing ambiguous borderline samples). *Quick check*: The two sequential operations are synthetic sample generation and ambiguous sample removal.

## Architecture Onboarding
**Component map**: Sleep Health Dataset → Preprocessing (encoding, BP split, feature engineering) → 80/20 Stratified Split → SMOTETomek (on training fold only) → Dual Pipelines: Pipeline 1 (RobustScaler → MI → LDA) and Pipeline 2 (MinMaxScaler → Boruta → Autoencoder) → 9 Classifiers trained on both outputs → Evaluation (metrics, latency, Wilcoxon test).

**Critical path**: Prevent data leakage by fitting all transformers (SMOTETomek, scalers, MI, Boruta, Autoencoder) strictly within each cross-validation training fold; apply fitted transformers to validation fold only. Leakage inflates performance unrealistically.

**Design tradeoffs**: 
- Pipeline 1 is fast and interpretable but may miss nonlinear signals, ideal for KNN and linear models.
- Pipeline 2 captures complex interactions but is computationally heavy and less interpretable, suiting tree ensembles like Extra Trees.
- Hybrid resampling improves minority recall but adds training time and risks overfitting on synthetic data if cross-validation is mishandled.

**Failure signatures**:
1. Poor minority class recall: SMOTETomek not applied or applied with leakage; check confusion matrices.
2. High CV variance: Overfitting from noisy Autoencoder or spurious Boruta selections; monitor standard deviations in performance tables.
3. Low KNN performance: MI or RobustScaler missing; KNN is sensitive to irrelevant dimensions and scale.
4. Extra Trees drops with Autoencoder: Autoencoder may lose discriminative features; default should use Pipeline 2 without Autoencoder for Extra Trees.

**First 3 experiments**:
1. **Baseline Replication**: Train all classifiers on raw, preprocessed training set without pipelines or resampling; verify baseline metrics (~97.33% for Logistic Regression) to confirm code correctness.
2. **Pipeline Isolation Test**: For KNN and Extra Trees, train separately on Pipeline 1 and Pipeline 2 outputs without SMOTETomek; expect KNN to prefer Pipeline 1, Extra Trees to be robust or lean toward Pipeline 2.
3. **SMOTETomek Integrity Check**: Perform manual stratified 8-fold CV, fitting SMOTETomek only on each training split; average validation accuracy should be ~98% with low std-dev. High variance indicates pre-split application.

## Open Questions the Paper Calls Out
- **Generalization to Real-World Data**: Does the framework maintain 98.67% accuracy on larger, multi-center clinical datasets with diverse populations, or is performance dataset-specific?
- **Resampling Conditions**: Under what dataset characteristics (e.g., class overlap, imbalance ratio) and for which classifiers does SMOTETomek improve versus degrade performance?
- **Pipeline Selection Criterion**: How to choose between the statistical and wrapper pipelines for a given classifier and dataset, or is always using both necessary?
- **Wearable Adaptation**: Can the static tabular pipeline be adapted for streaming wearable data (e.g., PPG, accelerometer) while keeping latency <400 ms and preserving accuracy?

## Limitations
- Key hyperparameters (e.g., MI feature count, Autoencoder architecture, Boruta iterations) are unreported, blocking faithful reproduction and validation.
- The 98.67% accuracy claim is vulnerable to data leakage risks from improper cross-validation and overfitting on the small synthetic dataset (n=374).
- No external validation on diverse, real-world sleep datasets; findings may not generalize beyond the Kaggle-sourced data.

## Confidence
- **Overall Performance Claim (98.67% accuracy)**: Low – due to missing implementation details and leakage susceptibility.
- **Dual-Pipeline Mechanism Efficacy**: Medium – supported by internal ablation but lacks external corroboration.
- **SMOTETomek's Role in Imbalance Handling**: Medium – internal evidence shows gains for some classifiers, but generalizability unclear.

## Next Checks
1. **Reproduce Baseline with Full Disclosure**: Request authors' exact hyperparameter distributions, Autoencoder specs, and MI `k`; re-run with strict within-CV fitting. If accuracy drops >2%, original result may be inflated.
2. **Ablation of Resampling Strategy**: Retrain optimal KNN and Extra Trees configurations without SMOTETomek; significant minority-class recall drop would confirm its necessity.
3. **Feature Set Concordance Analysis**: Compute global feature importance via nested Random Forest CV; compare with MI and Boruta selections. Low concordance supports tailored selection; high concordance suggests a universal feature set exists, questioning dual-pipeline overhead.
