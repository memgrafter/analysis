# StateLinFormer: Stateful Training Enhancing Long-term Memory in Navigation

## Quick Facts
*   **arXiv ID:** 2603.23571
*   **Source URL:** https://arxiv.org/abs/2603.23571
*   **Reference Count:** 40
*   **Primary Result:** Preserving memory states across training batches (stateful training) significantly improves long-horizon navigation success rates over stateless training and prior baselines, with performance scaling favorably with increased interaction context.

## Executive Summary
This paper introduces StateLinFormer, a method that improves long-term memory and in-context learning for navigation AI. Instead of resetting the internal memory state to zero at the start of each training batch—the standard practice—it propagates the final state of one batch to initialize the next. This "stateful training" aligns the training data distribution with the continuous, non-episodic nature of real-world deployment. On the challenging MAZE (10M frames) and ProcTHOR benchmarks, stateful training with a linear-attention model (RWKV-7) substantially outperforms both its stateless ablation and prior state-of-the-art models trained on more data. Results show monotonic improvement as the interaction context grows, indicating enhanced in-context learning capabilities without parameter updates.

## Method Summary
The core innovation is a training protocol for linear-attention models (specifically RWKV-7) that maintains a persistent memory matrix `M_t` across consecutive training batches. During standard "stateless" training, `M_t` is reset to zero for each new batch, exposing model parameters only to trajectories starting from a blank slate. In "stateful" training, the final memory state `M_T` from batch `b` is detached and used as the initial state `M_0` for batch `b+1` of the same trajectory. This exposes the parameters to a broader distribution of memory states encountered during ongoing interaction, approximating optimization over a single infinite stream of experience. The model architecture consists of frozen goal and image encoders (SigLIP), a goal-conditioned visual encoder, and an RWKV-7 decoder that performs the recurrent linear-attention update (`M_t = M_{t-1} + φ(k_t)v_t^⊤`). The policy is trained via imitation learning (negative log-likelihood) on expert demonstrations from long-horizon navigation tasks.

## Key Results
*   On MAZE (10M frames): Stateful training achieves a **0.77 success rate** vs. 0.64 for stateless linear-attention and 0.68 for SPOC-10M. Steps to goal are reduced to **189** from 249 (stateless).
*   On ProcTHOR: Stateful reaches **0.580 success rate**, surpassing stateless (0.420), SPOC-10M (0.479), and even SPOC-Pretrained (0.566) trained on 4x more frames (40M).
*   Performance scales monotonically with context length on the Continual Object Navigation (CON) benchmark, demonstrating enhanced in-context learning.

## Why This Works (Mechanism)
Stateful training improves long-horizon navigation by fundamentally altering the statistical distribution of memory states the model encounters during optimization.

**Mechanism 1: Aligning Training with Deployment Dynamics.** Stateless training optimizes parameters almost exclusively under the distribution of memory states concentrated at `M=0`, as each batch starts fresh. Stateful training propagates `M_T` to the next batch, exposing parameters to the distribution `d_θ` induced by the model's own long-horizon recurrent dynamics. This better approximates the continuous interaction scenario of deployment, where the agent never resets its memory between tasks. Evidence includes the paper's explicit formulation contrasting the two objectives and empirical analysis showing lower variance in memory norms under stateful training, consistent with sampling from a more stationary distribution.

**Mechanism 2: Enhancing In-Context Learning (ICL).** By maintaining memory continuity during training, the model learns to treat its internal state `M_t` as a persistent repository of experience. At inference, as the interaction trajectory lengthens, this accumulated state provides a richer context for decision-making. This is evidenced by the monotonic improvement in success rate as context length increases in CON evaluation, a hallmark of effective ICL. The training protocol forces the model to develop mechanisms to store, retrieve, and reason over an evolving state.

**Mechanism 3: Stabilizing the Memory Regime.** Stateless training optimizes the policy primarily for the "blank slate" phase of a trajectory, leading to transient memory dynamics. Stateful training exposes the model to memory states at various accumulation stages. This forces gradient updates to be effective across a wider range of memory "maturities," resulting in a policy that is more robust to the ongoing state of the memory buffer. The observed lower relative standard deviation (RSD) of the memory norm under stateful training supports this stabilization.

## Foundational Learning
*   **Concept: Linear Attention / Stateful Models**
    *   **Why needed:** The method relies on a linear attention mechanism (RWKV-7) that supports an explicit, constant-size state update (`M_t = M_{t-1} + φ(k_t)v_t^⊤`). Understanding this architectural capacity for unbounded memory is prerequisite.
    *   **Quick check:** What is the key computational advantage of the linear attention update rule over standard softmax attention for long sequences?
*   **Concept: POMDP & Goal-Conditioned Policy**
    *   **Why needed:** Navigation is framed as a Partially Observable MDP where the agent must map a history of partial observations and a goal prompt to actions. Memory compensates for partial observability over time.
    *   **Quick check:** Why is a single observation `o_t` insufficient for deciding the next action `a_t` in a long navigation task?
*   **Concept: Imitation Learning (IL) with Negative Log-Likelihood (NLL) Loss**
    *   **Why needed:** The training objective is minimizing NLL of expert actions. The stateful vs. stateless difference lies in *which memory states* are active when this loss is computed, not in the loss function itself.
    *   **Quick check:** In the loss `L = -Σ log π_θ(a_t | q_t)`, what does `q_t` explicitly contain according to the paper's formulation?

## Architecture Onboarding
*   **Component map:**
    Goal Encoder (`E_goal`) & Image Encoders (`E_image`) -> Goal-Conditioned Visual Encoder (`E_visual`) -> Linear Attention Decoder (`D`) -> Action Head (`MLP + Softmax`)
    `D` performs the core recurrent loop: `(h_t, M_t) = D([o_t, a_{t-1}], M_{t-1})`
*   **Critical path:** State propagation is controlled externally by the training loop, which detaches and carries `M_t` between consecutive batches of the same trajectory. The architecture itself remains unchanged; the change is in how training segments are sequenced and initialized.
*   **Design tradeoffs:**
    *   **Memory Stability vs. Plasticity:** Simple linear attention update is stable but may lack sophisticated gating to manage interference in very long horizons.
    *   **Training Complexity:** Stateful training requires ordered trajectory chunks and prevents perfect shuffling, potentially reducing data diversity per batch. It also demands careful memory management for long effective sequences.
    *   **Evaluation Alignment:** Benefits only manifest under a continuous interaction evaluation (CON). Evaluating on disjoint episodes (resetting memory per task) would nullify the advantage.
*   **Failure signatures:**
    *   Stateful model performs similarly to or worse than stateless ablation on the CON benchmark.
    *   Memory norm (`||M_t||`) grows exponentially or collapses to zero during training.
    *   Success rate does not improve (or degrades) as context length increases in CON evaluation.
*   **First 3 experiments:**
    1.  **State Propagation Sanity Check:** Train briefly on a single long dummy trajectory. Manually verify that the final memory `M_T` of batch *b* is correctly used as `M_0` for batch *b+1*.
    2.  **Stateless vs. Stateful Ablation (Short Horizon):** On a held-out short segment (e.g., 50 steps), both models should perform similarly, confirming the architectural capacity exists in both.
    3.  **Context Length Scaling Probe:** Evaluate both models on CON with truncated context lengths (e.g., 100, 250, 500, 1000 steps). Verify stateful success rate increases monotonically while stateless plateaus/drops.

## Open Questions the Paper Calls Out
*   **OQ1:** What are the formal convergence properties and stability conditions for the memory-state distribution \(d_\theta\) induced by stateful training? The paper does not establish theoretical guarantees.
*   **OQ2:** Does stateful training enhance long-horizon in-context learning and memory retention in non-navigation sequential domains (e.g., language modeling, control)? Its effectiveness outside embodied navigation remains to be validated.
*   **OQ3:** What is the precise mechanistic relationship between stateful training and the emergence of improved in-context learning (ICL) capabilities? The causal link (e.g., how memory dynamics affect gradients) is not isolated.
*   **OQ4:** Can stateful training be integrated with standard Transformer architectures (full softmax attention) to overcome fixed context windows, and does it yield similar benefits? Transformers lack an explicit fixed-size state, making implementation non-trivial.
*   **OQ5:** How does stateful training perform in truly continual multi-environment settings where agent experience accumulates across distinct environments, potentially leading to catastrophic interference? Inter-environment generalization of the learned memory distribution is unknown.

## Limitations
*   **Architectural Details Missing:** Precise RWKV-7 internals (feature map φ, initialization) and the SPOC-derived visual encoder fusion logic are not fully specified, hindering exact replication.
*   **Dataset Specifications Unclear:** Key parameters for MAZE/ProcTHOR trajectory generation (obstacle density, goal sequence statistics, camera parameters) are omitted.
*   **Evaluation Protocol Ambiguity:** The exact CON evaluation rules—particularly whether memory is *never* reset across the entire 5000-step sequence of tasks—are not explicitly defined.

## Confidence
*   **High:** Stateful training outperforms the stateless ablation on MAZE and ProcTHOR benchmarks. The experimental comparison is clear and consistent.
*   **Medium:** The link to enhanced in-context learning (monotonic improvement with context length) is supported by a key figure but lacks isolating ablations (e.g., does a stateless model with artificially extended context behave similarly?).
*   **Low:** The theoretical argument that stateful training approximates optimization over an "infinite interaction stream" via a stationary distribution `d_θ` is plausible but not directly validated (e.g., empirical measurement of the actual state distribution during deployment).

## Next Checks
1.  **Architecture Isolation Ablation:** Reimplement both stateful and stateless models using an identical, standard recurrent backbone (e.g., LSTM) to isolate the effect of the training protocol from the specific RWKV-7 architecture.
2.  **CON Protocol Audit:** Re-run the CON evaluation with explicitly documented and enforced rules to confirm memory is never reset across the entire sequence of sequential tasks within an episode.
3.  **Memory Distribution Profiling:** Actively track and compare the empirical distribution of memory state norms (`||M_t||`) during stateful vs. stateless training to validate the claimed RSD difference and convergence to a stationary regime.
