# Detection and Classification of Cetacean Echolocation Clicks using Image-based Object Detection Methods applied to Advanced Wavelet-based Transformations

## Quick Facts
- **arXiv ID:** 2602.17749
- **Source URL:** https://arxiv.org/abs/2602.17749
- **Reference Count:** 40
- **Primary Result:** Achieved 82.56% overall click detection accuracy and 95.93% click label accuracy on a challenging low-SNR dataset, significantly outperforming existing baseline methods.

## Executive Summary
Manual annotation of killer whale echolocation clicks and their echoes in large acoustic datasets is impractical, especially in low signal-to-noise ratio (SNR) environments. This paper introduces CLICK-SPOT, a toolchain that transforms audio into multi-representation RGB images (waveform, spectrogram, continuous wavelet transform) and applies a YOLO-based object detector. A subsequent first-order gradient detector refines event boundaries, and a random forest classifier using contextual temporal features reliably distinguishes original clicks from echoes. The system demonstrates a 98.01% correlation in detected click rate with ground truth and substantially surpasses prior art like PAMGuard and ANIMAL-SPOT.

## Method Summary
The core method converts 5 ms (960-sample) audio windows into a single 960×960 RGB image called SCWTSPEC: the red channel encodes the raw waveform, the green channel the continuous wavelet transform (CWT) using a Mexican Hat wavelet with 20 scales, and the blue channel the spectrogram. A YOLO object detection model processes these images to predict bounding boxes around potential click events. Each YOLO box is then refined using a first-order gradient (FOD) detector that identifies sharp impulse peaks, groups them, and defines new, more precise event boundaries. Finally, for each candidate event, a feature vector is extracted—including inter-arrival time to subsequent events, energy statistics, and duration—and classified by a random forest as a "click" or an "echo."

## Key Results
- Achieved 82.56% overall click detection accuracy and 95.93% click label accuracy on a 2m23s evaluation set (5,322 events).
- Outperformed key baselines: PAMGuard (39.7%), FOD-only (53.1%), and ANIMAL-SPOT (63.9%).
- Detected click rate showed a 98.01% Pearson correlation with ground truth annotations.
- Processing requires a real-time factor of ~25, indicating a significant computational burden.

## Why This Works (Mechanism)

### Mechanism 1: Multi-Representation Image Fusion
- **Claim:** Combining waveform, spectrogram, and continuous wavelet transform into a single RGB image improves click detection accuracy, especially in low SNR environments, by providing complementary temporal and spectral features for the YOLO network.
- **Mechanism:** Each 5 ms window is converted into three 960×960 grayscale images: waveform (red), CWT (green), and spectrogram (blue). These are stacked into an RGB SCWTSPEC image. YOLO processes the combined channels to predict bounding boxes.
- **Core assumption:** The three representations are complementary and not redundant; their fusion yields discriminative features that a CNN can exploit.
- **Evidence anchors:** Abstract and Section 4 detail the SCWTSPEC construction. The corpus includes related work using multiple representations for bioacoustics.
- **Break condition:** Omitting relevant high frequencies (>48 kHz) from CWT scales or using suboptimal spectrogram parameters degrades performance. Channel misalignment would also be detrimental.

### Mechanism 2: First-Order Gradient Refinement
- **Claim:** Applying a first-order gradient detector (FOD) within YOLO’s bounding boxes refines event boundaries and splits overlapping detections, producing more precise timestamps.
- **Mechanism:** For each YOLO box, compute the absolute first-order gradient of the contained audio, apply noise reduction via a moving average threshold, detect gradient peaks, and group nearby peaks to separate distinct events. New bounding boxes are defined around each peak cluster.
- **Core assumption:** Clicks and echoes are Dirac-like impulses with steep gradients detectable after local noise flooring.
- **Evidence anchors:** Abstract and Section 2.2 provide the mathematical formulation and noise reduction method.
- **Break condition:** In very low SNR, gradient peaks may fall below threshold. Extremely dense click trains (<2 ms apart) can lead to incorrect grouping (merged or split events).

### Mechanism 3: Contextual Random Forest Classification
- **Claim:** A random forest classifier that incorporates inter-arrival time and energy statistics, derived from the sequence of detected events, can reliably distinguish original clicks from echoes.
- **Mechanism:** After FOD yields candidate events, compute a feature vector (start/end times, confidence, length, number of FOD peaks, energy stats, dominant frequency, inter-arrival to next event). A random forest is trained on labeled data to classify each event as "click" or "echo."
- **Core assumption:** Temporal context (e.g., short inter-arrival times within a click burst) provides a discriminative pattern that isolated acoustic features lack.
- **Evidence anchors:** Abstract and Section 5.5 show 95.93% click label accuracy. Corpus emphasizes context-aware detection.
- **Break condition:** Solitary clicks or echoes with atypical inter-arrival times may be misclassified. Training data lacking diverse context patterns can cause overfitting.

## Architecture Onboarding
- **Component map:**  
  Raw audio (192 kHz) -> 5 ms (960-sample) windows -> SCWTSPEC image (waveform/CWT/spectrogram) -> YOLO model -> bounding boxes -> FOD (gradient peaks, grouping) -> refined event windows -> feature extraction (context metrics) -> random forest -> timestamps & labels (Audacity format).

- **Critical path:**  
  Audio segmentation -> image generation -> YOLO inference -> FOD refinement -> context classification -> output.

- **Design tradeoffs:**  
  - Window size: 5 ms captures most clicks but may include multiple events; shorter windows reduce sample count, limiting image quality.
  - Image channels: Adding CWT improves accuracy but increases memory/computation.
  - Confidence threshold: Lower values increase recall but add false positives; tuned to 30 for final accuracy focus.
  - FOD parameters: Moving average window adapts to local SNR but may need dataset-specific tuning.
  - Random forest context: Using future events adds slight latency but boosts accuracy.

- **Failure signatures:**  
  - YOLO misses low-SNR clicks or high-frequency (>48 kHz) clicks not captured by CWT scales.
  - FOD fails if gradient peaks are too weak or events are extremely dense (<2 ms apart).
  - Random forest misclassifies isolated clicks or echoes with ambiguous inter-arrival times.
  - Overall real-time factor ~25 prevents real-time deployment without optimization.

- **First 3 experiments:**  
  1. **PAMGuard baseline** (§5.1): Various dB thresholds; best accuracy 39.7% at 15 dB, indicating threshold methods are insufficient.
  2. **FOD only** (§5.2): 53.1% accuracy with 60.7% recall, showing gradient peaks are useful but noisy.
  3. **ANIMAL-SPOT** (§5.3): Best 63.9% with 4 ms windows, but windows still merged multiple events, demonstrating the need for frame-level detection (YOLO).

## Open Questions the Paper Calls Out
- **Question 1:** How can CLICK‑SPOT be optimized to achieve a real‑time processing factor of ≤1, enabling field deployment?
  - **Basis:** The author states the current implementation requires 25 minutes to process 1 minute of audio and calls for real‑time optimization.
  - **Why unresolved:** The high computational cost makes the tool unsuitable for on‑board or real‑time monitoring.
  - **Resolving evidence:** Applying model compression, reducing input resolution, or using hardware accelerators; benchmarking speed/accuracy trade‑offs on field hardware.

- **Question 2:** Can integrating temporal context via a recurrent architecture (e.g., RNN) into YOLO directly differentiate clicks from echoes, eliminating the separate random‑forest classifier?
  - **Basis:** The author speculates a recurrent YOLO could improve accuracy and directly differentiate.
  - **Why unresolved:** Baseline YOLO treats each 5 ms window independently, lacking burst‑pattern information.
  - **Resolving evidence:** Building a YOLO‑RNN hybrid, training on the original dataset, and comparing click/echo F1‑score against the existing pipeline.

- **Question 3:** To what extent does a CLICK‑SPOT model trained solely on killer‑whale data generalize to other odontocete species without retraining?
  - **Basis:** The author applied the killer‑whale model to other species' recordings with anecdotal, unlabeled results; notes adaptability via transfer learning but questions performance.
  - **Why unresolved:** Species‑specific click characteristics may cause missed detections/false positives; no quantitative cross‑species evaluation exists.
  - **Resolving evidence:** Obtaining annotated multi-species datasets, running the model with various thresholds, and measuring precision/recall/AUC to characterize transferability limits.

## Limitations
- **Generalization:** Validated on a single short dataset from one low-SNR environment. Performance on other species, habitats, or higher noise conditions is unknown, especially given the 48 kHz CWT scale limit.
- **Real-time feasibility:** A real-time factor of ~25x prevents large-scale deployment without significant optimization.
- **Component dependencies:** Reported gains rely on the synergistic combination of YOLO, FOD, and Random Forest. The isolated contribution of the SCWTSPEC image format in low-SNR conditions lacks direct ablation.

## Confidence
- **Claim Cluster 1 (SCWTSPEC image fusion improves low-SNR detection):** **Medium Confidence**. Final accuracy comparison supports it, but lacks a direct ablation showing performance with individual or pairwise channel combinations in controlled low-SNR tests.
- **Claim Cluster 2 (FOD refines event timing and splits overlaps):** **Medium Confidence**. Method is described and integrated, but failure modes in extremely dense trains or very low SNR are not stress-tested with dedicated experiments.
- **Claim Cluster 3 (Random forest with context reliably separates clicks from echoes):** **High Confidence**. The 95.93% click label accuracy on the evaluation set is strong direct evidence. The main limitation is potential misclassification on atypical temporal patterns, a known classifier generalization issue.

## Next Checks

2.  **FOD Stress Test on Synthetic Dense Trains:** Generate synthetic audio with simulated killer whale click bursts at varying inter-click intervals (e.g., 1.5 ms, 1.0 ms). Run the full pipeline and measure FOD's success rate in correctly splitting individual clicks versus merging them, across a range of SNRs.

Evaluate the random forest's classification accuracy on this set to probe its reliance on burst context and identify failure modes for solitary events.
