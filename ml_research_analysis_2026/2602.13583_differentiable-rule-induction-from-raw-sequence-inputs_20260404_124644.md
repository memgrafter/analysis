# Differentiable Rule Induction from Raw Sequence Inputs

## Quick Facts
- arXiv ID: 2602.13583
- Source URL: https://arxiv.org/abs/2602.13583
- Reference count: 13
- Primary result: NeurRL attains 0.891 mean accuracy on 13 UCR datasets, perfect rule recovery on synthetic data, and MNIST rule precision up to 0.99, while eliminating pre-trained networks and label leakage.

## Executive Summary
NeurRL is a fully differentiable pipeline that learns interpretable logic rules directly from raw sequential data, such as time series or images, without relying on pre-trained supervised networks or exposing representations to label leakage. It combines a self-supervised differentiable clustering module (autoencoder + differentiable k-means) that discretizes raw subsequences into symbolic patterns, with a differentiable rule learner that induces logical rules from fuzzy interpretation vectors. On synthetic data with known ground-truth patterns, NeurRL recovers perfect rules. Across 13 UCR time series benchmarks, it surpasses prior state-of-the-art in classification accuracy (mean 0.891 vs. 0.859) while also producing human-interpretable rules with high precision. On MNIST, the extracted rules highlight discriminative image regions with precision up to 0.99. The end-to-end differentiability eliminates the need for separate pre-training, shortens training time (e.g., 42s vs 3130s on the Coffee dataset), and provides quantitative interpretability.

## Method Summary
NeurRL processes raw sequences by first extracting overlapping fixed-length subsequences. Each subsequence is encoded by an autoencoder into a continuous embedding. A differentiable k-means module then assigns fuzzy cluster memberships over these embeddings, effectively mapping each subsequence to a set of symbolic pattern-region clusters. The sequence is divided into fixed spatial/temporal regions; cluster assignments within each region are aggregated into a region-cluster matrix, which is flattened into a fuzzy interpretation vector. This vector serves as input to a rule-learning module: a multi-layer neural network with modified ReLU activations and softmax weights that emulate logical conjunction and disjunction. The network computes a "program tensor" whose rows correspond to candidate rules; thresholding yields discrete Horn clauses. The entire pipeline is trained end-to-end with a combined loss: autoencoder reconstruction loss, clustering compactness loss (unsupervised), and classification cross-entropy loss (supervised). This joint optimization aligns the symbolic representations with the classification objective without explicit label leakage, while maintaining full differentiability.

## Key Results
- Perfect rule recovery on synthetic triangular pulse data (precision=1.0, recall=1.0).
- Mean classification accuracy of 0.891 on 13 UCR datasets (neural module), with extracted rules achieving 0.842, both outperforming prior SSSL (0.859).
- On MNIST, rule-based explanations highlight discriminative image regions with precision up to 0.99.
- Training time reduced significantly (e.g., 42s vs 3130s on the Coffee dataset) compared to pipelines using non-differentiable clustering and pre-trained networks.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim**: Self-supervised differentiable clustering discretizes raw subsequences into symbolic patterns and regions without requiring explicit label supervision, thereby avoiding label leakage.
- **Mechanism**: An autoencoder encodes each subsequence into an embedding; differentiable k-means then clusters these embeddings using a soft assignment (weight function G). The cluster assignments produce a fuzzy interpretation vector where each element corresponds to the likelihood that a subsequence belongs to a particular pattern-region cluster.
- **Core assumption**: Similar subsequences cluster together meaningfully, and the cluster index can serve as a symbolic predicate (pattern/region) that correlates with the target class.
- **Evidence anchors**:
  - Abstract: "Clustering discretizes raw subsequences into symbolic patterns and regions without labels"
  - Section 4.2: Describes the differentiable body symbolization function ˜Lb that maps raw sequence x to a fuzzy interpretation vector via clustering.
  - Corpus: The corpus includes differentiable k-means (Fard et al., 2020) but its application to ILP from raw data is novel; corpus evidence is weak for this specific integration.
- **Break condition**: Cluster collapse (all subsequences assigned to few clusters) or clusters that do not align with discriminative features; indicated by low rule precision/recall or uniform cluster distributions.

### Mechanism 2
- **Claim**: A differentiable rule-learning module induces interpretable logic rules from fuzzy interpretation vectors by emulating logical conjunction and disjunction via neural network layers.
- **Mechanism**: Input nodes receive fuzzy values of atoms; each dense layer uses a modified ReLU activation ReLU(x-d)/(1-d) and softmax-activated weights to represent weighted conjunctions. Multiplying softmax weights across layers yields a "program tensor" where high values indicate body atoms. The final disjunction layer aggregates rule bodies to predict the head atom.
- **Core assumption**: The neural network with specific activations can approximate the semantics of a logic program matrix (sum of weights normalized to 1), and fuzzy interpretations contain sufficient signal for rule induction.
- **Evidence anchors**:
  - Abstract: "differentiable rule learner"
  - Section 4.3: Details the forward computation and interpretation of the rule-learning module, including the program tensor extraction.
  - Section 3.1: Defines the logic program matrix representation and threshold function.
- **Break condition**: The network fails to converge to meaningful weights (e.g., all weights uniform) or extracted rules have low precision/recall; manifests as poor classification accuracy compared to neural module.

### Mechanism 3
- **Claim**: End-to-end differentiable training of clustering and rule-learning modules avoids explicit label leakage and improves efficiency by eliminating pre-trained supervised networks.
- **Mechanism**: A combined loss function (Eq. 9) jointly optimizes autoencoder reconstruction, clustering compactness (unsupervised), and rule-learning cross-entropy (supervised). Gradients flow through the differentiable k-means and rule learner, aligning symbolic representations with classification objectives.
- **Core assumption**: The losses are compatible and gradients do not conflict; the trade-off parameters (λ1, λ2) balance representation learning, clustering, and rule induction.
- **Evidence anchors**:
  - Abstract: "fully differentiable pipeline eliminates pre-trained supervised networks"
  - Section 4.3: Presents the target function and loss components.
  - Section 5.2: Table 2 shows improved running time with differentiable pipeline vs non-differentiable k-means.
- **Break condition**: Conflicting gradients cause one module to dominate (e.g., clustering loss minimized but rule quality poor); indicated by high autoencoder loss but low rule precision, or training instability.

## Foundational Learning
- **Concept**: Inductive Logic Programming (ILP)  
  - **Why needed here**: NeurRL learns logic programs from data; understanding ILP’s learning-from-interpretation-transitions setting and logic program representations (e.g., matrix form) is essential to grasp the rule extraction process.  
  - **Quick check question**: How does the immediate consequence operator `T_P` relate to the logic program matrix `M_P` and the differentiable approximation `DP`?

- **Concept**: Differentiable Clustering (e.g., differentiable k-means)  
  - **Why needed here**: Clustering provides the symbolic discretization; differentiability allows gradient flow from rule learner back to embeddings.  
  - **Quick check question**: What is the role of the weight function `G` in making the minimum operation differentiable, and how does it affect cluster assignments?

- **Concept**: Fuzzy Interpretation Vectors  
  - **Why needed here**: They bridge continuous raw inputs and discrete symbolic atoms; the rule learner operates on these vectors.  
  - **Quick check question**: How is the fuzzy interpretation vector `v_I` constructed from the region cluster matrix `c_p`, and why is flattening necessary?

## Architecture Onboarding
- **Component map**:  
  Raw sequence -> Subsequence extractor -> Autoencoder (encoder) -> Differentiable k-means (fuzzy cluster assignments) -> Region mapper (aggregation per region) -> Fuzzy interpreter (flatten to v_I) -> Rule learner (multi-layer dense network) -> Prediction.

- **Critical path**:  
  Subsequence extraction → embedding via encoder → fuzzy cluster membership → region-wise aggregation → interpretation vector → rule learner → class probability. The training loop jointly optimizes reconstruction, clustering, and classification losses.

- **Design tradeoffs**:
  - Differentiable vs. non-differentiable clustering: Differentiability enables end-to-end training but may sacrifice cluster purity; non-differentiable yields sharper assignments but breaks gradient flow.
  - Number of clusters K: Larger K enlarges the atom space and rule expressivity but risks overfitting and cluster collapse.
  - Subsequence length l: Must match the temporal granularity of discriminative patterns; too short loses context, too long dilutes signal.
  - Region count R: Balances spatial/temporal resolution; too many regions fragments patterns, too few merges distinct locations.

- **Failure signatures**:
  - Cluster collapse: most subsequences assigned to one or few clusters (check cluster distribution entropy).
  - Rule degradation: neural accuracy (NeurRL(N)) >> rule accuracy (NeurRL(R)) or low precision/recall on extracted rules.
  - Training instability: loss components oscillate or diverge, indicating gradient conflicts.
  - Poor interpretability: extracted rules are excessively long or highlight irrelevant subsequences (low sparsity).

- **First 3 experiments**:
  1. Synthetic data sanity check: Use simple triangular pulse patterns with known ground-truth rules; verify perfect precision/recall (Sec. 5.1).
  2. Ablation on pre-training: Compare models with and without autoencoder pre-training (random cluster init) to demonstrate pre-training’s role in preventing cluster collapse (Appendix A).
  3. Hyperparameter sensitivity: Vary K, R, and l on a small UCR dataset (e.g., ECG) to identify robust ranges and failure modes (Fig. 5).

## Open Questions the Paper Calls Out
### Open Question 1
How can NeurRL be extended to handle variable-length inputs using logical variables that represent entire sequences, rather than fixed-length subsequences, while still avoiding explicit label leakage?  
*Basis*: The conclusion states: "Future goals include variables representing entire inputs to explain handwritten digits without label leakage (Evans et al., 2021)."  
*Why unresolved*: The current method relies on fixed-length subsequences and predefined regions, limiting flexibility to capture patterns at arbitrary positions and scales. Introducing variables that range over full inputs requires a more expressive symbolic representation and may risk reintroducing label leakage if not carefully designed.  
*What evidence would resolve it*: A new architecture that integrates a differentiable mechanism for binding variables to subsequences of varying lengths, demonstrated on tasks like MNIST with variable-sized digits or variable-length time series, showing no label leakage and improved interpretability.

### Open Question 2
How can NeurRL be adapted to learn from incomplete data, such as time series with missing values or images with occlusions, without compromising rule quality or interpretability?  
*Basis*: The conclusion notes: "Another focus is learning from incomplete data (e.g., healthcare applications) to address real-world challenges."  
*Why unresolved*: The pipeline assumes fully observed sequences; the autoencoder and clustering modules expect complete inputs. Missing data could distort embeddings and cluster assignments, leading to spurious rules.  
*What evidence would resolve it*: Extensions to the autoencoder (e.g., masking, imputation) and clustering that robustly handle missing values, evaluated on synthetic and real-world incomplete datasets, with rules that remain accurate and interpretable.

### Open Question 3
How can the hyperparameters of NeurRL (number of clusters K, number of regions R, subsequence length l) be automatically determined to adapt to diverse datasets without manual tuning?  
*Basis*: Inferred from the ablation study (Section 5.4) showing accuracy sensitivity and manual per-dataset settings (e.g., K=5 for UCR, regions≈10). No automatic selection method is proposed.  
*Why unresolved*: Manual tuning is burdensome and may not generalize; inappropriate hyperparameters can lead to poor rule quality or cluster collapse. There is no theoretical guidance or data-driven method to choose them.  
*What evidence would resolve it*: A validation procedure or meta-learning approach that selects hyperparameters based on data characteristics, tested across a wide range of datasets, showing consistent performance close to manually tuned results.

### Open Question 4
Does the joint training of the autoencoder and rule learner introduce indirect label leakage, where the autoencoder embeddings become specialized to the target class, thereby undermining the claim of learning from raw data without explicit label supervision?  
*Basis*: Inferred because the loss function includes the rule learning loss λ₂ f₂(NR(˜Lb(x);γₗ), y), which depends on the clustering output that uses the autoencoder embeddings h_{γₑ}(s). Thus, gradients from the supervised loss may influence the autoencoder, potentially causing it to encode label information.  
*Why unresolved*: The paper asserts avoidance of explicit label leakage, but the optimization loop connects the unsupervised components to the supervised loss. It is unclear whether the resulting embeddings retain only task-agnostic features or also label-related ones, which could affect interpretability and generality.  
*What evidence would resolve it*: Analysis of the learned embeddings (e.g., using linear probes or mutual information) to quantify label-related information; experiments where the autoencoder is frozen after pre-training to isolate its effect; comparisons of rule quality and interpretability under different training regimes.

### Open Question 5
Can NeurRL learn richer logical rule structures, such as disjunctions in rule bodies, recursive rules, or rules with multiple head atoms, to capture more complex patterns in data?  
*Basis*: Inferred because the current rule format is restricted to conjunctions of pattern-region atoms with a single head atom (Eq. 4). The differentiable rule-learning module uses a disjunction only at the final layer to combine conjunctions, but does not support disjunctions within rule bodies or recursion, which are common in ILP.  
*Why unresolved*: The design of the neural network rule learner (dense layers with specific activation) inherently limits the expressivity to monotone DNF-like formulas. While sufficient for the evaluated tasks, many real-world concepts require more expressive logics.  
*What evidence would resolve it*: Extensions to the architecture that allow disjunctive bodies (e.g., using multiple paths or attention) or recursive definitions, validated on datasets requiring such structures, with evaluation of both accuracy and interpretability.

## Limitations
- Missing critical hyperparameters (cluster count K, region count R, subsequence length l, network architectures, learning rates, optimizers) for UCR/MNIST experiments, hindering exact replication.
- Potential cluster collapse without proper autoencoder pre-training; the unsupervised symbolization may degrade, producing trivial fuzzy interpretation vectors.
- Rule extraction depends on a threshold τ with no guidance; rule sparsity and interpretability are not formally quantified, and the trade-off between neural accuracy and rule fidelity is not well understood.

## Confidence
- Self-supervised clustering yields meaningful symbolic patterns: **Medium** (evidence from synthetic results but no standalone clustering metric).
- Differentiable rule learner induces interpretable rules: **Medium** (quality hinges on clustering; τ sensitivity unaddressed).
- End-to-end training avoids label leakage & improves efficiency: **Medium** (runtime comparison exists, leakage claim indirect).
- Perfect synthetic rules: **High** (controlled setting, clear results).
- UCR accuracy superiority: **Medium** (results promising but missing specifics impede verification).
- MNIST interpretability (precision up to 0.99): **Medium** (no human evaluation or robustness checks).
