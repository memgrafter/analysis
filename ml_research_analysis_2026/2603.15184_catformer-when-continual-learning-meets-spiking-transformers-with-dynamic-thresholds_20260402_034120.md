# CATFormer: When Continual Learning Meets Spiking Transformers With Dynamic Thresholds

## Quick Facts
- **arXiv ID:** 2603.15184
- **Source URL:** https://arxiv.org/abs/2603.15184
- **Reference count:** 40
- **Primary result:** CATFormer achieves state-of-the-art class-incremental learning in spiking networks by freezing the backbone and modulating task-specific firing thresholds, showing a "reverse forgetting" trend where accuracy improves with more tasks (e.g., 68.33% to 75.66% on Split CIFAR-100 from 10 to 50 tasks) using minimal memory (~64.2 KB per task).

## Executive Summary
CATFormer addresses catastrophic forgetting in spiking neural networks (SNNs) for class-incential learning (CIL) through a radical departure from weight-based adaptation. After a two-stage training protocol, it completely freezes the SpikFormer backbone and instead learns per-task firing thresholds for its neurons. A lightweight gating network enables task-agnostic inference by predicting the appropriate task-specific thresholds and classification head. This approach yields state-of-the-art accuracy on both static and neuromorphic datasets while drastically reducing memory overhead compared to rehearsal-based methods. Notably, it exhibits a "reverse forgetting" phenomenon where performance improves as more tasks are added, a counterintuitive trend not observed in prior work.

## Method Summary
CATFormer employs a two-stage training protocol. In Stage 1, the SpikFormer backbone (weights θ), initial thresholds ϕ^(0), and the first classification head (W₀) are jointly trained on the first task. For all subsequent tasks (k > 0), the backbone θ is permanently frozen. Only a new classification head Wₖ and a new set of task-specific thresholds ϕ^(k) for the Dynamic Threshold Leaky Integrate-and-Fire (DTLIF) neurons are trained on the current task's data. The DTLIF neurons modulate spiking dynamics via these thresholds without altering synaptic weights. A separate two-layer gating MLP (G) is trained incrementally on features extracted with the base threshold ϕ_init from all seen tasks to predict the task ID during inference. At test time, an input undergoes two forward passes: first with ϕ_init to extract base features for the gating network, and second with the selected ϕ^(k*) and corresponding head Wₖ* to produce the final classification.

## Key Results
- **SOTA Performance:** Outperforms prior SNN-based CIL methods on CIFAR-10/100, Tiny-ImageNet, CIFAR10-DVS, and SHD datasets, while matching rehearsal-based ANN performance with far fewer stored parameters.
- **Reverse Forgetting Trend:** On Split CIFAR-100, average accuracy increases from 68.33% (10 tasks) to 75.66% (50 tasks), while competing methods degrade.
- **Memory Efficiency:** Stores only ~64.2 KB per task (thresholds and classifier), avoiding expensive raw data exemplars.

## Why This Works (Mechanism)

### Mechanism 1: Frozen Backbone with Threshold Modulation
- **Claim:** Task-specific, learnable firing thresholds in the Dynamic Threshold Leaky Integrate-and-Fire (DTLIF) neuron are the primary mechanism for preventing catastrophic forgetting in a frozen backbone.
- **Mechanism:** After initial task training, the SpikFormer's synaptic weights (θ) are frozen. For new tasks, only per-channel threshold parameters ϕ^(k) for DTLIF neurons are trained via gradient descent. This modulates neuronal excitability on a per-task basis, allowing the same fixed weights to produce different spiking patterns appropriate for each task's input distribution without overwriting previous weight-based knowledge.
- **Core assumption:** The fixed weight matrix encodes sufficient general features; task-specificity can be achieved solely by adjusting the neuronal firing threshold (excitability), not by altering synaptic strengths.
- **Evidence anchors:** [abstract] "frozen backbone learns via task-specific threshold modulation." [section 3.2] "During training on task k, the threshold ϕ(k) is updated via gradient descent... This mechanism allows each channel to adjust its firing threshold for different tasks." Ablation: Fixed thresholds cause ~26% accuracy drop on Split CIFAR-10 (5 tasks).
- **Break condition:** If thresholds are fixed across all tasks, catastrophic forgetting occurs.

### Mechanism 2: Gated Dynamic Head Selection (G-DHS)
- **Claim:** The Gated Dynamic Head Selection (G-DHS) mechanism enables task-agnostic inference by predicting the current task ID and routing to the correct task-specific classification head and threshold set.
- **Mechanism:** A lightweight, trainable gating MLP processes features extracted with the base thresholds (ϕ_init). It outputs a task probability distribution. The predicted task ID selects both the corresponding classification head (Wₖ) and the task-specific threshold set (ϕ^(k)). The input is then re-processed through the backbone using the selected thresholds to generate the final task-specific features for classification.
- **Core assumption:** A small gating network can reliably infer task context from the base feature representation, and this inference is separable from the main classification path.
- **Evidence anchors:** [abstract] "paired with a Gated Dynamic Head Selection (G-DHS) mechanism for task-agnostic inference." [section 3.4] describes the two-pass inference process (Algorithm 2).
- **Break condition:** Gating misprediction applies incorrect thresholds/heads, degrading accuracy. Relies on buffer `F_gate` for training; data scarcity for older tasks could impair gating.

### Mechanism 3: Two-Stage Training Protocol
- **Claim:** The two-stage training protocol (joint training on task 0, followed by frozen backbone training with only heads and thresholds for new tasks) is the critical orchestration that makes the threshold-modulation mechanism viable and scalable.
- **Mechanism:** Stage 1: Train backbone θ, thresholds ϕ^(0), and head W₀ jointly. This establishes a robust, general feature extractor and an initial set of thresholds. Stage 2 (for k>0): Freeze θ completely. For each new task k, initialize a new head Wₖ and a new set of thresholds ϕ^(k). Only {Wₖ, ϕ^(k)} are optimized on the new task's data. The frozen backbone provides a stable feature space; the new thresholds "reprogram" its spiking dynamics for the new classes. The gating network G is trained incrementally on all accumulated base features.
- **Core assumption:** A single, well-trained backbone (from Stage 1) is a sufficiently rich and stable foundation for all future tasks; further weight changes would destabilize past knowledge.
- **Evidence anchors:** [abstract] "a two-stage training protocol." [section 3.1 & Algorithm 1] explicitly defines the protocol (lines 5-10).
- **Break condition:** Updating the frozen backbone parameters for any task after k=0 would violate the core premise, leading to weight-based interference and forgetting.

## Architecture Onboarding
- **Component map:** SpikFormer Backbone (θ, frozen after task 0) contains DTLIF Neurons (with base ϕ_init and task-specific ϕ^(k)). For each task k, a Task-Specific Head (Wₖ) is added. A Gating MLP (G) is trained on features from all tasks (extracted with ϕ_init) to predict task ID. Buffers (F_gate, L_gate) store these feature-label pairs.
- **Critical path:** Inference: Input x -> Pass 1 (ϕ_init) -> f_base(x) -> G(f_base) -> predict task k* -> Pass 2 (ϕ^(k*)) -> fₖ*(x) -> Wₖ*(fₖ*) -> class. Training (task k>0): Input (x,y) -> Pass with ϕ^(k) -> loss with Wₖ -> optimize {ϕ^(k), Wₖ} (θ and G frozen).
- **Design tradeoffs:** Memory vs. Rehearsal: Avoids storing raw data exemplars (~64.2 KB/task vs. ~MBs for images) but requires storing ϕ^(k), Wₖ, and managing F_gate buffer. Plasticity vs. Stability: High stability (no backbone updates) but limited plasticity to threshold/head space; may fail for fundamentally new distributions. Inference Cost: Requires two full backbone forward passes, doubling compute.
- **Failure signatures:** 1) "Fixed Threshold" ablation: steady accuracy decay. 2) Gating confusion: misrouting applies wrong thresholds/heads. 3) Backbone drift: accidental gradient flow into θ during k>0 training causes rapid forgetting.
- **First 3 experiments:** 1) Ablate dynamic thresholds (use fixed LIF); expect severe forgetting (>15% drop on Split CIFAR-10 5-task). 2) Remove gating (oracle task ID); isolates threshold mechanism's power from gating errors. 3) Scale tasks on Split CIFAR-100 (10, 25, 50); validate "reverse forgetting" trend; if accuracy plateaus/drops at high counts, indicates saturation.

## Open Questions the Paper Calls Out
- **Open Question 1:** What explains the "reverse forgetting" trend where CATFormer's accuracy improves with more tasks? The paper reports gains from 68.33% (10 tasks) to 75.66% (50 tasks) on Split CIFAR-100 but does not analyze causality. The role of dynamic thresholds and gating lacks empirical disentanglement or theoretical justification; it is unknown if the trend continues beyond 100 tasks. Resolving evidence: Ablation separating threshold adaptation and gating; track threshold distributions across tasks; evaluate on >100-task sequences; develop a formal model linking thresholds to interference reduction.
- **Open Question 2:** Can the dynamic thresholds and gating mechanisms be efficiently deployed on neuromorphic hardware like Loihi 2? The discussion states hardware implementation should be investigated but current results are software simulations. Real hardware introduces constraints (limited precision, neuron model mismatches) that may affect energy benefits and accuracy. Resolving evidence: Port the model to Loihi 2 using native LIF neurons; measure energy, latency, spike rates; compare against simulated results and other SNN CIL methods.
- **Open Question 3:** Does the dynamic threshold mechanism generalize to other SNN architectures, such as convolutional spiking networks? CATFormer is exclusively evaluated with a SpikFormer backbone; applicability to other architectures is untested. Benefits might rely on transformer-specific properties and could fail in CNNs, limiting applicability. Resolving evidence: Implement DTLIF in a CNN-based SNN (e.g., spiking ResNet) on same CIL benchmarks; benchmark against prior SNN CIL methods; analyze performance across task sequences.

## Limitations
- Missing critical implementation details (hyperparameters, exact architecture dimensions) hinder faithful reproduction.
- Gating network performance is untested; no reported accuracy metrics for task ID prediction, leaving a key failure point unexamined.
- The "reverse forgetting" phenomenon is counterintuitive and lacks theoretical justification; its generalizability is uncertain.
- Buffer management for gating training (size, replay policy) is unspecified, potentially affecting memory claims.

## Confidence
- **DTLIF threshold modulation:** Medium. Supported by strong ablations (~26% drop with fixed thresholds), but theoretical assumptions about frozen weight generality are unproven.
- **G-DHS inference:** Medium-Low. Core to task-agnostic operation, yet absence of gating accuracy data leaves a key failure point unexamined.
- **Two-stage protocol:** Medium. Logically coherent, but sensitivity to Stage 1 backbone quality is not stress-tested; no ablation on joint vs. staged training.
