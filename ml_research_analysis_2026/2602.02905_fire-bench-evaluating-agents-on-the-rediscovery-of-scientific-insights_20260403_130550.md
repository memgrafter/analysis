# FIRE-Bench: Evaluating Agents on the Rediscovery of Scientific Insights
## Quick Facts
- arXiv ID: 2602.02905
- Source URL: https://arxiv.org/abs/2602.02905
- Reference count: 40
- Primary result: Best average F1 score of 46.7% with frontier models (gpt-5-medium), high run-to-run variance, and dominant failures in research planning and conclusion formation.

## Executive Summary
FIRE-Bench addresses the evaluation of autonomous AI research agents by tasking them with rediscovering non-trivial empirical findings from recent, high-impact machine learning papers. Given only a high-level research question, agents must independently design experiments, implement code, execute, and derive conclusions. The benchmark uses automated claim-level entailment against ground-truth findings to compute precision, recall, and F1, avoiding subjective LLM-as-judge assessments. Results with frontier models show limited success (best F1 46.7%) and high variance. Error analysis reveals that current agents struggle most with research planning (method deviation) and conclusion formation (analysis failure), with minimal evidence of creative discovery or data contamination.

## Method Summary
FIRE-Bench constructs 30 tasks by parsing source papers into hierarchical research-problem trees and selecting parent nodes of key figures/tables as prompts. Agents operate autonomously with shell and file-operation tools to design and run experiments on provided datasets. Conclusions are decomposed into atomic claims using an LLM extractor; entailment against ground-truth claims is performed by a frozen judge model (gpt-5.2) to compute claim-level precision, recall, and F1. Each task is run three times per agent. Reproduction requires setting up agent frameworks, a GPU sandbox, and API access; then executing agents on task prompts and evaluating outputs with the provided claim extraction and entailment scripts.

## Key Results
- Best average F1 score: 46.7% (gpt-5-medium), with high run-to-run variance.
- Dominant errors: Research Planning (Method Deviation) and Conclusion Formation (Analysis Failure).
- False-positive claims are mostly contradictory or unrelated, indicating minimal creative discovery.
- No strong evidence of data contamination across difficulty strata or cutoff dates.

## Why This Works (Mechanism)
**Mechanism 1: Constrained Rediscovery Formulation**  
FIRE-Bench balances open-ended exploration with verifiable evaluation by giving agents only a high-level research question while withholding experimental details. This forces independent experiment design to recover established findings. Tasks are created by selecting the parent node of a key figure/table in a hierarchical research-problem tree from the source paper. The core assumption is that rediscovering known insights under constraints is a valid proxy for scientific reasoning. Evidence: Section 3.1 describes task construction; neighbor benchmarks (InsightEval, CycleResearcher) similarly seek diagnostic evaluation.

**Mechanism 2: Automated Claim-Level Evaluation**  
Atomic claim decomposition and entailment scoring provide scalable, objective assessment. Both agent output and ground truth are split into atomic claims (quantitative, directional, comparative assertions). A fixed judge model (gpt-5.2) performs entailment, yielding precision, recall, F1. Human validation on 33% of reference instances shows high agreement (F1=0.89). Evidence: Abstract and Section 3.3 detail the process; Section 3.3 reports human validation metrics.

**Mechanism 3: Fine-Grained Error Analysis**  
A diagnostic framework attributes false positives/negatives to 16 sub-types across four stages (Research Planning, Implementation, Execution, Conclusion Formation). Hybrid LLM-assisted and human-verified procedure applied to trajectories reveals failures dominated by deficiencies in Research Planning and Conclusion Formation. Evidence: Section 5.2 reports error distributions and dominant failure types; related work emphasizes process-level diagnostics.

## Foundational Learning
- **Constrained Open-Ended Task Design**: Needed to understand how FIRE-Bench transforms a paper into a research question without revealing methods, testing genuine reasoning over replication. Quick check: How does selecting the parent node create a constrained yet open-ended task requiring independent experiment design?
- **Claim-Level Evaluation Paradigm**: Central to objective, scalable assessment; defines success metrics and distinguishes from other benchmarks. Quick check: What are the steps in claim-level transformation and why does this improve reliability over LLM-as-judge?
- **Error Taxonomy for Agent Workflows**: Provides common language for diagnosing failures; categories like Method Deviation, Analysis Failure are key for debugging. Quick check: What are the four pipeline stages and three most frequent error types? (Answer: Research Planning → Method Deviation; Conclusion Formation → Analysis Failure; Implementation → Unsound Implementation.)

## Architecture Onboarding
Task Interpreter -> Research Planner -> Code Generator -> Execution Engine -> Result Analyzer -> Conclusion Synthesizer -> Logger.  
Critical path: Task Interpreter → Research Planner → Code Generator → Execution Engine → Result Analyzer → Conclusion Synthesizer. Any failure yields invalid conclusions; Execution Engine must handle environment setup autonomously.  
Design tradeoffs: Exploration depth vs. budget (hard API call limit); Generality vs. specialization (diverse tasks require broad capabilities); Autonomy vs. robustness (cascading errors); Cost vs. performance (stronger LLMs yield higher F1 but higher cost).  
Failure signatures:  
- Research Planning: Method Deviation, Goal Deviation  
- Implementation: Unsound Implementation  
- Execution: Laziness, Endless Loop, Premature Termination, Environment Setup Errors  
- Conclusion: Analysis Failure, Overgeneralized Conclusion  
- System: API rate limits, timeouts, sandbox crashes.  
First 3 experiments:  
1. Sanity check on "Lost in the Middle" (task 2): expect F1 > 70; validates plan varies position and analysis interprets trend.  
2. Test experimental design on "Persona with Catch" (task 29): expect F1 50–80 (best 88.6); monitor for Method Deviation.  
3. Stress test conclusion formation on "LLM Racial Bias in Medicine" (task 1): expect F1 < 30; inspect error attribution for Research Planning and Conclusion Formation failures.

## Open Questions the Paper Calls Out
1. How can benchmarks evaluate the full research process rather than just final claims? Basis: explicit call for process-level evaluation. Why unresolved: current benchmarks don't capture step-by-step reasoning. Evidence needed: automatic scoring rubrics validated by expert correlation.
2. How can we reduce method and goal deviation in agents' experimental planning, especially for control-based tasks? Basis: error analysis shows Research Planning failures dominate. Why unresolved: agents omit controls or stray from question. Evidence needed: causal reasoning module or explicit control generation reduces deviation in ablations.
3. How can we guarantee that rediscovery benchmarks are not vulnerable to data contamination? Basis: contamination analysis is coarse; authors call for stronger defenses. Why unresolved: limited samples and unknown training data risk memorization. Evidence needed: large-scale benchmark with temporally held-out papers or adversarial tasks showing stable performance gaps.

## Limitations
- Benchmark data (tasks, datasets, ground-truth claims) availability is uncertain; reproduction depends on authors.
- Evaluation relies on proprietary gpt-5.2 judge; scores may not generalize with substitutes.
- Exact system prompts and configurations for proprietary agents are undisclosed, hindering exact replication.

## Confidence
- Rediscovery as proxy validity: Medium (supported by task design and human validation, but assumes rediscovery equals reasoning without testing novelty)
- Claim-level evaluation reliability: Medium-High (human-validated claim extraction, fixed judge, but judge bias risk)
- Error analysis diagnostic utility: Medium (hybrid attribution adds rigor, but may miss higher-level strategic failures, consistency unclear)
