# Learning Without Training

## Quick Facts
- arXiv ID: 2602.17985
- Source URL: https://arxiv.org/abs/2602.17985
- Reference count: 0
- Primary result: Introduces mathematically grounded kernel methods for manifold learning, transfer learning, and classification, accompanied by theoretical guarantees and an active algorithm (MASC) that outperforms LAND/LEND on hyperspectral data.

## Executive Summary
The dissertation presents three interconnected contributions to machine learning without training. First, a supervised learning method for unknown compact manifolds uses a localized spectral kernel to directly approximate the target function, achieving an error decay of \(O(n^{-\gamma})\) with sample complexity \(M \gtrsim n^{q+2\gamma} \log n\) under smoothness assumptions. Second, transfer learning is formalized via joint data spaces, where a function defined on a base space lifts to a target space using a kernel adapted to a joint distance; the lifted function’s smoothness is bounded by the base smoothness and joint exponents. Third, classification is addressed as a support estimation problem: a signal separation approach estimates the supports of class-specific measures using a localized kernel density estimator. Under detectability and fine structure of the mixture measure, the estimator’s support covers the true union and, with fine structure, splits into well-separated components that asymptotically recover each class (F-score → 1). An active multiscale algorithm (MASC) exploits this structure, querying very few points while maintaining competitive accuracy and faster runtimes compared to LAND/LEND on hyperspectral data.

## Method Summary
The three methods share a common ingredient: localized spectral kernels constructed from smooth filters and orthonormal polynomial bases. For manifold learning, data are projected onto a sphere of intrinsic dimension \(q\), and a univariate kernel \(\Phi_{n,q}(t)\) built from ultraspherical polynomials is applied directly to the dot products. For transfer learning, two data spaces are linked via a joint distance, and a joint kernel with connection coefficients lifts functions from the base to the target. For classification, a squared kernel \(\Psi_n = \Phi_n^2\) yields a density estimator whose level sets approximate the union of class supports; MASC then uses graph-based multiscale analysis to isolate components and actively query informative points.

## Key Results
- **Manifold learning:** Uniform error bound \(\|F_n - f f_0\|_\infty \lesssim n^{-\gamma}\) with \(M \gtrsim n^{q+2\gamma} \log n\) samples.
- **Transfer learning:** The lifting operator \(\sigma_n\) converges uniformly on a tubular set \(B\); the lifted function belongs to \(W^{\gamma - Q + q_2}(\Xi_1)\) under smoothness and joint regularity conditions.
- **Classification:** Under detectability and fine structure, \(X \subseteq G_n(\Theta) \subseteq B(X, r(\Theta)/n)\) with \(r(\Theta) \propto \Theta^{-1/(S-\alpha)}\); components of \(G_n(\Theta)\) separate and asymptotically recover true class supports (F-score → 1); MASC achieves high accuracy with orders-of-magnitude fewer queries than LAND/LEND on hyperspectral benchmarks.

## Why This Works (Mechanism)

### Mechanism 1 (Supervised learning on unknown manifolds)
- **Claim:** The method approximates an unknown target function on an unknown compact manifold directly from data, using a localized spectral kernel without manifold estimation; the uniform error decays as \(O(n^{-\gamma})\) with sample complexity \(M \gtrsim n^{q+2\gamma} \log n\), where \(q\) is the intrinsic dimension and \(\gamma\) reflects smoothness.
- **Mechanism:** Data points (if not already) are projected onto a sphere \(S^Q\) of the same intrinsic dimension. A smooth filter \(h\) constructs a univariate localized kernel \(\Phi_{n,q}(t) = \sum_{\ell=0}^n h(\ell/n)\,p_{q,\ell}(1)\,p_{q,\ell}(t)\) where \(p_{q,\ell}\) are ultraspherical polynomials. At a test point \(x\), the estimate is \(F_n(x) = \frac{1}{M}\sum_{j=1}^M z_j\,\Phi_{n,q}(x\cdot y_j)\). The localization property \(|\Phi_{n,q}(\cos\rho)| \leq C n^q/(1+n\rho)^S\) ensures only points with small geodesic distance \(\rho\) contribute. The error analysis uses an integral operator \(\sigma_n\), splits the manifold into small balls (connected via the exponential map to tangent spheres) and large ball contributions (controlled by the localization bound). Concentration inequalities yield high-probability bounds.
- **Core assumption:**
  1. The data domain \(X\) is a compact, smooth, \(q\)-dimensional submanifold of \(S^Q\) (or of \(\mathbb{R}^{Q+1}\) via a bi‑Lipschitz projection).
  2. The target function \(f\) and the density \(f_0\) of the marginal measure (with respect to Riemannian volume \(\mu^*\)) belong to the smoothness class \(W^\gamma(X)\) and satisfy the ball measure condition \(\mu^*(B(x,r)) \lesssim r^q\).
  3. The intrinsic dimension \(q\) is known (or can be tuned as a hyperparameter).
  4. The filter \(h\) is \(C^\infty\), supported in \([0,1]\), and the exponent \(S > q\) in the localization bound.
- **Evidence anchors:**
  - [abstract] “supervised learning on unknown compact manifolds, a localized spectral kernel directly approximates the target function without manifold estimation; the error decays as \(O(n^{-\gamma})\) with \(M \gtrsim n^{q+2\gamma} \log n\) samples, depending on intrinsic dimension \(q\) and smoothness \(\gamma\).”
  - [section] Section 2.5 Theorem 2.5.1 gives the uniform bound: for \(M \gtrsim n^{q+2\gamma} \log(n/\delta)\), with probability at least \(1-\delta\), \(\|F_n - f f_0\|_{X,\infty} \lesssim ( \|f_0\|_{X}\|z\| + \|f f_0\|_{W^\gamma} ) n^{-\gamma}\). The proof (Section 2.7) uses the local exponential map and Lemma 2.7.1.
  - [corpus] Weak – the corpus contains manifold learning methods (e.g., LAND [74]) that explicitly estimate the manifold; the present mechanism avoids that step, which is a key novelty.
- **Break condition:**
  - The intrinsic dimension \(q\) is mis‑specified → approximation degrades.
  - \(f\) or \(f_0\) not smooth enough → rate slower than \(n^{-\gamma}\) or bound invalid.
  - The manifold has boundary or fails the ball measure condition (2.5.3) → integral estimates fail.
  - Sample size \(M\) below \(n^{q+2\gamma} \log n\) → high‑probability guarantee lost; empirical \(F_n\) noisy.
  - The filter \(h\) not sufficiently smooth → weaker localization → larger errors.
  - Projection to sphere not bi‑Lipschitz (e.g., points with large ambient distance map close on sphere) → localization no longer correlates with geodesic distance.

### Mechanism 2 (Local transfer learning via joint data spaces)
- **Claim:** A function defined on a base data space can be lifted to a target space using a joint kernel adapted to a joint distance; the lifted function’s smoothness on a subset \(B\) of the target is bounded by the base smoothness and the exponents of the joint spaces.
- **Mechanism:** Two data spaces \(\Xi_1\) (target), \(\Xi_2\) (base) are equipped with orthonormal eigenbases \(\{\phi_{j}\}\), eigenvalues \(\{\lambda_j\}\), and a joint distance \(d_{1,2}\) that satisfies a generalized triangle inequality. They form a *joint data space* with connection coefficients \(A_{j,k}\) and joint eigenvalues \(\ell_{j,k}\). The joint kernel is \(\Phi_n(H,\Xi_1,\Xi_2;x_1,x_2) = \sum_{j,k} H(\ell_{j,k}/n) A_{j,k} \phi_{1,j}(x_1)\phi_{2,k}(x_2)\). The lifting operator is \(\sigma_n(\Xi_1,\Xi_2;f)(x_1) = \int_{\Xi_2} f(x_2)\,\Phi_n(...)\, d\mu_2(x_2)\). Under a joint Gaussian upper bound and a polynomial preservation condition, \(\sigma_n\) converges uniformly on a set \(B = I(r,s;A)\) (the image of a compact \(A \subset \Xi_2\)) to a limit \(E(f)\). Moreover, if \(f \in W^\gamma(\Xi_2;A)\) and \(\Xi_1\) satisfies the strong product assumption, then \(\phi E(f) \in W^{\gamma-Q+q_2}(\Xi_1)\) for any \(\phi \in C^\infty(B)\).
- **Core assumption:**
  1. \(\Xi_1,\Xi_2\) are compact data spaces (Definition 3.2.1) with exponents \(q_1,q_2\) and Gaussian upper bounds.
  2. The tuple \((\Xi_1,\Xi_2,d_{1,2},A,L)\) is a joint data space (Definition 3.3.3) satisfying joint regularity, variation bound, and the joint Gaussian upper bound \(\|K_t\| \leq c_1 t^{-Q}e^{-c_2 d_{1,2}^2/t}\).
  3. Polynomial preservation condition (Definition 3.3.4): there exists \(c^*\) such that if \(P_n \in \Pi_n(\Xi_2)\) then \(\sigma_m(\Xi_1,\Xi_2;P_n) = P_{c^*n}(\Xi_1)\) for all \(m \ge c^*n\).
  4. Partition of unity holds on \(\Xi_2\) (and on \(\Xi_1\) for the smoothness result). For the smoothness transfer \(\Xi_1\) additionally satisfies the strong product assumption (Definition 3.2.4).
  5. \(f \in W^\gamma(\Xi_2;A)\) for a compact \(A \subset \Xi_2\) with a positive distance to the complement such that the set \(B^-\) from (3.4.2) is nonempty.
  6. There exists \(\alpha > 0\) with \(\alpha \ell_{j,k} \ge \lambda_{1,j}\) (ensures target smoothness transfer).
- **Evidence anchors:**
  - [abstract] “Transfer learning is formalized via joint data spaces: a function on a base space lifts to a target space using kernels adapted to a joint distance, with the lifted function’s smoothness bounded by the base smoothness and joint exponents.”
  - [section] Section 3.4 Theorem 3.4.1: (a) existence of \(E(f)\) on \(B\) with explicit bound; (b) smoothness conclusion \(\phi E(f) \in W^{\gamma-Q+q_2}(\Xi_1)\) given \(\gamma\) between \(Q-q_2\) and \(S-q_2\). Example 3.4.1 using trigonometric Jacobi polynomials illustrates the theory.
  - [corpus] Weak – the corpus contains transfer learning papers (e.g., [76]) that focus on network weight reuse; the joint‑space formalism with kernels and smoothness transfer is original to this dissertation.
- **Break condition:**
  - The joint distance \(d_{1,2}\) violates generalized triangle inequalities → the tubular set \(B\) defined in (3.4.2) may be empty or too small; uniform convergence on \(B\) fails.
  - The joint Gaussian upper bound fails → Proposition 3.3.1’s localization estimate breaks → Lemma 3.5.1 fails → overall error control lost.
  - Polynomial preservation fails → \(\sigma_n\) does not reproduce polynomials on \(\Xi_1\) → convergence of \(\sigma_n\) to \(E(f)\) may not hold or the rate degrades.
  - The base subset \(A\) is too close to the complement of \(\Xi_2\) (i.e., \(B^-\) empty) → lifting undefined on any useful subset of \(\Xi_1\).
  - \(f \notin W^\gamma(\Xi_2;A)\) → the smoothness conclusion fails; \(E(f)\) may not be continuous on \(B\).
  - The \(\alpha\)-inequality (6th assumption) fails → the inclusion \(\sigma_n(\Xi_1,\Xi_2;f) \in \Pi_{\alpha n}(\Xi_1)\) is not guaranteed, compromising the approximation.

### Mechanism 3 (Classification as support estimation)
- **Claim:** Classification is solved by estimating the supports of the class‑specific probability measures using a localized kernel; under detectability and fine‑structure of the data measure, the estimator \(G_n(\Theta)\) asymptotically covers the union of supports and splits into well‑separated components that recover the true class supports (F‑score \(\to\) 1). This enables an active learning algorithm (MASC) that queries very few points (modes of components) while achieving high accuracy.
- **Mechanism:** Given \(M\) samples from a compact metric space \(\mathcal{M}\) (normalized to diameter \(\le \pi\)), compute the empirical kernel density \(F_n(x) = \frac{1}{M}\sum_{j=1}^M \Psi_n(x,x_j)\) with \(\Psi_n(x,y) = \Phi_n(\rho(x,y))^2\) and a periodic localized kernel \(\Phi_n\). Under *detectability* (ball measures grow like \(r^\alpha\)) and *fine structure* (for each small \(\eta\) the support \(X\) has a partition into far‑separated sets plus a vanishing overlap), for appropriate \(n,\Theta\) we have \(X \subseteq G_n(\Theta) \subseteq B(X, r(\Theta)/n)\). Moreover, for a suitable \(\eta\), \(G_n(\Theta)\) decomposes into disjoint tubes around the true class supports. The F‑score therefore tends to 1. MASC (Algorithm 1) then runs a multiscale loop over \(\eta\): build a graph with edges if \(\rho < \eta\); find connected components of size \(\ge p\); for a component with no queried points, query the point maximizing \(F_n\) inside it and extend that label throughout; if the component already has queried points and all agree, extend; otherwise mark as uncertain. Increase \(\eta\) until the graph becomes connected or a maximum is reached. Finally, label remaining uncertain points by \(k\)‑nearest neighbors among the queried set. The active queries are drastically fewer than labeling all data.
- **Core assumption:**
  1. \(\mathcal{M}\) is a compact metric space (distance \(\rho\)); often derived from a compact manifold after normalization.
  2. The underlying mixture measure \(\mu = \sum_{k=1}^K a_k \mu_k\) is *detectable* (Definition 4.4.1): \(\exists \alpha,\kappa_1,\kappa_2>0\) such that \(\mu(B(x,r)) \le \kappa_1 r^\alpha\) for all \(x\), and \(\mu(B(x,r)) \ge \kappa_2 r^\alpha\) for \(x\in X\) and small \(r\).
  3. \(\mu\) has a *fine structure* (Definition 4.4.2): for every \(\eta \in (0,\eta_0]\), there is a partition \(\{S_{k,\eta}\}_{k=1}^{K_\eta+1}\) of \(X\) with pairwise separation \(\ge 2\eta\) and \(\lim_{\eta\to0} \mu(S_{K_\eta+1,\eta}) = 0\). In the classical case \(S_k = \supp(\mu_k)\) are disjoint.
  4. Sample size \(M \gtrsim n^\alpha \log n\) (to control empirical concentration).
  5. Hyperparameters satisfy: \(n \gtrsim 1/(\eta \Theta^{1/(S-\alpha)})\) and \(\mu(S_{K_\eta+1,\eta}) \lesssim \Theta n^{-\alpha}\). Also \(p\) (minimum component size) and \(k\) (k‑NN size) are suitably chosen.
  6. The filter \(h\) is even, \(C^\infty\), supported in \([0,1]\), and \(S > \alpha\).
- **Evidence anchors:**
  - [abstract] “Classification … a signal separation approach estimates supports of class measures. Assuming detectability and fine structure … \(G_n(\Theta)\) satisfies \(X \subseteq G_n(\Theta) \subseteq B(X, r(\Theta)/n)\); with fine structure, \(G_n(\Theta)\) partitions into well‑separated components … (F‑score \(\to\) 1). MASC shows competitive accuracy and faster runtimes vs. LAND/LEND on hyperspectral data.”
  - [section] Section 4.5 Theorem 4.5.1 (bounds on \(G_n(\Theta)\)), Theorem 4.5.2 (component separation and inclusion), Theorem 4.5.3 (F‑score limit). Section 4.6 describes MASC (Algorithm 1). Section 4.7 reports experiments on synthetic, document, and hyperspectral data; Tables 4.3–4.4 compare with LAND/LEND, showing speed and accuracy.
  - [corpus] The corpus includes LAND [74] and LEND [133] – active learning algorithms for hyperspectral data – which MASC outperforms in runtime and often accuracy. The signal separation perspective links to classic super‑resolution literature (e.g., de Prony via [113]) but is extended to measures on metric spaces.
- **Break condition:**
  - Detectability fails (e.g., a class has very low density near its support, below \(\kappa_2 r^\alpha\)) → that support is missed in \(G_n(\Theta)\) → false negatives.
  - Fine structure violated (classes overlap significantly or overlap set measure does not decay) → false positives, merged components in \(G_n(\Theta)\).
  - \(\Theta\) too large → threshold too high, \(G_n\) empty or missing low‑density parts; \(\Theta\) too small → includes outliers/noise → graph connection mixes classes.
  - \(n\) too small relative to \(\eta\) (i.e. \(n \lesssim 1/(\eta \Theta^{1/(S-\alpha)})\)) → kernel not localized enough → components merge across true boundaries.
  - \(M\) too small (below \(n^\alpha \log n\)) → empirical \(F_n\) deviates from expectation; uniform concentration fails.
  - \(p\) too large discards small but valid classes; \(p\) too small yields many tiny components (high query cost, possible instability).
  - The metric normalization diameter \(\ne \pi\) → the periodic kernel’s behavior on \([-\pi,\pi]\) is mismatched, harming localization.

## Foundational Learning

- **Concept:** *Function Approximation Theory*
  - *Why needed here:* All three projects rely on constructive approximation (e.g., integral operators with localized kernels) and smoothness classes \(W^\gamma\). The error bounds use degree of approximation, Bernstein inequalities, and the interplay between kernel degree \(n\) and smoothness \(\gamma\).
  - *Quick check question:* “What does the inequality \(E_n(f) \le \|f-\sigma_n(f)\| \lesssim E_{n/2}(f)\) tell us about the quality of the reconstruction operator \(\sigma_n\) relative to the best approximation?”
- **Concept:** *Data Spaces and Manifold Learning*
  - *Why needed here:* The first two projects are set in the general framework of *data spaces* (Definition 3.2.1), which abstracts smooth manifolds but requires only a metric, a measure, and an orthonormal basis with a Gaussian upper bound on the heat kernel. This allows the theory to go beyond differentiable settings.
  - *Quick check question:* “List the three conditions in Definition 3.2.1 for a compact data space and explain how each relates to properties of a smooth Riemannian manifold.”
- **Concept:** *Active Learning via Density‑Based Querying*
  - *Why needed here:* The classification method (MASC) is an active learner that queries points where the kernel‑density estimator \(F_n\) is large within graph components. This exploits the detectability condition and ensures few labeled points suffice for high‑fidelity classification.
  - *Quick check question:* “In MASC, why does choosing the point with maximal \(F_n\) within a component lead to an informative query, and how does this connect to the detectability assumption?”

## Architecture Onboarding

- *Component map:* 
  Kernel generator → Density estimator → Thresholding & support extraction → Graph builder → Component analyzer → Query selector → Label propagator → k‑NN fallback
  (Note: for transfer learning the density estimator is replaced by the lifting operator evaluation.)
- *Critical path:*
  1. Preprocess data: (i) For manifold: project to sphere; (ii) normalize distances so diameter ≤ π; (iii) compute distance matrix or approximate nearest neighbor structure.
  2. Choose hyperparameters: \(n, q, \Theta, \eta_{\text{start}}, \eta_{\text{step}}, p, k\) (see tradeoffs).
  3. Precompute kernel values or compute \(F_n\) on the fly (nested loops over points; possible use of matrix multiplication if distances precomputed).
  4. For classification: obtain \(G_n(\Theta)\); then while \(\eta\) small, build graph and process components; after loop, run \(k\)-NN on leftovers.
- *Design tradeoffs:*
  - \(n\) (kernel degree): larger → better approximation/locality but ↑ computational cost (∼ \(M^2 n\) naive) and requires larger \(M\). Should reflect smoothness \(\gamma\) and separation \(\eta\) (in classification, \(n \gtrsim 1/(\eta \Theta^{1/(S-\alpha)}\))).
  - \(\Theta\) (threshold): too high → empty support; too low → outliers/spurious connections. Can be set adaptively or via a small validation set.
  - \(\eta\) (graph scale): small → fine clusters (lots of queries); large → merged classes. Start small and increase slowly until the whole dataset connects or a pre‑set maximum.
  - \(p\) (min cluster size): filters tiny components (likely noise/outliers); too high discards small legitimate classes; typically set to a small integer like 3–15.
  - \(q\) (intrinsic dim, manifold): affects the projection; if unknown, can be estimated or tuned.
  - \(S\) (filter smoothness): usually fixed by the choice of \(h\); higher \(S\) improves localization but requires higher \(n\) to maintain accuracy.
- *Failure signatures:*
  - *Manifold:* \(F_n\) nearly constant across points; learning curve flat; projected data not lying on a low‑dimensional structure (PCA shows high explained variance dimension). Possibly increase \(q\) or use a different method.
  - *Transfer:* \(\sigma_n\) blows up or vanishes on the target; validate the joint Gaussian bound by checking joint kernel values decay as expected; verify \(A\) and \(L\) correctly constructed.
  - *Classification:* Histogram of \(F_n\) shows no gap; graph either all isolated or one giant component; MASC uses excessive queries (many components) yet many points remain unlabeled; final accuracy low. Check detectability by examining small‑ball frequencies locally.
- *First 3 experiments:*
  1. **Manifold sanity:** Generate data on a circle \(S^1\) with \(f(\theta)=\sin(3\theta)\) and uniform sampling. Vary \(n\) (32→128), keep \(M\) large. Compute mean squared error on a dense grid. Expect \(O(n^{-2})\) decay; also test with wrong \(q=2\) to see degradation.
  2. **Transfer – analytic lifting:** Use Example 3.4.1: base and target are intervals with different Jacobi polynomial systems (e.g., Chebyshev → Legendre). Choose \(f\) a smooth function on base, compute its expansion coefficients (via numerical integration), lift using the joint coefficients \(A_{m,n}\) to target coefficients, recombine, and compare to direct evaluation of \(f\) on the target (since domain same). Verify smoothness order reduction matches Theorem 3.4.1.
  3. **Classification – well‑separated mixtures:** Generate \(K=3\) Gaussian clusters on \(S^2\) with pairwise distances > 0.5 rad. Sample \(M=500\). Run MASC with \(n=16\), \(\Theta=0.15\), \(\eta\) from 0.01–0.1, \(p=5\). Check that after a few \(\eta\) increments all points in \(G_n(\Theta)\) get labeled correctly with very few queries (\(<K+3\)). Compute F‑score (should be 1). Then reduce separation to test failure.

## Limitations
- Assumption sensitivity: strong mathematical assumptions (e.g., known intrinsic dimension, detectability) may be violated in real data.
- Hyperparameter dependence: practical choices require tuning with minimal validation data.
- Limited empirical validation: experiments confined to synthetic, document, and hyperspectral datasets; broader testing needed.

## Confidence
- Supervised manifold learning: High confidence in theory; Medium confidence in practical robustness.
- Transfer learning: Medium confidence.
- Classification (MASC): Medium confidence.

## Next Checks
1. **Manifold learning robustness:** Test on manifolds with boundaries and varying curvature (e.g., spheres, tori, surfaces with edges). Measure uniform error vs. sample size and compare against manifold‑estimating baselines (e.g., LAND) to quantify vulnerability to assumption breaches.
2. **Transfer learning empirical verification:** Apply the joint‑space lifting to a controlled cross‑modal benchmark (e.g., synthetic signal to real‑world sensor data) with a known smoothness relationship. Validate the predicted smoothness order reduction by measuring target error as base smoothness varies.
3. **Active classification stress test:** Evaluate MASC on multiclass datasets with deliberate overlap (violating fine structure) and low‑density minority classes. Compare query efficiency and final F‑score against modern active learners (e.g., coreset‑based, uncertainty sampling) to delineate operational boundaries.
