# CO-EVOLVE: Bidirectional Co-Evolution of Graph Structure and Semantics for Heterophilous Learning

## Quick Facts
- **arXiv ID:** 2603.19596
- **Source URL:** https://arxiv.org/abs/2603.19596
- **Reference count:** 40
- **Primary result:** CO-EVOLVE improves node classification accuracy by 9.07% and F1 by 7.19% over SOTA, with high robustness (<9% accuracy loss under 30% semantic corruption, ~1.8% under 30% edge deletion).

## Executive Summary
Heterophilous graph learning suffers from bidirectional error propagation between structural and semantic views, leading to performance degradation under noise. CO-EVOLVE introduces a dual-view co-evolution framework that alternately refines both a graph neural network (GNN) and a large language model (LLM) via a Gauss-Seidel optimization loop. The GNN injects topological context as soft prompts into the LLM, grounding its reasoning and reducing hallucinations. Conversely, the LLM constructs a dynamic semantic graph to rewire the GNN’s structure, correcting topological noise. Key innovations include a Hard-Structure Conflict-Aware Contrastive Loss (using PPR to push apart false semantic friends), an Adaptive Node Gating mechanism (fusing static and learned structures), and an Uncertainty-Gated Consistency loss that prevents blind alignment by down-weighting uncertain predictions. On Reddit, Instagram, and WikiCS, CO-EVOLVE achieves average gains of 9.07% in Accuracy and 7.19% in F1 over state-of-the-art baselines. It demonstrates exceptional robustness: under 30% semantic corruption, accuracy drops by less than 9% on Reddit (vs >23% for LLaGA), and under 30% edge deletion, accuracy declines by only ~1.8% (vs ~18% for GCN).

## Method Summary
The method consists of three stages. (1) Warm-up: A 2-layer GCN is pre-trained on the original graph, and an LLM (LLaMA-3.2-1B) is fine-tuned with LoRA on node text. (2) Alternating co-evolution: In each cycle, the frozen GNN generates structural embeddings that are projected into soft prompts and fed to the LLM. The LLM is updated using a combined loss: cross-entropy task loss, Hard-Structure Conflict-Aware Contrastive loss (leveraging a pre-computed PPR matrix to separate hard negative pairs), and Uncertainty-Gated Consistency loss (entropy-weighted KL divergence). The updated LLM produces semantic embeddings used to build a dynamic similarity graph via a multi-head learnable metric. This graph is fused with the original adjacency using a node-level gating network (α_i) and top-k sparsification to produce a rewired adjacency matrix. The LLM is frozen, and the GNN is updated on this new graph using the same losses. The cycle repeats. (3) Inference: A single forward pass fuses predictions from the GNN and LLM through an entropy/structural-context-gated β network, yielding the final label.

## Key Results
- Average improvement of 9.07% in Accuracy and 7.19% in F1 over SOTA on Reddit, Instagram, WikiCS.
- Under semantic corruption (text swapping), CO-EVOLVE loses <9% accuracy at 30% corruption on Reddit, compared to >23% for LLaGA.
- Under edge deletion (30% edges removed), accuracy drops by ~1.8% vs ~18% for GCN, demonstrating high structural robustness.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** The cyclic Gauss-Seidel feedback loop halts bidirectional error propagation by allowing mutual correction between the GNN's structural view and the LLM's semantic view.
- **Mechanism:** The GNN injects topological context as differentiable Soft Prompts into the LLM's input, grounding its reasoning and reducing hallucinations. Concurrently, the LLM generates semantic embeddings used to construct a Dynamic Semantic Graph that rewires the GNN's structure, correcting topological noise. This creates a closed loop where errors from one modality can be rectified by the other in subsequent alternating optimization steps.
- **Core assumption:** Errors in one modality are not perpetually fixed but can be identified and mitigated by the complementary, co-evolving modality.
- **Evidence anchors:** 
  - Abstract: "Gauss-Seidel alternating optimization... GNN provides structural soft prompts to the LLM, and the LLM constructs a dynamic semantic graph to rewire the GNN... halts bidirectional error propagation."
  - Section III.E: Explicit training cycle description: "Step A (LLM Update)" uses GNN-generated prompts, "Step B" reconstructs graph from LLM embeddings, "Step C (GNN Update)" uses the new graph.
  - Corpus: Weak direct evidence; neighbor papers like KG-BiLM and SEMMA discuss bidirectional integration but do not describe an *alternating optimization* loop for mutual error correction.
- **Break condition:** If the Soft Prompting (III.A) or Semantic Structure Learning (III.B) modules are disabled (as shown in ablation w/o SP and w/o SSL), the framework reverts to a static pipeline and loses its robustness advantage.

### Mechanism 2
- **Claim:** The Hard-Structure Conflict-Aware Contrastive Loss resolves semantic-structural dissonance in heterophilous graphs by warping the semantic embedding space to respect high-order topological boundaries.
- **Mechanism:** Using a pre-computed Personalized PageRank (PPR) matrix as a global topological ground truth, the loss dynamically identifies "Hard Conflict Negatives" (semantically similar but topologically distant node pairs) and "Structural Positives" (topologically close pairs). It applies a margin-based loss to explicitly push apart false semantic friends and pull together true structural neighbors, forcing the LLM's semantic space to align with the graph's global community structure rather than superficial keyword similarity.
- **Core assumption:** Global, smoothed topological affinity (via PPR) is a more reliable indicator of true community membership than direct adjacency or local neighborhood, especially under heterophily.
- **Evidence anchors:**
  - Abstract: "Hard-Structure Conflict-Aware Contrastive Loss (using PPR to push apart false semantic friends)... resolves semantic-structural dissonance."
  - Section III.C: Full derivation and definition of the loss using PPR to mine Hi (Hard Conflict Negatives) and Pi (Structural Positives). Figure 3b empirically shows the cosine similarity of hard negative pairs decreasing from µ=0.643 to µ=0.355.
  - Corpus: Weak direct evidence. Neighbors like "Learn from Heterophily" and "GLANCE" address heterophily in GNNs but do not propose a contrastive loss using PPR to resolve semantic-structural conflict. The specific mechanism is novel to this paper.
- **Break condition:** Disabling this loss (w/o CAL in ablation) causes a severe performance drop, as false semantic friends are not penalized and the semantic manifold remains dissonant from topology.

### Mechanism 3
- **Claim:** Uncertainty-Gated Consistency prevents "blind alignment" and noise amplification by ensuring the two modalities only learn from each other when the teacher view is confident.
- **Mechanism:** For each node, the entropy of the predicted probability distribution from each model (LLM and GNN) is computed. A high-entropy (uncertain) model's output is down-weighted in the bidirectional KL divergence consistency loss. This means an uncertain LLM will not be forced to align with a potentially erroneous GNN distribution, and vice-versa. The gating acts as a meta-cognitive filter during co-evolution.
- **Core assumption:** Model confidence (low entropy) is a reasonable proxy for the reliability of a model's predictions for a given node, and thus for its suitability as a "teacher" in consistency regularization.
- **Evidence anchors:**
  - Abstract: "Uncertainty-Gated Consistency... ensures models only learn from the confident view... solves the Blind Alignment problem."
  - Section III.D: Equation (12) defines the gated loss: `Lcons = (1−H(P_GNN))·KL(...) + (1−H(P_LLM))·KL(...)`. Figure 4 shows average entropies of both models decreasing over epochs, indicating stable mutual enhancement.
  - Corpus: Weak direct evidence. Neighbors like FLAG use consistency regularization but without explicit uncertainty gating. The concept of entropy-gated knowledge transfer in this specific co-evolution context is not present in provided neighbor papers.
- **Break condition:** Removing this component (w/o UGC) leads to a 1-2% performance drop, as noisy supervision signals are no longer filtered, destabilizing the alternating optimization.

## Foundational Learning
- **Concept: Graph Neural Network Message Passing**  
  *Why needed here:* CO-EVOLVE's GNN relies on message-passing to generate structural embeddings and updates after rewiring; understanding aggregation reveals how structural noise spreads and how dynamic rewiring alters flows.  
  *Quick check:* If you delete a critical edge between two same-class nodes in a heterophilous graph, how does the standard GNN's representation for the isolated node change in the next layer?
- **Concept: Large Language Model Prompting & LoRA**  
  *Why needed here:* The framework conditions the LLM on structure-derived soft prompts, requiring knowledge that LLM inputs are token embeddings and differentiable soft prompts can steer latent activations; LoRA enables efficient fine-tuning.  
  *Quick check:* Why use a soft prompt (learned vector sequence) instead of a discrete natural language prompt to inject structural information?
- **Concept: Contrastive Learning & Hard Negative Mining**  
  *Why needed here:* The Conflict-Aware Loss is a supervised contrastive method; it requires identifying true positives/negatives in heterophily, with the innovation of mining "hard" conflict negatives via PPR.  
  *Quick check:* In standard contrastive loss for graphs, why would treating all adjacent node pairs as positives fail on a heterophilous graph?

## Architecture Onboarding
**Component map:**  
GNN Encoder (2-layer GCN) → Soft Prompt Projector (MLP) → LLM (LLaMA-3.2-1B with LoRA) → Semantic Structure Learner (Learnable Metric → Adaptive Gating → Top‑K Pruning) → Updated adjacency → GNN Encoder (next iteration). Additional modules: Conflict‑Aware Loss (PPR‑based), Uncertainty‑Gated Consistency (entropy‑weighted KL), Inference Fusion Gate (β network).

**Critical path:**  
Warm‑up (separate pre‑training) → [GNN → Prompt → LLM → Update LLM (task + CAL + UGC)] → [LLM → Reconstruct dynamic graph S] → [Adaptive fusion (α_i) + Top‑k → new Ã] → [Update GNN on Ã (frozen LLM)] → Repeat.  
Inference: GNN → Prompt → LLM → Reconstruct graph → GNN again → Fuse via β gate.

**Design tradeoffs:**  
- Computational Cost vs. Robustness: Alternating optimization is heavier but yields robustness gains.  
- Sparsity (k) vs. Completeness: Low k yields sparse clean graph but may miss beneficial links; high k adds noise. Sensitivity analysis guides tuning.  
- Threshold Sensitivity: Conflict loss thresholds (α, ϵ, τ) control mining strictness; mis‑tuning degrades performance.

**Failure signatures:**  
- Model collapse: If CAL loss too strong or gating drives α_i→0, dynamic graph becomes dense, losing structural signal.  
- No evolution: If UGC dominant or gating broken, predictions stay divergent (high entropy gap), indicating failed mutual learning.  
- Catastrophic forgetting: During LLM update, if task loss overwhelms UGC/CAL, LLM ignores structural guidance.

**First 3 experiments:**  
1. Reproduce Benchmarks (Q1): Run CO‑EVOLVE and baselines on Reddit/Instagram/WikiCS; verify ~9% Accuracy gain over SOTA.  
2. Stress Test: Semantic Corruption (Q2): Apply text‑swap (10‑30%); verify CO‑EVOLVE’s accuracy drop <9% vs >23% for LLaGA at 30% on Reddit.  
3. Ablation: w/o Semantic Structure Learner (SSL): Train with fixed static graph; expect >5% F1 drop, proving dynamic reconstruction is essential for robustness under edge deletion.

## Open Questions the Paper Calls Out
- **Convergence of alternating optimization:** Does the Gauss‑Seidel loop always converge to a stable fixed point, or can it oscillate? No theoretical analysis or long‑term empirical tracking (e.g., representation drift over hundreds of epochs) is provided.
- **Generality under extreme heterophily and diverse noise:** The evaluation uses only moderately homophilic graphs and two corruption types (semantic swap, edge deletion). It is unclear if the approach extends to graphs with near‑zero homophily or other noise models (e.g., adversarial features, stochastic block models with anti‑homophily).
- **Optimality of PPR for conflict mining:** The Hard‑Structure Conflict‑Aware Loss uses PPR as a global topological ground truth without justification. Could other metrics (Katz centrality, spectral embeddings) yield better or more robust alignment? Theoretical grounding is lacking.

## Limitations
- LLM integration details (exact LoRA hyperparameters, prompt template, tokenization, optimizer settings) are unreported, hindering soft prompting replication.
- Architecture specifics (layer sizes, activations, head counts for projection/gating/metric networks) and precise loss thresholds (Δ⁺, Δ⁻, λ, τ, etc.) are omitted.
- PPR computation (restart probability γ, dense/sparse storage) and unit/scale of τ (cosine similarity) remain unspecified, affecting reproducibility of the conflict loss.
