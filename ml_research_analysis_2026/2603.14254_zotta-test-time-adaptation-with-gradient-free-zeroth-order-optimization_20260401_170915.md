# ZOTTA: Test-Time Adaptation with Gradient-Free Zeroth-Order Optimization

## Quick Facts
*   **arXiv ID:** 2603.14254
*   **Source URL:** https://arxiv.org/abs/2603.14254
*   **Reference count:** 40
*   **Primary result:** A gradient-free test-time adaptation method that matches or exceeds backpropagation-based baselines while reducing memory usage by 84%.

## Executive Summary
ZOTTA is a test-time adaptation (TTA) framework that eliminates the need for backpropagation by employing zeroth-order optimization (ZOO). It introduces two key innovations: Distribution-Robust Layer Selection (DRLS), which adapts only domain-sensitive layers to reduce optimization dimensionality, and Spatial Feature Aggregation Alignment (SFAA), which stabilizes the noisy ZOO objective by aligning aggregated spatial feature statistics with the source domain. Evaluations on ImageNet corruptions and a multimodal task show ZOTTA outperforms prior BP-free methods and is competitive with BP-based ones, with significant memory savings.

## Method Summary
ZOTTA adapts a pre-trained model at test time without storing intermediate activations or using gradients. It uses a ZOO estimator (e.g., random gradient-free queries) to update a subset of parameters selected by DRLS. DRLS identifies layers whose features are sensitive to distribution shift by measuring divergence between source batch statistics and a small target batch, freezing layers with low divergence. SFAA further processes features from selected layers by spatially aggregating them (e.g., via pooling) and aligning their mean/variance to source domain statistics, creating a smoother, lower-variance loss landscape for the ZOO update.

## Key Results
*   ZOTTA achieves 66.6% accuracy on ImageNet-C, substantially higher than prior BP-free method T3A (56.9%) and exceeding BP-based SAR (62.7%).
*   It reduces memory consumption by 84% (825 MB vs. 5165 MB for BP methods) and demonstrates strong performance on 8-bit quantized models (64.8% vs. FOA's 58.6%).
*   The method generalizes to a multimodal large model, attaining 38.9% on the MathVista benchmark under wild TTA conditions.

## Why This Works (Mechanism)
The paper does not provide a detailed mechanistic analysis in the supplied text. The efficacy is attributed to the synergy of DRLS and SFAA: DRLS confines adaptation to layers most affected by domain shift, reducing the curse of dimensionality for gradient-free search, while SFAA's alignment provides a stable optimization target by matching feature distributions to the source, mitigating noise in zeroth-order gradient estimates.

## Foundational Learning
*   **Test-Time Adaptation (TTA):** Adapting a model to a new target domain using only unlabeled test data during deployment. *Why needed:* Models fail under distribution shift; TTA offers a lightweight fix without retraining. *Quick check:* Can a given method adapt on a single batch of corrupted data without labels?
*   **Zeroth-Order Optimization (ZOO):** Gradient-free optimization using function evaluations (e.g., random perturbations). *Why needed:* Avoids storing computational graph, enabling BP-free adaptation. *Quick check:* Does the method's memory footprint remain constant with model size?
*   **Distribution Shift / Domain Gap:** The mismatch between training (source) and test (target) data distributions. *Why needed:* The core problem TTA addresses. *Quick check:* Does performance degrade on a known corrupted benchmark (e.g., ImageNet-C)?
*   **Layer Sensitivity Analysis:** Estimating which layers' features change most under distribution shift. *Why needed:* To reduce ZOO's high-dimensional search space via DRLS. *Quick check:* Can feature statistics (e.g., mean, variance) from a small batch predict which layers need updating?
*   **Feature Statistics Alignment:** Matching the mean and variance of intermediate features to a reference distribution. *Why needed:* SFAA uses this to smooth the loss landscape for ZOO. *Quick check:* Does aligning statistics improve ZOO convergence compared to raw features?
*   **Memory-Efficient Adaptation:** Methods that avoid backpropagation's activation storage. *Why needed:* Critical for edge deployment or large models. *Quick check:* Measure GPU memory usage during adaptation relative to batch size and model size.

## Architecture Onboarding
**Component Map:** Target Batch -> DRLS (Select Layers) -> Model (Selected Layers) -> SFAA (Aggregate & Align Features) -> ZOO Update (Perturb & Query) -> Adapted Parameters

**Critical Path:** The adaptation loop centers on the ZOO update, but its efficiency depends on the DRLS selection (reducing dimension) and SFAA preprocessing (stabilizing objective).

**Design Tradeoffs:** DRLS trades off computation for memory (a forward pass for statistics) but reduces ZOOquery budget. SFAA trades representational fidelity (via aggregation) for optimization stability.

**Failure Signatures:** 1) DRLS incorrectly freezes critical layers (no performance gain). 2) SFAA over-smooths features (catastrophic forgetting of source knowledge). 3) ZOO query budget too low (no convergence) or too high (slow/memory waste).

**First Three Experiments:** 1) Ablate DRLS: compare performance with random layer selection vs. DRLS on a fixed ZOO budget. 2) Ablate SFAA: replace alignment with no processing or different aggregations (e.g., mean vs. max pooling). 3) Memory/Accuracy Curve: vary model size (e.g., ViT-Base vs. Large) and measure both accuracy gain on ImageNet-C and peak memory usage.

## Limitations
*   Hyperparameter sensitivity for DRLS thresholds and SFAA aggregation windows is not thoroughly analyzed.
*   Evaluation is confined to image classification (ImageNet-C, CIFAR-100-C) and one multimodal task; generalizability to detection, segmentation, audio, or video is unknown.
*   "Wild TTA" conditions and extreme data scarcity scenarios are not rigorously defined or tested.

## Confidence
*   **Superiority over prior BP-free methods (e.g., 66.6% vs. 56.9% on ImageNet-C):** High
*   **Matching/exceeding BP-based baselines (e.g., 66.6% vs. 62.7% for SAR):** Medium
*   **Memory reduction claim (84% savings):** High
*   **Effectiveness on 8-bit quantized models:** Medium
*   **Effectiveness on multimodal large models (MathVista):** Low
*   **Robustness under wild TTA settings:** Medium
