# Interpretable clustering via optimal multiway-split decision trees

## Quick Facts
- **arXiv ID**: 2602.13586
- **Source URL**: https://arxiv.org/abs/2602.13586
- **Reference count**: 37
- **Primary result**: ICOMT (especially with K-means discretization) achieves higher Adjusted Rand Index (ARI) than baseline methods while producing significantly shallower trees (often depth 1–3) with concise, interpretable splitting rules, and with acceptable computation times for offline analysis.

## Executive Summary
The paper tackles the trade-off between clustering accuracy and interpretability. Existing optimal decision tree methods for clustering rely on binary splits, leading to deep trees and complex rules. The proposed method, ICOMT, uses optimal multiway-split decision trees to represent clusters as conjunctive feature conditions along single root-to-leaf paths, yielding much shallower trees. Clustering quality is driven by a 0–1 integer linear program that selects an optimal subset of these paths under a leaf budget. Continuous features are adaptively discretized using one-dimensional K-means with BIC model selection to align split thresholds with the data distribution. Experiments on four public datasets show that ICOMT-K (K-means discretization) consistently outperforms baselines in external validation (ARI) while maintaining high interpretability through shallow depths and concise rules.

## Method Summary
ICOMT formulates interpretable clustering as a combinatorial selection problem over candidate multiway-split decision paths. First, each continuous feature is discretized independently: for feature *f*, 1D K-means is run for candidate cluster counts *K* ∈ {2,…,6}, and *K* is chosen by minimizing BIC; split thresholds are midpoints between centroids. This yields a set of intervals per feature. A layered directed feature graph is constructed: each layer corresponds to a feature, with nodes for each interval plus a “Skip” node (meaning the feature is not used in that path). Edges connect all nodes in layer *f* to all nodes in layer *f*+1, with added Source and Sink nodes. All Source→Sink paths are enumerated, each representing a candidate cluster defined by a conjunction of feature intervals. Redundant paths are removed: (i) those covering identical data point sets as another, and (ii) those where dropping the last condition does not change coverage. For each remaining path *j*, its within-cluster sum of squares ξ<sub>j</sub> is precomputed, along with coverage indicators *a*<sub>ij</sub> (1 if point *i* is in path *j*’s region). The final tree is obtained by solving a 0–1 integer linear program: minimize Σ ξ<sub>j</sub> *z*<sub>j</sub> subject to each point covered at most once (Σ *a*<sub>ij</sub> *z*<sub>j</sub> ≤ 1), at most *l* leaves (Σ *z*<sub>j</sub> ≤ *l*), and coverage of at least ρ*N* points (Σ *n*<sub>j</sub> *z*<sub>j</sub> ≥ ρ*N*). The solution *z*<sub>j</sub>=1 defines the selected paths, which are translated into a multiway-split tree; points are assigned to the first selected path they satisfy.

## Key Results
- ICOMT-K achieves higher Adjusted Rand Index (ARI) than compared methods (ICOT, CART-Hybrid, PCT) on most datasets, with a notable improvement on Statlog Vehicle.
- Trees are significantly shallower (often depth 1–3) than binary counterparts, leading to more concise and interpretable splitting rules.
- Computation times are comparable to or slightly longer than some baselines but remain acceptable for offline clustering analysis.

## Why This Works (Mechanism)

### Mechanism 1: Multiway-split structure for shallower trees
- **Claim:** Using a multiway-split tree structure (instead of binary splits) yields shallower trees with more concise decision rules, improving interpretability while maintaining accuracy.
- **Mechanism:** A multiway node can split into multiple children based on multiple discretized feature values simultaneously. A cluster is then defined by a single root-to-leaf path representing a conjunction of feature conditions (e.g., `x1 in bin A AND x2 in bin B`), compressing the logical representation compared to sequential binary splits.
- **Core assumption:** Complex cluster boundaries can be expressed as a conjunction of several simple, univariate feature conditions without requiring deep binary decision sequences.
- **Evidence anchors:** Abstract states “producing significantly shallower trees (often depth 1-3) with concise, interpretable splitting rules.” Section 2.1 notes multiway-split trees yield more concise rules and maintain high interpretability with shallower trees. Neighboring work on multiway-split trees supports this direction.
- **Break condition:** For cluster structures requiring long sequences of sequential, dependent binary decisions (e.g., XOR-like problems), a multiway path enumeration may become combinatorially large or fail to capture the structure efficiently, negating the depth benefit.

### Mechanism 2: Adaptive K-means discretization
- **Claim:** Adaptive discretization of continuous features via one-dimensional K-means (ICOMT-K) provides more accurate cluster boundaries than fixed cumulative binning (ICOMT-B) by aligning split points with the underlying data distribution.
- **Mechanism:** For each feature, 1D K-means clusters the values into *K*<sub>f</sub> segments; BIC selects *K*<sub>f</sub> to balance fit and complexity; split thresholds are midpoints between centroids. This creates data-driven intervals that respect natural groupings (e.g., separating bimodal modes).
- **Core assumption:** The optimal split points for a clustering objective align with modes or natural groupings in the marginal distribution of individual features.
- **Evidence anchors:** Abstract mentions “employs one-dimensional K-means for adaptive discretization.” Section 2.3 states discretization flexibly defines intervals according to data distribution. Section 3.4.1 shows ICOMT-K outperforms on non-linear datasets (Statlog, Customer) while ICOMT-B suffices on simpler, linear-like data (Real Estate), confirming the mechanism’s conditional benefit.
- **Break condition:** For features with uniform or near-linear relationships to cluster structure, K-means overhead adds complexity without benefit; simpler cumulative binning may suffice.

### Mechanism 3: ILP formulation for tractable global optimization
- **Claim:** Formulating the path selection problem as a 0–1 integer linear program (ILP) provides a tractable, globally optimal solution for the multiway tree structure, avoiding the suboptimal solutions and high nonlinear computational cost of binary-tree mixed-integer formulations.
- **Mechanism:** The clustering objective (minimize total within-cluster sum of squares) is reformulated by pre-enumerating candidate paths (conjunctions of feature bins) and precomputing ξ<sub>j</sub>. Selection of paths becomes a linear objective with linear constraints (coverage, max leaves, exclusivity), transforming a complex tree-building process into a combinatorial selection problem.
- **Core assumption:** The global optimum under a maximum leaf constraint can be found by selecting from a pre-enumerated set of conjunctive feature rules, and the resulting ILP is solvable for considered problem scales.
- **Evidence anchors:** Abstract claims the reformulation “renders the optimization problem more tractable compared to existing models.” Section 1.2 contrasts with ICOT’s mixed-integer nonlinear formulation. Section 3.4.1 reports computation times comparable to or slightly longer than some baselines but acceptable for offline use, supporting tractability relative to nonlinear alternatives.
- **Break condition:** The combinatorial explosion of candidate paths with increasing features *p* and bins per feature will make path enumeration and ILP solving intractable; the method relies on a feature graph with a manageable number of nodes per layer.

## Architecture Onboarding
**Component map:**  
Discretization Module -> Feature Graph Constructor -> Path Enumerator & Redundancy Remover -> Path Evaluator -> ILP Solver -> Tree Reconstructor & Assigner

**Critical path:**  
1. Discretize continuous features with 1D K-means (BIC selection).  
2. Build layered feature graph with intervals and Skip nodes.  
3. Enumerate all Source→Sink paths and remove redundancies.  
4. Precompute ξ<sub>j</sub> and coverage matrix *a*<sub>ij</sub> for each path.  
5. Solve 0–1 ILP with Gurobi to select paths under leaf budget *l* and coverage ρ.  
6. Reconstruct multiway tree from selected paths and assign points.

**Design tradeoffs:**  
- **Tree depth vs. candidate paths:** Allowing more features per path (shallower trees) exponentially increases candidate paths |*J*|, impacting ILP solve time. The algorithm implicitly trades global optimality for tractability via redundancy removal.  
- **Discretization granularity:** Using *K*<sub>f</sub> ∈ {2,…,6} controls bins per feature. More bins increase path diversity (better accuracy potential) but also increase |*J*|; BIC selection automates this tradeoff.  
- **Coververage ratio (ρ):** Setting ρ=1 forces all points into clusters. Lower ρ ignores outliers but may leave data unassigned, which could be desirable or problematic.

**Failure signatures:**  
- **Solver timeout/fail:** ILP too large due to high |*J*| from many features/bins. Symptom: Gurobi returns non-optimal or infeasible status.  
- **Over-aggressive redundancy removal:** Removing paths with identical coverage sets might eliminate semantically different rules. Check if removal criterion (ii) incorrectly flags a condition as redundant.  
- **Poor discretization:** If BIC consistently selects *K*<sub>f</sub>=2, multiway advantage is lost. Inspect chosen *K*<sub>f</sub> values per feature.  
- **Low ARI despite high Silhouette:** Internal cluster quality good but clusters misaligned with true labels; indicates WCSS objective mismatch with external structure.

**First 3 experiments:**  
1. **Seeds dataset (low-dim, clear structure):** Verify ICOMT-K achieves shallow tree (depth 1–3) and high ARI (~0.61). Baseline ICOT should be deeper.  
2. **Statlog Vehicle Silhouettes (higher-dim, non-linear):** Verify ICOMT-K achieves best ARI with very shallow tree (depth 1 in Fig 7); check reliance on a single powerful feature (X12).  
3. **Real Estate Valuation (linear-ish relationships):** Verify ICOMT-B (tercile binning) matches or beats ICOMT-K. This negative control confirms K-means adds value only on non-linear data; tree depth should remain shallow.

## Open Questions the Paper Calls Out
- **Question:** How can ICOMT be extended to support overlapping clustering, allowing data points to belong to multiple clusters while preserving multiway-split tree interpretability?  
  *Basis:* Section 4.2 explicitly states extension to overlapping clustering as future work. Current constraint (3) enforces exclusive assignment.  
  *Why unresolved:* Relaxing exclusivity may complicate optimization, affect tree clarity, and challenge interpretability due to multiple covering paths.  
  *Resolving evidence:* Develop a framework with soft/multi-assignment variables and test on overlapping-cluster benchmarks, measuring both ARI and interpretability (depth, rule simplicity).

- **Question:** What discretization method for continuous features optimally balances clustering accuracy and interpretability in ICOMT, and can it be selected automatically per feature?  
  *Basis:* Section 4.2 notes that comparing discretization methods and adaptive per-feature selection remain future work. Only 1D K-means vs. cumulative binning is evaluated.  
  *Why unresolved:* The choice impacts feature graph size, split boundaries, and final tree interpretability/accuracy; no systematic comparison or automated selection is provided.  
  *Resolving evidence:* Comprehensive empirical study across datasets comparing multiple discretization strategies; design a meta-criterion (e.g., based on data distribution metrics or validation performance) for automatic per-feature selection.

- **Question:** Can ICOMT scale to high-dimensional or large-scale datasets without sacrificing interpretability, and what approximations are viable?  
  *Basis:* Inferred from reported times (up to 86 s for Statlog with 18 features) and notes on path enumeration cost; scalability limits not formally analyzed, and larger datasets untested.  
  *Why unresolved:* Feature graph size grows combinatorially with features and bins; exact optimization may become intractable, potentially requiring heuristics that compromise optimality guarantees.  
  *Resolving evidence:* Theoretical complexity analysis of path enumeration and optimization; test on larger datasets (thousands of instances, hundreds of features); evaluate approximation algorithms (beam search, Lagrangian relaxation) that maintain shallow depths and clear rules.

- **Question:** Does per-feature independent discretization in ICOMT overlook feature interactions that could enhance clustering performance, and how can joint discretization be incorporated?  
  *Basis:* Inferred from Section 2.3: discretization is independent per feature, assuming optimal split boundaries are univariate. Multiway paths involve feature conjunctions where interactions might matter.  
  *Why unresolved:* Independent discretization may produce suboptimal bins that do not align with multi-feature decision boundaries, missing clusters dependent on feature combinations.  
  *Resolving evidence:* Compare ICOMT with a variant where discretization is co-optimized with tree structure (e.g., integrated into ILP or using multivariate discretization); measure ARI and interpretability improvements on datasets with known feature interactions.

## Limitations
- **Path enumeration implausibility:** Claim of enumerating all paths is implausible for datasets like Statlog (18 features); unknown pruning or column-generation strategy is likely used but not described.
- **ILP optimality conditional:** Redundancy removal may discard globally optimal paths; solution is optimal only over the reduced candidate set, not necessarily the true global optimum.
- **Discretization sensitivity:** Details of merging rules for ICOMT-B and BIC selection are under-specified; sensitivity to *K*<sub>f</sub> range (2–6) is unexplored.

## Confidence
- **Multiway-split yields shallower trees:** Medium (empirical depth reduction clear, but global optimality uncertain due to candidate pruning).
- **K-means discretization improves accuracy:** Medium (dataset-specific results plausible, but adaptive selection not fully validated across diverse distributions).
- **ILP formulation is tractable and globally optimal:** Low (times acceptable but likely due to aggressive candidate pruning; exact optimality over all paths unproven).
