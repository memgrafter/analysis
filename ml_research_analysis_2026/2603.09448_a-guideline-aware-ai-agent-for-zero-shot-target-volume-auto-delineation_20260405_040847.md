# A Guideline-Aware AI Agent for Zero-Shot Target Volume Auto-Delineation

## Quick Facts
- arXiv ID: 2603.09448
- Source URL: https://arxiv.org/abs/2603.09448
- Reference count: 21
- Primary result: OncoAgent achieved Dice scores of 0.842 (CTV) and 0.880 (PTV) on esophageal cancer, comparable to a supervised nnU-Net baseline, and demonstrated zero-shot adaptability to different guidelines and the prostate site without retraining.

## Executive Summary
OncoAgent is a novel AI agent framework that converts textual radiotherapy guidelines into 3D target volume contours without retraining. It uses a large language model (LLM) to interpret the guideline and generate a structured plan of tool calls, which an execution engine carries out using pre-trained segmentation models and geometric operations. Evaluated on esophageal cancer, OncoAgent reached Dice scores of 0.842 for CTV and 0.880 for PTV, statistically indistinguishable from a fully supervised nnU-Net. In a blinded clinician review, OncoAgent was preferred for better guideline compliance and less manual modification. Importantly, the system adapts instantly to new guidelines and even to other anatomical sites (e.g., prostate) in a zero-shot manner, eliminating the need for costly model retraining.

## Method Summary
OncoAgent employs a two-stage pipeline: (1) An LLM processes the clinical guideline, patient data, and a system prompt that defines the agent’s role, provides domain-specific templates (e.g., CTV = (GTV ⊕ m_ctv) \ OARs), and includes examples. The LLM outputs a JSON plan of tool calls, which undergoes schema validation with a self-refinement loop to ensure correctness. (2) A deterministic execution engine sequentially executes the plan: segmentation tools (pre-trained models) generate binary masks for organs-at-risk (OARs), while geometric operations (dilation, subtraction, union via VTK) manipulate these masks according to the plan, applying margins and exclusions. Post-processing (smoothing, hole-filling) yields the final 3D contours. This separation of reasoning (LLM) and execution (fixed tools) enables zero-shot adaptation—changing the guideline or anatomical site only requires new textual input.

## Key Results
- Dice scores: 0.842 (CTV) and 0.880 (PTV) on esophageal cancer.
- Result statistically comparable to a fully supervised nnU-Net baseline.
- Blinded clinician evaluation: physicians preferred OncoAgent for higher guideline compliance and lower modification effort.
- Zero-shot generalization to alternative esophageal guidelines and to prostate without retraining.

## Why This Works (Mechanism)
**Mechanism 1: Parse guideline into plan via LLM**
OncoAgent leverages an LLM’s zero-shot instruction following to translate the textual guideline into a structured JSON plan of tool calls. A system prompt assigns the LLM the role of a radiation oncology expert, provides domain templates (e.g., CTV = (GTV⊕m_ctv)\OARs), includes examples of OAR aliasing, and enforces a step-by-step order. The LLM self-refines if the plan violates a schema, ultimately producing a valid, deterministic plan. Evidence: Section 2.2 details the prompting strategies; the abstract confirms the training-free conversion.

**Mechanism 2: Deterministic execution of the plan**
The execution engine receives the validated JSON plan and dispatches each tool call sequentially. Segmentation tools invoke pre-trained deep learning models to produce OAR binary masks. Geometric operation tools (dilate, subtract, union) manipulate these masks using VTK, applying direction-specific margins and handling exclusions. The output of each step feeds the next, and post-processing (smoothing, hole-filling) generates the final 3D contours. Evidence: Section 2.3 describes the engine; neighbor work on physics-guided planning also uses modular execution.

**Mechanism 3: Zero-shot adaptation through textual input**
Because the plan is generated at inference from the guideline text, adapting to new guidelines or anatomical sites requires no model updates. The same LLM and execution engine are reused; a different guideline yields a different plan. Evidence: Section 3.4 reports Tool Call F1 scores across esophageal guidelines and prostate; the abstract highlights instant zero-shot adaptability.

## Foundational Learning
- **Clinical Target Volume (CTV) and Planning Target Volume (PTV)**  
  *Why needed*: The agent encodes guideline rules such as “CTV = GTV + margin excluding OARs” and “PTV = CTV + setup margin.” Without these definitions, the plan lacks clinical meaning.  
  *Quick check*: What is the difference between CTV and PTV, and why are their margins applied differently?

- **Zero-shot learning with large language models**  
  *Why needed*: This core capability enables training-free guideline interpretation; the LLM must follow novel instructions without fine-tuning.  
  *Quick check*: In a zero-shot setting, what input components does the LLM rely on to solve a new task?

- **3D binary morphological operations (dilation, subtraction, union)**  
  *Why needed*: These operations implement guideline-prescribed margin expansions and OAR exclusions; understanding their spatial effect is crucial to reason about the final volume.  
  *Quick check*: How does subtracting a binary OAR mask from a dilated GTV mask enforce an anatomical exclusion rule?

- **Tool orchestration in AI agent frameworks**  
  *Why needed*: The agent’s plan is a sequence of tool calls; the execution engine bridges the LLM’s textual plan to actionable computations. Grasping this separation of reasoning and execution is fundamental.  
  *Quick check*: What is the role of the execution engine relative to the LLM-generated plan?

## Architecture Onboarding
- **Component map**:  
  Guideline text + System Prompt → LLM → Plan (JSON) → Schema validator (with self-refine loop) → Execution engine (tool library: pre-trained OAR segmentation models, geometric operations) → Sequential tool dispatch → Post-processing (smoothing, hole-filling) → Final 3D contours. Data flows via binary masks and JSON parameters.

- **Critical path**:  
  1. LLM produces a valid plan.  
  2. Execution engine runs the plan without tool errors.  
  3. Post-processing yields final contours.  
  Failure in any step halts the pipeline.

- **Design tradeoffs**:  
  • *LLM capability vs cost*: More powerful LLMs improve parsing accuracy but increase API cost and latency; simpler models reduce cost but may jeopardize plan validity.  
  • *Tool coverage vs maintenance*: Adding more pre-trained segmentation models extends anatomical site coverage but raises integration and error-propagation risks.  
  • *Strict guideline compliance vs clinical pragmatism*: Exact rule adherence ensures safety but may produce over-eroded volumes near sensitive structures; incorporating adaptive margins could improve robustness at the expense of interpretability.  
  • *Self-refine iterations*: More iterations increase the chance of obtaining a valid plan but also add latency; a fixed maximum balances safety and speed.

- **Failure signatures**:  
  • Repeated schema rejections during LLM self-refinement.  
  • OAR segmentation quality dropping below expected Dice threshold (e.g., <0.85 for critical structures).  
  • Post-execution contours overlapping prohibited OARs or having zero volume.  
  • Execution exceptions: missing tool, parameter type mismatch, coordinate system misalignment, or VTK runtime errors.

- **First 3 experiments**:  
  1. **Plan validity test**: Input a standard guideline for one patient; verify the LLM outputs a JSON plan that conforms to the schema and matches a manually authored reference plan (high Tool Call F1).  
  2. **OAR segmentation audit**: Run the integrated OAR models on a small validation set with manual labels; compute Dice scores to ensure baseline quality (e.g., >0.85 for lungs, heart).  
  3. **End-to-end accuracy**: Execute the full pipeline on a few test cases; compare generated CTV/PTV to expert ground truth using DSC and MSD, and visually inspect for anatomical violations.

## Open Questions the Paper Calls Out
1. **How can OncoAgent incorporate adaptive margins to account for respiratory and organ motion while maintaining guideline compliance and geometric precision?**  
   - *Basis*: [explicit] The authors state: "future work should integrate adaptive margin strategies to reconcile geometric precision with motion robustness."  
   - *Why unresolved*: Static margins may undercover moving targets, risking treatment failure.  
   - *What evidence would resolve it*: Test using 4D CT to derive patient-specific margins, compare coverage and OAR sparing against fixed margins, and assess clinical impact.

2. **Does OncoAgent generalize zero-shot to multiple institutions and other tumor sites (e.g., head and neck, cervical cancer)?**  
   - *Basis*: [explicit] The authors list "multi-center validation, extension to other tumor sites (e.g., head and neck, cervical cancer)" as important future directions.  
   - *Why unresolved*: The single-institution study (40 patients) provides limited evidence of broader generalizability.  
   - *What evidence would resolve it*: Perform a multi-center trial on ≥3 new sites, evaluating segmentation consistency, guideline compliance, and physician acceptance.

3. **How can clinician feedback be integrated into OncoAgent to iteratively improve outputs and reduce manual modification effort?**  
   - *Basis*: [explicit] The authors state that "clinician feedback loops are important future directions."  
   - *Why unresolved*: The system currently does not learn from corrections, requiring repeated manual adjustments.  
   - *What evidence would resolve it*: Implement an interactive correction capture system, adjust parameters, and demonstrate reduced modification effort over successive cases in a longitudinal study.

## Limitations
- LLM semantic parsing robustness: Performance on guidelines with novel terminology or complex logical structures not covered in prompt examples is unquantified; the lower prostate F1 score (0.64) suggests sensitivity to anatomical domain shift.
- Error propagation from OAR segmentation: The impact of individual OAR model failures on final CTV/PTV accuracy is not isolated; evaluation uses integrated end-to-end scores.
- Generalizability: Validation is limited to esophageal cancer and a single pilot on prostate; performance on other complex sites (e.g., head & neck) or varied guideline styles remains unknown.

## Confidence
- Guideline-to-plan parsing by LLM: **Medium**
- Deterministic execution engine: **Medium**
- Zero-shot adaptation to new guidelines/sites: **Medium-High**

## Next Checks
- Adversarial Guideline Stress Test: Systematically perturb validated guidelines (e.g., synonym substitution, logical negation, adding contradictory clauses) to measure plan failure rate and identify prompt engineering gaps.
- OAR Failure Isolation Audit: Run the pipeline with intentionally degraded OAR segmentations (e.g., by dropping specific structures or injecting noise) to quantify their contribution to final Dice loss and identify critical failure points.
- Multi-Center, Multi-Anatomical Blinded Study: Replicate the blinded clinical evaluation across 2-3 additional institutions with diverse patient demographics and guideline variants for at least two new anatomical sites (e.g., lung, cervix).
