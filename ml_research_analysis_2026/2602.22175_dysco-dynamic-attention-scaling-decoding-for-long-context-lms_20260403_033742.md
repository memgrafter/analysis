# DySCO: Dynamic Attention-Scaling Decoding for Long-Context LMs

## Quick Facts
- **arXiv ID**: 2602.22175
- **Source URL**: https://arxiv.org/abs/2602.22175
- **Reference count**: 40
- **Primary result**: Training-free decoding that dynamically up-weights attention to task-relevant tokens, yielding up to 25% relative gains on long-context reasoning benchmarks at 128K context.

## Executive Summary
DySCO is a training-free decoding algorithm that mitigates accuracy degradation in language models processing long contexts. It addresses misaligned attention by dynamically identifying task-relevant tokens at each generation step using a small set of specialized “retrieval heads” and explicitly up-weighting attention to those tokens across all heads. The method requires no model modifications and adds minimal compute overhead (~4% FLOPs at 128K context). Evaluations on Qwen3-4B/8B/32B and Llama-3.1-8B show consistent improvements on long-context reasoning benchmarks, achieving up to 25% relative gains on MRCR and LongBenchV2 at 128K context versus strong baselines like YaRN and uniform attention scaling. DySCO also boosts recall task performance and can outperform RAG and prompt compression methods in some settings.

## Method Summary
DySCO operates as a wrapper during decoding without altering model parameters. At each generation step, it uses a predefined subset of “retrieval heads” to compute attention scores over the full context. These scores are aggregated into a relevance score per context token. The relevance scores are then transformed into multiplicative factors that scale the attention logits of all heads before softmax. This dynamic reweighting amplifies the influence of tokens deemed relevant, correcting the uniform attention distributions that plague long contexts. The approach adds only a small computational burden because only a few retrieval heads are used for relevance estimation.

## Key Results
- Up to 25% relative improvement on long-context reasoning benchmarks (MRCR, LongBenchV2) at 128K context.
- Outperforms YaRN and uniform attention scaling across Qwen3 and Llama-3.1 models.
- Enhances recall task performance and surpasses RAG/prompt compression in certain evaluations.

## Why This Works (Mechanism)
DySCO corrects attention misalignment caused by softmax dilution over many tokens. Retrieval heads dynamically pinpoint tokens relevant to the current generation step. Up-weighting these tokens across all heads ensures the model focuses on critical information. This targeted guidance leverages the model’s existing attention capacity but steers it toward salient context, all without retraining.

## Foundational Learning
1. **Attention Misalignment in Long Contexts**  
   *Why needed*: Core problem—accuracy drops as context grows due to unfocused attention.  
   *Quick check*: Evaluate a fixed task while increasing context length; a sharp decline indicates misalignment.

2. **Retrieval Heads**  
   *Why needed*: Specialized heads efficiently identify relevant tokens without full-model cost.  
   *Quick check*: Inspect attention patterns of individual heads on a retrieval task; heads consistently attending to gold-standard relevant tokens are candidates.

3. **Dynamic Token Up-Weighting**  
   *Why needed*: Amplify influence of selected tokens to correct attention distribution.  
   *Quick check*: Apply a constant up-weighting factor to known relevant tokens and observe performance changes; sensitivity indicates need for dynamic scaling.

4. **Training-Free Adaptation**  
   *Why needed*: Apply the method to any pretrained model without fine-tuning.  
   *Quick check*: Wrap a pretrained model with DySCO and test on a long-context benchmark; gains without parameter changes confirm viability.

## Architecture Onboarding
- **Component Map**: Input tokens → Retrieval heads → Relevance scorer → Up-weighting factor generator → Attention logit modifier → Modified attention → Generation. In plain text: Model’s existing attention heads are intercepted; a subset (retrieval heads) computes relevance scores, which are transformed into scaling factors applied to all heads’ logits before softmax.

- **Critical Path**: At each decoding step: (1) Compute queries, keys, values for all heads. (2) For each retrieval head, compute attention scores with context tokens. (3) Aggregate scores across retrieval heads to get a relevance score per token. (4) Transform relevance into multiplicative factors. (5) Multiply each attention logit by its token’s factor. (6) Apply softmax and aggregate values.

- **Design Tradeoffs**:
  - Number of retrieval heads: More improves relevance estimation but increases compute; too few risks missing signals.
  - Up-weighting strength: Aggressive scaling may cause over-concentration; weak scaling may be ineffective.
  - Dynamic vs static relevance: Per-step adaptivity vs. lower overhead.

- **Failure Signatures**:
  - Performance drops on tasks where relevant tokens are not identifiable by retrieval heads (e.g., global reasoning).
  - Attention collapse from excessive up-weighting, reducing diversity.
  - Memory overhead becomes prohibitive for extremely long contexts if per-token relevance is stored per step.

- **First Experiments**:

  3. **Hyperparameter Sensitivity**: Vary number of retrieval heads (1, 2, 4, 8) and up-weighting factors (1.0, 1.5, 2.0, 5.0) on a validation set to find robust defaults and performance boundaries.

## Limitations
- Model coverage limited to Qwen3 and Llama-3.1-8B; generalizability to other architectures is uncertain.
- Benchmarks restricted to reasoning and recall; performance on other long-context tasks (summarization, translation) not reported.
- No ablations on hyperparameters (retrieval head count, up-weighting strength) or memory overhead, leaving robustness and practicality unclear.
