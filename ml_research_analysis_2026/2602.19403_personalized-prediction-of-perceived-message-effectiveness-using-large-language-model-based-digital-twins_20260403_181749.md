# Personalized Prediction of Perceived Message Effectiveness Using Large Language Model Based Digital Twins

## Quick Facts
*   **arXiv ID:** 2602.19403
*   **Source URL:** https://arxiv.org/abs/2602.19403
*   **Reference count:** 40
*   **Primary result:** LLM-based digital twins, conditioning on individual participant profiles and prior message ratings, significantly outperformed zero/few-shot LLMs and traditional supervised models in predicting perceived message effectiveness for smoking cessation interventions.

## Executive Summary
This study tackles the personalization challenge in health messaging by predicting individual-level perceived message effectiveness (PME). The authors introduce "LLM-based digital twins," a method that uses large language models (LLMs) to simulate a person's message preferences by providing the model with that individual's static demographic/psychographic profile and their history of ratings on previous messages. Evaluated on a dataset of 301 participants, the digital twin approach consistently achieved higher prediction accuracy and greater output dispersion across rating categories compared to standard zero/few-shot prompting and traditional machine learning baselines. The results suggest that personalizing LLM context with user-specific history is a powerful strategy for tailoring health interventions.

## Method Summary
The study used a dataset of 3,010 ratings from 301 participants who evaluated smoking cessation messages across three domains (content, coping support, quitting support) on a 5-point scale. A within-participant split allocated 7 prior message ratings for conditioning/training and 3 for held-out testing. Models compared included: (1) traditional supervised learners (logistic regression, random forest) trained on participant features only; (2) zero-shot and few-shot (2 examples) LLM prompting with static participant features; and (3) the proposed LLM-based digital twin, which conditioned the LLM on the full participant profile plus all 7 prior message-rating pairs. Performance was evaluated using exact accuracy, directional accuracy (collapsed 3-point scale), Cohen's κ, and macro-F1.

## Key Results
*   The best digital twin configurations achieved exact 5-class accuracies of 0.49 (content), 0.45 (coping), and 0.49 (quitting), improving upon zero/few-shot LLMs by ~12 percentage points and supervised baselines by ~13 points.
*   Directional accuracies on a 3-point scale reached 0.75, 0.66, and 0.70, respectively.
*   Digital twin predictions showed significantly greater dispersion across rating categories, indicating enhanced sensitivity to individual-level variation in message perception, unlike the concentrated outputs of other models.

## Why This Works (Mechanism)
### Mechanism 1: Personalized History Conditioning
*   **Claim:** LLM-based digital twins personalize predictions by conditioning on individual-specific historical message ratings and profiles.
*   **Mechanism:** The prompt includes a participant's static features and their specific ratings for prior messages, creating a "digital twin" that simulates that person's judgment pattern for a new message, moving beyond population-level trends.
*   **Core Assumption:** An individual's past ratings reliably predict future preferences on similar messages, and an LLM can infer a consistent persona from this history.
*   **Evidence Anchors:** The paper explicitly defines the digital twin framework as an extension of few-shot learning contextualized at the individual level [section 2.2.3]. Break condition: Low intra-rater reliability would make the history a noisy signal.

### Mechanism 2: Failure of Generic Context
*   **Claim:** Zero-/few-shot LLMs underperform because they lack persistent, person-specific context and must infer preferences from sparse, generic prompts.
*   **Mechanism:** These models receive only the new message text and a static list of participant features (zero-shot) or a few randomly selected examples not tied to the target user (few-shot). They rely on general associations, failing to capture idiosyncratic preferences.
*   **Core Assumption:** General LLM knowledge is insufficient for nuanced, individual-level PME prediction without personalized conditioning data.
*   **Evidence Anchors:** Reported zero-shot accuracy was only 24.2-39.1%. Few-shot yielded ≤4 percentage point gains [section 3.1]. Both baselines showed concentrated predictions [section 3.2].

### Mechanism 3: Capturing Individual Heterogeneity
*   **Claim:** Digital twins achieve greater prediction dispersion because they model individual preference distributions rather than collapsing to population modes.
*   **Mechanism:** Learning from a participant's specific rating history allows the digital twin's predictions to reflect that person's unique range of favorable/unfavorable responses, resulting in a wider spread of scores across the 5-point scale.
*   **Core Assumption:** Individual PME judgments vary meaningfully across messages for a given person; a good model should reflect this within-person variance.
*   **Evidence Anchors:** The paper reports digital twin predictions exhibited "greater dispersion across rating categories" [section 3.2], with Figure 3 histograms showing a spread across all five categories compared to concentrated predictions from other models.

## Foundational Learning
*   **Concept: Digital Twin Simulation**
    *   **Why needed:** Understanding that a "digital twin" here is a prompting strategy—conditioning an LLM on a specific user's data—not a separate model architecture, is key to implementation.
    *   **Quick Check:** How does the digital twin prompt structure differ from a few-shot prompt in this study?
*   **Concept: Perceived Message Effectiveness (PME)**
    *   **Why needed:** PME is the multi-dimensional, ordinal (5-point Likert) target outcome that defines the prediction task and evaluation metrics.
    *   **Quick Check:** Why did the authors evaluate both exact 5-class accuracy and directional 3-class accuracy?
*   **Concept: In-Context Learning vs. Fine-Tuning**
    *   **Why needed:** All LLM approaches used are zero/few-shot (in-context learning), not fine-tuned. This affects data efficiency requirements and the central role of the prompt.
    *   **Quick Check:** What is the practical implication of using in-context learning for a new health domain with limited labeled data?

## Architecture Onboarding
*   **Component map:**
    Participant Static Profile + Participant Dynamic History (7 prior ratings) -> Prompt Assembly Engine -> LLM Inference Core (API call) -> Structured JSON Prediction -> Evaluation Module -> Metrics (Accuracy, κ, F1)
*   **Critical path:** For each participant and hold-out message: load participant data -> assemble model-specific prompt (prevent leakage) -> call LLM API -> parse JSON response -> compare to true label -> aggregate metric.
*   **Design tradeoffs:**
    *   **History size:** More ratings (1-10) may improve personalization but risk context window limits or noise. Study found stable performance from 1-7 ratings.
    *   **Feature set:** "All features" (23) vs. "selected features" (5). More features may add signal but increase prompt complexity; selected features performed reasonably well.
    *   **Model choice:** Performance varied by up to 10 percentage points between LLM vendors, involving tradeoffs between cost, latency, and accuracy.
*   **Failure signatures:**
    *   **Prediction collapse:** Model predicts only 1-2 categories for all messages (observed in baselines, Fig 3). Indicates failure to leverage individual variation.
    *   **History misuse:** LLM ignores provided history, predicting based on message text or generic stereotypes.
    *   **Format drift:** LLM output does not conform to required JSON schema, breaking automated evaluation.
*   **First 3 experiments:**
    1.  **Baseline replication:** Reproduce Table S1-S3 for one model (e.g., GPT-5) to validate the pipeline matches the paper's reported digital twin accuracy (~0.49).
    2.  **Ablation - History:** Run the digital twin prompt with the same participant profile but **zero** history messages. Expect a significant accuracy drop (~12 points), confirming history is the key driver.
    3.  **Sensitivity - Feature set:** Compare "digital twin with all features" vs. "digital twin with selected features" for a single LLM. Quantify the accuracy difference to justify using the simpler prompt.

## Open Questions the Paper Calls Out
1.  **What specific factors account for the ~19% within-person variability in PME ratings not captured by the models?** The authors note that intra-individual fluctuations (momentary affect, context) are not recoverable from static metadata or simple prompts.
2.  **Do LLM-based digital twin predictions reflect true individual-level preference learning, or are they primarily recombining population-level patterns?** While showing greater dispersion, it's unclear if personalization arises from genuine modeling of participant history or from the LLM's pre-existing priors.
3.  **Are the reported improvements in directional accuracy sufficient to meaningfully improve downstream smoking cessation outcomes?** The link between predicting PME and changing actual behavior is assumed but not validated; a prospective trial is needed.
4.  **What is the minimal viable personalization data required to initialize a functional digital twin?** The study used 7 prior ratings and noted stable performance with as few as one, but the precise trade-off curve is not quantified.
5.  **How do the costs (financial, latency) of digital twin prompting scale for real-time, high-volume deployment?** The paper focuses on accuracy; operational scalability for a live mHealth system remains an open engineering question.

## Limitations
*   **Reproducibility gaps:** Unclear details on few-shot example selection, supervised model preprocessing (categorical encoding, missing values), exact LLM API parameters (temperature), and precise prompt formatting hinder exact replication.
*   **Generalizability:** Evaluation is confined to a single smoking cessation dataset (301 participants). Performance in other health domains or with different message modalities is unknown.
*   **Causal attribution:** The performance gain could stem from the *content* of personalized history or simply from increased context length; this distinction is not experimentally isolated.

## Next Checks
1.  **History Ablation Test:** For fixed participants, run the digital twin prompt with the same profile but **progressively remove** prior ratings (7 → 3 → 0). A steep accuracy drop would confirm personalization, not context length, drives performance.
2.  **History Donor Swap:** For participant A, construct a prompt using A's profile but **B's** rating history (and vice versa). If predictions follow the *history donor's* pattern, it confirms the LLM uses the provided individual context.
3.  **Cross-Domain Generalizability:** Apply the digital twin framework (same prompt structure) to a **different PME dataset** (e.g., physical activity messages). A significant drop in the personalization advantage would indicate domain-specificity.
