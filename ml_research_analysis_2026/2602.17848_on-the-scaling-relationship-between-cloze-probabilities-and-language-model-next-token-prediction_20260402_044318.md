# On the scaling relationship between cloze probabilities and language model next-token prediction

## Quick Facts
- **arXiv ID**: 2602.17848
- **Source URL**: https://arxiv.org/abs/2602.17848
- **Reference count**: 23
- **Primary result**: Larger language models align more with human cloze probabilities but systematically under-allocate probability to human-chosen completions; data deduplication consistently improves alignment.

## Executive Summary
This study evaluates how well language model next-token predictions match human cloze probabilities across model scales. Using the Pythia suite (14M–2.8B parameters) and a large English cloze dataset, the authors find that lexical correlation with human responses improves with model size and data deduplication. However, models consistently assign lower probabilities to human-preferred tokens. Analyses of n-gram baselines and semantic representational similarity indicate that larger models rely less on surface statistics and more on semantic fit, though gains in semantic alignment are modest. Results suggest that scaling and deduplication enhance the semantic grounding of model predictions.

## Method Summary
The task is to assess alignment between language model next-token distributions and human cloze probabilities from the Peelle et al. (2020) dataset (3,085 English sentence stems, ≥100 responses each). Inputs include Pythia models (standard and deduplicated variants, 14M–2.8B parameters), a Wikipedia-trained 5-gram baseline (2023-11-01 dump, GPT-2 tokenizer, Stupid Backoff α=0.4), and human responses mapped to first subwords via the GPT-2 tokenizer. Key metrics are: Spearman’s ρ for lexical rank alignment; correlation with 5-gram ranks; representational similarity analysis (RSA) on PPMI-weighted context matrices; and average Jaccian neighborhood overlap for top-k neighbors in static embedding spaces. Procedure: for each preamble, derive LM next-token distribution; extract probabilities for human response first subwords; rank within preamble; pool ranks across stems to compute ρ. For semantics, form top-40 completion sets per preamble, generate contextual embeddings with Pythia-2.8B, derive static vectors, and compute RSA/neighborhood overlap. Mixed-effects regression on logit-probabilities probes systematic biases.

## Key Results
- Larger models show stronger lexical correlation with human cloze ranks (Spearman ρ up to 0.485), but systematically under-allocate probability to human-preferred tokens.
- Data deduplication consistently improves lexical alignment across all model sizes.
- Correlation with 5-gram statistics decreases with model size (from ρ=0.57 to 0.44), indicating reduced reliance on n-gram memorization.
- Semantic alignment (RSA and neighborhood overlap) exhibits modest, size-dependent improvements; all models maintain ~50% neighborhood overlap with human semantic spaces.

## Why This Works (Mechanism)
Scaling model size and applying data deduplication enhance the semantic grounding of next-token predictions. Larger models develop richer contextual representations that better capture human-like semantic associations, moving beyond surface-level n-gram statistics. Deduplication reduces training-set memorization, forcing models to generalize to underlying linguistic patterns. The decreasing correlation with 5-gram baselines and modest gains in semantic similarity metrics suggest that while scaling improves alignment, qualitative differences remain in how models and humans conceptualize word relationships.

## Foundational Learning
- **Cloze task**: A psycholinguistic paradigm where participants complete sentence fragments; provides human ground truth for lexical expectation. *Why needed*: Establishes the target distribution for model evaluation. *Quick check*: Verify the Peelle dataset has ≥100 responses per stem.
- **Spearman’s ρ**: Rank correlation coefficient. *Why needed*: Measures monotonic alignment between human and model rankings without linearity assumptions. *Quick check*: Compute on a small stem subset; expect ρ > 0 for larger models.
- **PPMI (Positive Pointwise Mutual Information)**: Weighted word-context association. *Why needed*: Constructs distributional semantic spaces for RSA. *Quick check*: Ensure PPMI matrix is sparse and dimensionality reduction retains variance.
- **RSA (Representational Similarity Analysis)**: Correlation between pairwise similarity matrices. *Why needed*: Compares semantic structure across human and model spaces. *Quick check*: Use the same word intersection (W) for both matrices.
- **Tokenizer consistency**: Using GPT-2 tokenizer across models and human responses. *Why needed*: Guarantees comparable subword units. *Quick check*: Check that ~50% of human responses are single tokens.
- **Mixed-effects modeling**: Accounts for random variation across stimuli and responses. *Why needed*: Isolates systematic bias while controlling for preamble/response effects. *Quick check*: Inspect random effect variances; ensure model convergence.

## Architecture Onboarding
Component map: Peelle Dataset -> GPT-2 Tokenizer -> Pythia Models (standard/deduped) -> Next-Token Distribution -> Probability Extraction -> Lexical/Semantic Metrics -> 5-gram Baseline -> Analysis

Critical path:
1. Load Peelle dataset; map human responses to first subword IDs.
2. For each Pythia model, run forward passes on preambles to obtain next-token distributions.
3. Align LM probabilities with human response IDs; compute within-stem ranks.
4. Aggregate rank pairs across stems; compute Spearman’s ρ.
5. Train 5-gram on Wikipedia; repeat ranking and correlation with human/LM ranks.
6. Build top-40 completion sets per preamble; generate contextual embeddings via Pythia-2.8B.
7. Derive static vectors by averaging embeddings per word across occurrences.
8. Construct PPMI matrices; reduce via PCA; compute RSA on cosine similarity matrices for word intersection W.
9. Compute neighborhood overlap (Jaccard) for top-k neighbors in human and LM spaces.

Design tradeoffs:
- First-subword simplification discards multi-token response information but ensures tokenization alignment.
- Top-40 completion set balances coverage and noise; stems with fewer responses may be under-represented.
- Using Pythia-2.8B for contextual embeddings introduces size bias but provides high-quality representations.

Failure signatures:
- Tokenization mismatch: Low coverage of human response tokens in model vocabulary; check token ID mapping success rate.
- 5-gram correlation drift: Implementation deviations (e.g., smoothing, backoff) may obscure the decreasing trend with model size.
- Neighborhood overlap instability: Sensitive to top-k choice and PCA dimension; require sensitivity analysis.

First experiments:
1. Tokenization coverage: Compute percentage of human responses that are single GPT-2 tokens; expect ~50%.
2. Baseline 5-gram sanity: Train on a 1% Wikipedia sample; verify common bigram probabilities (e.g., "the of" ≈ 0.02).
3. Minimal model test: Run Pythia-14M on 10 preambles; confirm next-token distribution sums to ~1 and has entropy > 2.0.

## Limitations
- Peelle dataset source is not explicitly provided in the paper.
- Semantic analysis details (e.g., PCA dimensionality, exact top-k for neighborhoods) are unspecified.
- 5-gram implementation parameters (zero handling, backoff recursion) are omitted.
- Reduction to first subword may oversimplify multi-token human responses.
- Findings are limited to English; cross-lingual generalizability is unknown.

## Confidence
- Scaling improves lexical alignment: High
- Deduplication improves alignment: High
- Systematic under-allocation of human choices: Medium
- Decreasing 5-gram correlation with size: Medium
- Modest semantic improvements (RSA/neighborhood): Low
- Overall scaling+deduplication enhance semantic alignment: Medium
