# A Closer Look into LLMs for Table Understanding

## Quick Facts
- **arXiv ID:** 2603.15402
- **Source URL:** https://arxiv.org/abs/2603.15402
- **Reference count:** 40
- **Primary result:** LLMs process tables via a three-phase attention pattern; MoE models activate table-specialized experts in middle layers; CoT and table-tuning significantly boost accuracy; causal masking of early-to-middle layers causes 44–65 point drops.

## Executive Summary
This paper empirically investigates the internal mechanisms by which large language models (LLMs) process tabular data. Analyzing 16 models across attention dynamics, effective layer depth, Mixture-of-Experts (MoE) activation, and input design, the study reveals a consistent three-phase attention pattern: early layers broadly scan the table, middle layers localize query-relevant cells with minimal entropy, and late layers amplify contributions for answer generation. Table-specific tasks require deeper layer engagement than mathematical reasoning, and MoE models activate distinct table-specialized experts primarily in middle layers, with minimal overlap from experts used for math tasks. Input format and prompting strategy further modulate attention—HTML tables initially increase entropy but converge later, while Chain-of-Thought (CoT) prompting increases table attention, an effect amplified by table-specific fine-tuning.

## Method Summary
The authors analyze 16 LLMs (general-purpose instruct, table-tuned, and MoE variants) on four table QA datasets (WTQ, HiTab, AITQA, TabFact) using 500 samples per dataset. Key metrics include layer-wise segment attention ratio, table attention entropy, value-weighted contribution, and effective depth via LogitLens (KL divergence and token overlap). Causal masking tests functional necessity by zeroing table attention in specified layer blocks. For MoE models, expert activation entropy and task overlap (e.g., with math) are tracked. Comparisons are made across input formats (Markdown vs. HTML) and prompting strategies (Direct vs. CoT).

## Key Results
- LLMs exhibit a three-phase attention pattern: early high-entropy scanning, middle low-entropy localization of query-relevant cells, late amplification of those cells for output generation.
- MoE models activate table-specific experts in middle layers; these experts show minimal overlap with those engaged for math tasks.
- CoT prompting increases table attention ratio, especially in table-tuned models (e.g., Table-R1-7B accuracy rose from 69.75% to 82.30% with CoT).
- HTML tables initially increase attention entropy versus Markdown but representations converge in later layers.
- Masking table attention in early-to-middle layers causes severe performance degradation (44–65 point drops).

## Why This Works (Mechanism)
### Mechanism 1: Three-Phase Attention Pattern
LLMs process tabular data through a systematic evolution of attention distributions. Early layers distribute attention widely across all table cells (high entropy), encoding full structure. Middle layers concentrate attention on a small set of query-relevant cells (low entropy), effectively localizing key information. Late layers slightly disperse attention while increasing the value-weighted contribution of localized cells, amplifying their influence on output generation. Functional causality is confirmed by causal masking: zeroing table attention in early-to-middle layers causes 44–65 point accuracy drops across models. Evidence includes U-shaped entropy curves and cell-level heatmaps showing localization.

### Mechanism 2: MoE Expert Specialization
In Mixture-of-Experts models, the routing mechanism engages distinct, table-specialized experts primarily in middle layers. Activation entropy reaches a minimum in these layers, indicating concentrated specialization. Overlap analysis shows these table experts are largely separate from experts activated on math tasks, suggesting functional specialization. Early and late layers share more general-purpose experts across domains. Evidence includes entropy minima for DeepSeek-V2, Qwen3-30B-A3B, and OLMoE, alongside low overlap metrics between table and math task activations.

### Mechanism 3: Input Format and Reasoning Strategy Modulation
Input format affects early-layer attention: HTML tables, with explicit tags (`<tr>`, `<td>`), increase attention entropy initially due to syntactic verbosity, but deeper layers extract semantic structure, causing representations to converge with Markdown. Chain-of-Thought prompting increases table attention ratio in middle and late layers by forcing repeated reference to table content, an effect amplified by table-specific fine-tuning. Evidence includes entropy comparisons, t-SNE visualizations of convergence, and performance gains with CoT.

## Architecture Onboarding
**Component map:**  
Input Segmentor -> Layer-wise Attention Analyzer -> Causal Masking Module -> LogitLens Projector -> MoE Expert Tracker -> Format/Strategy Comparator

**Critical path:**  
1. Preprocessing: Serialize tables into Markdown/HTML and generate Direct/CoT prompts.  
2. Forward Pass with Hooks: Run samples, capturing attention weights, hidden states, and MoE routing at every layer.  
3. Metric Computation: Calculate segment ratios, table entropy, value-weighted contributions, LogitLens distributions.  
4. Aggregation & Visualization: Average metrics, plot trends (entropy U-curve, KL divergence).  
5. Causal Tests: Apply attention masking blocks and remeasure accuracy; compute expert overlap matrices.

**Design tradeoffs:**  
- Granularity vs. Compute: Cell-level heatmaps provide rich detail but scale poorly with table size; sample key rows for large tables.  
- Metric Selection: Entropy is sensitive to table token count; normalization may be needed for format comparisons.  
- Generalization: The three-phase pattern holds for TQA/TFV tasks; complex tasks (e.g., spreadsheet manipulation) may differ—start with simple lookups to validate.

**Failure signatures:**  
- Entropy curve not U-shaped: Model may not localize query-relevant cells.  
- No performance drop from masking: Model might rely on heuristics or late-layer shortcuts.  
- MoE entropy flat: Routing may be random or uniform, lacking specialization.  
- Format divergence persists: Model remains brittle to input format changes.

**First 3 experiments:**  
1. Replicate three-phase pattern with Llama-3.1-8B on WTQ (Markdown), expecting U-shaped entropy curve and rising contribution.  
2. Causal masking test: Mask layers 1–8 and 9–16; expect >40 point accuracy drop for early blocks.  
3. MoE expert entropy: Run Qwen3-30B-A3B on table vs. math data; expect middle-layer entropy minimum for tables and low expert overlap.

## Open Questions the Paper Calls Out
- How do internal mechanisms of table understanding (attention dynamics, effective depth, expert activation) scale with model size, particularly for LLMs exceeding 32B parameters?
- Do multimodal LLMs (MLLMs) that process table images exhibit similar three-phase attention patterns and layer engagement as text-serialized table processing in unimodal LLMs?

## Limitations
- Sample selection for 500-example splits lacks randomization details, risking selection bias.
- Causal masking implementation (attention weight zeroing specifics) is underspecified, hindering reproducibility.
- MoE "table-specific expert" definitions (thresholds, baselines) are ambiguous, limiting cross-model comparisons.

## Confidence
- **Three-phase attention pattern:** High confidence (causal masking shows 44–65 point drops, providing functional evidence).
- **MoE expert specialization:** Medium confidence (entropy minima and overlap metrics are suggestive but lack robustness across architectures).
- **Input format/CoT effects:** Medium confidence (trends align but convergence relies on t-SNE; model-scale interactions unexplored).

## Next Checks
