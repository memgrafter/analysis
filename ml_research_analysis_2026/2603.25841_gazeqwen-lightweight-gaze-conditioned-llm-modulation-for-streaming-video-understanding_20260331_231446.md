# GazeQwen: Lightweight Gaze-Conditioned LLM Modulation for Streaming Video Understanding
## Quick Facts
- **arXiv ID:** 2603.25841
- **Source URL:** https://arxiv.org/abs/2603.25841
- **Reference count:** 23
- **Primary result:** GazeQwen achieves 63.9% accuracy on StreamGaze, exceeding GPT-4o by +10.5 points and the same Qwen2.5-VL backbone with gaze prompts by +16.1 points.

## Executive Summary
Current multimodal LLMs cannot effectively use eye-gaze data for video understanding, even when explicitly provided via prompts or visual overlays. GazeQwen solves this by directly injecting gaze information into the LLM’s hidden states. It uses a tiny (~1–5M parameter) gaze resampler that encodes both V-JEPA video features and fixation coordinates, producing additive residuals that are injected into multiple decoder layers via forward hooks; an optional LoRA stage further adapts the LLM. On the StreamGaze benchmark, GazeQwen reaches 63.9% accuracy, significantly outperforming GPT-4o (+10.5 pp) and a gaze-prompted Qwen2.5-VL (+16.1 pp), with especially large gains on spatially dependent tasks.

## Method Summary
GazeQwen augments a frozen MLLM (Qwen2.5-VL-7B) with a lightweight gaze resampler trained in two stages. The resampler takes spatial-temporal features from a frozen V-JEPA encoder and sinusoidal encodings of active fixations, and produces a residual vector via a cross-attention bottleneck with reverse attention. Four independent resamplers (one per injected layer) generate residuals that are added to the LLM decoder’s hidden states at layers 6, 13, 20, and 27 using PyTorch forward hooks. Stage 1 trains only the resamplers with the LLM frozen; Stage 2 adds rank-8 LoRA adapters to the LLM’s Q/V projections for tighter integration. This design avoids modifying the LLM’s forward pass and keeps added parameters minimal.

## Key Results
- GazeQwen achieves 63.9% accuracy on StreamGaze, outperforming GPT-4o by +10.5 points and gaze-prompted Qwen2.5-VL by +16.1 points.
- Largest improvements on spatially-dependent tasks: +34.1 pp on Object Appearance Alert, +29.4 pp on Object Tracking in Past.
- Ablation confirms all design choices contribute: per-layer resamplers, sinusoidal gaze encoding, V-JEPA backbone, and LoRA each improve performance.

## Why This Works (Mechanism)
**Mechanism 1: Direct hidden-state injection**
Gaze residuals are injected at multiple decoder layers via hooks, rather than as input tokens. This allows gaze to influence both low-level and high-level representations. Evidence: Section 2.3 describes injection at four evenly-spaced layers; corpus shows novelty.

**Mechanism 2: Per-layer resamplers**
Independent resamplers for each injected layer allow gaze conditioning tailored to the representation semantics at that depth. Evidence: Table 2 shows per-layer (4 ind.) gains +5.2pp over shared on OAR.

**Mechanism 3: Two-stage training**
First train only small resamplers with frozen LLM to avoid catastrophic forgetting; then add LoRA for fine-grained adaptation. Evidence: Section 2.4 and Table 2 show LoRA gives additional +5.2pp on OI-Hard.

## Foundational Learning
- **PyTorch Forward Hooks:** Needed to inject residuals into intermediate activations without altering model code. Quick check: How to register a hook that adds a learned residual to the output of a transformer decoder layer?
- **Sinusoidal Positional Encoding for Sparse Coordinates:** Encodes fixation coordinates with high precision, preserving sub-pixel detail unlike discretized heatmaps. Quick check: Why might Gaussian heatmaps lose spatial precision compared to sinusoidal encoding?
- **Separate Visual Backbone (V-JEPA):** Provides fine-grained spatiotemporal features that retain spatial detail for gaze alignment, unlike the host LLM's vision encoder optimized for language grounding. Quick check: What property of V-JEPA makes it suitable for gaze-aligned video features?

## Architecture Onboarding
Component map: Video frames → V-JEPA 2.1 encoder → spatial-temporal feature grids (F_t) → per-time-step resampler (with active fixations A_t) → residuals R_t → injected via hooks into LLM decoder layers (6,13,20,27) of Qwen2.5-VL-7B (plus optional LoRA) → answer logits.

Critical path: The resampler must produce residuals that meaningfully bias the LLM's spatial attention toward gaze-attended regions; successful integration hinges on correct alignment of V-JEPA features to LLM's visual token grid and proper initialization of residual projections.

Design tradeoffs: Per-layer resamplers add parameters but yield depth-specific conditioning; frozen LLM + LoRA avoids catastrophic forgetting but may limit integration depth; sinusoidal PE preserves precision but heatmaps may be more intuitive.

Failure signatures: Accuracy ≈ Qwen2.5-VL baseline (47.8%) suggests trivial zero residuals; training crashes indicate shape mismatches; gains only on "Present" tasks but not "Past" or "Proactive" may indicate ineffective temporal scanpath history capture.

First 3 experiments:
1. Layer injection ablation: Vary number and positions of injected layers (1,2,4,8,all) to confirm optimal four layers (6,13,20,27).
2. Resampler architecture sweep: Replace cross-attention bottleneck with simpler MLP or remove reverse cross-attention to test necessity.
3. Gaze encoding robustness test: Perturb fixation coordinates with noise (e.g., ±5% normalized) and compare sinusoidal PE vs. Gaussian heatmaps for degradation.

## Open Questions the Paper Calls Out
- Does GazeQwen's modulation generalize to other MLLM architectures beyond Qwen2.5-VL?
- How robust is GazeQwen to noise and inaccuracies in real-world gaze estimates?
- What is the impact of the two-stage training (resampler then LoRA) versus joint end-to-end training?
- Why do tasks OI-Easy and FAP show negligible gains from gaze, and how can the model be improved for high-level reasoning?

## Limitations
- Benchmark scope: StreamGaze covers only egocentric videos; unknown if gains hold for third-person or diverse video QA tasks.
- Missing details: Interpolation parameters for aligning V-JEPA features and LoRA configuration (e.g., dropout, target modules) impede exact replication.
- Component trade-offs: Per-layer resamplers increase parameters (~4×); a shared dynamic variant might match performance. V-JEPA’s role vs. using the host LLM’s visual encoder remains unclear.

## Confidence
- Hidden-state modulation effectiveness: Medium (large improvement over gaze prompts but only on one benchmark).
- Per-layer resamplers: Medium (ablation shows +5.2pp but may be dataset-specific).
- Two-stage training (resamplers → LoRA): Medium (LoRA adds +5.2pp on OI-Hard but no direct comparison to joint training).

## Next Checks
1. Layer injection ablation: Systematically vary number and positions of injected layers.
2. Gaze encoding robustness: Replace sinusoidal PE with Gaussian heatmaps under increasing coordinate noise.
3. Cross-dataset generalization: Test on external gaze-video QA dataset (e.g., EyeTrackUAV).
