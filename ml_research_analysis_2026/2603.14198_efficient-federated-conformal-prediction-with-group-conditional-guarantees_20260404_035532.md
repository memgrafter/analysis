# Efficient Federated Conformal Prediction with Group-Conditional Guarantees
## Quick Facts
- **arXiv ID:** 2603.14198
- **Source URL:** https://arxiv.org/abs/2603.14198
- **Reference count:** 40
- **Primary result:** GC-FCP guarantees group-conditional coverage with additive error π/δ, reduces communication to O(Kδ) and computation to O(δ^{3/2}|G|^2), and achieves up to 34× speedup over centralized CondCP while maintaining competitive set sizes.

## Executive Summary
Federated conformal prediction (FCP) currently offers only marginal coverage guarantees, which fail to ensure valid coverage for overlapping group-conditional strata that reflect client-specific or cross-cutting patterns. This paper introduces GC-FCP, a novel framework that compresses locally stratified calibration scores into mergeable T-Digest coresets defined over atoms (unique group membership patterns). The server aggregates these coresets and solves a weighted quantile regression over group indicators to produce adaptive thresholds. Theoretically, GC-FCP achieves group-conditional coverage with an additive error term π/δ (Theorem 5.1). It significantly improves communication (O(Kδ) vs. O(n)) and computational complexity (O(δ^{3/2}|G|^2) vs. O(n^{3/2}|G|^2)). Empirical evaluations on CIFAR-10 and PathMNIST demonstrate near-target group coverage (e.g., 0.903 vs. 0.879 for baselines) and up to 34 times speedup compared to centralized CondCP, without sacrificing set size efficiency.

## Method Summary
GC-FCP operates in two phases: calibration and prediction. During calibration, each client computes conformity scores for its local calibration data using a shared pretrained model. The clients partition these scores according to atoms—disjoint regions defined by all combinations of overlapping groups—and construct a T-Digest for each atom. The T-Digest uses an arcsine scale function and a compression parameter δ to produce a weighted coreset that accurately approximates the empirical CDF within an additive error bound. Clients transmit their digests to the central server. The server merges digests atom-wise to obtain a global coreset that preserves the weighted score distributions. It then solves a convex weighted quantile regression problem (via its dual linear program) over group indicator variables to determine a threshold function adaptive to the groups. At prediction time, for a new test point, the server computes the group membership vector and applies the threshold to construct the conformal prediction set. The method requires known mixture weights πk (client proportions in the target population) and respects exchangeability within each client.

## Key Results
- Group-conditional coverage guarantee with explicit additive error π/δ (Theorem 5.1), even under overlapping groups.
- Communication reduced to O(Kδ) and computation to O(δ^{3/2}|G|^2), yielding up to 34× speedup versus centralized CondCP.
- Empirical group coverage on CIFAR-10 reaches 0.903 (vs. 0.879 for baselines) and on PathMNIST, with set sizes comparable to centralized methods.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** GC-FCP reduces communication and computation by compressing locally stratified calibration scores into mergeable T-Digest coresets per atom.
- **Mechanism:** Each client partitions its calibration scores by atom (disjoint region defined by overlapping groups), then applies T-Digest sketching (clustering with weight-based limits) to each partition. The server merges these digests atom-wise, preserving weighted empirical CDF structure within an additive error bound controlled by compression parameter δ.
- **Core assumption:** T-Digest’s arcsine scale function yields a maximal cluster mass ρmax ≤ sin(π/δ), which bounds the uniform CDF approximation error (Lemma 5.1).
- **Evidence anchors:** [abstract] "GC-FCP compresses locally stratified calibration scores into mergeable T-Digest coresets per atom." - **Break condition:** If δ is too small (aggressive compression), ρmax grows, degrading quantile accuracy and violating coverage (Theorem 5.1 additive term π/δ).

### Mechanism 2
- **Claim:** The server performs weighted quantile regression over group indicators using merged digests, approximating the federated augmented quantile estimator (10).
- **Mechanism:** The server solves a convex optimization (22) that weights each atom’s digest entries by mixture weights πk and local sample counts nk. This dualizes to a linear program enforcing a linear combination of group-membership indicators, yielding group-adaptive thresholds.
- **Core assumption:** The first-order optimality condition of the pinball loss induces a weighted count of scores below the threshold that balances at (1−α) for each group (Equation 28).

### Mechanism 3
- **Claim:** GC-FCP achieves group-conditional coverage with an additive error term π/δ (Theorem 5.1), even with overlapping groups.
- **Mechanism:** Coverage analysis combines (a) T-Digest uniform CDF error (Lemma 5.1), (b) first-order condition linking empirical counts to 1−α, and (c) exchangeability within each client’s scores. The tower rule averages over client mixture, bounding conditional coverage degradation by the T-Digest error.
- **Core assumption:** Scores within each client are exchangeable under the mixture; test point is drawn from mixture (1). Group probabilities P(X∈G)>0 for at least one client with πk>0.
- **Evidence anchors:** [abstract] "Guarantees group-conditional coverage with an additive error term π/δ (Theorem 5.1)." ## Architecture Onboarding
### Component map
Client (score computation, atom partitioning, T-Digest construction) → Server (digest merging, coreset assembly, weighted quantile regression) → Prediction set generation

### Critical path
Score computation → atom partition → T-Digest construction → digest transmission → server merge → solve (22) → predict.

### Design tradeoffs
- **δ (compression):** Lower δ → fewer clusters → less communication/computation but larger coverage error π/δ. Higher δ → near-centralized accuracy but higher cost.
- **Atom count |A|:** In worst case |A| = 2^{|G|}, drives coreset size |êD| = Θ(|A|δ). Must balance group expressivity vs. overhead.
- **Mixture weights πk:** Must be known a priori; they weight both local digest construction (λk) and server aggregation. Mis-specification biases group calibration.

### Failure signatures
- **Group under-coverage:** Observed when δ is too small. Check per-group coverage; if any group significantly below 1−α, increase δ.
- **High communication:** If |A| is large (many overlapping groups), coreset size O(|A|δ) may still be large. Monitor |A| and consider grouping simplification.
- **Numerical instability:** Solving (22) requires convex optimization; if digest weights WA are very small, condition number worsens. Ensure minimum cluster mass via δ scaling.

### First 3 experiments
1. **Synthetic regression with overlapping intervals:** Validate that GC-FCP achieves uniform group-wise miscoverage near α across all groups, while marginal CP fails on some groups.
2. **CIFAR-10 with label-partitioned clients:** Compare group-conditional coverage vs. δ; verify tradeoff. Also measure speedup vs. centralized CondCP.
3. **PathMNIST with medical classes:** Test on real-world heterogeneous data; confirm GC-FCP maintains group coverage across overlapping confidence-based groups and observe set size stability.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** How can GC-FCP be extended to handle richer conditional structures beyond a finite set of overlapping groups, such as continuous or hierarchical conditioning?
- **Basis in paper:** Explicit: “Future work includes extending the framework to richer conditional structures beyond finite group families.”
- **Why unresolved:** The atom-based partition grows exponentially with the number of groups and is undefined for infinite families; the current coreset and quantile regression rely on this discrete structure.
- **What evidence would resolve it:** A theoretical extension that replaces atoms with a flexible function class (e.g., neural networks) or a conditional coreset that approximates quantiles for arbitrary conditioning events, together with a communication‑efficient federated algorithm and a coverage guarantee.

### Open Question 2
- **Question:** Can GC-FCP be adapted to fully decentralized network topologies where clients communicate over arbitrary graphs instead of a central server?
- **Basis in paper:** Explicit: The conclusion mentions investigating robustness to “decentralized calibration [Wen et al., 2025]” as future work.
- **Why unresolved:** GC-FCP assumes a star topology with a central aggregator; in decentralized settings, no server exists and clients must exchange messages locally. The merger of T‑Digests and the weighted quantile regression step need to be distributed without global coordination, which may affect the coverage guarantee.
- **What evidence would resolve it:** A distributed protocol, possibly based on message passing, that allows each client to compute a prediction set using only local information and neighbor communications, along with a proof that group‑conditional coverage still holds under the original mixture distribution.

### Open Question 3
- **Question:** How can GC-FCP be made robust to adversarial or Byzantine clients that submit malicious T‑Digest summaries?
- **Basis in paper:** Explicit: The authors reference adversarial behavior “Kang et al., 2024” as a direction for future robustness studies.
- **Why unresolved:** The aggregation of client digests assumes all participants follow the protocol. A malicious client could send incorrect cluster weights or means to skew the quantile estimation, leading to under‑coverage for some groups. No defense is currently proposed.
- **What evidence would resolve it:** A robust aggregation mechanism (e.g., median or trimmed mean of digests) that can tolerate a bounded fraction of Byzantine clients, together with a theoretical analysis showing that the resulting prediction sets still achieve group‑conditional coverage up to a small degradation.

### Open Question 4
- **Question:** Can the GC-FCP principles be extended to an online setting where calibration data arrives sequentially and group‑conditional guarantees must be maintained under potential distribution drift?
- **Basis in paper:** Explicit: The conclusion cites “online CP [Angelopoulos et al., 2024, Gasparin and Ramdas, 2024]” as a promising avenue.
- **Why unresolved:** GC‑FCP treats calibration as a one‑shot batch process. In many applications (e.g., mobile sensing, finance), data streams require continuous updates to the predictive model and the conformal threshold. The current coreset merging and quantile regression would need to be performed efficiently over time while controlling the coverage error.
- **What evidence would resolve it:** An online algorithm where clients maintain local T‑Digests that are updated incrementally and the server periodically recomputes the quantile regression with decaying weights, together with a theoretical bound on group‑conditional coverage over time.

## Limitations
- The additive coverage error π/δ depends on the compression parameter δ; smaller δ improves efficiency but degrades coverage, with no principled trade-off selection method.
- The method requires predefined overlapping groups and suffers from exponential atom blowup when many groups are specified, potentially limiting scalability.
- Accurate knowledge of mixture weights πk is necessary; misspecification biases group calibration, especially for low-mass groups.
