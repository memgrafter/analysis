# Is my model "mind blurting"? Interpreting the dynamics of reasoning tokens with Recurrence Quantification Analysis (RQA)

## Quick Facts
- arXiv ID: 2602.06266
- Source URL: https://arxiv.org/abs/2602.06266
- Reference count: 9
- Primary result: Temporal RQA improves classification of combinatorial task complexity by 8% (36.94% vs. 28.97%) over response-length baselines.

## Executive Summary
The paper tackles the impracticality of analyzing Chain-of-Thought reasoning through generated text and the inadequacy of response length as a proxy for reasoning quality. It proposes Recurrence Quantification Analysis (RQA) applied to hidden-state trajectories as a non-textual method to quantify repetition and stalling in latent dynamics. Experiments on DeepSeek-R1-Distill-Qwen-7B solving ZebraLogic puzzles show that temporal RQA features significantly enhance fine-grained complexity prediction, demonstrating that combinatorial difficulty is encoded in the non-stationary evolution of latent space patterns.

## Method Summary
For each generated token, the final-layer hidden state is extracted to form a temporal trajectory. Pairwise cosine distances between states are computed; a threshold (10th percentile) binarizes these into a recurrence matrix. RQA metrics (Determinism, Laminarity, Entropy) are calculated in sliding windows (150 tokens, step 15) to capture non-stationary dynamics. From each metric’s time series, descriptive statistics (mean, standard deviation, linear slope) and detrended fluctuation analysis (DFA) exponents are derived. These features train classifiers (Random Forest, Logistic Regression) for 9-way puzzle complexity and binary correctness prediction, evaluated via group cross-validation.

## Key Results
- Temporal RQA achieves 36.94% accuracy on 9-way complexity classification, outperforming the response-length baseline (28.97%) by 8%.
- Response length successfully predicts binary correctness (85.58%) but fails on intermediate complexity levels, confirming it is a coarse signal.
- Global RQA (full-trace averaging) performs near random (16.81%), highlighting the non-stationary nature of reasoning dynamics.

## Why This Works (Mechanism)
- **Latent trajectory quantification**: Treating token generation as a dynamical system via hidden-state trajectories enables measurement of internal reasoning structure beyond text. Autoregressive decoding induces effective recurrence, and RQA metrics like DET (repetition) and LAM (stalling) capture geometric patterns correlated with reasoning quality. Evidence: The paper explicitly models the trajectory (section 3.1) and frames RQA as a non-textual alternative (abstract).
- **Temporal dynamics matter**: The evolution of RQA metrics over time is a primary predictor of complexity; sliding-window analysis reveals phase shifts (e.g., parsing, stalling) erased by global averaging. Evidence: Temporal RQA yields 36.94% vs. Global RQA’s 16.81% (section 5); ablation shows `det_std`, `lam_slope`, and `lam_dfa` are top features.
- **Disentangling length effects**: Length conflates efficient, deep, and chaotic generation. RQA distinguishes a long structured trace from a long unproductive one by assessing trajectory regularity. Evidence: Length excels at binary correctness but only 28.97% on 9-way complexity, while Temporal RQA reaches 36.94%.

## Foundational Learning
- **Recurrence Quantification Analysis (RQA)**: Converts a trajectory into a binary recurrence plot via a distance threshold; metrics like DET (recurrence structures) and LAM (laminar phases) quantify geometric properties. *Why needed*: Core analytical tool to measure latent dynamics without decoding text. *Quick check*: What does high Laminarity (LAM) indicate about a model’s hidden-state trajectory?
- **Non-Stationary Time Series Analysis**: Reasoning dynamics change over time; sliding windows capture local instead of global properties. *Why needed*: Global RQA fails because LLM reasoning is fundamentally non-stationary. *Quick check*: Why does computing RQA over the entire trace perform poorly?
- **Dynamical Systems View of Autoregressive Decoding**: Even feedforward Transformers exhibit effective recurrence because each token’s hidden state depends on previous contexts via attention, forming a path-dependent trajectory. *Why needed*: Justifies treating generation as a dynamical system. *Quick check*: How does the paper justify applying dynamical systems analysis to a Transformer’s feedforward architecture?

## Architecture Onboarding
- **Component map**: Generation & Extraction -> Trajectory & Recurrence Matrix -> Sliding-Window RQA -> Feature Engineering -> Classification
- **Critical path**: Extract final-layer hidden states per token → compute pairwise cosine distances → threshold to binary recurrence matrix → apply sliding window to compute DET/LAM/ENTR per window → extract mean, std, slope, DFA from each series → train classifier.
- **Design tradeoffs**: Threshold ε fixed at 10th percentile to balance recurrence density; window size 150 trades local detail vs. metric reliability; final-layer states only (earlier layers may differ).
- **Failure signatures**: Global RQA ~16.81% accuracy indicates lost temporal information; length fails on intermediate complexities; O(N²) memory limits trace length (capped at 32k tokens).
- **First 3 experiments**: (1) Replicate length-only classifier on ZebraLogic traces; expect ~29% 9-way accuracy. (2) Implement Global RQA; expect near-random (<20%) performance. (3) Deploy Temporal RQA with given hyperparameters; expect ~37% complexity accuracy and ~85% binary correctness accuracy.

## Limitations
- Evaluation restricted to one model (DeepSeek-R1-Distill-Qwen-7B) and one domain (ZebraLogic).
- Prompt template details are unspecified, potentially influencing reasoning dynamics.
- DFA parameterization (window sizes, detrending order) is not documented, risking reproducibility.

## Confidence
- Length as coarse binary predictor: High
- RQA as dynamical proxy: Medium
- Temporal vs. global RQA: Medium

## Next Checks
1. Cross-model generalization: Apply Temporal RQA to multiple model families (e.g., Llama, Mistral) and non-logic tasks; maintain ≥5% gain over length for fine-grained complexity.
2. Prompt ablation: Systematically vary prompt phrasing (CoT trigger, few-shot examples); verify stability of top features (`det_std`, `lam_slope`) with Pearson r > 0.7.
3. DFA parameter sensitivity: Test DFA with different window sizes and detrending orders; ensure `lam_dfa` remains a top-3 feature across settings.
