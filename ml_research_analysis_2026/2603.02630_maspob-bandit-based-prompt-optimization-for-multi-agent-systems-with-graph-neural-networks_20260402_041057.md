# MASPOB: Bandit-Based Prompt Optimization for Multi-Agent Systems with Graph Neural Networks

## Quick Facts
- **arXiv ID:** 2603.02630
- **Source URL:** https://arxiv.org/abs/2603.02630
- **Reference count:** 37
- **Primary result:** MASPOB achieves state-of-the-art performance with an average of 80.58% across six benchmarks under a 50-evaluation budget, improving over IO by 12.02% and over AFlow by 2.06%.

## Executive Summary
MASPOB is a novel framework for optimizing prompts in fixed-topology multi-agent systems (MAS) where evaluating a full workflow is expensive. It addresses the combinatorial search problem and coupling from workflow dependencies by combining three key ideas: a graph neural network (GNN) surrogate that models topology-aware prompt interactions, a LinUCB-inspired bandit method for uncertainty-guided exploration, and coordinate ascent for scalable per-agent search. In experiments on QA, code, and math benchmarks, MASPOB significantly outperforms prior methods like IO and AFlow while being highly sample-efficient. Ablations confirm the importance of the GNN for capturing dependencies and the efficiency of coordinate ascent.

## Method Summary
MASPOB formulates prompt optimization as a combinatorial bandit problem over a MAS workflow DAG. It employs a frozen pre-trained encoder to map candidate prompts to embeddings. A Graph Attention Network (GAT) surrogate, trained on historical evaluations, predicts performance `µ(c)` for a prompt combination `c` by processing the graph of node embeddings and the workflow adjacency matrix. A linear contextual bandit (LinUCB) computes an uncertainty bonus `σ(c)` from an information matrix `M` accumulated from evaluated embeddings, yielding the UCB acquisition `ucb(c) = µ(c) + α·σ(c)`. To avoid exponential search, coordinate ascent iteratively optimizes one agent's prompt at a time, fixing others, by scoring all candidates for that agent via cheap GNN forward passes. The best combination is evaluated on the MAS, the result is stored, and the surrogate is retrained.

## Key Results
- Average accuracy of 80.58% across six benchmarks under a strict 50-evaluation budget.
- Improves over the IO baseline by 12.02% and over the prior SOTA AFlow by 2.06%.
- Ablation shows the GNN surrogate contributes a +2.31% average gain over an MLP baseline.
- Coordinate ascent achieves performance within -0.29% of global search but with 98–99.8% less runtime.

## Why This Works (Mechanism)

### Topology-Aware Surrogate via Graph Neural Network
The GNN surrogate encodes the MAS workflow DAG structure into prompt representations, allowing the model to learn how changes in one agent's prompt propagate to others through message-passing. This creates a prior that generalizes better from limited evaluations than an unstructured black-box model. The core assumption is that performance is not separable across agents; a prompt's effect depends on its predecessors. Evidence: The abstract mentions GNNs for structural priors, Section 3.1 details the GAT construction, and the ablation (Table 3) shows a ~2.3% drop when removing the GNN.

### Uncertainty-Guided Exploration via LinUCB
The LinUCB framework balances exploitation and exploration by quantifying epistemic uncertainty in the prompt embedding space via a linear kernel `Φ(c)^T M^{-1} Φ(c)`. The information matrix `M` is updated with `Φ(c)Φ(c)^T` after each evaluation, encouraging exploration of novel combinations. The core assumption is that the linear bonus is a sufficient and tractable uncertainty measure in the frozen encoder's embedding space. Evidence: The abstract and Section 3.2 define the UCB formula; Appendix B shows replacing the linear bonus with a neural estimator degrades performance.

### Scalable Search via Coordinate Ascent
Coordinate ascent reduces per-iteration search complexity from exponential to linear in the number of agents by sequentially optimizing one agent's prompt at a time, fixing others to the current best. For each agent, it evaluates `UCB(c_{-i}, p)` for all candidate prompts `p` via cheap GNN forward passes. The core assumption is that the UCB surface is amenable to coordinate-wise greedy optimization given the surrogate's smoothness. Evidence: The abstract and Section 3.3 define the update; Table 5 and Figure 4 show near-identical performance to global search with orders-of-magnitude speedup.

## Architecture Onboarding
- Component map: Prompt Embedding Module (frozen `Qwen3-Embedding-8B`) -> GNN Surrogate (GAT) -> Bandit Information Matrix (`M`) -> UCB Acquisition Function (`µ(c) + α·σ(c)`) -> Coordinate Ascent Searcher -> Evaluation Loop (MAS execution, retrain GNN, update `M`).
- Critical path: Initialize embeddings, `M`, and GNN. For each round `t=1..T`: run coordinate ascent to propose prompt combination `c`; execute MAS on validation set to get score `s(c)`; update history `H`, information matrix `M`, and retrain GNN on `H`; track best combination `c*`.
- Design tradeoffs: 
  - GNN vs. MLP: GNN adds topology bias but requires graph input; MLP is simpler but ignores dependencies (~2.3% drop).
  - Linear vs. Neural Uncertainty: Linear (LinUCB) is stable and cheap for low data; neural may be more expressive but less calibrated.
  - Coordinate vs. Global Search: Coordinate ascent offers ~1000x speedup with negligible performance loss, making budgeted setting feasible.
- Failure signatures:
  - Poor GNN generalization: validation performance plateaus early despite more rounds.
  - Stuck in local optimum: test performance of `c*` significantly below global search potential.
  - High variance in scores: large standard deviation across runs, indicating overfitting or unstable predictor.
- First 3 experiments:
  1. Ablation: Remove GNN (replace with MLP). Expect ~2% average drop.
  2. Ablation: Replace linear uncertainty bonus with a neural estimator. Expect inferior convergence.
  3. Runtime/Performance comparison: Run global search baseline on HotpotQA. Expect near-identical performance to coordinate ascent but ~10000% higher runtime.

## Open Questions the Paper Calls Out
- **Question 1:** How does MASPOB compare to MAPRO in sample efficiency and final performance under identical evaluation budgets? *Basis:* Section 6 identifies MAPRO as the closest prior but notes it relies on intricate inference procedures without empirical comparison.
- **Question 2:** What is the minimum evaluation budget required for MASPOB to reliably outperform baselines, and how does this budget scale with the number of agents? *Basis:* All experiments use a fixed budget of 50; no sensitivity analysis on budget or agent count is provided.
- **Question 3:** Can MASPOB be extended to optimize prompts for MAS with non-DAG topologies, such as those containing cycles for iterative refinement or feedback loops? *Basis:* Problem formulation explicitly restricts to DAGs; core design assumes topological order.

## Limitations
- Evaluation limited to six benchmarks and a fixed 50-evaluation budget; may not generalize to other domains or larger budgets.
- GNN surrogate may overfit on small data or fail on graphs with unusual topologies.
- LinUCB linear uncertainty may be inaccurate if embedding space poorly reflects performance.
- No statistical tests (e.g., confidence intervals, significance tests) provided; observed gains could be within variance.
- Results depend on the choice of frozen embedding model (Qwen3-Embedding-8B).

## Confidence
- **GNN surrogate:** Medium (ablation +2.31%, but limited benchmarks and architecture comparisons).
- **LinUCB exploration:** Medium (neural ablation supports linear bonus, but linearity assumption not thoroughly validated).
- **Coordinate ascent:** Medium (near-global performance on HotpotQA with huge speedup, but only one benchmark).
- **Overall SOTA claim:** Medium (strong absolute improvements but insufficient statistical validation and benchmark diversity).
