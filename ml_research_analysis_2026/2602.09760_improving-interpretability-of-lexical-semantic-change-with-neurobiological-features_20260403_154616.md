# Improving Interpretability of Lexical Semantic Change with Neurobiological Features

## Quick Facts
- **ArXiv ID:** 2602.09760
- **Source URL:** https://arxiv.org/abs/2602.09760
- **Reference count:** 25
- **Primary result:** By mapping BERT contextual embeddings to a neurobiological feature space (Binder features), the method achieves a Spearman's rank correlation of 0.667 on SemEval-2020 Task 1 for lexical semantic change detection, outperforming most prior methods without external knowledge.

## Executive Summary
Existing lexical semantic change (LSC) detection methods quantify how word meanings shift over time but lack human-interpretable explanations. This paper introduces an approach that represents word meanings via 65 neurobiologically-motivated primitive semantic features (Binder features). A regression model maps BERT's contextual embeddings into this interpretable space. LSC is then computed as the difference in average Binder feature vectors between two time periods, directly showing which primitive features increased or decreased. The method achieves strong performance on SemEval-2020 (Spearman's ρ = 0.667) without external knowledge. Furthermore, applying Sparse PCA to these LSC vectors uncovers novel, interpretable LSC types (e.g., shifts toward 'Sound' or 'Transportation' features) and effectively ranks words undergoing amelioration or pejoration by analyzing changes in positive/negative Binder features.

## Method Summary
The pipeline begins by training a linear regression model (LT) on 535 words with known Binder feature vectors. Using the CCOHA corpus, BERT contextual embeddings for each seed word are averaged over all occurrences in a specified time span (e.g., 1960–2010). The model learns to map the 768-dimensional BERT representation to the 65-dimensional Binder space. For any target word in two periods, all its contextual embeddings are transformed via this model to obtain sets of Binder vectors. The LSC score is the average pairwise distance (APD) between these sets, with cosine distance performing best. To discover general change patterns, an LSC vector is computed as the difference of the mean Binder vectors between periods. Sparse PCA is then applied to the LSC vectors of the top 500 words with largest norms, yielding sparse principal components that highlight small subsets of Binder features and define interpretable LSC types. For amelioration/pejoration, a word's score is the maximum change in a predefined set of positive or negative Binder features.

## Key Results
- The LT model (trained on 1960–2010 data) achieves a Spearman's rank correlation of 0.667 on SemEval-2020 Task 1, outperforming most prior methods that do not incorporate external knowledge.
- Sparse PCA on LSC vectors identifies novel, interpretable types of semantic change (e.g., shifts toward 'Sound' or 'Transportation' features), supported by usage examples from historical corpora.
- The method successfully ranks known ameliorative and pejorative words by scoring the maximum increase in positive Binder features (e.g., Pleasant, Happy) or negative ones (e.g., Pain, Harm), respectively.

## Why This Works (Mechanism)
**Mechanism 1: Mapping to an Interpretable Feature Space**  
A regression model transforms BERT's contextual embeddings into the Binder neurobiological feature space, where each of the 65 dimensions corresponds to a human-interpretable semantic primitive (e.g., Vision, Motion). The core assumption is that this space provides a stable, semantically meaningful basis that remains consistent over time. The model's generalization to unseen words and periods is validated by its strong performance on SemEval-2020 and qualitative examples that reveal coherent feature shifts (e.g., *bluegrass* showing increased Audition). The approach would fail if Binder features cannot capture the dimensions along which words actually change (e.g., metaphorical shifts unrelated to neurobiological primitives) or if the mapping becomes inaccurate for earlier language due to domain shift.

**Mechanism 2: LSC Detection via Feature-Space Distance**  
Computing the average pairwise distance (APD) between sets of Binder vectors for two periods yields a graded LSC score that correlates with human judgments. The assumption is that human-perceived semantic change manifests as a measurable shift in the distribution of primitive features. The APD metric in Binder space, particularly with cosine distance, proves robust (ρ = 0.667 on SemEval). This works because the Binder space distills meaning into a fixed set of dimensions where semantic shifts become visible as changes in feature intensities. The metric could break down if the regression distorts relative distances or if the change is purely connotative without affecting the neurobiological primitives.

**Mechanism 3: Unsupervised Discovery of LSC Types via Sparse PCA**  
Applying Sparse PCA to LSC vectors of highly changing words extracts directions of maximum variance with sparse loadings, each highlighting only a few Binder features. The assumption is that these sparse patterns correspond to meaningful, recurrent types of semantic change. Evidence comes from qualitative interpretation: principal components align with coherent semantic dimensions (e.g., one PC loads on Audition and Sound, with top words like *bluegrass* shifting toward music). This yields novel LSC types not previously identified. However, the discovery is data-driven and not validated against a gold standard; different sparsity parameters or word subsets could produce less coherent or different patterns.

## Foundational Learning
- **Neurobiological Semantic Features (Binder Features):** Provides a fixed set of 65 human-interpretable semantic primitives (e.g., Vision, Motion) that serve as the basis for explaining LSC. *Why needed:* Without this predefined "alphabet," change vectors remain as opaque as the original embeddings. *Quick check:* If an LSC vector shows large positive changes in *Motion* and *Path*, what plausible semantic shift might this indicate (e.g., from a static object to a vehicle concept)?
- **Contextual Word Embeddings (BERT):** Captures time-specific usages of words; the regression model learns to project these contextually grounded meanings onto the stable Binder space. *Why needed:* Static embeddings cannot capture usage variation within a period; averaging contextual embeddings approximates the word's period meaning. *Quick check:* Why is taking the average of all contextual embeddings for a word in a decade a reasonable, though simplified, representation of its "meaning" in that period?
- **Sparse PCA:** A dimensionality reduction technique that imposes sparsity on the principal components, forcing each to load strongly on only a few features. *Why needed:* Standard PCA yields dense, hard-to-interpret components; sparsity creates clear "signatures" for LSC types. *Quick check:* How does the sparsity constraint improve interpretability when analyzing LSC vectors compared to standard PCA?

## Architecture Onboarding
Component map: Input Corpora (CCOHA 10-year slices) -> BERT Encoder (bert-base-uncased) -> Regression Model (ψ) -> Mapped Binder Vectors (per context) -> LSC Vector Computation (difference of period means) -> Sparse PCA Analyzer (for LSC types) / APD Scorer (for graded LSC) -> Downstream Applications (word ranking for amelioration/pejoration).  
Critical path: The entire pipeline depends on the quality of the regression model ψ; errors in training (e.g., high MSE) cascade to all downstream tasks.  
Design tradeoffs: (1) LT vs. MLP: The linear transform (LT) is simpler, faster, and outperforms a 4-layer MLP in both training MSE and SemEval correlation, suggesting the mapping is largely linear and the MLP overfits. (2) Distance metric: Cosine APD is most stable and best-performing; Euclidean and Spearman are more sensitive to model/period choices. (3) Sparse PCA: Number of components fixed at 10 without tuning; sparsity level (α) not specified—more components may reveal finer types but risk fragmentation, while higher sparsity improves interpretability but may miss nuanced patterns.  
Failure signatures: High regression MSE indicates ψ cannot accurately map BERT to Binder space (check: training data size, corpus period mismatch). Poor SemEval correlation (<<0.667) suggests APD metric or mapping issues (check: use cosine distance, compute APD on full sets, ensure correct periods). Incoherent Sparse PCA components (dense loadings, semantically unrelated top words) imply noisy LSC vectors or inappropriate sparsity settings. Failure to rank known ameliorative/pejorative words may stem from misaligned Binder feature sets or the max reduction being too sensitive.  
First 3 experiments: (1) Train the LT regression model on the 535 Binder words using CCOHA (1910–2010); verify MSE ~0.6–0.7 and inspect a few predicted vs. true Binder vectors. (2) Replicate SemEval-2020 evaluation: for each test word, compute APD (cosine) between periods 1810–1860 and 1960–2010 using the trained LT-1960–2010 model; confirm Spearman ρ ≈ 0.667. (3) Compute LSC vectors for 8,570 target words (1910s vs 2000s), select top 500 by norm, run Sparse PCA (n_components=10); examine loading sparsity and semantic coherence of top features per PC.

## Open Questions the Paper Calls Out
- How does changing the number of Sparse PCA components affect the discovery and interpretability of LSC types? The study fixed it at 10 without exploration.
- How can the method be extended to handle words that are tokenized into multiple subwords? The current approach excludes many words; optimal aggregation (e.g., averaging subword embeddings) is unknown.
- Can the Binder feature space be augmented to capture LSC types like metaphorization, metonymization, narrowing, and broadening? The fixed 65 features may not encode dimensions relevant to these processes.

## Limitations
- Access to the Binder feature dataset (65×535) is unclear; reproduction is blocked without it.
- Handling of multi-token words (subword aggregation strategy) is unspecified, potentially degrading embedding quality for many vocabulary items.
- Sparse PCA hyperparameters (e.g., sparsity parameter α) are not reported, risking inconsistent sparsity and interpretability across replications.
- CCOHA preprocessing details (tokenization, sentence splitting, minimum occurrence thresholds) are missing.
- Domain shift between training corpus (1910–2010) and SemEval test periods (1810–1860) may impair the regression model's generalization.

## Confidence
- **Interpretable mapping to Binder space:** Medium. Qualitative illustrations are compelling, but the stability of Binder features over centuries is not directly validated.
- **LSC scoring via APD:** High. The SemEval correlation of 0.667 is strong and likely replicable under controlled settings.
- **Unsupervised LSC type discovery:** Low-Medium. Sparse PCA patterns are plausible but lack objective evaluation; results are post-hoc interpretations.
