# Benchmark Problems and Benchmark Datasets for the evaluation of Machine and Deep Learning methods on Photoplethysmography signals: the D4 report from the QUMPHY project

## Quick Facts
- arXiv ID: 2604.01398
- Source URL: https://arxiv.org/abs/2604.01398
- Reference count: 40
- Primary result: The report establishes standardized benchmark problems and datasets for evaluating ML/DL methods on PPG signals across six clinically relevant medical tasks, with protocols and code for reproducibility and uncertainty quantification.

## Executive Summary
The D4 report from the QUMPHY project defines a comprehensive framework for benchmarking machine learning and deep learning on photoplethysmography (PPG) signals. It identifies six clinically motivated tasks—blood pressure estimation, atrial fibrillation detection, hypertension classification, vascular age estimation, sleep apnea detection, and respiratory rate regression—and curates existing datasets for each. The report provides detailed protocols, including subject-level stratified data splits, to enable fair comparison and rigorous evaluation of model accuracy and uncertainty, thereby promoting trustworthy PPG-based medical AI.

## Method Summary
The report specifies supervised learning tasks where PPG waveform segments serve as inputs to predict clinical parameters. It leverages existing datasets (e.g., Aurora BP, PulseDB, MIMIC-III-Ext-PPG, TriggersAF, OSASUD, MESA, MIMIC Perform Large), assigning subject-level folds for training, validation, calibration, and testing to prevent data leakage. Evaluation metrics are task-specific (e.g., MAE for regression, AUC for classification) and include calibration measures for uncertainty. Code for generating stratified splits and preprocessing guidance is provided, though some datasets require formal access requests.

## Key Results
- Six benchmark problems are defined with clear physiological motivation and input-output specifications.
- Datasets are curated and partitioned with subject-level stratification to support robust generalization assessment.
- Standardized protocols, code for splits, and calibration sets are released to facilitate reproducible evaluation and uncertainty quantification.

## Why This Works (Mechanism)
### Blood pressure estimation from PPG waveform morphology
Claim: PPG pulse wave shape features correlate with systolic and diastolic blood pressure due to changes in arterial compliance and peripheral resistance.
Mechanism: Arterial stiffness modifies pulse wave velocity and contour; ML models learn mappings from morphological features (e.g., derivatives, amplitude) to BP.
Core assumption: Arterial mechanical properties dominate the link between cardiac output and PPG-measured blood volume changes and vary systematically with BP.
Evidence anchors: Report states tasks are chosen based on "plausible physiological mechanism"; Section 2.1 discusses continuous PPG advantages over cuff methods.
Break condition: Acute vasoactive drugs, extreme temperatures, or vascular anomalies may decouple arterial stiffness from BP.

### Atrial fibrillation detection via pulse interval irregularity
Claim: Irregular ventricular response during AF manifests as irregular inter-beat intervals in PPG.
Mechanism: AF causes chaotic electrical activity leading to irregular RR intervals; PPG pulse onsets reflect this irregularity via time-domain variability metrics.
Core assumption: PPG pulse detection is sufficiently accurate, and AF is the primary cause of such irregularity in target populations.
Evidence anchors: Section 3.1 notes AF detection relies on "irregular rhythms"; TriggersAF dataset includes synchronized ECG for verification.
Break condition: Motion artifacts, poor perfusion, or ectopic beats could mask or mimic irregularity.

### Respiratory rate estimation from respiratory modulations
Claim: Respiratory cycles induce baseline wander, amplitude modulation, and frequency modulation on PPG.
Mechanism: Breathing changes intrathoracic pressure, affecting venous return (AM, BW) and autonomic modulation (FM); algorithms extract dominant low-frequency component.
Core assumption: These modulations are detectable in clean PPG under resting conditions and correspond to respiration frequency.
Evidence anchors: Section 7.1 explicitly describes BW, AM, FM mechanisms; cited literature supports plausibility.
Break condition: Tachypnea, shallow breathing, or high movement noise may obscure modulations; Cheyne-Stokes adds complexity.

## Architecture Onboarding
- **Component map**: Datasets (Aurora BP, PulseDB, MIMIC-III-Ext-PPG, etc.) -> Code utilities (fold generation, preprocessing scripts) -> Model expectations (segmented PPG windows or extracted features) -> Evaluation metrics (MAE, AUC, calibration error).
- **Critical path**:
  1. Choose task and dataset; download open data or request access.
  2. Load provided `metadata.csv` and signal files; use fold columns to select train/val/calib/test sets.
  3. Preprocess PPG (resampling, filtering) per dataset guidelines.
  4. Define model architecture (e.g., 1D CNN for raw signals, MLP for features).
  5. Train on training set; tune hyperparameters on validation set; calibrate uncertainty on calibration set.
  6. Evaluate on test set using standardized metrics; compare against baselines.
  7. Repeat with external test sets for robustness.
- **Design tradeoffs**:
  - Raw vs. features: Raw waveforms capture more information but require more data; handcrafted features are interpretable but may discard signal.
  - Model complexity: Deep models (CNNs, Transformers) risk overfitting on smaller datasets (e.g., OSASUD with 30 subjects).
  - Sensor heterogeneity: Training on fingertip (MIMIC) vs. wrist (DeepBeat) PPG may not generalize; consider domain adaptation.
  - Uncertainty approach: Predictive uncertainty (e.g., MC-dropout) increases compute; conformal prediction uses calibration set but assumes exchangeability.
- **Failure signatures**:
  - Poor cross-dataset generalization (e.g., model trained on Aurora BP fails on VitalDB).
  - Miscalibrated uncertainty: prediction intervals too narrow or wide; check reliability diagrams.
  - Subgroup performance drops for certain skin tones, ages, or BMI groups.
  - Degraded performance on artifact-heavy segments; consider signal quality indices if available.
- **First 3 experiments**:
  1. Baseline replication: Hypertension classification on Aurora BP; train logistic regression on basic features (e.g., mean pulse interval) using provided folds; report accuracy.
  2. Modality comparison: Sleep apnea detection on OSASUD; compare 1D CNN on raw 1‑min PPG segments vs. model using 4 extracted PPG features.
  3. Uncertainty calibration: AF detection on DeepBeat; train Bayesian neural network or MC-dropout CNN; evaluate expected calibration error (ECE) on calibration set.

## Limitations
- Dataset access restrictions (Aurora BP, MESA, MIMIC Perform Large) delay widespread reproduction.
- Incomplete documentation on preprocessing and feature extraction; users must refer to cited papers.
- Sensor heterogeneity (fingertip vs. wrist) and label noise (e.g., MIMIC-III-Ext-PPG automated annotations) risk poor generalization.
