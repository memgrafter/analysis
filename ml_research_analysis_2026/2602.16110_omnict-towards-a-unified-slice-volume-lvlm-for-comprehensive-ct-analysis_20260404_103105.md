# OmniCT: Towards a Unified Slice-Volume LVLM for Comprehensive CT Analysis

## Quick Facts
- **arXiv ID**: 2602.16110
- **Source URL**: https://arxiv.org/abs/2602.16110
- **Reference count**: 29
- **Primary result**: 7B model averages 81.45 on 2D CT benchmarks (+11.01 over prior) and 66.15 on 3D benchmarks (gains up to 31 points).

## Executive Summary
OmniCT introduces a unified slice-volume large vision-language model for comprehensive CT analysis, resolving the fragmentation between 2D slice and 3D volume processing. It combines Spatial Consistency Enhancement (using volumetric slice composition and tri-axial positional embedding) with Organ-level Semantic Enhancement (via segmentation-guided region aggregation) to achieve state-of-the-art performance on both 2D and 3D benchmarks. Evaluated on the new MedEval-CT dataset with 1.7M VQA samples across 7 task types and 13 organs, the 7B model averages 81.45 on 2D tasks and 66.15 on 3D tasks, demonstrating strong cross-modal generalization and balanced organ-level understanding.

## Method Summary
OmniCT processes CT slices or volumes by first applying Volumetric Slice Composition (VSC) to group adjacent slices into 3-channel units or replicate single slices. These units are fed to a 2D vision encoder (SigLIP) with Tri-Axial Positional Embedding (TPE) to encode 3D spatial context. Tokens are downsampled via unshuffle and routed through a Mixture of Experts Hybrid Projection (MHP), which uses modality-specific experts for slice and volume tokens before a shared projection aligns features to the LLM space. In parallel, Organ-level Semantic Enhancement (OSE) uses pre-computed segmentation masks (TotalSegmentor) to adaptively aggregate tokens within target organs, concatenating these with global tokens. Training is two-stage: first pretrain MHP with frozen vision encoder and LLM, then instruction tune the LLM and MHP together on mixed 2D/3D VQA data.

## Key Results
- On 2D CT benchmarks (SLAKE, VQA-RAD, OmniMedVQA, RadFig-VQA), the 7B model averages 81.45, surpassing the next best (Lingshu) by 11.01 points.
- On 3D benchmarks (M3D, CT-RATE, 3D-RAD), it averages 66.15, with gains up to 31 points over prior models.
- MedEval-CT provides 1.7M VQA samples across 7 task types and 13 organs, enabling comprehensive, fair evaluation and demonstrating balanced organ-level performance.

## Why This Works (Mechanism)
- **Mechanism 1: Spatial Consistency Enhancement (SCE)** via Volumetric Slice Composition and Tri-Axial Positional Embedding. VSC groups 3 adjacent slices (or replicates a slice) into a 3-channel unit, creating local volumetric context. TPE adds sinusoidal positional encodings along depth, height, and width to explicitly encode 3D layout into 2D features. *Evidence*: Abstract and section 2.1 define VSC (Eq. 1) and TPE (Eq. 2); break condition if spatial relationships are highly non-local (e.g., large slice gaps).
- **Mechanism 2: MoE Hybrid Projection (MHP)** for efficient slice-volume adaptation. MHP routes tokens to modality-specific experts (`W_s` for slices, `W_v` for volumes) based on binary indicators (`1_slice`, `1_volume`), followed by a shared projection `W_share` to align with LLM space. *Evidence*: Abstract, section 2.1 (Eq. 4), and t-SNE visualization in appendix H.2(ii) shows separated clusters; break condition on incorrect routing indicators.
- **Mechanism 3: Organ-level Semantic Enhancement (OSE)** via segmentation-guided region aggregation. Using TotalSegmentor masks, tokens within an organ mask are adaptively aggregated (compressed) to a fixed length and concatenated with global tokens, emphasizing small organs and compressing large ones. *Evidence*: Abstract, section 2.2, and ablation in appendix H.2(iii) shows performance drop when removing or randomizing ROI; break condition on inaccurate masks from pathology or artefacts.

## Foundational Learning
- **3D Positional Encoding (Sinusoidal)**: Needed to encode volumetric layout in TPE by creating unique, continuous identifiers for tokens in a 3D grid (depth, height, width). *Quick check*: How would you design sinusoidal embeddings for a token at (z=5, y=32, x=64) in a reassembled unit, and why use separate axes?
- **Mixture of Experts (MoE) Routing**: Needed for MHP's conditional computation, where a binary router directs tokens to slice or volume experts. *Quick check*: For tokens from a VSC-processed volume, which indicator (`1_slice` or `1_volume`) should be active, and what if both are active?
- **Medical Image Segmentation as a Prior**: Needed for OSE to use pre-computed masks as region proposals for organ-centric aggregation. *Quick check*: How does OSE select which organ mask for a clinical question involving multiple organs, and what if masks are incomplete?

## Architecture Onboarding
- **Component map**: CT Input -> VSC -> Vision Encoder (SigLIP) -> TPE -> Unshuffle -> MHP -> OSE branch -> LLM (Qwen2.5)
- **Critical path**: Input CT undergoes VSC, encoding, TPE, unshuffle, and MHP. OSE operates in parallel on MHP output using segmentation masks; the combined token stream is fed to the LLM with text prompts.
- **Design tradeoffs**: Token count vs. detail (VSC/TPE increase tokens, unshuffle reduces but loses fine detail); 2D vs. 3D encoder (2D encoders with SCE outperform native 3D); Generalization vs. specialization (MoE aims for unified handling but routing may oversimplify).
- **Failure signatures**: Contradictory findings across adjacent slices (SCE failure); organ mislocalization or confusion (OSE failure); performance drop on one modality when trained on mixed data (modality collapse); out-of-memory errors due to excessive token length.
- **First 3 experiments**:
  1. **SCE Ablation**: Train without VSC/TPE (feed raw slices/volumes to vision encoder). Expect large drop on 3D benchmarks (per Table 1: 62.17 → 66.15).
  2. **OSE Ablation**: Replace OSE with (a) no OSE, (b) naive concatenation of all organ tokens, (c) random token selection. Expect adaptive OSE best (per Table 12).
  3. **Modality Generalization**: Train on pure-2D, pure-3D, and mixed data (equal samples). Test on both 2D and 3D sets. Expect mixed training best overall, and 2D-only generalizes better to 3D than 3D-only to 2D (per appendix H.2(vi)).

## Open Questions the Paper Calls Out
1. To what extent does OmniCT's unified paradigm depend on the choice of 2D vision encoder (e.g., SigLIP), and can other 2D encoders achieve comparable results with SCE?
2. How robust is MHP's binary routing for ambiguous inputs like sparse multi-slice stacks or low-contrast volumes?
3. How does OSE perform with inaccurate segmentation masks from pathologies, motion artefacts, or uncommon anatomies?
4. Does the unified slice-volume design generalize to other 3D medical modalities (e.g., MRI, PET) with different spatial and contrast properties?

## Limitations
- Architecture details (Agg(·) design, unshuffle size *m*, positional embedding dimensions) are unspecified, requiring assumptions for reproduction.
- OSE's reliance on TotalSegmentor masks may degrade performance on scans with significant pathology or distorted organ boundaries.
- Training data mixing ratio and orchestration (e.g., Data Orchestration Engine) are not described, affecting modality balance.
- VSC and OSE increase token count, raising memory demands and potentially limiting batch sizes for large volumes.

## Confidence
- **SCE (spatial consistency)**: Medium (overall gains support it, but direct ablation of VSC/TPE is missing).
- **MHP (modality adaptation)**: Medium (t-SNE clusters indicate separated paths, but routing analysis on edge cases is lacking).
- **OSE (organ semantics)**: High (ablation shows significant drop when removing or randomizing ROI).
- **Unified model superiority**: Medium (results on MedEval-CT are promising but not externally validated).

## Next Checks
1. **SCE ablation**: Train OmniCT without VSC/TPE and evaluate on 3D benchmarks to isolate SCE's contribution.
2. **OSE robustness**: Substitute TotalSegmentor masks with (a) no masks, (b) random masks, (c) masks from another segmentor (e.g., nnU-Net) to test sensitivity to segmentation quality.
3. **Modality-mixing study**: Train models on pure-2D, pure-3D, and mixed data (equal total samples); test on both 2D and 3D sets to verify cross-modal generalization and the "2D encoder as anchor" hypothesis.
