# VertCoHiRF: Decentralized Vertical Clustering Beyond k-means

## Quick Facts
- **arXiv ID:** 2602.07279
- **Source URL:** https://arxiv.org/abs/2602.07279
- **Reference count:** 22
- **Primary result:** VertCoHiRF enables fully decentralized, privacy-preserving vertical clustering beyond k-means with structural consensus, achieving perfect recovery on synthetic multimodal data and superior ARI across real-world datasets.

## Executive Summary
VertCoCoHiRF addresses vertical federated clustering without sharing raw features or relying on a central coordinator. Unlike traditional distributed k-means that optimize a shared objective, it achieves structural consensus: agents independently cluster their local feature views and reconcile only through unanimous agreement on sample groupings and ordinal rankings for medoid selection. This yields a shared hierarchical Cluster Fusion Hierarchy (CFH) that infers cluster numbers automatically. Theoretical guarantees include linear communication in sample count, identifier-level privacy by design, and robustness to Byzantine agents via a veto mechanism. Experiments on synthetic multimodal data show perfect recovery (ARI=1.0) of six clusters where baselines fail, and across five real datasets, VertCoHiRF with suitable base methods (e.g., SC-SRGF, DBSCAN) consistently outperforms distributed k-means, coreset k-means, and differentially private baselines.

## Method Summary
VertCoHiRF operates in a vertical federated setting where each agent holds a distinct subset of features for the same sample identifiers. The algorithm iterates: (1) each agent applies its chosen local base clustering method (BCM) to the current active medoid set; (2) Phase 1 (strict consensus): agents broadcast cluster labels; two samples are merged into the same consensus cluster only if all agents assign them identical labels; (3) Phase 2 (medoid selection): within each consensus cluster, each agent ranks its samples by a local criterion; aggregated scores (sum of ranks) select one representative medoid per cluster; (4) the new active set becomes the selected medoids, non-selected samples become children in a hierarchy, building a dendrogram-like Cluster Fusion Hierarchy (CFH). Iteration continues until the active set stabilizes. Only identifiers, cluster labels, and ordinal rankings are exchanged; raw features never leave the agent. The final clustering is extracted from the CFH.

## Key Results
- Perfect ARI (1.0) on synthetic multimodal data with six clusters, while distributed k-means and other baselines failed.
- Consistent ARI improvement over distributed k-means, coreset k-means, and differentially private baselines across five real-world datasets when paired with appropriate local base methods.
- Linear communication in sample count \(n\) and quadratic in number of agents \(A\), with built-in Byzantine robustness and identifier-level privacy.

## Why This Works (Mechanism)

### Mechanism 1: Strict identifier-level consensus filters view-specific noise
- **Claim:** Robust clustering is achieved by retaining only groupings unanimously agreed upon by all agents, eliminating view-specific artifacts.
- **Mechanism:** Agents independently cluster their local views on active medoids; two samples share a consensus cluster iff all agents assign them the same label. This conservative rule ensures only cross-view consistent structures survive.
- **Core assumption:** Genuine global cluster structure appears consistently across heterogeneous local views; noise or view-specific patterns lack universal agreement.
- **Evidence anchors:** [abstract] “agents cluster their local views independently and reconcile their proposals through identifier-level consensus.”; [section 2.2] “Two samples are assigned to the same cluster if and only if they share the same code.”; [section 3.3] “no Byzantine agent can induce the creation of a consensus cluster that is incompatible with the structure induced by the partitions produced by all honest agents.”
- **Break condition:** Systematic omission of critical features across all agents or true structure invisible in any single view may cause over-fragmentation, preventing meaningful merges.

### Mechanism 2: Decentralized ordinal ranking selects cross-view representative medoids
- **Claim:** Medoid selection via aggregated ordinal rankings ensures representatives are consistently highly ranked across agents, preserving cluster cores.
- **Mechanism:** For each consensus cluster, agents order their samples by a local criterion (e.g., centrality); exchange ranked lists; global score = sum of ranks; lowest scores win. Aggregates preferences without sharing features.
- **Core assumption:** True cluster centers or prototypes rank near the top in each agent’s local view despite heterogeneous methods.
- **Evidence anchors:** [section 2.2] “These rankings are then aggregated through a score-based rule to select a single representative per cluster.”; [section 3.3] “Phase 2 operates exclusively on clusters that have already been filtered by strict consensus… performs a fine-grained selection among candidates that are all structurally admissible.”; [section 4.1] Synthetic experiment shows perfect recovery with appropriate base methods.
- **Break condition:** Highly discordant rankings (due to incompatible metrics or heavy noise) may yield non-representative medoids; Byzantine robustness experiments (Figure 1) show degradation only when honest signal is weak.

### Mechanism 3: Iterative hierarchical reduction infers cluster numbers and yields multi-resolution structure
- **Claim:** Progressive contraction of active medoids across iterations automatically discovers cluster counts and produces an interpretable CFH without requiring \(k\).
- **Mechanism:** Initially all samples are active. Each iteration forms consensus clusters on the active set, selects one representative per cluster as the new active set, and attaches non-selected samples as children. This reduces active set size until stabilization; parent-child links define a hierarchy.
- **Core assumption:** True clustering structure is hierarchical; repeatedly merging only consistently observed groups approximates a valid dendrogram.
- **Evidence anchors:** [abstract] “yielding a shared hierarchical Cluster Fusion Hierarchy (CFH) that infers cluster numbers without prior specification.”; [section 2.3] “The resulting parent-child relationships define a hierarchical clustering structure.”; [section 4.1] On synthetic data with 6 clusters, ARI=1.0 demonstrates automatic recovery.
- **Break condition:** Non-hierarchical ground truth (e.g., overlapping or flat clusters) may be misrepresented; early consensus errors propagate down the hierarchy.

## Architecture Onboarding
**Component map:**  
Agent (vertical feature slice, local BCM, consensus protocol, hierarchy tracker) -> Communication layer (peer-to-peer exchange of cluster labels and ranked identifier lists) -> Global state (active medoid set K(e), consensus assignments L(e), parent-child hierarchy P).

**Critical path:**  
1. Initialize: all samples are active medoids.  
2. Repeat until convergence:  
   a. Local clustering: each agent runs its BCM on active medoids’ local features, producing labels L_a.  
   b. Cluster consensus: broadcast L_a; consensus label L formed by concatenation – samples share label only if all agents agree.  
   c. Medoid consensus: for each consensus cluster, agents rank members locally; exchange lists; aggregate scores to pick one representative per cluster as new active set K.  
   d. Update hierarchy: non-selected samples become children of their chosen medoid.  
3. Extract final labels from hierarchy.

**Design tradeoffs:**  
- Strict vs. relaxed consensus: strict ensures no spurious merges but may over-fragment; * variants allow local filtering to relax when views are noisy.  
- Base clustering method choice: must suit local feature modality; no universal best method.  
- Communication topology: analysis assumes fully connected peer-to-peer; sparse graphs may affect robustness.  
- Byzantine tolerance: veto mechanism prevents malicious merges but cannot prevent denial-of-service.

**Failure signatures:**  
- Active set does not shrink: consensus too fragmented due to heterogeneous views or overly strict consensus; consider relaxing or tuning BCMs.  
- Rapid collapse to single cluster: overly permissive local clusterings (e.g., k-means with too large k) causing universal agreement.  
- Performance below local baseline: incompatible views or one agent dominating negatively; consider weighted rankings or selective participation.  
- High variance across feature partitions: sensitivity to feature split; may need more overlap or careful agent selection.

**First 3 experiments:**  
1. Synthetic multimodal dataset: Two agents with spherical (2 clusters) and square-based (3 clusters) modalities; true global 6 clusters. VertCoHiRF with DBSCAN for agent 0 and k-means for agent 1 achieved ARI=1.0; k-means and distributed k-means failed.  
2. Scaling number of agents: On alizadeh-2000-v2, varied agents from 2 to 6 with overlapping features. VertCoHiRF with SC-SRGF maintained high ARI; DPFMPS degraded and distributed k-means was lower.  
3. Real-world datasets: Evaluated on five datasets (alizadeh, chowdary, coil-20, garber, nursery, shuttle) with feature splits. VertCoHiRF paired with dataset-appropriate BCM (e.g., DBSCAN for coil-20, SC-SRGF for others) consistently outperformed baselines in ARI.

## Open Questions the Paper Calls Out
- **Open Question 1:** How can VertCoHiRF be extended to hybrid partitioning settings where some samples are not shared across all agents, or feature/sample alignments are imperfect? Basis: [explicit] “Future work will investigate the adaptation of our approach to hybrid partitioning regimes.” Why unresolved: Current protocol assumes fully shared sample indices and relies on strict unanimity; hybrid settings introduce missing views and misalignment. What evidence would resolve: Modified protocol tolerating missing data (e.g., unanimity threshold) with theoretical guarantees and experiments on hybrid datasets.
- **Open Question 2:** What alternative communication topologies can reduce the quadratic dependency on the number of agents while preserving privacy and robustness? Basis: [explicit] “Exploring alternative communication topologies is a natural extension, but is beyond the scope of this work.” Why unresolved: Analysis assumes fully connected peer-to-peer; infeasible for large A. What evidence would resolve: Systematic study of sparse/graph-based consensus (e.g., gossip) with updated complexity bounds and scaling results.
- **Open Question 3:** Under what conditions does structural consensus (VertCoHiRF) significantly outperform objective-sharing VFL clustering (e.g., distributed k-means)? Basis: [inferred] Synthetic multimodal experiment shows perfect recovery where k-means fails, suggesting advantage when views encode heterogeneous complementary structures. Why unresolved: No general characterization; practitioners lack criteria to choose methods a priori. What evidence would resolve: Theoretical analysis (e.g., heterogeneity metrics) and extensive experiments across diverse regimes to derive predictive heuristics.
- **Open Question 4:** How does the choice of base clustering methods per agent affect convergence speed and CFH quality, especially with varying granularity or robustness? Basis: [inferred] Gains depend on suitability of local method; VertCoHiRF(K-means) underperforms on some datasets, but interaction dynamics unanalyzed. Why unresolved: Flexibility is a strength, but without understanding local properties’ influence, tuning is guesswork; hierarchy structure may be impacted. What evidence would resolve: Sensitivity analysis varying base method type and parameters, measuring convergence rates, ARI, CFH metrics, possibly with theoretical links.

## Limitations
- Performance highly sensitive to choice and tuning of local base clustering methods; no automatic selection guidance provided.
- May over-fragment when no single view reflects true cluster structure; no fallback strategy for stringent consensus failures.
- Undocumented Optuna configuration and ranking tie-break details hinder exact reproduction; small deviations in hyperparameters possible.
- No evaluation on overlapping or non-hierarchical ground truth; imposed hierarchy may misrepresent true relationships.

## Confidence
- Structural consensus (strict identifier agreement): Medium (theoretically sound, synthetic success, but over-fragmentation risk with heterogeneous views).
- Ordinal medoid selection: Medium (robust in experiments; behavior under tied/noisy rankings unknown).
- Automatic cluster number inference: Low (validated on one synthetic hierarchical dataset; may fail on flat/non-hierarchical structures).
- Privacy & Byzantine robustness: High (identifier-only communication guarantees privacy; veto mechanism provably blocks malicious merges).
