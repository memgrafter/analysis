# InkDrop: Invisible Backdoor Attacks Against Dataset Condensation

## Quick Facts
- **arXiv ID:** 2603.28092
- **Source URL:** https://arxiv.org/abs/2603.28092
- **Reference Count:** 40
- **Primary Result:** InkDrop achieves near-perfect attack success rates (~1.0) while preserving clean accuracy and outperforming prior methods in stealth (PSNR >64, SSIM >0.75) across multiple datasets.

## Executive Summary
InkDrop introduces a stealthy backdoor attack specifically designed for dataset condensation. It exploits model uncertainty near decision boundaries to select vulnerable source-class samples, then trains an instance-specific perturbation generator using a multi-objective loss. By injecting a small fraction of these imperceptibly perturbed samples into the target-class distribution before condensation, the backdoor is embedded into the synthetic dataset. The attack consistently balances high effectiveness, preserved utility, and strong stealth across standard benchmarks, demonstrating resilience against common defenses and cross-architecture transferability.

## Method Summary
InkDrop operates in three stages. First, a **candidate selector** uses a surrogate model to identify a source class and its samples closest to the target class decision boundary via KL divergence and misclassification rate scores. Second, an **attack model** (a neural network) is trained to generate instance-specific perturbations for these samples, optimizing a combined loss: InfoNCE contrastive loss for feature alignment, Earth Mover’s Distance for soft-label distribution matching, L2 norm regularization, and LPIPS perceptual loss. Third, a **malicious condensation** phase mixes a small fraction of these triggered samples with clean target-class data. This mixed set is used as the real data for condensing the synthetic subset of the target class, while other classes are condensed normally—thereby encoding the backdoor into the final small dataset.

## Key Results
- **Near-Perfect Attack Success:** Achieves ASR ≈ 1.0 on STL-10, Tiny-ImageNet, CIFAR-10, and SVHN.
- **Preserved Clean Utility:** Maintains competitive Clean Task Accuracy (CTA) after condensation.
- **Superior Stealth:** Significantly outperforms baselines with PSNR >64 and SSIM >0.75, and shows resilience against fine-tuning and neural cleanse defenses.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Selecting source-class samples near the decision boundary for the target class increases attack efficiency and stealth, as minor perturbations suffice for misclassification.
- **Mechanism:** Computes a joint score `I_{o→τ} - λ π_{o→τ}` for each source class `o`, where `I` is expected KL divergence to a target reference distribution `q_τ`, and `π` is the misclassification rate. The minimal score class `o*` is chosen. Within `o*`, the top-κ₁ fraction of samples ranked by target-class confidence `f_τ(x)` forms the candidate pool.
- **Break Condition:** If the surrogate model `f` poorly approximates downstream model boundaries, the candidate pool’s transferability drops, reducing ASR.

### Mechanism 2
- **Claim:** A multi-objective loss trains an instance-dependent attack model to generate perturbations that are both effective and perceptually stealthy.
- **Mechanism:** Four losses: (i) **InfoNCE** aligns poisoned sample features `ϕ(x_atk)` with target embeddings `Z_τ` and repels clean source features; (ii) **EMD** aligns output distribution `f(x_atk)` with target soft labels `Q_τ`; (iii) **L2** constrains `‖δ‖₂`; (iv) **LPIPS** maintains deep feature similarity between `x` and `x_atk`.
- **Break Condition:** Poor hyperparameter weighting (λ₁–λ₄) can over-prioritize one objective (e.g., high ASR with poor stealth or vice versa).

### Mechanism 3
- **Claim:** Injecting a small fraction of poisoned samples into the target-class distribution before condensation embeds the backdoor into the synthetic dataset while preserving clean accuracy.
- **Mechanism:** For target class τ, build `T_mixed = D_τ ∪ {(x_atk, τ)}` using a fraction ρ of triggered samples from the candidate pool. Condense `T_mixed` to produce synthetic subset `Ŝ_τ`; other classes use clean data. The condensation objective (e.g., MMD, attention matching) preserves the mixed distribution’s statistics, including the trigger pattern.
- **Break Condition:** ρ too high degrades CTA; ρ too low dilutes the backdoor signal during condensation, reducing ASR.

## Foundational Learning
- **Dataset Condensation (DM/IDM/DAM):** Synthesizes a small dataset `Ŝ` that matches the feature distribution of a large real dataset `D` via matching losses (e.g., MMD, attention). **Why needed:** InkDrop poisons the *real* data *before* condensation, so the synthetic set inherits the backdoor. **Quick check:** If you poison 10% of 'cat' images in `D`, the condensed 'cat' images should statistically reflect that poisoned distribution.
- **Backdoor Attack Metrics (ASR, CTA, Stealth):** ASR measures attack success on triggered inputs; CTA measures utility on clean inputs; Stealth (PSNR, SSIM, IS) measures trigger imperceptibility. **Why needed:** InkDrop’s core contribution is balancing these three competing goals. **Quick check:** Can an attack have ASR=1.0 but be impractical? Yes—if triggers are obvious or CTA plummets.
- **Instance-Dependent vs. Fixed Triggers:** InkDrop uses a learned generator `g_θ(x)` to produce a unique perturbation per sample, unlike fixed patterns (e.g., a square patch). **Why needed:** Instance-dependent triggers adapt to each sample’s features, achieving higher stealth and surviving condensation’s averaging effects. **Quick check:** Why might a fixed trigger fail in a condensed dataset? The condensation process may average out or distort a fixed pattern across synthesized samples.

## Architecture Onboarding
Candidate Selector -> Attack Model Trainer -> Malicious Condenser
- **Critical Path:** The candidate selector’s output `P_τ` feeds the attack model trainer. The trained `g_θ` then produces triggers for `P_τ`, which are mixed into the target-class data for the malicious condenser. Quality degrades at any stage: a poor `P_τ` yields ineffective `g_θ`; a weak `g_θ` produces detectable triggers; faulty mixing fails to embed the backdoor.
- **Design Tradeoffs:**
  - **κ₁ (candidate pool size):** Larger pool provides more training data for `g_θ` but includes less boundary-adjacent samples, requiring larger perturbations.
  - **ρ (poisoning rate in `T_mixed`):** Higher ρ strengthens the backdoor signal but risks degrading CTA.
  - **Loss weights (λ₁–λ₄):** Balance ASR vs. stealth; requires tuning. Paper’s defaults prioritize high ASR with strong stealth.
- **Failure Signatures:**
  - High PSNR/SSIM but low ASR: `g_θ` made minimal perturbations that failed to cross the decision boundary.
  - High ASR but low CTA: ρ too high, or condensation failed to preserve clean semantics.
  - ASR drops under cross-architecture transfer: Candidate pool `P_τ` not transferable; surrogate `f` misaligned with downstream models.
- **First Three Experiments:**
  1. **Candidate Selection Validation:** Verify that the selected source class `o*` and top-κ₁ samples indeed lie near the decision boundary (high `f_τ(x)`).
  2. **Attack Model Ablation:** Train `g_θ` with loss components removed one-by-one to confirm each’s contribution to ASR and stealth (e.g., removing LPIPS harms SSIM).
  3. **Stealth Visualization:** Compare clean vs. triggered images and compute PSNR/SSIM/IS to demonstrate imperceptibility against baselines.

## Open Questions the Paper Calls Out
- **Open Question 1:** Does InkDrop generalize to non-image data modalities and high-resolution image datasets?
  - **Basis in paper:** [inferred] Evaluation limited to four image datasets (STL-10, Tiny-ImageNet, CIFAR-10, SVHN).
  - **Why unresolved:** Mechanism relies on image-space perturbations and perceptual metrics; applicability to text/audio/large-scale images unknown.
  - **What evidence would resolve it:** Experiments on text (e.g., AG News) with textual triggers and on high-resolution datasets like ImageNet, reporting ASR, CTA, PSNR, SSIM.
- **Open Question 2:** How robust is InkDrop against modern adaptive detection defenses beyond the few evaluated?
  - **Basis in paper:** [inferred] Tests against PDB, RNP, PIXEL, ABS but not many state-of-the-art detectors (e.g., activation clustering, STRIP, frequency analysis).
  - **Why unresolved:** Stealth claim may not hold against more sophisticated or specialized detection.
  - **What evidence would resolve it:** Apply advanced backdoor detection methods to poisoned condensed datasets; measure detection rates, false positives, impact on ASR.
- **Open Question 3:** How sensitive is InkDrop to its hyperparameters, and can they be set automatically?
  - **Basis in paper:** [inferred] Hyperparameters (κ₁, κ₂, ρ, λ₁…λ₄) fixed without sensitivity analysis or adaptive selection.
  - **Why unresolved:** Practitioners need parameter robustness understanding and tuning heuristics.
  - **What evidence would resolve it:** Systematic sensitivity study varying each hyperparameter; plot ASR, CTA, stealth to identify stable regions.
- **Open Question 4:** What is the impact of surrogate model quality on InkDrop’s effectiveness?
  - **Basis in paper:** [inferred] Threat model assumes well-trained surrogate approximates downstream model; no experiments vary surrogate accuracy or architecture mismatch.
  - **Why unresolved:** Attacker may have limited/poorly aligned surrogate info, potentially degrading transferability.
  - **What evidence would resolve it:** Train surrogates with reduced data, different architectures, or degraded accuracy; evaluate resulting ASR/CTA after condensation and downstream training.

## Limitations
- **Implementation Details Withheld:** Architecture, initialization, and training regimen of attack model `g_θ` are unspecified; hyperparameter values (κ₁, κ₂, λ, λ₁–λ₄, ρ) are not listed, hindering reproducibility without source code.
- **Surrogate Fidelity Assumption Untested:** Transferability hinges on surrogate `f` accurately approximating downstream model decision boundaries; no measurement of boundary alignment (e.g., prediction agreement) is provided.
- **Condensation Algorithm Generalizability Unclear:** Evaluated only on DM/IDM/DAM; interaction between poisoning fraction ρ and other condensation objectives (e.g., different matching losses) is not deeply analyzed.
