# Multimodal In-context Learning for ASR of Low-resource Languages

## Quick Facts
- **arXiv ID:** 2601.05707  
- **Source URL:** https://arxiv.org/abs/2601.05707  
- **Reference count:** 40  
- **Primary result:** Multimodal in-context learning (MICL) with speech LLMs consistently lowers perplexity compared to standard ASR prompting and text-only ICL for low-resource languages, and cross-lingual fine-tuning improves efficiency without target-language data.

## Executive Summary
This paper introduces multimodal in-context learning (MICL) for automatic speech recognition (ASR) in low-resource and endangered languages. MICL conditions a speech LLM on paired audio-text demonstrations to transcribe unseen target audio, leveraging both acoustic and textual information. Evaluated on three diverse endangered languages, MICL consistently reduces perplexity compared to text-only in-context learning and standard ASR prompting. Moreover, cross-lingual instruction fine-tuning on other languages enhances MICL efficiency for the target language without using its data. Attention analysis reveals a layer-dependent modality preference with an overall bias toward text context. A practical ASR system combining a strong acoustic model with MICL-based hypothesis selection yields lower word error rates than the acoustic model alone.

## Method Summary
The method uses a speech LLM (e.g., Qwen3-Omni, Phi-4) that processes interleaved audio encoder outputs and text tokens. For a given target audio, the model is provided with a prompt containing a system instruction, a user query, and a set of paired audio-text demonstrations (in-context examples). The audio encoder (e.g., Wav2Vec2) converts raw audio into a sequence of continuous representations, which are projected into the LLM’s token embedding space. The LLM decoder then autoregressively generates the transcription of the target audio, conditioned on the entire context. The system can be enhanced by cross-lingual instruction fine-tuning, where the model is trained on MICL tasks in multiple source languages to learn the general procedure of using audio-text pairs. For ASR, a separate acoustic model generates candidate hypotheses, and the speech LLM (via MICL) scores them to select the best transcription.

## Key Results
- MICL lowers perplexity compared to text-only ICL and ASR prompting across three endangered languages.
- Cross-lingual instruction fine-tuning improves MICL efficiency on target languages without using target-language data.
- Attention analysis shows layer-dependent modality preferences and an overall bias toward text context; a practical hybrid system with MICL hypothesis selection reduces WER.

## Why This Works (Mechanism)
**Mechanism 1: Joint Audio-Text Conditioning**  
- **Claim:** MICL reduces perplexity by jointly conditioning on paired audio-text demonstrations.  
- **How:** The speech LLM processes interleaved audio and text tokens. Paired demonstrations teach the audio-to-text mapping, allowing the model to generalize lexical and phonetic patterns.  
- **Evidence:** Consistent outperformance of MICL over ICL (text-only) in experiments; gains hold across context lengths for Qwen3-Omni.

**Mechanism 2: Cross-lingual Transfer of MICL Procedure**  
- **Claim:** Cross-lingual instruction fine-tuning on other languages improves MICL on unseen target languages.  
- **How:** Fine-tuning teaches the model the language-agnostic procedure of using audio-text pairs, which transfers to the target language.  
- **Evidence:** Fine-tuned models achieve performance close to target-language fine-tuning without using target data.

**Mechanism 3: Layer-dependent Modality Preference and Text Bias**  
- **Claim:** The model’s attention shows layer-dependent modality preferences, with an overall bias toward text.  
- **How:** Early and final layers attend more to audio, middle layers to text; overall more attention mass on text.  
- **Evidence:** Attention mass analysis and intervention experiments (replacing demo text with gold text improves performance and increases text attention).

## Foundational Learning
**In-context Learning (ICL)**  
- *Why needed:* The core method relies on providing examples in the prompt to adapt to a new language without weight updates.  
- *Quick check:* What are two possible failure modes of ICL when applied to a truly unseen language (e.g., different script, phonology)?

**Multimodal Sequence Interleaving**  
- *Why needed:* Speech LLMs process a single stream of tokens from different modalities (audio encoder outputs + text tokens). The model must learn cross-modal associations.  
- *Quick check:* Why might the model find text tokens easier to attend to than audio-derived tokens, even when audio is the primary input modality?

## Architecture Onboarding
**Component map**  
- **Input Encoders:** Separate audio encoder (e.g., Wav2Vec2-style) and text tokenizer. Audio encoder produces a sequence of continuous representations.  
- **Modality Projector:** Maps audio encoder outputs into the LLM’s token embedding space.  
- **LLM Decoder:** Autoregressive transformer (Phi-4 or Qwen3-Omni) that processes interleaved audio and text embeddings.  
- **Prompt Builder:** Constructs the multimodal prompt with system, user, audio, and text.  
- **Hypothesis Scorer:** For ASR, scores candidate hypothesis strings given the prompt and target audio.

**Critical path**  
Raw Audio → Audio Encoder → Projected Audio Tokens → (interleaved with) Text Demo Tokens → LLM Decoder → Target Transcription

**Design tradeoffs**  
- Context length vs. performance: longer context (more demos) lowers perplexity but increases compute and may introduce noise.  
- Modality balance: audio sequences are longer (3×) than text, and the model has a text bias.  
- Fine-tuning scope: full fine-tuning vs. LoRA (marginal differences, LoRA chosen for efficiency).

**Failure signatures**  
- High perplexity with ASR prompt (no context) on unseen language.  
- MICL offers no gain over text-only ICL (or is worse) when in-context audio is added (especially Phi-4 in long contexts).  
- Attention distribution does not shift when demo text/audio is replaced with gold.  
- Cross-lingual fine-tuning fails to reduce perplexity if fine-tuning languages are few/not diverse.

**First 3 experiments**  
1. Baseline ASR Prompting: Run ASR task (no context) to confirm zero-shot failure.  
2. Modality Ablation: Compare T-ICL, ICL, and MICL for a fixed number of samples to verify MICL advantage.  
3. Attention Sanity Check: Compute attention mass to different prompt components for MICL vs. ICL to verify text bias and layer-dependent pattern.

## Limitations
- Evaluated on only three endangered languages, limiting generalizability across typological profiles.  
- Cross-lingual fine-tuning benefit likely depends on the choice and diversity of source languages.  
- Attention analysis is correlational; causality not established.

## Confidence
- **MICL efficacy vs. text-only ICL:** Medium-High  
- **Cross-lingual fine-tuning transfer:** Medium  
- **Layer-dependent modality preference & text bias:** Medium  

## Next Checks
1. Expand linguistic diversity: replicate core experiments on a larger, typologically diverse set of low-resource languages to test robustness of MICL advantage and attention patterns.  
2. Source language ablation for fine-tuning: study the effect of number and genealogical/phonetic similarity of fine-tuning languages on MICL transfer.  
3. Causal attention intervention: implement targeted attention head patching (e.g., suppress middle-layer text-attending heads) to test if disrupting observed patterns degrades perplexity.
