# Same Meaning, Different Scores: Lexical and Syntactic Sensitivity in LLM Evaluation

## Quick Facts
- **arXiv ID:** 2602.17316
- **Source URL:** https://arxiv.org/abs/2602.17316
- **Reference count:** 0
- **Primary result:** Meaning-preserving lexical perturbations (synonym substitution) cause large, significant performance drops across LLMs (e.g., -7.72 pp on MMLU), while syntactic perturbations have weaker, heterogeneous effects; both destabilize model rankings on complex tasks.

## Executive Summary
This study evaluates the robustness of LLM benchmarks by applying linguistic perturbations that preserve meaning to three major benchmarks: MMLU (multiple-choice QA), SQuAD (extractive QA), and AMEGA (clinical QA). Across 23 models, synonym substitutions lead to substantial accuracy declines, whereas syntactic transformations (e.g., active-to-passive) yield much smaller drops. Critically, these perturbations reshuffle relative model rankings—especially on SQuAD and AMEGA—indicating that leaderboard positions are brittle to minor linguistic changes. The relationship between model size and robustness is inconsistent: larger models are more vulnerable on MMLU but more robust on SQuAD and AMEGA. The findings suggest LLMs rely heavily on surface lexical patterns rather than deeper syntactic or semantic understanding, raising concerns about the validity of current evaluation practices.

## Method Summary
The study tests 23 LLMs on original and perturbed versions of MMLU, a 1,000-question sample of SQuAD, and AMEGA. Two perturbation pipelines are used: (1) **Lexical**: a quantized Llama-3.3-70B-Instruct rewrites each instance via guided synonym substitution, ensuring answer spans remain contiguous for SQuAD. (2) **Syntactic**: sentences are parsed with spaCy to identify constituents (subjects, objects); a rule-based selector applies transformations (e.g., active↔passive, wh-movement) from a predefined list, and the same LLM rewrites only the matrix clause to maintain propositional meaning. All models are evaluated zero-shot (temperature=0) on original and both perturbed sets. Performance deltas are computed, statistical significance assessed via McNemar’s test, and ranking stability measured with Kendall’s τ.

## Key Results
- Lexical perturbations cause an average accuracy drop of 7.72 percentage points on MMLU, versus 1.64 pp for syntactic perturbations.
- Leaderboard rankings are destabilized on SQuAD (τ=0.93) and AMEGA (τ=0.89) under lexical changes, falling below the strict agreement threshold (τ > 0.9).
- Correlations between model size and robustness are positive for MMLU (r=0.84) but negative for SQuAD (r=−0.47) and AMEGA (r=−0.67).

## Why This Works (Mechanism)

### Mechanism 1: LLMs rely on surface lexical patterns, not abstract syntax
- **Claim:** LLMs build strong associations between specific token sequences and correct answers. Lexical perturbations break these surface patterns, forcing reliance on deeper semantic or structural understanding, which is less developed.
- **Mechanism:** During training, models memorize frequent lexical collocations tied to answers. Substituting synonyms disrupts these surface cues without altering meaning, exposing dependence on exact wording.
- **Core assumption:** Performance on meaning-preserving perturbations reflects the degree to which a model’s behavior is tied to superficial input features versus stable semantic representations.
- **Evidence anchors:**
  - [abstract] Lexical perturbations induce substantial, statistically significant degradation, while syntactic effects are more heterogeneous.
  - [section 4, Finding 1] On MMLU, lexical drop = 7.72 pp, syntactic drop = 1.64 pp.
  - [corpus] Neighboring work on prompt sensitivity supports general brittleness but not the specific lexical > syntactic hierarchy.
- **Break condition:** If lexical perturbations consistently cause performance gains or negligible change across models and tasks, the claim of heavy lexical reliance is falsified.

### Mechanism 2: Minor linguistic variations destabilize model leaderboards
- **Claim:** Because model capabilities are not uniformly distributed across linguistic dimensions, perturbations that stress a particular dimension (e.g., lexical variation) reshuffle performance order.
- **Mechanism:** Models have uneven robustness; a perturbation that disadvantages lexically reliant models will advantage others with more robust semantic processing, altering rankings.
- **Core assumption:** A robust evaluation should yield stable rankings under linguistically valid transformations of test instances.
- **Evidence anchors:**
  - [abstract] Both perturbation types destabilize model leaderboards on complex tasks.
  - [section 4, Finding 2 & Table 3] Kendall’s τ for lexical perturbations on SQuAD (0.93) and AMEGA (0.89) are below 0.9, indicating meaningful rank volatility.
  - [corpus] Limited direct evidence; prior studies examine prompt sensitivity but not relative ranking effects across multiple models.
- **Break condition:** If Kendall’s τ between original and perturbed leaderboards consistently exceeds 0.95 for all tasks and perturbation types, significant brittleness is contradicted.

### Mechanism 3: Model size-robustness relationship is task-dependent
- **Claim:** Scaling improves some capabilities (e.g., factual recall) but can amplify spurious correlations or overfitting to benchmark-specific patterns; the dominant effect depends on task nature.
- **Mechanism:** Larger models have more capacity, but how that capacity is allocated (robust abstraction vs. surface memorization) varies with training data and objectives.
- **Core assumption:** Parameter count alone does not guarantee uniform improvements across all linguistic dimensions.
- **Evidence anchors:**
  - [abstract] Model robustness did not consistently scale with model size, revealing strong task dependence.
  - [section 4, Finding 3 & Figure 5] For MMLU, size–drop correlation r=0.84 (positive: larger models degrade more); for SQuAD r=−0.47 and AMEGA r=−0.67 (negative: larger models degrade less).
  - [corpus] No prior work directly addresses task-dependent scaling for perturbation robustness.
- **Break condition:** If a large-scale study finds a consistent positive correlation (r > 0.7) between model size and robustness across diverse tasks and perturbations, task-dependence is weakened.

## Foundational Learning
- **Concept: Truth-Conditional Meaning Preservation**
  - **Why needed:** The entire study’s validity requires perturbations that preserve factual content and communicative intent; otherwise, performance drops could reflect altered questions, not model sensitivity.
  - **Quick check:** Changing “Abraham Maslow proposed the idea” to “The idea was proposed by Abraham Maslow” preserves the truth-conditional proposition that Maslow was the proposer.
- **Concept: Dependency Parsing for Syntactic Analysis**
  - **Why needed:** The syntactic pipeline uses dependency grammar to identify safe, meaning-preserving transformations (e.g., active-to-passive) by locating grammatical roles (subject, object), not just word order.
  - **Quick check:** In “The cat chased the mouse,” the dependency label for “the cat” in relation to “chased” is `nsubj` (nominal subject).
- **Concept: Kendall’s Tau for Rank Correlation**
  - **Why needed:** A core claim is about the *stability of model rankings*. Accuracy drops alone do not capture order changes; Kendall’s τ measures similarity between ranked lists.
  - **Quick check:** If Model A is #1 and Model B is #2 originally, but after perturbation Model A is #2 and Model B is #1, Kendall’s τ = −1 (perfect inversion).

## Architecture Onboarding
- **Component map:** Benchmark Selection -> Perturbation Engine -> Evaluation Harness -> Analysis Suite
- **Critical path:** Raw benchmark data → Generate perturbed versions (lexical & syntactic) → Run all 23 models on original and perturbed sets (zero-shot, fixed seed) → Compute per-instance correctness → Aggregate metrics (accuracy, EM/F1, adherence) → Calculate deltas, run statistical tests (McNemar, Wilcoxon) → Compute Kendall’s τ for ranking stability → Plot size vs. robustness.
- **Design tradeoffs:** 
  - Lexical pipeline uses an LLM for fluency but is non-deterministic and costly; syntactic pipeline uses deterministic parsing for precision but may miss context-dependent transformations.
  - Quantized LLM balances cost/speed against output quality.
- **Failure signatures:**
  - High lexical drop + high syntactic drop: Model generally brittle to surface changes.
  - High lexical drop + low syntactic drop: Model relies on exact token patterns (supports Mechanism 1).
  - Low Kendall’s τ (< 0.8) for SQuAD/AMEGA: Confirms leaderboard brittleness on complex tasks (Mechanism 2).
  - Positive size-robustness correlation on MMLU only: Confirms task-dependent scaling (Mechanism 3).
- **First 3 experiments:**
  1. **Baseline Replication:** Evaluate all 23 models on the original MMLU, SQuAD, and AMEGA to reproduce canonical leaderboard scores (Table 2).
  2. **Lexical Perturbation Replication:** Generate lexically perturbed versions of a fixed subset (e.g., 100 MMLU questions). Verify average accuracy drop matches reported ~7–8 pp.
  3. **Syntactic Perturbation Sanity Check:** Apply syntactic pipeline to the same subset. Verify average drop is smaller (~1–2 pp for MMLU) and manually check a few examples for grammaticality and meaning preservation.

## Open Questions the Paper Calls Out
- **Why are LLMs more sensitive to lexical than syntactic perturbations?** The paper documents the effect but not the underlying cause; requires analyzing model internals or training data frequencies.
- **Why does robustness correlation with size vary across tasks?** The task-dependent link is unknown; may relate to task characteristics or training data composition.
- **Do these robustness patterns hold for other tasks and languages?** Only three English benchmarks studied; unknown if sensitivity extends to other domains (e.g., code generation) or multilingual settings.
- **Can training with perturbed inputs or consistency losses improve robustness?** No experiments yet; investigating data augmentation or semantic consistency objectives is needed.

## Limitations
- Missing exact prompt templates for the LLM in both perturbation pipelines, risking implementation drift.
- Ambiguity in the exact version and quantization method of “quantized Llama-3.3-70B-Instruct” used for generation.
- Undisclosed sampling strategy for SQuAD/AMEGA subsets and precise scoring logic for AMEGA’s guideline adherence evaluator.
- Ambiguous model list (e.g., “GPT-5-Nano”, “GPT-OSS-120b”) complicates size-robustness correlation analysis.

## Confidence
- **Mechanism 1 (Lexical > Syntactic vulnerability):** Medium. Large lexical drops are direct evidence, but claim strength depends on unspecified prompts generating truly meaning-preserving perturbations.
- **Mechanism 2 (Ranking brittleness):** Medium. Kendall’s τ values are provided, but generalizability depends on exact model set and dataset samples.
- **Mechanism 3 (Task-dependent scaling):** Medium. Correlations are reported, but ambiguity in model parameter counts (especially proprietary variants) weakens conclusiveness.

## Next Checks
