# Active Learning Using Aggregated Acquisition Functions: Accuracy and Sustainability Analysis

## Quick Facts
- **arXiv ID:** 2602.07440  
- **Source URL:** https://arxiv.org/abs/2602.07440  
- **Reference count:** 40  
- **Primary result:** Series aggregation (K-Centers then BALD) matches accuracy with up to 12% fewer labeled samples and cuts acquisition cost by nearly half; alternating BALD and BADGE yields robust performance across datasets, improving data and energy efficiency while mitigating batch mode pathologies.

## Executive Summary
Batch mode active learning (BMAL) faces an exploration‑exploitation dilemma: uncertainty‑based acquisition functions (e.g., BALD) refine decision boundaries, while representativity‑based functions (e.g., K‑Centers) cover the data space. This paper proposes six aggregation structures—series, parallel, hybrid, adaptive feedback, random, and annealing—to combine multiple acquisition functions. Experiments on CIFAR‑10, CIFAR‑100, and PTB‑XL using VGG and ResNet models show that a series structure (first K‑Centers, then BALD) attains the same test accuracy with up to 12% fewer labeled samples and reduces acquisition computational cost by almost 50%. Alternating structures, particularly those switching between BALD and BADGE, achieve >50% average winning rates across datasets, mitigating cold‑start and batch redundancy while improving energy efficiency. These results demonstrate that carefully orchestrated aggregation can effectively balance exploration and exploitation in BMAL.

## Method Summary
The active learning loop starts with a small labeled set and retrains the model from scratch each round (40 epochs, learning rate 0.001). In every round, a pool of unlabeled samples is drawn, and an aggregation structure selects a batch of fixed size \(b\) for labeling. Series aggregation first applies a cheap, representativeness‑based function (e.g., K‑Centers) to pick \(\kappa b\) diverse samples, then runs an expensive uncertainty‑based function (e.g., BALD with MC‑Dropout) only on that reduced subset. Parallel aggregation splits the pool equally between two functions and merges their selections. Adaptive feedback monitors the loss of the previous model on the current batch to decide which function to use next; annealing switches functions according to a schedule (e.g., initial exploration, then exploitation, then exploration again). Evaluations use CIFAR‑10, CIFAR‑100, and PTB‑XL with VGG and ResNet architectures. Performance is compared via pairwise t‑tests over multiple seeds, reporting winning rates, and metrics include test accuracy, labeled sample efficiency, and acquisition time.

## Key Results
- Series aggregation (K‑Centers → BALD) achieves equal accuracy with up to 12% fewer labeled samples and cuts acquisition cost by nearly half.
- Alternating structures (BALD ↔ BADGE) yield robust performance across datasets, attaining >50% average winning rates and mitigating batch mode pathologies.
- Aggregation balances exploration and exploitation, improving both data and energy efficiency.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: The series aggregation structure (e.g., K‑Centers then BALD) reduces labeled sample requirement by up to 12% and acquisition computational cost by nearly half while maintaining accuracy.
- **Mechanism**: The first acquisition function (K‑Centers) selects a diverse subset of the pool that covers the data distribution, thus reducing redundancy. The second acquisition function (BALD) then operates on this smaller, diverse subset to select the most uncertain points, avoiding the high computational cost of MC‑Dropout on the full pool. The two‑stage filtering ensures that the final batch is both diverse and uncertain.
- **Core assumption**: The initial representative selection must preserve the overall data structure such that uncertainty‑based selection on the subset remains effective. Also, the cost of the first function must be significantly lower than the second to yield net savings.
- **Evidence anchors**:  
  - [abstract]: "Sequentially running functions like K‑Centers then BALD has achieved the same performance goals with up to 12% fewer samples, while reducing the acquisition cost by almost half."  
  - [section V‑D]: "Series K‑Centers then BALD performs better with respect to both objectives (time and accuracy) with minimal sensitivity to the κ parameter."  
  - [corpus]: Not directly supported by neighboring papers; relies on the paper's own experiments.
- **Break condition**: If the first function is poorly matched to the data distribution (e.g., K‑Centers on PTB‑XL, where feature‑space distance does not capture informativeness), the series may underperform relative to the second function alone.

### Mechanism 2
- **Claim**: Alternating between acquisition functions with complementary paradigms (e.g., BALD for exploitation and BADGE for exploration) across rounds yields robust performance across datasets, mitigating batch mode pathologies and cold start.
- **Mechanism**: Uncertainty‑based BALD focuses on decision boundary refinement (exploitation), while gradient‑embedding‑based BADGE emphasizes diversity in weight space (exploration). By switching between them—randomly, via annealing schedule, or via adaptive feedback—the active learning cycle periodically explores new regions and then exploits them, avoiding overfitting to local structures or redundant sampling.
- **Core assumption**: The two functions must have distinct operational foci (prediction space vs. weight space) so that their combination covers more aspects of informativeness. The switching frequency or schedule must be appropriate for the dataset's complexity.
- **Evidence anchors**:  
  - [abstract]: "Alternating structures like BALD and BADGE yield robust performance across datasets, improving data and energy efficiency while mitigating batch mode pathologies."  
  - [section V‑F]: "The three top combinations are Random Least confident ‑ FL, Annealing BALD ‑ BADGE and Annealing Least Confident ‑ BADGE. These three combinations outperform on average with more than 54% winning rate over the baseline."  
  - [section V‑F]: "Approaches alternating between BADGE and BALD consistently achieve winning rates above 50% across domains."
- **Break condition**: If the alternating functions are too similar (e.g., two uncertainty‑based methods), the benefits diminish. Fixed schedules may not adapt to dataset‑specific needs, causing suboptimal performance.

### Mechanism 3
- **Claim**: Adaptive feedback switching based on the previous model's loss on the selected batch dynamically balances exploration and exploitation, alleviating cold start and batch inefficiencies without manual tuning.
- **Mechanism**: The loss of the previous model on the current batch indicates batch informativeness: high loss suggests the batch contained novel points (successful exploration), so next round should exploit (use uncertainty sampling). Low loss suggests redundancy, so next round should explore (use diversity/representativity). A normalized sliding‑window score \(s_t\) updates trade‑off parameter \(\beta_t\) to decide which acquisition function to use.
- **Core assumption**: The previous model's loss on the selected batch is a reliable proxy for batch informativeness and current model knowledge gaps. The normalization window and exponential update rule appropriately track trends.
- **Evidence anchors**:  
  - [section IV‑D]: "The key idea is to alternate between exploration‑oriented acquisition functions (e.g., K‑Centers) and exploitation‑oriented ones (e.g., BALD) depending on the observed behavior of the feedback metric."  
  - [section V‑F]: "Adaptive Feedback BALD ‑ BADGE and Annealing BALD ‑ BADGE are again the top acquisition functions, each attaining an average winning rate of 58% on PTB‑XL."  
  - [section V‑F]: "Annealing BALD ‑ BADGE works better than Adaptive feedback BALD ‑ BADGE with 50% average winning rate on CIFAR10 for VGG." (shows adaptive is competitive but not always superior)
- **Break condition**: If the loss metric is noisy or uninformative (e.g., due to model instability early in training), the switching may become erratic. Hyperparameters (window size, \(\lambda\)) may need dataset‑specific tuning.

## Foundational Learning

### Concept: Active Learning (AL) and Batch Mode Active Learning (BMAL)
- **Why needed here**: The paper operates within the AL framework, specifically BMAL, where a batch of samples is selected per round. Understanding AL's goal (minimizing labeling effort) and BMAL's constraints (computational efficiency, batch selection pathologies) is essential to appreciate the aggregation structures.
- **Quick check question**: What is the primary difference between standard pool‑based active learning and batch mode active learning, and why is BMAL necessary for deep neural networks?

### Concept: Acquisition Function Paradigms
- **Why needed here**: The paper aggregates acquisition functions from different paradigms (uncertainty, diversity, representativity). Knowing the strengths and weaknesses of each paradigm explains the exploration‑exploitation dilemma and why combining them might help.
- **Quick check question**: Give an example of an uncertainty‑based acquisition function and a diversity‑based acquisition function, and explain how their selection behaviors differ on a toy dataset.

### Concept: Exploration‑Exploitation Dilemma
- **Why needed here**: The core motivation for aggregation is to balance exploration (covering data space) and exploitation (refining boundaries). This dilemma is central to interpreting the results and designing effective combinations.
- **Quick check question**: Why might an active learning strategy that only uses uncertainty sampling (exploitation) fail to discover all class regions in a dataset with multimodal class distributions?

## Architecture Onboarding

### Component map
The system consists of:
- **Model**: Neural network (e.g., VGG, ResNet) trained incrementally.
- **Unlabeled pool**: Subset `Dpool` drawn from large unlabeled set `DU` each round.
- **Acquisition functions**: Individual selectors (e.g., BALD, BADGE, K‑Centers) that score or rank samples in `Dpool`.
- **Aggregation structure**: Orchestrates multiple acquisition functions (series, parallel, hybrid, adaptive feedback, annealing, random) to produce final batch `D_t`.
- **Feedback module** (for adaptive): Computes loss of previous model on current batch, updates trade‑off parameter `β_t`.
- **Training loop**: Retrains model after each batch addition.

### Critical path
1. Start with small initial labeled set `DL`, train model `M0`.
2. For each AL round `t`:
   - Randomly sample `Dpool` from `DU`.
   - **Aggregation step**: Apply chosen structure to `Dpool` and current model `M_{t‑1}` to select batch `D_t` of size `b`.
     - For series: first function selects `κb` samples, second selects `b` from those.
     - For alternating: one function selected via schedule (random, annealing, adaptive) selects `b` from `Dpool`.
     - For parallel: split `Dpool`, each function selects `b/2` from its half, combine.
   - Query labels for `D_t`, add to `DL`, remove from `DU`.
   - Retrain model `M_t` on updated `DL`.
   - If adaptive: compute loss `ℓ_t = J(D_t, ω_{t‑1})`, update `β_t` via sliding window.

### Design tradeoffs
- **Series vs. parallel**: Series reduces computational cost by shrinking pool for expensive functions (e.g., BALD) but depends on first function's representativeness. Parallel runs functions independently but may suffer from Top‑K redundancy and higher cost.
- **Function pairing**: Combine uncertainty (BALD) with representativity/diversity (K‑Centers, BADGE, FL) to balance exploration‑exploitation. Pairing two uncertainty‑based functions yields little gain.
- **Dataset sensitivity**: K‑Centers assumes feature‑space distances correlate with informativeness; this fails on noisy time‑series (PTB‑XL). BADGE works well across domains.
- **Cost vs. accuracy**: Series K‑Centers then BALD improves both; alternating structures (Annealing BALD‑BADGE) offer robustness but may not reduce cost as much.

### Failure signatures
- **Accuracy stagnation**: Model performance plateaus early, indicating batch informativeness dropped. Check for redundancy (e.g., similar feature vectors in batch).
- **Computational blowup**: If series κ is too large or parallel used unnecessarily, cost increases. Profile inference counts: BALD on full pool vs. series.
- **Dataset mismatch**: If using K‑Centers on data where feature embeddings are not meaningful (early training stages or complex signals), series performance degrades (as in PTB‑XL).
- **Adaptive instability**: Loss window too small or λ too high causes erratic switching between functions, visible in fluctuating β_t.

## Open Questions the Paper Calls Out
1. **How can the query batch size \(b\) be dynamically optimized during active learning to further improve energy efficiency without sacrificing accuracy?**  
   *Basis:* Explicitly identified as future work.  
   *Why unresolved:* The paper uses fixed \(b\); no framework or empirical evaluation for adaptive \(b\) is provided.  
   *What evidence would resolve it:* Comparative experiments with varying \(b\) schedules (e.g., annealing, predictive based on uncertainty) measuring accuracy, labeling cost, and energy consumption over time.

2. **Why does alternating between BALD and BADGE (e.g., via annealing or random structures) consistently achieve robust performance across diverse datasets and architectures?**  
   *Basis:* Results show alternating BALD–BADGE attains >50% winning rates across domains, with speculation that they operate in "complementary spaces" (prediction vs. weight space), but underlying dynamics are not analyzed.  
   *Why unresolved:* The paper hypothesizes complementarity but lacks theoretical or ablation studies dissecting the interaction between gradient embeddings and uncertainty sampling.  
   *What evidence would resolve it:* Controlled experiments swapping component functions, measuring information gain or gradient diversity, and theoretical analysis of convergence properties under alternation.

3. **Under what specific dataset characteristics (e.g., feature stability, label noise, domain type) do representativeness‑based functions like K‑Centers fail, and can this be predicted a priori?**  
   *Basis:* K‑Centers excels on CIFAR (visual) but fails on PTB‑XL (ECG): "feature space assumptions may not translate effectively to time series," implying domain sensitivity, but no generalizable criterion is given.  
   *Why unresolved:* No systematic study linking data properties (e.g., embedding variance, manifold structure) to the efficacy of diversity‑based selection.  
   *What evidence would resolve it:* Meta‑analysis across diverse datasets correlating performance drop with metrics like early‑stage embedding entropy, class imbalance, or signal‑to‑noise ratio.

4. **Why does the adaptive feedback mechanism (using previous model loss) underperform relative to simpler random or annealing alternation in some cases, and what are its optimal use conditions?**  
   *Basis:* Adaptive feedback BALD–BADGE is outperformed by annealing/random on CIFAR‑10 VGG, yet the authors attribute this to feedback design without detailed failure analysis.  
   *Why unresolved:* The feedback loop's sensitivity to hyperparameters (e.g., window size, learning rate λ) and loss normalization is not investigated; potential instability or misalignment with AL progress remains unexplained.  
   *What evidence would resolve it:* Sensitivity analysis varying feedback metric (loss, accuracy), window lengths, and λ; comparison with oracle selections to diagnose if feedback signal is noisy or delayed.

## Limitations
- Hyperparameter details (initial labeled set size, optimizer settings, data augmentation) are underspecified, which may hinder exact replication.
- Evaluation is limited to CIFAR‑10/100 and PTB‑XL with VGG/ResNet models; applicability to other domains or architectures is uncertain.
- Series aggregation fails when the first function's representativeness assumptions are invalid (e.g., K‑Centers on PTB‑XL), and adaptive feedback can be unstable early in training.

## Confidence
- Series aggregation (K‑Centers then BALD) reduces sample requirement and computational cost: **Medium**.
- Alternating structures (e.g., BALD–BADGE) yield robust cross‑dataset performance: **Medium**.
- Adaptive feedback dynamically balances exploration/exploitation without manual tuning: **Low**.
- Aggregation generally solves the exploration‑exploitation dilemma in BMAL: **Medium**.
