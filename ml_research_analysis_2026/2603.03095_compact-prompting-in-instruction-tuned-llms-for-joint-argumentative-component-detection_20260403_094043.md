# Compact Prompting in Instruction-tuned LLMs for Joint Argumentative Component Detection

## Quick Facts
- arXiv ID: 2603.03095
- Source URL: https://arxiv.org/abs/2603.03095
- Reference count: 10
- Primary result: Instruction-tuned LLMs with compact XML-tag prompts achieve SOTA macro-F1 0.8778 on Persuasive Essays, exceeding CRF baselines and approaching human upper bound.

## Executive Summary
This paper reframes joint argumentative component detection (ACD) as a generative task, where models reproduce input text while inserting XML tags (`<claim>`, `<premise>`) to denote argument spans. Using compact prompts and instruction-tuned decoder-only LLMs (e.g., Llama-3-8B), the approach jointly performs segmentation and classification in a single forward pass, avoiding error propagation from pipeline methods. On the Persuasive Essays benchmark, it achieves macro-F1 0.8778 and accuracy 0.9004, surpassing feature-engineered CRFs and nearing human performance. On a merged multi-domain dataset, generative models maintain robust performance (macro-F1 0.7822), while encoder-based token classifiers drop drastically (to ~0.49), underscoring the generative formulation's cross-domain advantage.

## Method Summary
The method transforms BIO-annotated corpora into pairs of original plain text and corresponding XML-tagged text, where contiguous argumentative spans are wrapped in `<claim>` or `<premise>` tags. Models are fine-tuned on these pairs using a prompt template that instructs the model to reproduce the input exactly while inserting tags. Training uses standard fine-tuning regimes (e.g., 3–4 epochs, low learning rate) with low-temperature decoding to ensure deterministic output. At inference, long inputs are chunked to 1024 tokens, and generated outputs are parsed back into BIO labels for evaluation against gold standards. This unified generative framework leverages the autoregressive nature of decoder-only LLMs to model long-range dependencies across discourse, enabling joint learning of boundary detection and label assignment.

## Key Results
- Llama-3-8B achieves macro-F1 0.8778 and token accuracy 0.9004 on Persuasive Essays, surpassing the prior CRF SOTA (0.8670) and approaching human upper bound (0.8860).
- On a merged heterogeneous dataset (USElecDeb, Web Discourse, Persuasive Essays), OPT-6.7B attains macro-F1 0.7822.
- Encoder-only models (RoBERTa, DeBERTa) experience severe performance degradation on the merged data (macro-F1 ~0.49), highlighting the generative approach's superior cross-domain robustness.

## Why This Works (Mechanism)
**Joint Generative Formulation**  
Reframing ACD as a single text generation task (inserting XML tags) jointly solves segmentation and classification, eliminating error propagation from pipeline stages. The model learns explicit dependencies between boundary placement and label assignment by generating a sequence where tag positions define spans. Evidence: Llama-3-8B outperforms CRF on Persuasive Essays, suggesting the joint formulation captures nuanced patterns.

**Instruction-Driven Format Mastery**  
Compact prompts with explicit task description and output schema teach the model to map plain text to structured XML output. Instruction tuning sensitizes the model to format constraints, enabling it to apply tagging conventions reliably. Evidence: Strong results with compact models (OPT-6.7B) indicate efficient supervision; qualitative examples show adherence to XML format even with labeling errors.

**Autoregressive Long-Range Modeling**  
The decoder-only architecture's causal self-attention allows each token prediction to consider all preceding context, integrating discourse-level cues essential for identifying argument boundaries that span multiple sentences. Evidence: Encoder models degrade more on heterogeneous data, likely due to limited context in token classification; premise vs. claim F1 differences suggest claims rely more on long-range context.

## Architecture Onboarding
Component map: Input Processor → Prompt Template → Fine-Tuning Engine → Decoding Module → Post-Processor

Critical path:
1. Convert each dataset's BIO annotations to (plain text, XML-tagged text) pairs, preserving original whitespace and token order.
2. Construct a prompt template with a task description, input placeholder, and example output following the XML schema.
3. Fine-tune an instruction-tuned decoder-only LLM (e.g., Llama-3-8B-Instruct) on the training pairs for 3–4 epochs with early stopping on validation macro-F1.
4. For inference, chunk inputs exceeding 1024 tokens, generate with `temperature=0.01` and `top_p=0.1`, ensuring `max_new_tokens` covers input length plus tags.
5. Parse generated XML tags into BIO labels (B-/I-/O) by aligning to the original token sequence; compute macro-F1 and accuracy.

Design tradeoffs:
- **Open vs. Closed Models**: Open-weight models ensure reproducibility but may hallucinate more than proprietary ones (e.g., GPT-4).
- **Determinism vs. Creativity**: Low temperature reduces hallucination but may limit the model's ability to "discover" valid but unannotated components.
- **Chunking Strategy**: Splitting long documents risks losing cross-chunk argumentative links; the paper does not address this limitation.

Failure signatures:
- **Hallucination**: Generated text alters non-tagged words; detected by mismatched plain text after tag removal.
- **Format Drift**: Invalid XML structure (e.g., missing closing tags); detected by parsing errors.
- **Domain Drop**: Sharp performance decline on merged heterogeneous data, especially for encoder models (~0.49 F1).

First 3 experiments:
1. **Replicate Persuasive Essays benchmark**: Fine-tune Llama-3-8B with the exact prompt; verify macro-F1 ≥0.877 and accuracy ≥0.900, confirming SOTA over CRF.
2. **Merge dataset generalization**: Train OPT-6.7B on combined USElecDeb + Web Discourse + PE; expect macro-F1 ~0.7822. Analyze error breakdown: are boundary errors or label confusions dominant?
3. **Qualitative error audit**: Manually review 50 model outputs on test set. Categorize errors as (a) hallucination, (b) boundary misalignment, (c) label swap, (d) valid "discovery." Quantify distribution to inform error analysis.

## Open Questions the Paper Calls Out
**Open Question 1**: How can hallucination in generative ACD be systematically mitigated while preserving verbatim input reproduction? The paper identifies hallucination as a key challenge; future work on constrained decoding or hybrid extractive-generative architectures is needed.

**Open Question 2**: Can the generative prompting framework extend to other argument mining subtasks (e.g., relation extraction, stance detection) for an end-to-end pipeline? The authors note that only claim/premise detection was explored; unifying full argument structure remains open.

**Open Question 3**: Do model "argument type refinement" predictions reveal annotation noise or legitimate ambiguity in corpora? The paper suggests that some label mismatches may reflect inconsistent annotations, but this is unquantified; using LLMs to audit and refine datasets is a promising direction.

**Open Question 4**: Why do generative LLMs generalize better across domains than encoder-based models? The observed robustness (smaller F1 drop on merged data) is hypothesized to stem from decoder architecture and joint learning, but controlled experiments isolating architecture, training paradigm, and task formulation are lacking.

**Open Question 5**: How can ACD evaluation metrics reward semantic equivalence rather than exact string matches? Current token-level F1 penalizes minor rephrasings or valid new spans; developing metrics based on semantic similarity or human assessment of functional equivalence is needed.

## Limitations
- **Prompt specification ambiguity**: The exact wording of the compact prompt beyond the example in Figure 1 is unspecified, risking performance variability.
- **Preprocessing details missing**: BIO-to-XML conversion rules (e.g., whitespace handling, token alignment) are not fully documented, potentially hindering faithful reproduction.
- **Hallucination impact unquantified**: The cost of text alteration on final metrics is discussed qualitatively but not measured systematically (e.g., token-level exact-match rates correlated with F1).

## Confidence
- Generative formulation superiority vs. encoders: **High** (consistent SOTA results across datasets, large gap with encoder baselines).
- Compact prompting efficiency: **Medium** (performance demonstrated but ablations on prompt length/complexity are absent).
- Long-range dependency modeling: **Medium-Low** (plausible and hinted by results, but not isolated from other factors like instruction tuning; chunking limits not tested).
