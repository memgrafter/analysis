# Mamba-3: Improved Sequence Modeling using State Space Principles

## Quick Facts
- **arXiv ID**: 2603.15569
- **Source URL**: https://arxiv.org/abs/2603.15569
- **Reference count**: 40
- **Primary result**: Mamba-3 SISO improves downstream accuracy by 0.6 points over Gated DeltaNet at 1.5B scale; MIMO adds 1.2 points (total 1.8 gain) with no decode latency increase, matches Mamba-2 perplexity with half state size, solves synthetic state-tracking, and boosts decode FLOPs 4×.

## Executive Summary
Mamba-3 improves sequence modeling with state space models (SSMs) through three innovations: (1) exponential-trapezoidal discretization for greater recurrence expressiveness, (2) complex-valued state updates via data-dependent RoPE to enable robust state tracking (e.g., parity, modular arithmetic), and (3) a multi-input multi-output (MIMO) formulation that increases decode FLOPs without latency penalty. At 1.5B scale, Mamba-3 SISO exceeds the prior best linear model (Gated DeltaNet) by 0.6 points on downstream accuracy, and the MIMO variant adds a further 1.2 points. It matches Mamba-2 perplexity with half the state size, solves challenging synthetic state-tracking tasks, and achieves up to 4× decode FLOPs with negligible latency overhead, advancing the performance-efficiency frontier.

## Method Summary
Mamba-3 extends prior SSM-based architectures (Mamba-2, Gated DeltaNet) with three methodological advances: exponential-trapezoidal discretization replaces Euler’s method, yielding a width‑2 convolution on state‑inputs for richer dynamics; complex state dynamics are realized by applying data‑dependent RoPE rotations to the input (B) and output (C) projections, effectively simulating a complex‑valued SSM without storing complex states; and a MIMO formulation (rank R) transforms the state update from an outer product to a matrix multiply, raising arithmetic intensity during decoding. The resulting model retains a pre‑norm Transformer layout with SwiGLU, includes BCNorm and head‑specific biases, and is trained on 100B tokens of FineWeb‑Edu at the 1.5B scale using standard optimizers and custom kernels (Triton for prefill, CuTe for decode). These changes allow sub‑quadratic inference while closing the gap with attention‑based models.

## Key Results
- **Downstream accuracy**: Mamba‑3 SISO (1.5B) surpasses Gated DeltaNet by 0.6 percentage points on average; MIMO (R=4) adds another 1.2 (total 1.8 gain).
- **Efficiency**: Comparable perplexity to Mamba‑2 with half the state size; MIMO raises decode FLOPs up to 4× with no increase in latency.
- **State tracking**: Solves synthetic tasks (parity, modular arithmetic) that earlier linear models fail.

## Why This Works (Mechanism)

### Mechanism 1: Exponential-Trapezoidal Discretization
Exponential-trapezoidal discretization replaces Euler’s method with a generalized trapezoidal rule, creating a width‑2 convolution on the state‑input sequence (B_t x_t) before the linear recurrence. This yields a more expressive recurrence because it convex‑combines contributions from the previous and current tokens via a learned parameter λ_t ∈ [0,1], whereas Euler uses only the current token. The local discretization error is O(Δt³) under stability, and λ_t can adapt to the data. Evidence: Section 3.1 derives the recurrence and its 2‑band mask; Table 5a shows a ≈0.6% accuracy drop when using constant λ (Euler). The approach fails if λ_t is constrained to a constant (Remark 2).

### Mechanism 2: Complex-Valued State Updates via Data-Dependent RoPE
By using complex‑valued state dynamics and applying data‑dependent rotary position embeddings (RoPE) to the input and output projections (B and C), Mamba‑3 effectively simulates a complex SSM without storing complex states. The imaginary part of the state matrix A rotates B and C via a cumulative product of rotation matrices, enabling rotational dynamics essential for state‑tracking tasks like parity. The core assumption is that these rotations commute and can be merged into B and C. Evidence: Proposition 2 (complex‑to‑real equivalence) and Proposition 3 (RoPE trick) in Section 3.2; Table 5b demonstrates successful parity and modular arithmetic performance absent in real‑valued baselines. If the transition matrix is restricted to real non‑negative eigenvalues, such rotational behavior cannot be expressed, leading to state‑tracking failure.

### Mechanism 3: MIMO Formulation for Efficiency
Extending the SSM recurrence to multi‑input multi‑output (MIMO) with rank R converts the state update from an outer product to a matrix multiplication, increasing FLOPs from O(NP) to O(NPR). This raises arithmetic intensity linearly with R, moving the decode kernel from memory‑bound toward compute‑bound on GPUs, thus improving hardware utilization without increasing decode latency. Evidence: Section 3.3 shows Θ(R) arithmetic intensity; Tables 6‑7 report up to 4× decode FLOPs for R=4 with negligible latency overhead. The parameter count growth from MIMO is mitigated by reducing MLP width, preserving model size.

## Architecture Onboarding

### Component Map
Input token residual (D) & previous state (h_{t-1} ∈ ℝ^N or H_{t-1} ∈ ℝ^{N×P}) → Linear projections (Δ, A, B, C; MIMO adds X, Z) → BCNorm (RMSNorm on B,C) → Add head‑specific biases → Compute RoPE matrix R_t and update cumulative product Π → Compute α,β,γ → State update: h_t = α R_t h_{t-1} + β Π^T (B_{t-1} x_{t-1}) + γ Π^T (B_t x_t) → Output: y_t = (Π^T C_t)^T h_t → Gate: y_t · SiLU(Z_t) → Down projection → Add residual.

### Critical Path
1. Compute projections for current token.
2. Apply RMSNorm to B_t, C_t.
3. Add biases.
4. Compute λ_t (sigmoid of learned projection).
5. Compute α, β, γ.
6. Compute rotation matrix R_t; update cumulative rotation product.
7. Compute state update using previous state.
8. Compute output using rotated C_t.
9. Apply gate (SiLU) to Z_t, multiply with output; down‑project; add residual.

### Design Tradeoffs
- **SISO vs MIMO**: SISO has lower training cost; MIMO (R=4) improves accuracy (~1.2% at 1.5B) at ~2× training time, with no decode latency overhead.
- **Biases**: Adding head‑specific channel‑wise biases to B and C improves perplexity at modest parameter cost (O(DN) per layer).
- **BC normalization**: Stabilizes training, allowing omission of post‑gate RMSNorm in pure Mamba; for hybrids, pre‑gate grouped RMSNorm aids length generalization.
- **Discretization**: Exponential‑trapezoidal requires learning λ_t; using Euler instead loses ~0.6% accuracy (Table 5a).
- **Complex state**: Effectively doubles state dimension in real representation; do not reduce state size proportionally when using complex transitions.

### Failure Signatures
- **State‑tracking failure** (parity <<100%): RoPE implementation incorrect; verify cumulative rotations and B/C transformation.
- **Training instability**: Likely missing BC normalization or biases; check RMSNorm placement.
- **High decode latency**: Kernel fusion suboptimal; profile to ensure memory‑bound regime; MIMO should not increase wall‑clock time, otherwise check rank R and chunk size.
- **Poor length extrapolation** (hybrid models): Incorrect RMSNorm placement; use pre‑gate grouped RMSNorm as recommended.

### First 3 Experiments
1. **Synthetic state‑tracking**: Train a one‑layer Mamba‑3 on parity task (length 256). Expect >99% accuracy; if lower, debug RoPE and complex SSM.
2. **Ablation on core components**: At 440M scale, compare exponential‑Euler vs trapezoidal and with/without biases. Trapezoidal+biases should yield lower perplexity (Table 5a).
3. **Throughput benchmark**: Implement decode kernels for SISO and MIMO (R=4) on H100. MIMO latency should match SISO (Table 6) while FLOPs increase ~4× and validation perplexity improves slightly.
