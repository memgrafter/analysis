# A Cortically Inspired Architecture for Modular Perceptual AI

## Quick Facts
- ArXiv ID: 2603.07295
- Source URL: https://arxiv.org/abs/2603.07295
- Reference count: 18
- Primary result: Modular decomposition improves within-domain feature stability by 15.4 percentage points (55.7% → 71.1%) while preserving reconstruction fidelity.

## Executive Summary
The paper introduces a cortically inspired modular architecture to address interpretability, compositional generalization, and robustness in monolithic AI models. It proposes three core principles: modular specialization, predictive feedback, and cross-modal integration. As a proof-of-concept, the authors train domain-specific sparse autoencoders (SAEs) on activations from Mistral-7B, using ground-truth semantic routing to isolate the effect of modular decomposition. Results show a substantial increase in feature stability within semantic domains (Jaccard overlap +15.4 pp) and comparable reconstruction fidelity, indicating that explicit semantic partitioning can yield more consistent and inspectable internal representations.

## Method Summary
The proof-of-concept isolates modular decomposition by routing inputs from four semantic domains to dedicated sparse autoencoders, each trained on activations from the Mistral-7B model. The routing is oracle-based, using ground-truth domain labels, which removes the complexity of learning a routing function. Each SAE learns an overcomplete sparse representation of its domain’s activations, with the total feature count across all modules matching that of a monolithic baseline (1024 features total, split as 4×256). The modular setup is compared against a monolithic SAE of equal capacity in terms of feature stability (within-domain Jaccard overlap), semantic clustering (feature-domain entropy), and reconstruction error (MSE).

## Key Results
- Within-domain feature stability improves by 15.4 percentage points (Jaccard overlap: 55.7% → 71.1%) in the modular setup relative to the monolithic baseline.
- Reconstruction fidelity remains comparable between modular (MSE 0.0031) and monolithic (MSE 0.0026) models.
- Semantic concentration (entropy) is lower in the modular model than a shuffled baseline, but this effect is confounded by capacity as the monolithic model with per-domain capacity matching shows even lower entropy.

## Why This Works (Mechanism)
The improvement in feature stability arises from the partitioning of the representational space: by gating activations into domain-specific SAEs, the system reduces interference between semantic domains, reinforcing domain-specific activation patterns and increasing feature consistency. This stability is a desirable proxy for interpretable and robust representations.

Modular decomposition also promotes semantic concentration: limited capacity per module forces features to align with the statistics of their assigned domain, reducing dispersion across unrelated domains. However, this effect is partially confounded by capacity allocation, as a monolithic model with equal per-domain capacity can achieve even lower entropy.

Finally, the modular approach preserves reconstruction fidelity because the SAE training objective (reconstruction + sparsity) ensures that partitioned representations can still recover the original activations adequately. The structural changes (more stable, domain-concentrated features) come without significant information loss.

## Architecture Onboarding
**Component map**: Input → Routing Controller → Peripheral Specialist Encoders → Shared Cross-Modal Latent Workspace → Higher-Level Reasoning Module → Hierarchical Predictive Feedback Loops → (loop back to Specialists) → Integrated Output.

**Critical path**: An input is first routed by the controller to the appropriate specialist encoder(s). Their outputs enter the shared workspace where cross-modal integration occurs. A higher-level module generates hypotheses and sends top-down predictions via predictive feedback loops, prompting specialists to re-evaluate their representations. This iterative cycle refines the final integrated output.

**Design tradeoffs**:
- *Modularity vs. Capacity*: More specialists with smaller capacity can improve specialization but risk information loss; a larger shared workspace preserves information but may cause entanglement.
- *Routing Complexity*: Rule-based routing is interpretable but brittle; learned routing (e.g., mixture-of-experts) is flexible but may become opaque.
- *Feedback Depth*: Additional recurrent cycles enhance disambiguation but increase latency and computation.

**Failure signatures**:
- *Routing Failure*: Misrouting inputs (e.g., vision prompt to language specialist) degrades reconstruction and task performance.
- *Feedback Collapse*: Overly strong top-down priors cause specialists to ignore bottom-up evidence, analogous to hallucinations.
- *Workspace Entanglement*: The shared space fails to maintain separable modalities, leading to cross-talk and loss of specialist advantages.

**First 3 experiments**:
1. **Replicate PoC with Learned Routing**: Replace oracle routing with a simple learned router (e.g., linear probe on input embeddings). Measure the drop in within-domain stability and reconstruction error compared to oracle to quantify routing overhead.
2. **Minimal Feedback Loop Test**: Implement a two-module system (e.g., vision specialist + language reasoner) with one top-down prediction round. Test on ambiguous stimuli (occluded images with textual hints) for improvement over a feedforward baseline.
3. **Failure Mode Stress Test**: Corrupt one specialist’s input (e.g., add noise to image encoder output) and measure if feedback from other specialists compensates to maintain output quality, compared to a monolithic model.

## Open Questions the Paper Calls Out
The paper does not explicitly list remaining open questions beyond suggesting future work on learned routing and feedback mechanisms.

## Limitations
- The entropy metric for semantic concentration is confounded by model capacity; a monolithic model with per-domain capacity matching achieved lower entropy than the modular one.
- The proof-of-concept relies on ground-truth routing, sidestepping the critical challenge of learning a robust, flexible routing function.
- The proposed principles of predictive feedback and cross-modal integration remain unevaluated beyond the isolated decomposition test.

## Confidence
- Feature stability gain: **High**
- Semantic clustering/specialization: **Low**
- Reconstruction fidelity preservation: **Medium**
- Architectural principles (feedback, integration): **Medium**

## Next Checks
1. **Capacity-Controlled Entropy Test**: Re-analyze entropy using a monolithic SAE with domain-specific regularization (e.g., auxiliary losses) while keeping total feature count constant, to isolate the effect of modular structure from capacity allocation.
2. **Learned Routing Stress Test**: Replace oracle routing with a simple learned router (e.g., linear probe on input embeddings). Quantify the degradation in within-domain Jaccard stability and reconstruction error relative to oracle routing.
3. **Cross-Domain Ambiguity Benchmark**: Build a minimal two-module system (visual + linguistic specialists) with one feedback cycle. Evaluate on ambiguous stimuli (e.g., image with contradictory caption) to measure if feedback improves disambiguation and robustness over a monolithic feedforward baseline.
