# FISformer: Replacing Self-Attention with a Fuzzy Inference System in Transformer Models for Time Series Forecasting

## Quick Facts
- **ArXiv ID**: 2603.21724  
- **Source URL**: https://arxiv.org/abs/2603.21724  
- **Reference count**: 40  
- **Primary result**: FISformer replaces self-attention with a learnable Sugeno fuzzy inference system, achieving superior accuracy (best in 37/40 MSE/MAE comparisons) on multivariate time series forecasting benchmarks.

## Executive Summary
FISformer introduces a novel token interaction mechanism for Transformers by replacing the deterministic dot-product attention with a learnable Sugeno-type Fuzzy Inference System (FIS). This approach models uncertainty and nonlinear dependencies in time series data through fuzzyfication of queries and keys, rule-based reasoning, and defuzzification. Extensive experiments on seven multivariate datasets show that FISformer consistently outperforms state-of-the-art Transformer variants, reducing error metrics and offering improved noise robustness and interpretability while maintaining linear computational complexity relative to sequence length. The success demonstrates that integrating fuzzy logic into deep attention architectures yields more robust and transparent models for time series forecasting, opening avenues for hybrid neuro‑fuzzy systems.

## Method Summary
FISformer is a Transformer encoder where the standard self‑attention module is replaced by a custom FIS Interaction layer. Given query, key, and value matrices of shape (N, d) (N tokens = variables, d model dimension), the FIS layer performs per‑feature fuzzy inference: each scalar query and key element is fuzzified using three learnable Gaussian membership functions, producing membership degrees. A product t‑norm combines corresponding query and key memberships to compute firing strengths for nine rules (all combinations). The firing strengths are normalized and used to weight input‑dependent consequent functions (linear combinations of the original query and key). Defuzzification aggregates these weighted consequents to produce an interaction score matrix *f*<sub>QK</sub> of shape (N, d). For each feature dimension *j*, a softmax over tokens (axis 0) converts *f*<sub>QK</sub>[:, *j*] into attention weights, which are then multiplied element‑wise with the value matrix to produce the output. The rest of the Transformer (layer norms, feed‑forward networks, residual connections) remains unchanged. Training uses Adam optimizer, L2 loss, batch size 32, 10 epochs, with hyperparameter search over depth *L* ∈ {2,3,4} and embedding dimension *D* ∈ {256,512}. The model employs variate‑wise tokenization (each variable is a token).

## Key Results
- Outperforms SOTA Transformer variants in 37 of 40 MSE/MAE comparisons across seven multivariate benchmarks.
- Significant error reductions: e.g., ETT (Avg) MSE 0.375 / MAE 0.395; PEMS (Avg) MSE 0.122 / MAE 0.219.
- Enhances noise robustness and model interpretability through its rule‑based fuzzy inference while maintaining comparable (linear) computational complexity.

## Why This Works (Mechanism)
### Mechanism 1: Fuzzy inference replaces dot‑product similarity
The FIS Interaction layer substitutes the rigid dot‑product with a differentiable fuzzy inference process that accounts for uncertainty and nonlinear relationships. Queries and keys are fuzzified using learnable Gaussian membership functions into degrees (e.g., low, medium, high). For each feature, a complete set of nine rules (from three membership functions per input) is formed; the firing strength of each rule is the product of the corresponding query and key memberships. These strengths are normalized and used to weight input‑dependent consequent functions (linear combinations of the original query and key). Defuzzification sums these weighted consequents to produce an interaction score. Softmax over tokens per feature converts scores to attention weights, which modulate the values. This pipeline allows the model to learn fuzzy partitions and rule parameters adaptively, providing a smoother, more expressive similarity measure than the dot‑product. Break condition: if membership parameters collapse (identical centers or extreme variances), the mechanism degenerates to a linear projection.

### Mechanism 2: Learnable fuzzy partitions and rules
The centers and widths of Gaussian membership functions (for both queries and keys) and the linear coefficients in each rule’s consequent are trained via gradient descent. This enables the model to automatically discover meaningful fuzzy sets (e.g., “low,” “medium,” “high” activation patterns) and data‑driven linear relationships between fuzzified inputs and interaction scores. The end‑to‑end differentiable fuzzy inference balances interpretability with representational flexibility. Break condition: poor initialization or optimization may cause membership saturation (all inputs map near 0 or 1), hindering gradient flow and rule diversity.

### Mechanism 3: Interpretability and robustness
The rule‑based structure yields transparent, linguistically meaningful interactions (e.g., “IF query is high AND key is medium THEN …”). Soft membership boundaries produce gradual output changes, reducing sensitivity to input noise. The normalized firing‑strength distribution across rules provides insight into which relational patterns dominate for a given token pair. This design improves trust and generalization on noisy real‑world series. Break condition: too many rules (>3) degrades interpretability; too few (<3) may underfit.

## Architecture Onboarding
**Component map**  
Input → Embedding → [FIS Interaction → LayerNorm → FFN] × *L* → Projection → Forecast

**Critical path**  
- *Data flow*: Raw multivariate series → tokenization → embedding → repeated FIS‑augmented Transformer blocks → linear projection → forecast.  
- *Parameter flow*: Embedding weights, all FIS parameters (membership centers/widths, rule consequent coefficients), layer‑norm parameters, FFN weights, projection weights are updated via backpropagation.  
- *Key substitution*: Only the `ScaledDotProductAttention` module is replaced by `FISInteraction`; all other components remain identical.

**Design tradeoffs**  
- *Membership count (R)*: More rules increase capacity but add parameters and risk overfitting/less interpretability; paper uses *R* = 3.  
- *MF type*: Gaussian offers smoothness but extra parameters; triangular/trapezoidal are simpler but may lose some nonlinearity.  
- *Tokenization compatibility*: FIS Interaction is agnostic to token count (variate‑wise or time‑wise); however, token count directly impacts complexity O(*N*·*D*·*R*).  
- *Complexity vs. expressivity*: Linear in token count but introduces *R*·*D* per token; efficient for high‑dimensional or long series but may limit cross‑feature interactions within the attention module.

**Failure signatures**  
- *Training instability*: Loss diverges/plateaus → likely due to poor MF initialization (centers too far, variances extreme).  
- *No learning signal*: All firing strengths near uniform → MF widths too large/small or consequent weights collapsed.  
- *Poor generalization*: High train, low test accuracy → too many rules or insufficient regularization.  
- *Interpretability loss*: Learned MFs do not form distinguishable sets → model may be ignoring fuzzy reasoning.

**First 3 experiments**  
1. Replace FIS Interaction with standard multi‑head self‑attention in the same architecture on a small dataset (e.g., ETTh1) to verify the reported baseline performance gap.  
2. Ablate rule count: train variants with *R* = 1,2,4 on a subset (e.g., ETT) and plot performance vs. *R* to confirm *R* = 3 is optimal.  
3. Visualize learned Gaussian MF parameters for representative features; plot membership curves and compute firing‑strength distributions on validation samples to check distinctness and rule activity.

## Open Questions the Paper Calls Out
- **Cross‑modal extension**: How can FISformer be adapted for forecasting tasks that combine multiple data modalities (e.g., text, images) with time series? The current architecture targets unimodal series and needs mechanisms to align fuzzy inference across heterogeneous feature spaces.
- **Graph‑based spatio‑temporal forecasting**: What architectural modifications are required to integrate FISformer with graph structures for domains like traffic or social networks? The token interaction currently lacks explicit spatial relational modeling.
- **Hybrid neuro‑fuzzy systems**: Can more sophisticated hybrid architectures further improve explainability and domain adaptability without sacrificing predictive performance? While FISformer introduces rule‑based interpretability, exploring deeper integrations of fuzzy logic and neural networks remains open.

## Limitations
- **Hyperparameter ambiguity**: The paper reports search spaces for depth *L* and dimension *D* but not final values per dataset, hindering exact replication and fair comparison.
- **Rule base incompleteness**: The exact rule structure (e.g., number of rules, consequent form) is not fully described; we assume a complete 9‑rule base from 3 Gaussian MFs per query/key, but this needs confirmation.
- **Complexity unverified**: The claim of linear scaling is theoretical; no empirical benchmarks against standard attention are provided, and per‑feature processing may restrict cross‑feature interactions.

## Confidence
- **Performance superiority**: *Medium* – strong tabular evidence but dependent on unspecified hyperparameters.
- **Mechanism validity**: *Medium* – theoretically sound, but lacking ablation isolating the FIS component’s contribution.
- **Interpretability**: *Low* – asserted based on rule‑based structure without quantitative evaluation of learned rule semantics or user studies.
- **Computational complexity**: *Medium* – linear scaling is plausible but not empirically verified.
