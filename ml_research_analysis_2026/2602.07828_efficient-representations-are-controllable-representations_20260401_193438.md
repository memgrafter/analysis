# Efficient Representations are Controllable Representations

## Quick Facts
- **arXiv ID:** 2602.07828
- **Source URL:** https://arxiv.org/abs/2602.07828
- **Reference count:** 5
- **Primary result:** A simple fine-tuning method installs 16 interpretable binary feature flags into a model's residual stream; overwriting these dimensions at inference causally steers output, with minimal impact on language modeling performance.

## Executive Summary
The paper addresses the challenge of installing interpretable, controllable features into a large language model's internal representations without requiring a full decode of its existing geometry. The core method involves fine-tuning with a lightweight auxiliary loss that trains 16 designated residual stream dimensions to act as binary flags for target concepts. These dimensions receive no architectural privilege. After a two-stage training process, the model learns to write correct flags and, crucially, comes to depend on them during generation. Overwriting these fenced dimensions at inference overrides input context and steers output. Linear probes confirm that feature information migrates into the fenced dimensions, with recoverability from the remaining dimensions dropping significantly. The language modeling cost is minimal, with perplexity increasing by only 0.12 on WikiText-2 when fencing 16 dimensions.

## Method Summary
The method fences a small set of contiguous residual stream dimensions (16 total) across all layers of a pretrained LLM (Phi-3-Mini). A two-stage curriculum is used. First, correct binary flag values are manually injected into the fenced dimensions during training, teaching the model to consume these signals. Second, manual injection stops, and an auxiliary position loss (mean squared error between actual and target binary values) is introduced. This loss trains the model to produce the flags itself. The combined loss (language modeling + position loss) is used to fine-tune all model parameters. The fenced dimensions are thus trained to reliably encode feature presence. Because the fenced signal is consistent and low-effort, the model, under efficiency pressure from the language modeling objective, gradually erodes redundant encodings of the same features elsewhere in the residual stream. This consolidation makes the fenced dimensions causally influential: overwriting them at inference steers generation.

## Key Results
- Fenced dimensions reliably activate for target concepts across layers after training.
- Overwriting fenced dimensions at inference causally steers model output, overriding explicit input context.
- Linear probe accuracy for fenced features drops by 4–18 percentage points when probing only non-fenced dimensions, indicating information migration.
- Perplexity penalty is small: +0.12 on WikiText-2 for 16 fenced dimensions.

## Why This Works (Mechanism)
### Mechanism 1: Auxiliary Loss Locks Flag Behavior
The position loss directly supervises the model to write correct binary classifications into the fenced dimensions during training. This forces the model to map input context to feature presence and express it in the designated locations. Evidence includes visualizations (Figure 2) showing sharp, layer-wise activation of fenced regions for associated features.

### Mechanism 2: Efficiency Pressure Induces Dependence
Once the fenced dimensions provide a reliable, low-cost signal, maintaining independent redundant representations elsewhere becomes computationally wasteful. Gradient descent, optimizing the language modeling loss over a finite residual stream, promotes the erosion of these redundant encodings to free capacity. This causes the model to depend on the fenced flags. Causal intervention experiments (overwriting fenced dims at inference) demonstrate this dependence, as forced flags steer output even against contrary input.

### Mechanism 3: Redundancy Erosion is Measurable via Probe Degradation
If feature information migrates into the fenced dimensions and is stripped from elsewhere, a linear probe restricted to non-fenced dimensions will show significantly lower accuracy compared to a probe on the full (pre-fencing) model. Table 1 confirms this drop (4–18 pp) for fenced features, while a control feature shows negligible change, supporting the consolidation hypothesis.

## Foundational Learning
- **Auxiliary Loss Curriculum**  
  *Why needed:* The two-stage schedule (manual injection → self-production) first builds dependence on a reliable signal, then transfers responsibility for producing that signal to the model. This separation simplifies learning.  
  *Quick check:* What would likely happen if the full position loss were applied from the start without the initial manual injection stage?

- **Residual Stream Geometry**  
  *Why needed:* The method installs flags in specific dimensions *within* the residual stream at *every* layer. Understanding that the residual stream is the concatenated hidden state across layers is essential to map where flags are written and read.  
  *Quick check:* Why install flags in both `hR_k` (post-attention) and `h_k` (post-MLP) at every layer?

- **Linear Probing for Representational Change**  
  *Why needed:* To measure erosion of alternative representations, a diagnostic is needed to compare feature information content across different activation subspaces before and after intervention.  
  *Quick check:* Why is the probe comparison in Table 1 deliberately "unfair" to the fenced model (probing fewer dimensions), and what does a significant drop imply?

## Architecture Onboarding
- **Component map:**  
  Pretrained Phi-3-Mini (3072d, 32 layers) -> Fence 16 contiguous dimensions (across all layers, in both hR_k and h_k) -> Two-stage fine-tuning (Stage 1: inject correct flags; Stage 2: add L_position) -> Erosion of non-fenced feature encodings -> Causal control via overwriting fenced dims at inference.

- **Critical path:**  
  1. Generate ~100M synthetic tokens with known binary feature labels (implicit engagement).  
  2. Stage 1: Manually inject correct flag values into fenced dims; train with L_CE only.  
  3. Stage 2: Remove injection; add L_position (MSE on fenced dims) with increasing weight λ_t; train all parameters.  
  4. Evaluate: (a) flag correctness on held data; (b) overwriting interventions; (c) train linear probes pre- and post-fencing.

- **Design tradeoffs:**  
  - **Fenced dimension count:** More dims improve signal but consume capacity, raising perplexity (e.g., 16 dims: +0.12 PPL; 128 dims: +1.18).  
  - **Binary vs. continuous flags:** Binary yields clear "switch" semantics but may be harder to learn; continuous values could ease optimization.  
  - **Feature selection:** Features must be distinct for clean probing but not so rare that the model seldom writes their flags.

- **Failure signatures:**  
  - **No flag convergence:** Fenced dims remain noisy/inactive after Stage 2; L_position does not drop.  
  - **No causal effect:** Overwriting fenced dims at inference fails to steer output; model never integrated flags.  
  - **No probe degradation:** Linear probe accuracy on non-fenced dimensions remains high for fenced features; model kept redundant encodings.

- **First 3 experiments:**  
  1. **Flag Training Verification:** Generate 100 random prompts with known labels. Record fenced-dim activations per layer. Compute accuracy: % of non-masked tokens where active fenced regions exceed threshold and inactive regions are near zero. Expect >90% from layer 5 onward.  
  2. **Overwriting Intervention Test:** For a neutral prompt (e.g., "Tell me a funny story"), clamp all fenced dims to (a) all-zero, (b) `dogs`+`animals` on, others off, (c) `programming`+`animals` on. Compare completions to baseline; forced features should dominate narrative content.  
  3. **Probe Erosion Measurement:** Train a logistic regression probe on layer-10 activations from 10k baseline tokens to predict each feature. Record accuracy. Repeat on fenced model, probing *only* the 3056 non-fenced dimensions. Expect significant drop (≥5 pp) for fenced features, minimal change for control feature.

## Open Questions the Paper Calls Out
- **What categories of features can be installed?** The paper tests only five concrete binary features (dogs, cats, animals, food, programming). It is unknown whether abstract, relational, continuous, or multi-faceted features can be reliably installed and still produce strong consolidation and steering.
- **What are the boundary conditions for consolidation?** The consolidation mechanism relies on "reliable supply at a fixed location," but the paper does not vary signal reliability, consistency, or layer coverage. The minimal frequency or fidelity of the fenced signal required to induce dependence is unknown.
- **Is the two-stage curriculum necessary?** The method uses a curriculum but includes no ablation comparing it to single-stage alternatives. It is unclear whether both stages are essential or if a simpler training regime could achieve comparable results.
- **How does cost scale?** Table 2 shows perplexity increasing with more fenced dimensions on a 3.8B model. The scaling law with model size, architecture, and proportion of residual stream is unresolved.

## Limitations
- Critical hyperparameters (λ_t schedule, Stage 1/2 durations, exact ¯hk values, dimension allocation) are unspecified, blocking exact replication.
- Consolidation is inferred from linear probe degradation; nonlinear feature remnants could persist undetected.
- Generalization to abstract, rare, or complex feature types is untested; synthetic data generation details for ensuring *implicit* feature engagement are underspecified.
- Fencing consumes a fixed portion of the residual stream; scalability to many features is unclear given rising perplexity.

## Confidence
- **Flag learning:** High (direct visualizations and loss curves show reliable activation).
- **Causal steering:** High (overwriting interventions produce coherent, feature-driven outputs even against input).
- **Consolidation:** Medium (probe drops are significant but rely on linear probe assumption; nonlinear remnants possible).
- **Perplexity cost:** High (direct metric across varying fenced-dimension counts).

## Next Checks
1. **Hyperparameter sensitivity analysis:** Systematically vary λ_t ramp and Stage 1/2 proportions to map the minimal regime for successful consolidation; report thresholds for flag correctness and probe erosion.
2. **Nonlinear probe complement:** Train a shallow MLP probe on non-fenced dimensions; if accuracy remains high despite linear probe failure, consolidation may be incomplete.
3. **Cross-feature generalization test:** Apply the method to a new feature set (e.g., abstract “irony”, domain-specific jargon) and re-evaluate steering coherence and probe degradation to assess broad applicability.
