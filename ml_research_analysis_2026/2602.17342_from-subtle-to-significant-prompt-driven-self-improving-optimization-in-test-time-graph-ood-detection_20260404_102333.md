# From Subtle to Significant: Prompt-Driven Self-Improving Optimization in Test-Time Graph OOD Detection

## Quick Facts
- **arXiv ID:** 2602.17342  
- **Source URL:** https://arxiv.org/abs/2602.17342  
- **Reference count:** 25  
- **Primary result:** SIGOOD achieves up to **14.20% AUC improvement** on OOD detection and the **best average rank (1.2)** on anomaly detection across 21 benchmark datasets, outperforming 12 state-of-the-art methods.

## Executive Summary
SIGOOD tackles test‑time graph out‑of‑distribution (OOD) detection without access to training data. It introduces an optimizable prompt that perturbs node embeddings of a test graph, creating a *prompt‑enhanced* version. Energy (a measure of model confidence) is computed for both the original and perturbed graphs; the *variation* of energy per node separates potential OOD nodes (energy increases) from ID nodes (energy decreases). An *Energy Preference Optimization* (EPO) loss, inspired by the Bradley‑Terry model and regularized by KL divergence, iteratively refines the prompt generator to amplify this gap in a self‑improving loop. After convergence, the final EPO loss value serves as the OOD score. Extensive evaluation on 21 benchmarks demonstrates consistent and significant gains over prior art.

## Method Summary
Given a frozen, pre‑trained GNN and a lightweight scoring head, SIGOOD processes a single test graph in an iterative loop. First, a three‑layer MLP *prompt generator* creates node‑level perturbations from current embeddings. These are added element‑wise to the node features, forming a new graph. Energies (negative log‑sum‑exp of the scoring head’s two‑dimensional logits) are computed for both the current and perturbed graphs. For each node, the logarithmic difference *ΔE* is calculated; nodes with ΔE > 0 are hypothesized as OOD, those with ΔE < 0 as ID. The EPO loss encourages the average ΔE of OOD nodes to exceed that of ID nodes by a margin controlled by β, while a KL term keeps the perturbed graph close to the current one. Only the prompt generator is updated; after each step the perturbed graph replaces the current graph. The loop terminates after a fixed number of iterations or when the loss stabilizes. Finally, the optimized prompt is applied to the original graph, and the resulting EPO loss is used as the OOD detection score.

## Key Results
- Average AUC improvement up to **14.20%** on OOD detection compared to 12 SOTA methods.  
- Best average rank (**1.2**) on anomaly detection tasks.  
- Ablation studies confirm the necessity of both the EPO loss and the prompt generator; a three‑layer MLP and moderate β yield optimal performance.

## Why This Works (Mechanism)
### Mechanism 1: Prompt Injection Amplifies Subtle OOD Signals
The prompt generator produces additive perturbations to node embeddings. Because the pre‑trained GNN has a strong inductive bias toward ID patterns, foreign perturbations disrupt OOD node representations more severely, leading to a larger increase in energy. This exaggeration makes subtle OOD patterns more distinguishable in energy space. **[break condition]** The amplification fails if prompts are too weak (no separation) or too strong (causing saturation/collapse of GNN outputs).

### Mechanism 2: Energy Variation Discriminates OOD/ID Nodes
Node‑wise energy scores for the original and perturbed graphs are computed. The logarithmic ratio ΔE serves as a directional indicator: OOD nodes are expected to show a positive ΔE (energy increases under perturbation), while ID nodes show a negative ΔE (energy stable or decreases). This provides an unsupervised local signal. **[break condition]** Significant overlap in ΔE distributions between true OOD/ID nodes would make the directional signal noisy, corrupting the feedback loop.

### Mechanism 3: EPO Loss Drives Self‑Improving Refinement
The EPO loss combines a Bradley‑Terry pairwise preference model (favoring OOD nodes) with a KL divergence regularization term. The reward (β · (avgₒₒ𝑑 ΔE − avgᵢ𝑑 ΔE)) is maximized via gradient updates to the prompt generator. By repeatedly replacing the current graph with the perturbed version, the loop iteratively amplifies the energy gap between OOD and ID nodes, enhancing separability. **[break condition]** The optimization may converge to a local optimum where ΔE values collapse or overfit noise, harming detection.

## Architecture Onboarding
**Component map** (plain text flow):  
Pre‑trained GNN Encoder → Prompt Generator → Prompt Injection Module → Energy Scorer → EPO Loss Calculator → Iteration Controller → Final Scorer.  
*(After each update the perturbed graph becomes the next input, forming a loop.)*

**Critical path**  
1. Test graph → GNN → node embeddings.  
2. Prompt generator creates perturbation → added to features → prompt‑enhanced graph.  
3. Energy scores for both graphs → ΔE per node.  
4. Nodes with ΔE > 0 labeled OOD, ΔE < 0 labeled ID.  
5. Compute EPO loss from average ΔE gap.  
6. Back‑propagate loss to prompt generator, update parameters.  
7. Replace current graph with perturbed version.  
8. Repeat 1‑7 for T iterations or until convergence.  
9. After loop, compute final EPO loss on original vs. final perturbed graph; use this score for detection.

**Design tradeoffs**  
- *Prompt generator capacity*: Deeper MLPs capture non‑linearities better but increase test‑time cost and risk overfitting noise.  
- *β parameter*: Balances preference strength and KL regularization; too high risks distortion, too low yields subtle refinement.  
- *Iteration count*: More iterations allow finer signal amplification but cost more compute; early stopping needed.

**Failure signatures**  
- EPO loss diverges or fails to decrease (unstable optimization).  
- Mean energy of hypothesized ID nodes starts rising in later iterations (ID destabilization).  
- Histogram of ΔE values shows no clear separation (pseudo‑labeling random).

**First 3 experiments**  
1. **Synthetic OOD sanity check:** Inject a known anomalous node (e.g., random feature perturbation) and verify that its ΔE becomes strongly positive after a few iterations.  
2. **Ablation study:** Remove either the EPO loss or the prompt generator on a dataset pair (e.g., BZR/COX2); expect significant AUC drop, confirming their necessity.  
3. **β sensitivity sweep:** On ENZYMES, vary β (e.g., 1, 10, 50, 80, 100, 200) and plot AUC vs. β; expect a peak at moderate values, reproducing Fig. 4b.

## Open Questions the Paper Calls Out
1. **How does GNN quality affect SIGOOD?** The method assumes a strong ID inductive bias, but sensitivity to sub‑optimal GNNs is unexplored.  
2. **Convergence guarantees for EPO?** The Bradley‑Terry model and iterative loop lack theoretical analysis; local optima or divergence are possible.  
3. **Optimal prompt generator architecture?** Only MLP depth is tested; GNN‑ or attention‑based generators might better capture graph structure.  
4. **Node‑level heterogeneity?** All nodes are treated equally in ΔE; weighting nodes by importance (e.g., centrality) could improve detection.  
5. **Threshold selection without validation?** The paper uses a fixed threshold τ; unsupervised adaptive thresholding for test‑time streams remains open.

## Limitations
- **Scoring head and final score ambiguity:** It is unclear whether the scoring head is frozen or trainable during test time, and whether the final OOD score is the raw EPO loss, its argument S, or the energy of the final PE graph.  
- **Hyperparameter sensitivity:** Optimal values for β, iteration count T, and MLP hidden size are dataset‑dependent and not theoretically derived.  
- **Lack of convergence analysis:** No formal guarantees that the self‑improving loop will converge to a good separator; risk of collapse or overfitting to noise.
