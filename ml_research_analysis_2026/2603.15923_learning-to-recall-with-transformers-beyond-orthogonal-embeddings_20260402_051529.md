# Learning to Recall with Transformers Beyond Orthogonal Embeddings

## Quick Facts
- arXiv ID: 2603.15923
- Source URL: https://arxiv.org/abs/2603.15923
- Reference count: 40
- Primary result: The paper provides a precise characterization of how sample size, embedding dimension, sequence length, and model width jointly constrain the learnability of factual recall in transformers with non-orthogonal embeddings, revealing fundamental multiplicative trade-offs.

## Executive Summary
The paper investigates how transformers learn factual recall under realistic conditions: random (non-orthogonal) embeddings and finite data. Moving beyond idealized orthogonal settings, the authors analyze a single-layer transformer with an attention+MLP block trained via early-phase gradient descent on a synthetic recall task. They derive explicit scaling relations showing that successful learning requires the signal-to-noise ratio to satisfy conditions where signal scales as 1/(V L²) and noise terms decay as 1/(N d), 1/(N d L), and 1/(N d √m). This yields multiplicative dependencies among N, d, L, and m. Key findings include capacity-optimal storage (md ∼ V) for short sequences, but for longer sequences, a trade-off emerges: either increase d (reducing capacity efficiency) or increase N (worsening sample complexity). Numerical experiments confirm the scaling, and a statistical lower bound suggests the multiplicative dependence is inherent for gradient-based estimators.

## Method Summary
The study uses a synthetic factual recall task where a transformer must identify a single informative token in a sequence of length L and map it to a label via a one-to-one permutation. The model is a single-layer transformer with an attention block followed by either a linear output (attention-only) or a two-layer MLP (attention-MLP). Embeddings are random Gaussian (non-orthogonal). Training proceeds via a three-step gradient descent procedure: first updating the query-key matrix W_KQ with a large step size to align with a trigger vector, then updating the value matrix V with a small step, and finally updating the output embedding matrix. This early-phase analysis allows deriving closed-form expressions for the attention scores and the signal and noise terms that govern whether the informative token is correctly selected.

## Key Results
- The learning condition requires the signal term (∝ 1/(V L²)) to dominate three noise terms: gradient noise (∝ 1/(N d)), mean bias (∝ 1/(N d L^{4/3})), and MLP noise (∝ 1/(N d √m) for attention-MLP).
- For attention-only models, capacity-optimal storage (d² ∼ V) is achievable only when L is small; for larger L, d must scale as V^{1/3} L^{4/3} / N^{2/3}, implying a trade-off between d and N.
- For attention-MLP models, capacity-optimal storage becomes md ∼ V, but an additional MLP noise term introduces a trade-off: increasing m reduces MLP noise but may require larger d to control other noise sources.
- A statistical lower bound shows that any estimator using only gradient information from initialization suffers the same multiplicative dependence, suggesting the result is inherent to the problem.

## Why This Works (Mechanism)
**Mechanism 1**: The attention mechanism learns to select the informative token if the signal term (∝ 1/(V L²)) dominates noise from non-informative tokens, which depend on N, d, L. During early gradient descent, W_KQ aligns with the trigger vector. The condition couples N, d, L multiplicatively. Break condition: if L > √(N d) (attention-only), attention fails.

**Mechanism 2**: MLP width m can compensate for smaller d but introduces MLP noise ∝ 1/(N d √m). Capacity condition becomes md ≥ V instead of d² ≥ V. However, if m is too small (or d too small), MLP noise dominates even if md ≥ V. Trade-off: larger m reduces MLP noise but may require larger d for other noise terms.

**Mechanism 3**: The problem exhibits a fundamental multiplicative trade-off among N, d, L, m. Derived inequalities (e.g., d² ≥ V and d ≥ V^{1/3} L^{4/3}/N^{2/3}) show that increasing one parameter can compensate for others but not without cost. This trade-off is intrinsic, as confirmed by a lower bound for gradient-based estimators.

## Foundational Learning
- **Token Embedding Superposition**: Random Gaussian embeddings allow token vectors to overlap, enabling capacity-optimal storage (md ∼ V) but causing interference that increases noise. *Why needed*: The paper's setting uses non-orthogonal embeddings to study realistic capacity-noise trade-offs. *Quick check*: Why are strictly orthogonal embeddings not capacity-optimal for factual recall?
- **Early-Phase Gradient Dynamics**: Focusing on the first few gradient steps simplifies analysis of non-orthogonal embeddings and yields closed-form noise terms. *Why needed*: To isolate the learning mechanism before chaotic later dynamics. *Quick check*: How does a three-step gradient descent procedure help isolate the “learning” of the recall mechanism compared to full training?
- **Associative Memory Capacity**: The task maps tokens to labels like an associative memory. Capacity scales as O(md) for a linear model with input dim d and output m. *Why needed*: To derive conditions like md ≥ V for storing V token-label pairs. *Quick check*: For a linear model with input dimension d and output m, why does the number of random patterns it can store scale as O(md) rather than O(d + m)?

## Architecture Onboarding
- **Component map**: Input Tokens (sequence of one-hot vectors) -> Embedding Layer (random Gaussian Z_in) -> Attention Mechanism (scores via W_KQ, softmax weighting) -> [Attention-Only: Linear output (Z_out) -> softmax | Attention-MLP: MLP (fixed random W_in, polynomial ϕ, trainable V) -> Linear output (Z_out) -> softmax].
- **Critical path**: The core pipeline is: token embedding → attention score computation → weighted sum of token embeddings → (for MLP: nonlinear transformation via W_in and V) → unembedding → classification. The key is that the attention must assign high weight to the position of the informative token, which is triggered by a dedicated vector z_trig.
- **Design tradeoffs**:
  1. **d vs. m**: Smaller embedding dimension d increases superposition (better capacity) but reduces orthogonality, increasing gradient noise. Adding MLP width m compensates capacity (md ∼ V) but introduces MLP noise ∝ 1/(N d √m).
  2. **d vs. N vs. L**: Larger d reduces gradient noise and mean bias; larger N also reduces them. Longer sequence length L increases mean bias (∝ L^{4/3}) and gradient noise (∝ L), forcing larger d or N.
  3. **Capacity vs. noise**: Optimal storage md ∼ V is achievable for short L with moderate N, d, m. For long L, either d must increase beyond the capacity-optimal point (wasting capacity) or N must increase (worse sample complexity).
- **Failure signatures**:
  - Attention failure: Attention weight on informative token not significantly larger than on noise tokens; accuracy ≈ 1/V.
  - MLP noise regime: Even with correct attention, random MLP weights cause variance in predictions; accuracy plateaus below 1.
  - Mean bias regime: Non-zero mean of token embeddings creates a bias term that grows with L; problematic when d is too small.
  - Insufficient capacity: md < V; model cannot memorize all token-label pairs.
- **First 3 experiments**:
  1. Vary V and d with short L (L ≈ √V), N ≈ V log V, m adjusted. Expect log-log slope of d vs. V ≈ 0.5 (confirming d² ∼ V).
  2. Vary N with long L (L ∼ V), fixed small d (e.g., d ≈ V^{0.3}), m adjusted so md ≈ V. Accuracy should improve as N increases, showing N compensates for long L.
  3. Vary L with fixed V, N, d, m. Observe sharp accuracy drop when L exceeds a threshold determined by the dominant noise term (likely mean bias), confirming multiplicative dependence on L.

## Limitations
- Analysis is restricted to a single-layer transformer and early-phase (three-step) gradient descent; full training dynamics and deeper architectures are not covered.
- The synthetic task (single informative token, permutation mapping) oversimplifies real-world factual recall in natural language.
- Results assume random Gaussian embeddings; learned embeddings may exhibit different scaling behavior.

## Confidence
- Derived scaling inequalities under model assumptions: High
- Claim that multiplicative dependence is inherent for gradient-based estimators: Medium
- Implications for long contexts and parameter efficiency: Medium
