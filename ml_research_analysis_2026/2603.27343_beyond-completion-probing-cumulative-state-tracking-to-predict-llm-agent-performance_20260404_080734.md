# Beyond Completion: Probing Cumulative State Tracking to Predict LLM Agent Performance
## Quick Facts
- **arXiv ID:** 2603.27343  
- **Source URL:** https://arxiv.org/abs/2603.27343  
- **Reference count:** 31  
- **Primary result:** WMF-AM predicts agent performance with Kendall’s τ = 0.612 (p < 0.001, 95% CI [0.360, 0.814]).

## Executive Summary
The paper identifies the “Completion Fallacy”—where identical final task success rates mask differences in intermediate state tracking—and introduces the Working Memory Fidelity–Arithmetic Metric (WMF-AM), a no‑scratchpad probe that measures cumulative arithmetic state tracking under load. By requiring models to report a final sum after K sequential updates, WMF-AM exposes a fidelity bottleneck in maintaining latent state. Evaluated across 20 open-weight models (0.5B–35B) and a deterministic 10‑task agent battery, WMF-AM shows strong predictive validity, incremental explanatory power over completion scores, and specificity to cumulative tracking via rigorous ablations.

## Method Summary
WMF-AM presents a model with an initial numeric value followed by K add/subtract operations, then asks for the final number without any scratchpad. Depth K is calibrated (3, 5, 7) to ensure discriminative accuracy gradients across model scales; the probe uses three surface forms (points, warehouse inventory, bank accounts). Control ablations include K=1 (single‑step), yoked cancellation (operations cancel to require no net change), and a non‑arithmetic ceiling (direct assignment of non‑numeric states). Mean exact‑match accuracy across seeds and surfaces yields the WMF‑AM score. Agent performance is measured by a deterministic 10‑task battery. Predictive validity is quantified by Kendall’s τ between WMF‑AM scores and agent scores, with partial τ analyses testing incremental contributions beyond task completion rates and model size.

## Key Results
- WMF-AM strongly predicts agent performance: Kendall’s τ = 0.612, p < 0.001, 95% CI [0.360, 0.814].
- The signal is incremental: partial τ remains significant after controlling for completion scores and parameter count, demonstrating orthogonal variance.
- Construct isolation confirms the bottleneck: yoked cancellation shows negligible correlation (τ ≈ –0.031), non‑arithmetic ceiling reaches ~0.98 accuracy, and K=1 accuracy is high (~0.957), indicating that cumulative tracking under load—not arithmetic parsing or generic entity tracking—drives the results.

## Why This Works (Mechanism)
### Mechanism 1
**Claim:** WMF-AM predicts agent performance because it measures a load‑sensitive fidelity bottleneck in maintaining and transforming a numeric state across sequential updates, which is required for reliable multi‑step agent behavior.  
**Mechanism:** The probe imposes a cognitively inspired working‑memory span paradigm. As depth K increases, demand on an internal state maintenance mechanism rises; models with higher “Working Memory Fidelity” sustain accuracy, while others degrade sharply. The depth‑accuracy interaction pattern is the diagnostic signal.  
**Core assumption:** The no‑scratchpad regime forces reliance on a latent state maintenance process analogous to (but not identical to) human working memory. Performance collapse at moderate K reflects failure of this process, not arithmetic or parsing deficits.  
**Evidence anchors:** The probe’s core manipulation (cumulative tracking under load), K‑calibration maintaining discriminative accuracy, and ablations isolating cumulative tracking.  
**Break condition:** If the depth‑accuracy curve is flat (no degradation with K), the signal vanishes; K‑calibration is critical to avoid universal floor/ceiling effects.

### Mechanism 2
**Claim:** The predictive signal is incremental to task completion metrics because completion scores compress variance in process quality (“Completion Fallacy”).  
**Mechanism:** Outcome‑based batteries reward correct final answers regardless of process. WMF‑AM exposes variance in intermediate state fidelity by controlling for outcome difficulty and stripping external aids (no scratchpad). This variance (spread Δ=0.933) is largely orthogonal to completion spreads (Δ=0.480).  
**Core assumption:** Multi‑step agent tasks similarly tax a latent state maintenance process; hence a load‑sensitive probe’s score correlates with downstream agent success even when completion scores are similar.  
**Evidence anchors:** Tens of model pairs with near‑identical completion scores show substantial WMF‑AM differences; partial τ analyses confirm incremental prediction.  
**Break condition:** The incremental prediction would collapse if all models’ WMF‑AM scores were perfectly predicted by their completion scores (τ(WMF‑AM, OC) → 1). Empirically, τ=0.279 (p=0.150) shows independence.

### Mechanism 3
**Claim:** The signal is specific to cumulative arithmetic state tracking under load, not generic entity tracking, arithmetic parsing, or instruction following.  
**Mechanism:** Yoked cancellation uses identical arithmetic operations arranged to cancel, demanding parsing but no cumulative state change; its near‑zero correlation with agent performance rules out arithmetic parsing. The non‑arithmetic ceiling (direct assignment) shows near‑perfect accuracy, ruling out generic entity tracking or instruction‑following as primary bottlenecks.  
**Core assumption:** The only meaningful difference between WMF‑AM and its ablations is the requirement for cumulative state maintenance; therefore, the predictive validity of WMF‑AM is attributable to that specific demand.  
**Evidence anchors:** Yoked cancellation τ ≈ –0.031; non‑arithmetic ceiling raises accuracy to mean 0.98 vs. arithmetic range 0.20–0.72; K=1 ceiling ~0.957 yet K=7 mean ~0.151.  
**Break condition:** If yoked control showed significant positive τ, the mechanism would default to arithmetic parsing; if non‑arithmetic ceiling showed comparable degradation, the mechanism would default to generic tracking/instruction‑following.

## Foundational Learning
- **Cognitive Load Theory**  
  *Why needed:* WMF‑AM manipulates load (K) to reveal capacity limits; performance degradation under increasing load indicates a limited buffer, not lack of knowledge.  
  *Quick check:* Why would a model that solves a single arithmetic step (K=1) fail at K=7 if it only lacked arithmetic skill? What does the K=1 ceiling imply?  
  *(Answer: Degradation reflects a limited working‑memory fidelity, not arithmetic ability; K=1 ceiling shows the model possesses the requisite arithmetic knowledge.)*

- **Multiple Realizability & Process‑Outcome Dissociation**  
  *Why needed:* The paper’s thesis is that identical outcomes (completion) can arise from categorically different processes; this undermines outcome‑only evaluation and motivates process‑sensitive probes.  
  *Quick check:* Give an example of how two models could achieve the same final answer on a multi‑step task but use fundamentally different internal strategies. Why would a process‑sensitive probe distinguish them?  
  *(Answer: One model might maintain a running sum; another might recompute from the initial state at each step. Under increasing K, the recomputation strategy fails due to exponential cost, while the running‑sum strategy succeeds if fidelity is high.)*

- **Rank‑Correlation & Partial Correlation**  
  *Why needed:* The paper relies on Kendall’s τ to quantify rank predictability and partial τ to test incremental validity (controlling for completion/scale). Misinterpreting these could lead to overclaiming.  
  *Quick check:* What does a significant partial τ(WMF‑AM, Agent | OC) tell you that a simple τ(WMF‑AM, Agent) does not? Why is τ used instead of Pearson’s ρ?  
  *(Answer: Partial τ shows that WMF‑AM predicts agent performance beyond what can be explained by task completion scores alone. Kendall’s τ is robust to non‑linear relationships and small samples, making it suitable for ordinal predictions.)*

## Architecture Onboarding
- **Component map:** Probe Core -> Ablation Controls -> Calibration Layer -> Validation Layer
- **Critical path:**  
  1. Define construct: operationalize “cumulative state tracking under load” as a K‑calibrated no‑scratchpad arithmetic update task.  
  2. Build probe & controls: implement WMF‑AM and three ablations with identical parsing demands.  
  3. Discriminability check: run a K‑sweep to ensure accuracy spread >0.5 and monotonic degradation; if all models floor/ceiling, adjust K.  
  4. Construct isolation: verify yoked control τ ≈ 0, non‑arithmetic ceiling >> WMF‑AM, K=1 ceiling.  
  5. Predictive validation: test pre‑specified τ(WMF‑AM, Agent) and then partial τ controlling for completion/scale.
- **Design tradeoffs:**  
  - *No‑scratchpad vs. CoT:* No‑scratchpad reveals the fidelity bottleneck; CoT bypasses it (ceiling) but may be more ecologically valid.  
  - *Template sensitivity:* Bare (direct) vs. chat (natural) prompts; chat adds instruction‑following noise but maintains τ > 0.5.  
  - *Depth K:* Too shallow → no degradation; too deep → universal floor; must be calibrated per model scale distribution.
- **Failure signatures:**  
  - All models score 0.0 or 1.0 on WMF‑AM → K mis‑calibrated.  
  - Yoked control shows similar τ to WMF‑AM → signal is arithmetic parsing, not cumulative tracking.  
  - Non‑arithmetic ceiling shows comparable degradation → bottleneck is generic tracking/instruction‑following.  
  - τ(WMF‑AM, Agent) not significant after Bonferroni correction → construct lacks predictive validity.  
  - Template instability: τ(bare, chat) < 0.4 → probe too sensitive to phrasing.
- **First 3 experiments:**  
  1. **K‑Sweep Pilot:** Test K ∈ {1,3,5,7,10,20} on 5 diverse models to find a discriminative window (accuracy spread >0.5, monotonic degradation).  
  2. **Yoked Cancellation Control:** Run yoked version at the same K values; confirm τ(yoked, agent) ≈ 0 and yoked accuracy >> WMF‑AM accuracy at high K.  
  3. **Template Stability:** Administer WMF‑AM under bare and chat wrappers (same K) to 10 models; compute τ between bare and chat rankings; target τ ≥ 0.5.

## Limitations
- Probe and agent battery details are incompletely disclosed; faithful reproduction requires an external repository and risks implementation drift.
- Evaluation is limited to open‑weight models (0.5B–35B); generalizability to larger or proprietary models is uncertain.
- The small model sample (20) and narrow deterministic task set (10 tasks) may restrict statistical robustness and scope of conclusions.

## Confidence
- Predictive validity (τ=0.612, p<0.001): **High**  
- Incremental validity (partial τ): **Medium**  
- Construct specificity (ablations): **High**  
- K‑calibration discriminative power: **Medium**

## Next Checks
1. Replicate on closed‑weight models (e.g., GPT‑4, Claude 3) to test external validity and re‑calibrate K for larger capacities.
2. Correlate WMF‑AM scores with independent agent benchmarks (AgentBench, WebArena) to confirm cross‑dataset predictive robustness.
3. Develop a non‑arithmetic cumulative tracking probe (e.g., symbolic string concatenation) to examine whether the bottleneck generalizes beyond numeric state maintenance.
