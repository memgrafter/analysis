# Set-Valued Prediction for Large Language Models with Feasibility-Aware Coverage Guarantees
## Quick Facts
- arXiv ID: 2603.22966
- Source URL: https://arxiv.org/abs/2603.22966
- Reference count: 40
- Primary result: Achieves empirical coverage ≥1-α for feasible risk levels α≥MRL across six NLG tasks with five LLMs.

## Executive Summary
Large language models (LLMs) often produce multiple valid outputs for a given input, but standard point prediction fails to capture this diversity and coverage guarantees become unreliable due to finite sampling artifacts. This paper proposes a set-valued prediction framework that ensures coverage guarantees in discrete output spaces by introducing a feasibility-aware calibration step. The method derives a Minimum Achievable Risk Level (MRL) from a held-out calibration set, representing the smallest risk that can be reliably attained. Then, using a Learn-Then-Test (LTT) calibration procedure combined with a multi-view reliability score—self-uncertainty, cross-sample consistency, and semantic consensus—it thresholds candidate sets to achieve the desired coverage. Experiments on six natural language generation tasks across five LLMs show that when the target risk α is at least the MRL, the resulting sets achieve the nominal coverage (at least 1-α). The approach also yields efficient prediction sets, with average size decreasing as α increases, and semantic deduplication further improves efficiency without coverage loss. The method proves robust to smaller calibration splits, though external validity and assumptions about calibration representativeness remain open concerns.

## Method Summary
The pipeline begins by estimating the Minimum Achievable Risk Level (MRL) from a calibration set: for a range of risk levels α, the smallest α is identified such that there exists a selection rule achieving risk ≤ α with high probability. This MRL defines the boundary of feasible coverage guarantees. For a new input, the LLM samples multiple outputs; each candidate set is evaluated by a multi-view reliability score that aggregates self-uncertainty (model confidence), cross-sample consistency (agreement among samples), and semantic consensus (embedding similarity). A Learn-Then-Test (LTT) procedure then uses the calibration data to learn a threshold on this score that controls the false discovery rate, ensuring that the selected prediction sets satisfy the coverage guarantee 1-α for any α ≥ MRL. Optionally, semantic deduplication reduces redundancy within sets. The entire approach is distribution-free and adapts to the LLM and task through the calibration set.

## Key Results
- Empirical coverage meets or exceeds the target 1-α for all α ≥ MRL across all six NLG tasks and five LLMs.
- Average prediction set size decreases with higher α, demonstrating a coverage-efficiency trade-off; semantic deduplication further reduces size without coverage loss.
- The method remains robust even when the calibration set is split into smaller subsets, indicating resilience to limited calibration data.

## Why This Works (Mechanism)
The MRL defines the lowest risk level that can be feasibly achieved given the calibration distribution, ensuring that any α above this value admits a valid selection rule. The Learn-Then-Test calibration leverages the multi-view reliability score to rank candidate sets and selects a threshold that controls the false discovery rate, thereby guaranteeing that the chosen sets satisfy the nominal coverage. Multi-view scoring captures complementary aspects of set quality: self-uncertainty reflects model confidence, cross-sample consistency indicates stability across samples, and semantic consensus measures output diversity. Together they enable efficient (smaller) sets while maintaining coverage, and the distribution-free nature of conformal principles ensures the guarantees hold without model assumptions.

## Foundational Learning
- **Conformal Prediction**  
  *Why needed*: Provides distribution-free guarantees for prediction sets.  
  *Quick check*: On a calibration set, does the empirical coverage of constructed sets match the nominal level?

- **Coverage Guarantee**  
  *Why needed*: Core property the method aims to achieve.  
  *Quick check*: Compute fraction of test points whose true output lies in the predicted set; should be ≥ 1-α.

- **Set-Valued Prediction**  
  *Why needed*: Captures ambiguity in generative tasks and enables coverage.  
  *Quick check*: For a given input, verify that at least one candidate answer matches a reference.

- **Minimum Achievable Risk Level (MRL)**  
  *Why needed*: Determines the lowest risk at which a coverage guarantee can be provided.  
  *Quick check*: Estimate MRL by checking the smallest α where the empirical risk on calibration samples is ≤ α with high probability.

- **Learn-Then-Test (LTT)**  
  *Why needed*: Enables selecting a reliability threshold while controlling the false discovery rate.  
  *Quick check*: After threshold selection, verify that the number of calibration points with risk > α does not exceed the allowed budget.

- **Multi-View Reliability Scoring**  
  *Why needed*: Improves set quality, leading to smaller sizes while maintaining coverage.  
  *Quick check*: Compare correlation between each view (self-uncertainty, consistency, semantic consensus) and eventual correctness; higher correlation indicates usefulness.

## Architecture Onboarding
**Component Map**  
Calibration Set -> MRL Derivation -> Candidate Sampling -> Multi-view Scoring -> Learn-Then-Test Thresholding -> Final Prediction Set

**Critical Path**  
1. Compute MRL from calibration data.  
2. For each test input, sample candidate outputs.  
3. Score each candidate set via multi-view reliability.  
4. Apply LTT-derived threshold to select a set.  
5. (Optional) apply semantic deduplication.  
The MRL must be established before thresholding; the reliability score directly determines which sets are selected.

**Design Tradeoffs**  
- Coverage vs. Efficiency: Higher coverage (lower α) yields larger sets; MRL restricts the lowest α with a guarantee.  
- Scoring Complexity: Adding more views improves set quality but increases computational cost.  
- Calibration Size: Larger sets yield more accurate MRL and thresholds but reduce data for training/testing.

**Failure Signatures**  
- Coverage below 1-α for α ≥ MRL → MRL misestimation or poor reliability ranking.  
- Excessively large sets → overly conservative threshold or ineffective deduplication.  
- High variance in set sizes → unstable multi-view scoring or insufficient calibration diversity.

**First Experiments**  
1. Estimate MRL on calibration data and verify on held-out test set that for α just above MRL, empirical coverage meets the target.  
2. Compare prediction set sizes with and without semantic deduplication, while checking that coverage remains unaffected.  
3. Ablate each multi-view component (remove self-uncertainty, cross-sample consistency, or semantic consensus) and measure changes in coverage and average set size.

None.

## Limitations
- External validity unknown: Results from 6 NLG tasks & 5 LLMs may not generalize to other domains/models (e.g., code generation, multimodal LLMs).
- Theoretical assumptions: Feasibility-aware MRL derivation assumes calibration set representativeness; distribution shift could break coverage guarantees.
- Reproducibility gap: Code and data are unavailable, hindering independent verification.
