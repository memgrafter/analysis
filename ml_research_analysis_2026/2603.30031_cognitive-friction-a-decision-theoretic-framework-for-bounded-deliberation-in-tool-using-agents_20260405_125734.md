# Cognitive Friction: A Decision-Theoretic Framework for Bounded Deliberation in Tool-Using Agents

## Quick Facts
- arXiv ID: 2603.30031
- Source URL: https://arxiv.org/abs/2603.30031
- Reference count: 20
- Primary result: TCA reduces deliberation time by 87% (112.5→14.4 steps) and improves patient viability by 36 points (57.34→93.06) over a greedy ReAct baseline, while maintaining diagnostic accuracy (1.00→1.00) and only slightly reducing total information gain (1.5688→1.4450).

## Executive Summary
The paper presents the Triadic Cognitive Architecture (TCA), a decision-theoretic framework that formalizes cognitive friction by jointly modeling belief evolution, congestion-dependent routing costs, and optimal stopping. TCA uses an HJB-inspired stopping boundary and a rollout-based value-of-information estimator to bound deliberation in tool-using agents. In the Emergency Medical Diagnostic Grid (EMDG) environment, TCA achieves a dramatic 87% reduction in deliberation time and a 36-point increase in patient viability compared to a greedy ReAct baseline, without sacrificing diagnostic accuracy.

## Method Summary
TCA operates in the EMDG, a medical diagnosis simulation where an agent selects diagnostic tools with known latencies and spatial loads. The agent maintains a belief distribution over pathologies, updating via Bayes' rule. For each candidate tool, TCA estimates expected entropy reduction (d∆H) using Monte Carlo rollouts. The net utility of an action is U(a) = d∆H(a) − α[λ_S(C_t + Ω(a)) + β(t + τ(a))], where C_t is accumulated congestion. The agent selects the action maximizing U and stops when no action yields positive utility. The ReAct baseline selects tools maximizing d∆H alone and stops when the leading belief exceeds 0.994.

## Key Results
- Deliberation time: 87% reduction (112.5 → 14.4 steps)
- Patient viability: +36 points (57.34 → 93.06)
- Diagnostic accuracy: maintained at 1.00
- Total information gain: slight decrease (1.5688 → 1.4450)

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** An HJB-inspired stopping boundary bounds deliberation by comparing marginal value-of-information (VOI) against spatio-temporal costs.
- **Mechanism:** The continuous-time formulation defines a value function V(p, γ, t) satisfying a Hamilton–Jacobi–Bellman (HJB) variational inequality. The optimal stopping region D is hit when the net continuation utility becomes non-positive.
- **Core assumption:** The idealized filtering dynamics and cost structure yield a well-posed Markov state; the discrete implementation approximates this boundary via a myopic net-utility rule.
- **Evidence anchors:** [abstract] "TCA uses an HJB-inspired stopping boundary..."; [section 3.3] HJB variational inequality (5) and stopping region D; weak direct support from neighboring papers on bounded neural architecture and cognitive friction.
- **Break condition:** Systematic bias in belief-dependent VOI estimates (e.g., high rollout variance) could mis-locate the stopping boundary, causing premature or delayed halting.

### Mechanism 2
- **Claim:** Rollout-based approximation of belief-dependent VOI enables a computable, inference-time stopping rule that prices epistemic gain against congestion and latency.
- **Mechanism:** For each candidate action, Monte Carlo rollouts simulate one-step belief updates to estimate expected entropy reduction d∆H(a|b_t). This is subtracted from a cost term scaling spatial load Ω(a) and temporal delay τ(a), with stopping when max_a U(a) ≤ 0.
- **Core assumption:** A one-step lookahead (η=0) provides a robust, computationally cheap proxy for the full continuation value; rollout noise averages out over candidate evaluations.
- **Evidence anchors:** [section 3.4] Rollout formula (6) and net-utility objective (7) with stopping condition (8); [abstract] "computable rollout-based approximation of belief-dependent value-of-information."; neighbor paper "Value of Information..." supports VOI framework but not the rollout approximation.
- **Break condition:** High epistemic ambiguity or very large action spaces could make K rollouts per action insufficient, leading to noisy VOI estimates and suboptimal actions or stopping.

### Mechanism 3
- **Claim:** Jointly coupling spatial routing costs, temporal decay, and belief evolution (the "triad") prevents the three failure modes: topological saturation, infinite deliberation, and epistemic collapse.
- **Mechanism:** The routing state γ_t on a Riemannian manifold evolves under control u_t with cost L_routing. Beliefs p_t evolve via Kushner–Stratonovich filtering. The instantaneous reward in the value function combines expected information gain minus L_routing and temporal penalty β(t).
- **Core assumption:** The environment's spatio-temporal friction can be modeled as differentiable costs (Ω(a), τ(a)) that directly impact utility; ignoring any triad component degrades performance.
- **Evidence anchors:** [abstract] "coupling belief evolution with congestion-dependent routing costs and optimal stopping."; [section 5.1] explicit triad description (Space, Time, Truth); [section 4.4] ablation results showing triad components are essential; [corpus] "From Particles to Agents..." supports spatial component.
- **Break condition:** If cost parameterization (α, β, λ_S) is heavily mis-specified relative to true environmental friction, the triad trade-off becomes maladaptive (e.g., over-penalizing time leads to premature stopping).

## Foundational Learning
- **Stochastic Optimal Stopping:** Needed to interpret the theoretical stopping guarantee and discrete approximation. Quick check: Given V satisfying HJB inequality, characterize the stopping region D and why the first hitting time T* = inf{s: (p_s, γ_s, s) ∈ D} is a minimal optimal stopping time.
- **Nonlinear Filtering (Kushner–Stratonovich Equation):** Formal model of belief evolution under uncertain evidence. Quick check: In the continuous formulation, what role does the innovation process dν_t = dY_t − ¯h(γ_t)dt play in the Kushner–Stratonovich drift for dp_t(θ)?
- **Value of Information (VOI):** Quantifies expected benefit of a query; TCA prices this against spatio-temporal costs. Quick check: Why is expected entropy reduction E[H(b_t) − H(b_{t+1})] a reasonable (though not perfect) surrogate for long-term value in a diagnostic task?

## Architecture Onboarding
Component map:
- Belief State (b_t): Categorical distribution over hypotheses Θ, updated via Bayes' rule after each observation.
- Routing State (C_t): Scalar representing cumulative spatial congestion cost; updated as C_{t+1} = C_t + Ω(a_t).
- VOI Estimator: For each candidate action a, runs K rollouts: sample observation, update belief clone, compute entropy drop; outputs d∆H(a|b_t).
- Net Utility Scorer: Computes U(a) = d∆H(a) − α[λ_S(C_t + Ω(a)) + β(t + τ(a))].
- Stopping Rule: STOP if max_a U(a) ≤ 0; else select a_t = argmax_a U(a) and execute.

Critical path:
1. Initialize b_0 (uniform), C_0=0, t=0.
2. At each step:
   a. Compute U(a) for all candidate actions a.
   b. If max_a U(a) ≤ 0, stop and output diagnosis = argmax b_t.
   c. Else, select a_t = argmax_a U(a), execute it, receive observation, update b_t, update C_t ← C_t + Ω(a_t), set t ← t + τ(a_t), and repeat.

Design tradeoffs:
- **Myopic (η=0) vs. Lookahead:** Myopic stopping is cheap and stable but may ignore future VOI chains; multi-step lookahead left for future work.
- **Rollout count K:** Higher K reduces variance in d∆H estimates but increases per-step compute; caching or learned surrogates suggested for scalability.
- **Parameter sensitivity:** α scales cost-utility trade-off; β controls time urgency; λ_S weights spatial costs. Sweeps show performance stable but requires calibration to environment dynamics.

Failure signatures:
- **Over-deliberation (No-Stop ablation):** Deliberation time ~112 steps, viability ~57; agent ignores temporal decay, queries high-latency tools.
- **Spatial saturation (No-Space):** High congestion costs ignored; may overload network subsystems.
- **Premature stop (over-penalization):** If α too high or β too steep, agent stops with high entropy, sacrificing accuracy.
- **VOI estimation error:** Too few rollouts make d∆H noisy → suboptimal action selection or erratic stopping.

First 3 experiments:
1. **VOI estimation sanity check:** With fixed belief b_t, compare d∆H estimates from K=10 vs. K=1000 rollouts against oracle exact expected entropy reduction; quantify variance and bias.
2. **Ablation replication:** Reproduce NoStop, NoSpace, NoTime conditions; expect viability drop and time increase in each.
3. **Hyperparameter sweep:** Vary α, β, λ_S ±25% over N=20 seeds each; plot viability vs. deliberation time to identify robust parameter regimes.

## Open Questions the Paper Calls Out
1. **Effect of continuation value (η>0):** How does multi-step lookahead affect stopping and performance? Evidence: Authors leave η>0 and deeper lookahead to future work (Sections 3.4, 4.3). Resolution: Run experiments in EMDG and NSTG with η∈{0.1,0.3,0.5} and multi-step lookahead, comparing viability, deliberation time, total info gain, and stopping boundaries.
2. **Sensitivity to cost parameters (α, β, λ_S):** How robust is TCA to variations? Authors will leave systematic sensitivity sweep to future work (Section 4.3). Resolution: Conduct structured sweep (±25% of defaults) in EMDG and NSTG; evaluate metrics and identify stable regimes.
3. **Cross-domain generalization:** Can a single set of spatio-temporal cost parameters work across heterogeneous tool domains? Authors identify this as a key direction (Section 4.2). Resolution: Apply hyperparameters tuned on EMDG to diverse environments (web navigation, code execution, multi-hop QA); compare performance against domain-specific tuning.
4. **Scalable VOI estimation:** How to scale rollout-based VOI in large tool ecosystems? Authors note naive Monte Carlo can be costly and suggest amortization (Section 4.2). Resolution: Implement candidate approximations (Fisher information, local linearization, learned models) on a simulated large-tool environment; measure estimation error, computational cost, and downstream performance.

## Limitations
- Environmental details (observation models, congestion dynamics, viability decay) are not fully specified; reproduction relies on assumptions.
- The ReAct baseline's stopping rule is unspecified; threshold choice may alter comparative results.
- The theoretical gap between continuous HJB formulation and discrete myopic implementation lacks analysis; suboptimality possible.
- Evaluation is limited to a single simulated medical domain; generalization to other tool-using agents remains uncertain.

## Confidence
- HJB-inspired stopping boundary: Medium confidence
- Rollout-based VOI approximation: Medium confidence
- Triadic coupling (space, time, truth): Medium-High confidence
