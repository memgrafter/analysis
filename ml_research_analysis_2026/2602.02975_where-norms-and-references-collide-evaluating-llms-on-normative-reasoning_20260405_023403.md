# Where Norms and References Collide: Evaluating LLMs on Normative Reasoning

## Quick Facts
- **arXiv ID:** 2602.02975
- **Source URL:** https://arxiv.org/abs/2602.02975
- **Reference count:** 11
- **Primary result:** LLMs require explicit social norms to achieve high accuracy on norm-based reference resolution; without them, average accuracy is 44.08%, rising to 70.51% with norms.

## Executive Summary
This paper introduces Norm-Based Reference Resolution (NBRR) as a critical challenge for embodied agents, where ambiguous referring expressions must be resolved using implicit social norms. To evaluate this, the authors construct SNIC, a dataset of 9,000 text-based scenarios across 51 human-validated seeds covering physically grounded norms in tasks like cleaning and serving. Testing 11 LLMs under three conditions—scene description only, scene plus formal logic (FOL), and scene plus explicit norms—reveals that models perform poorly without explicit norm guidance (average accuracy 44.08%), but accuracy jumps to 70.51% when norms are provided. Formalization offers negligible benefit. The findings highlight a significant gap in LLMs' inherent normative reasoning, particularly for implicit and conflicting norms, limiting their deployment in socially situated embodied settings.

## Method Summary
The authors created the SNIC dataset to isolate normative reasoning in reference resolution. Starting with 120 seed vignettes written by experts, a crowdsourced validation study (n=210) filtered to 51 seeds where a socially normative referent was the plurality choice. A procedural augmentation engine then generated ~176 variants per seed by substituting objects, properties, and settings while preserving the core normative structure, totaling 9,000 instances. Each instance includes a scene description, candidate objects, an ambiguous referring expression, and a norm-guided correct referent. The evaluation harness tests 11 pretrained LLMs (ranging from Granite-3 2B to GPT-4.1) in zero-shot fashion under three input conditions: (1) scene description only, (2) scene description plus a Prolog-based formal logic encoding, and (3) scene description plus formal logic plus an explicit list of relevant norms. Model outputs are parsed to select a referent, and accuracy is computed against the ground truth.

## Key Results
- Without explicit norms, average accuracy across 11 LLMs is 44.08%, with the best model (GPT-4.1) reaching 59.62%.
- Providing an explicit list of relevant norms boosts average accuracy to 70.51%, and GPT-4.1 achieves 99.6%.
- Adding a formal logic (FOL) representation yields minimal improvement (average 44.22% vs. 44.08% without), indicating that formalization does not aid norm-based reasoning.

## Why This Works (Mechanism)
**Mechanism 1: Social norms as disambiguating constraints**  
Norms function as a layer of normative expectations that filter candidate referents when multiple objects match perceptual descriptors. For example, in a serving task, the norm "use clean items when serving" selects the clean mug over dirty ones. Evidence: Models perform near random (44.08%) without explicit norms but succeed when norms are provided, confirming that norms are necessary constraints. Break condition: If all objects are norm-neutral or norms are contradictory without hierarchy, the mechanism fails.

**Mechanism 2: Formalization fails because LLMs lack procedural logic understanding**  
Providing a Prolog encoding of the scene does not improve performance (44.22% vs. 44.08%). The mechanism posits that LLMs treat formal code as a token sequence without grounding it to normative inference; they lack a consistent internal mapping from natural language to formal semantics. Break condition: If models were fine-tuned on formal logic-norm pairs or given a simplified aligned formalism, the effect might change.

**Mechanism 3: Explicit norms enable retrieval and application**  
Listing the relevant norms in the context window dramatically improves accuracy (to 70.51%), indicating the bottleneck is retrieving the correct norm from parametric knowledge, not applying it. Once the norm is externalized, models can match object properties to the norm's prescription. Break condition: If norms are presented in an unparseable format or involve irresolvable conflicts without meta-priorities, performance degrades.

## Foundational Learning
**Concept: Norm-Based Reference Resolution (NBRR)**  
- *Why needed:* It defines the core task—resolving ambiguous referents using social norms rather than pure perception.  
- *Quick check:* In a kitchen with a clean and dirty spoon during cooking, what does "hand me the spoon" refer to based on the relevant norm, and what is that norm? (Answer: The clean spoon, because the norm is to use clean utensils for food preparation.)

**Concept: Implicit vs. Explicit Norms**  
- *Why needed:* The paper's key finding is that LLMs fail on implicit norms but succeed when norms are made explicit, highlighting a retrieval gap.  
- *Quick check:* Give an example of an implicit norm in a dining setting (e.g., "don't start eating before the host") and how you would make it explicit for an LLM (e.g., list: "Wait for the host to begin eating before you start").

**Concept: Physical Grounding of Norms**  
- *Why needed:* SNIC's norms are tied to concrete object states (clean/dirty) and tasks, making them both learnable from text and challenging for LLMs.  
- *Quick check:* Why is the norm "don't use decorative items for serving" physically grounded? Because it references object functionality (decoration vs. utility) rather than abstract social behavior. How does that differ from "address elders formally"? The latter is purely social and lacks physical object constraints.

## Architecture Onboarding
**Component map:**  
Seed Scenario Creator → Human Validation Pipeline → Procedural Augmentation Engine → Formal Grounding Module → Evaluation Harness

**Critical path:**  
1. Seed validation (ensures human norm alignment)  
2. Augmentation rules (preserves normative logic)  
3. Evaluation condition design (isolates the norm knowledge variable)  
4. Result analysis (quantifies the norm gap)

**Design tradeoffs:**  
- *Scalability vs. Nuance:* Procedural augmentation creates scale but may miss subtle contextual interactions.  
- *Text-only vs. Embodied:* Using text vignettes is scalable and controlled but ignores perceptual and physical affordance cues crucial for real robots.  
- *Controlled Norms vs. Ecological Validity:* Focusing on 9 specific norm categories allows precise measurement but may not capture full real-world diversity.

**Failure signatures:**  
- **Primary:** Model accuracy near random chance (~14-20%) in the "Description Only" condition.  
- **Secondary:** High variance in performance across norm categories, indicating some norms are systematically opaque.  
- **Tertiary:** No significant performance gain when FOL is added, and potential degradation in some models (e.g., Llama-3 3B).

**First 3 experiments:**  
1. **Baseline Norm Gap:** Run all models on the 9,000-instance test set with only the scene description. Expect ~44% avg accuracy, confirming the primary finding.  
2. **Formalization Probe:** Compare each model's performance between "Description Only" and "Description + FOL" conditions. Expect minimal average change, validating that formal syntax doesn't help.  
3. **Norm Provision Efficacy:** Test all models with the explicit norm list added. Expect a sharp rise to ~70% avg accuracy, confirming the retrieval/activation bottleneck hypothesis. Analyze per-norm gains to see which norms benefit most.

## Open Questions the Paper Calls Out
1. **Why do state-of-the-art LLMs fail to inherently encode and apply physically grounded social norms for reference resolution?**  
   - *Basis:* Models perform poorly (44.08% avg) without explicit norms but succeed when norms are listed, suggesting norms are underrepresented in training data.  
   - *Unresolved:* The paper does not analyze specific training data deficiencies or architectural biases causing this failure.  
   - *Resolving evidence:* Analysis of training data frequency for norm-like statements; probing studies isolating norm knowledge; comparing models trained with/without norm-focused corpora.

2. **What formal representation characteristics could effectively support normative reasoning?**  
   - *Basis:* Adding Prolog-based FOL yielded negligible benefit (44.22% vs. 44.08%).  
   - *Unresolved:* The paper tests only one formalism and does not explore why it failed or what properties a successful formalism would need.  
   - *Resolving evidence:* Systematic evaluation of multiple formalisms (e.g., probabilistic graphical models, narrative knowledge graphs) on NBRR tasks across model architectures.

3. **What mechanisms cause inconsistent and contradictory norm prioritization in LLMs?**  
   - *Basis:* Strong negative correlations in performance between some norm categories suggest models apply fixed precedence (e.g., safety over tidiness) regardless of context.  
   - *Unresolved:* The root cause (spurious correlations, lack of conflict-resolution training, inherent inability to contextualize) is not investigated.  
   - *Resolving evidence:* Controlled experiments varying conflict priorities; probing model attention when processing norms; fine-tuning on conflict-resolution cases.

4. **Do text-based NBRR limitations persist with multimodal perceptual grounding?**  
   - *Basis:* The evaluation is text-only; limitations likely extend to embodied agents requiring vision and proprioception.  
   - *Unresolved:* The paper does not hypothesize or test how multimodal grounding might alter the normative reasoning burden.  
   - *Resolving evidence:* Extending SNIC to a multimodal benchmark (e.g., AI2-THOR); evaluating vision-language models with visual scene inputs; studying whether perceptual cues can implicitly activate correct norms.

## Limitations
- The evaluation uses a purely textual, zero-shot setup, limiting ecological validity for embodied agents.
- Unknowns block exact replication: prompt templates and precise formal representation schema are unspecified.
- Procedural augmentation may oversimplify contextual nuance, and the 9 norm categories may not capture real-world diversity.

## Confidence
- *LLMs require explicit norms for NBRR:* High (consistent ~26-point gain across 11 models).
- *Formal logical encoding provides minimal benefit:* Medium (scores nearly identical, but deeper logical competence untested).
- *Bottleneck is norm retrieval/activation, not application:* High (explicit norms yield near-perfect scores for top models).

## Next Checks
1. **Prompt fidelity audit:** Request full prompt templates and FOL/norm formatting from authors; run a 100-instance pilot to match reported baseline accuracies (e.g., GPT-4.1 ~60% in Description Only).
2. **Embodied generalization test:** Port a subset of SNIC to a multimodal simulation (e.g., AI2-THOR) to determine if visual/physical grounding reduces the norm gap without explicit textual norms.
3. **Norm conflict stress test:** Generate instances with irreconcilable norms (e.g., “use clean items” vs. “use designated guest items”) to probe whether models can hierarchically resolve conflicts when norms are explicit, testing Mechanism 3’s break condition.
