# NAU-QMUL: Utilizing BERT and CLIP for Multi-modal AI-Generated Image Detection
## Quick Facts
- **arXiv ID:** 2602.23863
- **Source URL:** https://arxiv.org/abs/2602.23863
- **Reference count:** 12
- **Primary result:** 5th place in the CT2 competition with test F1 scores of 83.16% (Task A) and 48.88% (Task B).

## Executive Summary
The paper presents a multi-modal approach for detecting AI-generated images and identifying their source models, combining text and image information. It leverages pre-trained BERT and CLIP encoders to extract semantic and visual features, which are fused and processed by a conditional multi-task learning framework. A pseudo-labeling strategy is employed to augment training data with high-confidence samples from the competition test set. The system achieved notable success in the CT2 competition, ranking 5th overall with an F1 score of 83.16% on the binary detection task (Task A) and 48.88% on the multi-class model identification task (Task B). The work highlights the potential of cross-modal feature fusion and conditional losses in addressing the challenges of AI-generated image detection.

## Method Summary
The proposed model processes a text caption and an image pair. Text features are extracted via a frozen BERT encoder; image features are obtained from CLIP's vision transformer. These features are concatenated and projected into a shared representation space. Two classification heads operate on this shared vector: one for binary detection (AI vs. real) and another for multi-class identification among five generative models. The multi-task loss includes a binary cross-entropy for Task A always, and a conditional cross-entropy for Task B applied only to samples predicted as AI-generated. To enlarge training data, the model pseudo-labels competition test samples with both task confidences above 0.8, which are then mixed with the original training set. Training uses an AdamW optimizer with a learning rate of 2e-5, weight decay 0.01, batch size 256, for 8 epochs.

## Key Results
- Task A (AI vs. real) test F1: 83.16%
- Task B (source model identification) weighted test F1: 48.88%
- Competition rank: 5th place in the CT2 challenge.

## Why This Works (Mechanism)
### Mechanism 1: Cross-modal Feature Fusion
- **Claim:** Cross-modal feature fusion via concatenation and projection enables the model to learn joint representations that capture artifacts unique to AI-generated images across both text and image modalities.
- **Mechanism:** Text features from BERT and image features from CLIP Vision are concatenated into a single vector and then passed through a fully connected projection layer to align them into a shared space. This forces the model to synthesize information from both modalities into a unified representation for classification.
- **Core assumption:** The distinct, often subtle, fingerprints left by text-to-image generation models manifest simultaneously in the image pixel patterns and the semantic alignment (or misalignment) with the source caption. A single-modality approach would miss these cross-modal cues.
- **Evidence anchors:** 
  - [abstract] "...leverages pre-trained BERT and CLIP Vision encoders for text and image feature extraction, respectively, and employs cross-modal feature fusion..."
  - [section 3.1] "Once the textual and visual features are extracted, they are concatenated and projected into a shared feature space through a fully connected layer, enabling effective multi-modal feature fusion."
  - [corpus] Neighbor papers (e.g., "Vision-Language Consistency Guided...", "MiraGe: Multimodal Discriminative...") also explore multi-modal fusion for detection, suggesting this is a recognized direction, but do not directly validate *this specific concatenation+projection* mechanism.
- **Break condition:** If the textual captions are generic or unrelated to the image generation process (e.g., random captions), the text features may provide noisy or irrelevant signals, degrading the fused representation's utility.

### Mechanism 2: Conditional Multi-task Loss
- **Claim:** A conditional multi-task loss, where the source model identification loss (Task B) is only applied to samples classified as AI-generated (Task A == 1), prevents noise from real images and focuses learning on the discriminative features of generative models.
- **Mechanism:** The total loss = Binary Cross-Entropy (Task A) + (Conditional Cross-Entropy for Task B * I[Task_A_prediction==1]). The indicator function I ensures gradients for Task B only flow for images the model currently believes are AI-generated.
- **Core assumption:** Real images (LABEL_A == 0) have no meaningful "source model" label. Applying a multi-class loss to them would force the model to learn arbitrary and misleading distinctions among real images, harming Task B performance.
- **Evidence anchors:**
  - [abstract] "...employs a tailored multi-task loss function."
  - [section 3.2] "For Task B, a Conditional Cross-Entropy Loss is computed only for samples that Task A has classified as AI-generated... this conditional design prevents unnecessary computations for real images... reducing noise and improving classification efficiency."
  - [corpus] The concept of task conditioning is standard in multi-task learning but its specific application here for this problem is not directly evidenced in neighbor papers.
- **Break condition:** Early in training, if Task A's classifier is inaccurate (high false negatives for AI images), many AI-generated samples will be incorrectly masked (I[Task_A==1] = 0), starving Task B of critical learning signals.

### Mechanism 3: Pseudo-labeling Data Augmentation
- **Claim:** Pseudo-labeling with a high confidence threshold (0.8) on competition test data expands the training set with high-quality, diverse samples, improving model generalization and robustness.
- **Mechanism:** The trained model predicts labels (Task A and Task B) on the unlabeled test set. Only samples where both prediction confidences exceed 0.8 are added to the training data with their pseudo-labels. This creates a larger, more varied dataset.
- **Core assumption:** The competition test set distribution is sufficiently similar to the training set that high-confidence predictions on it are likely correct and represent novel variations of AI-generated artifacts not seen in the original training data.
- **Evidence anchors:**
  - [abstract] "A pseudo-labeling-based data augmentation strategy was utilized to expand the training dataset with high-confidence samples."
  - [section 4.3] Details the process: confidence threshold of 0.8, concatenation with original data, 8:2 split.
  - [corpus] Neighbor papers (e.g., "Team NYCU at Defactify4...") also use pseudo-labeling or test-time augmentation, indicating it's a common competition tactic, but no direct evidence this specific threshold was optimal.
- **Break condition:** If the test set distribution significantly differs from the training set (e.g., contains novel generation models or perturbation types), high-confidence pseudo-labels could be systematically wrong, leading to error propagation and degraded model performance.

## Foundational Learning
### Pre-trained Multi-modal Encoders (BERT, CLIP)
- **Why needed:** Transfer learning avoids training encoders from scratch; BERT provides contextual understanding of captions, while CLIP's vision encoder is pre-aligned with semantic concepts from paired text-image data.
- **Quick check:** Why is CLIP's pre-training on "text-image pairs" particularly relevant for this detection task compared to an ImageNet-trained ResNet?

### Multi-task Learning with Conditional Losses
- **Why needed:** The two tasks share a common feature space but have different label structures (binary vs. multi-class). Conditional losses prevent noise from real images on Task B and allow shared backbone to learn efficient representations.
- **Quick check:** What is the specific risk of applying the multi-class cross-entropy loss to all samples (both real and AI-generated) instead of conditioning it?

### Pseudo-labeling as Semi-supervised Augmentation
- **Why needed:** The competition's training set may be limited or biased; pseudo-labeling on the test set can augment data with in-distribution but unseen examples, boosting performance.
- **Quick check:** Besides "error propagation," what is one specific form of selection bias introduced by filtering only samples with >0.8 confidence for both tasks?

## Architecture Onboarding
**Component map:** Text Caption -> BERT Tokenizer -> BERT Encoder ([CLS] token) -> Text Feature Vector; Image -> CLIP FeatureExtractor -> CLIP Vision Encoder (pooled output) -> Image Feature Vector; Concatenation of Text and Image Feature Vectors -> Fully Connected Projection Layer -> Shared Feature Vector -> {Task A Head (Linear) -> Binary Prediction (sigmoid), Task B Head (Linear) -> Multi-class Prediction (softmax)}.

**Critical path:** 1) Preprocess caption with BERT tokenizer; 2) Preprocess image with CLIP feature extractor; 3) Encode text via BERT, image via CLIP Vision; 4) Concatenate features; 5) Project to shared space; 6) Apply both classification heads; 7) Compute binary cross-entropy for Task A on all samples; 8) Compute cross-entropy for Task B only on samples where label_A == 1 (or model prediction AI for pseudo-phase); 9) Sum losses; 10) Backpropagate and update parameters.

**Design tradeoffs:**
- **Fusion Simplicity:** Concatenation+projection is computationally cheap but may not model complex interactions; attention-based fusion could capture finer cross-modal cues at the cost of added parameters and complexity.
- **Pseudo-labeling Threshold:** A high threshold (0.8) ensures high-quality pseudo-labels but severely limits the amount of augmented data; a lower threshold could yield more samples at the risk of increased noise.
- **Task weighting:** Losses are summed equally (λ_A = 1, λ_B = 1). Since Task A is easier and often already high-performing, Task B may benefit from a higher weight to balance learning.

**Failure signatures:**
- **Task A high, Task B low:** Indicates potential issues with conditional loss implementation or insufficient learning signal for Task B; check gradient flow and the number of samples satisfying the mask per batch.
- **Degraded performance on specific generative models (e.g., SD 3):** Suggests the fused features do not effectively capture that model's unique artifacts; perform per-model error analysis.
- **Validation loss spikes after introducing pseudo-labeled data:** Suggests significant label errors in the pseudo-set; examine confidence distribution of added samples and consider raising the threshold.

**First 3 experiments:**
1. **Modality Ablation:** Train variants using only CLIP image features and only BERT text features, then compare their F1 scores on both tasks against the full fused model.
2. **Fusion Ablation:** Replace concatenation+projection with alternative fusion strategies (e.g., element-wise addition, learned weighted sum) and evaluate performance differences.
3. **Loss Ablation:** Compare the proposed conditional Task B loss against a standard multi-task loss where Task B loss is computed on all samples; measure impact on Task B validation F1 and training stability.

## Open Questions the Paper Calls Out
1. **Error propagation mitigation in pseudo-labeling:** How can error propagation from incorrect pseudo-labels be mitigated in multi-modal AI-generated image detection? The authors explicitly state that error propagation is a key concern of their pseudo-labeling strategy. The current 0.8 confidence threshold filters only high-confidence samples, but errors in those can still propagate and ambiguous cases are excluded, limiting robustness. Evidence would come from comparative experiments using uncertainty estimation (e.g., Monte Carlo dropout) to weight pseudo-labels, or iterative refinement with lower thresholds and consistency checks, measuring impact on validation F1 and error rates.

2. **Advanced multi-modal fusion techniques:** What advanced multi-modal fusion techniques (beyond concatenation) most effectively capture interactions between textual and visual features for AI-generated image detection? The authors identify exploring "more advanced and effective multi-modal feature fusion strategies" as future work. Simple concatenation may not model nuanced cross-modal relationships crucial for distinguishing subtle generation artifacts. Evidence would come from a systematic comparison of fusion methods (attention, cross-modal transformers, graph networks) via ablation studies on the CT2 dataset, reporting F1 scores for both tasks and computational efficiency.

3. **Modeling relationships between same-caption images:** How can the relationships between multiple images generated from the same caption be modeled to improve detection performance? The authors note future work should "model the relationships between images associated with the same caption, rather than treating them as independent samples." The current approach ignores potential shared artifacts or variations from identical text prompts. Evidence would come from developing a graph-based or set-based architecture that encodes dependencies between images from the same caption, evaluated with clustered validation splits to test generalization within prompt groups.

4. **Biases reduction in pseudo-labeling:** What data augmentation and training strategies effectively reduce biases (selection bias, class imbalance) introduced by pseudo-labeling in this context? The authors propose incorporating "uncertainty-aware training, employ diverse augmentation techniques, and implement strategies to address class imbalance" in future work. Their pseudo-labeling with a 0.8 threshold likely overrepresents easier samples and certain models. Evidence would come from experiments with confidence-aware sampling, class re-weighting, and augmentation from diverse sources, assessing fairness via per-class F1 scores and distribution similarity metrics.

## Limitations
- Dataset splits (train/val/test) and label encoding are unspecified, hindering reproducibility.
- Pseudo-labeling implementation details (e.g., one-time vs iterative, confidence metric, class balance) are missing, limiting assessment of its impact and potential biases.
- No ablation studies to isolate the contributions of cross-modal fusion, conditional loss, or pseudo-labeling; the high confidence threshold may introduce selection bias toward easier samples.
