# Generating Hierarchical JSON Representations of Scientific Sentences Using LLMs

## Quick Facts
- **arXiv ID:** 2603.23532
- **Source URL:** https://arxiv.org/abs/2603.23532
- **Reference count:** 18
- **Primary result:** Hierarchical JSON generation via fine-tuned Mistral-7B yields 100% valid JSON and high semantic similarity (mean cosine 0.8724) for scientific sentence reconstruction.

## Executive Summary
This paper explores whether hierarchical structured representations can preserve the meaning of complex scientific sentences more effectively than flat schemas. The authors fine-tune the lightweight Mistral-7B language model with a novel structural loss function to produce hierarchical JSON outputs that explicitly separate core claims from supporting components. The fidelity of these representations is evaluated by feeding them to GPT-4o to reconstruct the original sentences and comparing the results using semantic (cosine similarity) and lexical (BLEU, ROUGE, METEOR) metrics. On a held-out set of 274 sentences, the method achieved 100% syntactically valid JSON and a mean cosine similarity of 0.8724, indicating strong meaning retention, although lexical scores were modest. The findings suggest that hierarchical JSON is a promising intermediate format for capturing scientific text semantics.

## Method Summary
The authors defined a hierarchical JSON schema with a core claim field and multiple supporting component fields. They collected a dataset of scientific sentences and fine-tuned Mistral-7B on this data using a combined loss: standard language modeling loss plus a structural loss that enforces schema conformity (e.g., via constrained decoding or post-hoc validation). The trained model generates hierarchical JSON for new input sentences. To assess reconstruction quality, the JSON is provided to GPT-4o with a prompt to regenerate the original sentence. Semantic preservation is measured by cosine similarity of sentence embeddings, while lexical overlap is evaluated with BLEU, ROUGE-1 F1, and METEOR. Experiments are conducted on 274 test sentences.

## Key Results
- 100% of generated JSON outputs were syntactically valid.
- Mean cosine similarity between original and reconstructed sentences was 0.8724, with most scores above 0.85.
- Lexical scores: BLEU 0.1496, ROUGE-1 F1 0.5725, METEOR 0.4907.

## Why This Works (Mechanism)
The hierarchical JSON format captures logical relationships (core claim vs. support) that flat schemas cannot, reducing information loss. The structural loss function explicitly trains the model to respect the target schema, ensuring syntactically valid and logically organized outputs. Fine-tuning on domain-specific scientific sentences adapts the base LLM to the genre and output format. Reconstruction with a powerful generative model (GPT-4o) tests whether the structured representation contains sufficient information to recover the original meaning. The high cosine similarity demonstrates that the essential semantics survive both the structuring and reconstruction steps.

## Foundational Learning
- **Fine-tuning Large Language Models (LLMs)**  
  *Why needed:* To adapt a general-purpose pre-trained model to generate structured hierarchical JSON, a capability absent in the base model.  
  *Quick check:* Monitor training loss and the fraction of outputs that conform to the JSON schema during validation epochs.

- **Structural Loss Function**  
  *Why needed:* To explicitly penalize deviations from the desired hierarchical schema, guiding the model toward syntactically correct and logically organized outputs.  
  *Quick check:* Track schema conformance rate (e.g., via parsing success) on a held-out set during training.

- **Hierarchical Representation of Scientific Claims**  
  *Why needed:* Scientific sentences often embed a main claim and subordinate facts; a flat structure cannot capture this dependency, leading to meaning loss.  
  *Quick check:* Verify that >95% of generated JSONs contain both a core claim and at least one supporting component.

- **Semantic Similarity Metrics**  
  *Why needed:* Lexical metrics (BLEU, ROUGE) are insufficient when paraphrasing occurs; semantic similarity (e.g., cosine similarity of embeddings) better gauges meaning retention.  
  *Quick check:* Compute similarity on a small hand-labeled set of equivalent/non-equivalent pairs to confirm correlation with human judgment.

- **Reconstruction Evaluation with a Generative Model**  
  *Why needed:* Feeding the JSON to a strong model like GPT-4o tests whether the structured representation can be faithfully converted back to natural language.  
  *Quick check:* Perform a manual inspection of a sample of reconstructions to ensure the automatic metrics align with perceived fidelity.

## Architecture Onboarding
- **Component map:**  
  Input Scientific Sentence -> Mistral-7B (fine-tuned with structural loss) -> Hierarchical JSON -> GPT-4o (reconstruction) -> Reconstructed Sentence -> Evaluation Metrics (Cosine Similarity, BLEU, ROUGE, METEOR)

- **Critical path:** The pipeline’s critical path spans from sentence input through hierarchical JSON generation, reconstruction by GPT-4o, and finally metric computation. Failures in JSON validity or reconstruction break downstream evaluation.

- **Design tradeoffs:**  
  - *Hierarchical depth vs. complexity:* Deeper schemas capture finer details but increase generation difficulty and risk of invalid JSON.  
  - *Model size vs. efficiency:* A lightweight 7B model reduces computational cost but may limit expressiveness compared to larger models.  
  - *Automated vs. human evaluation:* Using GPT-4o and embedding scales but may miss subtle meaning nuances that human annotators detect.  
  - *Compression vs. completeness:* Hierarchical JSON may compress information, yielding lower lexical scores but potentially higher semantic similarity; the optimal trade‑off depends on application needs.

- **Failure signatures:**  
  - Invalid JSON syntax or schema violations (detected during parsing).  
  - Low cosine similarity (<0.6) indicating semantic drift.  
  - Missing core claim or supporting components in generated JSON.  
  - Reconstructed sentences that omit critical details upon manual review.  
  - Discrepancy where lexical scores are abnormally high while semantic scores are low, suggesting verbatim copying without proper structuring.

- **First experiments:**  
  1. **Baseline comparison:** Fine-tune Mistral-7B to produce flat-schema JSON and compare reconstruction metrics to the hierarchical version.  
  2. **Ablation of structural loss:** Remove the structural loss component and measure the impact on JSON validity and reconstruction quality.  
  3. **Cross-domain generalization:** Test the model on scientific sentences from a different subfield (e.g., biology) to assess domain robustness and the need for domain-specific fine-tuning.

## Limitations
- Dataset provenance and diversity are unspecified; the 274 test sentences may not represent a broad range of scientific domains or complexity levels.
- No direct comparison to flat-schema baselines or alternative hierarchical methods; the claimed advantage of hierarchical representation is inferred rather than measured.
- Reconstruction relies on GPT-4o, introducing potential bias from the evaluator model and leaving human‑judged fidelity unverified.

## Confidence
- **High:** Syntactic validity (100% JSON) and cosine similarity results (mean 0.8724) are directly reported and reproducible from the provided metrics.
- **Medium:** The assertion that hierarchical JSON preserves meaning better than flat schemas is supported indirectly by reconstruction quality, not by a direct baseline comparison.
- **Low:** Generalizability beyond the test set; scalability to longer texts or diverse scientific genres remains untested.
