# From Prerequisites to Predictions: Validating a Geometric Hallucination Taxonomy Through Controlled Induction

## Quick Facts
- **arXiv ID:** 2603.00307
- **Source URL:** https://arxiv.org/abs/2603.00307
- **Reference count:** 7
- **Primary result:** Only Type 3 (coverage gap) hallucinations display a stable geometric signal in GPT-2; Types 1 and 2 remain indistinguishable at 124M parameters.

## Executive Summary
This study tests a geometric hallucination taxonomy—Type 1 (center-drift), Type 2 (wrong-well), Type 3 (coverage gap)—by inducing hallucinations in GPT-2 via 45 engineered prompts. By comparing static input embeddings and contextual hidden states across 20 independent generation runs, the authors find an asymmetric separation: Type 3 hallucinations produce a robustly higher norm in static embeddings, while in contextual states the effect is directionally stable but underpowered. Types 1 and 2 show no stable separation in either representational space. The work also reveals that token-level statistical tests are severely inflated by pseudoreplication, emphasizing the need for prompt-level inference.

## Method Summary
The experiment uses 45 prompts (15 per hallucination type) to generate 60 tokens each from GPT-2-small (124M). Two representation spaces are analyzed: static input embeddings (non-autoregressive extraction) and contextual last-layer hidden states (autoregressive decoding with state capture per token). Calibration with a fixed seed defines geometric zones via MiniBatchKMeans clustering (k=40) on a corpus of filtered tokens or prompt-conditioned states. Per-token metrics—soft cluster membership H(v), norm, and maximum centroid similarity—are aggregated to prompt-level means. Statistical inference uses Mann-Whitney U tests with Holm correction across 20 generation seeds, quantifying stability via significance rates and effect sizes.

## Key Results
- **Static embeddings:** Type 3 norm is robustly higher than Types 1 and 2 (Holm-corrected significance in 14/20 runs, median rank-biserial r = +0.61).
- **Contextual hidden states:** Type 3 norm is consistently lower (19/20 runs) but nominally significant in only 4/20 runs at N=15 (median r ≈ −0.28), indicating an underpowered micro-signal.
- **Non-separation:** Types 1 and 2 never show stable separation in any metric or space (≤3/20 runs). Token-level significance is inflated 4–16× by pseudoreplication.

## Why This Works (Mechanism)
### Mechanism 1: Static norm elevation for Type 3
- **Claim:** Type 3 hallucinations produce a robustly higher norm in static input embeddings compared to Types 1 and 2.
- **Mechanism:** Compositional novelty prompts force the model to select rarer vocabulary items, which have systematically higher norms in the embedding matrix.
- **Evidence:** In static embeddings, Type 3 norm is significantly higher (Holm-corrected in 14/20 runs, median r = +0.61); magnitude difference is consistent (3.223±0.033 vs. ~3.112).
- **Break condition:** Disrupting the correlation between token frequency and embedding norm (e.g., via tokenizer or corpus change) would invalidate this mechanism.

### Mechanism 2: Contextual norm reduction for Type 3
- **Claim:** Type 3 hallucinations produce a stable but underpowered lower norm in contextual hidden states.
- **Mechanism:** Processing compositionally novel input yields less confident internal representations (lower activation magnitude) because the model lacks learned pathways to compose the required concepts.
- **Evidence:** Type 3 has the lowest contextual norm in 19/20 runs, with moderate effect sizes (median r ≈ −0.28) but low nominal significance at N=15.
- **Break condition:** Increasing prompt sample size (N≥30) or applying representational preprocessing could solidify the signal; persistent underpower may reflect a fundamental limitation at 124M parameters.

### Mechanism 3: Pseudoreplication inflation
- **Claim:** Token-level statistical significance in autoregressive generation is inflated by pseudoreplication.
- **Mechanism:** Consecutive tokens from the same prompt share generation history, violating independence assumptions; treating each token as independent massively overestimates significance.
- **Evidence:** Token-level significance rates are 4–16× higher than prompt-level rates for angular metrics; prompt-level tests show no stable separation for Types 1/2.
- **Break condition:** Accounting for within-prompt correlation (e.g., mixed-effects models) should eliminate inflation; if not, the effect may be truly token-level.

## Foundational Learning
- **Geometric Hallucination Taxonomy:** Defines three failure modes (center-drift, wrong-well, coverage gap) based on geometric relationships between generated tokens and cluster centroids. *Why needed:* The entire experiment tests predictions derived from this taxonomy. *Quick check:* What is the predicted difference in cluster membership (H(v)) between a Type 2 and Type 3 token?
- **Static vs. Contextual Embeddings:** Static embeddings are fixed vocabulary vectors; contextual hidden states dynamically encode generation history. *Why needed:* Their different properties explain the asymmetric results (strong static signal, weak contextual). *Quick check:* Why might a hallucination signature be visible in static embeddings despite ignoring context?
- **Pseudoreplication in Autoregressive Sequences:** Consecutive tokens are not independent due to shared generation history. *Why needed:* Token-level tests inflate significance; prompt-level aggregation is required. *Quick check:* If you generate 60 tokens from one prompt, how many independent data points do you have for a prompt-condition effect?

## Architecture Onboarding
Calibration (once, seed 42) sets zone thresholds via MiniBatchKMeans (k=40) on a corpus. For each of 20 seeds: Generate tokens for 45 prompts → Extract representations (static E or contextual h) → Compute per-token metrics (H(v), norm, max sim) → Aggregate to prompt-level means per condition → Run Mann-Whitney tests (Holm-corrected) → Store results. Stability assessed via significance rates and effect sizes.

**Component map:**
GPT-2-small (124M) → Prompt Set (45 engineered prompts) → Generation Engine (static: `model.generate()`; contextual: manual autoregressive loop with hidden-state capture) → Metric Calculator (H(v), norm, max sim) → Statistical Module (prompt-level Mann-Whitney, Holm correction) → Stability Tracker (20-run aggregation)

**Design tradeoffs:**
- Static vs. Contextual: Static is simpler and shows stronger effects (vocabulary frequency proxy), but contextual is more ecologically valid yet reveals only a micro-signal due to representational saturation.
- Prompt-level (N=15) vs. Token-level (N≈900): Prompt-level is correct but underpowered for small contextual effects; token-level is invalid due to pseudoreplication.

**Failure signatures:**
- Zone classification failure: Mean diagonal in confusion matrices is low (0.295 static, 0.185 contextual), indicating no condition maps cleanly to one zone.
- Type 1/2 non-separation: Absent across metrics and spaces (≤3/20 runs), suggesting a genuine capacity limit at 124M parameters.
- Micro-signal regime: Contextual metrics are near-saturated (H(v)>0.98), compressing between-condition differences.

**First 3 experiments:**
1. Static Embedding Norm Analysis: Expect Type 3 norm > Types 1/2 in ~18–20 runs with large effect (r≈0.6), Holm survival in ~14 runs; Types 1/2 never separate.
2. Contextual Hidden-State Norm Analysis: Expect Type 3 norm lowest in ~19 runs but nominal significance in only ~4 runs at N=15; confirms underpowered stable direction.
3. Pseudoreplication Check: Compare token-level vs. prompt-level significance for angular metrics (H(v), max sim); expect 4–16× inflation at token level, vanishing at prompt level.

## Open Questions the Paper Calls Out
1. Does spectral decomposition of contextual hidden states reveal Type 1/Type 2 separation in specific eigenspectrum bands? The paper proposes this as a test of the spectral hypothesis but did not perform it.
2. Does scaling to larger language models (≥1B parameters) enable detectable Type 1/Type 2 separation, or does non-separation persist as a fundamental capacity limit?
3. What is the minimum number of prompts per condition (N) required for ≥80% power to detect the contextual norm effect of Type 3 hallucinations? The paper infers N≥30 but provides no formal power analysis.
4. Can representational preprocessing (e.g., whitening, learned projections) amplify micro-signals in contextual hidden states enough to achieve prompt-level significance for Type 3 norm separation and possibly reveal Type 1/2 separation?

## Limitations
- Exact engineered prompts (15 per type) and calibration centroids (k=40) are unreported, blocking exact replication.
- Findings are restricted to GPT-2-small (124M); scalability to larger models or architectures is unknown.
- The contextual experiment is underpowered at N=15, limiting definitive conclusions about effect sizes.

## Confidence
- **Static embedding norm signal (Type 3 > Types 1/2):** High—robust Holm-corrected separation (14/20 runs), large median effect (r=+0.61).
- **Contextual hidden-state norm signal (Type 3 lowest):** Medium—directionally stable (19/20 runs) but low significance at N=15 (≤4/20 runs), median |r|≈0.28.
- **Non-separation of Types 1 & 2:** High—tested across spaces and metrics; ≤3/20 runs show separation, consistent with signal absence at this scale.
- **Token-level pseudoreplication inflation:** High—clear 4–16× inflation demonstrated, supported by methodological principles.

## Next Checks
1. **Prompt-set replication:** Re-engineer 15 prompts per type using the geometric criteria and verify they reproduce the norm patterns (static: T3 >> T1/T2; contextual: T3 lowest).
2. **Centroid re-derivation:** Re-run k=40 MiniBatchKMeans on the fixed calibration corpus (seed 42) to obtain centroids and confirm zone definitions yield similar between-type separations.
3. **Scale stress test:** Repeat experiments on GPT-2-medium (355M) and GPT-2-large (774M) to check if Type 1/2 separation emerges or contextual signal strengthens.
