# Causal Interpretation of Neural Network Computations with Contribution Decomposition
## Quick Facts
- arXiv ID: 2603.06557
- Source URL: https://arxiv.org/abs/2603.06557
- Reference count: 40
- Primary result: CODEC reveals that hidden-neuron contributions become sparser and higher-dimensional across layers, with positive/negative effects decorrelating, and decomposed modes show stronger class correlation and selective impairment in ablations.

## Executive Summary
The paper introduces CODEC, a framework for causal interpretability that overcomes limitations of activation-based methods. By using gradient attribution to compute causal contributions of hidden neurons and decomposing them with sparse autoencoders, CODEC identifies coordinated, sparse contribution modes. Applied to ResNet-50 on ImageNet, it shows increasing sparsity and decorrelation across layers, with modes more class-selective than individual channels or activation modes. Ablation studies confirm modes' functional relevance, and applications to retinal CNNs reveal combinatorial interneuron actions.

## Method Summary
CODEC quantifies causal hidden-neuron contributions via gradient-based attribution (e.g., Integrated Gradients), producing a contribution matrix for inputs and neurons. This matrix is then decomposed using a sparse autoencoder trained to yield sparse, coordinated modes. The autoencoder's latent representations capture patterns of coordinated contributions, which are analyzed for sparsity (Hoyer), class correlation, and functional impact via channel ablation. The framework is evaluated on ResNet-50 and retinal CNNs, with reconstruction accuracy around R² ≈ 0.85.

## Key Results
- Contributions become sparser and higher-dimensional in deeper layers of ResNet-50, with positive and negative effects progressively decorrelating.
- Decomposed contribution modes exhibit significantly higher correlation with image classes than individual channels or activation-based modes from standard sparse autoencoders.
- Removing top-weighted channels from contribution modes impairs target-class accuracy more selectively than removing from activation modes, indicating modes' functional specificity.

## Why This Works (Mechanism)
CODEC shifts from correlative activation analysis to causal contribution estimation using input-gradient methods, which attribute output changes to neurons. Sparse autoencoders then extract coordinated patterns from these contributions, enforcing sparsity to highlight salient, interpretable modes. This combination allows identifying neuron groups that jointly drive class-specific predictions, with decorrelation reflecting specialized functional roles across layers. The mechanism effectively translates continuous contribution signals into discrete, analyzable modes via learned sparsity constraints.

## Foundational Learning
- **Gradient Attribution (e.g., Integrated Gradients)**: Estimates causal impact of neurons on output by integrating gradients along a path from baseline to input. *Why needed*: Provides post-hoc causal explanations, unlike activation maps. *Quick check*: Verify attribution sums match output difference on simple models.
- **Sparse Autoencoders (SAEs)**: Neural networks that learn compressed, sparse representations via sparsity penalties. *Why needed*: Decomposes high-dimensional contributions into interpretable, coordinated features. *Quick check*: Check latent activation sparsity (e.g., Hoyer) and reconstruction quality (R²).
- **Contribution Matrix**: A tensor aggregating per-neuron contributions across many inputs. *Why needed*: Serves as input to SAE for mode discovery. *Quick check*: Ensure matrix captures class-discriminative patterns via correlation analysis.
- **Hoyer Sparsity**: Normalized measure of sparsity (l1/l2 norm). *Why needed*: Quantifies how concentrated contributions are. *Quick check*: Compare sparsity across layers after normalization.
- **Class-Correlation Metrics**: Pearson or other correlations between mode activations and class labels. *Why needed*: Evaluates semantic meaningfulness of modes. *Quick check*: Top modes should show high correlation with specific classes.

## Architecture Onboarding
CODEC processes a trained model and dataset to produce contribution modes.
Component map: Input samples -> Forward pass through model -> Gradient attribution (Integrated Gradients) -> Contribution matrix (samples × neurons) -> Sparse autoencoder training -> Contribution modes (latent dimensions).
Critical path: The pipeline flows from data input through attribution to decomposition; each step depends on the previous (e.g., SAE requires contribution matrix).
Design tradeoffs: Attribution baseline choice affects gradient reliability; SAE sparsity penalty vs. reconstruction accuracy; latent dimension size controls mode granularity.
Failure signatures: Low SAE reconstruction R² (<0.8) indicates poor mode capture; noisy or unstructured contribution matrices; ablation experiments showing no selective impairment.
First experiments: (1) Replicate on a small CNN (e.g., on CIFAR-10) to validate sparsity trends. (2) Visualize top-contributing modes for misclassified images to detect failure modes. (3) Compare mode interpretability via human evaluation on a subset of ImageNet classes.

## Limitations
- Gradient attribution methods (e.g., Integrated Gradients) can be noisy and baseline-dependent, potentially affecting contribution reliability.
- Findings are limited to ResNet-50 and retinal CNNs; trends like increasing sparsity may not generalize to transformers or other architectures.
- Sparse autoencoder reconstruction leaves ~15% unexplained variance, and modes may not correspond to semantically meaningful features without further validation.

## Confidence
- High: CODEC framework implementation and accurate reconstruction (R² ≈ 0.85); modes show higher class correlation than baselines.
- Medium: Observations of sparsity increase and decorrelation across ResNet-50 layers; supported by data but lacking cross-architecture evidence.
- Low: Interpretations of retinal CNN combinatorial actions and dynamic receptive field explanations; speculative without controlled feature tests.

## Next Checks
