# UniSkill: A Dataset for Matching University Curricula to Professional Competencies

## Quick Facts
- **arXiv ID:** 2603.03134  
- **Source URL:** https://arxiv.org/abs/2603.03134  
- **Reference count:** 0  
- **Primary result:** A BERT model using the Combined Approach (title + sentence) with synthetic data achieves 87% F1-score and 89% recall for matching university courses to ESCO skills.

## Executive Summary
This paper introduces UniSkill, a manually annotated dataset linking 2,192 Finnish university course title and sentence instances to standardized ESCO professional skills. It addresses the scarcity of public data connecting curriculum content to job market competencies. The core methodological contribution is the Combined Approach (CA), which concatenates course title and a single sentence from the description with special labeling tokens for input to a BERT classifier. To augment limited manual annotations, the authors generate domain-specific synthetic course sentences and titles using GPT-4o, explicitly prompting for both explicit and implicit skill mentions. The best model, trained on both manual and synthetic data using the CA format, achieves high performance (87% F1, 89% recall). Error analysis reveals that sentence-level ambiguity is the primary source of false negatives, and the inclusion of the course title context significantly improves recall by disambiguating borderline cases.

## Method Summary
The research pipeline begins with preprocessing public Finnish graduate-level course catalogs (in English) to extract titles and split descriptions into individual sentences. Candidate skill-course pairs are generated using a pre-trained similarity model to select high- and low-scoring examples for efficient human annotation. Annotators label sentence-skill and title-skill pairs as relevant or not, following iteratively refined guidelines, yielding the manual UniSkill dataset. A synthetic dataset (~3,200 triplets) is created by prompting GPT-4o with ESCO skill names and definitions to generate both positive (matching) and negative (non-matching) course sentences and titles, with instructions to produce explicit and implicit mentions. Models are fine-tuned BERT classifiers trained on various input configurations: separate title-skill or sentence-skill pairs, or the Combined Approach (CA) that concatenates title, sentence, and skill with optional special tokens (e.g., [TITLE], [SENTENCE]). Training configurations systematically vary the inclusion of synthetic data and the use of labeled inputs. Performance is evaluated on a held-out test set of 300 manually annotated pairs, with primary metrics being F1-score and recall for the positive (match) class.

## Key Results
- The Combined Approach (CA) using course title and sentence input, with special labeling tokens, achieves an **87% F1-score** and **89% recall** on the test set.
- Incorporating the **domain-specific synthetic dataset** yields a **6–8% recall improvement** over models trained only on manual data.
- Models that process the **sentence alone show significantly lower recall** (below 80%), and error analysis identifies **sentence-level ambiguity** as the primary cause of false negatives.

## Why This Works (Mechanism)

### Mechanism 1: Combined Approach (Title + Sentence) Improves Recall
- **Claim:** Concatenating the course title and a single descriptive sentence as input improves recall for skill relevance classification.
- **Mechanism:** The course title provides broader thematic context that helps disambiguate sentences with only implicit or borderline references to a skill. When the sentence is ambiguous, the title's signal pushes the prediction toward the correct positive class.
- **Core assumption:** Course titles are less ambiguous than individual sentences and are predictive of the skills taught.
- **Evidence anchors:**
  - The best model achieves 89% recall for positive matches.
  - Section 4.2 shows a 7% recall increase for the CA compared to sentence-only models.
  - Prior works (e.g., Course-Skill Atlas) evaluate sentences in isolation, making the CA's gain novel in this context.
- **Break condition:** If titles are generic, missing, or misleading, the added context may introduce noise rather than disambiguation.

### Mechanism 2: Domain-Specific Synthetic Data Boosts Generalization
- **Claim:** Task-specific synthetic data generated with GPT-4o using prompts for explicit/implicit skill mentions significantly improves recall (6–8%) by augmenting limited manual annotations.
- **Mechanism:** Synthetic data expands the training distribution with diverse linguistic expressions of the same skills, helping the model generalize to unseen sentence formulations while maintaining correct relevance labels.
- **Core assumption:** High-quality, on-domain synthetic course sentences can be reliably produced by instructing an LLM with skill definitions and relevance constraints.
- **Evidence anchors:**
  - Models trained with synthetic data show 6–8% higher recall than those without.
  - Using synthetic data from a different domain (job advertisements) harms performance, underscoring the need for domain specificity.
- **Break condition:** Poor prompt design or model drift can generate low-quality or off-domain synthetic text, introducing harmful noise.

### Mechanism 3: Special Input Tokens Enhance Component Integration
- **Claim:** Using special tokens (e.g., [TITLE], [SENTENCE], [SKILL], [DESCRIPTION]) to label each component in the input sequence improves classification performance.
- **Mechanism:** The tokens act as explicit delimiters, guiding the transformer's attention to treat each text segment (title, sentence, skill name, definition) differently, leading to better integration of heterogeneous information.
- **Core assumption:** The model's token-level attention can be steered by artificial markers to learn more effective task-specific representations.
- **Evidence anchors:**
  - Table 3 in Section 4.2 shows labeled input yields 89% recall vs. 83% for unlabeled input on the test set.
  - The paper notes labeling has a more pronounced effect on the course title approach.
- **Break condition:** The benefit may diminish with model architectures that already encode structural information (e.g., via segment embeddings) or if input length constraints force truncation of critical tokens.

  - **Why needed:** All baseline models are BERT-based; knowing how to format inputs (concatenation, special tokens) and fine-tune for binary classification is fundamental.
  - **Quick check:** In the combined approach, how are the title, sentence, and skill concatenated for BERT input, and which additional tokens are optionally used?
- **Concept: Skill Matching vs. Skill Extraction**
  - **Why needed:** The task is to judge relevance between a predefined skill and a course, unlike extracting skills from text; this distinction affects model design and evaluation.
  - **Quick check:** How does this validator approach differ from a retrieval-based skill extraction system like Decorte et al. (2023)?

## Architecture Onboarding
- **Component map:**
  Finnish course catalogs -> Preprocessing (filter, split sentences) -> Candidate Generation (similarity model) -> Human Annotation (guidelines) -> Manual UniSkill Dataset -> Synthetic Data Generation (GPT-4o prompts) -> Model Training (BERT + CA + labeled tokens) -> Evaluation (test set metrics, error analysis).

- **Critical path:**
  Raw course descriptions must be preprocessed into titles and sentences. Candidate generation selects pairs for annotation to manage labeling effort. The manual and synthetic datasets are then combined for model training, where the CA input format and special tokens are applied. Evaluation on the held-out test set identifies performance and error patterns.

- **Design tradeoffs:**
  - **Manual vs. Synthetic:** Manual annotations are high-quality gold but expensive; synthetic data scales but risks domain mismatch. The paper shows job-ad synthetic data harms performance, so domain-specific generation is crucial.
  - **Combined vs. Separate:** The CA improves overall F1 and recall but requires conservative labeling (both title and sentence must match). Separate models allow component-level diagnostics but yield lower performance.
  - **Special Tokens:** Adding tokens improves performance but increases input complexity and may require truncation management.
  - **Model Choice:** Domain-specific pretrained models (e.g., ESCOXLM-R) underperformed vs. generic BERT, suggesting potential overfitting or pretraining objective mismatch.

- **Failure signatures:**
  - High false negative rate on sentences with implicit skill mentions or broad interpretations.
  - Moderate inter-annotator agreement (Cohen’s κ ~0.45) indicates subjective labeling, potentially capping performance.
  - Performance drop when using out-of-domain synthetic data (e.g., job ads).
  - Sentence-only models show consistently lower recall (<80%), highlighting the title's disambiguation role.

- **First 3 experiments:**
  1. Train separate BERT models on title-skill and sentence-skill pairs to establish baseline performance; expect lower recall for sentence-only models.
  2. Implement the Combined Approach (CA) with labeled input format; measure gain in recall and F1 compared to separate models.
  3. Incorporate the domain-specific synthetic dataset into training while holding model and input format constant; quantify the 6–8% recall improvement and verify out-of-domain synthetic data fails.

## Open Questions the Paper Calls Out
- **Open Question 1:** How can the synthetic data generation process be systematically optimized to maximize its positive impact on model performance for the course-skill matching task?
  - *Basis:* The paper states future research should investigate variables in generating synthetic course descriptions and notes that job-ad synthetic data did not transfer well.
  - *Why unresolved:* No controlled ablation study on prompt variables (skill definition inclusion, implicit/explicit balance, negative example generation) exists.
  - *Resolving evidence:* A large-scale study comparing model performance across systematic prompt variations, linking specific characteristics to test-set improvements.

- **Open Question 2:** To what extent do the findings on the Combined Approach's effectiveness and the primary source of false negatives (sentence-level ambiguity) generalize beyond Finnish graduate-level IT/Business courses and the two ESCO occupation groups?
  - *Basis:* The limitations state the study focuses on a limited set of occupational groups and suggests examining generalizability to other occupations, study levels, and languages.
  - *Why unresolved:* Dataset is geographically (Finland), linguistically (English), and domain-specific (graduate, two occupation groups).
  - *Resolving evidence:* Replication studies on curricula from other countries, languages, and academic levels (e.g., undergraduate, vocational), measuring CA performance and error patterns.

- **Open Question 3:** How do specific characteristics of course descriptions (institution-specific jargon, section structure, length, verbosity) concretely impact the accuracy of skill-course matching models?
  - *Basis:* Error analysis points to sentence-level ambiguity and the authors speculate about institution-specific phrasing in limitations; dataset shows variance in sentence length.
  - *Why unresolved:* Errors are analyzed in aggregate; no feature-level correlation (e.g., lexical overlap, jargon, complexity) is measured.
  - *Resolving evidence:* Annotate false negatives/positives with features like vocabulary overlap, acronym density, sentence complexity, and description section type to identify problematic textual traits.

- **Open Question 4:** Can a validator model like the CA be effectively integrated into an end-to-end course recommendation or curriculum analysis pipeline, and does its "high performance" translate to practical utility and user trust?
  - *Basis:* The conclusion suggests evaluating the validator within a complete course recommendation pipeline and raises ethical concerns about communicating relevance.
  - *Why unresolved:* Evaluation is a binary classifier on a balanced test set; real-world systems require ranking, large candidate pools, and handling partial matches.
  - *Resolving evidence:* Build a retrieval prototype using the validator to re-rank candidates from a bi-encoder, evaluate on metrics like MRR or Precision@10, and conduct user studies with academic advisors.

- **Open Question 5:** How can the UniSkill framework be extended to handle the dynamic nature of skill taxonomies, specifically to incorporate emerging skills not yet in ESCO and capture temporal evolution?
  - *Basis:* Limitations note exploring emerging skills outside ESCO and the dataset spans 2019–2025 without temporal analysis.
  - *Why unresolved:* ESCO is static; rapidly evolving fields (e.g., AI) generate new skills, and the model cannot suggest out-of-taxonomy skills. No temporal alignment with market demand is modeled.
  - *Resolving evidence:* Develop methods for zero/few-shot matching to novel skills (e.g., via LLM-generated definitions) and create a temporal UniSkill version linking courses to historical job ads to analyze skill demand alignment over time.

## Limitations
- Exact GPT-4o prompts and similarity model thresholds (Pérez Amado 2025) are undocumented, blocking full synthetic data replication.
- Moderate inter-annotator agreement (Cohen’s κ ≈ 0.45) indicates subjective skill relevance labeling, potentially capping achievable model performance.
- The dataset is limited to Finnish graduate courses in two ESCO occupation groups; generalizability to other disciplines, education levels, languages, or skill taxonomies is unknown.

## Confidence
- **High confidence:** CA (title+sentence) improves recall. Evidence is consistent across internal experiments and the disambiguation rationale is sound.
- **Medium confidence:** Domain-specific synthetic data improves recall (6–8%). Gains are clear, but missing prompt details introduce replication risk and quality variability.
- **Low confidence:** Special input tokens provide a benefit. Supported only by internal ablations; no external validation, and effects may diminish with different architectures.

## Next Checks
1. **Synthetic data replication:** Regenerate the synthetic dataset using prompts (once released) and re-train the CA model. Performance should match the reported 6–8% recall gain over manual-only training.
2. **Title quality stress test:** Construct a test subset with generic or erroneous titles. Verify the CA model's recall degrades meaningfully versus a sentence-only model, confirming title context dependency.
3. **Cross-domain robustness:** Apply the best trained model to a held-out set from a different national curriculum (e.g., Course-Skill Atlas) or a disjoint ESCO skill group. Significant performance drop would indicate limited transferability.
