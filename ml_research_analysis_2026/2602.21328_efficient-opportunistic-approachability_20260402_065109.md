# Efficient Opportunistic Approachability
## Quick Facts
- **arXiv ID:** 2602.21328
- **Source URL:** https://arxiv.org/abs/2602.21328
- **Reference count:** 20
- **Primary result:** Efficient polynomial-time algorithms for opportunistic approachability with O(d_P^{1/2} T^{-1/4}) convergence for strict and ε-statistical variants, and optimal O(T^{-1/2}) when the adversary dimension d_L ≤ 2, avoiding high-dimensional calibration.

## Executive Summary
The paper tackles opportunistic approachability, a variant of Blackwell approachability where the learner aims to approach a smaller target set when the adversary is restricted to a convex set Q of actions. Prior solutions relied on high-dimensional online calibration, suffering from slow rates T^{-O(1/dL)} and exponential runtime. This work introduces an epoch-based framework that separates decision-making across two online learners: an outer learner selects direction vectors in payoff space, and an inner learner minimizes losses defined via a valid rule and a consistent target function. For strict opportunistic approachability (adversary confined to Q), the framework yields an efficient algorithm with rate O(d_P^{1/2} T^{-1/4}) and an inefficient variant achieving O(d_P^{1/3} T^{-1/3}). For the ε-statistical variant (where a (1-ε) fraction of adversary actions lie in Q), analogous rates with ε-dependent additive terms are obtained. Notably, for low adversary dimension (d_L ≤ 2), a simpler expanding set approach attains the optimal O(T^{-1/2}) rate efficiently. The paper also proves a lower bound confirming that the dimension dependence in the rates is unavoidable.

## Method Summary
The core contribution is an epoch-based decomposition that avoids high-dimensional calibration. The horizon T is split into L epochs. In each epoch e, the outer online convex optimization (OCO) learner picks a direction vector λ_e ∈ B^d(1) (the unit ball in payoff space). The inner OCO learner then interacts with the adversary for T_e steps, selecting actions p_t ∈ P (learner’s convex action set). The loss functions used by the inner learner are constructed from λ_e and the observed adversary actions ℓ_t. After the epoch, the algorithm computes a target payoff U(L_e) based on the average adversary action or a regularized mean (for the statistical case). The inner learner’s comparator is a best response to that target. Two families of loss rules are analyzed: a simple linear rule F(p)=⟨λ, u(p,ℓ_t)⟩, which yields the efficient O(d_P^{1/2} T^{-1/4}) rate under proper epoch scheduling; and monotonic/offset-max rules that control the path-length of the comparator, improving the rate to O(d_P^{1/3} T^{-1/3}) at the cost of additional computation (e.g., solving an LP for the statistical case). For the special case d_L ≤ 2, an expanding set method maintains the convex hull of past adversary actions, projects each new ℓ_t onto that hull, and uses a standard Blackwell approachability algorithm; this achieves the optimal O(T^{-1/2}) rate without calibration.

## Key Results
- **Strict opportunistic approachability:** Efficient algorithm with convergence rate O(d_P^{1/2} T^{-1/4}); an alternative (calibration-based) achieves O(d_P^{1/3} T^{-1/3}) but is inefficient.
- **ε-statistical opportunistic approachability:** Analogous efficient rate O(d_P^{1/2} T^{-1/4}) with additive term α(ε)=O((ε d_P)^{1/3}), and an inefficient O(d_P^{1/3} T^{-1/3}) with smaller α(ε).
- **Optimal rate for low adversary dimension:** When d_L ≤ 2, the expanding set method attains the optimal O(T^{-1/2}) rate efficiently, matching lower bounds for standard approachability.
- **Lower bound:** The dependence on d_P in the rates is inherent; no algorithm can achieve a rate independent of d_P.

## Why This Works (Mechanism)
The epoch-based framework sidesteps the need for high-dimensional calibration by decoupling the selection of payoff directions from action selection. The outer learner’s direction vectors λ_e explore the payoff space, while the inner learner minimizes linearized losses that correlate with distance to the target set. The key analytic insight is that the loss functions can be designed so that the comparator’s path-length (the cumulative variation of the best response across epochs) grows slowly. For the simple linear loss, the path-length is O(ε d_P T) leading to the T^{-1/4} rate after optimizing epoch lengths. The monotonic/offset-max rules further curtail the path-length by keeping the comparator within a shrinking neighbourhood of the ideal target, improving the rate to T^{-1/3}. For d_L ≤ 2, the expanding set method leverages the fact that the adversary’s restricted set Q can be approximated efficiently by the convex hull of past actions, enabling the use of standard Blackwell approachability with a dynamic target set that converges quickly.

## Architecture Onboarding
The implementation consists of two interacting online convex optimization modules and a bookkeeping unit for epochs and target computation.

**Component Map:**  
Outer Learner (OCO over B^d(1)) → selects λ_e → Inner Learner (OCO over P) → plays p_t using loss f_t(p)=F(p; λ_e, ℓ_t) → adversary observes ℓ_t (restricted to Q or ε-statistical) → Payoff u_t = u(p_t, ℓ_t) → After epoch e, compute target U(L_e) and update inner comparator p*(U(L_e)) → Outer updates λ_e based on losses defined by U(L_e) and inner’s average payoff → Repeat for L epochs → Final average ū_T → Compute distance to S(Q) or S(Q_ε^int).

**Critical Path:**  
1. Initialize outer and inner learners (e.g., OGD with learning rates).  
2. For epoch e = 1,…,L:  
   a. Outer outputs λ_e (e.g., via OGD update using past epoch feedback).  
   b. For each step t in epoch: inner learner receives ℓ_t, computes loss f_t(p)=⟨λ_e, u(p,ℓ_t)⟩ (or other rule), selects p_t, suffers loss.  
   c. After epoch, collect all ℓ_t in epoch; compute mean ¯ℓ_e or regularized mean ¯ℓ_e^* (statistical); set U(L_e)=u(p*(¯ℓ_e), ¯ℓ_e) or u(p*(¯ℓ_e^*), ¯ℓ_e^*).  
   d. Provide feedback to outer learner: e.g., loss vector λ_e·(ū_e - U(L_e)) or similar.  
3. After L epochs, aggregate all played actions to compute overall average payoff ū_T.  
4. Evaluate distance to the target set S(Q) (strict) or S(Q_ε^int) (statistical).

**Design Tradeoffs:**  
- **Loss rule choice:** Linear loss (⟨λ, u⟩) is simplest and efficient but gives O(T^{-1/4}); monotonic/offset-max rules yield faster O(T^{-1/3}) but require additional computation (e.g., solving an LP for α_e^* in statistical case).  
- **Epoch length schedule:** For linear loss, optimal L = ⌊√T/d_P⌋; for improved rates, L scales differently (e.g., L ~ (T/d_P)^{2/3}). Choosing L incorrectly can degrade rates.  
- **Isotropy assumption:** The analysis assumes P is isotropic (contains unit ball, inside ball of radius d_P). If not, learning rates must be adjusted based on the actual diameter, otherwise the stated O(d_P^{1/2} T^{-1/4}) bound may not hold.  
- **Inner oracle efficiency:** Projection onto P and computation of p*(ℓ) must be polynomial-time; otherwise overall runtime may exceed polynomial.  
- **d_L ≤ 2 special case:** The expanding set method is efficient and optimal but only works for d_L ≤ 2 because convex hull maintenance and projection are easy in low dimensions; it does not scale.

**Failure Signatures:**  
- Distance to target set decreases slower than expected (e.g., slope on log-log plot shallower than -1/4).  
- High variance in ū_T across runs suggests instability in inner learner’s learning rate or path-length blowup.  
- In statistical setting, if ε is too large (≥ 1/(d_P+1)), the Helly-based guarantee may fail; monitor if α(ε) behaves worse than O(ε^{1/3}).  
- If ℓ_t are not actually restricted to Q (strict) or the ε-fraction condition is violated, the target set S(Q) may be misspecified.  
- The inner learner’s comparator p*(U(L_e)) may not be well-defined if U(L_e) is outside the learner’s feasible range or if p* is not computed accurately.

## Limitations
- The efficient rates rely on polynomial-time oracles for computing p*(ℓ) and projecting onto P; for arbitrary convex sets these subroutines may be costly, potentially undermining the claimed polynomial runtime.  
- In the ε-statistical case, determining Q_ε^int or the weight vector α_e^* requires solving a linear program whose size grows with epoch length; moreover the guarantee requires ε < 1/(d_P+1) due to Helly’s theorem, which may be restrictive.  
- The convergence bounds assume the action set P is isotropic; if this condition is not met, learning rates must be adapted and the stated O(d_P^{1/2} T^{-1/4}) bound can degrade.

## Confidence

- **Strict efficient rate (Theorem 3.3):** Medium – proof is sound but depends on efficient oracles and isotropy.
