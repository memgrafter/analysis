# Adaptive Disentangled Representation Learning for Incomplete Multi-View Multi-Label Classification
## Quick Facts
- arXiv ID: 2601.05785
- Source URL: https://arxiv.org/abs/2601.05785
- Reference count: 40
- Primary result: ADRL consistently outperforms nine state-of-the-art competitors on six benchmark datasets across missing ratios from 30% to 90%, with ~15% AP improvement at 90% missing on Corel5k and ESPGame.

## Executive Summary
The paper tackles incomplete multi-view multi-label classification (iMvMLC), where both feature views and label annotations are simultaneously missing. Existing methods struggle under high sparsity. ADRL introduces three synergistic components: a mask attention-guided view completion mechanism that imputes missing views by propagating affinities across samples with neighborhood awareness and stochastic fragment masking for robustness; a mutual information-based disentanglement framework that separates shared and view-specific representations to enforce cross-view consistency while reducing redundancy; and a graph-based variational label representation module that propagates label co-occurrence information and generates pseudo-labels to guide adaptive view fusion. Extensive experiments on six datasets with missing ratios up to 90% show ADRL achieving superior performance across six standard metrics. Ablation studies validate the contribution of each module. The approach also generalizes to a real-world NBA player potential prediction task.

## Method Summary
ADRL consists of three main modules. First, missing views are completed using a mask attention mechanism: for each view, high-affinity neighbors are identified based on l2-normalized features; missing entries are reconstructed as a weighted average of neighbors’ features, followed by random fragment masking to enhance robustness. Second, a dual-channel encoder extracts shared and private representations for each view. These are sampled from Gaussian distributions and fused with earlier features using reciprocal variance weighting. Reconstruction decoders rebuild the original view features, providing a reconstruction loss. Mutual information losses encourage consistency among shared representations across views and suppress dependence of private representations on shared ones. Third, a graph attention network operates on a label co-occurrence matrix to refine learnable label prototypes, capturing uncertainty. For each view, label-specific features are derived by element-wise multiplication of prototype variances with the view representation, and linear classifiers produce pseudo-labels. A manifold consistency loss aligns feature similarity with pseudo-label similarity, and its value per view determines fusion weights. All views’ shared and private representations are weighted-averaged, then gated by the private variance and multiplied with the shared to form a final representation, which is classified. The total loss combines cross-entropy on known labels and pseudo-labels with reconstruction, disentanglement, and consistency terms.

## Key Results
- At 50% missing views and labels, ADRL achieves the best average ranking across six evaluation metrics (1-HL, 1-OE, 1-Cov, 1-RL, AP, AUC), with particularly large gains in AP and AUC.
- Under extreme incompleteness (90% missing), ADRL improves AP by approximately 15% on Corel5k and ESPGame compared to the strongest baselines.
- Ablation experiments confirm that all three modules (completion, disentanglement, label graph) are indispensable; removing any leads to significant performance drops.

## Why This Works (Mechanism)
ADRL’s strength lies in its coordinated handling of both view and label incompleteness. The masked attention completion leverages cross-view affinities to fill missing features with contextually appropriate samples, while stochastic fragment masking prevents over-reliance on any single region. The dual-channel disentanglement explicitly separates inter-view semantic information from view-specific idiosyncrasies via mutual information constraints, ensuring that shared representations remain consistent across views and private ones do not leak shared content. The graph-based label module enriches sparse label data by diffusing co-occurrence statistics through a learned prototype space, producing reliable pseudo-labels even when many labels are missing. These pseudo-labels, in turn, drive an adaptive fusion strategy that weights each view according to its compatibility with the label structure. The composite loss balances classification accuracy with representation quality, allowing ADRL to remain robust as missing rates increase.

## Foundational Learning
Several key concepts underpin ADRL:

- **Mask attention for imputation**: Uses attention over normalized features to find similar samples and reconstruct missing views. *Quick check*: For a held-out fully observed set, randomly mask a view and compute reconstruction MSE; should be low relative to simple imputation.
- **Disentangled variational representation**: Employs dual pathways to model shared and private factors as Gaussian variables, with reparameterization. *Quick check*: Train encoders on complete data, compute correlation between shared features across views (high) and between private features across views (low).
- **Mutual information estimation**: Uses a contrastive JSD estimator to bound MI between views. *Quick check*: With synthetic data where ground-truth MI is known, verify estimated MI correlates with true value.
- **Graph attention networks for labels**: Diffuses information over label co-occurrence graph to refine prototypes. *Quick check*: Visualize learned label embeddings; semantically related labels should cluster.
- **Adaptive view fusion**: Determines view contributions via inverse consistency loss. *Quick check*: Correlate fusion weights with individual view classification accuracies on a validation set.

## Architecture Onboarding
**Component map**: Input (multi-view features X^v, labels Y, missing indicators) → Completion module (reconstruction + fragment masking) → Dual-channel encoders (Shared Z_s^v, Private Z_p^v) → Decoders (reconstruction loss) → Mutual information loss (disentanglement) → Graph label module (GAT on Q → prototypes l_i) → Label-specific features (σ(l)·X^v) → Pseudo-label heads (U^v, V^v) → Manifold consistency loss L_gc^v → Fusion weights w_v=1/L_gc^v → Aggregated shared Z̄_s, private Z̄_p → Final fused Z = σ(Z̄_p)⊙Z̄_s → Linear classifier → Predictions P.

**Critical path**: For each training iteration:
1. Complete missing views using mask-attention imputation.
2. Encode each completed view to obtain distributions for shared and private latents.
3. Sample latents and compute reconstruction loss.
4. Compute MI loss by contrasting representations across views (for shared) and penalizing private MI (for private).
5. Build/co-occurrence matrix Q from batch; run GAT to get label prototypes.
6. Generate pseudo-labels per view, calculate L_gc.
7. Compute view weights, aggregate representations, fuse, classify, and compute classification losses (on known labels and pseudo-labels).
8. Sum losses and backpropagate.

**Design tradeoffs**:
- Completion accuracy vs. over-smoothing: Stronger attention yields coherent reconstructions but may lose discriminative details; stochastic masking mitigates overfitting.
- Disentanglement strength: MI weight β trades off shared-consistency vs. private retention; too high β may discard useful private cues.
- Fusion weight computation: Simple inverse of L_gc is intuitive but susceptible to outliers; could use a softmax with temperature for smoother distribution.
- Static label graph: Using a fixed co-occurrence matrix simplifies training but cannot capture label dynamics; an online update could help streaming settings.
- Loss balancing: Hyperparameters α, λ1, λ2 need careful tuning per dataset; an adaptive weighting scheme might reduce search effort.

**Failure signatures**:
- Reconstruction error skyrockets on validation: Indicates ineffective attention or too aggressive fragment masking; check attention threshold τ and masking length.
- MI loss saturates at zero without gradient: Contrastive estimator may be too weak; increase negative samples or temperature, verify network capacity.
- Private representations correlate with shared ones: Disentanglement insufficient; increase β or add adversarial loss.
- Label prototypes collapse to near-identical vectors: GAT oversmooths; add dropout, residual connections, or increase number of heads.
- Fusion weights concentrate on a single view: Might be due to some view providing consistently low L_gc; check for bugs in weight computation or consider temperature scaling.
- Training unstable (loss spikes): Unbalanced loss terms; try gradient clipping or normalize each loss term by a moving average.

**First experiments**:
1. **Reconstruction sanity**: On a small fully-observed dataset, randomly hide 30% of a view, run the completion module, and compute MSE between imputed and original features. Compare against a k-NN baseline; ADRL should perform similarly or better.
2. **Disentanglement check**: After partial training, compute average cosine similarity of shared features between two views (should be high >0.7) and of private features (should be low <0.3). Tune β if private similarity is too high.
3. **Fusion weight sanity**: Run validation with a fixed missing pattern; record w_v for each view. Expect weights >0 for all views (unless a view is entirely missing) and to reflect each view’s discriminative power. Plot weight distribution.

## Open Questions the Paper Calls Out
1. **Integration of large language models**: The paper explicitly mentions future work to incorporate LLM prior knowledge for representation extraction and label semantic understanding, but provides no implementation or results.
2. **Sensitivity to non-Gaussian assumptions**: ADRL’s variational formulation assumes Gaussian posteriors for shared/private representations. Its robustness to non-Gaussian data characteristics is not investigated.
3. **Dynamic label correlation**: The static label co-occurrence matrix may not adapt to drifting label relationships in streaming settings; an online update mechanism is an open direction.

## Limitations
- **Incomplete specification**: Exact architecture details (layer sizes, activations, attention temperature, affinity threshold, fragment length, top‑k, GAT heads, contrastive estimator setup) are missing, hindering faithful replication.
- **Hyperparameter ranges only**: Only broad ranges for loss weights (α, λ₁, λ₂) are provided; dataset‑specific optimal values require exhaustive search.
- **Static assumptions and instability**: The label correlation graph is fixed, which may limit adaptation to dynamic environments; the interplay of multiple modules could cause noise amplification, contrastive collapse, or loss imbalance, especially under high missing rates.
