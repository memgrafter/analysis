# PAct: Part-Decomposed Single-View Articulated Object Generation

## Quick Facts
- **arXiv ID:** 2602.14965
- **Source URL:** https://arxiv.org/abs/2602.14965
- **Reference count:** 40
- **Primary result:** PAct generates articulated 3D objects from a single image with superior part accuracy (RS-dCD ↓ 0.0016 vs. 0.0040) and articulation plausibility (AOR ↓ 0.0011 vs. 0.0097), while maintaining fast inference (~15 s/object).

## Executive Summary
PAct introduces a part-centric generative framework for creating high-fidelity articulated 3D objects from a single RGB image. It extends the TRELLIS latent diffusion model by modifying its transformer to generate part-decomposed sparse structures. The method operates in two stages: first, a part-aware flow model produces coarse part geometries under guidance from a 2D part mask; second, a sparse transformer refines each part's detailed geometry and appearance, while a lightweight articulation module predicts joint parameters by aggregating features across multiple denoising steps. Experiments on PartNet-Mobility and ACD datasets demonstrate significant improvements over retrieval and optimization baselines in part accuracy, articulation plausibility, and visual consistency, with robust performance even when using automatically generated masks.

## Method Summary
PAct fine-tunes the pretrained TRELLIS model through two specialized stages. Stage 1 adapts TRELLIS’s denoising transformer by interleaving global self-attention (across all tokens) and within-part local attention (restricted to tokens sharing a part identity), and by adding learnable part-identity embeddings. This part-aware flow model generates a set of part-level sparse structure latents conditioned on the input image and an optional 2D part mask. Stage 2 takes the coarse part voxels derived from Stage 1, flattens them into tokens with shared part embeddings, and runs a structured latent transformer to refine geometry and appearance via flow matching. In parallel, the articulation module caches intermediate features from the last 20 denoising steps, pools per-part representations, and regresses joint type, axis, pivot, and motion range with a small MLP. The final output is a set of textured part meshes plus articulation parameters, forming a ready-to-use articulated object.

## Key Results
- **Part accuracy:** PAct achieves a resting-state chamfer distance (RS-dCD) of 0.0016, substantially lower than the best baseline (0.0040).
- **Articulation plausibility:** It yields an articulated-state occupancy ratio (AOR) error of 0.0011, far below the previous best of 0.0097.
- **Visual consistency:** CLIP similarity reaches 0.9053, outperforming baselines (e.g., 0.8779). Inference runs in approximately 15 seconds per object.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Enforcing within-part self-attention while preserving global cross-part attention allows coherent part geometries without merging distinct parts.
- **Mechanism:** The transformer layers are split: even-indexed layers perform standard global attention over all tokens to model inter-part relationships. Odd-indexed layers restrict self-attention to tokens belonging to the same part (using a part membership mask), allowing each part's latent code to be refined independently. Part-identity embeddings are concatenated to each part's latent token to maintain semantic distinctness.
- **Core assumption:** The pretrained TRELLIS model already encodes strong priors for coherent object-level geometry; by repurposing some layers for local part refinement, the model can adapt these priors to a part-decomposed representation without losing object-level coherence.
- **Evidence anchors:** Abstract mentions augmenting transformer with within-part local attention and part-identity embeddings. Section 4.2, Paragraph 3 describes repurposing attention layers. Ablations in neighbor papers (OmniPart, PartCrafter) support part-aware conditioning but not the specific layer interleaving.
- **Break condition:** May fail for ambiguous decompositions or physically interlocked parts (e.g., a drawer inside a closed cabinet) where strict local attention could hinder necessary cross-part geometric coordination.

### Mechanism 2
- **Claim:** Aggregating hidden features from multiple denoising timesteps yields a more robust representation for articulation parameter regression than using a single timestep.
- **Mechanism:** During Stage 2 denoising, the model caches output token features from the final transformer block at a selected set of timesteps (e.g., last 20 steps). For each part, these multi-step features are averaged across timesteps and then pooled (mean/max) over the token dimension to produce a fixed-size part vector. A lightweight MLP regresses joint parameters (type, axis, pivot, range) from this fused vector.
- **Core assumption:** Features at different diffusion timesteps capture complementary information—early steps contain coarser structural patterns, later steps focus on finer details and global context. Fusing them averages out noise and enriches the representation for the downstream articulation task.
- **Evidence anchors:** Abstract states the articulation module aggregates features from multiple steps. Section 4.3.2 explains the aggregation inspired by Diffusion Hyperfeatures. Ablation Table 3 shows consistent error reduction when increasing S (aggregated steps) from 1 to 20.
- **Break condition:** Benefit diminishes if selected timesteps are uninformative (e.g., only very early or very late). Adds small memory overhead for caching, which could strain resources for objects with many parts.

### Mechanism 3
- **Claim:** Conditioning on a 2D part mask enables controllable, instance-specific part decomposition, resolving ambiguity in movable part identification from a single image.
- **Mechanism:** The input image is processed by a frozen DINOv2 encoder. A 2D part mask assigns a discrete part index to each pixel. These indices are converted into a dense embedding map using the same learnable part-identity embedding matrix used in Stage 1. The embedding map is downsampled and added to the image features, which are then fed into the cross-attention layers as conditioning signals. This explicitly guides the model to activate the correct part-identity tokens and generate corresponding part latents.
- **Core assumption:** A 2D part mask provides a sufficient spatial prior to disambiguate part segmentation in 3D generation. The model can align its 3D part tokens to the 2D segmentation via the shared part-identity embedding space.
- **Evidence anchors:** Abstract mentions conditioning on a 2D part mask for controllable decomposition. Section 4.2, Paragraph 4 details the mask embedding and conditioning. Section 5.2 shows performance remains comparable with VLM-predicted masks vs. GT masks, indicating robustness. Figure 8 qualitatively demonstrates that different masks yield different decompositions.
- **Break condition:** Fails if the mask is severely incorrect (major parts missing, wrong semantics) or if the VLM+SAM pipeline produces a fragmented mask; parts may not correspond to true movable components.

## Foundational Learning
- **Structured Latent Representations for 3D Generation** (e.g., TRELLIS’s sparse structure latent Z and sparse latent attention tokens). *Why needed:* PAct directly fine-tunes TRELLIS’s two-stage latent diffusion framework. Understanding how a 3D object is encoded as a set of sparse voxels/features and decoded is essential to grasp how part-level latents are substituted and manipulated. *Quick check:* How does TRELLIS encode a 64³ occupancy grid into a 16³ latent tensor, and why is a rectified flow model trained on this latent space?

- **Part-Aware Neural Architectures** (part-identity embeddings, within-part attention masking). *Why needed:* PAct’s core innovation is modifying a monolithic object generator to handle multiple parts. This requires understanding how to inject part semantics (embeddings) and constrain attention flows (masking) within a transformer. *Quick check:* What is the difference between global attention and within-part local attention in the repurposed transformer layers, and how does concatenating part-identity embeddings help?

- **Articulation Parameterization for Kinematic Trees** (joint type τ, origin o, axis u, range ρ, parent q, semantic label s). *Why needed:* The output goal is a physics-ready articulated object. The loss function (ℓ²) and evaluation metrics depend on regressing this specific parameter vector. Understanding this representation is key to interpreting the articulation module’s design. *Quick check:* Under the paper’s depth-1 tree assumption, how is the parent-child relationship (qᵢ) determined after semantic part labeling, and why are fixed-joint sub-components collapsed into their parents?

- **Conditional Image-to-3D Generation** (using DINOv2 features, cross-attention). *Why needed:* PAct conditions on an RGB image and optionally a 2D mask; this relies on aligning 2D visual features to 3D latents via cross-attention. *Quick check:* How does the model combine DINOv2 features with the part mask embedding to guide the diffusion process?

- **Rectified Flow Matching for Diffusion** (flow-matching loss, CFG). *Why needed:* Both stages are trained with flow-matching objectives, a variant of diffusion. *Quick check:* What is the difference between standard diffusion and rectified flow, and why might flow-matching improve sample quality?

### Critical path
1. Process image with DINOv2 to obtain visual features.

### Design tradeoffs
- *Fixed depth-1 tree vs. general graphs:* The model assumes all movable parts attach directly to a root "base" part. This simplifies the articulation head and matches most domestic objects but fails for complex mechanisms like parallel linkages or closed chains.
- *Deterministic regression vs. generative articulation:* A simple MLP regression from fused features was chosen over a flow-matching predictor for stability and efficiency, sacrificing potential diversity for accuracy.
- *Stage1 local attention granularity:* The ratio of global to local layers (even/odd) is heuristic; more local layers could improve part separation but might harm global coherence.

### Failure signatures
- **Part merging/splitting:** Insufficient within-part attention leads to distinct parts bleeding together; too strong attention fragments a single semantic part.
- **Articulation implausibility:** Predicted axes not aligned with part geometry (e.g., a drawer sliding sideways) or motion ranges causing self-collision (high AOR).
- **Mask sensitivity:** Large drop in CLIP similarity or part accuracy when using VLM+SAM masks vs. GT masks indicates overfitting to perfect segmentations.
- **Scalability limit:** Performance degrades for objects with >8 parts, likely due to fixed part-embedding matrix size and dataset bias.

### First 3 experiments
1. *Isolate Stage1 output quality:* Render coarse part voxels from Stage1 (before Stage2) using GT masks. Evaluate part separation via dgIoU between part AABBs to confirm distinct, correctly placed parts.
2. *Validate multi-step feature aggregation:* Train ablation models with S=1, 5, 20 aggregated steps. Compare articulation prediction ℓ² loss and final AOR/CLIP to confirm hyperfeature contribution.
3. *Test mask controllability:* For a fixed image, generate with (a) GT mask, (b) a mask merging two true parts, (c) a mask splitting one true part. Measure changes in part count, dCD, and conduct a user study on plausibility to bound controllability.

## Open Questions the Paper Calls Out
- **Scaling to many-part objects:** How can PAct handle articulated objects with a large number of parts? Current benchmarks contain few hinge-based objects with many parts, and the part-centric transformer may not efficiently handle long part sequences.
- **Inferring occluded or state-dependent parts:** How can PAct reliably infer parts that are occluded or only visible in specific articulation states? The single-image setting provides incomplete observations; the model lacks mechanisms for reasoning about hidden or state-dependent components.
- **Extending beyond shallow trees:** Can PAct’s kinematic modeling be extended beyond depth-1 tree structures to handle closed-chain mechanisms or shared constraints? Closed-chain loops violate the tree assumption and require constraint satisfaction.

## Limitations
- Performance degrades for objects with more than eight parts due to dataset bias and model capacity constraints.
- Full reproduction requires TRELLIS pretrained checkpoints, which are not released, and a GPT-5 VLM for automatic mask generation, which is unavailable.
- The model assumes a fixed depth-1 kinematic tree, failing for complex mechanisms like closed chains or shared constraints.

## Confidence
- **Part decomposition via interleaved attention:** Low. No direct ablation isolating the layer-splitting; evidence relies on conceptual reasoning and neighbor papers.
- **Multi-step feature aggregation for articulation:** High. Ablation (S=1→20) shows consistent error reduction (AS-cDist ↓ 0.0966→0.0653).
- **Mask-based controllability:** Medium. Robustness to VLM+SAM masks shown, but GPT-5 specifics are opaque; no stress-test on severely fragmented masks.
- **Overall superiority over baselines:** High. Comprehensive quantitative and qualitative results on two datasets support claims.
- **Generalization to unseen object categories:** Medium. Evaluated on standard splits; however, dataset bias toward common household objects may limit broader applicability.
