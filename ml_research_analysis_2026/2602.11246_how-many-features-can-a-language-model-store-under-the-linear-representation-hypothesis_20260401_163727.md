# How Many Features Can a Language Model Store Under the Linear Representation Hypothesis?

## Quick Facts
- **arXiv ID:** 2602.11246
- **Source URL:** https://arxiv.org/abs/2602.11246
- **Reference Count:** 8
- **Primary Result:** Under the linear representation hypothesis with linear accessibility, storing m k‑sparse features requires d = Ω((k²/log k) log(m/k)) and d = O(k² log m), showing a quadratic gap from classical compressed sensing; superposition (exponential m) is possible but with a higher dimensionality cost.

## Executive Summary
The paper studies the Linear Representation Hypothesis (LRH), distinguishing between linear representation (features embedded linearly) and linear accessibility (features recoverable via linear probes). It asks: how many neurons d are needed to store and linearly decode m features, assuming inputs are k‑sparse? Classical compressed sensing (non-linear decoding) needs d = O(k log(m/k)), but imposing linear accessibility raises the requirement to d = Θ(k² log(m/k)), showing a strict quadratic penalty in k. The upper bound uses random incoherent matrices to keep interference low; the lower bound combines Alon’s rank theorem and Turán’s graph theorem to prove that if d is smaller, some row of BᵀA must have many large off‑diagonal entries, causing a recovery error on a carefully chosen input. These nearly matching bounds confirm that superposition—storing an exponential number of features—is possible under LRH, but at a higher dimensionality cost than previously believed. Extensions to binary features and activation‑based probes are also analyzed.

## Method Summary
The authors formalize LRH as a pair of matrices (A, B) where A encodes features into d‑dimensional activations f = A z and B decodes via Bᵀ f. The objective is to minimize d such that ∥Bᵀ A z − z∥_∞ < ε holds for all k‑sparse z ∈ [-1,1]^m. The upper bound constructs A = B as a random ±1/√d matrix; with d = O(k² log m) this yields a µ‑incoherent matrix (|⟨a_i, a_j⟩| ≤ µ) with µ = ε/k, which bounds interference by kµ = ε. The lower bound assumes a solution exists with d < Ω(k² log(m/k)/log k). Analyzing M = Bᵀ A, they show that if rank(M) ≤ d, then many r×r submatrices of M must contain a large entry; applying Turán’s theorem forces a row with ≥2k entries > ε/k, which combined with a specific k‑sparse z violates the error guarantee. The proof accommodates general A ≠ B and extends to binary features and probes with activation functions.

## Key Results
- d = O(k² log m) neurons suffice for linear accessibility of k‑sparse features.
- d = Ω((k² / log k) log(m/k)) neurons are necessary.
- The quadratic factor in k demonstrates that linear accessibility is strictly stronger than linear representation; superposition (m ≫ d) remains possible but requires higher dimension.

## Why This Works (Mechanism)
The core mechanism is the separation of LRH into representation and accessibility. Under representation alone, classical compressed sensing (non‑linear decoding) achieves d = O(k log(m/k)). Adding linear accessibility forces Bᵀ A to approximate the identity on all k‑sparse inputs, which imposes that off‑diagonal entries |⟨b_i, a_j⟩| must be < ε/k to limit interference from at most k active features. An upper bound is obtained by constructing A (and B = A) as a random matrix with small pairwise inner products (µ‑incoherence). Setting d large enough ensures µ ≈ ε/k, giving the O(k² log m) bound. The lower bound shows that if d is smaller than roughly k² log(m/k)/log k, then the rank of Bᵀ A is too low to avoid having a row with many large off‑diagonals; by Turán’s theorem, some row must have at least 2k entries exceeding ε/k, which yields a counterexample sparse z causing error > ε. This quadratic penalty in k is thus inherent. The results extend to binary features and activation‑based decoders, confirming the theoretical possibility of superposition albeit with a higher cost.

## Foundational Learning
**Concept: Compressed Sensing (Classical vs. Linear)**  
**Why needed:** To contrast the standard non‑linear recovery setting (ℓ₁‑minimization) with the linear recovery required here, clarifying the source of the quadratic gap.  
**Quick check:** What algorithm enables exact reconstruction of k‑sparse signals from O(k log(m/k)) measurements in classical compressed sensing?

**Concept: Matrix Incoherence and Random Embeddings**  
**Why needed:** Random incoherent matrices ensure that the inner products between distinct columns are uniformly small, directly bounding interference in linear recovery.  
**Quick check:** Why does a µ‑incoherent matrix guarantee ∥Aᵀ A z − z∥_∞ ≤ k µ for any k‑sparse z?

**Concept: Turán’s Theorem (Extremal Graph Theory)**  
**Why needed:** Used to convert a combinatorial condition about interfering pairs into a lower bound on the total number of interferences, which via pigeonhole forces a row with many large off‑diagonals in Bᵀ A.  
**Quick check:** What does Turán’s theorem bound, and how does it relate to the absence of large independent sets?

## Architecture Onboarding
**Component map:**  
Sparse feature vector z → Encoder matrix A → Activations f = A z → Decoder matrix Bᵀ → Reconstructed features ẑ = Bᵀ f.

**Critical path:**  
1. Formalize LRH as the pair (A, B) with constraint ∥Bᵀ A z − z∥_∞ < ε for all k‑sparse z.  
2. Upper bound: choose A = B as a random µ‑incoherent matrix with µ = ε/k; this requires d = O(k² log m).  
3. Lower bound: assume d < Ω(k² log(m/k)/log k); then via Alon’s rank bound on submatrices of M = Bᵀ A and Turán’s theorem, construct a sparse z that violates the constraint.

**Design tradeoffs:**  
- *A = B vs A ≠ B:* Using A = B simplifies and aligns with sparse autoencoders, but allowing A ≠ B offers slight capacity gains and exotic geometries.  
- *Norm constraints:* Unbounded column norms can ease matrix construction but are less realistic; imposing norm bounds (e.g., ∥a_i∥, ∥b_i∥ ≤ γ) typically increases required d.  
- *Sparsity k:* The required d scales quadratically with k, meaning that as sparsity grows, the cost of superposition rises sharply; for small k the cost is more favorable.

**Failure signatures:**  
- **Interference spikes:** For some i and a support of size k, many |⟨b_i, a_j⟩| exceed ε/k, causing recovery error > ε.  
- **Insufficient rank:** If rank(Bᵀ A) ≤ d is too low, Alon + Turán force a row with ≥2k large off‑diagonals, leading to a counterexample.  
- **Dense inputs:** When inputs have more than k active features, the interference bound becomes (actual sparsity)·µ, breaking recovery unless d is increased accordingly.

**First 3 experiments:**  
1. *Validate upper bound:* For chosen d = c·k²·log m, generate random A ∈ ℝ^{d×m} with i.i.d. ±1/√d entries, set B = A, and test recovery error on many random k‑sparse z ∈ [-1,1]^m. Confirm error < ε for sufficiently large c.  
2. *Test Proposition 9 geometry:* Construct a highly incoherent base matrix C ∈ ℝ^{d×(m+2)}; set a_i = c_i + λ a*, b_i = c_i + λ b* with λ = √(1/δ−1). Verify that ⟨a_i/∥a_i∥, b_i/∥b_i∥⟩ is small while ⟨a_i/∥a_i∥, a_j/∥a_j∥⟩ ≈ 1 for i≠j, and that ∥Bᵀ A z − z∥_∞ < ε holds.  
3. *Empirical scaling:* Fix ε, vary k and m, find the minimal d such that a random A (with B=A) achieves recovery error < ε on a test set. Check whether d scales as approximately k² log m.

## Limitations
- Asymptotic bounds consider worst‑case k‑sparse inputs; structured sparsity may require fewer neurons in practice.  
- The lower bound holds only for ε > k^{3/2}/√(5m) and k < √m, leaving small‑ε and high‑density regimes unexplored.  
- Existential constructions (random matrices) may not be realizable with standard training or with bounded‑norm constraints, limiting practical applicability.
