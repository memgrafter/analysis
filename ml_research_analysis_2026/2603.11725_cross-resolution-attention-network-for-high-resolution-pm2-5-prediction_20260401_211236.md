# Cross-Resolution Attention Network for High-Resolution PM2.5 Prediction

## Quick Facts
- **arXiv ID:** 2603.11725
- **Source URL:** https://arxiv.org/abs/2603.11725
- **Reference count:** 40
- **Primary result:** A dual-branch Vision Transformer fuses global 25 km meteorology with local 1 km PM2.5 tiles via cross-resolution attention and physics-informed biases, reducing 72-hour RMSE by 10.7% vs. single-resolution baselines and cutting terrain-induced bias by 36% while generating a continental map in 1.8 seconds.

## Executive Summary
CRAN-PM tackles the computational intractability of applying standard Vision Transformers to continent-scale, 1 km PM2.5 forecasting. It introduces a dual-branch architecture that separately processes global 25 km meteorological data and local 1 km PM2.5 tiles, then fuses them through cross-resolution attention where local tokens query a cached set of global tokens. This design efficiently incorporates long-range atmospheric drivers without the quadratic memory cost of full-resolution self-attention. The model further integrates physics-informed biases—elevation-aware attention and wind-guided cross-attention—as soft constraints to encode topographic and advective transport processes. Evaluated on 2,971 European stations across 362 days in 2022, CRAN-PM achieves significant improvements in predictive accuracy and bias reduction while maintaining high inference speed.

## Method Summary
The model uses two separate input streams: a global branch ingests 70 channels of ERA5 and CAMS data at 25 km resolution, and a local branch processes 5-channel GHAP PM2.5 tiles at 1 km resolution (512×512). The global branch encodes the full domain into 735 tokens, which are cached per day. The local branch processes each tile (1,024 tokens) independently. Fusion occurs via two layers of cross-resolution attention, where local tokens attend to the global tokens, augmented with wind-guided bias to align attention with advection pathways. A decoder upsamples the fused local features to 1 km resolution, and the final prediction is a residual (`Δ`) added to the input day's PM2.5. Physics-informed biases are embedded directly into the attention logits: an elevation-aware penalty discourages uphill attention, and a wind-guided bias encourages downwind attention. The model is trained with a combined loss (pixel MSE, feature fidelity, station-level loss) using AdamW on 64 GPUs for 30 epochs, with strategic sampling of high-pollution tiles.

## Key Results
- Reduces RMSE by 4.7% at T+1 (24h) and 10.7% at T+3 (72h) versus the best single-resolution baseline.
- Cuts terrain-induced prediction bias by 36% in complex topography.
- Generates a full 29-million-pixel European map in 1.8 seconds on a single GPU.

## Why This Works (Mechanism)

### Cross-Resolution Attention for Efficient Multi-Scale Fusion
The dual-branch architecture processes global and local data separately to avoid the O(n²) memory cost of naive self-attention over all 1 km pixels. The global branch compresses the full-domain 25 km data into a small token set (735), while the local branch handles high-resolution tiles (1,024 tokens each). During cross-attention, local tokens query the cached global tokens, allowing each tile to incorporate large-scale meteorological context with a manageable attention matrix (1,024 × 735 per head). This relies on the physical assumption that local PM2.5 evolution is primarily driven by global atmospheric forcings (e.g., synoptic weather) that can be captured at 25 km, and that this influence is unidirectional (global → local). Evidence includes memory efficiency claims and ablations showing cross-attention outperforms feature addition. A break condition would be if local feedbacks to the global scale or loss of large-scale patterns during global encoding became significant.

### Elevation-Aware Attention Bias for Topography
An asymmetric additive bias `B_elev = -α·ReLU((E_j - E_i)/E0)` is applied to attention logits, penalizing attention from a lower-elevation token (`E_i`) toward a higher-elevation source (`E_j`). This encodes the physical prior that downslope (katabatic) flows are more relevant for local pollutant accumulation than upslope flows in complex terrain. The bias is a soft constraint, not a hard rule, allowing the model to learn exceptions. Direct evidence is the 36% terrain bias reduction reported and the +0.17 RMSE degradation when the bias is ablated. This mechanism could fail in well-mixed boundary layer conditions (neutral stability) where upslope transport is valid, potentially suppressing correct signals.

### Wind-Guided Biases for Advection Alignment
Two components align token processing with wind-driven transport: (1) *Wind-guided shuffling* reorders the global branch's 7×7 patch groups upwind-to-downwind according to ERA5 wind direction, scanning order that matches probable advection paths. (2) *Wind-guided cross-attention bias* adds `B_wind = β·γ_ij` to logits, where `γ_ij` is the cosine similarity between the patch displacement vector and local wind, encouraging attention to downwind sources. These biases assume advection is the dominant large-scale transport mechanism. Evidence includes a +0.14 RMSE increase when both are removed and improved capture of biomass burning plumes and winter smog events. Limitations arise if transport is dominated by non-advective processes (e.g., turbulent diffusion, urban recirculation), where wind direction misaligns with actual source-receptor relationships.

## Foundational Learning
- **Vision Transformer (ViT) scalability limits:** Standard self-attention has O(n²) memory complexity, making continent-scale 1 km prediction (~115,000 tokens) intractable (~300 GB VRAM). CRAN-PM’s cross-resolution attention reduces this by limiting one attention dimension to the small global token set.

- **Dual-branch / multi-scale feature fusion:** CRAN-PM’s cross-resolution attention (fine tokens query coarse tokens) differs fundamentally from simple concatenation of multi-scale features followed by self-attention, which would still incur high memory costs if all tokens attend to all others.
  - *Quick check:* How does cross-resolution attention (fine queries, coarse keys/values) differ fundamentally from a simple concatenation of multi-scale features followed by self-attention?
- **Physics-guided deep learning (soft constraints):** The elevation and wind biases are baked into the attention mechanism as inductive biases, unlike typical PINNs that add auxiliary physics-based loss terms. This integrates domain knowledge directly into the computation graph.
  - *Quick check:* What is the key difference between adding a physical loss term (e.g., PDE residual) and adding a physical bias directly into the attention logits?

## Architecture Onboarding
**Component map:**  
Global Input (70 channels, 25 km) → Global Branch (Unfold → Linear → Wind Shuffle → ElevationAttn → Swin ×7 → Wind Unshuffle) → Cached Z_global (735×768)  
Local Input (5 channels, 1 km tile) → Local Branch (Unfold → Linear + Lead-time Embed → ElevationAttn → Swin ×5) → Z_local (1,024×512)  
Cross-Resolution Bridge (CrossAttn ×2 with Wind Bias, Q=Z_local, KV=Z_global) → Fused Z_local  
Decoder (Reshape → 4× PixelShuffle Upsample → Zero-init 1×1 Conv) → Residual Δ  
Output: y_pred = x_local,0 + Δ  

**Critical path:** Per-day: compute Z_global once and cache. Per-tile: process Local Branch → Cross-Attention → Decoder → add to input. The global branch is reused across all 126 overlapping tiles.

**Design tradeoffs:**  
- *Memory vs. Resolution:* Tiling enables 1 km prediction but risks boundary artifacts (mitigated by 64 px overlap and cosine blending).  
- *Global Context vs. Local Detail:* Cross-attention with fine queries is chosen over coarse queries based on the physical asymmetry that local PM2.5 is driven by global meteorology.  
- *Physical Priors vs. Flexibility:* Hard-coded biases reduce parameters and improve interpretability but may constrain learning in atypical regimes (e.g., India OOD).  
- *Training Cost:* Dual-branch with caching reduces but does not eliminate cost; still requires ~860 GPU-hours on 64 GPUs.

**Failure signatures:**  
- Memory overflow: likely from incorrect tile count/overlap or recomputing Z_global per tile instead of caching.  
- Poor performance in complex terrain despite elevation bias: could be inaccurate elevation data or an insufficient bias function for non-katabatic flows.  
- Systematic OOD bias (e.g., India underestimation): suggests memorization of European emission patterns.  
- Tile boundary seams: if cosine blending is misapplied or overlap insufficient.

**First 3 experiments:**  
1. **Single-tile inference:** Process one 512×512 tile with cached Z_global. Verify output shape, memory <2 GB, runtime ~14 ms/tile, and spatial coherence of Δ.  
2. **Ablation of cross-resolution attention:** Replace cross-attention with feature addition. Expect RMSE degradation (~+0.07) confirming fusion necessity.  
3. **Zero-shot OOD test:** Run Europe-trained model on USA/Canada (Supplementary S2). Check scatter slope (~1.02) and identify regime-specific biases.

## Limitations
- Unknown tile sampling strategy beyond "hotspot ratio 0.5" (how non-hotspots are chosen) may affect exposure to diverse conditions.
- Wind-guided shuffling implementation detail (global vs. per-tile reordering) is unspecified and could alter performance.
- Model shows systematic underestimation in high-pollution OOD regions (e.g., India), indicating learned European emission priors limit transferability.
- Elevation-aware `ReLU` penalty may suppress valid upslope transport under neutral stability conditions.

## Confidence
- **Cross-resolution attention mechanism:** Medium (strong ablations and memory evidence, but unidirectional global→local assumption is a potential break condition).
- **Elevation-aware attention bias:** High (directly linked to 36% terrain bias reduction and consistent RMSE degradation in ablations).
- **Wind-guided biases:** Medium (ablation shows +0.14 RMSE degradation and captures advection events, but OOD gaps suggest potential overfit to European wind-pollutant relationships).

## Next Checks
1. **Reconstruct training tile sampling:** Implement the exact "hotspot ratio 0.5" policy and vary non-hotspot selection (random vs. stratified). Compare validation RMSE on complex terrain and diverse land-cover strata to resolve Unknown 1.
2. **Validate wind shuffling implementation:** Create two variants: (a) global reordering once per day, (b) per-tile reordering. Run inference on 10 test days with fixed seeds; compare pixel-level predictions and attention maps to detect significant differences (>0.5% RMSE shift).
3. **Benchmark per-tile memory footprint:** Measure GPU memory (MiB) for a single tile pass with cached global tokens. The claim is <2,048 MiB; a measured value >2,200 MiB indicates implementation discrepancy (e.g., incorrect token count or global branch recomputation).
