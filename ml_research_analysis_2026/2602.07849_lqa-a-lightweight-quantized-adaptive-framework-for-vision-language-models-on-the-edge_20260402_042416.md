# LQA: A Lightweight Quantized-Adaptive Framework for Vision-Language Models on the Edge

## Quick Facts
- **arXiv ID:** 2602.07849
- **Source URL:** https://arxiv.org/abs/2602.07849
- **Reference count:** 39
- **Primary result:** LQA improves average accuracy by 4.5 percentage points over state-of-the-art test-time adaptation methods while reducing memory to 196.73 MB and latency to 26.04 ms; a 4-bit variant (LQA-Lite) further cuts memory to 139.63 MB with minimal accuracy loss.

## Executive Summary
Deploying vision-language models like CLIP on edge devices is challenging due to tight memory and latency constraints, and standard test-time adaptation (TTA) methods are computationally prohibitive on-device. LQA proposes a two-part framework: (1) Selective Hybrid Quantization (SHQ) applies modality-aware low-bit quantization (4-bit vision encoder, 8-bit text encoder) while preserving a small set of critical layers in full precision; (2) Quantized Test-Time Adaptation (Q-TTA) uses a gradient-free, cache-based mechanism that operates entirely in low precision, eliminating backpropagation costs. Evaluated on diverse shifted datasets, LQA achieves significant accuracy gains over prior TTA while drastically lowering resource use, enabling robust, privacy-preserving VLM deployment on edge hardware.

## Method Summary
LQA combines a data-free quantization scheme with a lightweight adaptation phase. SHQ quantizes the CLIP backbone asymmetrically: the vision encoder uses Hessian-aware 4-bit quantization (with group-wise scaling) to capture spatial details, while the text encoder uses symmetric 8-bit quantization to preserve token embeddings; a handful of high-sensitivity cross-modal projection layers (selected via a Hessian trace heuristic) remain in float16. Q-TTA then operates on this quantized model: it maintains small FIFO queues of quantized positive and negative image features with pseudo-labels. For each test image, its quantized vision feature is compared to cache entries; cosine similarities re-weight the baseline logits without any gradient computation. Cache updates occur only for high-confidence predictions, avoiding noise accumulation. The joint design ensures all operations—including cache similarity searches—stay in low-bit integer arithmetic, preventing costly dequantization overhead.

## Key Results
- LQA improves average accuracy by 4.5 percentage points over state-of-the-art TTA methods on seven shifted datasets.
- Peak memory reduced to 196.73 MB (vs. 355 MB for full-precision CLIP) and latency to 26.04 ms per image; up to 19.9× lower memory than gradient-based TTA.
- LQA-Lite (4-bit vision) further cuts memory to 139.63 MB with only ~1.5% average accuracy drop, offering an extreme efficiency trade-off.

## Why This Works (Mechanism)
### Mechanism 1: Modality-Aware Hybrid Quantization
**Claim:** SHQ reduces memory while preserving accuracy by applying different bit-widths to vision and text encoders based on their statistical sensitivity, keeping a few critical layers full precision.
**Mechanism:** SHQ uses a Hessian-aware asymmetric quantizer (4-bit) for the vision encoder to minimize error on sensitive spatial details and a symmetric uniform quantizer (8-bit) for the text encoder to protect token embeddings. The set of layers to retain in FP16 (e.g., final LayerNorm, projection) is selected via a Hessian trace heuristic, targeting the highest sensitivity.
**Core assumption:** The vision pathway is more sensitive to low-bit quantization than the text pathway; safeguarding a small subset of high-sensitivity layers mitigates most accuracy loss.
**Evidence anchors:** (Abstract) describes modality-aware bit-widths and selective full-precision layers; (Section 3.3) details Hessian-aware vs. symmetric quantization and layer selection via Hessian trace; (Table 7) shows accuracy collapse below 4-bit vision quantization, supporting the 4-bit boundary.

### Mechanism 2: Gradient-Free Cache-Based Adaptation
**Claim:** Q-TTA enables on-device robustness without backpropagation by operating entirely in low precision using cached feature similarities.
**Mechanism:** Q-TTA maintains quantized positive/negative caches of image features and pseudo-labels. For a new image, its quantized vision feature is compared to cache entries; the baseline logits are adjusted by a weighted sum of similarities to cached features (Equation 8). Cache updates use conservative thresholds (entropy, confidence) to avoid noise.
**Core assumption:** Cache-based similarity adjustment can mimic gradient-based adaptation’s benefit on domain shift when gradients are too expensive.
**Evidence anchors:** (Abstract) states gradient-free, cache-based, low-precision operation; (Section 3.4, Algorithm 1) defines cache logic and thresholds; (TDA precursor) provides similar cache-based TTA; (Table 8) shows sensitivity to cache hyperparameters, indicating a delicate balance.

### Mechanism 3: End-to-End Low-Precision Integration
**Claim:** Jointly designing SHQ and Q-TTA for the same low-precision representation avoids dequantization overhead that would otherwise erode efficiency gains.
**Mechanism:** Both the quantized encoders and the Q-TTA cache module operate in INT4/INT8. Cached features and similarity computations use low-bit arithmetic, eliminating conversion to higher precision.
**Core assumption:** Maintaining uniform precision across quantization and adaptation prevents interoperability overhead that could negate memory/latency improvements.
**Evidence anchors:** (Abstract) notes "purposely designing the backbone and the TTA with the same low-precision representation"; (Section 3.2) states joint design ensures efficient operation; (Tables 1–4) report low memory/latency, but no explicit profiling rules out hidden upconversions.

- **Test-time adaptation (TTA):** Needed to contextualize Q-TTA. Standard TTA (e.g., entropy minimization) uses backpropagation on unlabeled data, which is memory-intensive. Cache-based TTA (e.g., TDA) avoids gradients but may be less stable. *Quick check:* What are the memory implications of backpropagation in standard TTA vs. cache-based TTA?
- **Modality-specific sensitivity in VLMs:** Needed to grasp SHQ’s bit-width split. In CLIP, the vision encoder’s spatial MLPs and patch embeddings may be more robust to low-bit quantization than the text encoder’s token embeddings, which require finer semantic distinctions. *Quick check:* Why might the vision encoder tolerate lower bit-width than the text encoder in CLIP-style models?

## Architecture Onboarding
- **Component map:** Input Image -> EQ_V (4-bit Hessian-aware vision quantizer) -> quantized feature f -> dot product with P_Q (precomputed quantized text prototypes from EQ_T, 8-bit symmetric) -> baseline logits -> cache-weighted adjustment (sum over C+ and C- using similarity scores and weights λ, μ) -> final prediction -> (if high confidence) update C+ or C- with f and pseudo-label.
- **Critical path:** Image passes through quantized vision encoder once; text prompts are pre-encoded. Adaptation occurs entirely during the forward pass via cache lookup and weighted sum; no backward pass.
- **Design tradeoffs:** (1) Bit-width choice: 4-bit vision vs. 8-bit text balances memory and accuracy; LQA-Lite pushes vision to 4-bit for extreme memory saving. (2) Cache size K: larger K improves adaptation but increases memory; paper uses fixed small sizes (K=3 positive, K=2 negative). (3) Selective layer retention: keeping projection layers full-precision avoids collapse but slightly increases memory; Hessian trace is a heuristic not guaranteed optimal.
- **Failure signatures:** (1) Accuracy collapse when quantizing vision below 4-bit or text below 8-bit (Table 7). (2) Cache contamination from noisy pseudo-labels if confidence/entropy thresholds are lax, causing adaptation degradation. (3) Latency spikes with extreme quantization (e.g., HQQ-1bit) due to fine-grained operations.
- **First 3 experiments:** (1) Ablate SHQ by quantizing encoders separately to validate modality-aware benefit (Table 6). (2) Cache sensitivity test: vary positive/negative cache sizes and weights α/β to show robustness to hyperparameters (Tables 8–9). (3) Low-bit limit test: quantize to 1–3 bits to identify practical bit-width floors (Table 7).

## Open Questions the Paper Calls Out
- **How reliable is gradient-free TTA optimization on quantized VLMs?** Quantization instability may degrade gradient-free updates; this interaction remains unstudied.
- **Does LQA maintain efficiency and robustness on actual edge hardware versus desktop GPUs?** Experiments use a high-end GPU; performance on mobile NPUs/SoCs with different architectures is unknown.
- **Is the fixed modality-specific bit-width (4-bit vision, 8-bit text) universally optimal across VLM architectures?** Heuristic fixed allocation may not transfer to BLIP, Flamingo, etc.
- **Can more principled layer selection improve accuracy over the Hessian trace heuristic?** Layers critical for adaptation may differ from inference-critical; alternatives (gradient-based, attention stability) could help.

## Limitations
- Full-precision layer selection (via Hessian trace) is not fully disclosed or validated; the exact layers kept FP16 for CLIP ViT-B/16 are unspecified.
- Q-TTA hyperparameters (entropy thresholds, confidence masks, per-dataset λ/μ) are given only as ranges; the specific settings yielding reported results are omitted.
- The claim of end-to-end low-precision operation (no dequantization) lacks explicit profiling evidence; hidden upconversions could invalidate reported efficiency gains.

## Confidence
- **SHQ (modality-aware hybrid quantization):** Medium. Strong accuracy-memory trade-offs in tables, but fragility below 4-bit and opaque layer selection introduce uncertainty.
- **Q-TTA (gradient-free cache adaptation):** Medium. Builds on TDA; however, cache poisoning risks and unstated threshold choices could harm robustness; sensitivity ablations show hyperparameter dependence.
- **End-to-end low-precision integration:** Low. Design premise is plausible but not empirically verified; no instrumentation rules out implicit float conversions.
