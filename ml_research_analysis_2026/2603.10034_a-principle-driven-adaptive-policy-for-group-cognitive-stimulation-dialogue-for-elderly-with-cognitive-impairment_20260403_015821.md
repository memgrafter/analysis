# A Principle-Driven Adaptive Policy for Group Cognitive Stimulation Dialogue for Elderly with Cognitive Impairment

## Quick Facts
- **arXiv ID:** 2603.10034
- **Source URL:** https://arxiv.org/abs/2603.10034
- **Reference count:** 12
- **Primary result:** GCSD-3b achieves BLEU-4 27.93, BERTScore 80.12, human-evaluated Relevance 4.15, and 75% win rate vs. ERNIE in A/B tests on real Cantonese CST dialogues.

## Executive Summary
Cognitive Stimulation Therapy (CST) is clinically effective for elderly with cognitive impairment but faces scaling challenges due to reliance on human therapists and limitations of existing digital systems in managing multi-party dialogues and therapeutic principles. This paper introduces the Group Cognitive Stimulation Dialogue (GCSD) system, a principle-driven adaptive policy that integrates four modules: multi-speaker context control, dynamic participant cognitive state modeling, cognitive stimulation-focused attention loss, and a multi-reward strategy. Trained on over 500 hours of real Cantonese CST conversations and 10,000+ simulated dialogues generated via Principle-Guided Scenario Simulation, GCSD-3b significantly outperforms strong baselines across automated metrics and human evaluations. The dual-data strategy and specialized modules enable the system to handle group dynamics, personalize interactions, and adhere to therapeutic principles, demonstrating a viable path to scalable, automated CST.

## Method Summary
GCSD employs a two-phase training pipeline using a Qwen-2.5-3B base model. First, supervised fine-tuning (SFT) on combined real and simulated data optimizes a joint loss: generation loss (cross-entropy), cognitive stimulation-focused attention loss (MSE aligning model attention with CST keywords extracted by Jiagu), and smoothness regularization for dynamic prompts. The system handles multi-party dialogue via special tokens ([Assistant], [Human_i]) and personalizes responses through a dynamic participant state model (DPSM)—an MLP that converts user cognitive features into continuous soft prompts, with smoothing to ensure gradual transitions. Second, multi-reward policy optimization (MRPO) fine-tunes the model using a composite reward (BLEU-4, BERTScore, Distinct-2, structural correctness) via group relative policy optimization. The simulated data is generated with explicit CST principles via Principle-Guided Scenario Simulation, providing a curriculum that teaches therapeutic dialogue structure before fine-tuning on authentic real-world conversations.

## Key Results
- Automated metrics on real Cantonese CST test set: BLEU-4 27.93, BERTScore 80.12.
- Human evaluation: Relevance 4.15/5 (scale 1–5).
- A/B testing: 75% win rate against ERNIE, competitive with GPT-4o (~50% win rate).
- Ablation studies: All four modules contribute synergistically; removing simulated pre-training (w/o CT) causes a notable drop (BLEU-4 27.93→26.51).

## Why This Works (Mechanism)

**Mechanism 1: Dual-Data Strategy**  
The combination of principle-guided simulation and real fine-tuning enables the model to internalize CST principles while adapting to authentic multi-party dynamics. Simulated data provides high-coverage, principle-anchored patterns that teach the "grammar" of therapeutic dialogue; real data then fine-tunes on linguistic variation and turn-taking. Core assumption: Simulated dialogues sufficiently capture therapeutic intent. Evidence: [abstract] and [section 2] describe PGSS; ablation w/o simulated pre-training shows significant performance drop (Table 2). Break condition: Poorly formulated simulation prompts or theme distribution divergence could lead to rigid scripts and degraded real-data performance.

**Mechanism 2: Dynamic Participant Cognitive State Modeling (DPSM)**  
DPSM generates personalized, time-evolving soft prompts from user state features (e.g., cognitive scores, dialogue history) using a lightweight MLP, with smoothing regularization to prevent jarring transitions. Core assumption: A low-dimensional soft prompt adequately encapsulates relevant cognitive state aspects for personalization. Evidence: [section 3.2] details MLP architecture and equations; [abstract] highlights adaptive interaction. Break condition: Inappropriate feature selection, infrequent updates, or extreme smoothing coefficient γ3 cause ineffective or disruptive personalization; ablation confirms contribution but sensitivity is unquantified.

**Mechanism 3: Cognitive Stimulation-Focused Attention Loss (CSFAL)**  
During SFT, CSFAL penalizes the model’s attention distribution if it does not concentrate on CST principle-related keywords (extracted from reference responses via Jiagu). This forces the model to learn which tokens are therapeutically salient. Core assumption: Aligning attention with an external keyword set effectively teaches principle-aligned response generation. Evidence: [section 3.3] defines the loss; [abstract] notes instillation of cognitive stimulation reasoning. Break condition: Inaccurate Jiagu extraction or poor saliency weighting κ cause misaligned focus, potentially lowering human Relevance despite similar n-gram metrics.

## Architecture Onboarding

**Component map:**  
User State Features -> DPSM (MLP) -> Soft Prompt -> Input Processor (role tokenization + soft prompt prepend) -> Base LM (Qwen-2.5-3B) -> Response. Training modules: Loss Calculator (L_Gen, L_CSFAL, L_Smooth) and Reward Calculator (MRPO composite).

**Critical path:**  
1) Process real and simulated data into tokenized sequences with role tags.  
2) During SFT, jointly train Soft Prompt Generator (DPSM) and base LM with joint loss.  
3) Freeze SFT model as reference.  
4) Apply MRPO fine-tuning using composite reward and group sampling.

**Design tradeoffs:**  
- Simulation coverage vs. authenticity: PGSS covers rare themes but may generate unnatural dialogues; real data is authentic but sparse.  
- Soft prompt dimension vs. stability: Higher dimension allows richer representation but risks overfitting; smoothing coefficient trades adaptation speed vs. stability.  
- Reward term weighting: Over/under-weighting terms (e.g., BLEU-4, Distinct-2) can cause superficial pattern matching or repetition.

**Failure signatures:**  
- Role confusion: Model uses [Assistant] for elder utterances or mixes [Human_i] identities.  
- Principle drift: Responses fluent but lack CST elements (e.g., no reminiscence prompts).  
- State oscillation: Soft prompts change drastically turn-to-turn, causing inconsistent personalization.  
- Reward hacking: Model maximizes BLEU-4 by copying phrases out of context.

**First 3 experiments:**  
1. Ablation - w/o CT: Train only on real data. Expect significant BLEU-4 drop (27.93→26.51).  
2. Attention Visualization: Compare attention weights on CST keywords with/without CSFAL; with CSFAL, expect higher focus on therapeutic terms.  
3. A/B Test Against Strong Baseline: Human evaluation vs. GPT-4o; expect competitive win rate (~50%).

## Open Questions the Paper Calls Out
1. Does GCSD produce long-term cognitive benefits in real-world settings? Future work needs longitudinal clinical trials (e.g., MMSE scores over months) to bridge computational performance and clinical efficacy.
2. How best to integrate multimodal cues (visual/acoustic) into GCSD? Current text-only system cannot capture non-verbal signals critical for elders with severe impairment.
3. What safeguards prevent hallucinations in GCSD's therapeutic dialogues? LLMs risk generating plausible but incorrect information, which could harm vulnerable users.
4. Can the GCSD policy generalize beyond Cantonese to other languages/cultures? CST principles are universal but linguistic/cultural realizations may vary; overfitting to Cantonese patterns could hinder transfer.

## Limitations
- DPSM input feature composition and smoothing hyperparameters are unreported, hindering reproduction and sensitivity analysis.
- CSFAL relies on Jiagu keyword extraction, which may be inaccurate for the Cantonese CST domain, risking misaligned attention guidance.
- PGSS simulation may not generalize beyond the specific cultural and linguistic context of the training data.
- Reward weighting in MRPO is not systematically explored; suboptimal choices could affect balance between fluency and principle adherence.

## Confidence
- Dual-data strategy (PGSS + real): **High** – Ablation shows significant performance drop without simulated pre-training.
- Dynamic Participant State Modeling: **Medium** – Ablation confirms contribution but feature design and smoothing lack empirical validation.
- Attention-based principle learning: **Medium** – Gains observed but reliance on external keyword extractor introduces uncertainty.
- Overall system superiority: **High** – Robust gains across automated metrics and human A/B tests (e.g., 75% win vs. ERNIE).

## Next Checks
1. **Feature ablation for DPSM:** Evaluate performance and turn-level prompt stability across variations in input features (e.g., remove cognitive scores) and smoothing coefficient γ3.
2. **Keyword extraction reliability study:** Human annotators label CST-relevant keywords; compare with Jiagu outputs; correlate discrepancies with CSFAL loss and attention alignment.
3. **Cross-language generalization test:** Apply GCSD to an English CST dataset (with token adaptation) to assess whether PGSS and attention mechanisms transfer without retraining.
