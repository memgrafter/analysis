# Robust Language Identification for Romansh Varieties

## Quick Facts
- **arXiv ID**: 2603.15969
- **Source URL**: https://arxiv.org/abs/2603.15969
- **Reference count**: 18
- **Primary result**: First LID system for six Romansh varieties, achieving 97% in-domain accuracy and 98.1% macro F1 on a balanced test set, but dropping to 69.1% on out-of-domain informal text.

## Executive Summary
This paper presents the first language identification (LID) system capable of distinguishing between six Romansh varieties (five regional idioms plus the standardized Rumantsch Grischun). The authors train a linear SVM classifier using TF-IDF features derived from character 1-4-grams and word unigrams on a newly curated multi-source benchmark spanning news and educational domains. The model achieves high in-domain performance (97% average accuracy, up to 98.1% macro F1 on a balanced test set) but suffers a significant degradation on out-of-domain informal text (69.1% macro F1). The work enables downstream applications like idiom-aware spell checking and highlights the challenge of domain shift in dialectal LID.

## Method Summary
The authors assemble a dataset from five sources (Pledari Grond, La Quotidiana, RTR, Telesguard Notes, Mediomatix) and apply preprocessing to remove duplicates, HTML, and dictionary artifacts (e.g., numerals, “cf.” stubs). The data are split into training, development, and three test sets: in-domain news (unbalanced), balanced broadcasts, educational textbooks, and informal notes. Features are extracted via a FeatureUnion of two TF-IDF vectorizers: one for character n-grams (1–4) and another for word unigrams, both with sublinear tf scaling and L2 normalization. A linear SVM is trained; its regularization parameter C is selected via randomized search on 20% of the training data using stratified 5-fold cross-validation optimizing macro F1. The final model is evaluated on all test sets. The impact of named entity masking (using SwissBERT) is also tested but found negligible.

## Key Results
- Average in-domain accuracy: 97% across all six varieties.
- Best macro F1: 98.1% on a balanced in-domain test set (test-b).
- Out-of-domain performance: macro F1 drops to 69.1% on informal text (test-d), with confusion mainly between Puter and Rumantsch Grischun.
- Character n-grams proved most discriminative; named entity masking had negligible impact.

## Why This Works (Mechanism)
The system works because character n-grams effectively capture orthographic and morphological patterns that differentiate Romansh varieties, which often differ in subtle spelling conventions (e.g., underdotted characters). The linear SVM with TF-IDF weighting is well-suited for high-dimensional sparse features, providing a strong baseline for text classification. The multi-source training data covering news and educational domains exposes the model to a range of formal registers, contributing to high in-domain accuracy. However, the significant out-of-domain drop indicates that informal text introduces vocabulary and stylistic shifts that char n-grams alone cannot fully compensate for, suggesting a need for domain adaptation techniques.

## Foundational Learning
1. **Language Identification (LID)**: The task of determining which language a given text is written in. *Why needed*: To enable language-specific processing (e.g., spell checking, translation). *Quick check*: What are the main challenges in LID for closely related dialects?
2. **Support Vector Machines (SVM)**: A supervised learning model that finds a hyperplane maximizing the margin between classes. *Why needed*: Effective for high-dimensional sparse data like text n-grams. *Quick check*: How does the margin relate to generalization?
3. **TF-IDF Weighting**: Term frequency-inverse document frequency, a weighting scheme that increases with term frequency in a document but decreases with frequency across the corpus. *Why needed*: To highlight discriminative n-grams while downplaying common ones. *Quick check*: What is the effect of sublinear tf scaling?
4. **Character n-grams**: Contiguous sequences of characters of length n. *Why needed*: Capture subword patterns (e.g., affixes, digraphs) that are characteristic of specific dialects, even when vocabulary is shared. *Quick check*: How might underdotted characters (e.g., `ẓ`) be represented in character n-grams?

## Architecture Onboarding
Component map: Raw text -> Preprocessing -> Feature extraction (Character n-grams + Word unigrams) -> TF-IDF weighting -> Linear SVM -> Predictions
Critical path: The pipeline flows from text normalization to feature representation, then classification.
Design tradeoffs:
- N-gram range: character 1-4-grams capture both single letters (e.g., diacritics) and short morphemes; larger n increases sparsity and computational cost.
- Feature combination: char n-grams alone may suffice, but word unigrams add lexical cues; combining via FeatureUnion increases dimensionality but can improve performance.
- Classifier: Linear SVM chosen for scalability and performance on sparse data; nonlinear kernels could capture more complex boundaries but at higher cost.
- Class imbalance: Rumantsch Grischun (RG) is overrepresented; the paper does not mention class weighting, which might affect performance on minority idioms.
Failure signatures:
- Low overall accuracy (<90% in-domain) suggests data leakage or feature extraction errors.
- High confusion between specific pairs (e.g., Puter ↔ RG) indicates those varieties are most similar; may require more training data or additional features.
- Severe out-of-domain drop (>30% F1 loss) signals domain shift; check if informal text contains many named entities or slang not seen in training.
First experiments:
1. **Feature ablation**: Train models with only char n-grams, only word unigrams, and their combination to quantify each contribution.
2. **Hyperparameter sweep**: Systematically vary the SVM regularization parameter C on the development set to find the optimal value, rather than relying on randomized search.
3. **Domain adaptation test**: Apply the trained model to a held-out informal domain (if available) and analyze error patterns to guide future adaptation strategies.

## Limitations
- Exact hyperparameter search details (distribution, iterations, CV folds) and final chosen C value are unreported, hindering precise replication.
- Preprocessing heuristics for removing "dictionary artifacts" (e.g., numerals, “cf.” stubs) are ambiguous, risking variation in sample counts and potential noise.
- The claim that named entity masking has negligible effect lacks statistical validation; performance on very short texts (<5 words) is unexamined.

## Confidence
- In-domain accuracy (97%): Medium (dependent on unreported split randomness and preprocessing).
- Feature importance (char n-grams): High (consistent with LID literature and likely validated via ablation).
- Out-of-domain drop (~30% F1 loss): Medium (expected for informal vs. formal domains, but exact magnitude sensitive to preprocessing).
- NE masking negligible effect: Low (only pairwise comparison shown, no confidence intervals or repeated trials).
