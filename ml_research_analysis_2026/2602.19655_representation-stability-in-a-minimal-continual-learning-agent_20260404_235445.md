# Representation Stability in a Minimal Continual Learning Agent

## Quick Facts
- **arXiv ID:** 2602.19655
- **Source URL:** https://arxiv.org/abs/2602.19655
- **Reference count:** 5
- **Primary result:** A minimal continual learning agent exhibits emergent stability-plasticity trade-offs through persistent state and incremental accumulation alone, without explicit regularization, replay, or architectural complexity.

## Executive Summary
This paper studies internal representation dynamics in continual learning, decoupling stability from task performance. The authors employ a minimal agent that maintains a persistent token-frequency state vector across eight sequential executions of textual data. Representational change is quantified via cosine similarity between successive normalized states. Results show a rapid initial increase in similarity (from ~0 to 0.98), marking a transition from plastic to stable behavior under coherent input. A deliberate semantic perturbation at Day 5 induces a bounded drop in similarity (0.9868 → 0.8957), followed by recovery and re-stabilization to 0.9984 under subsequent consistent data. These dynamics arise without any specialized continual learning mechanisms, demonstrating that stability-plasticity trade-offs can emerge from simple incremental accumulation and persistent state.

## Method Summary
The agent implements a single, persistent token-frequency vector `t ∈ ℝ^d`. At each run, it observes all newly added documents (the corpus grows cumulatively), tokenizes them (simple whitespace split), and increments the corresponding counts in `t`, adding new dimensions for unseen tokens. After updating, the entire vector is L2-normalized to yield a unit vector `s_t`. Cosine similarity `cos(s_{t-1}, s_t)` is computed and stored as a measure of representational stability. The experiment consists of eight runs: Runs 1–4 use a coherent text corpus; Run 5 injects a single semantically orthogonal document; Runs 6–8 return to the coherent corpus. Tracked statistics include cosine similarity, cumulative tokens seen, and vocabulary size.

## Key Results
- Initial executions show a rapid rise in cosine similarity from near 0 to ~0.98, indicating a swift transition to a stable regime.
- The semantic perturbation on Day 5 produces a bounded similarity decrease from 0.9868 to 0.8957.
- Subsequent coherent data drives recovery and re-stabilization, with similarity reaching 0.9984 by Day 8.

## Why This Works (Mechanism)

### Mechanism 1
**Claim:** Stability emerges from cumulative, incremental state updates without explicit regularization.  
**Mechanism:** The agent maintains a persistent token-frequency state vector. At each run, counts from new documents are added to the existing vector (expanding dimensionality as needed), then the whole vector is normalized. This trajectory yields large directional shifts early on, but continued exposure to consistent input converges the normalized direction.  
**Core assumption:** Normalization removes scale effects, so directional convergence reflects structural stabilization rather than mere volume growth.  
**Evidence anchors:**  
- Abstract: “stability-plasticity trade-offs can arise from persistent state and incremental accumulation alone.”  
- Section 2.2: “The representation is updated incrementally as new documents are added, rather than recomputing from scratch…”  
- Section 3.1: “During the initial executions… representational similarity increases rapidly… By Day 4, the agent transitions into a stable regime.”  
**Break condition:** If updates are rescaled or non-additive, directional convergence may fail; a state reset between runs collapses the trajectory.

### Mechanism 2
**Claim:** Representational change can be measured intrinsically via self-similarity, decoupled from task performance.  
**Mechanism:** After each update, cosine similarity between the current normalized state and the previous run’s normalized state is computed. High similarity indicates minor adjustment (stability); a drop indicates significant adaptation (plasticity).  
**Core assumption:** Cosine similarity on normalized token-frequency vectors meaningfully captures semantic-structural drift even as vocabulary grows.  
**Evidence anchors:**  
- Abstract: “We quantify representational change using cosine similarity between successive normalized state vectors.”  
- Section 2.4: “Cosine similarity… captures changes in representational structure independently of overall magnitude.”  
- Section 3.1: Figure 1 and Table 1 show similarity values tracking learning phases.  
**Break condition:** If vocabulary growth becomes highly volatile or new tokens dominate the norm, similarity may become noisy or uninterpretable; normalization failure distorts the metric.

### Mechanism 3
**Claim:** Bounded adaptation to semantic novelty occurs via incremental token addition while preserving alignment with the prior state.  
**Mechanism:** When a semantically orthogonal document is introduced (Day 5), many new tokens are added. Because the update is additive and normalization is applied, the new state direction shifts but remains partially aligned with the old direction. The cosine similarity drop is bounded (~0.89), and subsequent consistent input allows re-convergence.  
**Core assumption:** The additive nature of token-frequency vectors ensures novel information is incorporated without overwriting; the previous state’s directional influence persists unless novelty is overwhelmingly dominant.  
**Evidence anchors:**  
- Section 3.2: “The perturbation produces a clear and immediate effect… drop from approximately 0.99 to 0.8957… The observed deviation remains bounded.”  
- Section 3.3: Table 1 shows vocabulary jump on Day 5 (273→292) while similarity recovers in following days.  
- Abstract: “A deliberately introduced semantic perturbation produces a bounded decrease in similarity… followed by recovery and re-stabilization.”  
**Break condition:** If the perturbation introduces a volume of novel tokens so large that the old state’s contribution becomes negligible in the normalized vector, similarity could collapse toward 0.

## Foundational Learning
- **Concept: Continual learning (lifelong learning)**  
  *Why needed here:* The paper’s setup assumes a non-episodic, irreversible learning process where data accumulates over time. Understanding the standard continual learning problem (e.g., catastrophic forgetting, stability-plasticity dilemma) contextualizes why this minimal agent is surprising—it achieves bounded adaptation without known mitigation techniques.  
  *Quick check:* What is the key difference between batch learning and continual learning in terms of data availability and system state?

- **Concept: Vector space representation**  
  *Why needed here:* The agent’s state is a bag-of-words vector where dimensions correspond to tokens. Grasping how such representations work (sparsity, growth, normalization) is essential to interpret the stability metric and vocabulary growth.  
  *Quick check:* How does adding a new token affect a normalized term-frequency vector’s direction versus its magnitude?

- **Concept: Cosine similarity as a measure of directional alignment**  
  *Why needed here:* The primary metric is cosine similarity between consecutive normalized states. Understanding that cosine similarity ranges from -1 to 1 and is invariant to vector length is key to interpreting why it can track representational drift independent of corpus size.  
  *Quick check:* If two normalized vectors are identical, what is their cosine similarity? What does a value of 0 imply?

## Architecture Onboarding
**Component map:**  
Observation → Representation → Update → Normalization → Comparison → Storage  
- **Observation:** Reads all new textual documents available at the current execution.  
- **Representation:** Maintains a token-frequency dictionary; each unique token is a dimension, value = count across all seen documents.  
- **Update:** Incrementally adds counts from new documents to the existing dictionary; adds new keys for unseen tokens (expanding dimensionality).  
- **Normalization:** Converts the cumulative frequency vector to a unit vector (L2 norm = 1).  
- **Comparison:** Computes cosine similarity between current normalized vector and the previous run’s vector.  
- **Storage:** Persists the normalized vector (and possibly raw counts) for the next execution.

**Critical path:** Load previous state → observe new data → update raw counts → normalize → compute similarity → store new state. The similarity computation is the key diagnostic; the incremental update is the core learning mechanism.

**Design tradeoffs:**  
- *Simplicity vs. scalability:* Token-frequency vectors are transparent but grow unbounded in dimensionality; no compression limits memory use.  
- *Interpretability vs. expressivity:* Each dimension is human-readable, but the representation lacks semantic relationships (synonyms map to different dimensions).  
- *Plasticity vs. stability:* Additive update naturally balances both, but offers no explicit protection against catastrophic novelty spikes.

**Failure signatures:**  
- Representational similarity collapses to near 0 after perturbation and does not recover (loss of prior structure).  
- Vocabulary size grows superlinearly with tokens seen, indicating poor reuse or high semantic divergence.  
- Normalization fails due to zero vector or division by zero (unlikely after first run).  
- State file corruption or loss between runs resets accumulation.

**First 3 experiments:**  
1. **Baseline longitudinal run:** Execute the agent sequentially with a coherent corpus for 8+ runs. Plot cosine similarity over time to verify the plastic→stable transition pattern.  
2. **Semantic perturbation test:** At a stable phase (e.g., Day 4), inject a document from a very different domain (e.g., legal text if prior was news). Measure similarity drop and recovery trend over subsequent runs with original-domain data.  
3. **Vocabulary vs. similarity correlation:** For each run, record vocabulary size and similarity to previous run. Expect inverse relationship during perturbation (vocab spikes, similarity drops) and direct relationship during recovery (vocab grows slowly, similarity rises).

## Open Questions the Paper Calls Out
### Open Question 1
How can the unbounded growth of the internal state vector be managed to ensure long-term scalability and memory efficiency?  
*Basis in paper:* The paper notes that the representation grows without bound, raising questions about long-term scalability, memory efficiency, and compression.  
*Why unresolved:* The minimal agent lacks any compression or pruning mechanism, so it is unclear how to handle practical memory constraints while preserving representational stability.  
*What evidence would resolve it:* Introduce explicit compression techniques (e.g., feature hashing, low-rank approximations) and evaluate whether the stability-plasticity trade-offs persist, measuring both representation similarity and resource usage.

### Open Question 2
How do alternative representation forms, such as structured or compressed embeddings, influence the emergence and nature of stability-plasticity trade-offs in continual learning?  
*Basis in paper:* The authors suggest future work incorporating structured representations and dimensionality reduction.  
*Why unresolved:* The token-frequency representation is fixed and not scalable; different representation geometries might fundamentally alter the observed dynamics.  
*What evidence would resolve it:* Implement variants of the agent with different embedding strategies (e.g., random projections, autoencoders) and compare stability metrics and perturbation responses.

### Open Question 3
How robust are the observed stability-plasticity dynamics when the agent operates under realistic constraints such as delayed feedback, partial observability, or real-time processing?  
*Basis in paper:* The paper mentions robotics and autonomous systems as a direction for studying learning under physical constraints.  
*Why unresolved:* The current experimental setup assumes immediate, full access to cumulative text, which may not hold in dynamic environments.  
*What evidence would resolve it:* Simulate conditions like asynchronous data arrival, incomplete context, or streaming updates and assess changes in self-similarity and recovery patterns.

### Open Question 4
Can the representational evolution be formalized within dynamical systems theory, e.g., identifying attractors or phase transitions in the state trajectory?  
*Basis in paper:* The authors propose using dynamical systems analysis to better characterize state evolution.  
*Why unresolved:* The current analysis relies on empirical similarity trends; a theoretical framework could explain the transition from plasticity to stability.  
*What evidence would resolve it:* Apply tools such as Lyapunov exponents, manifold learning, or recurrence quantification to the state sequences to detect invariant structures or critical points.

## Limitations
- Exact corpora and perturbation document are unspecified, preventing exact numerical replication.
- Tokenization and vector alignment details (handling case/punctuation, managing expanding dimensionality for cosine similarity) are ambiguous.
- Cosine similarity metric’s validity as a proxy for “representational stability” lacks external validation; it may only reflect lexical overlap.
- Results derive from a single minimal agent and one corpus sequence; generalizability to other domains or architectures is unknown.

## Confidence
- **Mechanism 1 (stability from incremental accumulation):** Medium – observed trends align, but causal necessity of incremental updates is not isolated.
- **Mechanism 2 (self-similarity as intrinsic metric):** Medium – calculation is clear, but interpretive power beyond this setup is unverified.
- **Mechanism 3 (bounded adaptation to novelty):** Medium – bounded drop and recovery are reported, but boundary conditions (perturbation size/orthogonality thresholds) are not mapped.

## Next Checks
1. **Break-condition experiment:** Reset the state vector between runs. If the rapid similarity increase vanishes, it confirms accumulation is necessary for the observed stability regime.
2. **Metric-correlation test:** Introduce a downstream task (e.g., document classification) and track task accuracy alongside representational similarity. A disconnect would challenge the claim that similarity reflects meaningful structural stability.
3. **Perturbation scaling:** Systematically increase the size or semantic distance of the Day 5 perturbation (e.g., multiple disjoint-domain documents). Identify if/when similarity drop becomes unbounded (~0), testing the robustness of the “bounded” claim.
