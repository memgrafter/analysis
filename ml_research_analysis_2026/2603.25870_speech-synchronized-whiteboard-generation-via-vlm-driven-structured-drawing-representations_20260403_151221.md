# Speech-Synchronized Whiteboard Generation via VLM-Driven Structured Drawing Representations

## Quick Facts
- arXiv ID: 2603.25870
- Source URL: https://arxiv.org/abs/2603.25870
- Reference count: 9
- Primary result: Introduces ExcaliTeach dataset and a VLM-based model that achieves millisecond-precise speech-drawing synchronization by predicting structured drawing elements autoregressively conditioned on transcript and canvas.

## Executive Summary
The paper presents ExcaliTeach, the first dataset of 24 Excalidraw demonstrations with millisecond-aligned audio, and a method to automate speech-synchronized whiteboard video creation. By fine-tuning Qwen2-VL-7B via LoRA to predict structured drawing elements (serialized as TYPE|ONSET|coordinates) conditioned on the transcript and evolving visual canvas, the approach significantly reduces Temporal Alignment Error compared to ablations that omit timestamp conditioning, transcript, or autoregressive canvas updates. The model generalizes to unseen STEM topics, with human and automated evaluations confirming improved synchronization and pedagogical clarity.

## Method Summary
The method treats whiteboard creation as a sequence prediction task: given a transcript and the current canvas state (rasterized image), the model predicts the next drawing element's type, onset time, and geometry in a serialized format. The ExcaliTeach dataset provides aligned drawing elements (via DTW between ASR word timestamps and drawing actions) and transcripts. The model is a VLM (Qwen2-VL-7B) fine-tuned with LoRA for parameter efficiency, and it updates the canvas autoregressively by rasterizing the scene graph after each prediction. Training uses topic-stratified 5-fold splits to evaluate generalization across STEM domains.

## Key Results
- Conditional onset prediction (timestamped elements) reduces Temporal Alignment Error significantly over baselines without onset or transcript.
- Autoregressive canvas updates improve spatial coherence (lower Chamfer distance) and human preference for layout.
- The model generalizes to unseen STEM topics, as shown by topic-stratified 5-fold evaluation.

## Why This Works (Mechanism)
### Mechanism 1
Claim: Element-level, timestamped annotations in ExcaliTeach enable the model to learn precise speech-drawing synchronization.
Mechanism: The dataset serializes every drawing action (type, absolute onset time, geometry) aligned via DTW to ASR word timestamps. This turns whiteboard creation into a supervised sequence-to-sequence task where the target is a structured token stream (TYPE|ONSET|coords). The core assumption is that millisecond-precision temporal alignment from human demonstrations is learnable and generalizable by a VLM when conditioned on the evolving visual canvas.
Evidence anchors: Abstract and section 3 describe the dataset creation and alignment via DTW. Section 4.3 details the serialization and conditioning. The ablation E5 (removing transcript) shows degraded TAE.
Break condition: If DTW alignment fails on disfluent speech or highly nonlinear drawing pacing, the supervision signal becomes noisy, limiting onset prediction accuracy.

### Mechanism 2
Claim: Parameter-efficient fine-tuning (LoRA) on a tiny dataset (24 demos) adapts a general-purpose VLM for this specialized multimodal task without overfitting.
Mechanism: LoRA injects trainable low-rank matrices into Qwen2-VL’s attention and MLP layers, updating only a small fraction of parameters. The pretrained model’s vision-language and geometry priors are preserved while learning the new structured output format and temporal conditioning.
Evidence anchors: Section 4.4 and 5 describe LoRA fine-tuning with 24 demonstrations and the results showing significant TAE improvement.
Break condition: If the base model lacks latent geometry understanding (e.g., cannot parse freehand strokes), LoRA fine-tuning may be insufficient.

### Mechanism 3
Claim: Autoregressive canvas updates with visual context prevent spatial drift and maintain layout coherence across long stroke sequences.
Mechanism: At each step, the current canvas is rasterized and fed as an image input alongside the transcript history. The model predicts the next element; this element is added to the scene graph and re-rendered, forming a closed-loop where later elements condition on prior spatial decisions.
Evidence anchors: Section 4.3 describes the canvas rendering and input. Section 5.4 ablation E3 (no canvas image) and E4 (one-shot) show degradation in geometric metrics and human preference.
Break condition: If early geometric errors are not corrected by subsequent steps, drift accumulates; also, rasterization resolution may lose fine details.

## Architecture Onboarding
Component map: Data loader -> Serializer -> Canvas renderer -> VLM engine (Qwen2-VL-7B with LoRA) -> Decoder loop (which updates canvas via renderer)

Critical path: Input transcript + empty canvas -> first element -> update canvas -> repeat until full sequence. Visual context is re-rendered each cycle.

Design tradeoffs:
- Absolute vs. relative coordinates: Absolute ensures deterministic replay but may require larger context; relative could generalize better but risks drift.
- Full canvas image vs. cropped region: Full image preserves global layout but costs tokens; cropping saves compute but may lose spatial context.
- Greedy vs. sampling decoding: Greedy favors stability/synchronization; sampling may increase diversity but risks errors.

Failure signatures:
- High TAE: Onset tokens poorly predicted; model ignores transcript timing cues.
- High Chamfer: Geometric inaccuracies; likely due to absent visual context or one-shot decoding.
- Type misclassification: Model confuses primitives or freehand vs. text.

First 3 experiments:
1. Baseline sanity check: Train on a single domain with random onset (ignore transcript); expect high TAE, moderate Chamfer.
2. Ablate visual context: Disable canvas rendering (use only text history); expect spatial overlaps, increased Chamfer.
3. Full model vs. no transcript: Compare E1 and E5; expect TAE spike in E5, confirming transcript necessity for timing.

## Open Questions the Paper Calls Out
1. Does expanding the dataset with multiple instructors across diverse STEM topics improve cross-domain generalization and reduce temporal alignment error?
2. Can explicit correction mechanisms, such as periodic canvas re-rendering with error feedback, effectively mitigate geometric drift in long-horizon whiteboard lesson generation?
3. Is low-latency streaming ASR integration feasible for real-time speech-synchronized drawing in live classrooms without significant synchronization degradation?
4. Does a mixed-initiative interface, allowing instructors to manually adjust element timing and layout, enhance pedagogical clarity and reduce post-generation editing effort compared to fully automatic generation?
5. Does the use of speech-synchronized whiteboard videos generated by this system lead to measurable improvements in student learning outcomes compared to static slides or non-synchronized drawings?

## Limitations
- Dataset scale & diversity: Only 24 demonstrations across 8 domains; limited coverage of speaking styles, drawing paces, and diagram complexity.
- Temporal alignment assumption: Relies on DTW to map ASR words to drawing onsets; disfluencies or nonlinear narration could degrade supervision.
- Coordinate representation & prompt engineering: Unclear normalization and tokenization of coordinates; exact multimodal prompt format unspecified, affecting reproducibility.

## Confidence
- Timestamped annotations enable learnable synchronization: Medium
- LoRA adapts VLM effectively with minimal data: Low
- Autoregressive canvas updates maintain spatial coherence: Medium
- Generalization to unseen STEM topics: Medium

## Next Checks
1. DTW Alignment Robustness Test: Manually annotate a subset with word-level disfluencies and recompute alignments. Measure correlation between DTW confidence scores and final TAE.
2. Long-Sequence Drift Quantification: Run full autoregressive rollouts on longest demonstrations. Compute per-element Chamfer distance relative to ground truth; fit linear trend to detect cumulative geometric error.
3. Coordinate Tokenization Impact: Re-run key experiments with explicit coordinate quantization (e.g., 1-pixel vs. 5-pixel grids) and with relative (delta) vs. absolute encoding. Compare TAE and Chamfer.
