# Automating Agent Hijacking via Structural Template Injection

## Quick Facts
- **arXiv ID:** 2602.16958
- **Source URL:** https://arxiv.org/abs/2602.16958
- **Reference Count:** 40
- **Primary Result:** Phantom achieves a 79.76% average attack success rate across seven state-of-the-art closed-source agents (GPT, Qwen, Gemini), significantly outperforming semantic and structural baselines.

## Executive Summary
Indirect prompt injection attacks on LLM‑powered agents typically rely on semantic manipulation, yielding low success rates and poor transferability to closed‑source models. This paper introduces Phantom, an automated framework that hijacks agents by injecting structurally malicious chat templates that exploit architectural parsing logic and induce role confusion.

Phantom combines multi‑level template augmentation, a Template Autoencoder to embed templates into a continuous latent space, and Bayesian optimization guided by a lightweight proxy—all operating under black‑box conditions. Evaluated on seven state‑of‑the‑art closed‑source agents (GPT, Qwen, Gemini), Phantom achieves an average attack success rate of 79.76%, far surpassing semantic and structural baselines. The framework has discovered over 70 vulnerabilities in commercial products, highlighting a severe and transferable threat that bypasses semantic defenses.

## Method Summary
Phantom operates in three stages. First, it performs multi‑level template augmentation to generate diverse variations of base chat templates, introducing structural perturbations. Second, a Template Autoencoder encodes discrete templates into a continuous latent space, allowing gradient‑free optimization techniques to search efficiently. Third, Bayesian optimization, driven by a lightweight proxy model that predicts attack success, iteratively proposes new latent vectors; the corresponding decoded templates are evaluated on target agents, and high‑performing templates are retained. This process requires no access to model weights or gradients, only black‑box interaction, thus enabling transfer across diverse LLM families.

## Key Results
- **High Attack Success Rate:** 79.76% average ASR across seven closed‑source agents, compared to 39.86% for semantic attacks and lower rates for other structural baselines.
- **Transferability:** The same attack framework succeeds on GPT, Qwen, and Gemini families without model‑specific tuning.
- **Real‑World Impact:** Over 70 vulnerabilities were confirmed in commercial agent products, demonstrating practical exploitability.

## Why This Works (Mechanism)
Phantom succeeds because it targets the structural parsing layer of chat‑based agents rather than their semantic content. Many agents rely on rigid template formats (e.g., `<|system|>`, `<|user|>`, `<|assistant|>`) to assign roles and control interaction flow. By subtly altering these templates—e.g., injecting additional role tags or reordering them—the attacker can induce *role confusion*, causing the agent to mistake system prompts for user inputs or vice versa. This bypasses conventional input sanitization and semantic alignment defenses, as the content remains innocuous while the structural cues trigger unintended behaviors. The Bayesian optimization loop with a lightweight proxy efficiently navigates the combinatorial space of template modifications, finding high‑impact injections that generalize across different internal parsers.

## Foundational Learning
- **Template Injection**  
  *Why needed:* Understanding how raw chat templates are parsed reveals where malicious modifications can alter role assignment.  
  *Quick check:* Identify the delimiters used in a target agent’s API documentation (e.g., `[INST]`, `</s>`).
- **Role Confusion**  
  *Why needed:* The core attack mechanism relies on making the model misinterpret system vs. user context.  
  *Quick check:* Craft a simple template that swaps system and user tags and observe if the model’s response changes accordingly.
- **Continuous Latent Space Search**  
  *Why needed:* Discrete template edits are combinatorial; a continuous embedding enables gradient‑free optimization.  
  *Quick check:* Train an autoencoder on a small set of valid templates and verify that decoded outputs preserve syntax.
- **Bayesian Optimization**  
  *Why needed:* It efficiently proposes new points with a balance of exploitation and exploration, minimizing expensive evaluations.  
  *Quick check:* Optimize a 2‑D synthetic function using `skopt` or similar; observe convergence after few iterations.
- **Transferability**  
  *Why needed:* Attackers aim for templates that work across model families without retuning.  
  *Quick check:* Generate a template on one model and test it on another; measure drop in ASR.

## Architecture Onboarding
**Component Map**  
Input Template → Template Augmenter → Autoencoder (Encoder) → Latent Vector → Bayesian Optimizer ↔ Proxy Score → Decoder → Candidate Template → Agent Evaluation → Feedback Loop

**Critical Path**  
1. Start with a benign chat template from the target agent’s specification.  
2. Apply multi‑level augmentation to create a diverse candidate pool.  
3. Encode each candidate into the latent space using the pre‑trained autoencoder.  
4. Bayesian optimizer selects promising latent vectors based on proxy scores.  
5. Decode vectors back to discrete templates and query the agent.  
6. Record success/failure; update proxy model and repeat until convergence or budget exhaustion.

**Design Tradeoffs**  
- *Proxy Accuracy vs. Speed:* A lightweight proxy enables thousands of queries but may misestimate success, leading to false positives/negatives.  
- *Latent Space Expressivity:* Continuous embeddings may struggle to capture discrete structural constraints, risking invalid templates that require repair.  
- *Augmentation Breadth vs. Cost:* More augmentation levels increase diversity but linearly raise encoding/decoding overhead.

**Failure Signatures**  
- Proxy correlation drops (e.g., <0.5) relative to ground‑truth agent feedback.  
- Decoded templates frequently violate format (e.g., unbalanced tags).  
- Attack success plateaus early (<30% ASR) after 50 optimizer iterations.

**First Three Experiments**  
1. **Baseline Replication:** Run Phantom on a single agent (e.g., GPT‑4) with default parameters to confirm the reported ~80% ASR.  
2. **Proxy Ablation:** Replace the lightweight proxy with a full‑model evaluator (oracle) to measure the performance gap caused by proxy approximation error.  
3. **Cross‑Model Transfer:** Train the system on Qwen, then directly test the discovered templates on Gemini and GPT to quantify transferability without retraining.

## Limitations
- Discovered template injection flaws may be patched by vendors after disclosure, reducing long‑term exploitability.  
- Evaluation covered only seven closed‑source agents; results may not generalize to open‑source or specialized agents.  
- The design and limitations of the lightweight proxy are underspecified, potentially constraining scalability to larger template spaces.

## Confidence
- **High ASR (79.76%) on closed‑source agents:** Medium  
- **Transferability across LLM families (GPT, Qwen, Gemini):** Medium  
- **70+ confirmed vulnerabilities in commercial products:** Low  
- **Automation superiority over semantic/structural baselines:** High
