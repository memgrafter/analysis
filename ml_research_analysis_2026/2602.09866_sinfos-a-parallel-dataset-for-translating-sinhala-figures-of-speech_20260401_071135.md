# SinFoS: A Parallel Dataset for Translating Sinhala Figures of Speech

## Quick Facts
- arXiv ID: 2602.09866
- Source URL: https://arxiv.org/abs/2602.09866
- Reference count: 40
- Primary result: Introduces SINFOS, a 2,344-entry parallel dataset for Sinhala figures of speech, and shows that even the best LLM (Gemini) achieves only modest performance on idiomatic translation (Cosine Similarity 0.6678, Fidelity 0.3117).

## Executive Summary
The paper addresses the scarcity of resources for translating Sinhala figurative language—a culturally specific, low-resource task—by introducing SINFOS, a carefully curated parallel dataset of 2,344 Sinhala figures of speech annotated with type, literal imagery, English equivalents, and implied meanings. Using this resource, the authors train a binary classifier to distinguish proverbs from idioms (92% accuracy), conduct a cross-lingual thematic analysis revealing cultural divergence between Sinhala and English, and evaluate several large language models, uncovering systematic failures in capturing idiomatic meaning. The work highlights the need for culturally aware machine translation and provides a benchmark for future research.

## Method Summary
SINFOS was built from authoritative Sinhala literary sources and Wikipedia, with annotations by native speakers strictly based on verified references to ensure integrity. The dataset comprises fields for the Sinhala expression, its type, literal/visual image, corresponding English figure of speech (when available), the implied meaning in English, and optional contextual notes. A binary classifier separating proverbs and idioms was developed using TF-IDF and Word2Vec features with several models, a deep neural network achieving the best accuracy (92.7%). A cross-lingual thematic analysis used TF-IDF and K-Means clustering on the English implied meanings to map source domains (e.g., somatic, agrarian) to target themes (e.g., ethics, karma). Finally, a stratified sample of 499 items was used to evaluate LLMs via a dual-metric framework: Cosine Similarity (using FlagEmbedding) measured topical closeness, while a cross-encoder (stsb-roberta-large) measured entailment-based Fidelity. The combination exposed distinct failure modes such as “hallucinated relevance” and hyper-literalness.

## Key Results
- SINFOS provides the first large-scale, high-quality parallel resource for Sinhala figures of speech, with 2,344 annotated entries.
- A deep neural network binary classifier distinguishes proverbs from idioms with 92.7% accuracy.
- Cross-lingual thematic analysis shows low symbolic overlap (Jaccard index 0.05) and lexical similarity (0.32) between Sinhala source and English target domains, underscoring cultural divergence.
- LLM evaluation reveals poor idiomatic translation: the best model (Gemini) scores only 0.6678 Cosine Similarity and 0.3117 Fidelity; many outputs either keyword-stuffed or produced literal translations.

## Why This Works (Mechanism)

### Mechanism 1
A high-quality, culturally grounded parallel dataset directly tackles the data scarcity bottleneck for Sinhala figurative language translation. The authors systematically gathered 2,344 Sinhala FoS from authoritative sources and annotated them with four key fields, providing both the source expression and semantic grounding for training and evaluation. The core assumption is that a sufficiently large, well-annotated dataset can serve as a foundational resource for developing NLP systems for low-resource cultural constructs. Evidence: The dataset volume and annotation process are described in Section 3; the scarcity of similar resources is noted in the related work. Break condition: Annotation may still miss cultural nuance, and the type distribution is imbalanced (e.g., only 11 entries for `පුද්ගලික`).

### Mechanism 2
Hybrid thematic analysis of the dataset’s literal and implied meaning fields reveals the distinct cultural model underlying Sinhala figurative language, explaining translation difficulty. Using TF-IDF and K-Means clustering on the English “What it really implies” field, followed by rule-based classification, the authors map Sinhala FoS to source domains (somatic, agrarian, etc.) and target themes (ethics, karma, etc.). Cross-tabulation shows strong associations (e.g., Nature imagery → Moral Conduct), indicating that Sinhala FoS draw from a culturally specific set of conceptual metaphors. Core assumption: Recurring lexical patterns in the English translations can inductively uncover the original Sinhala cultural themes. Evidence: Section 4.2 details the unsupervised clustering and keyword mapping; Table 7 shows resulting frequencies. Break condition: The English summaries may be too paraphrased, making induced themes artifacts of translation.

### Mechanism 3
A dual-metric evaluation framework (Cosine Similarity + Fidelity) more robustly diagnoses idiomatic translation failures than standard metrics, distinguishing keyword matching from true semantic understanding. For a stratified sample of 499 FoS, model outputs are scored: a bi-encoder computes Cosine Similarity against the ground truth meaning (topical retrieval), and a cross-encoder computes Fidelity (logical entailment). High Cosine + low Fidelity indicates “hallucinated relevance”; low scores on both indicate fundamental failure. Core assumption: Combining a fast, topical similarity metric and a slow, pairwise logical metric isolates specific failure modes. Evidence: Section 5 defines the metrics; examples show the pattern (e.g., `කහඹගහට...` high Cosine but wrong meaning). Break condition: The chosen embedding models may be biased or uncalibrated, or the ground truth “What it really implies” may be too brief for fine-grained entailment.

## Architecture Onboarding

### Component Map
Data Pipeline (Sources → Extraction → Native Speaker Annotation → Validation) → Classification Module (Preprocessing → Classifier Training) → Cultural Analysis Module (English Implications → TF-IDF/K-Means → Rule-based Mapping) → LLM Evaluation Module (Stratified Sampling → Prompting → Dual Scoring).

### Critical Path
The Data Assembly & Annotation stage (Section 3) is an absolute prerequisite; without the validated SINFOS dataset, no subsequent analysis (classification, cultural, LLM evaluation) is possible. The LLM Evaluation module directly depends on the stratified sample derived from the complete dataset.

### Design Tradeoffs
- **Annotation Depth vs. Coverage:** Source-based annotation ensured high integrity but left many fields (e.g., “Corresponding FoS in English”) empty for a third of the corpus, trading completeness for avoidance of annotator hallucination.
- **Metric Complementarity:** Using both Cosine and Fidelity increases computational cost but is necessary to avoid false positives from keyword matching or overly strict lexical matching.
- **Classifier Granularity:** The binary classifier achieved strong performance (92.7%) but could not extend to all five FoS types due to severe class imbalance (e.g., `පුද්ගලික` n=11), trading full taxonomy coverage for practical utility.

### Failure Signatures
- **Data-level:** Missing English equivalents for 33% of entries cripples cross-lingual analysis; sparse “Additional Context” (125 entries).
- **Model-level (LLMs):** “Illusion of competence” (high Cosine, low Fidelity) and “broken figurative triggers” (outputting literal meanings for idiomatic input).
- **Analysis-level:** Cultural analysis depends entirely on the quality of English translations of “What it really implies”; meaning loss is a cited limitation.

### First 3 Experiments
1. **Reproduce the binary classifier:** Implement the Deep NN described (Keras Sequential, two hidden layers, dropout 0.2) using the SINFOS dataset split and character-level 3‑gram TF‑IDF features; target ≥90% accuracy.
2. **Validate cultural coding:** Manually inspect the top TF‑IDF terms per K‑Means cluster from Section 4.2 to see if the induced keyword dictionary logically aligns with the reported domains (Somatic, Agrarian, Ethics, etc.).

## Open Questions the Paper Calls Out
1. What is the statistical significance of the observed performance differences among language models on the SINFOS benchmark?
2. How can we mitigate the class imbalance in SINFOS to enable accurate classification and analysis of all figures of speech types, particularly the rare categories (`පුද්ගලික`, `කියමන්`)?
3. What methods can reduce meaning loss when translating culture-bound Sinhala figures of speech into English, thereby improving the fidelity of cross‑lingual equivalents?
4. How can we construct a more comprehensive evaluation metric for idiomatic translation that overcomes the “keyword bag” problem of Cosine Similarity and the “hyper‑literal” problem of Fidelity?

## Limitations
- Dataset scope: Missing English equivalents for one third of entries; sparse additional context.
- Cultural analysis dependency: Theme induction relies on English translations of implied meanings, risking misalignment with original Sinhala conceptual metaphors.
- Evaluation generalizability: Metric validation is confined to SINFOS; embedding models may be biased for low‑resource figurative language.
- Classifier limits: Binary task success does not extend to full taxonomy due to severe class imbalance.
