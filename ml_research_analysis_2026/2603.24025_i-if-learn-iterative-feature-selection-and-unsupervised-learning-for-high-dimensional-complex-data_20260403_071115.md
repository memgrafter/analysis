# i-IF-Learn: Iterative Feature Selection and Unsupervised Learning for High-Dimensional Complex Data

## Quick Facts
- arXiv ID: 2603.24025
- Source URL: https://arxiv.org/abs/2603.24025
- Reference count: 40
- Primary result: State-of-the-art unsupervised clustering on 18 real gene and scRNA-seq datasets via iterative joint feature selection and clustering with adaptive weighting.

## Executive Summary
i-IF-Learn tackles unsupervised clustering in high dimensions where irrelevant features obscure cluster structure. It jointly iterates feature selection and clustering using an adaptive statistic that combines pseudo-label supervision with unsupervised signals, dynamically weighting them based on label reliability to prevent error propagation. On 18 real-world genomic datasets, i-IF-Lap (using Laplacian eigenmaps) significantly outperforms 12 baselines, achieving the lowest average rank and regret in Accuracy and Adjusted Rand Index. Its selected features also enhance downstream methods like DeepCluster, UMAP, and VAE. Synthetic experiments confirm robustness, especially under weak signals and nonlinear manifolds.

## Method Summary
i-IF-Learn starts with IFPCA initialization: unsupervised KS tests and Higher Criticism Thresholding (HCT) select initial features, PCA embeds to K-1 dimensions, and k-means yields initial pseudo-labels. Then it iterates: for each feature, compute supervised F-statistic p-value (using pseudo-labels) and unsupervised KS p-value (static); combine via inverse normal transforms with weight ω(t). The weight is derived from a Higher Criticism test on the F-statistic p-values of currently selected features, increasing when those p-values deviate from uniform. Apply HCT on the composite scores to select a new feature set. Normalize selected features, embed via PCA or Laplacian eigenmaps (K+2 dimensions), and recluster with k-means to update pseudo-labels. Repeat until feature set change rate ≤10% or max iterations (10). The method outputs final cluster labels and influential features.

## Key Results
- On 18 real gene and scRNA-seq datasets, i-IF-Lap achieves the lowest average rank and regret in Accuracy and ARI compared to 12 baselines.
- Selected features substantially improve downstream DeepCluster, UMAP, and VAE performance.
- Synthetic experiments show superior feature selection (TPR/FDR) and clustering accuracy, especially for weak signals and nonlinear manifolds.

## Why This Works (Mechanism)
### Mechanism 1
**Claim:** Iterative joint refinement improves weak signal recovery and prevents error propagation.  
**Mechanism:** Begin with initial pseudo-labels (e.g., from IFPCA). Each iteration computes composite feature importance via supervised (F-test) and unsupervised (KS) scores, selects features with HCT, re-embeds, and reclusters.  
**Core assumption:** Initial labels contain enough signal to identify some true influential features; subsequent iterations refine both.  
**Break condition:** Initial labels completely random may reinforce noise; assumes feature sparsity.

### Mechanism 2
**Claim:** Adaptive composite statistic balances supervised/unsupervised signals to mitigate error propagation when pseudo-labels are unreliable.  
**Mechanism:** Weight ω(t) from Higher Criticism on F-stat p-values of selected features; increases as p-values show non-uniformity (more signal). Composite score = ω(t)Φ⁻¹(1-P_F) + (1-ω(t))Φ⁻¹(1-P_KS).  
**Core assumption:** True influential features cause F-stat p-values to deviate from uniform; requires mean cluster separation ≥ (log p)/√n.  
**Break condition:** Extremely noisy pseudo-labels yield uniform F-stat p-values, ω(t) stays low, may miss weak signals; KS normal null assumption must hold.

### Mechanism 3
**Claim:** Laplacian eigenmap embedding after feature selection captures nonlinear manifold structure, enhancing clustering.  
**Mechanism:** Construct similarity graph on selected features (cosine-based Gaussian kernel, 8 neighbors), compute Laplacian eigenmap to K+2 dimensions, then k-means.  
**Core assumption:** Influential features lie on a low-dimensional nonlinear manifold; local geometry separates clusters.  
**Break condition:** If data is linear, PCA suffices; too few selected features destabilize graph; clusters not separated by local geometry hinder embedding.

## Architecture Onboarding
**Component map:** IFPCA initialization → Start iteration: compute F-stat & KS p-values → compute weight ω(t) via HC → form composite scores → HCT threshold → select features → normalize → Laplacian/PCA embedding (K+2 dims) → k-means clustering → check convergence (set-change rate ≤10% or max iterations) → if not converged, repeat with new pseudo-labels; else output labels and features.

**Critical path:** The iterative loop (steps 2-5) is critical; initialization must provide a non-random starting point. Weight computation directly influences feature selection and error propagation risk.

**Design tradeoffs:**
- PCA vs. Laplacian eigenmap: Laplacian captures nonlinearity but sensitive to graph parameters (neighbors, γ); PCA is simpler/faster but may miss structure.
- Threshold selection: HCT is parameter-free but asymptotic; may over/under-select in finite samples.
- Weight constant c: default 0.6; smaller c emphasizes unsupervised signal early; robustness for 0.4–0.6.

**Failure signatures:**
- Initialization fails: IFPCA selects too few/many features (check HCT threshold sanity).
- Weight ω(t) stays near 0: pseudo-labels remain unreliable, iteration may not improve.
- Feature set oscillates or grows: instability in scoring or thresholding.
- Embedding collapses: selected features too few, affinity matrix sparse, Laplacian embedding poor.

**First 3 experiments:**
1. Synthetic linear Gaussian: Generate data with known sparse influential features (strong/weak signals). Compare i-IF-Lap vs. IFPCA on TPR/FDR and clustering accuracy.
2. Synthetic nonlinear manifold: Sample from nonlinear 2D manifold, project to high dimensions with influential features. Compare i-IF-Lap vs. i-IF-PCA; expect i-IF-Lap higher accuracy.
3. Real microarray dataset (SRBCT): Run i-IF-Lap with both embeddings; measure Accuracy and ARI. Expect i-IF-Lap outperforms baselines (KMeans, IFPCA, DeepCluster) and i-IF-PCA. Test downstream with UMAP/DeepCluster on selected features.

## Open Questions the Paper Calls Out
1. **Joint effects:** How to extend i-IF-Learn to select features with interactions rather than marginal effects? Current per-feature statistics ignore synergies.  
2. **Cluster-specific features:** Can it identify features important for specific clusters? Global set limits interpretability.  
3. **Automatic c selection:** How to choose constant c in weight function data-adaptively? Fixed range may not generalize.  
4. **Scalability:** Can i-IF-Learn handle very large datasets (n > 100k) given O(T n² s) complexity? Quadratic cost prohibitive.

## Limitations
- Empirical null correction details for F and KS statistics are missing, requiring inference from cited works.
- Fixed Laplacian parameters (γ=1, neighbors=8) may not generalize across datasets; sensitivity unknown.
- Convergence criterion formula ambiguous (likely set-difference ratio) and pseudo-label noise can suppress weight ω(t), weakening supervised signal.

## Confidence
- Iterative refinement: Medium (strong synthetic evidence but depends on sparse features and good initialization).
- Adaptive weighting: Medium (theory sound, but small-sample behavior and uniform p-value assumptions uncertain).
- Nonlinear embedding: Medium (Laplacian helps but parameter robustness unproven).

## Next Checks
