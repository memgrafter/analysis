# The Value of Graph-based Encoding in NBA Salary Prediction

## Quick Facts
- **ArXiv ID:** 2603.05671
- **Source URL:** https://arxiv.org/abs/2603.05671
- **Reference Count:** 14
- **Primary Result:** Static graph embeddings (RotatE) improved RMSE by 0.037 over a weak tabular baseline (0.654 vs. 0.691), rescued high-error veteran salaries in 44.8% of outlier cases, but caused a severe cold-start collapse for rookies (R² ≈ -0.31); benefits diminished when explicit team/agent IDs were provided.

## Executive Summary
This study investigates whether encoding relational structure via a knowledge graph can improve NBA player salary prediction beyond traditional tabular models. The authors constructed a heterogeneous player-season graph from on/off-court data, generated embeddings (e.g., RotatE), and concatenated them with performance stats for supervised learning. Under a strict matched-information framework preventing data leakage, static graph embeddings provided a significant orthogonal signal, reducing prediction error for veterans by capturing accumulated social capital (e.g., agency prestige). However, the approach failed catastrophically for rookies and offered no benefit when explicit team/agent identifiers were already included in the tabular data. The work reveals a maturity-dependent utility of graph representations and underscores that edge quality, not quantity, drives predictive value.

## Method Summary
The method follows a pipeline: (1) Align seasonal data (2020–2024) into player-season rows with tabular features (on-court stats, career controls). (2) Build a heterogeneous knowledge graph linking each PlayerSeason node to Team, Agent, Award, and Injury entities, applying strict temporal masking so only edges from the current or prior seasons are visible. (3) Generate node embeddings using static methods (RotatE, Node2Vec) or dynamic GNNs (e.g., GraphSAGE variants), training on the 2020–2022 graph(s). (4) Concatenate embeddings with tabular features and train a downstream regressor (Random Forest or XGBoost) to predict log-salary. (5) Evaluate on a held-out 2024 test set (668 player-seasons), compute RMSE/R², and run a Tri-State outlier analysis to measure rescue/misguidance rates. The matched-information design compares three regimes: Weak Baseline (stats + controls), Strong Baseline (adds explicit Team/Agent IDs), and Graph models (stats + controls + embeddings, IDs withheld).

## Key Results
- Static graph embeddings (RotatE) reduced test RMSE to 0.654 from 0.691 (Weak Baseline), a significant improvement; the Strong Baseline achieved 0.598, crowding out graph utility.
- Graph models rescued >$10M errors in 44.8% of high-error veteran outliers but misguided 20.5%; for rookies, they collapsed to R² ≈ -0.31, while tabular models remained positive.
- Dense heterogeneous graphs (including awards/injuries) underperformed simpler topologies focused on stable affiliations (Team/Agent), indicating edge quality outweighs quantity.

## Why This Works (Mechanism)
### Mechanism 1
Static graph embeddings provide an orthogonal signal that recovers latent institutional representations, improving salary prediction over a weak tabular baseline when explicit Team/Agent IDs are withheld. Embeddings like RotatE map nodes to vectors where proximity reflects structural similarity, capturing contextual factors (e.g., agency prestige) absent from performance stats. The core assumption is that network topology contains economically meaningful signals not linearly reducible to the provided tabular controls. Evidence: RotatE+Stats reduced RMSE to 0.654 vs. 0.691 (Weak Baseline). The benefit disappears when explicit IDs are given (Strong Baseline), evidencing a crowding-out effect.

### Mechanism 2
Graph embeddings exhibit a structural maturity dichotomy—they rescue valuation errors for veteran players by capturing accumulated social capital but catastrophically fail for rookie cold-starts due to sparse structural history. Veterans have stable, dense network affiliations (long-term team ties, established agents) that form a robust relational prestige signal; rookies lack such edges, so embeddings introduce detrimental variance. Core assumption: Veteran salaries are partially driven by accumulated relational capital encoded in network structure, while rookie salaries follow rule-based pricing determined by demographics. Evidence: Graph models achieved R² ≈ -0.31 on rookies, vs. positive R² for tabular models; veteran rescue rate was 44.8%.

### Mechanism 3
Overloading the knowledge graph with dense heterogeneous edges (e.g., awards, injuries) dilutes the core affiliation signal, causing underperformance compared to simpler topologies focused on stable team/agent relationships. The predictive value resides primarily in stable affiliation edges; adding many event-based edges introduces high-frequency noise that blurs institutional prestige representations. Core assumption: A small set of high-signal relationship types dominates salary prediction; additional edges contribute more noise than signal. Evidence: V2-Full (heterogeneous dynamic GNN) underperformed RotatE in RMSE; the paper concludes quality of edges outweighs quantity.

## Architecture Onboarding
**Component map:**  
Data ingestion -> Graph construction (with temporal masking) -> Embedding generation (static/dynamic) -> Feature fusion (concatenate embeddings with tabular) -> Downstream regression (RF/XGBoost) -> Evaluation (RMSE, R², Tri-State)

**Critical path:**  
1. Align all seasonal data (2020–2024) into player-season rows.  
2. Construct knowledge graph for each season with strict temporal masking (edges only if timestamp ≤ target season).  
3. Train embedding model (e.g., RotatE) on training-season graph(s); generate embeddings for train/val/test splits with no test-node leakage.  
4. Fuse embeddings with tabular features; train downstream regressor.  
5. Evaluate on 2024 test set; compute global metrics and run Tri-State outlier protocol.

**Design tradeoffs:**  
- Static vs dynamic embeddings: Static (RotatE) are transductive but simpler and less prone to oversmoothing; dynamic GNNs are inductive but may suffer structural lag and crowding-out.  
- Graph density: Simpler topologies (only Team/Agent) protect core affiliation signal; dense event edges risk noise dilution.  
- Downstream regressor: XGBoost may absorb explicit patterns quickly, reducing marginal graph utility; Random Forest shows clearer graph benefits.  
- Matched-information strictness: Strict masking prevents leakage but limits model capacity; baseline choice determines detectable graph value.

**Failure signatures:**  
- Rookie cold-start collapse (negative R²) indicates embeddings are unsuitable for players with sparse graph history.  
- High misguidance rate vs Strong Baseline, especially for inductive GNNs, suggests crowding-out and structural lag.  
- Oversmoothing of superstar nodes (e.g., Giannis) leading to underestimation, typical of mean-aggregation GNNs.  
- Legacy hangover: systematic overestimation of aging veterans due to excessive reliance on historical prestige.

**First 3 experiments:**  
1. **Baseline comparison:** Train Weak Baseline (stats+time) and Strong Baseline (adds explicit IDs) with Random Forest. Then add RotatE embeddings to Weak Baseline. Verify RMSE improvement (0.654 vs. 0.691) as in Table I.  
2. **Cold-start validation:** Isolate test-set rookies (first-season players). Compare R² of Weak Baseline, RotatE+Stats, and Strong Baseline. Expect graph models to be negative or near zero, tabular to be >0.  
3. **Tri-State outlier analysis:** Using Weak Baseline residuals, define eligible outliers (75th percentile threshold). Compute rescue and misguidance rates for RotatE+Stats. Expect rescue ≈44.8% and misguidance ≈20.5% (Figure 2). Repeat against Strong Baseline to observe crowding-out.

## Open Questions the Paper Calls Out
- **Open Question 1:** How can a hybrid model dynamically switch between tabular and graph representations based on player maturity (e.g., tenure or draft year), and does such a system improve overall prediction accuracy while maintaining low misguidance rates across cohorts?  
  *Basis:* The conclusion states optimal systems must be maturity-aware hybrids, but no such hybrid is implemented.  
  *Resolution evidence:* Build a hybrid with a maturity classifier (years since draft) routing to tabular-only or graph-augmented regressors; evaluate global RMSE and Tri-State rates vs. standalone models.

- **Open Question 2:** Which specific edge types (e.g., agent affiliations, team tenure, award histories) are most predictive of veteran salary premiums, and can selective pruning of low-value edges enhance performance by reducing noise?  
  *Basis:* Dense heterogeneous graphs underperformed; quality over quantity is emphasized, but edge-type contributions are unanalyzed.  
  *Resolution evidence:* Perform systematic edge-type ablation: remove each relation type iteratively and re-evaluate RMSE/rescue rates for veterans; use gradient-based attribution on embeddings to identify influential edges.

- **Open Question 3:** What architectural modifications to dynamic GNNs (e.g., attention, skip connections) can mitigate the high misguidance rates observed when explicit metadata is available, without sacrificing veteran rescue benefits?  
  *Basis:* Tri-State shows dynamic GNNs misguidance up to 52.4% vs. Strong Baseline, attributed to structural lag and hub oversmoothing; only fixed GNN designs were tested.  
  *Resolution evidence:* Replace mean aggregation in V2-Ind with GAT or jump knowledge networks; retrain and compare rescue/misguidance rates and global metrics against original V2-Ind.

- **Open Question 4:** Can temporal graph neural networks (e.g., TGN, EvolveGCN) that model season-to-season evolution reduce the severe cold-start collapse (R² ≈ -0.31) for rookies observed with static graph embeddings?  
  *Basis:* Static embeddings and simple dynamic GNNs treated seasons as independent snapshots; continuous-time graph learning was not explored.  
  *Resolution evidence:* Implement a temporal GNN ingesting season-ordered edges and node features; evaluate on cold-start rookies, comparing R²/RMSE to static embeddings; analyze if temporal modeling captures early-career patterns.

## Limitations
- **Feature ambiguity:** The exact composition of on-court stats and career controls (x, c) is not enumerated, altering model inputs and outputs.
- **Graph construction underspecification:** Edge types, directionality, and precise temporal masking implementation (admissibility function A(e,s)) are unclear; the encoding of “cumulative intensity” in V2-Full MG is ambiguous.
- **Evaluation thresholds:** τerr values (75th percentile residual threshold) are approximate; cold-start definition (“players absent from training seasons”) could refer to table or graph absence, affecting cohort identification.

## Confidence
- **Static embeddings orthogonal value (RMSE improvement with Weak Baseline):** Medium (improvement clear but graph construction details uncertain)
- **Crowding-out effect (benefit vanishes with Strong Baseline):** Medium (plausible but ID encoding unclear)
- **Maturity dichotomy (veteran rescue vs. rookie collapse):** Medium (striking but relies on cold-start definitions)
- **Dense graph underperformance (quality over quantity):** Low (based on limited comparisons and ambiguous edge types)
