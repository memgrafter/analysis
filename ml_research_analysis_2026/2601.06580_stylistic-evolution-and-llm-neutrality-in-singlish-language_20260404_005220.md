# Stylistic Evolution and LLM Neutrality in Singlish Language

## Quick Facts
*   **arXiv ID:** 2601.06580
*   **Source URL:** https://arxiv.org/abs/2601.06580
*   **Reference count:** 17
*   **Primary result:** Singlish shows a monotonic decrease in stylistic similarity over a decade, and no tested LLM (including fine-tuned variants) can generate outputs that are temporally neutral across years.

## Executive Summary
This study investigates the diachronic evolution of Singlish in digital messages (2012–2021) and evaluates whether large language models (LLMs) can generate text that is stylistically neutral with respect to time. A classifier-based similarity framework was developed, using both handcrafted linguistic features and encoder embeddings to quantify stylistic divergence between year-specific corpora. Analysis of real data (CoSEM) confirms a steady increase in divergence with larger temporal gaps, driven significantly by increasing message length and rising formality metrics. When applied to outputs from several state-of-the-art LLMs (Qwen, Mistral, SeaLLM, DeepSeek-R1), both prompting and fine-tuning failed to produce temporally neutral generations; similarity scores varied significantly across target years for all models.

## Method Summary
The core methodology involves a stylistic similarity metric derived from a binary classifier's accuracy. For any two year-specific subsets of the CoSEM dataset, features are extracted via two parallel pipelines: (1) handcrafted lexico-structural, pragmatic, and LIWC psycholinguistic metrics, and (2) embeddings from a sentence-transformer model. A Gradient Boosting Classifier is trained to distinguish the two years. Its test accuracy is transformed into a normalized similarity score `S = 1 - 2|acc - 0.5|`, where `S`≈1 indicates high similarity and `S`≈0 indicates low similarity. To assess an LLM's temporal neutrality, its generated texts are compared against each yearly slice of CoSEM using the same pipeline, and the standard deviation of the resulting ten similarity scores is computed (low σ = neutral). SHAP analysis is used to interpret the features most responsible for temporal discrimination.

## Key Results
*   Real Singlish messages show a monotonic decrease in stylistic similarity (`S`) as the year gap increases, for both handcrafted and encoder features (e.g., encoder `S` drops from 84.3% for 1-year gap to 53.8% for 9-year gap).
*   SHAP analysis identifies **message length** (`length_char`) as the strongest discriminator of temporal origin; LIWC trends indicate increased formality (rising `Clout`, `Analytic`) and decreased affective expression over the decade.
*   All tested LLMs (Qwen, Mistral, SeaLLM, DeepSeek-R1) and prompting strategies exhibit **significant variance** in similarity scores across the 10 target years, failing to produce temporally neutral Singlish. Fine-tuning improved surface-level realism for some models but did not eliminate temporal bias.

## Why This Works (Mechanism)

### Mechanism 1
*   **Claim:** Stylistic similarity between temporally separated text corpora can be quantified by training a binary classifier to distinguish between them and transforming classification accuracy into a normalized score.
*   **Mechanism:** A classifier (Gradient Boosted) is trained on feature vectors from two year-specific text sets. Its ability to correctly classify a held-out text as originating from one year or the other indicates stylistic divergence. Accuracy near 50% (chance) implies high similarity; deviation implies lower similarity. This deviation is normalized into a similarity score `S = 1 - 2|acc - 0.5|`.
*   **Core assumption:** A classifier learns to exploit genuine, systematic stylistic differences between corpora, not noise or idiosyncratic year-specific events. The similarity metric linearly maps discriminative power onto an interpretable scale.
*   **Evidence anchors:**
    *   [abstract] "A stylistic similarity framework was developed... to quantify diachronic divergence via a classifier accuracy-based similarity metric."
    *   [section 3.3] Formal definition of the similarity metric `S`.
    *   [section 5.1] Application shows monotonic decrease in `S` with increasing year gap for both encoder and handcrafted features, supporting the mechanism's validity.
*   **Break condition:** If classifier accuracy does not systematically differ from 50% for increasing temporal gaps, the mechanism fails to capture diachronic signal. If SHAP analysis reveals that top features are non-linguistic artifacts (e.g., metadata, platform-specific tags), the learned signal may not reflect intended stylistic evolution.

### Mechanism 2
*   **Claim:** SHAP (SHapley Additive exPlanations) values applied to a classifier's feature importance can identify interpretable linguistic features that drive temporal discrimination, linking neural representational divergence to human-understandable changes.
*   **Mechanism:** After training the classifier on handcrafted features for a given year-pair or gap, SHAP computes the contribution of each feature to individual predictions. Aggregating absolute SHAP values across predictions yields a global importance score per feature. Features with consistently high importance across temporal gaps are key drivers of diachronic differentiability.
*   **Core assumption:** Features with high SHAP values for temporal discrimination are causally linked to the diachronic process (e.g., evolving formality) rather than being spurious correlates. The handcrafted feature set sufficiently captures the primary axes of stylistic change.
*   **Evidence anchors:**
    *   [section 5.1] "SHAP analysis identified message length as the strongest temporal discriminator... LIWC trends revealed increased formality (rising Clout, Analytic) and decreased affective expression."
    *   [figure 3] Plot of SHAP values vs. year-gap for handcrafted features, showing length-related features dominate.
*   **Break condition:** If SHAP importance is dominated by features with no plausible link to language change (e.g., random character n-grams), the mechanism confounds noise with signal. If psycholinguistic trends (LIWC) contradict SHAP's top features, the interpretative link breaks.

### Mechanism 3
*   **Claim:** The temporal neutrality of an LLM's generated text is assessed by measuring the variance of its similarity score (vs. real yearly corpora) across target years. Low variance indicates the model produces a style agnostic to specific years.
*   **Mechanism:** For each LLM output set, the same stylistic similarity pipeline is run against *each* yearly slice of the CoSEM data (2012–2021), producing 10 similarity scores. The standard deviation (σ) of these scores is the neutrality metric. A model that generates "averaged" or "timeless" Singlish should have similar similarity to all years, yielding low σ.
*   **Core assumption:** The real-world CoSEM data for each year contains a stable, representative "target" style for that period. LLM outputs are compared *only* on the feature space defined by the classifier trained on real data, so variance reflects stylistic drift in that space.
*   **Evidence anchors:**
    *   [section 3.4] Definition of the temporal neutrality metric (standard deviation of similarity scores across years).
    *   [section 5.2] "Variance tests confirmed that similarity scores varied significantly across years for all models... none of the models produced temporally neutral outputs."
    *   [table 1] Lists mean and std for each model/prompt combo.
*   **Break condition:** If the yearly CoSEM subsets are too small or unstable, their "target" styles may vary spuriously, making variance an unreliable neutrality measure. If the feature extractor/classifier is itself temporally biased (e.g., trained on a specific era), all comparisons inherit that bias.

## Foundational Learning
*   **Concept: Diachronic Sociolinguistics**
    *   **Why needed here:** The entire study hinges on understanding that language, especially a dynamic contact variety like Singlish, changes systematically over time due to social, technological, and generational shifts. This frames the research questions and interprets feature trends (e.g., increased formality as "selective formalization").
    *   **Quick check question:** Why might a creole language like Singlish show increased `Clout` and `Analytic` scores (from LIWC) over a decade in digital messages?
*   **Concept: Classifier-Based Similarity Metrics**
    *   **Why needed here:** The core methodological innovation is using a supervised classifier's accuracy as a proxy for stylistic similarity. This moves beyond simple distance metrics (e.g., cosine similarity on embeddings) to a *learned* notion of distinction relevant to the specific corpus.
    *   **Quick check question:** What is the key limitation of using a pre-trained embedding's cosine similarity directly for diachronic comparison, which this paper's method aims to overcome?
*   **Concept: Feature Attribution (SHAP) for Interpretability**
    *   **Why needed here:** To move from the black-box conclusion "styles diverged" to the interpretable insight "messages got longer, self-references decreased." SHAP bridges the gap between the classifier's high-dimensional decisions and linguistically meaningful trends.
    *   **Quick check question:** Why is the high SHAP importance of `length_char` for temporal discrimination potentially less surprising than a high importance for a specific particle like `lah`?

## Architecture Onboarding
*   **Component map:**
    Data Ingestion (CoSEM, LLM outputs) -> Feature Extraction (Handcrafted + Encoder) -> Classifier & Similarity Engine (GradientBoost -> S score) -> Diagnostics (SHAP, LIWC trends, Variance calc) -> LLM Evaluation Harness (Prompting/FT/Generation)
*   **Critical path:** `CoSEM by year` → `Feature Extraction (A+B)` → `Classifier Training (year-pair)` → `Similarity Score (S)` → `Plot S vs. Year Gap (real data)` → `LLM Gen` → `Feature Extraction (A+B) on LLM output` → `Similarity vs. each CoSEM year` → `Compute variance (σ) for neutrality`.
*   **Design tradeoffs:**
    *   Handcrafted vs. Encoder Features: Handcrafted offers interpretability but may miss subtle patterns; encoder captures complexity but is opaque. The study uses both, finding parallel trends.
    *   Classifier Choice: Gradient Boosting was chosen for simplicity/power. A more complex model (e.g., neural net) might capture non-linearities but risk overfitting to year-specific noise.
    *   LIWC Aggregation: Required due to short message lengths. Sacrifices per-message resolution for stable yearly trends.
*   **Failure signatures:**
    *   Real-data analysis: Non-monotonic `S` vs. gap, or diverging trends between handcrafted/encoder features.
    *   LLM analysis: No significant variance in similarity scores across years (false neutrality) or uniformly low similarity (all outputs unrealistic).
    *   Feature importance: SHAP dominated by non-linguistic features (e.g., message length alone without linguistic context).
*   **First 3 experiments:**
    1.  **Reproduce real-data diachronic trend:** Train classifier on 2012 vs. 2013, 2012 vs. 2014,... 2012 vs. 2021. Verify `S` decreases monotonically with gap for both feature sets (as in Figure 4).
    2.  **Validate SHAP drivers:** For a fixed gap (e.g., 5 years), run SHAP on the classifier. Confirm top features are length-related and that their directional change aligns with known formalization trends (e.g., longer messages, fewer first-person pronouns).
    3.  **Confirm LLM temporal bias:** For one model (e.g., Qwen), generate 100 texts per prompt. Compute similarity against each year (2012–2021). Perform one-way ANOVA on the 10 scores. Expect significant p-value (>0.05), rejecting temporal neutrality.

## Open Questions the Paper Calls Out
*   **Open Question 1:** Does the diachronic evolution pattern of Singlish observed in SMS messages hold for other digital communication platforms such as social media?
    *   **Basis in paper:** [explicit] The limitations section states the study focuses on SMS messages and may not generalize to social media text, where interactional norms differ, and future work should extend to such platforms.
    *   **Why unresolved:** The current analysis is limited to the CoSEM SMS dataset; other platforms (e.g., Twitter, Instagram) have different stylistic conventions and user demographics, which could influence the direction or magnitude of linguistic change.
    *   **What evidence would resolve it:** Collect comparable yearly corpora from target social media platforms, extract the same handcrafted and encoder features, and apply the stylistic similarity framework. Consistency of the monotonic decrease in similarity across platforms would confirm generalizability; divergence would indicate platform-specific evolution.
*   **Open Question 2:** What aspects of LLM architecture or training cause persistent temporal bias in Singlish generation despite fine-tuning?
    *   **Basis in paper:** [explicit] Results show fine-tuning does not eliminate diachronic signals; the discussion attributes this to "architectural and representational factors" but does not specify them.
    *   **Why unresolved:** The paper tests prompting and LoRA fine-tuning but does not probe internal model mechanics (e.g., attention patterns, positional embeddings) to identify which components retain year-specific information.
    *   **What evidence would resolve it:** Conduct controlled ablation studies (e.g., modifying positional encoding, freezing layers) and representational similarity analysis between model hidden states and annual CoSEM embeddings. If temporal signals localize to specific layers or heads, targeted interventions could reduce bias.
*   **Open Question 3:** How can computational models better represent the socio-pragmatic functions of low-frequency Singlish particles (e.g., *lah*, *leh*) beyond surface frequency?
    *   **Basis in paper:** [inferred] The SHAP analysis found most particles contributed minimally to diachronic discriminability, yet the discussion cautions that frequency-based metrics may underestimate their pragmatic importance and that particles remain essential sociolectal markers.
    *   **Why unresolved:** Current handcrafted features treat particles as binary presence/absence; they ignore positional, intonational, and discourse-level functions that give particles nuance.
    *   **What evidence would resolve it:** Design features that capture particle context (e.g., clause position, preceding/following punctuation, co-occurrence with certain verbs) and test whether these improve classification of temporal origin or align better with human judgments of authenticity. Qualitative case studies could ground these features pragmatically.
*   **Open Question 4:** Are there abrupt shifts or nonlinear patterns in Singlish diachronic change that the current similarity metric smooths over?
    *   **Basis in paper:** [inferred] The analysis groups year-pairs by temporal gap and observes a monotonic decrease in similarity, which suggests gradual change. However, no explicit test for change points or external triggers (e.g., policy shifts, tech adoption) is performed.
    *   **Why unresolved:** The similarity metric aggregates across all messages per year; it may mask shorter-term volatility or sudden jumps that could reflect sociolinguistic events.
    *   **What evidence would resolve it:** Apply change point detection algorithms (e.g., Bayesian online changepoint detection) on yearly feature distributions (e.g., LIWC scores, particle frequencies). Correlate detected shifts with historical events (e.g., introduction of smartphones, language campaigns) to assess causality.

## Limitations
*   Fine-tuning hyperparameters (LoRA rank, LR, epochs) are unspecified; optimal settings could affect neutrality outcomes.
*   Train-test split details (stratification, seeds) are unclear; classifier may overfit to year-specific noise.
*   Yearly CoSEM subset stability (sample size, topic distribution) unverified; could introduce spurious variance.

## Confidence
*   **Singlish shows monotonic diachronic divergence.** **High** – consistent across two feature modalities and validated via classifier accuracy trends.
*   **Length-related features drive temporal discrimination.** **Medium** – SHAP importance plausible but may be confounded by non-linguistic factors; requires ablation.
*   **LLMs fail to generate temporally neutral Singlish.** **Medium** – tested on multiple models/prompts but fine-tuning regime not fully optimized; neutrality metric assumes stable yearly targets.
*   **Fine-tuning improves surface realism.** **Medium** – based on qualitative observation; lacks quantitative realism metrics.

## Next Checks
1.  **Classifier robustness:** Repeat similarity analysis with multiple classifier types (Random Forest, MLP) and random seeds; compute confidence intervals for `S` vs. gap and test monotonicity significance.
2.  **Feature ablation:** Remove length-dominated features from handcrafted set; re-evaluate similarity trend. If trend persists, temporal signal is not solely due to length.
3.  **Fine-tuning optimization:** Perform grid search over LoRA hyperparameters (rank, α, LR, epochs) for Qwen and Mistral; reassess neutrality (σ) to confirm failure is not due to suboptimal training.
