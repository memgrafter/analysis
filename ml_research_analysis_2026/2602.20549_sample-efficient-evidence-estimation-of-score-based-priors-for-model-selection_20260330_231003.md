# Sample-efficient evidence estimation of score based priors for model selection

## Quick Facts
- **arXiv ID**: 2602.20549
- **Source URL**: https://arxiv.org/abs/2602.20549
- **Reference count**: 40
- **Primary result**: DiME achieves 0.3-1.5% relative error on a 1000-D Gaussian mixture, matching or beating TI, AIS, SMC while using only ~20 posterior paths and no explicit prior score evaluation.

## Executive Summary
DiME (Diffusion-based Model Evidence) provides a sample-efficient method for computing Bayesian model evidence when the prior is defined via a diffusion model. The key insight is that evidence can be estimated by integrating KL divergence between posterior and prior along the diffusion time-marginals, using intermediate samples naturally produced during diffusion posterior sampling. This approach avoids the intractable direct evaluation of prior scores while requiring only a handful of posterior paths. The method demonstrates strong performance on synthetic Gaussian mixtures and real M87* black hole imaging tasks, correctly identifying the most likely prior and validating in-distribution models via z-scores.

## Method Summary
DiME estimates model evidence by integrating KL divergence along diffusion time-marginals using intermediate samples from posterior sampling methods like DAPS or PnP-DM. The core identity transforms evidence computation into a tractable time integral that avoids explicit prior score evaluation. For each timestep, DiME computes squared score norms using two independent posterior samples via either high-noise or low-noise estimators, selecting the lower-variance option. An improved Gaussian covariance approximation enhances accuracy in high-noise regimes. The method requires only ~20 posterior paths, making it significantly more sample-efficient than traditional methods like TI, AIS, or SMC.

## Key Results
- On a 1000-D Gaussian mixture, DiME achieves 0.3-1.5% relative error vs. analytic evidence, matching or beating TI, AIS, SMC
- On MNIST phase-retrieval tasks, DiME consistently selects the correct digit-specific diffusion prior from ten candidates while SMC fails
- On real M87* black hole data, DiME identifies GRMHD simulations as most likely prior and confirms in-distribution validity (z-score -0.81)
- Gaussian-approx DAPS variant provides 7× speedup with comparable accuracy

## Why This Works (Mechanism)

### Mechanism 1: KL Integration Along Diffusion Path
Model evidence `log p(y)` is expressed as an integral over diffusion time-marginals of the KL divergence between posterior and prior. This transforms the intractable KL term at `x0` into a tractable time integral using the probability flow ODE continuity equations. The method relies on smooth marginal distributions throughout the diffusion path.

### Mechanism 2: Intermediate Sample Reuse from Posterior Sampling
Diffusion posterior samplers naturally generate intermediate states `x_t` and denoised samples `˜x0` that provide cheap access to required expectations. These samples enable estimation of the score term without needing the prior score, leveraging the annealing process inherent in methods like DAPS.

### Mechanism 3: Adaptive High/Low-Noise Scoring with Variance Control
Two complementary score estimators (Θ_high for high noise, Θ_low for low noise) have complementary variance properties across the diffusion timeline. Selecting the lower-variance option per timestep yields robust overall evidence estimates. The method uses unbiased estimators requiring two independent samples per state.

## Architecture Onboarding

**Component map**: Diffusion model -> Posterior sampler (DAPS/PnP-DM) -> Estimator module -> Covariance approximation -> Evidence computation

**Critical path**:
1. Choose diffusion schedule and posterior sampler
2. Run DAPS/PnP-DM, storing all intermediate `x_t` samples
3. For each `x_t`, compute E[x0|x_t], draw two `˜x0` via Langevin with guidance
4. Compute Θ_high and Θ_low, select lower variance, accumulate integral
5. Combine with E[log p(y|˜x0)] to obtain final evidence

**Design tradeoffs**:
- Standard marginals (DAPS) vs Unnormalized (PnP-DM): DAPS yields normalized evidence and better out-of-distribution performance; PnP-DM is simpler but requires constant factor for comparison
- Covariance approximation: Full vs diagonal vs approximation with Σ0; full improves accuracy but costs O(d³) memory
- Number of paths: More paths reduce variance but linearly increase compute; 20-50 paths typically sufficient
- Annealing steps: More steps improve integral accuracy but increase memory for storing samples

**Failure signatures**:
- Evidence estimates vary wildly across paths (high variance) → too few paths or poor Σ_{x0|x_t}
- Model selection picks wrong prior when ground truth is out-of-distribution → PnP-DM path bias or DAPS with original covariance heuristic
- All evidence estimates cluster near same value for different priors → insufficient annealing steps or sampling error dominates

**First 3 experiments**:
1. Setup mixture of Gaussians with known analytic evidence; test in-distribution, out-of-distribution, saddle point; verify DiME's bias remains <~1% across conditions
2. Run MNIST phase retrieval with ten digit-specific diffusion priors; confirm DiME selects correct model while SMC fails
3. Apply to M87* data with five candidate priors; verify GRMHD is selected and compute z-score for prior validation using in-distribution simulations

## Open Questions the Paper Calls Out

### Open Question 1
Can DiME be theoretically guaranteed for arbitrary annealing paths, and do different paths yield significantly different evidence estimates?
*Evidence needed*: Theoretical error bounds as a function of path smoothness; empirical comparison across diverse paths on tasks with known evidence.

### Open Question 2
How robust is DiME's Gaussian prior approximation for non-Gaussian priors, and can more flexible approximations reduce bias?
*Evidence needed*: Evaluate DiME with non-Gaussian approximations (e.g., mixture models, normalizing flows) on synthetic non-Gaussian priors; measure evidence estimation error.

### Open Question 3
Can we reduce the number of required posterior sample paths in DiME without increasing variance, e.g., by improved score estimation?
*Evidence needed*: Develop and test low-variance estimators (e.g., control variates, coupled samples) showing fewer paths achieve same accuracy.

### Open Question 4
How does DiME perform on large-scale, high-dimensional inverse problems (e.g., full-resolution EHT imaging) and what are the main scaling bottlenecks?
*Evidence needed*: Application to high-resolution real-world dataset with profiling; identification of computational bottlenecks and mitigation strategies.

## Limitations
- Performance depends critically on posterior sampling method accurately targeting correct marginals throughout annealing
- Covariance approximation may break down for strongly non-Gaussian priors or high-dimensional cases
- Method requires tuning of multiple hyperparameters (annealing steps, Langevin steps, learning rates) not fully specified
- Scalability to extremely high dimensions (>10k) is uncertain due to cubic covariance cost

## Confidence

**High confidence**: Mathematical derivation of KL integration identity and variance analysis of Θ_high/Θ_low estimators
**Medium confidence**: Empirical performance on synthetic and real data demonstrates viability, but absence of public data limits independent verification
**Low confidence**: Behavior in pathological cases (multimodal posteriors, strong prior-data conflicts, far-from-Gaussian priors) not fully characterized
