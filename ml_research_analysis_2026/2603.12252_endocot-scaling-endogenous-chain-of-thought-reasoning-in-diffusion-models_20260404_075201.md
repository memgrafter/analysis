# EndoCoT: Scaling Endogenous Chain-of-Thought Reasoning in Diffusion Models
## Quick Facts
- arXiv ID: 2603.12252
- Source URL: https://arxiv.org/abs/2603.12252
- Reference count: 40
- Primary result: EndoCoT achieves 92.1% average accuracy on four reasoning benchmarks, outperforming the strongest baseline by 8.3 percentage points.

## Executive Summary
Diffusion models, when paired with multimodal LLMs, typically rely on static text guidance that fails at complex multi-step reasoning. EndoCoT introduces iterative thought guidance, which recursively refines latent "thought" states within the MLLM across diffusion steps, and terminal thought grounding, which aligns the final state with ground-truth reasoning to prevent drift. On Maze, TSP, Sudoku, and VSP benchmarks, EndoCoT reaches 92.1% average accuracy, with gains of 25–40% on harder tasks like Maze-32 and Sudoku-35.

## Method Summary
EndoCoT builds on a Diffusion Transformer (DiT) with a pretrained MLLM (Qwen-Image-Edit-2511) as the reasoning engine. It introduces iterative thought guidance: at each of T steps, the MLLM takes the previous latent state h^{τ-1} as high-dimensional input (bypassing token embedding) to produce an updated state h^τ, which conditions a full denoising trajectory to generate an intermediate image I^τ. Terminal thought grounding computes a reference embedding from ground-truth reasoning steps and enforces an L2 loss on the final state h^T to prevent semantic drift. Training uses a two-stage progressive strategy: Stage 1 optimizes flow matching loss on all intermediate steps to learn reasoning; Stage 2 freezes intermediate gradients and optimizes only the final output to preserve visual quality. The model is fine-tuned via LoRA on both DiT and MLLM components.

## Key Results
- Average accuracy of 92.1% across Maze, TSP, Sudoku, and VSP benchmarks.
- Outperforms the strongest baseline by 8.3 percentage points.
- Gains of 25–40% on complex tasks (Maze-32, Sudoku-35) compared to prior work.

## Why This Works (Mechanism)
### Mechanism 1
Claim: EndoCoT enables genuine multi-step reasoning by iteratively refining latent "thought" states within the MLLM, creating an endogenous Chain-of-Thought process aligned with the diffusion denoising steps.
Mechanism: At each of T reasoning steps, the current latent thought state h^τ is recursively updated by feeding the previous state h^{τ-1} back into the MLLM as a high-dimensional input (bypassing the discrete token embedding lookup). This updated state h^τ then conditions a full DiT denoising trajectory to generate an intermediate visual output I^τ.
Core assumption: The MLLM's internal representations can be coherently and meaningfully refined over continuous, iterative passes, and this refined state provides progressively better conditioning for the DiT's spatial grounding.
Evidence anchors:
- [abstract] "iteratively refining latent thought states within the MLLM (iterative thought guidance)... enabling step-by-step reasoning aligned with the denoising process."
- [section 4.2.1] "The reasoning process is formulated as a sequence of hidden state updates... h^τ = e_{L+1}^⊤ f_φ([P; h^{τ-1}])... Crucially, h^{τ-1} directly serves as a high-dimensional input to the first layer of f_φ."
- [section 3] Analysis shows the MLLM handles the "bulk of logical reasoning" but a "single forward pass... is insufficient for complex tasks."
Break condition: The mechanism fails if the MLLM cannot maintain a coherent reasoning trajectory across iterations, leading to state divergence or collapse into repetitive/unmeaningful patterns (as seen in the "explicit token" ablation failure).

### Mechanism 2
Claim: Terminal Thought Grounding prevents cumulative drift in the latent reasoning trajectory by aligning the final latent state with an explicit textual supervision signal derived from the ground-truth reasoning steps.
Mechanism: An auxiliary reference embedding h^ref is computed from the ground-truth reasoning chain and input. An L2 (Semantic) loss ℒ_align forces the model's final reasoning state h^T to match this reference, acting as a regularizer.
Core assumption: Purely visual supervision on intermediate steps is insufficient to prevent semantic drift in the high-dimensional latent reasoning space over many iterative updates. A direct textual anchor is needed.
Evidence anchors:
- [abstract] "terminal thought grounding module is applied to ensure the reasoning trajectory remains grounded in textual supervision by aligning the final state with ground-truth answers."
- [section 4.2.2] "aligns the final reasoning state h^T with this reference using an L2 (Semantic) loss... preventing drift in the latent reasoning states."
- [section 5.2, Table 2] Ablation shows "w/o semantic loss" leads to severe degradation on complex mazes (ACC: 14% vs 90% on Maze-32), confirming its role as a crucial regularizer.
Break condition: The grounding signal is ineffective or harmful if the reference h^ref is poorly constructed (e.g., not representing a valid reasoning chain) or if the alignment loss overwhelms the primary visual generation objective, degrading image quality.

### Mechanism 3
Claim: Progressive Training Strategy resolves an objective conflict between learning robust multi-step reasoning dynamics (which requires supervision on all intermediate I^τ) and achieving high-fidelity final output quality (which may require different optimization focuses).
Mechanism: A two-stage process: Stage 1 trains with flow matching loss on all reasoning steps to build the reasoning capability. Stage 2 freezes gradients for intermediate steps (τ < T) and computes loss only on the final output (τ = T) to consolidate visual accuracy without destroying the learned reasoning chain.
Core assumption: The gradients from optimizing intermediate visual states and the final state can be conflicting. Decoupling their learning phases prevents the model from sacrificing reasoning coherence for final output quality or vice versa.
Evidence anchors:
- [section 4.2.3] "Reasoning steps and final outputs serve distinct objectives... Directly optimizing both objectives simultaneously can lead to conflicting gradients. We therefore adopt a two-stage progressive training strategy."
- [section 5.2, Table 6] Single-stage training yields much lower accuracy (14% on Maze-32) compared to the proposed two-stage approach (90%).
- [section E.2, Fig. 10] Illustrates that excessive Stage 2 training can make intermediate steps sparse, highlighting the delicate balance the strategy manages.
Break condition: The strategy fails if Stage 1 does not sufficiently establish a coherent reasoning chain before Stage 2 begins, or if Stage 2 training duration is too long, causing the intermediate reasoning process to degenerate as the model overfits to the final output.

## Architecture Onboarding
- **Component map**: MLLM (f_φ) takes prefix embeddings P and previous latent state h^{τ-1} to produce updated h^τ; DiT (f_ψ) conditions on h^τ to denoise and generate I^τ; Terminal Grounding Module computes h^ref from ground-truth and applies L2 loss on h^T; Training Controller orchestrates two-stage loss application.
- **Critical path**:
  1. Encode prompt and input to get P; initialize h^0.
  2. For τ = 1 to T: h^τ = MLLM([P; h^{τ-1}]); solve flow ODE conditioned on h^τ to get I^τ.
  3. At τ = T, compute ℒ_align = ||h^T - h^ref||_2.
  4. Apply total loss ℒ_total (ℒ_FM for all/selected steps + λℒ_align at T) with progressive stage logic.
- **Design tradeoffs**:
  - Implicit vs. explicit tokens: Implicit continuous tokens prevent error collapse but are less interpretable; explicit tokens caused failure (0% on Maze-32).
  - Semantic loss placement: Applying ℒ_align only at final step is optimal; intermediate application disrupts DiT-MLLM synergy.
  - Reasoning steps T: Larger T improves accuracy on hard tasks but increases latency; not adaptive.
- **Failure signatures**:
  - Without semantic loss: drastic accuracy drop on complex tasks, path repetition rate plummets (e.g., Maze-32: 14% vs 90%, repetition 67% vs 98%).
  - With explicit tokens: model degenerates into repetitive loops (e.g., "Rencontre Rencontre"), fails on all but simplest tasks.
  - Excessive Stage 2 training: intermediate reasoning steps become sparse/meaningless as model overfits to final output.
- **First 3 experiments**:
  1. Layer-wise sensitivity analysis: compute activation magnitudes across ViT, LLM, DiT layers; confirms peak sensitivity at LLM-DiT junction.
  2. Ablation: semantic loss: remove ℒ_align and train; expect severe accuracy and path repetition degradation on Maze-32.
  3. Inference-time scaling: vary reasoning step budget T at test time; expect monotonic improvement in accuracy and path repetition on hard tasks like Maze-32, with increased latency.

## Open Questions the Paper Calls Out
1. How can the model automatically determine the optimal number of reasoning steps without manual tuning? The Conclusion identifies this as future work; an adaptive halting mechanism would improve efficiency and usability.
2. Can EndoCoT be applied to a wider range of multimodal reasoning tasks beyond grid-based puzzles? The Conclusion mentions extending to broader tasks; current evaluation is limited to four deterministic planning benchmarks.
3. Can the model perform latent reasoning without relying on datasets that provide explicit intermediate step supervision? The Conclusion notes reliance on high-quality datasets with intermediate supervision; a self-supervised objective would broaden applicability.
4. What causes the performance drop in unified training compared to task-specific training, and how can multi-task interference be mitigated? Table 1 shows unified training yields lower accuracy (84.2% vs 92.1%); the paper does not analyze this gap.

## Limitations
- Exact implementation details for iterative latent state integration (bypassing token embeddings) are unspecified.
- Task-specific construction of ground-truth reasoning chains for terminal grounding lacks detailed methodology.
- Evaluation is confined to synthetic planning tasks (Maze, TSP, Sudoku, VSP); generalization to natural images or open-ended tasks is untested.

## Confidence
- Iterative latent reasoning: Medium (supported by explicit token ablation failure, but implementation details opaque)
- Terminal grounding necessity: High (catastrophic performance drop without semantic loss across complex tasks)
- Progressive training strategy: Medium (effective but sensitive to stage duration)
- Reported benchmark performance: High (consistent numbers within synthetic domain)
