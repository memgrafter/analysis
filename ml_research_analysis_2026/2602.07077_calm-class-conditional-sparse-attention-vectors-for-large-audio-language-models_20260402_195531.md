# CALM: Class-Conditional Sparse Attention Vectors for Large Audio-Language Models

## Quick Facts
- **arXiv ID:** 2602.07077
- **Source URL:** https://arxiv.org/abs/2602.07077
- **Reference count:** 12
- **Primary result:** CALM achieves absolute gains of up to 14.52% on audio classification, 1.53% on audiovisual classification, and 8.35% on spoofing detection compared to uniform-voting baselines.

## Executive Summary
Large audio-language models (LALMs) often underperform on discriminative tasks like classification compared to specialized models. Existing methods using sparse attention heads for few-shot classification assume all selected heads are equally reliable for every class. This work introduces CALM, which learns class-conditional importance weights over attention heads, allowing different heads to specialize for different semantic categories. Predictions are made via reliability-weighted soft voting. Across multiple audio, audiovisual, and spoofing benchmarks, CALM consistently improves over uniform-voting baselines, achieving absolute gains of up to 14.52% on audio classification, 1.53% on audiovisual classification, and 8.35% on spoofing detection. It remains competitive with fine-tuning-based approaches like linear probing and LoRA without requiring task-specific training.

## Method Summary
CALM is a few-shot adaptation method for frozen large audio-language models that leverages class-conditional sparse attention vectors. Given a few-shot support set, CALM first extracts representations from each attention head of the LALM and computes class centroids in each head's feature space. For each head and class, it estimates reliability by averaging the clamped margin (difference between true class posterior and next highest) over support examples. Then, for each class, it selects the top-k heads with highest reliability and normalizes their weights via softmax with temperature τw. During inference, for a test sample, CALM computes per-head class posteriors using cosine similarity to centroids (with L2 normalization and temperature τp), aggregates these posteriors weighted by the class-specific head weights, and predicts the class with highest aggregated probability. This approach allows different attention heads to specialize for different classes without any task-specific training, only requiring few-shot examples and hyperparameter tuning.

## Key Results
- Absolute gains up to 14.52% on audio classification (ESC-50), 1.53% on audiovisual classification (VGGVideo), and 8.35% on spoofing detection (LA-Spoof) over uniform-voting baselines.
- Consistent improvements across audio (VGGSound, AudioSet), audiovisual, and spoofing benchmarks.
- Competitive with fine-tuning methods (linear probing, LoRA) without requiring task-specific training.

## Why This Works (Mechanism)
CALM improves few-shot classification through three interconnected mechanisms:

**1. Class-conditional reliability weighting**: For each attention head j and class c, CALM computes the average clamped margin r_c^{(j)} over support examples, where margin is the posterior probability for true class minus the highest among others. This margin estimates the head's discriminative power for that class. At inference, per-head class posteriors are aggregated using normalized weights derived from these reliabilities via softmax with temperature τw. This allows heads to specialize for different semantic categories. Evidence: [abstract] states learning class-dependent importance weights; [section 3.2.2] details equations; corpus includes work on audio-specialist heads. Break condition: Margin estimates become high-variance with extremely small (e.g., 1-shot) or noisy support sets, leading to unreliable weights and potential overfitting.

**2. Sparse top-k head selection**: For each class, only the k heads with highest reliability r_c^{(j)} are retained; others receive zero weight. This sparsity filters out non-discriminative or noisy heads, focusing on expert heads. Core assumption: A small subset of heads carries most discriminative signal for any class; including all heads introduces noise. Evidence: [abstract] mentions "sparse attention vectors"; [section 3.2.2] Step 8 selects top-k; corpus shows sparse patterns isolate functional components. Break condition: If k is too low, useful heads are discarded; if too high, benefit diminishes as noisy heads are included.

**3. L2 normalization and temperature-scaled softmax**: Head activations and class centroids are L2-normalized before cosine similarity, ensuring comparable scales across heads. Cosine scores are converted to posteriors via softmax with temperature τp, controlling entropy and thus margin magnitudes used for reliability. Core assumption: Normalization puts activations on common hypersphere; temperature accounts for few-shot uncertainty. Evidence: [abstract] implies cosine similarity; [section 4.3.3] Table 4 shows removing L2 hurts accuracy; metric learning literature supports normalization. Break condition: If activations already normalized, additional L2 may harm; inappropriate τp yields over/underconfident posteriors, distorting margins.

## Foundational Learning
- **Few-shot nearest-centroid classification**: Needed because CALM builds class centroids from support examples in each head space. Quick check: Given support feature vectors for a class, compute centroid as mean; classify query by nearest centroid (e.g., cosine similarity).
- **Transformer attention heads**: Needed because CALM extracts representations from individual heads. Quick check: In a multi-head attention layer, each head produces a separate hidden state vector via attention computation before concatenation and projection.
- **Softmax with temperature and margin-based confidence**: Needed because CALM uses temperature-scaled softmax to convert similarities to probabilities, and margin (probability difference between top two classes) as a reliability measure. Quick check: Larger margin indicates higher confidence in the predicted class relative to alternatives.

## Architecture Onboarding
- **Component map**: Frozen LALM → Head Extractor → Centroid Builder → Reliability Estimator → Weight Selector → Inference Aggregator (During support, data flows through all components; during test, from Head Extractor to Inference Aggregator, which uses stored centroids and weights.)
- **Critical path**: 
  1. Support processing: Extract head features for support examples; compute centroids μ_c^{(j)}.
  2. Reliability estimation: For each (head, class), compute posteriors on support using Eq (5), margins via Eq (6), average to get r_c^{(j)}.
  3. Weight selection: For each class, select top-k heads by r_c^{(j)}; compute normalized weights w_c^{(j)} via Eq (12).
  4. Test inference: Extract head features for test; compute p_c^{(j)}(test); aggregate with weights; predict argmax_c p_c.
- **Design tradeoffs**:
  - Sparsity k: Smaller k increases focus but may discard useful heads; larger k includes more evidence but may dilute experts. Optimal k often intermediate.
  - Temperatures τp and τw: τp controls posterior sharpness; lower values yield higher margins but may overfit. τw controls weight distribution; higher values concentrate on top heads. Both require tuning, though pseudo-labeling helps.
  - Per-class vs. global head selection: CALM uses per-class allowing specialization but needs more shots; global (SAV) is simpler but less adaptive.
  - Computational cost: Head extraction linear in heads; weighting negligible. Main cost is forwarding LALM.
- **Failure signatures**:
  - No improvement over SAV, especially on large heterogeneous datasets (e.g., AudioSet), indicating noisy reliability estimates or lack of head specialization.
  - Degradation on binary tasks (e.g., LA-Spoof with Qwen2-Audio), suggesting overfitting with few shots.
  - High variance across random seeds, indicating unstable margin estimation.
  - Ablation sensitivity: If removing L2 norm does not hurt, normalization may not be critical, but paper shows consistent drops.
- **First 3 experiments**:
  1. Benchmark comparison: Evaluate CALM vs. SAV and zero-shot on audio (ESC-50, VGGSound, AudioSet), audiovisual (VGGVideo), and spoofing (LA-Spoof) datasets.
  2. Ablation study: Compare class-conditional vs. global weighting and remove L2 normalization or margin weighting.
  3. Sensitivity analysis: Vary number of shots and sparsity k to analyze data efficiency and head selection effects.

## Open Questions the Paper Calls Out
- **How can CALM’s reliability estimation be made robust to very few and noisy labels, particularly in binary classification?** Basis: Authors note sensitivity on LA-Spoof. Why unresolved: Real-world tasks often have scarce/noisy labels. Evidence needed: Robust reliability scores (e.g., regularized margins) evaluated under controlled noise.
- **Can CALM avoid dataset-specific hyperparameters (τp, τw, sparsity) and still perform well?** Basis: Current method requires tuning; pseudo-labeling helps but not fully. Why unresolved: Hyperparameter dependence undermines fine-tuning-free promise. Evidence needed: Self-tuning mechanism tested across datasets without validation.
- **Does CALM generalize to other model architectures (e.g., decoder-only LALMs) and modalities (e.g., video, tactile)?** Basis: Paper only tests two LALMs on audio/visual tasks. Why unresolved: Without broader evaluation, gains may be architecture-specific. Evidence needed: Application to multiple LALM families and non-audio modalities.
- **Why do attention heads in LALMs specialize by class, and can CALM’s weights be interpreted to identify each head’s semantic concepts?** Basis: Paper visualizes head usage but doesn't explain functional roles. Why unresolved: Understanding specialization could aid pruning, interpretability, transfer. Evidence needed: Probing tasks on individual heads (e.g., acoustic attributes) and analysis of high-weight heads.

## Limitations
- Margin estimates are unstable with 1-shot support or label noise, leading to unreliable class-specific weights.
- CALM underperforms on binary tasks with few shots (e.g., LA-Spoof), indicating overfitting risk.
- Hyperparameters (k, τp, τw) require dataset-dependent tuning, though pseudo-labeling mitigates this somewhat.

## Confidence
- Class-conditional weighting improves accuracy: Medium (gains on 4/5 benchmarks but degradation on one binary task).
- Sparse top-k selection filters noise: Medium (ablations and sensitivity analysis support, but optimal k varies).
- L2 normalization and temperature scaling are essential: High (consistent accuracy drops when removed).

## Next Checks

3. Evaluate CALM on a large-scale audiovisual benchmark (e.g., AudioSet with 500+ classes) to verify scalability of per-class head selection.
