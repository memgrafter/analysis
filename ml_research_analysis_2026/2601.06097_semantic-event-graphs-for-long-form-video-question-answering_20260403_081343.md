# Semantic Event Graphs for Long-Form Video Question Answering

## Quick Facts
- **arXiv ID**: 2601.06097
- **Source URL**: https://arxiv.org/abs/2601.06097
- **Reference count**: 1
- **Primary result**: Achieves 65.0% accuracy with 91.4% token reduction (3.47k vs 40.39k tokens per query) on long-video QA.

## Executive Summary
Long-form video question answering (LVQA) suffers from high token costs when processing raw frames. This paper introduces Semantic Event Graphs (SEG), a method that compresses video into a Temporal Scene Graph of human-object interaction (HOI) events. Objects are tracked with YOLOv11 and interactions are detected via proximity. A query-aware pruning module selects a relevant subgraph, which is verbalized and fed to Gemini 2.5 Flash. On five long videos (120 questions), SEG attains 65.0% accuracy using only 3.47k tokens per query, matching a full-log baseline (62.5% accuracy, 40.39k tokens) while reducing token usage by 91.4%. A short-context (last 30-second) baseline collapses to 2.5% accuracy, demonstrating the necessity of explicit long-range temporal memory.

## Method Summary
SEG constructs a semantic video representation in three stages: (1) object tracking with YOLOv11, (2) HOI detection using a proximity heuristic, and (3) aggregation into a Temporal Scene Graph spanning the video timeline. For a given question, a query-aware pruning step extracts the most relevant subgraph. This subgraph is verbalized into natural language text, which is then processed by a large language model (Gemini 2.5 Flash) to produce an answer. By avoiding raw frame or full transcript processing, the method achieves substantial token efficiency while preserving the semantic content needed for accurate LVQA.

## Key Results
- SEG achieves **65.0% accuracy** on long-video QA using only **3.47k tokens** per query.
- Matches the full-log baseline (**62.5% accuracy**) while reducing token usage by **91.4%** (40.39k vs 3.47k tokens).
- A short-context (30-second) baseline yields **2.5% accuracy**, underscoring the need for long-range temporal memory.

## Why This Works (Mechanism)
SEG replaces high‑dimensional frame sequences with a compact graph of semantic events. Human‑object interactions are detected and organized temporally, providing a structured summary that retains information crucial for answering questions. Query‑aware pruning further discards irrelevant events, minimizing noise and token load. The verbalized graph is fully compatible with LLMs, enabling accurate reasoning without ever processing raw video data.

## Architecture Onboarding
**Component map**:  
Video → YOLOv11 Tracking → HOI Detection (Proximity) → Temporal Scene Graph → Query‑Aware Pruning → Verbalization → Gemini 2.5 Flash → Answer

**Critical path**:  
Tracking and HOI detection must run sequentially to build the graph; pruning depends on the query; verbalization and LLM inference follow.

**Design tradeoffs**:  
- Proximity‑based HOI is cheap but misses non‑proximal interactions.  
- Aggressive pruning reduces tokens but risks removing relevant context.  
- Verbalization simplifies the graph for the LLM but may lose structural nuance.

**Failure signatures**:  
- Low accuracy on questions requiring detailed spatial reasoning or occluded interactions.  
- High token usage if pruning fails to discard irrelevant events.  
- Temporal inconsistencies when tracking loses objects or merges identities.

**First experiments**:  
1. Vary pruning threshold (e.g., keep top‑k events) to measure accuracy vs. token trade‑off.  
2. Replace proximity HOI with a learned detector to assess impact on quality.  
3. Test alternative LLMs (e.g., GPT‑4, Claude) to evaluate robustness of verbalized representation.

## Limitations
- Evaluation conducted on only 5 long videos (120 questions), limiting generalizability.
- The full‑log baseline’s exact input (frames/audio/text) is unclear, making direct comparison difficult.
- Graph construction relies on YOLOv11 and proximity, potentially missing nuanced or occluded interactions critical for QA.

## Confidence
- Token reduction claim: **High** (explicit counts provided).
- Accuracy parity with full‑log baseline: **Medium** (close but no statistical test; small test set).
- Necessity of long‑range memory: **High** (30‑second collapse strongly supports).
- Query‑aware pruning effectiveness: **Medium** (no ablation on selection rationale).

## Next Checks
1. **Scale evaluation**: Replicate on a larger, multi‑domain long‑video QA dataset (e.g., NExT‑QA, ActivityNet‑QA).
