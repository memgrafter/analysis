# AgilePruner: An Empirical Study of Attention and Diversity for Adaptive Visual Token Pruning in Large Vision-Language Models

## Quick Facts
- **arXiv ID**: 2603.01236  
- **Source URL**: https://arxiv.org/abs/2603.01236  
- **Reference count**: 28  
- **Primary result**: Adaptive pruning based on image effective rank improves accuracy and reduces object hallucination (CHAIR Cs=52.2, Ci=15.9 with 64 tokens) while matching full-token performance using only 11%-25% tokens.

## Executive Summary
Large vision-language models (LVLMs) generate a large number of visual tokens, leading to high computational overhead. This paper empirically studies token importance using effective rank (erank) and attention entropy, revealing a key trade-off: attention-based pruning reduces object hallucination but degrades on complex images, while diversity-based pruning preserves coverage on complex images but increases hallucination. The authors propose an adaptive pruning method that dynamically adjusts token selection based on image complexity measured by erank, combining the strengths of both approaches. Evaluated on LLaVA-1.5-7B across nine benchmarks, AgilePruner achieves lower CHAIR scores and competitive accuracy with only a fraction of tokens, and these gains generalize to larger models and different architectures without any fine‑tuning.

## Method Summary
For each input image, visual token embeddings are extracted from the penultimate layer of a frozen vision encoder (e.g., CLIP‑ViT‑L). Two metrics are computed: (1) effective rank (erank) of the token embedding matrix, which quantifies the intrinsic dimensionality and thus image complexity, and (2) attention entropy of the CLS token, indicating how focused the encoder’s attention is. An adaptive threshold τ is set based on erank: τ = min(τ_max, α · (erank − erank_min)/(erank_max − erank_min)). Pruning then proceeds iteratively: tokens are sorted by descending attention score; the highest‑scoring unpruned token is selected, and all remaining tokens with cosine similarity below τ relative to that token are discarded. This repeats until a fixed token budget (e.g., 64) is reached. The selected tokens are fed into the language model for generation, with no additional training.

## Key Results
- AgilePruner achieves CHAIR Cs=52.2, Ci=15.9 with 64 tokens, improving over DivPrune (Cs=57.4, Ci=18.0) while maintaining accuracy on VQAv2, GQA, and other benchmarks.
- It matches the full‑token model’s performance using only 11%‑25% of visual tokens across nine datasets.
- Gains generalize to LLaVA‑1.5‑13B, LLaVA‑NeXT‑7B, and Qwen2.5‑VL‑7B.

## Why This Works (Mechanism)
### Mechanism 1: Attention‑based token selection reduces hallucination via concentration of reliable cues
- **Claim**: Prioritizing tokens with high attention scores from the vision encoder yields a conservative token set that suppresses object hallucination.
- **Mechanism**: The vision encoder’s class token attends strongly to a small set of semantically salient regions. These tokens are treated as containing more reliable visual evidence. Pruning removes low‑attention tokens, retaining a focused subset that prevents the LVLM from generating unsupported objects.
- **Core assumption**: Information in simple images is concentrated in a few key regions, so high‑attention tokens capture most of the task‑relevant semantics.
- **Evidence anchors**:
  - Abstract: “attention‑based pruning reduces hallucination” and “attention‑based approaches are more effective on simple images where visual evidence is concentrated.”
  - Results: Table 2 shows lower CHAIR scores for attention‑based methods vs. diversity‑based; Section 4.2 contrasts performance on ScienceQA (simple) vs. POPE (complex); Figure 3(b) links low entropy/erank to simple images where attention‑based excels.
- **Break condition**: When the image is complex and key information is distributed across many regions, attention‑based selection discards too many diverse tokens, degrading performance on tasks requiring broad coverage.

### Mechanism 2: Diversity‑based token selection improves coverage but increases hallucination by encouraging dispersion
- **Claim**: Maximizing inter‑token feature diversity (e.g., via farthest point sampling) preserves a broader representation of the image but is associated with higher hallucination rates.
- **Mechanism**: Diversity‑based methods explicitly minimize feature similarity among retained tokens, ensuring the selected set covers scattered visual concepts. However, this may include tokens with weak semantic signals that do not reliably ground the LVLM’s generation, increasing the chance of describing absent objects.
- **Core assumption**: Complex images contain semantically important distributed information; capturing this breadth improves accuracy on complex scenes but also increases risk of hallucination.
- **Evidence**: Table 2 shows higher CHAIR scores for diversity‑based pruning compared to attention‑based; diversity‑based methods perform better on POPE (complex) than on ScienceQA (simple) relative to attention‑based.

## Foundational Learning
#### Effective Rank (erank)
- **Why needed**: Quantifies the intrinsic dimensionality of the token embedding set; higher erank indicates more distributed information (complex image), which should influence pruning toward diversity. Lower erank suggests concentrated information, favoring attention‑based selection.
- **Quick check**: Compute the covariance matrix of token embeddings (N×D), then effective rank = (sum of singular values)² / sum of squared singular values, or use the efficient trace(XXᵀ)/‖XXᵀ‖_F method.

#### Attention Entropy
- **Why needed**: Measures how uniformly the CLS token’s attention is distributed across visual tokens. Low entropy indicates focus on few tokens (simple image); high entropy suggests dispersed attention (complex image). Used as a correlate for image complexity in analysis.
- **Quick check**: Extract the CLS token’s attention weights from the vision encoder’s last self‑attention layer, normalize to a probability distribution, and compute entropy: –∑ pᵢ log pᵢ.

#### Adaptive Pruning Threshold (τ)
- **Why needed**: Dynamically balances conservative (high‑attention) and diverse (low‑similarity) token selection based on image complexity. Prevents fixed thresholds from underperforming on either simple or complex images.
- **Quick check**: For a given image erank, compute τ = min(τ_max, α·(erank – erank_min)/(erank_max – erank_min)). Parameters (α, τ_max, erank_min, erank_max) are derived from the training set distribution.

#### Object Hallucination (CHAIR)
- **Why needed**: Evaluates whether generated text mentions objects not present in the image. Critical for assessing whether pruning discards essential visual evidence.
- **Quick check**: Generate captions for a set of images, extract object mentions, compare against ground‑truth objects; CHAIR = (# sentences with hallucinated objects)/(# sentences) and # hallucinated objects / # total objects.

#### Token Budget
- **Why needed**: Controls the computational trade‑off; fewer tokens reduce FLOPs and latency but risk information loss.
- **Quick check**: Set a fixed number K (e.g., 64) for retained tokens; pruning stops when K tokens are selected.

## Architecture Onboarding
**Component map**:  
Image → Vision Encoder (CLIP) → Penultimate Layer Token Embeddings (N×D) → Pruning Module (computes attention scores, erank, adaptive τ, iterative selection) → Pruned Token Set (K×D) → LLM Decoder → Generated Text  

**Critical path**: The essential flow is extracting token embeddings from the vision encoder, computing importance metrics, selecting K tokens via the adaptive threshold, and feeding these into the LLM for generation. Pruning occurs before the modality projection into the LLM space.

**Design tradeoffs**:
- *Conservative vs. Diverse*: Attention‑based keeps only high‑attention tokens, lowering hallucination but possibly missing details in complex images; diversity‑based covers more regions but risks including spurious tokens leading to hallucination.
- *Fixed vs. Adaptive Threshold*: Fixed τ simplifies implementation but cannot adjust to image complexity; adaptive τ adds a small erank computation overhead but generalizes across simple and complex images.
- *Token Budget*: Smaller K improves efficiency but may degrade accuracy if too aggressive; the adaptive method aims to minimize degradation for a given budget.

**Failure signatures**:
- High CHAIR on simple datasets (e.g., ScienceQA) when using diversity‑based or high τ: indicates loss of concentrated salient information.
- Low accuracy on complex datasets (e.g., POPE) when using attention‑based or low τ: indicates insufficient coverage of distributed details.
- Erank miscalculation leads to mis‑scaled τ; check by comparing erank distribution against known statistics (e.g., mean erank on MME ≈94.9).
- Pruning from the wrong layer (not penultimate) can alter attention/erank statistics, causing performance drop.

**First experiments (3)**:
1. **Baseline replication**: Implement DivPrune (farthest‑point sampling), attention‑only (top‑attention), and the adaptive method. Run on POPE and ScienceQA with 64 tokens; verify CHAIR and accuracy trends match paper (attention lower CHAIR, diversity higher recall, adaptive balances).
2. **Adaptive threshold ablation**: Replace adaptive τ with a fixed τ optimized for average performance. Compare adaptive vs. fixed on mixed datasets and on subsets split by erank (low vs. high). Expect adaptive to win on both tails.
3. **Erank sensitivity**: Corrupt erank estimation (e.g., add noise) and observe performance; confirm robustness to small errors. Also test different erank computation methods (full SVD vs. approximate) to ensure consistency.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question**: Is the linear mapping between effective rank (erank) and the attention/diversity mixing ratio optimal, or do non‑linear functions improve token selection across diverse image complexities?
- **Basis**: [inferred] The adaptive method uses a linear scaling (Eq. 6) without exploring alternatives.
- **Why unresolved**: Non‑linear relationships might better capture diminishing returns or saturation effects in erank.
- **What evidence would resolve it**: Ablation varying the mapping function (linear vs. polynomial vs. sigmoid) on datasets with wide erank span, measuring accuracy, efficiency, and hallucination.

### Open Question 2
- **Question**: Do the findings generalize to LVLMs with non‑CLIP vision encoders (e.g., DINO, MAE) or tokenization schemes such as region proposal‑based?
- **Basis**: [explicit] The study only covers LLaVA (CLIP‑L/SigLIP) and Qwen2.5‑VL; it states “architecturally different” but still CLIP‑family.
- **Why unresolved**: Encoder architecture influences attention and redundancy patterns; results may not hold for different pretrained vision models.
- **What evidence would resolve it**: Replicate experiments on models like BLIP, Flamingo, or open‑vocabulary detectors using distinct visual backbones, comparing erank/entropy trends and adaptive performance.

### Open Question 3
- **Question**: How sensitive is the adaptive threshold to domain shift, i.e. when test images have a different erank distribution than the LLaVA training set?
- **Basis**: [inferred] The method uses erank_avg computed from the training set; it assumes this average generalizes.
- **Why unresolved**: A fixed reference may become mismatched under severe domain change, causing systematic over‑ or under‑pruning.
- **What evidence would resolve it**: Test on out‑of‑domain data (e.g., medical, aerial) using original vs. domain‑specific erank_avg, evaluating accuracy and token budget adherence.

### Open Question 4
- **Question**: Does the proposed pruning influence hallucination types beyond object‑level errors, such as relational or attribute inconsistencies?
- **Basis**: [inferred] Evaluation limited to CHAIR (object presence); no analysis of finer‑grained hallucinations.
- **Why unresolved**: Different reasoning failures may correlate with different token biases; reducing object hallucinations might worsen relational reasoning.
- **What evidence would resolve it**: Evaluate on benchmarks designed for relational hallucination (e.g., VQA‑HAT, GQA with consistency checks) and attribute accuracy before/after pruning.

## Limitations
- **τ_max unspecified**: The adaptive threshold’s upper bound is described as a “statistical upper bound” but its exact value (e.g., 0.25 vs. 0.3) is not reported, hindering precise replication.
- **erank_avg computation ambiguous**: The average effective rank computed on the LLaVA training set is not specified (dataset split, sample size, resulting value), leaving the baseline for adaptation unclear.
- **Baseline implementation gaps**: Details for pruning baselines (e.g., PruMerge+ merging strategy, VisPruner’s token filtering thresholds) are not fully elaborated, making fair comparison difficult.

## Confidence
- **Core finding (adaptive > fixed)**: High  
- **Attention vs. diversity mechanisms**: Medium  
- **Generalization to unseen models**: Medium
