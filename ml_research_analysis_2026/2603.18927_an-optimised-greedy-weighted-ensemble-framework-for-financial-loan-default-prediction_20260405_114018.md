# An Optimised Greedy-Weighted Ensemble Framework for Financial Loan Default Prediction

## Quick Facts
- **arXiv ID:** 2603.18927
- **Source URL:** https://arxiv.org/abs/2603.18927
- **Reference Count:** 40
- **Primary Result:** Achieved an AUC of 0.80, macro-average F1-score of 0.73, and a default recall of 0.81 on the Lending Club dataset using a greedy-weighted ensemble and a BlendNet meta-learner.

## Executive Summary
This study addresses the challenges of loan default prediction—nonlinear relationships, severe class imbalance, and evolving borrower behavior—by proposing a three-stage Optimised Greedy-Weighted Ensemble framework. First, base model hyperparameters are tuned via Particle Swarm Optimisation (PSO). Second, a greedy convex optimisation algorithm dynamically reweights the optimised models based on rolling validation performance. Third, a neural network meta-learner (BlendNet) combines both the weighted and unweighted base predictions. On the Lending Club dataset, the framework achieved strong discrimination (AUC 0.80) and minority-class recall (0.81), with tree-based ensembles providing the best probability calibration (Brier score 0.18). Key predictive features included revolving utilisation, annual income, and debt-to-income ratio.

## Method Summary
The proposed framework proceeds in a strict sequence. *Stage 1:* Six heterogeneous base classifiers (Gradient Boosting, MLP, SVM, KNN, Logistic Regression, Extra Trees) are individually hyperparameter-optimised using PSO on a preprocessed and augmented (via SMOTE-like technique) training set. *Stage 2:* The predictions from these tuned models on a validation fold are combined via a regularised greedy iterative algorithm that finds convex weights to minimise Brier score. *Stage 3:* These greedy-weighted ensemble outputs, concatenated with all original unweighted base model predictions, form a 12-feature meta-matrix. This trains the BlendNet feedforward neural network to produce the final default probability. All preprocessing, tuning, and weight optimisation are confined to the training data, with final evaluation on a held-out test set.

- Macro-average F1-score: **0.73**

## Why This Works (Mechanism)

### Mechanism 1: Performance-Driven Greedy Weighting
The ensemble dynamically reallocates convex weights to base models via a regularised greedy optimisation on a rolling validation window. This allows the system to emphasise models currently performing well under the prevailing data distribution, assuming model utility is non-stationary. The mechanism iteratively adjusts each weight to minimise a regularised Brier loss, constrained to sum to one. **Break condition:** If the underlying data-generating process undergoes a sudden, unprecedented regime change, historical validation performance becomes uninformative, leading to erratic weight updates.

### Mechanism 2: Separated Hyperparameter Optimisation (PSO)
PSO is applied *before* ensemble weighting to ensure each base model is evaluated at its representational best. This prevents a poorly tuned instance of a strong algorithm (e.g., Gradient Boosting with bad learning rate) from being unfairly down-weighted. The population-based search navigates complex, non-convex hyperparameter spaces efficiently. **Break condition:** If the PSO fitness metric (e.g., AUC) is poorly correlated with the final ensemble loss (Brier), optimised models may excel individually but contribute poorly to the combined objective.

### Mechanism 3: Hybrid Meta-Learning with Dual Inputs (BlendNet)
BlendNet is fed a meta-feature matrix containing *both* the greedy-weighted ensemble output and the raw unweighted predictions from all base models. This enriched input allows the neural network to learn higher-order interactions and correct for residual calibration errors that the convex weighting alone might miss. **Break condition:** If base model predictions are highly correlated (low diversity), the dual-input space offers limited novel signal, increasing the risk of BlendNet overfitting without meaningful gain.

## Foundational Learning

### Concept: Ensemble Diversity & Complementary Error Patterns
**Why needed here:** The entire framework relies on base learners making different errors on different loan instances. Greedy weighting and meta-learning combine these complementary errors to reduce overall variance and bias. Without diversity, ensembling offers no benefit.
**Quick check:** If SVM misclassifies high-income, low-debt borrowers while Gradient Boosting misclassifies low-income, high-debt borrowers, why is this property valuable?

### Concept: Hyperparameter Optimisation as a Pre-Processing Step
**Why needed here:** Greedy weights are meant to compare the *predictive capability* of algorithm families. An untuned model will appear weak in validation, leading to under-weighting of its entire class, even if the algorithm is fundamentally powerful.
**Quick check:** What is the risk of performing greedy weighting *before* hyperparameter tuning versus after?

### Concept: Class Imbalance Handling (SMOTE/Quantile Augmentation)
**Why needed here:** Loan default datasets are typically >80% "Fully Paid." Without intervention, models become biased toward the majority class, resulting in very low recall for "Charged Off" (the critical class). Augmentation gives the minority class sufficient representation during training.
**Quick check:** Why might simple undersampling of the majority class (without synthetic oversampling) be insufficient for training robust base learners in this context?

## Architecture Onboarding

### Component map:
1. Input Layer: Raw tabular loan data -> 2. Pre-processing (BCP-HI outlier handling, missing value removal, encoding) -> 3. Feature Engineering/Selection (RFE to select top ~10 features) -> 4. Class Balancing (Quantile transform, undersampling, Gaussian noise augmentation) -> 5. Base Model Optimisation (PSO tuning for GB, MLP, SVM, KNN, LR, ExtraTrees) -> 6. Greedy Weighted Ensemble (GWE) (regularised convex optimisation on validation predictions) -> 7. Meta-Learning (BlendNet) (train NN on stacked [weighted + unweighted] predictions) -> 8. Evaluation (AUC, F1, Recall, Brier on held-out test).

### Critical path:
The flow is strictly linear from 1->4. Steps 5, 6, and 7 must be executed sequentially: PSO tuning *must* precede greedy weighting (5->6), and the greedy-weighted output must be generated before training BlendNet (6->7). Deviating (e.g., meta-learning on untuned models) breaks the design rationale.

### Design tradeoffs:
- **Adaptivity vs. Stability:** Greedy weighting provides adaptivity to non-stationarity but risks instability. Quadratic regularisation (λ) trades some adaptivity for numerical stability and prevention of extreme weight spikes.
- **Discrimination vs. Calibration:** The design prioritises ranking ability (AUC) for default detection. BlendNet excels at discrimination but has worse probability calibration (higher Brier) than pure tree ensembles, which may require post-hoc calibration for risk-based pricing.
- **Complexity vs. Interpretability:** BlendNet adds a "black box" layer, but the greedy weights remain explicit and interpretable. The trade-off accepts meta-learner opacity for a modest performance gain.

### Failure signatures:
1.  **Weight Collapse:** One or two weights dominate (w_i≈1, others≈0). Indicates a too-small/noisy validation set or overly weak regularisation (λ), collapsing the ensemble to a single model.
2.  **Meta-Learner Overfitting:** BlendNet replicates the best base model without learning interactions. Diagnose by monitoring validation loss during BlendNet training; check correlation matrix of 12 meta-features for high redundancy.
3.  **Concept Drift Ignored:** Rolling-window weighting assumes gradual drift. A sudden economic shock (e.g., pandemic) invalidates all historical performance windows, causing weights to become meaningless until new data accumulates.
4.  **Calibration Decay:** A model with high AUC but poor Brier score (like BlendNet here) assigns probabilities that don't match empirical default rates, leading to mispriced risk if used for loan pricing.

### First 3 experiments:
1.  **Baseline Establishment:** Train and evaluate all six PSO-tuned base models on the balanced test set. Record individual AUC, Macro-F1, and Default Recall to establish the performance floor.
2.  **Static vs. Greedy Weighting Comparison:** Construct an equal-weight voting ensemble and the greedy-weighted ensemble (without BlendNet). Compare their performance against the best single tuned model to isolate the value of adaptive weighting.
3.  **BlendNet Component Ablation:** Train the full framework. Then, run an ablation where BlendNet is trained *only* on the weighted ensemble predictions (excluding unweighted base predictions). Compare to the full BlendNet to test the dual-input design's contribution.

## Open Questions the Paper Calls Out
Although the paper does not explicitly list open questions, the work suggests several avenues for further inquiry:
1. How robust is the greedy weighting mechanism to sudden, unprecedented regime changes (e.g., economic crises) where historical validation performance becomes uninformative?
2. What is the sensitivity of the framework to the choice and diversity of base learners, and how does this affect the ensemble's adaptability?
3. How do the hyperparameters of the greedy optimisation (regularization λ, rolling window size) impact performance and stability?
4. Could the dual-input design of BlendNet be simplified (e.g., using only weighted or only unweighted predictions) without significant loss, given the risk of overfitting when base predictions are highly correlated?
5. How does the framework generalize to other financial datasets with different characteristics (e.g., varying class imbalance, feature sets, temporal dynamics)?

## Limitations
- High framework complexity (PSO, greedy optimisation, meta-learner, augmentation) increases overfitting risk and implementation burden.
- BlendNet exhibits poorer probability calibration (higher Brier score) than tree-based ensembles, potentially limiting its use in risk-based pricing where accurate probability estimates are critical.
- The rolling-window weighting assumption of gradual drift may fail during abrupt economic regime changes, causing weight instability.
- The exact "top 10" feature set from RFE and key hyperparameters for the greedy weighting (λ, δ) are not fully specified, hindering exact replication.
