# A Dataset is Worth 1 MB

## Quick Facts
- **arXiv ID:** 2602.23358  
- **Source URL:** https://arxiv.org/abs/2602.23358  
- **Reference count:** 40  
- **Primary result:** Transmits task knowledge with <1 MB payload (often 45–206 KB) by sending only hard pseudo-labels for a pruned subset of a preloaded unlabeled reference dataset, achieving high accuracy on 14 diverse target tasks.

## Executive Summary
The paper tackles the problem of distributing task knowledge to bandwidth-constrained heterogeneous clients without sending any pixel data. It proposes Pseudo-Labels as Data (PLADA), where clients are preloaded with a large unlabeled reference dataset (e.g., ImageNet-21K). The server computes hard pseudo-labels for the reference images using a teacher model trained on the target task, then prunes the reference set to a small semantically relevant subset using energy-based OOD scoring and a class-balanced Safety-Net. Only the indices and labels of this subset are transmitted (compressed with Zstd), allowing the client to locally reconstruct a tiny training set and train a student model. Across 14 natural and medical image classification datasets, PLADA achieves strong accuracy with payloads often below 200 KB, establishing a new frontier for communication-efficient dataset serving.

## Method Summary
PLADA operates in two phases. First, on the server, a teacher model (ConvNeXt-V2-Tiny) is fine-tuned on the target dataset. This teacher generates hard pseudo-labels for every image in the preloaded reference set. An energy score `E(x) = -log(sum(exp(logits)))` is computed per image; for standard (in-distribution) targets, the lowest-energy (most confident) reference images are retained to maximize semantic relevance. A Safety-Net enforces per-class quotas proportional to `(N_c)^-0.2` to preserve class balance. For far-OOD medical targets, the highest-energy (most uncertain) images are kept instead. The selected image indices are delta-encoded, labels are stored compactly, and the byte stream is compressed with Zstd (level 19). Second, on the client, the reference images corresponding to the received indices are paired with the pseudo-labels to form a tiny training subset. A student model (ResNet-18, pretrained) is trained locally on this subset using cross-entropy loss. The keep rate (e.g., 1%) controls the payload size, with lower rates yielding smaller transmissions but fewer training samples.

## Key Results
- With ImageNet-21K at 1% keep rate, PLADA achieves 86.7% on Caltech-101 and 82.5% on CUB-200-2011 with payloads as low as 45–206 KB.
- Aggressive pruning (0.1–0.5% keep) sometimes outperforms using the full reference set, indicating effective removal of irrelevant reference images.
- For far-OOD medical datasets (e.g., BloodMNIST, RetinaMNIST), selecting the highest-energy reference images yields significantly better accuracy than lowest-energy selection.
- PLADA surpasses random subset and K-Center coreset baselines in accuracy for a given payload size and approaches or exceeds dataset distillation where applicable.
- The method establishes a Pareto frontier enabling classification under ultra-low bandwidth constraints (e.g., deep-sea acoustic links).

## Why This Works (Mechanism)
PLADA succeeds because the energy score effectively filters the reference set for images that the target-aware teacher model processes with high confidence, which correlates with semantic relevance to the target task. The Safety-Net prevents the collapse of minority classes that would otherwise be excluded by pure energy ranking, crucial for imbalanced datasets. Transmitting only indices and hard labels—instead of pixels—reduces the payload to the theoretical minimum needed to reconstruct a training set, and modern compression (Zstd) exploits redundancy in the index sequence. The preloaded reference set acts as a shared "dictionary" between server and client, shifting the communication burden to a one-time deployment. Using a pretrained student speeds convergence on the small pseudo-labeled subset.

## Foundational Learning
- **Energy-based OOD scoring:** Uses negative log-sum-exp of logits to measure model confidence; low energy indicates in-distribution, high energy indicates uncertainty/out-of-distribution. *Why needed:* Provides an unsupervised criterion to rank reference images by relevance to a target task. *Quick check:* Compute energy on a validation set; confirm top-lowest images are semantically on-topic.
- **Pseudo-labeling:** Assigning model predictions as training labels. *Why needed:* Eliminates need for human annotation on the reference set. *Quick check:* Teacher accuracy on target should be high (>90% on average) to ensure label quality.
- **Coreset selection:** Selecting a representative subset (e.g., K-Center). *Why needed:* Baseline for data pruning. *Quick check:* Compare PLADA’s energy-based selection against random and K-Center on payload-accuracy curve.
- **Payload compression:** Using Zstd with delta encoding. *Why needed:* Minimizes transmitted bytes. *Quick check:* Compress a sorted index list; verify size matches theoretical `log2(N)` per index after delta and Zstd.
- **Class imbalance mitigation:** Power-law quota allocation. *Why needed:* Prevents majority-class domination in pruned set. *Quick check:* On imbalanced datasets (RESISC45), check class distribution in pruned set matches target distribution more closely than without Safety-Net.
- **Far-OOD filtering:** Inverting energy ranking for medical datasets. *Why needed:* Reference images are out-of-distribution; high uncertainty images may better cover the target domain’s edge cases. *Quick check:* Visualize top-energy reference images; confirm they share low-level features (texture, color) with medical scans.

## Architecture Onboarding
Server pipeline: Teacher fine-tuning on target → pseudo-label generation for full reference → energy scoring → Safety-Net quota filling → index delta-encoding → Zstd compression → transmission. Client pipeline: receive payload → reconstruct `(image, label)` pairs from preloaded reference → train student model.

Critical path: Teacher accuracy → pseudo-label quality → energy ranking → Safety-Net → payload size → student convergence. Design tradeoffs: Keep rate vs. payload size vs. accuracy; Safety-Net strength (α) vs. class balance; energy direction (low vs. high) for OOD targets. Failure signatures: (1) Payload >1 MB at 1% keep → encoding/compression error. (2) Student accuracy near random on medical datasets → used wrong energy direction. (3) Minority classes absent in student training → Safety-Net not implemented or α mis-set. (4) No accuracy gain from pruning → teacher not accurate or reference set mismatch.

## Limitations
- **Reference set ambiguity:** Exact ImageNet-21K variant (e.g., Winter 2021 release), resolution, and filtering criteria are unspecified; using a different subset may alter relevance.
- **Training details gaps:** Teacher/student augmentations, batch size, weight decay, warmup epochs, and exact learning rate schedule are not fully described; these are critical for reproducibility.
- **Pruning parameter opacity:** Safety-Net’s global budget fill procedure after quota assignment and the exact portion `s` reserved for Safety-Net are not quantified; α = -0.2 is given but sensitivity to other parameters is unexplored.

## Confidence
- **PLADA achieves <1 MB payload with high accuracy:** Medium (depends on reference set match and teacher quality).
- **Pruning can surpass full reference set:** Medium (requires precise energy ranking and Safety-Net).
- **Highest-energy filtering works for far-OOD medical:** High (explicitly validated in paper).
- **New Pareto frontier vs. baselines:** Medium-High (baseline implementations vary).
- **Payload size after Zstd compression:** Medium (encoding details could affect size).
- **Overall reproducibility:** Low (multiple critical unknowns in data and hyperparameters).
