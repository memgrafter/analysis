# Wideband Power Amplifier Behavioral Modeling Using an Amplitude Conditioned LSTM

## Quick Facts
- arXiv ID: 2603.00101
- Source URL: https://arxiv.org/abs/2603.00101
- Reference count: 14
- Primary result: AC-LSTM achieves NMSE -41.25 dB and ACPR -28.58 dB on 100 MHz 5G NR signal with only 1240 parameters.

## Executive Summary
This paper addresses behavioral modeling of wideband power amplifiers (PAs), which exhibit strong nonlinear and memory effects. The authors propose an amplitude-conditioned long short-term memory (AC-LSTM) network that employs a feature-wise linear modulation (FiLM) layer to modulate the LSTM's internal state based on the instantaneous input amplitude. Using a 100 MHz 5G NR signal and measured data from a GaN PA, the AC-LSTM attains a normalized mean square error (NMSE) of -41.25 dB and an adjacent channel power ratio (ACPR) of -28.58 dB, closely matching the PA's measured ACPR of -28.54 dB while using only 1240 parameters—significantly fewer than prior approaches.

## Method Summary
The AC-LSTM integrates amplitude conditioning into the LSTM recurrence. At each timestep, the input signal's amplitude is computed and passed through a small MLP to produce scaling (γ) and shifting (β) parameters. These parameters modulate the candidate cell state (or, per the abstract, the forget gate) before it is combined with the previous cell state. The model consists of one or more stacked AC-LSTM layers followed by a fully connected ReLU layer and a linear output layer projecting back to the complex baseband I/Q dimensions. Training uses the Adam optimizer with mean squared error loss, learning rate reduction on plateau, and normalization of I/Q components to zero mean and unit variance. The dataset comprises 200,000 samples split into training (80%), validation (10%), and test (10%) sets.

## Key Results
- NMSE: -41.25 dB (1.15 dB improvement over standard LSTM's -40.10 dB, 7.45 dB over AR VTDNN's -33.80 dB).
- ACPR: -28.58 dB, nearly identical to the measured PA's -28.54 dB.
- Model size: 1240 parameters, demonstrating high efficiency.

## Why This Works (Mechanism)
The AC-LSTM leverages the observation that PA nonlinearities are amplitude-dependent. By conditioning the LSTM's internal state on the input amplitude via FiLM, the model can dynamically adjust its memory and nonlinear processing to match the instantaneous operating region. This explicit amplitude conditioning helps the network disentangle amplitude-driven distortion from other dynamics, leading to better accuracy in both time-domain (NMSE) and spectral (ACPR) metrics while maintaining a compact parameter count.

## Architecture Onboarding
Component map: Input (complex I/Q) -> Amplitude computation (sqrt(I²+Q²)) -> FiLM MLP (linear -> γ, β) -> AC-LSTM cell (gates + candidate state) -> Modulation (γ·c̃+β) -> Cell state update -> Hidden state -> FC (ReLU) -> Linear output -> Predicted I/Q.

Critical path: The FiLM parameters derived from amplitude must be correctly applied to the candidate cell state; this is the key differentiator from standard LSTM.

Design tradeoffs: The model prioritizes parameter efficiency by using a single AC-LSTM layer with a modest hidden size (~14). This limits capacity but reduces overfitting risk and computational cost. The FiLM MLP is kept linear to minimize parameters. The tradeoff between accuracy and model size is evident; deeper stacks might improve accuracy but at the cost of more parameters.

Failure signatures: 1) High NMSE with correct overall shape suggests incorrect FiLM implementation (e.g., modulating forget gate instead of candidate state, or mismatched dimensions). 2) Good NMSE but poor ACPR indicates spectral mismatch; likely the model underfits out-of-band distortion or the PSD estimation is off. 3) Training loss does not decrease or overfits quickly; may be due to incorrect normalization or learning rate.

## Limitations
- Exact AC-LSTM architecture (layers, hidden size, MLP structure) is not fully specified; must be inferred from total parameter count.
- Original measured dataset from the GaN PA is not publicly available, forcing reliance on simulated data for reproduction.
- Training hyperparameters (e.g., learning rate decay factor, early stopping criteria) are incompletely described, risking suboptimal convergence.
- Discrepancy between abstract (modulating forget gate) and equations (modulating candidate cell state) creates ambiguity.
- Parameter count may be approximate; small changes in hidden size alter the total.

## Confidence
- Model design (FiLM-conditioned LSTM): High
- Performance metrics (NMSE -41.25 dB, ACPR -28.58 dB): Medium
- Parameter efficiency (1240 parameters achieving above): Low
