# Compact Conformal Subgraphs

## Quick Facts
- arXiv ID: 2602.07530
- Source URL: https://arxiv.org/abs/2602.07530
- Reference count: 40
- Primary result: Graph-based conformal compression via weighted densest k-subgraph yields compact nested subgraphs with valid coverage guarantees.

## Executive Summary
Conformal prediction constructs sets with guaranteed marginal coverage, but in structured output domains (e.g., routing) these sets can be oversized and impractical. This paper introduces graph-based conformal compression to produce compact subgraphs while preserving distribution-free coverage guarantees. The authors recast compression as a weighted densest k-subgraph problem on hypergraphs, where each hyperedge corresponds to a historical answer set with weight derived from a scoring function. They develop efficient approximation algorithms—linear programming (LP) rounding and parametric minimum cut—that achieve bicriteria constant‑factor guarantees on subgraph size and coverage loss in the high-coverage regime (i.e., when the target subgraph retains a linear fraction of total hyperedge weight). A key theoretical insight is that the LP relaxation satisfies a monotonicity property, proved via a reduction to parametric minimum cuts, ensuring the output subgraphs are nested as required for valid split conformal prediction. Empirical evaluations on synthetic navigation, trip planning, and real taxi data from Porto demonstrate substantial compression improvements over greedy baselines while maintaining well‑calibrated coverage.

## Method Summary
The method follows a split conformal procedure. Calibration data are split into D1 and D2. Using D1, a threshold d* is learned to filter unlikely outputs, yielding an initial candidate set S_{d*}(A*) for a new context A*. A monotone compression algorithm is then applied to S_{d*}(A*) across a range of parameters τ to generate a nested sequence of subgraphs {K_τ}. On D2, for each historical example (A_i, B_i) one computes the smallest τ such that B_i ⊆ K_τ(A_i), producing scores η_i. The final τ* is selected as the ϕ‑quantile of these scores. The compression algorithm itself solves an LP that minimizes the number of vertices while covering a (1‑ε) fraction of total hyperedge weight, followed by threshold rounding. An equivalent implementation uses parametric minimum cut, which directly yields nested min‑cuts. Under exchangeability of the data, this procedure guarantees that the final subgraph K_{τ*}(A*) covers the true answer B* with probability at least ϕ − δ.

## Key Results
- Formulates compression as a weighted densest k-subgraph problem and provides bicriteria constant‑factor approximation algorithms (LP rounding, parametric min‑cut) with guarantees on size and coverage.
- Proves that the LP relaxation yields nested subgraphs via a reduction to parametric minimum cuts, ensuring valid split conformal guarantees.
- Demonstrates superior compression over greedy baselines on navigation, trip planning, and real taxi data while preserving calibration.

## Why This Works (Mechanism)
### Mechanism 1
The LP relaxation (1) and rounding scheme achieve a bicriteria constant‑factor approximation for the weighted densest k‑subgraph problem in the high‑coverage regime (covering a 1‑ε fraction of hyperedge weight), bypassing classical inapproximability results. The LP minimizes vertex count subject to covering (1‑ε)W total weight. Rounding vertices with fractional value above ρ = κ/(1+κ) yields a subgraph K with |K| ≤ (1+1/κ)·r and uncovered weight ≤ (1+κ)·εW. This guarantee is meaningful only when ε is a small constant because the bounds degrade as ε grows. The core assumption is that an optimal solution O exists with |O|=r covering all but εW weight.

Evidence: [abstract] states formulation and bicriteria guarantees; [section 4.1] presents LP (1), rounding, and Theorem 1.

Break condition: When the target subgraph size is sublinear in m (classical densest‑k‑subgraph regime), the bicriteria guarantee degenerates.

### Mechanism 2
The LP rounding algorithm (or equivalently parametric min‑cut) produces a monotone sequence of subgraphs K_τ nested in τ, enabling valid distribution‑free split conformal calibration. The Lagrangian dual of LP (1) maps to a parametric min‑cut problem on a bipartite flow network. The min‑cut solutions X(λ) are nested in λ (Lemma 2). The LP solution structure (Lemma 4) is a convex combination of two nested optimal integral solutions at a breakpoint λ*. Threshold rounding (Section 4.2) preserves this nesting: as τ increases, fractional values α increase, so vertices pass the threshold in a fixed order, yielding K_{τ1} ⊆ K_{τ2}. This relies on the hyperedge inclusion constraint z_e ≤ x_v and the correctness of the min‑cut reduction; the optimal solution to the Lagrangian is integral (Lemma 3).

Evidence: [abstract] mentions monotonicity from parametric cuts; [section 4.2] derives the min‑cut network, cites Lemma 2 (monotonicity), and shows threshold rounding preserves monotonicity (Lemma 5); Theorem 2 states LP and min‑cut produce identical nested subgraphs.

Break condition: If the hypergraph structure violates the min‑cut reduction (e.g., hyperedges not represented as source→hyperedge→vertex→sink arcs) or if the LP relaxation had fractional extreme points that cannot be embedded in a single threshold over nested sets, monotonicity could fail.

### Mechanism 3
The two‑stage split conformal framework (Section 2.1) uses compression as a monotone black‑box to convert a pre‑filtered set S_{d*}(A*) into a nested sequence {K_τ}, and quantile selection on D2 yields the final subgraph with marginal coverage guarantee ϕ − δ. Stage 1 uses D1 to compute d* and the initial set S_{d*}(A*). Stage 2 runs a monotone compression algorithm on S_{d*}(A*) for each τ to produce K_τ(A*). On D2, compute nested scores η_i = min{τ: B_i ⊆ K_τ(A_i)} (or 1 if lost in Stage 1). Pick τ* as the ϕ‑quantile of {η_i}. By exchangeability, η* (test) ≤ τ* with probability at least ϕ, and this event implies B* ⊆ K_{τ*}(A*), except when B* was already lost in Stage 1 (bounded by δ).

Evidence: [abstract] states the method ensures valid conformal guarantees; [page 5, section 2.1] describes the two‑stage procedure, defines η_i, and Lemma 1 (conformal validity) with proof in Appendix A.

Break condition: Non‑monotone compression algorithm → invalid quantile calibration. Violation of exchangeability → coverage guarantee fails.

## Foundational Learning
- **Split conformal prediction**: Why needed? The entire validity guarantee rests on splitting calibration data into D1 (threshold calibration) and D2 (compression parameter calibration). Understanding the role of each split and the exchangeability argument is essential to grasp why the final subgraph has coverage ϕ − δ. Quick check: What would happen to the coverage guarantee if the same data were used for both threshold d* and τ* selection?
- **Densest subgraph / densest k‑subgraph (DkS)**: Why needed? The compression problem maps to a weighted densest k‑subgraph on hypergraphs. Recognizing the distinction between the "high‑coverage" regime here (subgraph keeps linear edge weight) and the classical "small subgraph" regime (NP‑hard to approximate) explains why efficient algorithms exist. Quick check: Why is the bicriteria guarantee (Theorem 1) meaningful only when ε is a small constant?
- **Parametric minimum cut**: Why needed? The connection to parametric min‑cut provides both the monotonicity property and an equivalent algorithm. The reduction transforms the Lagrangian into a flow network where increasing λ only raises source→hyperedge capacities, leading to nested min‑cuts. Quick check: In the flow network construction, which edges' capacities depend on λ, and why does this dependence imply nested source sets?

## Architecture Onboarding
**Component map**:
Input Data (calibration sets D1, D2) → Hypergraph Builder → Compression Engine (LP rounding or parametric min‑cut) → Nested Sequence Generator → Calibration Wrapper → Output Subgraph K_{τ*}(A*)

**Critical path**: Hypergraph H → Compression engine → Nested {K_τ} → Compute η_i on D2 → τ* → Final K_{τ*}(A*)

**Design tradeoffs**:
- κ parameter: Controls trade‑off between subgraph size (|K| ~ (1+1/κ)·r) and coverage slack ((1+κ)εW). Larger κ yields smaller subgraphs but worse coverage loss.
- LP vs. min‑cut: LP is conceptually simple but requires solving an LP; min‑cut leverages combinatorial structure, runs in O(γ(m+n)^2), and provides a constructive proof of monotonicity. Min‑cut is theoretically preferred.
- Fixed vs. variable context: In fixed‑context settings, τ directly relates to coverage probability, allowing size‑optimality claims via uniform convergence. In variable‑context settings, τ is a free parameter; coverage guarantee is distribution‑free but size optimality is not directly tied to ϕ.

**Failure signatures**:
- Non‑monotone sequence: Compression engine returns K_{τ1} ⊈ K_{τ2} for τ1<τ2 → violates Definition 1 → invalid split conformal guarantee.
- Excessive uncovered weight: e(K_τ) < (1−(1+κ)ε)W beyond guarantee → may indicate numerical LP issues or that ε is not small (regime breakdown).
- Sampling bias: If hyperedge sampling (Appendix E) does not produce a uniform or representative sample, uniform convergence may fail, affecting both compression and calibration.

**First 3 experiments**:
1. **LP rounding size/coverage validation**: Generate a synthetic hypergraph with known optimal subgraph O. Run LP rounding for a target τ and verify |K| ≤ (1+1/κ)|O| and uncovered weight ≤ (1+κ)εW (Theorem 1).
2. **Monotonicity via parametric min‑cut**: On a small hypergraph, compute K_τ for many τ (e.g., 0.05 increments) using both LP rounding and parametric min‑cut. Check that K_{τ1} ⊆ K_{τ2} for τ1<τ2 and that both methods produce identical nested sequences (Theorem 2).
3. **Conformal validity on synthetic navigation**: Use the 6×6 grid with a 20‑edge bypass. Generate calibration D1, D2 and test (A*, B*). Compute d* on D1, run compression on S_{d*}(A*) to get {K_τ}, select τ* on D2 to achieve target ϕ=0.9, and test whether B* ⊆ K_{τ*}(A*) over many trials. Empirical coverage should be ≥ ϕ − δ.

## Open Questions the Paper Calls Out
- PTAS or exact algorithms for conformal subgraph on planar or tree‑structured hypergraphs? (Road networks are planar, labels are tree‑structured.)
- End‑to‑end model training that optimizes compressibility while preserving conformal guarantees? (Any scoring function yields validity, suggesting a compressibility regularizer; non‑convexity is a challenge.)
- Under planted core‑periphery models, does LP rounding achieve exact recovery? (Simulations show exact recovery for some parameters; worst‑case analysis is loose.)
- What coverage ε threshold separates the tractable (constant‑factor approximation) from intractable regimes? (Theorem 1 degrades as ε grows; the phase transition is not characterized.)
- How to combine compression with conditional coverage across covariate groups? (Naive per‑group independence harms compression; a single monotone sequence achieving approximate conditional coverage per group is open.)

## Limitations
- The bicriteria guarantee (Theorem 1) holds only for small ε (high‑coverage regime); for larger ε the bounds become vacuous.
- Monotonicity relies on the correctness of the Lagrangian reduction to parametric min‑cut; mis‑encoding hyperedges could break nestedness and invalidate the conformal guarantee.
- Experimental details (exact κ, bypass path design, Porto preprocessing) are underspecified, making exact replication difficult.
