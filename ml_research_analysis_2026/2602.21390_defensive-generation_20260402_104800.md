# Defensive Generation

## Quick Facts
- arXiv ID: 2602.21390
- Source URL: https://arxiv.org/abs/2602.21390
- Reference count: 31
- Primary result: Achieves optimal O(√T) indistinguishability error with near‑linear per‑step time, handling non‑Bernoulli outcomes and infinite test classes.

## Executive Summary
The paper introduces Defensive Generation, an algorithm for online generative modeling where produced distributions must be indistinguishable from true data under a wide class of computational tests. The core method reduces indistinguishability to high‑dimensional multicalibration with respect to a reproducing kernel Hilbert space (RKHS), solved efficiently using recent advances in expected variational inequalities. The algorithm attains an optimal O(√T) indistinguishability error and runs in near‑linear time O(poly(d)·log T) per step, where d is the outcome dimension. It is the first to efficiently handle non‑Bernoulli outcomes—including multiclass, scalar, and vector‑valued—and infinite test classes such as all functions in an RKHS or tests examining higher‑order moments. Applications demonstrate guarantees in token‑based sequence modeling, multi‑state weather prediction, and linear dynamical systems, including conditional moment matching and self‑consistency.

## Method Summary
The method formulates generative modeling as an online game between a producer and a distinguisher. Indistinguishability under tests f(x,p,y) that are linear in a sufficient statistic s(y) is equivalent to multicalibration: the producer’s distribution µ_t must satisfy E[µ_t s(y)] = p_t for all tests in the chosen class (e.g., an RKHS). The online multicalibration problem is solved with a Follow‑the‑Leader strategy combined with an expected variational inequality (EVI) solver, yielding O(√T) regret. At each step, given p_t, the algorithm constructs µ_t by solving a moment‑matching feasibility problem, exploiting convexity of the sufficient statistics set (simplex, unit ball). This yields a distribution with advertised guarantees.

## Key Results
- Optimal O(√T) indistinguishability error and near‑linear per‑step time.
- First method to handle non‑Bernoulli outcomes and infinite test classes (e.g., all RKHS functions, higher‑order moments).
- Conditional guarantees applied to token sequences, weather prediction, and linear dynamical systems.

## Why This Works (Mechanism)
Indistinguishability under a broad class of tests reduces to matching expectations of sufficient statistics s(y) for all tests in that class. By linearizing tests in an RKHS, the problem becomes multicalibration over a finite‑dimensional feature space. The online multicalibration objective is a convex‑concave game; using an EVI solver provides optimal O(√T) regret with near‑linear computation. The construction of µ_t from p_t is a convex feasibility task that is tractable for common outcome structures, completing the efficient pipeline.

## Foundational Learning
- **Multicalibration**: Ensures predictions remain accurate across all subgroupings defined by test functions. *Why needed*: Formalizes indistinguishability as matching moments under a rich test class. *Quick check*: Are all tests in the RKHS simultaneously calibrated?  
- **Reproducing Kernel Hilbert Space (RKHS)**: Provides an infinite‑dimensional family of test functions with tractable kernel evaluations. *Why needed*: Captures a broad, non‑parametric class of distinguishers while keeping computation feasible. *Quick check*: Does the chosen kernel (e.g., Gaussian) approximate the desired smooth test functions?  
- **Expected Variational Inequality (EVI)**: A framework for solving online convex games with low regret. *Why needed*: Enables efficient online multicalibration with optimal O(√T) bound. *Quick check*: Does the EVI solver converge within the claimed iteration count?  
- **Sufficient Statistics s(y)**: Mapping from outcomes to feature vectors. *Why needed*: Linearizes test functions and reduces moment matching to a finite‑dimensional problem. *Quick check*: For a given outcome space, is the induced moment set Z convex and efficiently separable?  
- **Near‑linear time complexity**: Critical for scalability to high‑dimensional outcomes. *Why needed*: Makes the algorithm practical for large d. *Quick check*: How does empirical runtime scale with d and T?

## Architecture Onboarding
**Component Map**:  
History → Multicalibration Solver → p_t → Distribution Feasibility Solver → µ_t → Sampler → y_t  

**Critical Path**:  
(1) Update multicalibration predictor using history (EVI step). (2) Compute calibrated sufficient statistics p_t. (3) Construct distribution µ_t matching those moments via convex optimization. (4) Sample y_t from µ_t and output.

**Design Tradeoffs**:  
- *RKHS kernel*: Expressiveness vs. computational cost; approximations (random Fourier features) trade accuracy for speed.
- *Sufficient statistics*: One‑hot vectors guarantee exact reconstruction but scale poorly; low‑dimensional embeddings reduce complexity at the risk of limiting test expressivity.
- *Online solver*: Exact EVI gives optimal regret but is heavier; approximate variants offer speed at a possible optimality loss.

**Failure Signatures**:  
- Infeasible moment matching (p_t outside Z) halts the algorithm.
- Kernel approximation error may violate indistinguishability by excluding relevant tests.
- Unexpected growth in kernel matrix operations breaks near‑linear scaling, especially for high d.

**First Experiments**:  
1. Validate the O(√T) indistinguishability bound on a synthetic problem with linear tests (e.g., Gaussian outcomes) and track error vs. T.  
2. Test handling of non‑Bernoulli outcomes on a multiclass dataset (e.g., CIFAR‑10 with one‑hot s(y)) and evaluate calibration against a finite test set.  
3. Measure runtime scaling with increasing outcome dimension d (e.g., 32, 64, 128, 256) and per‑step time; confirm near‑linear scaling in log T.

## Open Questions
### Open Question 1
- **Question:** For linear dynamical systems with bounded observations, does setting the history length ℓ = O(log T) in Defensive Generation yield mean estimates as accurate as those from a Kalman filter?
- **Basis in paper:** [explicit] In the linear dynamical systems example, the authors state: "Using arguments from the literature (e.g., Simchowitz [2021]), it is plausible one can show that by setting ℓ in the order of O(log(T)), the means of the distributions µ_t will be as good as those produced by a Kalman filter. However, we defer a detailed investigation to future work."
- **Why unresolved:** The paper does not provide the analysis or proof; it is explicitly left for future work.
- **What evidence would resolve it:** A formal theorem establishing that, under conditions like system stability and bounded noise, the conditional mean estimates from the algorithm achieve comparable error to the Kalman filter, perhaps by bounding the multicalibration error with respect to linear tests over histories.

### Open Question 2
- **Question:** Can Defensive Generation be extended to non‑convex outcome spaces Y while preserving computational efficiency and indistinguishability guarantees?
- **Basis in paper:** [inferred] The algorithm relies on the convexity of the sufficient statistics set Z to implement efficient separation oracles. For non‑convex Y, Z may not be convex or efficiently separable.
- **Why unresolved:** The paper only instantiates the method for convex Y (simplex, unit ball). Non‑convex cases are not considered, and the separation oracle requirement might not hold.
- **What evidence would resolve it:** A characterization of the moment set for a specific non‑convex Y that admits an efficient separation oracle, or an approximation scheme with provable guarantees.

### Open Question 3
- **Question:** For general sufficient statistics s(y) (e.g., neural embeddings), can we efficiently compute a distribution µ_t with E[µ_t s(y)] = p_t in near‑linear time?
- **Basis in paper:** [inferred] The sampling oracle in Theorem 3 is abstract; the paper solves it for specific s(y) (moments, one‑hot). For arbitrary s(y), the feasibility and efficiency of the subproblem are not addressed.
- **Why unresolved:** The construction of µ_t is non‑trivial for complex s(y); it may require solving a hard inverse problem or moment problem.
- **What evidence would resolve it:** An algorithm that, given p_t in a compact Z, outputs a discrete or parametric µ_t with small support size in poly(d) time, for a broad class of s(y).

### Open Question 4
- **Question:** Can the indistinguishability guarantees be extended to non‑linear distinguishers f(x,p,y) that are not linear in s(y), while maintaining computational efficiency?
- **Basis in paper:** [inferred] The reduction to multicalibration in Section 2 critically uses that f(x,p,y) = h(x,p)^T s(y). For non‑linear f, this reduction fails, limiting the class of tests.
- **Why unresolved:** The paper's framework is built on this linearization; non‑linear f would require fundamentally different techniques, such as higher‑order calibration or alternative games.
- **What evidence would resolve it:** A new algorithmic reduction that guarantees online indistinguishability for a richer class of f, perhaps by approximating non‑linear f with linear ones or by extending the multicalibration concept to non‑linear tests.

## Limitations
- RKHS expressivity may not cover all practical distinguishers, weakening real‑world guarantees.
- Hidden constants and kernel matrix operations could hinder scalability for very high‑dimensional outcomes.
- Indistinguishability under computational tests does not necessarily correlate with human‑perceived sample quality or downstream task performance.
