# Interpretable Predictability-Based AI Text Detection: A Replication Study
## Quick Facts
- **arXiv ID:** 2603.15034
- **Source URL:** https://arxiv.org/abs/2603.15034
- **Reference count:** 21
- **Primary result:** Adding 26 document-level stylometric features improves detection and attribution performance across English and Spanish; a single multilingual configuration matches or exceeds language-specific models; SHAP analysis confirms interpretability.

## Executive Summary
This paper replicates and extends the AuTexTification 2023 hybrid system for AI-generated text detection and attribution. Exact replication was hindered by differences in data splits, unavailability of certain Spanish GPT-2 models, and ambiguous documentation of original linguistic features. The authors addressed these issues by adopting modern multilingual models—mDeBERTa-v3-base for contextual embeddings and Qwen/mGPT for predictability—and by introducing 26 new document-level stylometric features. Experiments on English and Spanish datasets show that the additional stylometric features consistently increase Macro F1 scores for both binary detection and model attribution tasks. Moreover, a unified multilingual configuration achieves performance comparable to or better than language-specific setups. SHAP analysis reveals that several of the new stylometric features rank among the most important predictors, thereby enhancing model interpretability. The work underscores that reproducibility requires precise documentation and that stylometric signals remain valuable complements to neural and probabilistic features.

A key implication is that hybrid architectures combining diverse feature types are robust for AI text detection, and that multilingual models can simplify deployment without sacrificing accuracy. The authors also provide a modular codebase to facilitate future research.

## Method Summary
The replication pipeline consists of three feature extraction modules followed by aggregation and classification. The Predictability module computes token-level log-probabilities, top-1 probabilities, and entropy from a suite of generative models (e.g., Qwen, mGPT), with sequences truncated to 128 tokens. The Embedding module fine-tunes mDeBERTa-v3-base on the task and extracts the pooled [CLS] vector. The Stylometric module calculates 26 document-level metrics (lexical diversity, sentence length variation, punctuation usage, etc.) plus traditional linguistic categories (POS, dependencies, NER) using spaCy and textstat. Token-level features are aggregated via mean/max/min/std or processed through a BiLSTM; document-level features are concatenated directly. Classifier heads include Random Forest, XGBoost, MLP, or neural networks, depending on the configuration. The authors compared the original AuTexTification baseline, variants with newer multilingual models, and the extended stylometric set. Performance was evaluated using Macro F1 on the official AuTexTification test set for both binary detection (human vs. AI) and multi-way attribution (identifying the generator). Training used Adam (learning rates 1e-3 for BiLSTM, 2e-5 for the encoder) with early stopping on a validation split. The main outcomes demonstrate that the added stylometric features yield consistent improvements and that a single mDeBERTa-based multilingual system can replace language-specific encoders without performance loss.

## Key Results
- The extension with 26 document-level stylometric features significantly increased Macro F1 scores for detection and attribution in both English and Spanish.
- A unified multilingual configuration (mDeBERTa-v3-base + large generative models) performed on par with or better than language-specific models.
- SHAP analysis identified multiple new stylometric features as top predictors, confirming their contribution and improving model interpretability.

## Why This Works (Mechanism)

### Mechanism 1: Hybrid Feature Architecture
**Claim:** Combining predictability-based, embedding-based, and document-level stylometric features improves AI text detection and attribution performance.  
**Mechanism:** Predictability features (token-level log-probabilities, entropy) capture statistical fluency differences between human and AI text. Embedding features ([CLS] vectors from fine-tuned transformers) capture contextual semantics. Stylometric features (lexical diversity, sentence structure, punctuation usage) capture higher-level writing style patterns not fully represented in the other two. Their concatenation provides a more comprehensive text representation.  
**Core assumption:** The stylometric signal is orthogonal or complementary to token-level predictability and embedding signals, so their combination yields a superset of predictive information.  
**Evidence anchors:** Tables 7 and 8 show Macro F1 gains when extended stylometric features are added to probabilistic models; SHAP summary plots (Appendix D) rank new stylometric features among the most important.  
**Break condition:** If the added stylometric features are highly correlated with predictability or embedding features (e.g., shorter sentences leading to higher average token predictability), their marginal contribution would diminish and gains would not materialize.

### Mechanism 2: Multilingual Configuration
**Claim:** A single, unified multilingual configuration based on mDeBERTa-v3-base and large generative models can achieve performance comparable to or better than language-specific configurations.  
**Mechanism:** mDeBERTa-v3-base produces contextual embeddings that align semantic spaces across languages, allowing a single classifier head to operate effectively on both English and Spanish. Large multilingual generative models (Qwen, mGPT, BLOOM) provide calibrated probability distributions across languages, making derived predictability features language-agnostic.  
**Core assumption:** The cross-lingual transfer capabilities of these models are sufficient to neutralize language as a confounding factor, preserving task-relevant signals (model fingerprints) in the shared representation.  
**Evidence anchors:** Table 6 shows the "Large" probabilistic model group with mDeBERTa-v3-base encoder achieves the highest average scores across both languages and subtasks, matching or exceeding language-specific baselines.  
**Break condition:** If generators' stylistic and error fingerprints are language-specific, a shared multilingual representation may lose these discriminations, causing performance to drop below language-specific models.

### Mechanism 3: SHAP Interpretability Enhancement
**Claim:** SHAP analysis on the hybrid system confirms that newly introduced stylometric features are among the most influential predictors, enhancing model interpretability.  
**Mechanism:** SHAP assigns each feature a contribution value for individual predictions; aggregating absolute SHAP values across the test set ranks global feature importance. High ranking of several of the 26 new stylometric features indicates the model relies on these stylistic cues, making the decision process less opaque.  
**Core assumption:** High global SHAP magnitude correlates with genuine feature utility, and the features' definitions align with human-interpretable stylistic concepts.  
**Evidence anchors:** The abstract and Section 6 state that SHAP confirms the new features' importance; Appendix D figures show features like `root_ttr`, `sentence_length_std`, `hedge_word_ratio` with high mean absolute SHAP values.  
**Break condition:** If SHAP values are unstable (high variance across seeds) or if high-importance stylometric features are proxies for simpler signals (e.g., text length), the interpretability claim is weakened.

## Foundational Learning

**Concept 1: Transformer-based contextual embeddings (e.g., mDeBERTa-v3)**  
- **Why needed:** The FLM component relies on pooled [CLS] vectors from a fine-tuned encoder to capture deep semantic context, a core signal in the hybrid system.  
- **Quick check question:** What is the key difference between using a frozen vs. a fine-tuned transformer for the [CLS] embedding in this architecture?

**Concept 2: Token-level predictability metrics (log-probability, entropy)**  
- **Why needed:** These are the foundational features from the original AuTexTification system, based on the hypothesis that AI text is more predictable; the entire "Pred" component is built from them.  
- **Quick check question:** Why might the entropy of the token probability distribution be a more robust signal than just using the top-1 token's probability?

**Concept 3: Document-level stylometric feature engineering**  
- **Why needed:** The extension's core contribution is a set of 26 hand-crafted features (e.g., TTR, sentence length CV) intended to capture writing style; understanding their calculation and normalization is critical for replication and analysis.  
- **Quick check question:** How does normalizing `punctuation_ratio` by total characters (vs. using raw count) mitigate the influence of document length on this feature?

## Architecture Onboarding

### Component map
Data Loader -> Feature Extraction Pipeline (Predictability Module: generative models -> token-level stats; Embedding Module: mDeBERTa fine-tuning -> [CLS]; Stylometric Module: spaCy/textstat -> doc-level features) -> Feature Aggregation (mean/max/min/std or BiLSTM) -> Concatenation -> Classifier Heads (Random Forest, XGBoost, MLP, or neural) -> Interpretability Module (SHAP)

### Critical path
1. Replication Baseline: Attempt exact reproduction of AuTexTification 2023 using original models and splits.  
2. Evaluate Baseline: Identify performance gaps and limitations (model unavailability, split differences).  
3. Model Selection: Choose mDeBERTa-v3-base as multilingual encoder and "Large" group of multilingual generative models for improved cross-lingual features.  
4. Feature Integration: Add the 26 new document-level stylometric features to the LingRF pipeline.  
5. System Assembly: Combine stylometric features with probabilistic outputs (PredOut) in a Random Forest (LingRF+PredOut) or other hybrid configurations.  
6. Interpretability: Train final model and compute SHAP values to assess feature importance.  
7. Evaluation: Report Macro F1 for binary detection and model attribution in English and Spanish.

### Design tradeoffs
- *Performance vs. Interpretability*: Neural-only (FLM) vs. stylometric-only (LingRF) vs. hybrid. Hybrid gains performance; SHAP shows stylometric features remain important even when combined.  
- *Multilingual vs. Language-specific*: Single mDeBERTa simplifies deployment but may lose language-specific nuances; evidence shows it matches or beats language-specific RoBERTa variants.  
- *Feature Complexity*: BiLSTM on raw token sequences (Hybrid) vs. aggregated statistics (Hybrid_flat). Aggregated approach is faster and more robust to length variation but may lose sequential patterns.

### Failure signatures
- **Reproducibility failure:** Macro F1 deviates >0.05 from reported values, indicating issues with data splits, spaCy versions, or model substitutions.  
- **Multilingual breakdown:** Performance drop >0.1 F1 for one language when using mDeBERTa, suggesting insufficient cross-lingual capacity.  
- **Stylometric insignificance:** Extended features do not improve LingRF performance or fail to appear in top SHAP importance ranks, implying redundancy or poor definition.

### First 3 experiments
1. **Exact Replication Attempt:** Run official GitHub code with original GPT-2/RoBERTa models on provided splits; record Macro F1 and log any modifications for missing components.  
2. **Encoder Swap Stress Test:** Replace RoBERTa with mDeBERTa-v3-base while keeping all other baseline components identical; evaluate impact on performance for both languages.  
3. **Stylometric Ablation:** Train LingRF with only new features, only original features, and both; compare Macro F1 to verify non-redundant signal; generate SHAP summary for combined model to confirm new features rank in top 10.

## Open Questions the Paper Calls Out
1. **Minimal universal stylometric features:** Can a smaller set of universal stylometric features achieve comparable performance across detection, attribution, and multiple languages? The study extended the feature set but did not perform selection to identify a compact, language-agnostic subset.  
2. **Impact of Spanish model replacements:** To what extent do alternative language models used as replacements for the unavailable Spanish GPT-2 variants affect reproducibility and Spanish performance? The original models were defunct; substitutions may cause variance.  
3. **Broader multilingual model evaluation:** Would a wider evaluation of multilingual encoder and generative architectures yield a more optimal unified configuration than mDeBERTa-v3 and the "Large" group? The study tested only a limited subset.  
4. **Generalization to other data:** How well do the findings generalize to other datasets, domains, and AI generators? Experiments were confined to AuTexTification 2023; performance may differ with newer LLMs or different genres.  
5. **Test set tuning bias:** Does using the test set for iterative configuration selection introduce performance optimism or unfair comparison with blind shared-task systems? The authors tuned on test labels, which would not be permissible in a shared task.

## Limitations
- Exact replication was impeded by unavailability of original Spanish GPT-2 models, ambiguous linguistic feature specifications, and non-identical data splits, leading to potential deviations from reported results.  
- The study evaluated a limited selection of multilingual models; other recent architectures might achieve better performance or robustness.  
- All experiments were conducted solely on the AuTexTification 2023 dataset, which restricts generalizability to other domains, languages, or newer AI generators.
