# GP2F: Cross-Domain Graph Prompting with Adaptive Fusion of Pre-trained Graph Neural Networks

## Quick Facts
- arXiv ID: 2602.11629
- Source URL: https://arxiv.org/abs/2602.11629
- Reference count: 29
- Primary result: GP2F achieves state-of-the-art cross-domain few-shot node and graph classification, improving average accuracy by 1.66% over the best prior method.

## Executive Summary
The paper investigates why graph prompt learning (GPL) remains effective under large cross-domain distribution shifts, revealing that both linear probing (LP) and full fine-tuning (FT) serve as strong baselines in such settings. Theoretical analysis proves that jointly optimizing a frozen pre-trained GNN branch and a lightweight adapted branch yields a strictly smaller estimation error than using either branch alone. Guided by this insight, GP2F implements a dual-branch architecture with an adaptive fusion mechanism, a contrastive loss for branch alignment, and a topology-consistent loss to regularize fusion. Extensive experiments on multiple node and graph classification datasets demonstrate consistent outperformance of LP, FT, and prior GPL methods, with an average accuracy gain of 1.66% over the previous state-of-the-art.

## Method Summary
GP2F adapts a pre-trained graph neural network (GNN) to a target domain with scarce labeled nodes/graphs. It employs two parallel branches: (1) a frozen pre-trained GNN that preserves source-domain knowledge, and (2) an adapted branch that injects lightweight residual adapters into each GNN layer to enable task-specific tuning. The two branch outputs, `H_pre` and `H_adp`, are fused via a learnable scalar `α`: `H_mix = α·H_pre + (1‑α)·H_adp`. The method optimizes three losses: (i) cross‑entropy `L_cls` on `H_mix`; (ii) contrastive loss `L_ctr` that aligns representations of the same node across branches while respecting graph structure; (iii) topology‑consistent loss `L_fus` that regularizes the fused similarity matrix `S_mix` to match the target adjacency `A`. Training updates adapters, a projection MLP (if needed), the classifier, and `α` while freezing the backbone GNN. Hyperparameters (e.g., adapter rank `r`, loss weights `λ₁`, `λ₂`) are tuned per dataset, with early stopping on a validation subset.

## Key Results
- GP2F surpasses linear probing, full fine‑tuning, and prior graph prompt learning baselines across a wide range of cross‑domain few‑shot node and graph classification tasks.
- Average accuracy improves by 1.66% over the best existing method.
- Gains are consistent on diverse datasets (e.g., CiteSeer, CS, CHEM, PROTEINS), demonstrating robustness to significant domain shifts.

## Why This Works (Mechanism)

### Mechanism 1
**Claim:** Jointly optimizing a frozen pre‑trained GNN branch and a lightweight adapted branch yields a strictly smaller estimation error than optimizing either branch alone under cross‑domain distribution shifts.  
**Mechanism:** The frozen branch (`h_g`) and adapted branch (`h_a`) are modeled as two unbiased noisy observations of the same latent node representation `z_i` with distinct error variances and cross‑covariance. Their affine fusion `z̃_i(λ) = λ h_g + (1−λ) h_a` forms a control variate; the optimal weight `λ*` minimizes the mean‑squared error (MSE) by exploiting complementary error patterns (`ρ < min{σ_g², σ_a²}`).  
**Core assumption:** The two branches' errors are zero‑mean, non‑identical, and not perfectly aligned (`σ_g² + σ_a² − 2ρ > 0`).  
**Evidence anchors:** Abstract; Section 3 (formal derivation of `MSE(λ)` as strictly convex quadratic, Theorem 3.4 showing `MSE(λ*) < min{MSE(0), MSE(1)}`); neighboring papers explore separate adaptation, but the explicit proof of complementary error fusion is unique.  
**Break condition:** If branches produce perfectly correlated errors (`ρ = σ_g² = σ_a²`), `λ*` is undefined or yields no improvement; practically this occurs if the adapted branch merely replicates the frozen branch's outputs.

### Mechanism 2
**Claim:** A contrastive loss (`L_ctr`) aligns the semantic representations of the two branches, guiding the adapted branch to generate representations that are task‑specific yet consistent with the pre‑trained knowledge structure.  
**Mechanism:** Representations of the same node from the frozen (`H_pre`) and adapted (`H_adp`) branches are treated as a positive pair. The (NT‑Xent‑style) loss minimizes their distance while maximizing separation from other nodes in the batch, ensuring both branches encode similar node semantics despite different parameter updates.  
**Core assumption:** Nodes that are the same should have consistent representations across branches; the graph's inherent structure provides a stable supervisory signal.  
**Evidence anchors:** Section 4.2 (describes constructing positive pairs and the loss formulation); statement that the loss aligns target‑domain structure with the source domain.  
**Break condition:** If domain shift is so severe that source‑domain features and target‑domain optimal features are semantically incompatible, forcing alignment may distort useful task‑specific signals captured by the adapted branch.

### Mechanism 3
**Claim:** A topology‑consistent fusion loss (`L_fus`) regularizes the adaptive fusion weight `α` by enforcing that the fused representation similarity matrix respects the target graph’s adjacency structure.  
**Mechanism:** Self‑similarity matrices of both branches (`S_pre`, `S_adp`) are computed. The fused matrix `S_mix = α S_pre + (1−α) S_adp` is compared against the ground‑truth adjacency `A` via binary cross‑entropy on a binary consistency mask `M`, constraining `α` so that fused similarities for connected nodes are high and for disconnected nodes are low.  
**Core assumption:** The topological structure of the target graph is a valid prior for semantic similarity; adjacent nodes should be similar in the final representation space.  
**Evidence anchors:** Section 4.3 (intuition that adjacent nodes should exhibit high similarity and the loss formulation).  
**Break condition:** If the target graph’s topology is noisy or not predictive of node semantics (e.g., many random edges), enforcing consistency may force `α` to discard useful discriminative signals from one branch.

## Foundational Learning

* **Concept: Graph Neural Networks (GNNs)**  
  Why needed here: GP2F's frozen and adapted branches are built on a pre‑trained GNN encoder; understanding message passing and representation learning on graphs is essential to grasp what “pre‑trained knowledge” means and how adapters modify it.  
  Quick check question: What is the difference between a node's representation after one GNN layer versus after several layers, and why might shallow layers preserve more general structure while deeper layers become task‑specific?

* **Concept: Contrastive Learning**  
  Why needed here: `L_ctr` is a contrastive loss. Understanding the principle of pulling positive pairs together and pushing negatives apart is key to seeing how the two branches are aligned.  
  Quick check question: In the contrastive loss defined (Eq. 18), what are the positive and negative samples, and why is the frozen branch's view used as the anchor?

* **Concept: Parameter‑Efficient Fine‑Tuning (e.g., Adapters, LoRA)**  
  Why needed here: The adapted branch uses lightweight “adapters” instead of full fine‑tuning to avoid catastrophic forgetting. Knowing the adapter design (down/up projection) explains how task‑specific adaptation is injected with minimal parameters.  
  Quick check question: Why is a small learnable scaling factor `β^(l)` used for each adapter layer, and how does it help in the early training phase?

## Architecture Onboarding

**Component map:**  
Frozen Branch: pre‑trained GNN `g_θ*` → `H_pre`;  
Adapted Branch: `g_θ*` + layer‑wise Adapters `A` + scaling factors `β` → `H_adp`;  
Fusion Module: scalar `α` → `H_mix = α·H_pre + (1−α)·H_adp`;  
Alignment Module: contrastive loss `L_ctr` (`H_pre`, `H_adp`);  
Regularization Module: similarity matrices `S_pre`, `S_adp`, `S_mix` → topology‑consistent loss `L_fus` vs. adjacency `A`;  
Classification Head: linear classifier on `H_mix` → `L_cls`.

**Critical path:**  
1. Input graph `(A, X)` → feature projection `H^(0)`.  
2. Parallel encoding: `H_pre = g_θ*(A, H^(0))`; `H_adp = g_θ*(A, H^(0))` with adapters.  
3. Compute `L_ctr(H_pre, H_adp)`.  
4. Fuse: `H_mix = α·H_pre + (1−α)·H_adp`.  
5. Compute `L_fus` from `S_mix` (derived from `H_mix`) and `A`.  
6. Predict with classifier on `H_mix` → `L_cls`.  
7. Total loss `L = L_cls + λ₁ L_ctr + λ₂ L_fus` → update Adapters `A`, Projection MLP (if any), classifier, `α`, `β`; freeze `g_θ*`.

**Design tradeoffs:**  
- Adapter rank `r`: too small limits adaptation capacity; too large risks overfitting and catastrophic forgetting (Fig. 5).  
- Loss weights `λ₁`, `λ₂`: high `λ₁` may over‑align branches, reducing autonomy of adapted branch; high `λ₂` may overfit to target topology if it is noisy.  
- Learnable `α`: initialized small (favoring frozen branch) must gradually increase as adapted branch learns; a high learning rate for `α` can cause fusion instability.

**Failure signatures:**  
1. Collapsed branches: `H_pre ≈ H_adp` → `L_ctr` near zero, `α` stuck at extreme → no benefit from dual‑branch (ablation “w/o L”).  
2. Topology mismatch: `S_mix` poorly aligned with `A` → high `L_fus`, indicating poor fusion or incompatibility between branches.  
3. Over‑adapted branch: `H_adp` overfits to few‑shot labels, diverges from `H_pre` → high `L_ctr`, `α` near 0, effectively reverting to linear probing.

**First 3 experiments:**  
1. Ablation – Single branch: Train only frozen branch (LP) or only adapted branch (prompt‑only) to establish baselines; GP2F should significantly outperform both.  
2. Ablation – Loss components: Remove `L_ctr` or `L_fus` individually to measure marginal contribution; each removal should cause a performance drop.  
3. Weight visualization: Track `α` during training; it should start near 1 and gradually decrease as adapted branch becomes useful, stabilizing before convergence.

## Open Questions the Paper Calls Out

**Open Question 1**  
*Question:* Do the theoretical assumptions of linear separability and second‑order error model (zero‑mean, non‑perfectly aligned errors) hold for real‑world cross‑domain graph data, and how sensitive is GP2F's performance to violations?  
*Basis in paper:* Theoretical analysis relies on Assumptions 3.1 and 3.2; the paper does not empirically validate whether latent representations are linearly separable or whether the two branches produce unbiased, complementary errors under significant domain shift.  
*Why unresolved:* Without verifying these assumptions, the theoretical guarantee that fusion reduces estimation error may not apply in practice, leaving the true reason for GP2F's effectiveness uncertain.  
*What evidence would resolve:* Measure linear separability (e.g., via linear classifier accuracy) of frozen and adapted branch representations on target domains; analyze error distributions (bias, correlation) relative to latent signals; conduct controlled experiments where assumptions are synthetically violated to quantify performance impact.

**Open Question 2**  
*Question:* Does the learnable fusion weight `α` converge to the theoretically optimal `λ⋆` derived from error statistics, and if not, what is the resulting gap in estimation error?  
*Basis in paper:* Theorem 3.4 shows optimal fusion `λ⋆` minimizes MSE under known error variances and covariance. GP2F learns `α` via gradient descent with auxiliary losses but never estimates the true parameters (`σ_g, σ_a, ρ`) nor proves convergence to `λ⋆`.  
*Why unresolved:* The paper does not link `α` to `λ⋆` empirically or theoretically. Thus, it is unclear whether adaptive fusion actually achieves the theoretical benefit or if gains come from other effects of the losses.  
*What evidence would resolve:* During training, compare `α` with an offline estimate of `λ⋆` computed from branch representations (e.g., using covariance of errors relative to labels). Alternatively, derive a regret bound for `α`'s deviation from `λ⋆` and correlate it with classification performance.

**Open Question 3**  
*Question:* How do the contrastive loss `L_ctr` and topology‑consistent loss `L_fus` individually and jointly promote the error complementarity required by the theory, and are they both necessary?  
*Basis in paper:* The paper introduces `L_ctr` and `L_fus` to align representations and regularize fusion, and ablation studies show each contributes to performance. However, their precise role in shaping error statistics is not explained.  
*Why unresolved:* The losses are heuristic; it is unknown whether they directly reduce error correlation or enforce unbiasedness. Without this understanding, the design may be suboptimal and difficult to improve.  
*What evidence would resolve:* Analyze error terms `ε_g`, `ε_a` before and after applying each loss (e.g., via proxy metrics like representation similarity to ideal features). Test alternative losses targeting error decorrelation. Theoretically, prove under what conditions these losses yield complementary errors.

## Limitations

- Unknown exact negative sampling scheme for `L_ctr` and threshold setting for `L_fus` create reproducibility challenges and may affect performance.
- Theoretical assumptions (e.g., error complementarity) may not hold under extreme domain shifts or noisy target topologies, risking breakdown of the guaranteed benefit.
- The learnable fusion weight `α` can be unstable, potentially favoring one branch excessively, especially when the adapted branch overfits or the target topology is unreliable.
