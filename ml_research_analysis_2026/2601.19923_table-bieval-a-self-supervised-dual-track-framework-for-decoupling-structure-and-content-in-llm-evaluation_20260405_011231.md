# Table-BiEval: A Self-Supervised, Dual-Track Framework for Decoupling Structure and Content in LLM Evaluation

## Quick Facts
- **ArXiv ID**: 2601.19923
- **Source URL**: https://arxiv.org/abs/2601.19923
- **Reference Count**: 22
- **Primary Result**: Proposes Table-BiEval, a self-supervised framework using deterministic intermediate representations to compute Content Semantic Accuracy (CSA) and Normalized Tree Edit Distance (NTED) for automated, granular evaluation of structured data generation.

## Executive Summary
Structured data generation by LLMs requires evaluation beyond traditional text metrics, which fail to capture structural fidelity and semantic drift. This paper introduces Table-BiEval, a self-supervised framework that decouples structure and content via deterministic Intermediate Representations (IRs), parsing outputs into unified abstract syntax trees. Two metrics are computed: Content Semantic Accuracy (CSA) measures semantic fidelity, while Normalized Tree Edit Distance (NTED) assesses topological consistency. Human-free evaluation of 15 LLMs across hierarchical and tabular formats revealed that mid-sized models (e.g., Qwen3-32B) achieve superior structural efficiency, deep recursive nesting causes severe performance collapse, and JSON is universally preferred over XML and HTML. The proposed metrics demonstrate higher sensitivity to structural errors than ROUGE-2.

## Method Summary
Table-BiEval operates in two tracks. First, a deterministic IR parser transforms structured outputs (JSON, XML, HTML, tables) into a unified abstract syntax tree (AST). Second, dual metrics are computed: CSA evaluates semantic fidelity by comparing leaf node content against a reference using embedding similarity, while NTED measures structural consistency by normalizing the tree edit distance between the generated and reference ASTs. The framework is self-supervised, requiring only reference structures without human annotations, enabling scalable, automated assessment of both content preservation and topological adherence.

## Key Results
- Mid-sized models (e.g., Qwen3-32B with CSA 0.912, NTED 0.958) outperform larger counterparts in structural efficiency on hierarchical tasks.
- Deep recursive nesting causes dramatic performance drops; DeepSeek-R1 shows a 67.6% decline on nested tasks despite near-perfect symbolic task scores.
- JSON formats are consistently favored by all models; HTML poses significant challenges for smaller models.
- Table-BiEval metrics exhibit higher variance than ROUGE-2, confirming superior sensitivity to structural errors.

## Why This Works (Mechanism)
Traditional text metrics (e.g., BLEU, ROUGE) conflate structure and content, masking semantic drift in structured outputs. Table-BiEval's dual-track design explicitly separates evaluation: CSA isolates content accuracy via semantic similarity of leaf values, while NTED isolates structural accuracy via tree topology. The use of deterministic IRs ensures consistent AST representation across formats, enabling format-agnostic comparison. This decoupling allows precise diagnosis of failure modes—e.g., high NTED with low CSA indicates structural corruption despite correct content, a pattern undetectable by token-level overlap metrics.

## Foundational Learning
- **Abstract Syntax Trees (ASTs)**: Tree representations of hierarchical data structure; needed to unify diverse formats (JSON/XML/HTML) into a common graph for edit-distance computation. Quick check: Verify parser outputs consistent ASTs for equivalent logical structures across formats.
- **Tree Edit Distance (TED)**: Measures minimal operations to transform one tree into another; normalized (NTED) to compare across trees of different sizes. Quick check: Confirm NTED scores align with intuitive structural similarity in small, hand-crafted examples.
- **Self-Supervised Evaluation**: Uses reference structures as ground truth without human raters; needed for scalable, reproducible fidelity assessment. Quick check: Ensure reference datasets are noise-free and cover target schema variations.
- **Semantic vs. Structural Fidelity**: Separates content correctness (CSA) from layout/topology correctness (NTED); needed to diagnose specific error types. Quick check: Correlate CSA drops with content alterations (e.g., value changes) and NTED drops with structural changes (e.g., nesting errors) in controlled perturbations.
- **Deterministic Intermediate Representations (IRs)**: Canonical, lossless ASTs derived from source formats; needed to eliminate format-specific biases in comparison. Quick check: Test IR reversibility—reconstruct original format from AST and confirm equivalence.
- **Schema-Agnostic Parsing**: Parser handles arbitrary schemas without retraining; needed for broad applicability. Quick check: Run parser on unseen schemas (e.g., YAML) and validate AST consistency with known logical equivalents.

## Architecture Onboarding
**Component Map**:  
Input Structured Output -> Deterministic IR Parser -> Unified AST -> CSA Module & NTED Module -> CSA Score & NTED Score

**Critical Path**:  
1. Parse output into AST via format-specific rules mapped to IR.  
2. Compute NTED via tree alignment algorithm (e.g., Zhang-Shasha) between generated and reference ASTs, normalized by reference tree size.  
3. Compute CSA by aligning leaf nodes (value-bearing terminals) and calculating mean embedding similarity (e.g., using a frozen encoder) across matches.

**Design Tradeoffs**:  
- Self-supervision vs. human benchmark: Enables large-scale runs but lacks direct human correlation validation.  
- IR generality vs. format coverage: Unified AST simplifies comparison but may lose format-specific nuances (e.g., HTML attributes).  
- Exact tree matching for NTED: Ensures topological precision but may penalize semantically equivalent rearrangements.

**Failure Signatures**:  
- Parser crashes on malformed output → no scores; indicates need for pre-validation.  
- High NTED + low CSA → severe structural corruption with intact content.  
- Low NTED + high CSA → correct structure but content errors (e.g., typos).  
- Consistently low scores on HTML → models struggle with non-JSON-like syntax.

**First Three Experiments**:  
1. **Format Generalization Test**: Run Table-BiEval on model outputs for JSON, XML, and HTML prompts; compare average NTED/CSA across formats to quantify format bias.  
2. **Nesting Depth Stress Test**: Generate outputs with varying recursive nesting levels (e.g., 1–5 levels); measure NTED/CSA decay to identify collapse thresholds.  
3. **Metric Sensitivity A/B Test**: Compare variance of NTED/CSA vs. ROUGE-2 on outputs with controlled structural errors (e.g., shuffled keys, missing parentheses); confirm higher discriminant power.

## Limitations
- IRs may not generalize to highly irregular or novel structured formats beyond the evaluated set (hierarchical tables/JSON/XML/HTML).
- Absence of human evaluation benchmarks for structural fidelity prevents validation that higher NTED/CSA scores correlate with real-world usability.
- Performance trends (e.g., mid-sized model advantage) are corpus-dependent and may not hold for domains outside synthetic/hierarchical tasks.

## Confidence
- **Metrics sensitivity (NTED/CSA vs. ROUGE-2)**: High – Direct comparative variance analysis provided.
- **Mid-sized model superiority (e.g., Qwen3-32B)**: Medium – Specific to 15 evaluated LLMs and task set; scaling trends may differ.
- **Format preferences (JSON > XML/HTML) & nested task collapse**: Medium – Consistent across tested models but may not generalize to models with specialized structured-data training.

## Next Checks
1. **External format generalization**: Apply Table-BiEval to non-tabular structured outputs (e.g., YAML, Protocol Buffers, domain-specific schemas) to test IR robustness.
2. **Human correlation study**: Collect expert ratings for structural/semantic fidelity on a subset of LLM outputs; compute correlation with CSA/NTED scores.
3. **Efficiency vs. accuracy trade-off**: Measure inference/compute cost of NTED/CSA computation across model scales and compare with lightweight proxies (e.g., schema validation accuracy).
