# Dataless Weight Disentanglement in Task Arithmetic via Kronecker-Factored Approximate Curvature

## Quick Facts
- **arXiv ID:** 2602.17385
- **Source URL:** https://arxiv.org/abs/2602.17385
- **Reference count:** 40
- **Primary result:** TAK achieves state-of-the-art dataless performance on 8 vision benchmarks, matching data-using baselines in task addition and surpassing them in task negation.

## Executive Summary
Task arithmetic enables model editing by adding/subtracting task vectors, but combining multiple vectors causes cross-task interference. Existing regularization methods for disentanglement require access to other tasks' data, conflicting with modularity and privacy. This paper proposes TAK, a dataless approach that treats representation drift regularization as a curvature approximation problem. It uses Kronecker-Factored Approximate Curvature (KFAC) to efficiently approximate the Generalized Gauss-Newton matrix and merges per-task factors into a single surrogate, achieving constant complexity in the number of tasks. On 8 vision benchmarks with CLIP ViTs, TAK matches or exceeds data-using baselines in both task addition and negation, while being robust to scaling coefficients and enabling task-localization.

## Method Summary
TAK operates in a linearized fine-tuning regime. For each task, a task vector τ is learned by minimizing the task-specific loss plus a regularization term that penalizes representation drift on other tasks. The drift is approximated as a quadratic form τᵀG₋ₜτ, where G₋ₜ is the sum of other tasks' Generalized Gauss-Newton (GGN) matrices. To avoid data dependence and linear scaling, G₋ₜ is approximated via KFAC: each layer's GGN block is factorized as B⊗A, where A and B are input and gradient covariance matrices. These factors are pre-computed (either per-task or shared) without requiring downstream data. During training, a heuristic merge aggregates all factors into a single surrogate (ΣB)⊗(ΣA), enabling constant-time regularizer evaluation. After independent per-task training, task vectors are merged by weighted summation at inference.

## Key Results
- On ViT-B/16, TAK reaches 88.3% absolute accuracy (97.9% normalized) on task addition with α=1.0, matching τJp (88.2%, 98.3%) which uses task data.
- For task negation, TAK achieves 3.4% target task accuracy while preserving control task performance, better than τJp's 4.7%.
- TAK exhibits robustness to scaling coefficients (α) and demonstrates effective task-localization, with task vectors affecting primarily their own input distribution.

## Why This Works (Mechanism)

### Mechanism 1: Representation Drift as Curvature Regularization
- **Claim:** Representation drift between tasks can be regularized via a quadratic form involving the Generalized Gauss-Newton (GGN) matrix, eliminating data dependence.
- **Mechanism:** Under linearization of the model around pre-trained weights, the drift in predictions for a task when adding another task vector is α² τᵀ G τ, where G is the Jacobian Gram matrix (GGN). This matrix can be pre-computed from the pre-trained model without requiring task data.
- **Core assumption:** The model linearization is valid, i.e., fine-tuning updates are small enough that the first-order Taylor expansion accurately approximates function changes.
- **Evidence anchors:** [section 3.1] derives the drift simplification into a quadratic form; [corpus] supports GGN use for data-free regularization.
- **Break condition:** If linearization fails (e.g., large parameter shifts or highly non-linear models), the quadratic form may not accurately represent drift, leading to poor disentanglement.

### Mechanism 2: Efficient GGN Approximation with KFAC
- **Claim:** Kronecker-Factored Approximate Curvature (KFAC) approximates the large GGN matrix by factorizing it into Kronecker products of small layer-wise covariances, reducing computational and storage costs.
- **Mechanism:** For each layer, KFAC approximates the GGN block as B⊗A, where A and B are input and gradient covariance matrices, respectively. This avoids instantiating the full P×P matrix and enables efficient quadratic form evaluation.
- **Core assumption:** The block-diagonal and Kronecker product approximations capture most relevant curvature information, and layer-wise independence holds.
- **Evidence anchors:** [section 3.3] shows the derivation for fully-connected layers; extensive literature validates KFAC's efficiency.
- **Break condition:** When intra-layer correlations are strong or the architecture deviates from assumptions (e.g., weight-sharing in transformers), KFAC may be inaccurate.

### Mechanism 3: Constant-Complexity Task Merging via Factor Aggregation
- **Claim:** Per-task KFAC factors can be merged into a single surrogate with O(1) complexity in the number of tasks, enabling scalable multi-task regularization without linear memory growth.
- **Mechanism:** Instead of storing and summing task-specific matrices Bₜ⊗Aₜ, use heuristic merge: Σₜ (Bₜ⊗Aₜ) ≈ (Σₜ Bₜ)⊗(Σₜ Aₜ). This leverages the distributive property under the Kronecker product and keeps storage and computation constant.
- **Core assumption:** KFAC factors across tasks are similar enough that the merged approximation error is small; justified when tasks share a common pre-trained backbone.
- **Evidence anchors:** [section 3.4] presents the merge heuristic and empirical evidence matching un-merged performance.
- **Break condition:** If task factors vary widely, the merge error may grow, leading to suboptimal regularization and increased interference.

## Architecture Onboarding
Pre-trained model (θ₀) -> Linearization wrapper -> KFAC estimator (offline) -> Regularization module (online) -> Fine-tuning optimizer -> Task vector storage -> Merger (inference)

**Critical path:**
1. Estimate KFAC factors per-task (using task data) or shared (e.g., ImageNet) for data-free operation.
2. For each task t', fine-tune τₜ' by minimizing L_Dt'(τₜ') + β Σₜ≠ₜ' λₜ τₜ'ᵀ G₋ₜ' τₜ', with G₋ₜ' from merged KFAC.
3. After training, merge all task vectors by summation (θ = θ₀ + Σ αₜ τₜ).

**Design tradeoffs:**
- Accuracy vs. memory: Full per-task KFAC is precise but scales linearly; merged surrogate is O(1) but may add approximation error.
- Data-dependence: Task-specific KFAC requires auxiliary data; shared KFAC (e.g., ImageNet) is fully dataless but less tailored.
- Regime choice: Linearized fine-tuning is designed for but can be paired with attention-only FT in non-linear settings.
- Overhead: KFAC estimation adds pre-computation cost; regularizer adds negligible training overhead.

**Failure signatures:**
- High disentanglement error ξ(α₁,α₂): indicates poor weight separation; check KFAC merge quality or λ.
- Sensitivity to α: performance drops sharply when α ≠ 1; suggests weak regularization or linearization breakdown.
- Memory overflow: for large models (e.g., ViT-L/14), storing full KFAC may exceed memory; use compression.
- Task interference in merged model: if tasks interfere, merged KFAC may not aggregate properly; verify per-task factor similarity or increase λ.

**First 3 experiments:**
1. Benchmark on 8 Vision with CLIP ViTs: evaluate TAK against baselines in task addition and negation.
2. Alpha-sweep analysis: test robustness to scaling coefficients across α ∈ [0, 2]; expect flat performance curves.
3. Task localization study: measure ∥Jθf(x,θ₀)τₜ∥² for in-task vs. out-of-task inputs; expect clear separation.

## Open Questions the Paper Calls Out
1. **Generalization to other fine-tuning paradigms:** How can TAK be extended to standard full fine-tuning or PEFT methods (e.g., LoRA)? Current linearization assumption may not hold.
2. **Constant-time merging guarantees:** Can curvature approximations maintain accuracy while enabling O(1) merging? The heuristic merge lacks theoretical bounds.
3. **Language domain refinement:** Why does TAK show less improvement in language tasks? More sophisticated curvature estimation for transformers may help.
4. **Optimal compression strategies:** What compression techniques best balance memory and disentanglement? Preliminary tests are inconclusive.

## Limitations
- **Layer specification ambiguity:** Exact set of "linear projection layers" in CLIP ViT is not precisely defined, risking incorrect KFAC application.
- **Merge heuristic generality:** Constant-complexity factor aggregation assumes task similarity; accuracy may decay for highly diverse tasks.
- **Scalability details:** For large models like ViT-L/14, compression hyperparameters (block size, SVD rank) are omitted, hindering memory-optimized replication.

## Confidence
- **Representation drift as curvature regularization:** Medium confidence. Linearization is sound for small updates, but breakpoints for large shifts are not fully characterized.
- **KFAC for GGN approximation:** High confidence for efficiency (established literature), Medium confidence for accuracy in transformers due to deviations from FC assumptions.
- **Constant-complexity merging:** Medium confidence. Heuristic is empirically validated on similar vision tasks, but lacks theoretical guarantees and may decay for divergent tasks.
