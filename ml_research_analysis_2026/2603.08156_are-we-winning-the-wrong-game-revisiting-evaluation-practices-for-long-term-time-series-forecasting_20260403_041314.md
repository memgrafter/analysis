# Are We Winning the Wrong Game? Revisiting Evaluation Practices for Long-Term Time Series Forecasting

## Quick Facts
- **arXiv ID:** 2603.08156
- **Source URL:** https://arxiv.org/abs/2603.08156
- **Reference count:** 25
- **Primary result:** Aggregated pointwise error metrics (MSE/MAE) obscure significant performance variability across different structural conditions in time series forecasting windows.

## Executive Summary
The paper argues that current evaluation practices in long-term time series forecasting (LTSF) overemphasize marginal improvements in aggregated pointwise metrics like MSE and MAE on fixed benchmarks. This narrow focus encourages models to specialize on benchmarks rather than capture meaningful temporal dynamics. To address this, the authors propose a three-dimensional evaluation framework encompassing statistical fidelity, structural coherence, and decision-level relevance. Using window-level error analysis on the ETTm2 dataset, they demonstrate that aggregated metrics hide substantial variability in model performance across different structural conditions (e.g., anomalies, regime shifts), undermining claims of universal superiority based on average scores.

## Method Summary
The study evaluates multiple state-of-the-art LTSF models (Informer, Autoformer, DLinear, NHITS, PatchTST) using the NeuralForecast library on the ETTm2 dataset. Standard train/validation/test splits (70%/10%/20%) and forecasting horizons (96, 192, 336, 720 steps) are employed. Beyond aggregated MSE/MAE, the authors compute these metrics at the individual sliding window level across the test set. Windows are sorted by error to identify worst, average, and best performing cases, which are visualized to compare predictions against ground truth. This approach reveals performance heterogeneity masked by average scores.

## Key Results
- Aggregated MSE/MAE rankings differ significantly from window-level analysis, where models excel in some structural regimes but fail in others.
- Window-level error distributions show heavy tails, indicating that average metrics are skewed by a minority of highly erroneous windows.
- Champion models on aggregated leaderboards do not consistently perform best across all window types, challenging the validity of universal superiority claims.

## Why This Works (Mechanism)
The mechanism relies on window-level error decomposition. By computing MSE/MAE per sliding window and sorting, it reveals that aggregated metrics arise from a heavy-tailed distribution of errors, where a small number of structurally challenging windows (e.g., containing anomalies, regime shifts) disproportionately inflate average scores. This exposes model specialization: top models on leaderboards may excel on easy windows but fail on hard ones, invalidating claims of universal superiority. The approach assumes that structural conditions are implicitly captured by error magnitude and that window-level trends reflect model robustness.

## Foundational Learning
- **Time series forecasting:** Predicting future values based on past observations; requires capturing temporal dependencies.
- **Pointwise error metrics (MSE/MAE):** Standard measures aggregating errors across all forecasted points; can mask localized failures.
- **Window-level analysis:** Evaluating forecasts on individual contiguous subsequences to expose performance variability.
- **Structural conditions:** Characteristics like trends, seasonality, anomalies, and regime shifts that affect forecast difficulty.
- **Neural forecasting models:** Deep learning architectures (e.g., Transformers, linear models) adapted for time series; prone to benchmark overfitting.
- **Benchmark specialization:** Models optimized for specific test sets rather than generalizable temporal dynamics.

## Architecture Onboarding
**Component Map:** Data loading -> Normalization -> Model training -> Sliding window inference -> Per-window MSE calculation -> Error distribution analysis

**Critical Path:** Prepare ETTm2 dataset -> Train each model -> Generate forecasts for all test windows -> Compute MSE per window -> Sort windows by MSE -> Select representative windows for visualization.

**Design Tradeoffs:** Aggregated metrics offer simplicity but obscure variability; window-level analysis adds granularity at the cost of computational overhead and interpretation complexity.

**Failure Signatures:** Low variance in window-level errors suggests dataset lacks structural diversity or preprocessing removed signal; high variance indicates metric sensitivity to local conditions.

**First Three Experiments:**
1. Replicate window-level MSE distribution for DLinear on ETTm2 horizon 96 using default NeuralForecast hyperparameters.
2. Compare window-level error distributions across all five models for a single horizon to identify consistent patterns of specialization.
3. Extend analysis to Electricity dataset to test if obscuring effect persists across domains.

## Open Questions the Paper Calls Out
The paper highlights the need to (1) quantify structural conditions (e.g., via trend or seasonality metrics) to enable systematic evaluation, (2) validate the proposed three-dimensional framework against downstream decision tasks, and (3) test if the obscuring effect of aggregated metrics persists across diverse datasets beyond ETTm2. It also questions whether current benchmark designs inadvertently promote overfitting to statistical artifacts rather than temporal dynamics.

## Limitations
- Analysis limited to ETTm2 dataset, raising questions about generalizability to other domains.
- Only five LTSF models evaluated, excluding recent architectures.
- Structural conditions are qualitatively described without standardized quantification.
- Proposed evaluation framework lacks empirical validation via downstream tasks or concrete structural coherence metrics.

## Confidence
- **Aggregated metrics mask window-level variability:** Medium (robust on one dataset, needs cross-dataset confirmation).
- **Structural coherence dimension:** Low (conceptual, not operationalized or measured).
- **Decision-level relevance dimension:** Low (not evaluated in study).

## Next Checks
1. Conduct identical window-level error analysis on at least three additional benchmark datasets (e.g., Electricity, Traffic, Weather) to test consistency.
2. Define and compute quantitative structural coherence metrics (e.g., trend preservation via Theil-Sen slope error, seasonality via spectral divergence) and compare model rankings against MSE.
3. Evaluate forecasts in a downstream decision-making task (e.g., inventory management) to assess correlation between pointwise errors and end-to-end performance.
