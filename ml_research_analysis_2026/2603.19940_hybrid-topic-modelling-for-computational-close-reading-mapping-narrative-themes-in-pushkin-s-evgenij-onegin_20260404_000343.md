# Hybrid topic modelling for computational close reading: Mapping narrative themes in Pushkin's Evgenij Onegin

## Quick Facts
- **ArXiv ID**: 2603.19940  
- **Source URL**: https://arxiv.org/abs/2603.19940  
- **Reference count**: 7  
- **Primary result**: A hybrid LDA‑sPLS‑DA framework identifies five stable, interpretable topics in a segmented Italian translation of Pushkin’s *Evgenij Onegin*, with sPLS‑DA achieving 85% accuracy in recovering LDA’s dominant topics.

## Executive Summary
This study investigates whether topic modeling can be applied to a single poetic text with a very small corpus. The authors use an Italian translation of Pushkin’s *Evgenij Onegin* divided into 35 stanza‑group blocks. They introduce a hybrid framework that first applies Latent Dirichlet Allocation (LDA) to obtain topic distributions and then uses sparse Partial Least Squares Discriminant Analysis (sPLS‑DA) in a one‑versus‑rest classification to test the discriminative power of those topics. Validation relies on a multi‑seed consensus protocol, and the resulting thematic map is interpreted against the poem’s narrative arc. The approach yields five stable topics and high classification accuracy, demonstrating that lightweight probabilistic models can support computational close reading even in data‑poor, high‑density literary settings.

## Method Summary
The Italian translation is segmented into 35 coherent blocks (stanza groups). LDA is applied to each block to derive topic distributions. The dominant topic per block (the one with highest proportion) serves as a label for sPLS‑DA, which learns a one‑versus‑rest classifier for each topic. Topic stability is evaluated by running LDA with multiple random seeds and computing Jaccard@30, Spearman’s γ, and the effective topic number (Neff). Narrative hubs are identified as contiguous blocks where topic mixtures shift, and these are qualitatively aligned with the poem’s emotional and structural progression.

## Key Results
- Five stable, interpretable topics emerged (mean Jaccard@30 = 0.41, mean Spearman(γ) = 0.91, Neff = 4.52).  
- sPLS‑DA classifiers achieved 85% overall accuracy (balanced accuracy 70%) in recovering LDA’s dominant topics.  
- Narrative hubs—contiguous stanza groups marking key episodes—showed thematic mixtures that align with the poem’s emotional and structural arc, particularly in epistolary scenes.

## Why This Works (Mechanism)
LDA provides a probabilistic, bag‑of‑words representation that works despite the small, segmented corpus. The subsequent sPLS‑DA classification acts as a supervised sanity check: if the LDA topics are lexically coherent, a discriminative model should be able to separate them with high accuracy. The multi‑seed consensus guards against artefacts of random initialization, and the high sPLS‑DA accuracy confirms that the extracted topics capture real lexical regularities that correspond to narrative episodes. This synergy between unsupervised discovery and supervised validation yields a reproducible thematic map suitable for close reading.

## Foundational Learning
- **Latent Dirichlet Allocation (LDA)**  
  *Why needed*: To uncover latent thematic structures from word counts in a small, segmented corpus.  
  *Quick check*: Inspect top words per topic; they should form a coherent, interpretable cluster.
- **sPLS‑DA (sparse Partial Least Squares Discriminant Analysis)**  
  *Why needed*: To test whether LDA‑derived topics are lexically discriminable via a supervised classifier.  
  *Quick check*: Classification accuracy should significantly exceed random baseline (1/K for K topics).
- **Multi‑seed consensus**  
  *Why needed*: To ensure topic stability beyond a single random seed.  
  *Quick check*: High Jaccard@30 and Spearman(γ) across seeds indicate robust topics.
- **Effective topic number (Neff)**  
  *Why needed*: To quantify how many truly distinct topics exist.  
  *Quick check*: Neff should be considerably less than the total number of topics fitted.
- **Narrative hubs**  
  *Why needed*: To identify contiguous blocks where thematic mixtures shift, signaling key narrative moments.  
  *Quick check*: Hubs should correspond to known plot turning points (e.g., letters, duels).
- **One‑versus‑rest classification**  
  *Why needed*: To evaluate each topic’s separability from all others.  
  *Quick check*: Individual classifiers should show high precision/recall for their assigned topic.

## Architecture Onboarding
- **Component Map**: Raw text → Segmentation → LDA → Topic distributions → sPLS‑DA → Validation (accuracy, stability metrics)  
- **Critical Path**: The pipeline is sequential: segmentation must precede LDA; LDA outputs feed sPLS‑DA; validation depends on both LDA and sPLS‑DA results. Parallelisation is possible only across seeds or classification folds.  
- **Design Tradeoffs**:  
  - *Segmentation granularity*: 35 blocks balance stanza‑group coherence against sparsity; finer segmentation may capture nuance but risks data scarcity.  
  - *Model simplicity*: LDA’s bag‑of‑words assumption ignores word order and syntax, but this simplicity helps in small corpora; more complex models (e.g., neural topic models) would overfit.  
  - *Supervised validation*: sPLS‑DA uses LDA’s dominant topic as label, creating a circular dependency; however, one‑versus‑rest classification tests discriminability without assuming label correctness.  
- **Failure Signatures**:  
  - Low topic stability (Jaccard@30 < 0.3, Neff ≈ number of topics) → LDA outputs are not robust.  
  - sPLS‑DA accuracy near chance → Topics are not lexically separable.  
  - Narrative hubs show no clear progression → Either segmentation misaligns with narrative structure or model failed to capture themes.  
- **First Experiments**:  
  1. Run LDA with varying topic numbers (K = 3–10) and compute stability metrics to select the optimal K.  
  2. Train sPLS‑DA on the chosen LDA output and evaluate classification accuracy on a held‑out set of blocks.  
  3. Manually inspect top words per topic and compare with known narrative episodes to assess interpretive alignment.

## Limitations
- **Translation dependency**: The analysis uses an Italian translation, which may not preserve the original Russian’s poetic devices and thematic nuances.  
- **Small, segmented corpus**: Only 35 blocks may limit topic stability and generalizability; segmentation granularity could artificially shape narrative hubs.  
- **Baseline absence**: No comparison to alternative topic modeling or clustering approaches, leaving uncertain the hybrid method’s incremental benefit.

## Confidence
- **Hybrid framework technical execution**: High  
- **Topic stability**: Medium  
- **Narrative hub interpretation**: Low  
- **Claim of “reproducible thematic maps” for close reading**: Medium  

## Next Checks
1. **Source‑text replication**: Apply the identical pipeline to the Russian original *Evgenij Onegin* and compare topic stability (Jaccard, Neff) and sPLS‑DA accuracy against the Italian results to quantify translation impact.  
2. **Cross‑text generalization**: Test the same method on 2–3 other 19th‑century verse narratives (e.g., Byron’s *Don Juan*, Goethe’s *Faust*) using the same block segmentation; assess whether 4–6 stable topics emerge consistently.  
3. **Baseline model comparison**: Run pure LDA (with optimal α, β), NMF, and BERTopic on the Italian blocks; compare topic coherence (C_v), interpretability (via blinded literary scholar ratings), and sPLS‑DA classification accuracy to isolate the hybrid method’s contribution.
