# From Diet to Free Lunch: Estimating Auxiliary Signal Properties using Dynamic Pruning Masks in Speech Enhancement Networks

## Quick Facts
- arXiv ID: 2602.10666
- Source URL: https://arxiv.org/abs/2602.10666
- Reference count: 0
- Primary result: Repurposes dynamic pruning masks from DynCP speech enhancement to estimate voice activity, noise class, and pitch with high accuracy at <1% compute overhead.

## Executive Summary
This study explores whether dynamic channel pruning (DynCP) masks from a speech enhancement (SE) network can serve as a compact, information-rich representation for estimating auxiliary signal properties. By applying simple linear predictors to the binary pruning masks, the method achieves strong performance on voice activity detection (93% accuracy), noise classification (59% accuracy), and fundamental frequency estimation (R² = 0.86). The additional computational cost is negligible (4,242 operations per frame), suggesting that DynCP masks encode linearly separable acoustic features. This enables a holistic on-device solution where enhancement and property estimation coexist with minimal overhead, addressing a key efficiency challenge in deployed SE systems.

## Method Summary
The approach uses a DynCP-based SE model that dynamically prunes channels during inference based on input. The binary pruning masks—indicating active channels per frame—are extracted and fed into separate lightweight linear predictors (e.g., linear classifiers or regressors) for each auxiliary task: voice activity detection, noise classification, and pitch estimation. These predictors are trained on top of the frozen SE model, leveraging the masks as features without modifying the core enhancement network. The method assumes the pruning decisions implicitly capture relevant acoustic cues, making them suitable for linear probing.

## Key Results
- Voice activity detection accuracy: 93%
- Noise classification accuracy: 59%
- Fundamental frequency estimation R²: 0.86
- Overhead: 4,242 arithmetic operations per frame (0.6–0.93% of total compute)

## Why This Works (Mechanism)
Dynamic channel pruning masks are binary decisions that adaptively select channels based on input-specific relevance. In an SE model, these decisions reflect the network’s internal assessment of which frequency-temporal patterns are salient for denoising. Consequently, the masks encode high-level abstractions about speech presence, noise type, and pitch harmonics. Because the pruning mechanism responses are often linearly separable with respect to these properties, simple linear predictors can extract them efficiently. The masks thus act as a compressed, task-agnostic representation that avoids the cost of separate feature extraction modules.

## Architecture Onboarding
Component map: Speech Input -> DynCP SE Model -> Pruning Masks -> Linear Predictors (VAD, Noise Classifier, Pitch Estimator)

Critical path: The pruning masks generated by the DynCP SE model are the pivotal intermediate representation; their quality directly determines auxiliary task performance.

Design tradeoffs:
- **Mask-based vs. dedicated features**: Masks reuse existing computation but may be suboptimal for auxiliary tasks if pruning is SE-only optimized.
- **Linearity assumption**: Linear predictors are extremely cheap but may underfit if mask-task relationships are nonlinear.
- **Training interference**: Adding auxiliary losses could alter pruning behavior and harm SE quality, though not studied.

Failure signatures:
- Low auxiliary accuracy (e.g., noise classification near random chance) indicates masks do not encode relevant information.
- Drop in SE metrics (STOI/PESQ) when auxiliary predictors are introduced suggests gradient interference or mask distribution shift.
- Highly variable mask statistics across different noise conditions imply poor robustness.

First experiments:
1. Validate linear separability: Train a logistic regression on masks for VAD using a held-out set; expect >90% accuracy to confirm claim.
2. Compare probe capacity: Replace linear predictors with a single-hidden-layer MLP; if performance improves significantly, linearity assumption is weak.
3. Measure SE integrity: Compute STOI/PESQ with the base DynCP model vs. the same model with auxiliary predictors attached (no gradient flow) to isolate any representation shift.

## Limitations
