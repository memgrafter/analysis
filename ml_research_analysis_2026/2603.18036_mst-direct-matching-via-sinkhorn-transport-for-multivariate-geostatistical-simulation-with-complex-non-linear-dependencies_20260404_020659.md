# MST-Direct: Matching via Sinkhorn Transport for Multivariate Geostatistical Simulation with Complex Non-Linear Dependencies
## Quick Facts
- **arXiv ID:** 2603.18036
- **Source URL:** https://arxiv.org/abs/2603.18036
- **Reference count:** 14
- **Primary result:** MST-Direct achieves perfect shape preservation (100% 2D histogram similarity) and high variogram correlation (>0.99) on synthetic bivariate geostatistical data with complex non-linear dependencies.

## Executive Summary
Traditional multivariate geostatistical simulation methods, such as Gaussian copula or LU decomposition, struggle to preserve complex non-linear dependencies (e.g., step functions, heteroscedasticity) between variables while maintaining spatial correlation structures. MST-Direct introduces a novel approach based on entropy-regularized optimal transport (Sinkhorn algorithm) to directly match the full joint multivariate distribution. By treating all variables as a single multidimensional vector and incorporating k‑nearest neighbor relational constraints, the method enforces spatial coherence. Evaluated on synthetic data with five challenging bivariate relationships, MST-Direct perfectly preserved the non‑linear shapes (100% similarity) and achieved variogram correlations >0.99, significantly outperforming competing methods. This demonstrates that optimal transport, when combined with spatial regularization, can overcome long‑standing limitations in multivariate geostatistical simulation.

The method's success lies in its ability to avoid distributional transformations that distort non-linear relationships, instead relying on a direct permutation-based transport that exactly matches marginals while optimizing feature similarity. The integration of a relational cost term derived from k‑NN graphs ensures that the simulated fields retain the original spatial structure. With a straightforward implementation and competitive computational cost, MST-Direct opens new avenues for realistic geostatistical modeling in complex environments.

## Method Summary
MST-Direct is a multivariate geostatistical simulation algorithm that preserves both non-linear dependencies and spatial correlation structures. The input consists of two (or more) spatial variables observed on a grid, each with its own variogram model. The algorithm stacks the standardized variable values into a multivariate feature vector for each location. It then creates an anchor set by randomly permuting these feature vectors, guaranteeing identical marginal distributions. The core of the method is the Relational Sinkhorn iteration, which computes a soft assignment matrix between original features and anchors. The transport cost combines a feature dissimilarity (cosine distance) and a relational penalty that rewards pairs of points whose k‑nearest neighbor relationships are preserved in the assignment. After convergence, a greedy rounding procedure extracts a permutation from the soft matrix, which directly maps each original sample to an anchor. Finally, the assigned anchor values are denormalized to produce simulated fields that simultaneously honor the original joint distribution and the spatial variogram constraints.

## Key Results
- Perfect shape preservation: 100% 2D histogram similarity across all five synthetic bivariate relationships.
- Superior to baselines: Gaussian Copula and LU Decomposition achieved only 0.4–0.7 similarity.
- Variogram reproduction: >0.99 correlation for the spherical variable X and best performance in 5/5 tests for the exponential variable Y.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim**: MST-Direct directly matches the full joint multivariate distribution via entropy-regularized optimal transport, avoiding transformations that distort non-linear dependencies.
- **Mechanism**: The method treats all variables as a single multidimensional vector and computes a coupling (soft assignment) between the original data and a randomly permuted anchor set using the Sinkhorn algorithm. The coupling minimizes the transport cost based on feature similarity (cosine distance on normalized vectors) while satisfying marginal constraints.
- **Core assumption**: The anchor set, being a permutation of the original data, has identical marginal distributions, so transporting the data to the anchors recovers the original joint distribution when the assignment is a permutation.
- **Evidence anchors**: 
  - [abstract] "directly match multivariate distributions while preserving spatial correlation structures. The method processes all variables simultaneously as a single multidimensional vector"
  - [section III.B, III.C] The discrete optimal transport formulation and Sinkhorn iterations.
  - [corpus] Corpus shows related optimal transport work but no direct validation for geostatistics; this application is novel per paper.
- **Break condition**: If the anchor set is not representative (e.g., due to small sample size or non-stationarity), the transport may not converge to a permutation that preserves the joint distribution.

### Mechanism 2
- **Claim**: Spatial coherence is maintained by incorporating k-nearest neighbor relational constraints into the transport cost, encouraging matched points to have similar spatial neighborhoods.
- **Mechanism**: The cost matrix includes a term that penalizes mismatches in the k-NN adjacency structure between source and target. Specifically, for each pair of points that are neighbors in the source, their matched targets should also be neighbors. This is implemented via a parameter λ that balances feature similarity and relational consistency.
- **Core assumption**: Spatial structure is adequately captured by local k-NN graphs, and preserving these neighborhood relationships is sufficient for variogram reproduction.
- **Evidence anchors**: 
  - [abstract] "enforcing spatial coherence via k-nearest neighbor relational constraints."
  - [section III.D] Equation 7 and 8 explicitly define the relational cost term and the combined objective.
  - [corpus] Corpus includes papers on graph-based spatial methods, but the specific combination with optimal transport is not directly evidenced; the paper presents it as novel.
- **Break condition**: If the spatial correlations have long-range or anisotropic patterns not captured by fixed k-NN graphs, the relational term may be insufficient, leading to variogram degradation.

### Mechanism 3
- **Claim**: The soft assignment matrix from Sinkhorn is converted to a valid permutation via greedy rounding, which prioritizes high-confidence assignments to minimize conflicts and preserve joint distribution fidelity.
- **Mechanism**: Points are sorted by their maximum assignment probability. Each point is assigned to its most probable unassigned anchor, ensuring a one-to-one mapping.
- **Core assumption**: High-confidence matches are less likely to conflict with others, and processing in confidence order yields a permutation close to the soft assignment's optimal transport plan.
- **Evidence anchors**: 
  - [section III.F] Description of greedy rounding procedure and confidence metric.
  - [corpus] No specific corpus evidence; greedy rounding is a common heuristic in assignment problems.
- **Break condition**: When many points have similar assignment probabilities, greedy rounding may make early suboptimal choices that propagate errors, degrading the final joint distribution match.

## Architecture Onboarding
**Component map**: Input -> Stacking/Normalization -> Anchor Generation -> k-NN Adjacency -> Relational Sinkhorn -> Greedy Rounding -> Denormalization -> Output

**Critical path**: The Relational Sinkhorn iteration is the computational core; it must converge before the greedy rounding step. Preprocessing (steps 1-4) prepares data, and post‑processing (denormalization) completes simulation.

**Design tradeoffs**:
- k (neighbors): larger k enforces more global coherence but may over‑smooth; smaller k risks breaking spatial structure.
- β (entropy regularization): controls assignment sharpness; too low yields diffuse matches, too high may cause numerical overflow.
- λ (relational weight): balances feature similarity vs. spatial constraints; mis‑setting degrades either shape or variogram fidelity.
- Anchor generation: random permutation ensures marginal preservation but introduces stochasticity; seed choice affects reproducibility.

**Failure signatures**:
- Sinkhorn fails to converge (row/column sums deviate from 1/n)
- Greedy rounding leaves anchors unassigned (incomplete permutation)
- Output variogram correlation < 0.99 for target variables
- 2D histogram similarity < 0.9 for known non‑linear relationships
- Memory/time explosion for large grids (>10k points)

**First 3 experiments**:
1. Synthetic Shape Preservation: Generate a step‑function bivariate relationship on a 25×25 grid. Run MST‑Direct and compare scatter/histogram similarity; expect 1.0.
2. Parameter Sensitivity: Vary k ∈ {4,8,12}, β ∈ {10,35,100}, λ ∈ {0,2.2,5}. Compute shape and variogram metrics to identify robust ranges.
3. Scalability Test: Increase grid to 100×100 (10,000 points). Measure runtime and memory; assess if Sinkhorn remains tractable.

## Open Questions the Paper Calls Out
**Open Question 1:** How to scale MST-Direct to grids >10,000 points?  
*Basis in paper:* Section VI.D acknowledges scalability as a challenge.  
*Why unresolved:* The algorithm’s O(n²) memory and computation become prohibitive for large grids.  
*What evidence would resolve it:* A scalable implementation (e.g., GPU, sparse Sinkhorn) that processes >10k points with >0.99 shape similarity and >0.98 variogram correlation in under a few hours.

**Open Question 2:** How to extend MST-Direct to >2 variables?  
*Basis in paper:* Section VI.D notes the curse of dimensionality in higher dimensions.  
*Why unresolved:* Increasing dimensionality amplifies computational cost and degrades matching quality.  
*What evidence would resolve it:* A method (e.g., dimensionality reduction or hierarchical approach) validated on multivariate data that preserves both non-linear dependencies and spatial structure.

**Open Question 3:** How to add hard data conditioning to MST-Direct?  
*Basis in paper:* Section VI.D states conditional simulation with hard data is not yet implemented.  
*Why unresolved:* Many applications require exact match of known measurements at specified locations.  
*What evidence would resolve it:* An algorithm that fixes assignments at conditional sites and demonstrates accurate statistics while honoring the hard data.

**Open Question 4:** How to adapt MST-Direct to anisotropic variograms?  
*Basis in paper:* Section VI.D suggests isotropic adjacency limits directional modeling.  
*Why unresolved:* Geological processes often exhibit anisotropy, demanding direction‑dependent spatial correlation.  
*What evidence would resolve it:* A directional k‑NN approach that correctly reproduces variograms in multiple directions on anisotropic test data.

## Limitations
- Algorithmic ambiguity: Underspecified relational Sinkhorn update and greedy rounding tie‑breaking hinder exact replication.
- Scalability: Quadratic memory/computation limits application to large grids (>10,000 points).
- Real‑world validation: Evaluation only on synthetic data; performance on natural systems remains unproven.
