# The Relativity of AGI: Distributional Axioms, Fragility, and Undecidability

## Quick Facts
- **arXiv ID:** 2601.17335
- **Source URL:** https://arxiv.org/abs/2601.17335
- **Reference count:** 40
- **Primary result:** AGI is shown to be a relative, fragile, bounded, and undecidable property rather than an absolute, distribution-independent notion.

## Executive Summary
The paper investigates whether Artificial General Intelligence (AGI) can be defined independently of any particular context. It introduces an axiomatic framework defining AGI as a distribution-indexed, resource-bounded semantic predicate AGI(A|T,µ,Π,B). Four central theorems are proven: (1) Relativity—whether an agent is AGI depends on the task distribution µ; no universal definition exists. (2) Fragility—tiny changes to µ can create “cliff sets” where AGI properties vanish abruptly, making robustness impossible. (3) Bounded transfer—finite computational resources fundamentally limit generalization across task families. (4) Undecidability—AGI qualifies as a nontrivial semantic property, so no algorithm can decide it, including self-certification, challenging schemes that rely on recursive self-improvement via internal verification. The work concludes that claims about strong AGI must explicitly specify µ and resource bounds, and empirical progress does not guarantee attainable self-certifying general intelligence.

## Method Summary
The paper presents a purely theoretical study. It formalizes AGI as a predicate over agents, task domains, distributions, and resource limits. Using arguments from distribution theory, resource-bounded computation, and Rice’s theorem, it establishes the four core results through mathematical proofs. No empirical experiments or implementation details are provided.

## Key Results
- **Relativity:** Generality of intelligence is relative to the task distribution µ; there is no distribution-independent AGI.
- **Fragility & Bounded transfer:** Arbitrarily small shifts in µ can cause abrupt failure (cliff sets), and finite resources restrict cross-domain generalization.
- **Undecidability:** AGI is a nontrivial semantic property; hence no computable procedure can certify it, undermining self-certification and recursive self-improvement.

## Why This Works (Mechanism)
The mechanism hinges on the precise axiomatization: by indexing AGI on µ and resource bounds Π,B, the authors can separate the semantic content (performance across tasks drawn from µ) from syntactic details of the agent. Relativity emerges because different µ select different subsets of tasks; an agent may excel on one distribution but fail on another, so no single agent can satisfy all µ. Fragility is shown by constructing variations of µ that change only infinitesimally yet alter the AGI predicate outcome due to discontinuities in the space of distributions. Bounded transfer follows from resource limitations: even if an agent is AGI for one resource bound, increasing demands can exceed limits, preventing transfer. Undecidability is a direct application of Rice’s theorem: the AGI predicate is semantic and nontrivial, so it cannot be recursively decidable.

## Foundational Learning
- **Distribution-indexed AGI**  
  *Why needed:* To make explicit that generality is always relative to a distribution, not absolute.  
  *Quick check:* Does the definition of AGI change when µ is altered? If yes, then distribution-indexing is essential.

- **Resource-bounded semantic predicate**  
  *Why needed:* To capture real-world constraints (time, memory) and avoid idealized infinite-resource assumptions.  
  *Quick check:* Would an agent still be considered AGI if its resource bounds are reduced below what is needed for some tasks?

- **Cliff sets**  
  *Why needed:* To model abrupt failures despite small distributional shifts, highlighting fragility.  
  *Quick check:* Can a minor tweak to the task distribution cause an AGI system to lose its status? If so, cliff sets exist.

- **Bounded transfer**  
  *Why needed:* To show that finite resources inherently limit the ability to generalize across task families.  
  *Quick check:* Does an AGI agent under a given resource bound B automatically retain AGI status when tasks become more complex?

- **Semantic undecidability**  
  *Why needed:* To demonstrate that no algorithm can generally verify AGI, including self-verification.  
  *Quick check:* Is there a general program that decides whether any given agent satisfies AGI? According to Rice’s theorem, no.

## Architecture Onboarding
The formal framework can be viewed as a conceptual pipeline:

**Component map:**  
µ → Task Sampler → Task Set T → Agent A → Performance Evaluation → AGI(A|T,µ,Π,B) decision

**Critical path:**  
1. Define task distribution µ.  
2. Sample tasks from µ to instantiate domain T.  
3. Run agent A on T under resource constraints Π,B.  
4. Compute performance metric (e.g., success rate).  
5. Compare against threshold to determine AGI predicate.

**Design tradeoffs:**  
- Choice of µ drastically influences whether an agent qualifies as AGI; a “fair” universal µ may be unattainable.  
- Resource bounds Π,B trade off expressiveness vs. realism; tighter bounds increase fragility but reflect practical limits.  
- The performance metric must be carefully chosen; cliff sets may be metric-dependent.

**Failure signatures:**  
- Abrupt performance deterioration when µ is perturbed even slightly (indicating fragility).  
- Inability to certify AGI status automatically (undecidability).  
- Transfer failure when task complexity exceeds resource bounds.

**First three experiments:**  
1. Empirical cliff detection: Train a multi-task learner on a fixed distribution (e.g., ARC‑GEN), then introduce small, systematic shifts and monitor for sudden drops in performance.  
2. Attempt automated certification: Implement a brute‑force or learned verifier for AGI on a restricted domain; expect to hit computational limits or non‑termination, illustrating undecidability.  
3. Explore distribution‑independent definition: Design a universal AGI test covering a broad set of distributions; evaluate whether any existing system passes consistently, probing the limits of relativity.

## Limitations
- Formalizing AGI requires an explicit task distribution µ, which for open‑ended intelligence may be as hard to define as AGI itself.  
- Resource bounds (Π, B) remain abstract and are not linked to concrete computational metrics, hindering translation to real systems.  
- The analysis is purely theoretical, with no empirical validation; practical significance of relativity, fragility, and bounded transfer remains uncertain.

## Confidence
- Relativity: Medium (logically sound under given definitions, but definitions debatable)  
- Fragility: Medium (cliff set construction plausible but not proven across metrics/distributions)  
- Bounded transfer: Medium (intuitive but formal statement may be overly restrictive)  
- Undecidability: High (classic application of Rice’s theorem)

## Next Checks

- **Empirical cliff detection** – Run controlled experiments on a multi‑task benchmark, applying small distributional shifts to test for abrupt performance declines.  
- **Alternative AGI definition exploration** – Investigate whether a natural distribution‑independent definition (e.g., universal approximability over all computable tasks) is possible and whether it bypasses the paper’s pitfalls.
