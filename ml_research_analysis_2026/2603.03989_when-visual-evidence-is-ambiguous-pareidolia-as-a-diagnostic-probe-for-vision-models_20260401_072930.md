# When Visual Evidence is Ambiguous: Pareidolia as a Diagnostic Probe for Vision Models

## Quick Facts
- **arXiv ID**: 2603.03989
- **Source URL**: https://arxiv.org/abs/2603.03989
- **Reference count**: 17
- **Primary result**: Face pareidolia tests reveal that uncertainty and bias are decoupled in vision models: low uncertainty can indicate either safe suppression (detectors) or extreme over-interpretation (VLMs).

## Executive Summary
This study uses face pareidolia—the tendency to perceive faces in inanimate objects—as a diagnostic tool to probe how vision models resolve ambiguous visual evidence. Evaluating six models (CLIP, LLaVA, ViT, YOLOv8, RetinaFace) on the FacesInThings dataset, the authors measure detection, localization, uncertainty (via a Representation Ambiguity Index), and bias (False Bias Score, non-human→Human rate). The results show that vision-language models (VLMs) over-activate the Human concept with bias amplified by negative emotions; the ViT classifier exhibits uncertainty-as-abstention, remaining diffuse and unbiased; and object detectors suppress responses through conservative priors. Crucially, uncertainty and bias are found to be decoupled, challenging the use of confidence as a sole proxy for safety.

## Method Summary
A unified framework evaluates models on FacesInThings, a dataset of images with face-like patterns annotated with bounding boxes, coarse labels (Human/Animal/Cartoon/Alien/Other), primary region flags, difficulty, and emotion. Classification models (CLIP, LLaVA, ViT) process cropped regions, while detectors (YOLOv8, RetinaFace) run on full images. Predictions are matched to ground-truth boxes via IoU≥0.2 or center containment, with greedy one-to-one assignment. Key metrics include Detection Rate, Primary Region Detection Rate (PPDR), RAI (entropy of class distribution over matched regions), bias metrics (FBS, non-human→Human, Alien→Human), and a GT-box control for detectors. No model fine-tuning is performed.

## Key Results
- VLMs over-activate the Human concept; LLaVA shows confident, extreme bias amplified by negative emotions.
- ViT employs uncertainty-as-abstention, yielding high RAI (diffuse uncertainty) without bias.
- Detectors suppress responses via conservative priors; GT-box control confirms low response rates even on known face locations.

## Why This Works (Mechanism)
- **VLM over-activation**: Models like CLIP and LLaVA, trained on human-centric datasets, assign high probability to "Human" for ambiguous patterns, reflecting a bias toward over-interpreting faces. Negative emotions in images further amplify this bias in LLaVA, likely due to affective associations in training data.
- **ViT uncertainty-as-abstention**: The ViT classifier’s features remain diffuse across classes for pareidolia images, leading to high entropy (RAI) without committing to a specific label. This abstention is unbiased, as it does not preferentially misclassify non-human patterns as Human.
- **Detector suppression**: YOLOv8 and RetinaFace use conservative confidence thresholds and class priors that suppress responses to non-face patterns, resulting in low detection rates even when ground-truth face boxes are provided (GT-box control). This conservative prior avoids false positives at the cost of missing ambiguous faces.
- **Uncertainty–bias decoupling**: Low uncertainty (low RAI) can coexist with high bias (e.g., VLMs confidently misclassify) or low bias (e.g., detectors suppress output), showing that uncertainty alone is an unreliable safety indicator.

## Foundational Learning
- **Pareidolia**: Face perception in non-face objects; provides a natural testbed for model ambiguity resolution. *Why needed*: Isolates cases where ground truth is ambiguous, probing model heuristics. *Quick check*: Verify dataset images indeed contain face-like patterns in non-human objects.
- **Representation Ambiguity Index (RAI)**: Entropy of the 5-class probability distribution from matched regions. *Why needed*: Quantifies model uncertainty on ambiguous inputs. *Quick check*: Compute entropy for a set of model outputs; higher values indicate more uniform distributions.
- **False Bias Score (FBS)**: Fraction of matched non-Human regions predicted as Human. *Why needed*: Measures direct bias toward over-activating Human. *Quick check*: Among non-Human GT boxes, count predictions labeled Human.
- **non-human→Human rate**: Fraction of primary non-Human regions predicted as Human. *Why needed*: Assesses bias on the most salient ambiguous pattern per image. *Quick check*: Filter images where primary GT≠Human; compute Human prediction rate on primary.
- **Alien→Human rate**: Same as above for primary GT=Alien. *Why needed*: Tests bias specifically for unreal/non-animal patterns. *Quick check*: Subset images with primary GT=Alien; compute Human prediction rate.
- **GT-box control**: Cropping GT boxes and running detectors to check response. *Why needed*: Isolates detector suppression from localization failure. *Quick check*: For each GT box, run detector on padded crop; record if any Human detection occurs.

## Architecture Onboarding
**Component map**: Input Image -> GT Annotations -> Model (Classifier/Detector) -> Predictions -> Matching (IoU/center) -> Metrics (Detection, PPDR, RAI, FBS, etc.)

**Critical path**: Image ingestion → model forward pass (crop or full image) → prediction extraction → spatial matching to GT boxes → aggregation of per-region class probabilities → computation of entropy (RAI) and bias rates.

**Design tradeoffs**:
- Off-the-shelf models vs. fine-tuning: Using pretrained models ensures generalizability but may not optimize for pareidolia.
- Matching heuristics: IoU≥0.2 or center containment balances false matches and missed detections but lacks threshold tuning.
- Class aggregation: Averaging probabilities across matched regions assumes independence and may smooth extremes.

**Failure signatures**:
- LLaVA output parsing fails if generative responses are not constrained; may yield non-class strings.
- ViT prototype mapping errors if ImageNet class grouping misaligns with coarse labels.
- YOLO class mapping mistakes if COCO classes misassigned (e.g., "teddy bear" → Animal vs. Other).
- Matching bugs if detector predictions not properly linked to GT boxes, inflating/deflating metrics.

**First experiments**:
1. Prompt validation: Run CLIP/LLaVA on a small labeled subset with slight prompt variations; check if Human bias persists.
2. Prototype audit: List all ImageNet classes mapped to Human/Animal/Other; recompute RAI after adjusting mappings.
3. Detector mapping check: Sample YOLO predictions; ensure no "alien" or "cartoon" classes appear, confirming correct coarse-label mapping.

## Limitations
- Prompt wording and parsing for CLIP/LLaVA are unspecified, potentially affecting bias magnitudes.
- ViT prototype construction is ad hoc; different ImageNet class groupings could alter RAI and bias scores.
- YOLO class mapping to coarse labels is incompletely specified; mis-mapping could bias detection metrics.
- Dataset cleaning steps beyond removing one corrupted image are vague.
- GT-box control details (e.g., required spatial checks within crops, confidence aggregation) are not fully described.

## Confidence
- VLM over-activation (LLaVA) & emotion modulation: Medium
- ViT uncertainty-as-abstention: Medium
- Detector suppression via conservative priors: Medium
- Uncertainty–bias decoupling: Medium
- Emotion effects only in VLMs: Low
