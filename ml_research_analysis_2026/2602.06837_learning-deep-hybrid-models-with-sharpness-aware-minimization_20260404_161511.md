# Learning Deep Hybrid Models with Sharpness-Aware Minimization

## Quick Facts
- arXiv ID: 2602.06837
- Source URL: https://arxiv.org/abs/2602.06837
- Reference count: 40
- Primary result: Using Sharpness-Aware Minimization (SAM) to enforce simplicity in machine‑learning parameters significantly improves identification of scientific parameters across six hybrid prediction tasks, especially for non‑additive models where existing regularizers fail.

## Executive Summary
Hybrid models combine known scientific structure with flexible machine‑learning components. However, the ML part can dominate and make the scientific parameters unidentifiable. This paper proposes applying Sharpness‑Aware Minimization (SAM) but only to the ML parameters (ϕ), not the scientific parameters (θ). SAM seeks flat minima in the loss landscape, which corresponds to simpler ML functions that cannot fit the data alone and therefore must rely on the scientific model fθ. Across six diverse tasks—including synthetic ODE/PDE systems and real‑world wind‑tunnel and light‑tunnel data—SAM variants markedly improved estimation of scientific parameters compared to empirical risk minimization and architecture‑specific regularizers. The method is architecture‑agnostic and introduces only the perturbation radius hyperparameter.

## Method Summary
The authors adapt SAM to regularize exclusively the ML parameters ϕ in a hybrid model. In each training iteration, they compute a perturbation ϵ∗ϕ that maximizes the loss within a neighborhood of radius ρ around the current ϕ (using the gradient with respect to ϕ). They then reevaluate the loss and gradients at the perturbed point (θ, ϕ+ϵ∗ϕ) and update both θ and ϕ using those gradients. This biasing toward flat minima in ϕ space encourages simpler ML functions that cannot absorb all residual variation, forcing the hybrid to use the scientific model fθ more. Because SAM operates directly on parameters, it works for any hybrid composition (additive, multiplicative, nested) without redesigning regularizers. The only new hyperparameter is ρ. Experiments on six tasks show consistent gains in scientific parameter identification, particularly for non‑additive hybrids where existing regularizers struggle.

## Key Results
- SAM variants (SAM, ASAM, FSAM) significantly reduced error in estimating scientific parameters θ compared to empirical risk minimization (ERM) and functional regularization (freg) across all six tasks.
- The improvement was especially pronounced for non‑additive hybrid models (e.g., Duffing oscillator, pendulum images, wind tunnel) where architecture‑specific regularizers failed or were inapplicable.
- SAM’s architecture‑agnostic nature allowed it to be applied without redesigning regularizers for different hybrid structures, requiring only the perturbation radius ρ as a new hyperparameter.

## Why This Works (Mechanism)
We present three key mechanisms explaining why SAM on ML parameters improves scientific parameter identification.

### Mechanism 1: Flat Minima Encourage Simpler ML Functions
- **Claim**: Seeking flat minima in the ML parameter space encourages simpler ML functions that must rely on the scientific model structure, thereby improving scientific parameter identification.
- **Mechanism**: SAM minimizes the worst‑case loss within a perturbation ball around current parameters. This biases optimization toward parameter regions where the loss landscape is flat—small perturbations do not increase loss. Such flat minima correspond to simpler functions (shorter description length) that cannot easily fit all data variations alone. With a simpler ML component, the hybrid model is forced to utilize the scientific model fθ more, making θ identifiable.
- **Core assumption**: Simpler ML functions have reduced capacity to absorb residual variation, so prediction error must be explained by fθ.
- **Evidence anchors**: 
  - [abstract] "SAM variants significantly improved identification of scientific parameters... by seeking flat minima in the loss landscape"
  - [section 3.1] KL divergence analysis showing that when θ is well‑identified, the posterior dependence between θ and ϕ is small; flat minima relate to simpler models with lower marginal KL
  - [section 5] Table 1: SAM methods achieve lower θ‑error across tasks, especially where baseline regularizers fail
- **Break condition**: If the ML model is severely underparameterized even at sharp minima, flatness may not add enough pressure to force reliance on fθ.

### Mechanism 2: Architecture‑Agnostic Regularization via Parameter Perturbation
- **Claim**: SAM's architecture‑agnostic formulation (perturbing parameters, not functions) allows it to regularize ML flexibility in any hybrid composition without manual redesign of regularizers.
- **Mechanism**: SAM operates directly on parameter gradients via perturbation, requiring only a loss function and parameter set. By applying perturbations solely to ϕ (ML parameters), it simplifies gϕ regardless of how gϕ combines with fθ—additive, multiplicative, nested, etc. This bypasses the need for architecture‑specific functional norms or reduction designs.
- **Core assumption**: Overflexibility manifests as sharp minima in ML parameter space regardless of the hybrid composition structure.
- **Evidence anchors**: 
  - [abstract] "The approach is architecture‑agnostic, requiring only the perturbation radius hyperparameter"
  - [section 1] "For general hybrid architectures, designing the regularizer is often challenging with various functional forms and complex function compositions"
  - [section 5] SAM succeeds on all six tasks (including non‑additive Duffing oscillator, pendulum images) where architecture‑specific freg is inapplicable or performs poorly
- **Break condition**: If hybrid architecture entangles θ and ϕ in shared parameters or complex ways, the clean separation of perturbation might not hold.

### Mechanism 3: Selective Perturbation Preserves Identifiability of θ
- **Claim**: Perturbing only ML parameters (not scientific ones) preserves inherent identifiability of θ by avoiding flattening in directions that would make θ unidentifiable.
- **Mechanism**: SAM's perturbation defines a preference for flat regions. If applied to all parameters, it would favor flatness along θ directions, which directly contradicts identifiability (flat θ‑direction means many θ values fit equally well). The proposed modification applies perturbation only to ϕ, so θ remains free to lie in sharp, identifiable regions while ϕ is constrained.
- **Core assumption**: Scientific parameters, if identifiable from data in principle, correspond to sharp directions in the loss landscape; flattening those harms identifiability.
- **Evidence anchors**: 
  - [section 3.2] "nothing requires the flatness along the direction of θ. On the contrary, the loss basically should not be flat along θ; being flat along θ means different values of θ achieve similarly small loss values, implying θ is hard to identify."
  - [algorithm 1] "ϵ∗ ϕ ← Eq. (2), (3), or (4) with w=ϕ" — perturbation only on ϕ
  - [section 5] SAM variants achieve better θ‑error than ERM and often better than freg, suggesting the selective perturbation helps
- **Break condition**: If scientific parameters themselves are in flat regions due to insufficient data or model misspecification, this approach cannot create identifiability.

## Architecture Onboarding
This section details the hybrid model structure, training procedure, design considerations, and initial experiments.

**Component map**:
Scientific model fθ(x) produces latent z; ML model gϕ(x, z) (or other compositions) produces y; hybrid hθ,ϕ combines them (e.g., hθ,ϕ(x)=gϕ(x, fθ(x))). Loss L(θ,ϕ)=∑||y−hθ,ϕ(x)||². SAM perturbation ϵ∗ϕ computed from gradient w.r.t. ϕ only. Optimizer: Adam with SAM two‑step update per minibatch.

**Critical path** (training loop):
1. Forward pass: compute hθ,ϕ(x) and loss L.
2. Compute ∇_ϕ L at (θ, ϕ).
3. Compute perturbation ϵ∗ϕ = ρ * (normalized gradient) or adaptive variant.
4. Re‑evaluate loss at (θ, ϕ+ϵ∗ϕ).
5. Compute ∇_θ and ∇_ϕ at perturbed point.
6. Update θ ← θ − η * ∇_θ L(θ, ϕ+ϵ∗ϕ), ϕ ← ϕ − η * ∇_ϕ L(θ, ϕ+ϵ∗ϕ).
7. Repeat.

**Design tradeoffs**:
- ρ (perturbation radius): Larger values increase flattening pressure, improve θ identification but risk underfitting (higher y‑error). Requires validation sweep.
- SAM variant: Standard SAM, ASAM (adaptive), or FSAM (Fisher). Adaptive variants may be more stable but add computation.
- Learning rates: θ and ϕ typically share η; if θ is small‑dimensional, might need η_θ ≤ η_ϕ to avoid oscillation.

**Failure signatures**:
- θ‑error remains near random/initial values: ML part still dominating; increase ρ or check gϕ flexibility.
- y‑error spikes while θ‑error drops: Over‑regularization; reduce ρ or combine with other regularization carefully.
- θ estimates diverge or oscillate: Learning rate too high for θ; try reducing η_θ relative to η_ϕ.
- No improvement over ERM: Possibly hybrid model intrinsically unidentifiable; or gϕ not flexible enough to compensate for flatness pressure.

**First 3 experiments**:
1. **Baseline replication on PENDULUM TIME‑SERIES**: Use additive hybrid. Compare SAM variants vs ERM, l2reg, freg. Expect SAM to achieve similar θ‑error to freg but with simpler implementation.
2. **Non‑additive architecture test on DUFFING OSCILLATOR**: Use same hybrid structure but different scientific model; test variant where gϕ is inside fθ (nested). SAM should still improve θ‑estimation while freg would need redesign.
3. **Hyperparameter sensitivity on WIND TUNNEL**: Sweep ρ over a range. Plot θ‑error and y‑error vs ρ. Expected: θ‑error decreases then plateaus; y‑error increases after threshold. Choose ρ balancing both.

## Open Questions the Paper Calls Out
The paper identifies several unresolved questions:

### Open Question 1
**Question**: What sufficient conditions on hybrid model structure, data distribution, and SAM hyperparameters guarantee that SAM‑based learning will identify the true scientific parameters?
**Basis**: The authors state: "More rigorous characterization of the parameter identification in hybrid models is an interesting but challenging open question." They also note: "unless one has specific assumptions about the data‑generating process, the proposed learning method does not necessarily identify the correct value."
**Why unresolved**: The paper offers an informal argument via mutual information in the posterior, but no rigorous mathematical conditions linking flatness along ML parameters to identifiability of scientific parameters.
**What evidence would resolve it**: A theoretical analysis deriving conditions under which minimizing SAM loss leads to a posterior over θ that concentrates around the true value, perhaps connecting flatness to low mutual information between θ and ϕ. Alternatively, identifiability analysis using the Fisher information matrix.

### Open Question 2
**Question**: Why does SAM's architecture‑agnostic regularization particularly benefit hybrid models with non‑additive compositions compared to additive ones, and how does this relate to the failure of existing regularizers?
**Basis**: The authors report: "SAM variants significantly improved identification of scientific parameters compared to empirical risk minimization and architecture‑specific regularizers, particularly on complex non‑additive models where existing methods fail."
**Why unresolved**: The paper hypothesizes SAM's simplicity‑encouraging effect via flatness is generally applicable, but does not explain why the advantage is more pronounced for non‑additive forms. Existing regularizers rely on specific patterns (e.g., additivity) that become difficult for nested compositions. But is SAM's success solely due to being architecture‑agnostic, or does flatness interact with non‑additive structure uniquely?
**What evidence would resolve it**: Comparative experiments measuring correlation between loss flatness (along ϕ) and θ‑estimation error across a spectrum of architectures. Analysis of why model reduction becomes ambiguous for non‑additive forms and how that affects freg. Theoretical investigation into whether non‑additive compositions inherently create more complex loss landscapes that SAM better navigates.

### Open Question 3
**Question**: How can the SAM perturbation radius ρ be theoretically calibrated for hybrid models to optimize the trade‑off between scientific parameter identifiability and prediction accuracy?
**Basis**: The paper's sensitivity analysis shows that θ‑estimation error is relatively insensitive to ρ within a standard range, but prediction error degrades when ρ is too large. No principled method for setting ρ is proposed beyond grid search.
**Why unresolved**: ρ controls neighborhood size for flatness enforcement. Too small may not regularize enough; too large may over‑regularize and harm fit. The paper uses the same ρ range as standard SAM but doesn't relate it to hybrid model properties (e.g., scale of ϕ, complexity of fθ).
**What evidence would resolve it**: Theoretical analysis linking ρ to desired flatness measure (e.g., maximum Hessian eigenvalue) and deriving bounds on how flatness affects θ‑identification. Empirical studies proposing heuristics for setting ρ based on ML parameter norm or adaptive schemes.

### Open Question 4
**Question**: Does SAM remain effective for hybrid models where the scientific component itself is a flexible, overparametrized model (e.g., a neural network), and how should perturbations be allocated between scientific and ML parameters?
**Basis**: The method only perturbs ML parameters (ϕ), assuming scientific parameters (θ) are few and should not be flattened. The paper acknowledges: "the effect of the modification is not necessarily dominant in performance because a scientific model usually has a small number of parameters." This implies the method may not scale to scientific models with many parameters.
**Why unresolved**: The paper focuses on scenarios where θ is low‑dimensional and structurally identifiable. However, hybrid models could involve complex scientific models (e.g., neural ODEs with neural right‑hand sides). Should we also seek flatness along θ? How to balance flatness for both components without losing identifiability? The current perturbation strategy is not designed for this regime.
**What evidence would resolve it**: Experiments with hybrid models where both fθ and gϕ are neural networks with varying sizes. Test different perturbation allocations (only ϕ, only θ, both with equal ρ, both with different ρ). Measure θ and ϕ estimation errors, prediction error, and flatness along each subspace.

## Limitations
- Exact neural network architectures, hyperparameters, and functional‑regularizer implementation details are partially unspecified, risking replication mismatch and obscuring performance drivers.
- The proposed mechanism (flat minima → simpler ML functions → improved θ identification) relies on indirect evidence (KL divergence) and unverified assumptions about model capacity and posterior dependence; direct validation (e.g., measuring ML complexity) is absent.
- Potential break conditions (severe ML underparameterization, flat θ‑directions, parameter entanglement) are not systematically explored, leaving the generality of SAM’s selective perturbation uncertain.

## Confidence
We assign confidence levels to the main claim clusters based on the evidence and uncertainties:

- **SAM‑on‑ϕ improves θ identification across six tasks**: Medium–High (strong empirical trends, but limited number of tasks, absence of statistical tests, and possible selection bias).
- **Flat‑minima mechanism**: Medium (theoretical intuition aligns with results, but evidence is indirect; requires direct link between flatness and ML simplicity).
- **Architecture‑agnostic via selective perturbation**: Medium (success on given architectures; untested on hybrids with deep θ–ϕ entanglement or shared parameters).

## Next Checks
To validate and extend the findings, we propose the following concrete checks:

1. **Exact replication**: Reimplement all six hybrid models with the described architectures and SAM’s ϕ‑only perturbation; ensure Table 1 θ‑errors fall within the reported standard deviations. Any systematic deviation indicates missing specification.
2. **Perturbation‑radius sweep**: For Duffing and Pendulum‑Images, vary ρϕ across a wide range (e.g., 1e‑3 to 10) and plot both θ‑error and y‑error. Expect a “valley” where θ‑error decreases and then plateaus while y‑error rises, confirming the trade‑off.
3. **Entanglement stress test**: Design a hybrid where θ and ϕ share layers (e.g., gϕ applied to fθ(x) with weight tying). Run SAM (ϕ‑only) vs. ERM; if SAM’s advantage diminishes, this reveals a break condition and clarifies the method’s boundary.
