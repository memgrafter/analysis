# Differential Privacy in Two-Layer Networks: How DP-SGD Harms Fairness and Robustness

## Quick Facts
- **arXiv ID:** 2603.04881
- **Source URL:** https://arxiv.org/abs/2603.04881
- **Reference Count:** 40
- **Primary Result:** DP-SGD harms fairness and robustness in two-layer ReLU CNNs due to imbalanced feature-to-noise ratios (FNR), which cause disparate impact across groups, greater loss on weak-feature data, and increased adversarial vulnerability.

## Executive Summary
This paper presents a theoretical framework analyzing how Differentially Private Stochastic Gradient Descent (DP-SGD) adversely affects fairness and robustness in two-layer ReLU CNNs. The core insight is the feature-to-noise ratio (FNR)—the ratio of a feature's magnitude to the DP noise standard deviation—which governs feature learning dynamics. The analysis reveals that DP-SGD induces disparate impact across classes and subpopulations because of imbalanced FNRs stemming from feature disparity, gradient clipping, and data imbalance. Within a class, samples with weaker features (e.g., long-tailed data) suffer greater accuracy loss. Furthermore, DP noise promotes non-robust features and inflates parameter norms, increasing adversarial vulnerability. Public pre-training followed by private fine-tuning degrades as the feature distribution shifts between datasets. These theoretical findings are validated on synthetic data, MNIST, and CIFAR-10.

## Method Summary
The study uses a simplified two-layer CNN architecture with shared-weight convolutional neurons in the first layer and fixed second-layer weights. Training employs DP-SGD: per-sample gradient clipping (threshold \(C\)) followed by Gaussian noise addition (\(\sigma_n\)) to the aggregated batch gradient. A synthetic data generator creates samples with two patches: one containing a class-specific feature vector (with varying magnitudes for majority/minority groups) and the other pure noise. This setup allows precise control over feature magnitudes (\(\|u_{i,j}\|^2\)), data imbalance (\(\gamma_{i,j}\)), and noise variance (\(\sigma_p^2\)). Theoretical bounds on standard and adversarial test loss are derived in terms of FNR. Real-data experiments on MNIST and CIFAR-10 manipulate "feature size" via padding and test fine-tuning under rotation-induced feature shifts.

## Key Results
- Imbalanced feature-to-noise ratios (FNR) across classes/subpopulations—due to feature disparity, gradient clipping, and data imbalance—cause disparate impact in DP-SGD models.
- Within a single class, data with semantically weak features (long-tailed) experiences significantly higher accuracy loss.
- DP-SGD induces non-robust features and increases parameter norms, leading to greater adversarial vulnerability compared to standard training.
- Public pre-training followed by private fine-tuning performance degrades as the feature distribution shift between pre-training and fine-tuning datasets grows.

## Why This Works (Mechanism)

### Disparate Impact via Imbalanced FNR
Disparate impact arises because DP-SGD's ability to learn a feature depends on the feature-to-noise ratio (FNR = \(\|u_{i,j}\|^2 / \sigma_n\)). Classes/subpopulations with smaller feature magnitudes (lower FNR) experience slower feature learning and higher test loss. Gradient clipping (threshold \(\Lambda\)) and data imbalance (\(\gamma\)) further distort gradients and reduce effective signal for underrepresented groups. The test loss bound is inversely related to FNR (Theorem 3.4). Evidence: Corollaries 4.1 identify feature disparity, clipping, and imbalance as primary sources; prior work empirically observes disparate impact.

### Within-Class Weak Feature Degradation
Within a class, feature magnitude varies across samples. Those with smaller feature magnitudes have lower FNR, leading to higher loss bounds. The paper shows test loss increases as feature size decreases (Figure 2a). This is a direct extension of the FNR imbalance principle to intra-class variation. Evidence: MNIST visualizations show misclassified digits are poorly written (weak features); padding experiments (reducing effective feature size) degrade accuracy (Section 6.2).

### Robustness Loss from Non-Robust Features and Norm Growth
DP noise causes the network to learn features correlated with noise (non-robust). Simultaneously, DP-SGD updates accumulate noise, causing parameter norms to grow over iterations. Both effects increase sensitivity to adversarial perturbations, as adversarial loss scales with parameter norms and non-robust features (Theorem 3.7). Evidence: Adversarial test loss rises with DP noise standard deviation (Figure 2b); analysis links norm growth to vulnerability (Section 4.2).

## Architecture Onboarding
**Component map:** Input patches \(x^{(1)}, x^{(2)} \in \mathbb{R}^d\) -> First Layer (\(m\) neurons per class, shared weights, ReLU) -> Second Layer (fixed weights \(1/m\), sums neuron outputs) -> Training (DP-SGD: per-example clip -> average -> add noise -> update).

**Critical path:** 1) Initialize weights \(W^{(0)} \sim \mathcal{N}(0, \sigma_0^2 I)\). 2) For each iteration: sample batch \(S^{(t)}\), compute per-example gradients, clip each to norm \(C\), average and add \(\mathcal{N}(0, \sigma_n^2 I)\) noise, update \(W^{(t+1)} = W^{(t)} - \eta \cdot (\text{aggregate} + \text{noise})\).

**Design tradeoffs:** Clipping threshold \(C\): lower improves privacy but harms feature learning. Noise scale \(\sigma_n\): set by privacy budget \((\epsilon,\delta)\); higher \(\sigma_n\) worsens utility/robustness. Batch size \(B\): larger reduces noise variance but requires privacy accounting. Number of neurons \(m\): more improve representation but may increase parameter norms.

**Failure signatures:** High test loss on specific classes/subpopulations; degraded accuracy on weak-feature samples; low adversarial accuracy under PGD; performance drop when fine-tuning on data with feature distribution shift (e.g., rotated images).

**First 3 experiments:** 1) Synthetic data: controlled feature sizes/proportions to validate bounds on test/adversarial loss across groups. 2) MNIST: visualize misclassifications (poorly written digits), apply padding to reduce feature size, measure accuracy drop. 3) CIFAR-10: similar padding; test public pre-training then fine-tune on rotated images to show feature shift degradation.

## Open Questions the Paper Calls Out
1. How can the feature-to-noise ratio (FNR) framework be extended to deeper networks and transformers?
2. Under what precise conditions does public pretraining fail under feature distribution shift, and how can pretraining be optimized to avoid degradation?
3. How do the three sources of disparate impact (feature disparity, gradient clipping, data imbalance) interact in practice, and can they be disentangled to design fairer DP-SGD algorithms?
4. Is the feature-to-noise ratio (FNR) a sufficient statistic for predicting DP-SGD's impact in arbitrary neural architectures, or do deeper networks introduce additional factors?

## Limitations
- Theoretical analysis depends on unspecified constants (\(c_1-c_4\)) and initialization variance \(\sigma_0^2\); exact thresholds are absent, hindering precise replication.
- Real-dataset experiments lack full architectural/training details (e.g., exact CNN layers, learning schedules), raising questions about generalizability.
- Synthetic data assumes perfectly orthogonal features; real-world feature correlations could alter FNR dynamics and bound tightness.

## Confidence
- *Disparate impact due to imbalanced FNR*: **High** – robust theoretical derivation and consistent synthetic validation.
- *Within-class weak feature degradation*: **Medium** – supported by theory and padding experiments, but padding may introduce confounding artifacts.
- *Robustness loss from non-robust features and norm growth*: **Medium** – theoretical link and PGD evidence exist, yet alternative factors (e.g., optimizer noise) are not fully disentangled.
