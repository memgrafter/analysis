# COVR:Collaborative Optimization of VLMs and RL Agent for Visual-Based Control

## Quick Facts
- arXiv ID: 2601.06122
- Source URL: https://arxiv.org/abs/2601.06122
- Reference count: 33
- Primary result: COVR achieves 248±81 episode reward on CARLA Highway, setting new SOTA

## Executive Summary
COVR introduces a collaborative optimization framework that fine-tunes a Vision-Language Model (VLM) using RL-generated trajectories and uses the enhanced VLM to guide RL policy learning. The method addresses action inconsistency in VLMs by using an Exploration-Driven Dynamic Filter (EDDF) to select high-return, exploratory samples and a Return-Aware Adaptive Loss Weight (RALW) to emphasize valuable samples during fine-tuning. This mutual enhancement between VLM and RL agent leads to state-of-the-art performance on both CARLA autonomous driving and DMControl robotic control tasks.

## Method Summary
COVR implements a two-stage iterative loop where a VLM and RL agent mutually enhance each other. First, the RL agent generates trajectories that are filtered using EDDF based on return and exploration metrics, then the VLM is fine-tuned on this filtered data using RALW to emphasize high-return samples. Second, the enhanced VLM guides the RL agent by providing action priors through regularization in the policy loss. This process repeats with progressive fine-tuning intervals that gradually increase. The framework uses Soft Actor-Critic (SAC) for continuous control, with specific implementations for CARLA (using a transition network) and DMControl (using RAD).

## Key Results
- COVR achieves 248±81 episode reward on CARLA Highway, setting new SOTA
- In DMControl Ball in cup, Catch task, COVR reaches 960±23 reward with lower variance than baselines
- Ablations confirm EDDF and RALW's essential contributions to performance gains

## Why This Works (Mechanism)
COVR works by addressing the fundamental challenge of action inconsistency in VLMs when used for control tasks. The EDDF mechanism ensures the VLM learns from trajectories that demonstrate both high performance and exploration, preventing it from overfitting to conservative or random behaviors. RALW then amplifies the learning signal from these valuable samples while suppressing noisy or irrelevant data. The mutual enhancement creates a positive feedback loop where the VLM becomes increasingly capable at generating reasonable actions, which in turn helps the RL agent learn more efficiently through guided exploration.

## Architecture Onboarding
- Component map: RL agent -> EDDF filter -> VLM fine-tuner -> VLM -> RL agent (closed loop)
- Critical path: RL interaction → trajectory storage → EDDF filtering → VLM fine-tuning → VLM inference → RL policy update
- Design tradeoffs: Exploration vs exploitation in EDDF (aggressive filtering may starve fine-tuning), VLM inference frequency vs latency (every 10 frames in CARLA)
- Failure signatures: EDDF filtering too aggressively (retention <20%), RALW weight instability (w_b variance spikes), VLM parsing failures (>1% error rate)
- First experiments: 1) Test EDDF threshold sensitivity with synthetic return distributions, 2) Validate RALW weight assignment on a small batch, 3) Verify VLM action parsing with varied output formats

- Evaluation limited to two domains without broader generalization tests
