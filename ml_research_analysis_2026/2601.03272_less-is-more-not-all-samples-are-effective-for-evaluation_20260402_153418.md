# Less is more: Not all samples are effective for evaluation

## Quick Facts
- arXiv ID: 2601.03272
- Source URL: https://arxiv.org/abs/2601.03272
- Reference count: 0
- Primary result: On a large-scale 3GPP communications benchmark, the method reduces the evaluation set to 10% of its original size, cutting cost by over 90% while preserving high fidelity (Spearman correlation 0.98, average absolute performance fluctuation <2%).

## Executive Summary
Evaluating large language models on extensive test sets is costly and often redundant. Existing test-set compression techniques rely on historical model performance data, rendering them ineffective for new tasks or domains where such data is unavailable (cold-start). This paper introduces a history-free framework that transforms test-set compression into a pure semantic analysis problem. By fine-tuning a base LLM on a small amount of domain-specific data, the method generates embeddings that capture task-relevant redundancy. Task-aware clustering and a novel “Dataset X-ray” mechanism then dynamically compress the benchmark based on cluster geometry. Applied to a large 3GPP communications benchmark, the approach shrinks the evaluation set to 10% of its original size while maintaining near-perfect ranking correlation (Spearman 0.98) and minimal performance fluctuation (<2%), dramatically reducing evaluation cost without compromising reliability.

## Method Summary
The proposed pipeline consists of five stages. First, a base pre-trained LLM is fully fine-tuned on a small domain-specific QA dataset to internalize task semantics. Second, the fine-tuned model processes each raw test sample (with a fixed system prompt) and extracts the last-layer hidden state of the final token, which is L2-normalized to produce a semantic embedding. Third, K-means clustering is applied to these embeddings to reveal the benchmark’s intrinsic redundancy structure. Fourth, a “Dataset X-ray” analyzer examines the geometry of each cluster—specifically the distribution of samples over distance intervals from the centroid—and determines an appropriate compression intensity: compact clusters are aggressively compressed (10% per interval), while diffuse clusters are sampled more conservatively (20–30%). Finally, stratified uniform sampling across the distance intervals yields the compressed test set. This history-free approach requires no prior model predictions and adapts compression dynamically to the data’s semantic density.

## Key Results
- Test set size reduced to 10% of original, lowering evaluation cost by >90%.
- Model rankings on compressed set achieve Spearman correlation of 0.98 with full benchmark.
- Average absolute performance fluctuation remains below 2%.

## Why This Works (Mechanism)
### Mechanism 1: History-Free Semantic Embedding
A domain-fine-tuned LLM generates embeddings that reflect test-sample redundancy without needing any model performance history. The fine-tuning internalizes task-relevant semantics (e.g., 3GPP protocols). The adapted model then processes raw test questions, and the final-layer hidden state for each sample is extracted as a high-level semantic embedding. In this space, Euclidean distance approximates functional equivalence within the target domain. The core assumption is that the internal representations of a fine-tuned LLM disentangle domain-specific concepts and structure such that query redundancy manifests as geometric proximity. If fine-tuning fails or the embedding space is poorly structured (e.g., silhouette score near 0), the semantic distance metric becomes unreliable.

### Mechanism 2: Task-Aware Clustering for Redundancy Discovery
Clustering in the domain-adapted embedding space reveals intrinsic semantic redundancies, enabling identification of dense (redundant) versus sparse (unique) regions. K-means clustering is applied to the normalized embeddings. The resulting clusters' geometry (compactness, separation, intra-cluster distance distribution) diagnoses the benchmark's redundancy level. Dense clusters suggest many semantically similar items; sparse clusters indicate diverse or edge-case instances. The core assumption is that the benchmark's inherent redundancy is accurately captured by the geometric structure of the fine-tuned model's embedding space. If clustering yields many small, scattered clusters with poor separation (low silhouette score), the method cannot reliably distinguish core redundancy from unique cases.

### Mechanism 3: Dataset X-ray for Dynamic Compression
Analyzing cluster geometry allows dynamic calibration of compression intensity, balancing cost reduction with fidelity preservation. The Dataset X-ray analyzes each cluster's sample distribution over distance intervals from its centroid. For compact clusters (high redundancy), it aggressively samples 10% from each of 5 equal-width distance bands, ensuring representation of both core and boundary samples. For diffuse clusters (low redundancy), it reduces compression (retains 20-30%) to avoid discarding unique instances. The core assumption is that uniform sampling across distance intervals within a cluster preserves the cluster's semantic range better than random or centroid-only sampling. If cluster distance distributions are highly irregular or multi-modal, fixed interval sampling may fail to capture representative modes, leading to biased subsets.

## Foundational Learning
- **Domain-Adaptive Fine-Tuning**: Fine-tuning a base LLM on a small domain-specific dataset aligns its internal representations with the target task’s semantics, enabling meaningful embedding-based similarity judgments. *Why needed*: Without domain alignment, the model’s embeddings may not capture task-relevant redundancy. *Quick check*: Why use full-parameter fine-tuning instead of prompt engineering or a frozen model for embedding extraction?
- **Embedding Space Geometry for Semantic Similarity**: The entire compression pipeline relies on Euclidean distance in the embedding space to approximate functional redundancy among test questions. *Why needed*: Geometric proximity in a task-adapted embedding space serves as a proxy for semantic equivalence. *Quick check*: What does a high silhouette score in this context imply about the test set’s structure?
- **Stratified Sampling within Clusters**: Ensures compressed sets retain both typical samples (near centroids) and challenging/edge cases (farther from centroids), maintaining task diversity. *Why needed*: Uniform random sampling may discard boundary samples that define task boundaries. *Quick check*: How does sampling uniformly across distance intervals differ from sampling uniformly at random within a cluster?

## Architecture Onboarding
Component map: Domain Fine-Tuning Module → Embedding Extractor → Clustering Engine → Dataset X-ray Analyzer → Sampler

Critical path: Fine-tuning → Embedding generation → Clustering → X-ray analysis → Sampling. Errors in fine-tuning or clustering propagate downstream.

Design tradeoffs:
- Number of clusters (K): Too low merges distinct tasks; too high splits coherent concepts. Typically set via heuristic (e.g., √n) or grid search on silhouette score.
- Compression aggressiveness: Directly tied to X-ray’s diagnosis; misdiagnosis causes fidelity loss.
- Embedding layer choice: Last layer captures high-level semantics but may be costly; earlier layers are cheaper but noisier.

Failure signatures:
- Low silhouette score (<0.3) after clustering → embeddings not task-structured; revisit fine-tuning data or model size.
- High performance fluctuation (|Δ| > 5%) on compressed set → X-ray misestimated redundancy; adjust interval count or sampling fractions.
- Compressed set fails leaderboard correlation check → subset not preserving ranking; consider increasing K or reducing compression ratio.

First 3 experiments:
1. **Sanity Check**: Run pipeline on a small, manually labeled redundant/unique subset. Verify embeddings cluster as expected (e.g., duplicates nearby) and X-ray assigns higher compression to dense clusters.
2. **Hyperparameter Sweep**: Vary K (e.g., 50, 100, 200) and measure Spearman correlation (full vs. compressed set rankings) to find stable region. Expect correlation peak at moderate K.
3. **Ablation – Embedding Source**: Compare using embeddings from base (non-fine-tuned) vs. fine-tuned model. Expect fine-tuned to yield higher correlation and lower fluctuation, validating domain adaptation’s role.

## Open Questions the Paper Calls Out
- How does the choice of base LLM architecture and the size of domain-specific fine-tuning data affect the fidelity of the compressed test set? The method was evaluated only with Qwen3-1.7B on a fixed fine-tuning set; cross-model and cross-data-scale effects remain unknown.
- How robust is the Dataset X-ray mechanism’s dynamic compression calibration when applied to benchmarks with low semantic redundancy or atypical cluster geometries? Validation was limited to a high-redundancy 3GPP benchmark; behavior on other geometries is untested.
- Does the proposed compression framework preserve model rankings for non-accuracy metrics (e.g., F1, BLEU) or open-ended generative tasks without correctness labels? All experiments used QA accuracy; applicability to generation or structured outputs is open.
- How sensitive are the compression results to the choice of clustering parameters (e.g., number of clusters K) and embedding extraction method (e.g., last-layer vs. mean pooling)? The paper fixed K=100 and last-layer hidden states without sensitivity analysis.

## Limitations
- Dataset X-ray thresholds (e.g., silhouette or distance cutoffs triggering 10% vs. 20–30% compression) are unspecified, limiting reproducibility.
- Generalizability is unproven; evaluation was performed solely on a 3GPP communications benchmark.
- Embedding robustness to fine-tuning data size, model scale, and prompt variations is not explored.

## Confidence
- History-free embedding utility: High
- Clustering-based redundancy discovery: Medium
- Dynamic compression fidelity: Medium-Low

## Next Checks
1. Cross-domain replication: Re-run the pipeline on at least two additional benchmarks (e.g., GSM8K, HumanEval) to test generalizability of the 10% compression claim.
2. X-ray sensitivity analysis: Ablate the compression decision thresholds (e.g., vary silhouette score cutoffs) and measure resulting Spearman correlation and fluctuation to expose robustness boundaries.
3. Embedding source ablation: Compare performance when using embeddings from the base (non-fine-tuned) model, a model fine-tuned on a different domain, and a frozen encoder (e.g., Sentence-BERT) to isolate the contribution of domain adaptation.
