# MMFormalizer: Multimodal Autoformalization in the Wild
## Quick Facts
- **ArXiv ID:** 2601.03017
- **Source URL:** https://arxiv.org/abs/2601.03017
- **Reference count:** 25
- **Primary result:** MMFormalizer recursively grounds visual elements into formal propositions using dimensional or axiomatic termination, achieving up to 71.4% compile accuracy in modern physics (GPT-5) and 76% on MathVerse plane geometry (Gemini-3-Pro), while successfully handling classical mechanics derived from Hamiltonian formalism.

## Executive Summary
MMFormalizer introduces a framework for multimodal autoformalization that translates natural language descriptions and visual inputs (diagrams, physical scenes) into verifiable formal statements in Lean. The system addresses the challenge of inferring hidden constraints (e.g., mass, energy) from images by recursively grounding perceptual primitives into a dependent type hierarchy. A key innovation is the adaptive termination mechanism that stops decomposition when propositions align with dimensional quantities or fundamental axioms, preventing over-decomposition. Evaluated on the new PhyX-AF benchmark (115 samples spanning math and physics), frontier models achieve significantly higher compile and semantic accuracy than open-source alternatives, with GPT-5 leading in physics and Gemini-3-Pro in geometry. Ablations confirm the necessity of termination conditions and image-grounded recursion for out-of-distribution generalization.

## Method Summary
The pipeline begins with a multimodal parser that converts an image into a scene graph of geometric primitives (points, lines, regions) and extracts a natural language problem statement. A recursive grounder then decomposes the scene, assigning informal semantic hypotheses to each node and retrieving matching Lean lemmas from mathlib/PhysLean via LeanSearch. At each recursion step, a termination controller checks whether the current set of propositions corresponds to a dimensional primitive (e.g., length, force) or a fundamental axiom (e.g., Newton's laws); if so, recursion on that branch stops. After grounding, an axiom composition module merges child lemmas into parent statements using an LLM, with Lean's type checker verifying syntax. Finally, a semantic verifier confirms that every formal statement is jointly supported by the visual and textual inputs. The system is evaluated on the PhyX-AF benchmark, measuring compile accuracy and semantic correctness.

## Key Results
- Frontier models achieve compile accuracies up to 71.4% in modern physics (GPT-5) and 76% on MathVerse plane geometry (Gemini-3-Pro), outperforming open-source models by a large margin.
- MMFormalizer is the first multimodal autoformalizer to handle classical mechanics derived from Hamiltonian formalism, demonstrating its ability to process advanced physics.
- Ablation studies show that explicit termination conditions prevent over-decomposition (e.g., a failure case with 684 nodes without termination) and that image-grounded recursion improves out-of-distribution performance.

## Why This Works (Mechanism)
**Mechanism 1: Recursive Visual Grounding**
Claim: The system maps perceptual primitives to formal propositions via a dependent type hierarchy.
Mechanism: The input image is parsed into a `SceneGraph` of primitive entities and spatial relations. Each primitive receives an informal semantic hypothesis. These hypotheses are iteratively aligned with retrieved Lean lemmas, constructing a `PropChain`—a dependent list where each lemma is a Σ-type `(P:PropChain, p:P)`. The `lift` function maps scene graph subgraphs to propositional chains, ensuring compositional dependency. Recursion stops when a node's proposition set can be grounded in a dimensional primitive or fundamental axiom.
Evidence: Section 3.1 defines `PropChain := Σ(L_t : List Lemma)` and `lift: SceneGraph → PropChain`. The parsing function `parse: I → SceneGraph` decomposes the image into a base-level graph G₀.

**Mechanism 2: Adaptive Termination**
Claim: Recursion terminates by anchoring abstraction in dimensional analysis or foundational axioms, avoiding uncontrolled decomposition.
Mechanism: At each step, the system checks if the current propositions `P_t` match either a dimensional quantity (e.g., `[M]`, `[L]`, `[T]`, `Energy`, `Force`) or a fundamental axiom (e.g., `Newton's First Law`, `SpeedOfLight`). The check `Termination(P_t)` returns `dim(p)` if `p∈D_t` or `axiom(p)` if `p∈A_t`, where `D_t`/`A_t` are domain-specific sets (Appendix A.4). This prevents infinite symbolic breakdown.
Evidence: Section 3.2 states the termination condition. Section 4.3 (ablation) shows that unspecified termination leads to excessively deep trees and synthesis failure. Appendix A.1 presents a failed case with 684 steps and 8 layers.

**Mechanism 3: Axiom Composition and Semantic Verification**
Claim: Grounded propositions are composed into verifiable formal statements, with semantic checking enforcing multimodal consistency.
Mechanism: Child lemmas are recursively combined using a `Compose` operator guided by an LLM, building parent nodes. The composed statements undergo Lean's type checking (`TypeComposition`). A semantic checking module then verifies that each lemma in the `PropChain` is supported by both visual and textual evidence; only fully consistent chains are accepted.
Evidence: Section 3.3 describes `TypeComposition: SceneGraph → PropChain → AxiomChain`. Section 3.4 introduces the semantic check. Section 4.4 reports semantic checking accuracy against human verification.

## Architecture Onboarding
**Component map:**  
Input Parser -> Recursive Grounder -> Termination Controller -> Axiom Compiler -> Semantic Verifier

**Critical path:**  
Multimodal input (image + text) → SceneGraph extraction → Recursive grounding with LeanSearch retrieval → Termination check (dimensional/axiomatic) → Axiom composition (LLM-driven `Compose` + Lean type checking) → Semantic verification → Valid PropChain/AxiomChain.

**Design tradeoffs**:
- Recursion depth vs. completeness: Deeper recursion reaches more fundamental axioms but risks over-decomposition; max depth = 6, max nodes = 100.
- Image grounding vs. efficiency: Including images during grounding improves OOD performance but increases compute per node.
- Retrieval code vs. Synthesis freedom: Providing full code snippets from LeanSearch helps in-domain (MATHVERSE) but hinders OOD generalization; letting LLM synthesize novel types aids synthetic geometry.

**Failure signatures**:
- Over-decomposition: Exponential node growth (e.g., 684 nodes) and spurious primitives; indicates missing/lenient termination.
- Compile failure: Lean type errors, often from incorrect axiom selection or mismatched dependencies.
- Semantic mismatch: High compile accuracy but low human/semantic check accuracy; propositions not truly grounded in visual evidence.

**First 3 experiments**:
1. Simple Plane Geometry: Validate on a MathVerse problem (e.g., circle with tangent). Expect shallow recursion (2–3 layers) and termination on geometric primitives like `Angle=90°`. Check that the PropChain matches diagram angles.
2. Physics with Hidden Constraint: Use a PhyX problem (e.g., pendulum with implicit tension). Expect recursion to bottom on dimensional `Force` or axiom `NetForceZero`. Verify termination set includes `[M][L][T⁻²]` or `Newton's Second Law`.
3. Out-of-Distribution Synthetic Geometry: Use a synthetic `RegularHexagonalPrism` (Appendix A.1). Expect the LLM to synthesize new dependent types extending `RightPrism`. Check that the novel structure compiles in Lean and matches numeric verification.

## Open Questions the Paper Calls Out
1. How can multimodal autoformalization be effectively grounded in truly uncontrolled, real-world settings beyond curated benchmarks? The PhyX-AF benchmark uses idealized diagrams; robustness to noise, ambiguity, and varied contexts remains unknown.
2. Why does geometry remain the most challenging domain for multimodal autoformalization, and what specific modifications could improve performance? Consistently lower accuracy suggests issues with geometric structure complexity, Lean coverage, spatial-to-dependent-type translation, or training data.
3. Are the proposed termination conditions (dimensional and axiomatic) universally applicable across all physical and mathematical domains? They work well in physics but may fail in non-dimensional domains like combinatorics or graph theory; generality needs testing.
4. Why do state-of-the-art open-source multimodal models significantly underperform frontier closed-source models in this task? Potential factors include scale, specialized fine-tuning, multimodal training on diagrams, or reasoning capabilities; without controlled ablations, the bottleneck is unclear.

## Limitations
- Core components (LeanSearch indexing, PhysLean toolkit, termination logic) lack open implementation; reproduction relies on reverse engineering.
- Prompt designs for recursive grounding and composition are undisclosed, introducing variability.
- The PhyX-AF benchmark is small (115 samples) and its representativeness is unverified by external studies.

## Confidence
- Recursive grounding mechanism: **Medium** (internal coherence, no independent validation)
- Termination condition preventing over-decomposition: **High** (ablation shows clear failure mode)
- Axiom composition + semantic checking: **Medium** (results plausible but LLM-dependent)
- Benchmark validity: **Low** (small size, single source)
