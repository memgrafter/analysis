# SpectraKAN: Conditioning Spectral Operators

## Quick Facts
- **ArXiv ID**: 2602.05187
- **Source URL**: https://arxiv.org/abs/2602.05187
- **Reference count**: 40
- **Primary result**: SpectraKAN achieves state-of-the-art accuracy across multiple PDE benchmarks, reducing RMSE by up to 49% on 1D compressible Navier-Stokes and showing consistent improvements on diffusion-reaction, Darcy flow, shallow water, and climate modelling.

## Executive Summary
Existing spectral neural operators use fixed Fourier kernels, which limits their ability to capture multi-scale and regime-dependent dynamics in PDE solutions. SpectraKAN introduces a conditioning mechanism that dynamically adapts the spectral operator to the input. By extracting a global token from spatio‑temporal history with a Kolmogorov‑Arnold Network (KAN) and modulating a multi‑scale Fourier trunk via single‑query cross‑attention, it transforms a static convolution into an input‑conditioned integral operator. Comprehensive evaluations on five PDE benchmarks demonstrate substantial accuracy gains, with up to 49% RMSE reduction, and robust performance across varying resolutions.

## Method Summary
SpectraKAN conditions the spectral operator on the input by employing a KAN to extract a global token representing the spatio‑temporal history. This token serves as a query that attends to multi‑scale Fourier coefficients (keys/values) of the input via single‑query cross‑attention. The attention output modulates the Fourier trunk, effectively weighting spectral components in an input‑dependent manner. The modulated coefficients are inverse‑transformed to produce the solution field. This design replaces static Fourier kernels with a flexible, data‑driven integral operator that adapts to regime‑specific and multi‑scale characteristics.

## Key Results
- Across five PDE benchmarks, SpectraKAN reduces RMSE by up to 49%: 1D compressible Navier‑Stokes (0.29493 → 0.14544), 1D Diffusion‑Reaction (to 0.00397), 2D Darcy Flow (to 0.01260), 2D Shallow Water (to 0.0024, 45% improvement), and Climate Modelling (to 0.0096119, 36% improvement).
- SpectraKAN exhibits robust resolution invariance, maintaining low errors under both up‑ and down‑sampling of input grids.

## Why This Works (Mechanism)
SpectraKAN works by conditioning the spectral operator on the input, enabling dynamic adaptation of the Fourier kernels to the specific regime and multi‑scale structure of the PDE data. The Kolmogorov‑Arnold Network (KAN) extracts a global token from the spatio‑temporal history, which via single‑query cross‑attention modulates the multi‑scale Fourier trunk. This input‑dependent modulation effectively transforms a static convolution into an integral operator that can capture varying spatial dependencies and cross‑scale interactions, overcoming the limitation of fixed spectral bases.

## Architecture Onboarding
- **Component Map**: Input → KAN Token Extractor → Global Token → (Query); Multi‑scale Fourier Trunk → (Keys/Values) → Single‑query Cross‑Attention → Modulated Fourier Coefficients → Inverse FFT → Output.
- **Critical Path**: (1) Input spatio‑temporal history processed by KAN to produce a global token; (2) Token used as query to attend to multi‑scale Fourier coefficients (keys/values); (3) Attention output modulates the Fourier trunk; (4) Inverse Fourier transform yields the solution field.
- **Design Tradeoffs**: Dynamic conditioning via KAN and attention improves expressivity and regime adaptation but increases parameter count and computational overhead versus static FNO. Multi‑scale representation adds complexity but captures a wider range of frequencies. Single‑query attention reduces cost vs. full self‑attention but may limit richer interactions. Choice of KAN activation functions trades off interpretability and training stability.
- **Failure Signatures**: Poor token extraction (KAN fails to capture relevant global features) leads to inappropriate modulation and high errors. Overfitting to training resolution may manifest as performance drop on novel resolutions. Vanishing/exploding gradients in Fourier domain or attention can cause instability. High variance across random seeds may indicate sensitivity.

  3. Ablate the KAN token extractor: replace KAN with an MLP of similar size and compare performance to isolate the benefit of KAN.
