# SoundPlot: An Open-Source Framework for Birdsong Acoustic Analysis and Neural Synthesis with Interactive 3D Visualization

## Quick Facts
- arXiv ID: 2601.12752
- Source URL: https://arxiv.org/abs/2601.12752
- Reference count: 33
- Primary result: High-fidelity perceptual preservation with mean mel spectrogram correlation of 0.929 on test recordings.

## Executive Summary
SoundPlot is an open-source framework addressing the lack of accessible, scalable tools for birdsong analysis. It features a modular analysis-synthesis pipeline that extracts acoustic features (spectral centroid, bandwidth, pYIN pitch, MFCCs), synthesizes audio via Griffin-Lim applied to mel spectrograms, and visualizes trajectories in an interactive 3D web interface. Quantitative evaluation shows high perceptual fidelity, with mel spectrogram correlations exceeding 0.92, confirming the effectiveness of the approach.

## Method Summary
The framework processes audio through discrete stages: loading and preprocessing (resampling to 22.05 kHz, mono conversion, normalization, optional silence trimming), feature extraction using STFT-based methods (window=2048, hop=512), synthesis via Griffin-Lim iterations on mel spectrograms (128 bands), and 3D visualization mapping normalized features (centroid, bandwidth, pitch) to Cartesian coordinates with PCA for MFCC reduction. The web interface, built with Three.js, renders synchronized trajectories for original and synthesized audio.

## Key Results
- Modular pipeline design enables maintainable, component-wise improvements.
- Griffin-Lim synthesis achieves high mel spectrogram correlation (mean 0.929), indicating preserved perceptual structure.
- Interactive 3D visualization facilitates intuitive exploration of acoustic dynamics through trajectory mapping.

## Why This Works (Mechanism)
- **Modular Pipeline Architecture**: Decoupling audio processing, feature extraction, synthesis, and visualization into independent modules with clear interfaces allows targeted updates without system-wide refactoring, assuming discrete transformations improve workflow robustness. Failure occurs if module interfaces become inconsistent.
- **Griffin-Lim on Mel Spectrograms**: Iterative phase estimation from magnitude-only mel spectrograms reconstructs audio that preserves perceptual features captured by mel-frequency warping, relying on the assumption that envelope structure matters more than exact phase. Limitations arise if critical features like rapid modulations are discarded.
- **3D Feature Trajectory Mapping**: Assigning a small set of interpretable acoustic features to spatial coordinates creates navigable paths where geometric shapes reflect acoustic evolution, leveraging human pattern recognition in 3D with audio sync. This may fail for complex sounds if chosen features insufficiently capture variance.

## Foundational Learning
- **Digital Signal Processing (STFT, Spectrograms)**: Essential for understanding windowing, overlap, and magnitude/phase separation in feature extraction and synthesis. Quick check: Doubling STFT window size improves frequency resolution butdegrades time resolution, affecting estimates for rapid trills.
- **Dimensionality Reduction (PCA)**: Used to project 13 MFCCs into 2D/3D for visualization; understanding linear vs. non-linear trade-offs is key. Quick check: PCA maximizes variance, while mel correlation measures spectrogram similarity; shifts in PCA plots may arise from non-linear distortions not captured by correlation.
- **WebGL/Three.js for Scientific Visualization**: Core to the interactive interface, requiring knowledge of scene graphs and render loops. Quick check: To size points by spectral energy, modify the `size` property of `THREE.Points` material or geometry attributes.

## Architecture Onboarding
- **Component map**: Audio file -> AudioLoader -> AudioPreprocessor -> FeatureExtractor -> (1) save features for PCA/3D mapping OR (2) AudioSynthesizer -> Griffin-Lim -> save WAV -> frontend loads both audios + PCA results -> renders dual 3D trajectories with synchronized playback.
- **Critical path**: Follow the sequence from audio input through preprocessing, feature extraction, optional synthesis, and finally 3D rendering in the browser, with PCA applied to MFCCs for dimensionality reduction.
- **Design tradeoffs**: Griffin-Lim chosen over neural vocoders for speed and determinism but accepts audible artifacts; fixed 3D mapping (3 features) prioritizes interpretability over variance capture; client-side rendering limits scalability for very long recordings.
- **Failure signatures**: Synthesis: ρmel < 0.85 indicates Griffin-Lim convergence issues or parameter mismatches; Visualization: 3D points not animating suggests WebGL context loss or render loop errors; Feature extraction: MFCC discrepancies from incompatible librosa versions cause PCA misalignment.
- **First 3 experiments**: 1. End-to-end smoke test: Process a sample WAV, verify session outputs, and confirm dual trajectories with sync in the web UI. 2. Feature extraction validation: Isolate FeatureExtractor on a short clip, plot features, and compare against Raven/Praat for plausibility. 3. Synthesis parameter sweep: Vary Griffin-Lim iterations (e.g., 10, 32, 100), plot ρmel vs. iterations to find plateau (expected ~32).

## Open Questions the Paper Calls Out
- How can neural vocoders (e.g., MelGAN, HiFi-GAN) be integrated to improve synthesis quality while maintaining real-time performance and interpretability?
- What perceptual or analytical information is lost by discarding stereo channels, and how can stereo cues be incorporated into the pipeline?
- Which dimensionality reduction technique (PCA vs. t-SNE/UMAP) best preserves perceptual relationships in birdsong spaces for real-time 3D visualization?
- To what extent do objective mel spectrogram correlations predict human perceptual similarity judgments for synthesized birdsong?

## Limitations
- Griffin-Lim generalizability on diverse, noisy, or polyphonic field recordings is unverified; high mel correlation may not hold for all datasets.
- Fixed 3D feature mapping may omit salient acoustic dimensions, leading to visual clutter for complex sounds; utility lacks systematic user validation.
- Key parameters (pYIN settings, PCA preprocessing) are unspecified, hindering reproducibility and causing potential implementation variances.

## Confidence
- Modular pipeline design: High (directly evidenced by code structure and figures).
- Griffin-Lim fidelity for birdsong: Medium (supported by metrics but lacks external perceptual validation).
- 3D trajectory utility: Low (based on assumption without controlled user studies).
