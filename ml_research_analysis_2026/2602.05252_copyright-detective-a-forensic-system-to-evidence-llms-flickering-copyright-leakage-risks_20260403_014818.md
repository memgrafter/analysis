# Copyright Detective: A Forensic System to Evidence LLMs Flickering Copyright Leakage Risks
## Quick Facts
- arXiv ID: 2602.05252
- Source URL: https://arxiv.org/abs/2602.05252
- Reference count: 9
- Primary result: Persuasive jailbreak (Pathos) shifts ROUGE-L leakage from ~0.1 to ~0.7; unlearning detection via PCA Shift reveals representational drift in final layers.

## Executive Summary
Large language models can intermittently reproduce copyrighted content due to stochastic decoding and alignment suppression, making single-query audits unreliable. This paper introduces Copyright Detective, a forensic audit system that integrates four detection paradigms—content recall, persuasive jailbreak probing, knowledge memorization, and unlearning verification—into a unified framework. By leveraging extensive inference scaling, the system surfaces latent memorization events that would otherwise be missed. Key findings demonstrate that persuasive jailbreak strategies (e.g., Pathos) dramatically increase leakage in GPT-4o-mini, and that unlearning leaves detectable representational traces in deeper transformer layers. The system is deployed as an interactive web tool for black-box auditing with reproducible evidence reports.

## Method Summary
Copyright Detective is a Streamlit-based application enabling auditors to evaluate LLMs for copyright leakage. Users provide reference texts, and the system runs up to four modules: Content Recall (direct continuation with multiple samples), Persuasive Jailbreak (adversarial mutation via rhetorical templates), Knowledge Memorization (auto-generated QA for semantic retention), and Unlearning Detection (Min-K% Prob for black-box token analysis or PCA/CKA for white-box representation comparison). Evaluation metrics include ROUGE-L, LCS, Jaccard, and F1. The tool visualizes matched spans, score distributions, and PCA plots, and generates audit PDFs. Its core innovation is the use of inference scaling to handle probabilistic leakage and persuasive jailbreaking to bypass alignment suppression.

## Key Results
- Persuasive jailbreak (Pathos) shifts ROUGE-L distribution from ~0.1 to ~0.7 in GPT-4o-mini.
- Unlearning leaves detectable representational drift in final transformer layers (PCA Shift).
- Inference scaling reveals intermittent memorization missed by single-query audits.

## Why This Works (Mechanism)
### Mechanism 1: Overcoming Output Uncertainty via Inference Scaling
**Claim**: Repeated sampling at test time surfaces intermittent memorization events that single queries miss.
**Mechanism**: The system generates multiple outputs per prompt (e.g., 1,000 samples) to estimate the probability distribution of ROUGE-L scores. Rare but severe verbatim reproductions become visible as outliers in the distribution.
**Core assumption**: Memorized content appears stochastically due to decoding randomness; more samples yield a more reliable risk estimate.
**Evidence anchors**: [abstract] "integrates multiple detection paradigms [...] into a unified forensic framework that uses extensive inference scaling to surface latent memorization." [section 4] "We found that copyright infringement in LLMs is highly probabilistic rather than deterministic [...] standard single-query audits would frequently miss severe leakage." [corpus] "Prior Aware Memorization" and related work; direct evidence for scaling efficacy is from this paper's experiments.
**Break condition**: If the target model is deterministic (temperature=0), scaling provides no additional information; leakage either appears consistently or not at all.

### Mechanism 2: Evading Alignment Suppression via Persuasive Jailbreaking
**Claim**: Rhetorically transformed prompts (e.g., Pathos, Ethos) destabilize refusal behaviors, shifting the leakage distribution from near-zero to measurable levels.
**Mechanism**: The module mutates safe queries into adversarial persuasive templates (e.g., framing as academic research) that preserve the core extraction intent. This bypasses content filters that block direct requests.
**Core assumption**: Alignment tuning suppresses explicit requests but is less effective against implicitly framed ones; the underlying memorization persists and can be probed.
**Evidence anchors**: [abstract] "persuasive jailbreak strategies (e.g., Pathos) shift ROUGE-L leakage distribution from ~0.1 to ~0.7 in GPT-4o-mini." [section 4] "while the baseline distribution is strictly confined to a low-risk zone (peak ∼0.1), persuasive prompts significantly shift the probability mass toward higher ROUGE-L scores." [section 3.2] Describes the mutation pipeline and "Intention Preservation Judge" to ensure semantic goal retention.
**Break condition**: If the model's alignment is robust to rhetorical reframing (e.g., via internal self-critique), all strategies may fail, yielding no shift. This could indicate effective safety fine-tuning rather than absence of memorization.

### Mechanism 3: Detecting Unlearning via Representational Drift (PCA Shift)
**Claim**: Post-training removal of copyrighted data leaves detectable traces in the final-layer activation geometry, even if output behavior appears compliant.
**Mechanism**: The system compares hidden states of the original and unlearned models when processing target texts. PCA on these states reveals centroid displacement (∆PC1/PC2) in deeper layers, indicating the model now processes the text differently.
**Core assumption**: Unlearning alters internal feature representations measurably; complete erasure would cause a large, uniform shift, while ineffective unlearning shows minimal drift.
**Evidence anchors**: [abstract] "unlearning leaves detectable representational drift in final transformer layers (PCA Shift)." [section 4] "unlearning induces a depth-stratified geometric divergence, where the final transformer blocks (Layers 29-31) exhibit drastic representation drift." [section 3.4] Notes this "quantifies the magnitude of representational divergence, serving to characterize the extent of model modification rather than to verify absolute erasure."
**Break condition**: If alignment training or other post-processing homogenizes representations regardless of content, PCA shift may be inconclusive. Also, this method requires white-box access to both original and unlearned model weights.

## Architecture Onboarding
**Component map**  
Input & Preprocessing -> Core Detection Modules (Content Recall, Persuasive Jailbreak, Knowledge Memorization, Unlearning Detection) -> Evaluation Engine -> Visualization & Reporting -> Legal Context Module

**Critical path**  
For black-box audits: start with Content Recall; if blocked, move to Persuasive Jailbreak; for semantic leakage, run Knowledge Memorization; if comparing model versions, apply Unlearning Detection. Each module runs with inference scaling to handle stochasticity.

**Design tradeoffs**  
- Black-box vs. white-box: System prioritizes black-box access for external auditors but offers deeper white-box analysis when weights are available.
- Inference cost vs. detection reliability: Extensive scaling (e.g., 1,000 samples) improves confidence but is computationally expensive.
- Automation vs. human judgment: Automates similarity scoring and mutation, leaving final legal interpretation to users.

**Failure signatures**  
- All modules return low similarity scores across scaling: could indicate no memorization or overly aggressive alignment (jailbreak failed to probe latent knowledge).
- High jailbreak success but low content recall: alignment suppresses direct requests but not implicitly framed ones.
- Inconclusive PCA shift (small change): could mean unlearning was effective, or that the text wasn't strongly encoded originally.

**First 3 experiments**  
1. **Baseline Content Recall**: Select a known copyrighted book excerpt (e.g., first 100 words of *Harry Potter*), run Next-Passage Prediction with 100 samples (temp=1.0) on target LLM. Inspect ROUGE-L distribution; any score >0.8 is strong verbatim evidence.
2. **Jailbreak Efficacy Test**: Using same text, configure "Pathos" strategy with 50 mutation attempts, 10 samples each. Compare score distribution to baseline. A shift toward higher scores confirms alignment suppression was masking memorization.
3. **Unlearning Verification (if white-box available)**: Load original and unlearned model versions. Process target text through both, extract final-layer activations, compute PCA centroid difference. A large ∆PC1 (>0.5 normalized) suggests the unlearning update significantly altered processing of that text.

## Limitations
- Heavy inference scaling (e.g., 1000 samples) is computationally expensive, limiting scalability for large audits.
- Persuasive jailbreak templates lack full disclosure; only “Ethos” example is detailed, impeding independent replication.
- Unlearning detection via PCA shift requires white-box access to both original and unlearned models, which is rarely available to external auditors.

## Confidence
- Inference scaling reveals intermittent memorization: Medium
- Persuasive jailbreaks induce leakage distribution shift: Medium
- Unlearning leaves detectable PCA shift: Medium
- Overall forensic system functionality: High

## Next Checks
1. Cross-model replication: Apply the full pipeline (with scaling) to open-weight models (Llama 2, Mistral) across varied temperatures to verify flickering detection consistency.
2. Jailbreak template audit: Generate and evaluate all rhetorical strategies on a fixed copyrighted text set, reporting success rates and semantic preservation (via intention judge).
3. Unlearning correlation study: On a standardized unlearning benchmark (e.g., TOFU), compute PCA shift and compare with established unlearning metrics (e.g., Min-K% Prob, membership inference) to assess alignment.
