# CustomTex: High-fidelity Indoor Scene Texturing via Multi-Reference Customization
## Quick Facts
- **arXiv ID:** 2603.19121
- **Source URL:** https://arxiv.org/abs/2603.19121
- **Reference count:** 40
- **Primary result:** Achieves state-of-the-art performance, ranking first in all image-to-texture and text-to-texture metrics on 3D-FRONT.

## Executive Summary
CustomTex addresses the challenge of generating high-fidelity textures for 3D indoor scenes with instance-level precision. Existing methods often produce low-resolution textures with artifacts and cannot align textures to multiple reference images accurately.  

CustomTex introduces a dual-distillation framework that separates semantic control (via instance cross-attention) from pixel-level enhancement (via super-resolution), both optimized under a Variational Score Distillation objective guided by CLIP. This yields a unified high-resolution texture map that precisely matches each object instance to its references. Evaluated on 3D-FRONT, the method attains state-of-the-art results across all metrics and demonstrates clear qualitative improvements, validated by a user study.

## Method Summary
Given a 3D scene mesh and multiple reference images for individual objects, CustomTex optimizes a texture map using Variational Score Distillation (VSD). The framework contains two branches: an instance cross-attention module that correlates each object with its references to enforce semantic consistency, and a super-resolution branch that upscales the texture to the target resolution. Both branches are trained jointly: the base VSD generator produces a low-resolution texture conditioned on the cross-attention features, the SR branch refines details, and the combined output is rendered to compute CLIP-based losses that guide updates. The final high-resolution texture is baked onto the mesh.

## Key Results
- **Quantitative SOTA:** Ranks first in all metrics (CLIP-I, CLIP-FID, Q-Align) for both image-to-texture and text-to-texture tasks on 3D-FRONT.
- **Qualitative advantages:** Textures exhibit superior sharpness, fewer artifacts (e.g., baked-in shading), and precise instance-level consistency with references.
- **User study:** Participants rated CustomTex higher than baselines in visual quality and prompt alignment.

## Why This Works (Mechanism)
The dual-distillation design isolates two distinct aspects of texture generation. The instance cross-attention branch provides semantic grounding by correlating each object instance with its reference images, ensuring that the texture content matches the desired appearance. The super-resolution branch decouples detail synthesis, allowing the use of a dedicated upscaling process that operates independently of the semantic alignment. Optimizing both under VSD ensures that the texture map adheres to the CLIP-defined semantics on a global scale while the SR branch recovers fine details without being constrained by the lower-resolution diffusion prior. This separation prevents the common trade-off between semantic accuracy and detail fidelity, leading to high-resolution textures that remain consistent with references.

- **Instance Cross-Attention:** A mechanism where queries correspond to object instances and keys/values come from reference images, enabling per-instance feature alignment. *Why needed:* Achieves pixel-level matching to references. *Quick check:* Are reference images explicitly linked to objects via attention? - **Super-Resolution Branch:** A neural network that upscales a low-resolution texture to the target resolution. *Why needed:* Generates high-fidelity details beyond the VSD generator's resolution. *Quick check:* Is there a separate SR step? Yes.

- **Texture Baking:** The process of projecting the optimized texture map onto the mesh UVs. *Why needed:* Produces the final asset-compatible texture. *Quick check:* Is baking part of the pipeline? Yes.

## Architecture Onboarding
**Component map:**  
Input Mesh + Reference Images -> Instance Cross-Attention Encoder -> Base Texture Generator (VSD) -> Super-Resolution Branch -> Final Texture Map -> Baking onto Mesh.

**Critical path:** The texture optimization loop runs VSD with the two branches: at each step, the base generator produces a low-resolution texture conditioned on the mesh and instance cross-attention features; the SR branch upscales it; the combined output is rendered, and CLIP-based losses feedback to both branches.

**Design tradeoffs:**  
- Semantic control vs. detail: separating branches allows independent optimization but adds computational overhead.  
- Reference dependency: performance drops with few or low-quality references, as cross-attention relies on them.  
- Memory cost: dual distillation requires storing gradients for two networks, increasing memory usage.

**Failure signatures:**  
- Misaligned textures across instances (e.g., wrong pattern on an object).  
- Blurry or lacking high-frequency details if SR branch is omitted.  
- Visible seams or stretching after baking due to inconsistent UV mapping or insufficient rendering views.  
- Overfitting to references causing texture repetition or lack of diversity.

**Three first experiments:**  
1. Run the full pipeline on a single scene with provided references to verify end-to-end generation.  
2. Disable the instance cross-attention branch and observe degradation in instance-level alignment.  
3. Vary the number of reference images (e.g., 1 vs. 3) to assess sensitivity to reference coverage.

## Limitations
- Evaluation restricted to 3D-FRONT; generalizability to other datasets or outdoor scenes is untested.
- The method’s reliance on multiple reference images raises questions about robustness to reference quantity and quality, which are not analyzed.
- The core dual-distillation architecture lacks an ablation study, making it difficult to isolate the contribution of each branch.

## Confidence
- Quantitative SOTA (CLIP-I, CLIP-FID, Q-Align): **High**.
- Qualitative improvements (sharpness, artifact reduction, instance consistency): **Medium**.
- Generalization beyond 3D-FRONT: **Low**.

## Next Checks
1. Cross-dataset benchmark: Test CustomTex on additional 3D scene datasets (e.g., ScanNet, Matterport3D) to evaluate transferability.
2. Component ablation: Systematically remove or replace the instance cross-attention and super-resolution branches, and vary reference quantity/quality to measure their impact.
3. Robust user study: Conduct a large-scale, double-blind study with ≥50 diverse participants, report inter-rater reliability (e.g., Krippendorff’s α), and test across varied prompt types.
