# On the Relationship between Bayesian Networks and Probabilistic Structural Causal Models

## Quick Facts
- arXiv ID: 2603.27406
- Source URL: https://arxiv.org/abs/2603.27406
- Reference count: 11
- Primary result: A Bayesian network can be transformed into a probabilistic structural causal model (PSCM) by solving a linear system Au=b, but solutions are generally non-unique and depend on matrix rank conditions; the transformation reveals semantic ambiguities when using PSCMs as causal substitutes for BNs.

## Executive Summary
The paper explores the theoretical connection between Bayesian networks (BNs) and probabilistic structural causal models (PSCMs). It poses the problem: given a BN (specified by its DAG and conditional probability tables), can one construct a PSCM that yields exactly the same joint probability distribution? The authors formulate the reconstruction of PSCM exogenous probabilities as solving a linear equation system Au=b, where A encodes deterministic PSCM conditionals, u is the distribution over exogenous variable values, and b contains the BN conditionals. They analyze existence (b must lie in the column space of A) and uniqueness (determined by the rank and dimensions of A). The study shows that transformation is often possible, but typically yields multiple valid PSCMs, highlighting a lack of semantic determinism when substituting BNs with PSCMs.

## Method Summary
The proposed transformation begins by extracting all independent conditional probabilities from the BN’s CPTs into a vector b. Next, a binary matrix A is constructed to represent deterministic PSCM conditionals: each row corresponds to one conditional equation (for a specific parent configuration and child value), and each column corresponds to a possible value of a single exogenous variable U; entry A[i,j]=1 indicates that when U takes value j, the deterministic function f_v maps the given parent configuration to the corresponding child value, thus contributing to that conditional. The linear system Au=b must hold, where u is the probability distribution over U’s values. The constraints Σ u_i = 1 and u_i ≥ 0 are imposed. The system can be solved via linear programming to obtain a feasible u. The rank of A determines solution existence (b must lie in the column space of A) and uniqueness (based on dimensions and rank). The authors provide a combinatorial algorithm that generates candidate A matrices (respecting deterministic constraints) and uses column-sorted caching to avoid duplicate permutations.

## Key Results
- The BN-to-PSCM mapping reduces to solving Au=b; a solution exists iff b is in the column space of A (i.e., rank(A)=rank([A|b])).
- Solution uniqueness depends on dimensions: unique if A is square and full rank; overdetermined with full column rank yields a unique basic solution; underdetermined systems (m<n) have infinitely many solutions.
- General BN conditionals often require more than two exogenous values; a binary exogenous distribution suffices only for special cases (e.g., complementary conditionals).
- The transformation is non-unique both because multiple A matrices can reproduce the same BN and because underdetermined systems yield infinitely many u for a fixed A.
- These non-uniqueness properties question the adequacy of PSCMs as a causal replacement for BNs.

## Why This Works (Mechanism)
### Mechanism 1
The transformation considers a single exogenous variable U with distribution u = (u_1, ..., u_n) where u_j = P(U=j). Each structural function f_v for node v is deterministic and depends on the parent variables and U: X_v = f_v(X_{pa(v)}, U). For a given parent configuration x_{pa} and child value x, the BN conditional probability P(X_v=x | X_{pa}=x_{pa}) must equal the marginal over U: Σ_{j: f_v(x_{pa}, j)=x} P(U=j). This yields a linear equation: Σ_{j: f_v(x_{pa}, j)=x} u_j = b_i, where b_i is the corresponding entry in the BN conditional vector. The binary matrix A encodes which u_j appear in each equation: A[i,j]=1 iff f_v(x_{pa_i}, j)=x_i. The system Au=b must be satisfied under u_i ≥ 0 and Σ u_i = 1.

### Mechanism 2
Existence requires that the augmented right-hand side b′ lies in the column space of A′ (i.e., rank(A′) = rank([A′|b′])). If A′ has full row rank (rank equals number of rows), then this condition holds automatically for any b′. Uniqueness of the solution to the linear system (before non-negativity) depends on the column rank of A′: if A′ has full column rank (rank = n), the solution is unique; if the number of independent equations is less than n, infinitely many solutions exist. The actual exogenous distribution u must also satisfy u_i ≥ 0 and Σ u_i = 1, which may further restrict the solution set to a convex polytope.

### Mechanism 3
The transformation is generally non-unique both due to underdetermined systems (m < n) and combinatorial choices in constructing the binary matrix A from causal functions (which exogenous values map to which BN conditionals), leading to multiple valid PSCMs representing the same BN. Different assignments of exogenous values to BN conditionals (different A matrices) can yield the same b with different u. Even for a fixed A, if m < n, free variables allow infinite u distributions satisfying Au=b. The solution set forms a convex polytope. The paper’s Python algorithm enumerates candidate A matrices, solves for u via LP, and caches sorted column representations to avoid counting permutations as distinct solutions.

- **Bayesian Network Factorization and Conditional Probability:** BNs factorize the joint distribution as ∏ P(X_v|X_pa(v)). The transformation must preserve each conditional, which becomes an equation summing over exogenous probabilities. Quick check: If a BN has node Y with parents X,Z and conditional table P(Y|X,Z), how many equations does this contribute to the system Au=b? What are the corresponding b entries?
- **PSCM Structure (Deterministic Functions + Exogenous Uncertainty):** PSCMs represent mechanisms as deterministic functions f_v plus independent exogenous noise U_w. The transformation requires defining f_v (encoding the 0/1 pattern in A) and the distribution P(U_w) (vector u). Quick check: In a PSCM B = f_B(T,R) with R exogenous, what does R represent causally? How does P(R) affect P(B|T) compared to a standard BN?

## Architecture Onboarding
**Component map:** BN Input Module -> PSCM Structure Specifier -> Matrix Generator -> Linear Solver -> Feasibility Check -> Solution Filter & Cache -> PSCM Output Module.

**Critical path:** BN CPTs (b) -> Generate A pattern -> Generate candidate A matrices -> Solve A′x=b′ -> Filter feasible u -> Output PSCM(s).

**Design tradeoffs:** Exhaustiveness vs. efficiency: enumerating all A matrices is combinatorial; caching reduces permutation duplicates but not pattern duplicates. Heuristics (e.g., limiting exogenous support size) trade completeness for speed. Linear algebra vs. LP: direct inversion is fast for square systems but ignores non-negativity; LP guarantees u≥0 but slower. Semantic interpretation: Different u for same A yield same BN but different causal strengths; no built-in criterion to select a "best" PSCM.

**Failure signatures:**
- No feasible u: LP infeasible (no u satisfies Au=b with u≥0 and Σu_i=1). Cause: b is not in the convex hull of the columns of A. Remedy: increase number of exogenous values or try different A matrix patterns.
- All solutions invalid: For all candidate A matrices, no feasible u exists, indicating the BN conditionals cannot be represented by a PSCM with the given exogenous support size and deterministic structure.
- Excessive solutions: The system is underdetermined (more exogenous values than independent equations), leading to infinitely many feasible u. Without a selection criterion, the output is ambiguous.

**First 3 experiments:**
1. Reproduce the motivating example from Section 2: BN P(B|T) complementary (0.01, 0.99) with two exogenous values. Verify LP yields u=[0.99,0.01].
2. Test non-complementary conditionals: P(B=n|T=n)=0.1, P(B=n|T=y)=0.99 with three exogenous values. Find at least one A and feasible u (e.g., u=[0.9,0.09,0.01]).
3. Explore underdetermined system: Construct BN with one child having 4 conditionals (m=5) but only 2 exogenous values (n=2). Observe rank deficiency and no solution; then with n=5 observe infinite solutions (LP returns one basic feasible solution).

## Open Questions the Paper Calls Out
The paper implicitly questions the adequacy of PSCMs as causal substitutes for BNs due to the non-uniqueness of the transformation. It leaves open the problem of selecting a semantically meaningful PSCM representation from the many possibilities, and whether additional causal assumptions can resolve the ambiguity.

## Limitations
- The algorithm for generating A matrices does not enforce partition constraints across rows corresponding to the same parent configuration, risking invalid deterministic conditionals for multi-state variables.
- The linear system combines all exogenous influences into a single vector u, whereas PSCMs typically assign independent exogenous noise to each endogenous variable; the mapping and its justification remain unclear.
- The exhaustive enumeration of candidate A matrices scales combinatorially, making the approach impractical for networks beyond a few conditional probabilities.

## Confidence
- Au=b formulation: High
- Existence/uniqueness analysis via rank: High
- General non-uniqueness claim: Medium
- Algorithm validity and practical generation: Low

## Next Checks
1. Implement partition constraints: for each group of rows sharing the same parent configuration, enforce disjoint and exhaustive column subsets. Verify whether known solutions persist or get eliminated.
2. Independence validation: construct a BN with two independent endogenous subgraphs (e.g., X→Y and Z) and convert using a single exogenous U. Check whether the implied joint distribution violates the independence of Z from X,Y.
3. Scalability profiling: measure runtime and memory for increasing numbers of conditionals (m) and exogenous values (n), both with and without partition constraints, to determine practical limits and guide heuristic improvements.
