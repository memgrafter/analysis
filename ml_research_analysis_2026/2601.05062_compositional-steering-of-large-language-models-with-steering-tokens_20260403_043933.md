# Compositional Steering of Large Language Models with Steering Tokens

## Quick Facts

- arXiv ID: 2601.05062  
- Source URL: https://arxiv.org/abs/2601.05062  
- Reference count: 25  
- Primary result: Steering tokens with an orthogonal `<and>` token enable a frozen LLM to satisfy multiple behavioral constraints simultaneously, achieving state-of-the-art compositional generalization (e.g., 76.9% accuracy on Qwen-8B for unseen 2-behavior compositions vs 71.8% for instruction steering).

## Executive Summary

The paper tackles the challenge of steering large language models (LLMs) to follow multiple behavioral constraints at once, a problem known as compositional steering. Existing methods, which often modify the model's internal activations, struggle to generalize to combinations of behaviors not seen during training. The authors propose "compositional steering tokens": each behavior is encoded as a special input token learned via self-distillation, and a dedicated `<and>` token is trained to mediate interactions between tokens while keeping the base model frozen. This operates entirely in the input token space.  

Empirical results across several LLM families (Qwen, Llama, SmolLM, OLMo) show that steering tokens significantly outperform instruction-based steering, activation steering, and LoRA merging on unseen behavior combinations. For instance, on Qwen-8B, the method achieves 76.9% accuracy on unseen 2-behavior compositions (vs 71.8% for instructions) and 59.5% on unseen 3-behavior compositions (vs 54.0%). A hybrid approach combining tokens with instructions yields further gains (76.3% and 62.9%) with reduced sensitivity to token order. The approach generalizes across model sizes and architectures, demonstrating effective zero-shot fusion of both unseen behaviors and unseen numbers of behaviors while maintaining response quality.

## Method Summary

The approach consists of two training stages. First, for each behavior, a unique token embedding is learned via self-distillation: a frozen LLM generates outputs conditioned on a natural language instruction; a student model conditioned on the same prompt plus the behavior token matches the teacher's next-token distribution by minimizing a KL divergence loss with temperature scaling (T=10.0). Second, a single `<and>` token is trained on pairs of behaviors from a seen set. The student prompt uses the two behavior tokens separated by `<and>`, while the teacher uses the corresponding instructions. The loss combines the distillation KL with an orthogonality regularization that forces `<and>` to be orthogonal to all frozen behavior embeddings, preventing collapse. At inference, for any desired set of behaviors (including unseen ones), the corresponding tokens are inserted into the prompt in all possible orders, separated by `<and>` (reusing the same token for each conjunction), and generations are evaluated for constraint satisfaction. The base model remains unchanged throughout.

## Key Results

- Steering tokens achieve higher accuracy on unseen compositions: e.g., Qwen-8B: 76.9% (2-behavior) and 59.5% (3-behavior) vs instruction (71.8%, 54.0%).
- The hybrid method (tokens + instructions) further improves performance (76.3% on 2-behavior, 62.9% on 3-behavior) and reduces order variance.
- Orthogonality regularization and zero-initialization of `<and>` are critical; ablations show large performance drops without them.

## Why This Works (Mechanism)

Behavior tokens act as soft prompts that activate the model's latent knowledge about a constraint. Self-distillation transfers the semantic effect of the natural language instruction into a single token embedding. The `<and>` token, trained with orthogonality, serves as a neutral separator that allows the behavior tokens to be processed independently without interference. By modifying only the input embeddings while keeping the model frozen, the method avoids overfitting to specific combinations and leverages the model's existing ability to compose concepts, leading to strong generalization to unseen behavior sets and numbers of constraints.

## Foundational Learning

- **Self-Distillation**: Aligns a trainable token's embedding with the model's behavior when given a natural language instruction. *Why needed*: It transfers the semantic meaning of the instruction into a single token that can be inserted programmatically. *Quick check*: How does KL divergence between teacher and student distributions update the token embedding while keeping model weights fixed?
- **KL Divergence (with temperature scaling)**: The training objective that measures distributional mismatch. *Why needed*: Provides a smooth, probabilistic signal for optimizing the token embedding to replicate the teacher's next-token probabilities. *Quick check*: How does temperature T=10.0 affect the sharpness of the teacher distribution and the gradient scale?
- **Orthogonal Regularization**: A penalty term (sum of squared cosine similarities) applied to the `<and>` token against all behavior embeddings. *Why needed*: Prevents the `<and>` token from collapsing onto existing behavior vectors, ensuring it remains a distinct mediator that composes rather than overrides. *Quick check*: Why would the `<and>` token tend to collapse without orthogonality?
- **Token Embedding Space**: The input embedding matrix of the frozen LLM. *Why needed*: Steering tokens are added as special tokens to this matrix, and their values directly influence the model's initial hidden states. *Quick check*: What initialization strategy (mean of instruction tokens) helps the token start near a meaningful region?
- **Compositional Generalization**: The ability to combine learned components in novel ways. *Why needed*: The goal is to steer the model with unseen combinations of behaviors without retraining. *Quick check*: How does training `<and>` only on seen pairs still enable zero-shot composition of unseen behaviors?

## Architecture Onboarding

**Component map:** Prompt → [Behavior Token 1, `<and>`, Behavior Token 2, ...] → Frozen LLM → Generated Response. The training pipeline includes separate self-distillation modules for individual tokens and for the `<and>` token with orthogonality regularization.

**Critical path:**  
1. Train each behavior token by minimizing KL(P_teacher || P_student) with the teacher conditioned on the instruction and the student on the token.  
2. Train the `<and>` token on pairs of seen behaviors using combined distillation + orthogonality loss, freezing all behavior tokens and model weights.  
3. At inference, construct input sequences by inserting the relevant behavior tokens and `<and>` in all orders, generate responses, and evaluate constraints.

**Design tradeoffs:**  
- **Token-space vs activation steering:** Tokens are non-invasive and preserve base knowledge but are limited by the expressivity of input embeddings.  
- **Orthogonality strength:** Strong orthogonality (λ=0.5) keeps `<and>` neutral but may restrict richer interactions.  
- **Token reuse:** A single `<and>` simplifies training but might not fully capture higher-order compositions.  
- **Frozen base model:** Avoids catastrophic forgetting but relies entirely on the input representation for composition.  
- **Permutation evaluation:** Tests robustness but increases compute cost.

**Failure signatures:**  
- Large accuracy variance across token orders → insufficient orthogonality or data diversity.  
- Low accuracy on unseen compositions → `<and>` overfitted to seen pairs or misaligned behavior tokens.  
- Self-distillation loss stagnates → learning rate/temperature misconfiguration.  
- Mismatch between automatic and human evaluations → flawed constraint verifiers.

**First experiments:**  
1. Validate single-behavior token efficacy by measuring constraint satisfaction when only one token is inserted.  
2. Test `<and>` on a held-out set of seen pairs and on compositions involving unseen single behaviors to confirm generalization.  
3. Ablate orthogonality regularization (set L_orth=0) and measure the drop in unseen accuracy and increase in order variance.

## Open Questions the Paper Calls Out

1. **Scaling to frontier models:** The study covers only up to 14B parameters; it remains unclear whether steering tokens continue to benefit from scale or face new challenges in >50B models.  
2. **Beyond three behaviors:** The trajectory of compositional accuracy as more constraints are added is unknown; real applications may require many simultaneous controls.  
3. **Subjective constraints:** The method has been evaluated on verifiable properties only; steering tone, style, or politeness requires reliable human or LLM-based evaluation.  
4. **Hybrid complementarity mechanism:** Why combining tokens with instructions yields especially large gains on some model families (e.g., Llama) is not understood.  
5. **Orthogonality necessity:** Is orthogonal regularization the only effective way to ensure compositional generalization, or could alternative constraints work equally or better?

## Limitations

- Automatic constraint verification may miss subtle failures, especially for more nuanced behavioral goals.  
- Evaluation is limited to at most three simultaneous behaviors; performance for higher-order compositions is unexplored.  
- Experimental models range only up to 14B parameters, so applicability to frontier models is speculative.
