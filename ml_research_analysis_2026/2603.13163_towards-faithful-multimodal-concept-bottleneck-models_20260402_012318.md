# Towards Faithful Multimodal Concept Bottleneck Models

## Quick Facts
- arXiv ID: 2603.13163
- Source URL: https://arxiv.org/abs/2603.13163
- Reference count: 38
- Primary result: f-CBM matches black-box task accuracy (98.5% on N24News) while reducing leakage up to -97% and improving concept detection (c-RMSE -51%), demonstrating a faithful concept bottleneck.

## Executive Summary
This paper addresses the faithfulness problem in multimodal Concept Bottleneck Models (mCBMs), where inadequate concept detection and information leakage compromise interpretability. The proposed f-CBM framework integrates a CLIP-based backbone with two complementary strategies: a differentiable leakage loss that penalizes task-relevant information in concept activations, and a Kolmogorov‑Arnold Network (KAN) prediction head for enhanced expressiveness. Evaluated on the N24News dataset, f-CBM achieves state‑of‑the‑art trade‑offs, matching black‑box task accuracy (98.5%) while drastically reducing leakage (up to 97%) and improving concept detection (c‑RMSE reduction up to 51%). Intervention tests confirm the bottleneck’s fidelity: only f‑CBM’s predictions improve when ground‑truth concepts are substituted, indicating the absence of smuggled task signals.

## Method Summary
f-CBM leverages a frozen CLIP encoder to extract multimodal features from image and text inputs. These features are projected into a concept space via a linear transformation followed by a sigmoid activation, producing concept scores. To ensure faithfulness, a differentiable leakage loss based on mutual information estimation penalizes any task‑relevant information remaining in the concept activations. The concept scores are then fed into a Kolmogorov‑Arnold Network (KAN) prediction head, which replaces conventional MLP layers with spline‑based activation functions on graph edges, offering high expressiveness while retaining a relatively interpretable structure. The total loss combines the primary task loss, optional concept supervision loss (if ground‑truth concepts are available during training), and the leakage regularization term. This end‑to‑end trainable system optimizes for both performance and concept fidelity.

## Key Results
- f‑CBM attains 98.5% task accuracy on N24News, comparable to black‑box models, while reducing leakage by up to 97% and c‑RMSE by up to 51% versus prior mCBMs.
- Across multiple runs, f‑CBM consistently ranks highest when considering the trade‑off between accuracy, concept error, and leakage.
- Intervention experiments show that only f‑CBM’s accuracy increases when ground‑truth concepts replace predicted ones, indicating a faithful bottleneck free of smuggled task information.

## Why This Works (Mechanism)
The differentiable leakage loss explicitly minimizes the mutual information between concept activations and the task label, forcing the concept encoder to discard task‑specific signals and thus preserve only human‑interpretable concepts. Simultaneously, the KAN prediction head replaces a standard MLP with a network of spline‑based activation functions, which can model complex relationships from concepts to outputs while maintaining a structure that is more interpretable than deep non‑linear stacks. This combination allows f‑CBM to maintain high task performance without leaking task information into the concept layer, thereby achieving faithful interpretability.

## Foundational Learning
- **Concept Bottleneck Models (CBMs):** Decompose predictions into intermediate human‑defined concepts; needed for interpretability. Quick check: Ensure each concept is semantically meaningful and can be annotated.
- **Leakage in CBMs:** Occurs when concepts contain information about the task directly; undermines faithfulness. Quick check: Measure mutual information between concept activations and task labels; should be near zero.
- **CLIP (Contrastive Language‑Image Pretraining):** Provides aligned multimodal representations; needed to handle both image and text inputs. Quick check: Verify that frozen CLIP features correlate with downstream tasks.
- **Differentiable Leakage Loss:** Enables end‑to‑end training to minimize task‑relevant info in concepts; needed for faithfulness. Quick check: Include leakage term in loss and monitor its reduction.
- **Kolmogorov‑Arnold Networks (KANs):** Use parameterized activation functions on graph edges; needed for expressive yet interpretable mapping from concepts to outputs. Quick check: Compare KAN vs MLP in accuracy with similar parameter counts.
- **Intervention Testing:** Substitutes ground‑truth concepts to assess bottleneck fidelity; needed to confirm concepts are actually used. Quick check: Replace predicted concepts with true values and measure accuracy change.

## Architecture Onboarding
- **Component map:** CLIP backbone -> Feature projector -> Concept activation layer -> (Leakage loss computed here) -> KAN prediction head -> Task output
- **Critical path:** Forward pass from input to task prediction; backward pass propagates task loss, concept detection loss (if available), and leakage regularization.
- **Design tradeoffs:** Leakage loss weight λ balances faithfulness vs task accuracy; KAN offers expressiveness but may increase training time; freezing CLIP reduces computational cost but limits adaptation.
- **Failure signatures:** High measured leakage (mutual information), large c‑RMSE indicating poor concept detection, or significant drop in task accuracy when leakage loss is increased disproportionately.
- **First three experiments:** (1) Sweep λ to find optimal leakage‑accuracy trade‑off. (2) Replace KAN head with MLP while keeping other components fixed to isolate KAN’s contribution. (3) Perform intervention test: compare model performance with predicted concepts vs ground‑truth concepts.

## Limitations
- Evaluation limited to N24News dataset; other multimodal domains not explored.
- KAN prediction head's computational efficiency and training stability are not discussed.
- Concept detection assessed only via automated metrics (c‑RMSE); human interpretability validation missing.
