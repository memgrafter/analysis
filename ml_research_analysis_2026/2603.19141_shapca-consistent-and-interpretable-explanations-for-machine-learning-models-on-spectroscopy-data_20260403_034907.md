# SHAPCA: Consistent and Interpretable Explanations for Machine Learning Models on Spectroscopy Data

## Quick Facts
- **arXiv ID:** 2603.19141  
- **Source URL:** https://arxiv.org/abs/2603.19141  
- **Reference count:** 40  
- **Primary result:** SHAPCA improves explanation consistency for spectroscopy ML by combining Sparse PCA with SHAP, yielding stable, biologically interpretable attributions linked to known spectral features.

## Executive Summary
SHAPCA addresses a critical challenge in explaining machine learning models for spectroscopy data: high dimensionality and collinearity destabilize feature-level attributions. The method integrates Sparse Principal Component Analysis (PCA) with SHAP, first compressing spectra into sparse, orthogonal components and then computing Shapley values at the component level. These component-level explanations are back-projected to the original wavelength space using the sparse PCA loadings. Experiments on Raman (binary) and diffuse reflectance spectroscopy (DRS, multi-class) datasets demonstrate substantially improved explanation consistency—measured by cosine similarity and Pearson correlation across cross-validation folds—over baseline SHAP applied directly to raw wavelengths. The resulting explanations align with known biological chromophores, enhancing trust for clinical deployment.

## Method Summary
SHAPCA transforms raw spectra via Sparse PCA into a low-dimensional set of uncorrelated components, each driven by a sparse subset of wavelengths. A classifier (Random Forest or SVM) is trained on these component scores. SHAP values are computed per component using the model’s outputs, avoiding dilution across collinear wavelengths. For global explanations, average class SHAP values are multiplied by the absolute loadings of Sparse PCA to attribute importance to individual wavenumbers. For local explanations, an instance’s positive and negative component SHAP values are separately back-projected. The final visualization overlays this attribution (opacity) and the normalized component value (color: red=higher than class mean, blue=lower) onto the original spectrum. The pipeline is evaluated through repeated cross-validation, measuring stability (cosine/Pearson) of back-projected SHAP vectors and qualitative alignment with known spectral biomarkers.

## Key Results
- Global explanation consistency (cosine similarity) increased from 0.759 to 0.842 (Raman, PML class) and from 0.640 to 0.993 (DRS, BoneMarrow class) compared to baseline SHAP.
- Local consistency improved, with SHAPCA achieving 0.982 cosine on DRS vs. 0.691 for SHAP.
- Back-projected explanations correspond to biologically meaningful spectral bands (e.g., lipid absorption near 1200 nm and hemoglobin dips near 450 nm).

## Why This Works (Mechanism)

1. **Sparse PCA reduces dimensionality and collinearity**  
   Sparse PCA imposes an L1 penalty on component loadings, forcing many to zero. This yields components that each depend on a limited number of contiguous wavelengths, grouping correlated spectral regions into orthogonal factors. The sparsity prevents attribution smearing and the orthogonality stabilizes downstream SHAP computation. Break condition: excessive sparsity (high α) may discard predictive signal, harming accuracy.

2. **Component-level SHAP improves stability**  
   SHAP values are computed on the uncorrelated component scores rather than on the original, highly collinear wavelengths. Each component’s Shapley value aggregates the joint contribution of a coherent spectral region, avoiding dilution across many interdependent features. This yields more consistent attributions across model retrainings. Break condition: if sparse components fail to capture relevant variance (poor sparsity-accuracy trade-off), component-level explanations become unstable.

3. **Back-projection links explanations to original bands**  
   Component-level SHAP values are mapped back to wavenumbers by multiplying by the absolute Sparse PCA loadings. This ensures only wavelengths that contribute to a component receive attribution. For global explanations, mean class SHAP is used; for local explanations, positive and negative SHAP contributions are separated. The absolute loading prevents sign cancellation and highlights contiguous regions. Break condition: if loadings are not sufficiently sparse, back-projected attributions spread across many wavelengths, reducing interpretability.

- **Sparse Principal Component Analysis**: Applies L1 regularization to PCA, yielding sparse loadings that select a subset of wavelengths per component while maintaining orthogonality. *Why needed*: Provides the compact, uncorrelated representation that enables stable latent-space explanation. *Quick check*: How does an L1 penalty in Sparse PCA differ from standard PCA, and why does this matter for interpretability?
- **Shapley Values and SHAP**: A game-theoretic framework assigning each feature a contribution to the model output, with desirable properties like consistency and local accuracy. *Why needed*: SHAP supplies the attribution method applied at the component level. *Quick check*: Why are SHAP values computed on model outputs considered more reliable for aggregation than gradient-based saliency maps?

## Architecture Onboarding
- **Component map**: Input spectrum -> Sparse PCA transformation -> Component scores -> Classifier prediction -> SHAP computation (component-level) -> Back-projection using absolute loadings -> Visualized explanation (opacity + color) on original spectrum.
- **Critical path**: Fit Sparse PCA on training data → Train classifier on PC scores → Compute SHAP with TreeExplainer (RF) or KernelExplainer (SVC) using training PC distribution as background → Back-project SHAP using stored absolute loadings → Evaluate consistency on fixed test set across multiple CV folds.
- **Design tradeoffs**:  
  - *Sparsity (α) vs. accuracy*: Higher α yields sparser, more interpretable components but may lose predictive signal; requires joint tuning with classifier.  
  - *Classifier choice*: Random Forest with TreeExplainer is efficient and stable; SVM with KernelExplainer is slower and noisier.  
  - *Absolute loadings*: Ensures non-negative attribution but discards sign information from loadings.
- **Failure signatures**:  
  - Low consistency scores (cosine/Pearson) across CV folds compared to baseline SHAP.  
  - Back-projected global explanations that fail to highlight known biochemical peaks (e.g., missing lipid bands at ~1200 nm in DRS).  
  - Sparse PCA components with excessive non-zero loadings, leading to smeared attribution.
- **First 3 experiments**:  
  1. Reproduce consistency metrics: Implement 5-fold CV with patient-level splits (Raman) or stratified splits (DRS); compute average pairwise cosine and Pearson for global/local back-projected SHAP vectors on a fixed test set; verify SHAPCA outperforms baseline SHAP.  
  2. Biological validation: For DRS BoneMarrow class, confirm top contributing wavelengths include ~1200 nm and ~1700 nm (lipid absorption); for Cortical Bone, include ~450 nm (hemoglobin dip).  
  3. Sensitivity to sparsity: Vary Sparse PCA α (e.g., 0.1, 0.5, 1, 2); plot consistency scores and test accuracy; identify α that maintains >95% of max accuracy while maximizing sparsity and consistency.

## Open Questions the Paper Calls Out
- How does the choice of dimensionality-reduction technique (e.g., NMF, autoencoders) affect SHAPCA's explanation consistency and interpretability compared to Sparse PCA?
- Can SHAPCA maintain explanation consistency when applied to longitudinal spectroscopic datasets with repeated measurements over time?
- How can SHAPCA be extended to multimodal spectroscopic data (e.g., combining Raman and infrared) to produce unified, consistent explanations across modalities?
- To what extent does SHAPCA's improvement in explanation consistency generalize to other 1-D signal classification tasks beyond spectroscopy (e.g., audio, EEG)?
- What is the optimal sparsity parameter α in Sparse PCA for SHAPCA to balance explanation sparsity, predictive accuracy, and stability across varying spectroscopy datasets?

## Limitations
- Dataset access uncertain: cited datasets [19] and [15] lack public download links, hindering reproduction.
- Incomplete hyperparameter reporting: exact final settings for Random Forest and SVM are not provided, only tuning ranges.
- Sparse PCA implementation ambiguity: differences in objective or solver across libraries (e.g., sklearn’s SparsePCA) may affect sparsity and orthogonality.
