# Reliable News or Propagandist News? A Neurosymbolic Model Using Genre, Topic, and Persuasion Techniques to Improve Robustness in Classification

## Quick Facts
- **arXiv ID:** 2604.01936
- **Source URL:** https://arxiv.org/abs/2604.01936
- **Reference count:** 0
- **Primary result:** A neurosymbolic model combining fastText embeddings with genre, topic, and persuasion technique features improves robustness in propagandist news detection, achieving average gains of 26.89% in accuracy and 41.85% in F1-score over text-only baselines on distribution-shifted test splits.

## Executive Summary
The paper tackles overfitting in propagandist news detection by language models due to dataset biases. It introduces a neurosymbolic hybrid model that fuses fastText text embeddings with symbolic features—genre, topic, and persuasion techniques—via a simple perceptron. Evaluated on biased data splits (Sources, Political, Credibility) from Ukraine-conflict corpora, the hybrid method significantly outperforms text-only baselines, maintaining robust generalization where text-only models fail completely (F1=0 on Sources/Credibility splits). Ablation studies and SHAP analysis confirm the individual contribution of each symbolic feature and the model’s reliance on them under distribution shifts.

## Method Summary
The hybrid model processes each news article through three parallel extractors: a fastText embedding module (300D), a GATE Cloud API for genre (3-class one-hot) and topic (9-class one-hot), and a persuasion technique counter (23 fine-grained or 6 coarse-grained counts). These are concatenated into a 335D vector and fed into a two-layer perceptron (335→335 ReLU →1 sigmoid) for binary classification. The model is trained with Adam (lr=1e-4), cross-entropy loss, and weighted sampling to handle class imbalance. Evaluation uses four splits: Random (standard), Sources (unseen outlets), Political (unseen leanings), and Credibility (unseen credibility labels), all derived from English subsets of the PPN propaganda corpus and MAINSTREAM reliable corpus.

## Key Results
- The hybrid model achieves average improvements of 26.89% in accuracy and 41.85% in F1-score over text-only baselines across Sources, Political, and Credibility splits.
- Text-only models collapse (F1=0) on Sources and Credibility splits, while the hybrid maintains robust performance (F1 up to 88.37%).
- Ablation shows each symbolic feature (genre, topic, persuasion) contributes to robustness; fine-grained persuasion techniques particularly help on biased splits, and SHAP analysis confirms conceptual features dominate predictions under distribution shift.

## Why This Works (Mechanism)

**Mechanism 1: Genre and Topic Distributions Mitigate Lexical Overfitting**  
- **Claim:** Incorporating genre and topic reduces overfitting to lexical artifacts by providing stable, corpus-agnostic signals.  
- **Mechanism:** One-hot encoded genre (Reporting/Opinion/Satire) and topic (9 categories) capture high-level structural properties less correlated with transient word choices than fastText embeddings, decorrelating predictions from spurious lexical patterns tied to specific sources.  
- **Evidence:** In-corpus analysis shows systematic genre/topic differences between propaganda and reliable news (e.g., propaganda over-represents Opinion). Ablation removing these features degrades robustness.  
- **Break condition:** If genre/topic mappings become source-specific or rapidly evolve, these features become new artifacts.

**Mechanism 2: Persuasion Techniques as Robust Propaganda Signals**  
- **Claim:** Persuasion techniques provide a direct, interpretable signal for propaganda that is orthogonal to topic and genre.  
- **Mechanism:** Counts of 23 fine-grained persuasion techniques (e.g., loaded language) capture rhetorical strategies associated with influence operations, helping the model focus on manipulative patterns rather than topic-specific vocabulary.  
- **Evidence:** Propaganda articles use more techniques (e.g., loaded language, repetition). SHAP shows persuasion features contribute highly on Credibility split where lexical signals fail. Fine-grained techniques outperform coarse-grained in ablation.  
- **Break condition:** If technique annotations are biased/inconsistent or propagandists adapt to avoid detectable patterns, signal degrades.

**Mechanism 3: Simple Perceptron Fusion Enforces Robustness**  
- **Claim:** A simple perceptron effectively integrates disparate features without overcomplicating, preserving robustness.  
- **Mechanism:** Concatenating fastText (300D) and symbolic (35D) vectors into a two-layer MLP (335→335→1) prevents the neural component from learning complex, dataset-specific interactions that could overfit, forcing reliance on cleaner symbolic signals when lexical patterns are non-predictive.  
- **Evidence:** Text-only model fails catastrophically on Sources/Credibility splits (F1=0), while hybrid learns; simplicity is chosen for explainability (SHAP).  
- **Break condition:** If the relationship between symbolic features and label is highly non-linear or involves complex interactions with lexical semantics, the perceptron’s capacity may be insufficient, limiting peak performance on in-distribution data.

## Architecture Onboarding
- **Component map:** Text → [fastText embedder, Genre/Topic extractor (GATE Cloud API), Persuasion extractor (GATE Cloud API)] → Concatenation (300D + 35D = 335D) → Two-layer Perceptron (335→335 ReLU →1 sigmoid) → Prediction  
- **Critical path:** Same as above; bottleneck is external API calls for symbolic features.  
- **Design tradeoffs:**  
  - *Simplicity vs. expressiveness:* Simple perceptron aids explainability and robustness but may underfit on in-distribution data.  
  - *Feature granularity:* Fine-grained (23) persuasion techniques improve robustness but require reliable annotation; coarse (6) is more robust to noise.  
  - *Embedding choice:* fastText is stable/fast but lacks context; BERT would be powerful but likely overfit on biased splits.  
- **Failure signatures:**  
  - Catastrophic drop on Sources/Credibility splits (F1=0 for Text Only) indicates reliance on spurious lexical correlations.  
  - Poor performance on Political split despite Hybrid suggests lack of political diversity in training.  
  - High variance in SHAP values for text embeddings on biased splits indicates instability of lexical signal.  
- **First 3 experiments:**  
  1. Baseline replication: Train Text Only (fastText + Perceptron) on Random split; expect ~79% Acc, 88% F1.  
  2. Robustness stress test: Train Hybrid on Random split, evaluate on Sources split; expect significant drop from Random but non-zero F1 (vs. 0 for Text Only).  
  3. Ablation validation: Compare Hybrid (fine-grained persuasion) vs. Hybrid Lite (coarse-grained) across splits; confirm fine-grained helps on Sources/Credibility.

## Limitations
- **External dependency risk:** MAINSTREAM corpus accessibility unclear; GATE Cloud API specifics undocumented.  
- **Domain confinement:** Evaluation only on Ukraine-conflict news; claims of robust generalization lack evidence from other topics or regions.  
- **Annotation pipeline opacity:** Persuasion technique extraction relies on third-party tool without reported inter-annotator agreement; potential biases unexamined.

## Confidence
- Mechanism 1 (Genre/Topic stability): Medium  
- Mechanism 2 (Persuasion techniques): Medium-Low  
- Mechanism 3 (Simple perceptron): Medium  
- Overall robustness within studied splits: High  
- Overall robustness out-of-domain: Low
