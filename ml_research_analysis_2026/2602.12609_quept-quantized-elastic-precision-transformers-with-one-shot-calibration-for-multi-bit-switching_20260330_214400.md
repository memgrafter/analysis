# QuEPT: Quantized Elastic Precision Transformers with One-Shot Calibration for Multi-Bit Switching

## Quick Facts
- **arXiv ID:** 2602.12609  
- **Source URL:** https://arxiv.org/abs/2602.12609  
- **Reference count:** 8  
- **Primary result:** Enables real-time bit-width switching for Transformers with one-shot calibration, matching or exceeding SOTA PTQ methods (e.g., +6.2% ImageNet accuracy over ERQ on ViT-S W4A4).

## Executive Summary
QuEPT introduces a post-training quantization framework for Transformer-based models that supports elastic precision—deployment at multiple bit-widths—without repeated optimization. It achieves this through a single calibration pass using two key components: Multi-Bit Token Merging (MB-ToMe), which balances robustness across bit-widths by selectively preserving high-precision tokens and fusing others, and Multi-Bit Cascaded Low-Rank Adapters (MB-CLoRA), which shares LoRA parameters hierarchically across bit-width groups to enhance correlation. Experiments on Vision Transformers, LLMs, and MLLMs show QuEPT attains state-of-the-art accuracy while drastically reducing training overhead.

## Method Summary
QuEPT performs one-shot, block-wise reconstruction on a small calibration dataset. For each transformer block, it initializes learnable clipping parameters (α, β) and a shared cascaded LoRA (A, B). The input to a block is the MB-ToMe merged output from the previous block: token-wise cosine similarity between high-bit and low-bit activations determines which tokens are preserved (top *p%*) and which are fused (λ₁X_H + λ₂X_M + λ₃X_L). During training, one bit-width is sampled from each predefined tier (low/mid/high); the quantized block output (using the corresponding LoRA slice and clipping) is compared to the full-precision block output via MAE loss. Gradients update only the used LoRA slices and the sampled α, β. After all blocks are processed, the frozen weights and learned parameters allow any predefined bit-width (uniform or mixed) to be selected at inference without retraining.

## Key Results
- ViT-S W4A4: +6.2% higher ImageNet accuracy than ERQ.
- LLaMA2-7B W4A4: +7.07% better average zero-shot accuracy than QuaRot.
- LLaVA-OneVision mixed precision: +1.5–4.3% higher average accuracy than MBQ.
- Training time reduced to 1/26 of PTMQ's overhead on ViT-B while supporting real-time bit-width switching.

## Why This Works (Mechanism)

### Mechanism 1: Multi-Bit Token Merging (MB-ToMe) for Balanced Robustness
**Claim:** MB-ToMe preserves token features with high similarity between high-bit and low-bit quantized activations, while fusing less similar tokens to stabilize multi-bit optimization and prevent any single bit-width from dominating the loss.
**Mechanism:** For a block’s input, token-wise cosine similarity between 8-bit and 4-bit representations is computed. Tokens in the top *p%* are kept in high precision; the rest are merged via weighted average (λ₁, λ₂, λ₃) of high/mid/low-bit features. This merged map `X'ₖ` feeds the next block.
**Core assumption:** Token similarity between high- and low-bit activations indicates inherent quantization robustness; preserving these anchors stabilizes training, while fusion smooths the feature distribution.
**Evidence anchors:** [abstract] mentions selective preservation and fusion; [section "Multi-Bit Token Merging (MB-ToMe)"] formalizes Equation 6 and shows selective merge (Case 3) empirically best.
**Break condition:** If token similarity does not correlate with actual task accuracy for a given architecture/dataset, selective preservation may discard critical information or retain noise, degrading multi-bit performance.

### Mechanism 2: Multi-Bit Cascaded Low-Rank Adapters (MB-CLoRA) for Synergistic Parameter Sharing
**Claim:** MB-CLoRA structures LoRA parameters in a cascaded hierarchy (RH ⊆ RM ⊆ RL) so that gradients from higher-bit optimization inform lower-bit adaptation, exploiting correlated error correction needs across bit-widths.
**Mechanism:** A single pair of matrices (A, B) is learned. Effective rank `r_b` for bit-width `b` sums ranks of its tier and all higher tiers (Equation 8). During training, one bit-width per tier is sampled; the shared A, B are optimized sequentially per sample using reconstruction loss (Equation 9), with cascaded structure ensuring high-bit parameters are available to low-bit configurations.
**Core assumption:** The error correction needed for a lower bit-width is a superset or highly correlated with that for a higher bit-width.
**Evidence anchors:** [abstract] describes hierarchical sharing; [section "Multi-Bit Cascaded LoRA (MB-CLoRA)"] details cascaded rank and objective.
**Break condition:** If error surfaces for different bit-widths are misaligned, cascaded sharing forces sub-optimal compromises, potentially harming high-bit accuracy more than independent LoRAs.

### Mechanism 3: One-Shot Block-Wise Reconstruction with Mixed-Precision Exposure
**Claim:** A single calibration pass on a small data slice can optimize a model for any predefined bit-width (uniform or mixed) by exposing each block to reconstruction losses from multiple bit-widths simultaneously.
**Mechanism:** Calibration proceeds block-by-block. For each block, clipping parameters and cascaded LoRA are initialized. The block input is the MB-ToMe merged output from the previous block. In each step, one bit-width per tier is sampled; the quantized block output (using corresponding LoRA slice and clipping) is compared to full-precision output via MAE. Gradients update only the active LoRA slice and clipping parameters. After training, selection of `R(b)`, `α_b`, `β_b` at inference enables any bit-width.
**Core assumption:** The optimal correction for a block’s quantized behavior is consistent enough across bit-widths that a single parameter set, optimized on mixed-bit losses, generalizes to any individual bit-width without retraining.
**Evidence anchors:** [abstract] states one-shot calibration and dynamic adaptation; [section "The Pipeline of QuEPT"] describes block-wise reconstruction and tiered sampling.
**Break condition:** If the calibration data slice is not representative, the single-pass optimization may overfit to slice-specific noise, leading to poor generalization. The method also assumes block-wise error reconstruction independence, which may not hold for highly dependent layers.

## Foundational Learning
- **Post-Training Quantization (PTQ):** Calibrates a pretrained model to low precision using a small dataset, determining scale/zero-point and optionally optimizing layer parameters to reduce accuracy loss. *Why needed:* QuEPT is a PTQ method; understanding the standard calibration and potential reconstruction steps is essential. *Quick check:* What is the primary difference between Quantization-Aware Training (QAT) and PTQ in terms of data and computational requirements?
- **Low-Rank Adaptation (LoRA):** Freezes original weight matrix `W` and learns a low-rank decomposition `BA` (`B ∈ ℝᵖˣʳ, A ∈ ℝʳˣq`) to approximate weight updates, with `W + BA` used at inference. *Why needed:* MB-CLoRA builds on LoRA to compensate for quantization error. *Quick check:* In standard LoRA for LLM fine-tuning, what are typical ranks (`r`) relative to original weight dimensions (`p, q`), and why is low-rank sufficient?
- **Token Merging in Vision Transformers:** Techniques like ToMe merge image patch tokens to reduce sequence length and computation. *Why needed:* MB-ToMe adapts this concept to merge features from different quantization states rather than reduce token count. *Quick check:* How does token merging typically decide which tokens to merge, and what is the trade-off between efficiency and accuracy?
- **Elastic Precision Quantization:** Enables a single quantized model to support multiple bit-widths at inference without retraining per bit-width. *Why needed:* QuEPT’s core goal is elastic precision; understanding prior work (e.g., MatGPTQ, MoBiQuant) provides context. *Quick check:* What are the main challenges in making a PTQ model elastic across bit-widths?

## Architecture Onboarding
**Component map:**  
Calibration Data -> Block-wise Reconstruction Loop -> MB-ToMe Module -> Quantization Engine -> MB-CLoRA Parameter Bank -> Loss & Optimizer -> Inference Selector.  
The loop iterates over all transformer blocks; MB-ToMe merges outputs from the previous block; Quantization Engine applies clipping and quantization using LoRA slice; Loss/optimizer updates shared A,B and α,β; Inference Selector chooses parameters for desired bit-width.

**Critical path:** `Calibration Data -> [MB-ToMe -> Block (Quantization + MB-CLoRA)]` repeated for each block. The key is that MB-ToMe’s merged output serves as the common input for all sampled bit-widths’ forward passes within the next block, forcing co-adaptation. Cascaded LoRA slicing enables single-pass learning across bit-widths.

**Design tradeoffs:**  
1. **MB-ToMe preserve % (p):** Higher `p` retains more high-bit info but reduces fusion effect; lower `p` increases smoothing but risks losing details.  
2. **LoRA rank allocation (r_h, r_m, r_l):** Fixed total rank; allocating more to `r_l` helps low-bit accuracy but may harm high-bit (Table 4).  
3. **Loss function:** MAE generally superior to MSE for robustness to outlier errors common in low-bit quantization (Table 6).  
4. **Calibration data size:** Small data (128–1024 samples) is efficient but risks overfitting due to one-shot optimization.

**Failure signatures:**  
1. **Catastrophic low-bit accuracy drop:** If `r_l` too small or MB-ToMe fusion too aggressive, W4A4 accuracy collapses.  
2. **High-bit performance regression:** Cascaded sharing may force sub-optimal LoRA for high bits if `r_h` insufficient (Table 6).  
3. **Instability in block-wise reconstruction:** Overmerged `X'` becomes a poor proxy for true next-block input, causing error accumulation.  
4. **Failure on outlier-heavy models:** Without explicit outlier handling (unlike QuaRot), extreme values in LLMs may cause high perplexity.

**First 3 experiments:**  
1. **Ablation 1 (MB-ToMe Cases):** Compare Random Select, Uniform Fusion, and Selective Merge on ViT-S (ImageNet) and LLaMA2-7B (0-shot avg). Expected: Selective Merge wins, validating similarity-guided selection.  
2. **Ablation 2 (MB-CLoRA vs. Baselines):** Test "Fully Shared" (same LoRA all bits), "Independent" (separate LoRA per tier), and "MB-CLoRA" with fixed total rank. Expected: MB-CLoRA best balances low-bit gains with minimal high-bit cost.  
3. **Module Combination Ablation:** Add components (Clip opt, MB-CLoRA, MB-ToMe, MAE loss) incrementally to baseline on ViT-S. Expected: Each adds gain; full combination achieves best multi-bit accuracy.

## Limitations
- **Hyperparameter gaps:** Critical values (MB-ToMe preserve % `p`, fusion weights λ, MB-CLoRA rank splits) are undisclosed, hindering exact reproduction.
- **Outlier handling:** No explicit mechanism for extreme activation/weight outliers; may degrade LLM accuracy without ad-hoc fixes like rotation.
- **Data dependence:** One-shot calibration assumes a single small, representative data slice suffices; performance may brittlely degrade with non-iid deployment data.

## Confidence
- **MB-ToMe mechanism:** *Medium* – Selective merge ablation shows benefit, but core assumption (cosine similarity → robustness) lacks external validation; risk of architecture/dataset-specific failure.
- **MB-CLoRA mechanism:** *Medium* – Cascaded sharing improves low-bit accuracy, but slight high-bit regression indicates imperfect correlation; universality across layers unproven.
- **One-shot reconstruction:** *Low* – Efficiency gains clear, but reliance on single-pass optimization makes it fragile to calibration data choice; no theoretical guarantee of block-wise independence.

## Next Checks
1. **MB-ToMe sensitivity sweep:** Systematically vary `p` (0.1–0.9) and λ ratios on ViT-B/LLaMA2-7B across multiple calibration datasets; measure correlation between token similarity and per-token quantization error.
2. **MB-CLoRA rank allocation study:** With fixed total rank, test extreme splits (e.g., `r_l`=90% total) on layers with varying sensitivity; track accuracy delta per bit-width to map where hierarchical sharing helps or harms.
3. **One-shot calibration robustness:** Evaluate QuEPT’s accuracy variance when calibration data is biased (e.g., only 10% of classes for ViT, only literary text for LLM) vs. random slice; use out-of-distribution data to quantify failure modes.
