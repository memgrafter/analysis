# CATNIP: LLM Unlearning via Calibrated and Tokenized Negative Preference Alignment

## Quick Facts
- arXiv ID: 2602.02824
- Source URL: https://arxiv.org/abs/2602.02824
- Reference count: 40
- Primary result: CATNIP achieves state-of-the-art forgetting-utility tradeoffs on MUSE and WMDP benchmarks without retention data or contrastive pairs, e.g., on WMDP Cyber (Zephyr 7Bβ) it reduces hazardous knowledge accuracy from 44.0 to 28.69 while preserving MMLU (58.10→53.01), yielding the highest overall quality shift (10.22) among retention-free methods.

## Executive Summary
Large language models (LLMs) often retain undesirable or harmful knowledge, necessitating effective unlearning. Existing unlearning methods either degrade model utility (e.g., gradient ascent) or rely on static reference models and suffer from length bias (e.g., negative preference optimization). CATNIP introduces calibrated and tokenized negative preference alignment to address these issues. It employs an adaptive reference policy (1−πθ) that scales gradients by token-level confidence, and applies loss at the token level to eliminate sequence length bias. Evaluated on MUSE (Harry Potter removal) and WMDP (hazardous knowledge suppression), CATNIP achieves superior forgetting-utility tradeoffs without requiring retention data or contrastive pairs, setting new state-of-the-art among retention-free approaches.

## Method Summary
CATNIP tackles LLM unlearning without requiring retention data or contrastive pairs by reformulating it as negative preference alignment. It introduces an adaptive reference policy, defined as one minus the current model’s token probabilities (1−π̂θ), which is kept frozen and serves to calibrate gradient scaling. The unlearning loss is applied at the token level: each token’s contribution is computed as −log(1−σ(β log(πθ(y_i|x,y<i)/(1−π̂θ(y_i|x,y<i)))) and then averaged across the sequence. This per-token design eliminates length bias and amplifies updates on high-confidence tokens, focusing on the most indicative undesirable content. Training minimizes this loss on the forget set only, updating the target model while preserving general capabilities.

## Key Results
- On WMDP Cyber (Zephyr 7Bβ): hazardous knowledge accuracy drops from 44.0 to 28.69, MMLU declines from 58.10 to 53.01, achieving ΔO=10.22 (best among retention-free methods).
- On Harry Potter (Llama3.2-3B): memorization (ROUGE-L) decreases from 39.99 to 2.29 with an 8.28-point MMLU drop.
- CATNIP outperforms baselines (NPO, SimNPO, GA, FLAT) in forgetting-utility tradeoff across both benchmarks.

## Why This Works (Mechanism)
### Mechanism 1: Adaptive Reference Policy Calibrates Gradient Updates
The loss uses an adaptive reference (1−π̂θ) that scales gradient updates proportionally to the target model’s token-level confidence on forget data. The rescaling factor 1/(1−πθ(yi|x,y<i)) becomes large when πθ assigns high probability to a token, amplifying the gradient for that token. This focuses unlearning pressure on tokens the model is most confident about, assuming confidence correlates with undesirable knowledge. Evidence includes ablations showing that a static reference (CATNIPref) underperforms CATNIP. If the model’s initial confidence on undesirable tokens is low or misaligned, calibration may misdirect unlearning.

### Mechanism 2: Token-Level Loss Aggregation Eliminates Length Bias
Instead of aggregating loss over entire sequences, CATNIP sums token-level contributions and averages them uniformly. This ensures each token contributes equally, preventing long responses from dominating gradient updates. The method treats each conditional token generation as an independent sample. Evidence: CATNIP maintains effectiveness on short QA data where sequence-level methods (NPO, SimNPO) degrade. A non-tokenized variant (CATNIP w/o CAT) shows worse forgetting, confirming the benefit.

### Mechanism 3: Combined Design Enables Retention-Free Unlearning
Tokenization provides many optimization steps from few samples, while the adaptive reference focuses updates on high-confidence tokens. Together they minimize unnecessary perturbations on uncertain or benign tokens, allowing effective unlearning without retention data. This addresses the core challenge of avoiding catastrophic forgetting. Evidence: CATNIP achieves the best ΔO (forgetting-utility tradeoff) among retention-free methods on both MUSE and WMDP, even with very small forget sets (e.g., 132 QA pairs).

## Foundational Learning
### Concept: Preference Optimization (DPO/NPO)
- Why needed here: CATNIP builds on the DPO framework, using a ratio-based loss to align the policy away from undesirable outputs. Understanding the role of the reference model in DPO and its static nature in NPO is key to appreciating CATNIP’s adaptive reference.

### Concept: Gradient Ascent (GA) for Unlearning
- Why needed here: GA (increasing loss on forget data) is the simplest baseline that CATNIP improves upon. GA’s uniform loss increase causes catastrophic forgetting, motivating CATNIP’s calibrated per-token weighting.
- Quick check: Why does applying gradient ascent directly on forget data degrade performance on unrelated tasks?

### Concept: Token-Level Loss Aggregation in LLMs
- Why needed here: LLM sequence probabilities factor into token log-probabilities; aggregating at the token level vs. sequence level determines how gradients scale with response length. This underpins CATNIP’s length-bias elimination.
- Quick check: How does the total gradient from a sequence-level loss L = log π(y|x) depend on the length of y?

## Architecture Onboarding
### Component Map
Forget dataset D -> Tokenization module splits y into tokens -> For each token i: compute πθ(yi|x,y<i) and reference 1-π̂θ(yi|x,y<i) (frozen) -> ratio r_i = πθ/π̂ -> compute u_i = β log r_i -> token loss L_i = -log(1-σ(u_i)) -> average L_i over tokens in sequence -> backpropagate to update πθ

### Critical Path
1. Sample a forget pair (x,y) from D.
2. Tokenize y into tokens y1,...,y|y|.
3. For each token i (optionally subsampling): get token probability from πθ given context (x, y< i).
4. Compute reference probability as (1 - π̂θ(yi|x,y<i)), where π̂θ is a frozen copy (or detach).
5. Calculate u_i = β * (log πθ - log(1-π̂θ)).
6. Compute L_i = -log(1 - σ(u_i)).
7. Average L_i over tokens to get L_seq.
8. Backpropagate L_seq to update parameters of πθ.

### Design Tradeoffs
- β (inverse temperature): Higher β increases gradient magnitude on high-confidence tokens, improving forgetting but risking utility drop. Requires tuning.
- Token subsampling: Sampling every k-th token (e.g., 16) reduces compute but may omit key tokens.
- Adaptive reference update: Using a static snapshot vs. a continuously moving target (detached each step) affects scaling stability and overhead.

### Failure Signatures
- Minimal forgetting: Check that weight w_i grows with πθ(yi|...); if not, verify reference is 1-πθ and not clipped.
- Utility collapse (large MMLU drop): Reduce β or epochs; ensure loss averaging is correct.
- Instability on short sequences: Ensure tokenization boundaries are correct and no empty token gradients.

## Open Questions the Paper Calls Out
### Open Question 1: Generalization to larger models
The paper evaluates only 7B/8B parameter models due to budget constraints. It remains unknown whether CATNIP’s forgetting-utility tradeoff scales to larger models (13B, 34B, 70B+).

### Open Question 2: Minimizing utility degradation further
Although CATNIP improves the tradeoff, it still causes non-zero utility loss. How can we further preserve general knowledge while unlearning? Possible directions include hybrid objectives or indirect retention signals.

### Open Question 3: Optimal token importance proxy
CATNIP uses token probability as a proxy for knowledge importance. Is this the best metric, or could alternatives (gradient magnitude, attention entropy) yield better tradeoffs?

## Limitations
- Incomplete reporting: missing training details (batch size, optimizer settings, scheduler) hampers exact replication.
- Dataset opacity: exact QA pairs, extended MUSE content, and truncation rules are not released, limiting reproducibility.
- Limited model scope: experiments restricted to Llama3.2-3B and Zephyr-7Bβ; performance on other architectures is unknown.
- Potential over-forgetting: requires careful β tuning; high confidence on undesirable tokens may still suppress benign knowledge.
