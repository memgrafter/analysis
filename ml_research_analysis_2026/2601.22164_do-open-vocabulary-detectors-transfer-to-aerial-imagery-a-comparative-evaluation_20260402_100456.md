# Do Open-Vocabulary Detectors Transfer to Aerial Imagery? A Comparative Evaluation

## Quick Facts
- **ArXiv ID:** 2601.22164  
- **Source URL:** https://arxiv.org/abs/2601.22164  
- **Reference Count:** 31  
- **Primary Result:** Off-the-shelf open-vocabulary detectors fail on aerial data (best F1 27.6%, 69% false positives); semantic confusion is the dominant bottleneck.

## Executive Summary
Open-vocabulary object detectors (OVDs) promise flexible, zero-shot detection of any object category via image–text alignment. This study evaluates whether five state-of-the-art OVDs—Grounding DINO, OWLv2, YOLO-World, YOLO-E, and LLMDet—can directly transfer to aerial imagery without adaptation. Using the LAE-80C dataset (3,592 images, 80 classes), the authors isolate the performance bottleneck by contrasting full-vocabulary (Global) inference with Oracle modes that limit the vocabulary to only ground-truth classes per image (average 3.2). Results show catastrophic failure: the best model (OWLv2) attains only 27.6% F1-score with a 69% false positive rate. However, Oracle mode yields a 15× F1 boost for Grounding DINO, pinpointing semantic confusion as the primary bottleneck. Prompt engineering (e.g., “aerial view of”) offers no meaningful gains, and performance varies widely across aerial datasets (LLMDet: F1 0.53 on DIOR vs. 0.12 on FAIR1M), exposing brittleness to scale and density. The findings indicate that off-the-shelf OVDs are not ready for aerial deployment and require domain-specific adaptation.

## Method Summary
The evaluation uses five pre-trained open-vocabulary detectors (all trained on natural images only) tested on the LAE-80C aerial dataset. Inference is performed in three modes: Global (prompt with all 80 classes), Oracle (prompt only the ground-truth classes for each image), and Single‑Category Oracle. Metrics include F1, Precision, and Recall with an Intersection‑over‑Area threshold of 0.7 and standard confidence thresholds. Prompt engineering strategies (domain prefix “Aerial view of”, synonym expansion) are ablated. All models use their default processors and post‑processing (class‑wise NMS). The design isolates the bottleneck by comparing Global and Oracle performance, which differ only in vocabulary size.

## Key Results
- Best model (OWLv2) achieves only 27.6% F1-score with a 69% false positive rate in Global mode.
- Reducing vocabulary from 80 to an average of 3.2 classes (Oracle) yields a 15× F1 improvement (e.g., Grounding DINO).
- Prompt engineering (domain prefixes, synonyms) provides no meaningful gains; performance varies drastically across aerial datasets (LLMDet F1: 0.53 on DIOR vs. 0.12 on FAIR1M).

## Why This Works (Mechanism)

### Prompt Engineering Fails Due to Architectural Mismatch
The visual encoders of OVDs are pretrained on ground‑level imagery and learn to recognize objects via canonical side‑view features (e.g., car wheels, building facades). Aerial nadir views lack these features, creating a fundamental mismatch. Text prompts only influence the final cross‑modal matching and cannot regenerate the missing low‑level visual representations. Evidence: the paper reports that prompt engineering (domain prefixes, synonym expansion) yields no meaningful gains (abstract) and explicitly states that “the domain gap is architectural, not lexical” (Section V).

### Semantic Confusion from Oversized Vocabulary
When the model processes a large number (80) of class tokens simultaneously, its cross‑attention mechanism diffuses across semantically similar categories (e.g., “vehicle”, “car”, “truck”), preventing confident grounding even if visual features are correctly extracted. This attention diffusion collapses performance in Global mode. Evidence: reducing the vocabulary to an average of 3.2 classes (Oracle) improves F1‑score by 15× for Grounding DINO (abstract, Section IV.C.1), directly implicating semantic confusion as the dominant bottleneck.

### Brittleness Across Aerial Conditions
The models fail to generalize across varying aerial imaging conditions (object density, scale, orientation) because their pretrained visual representations lack invariances to such operational extremes. A model calibrated on moderate‑density, oriented objects (DIOR) collapses on densely packed, small objects (FAIR1M, xView). Evidence: LLMDet’s F1 ranges from 0.53 on DIOR to 0.12 on FAIR1M; the authors note sharp declines when transitioning to these datasets (abstract, Section IV.D). This brittleness highlights that VLMs trained on natural images do not encode robustness to aerial variations.

## Foundational Learning
- **Concept: Vision‑Language Model (VLM) Pretraining**  
  *Why needed here:* All evaluated detectors rely on CLIP‑style alignment; understanding that open‑vocabulary capability stems from a shared image‑text embedding space—not explicit category training—is critical.  
  *Quick check:* Why does a VLM trained on web images struggle to match “aerial view of a car” with a top‑down image of a vehicle?

- **Concept: Transformer Cross‑Attention Bottleneck**  
  *Why needed here:* The 15× performance gap between Global and Oracle modes directly implicates the decoder’s attention mechanism as the site of semantic confusion failure.  
  *Quick check:* If you increase the number of text tokens in a DETR‑style decoder without changing model size, what happens to per‑token attention strength and detection confidence?

- **Concept: Aerial Imagery Taxonomies**  
  *Why needed here:* LAE‑80C’s hierarchical and attribute‑dependent classes (e.g., “working chimney”) create a uniquely challenging semantic landscape that natural‑image VLMs are not exposed to.  
  *Quick check:* How does distinguishing “liquid cargo ship” vs. “oil tanker” differ semantically from distinguishing “dog” vs. “cat” for a VLM?

## Architecture Onboarding
- **Component map:** Image and text → Input Processor → Visual Backbone (image features) & Text Encoder (text features) → Cross‑Modal Fusion (transformer decoder with cross‑attention) → Prediction Head (box and class scores) → Post‑Processing (thresholding, class‑wise NMS)
- **Critical path:** Image & text → processor → backbone → fusion → head → filtered boxes.
- **Design tradeoffs:**  
  - Vocabulary size vs. confusion: More classes increase coverage but exponentially increase cross‑attention interference.  
  - Precision vs. recall: Conservative thresholding reduces false positives but misses true objects; aggressive thresholding does the opposite.  
  - Prompt engineering vs. over‑constraining: Adding “Aerial view of” increases precision by making matching stricter, but kills recall.
- **Failure signatures:**  
  - High FP rate (e.g., OWLv2 69%): Model emits boxes for textured backgrounds → over‑matching to non‑object regions.  
  - Catastrophic recall in Global mode: Model predicts almost nothing → attention diffusion across many tokens.  
  - Precision spike with aerial prefix: Model becomes hyper‑conservative → text embedding for “aerial” is weak/rare in CLIP pretraining.
- **First three experiments to run:**  
  1. Replicate Global vs. Oracle gap on 100 LAE‑80C images for Grounding DINO & OWLv2; expect ~15× F1 difference.  
  2. Prompt engineering ablation: test `["class"]`, `["aerial view of class"]`, `["class", synonyms..."]`; expect aerial phrase increases precision/lowers recall; synonyms degrade both.  
  3. Dataset transition analysis: run LLMDet sequentially on DIOR → DOTA → FAIR1M → xView subsets; plot cumulative F1; expect sharp drops at FAIR1M/xView.

## Open Questions the Paper Calls Out
1. **Dynamic Vocabulary Selection**  
   *Basis:* Conclusion proposes hierarchical vocabulary management to mitigate confusion.  
   *Why unresolved:* No current OVD selects context‑relevant categories per image, leading to the 15× Global→Oracle gap.  
   *Resolving evidence:* A method that predicts ≤5 relevant classes per image and achieves >50% Oracle F1 on LAE‑80C.

2. **Test‑Time Adaptation**  
   *Basis:* Future work includes lightweight adaptation using ≤5 examples/class.  
   *Why unresolved:* All models were frozen; zero‑shot transfer failed drastically.  
   *Resolving evidence:* Adaptation (e.g., prompt tuning) on ≤5 images/class improves global F1 by >10% on LAE‑80C.

3. **Aerial‑Specific Metrics**  
   *Basis:* Authors advocate task‑specific evaluations reflecting real‑world deployment.  
   *Why unresolved:* Standard metrics may not correlate with mission success; e.g., many false positives could still be useful in human‑in‑the‑loop.  
   *Resolving evidence:* Benchmark of task‑oriented scenarios (e.g., “find at least one damaged building”) showing low correlation with traditional metrics but high correlation with expert assessments.

4. **Hybrid Detectors**  
   *Basis:* Proposal to combine fast specialized closed‑set detectors for common categories with OVD for rare objects.  
   *Why unresolved:* Pure OVD models have poor precision‑recall trade‑offs; hybrid systems remain unexplored.  
   *Resolving evidence:* Hybrid system using a closed‑set detector on common aerial classes and an OVD for the tail achieves >15% absolute F1 gain over SOTA OVD on LAE‑80C with ≥30 FPS.

## Limitations
- Oracle mode provides an idealized upper bound; real‑world open‑vocabulary deployment may not achieve the 15× gap closure.
- LAE‑80C aggregates four datasets with uncontrolled variables (sensor, preprocessing), confounding isolation of domain effects.
- Only basic prompt engineering strategies were tested; richer prompting might still offer partial gains.

## Confidence
- **Semantic confusion is the primary bottleneck:** High – backed by large empirical gap.
- **Prompt engineering inefficacy:** Medium – clear for tested strategies, but untested designs remain.
- **Brittleness across aerial datasets:** Low – evidence based on limited datasets without controlled ablations.
