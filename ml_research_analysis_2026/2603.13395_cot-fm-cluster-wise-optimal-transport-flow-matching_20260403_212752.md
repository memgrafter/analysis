# COT-FM: Cluster-wise Optimal Transport Flow Matching

## Quick Facts
- **ArXiv ID:** 2603.13395
- **Source URL:** https://arxiv.org/abs/2603.13395
- **Reference count:** 40
- **Primary result:** Cluster-wise optimal transport in Flow Matching yields straighter vector fields, enabling high-quality generation with as few as 1 step (e.g., 1-step FID 2.60 on CIFAR-10, 96.1% success rate on LIBERO).

## Executive Summary
COT-FM addresses the problem of curved transport trajectories in Flow Matching models, which increase discretization error and reduce sample quality in low-step generation. The core idea is to partition target data into clusters and assign each cluster a dedicated source distribution obtained by reversing a pretrained FM model. Intra-cluster optimal transport couplings are then computed, yielding straighter vector fields via local OT without the computational cost of global OT. As a plug-and-play framework, COT-FM requires no architectural changes and alternates between refining cluster-wise couplings and updating the FM model. Empirical results on 2D benchmarks, CIFAR-10, and robotic manipulation demonstrate consistent improvements in speed and quality.

## Method Summary
COT-FM begins with a pretrained Flow Matching model. The training data is clustered (e.g., via K-means on DINO features). For each cluster, the pretrained FM is reverse-integrated to estimate a Gaussian source distribution (mean and covariance). Batch-wise optimal transport is then computed between samples from this source distribution and the cluster’s target samples. The FM model is fine-tuned using the resulting couplings from all clusters via the conditional flow matching loss. Optionally, the process repeats: after updating the FM, new source distributions are estimated by reversing the updated model, and OT couplings are recomputed. This alternating scheme progressively straightens the vector field, leading to better low-step generation.

## Key Results
- On 2D benchmarks (e.g., 5-Gaussians), COT-FM achieves the lowest Wasserstein distance (0.1995 vs. 0.5421 for baselines) and minimal trajectory curvature.
- On CIFAR-10, it reduces 1-step FID from 378.0 to 205.0 for Rectified Flow and from 2.92 to 2.60 for MeanFlow; 10-step FID improves from 12.6 to 8.23.
- On LIBERO robotic manipulation, it attains 96.1% success rate with a single step, surpassing FLOWER’s 94.2% at 1 step and approaching its 97.1% at 4 steps.

## Why This Works (Mechanism)
### Mechanism 1: Cluster-specific source distributions reduce transport path crossings
- **Claim:** Assigning cluster-specific source distributions reduces intersection of transport trajectories between dissimilar data modes.
- **Mechanism:** COT-FM partitions target data into clusters (e.g., via semantic features). For each cluster, it reverses a pretrained FM model to estimate a cluster-specific Gaussian source distribution. Intra-cluster optimal transport (OT) couplings are then computed between these sources and the cluster’s data. Since reversed flows are non-intersecting by construction and OT minimizes crossing within each cluster, the resulting marginal vector field aggregates straighter paths.
- **Core assumption:** Data naturally forms separable clusters, and reversing a pretrained FM’s non-intersecting flows preserves cluster structure in the source space.
- **Evidence anchors:** Abstract: “clustering target samples and assigning each cluster a dedicated source distribution obtained by reversing pretrained FM models... yields straighter vector fields.” Section 3.1: “We reverse ODE integration to retrieve the source sample... By restricting the space of source distributions, learning the overall vector field becomes more efficient.” Corpus: Neighbors like “Multisample Flow Matching” and “OT-CFM” address minibatch OT locality issues; COT-FM’s cluster-wise approach directly tackles this via divide-and-conquer.
- **Break condition:** If clustering fails to capture semantic groupings (e.g., highly overlapping classes), intra-cluster OT may still induce path crossings, and benefits diminish.

### Mechanism 2: Alternating refinement converges to straighter flows
- **Claim:** Alternating between refining cluster-wise couplings and updating the FM model converges to a progressively straighter vector field.
- **Mechanism:** COT-FM iteratively: (1) fine-tunes the FM using batch-wise OT couplings within current clusters, (2) updates cluster source distributions by reversing the new FM’s flows. Each cycle starts from a better-aligned coupling, reducing curvature monotonically.
- **Core assumption:** The reverse ODE of a straighter flow yields more consistent source distributions for each cluster, and subsequent intra-cluster OT further straightens paths within that cluster’s manifold.
- **Evidence anchors:** Section 3.3: “COT-FM alternates between refining cluster-wise couplings and updating the FM model... Empirically, we find that the model performance converges within a small number of alternation rounds.” Supplement Fig. 8 shows training loss decreasing monotonically across iterations. Corpus: Limited direct evidence; “Multisample Flow Matching” uses fixed minibatch couplings without alternation, so COT-FM’s iterative refinement is a distinct contribution.
- **Break condition:** If the FM model drifts significantly during fine-tuning, reverse ODE may produce inconsistent source estimates, causing oscillation or degeneration.

### Mechanism 3: Local OT avoids global intractability while improving straightness
- **Claim:** Local OT within clusters avoids the computational intractability of global OT while achieving similar straightness gains.
- **Mechanism:** Global exact OT scales cubically with sample count. COT-FM reduces each OT subproblem to a cluster (size ~n/K), making batch-wise OT more accurate than global batch OT (which suffers from poor locality). Cluster-wise OT maps jointly define a straighter marginal vector field.
- **Core assumption:** Clusters are roughly balanced, ensuring each has enough samples for reliable batch OT approximation.
- **Evidence anchors:** Abstract: “cluster-wise optimal transport approach yields straighter vector fields via local OT within each cluster, avoiding the inefficiency of global OT and the inaccuracies of random or batch-wise couplings.” Section 3.1: “Our method reduces the number of source-target samples, thereby making batch-wise approximation more feasible.” Table 6 compares per-epoch OT time: COT-FM (n/K=500) matches OT-CFM (b=512) time but achieves better FID. Corpus: “Minibatch optimal transport” papers highlight locality issues; COT-FM’s clustering is a direct solution.
- **Break condition:** Highly imbalanced clusters (some very small) lead to unreliable OT estimates for those clusters, introducing noise into the vector field.

## Foundational Learning
**Concept: Optimal Transport (OT)**  
- *Why needed here:* OT defines couplings that minimize transport cost (e.g., squared Euclidean), yielding straight paths with minimal crossing. COT-FM approximates OT per cluster to avoid global computation.  
- *Quick check question:* How does the 2-Wasserstein OT map differ from random coupling in terms of path crossings?

**Concept: Flow Matching (FM)**  
- *Why needed here:* FM regresses a vector field that transforms a source distribution to the target. COT-FM modulates FM’s target probability path via cluster-wise couplings without changing the FM architecture.  
- *Quick check question:* What is the relationship between the conditional vector field \(v_t(x_t|z)\) and the marginal vector field \(\tilde{v}_t(x_t)\) in FM?

**Concept: Clustering for Generative Modeling**  
- *Why needed here:* Clustering partitions data into modes, allowing COT-FM to assign dedicated sources and apply local OT, exploiting data multimodality for straighter flows.  
- *Quick check question:* Why might class labels or self-supervised features (e.g., DINO) serve as effective clusters for conditional/unconditional generation?

## Architecture Onboarding
- **Component map:**  
  Pretrained FM model → Clustering module → Source distribution estimator → Intra-cluster OT solver → FM fine-tuner → (Conditional model for non-fixed conditions)

- **Critical path:**  
  1. Start with pretrained FM.  
  2. Cluster training data (e.g., K-means on DINO features).  
  3. For each cluster, reverse ODE from pretrained FM to estimate Gaussian source distribution (mean, covariance).  
  4. Sample source points from each Gaussian and compute mini-batch OT map between source and cluster targets.  
  5. Fine-tune FM using couplings from all clusters via CFM loss.  
  6. Optionally repeat steps 3–5 for additional alternation cycles.

- **Design tradeoffs:**  
  - *Cluster count K:* Larger K yields more local OT (straighter) but fewer samples per cluster (noisier OT). Ablation shows peak at K=100 on CIFAR-10.  
  - *Clustering method:* Supervised (class labels) vs. unsupervised (K-means). Unsupervised risks semantic misalignment; supervised requires labels.  
  - *Source distribution form:* Gaussian assumption simplifies but may not capture complex cluster shapes. For high-D conditional tasks, isotropic covariance is used.

- **Failure signatures:**  
  - High curvature in generated trajectories despite COT-FM indicates poor clustering or insufficient alternation.  
  - Degraded test FID vs. train FID suggests overfitting to cluster assignments.  
  - In robotics, low success rate with novel conditions indicates conditional model ϕ fails to generalize source distribution predictions.

- **First 3 experiments:**  
  1. **2D point clouds** (Mixture of 5-Gaussians, Two Moons): Validate basic mechanism—straight trajectories, low Wasserstein. Use K-means with K=5. Metrics: Wasserstein distance, curvature.  
  2. **CIFAR-10 unconditional:** Test scalability. Use DINO features + K-means (K=100). Compare 1/10/50-step FID vs. Rectified Flow/OT-CFM/MeanFlow. Ablate K and alternations.  
  3. **LIBERO robotic manipulation:** Test conditional/non-fixed clusters. Learn ϕ via PPO. Measure success rate (1 NFE) vs. FLOWER/2-RF. Verify generalization to new tasks.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** What is the theoretical justification for the rapid convergence (often within one or two iterations) of the alternating optimization process between cluster-wise source distribution refinement and Flow Matching model updates?
- **Basis in paper:** The paper states in Limitations: “the behavior of cluster-wise transport—particularly how local OT captures global structure and why alternating refinement converges within one or two cycles—remains not fully understood.”
- **Why unresolved:** The empirical observation is strong, but the underlying mechanism linking reversible flows, local OT approximations, and stability of the alternating scheme is not analyzed.
- **What evidence would resolve it:** A convergence analysis proving that the alternating minimization of a well-defined objective converges in finite steps under conditions (e.g., sufficient cluster separation, Lipschitz continuity of the flow model).

### Open Question 2
- **Question:** How does the quality of the initial clustering fundamentally limit the performance gains from COT-FM, and can a learnable clustering model integrated into the framework further improve results?
- **Basis in paper:** The paper acknowledges dependence on clustering quality and mentions an extension for non-fixed clustering using a learned conditional model. It also provides a robustness argument based on k=1 reducing to OT-CFM and k>1 always improving over that baseline.
- **Why unresolved:** The ablation shows performance sensitivity to K, but the precise relationship between clustering error and suboptimal cluster-wise OT is not quantified. The learned conditional model for robotics is presented as an extension but not compared against a jointly optimized clustering+OT pipeline for unconditional generation.
- **What evidence would resolve it:** Experiments measuring performance degradation as a function of introduced label noise into clustering. A fully differentiable framework where cluster assignments are soft (e.g., via Gumbel-Softmax) and optimized end-to-end with the FM objective would test if joint optimization surpasses the two-stage approach.

### Open Question 3
- **Question:** For conditional generation tasks with a very large or open-vocabulary condition space (e.g., text-to-image with arbitrary prompts), is the proposed learning-based prediction of cluster-wise source statistics (mean and isotropic covariance) sufficient, or does modeling full covariance or more complex source distributions yield significant benefits?
- **Basis in paper:** In Supplementary A, for non-fixed conditions, they state: “Since learning a full covariance matrix in high-dimensional space is prohibitively difficult and unstable, we approximate the covariance using only the predicted standard deviation.” They use a diagonal Gaussian \(N(\mu_\phi(c_k), \sigma^2_\phi(c_k)I)\).
- **Why unresolved:** The simplification is made for computational and stability reasons. However, the core premise of COT-FM is that straighter paths come from accurate local OT couplings, which depend on the source distribution matching the true reversed distribution for that condition. An isotropic Gaussian may be a poor approximation for complex, multi-modal condition-specific source manifolds.
- **What evidence would resolve it:** An ablation comparing the isotropic Gaussian model against a more expressive (but potentially less stable) model like a conditional normalizing flow or a mixture of Gaussians for the source distribution on a conditional benchmark. Measuring curvature reduction and FID improvement would quantify the benefit.

### Open Question 4
- **Question:** What is the computational and sample complexity trade-off when scaling COT-FM to very large datasets (e.g., LAION-5B) and high-dimensional data (e.g., 1024px images), given that the per-epoch OT computation scales with the inverse of the number of clusters?
- **Basis in paper:** Theoretical analysis in Supplementary B states: “Exact OT costs \(O(n^3)\), while batch OT... costs \(O(nb^2)\) per epoch. COT-FM computes exact OT within K clusters each epoch: \(O(n(n/K)^2)\).” They also note the “reverse ODE step can become inefficient as sample size grows” in Limitations.
- **Why unresolved:** The paper demonstrates feasibility on CIFAR-10 (n=50k, K=100). For n=1B, even with K=10,000 clusters, (n/K)=100,000, making exact cluster-wise OT impossible. The paper uses batch-wise OT within clusters, which reintroduces the batch OT problem at a smaller scale. The threshold where cluster size becomes too small for effective batch OT approximation is not analyzed. Scalability of reverse ODE for billion-sample datasets is also not addressed.
- **What evidence would resolve it:** A detailed empirical study scaling CIFAR-10 to larger synthetic subsets (e.g., 500k, 1M samples) with varying K, measuring correlation between intra-cluster sample count and quality of batch OT approximation (e.g., via transport cost residual). A scalable approximation (e.g., Sinkhorn with smaller ε per cluster) or hierarchical clustering strategy would need to be proposed and benchmarked.

### Open Question 5
- **Question:** Does the cluster-wise optimal transport objective implicitly encourage disentanglement of latent factors (e.g., class labels, poses) in the learned vector field, and can this be leveraged for controlled generation or editing?
- **Basis in paper:** The method groups samples by “modes” or by class labels. The cluster-wise source distributions become mode-specific. The resulting straighter flows within clusters suggest that the transport problem is decomposed along latent axes. This is hinted at (“data of the same mode can be generated from similar source samples”) but not explored as a latent property.
- **Why unresolved:** The paper focuses on FID and speed. It does not analyze whether the cluster index or the μ₀,k of a cluster correlates with semantic attributes. If true, COT-FM could be used for interventions (e.g., editing by moving inferred source sample toward μ₀,k of a target cluster). The connection between transport decomposition and latent semantics is speculative.
- **What evidence would resolve it:** Quantitative experiments measuring alignment between cluster assignments (or cluster source means) and known latent factors (e.g., class labels, object position, lighting). A linear classifier predicting semantic attributes from cluster ID or μ₀,k with high accuracy would support disentanglement. Follow-up generation experiments performing “source space interpolation” between cluster source Gaussians and observing smooth, attribute-controlled changes would demonstrate utility.

## Limitations
- Exact ODE solver and step count for reverse integration are unspecified, impacting source distribution estimation quality.
- Batch-wise OT implementation details (e.g., Sinkhorn regularization, exact vs. approximate solver) are not provided, hindering faithful reproduction.
- Clustering method and hyperparameters (number of clusters K, feature extractor) significantly influence performance, but robustness analysis is limited.

## Confidence
- **Cluster-wise OT reduces curvature:** High (empirically validated on 2D/CIFAR, mechanism aligns with OT theory).
- **Alternating optimization converges:** Medium (Fig. 8 shows loss decrease, but risk of model drift if FM changes drastically).
- **Local OT avoids global OT inefficiency:** High (time comparisons in Tab. 6, supported by minibatch OT literature).
- **Plug-and-play generality across domains:** Medium (validated on CIFAR/LIBERO, but unsupervised clustering may not generalize to all data).
