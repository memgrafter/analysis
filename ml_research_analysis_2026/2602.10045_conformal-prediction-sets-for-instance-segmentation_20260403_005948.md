# Conformal Prediction Sets for Instance Segmentation

## Quick Facts
- **arXiv ID:** 2602.10045
- **Source URL:** https://arxiv.org/abs/2602.10045
- **Reference count:** 40
- **Primary result:** Provides a conformal prediction algorithm that outputs adaptive confidence sets for instance segmentation, guaranteeing that at least one mask has Intersection‑over‑Union (IoU) > τ with probability ≥ 1−α.

## Executive Summary
Instance segmentation models typically output a single mask without uncertainty estimates. This paper introduces a distribution‑free conformal prediction framework that produces adaptive sets of masks for a queried pixel, with a coverage guarantee that at least one mask exceeds a user‑specified IoU threshold τ with high probability. The method varies a tunable parameter of an instance segmentation model to generate a pool of candidate masks, then selects a minimal subset of parameters that collectively cover a majority of a calibration set. Near‑duplicate masks are removed to keep the prediction set concise. Evaluated on three diverse tasks—agricultural field delineation, cell segmentation, and vehicle detection—the algorithm achieves empirical coverage close to nominal levels (79.7%, 83.5%, 84.3% versus 80% or 90% targets) and outperforms baselines such as Learn‑Then‑Test and morphological dilation. The size of the output set adapts automatically, ranging from 1 to 5 masks, and provides interpretable alternatives for ambiguous instances.

## Method Summary
The algorithm operates in two phases. In the **calibration** phase, a set of parameter values \(t_1,\dots,t_k\) is chosen for a base segmentation model \(f\). For each calibration example \((X_i, Y_i)\) and each parameter \(t_j\), the model output mask \(f(X_i, t_j)\) is compared to the ground truth \(Y_i\) by IoU. The set \(S_j\) collects indices of calibration points for which IoU exceeds a threshold \(\tau\). Using a set‑cover formulation, a minimal subset \(J_{\alpha,\tau} \subseteq [k]\) is identified such that \(\bigcup_{j \in J} S_j\) covers at least \((1-\alpha)n\) calibration examples. In the **test** phase, for a new query image and pixel, all masks \(f(X_{\text{test}}, t_j)\) with \(j \in J_{\alpha,\tau}\) are generated. An optional adaptive refinement (UNIQUE) removes masks that are near‑duplicates (IoU > \(\eta\)) by finding a minimum dominating set, and the IoU threshold \(\tilde{\theta}\) is recalibrated as the \(\alpha\)-quantile of the maximum IoU recorded over the refined sets on the calibration data. The final output is the subset of masks together with the guarantee \(\mathbb{P}\big(\max_{\hat{Y} \in C(X)}\text{IoU}(\hat{Y}, Y) > \tilde{\theta}\big) \ge 1-\alpha\).

## Key Results
- Empirical coverage closely matches nominal targets: 79.7% (target 80%) on Fields‑of‑The‑World, 83.5% (target 80%) on Cellpose, and 84.3% (target 90%) on Cityscapes vehicle detection.
- The method significantly outperforms feasible Learn‑Then‑Test/Conformal Risk Control and morphological dilation baselines in both coverage efficiency and set size.
- Adaptive prediction sets contain between 1 and 5 masks, effectively representing structural ambiguities such as over‑ and under‑segmentation that single‑mask or dilation‑only approaches miss.

## Why This Works (Mechanism)

### Mechanism 1
**Claim:** Varying a tunable parameter \(T\) of the segmentation model produces diverse mask predictions that capture structural uncertainty (e.g., over‑segmentation vs. under‑segmentation).  
**How:** For a fixed query (image, pixel), the model output \(f(X, T)\) changes as \(T\) varies; examples include watershed thresholds in field delineation or SAM mask index in vehicle detection. This yields a hypothesis set of plausible instances that covers different segmentation granularities.  
**Evidence:** Abstract states “generates a diverse set of predictions for each query by varying a tunable parameter”; Section 2.2 explains “By varying \(T\), we can modulate the behavior of \(f\) and obtain a diverse set of predictions”.  
**Break condition:** If \(T\) has limited range or fails to produce qualitatively distinct masks, the hypothesis set may lack necessary diversity, weakening the guarantee.

### Mechanism 2
**Claim:** Selecting a minimal subset of parameters via set cover on a calibration set ensures that for a new query, with probability \(\ge 1-\alpha\), at least one parameter yields a mask with IoU \(> \tau\).  
**How:** For each \(t_j\), define \(S_j = \{i : \text{IoU}(Y_i, f(X_i, t_j)) > \tau\}\). Algorithm 1 finds a smallest \(J_{\alpha,\tau}\) such that \(\bigcup_{j \in J} S_j\) covers at least \((1-\alpha)n\) calibration points. This \(J\) is then used at test time.  
**Evidence:** Abstract mentions “uses a calibration set to select a minimal subset of parameters that collectively achieve the coverage target”; Section 2.2 formalizes the set‑cover problem.  
**Break condition:** If no subset covers \((1-\alpha)n\) points, the algorithm fails (Line 8 of Alg. 1). Users must adjust \(\alpha\), \(\tau\), or expand the grid of \(T\).

### Mechanism 3
**Claim:** Removing near‑duplicate masks from the initial prediction set adapts its size to query difficulty, producing concise yet comprehensive uncertainty representations.  
**How:** After obtaining the initial set \(C_{\alpha,\tau}(X_{\text{test}})\), UNIQUE retains only masks that are not dominated by another with IoU > \(\eta\). The remaining set is typically smaller for easy queries where many masks are similar, and larger for hard queries. The IoU threshold is then recalibrated to \(\tilde{\theta}\) based on the behavior of these adaptive sets on the calibration data.  
**Evidence:** Abstract notes “removes near‑duplicate masks to adapt set size to query difficulty”; Section 2.3 discusses adaptivity.  
**Break condition:** The duplicate removal step is NP‑hard; brute‑force search becomes intractable if the initial set is large. Approximation heuristics are not provided, limiting scalability.

## Foundational Learning
- **Conformal Prediction** – Provides distribution‑free coverage guarantees. *Why needed:* Ensures the output set contains a mask with IoU > \(\tilde{\theta}\) with probability ≥ 1−α regardless of data distribution. *Quick check:* What does “with probability ≥ 1−α, at least one mask has IoU > τ” mean for a test query?
- **Instance Segmentation** – Predicts binary masks for individual objects. *Why needed:* The task involves distinguishing multiple instances in an image, requiring mask‑level uncertainty. *Quick check:* How does instance segmentation differ from semantic segmentation in output structure?
- **Intersection‑over‑Union (IoU)** – Overlap metric between predicted and ground‑truth masks. *Why needed:* Serves as the quality measure defining coverage thresholds (τ, \(\tilde{\theta}\)). *Quick check:* Why is IoU a stricter measure than pixel accuracy for mask similarity?
- **Set Cover Problem** – Selects a smallest family of sets whose union covers a universe. *Why needed:* The parameter selection step reduces to finding a minimal subset of \(t_j\) values that collectively cover enough calibration points. *Quick check:* Why is exact set cover NP‑hard, and what heuristic does the paper use (e.g., greedy algorithm)?
- **Tunable Parameter in Segmentation Models** – A controllable hyperparameter that changes the model’s output granularity. *Why needed:* Enables generation of multiple plausible masks from a single model, forming the hypothesis pool. *Quick check:* Give two examples of tunable parameters \(T\) from the paper’s applications and how they affect outputs.

## Architecture Onboarding
- **Component map**  
  Calibration dataset → Segmentation model \(f\) → Set cover module → Duplicate remover (UNIQUE) → Guarantee calibrator
- **Critical path**  
  *Calibration:* Compute IoU for all \((X_i, Y_i)\) and each \(t_j\); form sets \(S_j\); run set cover to obtain \(J_{\alpha,\tau}\).  
  *Test:* Generate masks \(\{f(X_{\text{test}}, t_j): j \in J_{\alpha,\tau}\}\); apply UNIQUE; recompute \(\tilde{\theta}\) using calibration data; output final set with guarantee.
- **Design tradeoffs**  
  *Asymptotic vs finite‑sample:* The asymptotic version (Alg. 1+2) allows exact minimality via brute‑force; the finite‑sample version (Alg. 3) uses a holdout split to maintain validity but may yield larger sets.  
  *Computational cost:* Brute‑force set cover and duplicate removal become prohibitive for large \(k\) or \(|J|\); the paper assumes small parameter grids in experiments.  
  *Global vs adaptive:* The IoU threshold \(\tau\) is global, but duplicate removal adapts set size to each query; the final threshold \(\tilde{\theta}\) is recalibrated to preserve coverage.
- **Failure signatures**  
  1. Infeasible \((\alpha, \tau)\): No parameter subset covers \((1-\alpha)n\) calibration points → algorithm error.  
  2. Exploding set size: Large \(|J_{\alpha,\tau}|\) or many duplicates → slow or memory‑intensive duplicate removal.  
  3. Coverage drop: Empirical coverage significantly below \(1-\alpha\) suggests calibration mismatch or model inadequacy.  
  4. Excessive runtime: Timers reveal bottlenecks as \(k\) grows beyond ~20.
- **First 3 experiments**  
  1. **Feasibility check** – On a small calibration set (e.g., 50 points), plot maximum achievable IoU over the parameter grid to select viable \((\alpha, \tau)\) and anticipate Algorithm 1 success.  
  2. **Coverage validation** – Run the full pipeline on the Fields‑of‑The‑World dataset; compute empirical coverage on the test set using the final threshold \(\tilde{\theta}\); verify closeness to the target \(1-\alpha\).  
  3. **Baseline comparison** – Implement feasible Learn‑Then‑Test/Conformal Risk Control (single best parameter) and morphological dilation baselines; compare coverage and set‑size distributions to highlight the benefits of the proposed adaptive approach.

## Open Questions the Paper Calls Out
1. **Can conformal prediction for instance segmentation use input‑adaptive IoU thresholds?** The current guarantee is global: every input receives the same threshold, even though some queries are easier than others. A conditional coverage method would allow query‑specific thresholds while preserving marginal coverage, potentially yielding more compact sets for easy cases and higher coverage for ambiguous ones.
2. **What if the model lacks a tunable parameter that yields diverse masks?** The algorithm fundamentally relies on a parameter sweep to create a hypothesis set. Many segmentation models are deterministic or have limited tunable knobs, leaving a gap for applying conformal methods without such diversity. Alternative sources (e.g., model ensembles, input perturbations, latent variations) need to be explored.
3. **Can the combinatorial steps be approximated efficiently without breaking guarantees?** Set cover and duplicate removal are NP‑hard in general; the paper uses exact brute‑force only for small parameter grids. Scalable approximations (e.g., greedy set cover with bounded approximation ratio) are needed for larger problems, but their effect on the conformal coverage guarantee must be understood theoretically and empirically.
4. **How can model training be designed to promote mask diversity?** Models are typically trained with a single‑target loss, so sweeping a parameter may produce only minor variations. Training objectives that explicitly encourage diverse mask proposals (e.g., diversity‑regularization) could improve the quality and informativeness of the conformal prediction sets.

## Limitations
- **Computational bottleneck:** Exact set‑cover and duplicate removal become intractable for more than ~10 parameter values; no fallback approximations are evaluated, limiting scalability.
- **Feasibility risk:** The set‑cover step may fail if no parameter combination covers the required \((1-\alpha)n\) calibration points, offering little guidance on selecting viable \((\alpha, \tau)\).
- **Sensitivity to heuristic choices:** The duplicate‑removal threshold \(\eta = 0.9\) is fixed experimentally; its impact on coverage and set size is not systematically studied.
- **Finite‑sample validation gap:** Algorithm 3 (finite‑sample version) is presented but not empirically evaluated, leaving uncertainty about performance with small calibration sets.
