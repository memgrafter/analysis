# Parity, Sensitivity, and Transformers

## Quick Facts
- **ArXiv ID:** 2602.05896  
- **Source URL:** https://arxiv.org/abs/2602.05896  
- **Reference count:** 22  
- **Primary result:** A single‑layer, single‑head transformer cannot compute parity because its average sensitivity is O(√n), while parity’s is Θ(n); in contrast, a 4‑layer transformer can compute parity using softmax attention, length‑independent polynomial positional encoding, no layer normalization, and it works with both full and causal masking.

## Executive Summary
This paper tackles the long‑standing open question of whether transformers can compute the parity function. It establishes a fundamental limitation: any constant‑size, single‑head, single‑layer transformer using ReLU and linear operations over the reals has average sensitivity O(√n), which is insufficient to capture parity’s Θ(n) sensitivity. The impossibility result is rigorous under the stated model. On the constructive side, the authors present an explicit 4‑layer transformer that computes parity with entirely practical components—softmax attention, a length‑independent polynomially bounded positional encoding, no layer normalization, and compatibility with causal masking. This construction improves over prior art that required length‑dependent encodings or hard attention. The work thus clarifies the role of sensitivity as a barrier for shallow transformers and demonstrates that parity is within reach with modest depth.

## Method Summary
The lower bound leverages average sensitivity analysis: any function computed by a 1‑layer, 1‑head transformer can be expressed as a constant‑size Boolean combination of linear inequalities (hyperplanes). Since each hyperplane intersects at most O(√n) edges of the n‑dimensional Boolean hypercube, the overall average sensitivity is O(√n). Parity’s average sensitivity is Θ(n), ruling out representation. For the upper bound, the authors design a 4‑layer transformer. The first layer computes a scalar γ based on the number of ones Σ. The second layer uses polynomial positional encoding to derive a normalized sum Γ. The third layer creates attention logits that sharply concentrate on position i = Σ, yielding a ratio z whose sign matches the parity. When the initial assumption Σ ≤ c n does not hold, the input is split into M even subsequences; each subsequence’s parity is computed in parallel using M heads, and a final feed‑forward network XORs the results. The construction relies on softmax, length‑independent polynomial encoding, and no layer normalization, and it works under both full and causal attention masking.

## Key Results
- A single‑layer, single‑head transformer cannot compute parity because its average sensitivity is O(√n), while parity has Θ(n).
- A 4‑layer transformer with softmax attention, length‑independent polynomial positional encoding, no layer norm, and compatibility with causal masking can compute parity for any input length.
- The 4‑layer construction uses only practical architectural choices, improving on earlier work that required length‑dependent encodings or hard attention.

## Why This Works (Mechanism)
**Mechanism 1 – Lower bound via average sensitivity**  
A 1‑layer, 1‑head transformer’s output can be written as a constant‑size Boolean combination of linear inequalities (hyperplanes) in (ℝ,+,<). Each hyperplane cuts at most O(√n) edges of the n‑dimensional Boolean hypercube (O’Neil, 1971). The function flips only when crossing a hyperplane, so its average sensitivity is O(√n). Parity’s average sensitivity is Θ(n), hence impossible for such a transformer.

**Mechanism 2 – Core 3‑layer construction**  
- *Layer 1:* Attention logits L_{i,n} ≈ (−ln n + δ)(1−x_i) produce a weighted sum γ ≈ 10/(1+ρ), where ρ = α(1/Σ − 1/n).  
- *Layer 2:* Positional encoding (ln i, i¹⁰) yields Γ = τ_n f(ρ)(1+o(1)) with τ_n = n¹⁰ and f(ρ) = (11+ρ)/(21+11ρ).  
- *Layer 3:* Attention weights L_{i,n} ≈ τ_n[−2f(ρ)(C/i) − τ_n(C/i)² − 2τ_n A_n(C/i)] concentrate on i = Σ with gap Ω(n⁶). The ratio z = (∑_i e^{L_{i,n}} (−1)^i)/(∑_i e^{L_{i,n}}) has sign (−1)^Σ.  
- *Output:* Final FFN reads sign(z) to output the correct parity token.

**Mechanism 3 – Removing the Σ ≤ c n assumption**  
Split the input into M even subsequences (M constant, M > 2/c). Layer 1 uses an FFN and modular positional cues to create M binary strings, each with ≤ c n ones. Layers 2‑4 run the core 3‑layer construction in parallel with M heads, producing z^r ≈ (−1)^{parity(x^r)}. The final FFN XORs the z^r by summing ReLU terms that activate only when an even number of z^r are negative, yielding the overall parity.

## Architecture Onboarding
### Component Map
Token embedding → Positional encoding (varies per layer) → Attention layers (softmax) → Point‑wise FFN (ReLU) → Output matrix.  
- *Token embedding:* Maps symbols 0/1 to fixed vectors.  
- *Positional encoding:* Layer 1: ln i (or constant); Layer 2: (ln i, i¹⁰); Layer 3: (1/i, 1/i², τ_i, τ_i A_i).  
- *Attention:* Four softmax layers (causal or full). Layer 1 usually 1 head; Layers 2‑4 use M heads (one per subsequence) in the general construction.  
- *FFN:* Position‑wise ReLU networks after each attention: compute subsequences (L1), weighted sums (L2), and final XOR (after L4).  
- *Output:* Matrix W maps the last position to logits over {0,1,⊥}.

### Critical Path
1. Embed tokens with TE and layer‑specific PE.  
2. **Layer 1:** FFN outputs M binary subsequences x^r.  
3. **Layer 2 (per head):** Attention logits L_{i,n} ∝ (1−x_i) yield γ_r.  
4. **Layer 3 (per head):** PE (ln i, i¹⁰) yields Γ_r.  
5. **Layer 4 (per head):** PE (1/i, …) defines L_{i,n} that separates i = Σ_r; compute z_r.  
6. **Final FFN:** Combine z^r to decide overall parity.

### Design Tradeoffs
- *Depth vs practicality:* 4 layers is deeper than prior 2‑layer work but uses more standard components (softmax, length‑independent PE, no LN).  
- *Positional encoding:* Length‑independent enables variable‑length generalization but requires polynomial growth to avoid overflow.  
- *Softmax vs hard:* Softmax provides smooth separation; hard attention would need different thresholds.  
- *No layer norm:* Simplifies analysis but may hinder training stability; construction assumes exact parameters.

### Failure Signatures
- Gap |L_Σ − max_{i≠Σ} L_i| falls below Ω(n⁶) → sign error in z.  
- Small n invalidates asymptotics → incorrect outputs.  
- PE values exceed polynomial bounds → numerical overflow/underflow.  
- M too small in splitting → some subsequences violate Σ ≤ c n.  
- Loss of critical values (γ, Γ, τ_n) across layers due to non‑identity FFNs or mixing.

### First 3 Experiments
1. **Parity accuracy sweep:** Test lengths n = 50,100,…,2000 with both full‑attention and causal masking; expect near‑perfect accuracy.  
2. **Attention gap measurement:** For random inputs, compute L_Σ − max_{i≠Σ} L_i; verify it scales as Ω(n⁶).  
3. **PE ablation:** Replace custom PE with sinusoidal or learned PE; parity accuracy should drop to chance, confirming necessity.

## Open Questions the Paper Calls Out
- **Single‑layer multi‑head parity:** Can a multi‑head single‑layer transformer compute parity under practical constraints? The lower bound only covers the single‑head case.  
- **Minimal depth:** Is 3 layers sufficient, or is 4 the minimum needed for parity with the stated constraints?  
- **Sensitivity of multi‑head transformers:** What is the maximum average sensitivity achievable by single‑layer transformers with multiple heads? Extending the O(√n) bound beyond one head remains open.

## Limitations
- The O(√n) average sensitivity lower bound applies only to single‑head, constant‑size ReLU transformers; multi‑head or deeper models might exceed this limit.  
- The 4‑layer construction depends on exact constants and large‑n asymptotic gaps; for small n the required separation may not hold.  
- The splitting technique for general n requires an even M and a potentially large XOR FFN; these are described but lack concrete parameterization for implementation.

## Confidence
- **Claim:** A single‑layer, single‑head transformer cannot compute parity. **Confidence:** High (rigorous sensitivity argument).  
- **Claim:** A 4‑layer transformer can compute parity under the stated constraints. **Confidence:** Medium (construction explicit but constant tuning and asymptotics need full verification).  
- **Claim:** The splitting technique removes the Σ ≤ c n assumption. **Confidence:** Medium‑Low (plausible but lacks detailed parameters and edge‑case handling).
