# Cough activity detection for automatic tuberculosis screening

## Quick Facts
- **arXiv ID:** 2603.11241
- **Source URL:** https://arxiv.org/abs/2603.11241
- **Reference count:** 0
- **Primary result:** Using only the first three layers of a pre-trained XLS-R model yields test set average precision of 0.96 and AUC of 0.99 for cough activity detection, outperforming an Audio Spectrogram Transformer (AST) by 9% absolute in average precision.

## Executive Summary
This study tackles automatic tuberculosis (TB) screening by developing a system to isolate cough sounds from audio recordings. It proposes using a pre-trained speech transformer model, XLS-R, in a frame-wise binary classification setup to detect cough start and end points. A key efficiency finding is that using only the first three layers of the 300M-parameter XLS-R model—just 51M parameters—achieves state-of-the-art segmentation performance (AP 0.96, AUC 0.99) while being significantly faster. This cough isolation method downstreams into TB classification, where performance using automatically segmented coughs nears that of manually annotated coughs (only 2% absolute AUC worse), demonstrating the viability of scalable, automated TB screening from audio.

## Method Summary
The method frames cough detection as a frame-wise binary classification task on short audio frames (20ms for XLS-R). A pre-trained XLS-R model, adapted for this domain, processes raw waveform input and outputs a probability for each frame indicating cough presence. Only the first three transformer layers are fine-tuned, drastically reducing computational cost. Frame probabilities are thresholded at three operating points (favoring coverage, equal error, or purity) to generate binary sequences, which are then converted into contiguous cough segments after optional median filtering. These automatically isolated cough segments are fed into a separate downstream LSTM model for tuberculosis classification.

## Key Results
- XLS-R using only its first three layers achieves a test set average precision (AP) of 0.96 and an area under the curve (AUC) of 0.99 for cough activity detection.
- This configuration outperforms an Audio Spectrogram Transformer (AST) baseline by 9% absolute in AP and a logistic regression baseline by 27% absolute in AP.
- A TB classifier trained on coughs automatically isolated by XLS-R performs nearly as well as one trained on manually annotated coughs (test AUC 0.63 vs. 0.65, 2% absolute difference) and significantly better than one using AST-isolated coughs.

## Why This Works (Mechanism)
### Mechanism 1
Pre-trained speech transformers (XLS-R) effectively generalize to cough sound segmentation because their early self-supervised representations capture generic acoustic-phonetic features shared with cough transients. The first layers, trained on 400k+ hours of multilingual speech, detect patterns like energy bursts and spectral tilts that also characterize coughs. Fine-tuning adapts these generic detectors to cough-specific timing. *Break condition:* Performance would degrade if cough acoustics diverge significantly from speech transients, such as in highly noisy, non-speech environments.

### Mechanism 2
Using only the first few transformer layers drastically reduces computational load while preserving segmentation accuracy because the binary frame-level decision boundary is learnable from low-level spectral-temporal features. Later layers build abstract, task-specific representations that are unnecessary for this relatively simple discrimination. *Break condition:* Performance would drop if the task critically depended on long-range temporal context across seconds, which later layers capture.

### Mechanism 3
High-quality automatic cough isolation via XLS-R yields downstream TB classification performance close to manual annotation because it maintains high coverage (97%) and purity (90%+), preserving disease-relevant acoustic signatures while removing contaminating audio. The downstream LSTM then learns from a cleaner distribution. *Break condition:* The small (2%) gap could widen if TB biomarkers are highly sensitive to precise phase boundaries and XLS-R systematically mis-trims.

  *Why needed here:* The task labels short audio frames (not whole clips) as cough/no-cough, then converts the sequence to segments. This standard setup frames segmentation as a sequence labeling problem.  
  *Quick check question:* How does the frame stride (20ms for XLS-R vs. 100ms for AST) impact the precision of estimated start/end points?

- **Concept: Evaluation Metrics for Imbalanced Segmentation**  
  *Why needed here:* The dataset has many more non-cough frames. Average Precision (AP) emphasizes precision (purity) at various recall (coverage) levels, which maps directly to clinical utility (few false alarms vs. missing coughs).  
  *Quick check question:* Why is Average Precision (AP) considered more clinically relevant than frame-wise AUC for this highly imbalanced task?

## Architecture Onboarding
- **Component map:** Input Raw Waveform -> XLS-R CNN Front-End & First 3 Transformer Layers -> Frame-wise Feature Sequence -> 2-layer MLP Classification Head -> Sigmoid Frame Probabilities -> Thresholding (C/EE/P) -> Median Filtering (optional) -> Contiguous Segment Merging -> Isolated Cough Audio
- **Critical path:** Raw audio → [Feature Extractor + Transformer (N=3 layers)] → Frame-wise probabilities → Development-set thresholding → Segment boundaries → Isolated cough WAV files → Downstream TB LSTM classifier. Threshold selection is strictly on the development set to prevent test set leakage.
- **Design tradeoffs:** 
  - XLS-R (speech pretraining, 20ms stride) vs. AST (general audio, 100ms stride). XLS-R wins on accuracy and temporal precision.
  - Layer depth vs. efficiency: Using 3XLS-R layers (51M params) outperforms full XLS-R (316M) and AST (87M) while being 3.8x faster.
  - Operating point: Coverage-optimized (C) threshold favored downstream TB performance, suggesting recall is more critical than precision here.
- **Failure signatures:**
  - Logistic Regression's AP drops 10% from dev to test (0.79→0.69), indicating poor cross-cohort generalization.
  - All models produce many sub-100ms "coughs," showing fragmentation and boundary detection issues.
  - LR at Purity operating point extracts too few coughs (3988 vs. 6886 ground truth) for viable TB training.
- **First 3 experiments:**
  1. Replicate baseline hyperparameters: Train XLS-R (3 layers) and AST (1 layer) on the Ugandan train set. Validate on Ugandan dev set to confirm APs ~0.90 (XLS-R) and ~0.82 (AST).
  2. Test layer reduction impact: Incrementally add layers (1 through 24) to XLS-R, measuring dev set AP. Confirm performance peaks at layer 3 and then decays.
  3. Evaluate boundary sensitivity: Apply C/EE/P thresholds to XLS-R's raw frame probabilities. Calculate median start/end error (ms) against ground truth and compare to AST and LR.

## Open Questions the Paper Calls Out
### Open Question 1
How well do the optimal cough activity detection models and their reported high performance (AP 0.96) generalise to tuberculosis screening datasets collected in different geographic regions, with varying languages, acoustic environments, and background noise profiles?
- **Basis in paper:** The study uses data from South Africa and Uganda with specific languages and clinical settings. The train-test split by country tests cross-cohort generalisation but not broader global diversity.
- **Why unresolved:** Performance is specific to this dataset and partition; generalisation to other regions, populations, or recording setups is unknown.
- **What evidence would resolve it:** Evaluate trained models on external TB cough datasets from other continents (e.g., Southeast Asia, South America). Report AP/AUC changes and analyse failure modes.

### Open Question 2
Is the finding that using only the first three layers of XLS-R yields optimal performance a universal property for cough detection, or does the optimal layer depth vary with the acoustic characteristics of different input datasets?
- **Basis in paper:** Authors report best AP with first 3 layers after optimising on their development set, but only for one dataset.
- **Why unresolved:** No investigation into whether layer 3 is optimal across different datasets, qualities, or populations.
- **What evidence would resolve it:** Repeat the layer ablation study on multiple independent cough datasets. Statistically analyse if layer 3 is consistently optimal.

### Open Question 3
Can post-processing methods effectively reduce cough segmentation fragmentation (i.e., splitting a single cough into multiple short segments) while preserving high coverage and purity, thereby improving the clinical utility of automatically extracted coughs?
- **Basis in paper:** All models produce fragmented coughs; median filtering helped XLS-R slightly but hurt AST. The impact of fragmentation on downstream TB classification was not isolated.
- **Why unresolved:** No evaluation of more sophisticated segmentation algorithms (beyond median filtering) or direct measurement of fragmentation's impact on TB classification.
- **What evidence would resolve it:** Design and test advanced segmentation algorithms (e.g., HMMs, learned post-processors). Measure segmentation metrics and downstream TB AUC to assess improvement.

### Open Question 4
How does the choice of downstream tuberculosis classification architecture influence the relative performance gap between manually annotated and automatically segmented coughs?
- **Basis in paper:** A single bidirectional LSTM was used for all downstream experiments to isolate segmentation effects. The interaction between segmentation quality and classifier robustness is unexplored.
- **Why unresolved:** Some classifiers may be more tolerant to segmentation errors (e.g., over-segmentation) than others. The reported 2% AUC gap might not generalise.
- **What evidence would resolve it:** Repeat downstream experiments with multiple classifier architectures (CNNs, transformers, other RNNs) on the same segmented datasets. Compare performance degradation relative to ground truth across classifiers.

## Limitations
- **Dataset & geographic generalizability:** All data is from a single Ugandan cohort. Performance may drop with different populations, languages, devices, or noise profiles. The LR baseline's dev→test AP drop hints at vulnerability.
- **Real-world noise & contamination:** Testing used research-grade recordings. Performance in homes/clinics with overlapping speech, traffic, or other sounds is unknown; the mechanism assumes coughs share transient features with speech.
- **Boundary precision vs. downstream impact:** The 2% gap between XLS-R-isolated and manually annotated coughs for TB classification is small but could stem from precise boundary alignment or other artifacts. Clinical relevance of sub-100ms fragmentation is unquantified.

## Confidence
- **High:** Internal performance claims (AP 0.96, AUC 0.99; 9% AST improvement; 2% downstream gap). Supported by clear tables/figures and consistent methodology.
- **Medium:** Generalisation of the "early layers suffice" mechanism beyond this specific dataset and task. Break conditions are plausible but not stress-tested.
- **Low:** Extrapolation to completely new acoustic environments (e.g., smartphone recordings in noisy markets) or to TB classifiers beyond the provided LSTM baseline. Root cause of the 2% downstream gap is not isolated.

## Next Checks
1. **Cross-dataset replication:** Apply the trained XLS-R (3-layer) segmenter to an independent, publicly available cough dataset from a different country/study with different microphones. Measure AP/AUC drop and analyse error types (boundary vs. false positive).
2. **Noise robustness stress test:** Artificially corrupt the clean test set with realistic noise (babble, street, music) at varying signal-to-noise ratios (SNRs). Re-evaluate AP to quantify the performance cliff and identify SNR thresholds where the speech-pretraining advantage vanishes.
3. **Boundary sensitivity ablation for TB:** Systematically vary start/end times of XLS-R-isolated coughs (±100ms increments). Measure change in downstream TB classification AUC to determine if the 2% gap is attributable to boundary error or other segmentation artifacts.
