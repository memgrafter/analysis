# Benchmarking Compact VLMs for Clip-Level Surveillance Anomaly Detection Under Weak Supervision

## Executive Summary
This paper investigates the use of compact vision-language models (VLMs) for clip-level anomaly detection in CCTV surveillance under weak supervision. The authors evaluate a standardized protocol comparing training-free zero-shot usage of VLMs against parameter-efficient fine-tuning using Low-Rank Adaptation (LoRA). Experiments on the UCF-Crime dataset show that LoRA-adapted compact VLMs (2-8B parameters) achieve competitive or superior detection performance (F1 up to 0.92, ROC-AUC up to 0.92) while maintaining low per-clip inference latency (2.8–8.8 seconds). These models outperform larger baselines and existing VLM pipelines, offering a favorable accuracy-efficiency trade-off and reduced prompt sensitivity. The study demonstrates that small VLMs can be effectively deployed in resource-constrained surveillance settings, though results are limited to a single dataset and lack reproducibility artifacts.

## Method Summary
The study adopts a standardized evaluation framework for clip-level anomaly detection under weak supervision, where only video-level labels are available during training. The authors consider compact pre-trained VLMs (2-8B parameters) in two modes: (1) training-free zero-shot inference by computing similarity between video frame embeddings and textual prompts (e.g., "normal" vs. "abnormal"), and (2) parameter-efficient fine-tuning using LoRA to adapt the VLM's attention layers with a small set of trainable parameters. LoRA freezes the base model and learns low-rank update matrices, enabling efficient adaptation with minimal overfitting. During inference, a video clip is decoded, frames are sampled, and each frame passes through the VLM image encoder. Frame-level features are aggregated (e.g., max pooling) to produce an anomaly score. The pipeline is evaluated on UCF-Crime using F1 and ROC-AUC, and latency is measured per clip on a fixed hardware setup (details not fully disclosed).

## Key Results
- LoRA-finetuned compact VLMs achieve state-of-the-art performance on UCF-Crime (F1 0.92, ROC-AUC 0.92) with low latency (2.8–8.8 s/clip).
- Adapted models outperform larger baseline VLMs and established VLM pipelines, demonstrating a strong accuracy-efficiency trade-off.
- Prompt sensitivity is significantly reduced compared to training-free VLM usage.

## Foundational Learning
- **Vision-Language Model (VLM)**: Pre-trained models that align visual and textual representations (e.g., CLIP). *Why needed*: Enable zero-shot anomaly detection by relating visual patterns to textual prompts without task-specific training. *Quick check*: Can a VLM assign higher similarity to images of "abnormality" when given the prompt "a normal scene" vs. "an abnormal scene"?
- **Parameter-Efficient Fine-Tuning (PEFT)**: Techniques like LoRA that modify a small subset of model parameters during adaptation. *Why needed*: Adapt large VLMs to new domains with limited data and computational resources, avoiding catastrophic forgetting. *Quick check*: Does LoRA freeze the original weight matrices and only train low-rank adapters?
- **Weak Supervision**: Learning from coarse labels (e.g., video-level annotations) instead of fine-grained annotations. *Why needed*: Reduces annotation cost for anomaly detection, where labeling each frame is impractical. *Quick check*: Is only a video-level anomaly label used during training?
- **Clip-Level Anomaly Detection**: Classifying entire video clips as normal or anomalous. *Why needed*: In surveillance, anomalies are often events that occur within a short timeframe; clip-level labeling is more feasible than frame-level. *Quick check*: Are predictions aggregated over frames to produce a clip-level score?

## Architecture Onboarding
**Component map**: Video Input -> Frame Sampling -> VLM Image Encoder (with LoRA adapters) -> Frame Feature Aggregation -> Anomaly Score Computation -> Clip-Level Prediction

**Critical path**: Inference proceeds through: (1) decoding and frame sampling; (2) VLM image encoder forward pass (including LoRA-updated attention); (3) feature pooling; (4) similarity computation or classification. The encoder on sampled frames dominates latency.

**Design tradeoffs**:
- Model size vs. latency: Larger VLMs may improve accuracy but increase inference time.
- LoRA rank vs. performance: Higher rank adapts more parameters, potentially boosting accuracy but at higher memory/compute cost.
- Frame sampling rate vs. temporal coverage: More frames enhance detection but linearly increase latency.

**Failure signatures**:
- High false positives on benign but unusual activities due to prompt misalignment.
- Performance drop when training and test data distributions (e.g., camera viewpoints) differ.
- Excessive latency when using high sampling rates or large VLMs, breaching real-time constraints.

**First experiments**:
1. Establish zero-shot baseline using training-free VLM with default prompts.
2. Apply LoRA adaptation with a low rank (e.g., r=4) and compare performance/latency to zero-shot.
3. Sweep LoRA rank to analyze the accuracy-efficiency trade-off.

## Limitations
- Single-dataset evaluation (UCF-Crime only) limits generalizability to other surveillance contexts.
- No code or data release hinders reproducibility and independent verification.
- Latency claims lack detailed hardware configuration and standardized comparison with larger baselines.

## Confidence
- Performance claims (F1/AUC on UCF-Crime): Medium
- Accuracy-efficiency trade-off: Medium
- Prompt robustness: Low

## Next Checks
1. **Reproducibility audit**: Verify public release of training splits, LoRA adapters, and exact inference pipeline (preprocessing, frame-sampling, VLM backend).
