# Knowledge-Guided Failure Prediction: Detecting When Object Detectors Miss Safety-Critical Objects
## Quick Facts
- **arXiv ID:** 2603.25499
- **Source URL:** https://arxiv.org/abs/2603.25499
- **Reference Count:** 40
- **Primary Result:** KGFP improves person recall on accepted images from 64.3% to 84.5% at 5% FPR on COCO, achieving a safety AUROC of 92.9% and the highest average recall (34.2%) across six COCO-O visual domains.

## Executive Summary
The paper addresses the critical challenge of silent failures in safety-critical object detection, where a detector misses important objects (e.g., pedestrians) without any warning signal. Traditional out-of-distribution (OOD) detection methods focus on identifying novel data distributions but do not directly predict such functional failures. The proposed Knowledge-Guided Failure Prediction (KGFP) framework introduces a dual-encoder architecture that measures the semantic misalignment between an object detector's internal features and the embeddings of a robust visual foundation model (DINO). This angular distance serves as a selective-prediction gate, allowing a system to reject uncertain inputs. Evaluated on person detection, KGFP substantially outperforms state-of-the-art OOD detection baselines on in-distribution (ID) and OOD benchmarks, demonstrating its potential as a runtime safety monitor.

## Method Summary
KGFP trains a lightweight gating module to predict whether a given input image will cause a pre-trained object detector (YOLOv8) to miss any safety-critical objects (persons). It extracts multi-scale features from the detector's FPN and a global embedding from the frozen DINO ViT. These features undergo a two-stage fusion: first, a cross-scale attention module aggregates context across the different spatial resolutions; second, a transformer applies self-attention for spatial refinement and cross-attention to condition the detector's features on the DINO embedding. Both streams are then projected separately via MLPs into a shared 64-dimensional space. The cosine similarity (angular distance) between these normalized embeddings is the failure signal: a low similarity indicates a semantic divergence between the detector's internal representation and robust world knowledge, suggesting a likely miss. The system is trained with binary cross-entropy loss on labels derived from detector performance (an image is "unsafe" if any person ground truth is missed).

## Key Results
- At a 5% false positive rate (FPR), KGFP increases person recall on accepted images from a baseline 64.3% to 84.5% on COCO validation.
- It achieves the highest average recall (34.2%) across six challenging COCO-O visual corruption domains, outperforming OOD baselines by a large margin.
- KGFP attains a safety AUROC of 92.9% on COCO Val, significantly exceeding the best OOD detection alternative (GRAM, ~70%).

## Why This Works (Mechanism)
### Mechanism 1
**Claim:** Semantic misalignment between an object detector's internal features and a foundation model's embeddings predicts detection failure for safety-critical objects.
**Mechanism:** A dual-encoder architecture extracts multi-scale features from the detector (YOLOv8 FPN) and a global embedding from a foundation model (DINO ViT). These are fused via cross-attention, projected to a shared space, and their cosine similarity is computed. High misalignment (low cosine similarity) signals that the detector's interpretation of the scene diverges from semantically coherent world knowledge, indicating likely failure to detect safety-critical objects.
**Core assumption:** When a detector fails (e.g., misses a pedestrian due to occlusion or unusual conditions), its internal feature representations become semantically incongruent with robust, general-purpose visual embeddings learned from vast data.
**Evidence anchors:**
- [abstract] "KGFP measures semantic misalignment between internal object detector features and visual foundation model embeddings using a dual-encoder architecture with an angular distance metric."
- [section 3.2] Detailed description of feature extraction, fusion via transformer blocks, projection to shared 64D space, and cosine similarity as the failure signal.
- [corpus] Related work shows OOD detection methods focus on distributional novelty, not functional failure. The gap KGFP fills is using foundation model alignment for failure prediction.

### Mechanism 2
**Claim:** Framing failure prediction as a supervised binary classification problem on safety-critical classes is more effective for safety monitoring than unsupervised OOD detection.
**Mechanism:** Labels are derived from detector performance: an image is "unsafe" if any ground-truth safety-critical object is missed (IoU<0.5). This direct supervision teaches the model to recognize patterns associated with missed detections, rather than generic distribution shifts.
**Core assumption:** Discriminative patterns in the combined detector+foundation model representations correlate specifically with missed safety-critical objects and can be learned from labeled data.
**Evidence anchors:**
- [abstract] "KGFP is trained to predict the safety of In-Distribution (ID) data, and demonstrates generalization capabilities to OOD data."
- [section 3.1] Formal definition of the failure label `z(x)` based on missed persons, explicitly differentiating from OOD detection.
- [section 5.1] KGFP outperforms unsupervised OOD baselines (84.5% vs ~65% recall @ 5% FPR), showing the benefit of explicit failure supervision.

### Mechanism 3
**Claim:** Multi-scale feature fusion with cross-attention to foundation model embeddings creates semantically-grounded representations that are more predictive of failure than using either source alone.
**Mechanism:** YOLOv8's multi-scale FPN features are fused via pre-fusion cross-scale attention to aggregate context. The fused features are refined with post-fusion self-attention and cross-attention with DINO's [CLS] token, allowing detector features to "query" world knowledge and align with semantic concepts.
**Core assumption:** Detector failures often involve scene-level semantic inconsistencies (e.g., atypical occlusion) that are not captured in detector-specific features alone. Cross-attention enables the incorporation of this missing semantic context.
**Evidence anchors:**
- [section 3.2] "Pre-Fusion Cross-Scale Attention" and "Post-Fusion Transformer" descriptions.
- [section 5.2, Table 3 left] Ablation shows removing post-fusion cross-attention degrades ID recall by ~1%, and removing all attention degrades by 2.3%.
- [section 5.2, Table 3 center] DINO ViT-B/16 achieves highest ID recall (85.1%) among foundation models.

## Foundational Learning
- **Concept: Self-Supervised Vision Transformers (e.g., DINO)**
  - **Why needed:** Provide rich, general-purpose visual embeddings learned without labels, capturing semantic patterns (e.g., typical person shapes, occlusions) that task-specific detectors may not robustly represent. KGFP uses DINO as an external "sanity check" for semantic plausibility.
  - **Quick check:** *If you replaced DINO with a randomly initialized ViT, how would KGFP's performance on OOD domains like 'weather' or 'painting' change, and why?*

- **Concept: Angular Distance / Cosine Similarity as a Metric**
  - **Why needed:** The paper argues that the angle between normalized embeddings in a shared space is a more stable measure of semantic alignment than Euclidean distance in high dimensions. The decision threshold is derived from the expected angle between random vectors (~90°).
  - **Quick check:** *Why might an MLP-based similarity head be more prone to overfitting than a fixed cosine similarity metric on 64D embeddings?*

- **Concept: Selective Prediction / Rejection Option**
  - **Why needed:** KGFP acts as a gate that rejects uncertain images, preventing the object detector from acting on them. This is a runtime safety mechanism. The metric "Person Recall @ 5% FPR" quantifies safety-coverage trade-off.
  - **Quick check:** *How would you interpret a high False Positive Rate (FPR) for the KGFP gate in deployment? What operational action would likely follow?*

## Architecture Onboarding
- **Component map:** YOLOv8 FPN Features (P3, P4, P5) -> Pre-Fusion Cross-Scale Attention -> Post-Fusion Transformer (Self + Cross-Attn with DINO) -> Dual MLP Encoders (to 64D) -> Cosine Similarity.
- **Critical path:** Input image -> Extract YOLOv8 multi-scale features & DINO [CLS] embedding -> Upsample/fuse YOLO scales via cross-attention -> Patchify and apply transformer (self then cross-attention) -> Project both streams to 64D -> Compute cosine similarity -> Threshold for safety decision.
- **Design tradeoffs:**
  - **Compute vs. Safety:** Dual forward passes (YOLO + DINO) and attention layers add significant latency (~2-3x). Mitigation: cache DINO embeddings or frame-skip in video.
  - **Frozen vs. Adaptive Backbones:** Using pretrained frozen models ensures stability but limits adaptation to new domains. Continual adaptation of the DINO encoder is a future need.
  - **Supervision:** Requires failure labels from detector performance. The binary "all persons detected" label is coarse; spatial localization or graded risk scores could be richer.
  - **Embedding Dim:** 64D chosen for balance; higher dimensions lead to overparameterization and poor angular structure.
- **Failure signatures:**
  - **Embedding collapse:** Mean cosine similarity approaching 1 during training (not observed, but possible with poor regularization).
  - **Threshold sensitivity:** The fixed 0.843 threshold is calibrated on COCO Val ID data. Performance on OOD domains may suffer if the score distribution shifts.
  - **Foundation model mismatch:** Using CLIP instead of DINO reduces ID performance slightly.
- **First 3 experiments:**
  1. **Architecture Ablation (Table 3 left):** Systematically remove pre-fusion attention, post-fusion cross-attention, self-attention, and all attention. Measure impact on Person Recall @ 5% FPR for ID and OOD average.
  2. **Foundation Model Comparison (Table 3 center):** Replace DINO ViT-B/16 with SigLIP, DINOv2, CLIP. Compare ID/OOD recall and parameter count.
  3. **Embedding Dimension & Optimizer Sweep (Table 3 right):** Vary shared embedding size (64, 128, 256, 512) and optimizer (LARS vs. Adam). Identifies 64D + LARS as optimal.

## Open Questions the Paper Calls Out
### Open Question 1
**Question:** Why does DINO's self-supervised training objective yield superior failure prediction performance compared to other foundation models (e.g., CLIP, SigLIP), and what specific visual failure patterns does it capture that others miss?
**Basis:** The authors explicitly compare DINO to CLIP, SigLIP, and DINOv2, finding DINO ViT-B/16 achieved the highest ID recall (85.1%). They hypothesize that DINO's self-distillation objective produces spatially coherent attention maps sensitive to "fine-grained visual cues as partial occlusions, atypical poses, unusual lighting," whereas CLIP's language-aligned features are less sensitive to these "sub-textual failure patterns."
**Why unresolved:** The paper provides a plausible hypothesis but lacks rigorous analysis (e.g., probing attention maps, failure case studies) to confirm which specific failure modes are uniquely detected by DINO. The relative importance of self-supervision versus model scale is unclear.
**What evidence would resolve it:** A detailed, quantifiable breakdown of KGFP's true positives/false negatives across failure types (occlusion, scale, pose, weather) when using different foundation models. Visualizations and metrics comparing alignment scores for success/failure cases across models. Controlled experiments isolating factors like pretraining objective and model architecture.

### Open Question 2
**Question:** Can the KGFP framework be extended to predict *partial* failures (e.g., specific missed object instances or categories) rather than a binary "safe/unsafe" image-level label, and how does this affect its practical utility for risk-aware decision-making?
**Basis:** The authors state a limitation: "The all-or-nothing safety label... may be too coarse for some applications. Extensions could predict expected miss counts or provide spatial failure localization."
**Why unresolved:** The current formulation predicts if *any* safety-critical object is missed. In practice, a system might need to know *how many* or *which specific* objects are likely missed to make graded safety decisions. The paper does not explore this.
**What evidence would resolve it:** Development and evaluation of a modified KGFP that outputs instance- or category-level failure probabilities. Testing its correlation with the actual number and location of missed detections. A user study or simulation showing how finer-grained predictions improve downstream controller policies.

### Open Question 3
**Question:** How robust is KGFP against *adversarial inputs* designed to simultaneously fool the object detector (YOLOv8) and the foundation model (DINO) to produce high alignment (low failure score) on an unsafe image?
**Basis:** The paper discusses robustness to natural corruptions (COCO-O) but states: "Adversarial perturbations designed to fool both YOLOv8 and DINO could evade safety monitoring." This is presented as a future concern, not tested.
**Why unresolved:** The core assumption is that detector and foundation model representations diverge on failure images. An adversary could craft inputs causing both models to produce *individually incorrect but mutually consistent* representations, yielding a false "safe" prediction. No analysis of this threat model exists.
**What evidence would resolve it:** Systematic adversarial attack experiments (e.g., PGD, CE) targeting the dual-encoder system's failure score. Measuring attack success rate in causing missed detections while keeping the KGFP safety score below threshold. Analysis of whether attacks transfer between models and whether adversarial training or detection of such manipulated alignment scores is possible.

## Limitations
- **Architecture Specs:** Critical fusion components (pre-fusion cross-scale attention, post-fusion transformer details) are underspecified, blocking exact replication.
- **Foundation Model Reliance:** Performance hinges on DINO's semantic robustness; its failure on novel OOD data may cause false positives, and replacement with weaker models breaks the core premise.
- **Threshold Calibration:** The 0.843 threshold is tied to a specific COCO Val split; its stability across random splits or new datasets is unknown, risking deployment FPR drift.

## Confidence
- **Mechanism 1 (Angular Misalignment):** Medium. Strong correlation shown, but causal link relies on DINO's universal semantic stability—unproven on extreme OOD.
- **Mechanism 2 (Supervised Failure Prediction):** High. Direct comparison to unsupervised OOD methods consistently favors KGFP; the advantage of explicit failure labels is empirically validated.
- **Mechanism 3 (Fusion Architecture):** High. Ablations confirm each module's contribution, though exact design choices remain opaque.
- **Overall Safety Improvement:** High. COCO and COCO-O results are clear and outperform baselines by large margins.
