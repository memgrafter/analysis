# BabyVision: Visual Reasoning Beyond Language

## Quick Facts
- **arXiv ID**: 2601.06521
- **Source URL**: https://arxiv.org/abs/2601.06521
- **Reference count**: 12
- **Primary result**: State-of-the-art MLLMs achieve only ~50% accuracy on basic visual reasoning tasks that adults solve with ~94% accuracy, revealing a fundamental gap in pre-linguistic visual skills.

## Executive Summary
This paper introduces BabyVision, a benchmark designed to isolate and evaluate the foundational visual reasoning abilities that humans acquire before language development. The authors argue that current multimodal large language models (MLLMs) suffer from a "verbalization bottleneck," where continuous visual features are compressed into discrete language-like tokens, leading to failures in fine-grained discrimination, spatial tracking, and 3D mental simulation. Testing 11 frontier MLLMs on 388 vision-only questions across 22 subclasses showed a large performance gap: the best model scored 49.7% versus 94.1% for adults, with visual tracking and spatial perception being the weakest domains. The study also presents BabyVision-Gen for visual-generation–based evaluation, where models failed catastrophically on tasks requiring continuous trajectory generation (0% accuracy). Reinforcement learning with verifiable rewards (RLVR) yielded a modest 4.8-point gain, but only on language-amenable tasks. The work highlights that excelling on knowledge-intensive multimodal benchmarks does not imply mastery of core visual primitives, calling for architectural changes to preserve visual fidelity beyond linguistic mediation.

## Method Summary
The study constructs BabyVision, a benchmark of 388 multiple-choice and fill-in-the-blank questions that require only visual input (no language context) across four domains: fine-grained discrimination, visual tracking, spatial perception, and visual pattern recognition. Questions are derived from developmental psychology and designed to be solvable by children before age 6. Each item undergoes double-blind annotation to ensure unambiguous solutions. An automatic evaluation pipeline uses LLM-as-judge (Qwen3-Max for BabyVision, Gemini-3-Flash for BabyVision-Gen) to score model outputs, achieving 96.1% agreement with human annotators. BabyVision-Gen extends this to 280 image-generation tasks where models must annotate an image visually (e.g., draw a path), with evaluation based on binary correctness of the generated annotation. The paper evaluates 11 proprietary and open-source MLLMs, reports per-subclass accuracy, and conducts an RLVR experiment on Qwen3-VL-8B-Thinking using 1,400 synthesized training examples.

## Key Results
- State-of-the-art MLLMs lag far behind human adults (94.1%) and typical 6-year-olds, with the best model (Gemini3-Pro-Preview) scoring only 49.7%.
- Models are weakest in Visual Tracking (e.g., maze navigation, line tracing) and Spatial Perception (e.g., 3D block counting), with the top open-source model (Qwen3-VL-8B) at 22.2% overall.
- RLVR improves Qwen3-VL-8B-Thinking by 4.8 points overall but yields negligible or negative gains on tracking tasks.
- On BabyVision-Gen, leading generation models (e.g., NanoBanana-Pro) attain only 18.3% overall, with 0% on tasks requiring continuous trajectory generation, underscoring persistent challenges in visual-spatial generation.

## Why This Works (Mechanism)
**Mechanism 1: Verbalization bottleneck**
- Claim: MLLMs lose fine-grained visual details because continuous geometric features are compressed into discrete linguistic tokens during processing, flattening sub-semantic cues (e.g., exact curvatures) into coarse semantic descriptors.
- Core assumption: Language-mediated reasoning discards "undescribable" visual properties readily processed in non-verbal perception.
- Evidence: Over-verbalization of geometry in failure cases; tasks like "Find the Different" expose reliance on semantic clusters rather than pixel-level差异. Related work (HueManity) shows similar fine-grained perception gaps.
- Break condition: If models solve fine-grained discrimination without text output (e.g., via pixel matching or generation), the hypothesis weakens.

**Mechanism 2: Loss of manifold identity**
- Claim: MLLMs fail to track continuous 1D manifolds (e.g., lines, paths) through spatial intersections because they lack persistent contour representations.
- Core assumption: Humans use primitive contour integration to lock onto curves; MLLMs map trajectories to discrete reasoning steps, losing topological consistency.
- Evidence: Largest failures in Visual Tracking (maze/line-tracing); "track-switching" and endpoint hallucination at intersections.
- Break condition: Reliable tracing via visual output (BabyVision-Gen) would suggest the deficiency is addressable through non-verbal pathways.

**Mechanism 3: Failure of spatial imagination**
- Claim: MLLMs cannot construct stable 3D mental models from 2D inputs and fail mental affine transformations (e.g., rotation, occlusion inference).
- Core assumption: Humans mentally simulate volumetric transformations; MLLMs approximate via descriptive language, preserving no coordinate system.
- Evidence: Poor performance on spatial perception tasks (e.g., 3D view selection); errors in occlusion and volume estimation.
- Break condition: Consistent success on 3D transformation tasks validated by internal probing or generation indicates overcoming the spatial bottleneck.

## Foundational Learning
- **Concept: Core Knowledge (Spelke, 2000)**  
  Why needed here: BabyVision assumes humans possess innate, pre-linguistic systems for representing objects, space, and continuity; MLLMs lack these foundational priors.  
  Quick check question: What are the four core knowledge systems hypothesized to be innate in infants?

- **Concept: Object Permanence**  
  Why needed here: Tasks like tracking occluded lines or counting hidden blocks require representing unseen but existent elements—a skill emerging by 3–4 months.  
  Quick check question: At what age do infants typically demonstrate object permanence for partially occluded objects?

- **Concept: Visual Primitives**  
  Why needed here: The benchmark isolates atomic visual competencies (discrimination, tracking, spatial perception, pattern recognition) that precede language; MLLMs are not explicitly trained on these primitives.  
  Quick check question: Give two examples of visual primitives that develop before language acquisition.

- **Concept: Contour Integration**  
  Why needed here: Critical for Visual Tracking tasks; humans integrate fragmented edges into unified contours, an ability present early in infancy.  
  Quick check question: What visual phenomenon describes the ability to perceive continuous contours amidst clutter?

## Architecture Onboarding
**Component map**:  
Vision encoder (e.g., CLIP-style) → visual token projection → language model backbone (LLM) → output head.  
BabyVision-Gen adds: → visual generation module (diffusion/autoregressive image generator).

**Critical path**:  
Input image → dense visual features → compressed visual tokens (bottleneck) → LLM processes tokens with language reasoning → answer generated. For BabyVision-Gen, final output is an annotated image instead of text.

**Design tradeoffs**:  
- Compression vs. fidelity: Projector layers reduce visual information to fit LLM context, losing fine details needed for perceptual tasks.  
- Language bias: LLM reasoning prioritizes semantic patterns over spatial ones, incentivizing shortcuts.  
- Generation cost: Visual output enables non-verbal reasoning but requires expensive generative models and complex evaluation.

**Failure signatures**:  
- Fine-grained tasks: Over-reliance on semantic clusters, missing subtle differences.  
- Tracking tasks: Path discontinuity at intersections, endpoint errors.  
- Spatial tasks: Inconsistent 3D volume estimates, incorrect occlusion handling.  
- Pattern tasks: Focus on surface attributes (color) over relational transformations.

**First 3 experiments**:  
1. Baseline replication: Run Qwen3-VL-8B on BabyVision; confirm large gap with human baseline and measure per-subtype accuracy.  
2. Ablation on failure modes: Select a high-error subtype (e.g., "Count 3D Blocks"); analyze 20 failures to categorize error type (fine detail loss, spatial imagination, etc.).  
3. RLVR pilot: Apply GRPO (from EasyR1) to Qwen3-VL-8B-Thinking on 500 BabyVision-style examples; measure delta per subtype, expecting gains in pattern recognition but not tracking.

## Open Questions the Paper Calls Out
**Open Question 1**: Why do state-of-the-art MLLMs fail on basic visual reasoning tasks that young children solve effortlessly, despite excelling at knowledge-intensive benchmarks?  
Basis: Section 6.1 identifies four systematic failure modes—loss of fine-grained detail, loss of manifold identity, failure of spatial imagination, and verbalization bottleneck—all stemming from compressing visual information into language representations.  
Why unresolved: The paper diagnoses modes but does not test architectural interventions that preserve visual fidelity or compare to neurodevelopmental mechanisms.  
What evidence would resolve: Ablation studies contrasting models with language bottlenecks versus native multimodal reasoning (e.g., Bagel) on BabyVision; representational analyses linking model errors to human infant visual development stages.

**Open Question 2**: Why does Reinforcement Learning with Verifiable Rewards (RLVR) improve overall visual reasoning in MLLMs but fail to enhance performance on visual tracking tasks?  
Basis: Section 6.2 shows RLVR on Qwen3-VL-8B-Thinking yields +4.8 overall gain but negligible/negative improvement on tracking (e.g., "Connect the Lines," "Maze").  
Why unresolved: Authors speculate tracking is less amenable to verbalization, so RLVR's language-focused optimization may not transfer; hypothesis lacks direct validation.  
What evidence would resolve: Controlled RLVR experiments on tracking tasks with/without intermediate language descriptions; probing model attention or feature coherence during trajectory tracing to determine what RLVR optimizes.

**Open Question 3**: How can visual generation models be trained or architected to reliably perform complex spatial reasoning tasks requiring continuous trajectory maintenance or 3D coherence?  
Basis: Section 5.3 and 6.3 report BabyVision-Gen scores only 18.3% overall, with 0% on maze/line-tracing, despite some human-like drawing behaviors.  
Why unresolved: Suggests generation bypasses verbalization bottleneck but provides no systematic exploration of training objectives, guided generation, or unified architectures.  
What evidence would resolve: Development of spatial reasoning training objectives (differentiable rendering losses, trajectory rewards); evaluation of native multimodal generative models (Bagel) on BabyVision-Gen; error analysis pinpointing generation drift in extended sequences.

**Open Question 4**: Do the failure modes identified in BabyVision correspond to specific developmental visual primitives in children, and are there age-dependent skills that MLLMs lack entirely?  
Basis: Paper compares models to children aged 3–12 but aggregates results broadly; models lag behind 6-year-olds but no fine-grained mapping to developmental milestones.  
Why unresolved: Without age-to-subtype analysis, unclear whether models miss early-born skills (e.g., tracking) or later ones (e.g., abstract transformations).  
What evidence would resolve: Testing BabyVision on narrower age bands (e.g., 4, 5, 7, 9 years) to derive a developmental accuracy curve; correlating model performance with known infant/child visual competencies to identify most delayed primitives.

## Limitations
- **Benchmark scope**: BabyVision isolates pre-linguistic skills but its 388 items may not capture the full breadth of human visual cognition (e.g., dynamic scenes, tactile-visual integration). Age-equivalence claims are informal comparisons, not controlled developmental studies.
- **Generation evaluation validity**: BabyVision-Gen’s automatic judge (96.1% human agreement) was validated only on one model (NanoBanana-Pro); consistency across diverse generative architectures is unknown. The "DO NOT modify original image" constraint is hard to enforce in text-to-image models, risking false failures.
- **Training data opacity**: The 1,400 RLVR training examples are unreleased, preventing replication of the +4.8% gain and assessment of generalization vs. overfitting.

## Confidence
- **High**: Claims about existence of a performance gap on the released BabyVision test set (388 items) and the benchmark’s construction methodology.
- **Medium**: Assertions that the gap stems from "verbalization bottleneck," "loss of manifold identity," or "spatial imagination failure"—plausible interpretations of error patterns, not causally proven mechanisms.
- **Low**: That RLVR improvements reflect fundamental architectural fixes. Unreleased training data prevents verifying whether gains are task-specific or transferable.

## Next Checks
1. **Reproduce core benchmark results**: Run Qwen3-VL-8B-Thinking on public BabyVision test set; verify per-subclass accuracy matches paper-reported ranges (e.g., <30% on tracking tasks). Log format-extraction mismatches.
2. **Judge robustness probe**: On 100 random BabyVision-Gen items, have three human annotators independently judge automatic evaluation outcomes; compute agreement with Gemini-3-Flash. If agreement <90%, recalibrate judge prompts or add human validation.
3. **Mechanism sanity check via ablation**: For a fine-grained discrimination task (e.g., "Find the Different"), run a non-verbal baseline: compute pixel-level SSIM between image pairs without LLM. If SSIM correlates with human performance, it supports the verbalization bottleneck hypothesis.
