# Neural Field Thermal Tomography: A Differentiable Physics Framework for Non-Destructive Evaluation

## Quick Facts
- arXiv ID: 2603.11045
- Source URL: https://arxiv.org/abs/2603.11045
- Reference count: 40
- Primary result: NeFTY achieves order-of-magnitude lower reconstruction error (MSE 3.66×10⁻⁴) and superior defect localization (IoU 0.45) compared to grid optimization and PINN methods on synthetic benchmarks, while maintaining high accuracy in surface temperature prediction (MSE 0.5×10⁻⁴) and reducing memory usage via adjoint gradients.

## Executive Summary
NeFTY introduces a differentiable physics framework for reconstructing three-dimensional thermal diffusivity fields from transient surface temperature measurements, a key task in non-destructive evaluation. It represents diffusivity as an implicit neural field and enforces the heat equation as a hard constraint via a differentiable numerical solver, avoiding the gradient stiffness and spectral bias of soft-constrained physics-informed neural networks. On synthetic benchmarks, NeFTY drastically outperforms grid-based optimization and PINN-based inversion, achieving an order-of-magnitude lower mean squared error (MSE) and substantially better defect localization (IoU). The adjoint gradient method reduces peak memory consumption from 18.6 GB to 4.3 GB, enabling high-resolution 3D inversion on standard hardware and demonstrating the viability of neural fields combined with differentiable solvers for inverse problems.

## Method Summary
NeFTY casts thermal tomography as an inverse problem: given surface temperature evolution \(T_{surf}(x,y,t)\), infer the spatially varying thermal diffusivity \(\alpha(\mathbf{x})\). The diffusivity field is represented by a coordinate-based neural network (an implicit neural field) that outputs \(\alpha\) for any 3D coordinate. A differentiable numerical solver (e.g., finite differences) integrates the heat equation \(\partial T/\partial t = \nabla \cdot (\alpha \nabla T)\) with specified initial and boundary conditions, yielding predicted surface temperatures. A loss measures mismatch between predicted and measured surface temperatures. Gradients of the loss with respect to the neural field parameters are obtained via an adjoint method, which solves a backward-in-time adjoint equation, thereby avoiding storage of forward solver states. This hard‑constraint approach guarantees physical consistency (up to numerical error) and sidesteps the spectral bias and stiffness issues that arise when the PDE is enforced as a soft penalty in PINNs.

## Key Results
- Reconstruction error (MSE): 3.66×10⁻⁴, vs 12.61×10⁻⁴ for grid optimization and 208.3×10⁻⁴ for PINN.
- Defect localization (IoU): 0.45 for NeFTY vs 0.07 (grid) and 0.01 (PINN); supervised U‑Net baseline achieved 0.70.
- Memory efficiency: adjoint gradients reduce peak memory from 18.6 GB to 4.3 GB, enabling high‑resolution 3D inversion.

## Why This Works (Mechanism)
NeFTY’s hard‑constraint formulation ensures that any proposed diffusivity field produces a physically valid temperature evolution, eliminating the need to balance multiple loss terms and avoiding gradient stiffness and spectral bias inherent in soft‑constrained PINNs. The differentiable solver propagates gradients accurately through the forward PDE solve. Moreover, the adjoint method computes these gradients with constant memory relative to the number of time steps, dramatically reducing memory overhead. This combination yields a smoother, more informative optimization landscape, leading to faster convergence and higher‑fidelity reconstructions.

## Foundational Learning
- **Implicit Neural Representations (INRs)**: Continuous fields via coordinate‑based networks. *Why needed*: Compact, differentiable parameterization of high‑dimensional 3D diffusivity. *Quick check*: Fit a known function (e.g., Gaussian blob) and measure representation error.
- **Physics-Informed Neural Networks (PINNs)**: Soft enforcement of physical laws in loss. *Why needed*: Baseline for physics‑based learning; highlights advantages of hard constraints. *Quick check*: Solve a simple PDE with a PINN and compare to analytical solution.
- **Differentiable Physics Solvers**: Numerical solvers supporting automatic differentiation. *Why needed*: Bridge neural field and forward PDE model; enables gradient flow. *Quick check*: Compute gradient of loss w.r.t. a parameter using finite differences vs autodiff.
- **Adjoint Gradient Method**: Compute gradients by solving backward‑in‑time adjoint equation. *Why needed*: Reduces memory from O(N) to O(1) relative to time steps; essential for high‑resolution 3D inversion. *Quick check*: Compare memory usage and gradient correctness with forward accumulation on a small problem.
- **Thermal Diffusivity Tomography**: NDE technique using thermal data to infer internal material properties. *Why needed*: Application domain; defines forward/inverse problems. *Quick check*: Reconstruct a simple layered medium from synthetic surface temperatures.

## Architecture Onboarding
Component map: Neural Field (diffusivity) -> Differentiable Heat Solver -> Predicted Surface Temperatures -> Loss (vs measurements) -> Adjoint Gradient -> Neural Field Parameters Update

Critical path: The adjoint gradient computation links the loss to the neural field parameters with constant memory, enabling large‑scale 3D inversion.

Design tradeoffs: Hard vs soft constraint (accuracy vs training stability); solver choice (explicit vs implicit, stability vs cost); network capacity (representation power vs optimization difficulty); adjoint implementation (memory vs compute).

Failure signatures: Solver instability (temperature blow‑up or NaNs), neural field convergence failure (loss plateau), high sensitivity to measurement noise, memory overflow if forward‑mode differentiation is used.

First experiments: 1. Train NeFTY on a homogeneous block with a single spherical defect from noiseless synthetic data; verify accurate recovery of defect shape and size. 2. Add Gaussian noise to surface temperatures at various SNR levels; quantify degradation in MSE and IoU to assess noise robustness. 3. Increase 3D grid resolution (e.g., 32³ → 128³) and measure peak memory and runtime to confirm the adjoint method’s memory advantage and identify practical limits.

## Limitations
- Synthetic‑only validation; real‑world performance uncertain.
- Assumes linear, isotropic heat conduction; may fail for anisotropic or nonlinear materials.
- Limited analysis of noise robustness and incomplete sensor coverage.

## Confidence

- Memory reduction via adjoints: High

## Next Checks
