# Cross-Domain Policy Optimization via Bellman Consistency and Hybrid Critics

## Quick Facts
- **arXiv ID**: 2603.12087
- **Source URL**: https://arxiv.org/abs/2603.12087
- **Reference count**: 0
- **Primary result**: QAvatar reduces environment steps to reach performance thresholds by 29-56% versus SAC and robustly handles low-quality or adversarial source models.

## Executive Summary
Cross-domain reinforcement learning (RL) suffers when transferring knowledge from a source domain to a target domain with distinct state-action spaces and unknown transferability, often resulting in negative transfer. This paper introduces QAvatar, a method that quantifies source model transferability via cross-domain Bellman consistency and employs hybrid critics to adaptively combine source and target Q-functions. An inter-domain mapping is learned by minimizing a cross-domain Bellman loss, bridging the domain gap. Experiments on MuJoCo locomotion, Robosuite manipulation, and DeepMind Control Suite image tasks show QAvatar significantly outperforms baselines (CMD, CAT, PAR, SAC, FT), reducing sample complexity by 29-56% relative to SAC and dynamically downweighting harmful source advice.

## Method Summary
QAvatar integrates three core components: (1) a transferability estimator that computes cross-domain Bellman consistency to assess how well a frozen source Q-function aligns with target dynamics; (2) a hybrid critic that linearly combines the source and a learned target Q-function using a weight derived from their relative prediction errors, eliminating hyperparameters; and (3) an inter-domain mapping network trained to minimize a Bellman loss, ensuring consistency between source Q-values and target bootstrapped targets. The target policy is updated using the hybrid critic, while the target Q-function undergoes standard off-policy temporal-difference updates. This design enables safe integration of source knowledge and mitigates negative transfer.

## Key Results
- Outperforms baselines (CMD, CAT, PAR, SAC, FT) on MuJoCo, Robosuite, and DMC image-based tasks.
- Reduces environment steps to reach performance thresholds by 29-56% versus SAC.
- Dynamically downweights harmful source advice, ensuring robust transfer even with low-quality or adversarial source models.

## Why This Works (Mechanism)
Bellman consistency provides a natural transferability metric: it measures whether a source Q-function, when rooted in target transitions, satisfies the target's Bellman equation. High consistency indicates accurate value estimates under target dynamics, making the source suitable for bootstrapping. The hybrid critic leverages this by weighting the source Q according to its relative error; when the source is reliable it contributes more, otherwise the target Q dominates. Learning the inter-domain mapping via Bellman loss aligns the source with the target, effectively bridging structural gaps. Together, these mechanisms allow QAvatar to incorporate beneficial source knowledge while avoiding negative influences, leading to improved sample efficiency and robustness.

## Architecture Onboarding
**Component map (plain text)**  
Source Q‑function (fixed) → Inter‑domain mapping (M) → Cross‑domain Bellman loss → Update M  
Target experience (s,a,r,s') → Compute target Q‑values → Bellman consistency estimator → Transferability score → Weight generator (w)  
Target Q‑function (trainable) → Standard TD loss → Update Q_t  
Hybrid critic: Q_h = w·Q_s + (1‑w)·Q_t → Policy update (e.g., SAC)  
Replay buffer → supplies batches for all updates

**Critical path**  
1. Collect target transitions and store in replay buffer.  
2. Sample a batch; update target Q‑network via TD loss.  
3. Update inter‑domain mapping M by minimizing the cross‑domain Bellman loss (using source Q and target data).  
4. Compute relative prediction errors of Q_s and Q_t on the batch; derive weight w.  
5. Form hybrid Q‑values Q_h = w Q_s + (1‑w) Q_t.  
6. Update policy network using Q_h as critic.  
7. Periodically refresh target networks.

**Design tradeoffs**  
- Hyperparameter‑free weight simplifies tuning but may be less robust if error estimates are biased.  
- Learning an inter‑domain mapping adds computational overhead and may struggle with large domain gaps.  
- Relying on Bellman consistency assumes the source Q is approximately optimal in parts of the target; if domains are too dissimilar, useful knowledge may be discarded.  
- Hybrid critic could introduce overestimation bias if source and target Q‑values are not properly scaled.

**Failure signatures**  
- Weight w collapses to 0 or 1 constantly, indicating either source is entirely ignored or target is not learning.  
- Mapping loss plateaus at a high value, suggesting the domains are not alignable.  
- Policy performance degrades below using only target RL (e.g., SAC), signaling negative transfer.  
- High variance in w across batches leads to unstable training curves.
