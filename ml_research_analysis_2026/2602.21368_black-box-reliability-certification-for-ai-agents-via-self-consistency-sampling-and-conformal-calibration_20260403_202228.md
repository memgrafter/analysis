# Black-Box Reliability Certification for AI Agents via Self-Consistency Sampling and Conformal Calibration

## Quick Facts
- **arXiv ID:** 2602.21368  
- **Source URL:** https://arxiv.org/abs/2602.21368  
- **Reference count:** 0  
- **Primary result:** Achieves conditional coverage >0.93 on solvable items across fifteen model–benchmark configurations; reliability scores reflect capability (e.g., GPT-4.1: 94.6% GSM8K, 96.8% TruthfulQA); sequential stopping reduces API costs by ~50% while preserving coverage guarantees; agent bias is transparently signaled via larger prediction sets.

## Executive Summary
We introduce a method to produce a single-number reliability certification for black‑box AI agents. The approach draws multiple outputs from the agent (self‑consistency sampling), aggregates them via canonicalization and ranking, and then applies conformal calibration on a small human‑labeled set to compute a reliability level. This level corresponds to the highest confidence such that the top‑ranked answers cover the acceptable answer with a user‑specified probability. Across fifteen model–benchmark configurations, conditional coverage on solvable items exceeds 0.93. The resulting reliability scores meaningfully differentiate model capabilities (e.g., GPT‑4.1 vs. GPT‑4.1‑nano). A sequential stopping variant cuts sampling costs by half without weakening the guarantee. Systematic agent bias does not hide behind a single score; it manifests as larger prediction sets, providing a clear diagnostic.

## Method Summary
The method requires a black‑box agent, a task with an `Accept(x,a)` predicate, a small human‑labeled calibration set (size *n*), and a fixed number of self‑consistency samples *K*. During calibration, for each query the agent is sampled *K* times; responses are canonicalized into equivalence classes, ranked by frequency, and the rank of the acceptable answer becomes a nonconformity score. The *k*th smallest score (with *k* = ⌈(*n*+1)(1–*α*)⌉) defines threshold *M*⋆. At test time, new queries are similarly sampled *K* times, canonicalized, and ranked; the top‑*M*⋆ classes form the prediction set. A reliability level is also reported: the fraction of calibration items where the acceptable answer ranked first. Sequential stopping can reduce *K* adaptively per query while preserving coverage. All guarantees hold under exchangeability of calibration and test data and i.i.d. samples from the agent.

## Key Results
- Conditional coverage on solvable items exceeds 0.93 in all fifteen model–benchmark configurations.
- Reliability scores vary systematically with capability (e.g., GPT‑4.1: 94.6% on GSM8K, 96.8% on TruthfulQA; GPT‑4.1‑nano: 89.8% on GSM8K, 66.5% on MMLU).
- Sequential stopping reduces API costs by approximately 50% while preserving the coverage guarantee, and agent bias is made visible through larger prediction sets rather than hidden in a single score.

## Why This Works (Mechanism)
### Mechanism 1: Exponential variance reduction via self‑consistency
- **Claim:** Self‑consistency sampling reduces the variance of the agent’s consensus answer exponentially, making the mode a more reliable indicator of the true acceptable answer.  
- **Mechanism:** Multiple i.i.d. samples are aggregated by canonicalizing and ranking answers by frequency. The probability that the top‑ranked (mode) answer is correct decays exponentially in the number of samples *K*, provided the correct canonical class probability *p* > ½.  
- **Core assumption:** The *K* samples per query are independent and identically distributed from a fixed agent policy; canonicalization correctly groups semantically equivalent answers.  
- **Evidence anchors:** Abstract states “Self‑consistency sampling reduces uncertainty exponentially”; Section 4.4 (Theorem 4.4) formalizes exponential decay via Hoeffding’s inequality.  
- **Break condition:** Violation of i.i.d. sampling (e.g., correlated API calls) slows convergence. If *p* ≤ ½, variance reduction fails and the mode may be consistently wrong.

### Mechanism 2: Distribution‑free coverage via conformal calibration
- **Claim:** Conformal calibration transforms the ranked consensus into a prediction set with a finite‑sample, marginal coverage guarantee that holds regardless of the agent’s biases.  
- **Mechanism:** A small calibration set provides nonconformity scores (the rank of the acceptable answer). The *k*th smallest score sets a threshold *M*⋆, so the top‑*M*⋆ answers form the prediction set. Exchangeability between calibration and test data ensures that the acceptable answer falls in this set with probability ≥ 1–*α* (up to a 1/(*n*+1) slack).  
- **Core assumption:** Calibration and test data are exchangeable; canonicalization is consistent across sets.  
- **Evidence anchors:** Abstract: “conformal calibration guarantees correctness within 1/(n+1) of the target level, regardless of the system’s errors”; Section 6.4 (Theorem 6.7) gives the finite‑sample guarantee.  
- **Break condition:** Exchangeability violations (e.g., temporal shift) invalidate the guarantee unless corrected (e.g., weighted conformal). Canonicalization errors inflate set sizes but do not break coverage.

### Mechanism 3: Transparent signaling of agent bias
- **Claim:** Agent bias (systematic errors where the most likely answer is wrong) is not hidden but becomes visible through larger prediction set sizes, providing a direct diagnostic of agent quality.  
- **Mechanism:** For queries where the agent is uncertain (*p*⋆ ≤ ½) or incapable, the acceptable answer ranks lower in the self‑consistency ordering, causing the calibrated threshold *M*⋆ to grow. Expected set size increases monotonically with the average rank of the acceptable answer.  
- **Core assumption:** The ranked consensus correctly reflects the agent’s output distribution; canonicalization does not collapse distinct correct and incorrect answers.  
- **Evidence anchors:** Abstract: “Agent bias is transparently signaled via larger prediction sets rather than hidden in scores.”; Section 7.5 (Theorem 7.5) proves monotonicity of set size in agent quality and that unsolvable items force *M*⋆ = ∞.  
- **Break condition:** Severe under‑merging fragments the correct class, inflating its rank; over‑merging merges incorrect classes into the correct cluster, making the mode wrong and degrading variance reduction. Both corrupt the set‑size diagnostic.

## Foundational Learning
- **Conformal prediction:** Provides distribution‑free, finite‑sample coverage guarantees for set‑valued predictions. Why needed here: It yields a formal reliability certificate that holds regardless of the agent’s internal biases or error profile.  
  *Quick check:* What does the 1/(*n*+1) slack in the coverage guarantee represent, and why is it conservative?

- **Self‑consistency decoding:** Aggregates multiple stochastic samples to identify a consensus answer, exponentially reducing variance when the correct answer is the mode. Why needed here: It is the only source of error reduction accessible without model internals.  
  *Quick check:* Why does self‑consistency fail to reduce bias when the agent’s probability of a correct answer is ≤ ½?

- **Canonicalization:** Maps semantically equivalent surface forms (e.g., “42”, “42.0”, “forty‑two”) to the same class. Why needed here: Ensures frequency counts reflect true semantic agreement, enabling meaningful consensus aggregation.  
  *Quick check:* How would fragmented canonical classes (e.g., splitting one correct answer into many) affect the variance reduction guaranteed by Theorem 4.4?

## Architecture Onboarding
**Component map:**  
Sampling module → Canonicalization engine → Ranking & nonconformity computation → Conformal calibrator → (optional: Sequential stopping controller)

**Critical path:**  
Calibration → compute nonconformity scores → threshold *M*⋆ → test time: sample → canonicalize/rank → return top‑*M*⋆ → coverage guarantee. Validity hinges on exchangeability and correct canonicalization.

**Design tradeoffs:**
- Sample count *K*: Larger *K* improves variance reduction but increases cost; sequential stopping reduces average cost by ~50% per query.
- Canonicalization method: Deterministic rules are preferred; LLM‑based canonicalization risks circular bias but is covered by the guarantee (larger sets compensate).
- Nonconformity score choice: Rank‑based score is discrete and conservative; continuous scores may tighten sets in ideal conditions but risk under‑coverage with coarse resolution (*K*=10).

**Failure signatures:**
- Marginal coverage < 1–*α* on test set: Check conditional coverage; low conditional coverage on solvable items suggests canonicalization fragmentation/over‑merging; coverage low only on unsolvable items indicates a capability gap *β* > *α*.
- Unstable *M*⋆ across bootstrap splits: The model sits near the capability boundary *β* ≈ *α*; consider the reliability level for a more stable summary.
- Sequential stopping uses near *K*<sub>max</sub> on many items: Consensus is marginal (*p*⋆ ≈ ½), so variance reduction is inherently limited.
- Set size |*S(x)*| = |*C(x)*| for many items: The acceptable answer never appeared in *K* samples, indicating extreme weakness (*p*⋆ << 1/*K*).

**First 3 experiments:**
1. **Coverage validation:** Sweep *α* ∈ {0.01,…,0.30} for a fixed model/task; confirm empirical coverage ≥ 1–*α*. Plot coverage vs. target (Figure 2); points below diagonal signal *β* > *α*.
2. **Variance reduction test:** Fix *α* and vary *K* ∈ {1,2,5,10,20}; measure mode error. Expect exponential decay on high‑accuracy tasks (Theorem 4.4). Plot mode error vs. *K* (Figure 3).
3. **Set‑size uncertainty correlation:** For each test query, compute consensus entropy *H(x)*. Correlate *H(x)* with |*S(x)*|; expect strong positive correlation (Section 11.4, Figure 4). Also validate that lower‑capability models have higher average |*S*| (Table 3).

## Open Questions the Paper Calls Out
- **Open Question 1:** How to obtain conditional (per‑query) coverage guarantees despite impossibility results? Distribution‑free conditional coverage is impossible without strong assumptions; new methods under realistic structure (e.g., smoothness, groups) are needed.
- **Open Question 2:** Can active learning reduce calibration set size below *n* ≥ 19 while preserving the 1/(*n*+1) coverage slack? Adaptive item selection may violate exchangeability; an algorithm with proof and empirical validation is required.
- **Open Question 3:** How to extend the framework to multi‑turn agent interactions where exchangeability fails? Conformal validity for Markovian or context‑dependent processes (e.g., conditional conformal) must be developed and validated on multi‑turn benchmarks.

## Limitations
- Canonicalization details are underspecified (missing judge prompt, embedding threshold, numeric rules), risking over‑/under‑merging that degrades variance reduction and set‑size diagnostics.
- The guarantee relies on exchangeability; deployment shifts (e.g., new domains) invalidate coverage unless weighted conformal is applied.
- Small calibration set sizes (e.g., *n* ≈ 82 on HumanEval) lead to a non‑negligible 1/(*n*+1) slack and unstable *M*⋆ across random splits.

## Confidence
- Self‑consistency variance reduction: **High** (Theorem 4.4, empirical validation on solvable tasks)
- Conformal coverage: **High** (Theorem 6.7; conditional coverage >0.93 in all 15 configurations)
- Bias transparency: **Medium** (Monotonicity proven, but set‑size diagnostic sensitive to canonicalization errors)
- Sequential stopping: **High** (Theorem 9.1; ~50% API saving demonstrated)

## Next Checks

2. **Exchangeability stress test:** Artificially create calibration‑test shift (e.g., by question difficulty); measure coverage drop; apply weighted conformal to recover the guarantee.
3. **Sequential stopping stability:** Across models with a wide range of *p*⋆, implement stopping; compare total API vs. fixed‑*K*, compute reduction, and bootstrap *M*⋆ to ensure low variance; verify coverage ≥ 1–*α*.
