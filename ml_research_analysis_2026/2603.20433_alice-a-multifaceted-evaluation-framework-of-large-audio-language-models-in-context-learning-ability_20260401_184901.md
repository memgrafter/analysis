# ALICE: A Multifaceted Evaluation Framework of Large Audio-Language Models' In-Context Learning Ability

## Quick Facts
- **arXiv ID:** 2603.20433
- **Source URL:** https://arxiv.org/abs/2603.20433
- **Reference count:** 0
- **Primary result:** In-context audio demonstrations reliably improve format compliance (up to ~30% gain) but fail to enhance core task performance, revealing LALMs' reliance on surface-level text pattern matching over cross-modal semantic grounding.

## Executive Summary
This paper introduces ALICE, a novel framework to evaluate the in-context learning (ICL) ability of Large Audio-Language Models (LALMs) under audio conditioning. ALICE systematically reduces textual guidance across three stages—explicit constraints, implicit constraints, and audio-only demonstrations—and tests models on four audio tasks. The key finding is a stark asymmetry: while format compliance rates (FCR) improve with demonstrations, core task metrics (word error rate, accuracy) remain unchanged or degrade, particularly when task descriptions are removed. This indicates that current LALMs cannot infer task objectives from audio-conditioned examples alone and instead rely on shallow pattern matching of output text formats.

## Method Summary
ALICE evaluates LALMs via a three-stage inference protocol that progressively removes textual guidance. Stage 1 provides explicit format instructions and in-context audio-label examples. Stage 2 removes explicit format rules, leaving only implicit patterns from examples. Stage 3 removes all task descriptions, presenting only audio-only demonstrations. Models are tested on four tasks—ASR (WER), SER, GR, MMAU (accuracy)—using two output constraint types: Closed-Ended Questions (CEQ) and Chain-of-Thought (CoT). For each model, task, and constraint, the evaluation samples *k* demonstrations (1–8) from a disjoint pool, constructs the stage-specific prompt, and measures FCR (via rule-based or LLM judge) and task performance. Zero-shot baselines are included for Stage 1.

## Key Results
- Format Compliance Rate (FCR) reliably improves with in-context demonstrations, with gains up to ~30% in Stage 1 for some models.
- Core task performance (WER for ASR, accuracy for others) remains stable or degrades when moving from Stage 1 to Stage 2, and drops substantially in Stage 3 for CEQ.
- The asymmetry persists across all six tested LALMs, indicating a general failure to leverage cross-modal semantic grounding for task inference.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** LALMs extract and replicate surface-level textual formatting patterns from in-context audio-label demonstrations without understanding the underlying audio task.
- **Mechanism:** The model performs shallow pattern matching on the textual output side of the demonstration examples (e.g., JSON structure, case, prefixes). The audio input serves as a contextual anchor but is not semantically integrated to inform the format decision.
- **Core assumption:** Format constraints are stereotypical text patterns separable from the audio-to-semantic mapping.
- **Evidence anchors:**
  - [abstract] "in-context demonstrations reliably improve format compliance rate (FCR), with gains up to ~30% in Stage 1... but fail to enhance core task performance"
  - [section 4.2] Format compliance decreases when explicit constraints are removed but task performance remains stable.
  - [section 4.3] FCR can remain high or even improve in Stage 3 (audio-only) while task performance degrades, indicating format inference does not require audio semantics.
- **Break condition:** When the format pattern is ambiguous, non-stereotypical, or conflicts with the model's prior textual biases.

### Mechanism 2
- **Claim:** Inferring the core task objective from audio-conditioned examples requires cross-modal semantic grounding that current LALMs lack.
- **Mechanism:** Task inference necessitates mapping acoustic features (phonemes, paralinguistics, sound events) to a textual label space defined by the task. Without explicit textual task descriptions, this mapping cannot be reliably learned from a few examples.
- **Core assumption:** Task semantics are embedded in the audio content, not just the output text format.
- **Evidence anchors:**
  - [abstract] "struggle to leverage cross-modal semantic grounding to reliably infer task objectives from audio-conditioned examples"
  - [section 4.3] Task performance in Stage 3 (audio-only) is "substantially below Stage 2" for CEQ, showing failure without explicit task wording.
  - [section 4.4] "CoT gains observed in Stage 3... indicate reliance on textual cues in reasoning traces rather than genuine audio–text integration."
- **Break condition:** When the audio content is acoustically ambiguous, out-of-distribution, or when the label set is large/abstract.

### Mechanism 3
- **Claim:** Strong instruction-following ability (zero-shot FCR) does not predict robust in-context format deduction from audio examples; these rely on different internal mechanisms.
- **Mechanism:** Instruction-following exploits the model's pretrained text-based directive comprehension. Format deduction from demonstrations requires recognizing output patterns *in the context of audio inputs*, a form of meta-learning that is disrupted by the audio modality's interference.
- **Core assumption:** The speech-text integration process in LALMs catastrophically forgets or impairs the parametric knowledge needed for ICL pattern recognition.
- **Evidence anchors:**
  - [abstract] "good instruction-following capability does not imply robust ICL deduction ability"
  - [section 4.2] Models with highest Stage 1 zero-shot FCR show substantial FCR drops in Stage 2, while weaker instruction-followers show smaller relative drops.
  - [introduction] Cites prior work on "degraded instruction-following capabilities" in LALMs, framing this as a shared underlying deficit.
- **Break condition:** When the model's text-only backbone has strong ICL capability, or when demonstrations contain misleading formatting patterns.

## Foundational Learning
- **Concept:** Cross-modal semantic grounding.
  - Why needed here: The core failure mode is the model's inability to map audio events to the semantic labels required by the task without explicit textual guidance. This is foundational to *task* inference.
  - Quick check question: Given an audio clip of a laughing child and a demonstration pairing a *different* audio clip with the text output "joy", can the model correctly label the new clip as "joy" without being told the task is emotion recognition?

- **Concept:** Surface pattern extraction.
  - Why needed here: This explains the consistent FCR improvements. The model isolates the text format from the audio context and replicates it, a much simpler operation than cross-modal mapping.
  - Quick check question: Given demonstrations with outputs in ALL CAPS, will the model output its answer in ALL CAPS even if the test instruction asks for standard case?

- **Concept:** Instruction variance robustness.
  - Why needed here: The ALICE stages manipulate textual guidance. A model sensitive to instruction phrasing may perform differently not due to ICL failure, but due to instability to linguistic variation.
  - Quick check question: If we rephrase the remaining text in Stage 2 while keeping the meaning identical, does the model's format compliance rate change significantly?

## Architecture Onboarding
- **Component map:**
  Audio Encoder -> Projection Layer -> LLM Backbone -> Context Manager

- **Critical path:** Raw Audio → Audio Encoder → Audio Embeddings → Projection → LLM Token Sequence (with text & audio) → Autoregressive Text Generation.
  - Key integration point: The projection layer's quality determines how well audio semantics align with textual concepts in the LLM's space.

- **Design tradeoffs:**
  - Modality Alignment vs. Catastrophic Forgetting: Training the projection layer on audio-text pairs may overwrite the LLM's pretrained ICL capabilities.
  - Context Window vs. Demonstration Quality: More examples (*k*) consume context length; marginal gains beyond *k*=1 for format suggest minimal effective context.

- **Failure signatures:**
  - High FCR + Low Task Accuracy (across Stages 1-3).
  - Task performance in Stage 3 (audio-only) drops precipitously for CEQ but stays stable for CoT.
  - Models with high zero-shot FCR show largest absolute FCR drop from Stage 1→2.

- **First 3 experiments:**
  1. **Baseline Replication:** Run Stage 1 (Explicit Constraint) for ASR CEQ with *k*=1 on Qwen2-Audio. Verify FCR ~55% and WER stable vs. zero-shot.
  2. **Progressive Ablation:** For same model/task, run all three stages. Observe FCR trend (Stage1→2↓, Stage2→3?↑/↓) and WER trend (stable Stage1→2, drop Stage2→3).
  3. **CoT vs. CEQ Contrast:** In Stage 3 (Audio Only), compare task performance for CoT vs. CEQ on SER/GR. Expect CoT to maintain/recover performance relative to CEQ.

## Open Questions the Paper Calls Out
- **Open Question 1:** Can ALICE's three-stage framework be extended to evaluate ICL in open-ended generative audio tasks (e.g., audio-based storytelling or dialogue generation), and would the observed format-vs-task asymmetry persist?
  - Basis in paper: [explicit] The conclusion states that "extending ALICE to open-ended generation, richer semantic settings, more diverse tasks such as speech synthesis remains an important direction for future work."
  - Why unresolved: The current framework is limited to format-constrained understanding tasks; it is unknown whether the asymmetry holds when outputs are more creative.

- **Open Question 2:** What specific architectural or training deficits in LALMs cause them to rely on surface-level pattern matching for format inference while failing at cross-modal semantic grounding for task objectives?
  - Basis in paper: [inferred] The paper attributes the asymmetry to LALMs' inability to "leverage cross-modal semantic grounding" but does not identify precise mechanisms.
  - Why unresolved: The exact failure modes—e.g., whether audio features are ignored, compressed, or incompletely fused—remain unknown.

- **Open Question 3:** Does strong instruction-following ability in LALMs correlate with robust ICL deduction from audio-only demonstrations, or are these capabilities governed by distinct mechanisms?
  - Basis in paper: [explicit] The authors note that "good instruction-following capability does not imply robust ICL deduction ability," as models like Gemini show high zero-shot compliance but large FCR drops when constraints are implicit.
  - Why unresolved: It is unclear what factors determine ICL robustness separately from instruction-following.

- **Open Question 4:** Can LALMs achieve genuine task inference in Stage 3 (audio-only demonstrations) without relying on textual cues within CoT reasoning traces, or is some form of textual scaffolding fundamentally necessary?
  - Basis in paper: [inferred] The paper observes that CoT performance recovery in Stage 3 "reflects reliance on textual clues in reasoning traces" rather than true speech-text integration.
  - Why unresolved: It is unknown whether any non-linguistic intermediate outputs could support audio-only ICL.

- **Open Question 5:** How do the selection, ordering, and linguistic diversity of in-context audio demonstrations quantitatively impact ICL effectiveness for format compliance and task performance in LALMs?
  - Basis in paper: [explicit] The conclusion identifies "investigating demonstration selection and ordering" as a key future direction.
  - Why unresolved: ALICE uses randomly ordered, label-balanced demonstrations; the influence of demonstration properties is unexplored.

## Limitations
- The mechanistic explanations (e.g., shallow pattern matching, catastrophic interference) are inferred from observational patterns and lack controlled ablation studies to isolate causes.
- The framework excludes MMAU in Stage 3, creating an uncontrolled gap in the audio-only evaluation for that task.
- No model ablations (e.g., training only the projection layer) are performed to disentangle architectural versus training-data effects.

## Confidence
- **Descriptive finding (FCR gain / task performance asymmetry):** High
- **Mechanistic explanations (pattern matching, grounding failure):** Medium

## Next Checks
1. **Pattern Ambiguity Stress Test:** In Stage 2, design demonstrations where the correct output format contradicts the model’s textual priors (e.g., JSON output when pretraining favors plain text). If FCR drops significantly, it confirms reliance on stereotypical patterns.
2. **Semantic Grounding Isolation:** For binary emotion SER, create audio-only demonstrations using acoustically ambiguous sounds (e.g., laughter vs. sobbing with reversed labels). Measure if models replicate the *incorrect* label from the demo.
3. **Reasoning Trace Ablation:** In Stage 3 CoT, manually remove or corrupt the textual reasoning steps while keeping the final answer format. If task performance collapses while FCR remains high, it proves CoT gains rely on textual clues.
