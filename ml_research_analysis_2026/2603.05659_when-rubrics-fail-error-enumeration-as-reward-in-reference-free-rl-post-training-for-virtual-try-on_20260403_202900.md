# When Rubrics Fail: Error Enumeration as Reward in Reference-Free RL Post-Training for Virtual Try-On

## Quick Facts
- arXiv ID: 2603.05659  
- Source URL: https://arxiv.org/abs/2603.05659  
- Reference count: 40  
- Primary result: Implicit Error Counting (IEC) enables effective reference‑free RL post‑training for virtual try‑on, outperforming rubric‑based rewards on both a curated mismatch benchmark (MDressBench) and standard VTO benchmarks.

## Executive Summary
Virtual try‑on (VTO) requires generating an image of a person wearing a given garment, but there is no single correct output—many outfits are plausible. Standard reinforcement learning from human feedback (RLHF) methods like Rubrics as Rewards (RaR) struggle in such reference‑free settings because they try to infer a rubric from an absent ideal. This paper introduces Implicit Error Counting (IEC), a reward scheme that asks a multimodal judge to internally enumerate and severity‑weight errors across task‑relevant axes, producing calibrated per‑aspect scores instead of explicit error lists. Two design choices—implicit score emission and group‑wise robust calibration—stabilize training. On a curated mismatched garment benchmark (MDressBench), IEC significantly lowers Cascaded Error Counting and improves aspect scores compared to RaR and direct holistic scoring. Moreover, on standard VTO datasets IEC matches or exceeds six supervised baselines on six of eight perceptual metrics, despite using fewer judge calls and only 60 RL steps. Ablations confirm that explicit error counting destabilizes optimization, while group calibration is essential for robust performance.

## Method Summary
The task takes as input a source image of a person, a reference garment image, an optional pose mask, and garment category. The base model is a 12‑billion‑parameter rectified‑flow network (Kontext‑dev) fine‑tuned with DiT‑VTON token concatenation for VTO. Reward computation explores three modes using a multimodal VLM (GPT‑5‑mini for training, GPT‑5 for evaluation): Direct (a single holistic scalar), RaR (generate a rubric then score binary items), and Implicit Error Counting (IEC) where the judge internally aggregates errors and outputs per‑aspect scores plus an error summary. Raw rewards are normalized per prompt group using robust group calibration (median and median absolute deviation) to remove scale drift while preserving ranking. Training uses Group Relative Policy Optimization (GRPO): for each prompt, sample K=12 candidates, compute raw rewards, apply group calibration, derive group‑normalized advantages, and perform clipped PPO updates with AdamW. The process runs for 60 steps, with best‑of‑8 selection during training.

## Key Results
- IEC achieves lower Cascaded Error Counting on MDressBench: 5.31 (flat) and 5.20 (non‑flat) vs. RaR (5.60, 5.53) and direct scoring.
- On VITON‑HD and DressCode, IEC matches or surpasses six supervised baselines on 6 of 8 perceptual metrics (LPIPS, SSIM, FID, KID) while using 2× fewer judge calls and only 60 RL steps.
- Ablations show explicit error counting (EEC) causes training instability and rank inversions, while removing group calibration degrades performance, confirming both design choices are necessary.

## Why This Works (Mechanism)

### Mechanism 1: Implicit Score Emission Stabilizes Reward Signals
- **Claim:** IEC stabilizes the reward signal compared to explicit error enumeration (EEC) by avoiding surface‑form variance in judge outputs.
- **Mechanism:** Instead of exposing raw error lists that vary across near‑identical generations, the judge internally aggregates errors into calibrated per‑aspect scores, preventing rank inversions within RL training groups.
- **Core assumption:** A multimodal judge can reliably map an internal error count to a consistent scalar score even when its textual descriptions vary.
- **Evidence:** The paper shows EEC produces rank inversions (e.g., a perfect score for an output missing sleeves) while IEC ranks correctly (Figure 9); training curves demonstrate IEC’s smooth improvement versus EEC’s early regression.
- **Break condition:** If the judge’s internal scoring becomes inconsistent across similar inputs due to prompt sensitivity, IEC’s advantage diminishes.

### Mechanism 2: Group‑Wise Robust Calibration Normalizes Prompt‑Dependent Scales
- **Claim:** Group calibration (median and MAD) reduces reward scale drift across prompts while preserving within‑group rankings, improving GRPO stability.
- **Mechanism:** For each candidate group, raw rewards are transformed via a monotonic function centered on the group median and scaled by the median absolute deviation. This normalizes absolute magnitudes across prompts without altering relative order.
- **Core assumption:** Reward magnitudes vary systematically with prompt difficulty or judge bias, but relative preferences within a prompt are reliable.
- **Evidence:** Ablation in Table 2 shows IEC without calibration performs worse on CEC (5.259 vs. 5.203). Figure 4 illustrates calibration’s stabilizing effect.
- **Break condition:** Calibration cannot recover signal if within‑group rankings are already corrupted, as in EEC.

### Mechanism 3: Error Counting Provides a Stronger Signal Than Rubrics in Reference‑Free Tasks
- **Claim:** When ideal answers are unavailable, counting errors yields a more reliable reward than constructing rubrics from a non‑existent ideal.
- **Mechanism:** Rubric generation without a reference yields generic or misaligned criteria; error counting focuses evaluation on detectable failure modes, which are fewer and more structured than the space of valid outputs.
- **Core assumption:** The space of possible errors is smaller and more consistently detectable than the space of correct variations for a given task.
- **Evidence:** IEC outperforms RaR on all MDressBench metrics (Table 1–2); RaR underperforms even direct holistic scoring, confirming the weakness of rubric‑only approaches in reference‑free settings.
- **Break condition:** If the error space is not enumerable or localizable (e.g., highly subjective aesthetic judgments without clear failure modes), error counting may fail to provide a structured signal.

## Architecture Onboarding

### Component map
Inputs: Source image, reference garment, pose mask, garment category  
Policy model: Rectified‑flow backbone (Kontext‑dev) with DiT‑VTON token concatenation, generating candidate images  
Reward judge: Multimodal VLM (GPT‑5‑mini for training, GPT‑5 for eval) configured for IEC (implicit per‑aspect scores + error summary), Direct (holistic scalar), or RaR (rubric generation + binary scoring)  
Group calibration: Applies robust normalization (median/MAD) to group rewards before advantage computation  
GRPO update: Computes group‑normalized advantages, clipped PPO‑style loss, updates policy via AdamW

### Critical path
For each training group: (a) sample K candidates from policy → (b) compute raw rewards via chosen method → (c) apply group calibration → (d) compute advantages → (e) perform gradient step on policy.

### Design tradeoffs
- Judge calls: IEC/Direct = 1 per candidate; RaR = 2 per candidate. IEC cuts compute by half compared to RaR.
- Signal granularity: IEC’s aspect scores offer interpretability; Direct loses fine‑grained error information; RaR’s binary rubric items may over‑ or under‑penalize.
- Calibration sensitivity: Calibration assumes stable within‑group rankings; it is ineffective if the judge is too stochastic (as in explicit error counting).

### Failure signatures
- EEC: High reward variance, rank inversions (e.g., perfect score for missing sleeves), early training regression.
- RaR: Generic rubrics leading to reward hacking like texture smoothing; underperformance on hard mismatched pairs.
- No calibration: Prompt‑dependent scale drift causing noisy GRPO updates.

### First three experiments
1. **Stability test:** Run GRPO with IEC, EEC, Direct, RaR on a fixed small batch; plot reward exponential moving average. Expect IEC to show smooth monotonic improvement; EEC should regress; RaR/Direct noisy.
2. **Calibration ablation:** Compare IEC with and without group calibration on MDressBench. Calibration should lower CEC and improve aspect scores (as in Table 2).
3. **Benchmark validation:** Evaluate IEC‑trained model on MDressBench (flat/non‑flat) and standard VTO benchmarks (VITON‑HD, DressCode) against six supervised SFT baselines. Expect IEC to outperform all on MDressBench and match/surpass on most perceptual metrics.

## Open Questions the Paper Calls Out
1. **How robust is IEC to different VLM judges?** Only GPT family models were tested; judge biases may affect gains and stability.
2. **Does IEC generalize to other reference‑free domains beyond virtual try‑on?** VTO may have a unique error structure; tasks like image editing or robotics might differ.
3. **Are human preferences for IEC outputs captured by CEC at scale?** The human study used only 25 samples; larger‑scale alignment is unknown.
4. **Can evaluation axes be automatically discovered for new domains?** Manual axis definition limits applicability; a VLM‑driven pipeline is needed.
5. **How does IEC compare to learned reward models from human feedback (e.g., VTON‑VLLM)?** A fine‑tuned VLLM on human preferences may offer different trade‑offs.

## Limitations
- **Judge dependency:** Results rely on proprietary GPT‑5‑mini/GPT‑5; performance with open‑source VLMs is unknown and likely requires prompt re‑tuning.
- **Base model specifics:** Exact architecture, fine‑tuning details, and hyperparameters of the “Kontext‑dev” 12B rectified‑flow backbone are not released, hindering exact replication.
- **Generalizability:** Evidence is limited to virtual try‑on and one curated benchmark; the claim that error counting outperforms rubrics in all reference‑free tasks remains unvalidated.

## Confidence
- Implicit score emission stabilizes RL: **High**  
- Group calibration improves robustness: **High**  
- Error counting outperforms rubrics in reference‑free settings: **Medium**

## Next Checks
1. **Judge consistency test:** Replicate IEC vs. EEC by repeatedly querying the same VLM for identical generations; measure rank inversion rates and reward variance within groups. IEC should show lower variance and stable rankings.
2. **Calibration sensitivity analysis:** Systematically vary group calibration parameters (α, ε, floor) on a held‑out prompt set; evaluate impact on within‑group ranking preservation (Spearman’s ρ) and downstream CEC/aspect scores.
3. **Cross‑task generalization:** Apply IEC to another reference‑free multimodal task (e.g., image editing for “no‑artifact” quality) using the same judge calibration protocol; compare against RaR and direct scoring on task‑specific error metrics.
