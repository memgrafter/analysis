# PRISM: Parallel Reward Integration with Symmetry for MORL

## Quick Facts
- **arXiv ID**: 2602.18277
- **Source URL**: https://arxiv.org/abs/2602.18277
- **Reference count**: 40
- **Primary result**: Achieves hypervolume gains exceeding 100% over baseline and up to 32% over oracle

## Executive Summary
This work addresses the challenge of heterogeneous Multi-Objective Reinforcement Learning where objectives differ significantly in temporal frequency. In such settings, dense rewards can dominate learning while sparse, long-horizon rewards receive inadequate credit assignment, resulting in poor sample efficiency. The authors propose PRISM, a method that enforces reflectional symmetry as an inductive bias to align reward channels across different temporal frequencies. PRISM introduces ReSymNet, a model that reconciles temporal-frequency mismatches using residual blocks to learn scaled opportunity values, and SymReg, a reflectional equivariance regularizer that constrains policy search to reflection-equivariant subspaces.

## Method Summary
PRISM tackles heterogeneous MORL by introducing symmetry constraints as an inductive bias to handle temporal-frequency mismatches between reward channels. The method uses ReSymNet, a theory-motivated architecture that employs residual blocks to learn scaled opportunity values, accelerating exploration while preserving optimal policies. Additionally, SymReg implements reflectional equivariance regularization to enforce agent mirroring and restrict policy search to reflection-equivariant subspaces. This constrained search provably reduces hypothesis complexity and improves generalization. The approach is evaluated across MuJoCo benchmarks, demonstrating superior Pareto coverage and distributional balance compared to both sparse-reward baselines and oracle-trained models.

## Key Results
- PRISM achieves hypervolume gains exceeding 100% over the sparse-reward baseline
- Outperforms oracle trained with full dense rewards by up to 32%
- Consistently improves Pareto coverage and distributional balance across MuJoCo benchmarks

## Why This Works (Mechanism)
PRISM leverages reflectional symmetry as an inductive bias to align reward channels operating at different temporal frequencies. By enforcing symmetry constraints through SymReg, the method restricts the policy search space to reflection-equivariant subspaces, reducing hypothesis complexity. The ReSymNet architecture uses residual blocks to learn scaled opportunity values that help reconcile temporal-frequency mismatches, allowing the agent to better credit sparse rewards while still benefiting from dense signals. This combination enables more efficient exploration and learning across heterogeneous reward structures.

## Architecture Onboarding

**Component Map**: PRISM -> ReSymNet (residual blocks + scaled opportunity value) -> SymReg (reflectional equivariance regularizer) -> policy search in reflection-equivariant subspace

**Critical Path**: Reward input → ReSymNet processing → SymReg regularization → Policy output → Reward credit assignment → Learning update

**Design Tradeoffs**: 
- Symmetry constraints improve generalization but may restrict expressiveness
- Residual architecture enables frequency reconciliation but adds complexity
- Reflection-equivariance regularization provides theoretical guarantees but requires careful implementation

**Failure Signatures**:
- Poor performance on environments without temporal-frequency heterogeneity
- Degraded performance when objectives lack natural symmetry
- Potential overfitting to synthetic symmetry patterns
