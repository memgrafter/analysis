# Point-Identification of a Robust Predictor Under Latent Shift with Imperfect Proxies

## Quick Facts
*   **arXiv ID:** 2603.15158
*   **Source URL:** https://arxiv.org/abs/2603.15158
*   **Reference Count:** 40
*   **Primary Result:** Introduces Latent Equivalent Classes (LECs) and a cross-domain rank condition to achieve point-identification of the robust predictor \(E[Y|X,Z]\) under latent shift with imperfect proxies, and proposes the PQAL active learning method to efficiently satisfy this condition.

## Executive Summary
This paper addresses the challenge of domain adaptation when the distribution shift is driven by unobserved latent confounders \(U\), and the available proxy \(W\) is imperfect—meaning multiple values of \(U\) produce the same distribution of \(W\), violating the standard "completeness" assumption required for point-identification. The core contribution is a novel theoretical framework based on **Latent Equivalent Classes (LECs)**, which partitions the latent space into sets of values that are observationally indistinguishable given \(W\). The robust predictor \(E[Y|X,Z]\) is point-identified if a set of source environments exhibits a full-rank **cross-domain rank condition** on their LEC mixture weights. To practically achieve this, the authors propose **Proximal Quasi-Bayesian Active Learning (PQAL)**, which actively selects a minimal set of diverse candidate domains to query, using the posterior uncertainty of Conditional Mean Embeddings (CMEs) as an acquisition criterion. Empirical results on synthetic and semi-synthetic dSprites data demonstrate that PQAL achieves lower mean squared error than existing baselines, especially under significant distribution shift.

## Method Summary
The method proceeds in two phases. First, given labeled source data, it estimates **Conditional Mean Embeddings (CMEs)** \(\mu_{W|X,Z}\) for each source environment via kernel ridge regression, and trains a **bridge function** \(h(X,W)\) that satisfies \(E[Y - h(X,W) | X, Z] = 0\) for all source domains. Second, in an active learning loop, it iteratively selects candidate \((x,z)\) pairs from an unlabeled pool whose CMEs have the highest posterior uncertainty. Querying the proxy \(W\) for these points updates the target environment's CME. After a small number of such proxy (and occasional label) queries, the method **adapts** the bridge parameters by fine-tuning on the new target data while regularizing to preserve the source-invariant structure. The target predictor is then computed as the expectation of the adapted bridge function with respect to the updated target CME.

## Key Results
*   **Theoretical:** Point-identification of \(E[Y|X,Z]\) is possible under imperfect proxies if the environments' LEC mixture weights matrix has full column rank (a strictly weaker condition than completeness).
*   **Empirical (Synthetic):** PQAL significantly outperforms baselines like Proxy-DA, especially under high shift (e.g., MSE 0.4015 vs. 1.0926 on Dataset 1).
*   **Empirical (dSprites):** PQAL achieves lower MSE (0.946 vs. 1.071) on a semi-synthetic image dataset, demonstrating robustness in a complex setting.

## Why This Works (Mechanism)

### Mechanism 1: Imperfect Proxies via Latent Equivalent Classes (LECs)
*   **Claim:** Imperfect proxies (where multiple latent confounder values produce the same proxy distribution) do not necessarily preclude point-identification.
*   **Mechanism:** The paper introduces **Latent Equivalent Classes (LECs)**. These are equivalence classes of latent confounder values \(U\) that are observationally indistinguishable given the proxy \(W\) (i.e., they induce the same \(P(W|U)\)). While individual \(U\) values cannot be recovered, the conditional distribution of \(W\) in any domain can be expressed as a **mixture** over these fixed LECs. The mixing weights \(\pi_j(x,z) = P(U \in O_j | X=x, Z=z)\) vary across environments \(Z\).
*   **Evidence anchors:** [abstract] "introduces latent equivalent classes (LECs) to group indistinguishable confounders based on proxy distributions"; [section 4.1, Definition 2] formal definition of LECs.
*   **Break condition:** If all LECs collapse into a single class (\(|O|=1\)), the proxy provides no information about the latent shift, and identification is impossible.

### Mechanism 2: Cross-Domain Rank Condition for Identification
*   **Claim:** Point-identification of \(E[Y|X,Z]\) is achievable under imperfect proxies if observed source domains exhibit sufficient diversity in their LEC mixing weights.
*   **Mechanism:** The predictor is point-identified if a set of source environments \(\mathcal{Z}^*\) is **distinguishing** (Definition 3). This means the matrix of mixing weights \(\Pi(x) = [\pi_j(x, z_l)]\) for these environments has full column rank (equal to the number of LECs). This **cross-domain rank condition** allows the target domain's conditional expectation operator to be expressed as a linear combination of the source operators.
*   **Evidence anchors:** [abstract] "point-identification remains achievable as long as multiple domains differ sufficiently in how they mix proxy-induced LECs... formalized as a cross-domain rank condition"; [section 4.2, Theorem 3] the core point-identification proof.
*   **Break condition:** If the mixing weights for all observed source domains are collinear (i.e., \(\Pi(x)\) is rank-deficient), the target predictor is not point-identified.

### Mechanism 3: PQAL Active Learning via CME Uncertainty
*   **Claim:** The Proximal Quasi-Bayesian Active Learning (PQAL) framework actively queries a minimal set of diverse domains to satisfy the cross-domain rank condition.
*   **Mechanism:** PQAL selects candidate \((x,z)\) points whose **posterior uncertainty of the Conditional Mean Embedding (CME)**, \(\sigma_\mu^2(x,z)\), is highest. High uncertainty indicates the CME for that \((x,z)\) is not well-explained by the current span of CMEs, suggesting it likely contributes a new linearly independent direction in the LEC mixture space. Querying such samples increases the rank of the matrix formed by CMEs across selected environments.
*   **Evidence anchors:** [abstract] "using CME posterior uncertainty as acquisition criterion"; [section 5.2] derivation of the CME uncertainty acquisition function.
*   **Break condition:** If the candidate pool's environments are intrinsically homogeneous (their CMEs lie in a low-dimensional subspace), no acquisition strategy can achieve full rank. The guarantee also relies on an assumption linking CME uncertainty to rank contribution.

## Foundational Learning

*   **Concept: Proximal Causal Inference (PCI) & Bridge Functions**
    *   **Why needed here:** PCI provides the framework for using proxies \(W\) to adjust for latent confounders \(U\). The central object is the bridge function \(h(X,W)\) which satisfies \(E[Y - h(X,W) | X=x, Z=z] = 0\). The robust predictor is then \(E[Y|X=x,Z=z] = \mathbb{E}_{W|X=x,Z=z}[h(X,W)]\). This work builds directly on PCI but relaxes its completeness assumption.
    *   **Quick check:** Given \(E[Y|X,Z] = \int h(x,w) P(w|x,z) dw\), what property must the operator \(f \mapsto \int f(x,w) P(w|x,z) dw\) have for the predictor to be point-identified, and why does imperfect proxy break it?
*   **Concept: Conditional Mean Embeddings (CMEs)**
    *   **Why needed here:** CMEs (\(\mu_{W|X,Z}(x,z) = \mathbb{E}[\phi(W) | X=x, Z=z]\)) provide a kernel-based representation of conditional distributions \(P(W|X,Z)\). They are used to compute the integral in the PCI formula non-parametrically. The LEC decomposition operates on CMEs: \(\mu_{x,z} = \sum_j \pi_j(x,z) m_j\).
    *   **Quick check:** If two environments have CMEs \(\mu_{x,z_1}\) and \(\mu_{x,z_2}\) that are perfect linear combinations of each other, what does that imply about their underlying LEC mixing weights and the ability to distinguish environments?
*   **Concept: Active Learning via Expected Predictive Information Gain (EPIG)**
    *   **Why needed here:** The goal is to select the most informative \((x,z)\) pairs to query \(W\) to achieve a distinguishing environment set with minimal queries. EPIG is a principled criterion for sample selection that maximizes expected reduction in predictive uncertainty. The paper adapts EPIG but uses CME uncertainty as a tractable surrogate.
    *   **Quick check:** Why is direct EPIG computation using the posterior of the bridge function \(h\) intractable in this setting, necessitating the CME uncertainty surrogate?

## Architecture Onboarding

*   **Component map:** Initial CME Trainer -> Initial Bridge Trainer -> Acquisition Module -> (Query) -> CME Updater -> Bridge Adapter -> Predictor
*   **Critical path:** The core logic to ensure identification is: **(1) Rank Condition Need** -> **(2) CME Uncertainty Acquisition** -> **(3) CME Updates** -> **(4) Bridge Adaptation**. The loop runs until the selected environments' CME matrix achieves sufficient rank or the query budget is exhausted.
*   **Design tradeoffs:**
    *   **Kernel choice vs. Completeness:** A richer kernel (e.g., high-degree polynomial) can better approximate the true bridge but may increase finite-sample noise, affecting the reliability of the rank condition check.
    *   **Active query budget split:** The budget is split between proxy-only queries (\(v_p\)) and labels+proxy queries (\(v_{lb}\)). More proxy-only queries improve CME diversity faster, but labels are needed for stable bridge adaptation.
    *   **Bridge adaptation regularization:** \(\lambda_{tgt}, \lambda_{manifold}, \lambda_{reg}\) trade off fitting new target data vs. preserving source knowledge vs. smoothness. Overfitting to few target labels can destroy the source bridge's validity.
*   **Failure signatures:**
    *   **Rank deficiency persists:** After querying, \(\Pi(x)\) remains rank-deficient. Symptom: high validation error that does not improve with more target CME updates.
    *   **Acquisition stagnation:** CME uncertainty \(\sigma_\mu^2\) drops uniformly across pool, indicating all candidate CMEs lie in the current span. The environment diversity in the pool is exhausted.
    *   **Catastrophic forgetting in bridge:** Bridge error on source data spikes after adaptation, indicating \(\lambda_{reg}\) is too low or \(v_{lb}\) is too high relative to source data size.
*   **First 3 experiments:**
    1.  **LEC Imperfection & Effective Rank:** Vary the discretization (number of bins \(B\)) of a discrete proxy \(W\). Measure the effective rank of the stacked CME matrix. Expected: More bins → higher effective rank.
    2.  **Robustness to Shift Degree:** Compare PQAL vs. baselines across increasing Beta distribution variances (proxy-controlled latent shift). Expected: PQAL's MSE grows slower than baselines as shift increases.
    3.  **Acquisition Function Ablation:** Compare CME uncertainty acquisition against Random, Z-uncertainty (environment coverage), and EER-inspired. Expected: CME uncertainty achieves the lowest final MSE.

## Open Questions the Paper Calls Out
*   **Open Question 1:** Under what finite-sample conditions does PQAL succeed in selecting a set of environments that satisfy the cross-domain rank condition with high probability? The paper lacks explicit sample complexity bounds for the active selection process.
*   **Open Question 2:** How can one estimate the number of latent equivalent classes (LECs) from observed data when proxies are imperfect? The theoretical framework treats the LEC partition as given, but its cardinality is crucial for the rank condition and is not estimated.
*   **Open Question 3:** Does the framework extend to scenarios where the invariant outcome assumption (\(P(Y|U)\) constant across domains) is violated? The identification proof relies on this invariance, limiting applicability to shifts where the outcome mechanism itself changes.

## Limitations
*   Hyperparameter values (lambda, kernel bandwidths) and kernel choices are not disclosed; their effect on CME estimation and rank condition verification is unclear.
*   The exact procedure for generating the dSprites semi-synthetic data is missing key details (e.g., `f_image` function, image preprocessing pipeline), hindering replication.
*   Core assumptions (existence of ≥2 distinct LECs, the link between CME uncertainty and rank contribution) lack real-data validation.

## Confidence
*   **LEC identification theory:** **Medium**. The theoretical construction is sound, but the practical requirement of having ≥2 distinct LECs induced by the proxy may not hold for arbitrary real-world proxies.
*   **Rank condition for point-identification:** **Medium-High**. The proof under the proposed assumptions is solid, but verifying the condition from finite empirical data is non-trivial and relies on accurate CME estimation.
*   **PQAL active learning effectiveness:** **Medium**. Synthetic gains are demonstrated, but the surrogate CME uncertainty criterion is not theoretically guaranteed to always increase the relevant rank (Assumption 4), and its robustness to noise/misspecification is untested.

## Next Checks
1.  **Hyperparameter sensitivity analysis:** Systematically vary λs and kernel bandwidths on synthetic data to understand their impact on CME estimation quality and the success rate of achieving full rank.
2.  **Test on a real-world domain adaptation problem:** Apply PQAL to a dataset with a known or plausible imperfect proxy (e.g., sensor data with aggregation, survey data with coarse demographics) to validate assumptions and practical utility.
3.  **Finite-sample rank analysis:** In synthetic settings with known LECs, measure the correlation between the acquisition score (CME uncertainty) and the actual increase in the effective rank of the LEC mixture matrix, and derive empirical sample complexity curves.
