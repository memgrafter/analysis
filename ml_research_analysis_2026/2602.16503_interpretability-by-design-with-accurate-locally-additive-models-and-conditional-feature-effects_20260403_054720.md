# Interpretability-by-Design with Accurate Locally Additive Models and Conditional Feature Effects

**Quick Facts**
- **arXiv ID**: 2602.16503
- **Source URL**: https://arxiv.org/abs/2602.16503
- **Reference count**: 40
- **Primary result**: Conditionally Additive Local Models (CALMs) match or exceed GA²M accuracy while using dramatically fewer interactions (average 6.2–15.1 vs. 15–97), preserving GAM-like interpretability.

**Executive Summary**
This paper introduces Conditionally Additive Local Models (CALMs), a novel approach to interpretable machine learning that bridges the gap between Generalized Additive Models (GAMs) and more accurate but less interpretable methods like GA²Ms. CALMs extend GAMs by allowing each feature to have multiple univariate shape functions, each active in a region defined by simple threshold conditions on other features. This conditional structure captures interactions while keeping each contribution one-dimensional and easy to visualize.

The authors propose a practical three-step pipeline: (1) train a black-box reference model to capture complex patterns; (2) for each feature, partition the space of remaining features using a heterogeneity measure derived from local effects; (3) fit region-specific shape functions via a modified backfitting algorithm. Theoretically, the approach is justified by bounds linking heterogeneity to approximation error. On 25 classification and regression benchmarks, CALMs consistently outperform GAMs and achieve accuracy on par with or better than GA²Ms while requiring far fewer interactions (average 6–15 vs. 15–97) and maintaining fast training times.

**Method Summary**
CALMs are trained via a distillation-based pipeline:

1. **Black-box training**: Fit a high-capacity model (e.g., XGBoost) on the full training data.
2. **Local effect estimation**: For each feature \(i\) and a set of background samples, compute local effects \(h(x_i, x_{-i})\) (e.g., via partial dependence plots).
3. **Region discovery**: Grow a shallow binary tree (max depth \(d_{\text{max}}\)) for feature \(i\). At each node, consider all feasible thresholds on other features and accept a split if the relative heterogeneity reduction exceeds \(\epsilon\). This partitions the space of \(x_{-i}\) into regions where the effect of \(x_i\) is approximately additive.
4. **Optional pruning**: If a maximum number of interactions \(K\) is desired, keep only the most heterogeneous splits (top \(K\)).
5. **Region-aware fitting**: Initialize all region-specific shape functions \(f_i^{(r)}\) to zero. Perform gradient boosting: for each feature \(i\) and region \(r\), compute the residual on samples whose \(x_{-i}\) fall in \(R_i^{(r)}\), fit a univariate weak learner (e.g., a shallow tree or spline) to these residuals, and update \(f_i^{(r)}\) with a learning rate. Repeat for \(M\) iterations.
6. **Assembly**: Combine the global intercept and all conditional effects into the final predictor.

The implementation mirrors Algorithm 4 of the paper. Key hyperparameters are \(d_{\text{max}}\) (controls region count), \(\epsilon\) (split threshold), black-box complexity, and the type of univariate weak learner.

**Key Results**
- CALMs consistently outperform GAMs and match or exceed GA²Ms in predictive accuracy across 25 benchmarks.
- They achieve this with dramatically fewer interactions: average 6.2–15.1 per feature, compared to 15–97 in GA²Ms.
- The models retain GAM-like interpretability (each feature effect is a set of one-dimensional curves conditioned on simple thresholds) and enjoy provable guarantees for local contributions and monotonicity, while maintaining practical runtime.

**Why This Works (Mechanism)**

**Conditional Feature Effects via Regional Partitioning**  
CALM models each feature \(x_i\) with multiple univariate functions \(f_i^{(r)}\), each active in a region \(R_i^{(r)}\) defined by threshold conditions on other features. This allows interactions to be expressed as axis-aligned splits, preserving local additivity. The overall model is \(\hat{y}(x) = \beta_0 + \sum_i f_i^{(r_i(x_{-i}))}(x_i)\).  
*Core assumption*: Interactions can be approximated by axis-aligned splits, such that within each subregion the effect of \(x_i\) becomes nearly additive.

**Heterogeneity-Driven Region Discovery**  
Regions are learned by minimizing a heterogeneity measure computed from a black-box reference model’s local effects. Low heterogeneity within a region indicates that the effect of \(x_i\) is nearly independent of \(x_{-i}\). A CART tree is grown greedily, splitting if the relative heterogeneity reduction exceeds \(\epsilon\). Theoretically, expected heterogeneity bounds the CALM approximation error (Proposition A.1).  
*Core assumption*: The heterogeneity measure is a valid proxy for interaction strength.

**Region-Aware Backfitting**  
Shape functions are fitted by a modified backfitting algorithm. For each feature \(i\) and region \(r\), updates use only samples with \(x_{-i} \in R_i^{(r)}\). This coordinate descent converges to the empirical risk minimizer over the CALM class under exact updates (Proposition 3.1); in practice, gradient boosting provides an efficient approximation. The procedure ensures accurate regional estimates while accounting for overlapping regions.

**Architecture Onboarding**

**Component map**  
Dataset \(D\), hyperparameters (\(d_{\text{max}}, \epsilon\)), choice of black-box model and local effect method → (1) Train black-box \(f_{\text{ref}}\) → (2) Compute local effects for each feature using training samples → (3) For each feature \(i\), grow a shallow binary tree \(T_i\) over other features by maximizing heterogeneity reduction → (4) Optional: prune trees to keep top \(K\) heterogeneous splits → (5) For each feature \(i\) and each region \(r\) in \(T_i\), initialize \(f_i^{(r)} = 0\); perform gradient boosting: at each iteration, update one \(f_i^{(r)}\) by fitting to residuals on samples with \(x_{-i}\) in region \(r\) → (6) Assemble final predictor: \(\beta_0 + \sum_i f_i^{(r_i(x_{-i}))}(x_i)\).

**Critical path**  
The pipeline is largely sequential: black-box training → local effects computation → per-feature partition tree building → optional pruning → region-aware boosting → final assembly. Partition trees must be fixed before shape function training; local effects are needed before tree building; region training for each feature could be parallelized after trees are built.

**Design tradeoffs**
- \(d_{\text{max}}\): larger values increase region count and model capacity, improving accuracy but reducing interpretability and risking overfitting.
- \(\epsilon\): heterogeneity reduction threshold; lower values yield more splits (more complex partitions) but may capture noise; higher values produce simpler models.
- Black-box model: a more accurate reference yields better heterogeneity estimates; simpler black-boxes are faster but noisier; training cost is overhead.
- Local effect method: PDP is cheap but may extrapolate; SHAP is more accurate but computationally expensive.
- Univariate weak learner for shape functions: choice of splines, decision stumps, etc., trades off smoothness, flexibility, and training time.

**Failure signatures**
- High final heterogeneity within regions: partitioning failed; consider more black-box capacity, lower \(\epsilon\), or alternative splitting features.
- Many regions per feature (near \(2^{d_{\text{max}}}\)): model becoming uninterpretable; increase \(\epsilon\) or reduce \(d_{\text{max}}\).
- CALM accuracy worse than plain GAM: interactions may be negligible or noisy; increase black-box complexity or adjust \(\epsilon\).
- Boosting convergence issues (loss plateau or divergence): reduce learning rate, increase boosting iterations, or check region-specific sample counts.
- Memory/time blow-up: due to many overlapping regions; optimize by caching region assignments and limiting \(d_{\text{max}}\).

**First 3 experiments (to validate core mechanisms)**
1. **Synthetic Case 1**: Generate data with a strong interaction (e.g., \(y = x_1^2 + \log|x_2|\cdot\sin(\pi x_3/2)\)). Fit CALM vs GAM and GA²M; expect CALM to match GA²M’s high R² while using only a few conditional effects (e.g., split \(x_1\) on \(x_3\)) with visualizable two univariate plots.
2. **Synthetic Case 2**: Data with a 3-way interaction producing four distinct regimes. Verify CALM learns four separate univariate curves for a target feature via conditioning on thresholds of two other features, achieving near-perfect R² with very few interactions.
3. **Real Dataset (e.g., COMPAS or Adult)**: Train CALM with XGBoost as black-box; confirm accuracy matches or exceeds best GA²M baseline while using far fewer interactions (average 6–15). Inspect conditional effects for plausibility (e.g., monotonic trends).

**Open Questions the Paper Calls Out**
The authors do not identify any open questions in the paper.

**Limitations**
- Reproduction gaps: critical hyperparameters (boosting iterations, weak learner type, categorical handling) are unspecified, hindering faithful replication.
- Sensitivity to black-box quality: partitioning relies on accurate local effects; a poor black-box leads to suboptimal regions and noisy estimates.
- Scalability not fully validated: the model’s complexity scales with \(2^{d_{\text{max}}}\) regions; runtime and memory behavior on high-dimensional or large datasets remains to be stress-tested.

**Confidence**
- Core mechanism (conditional partitioning + heterogeneity): High
- Black-box dependency & partitioning quality: Medium
- Categorical feature handling: Low
- Scalability claims: Medium
