# Model-based Offline RL via Robust Value-Aware Model Learning with Implicitly Differentiable Adaptive Weighting

## Quick Facts
- **arXiv ID:** 2603.08118
- **Source URL:** https://arxiv.org/abs/2603.08118
- **Reference count:** 40
- **Primary result:** ROMI achieves state-of-the-art offline RL performance on D4RL and NeoRL, beating RAMBO by 18.6% on MuJoCo (953.5 vs 804.1) while maintaining stable training without gradient explosions.

## Executive Summary
Model-based offline RL can suffer from model exploitation, where the policy visits states where the learned dynamics is inaccurate. ROMI addresses this by combining robust value-aware model learning with an implicitly differentiable adaptive weighting scheme. The robust loss forces the dynamics model to predict next states whose values are near the minimum within a scale-adjustable uncertainty set, providing controllable pessimism. A bi-level optimization adaptively balances dynamics (MLE) and value (RVL) learning, improving out-of-distribution generalization. Experiments on D4RL and NeoRL show ROMI significantly outperforms RAMBO (18.6% gain on MuJoCo) and attains state-of-the-art results across all tasks, with stable training and no gradient explosions.

## Method Summary
ROMI employs an ensemble dynamics model and a small weighting network. The dynamics model is first pre-trained via maximum likelihood estimation (MLE). During training, a bi-level optimization updates the model. In the inner loop, the dynamics parameters are updated using a weighted MLE loss, where each transition’s weight is produced by the weighting network. In the outer loop, the weighting network is updated via an implicitly computed gradient of a robust value-aware loss (RVL). The RVL loss penalizes the squared difference between the value of the model’s predicted next state and the minimum value over a set of perturbed versions of the dataset’s next states. The value function is estimated by the current critic and kept fixed during the bi-level updates. The policy is trained with SAC using both offline and model-generated data, with the replay buffer equally mixing real and synthetic transitions. A key hyperparameter is the uncertainty scale ξ, which controls the size of the perturbation set and thus the degree of conservatism.

## Key Results
- ROMI attains a total normalized score of 953.5 on MuJoCo, beating RAMBO’s 804.1 (18.6% improvement) and achieving state-of-the-art on D4RL and NeoRL benchmarks.
- It notably outperforms RAMBO on tasks where RAMBO underperforms, demonstrating robustness to model exploitation.
- Training is stable with no gradient explosions, and performance is consistent across a range of uncertainty scales ξ.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** The dynamics model learns to predict future states whose values are near the minimum within a scale-adjustable state uncertainty set, providing controllable conservatism.
- **Mechanism:** Instead of using a model gradient that directly pushes the model towards low-value regions (which can cause over-conservatism), ROMI reformulates the adversarial objective. It requires the model's predicted next state's value to be close to the minimum Q-value estimated over a set of perturbed versions of the dataset's next states (the uncertainty set `U_ξ(s')`). The scale ξ of this set directly controls conservatism.
- **Core assumption:** The value function `bV` is a reliable proxy for policy performance within the uncertainty set; minimizing the value estimation error on in-distribution states with a bounded uncertainty set ensures pessimistic yet stable value estimates during rollouts.
- **Evidence anchors:**
  - [abstract] "requires the dynamics model to predict future states with values close to the minimum Q-value within a scale-adjustable state uncertainty set, enabling controllable conservatism and stable model updates."
  - [section 4.1] Equation (6) defines the RVL loss `L_RVL(ψ)` that explicitly computes the squared difference between the value of the model's predicted next state and the *minimum* value among samples from `U_ξ(s')`.
  - [corpus] Neighbors discuss model-based RL and differentiable learning but do not directly address state-uncertainty-based value-aware model learning; this specific mechanism is novel to ROMI and Raman-based works.
- **Break condition:** If the minimum value within `U_ξ(s')` is estimated from too few samples (small N), the loss gradient becomes noisy and the model may not learn a consistent pessimistic bias. If ξ is set too large, the minimum value estimate becomes overly pessimistic, leading to under-estimation even with stable gradients.

### Mechanism 2
- **Claim:** A bi-level optimization framework with an adaptive weighting network adaptively balances dynamics-aware (MLE) and value-aware (RVL) model learning, improving out-of-distribution (OOD) generalization during multi-step rollouts.
- **Mechanism:** An inner loop updates the dynamics model parameters ψ using a Weighted Supervised Learning (WSL) loss, where an adaptive weighting network w_ν(s,a,s') re-weights each transition's MLE loss. An outer loop updates ν to minimize the RVL loss *with implicit differentiation*, effectively tuning w_ν to prioritize samples that are most helpful for achieving the value-aware objective. This prioritization implicitly encourages the model to fit well on states that matter for long-term value (dynamics awareness) while remaining pessimistic where the model is uncertain (value awareness).
- **Core assumption:** The weighting network can learn to identify which transitions from the offline dataset are most critical for reducing the value-aware loss on the synthetic rollout states. Implicit differentiation provides a stable gradient for ν despite the inner-loop optimization.
- **Evidence anchors:**
  - [abstract] "implicitly differentiable adaptive weighting, a bi-level optimization scheme that adaptively achieves dynamics- and value-aware model learning."
  - [section 4.2] Equations (8)-(10) and the surrounding text detail the bi-level setup: inner level minimizes `L_WSL(ψ, ν)`, outer level minimizes `L_RVL(ψ(ν))` using the implicit gradient `g_RVL = h · ∇νw_ν`.
  - [corpus] Neighbor papers (e.g., "Learning Implicit Rewards for Model-Based RL") explore bi-level optimization for reward/model tuning but not specifically for balancing dynamics/value awareness in an adversarial offline RL context.
- **Break condition:** The bi-level optimization can become unstable if the inner loop steps (β1) or outer step (β2) are poorly tuned, leading to oscillations in the weighting network. If the weighting network collapses to assigning uniform or near-zero weights, the benefit is lost. The implicit gradient approximation may also become inaccurate if inner-loop updates are large.

### Mechanism 3
- **Claim:** The combination of the robust value-aware loss and adaptive weighting bounds the Q-value during multi-step rollouts, preventing both over-estimation (model exploitation) and severe under-estimation (over-conservatism).
- **Mechanism:** The robust value-aware loss (L_RVL) enforces pessimism on in-distribution transitions. The adaptive weighting, by improving dynamics awareness, reduces the generalization error ϵ_1 (the discrepancy between in-distribution value-aware loss and OOD rollout loss). Proposition 4.2 mathematically shows that if ϵ_1 and ϵ_2 (discrepancy due to uncertainty set scale) are bounded, the learned Q-function remains close to the true Q-function during rollouts, avoiding divergence.
- **Core assumption:** The Lipschitz continuity of the value function `bV` (Assumption in Corollary 4.1) holds sufficiently in practice, allowing prediction errors to translate into bounded value errors. The bi-level optimization successfully minimizes the dynamics prediction error ϵ.
- **Evidence anchors:**
  - [section 4.1] Proposition 4.2 provides the bound `Q_true - γ(ϵ1+ϵ2)/(1-γ) ≤ bQ ≤ Q_true + γϵ1/(1-γ)` for all (s,a) in the model rollout dataset.
  - [section 4.2] Corollary 4.1 derives that `ϵ1 ≤ L_V · (ϵ + ξ)`, linking the generalization error to the Lipschitz constant `L_V`, the dynamics model error `ϵ`, and the uncertainty scale `ξ`.
  - [section 5.3] Empirical figures show that for a wide range of ξ (0.01 to 10), ROMI avoids the Q-value collapse and gradient explosion seen in RAMBO, supporting the theoretical stability.
- **Break condition:** If the value function `bV` is not Lipschitz or becomes too volatile during training, the bound becomes vacuous. If ϵ (dynamics prediction error during rollouts) grows too large due to compounding errors, ϵ_1 increases and may violate the bound in practice, causing performance degradation.

## Foundational Learning
- **Concept: Adversarial Model Learning / Robust MDPs**
  - *Why needed here:* ROMI operates within the theoretical framework of solving a max-min problem against an adversarial dynamics model within an uncertainty set. This is the foundation for introducing conservatism without explicit uncertainty estimation. Understanding this setup (Eq 1 in paper) is key to seeing why ROMI's implementation differs from RAMBO's.
  - *Quick check question:* What is the core objective of the inner minimization problem `min_{bT ∈ M_ξ} V^π_bT` in the adversarial model learning framework, and why is it difficult to solve directly?
- **Concept: Model Exploitation in Offline RL**
  - *Why needed here:* The entire problem ROMI addresses is model exploitation—where a learned dynamics model is inaccurate in OOD states visited by the policy, leading to degraded performance. ROMI's mechanisms are specifically designed to mitigate this.
  - *Quick check question:* Why can't model-based offline RL simply use a model trained via Maximum Likelihood Estimation (MLE) without additional conservatism?
- **Concept: Bi-level Optimization & Implicit Differentiation**
  - *Why needed here:* ROMI's adaptive weighting relies on a bi-level setup. Understanding the distinction between inner and outer loops, and how implicit gradients (via the chain rule through the inner optimization) enable updating ν without unrolling the inner loop, is crucial for grasping the stability claim.
  - *Quick check question:* What is the formula for the implicit gradient `∇_ν L_RVL(ψ(ν))` used in ROMI's outer loop update, and why is it preferred over a naive finite-difference approach?

## Architecture Onboarding
- **Component map:** 
  - **Dynamics Model (`bT_ψ`):** An ensemble of neural networks (input: s,a; output: parameters of Gaussian over s'). Updated in the *inner loop* via weighted MLE loss (`L_WSL`). 
  - **Weighting Network (`w_ν`):** A small MLP (input: s,a,s'; output: scalar weight). Updated in the *outer loop* via implicit gradient from the robust value-aware loss (`L_RVL`). Its outputs scale the MLE loss per transition.
  - **Value Network (`bV`):** Standard Critic network (input: s,a; output: Q-value). Updated via standard RL losses (e.g., SAC) using both offline data `D` and model rollouts `D_model`. Used in `L_RVL` as a fixed target during model updates.
  - **Policy Network (`π_θ`):** Actor network. Updated via SAC using `D ∪ D_model`.
  - **Uncertainty Set (`U_ξ(s')`):** Constructed by sampling `N` states via adding zero-mean Gaussian noise with standard deviation ξ to the dataset's next states `s'`. Not a learnable component but a hyperparameter-controlled sampler.
- **Critical path:** The core differentiator is the *bi-level model update loop*:
  1. From current `ψ, ν`, compute `L_WSL(ψ, ν)` and update `ψ` via gradient descent.
  2. Using the new `ψ` (implicitly as a function of ν), compute `L_RVL(ψ(ν))`.
  3. Compute implicit gradient `∇_ν L_RVL` using the stored inner-loop gradient (Eq 10).
  4. Update `ν` using this gradient.
  5. Repeat. The policy and value networks are updated independently in their own loops using the latest model.
- **Design tradeoffs:**
  - **ξ vs. Conservatism:** Larger ξ increases pessimism but risks over-conservatism and value under-estimation; smaller ξ risks insufficient protection against model exploitation. ROMI's formulation allows direct adjustment.
  - **Bi-level Cost vs. Stability:** The implicit bi-level optimization adds computational overhead (storing inner-loop gradients, two network updates) but is claimed to stabilize training compared to RAMBO's single-loop adversarial model gradient.
  - **Ensemble vs. Single Model:** Like RAMBO, an ensemble is used for robust rollouts. This increases memory but reduces variance in OOD predictions.
- **Failure signatures:**
  - **Dynamic Collapse:** The adaptive weights `w_ν` all converge to near 0 or 1, effectively disabling the adaptive mechanism.
  - **Gradient Explosion:** Despite ξ control, if the bi-level learning rates (β1, β2) are too large, the implicit gradient `g_RVL` can explode, causing NaN values. The paper shows RAMBO is prone to this; ROMI should be more robust.
  - **Policy Degeneration:** The policy learns to exploit a "hole" in the uncertainty set, achieving high value estimates in `U_ξ(s')` that do not correspond to true high-value states. Monitor if `min_{ŝ∈U_ξ(s')} bV(ŝ)` becomes unrealistically low while policy return is also low.
- **First 3 experiments:**
  1. **Reproduce RAMBO instability:** Run RAMBO on `halfcheetah-medium-expert-v2` with λ ∈ {0.05, 0.1}. Verify Q-value collapse and gradient norm spikes, as shown in the paper's Figure 1.
  2. **ROMI Sanity Check - ξ effect:** Run ROMI on the same dataset with ξ ∈ {0.01, 0.1, 1.0, 10}. Confirm that Q-values decrease monotonically with larger ξ and that no gradient explosion occurs, demonstrating controllable conservatism.
  3. **Ablation - Adaptive Weighting:** Train ROMI with the bi-level weighting *disabled* (i.e., set `w_ν ≡ 1`, revert to standard MLE for inner loop). Compare performance and model prediction error over multi-step rollouts (as in Figure 2) to verify that adaptive weighting improves OOD generalization.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** How can the computational overhead of bi-level optimization in ROMI be reduced to make it more practical for larger-scale problems?
- **Basis in paper:** [explicit] "One limitation of ROMI is that additional computational cost for bi-level optimization is required compared to the original RAMBO."
- **Why unresolved:** The paper identifies this as a limitation but provides no mitigation strategies, leaving efficiency improvements for future work.
- **What evidence would resolve it:** Proposing and validating approximations (e.g., single-level reformulations, gradient reduction techniques) that maintain ROMI's performance while lowering computational demands in benchmarks with larger models or datasets.

### Open Question 2
- **Question:** How can the conservatism parameter ξ be adjusted dynamically during training to adapt to data distribution shifts or task changes without pre-specification?
- **Basis in paper:** [explicit] "Another limitation is that the conservatism degree governed by ξ has to be specified before training, unlike methods that support runtime adjustment."
- **Why unresolved:** Fixed ξ limits adaptability; methods like Ghosh et al. (2022) show runtime tuning benefits, but ROMI lacks such mechanisms.
- **What evidence would resolve it:** Developing an adaptive controller for ξ (e.g., based on validation performance or uncertainty metrics) and demonstrating improved robustness across diverse offline datasets or transfer scenarios.

### Open Question 3
- **Question:** To what extent does the choice of uncertainty set (e.g., Wasserstein distance) in ROMI’s robust model learning affect its conservatism control and overall performance?
- **Basis in paper:** [inferred] ROMI adopts Wasserstein distance in Definition 4.1 but does not explore alternatives like KL divergence or f-divergences, nor analyze sensitivity.
- **Why unresolved:** Different distance metrics may yield varying uncertainty sets, impacting stability and generalization; this remains unstudied.
- **What evidence would resolve it:** Systematic ablation with multiple distance measures on benchmarks, measuring performance, gradient stability, and theoretical properties of the resulting value bounds.

### Open Question 4
- **Question:** Can ROMI be extended to settings with high-dimensional observations (e.g., pixels), partial observability, or discrete action spaces while maintaining its advantages?
- **Basis in paper:** [inferred] Experiments are limited to state-based MuJoCo and NeoRL tasks; no evaluation on visual domains (e.g., Atari) or discrete actions, leaving generalization unclear.
- **Why unresolved:** The value-aware model learning might face challenges with function approximation errors in complex domains; unaddressed in current work.
- **What evidence would resolve it:** Adapting ROMI’s architecture (e.g., convolutional networks) and testing on standard benchmarks like D4RL pixel-based or discrete tasks, comparing against strong baselines.

### Open Question 5
- **Question:** What are the theoretical guarantees for ROMI’s robust value-aware learning under weaker assumptions, such as non-Lipschitz dynamics or larger model errors?
- **Basis in paper:** [inferred] Proposition 4.2’s Q-value bounds rely on Lipschitz continuity and bounded prediction error (Corollary 4.1); real-world systems may violate these.
- **Why unresolved:** Assumptions may be restrictive; robustness under more realistic conditions is critical for deployment in safety-sensitive applications.
- **What evidence would resolve it:** Deriving tighter or more general bounds without Lipschitz assumptions, or conducting stress tests in environments with known non-Lipschitz dynamics to empirically assess performance degradation.

## Limitations
- Theoretical assumptions (Lipschitz continuity of value function, bounded prediction errors) may be violated in real-world settings, potentially undermining the theoretical guarantees.
- Implementation details (inner/outer update frequencies, ensemble size, replay buffer management) are under-specified, making exact replication challenging.
- The adaptive weighting network could collapse or become unstable if hyperparameters are not carefully tuned, requiring further empirical validation.
