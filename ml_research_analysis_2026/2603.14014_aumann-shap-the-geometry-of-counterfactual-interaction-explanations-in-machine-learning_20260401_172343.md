# Aumann-SHAP: The Geometry of Counterfactual Interaction Explanations in Machine Learning

## Quick Facts
- **arXiv ID:** 2603.14014
- **Source URL:** https://arxiv.org/abs/2603.14014
- **Reference count:** 0
- **Primary result:** A micro-player cooperative game on a discretized local hypercube yields geometry-aware counterfactual feature attributions; it converges to Integrated Gradients under refinement and outperforms standard Shapley in patch tests.

## Executive Summary
This paper introduces Aumann-SHAP, a method to explain how changes in input features lead to improvements in model outputs (counterfactual transitions). It constructs a cooperative game where each elementary step of a discretized path between baseline and counterfactual is a player. Shapley or LES values allocate the pure interaction "pots" (Harsanyi dividends) to features in a geometry-aware way, breaking the symmetric split of standard Shapley. Experiments on German Credit and MNIST show robust, stable explanations and superior performance in patch tests, requiring fewer feature edits to achieve a target prediction. The exact grid-state computation reduces complexity from exponential to polynomial in grid resolution for a fixed number of interacting features.

## Method Summary
Given a model g, a baseline instance x₀, and a counterfactual x₁ (with g(x₁)>g(x₀)), the set of changed features u is identified. First, all subsets S⊆u are evaluated to compute V(S)=g(x_S)-g(x₀), where x_S mixes x₁ on S and x₀ elsewhere. Harsanyi dividends ϕ_u for all u⊆u are obtained by Möbius inversion. For each interaction pot |u|≥2, the local hypercube is discretized with resolution m=(mᵢ) along each changed dimension. At each grid state p, the residual rₚ is computed via inclusion–exclusion over T⊆u, using linear interpolation for numerical features and an endpoint mixture for categoricals. The micro-game is defined with players corresponding to grid steps; the coalition value for a state p equals rₚ. Micro-Shapley or micro-LES values are computed via a closed-form grid-state sum (Proposition 3), avoiding enumeration of all 2^{|u|} coalitions. These micro-payoffs are aggregated per feature into within-pot contributions Sᵢ→u. The final attribution adds the main effect ϕᵢ: Sᵢ = ϕᵢ + Σ_{u∋i, |u|≥2} Sᵢ→u. The total sums to the output difference Δy.

## Key Results
- Aumann-SHAP and Aumann-LES provide within-pot attributions that reflect the geometric order of feature changes along the transition, unlike standard Shapley's equal split.
- Under grid refinement and model smoothness, the method converges to Integrated Gradients (diagonal Aumann-Shapley), linking discrete and continuous attribution.
- Patch tests on German Credit and MNIST demonstrate that explanations from Aumann-SHAP identify more effective early-change features, achieving higher target confidence with fewer edits.
- Exact grid-state computation reduces complexity from exponential in total features to polynomial in grid resolution for a fixed interaction order.

## Why This Works (Mechanism)
### Mechanism 1: Micro-player cooperative game construction
The local hypercube between baseline and counterfactual is discretized; each elementary grid-step move becomes a "micro-player" in a transferable utility game. The coalition value is defined as the residual interaction surface sampled at grid states (Equation 7). This transforms the continuous transition into a finite game amenable to Shapley/LES computation. Evidence: Section 3.3 defines the cube table and micro-players. Break condition: highly non-linear or discontinuous model behavior within the cube (e.g., decision tree splits on non-sampled points) may not be captured.

### Mechanism 2: Interaction pot reallocation in a geometry-aware manner
The pure interaction residual rᵤ(t) measures how synergy builds as features move. Discretization yields increments Δp(i)=r_{p+eᵢ}-rₚ representing the marginal increase in the k-way interaction pot when feature i advances one step. Micro-Shapley/LES averages these increments over all ordering contexts (states p), breaking the symmetric equal-split of standard Shapley. Evidence: Section 4.1 defines feature-level interaction contributions. Break condition: if ϕᵤ≈0, reallocation becomes numerically unstable; coarse grids default to near-symmetric splitting.

### Mechanism 3: Convergence to Integrated Gradients
As the minimum grid resolution min(mᵢ)→∞, the Riemann sum representation of Sᵢ→ᵤ (Equation S1.6) converges to the integral of the partial derivative of rᵤ along the diagonal τ·1ₖ (Theorem 2). This equals the continuous path-integral attribution (Integrated Gradients) provided g restricted to the cube is C¹ smooth. Evidence: Abstract and Section 4.1. Break condition: non-smooth models (e.g., piecewise-linear trees) violate the smoothness assumption, so convergence is not guaranteed.

## Foundational Learning
### Cooperative Game Theory (Shapley Value & Harsanyi Dividends)
- **Why needed:** The entire framework maps feature attribution to a transferable utility game. Shapley’s axioms (efficiency, symmetry, dummy, additivity) justify the allocation rule. Harsanyi dividends decompose the total value into pure interaction pots (Equation 3).
- **Quick check question:** Given V(S)=g(x_S)-g(x₀) and its Möbius inversion ϕᵤ, what does ϕ_{i,j} represent, and why is equal splitting of ϕ_{i,j} among i and j considered "geometry-blind"?

### Counterfactual Explanations & Residual Interaction Surfaces
- **Why needed:** The goal is to explain Δy = g(x₁)-g(x₀), not g(x₁) alone. The residual interaction rᵤ(t) (Equation 6) isolates the pure k-way synergy built along the transition, vanishing on boundaries (Proposition 1). This focuses attribution on interactions rather than main effects.
- **Quick check question:** Why does rᵤ(t)=0 when any feature is at its baseline value (tᵢ=0)? What does this property enforce about the interpretation of rᵤ?

### Discretization & Convergence of Path Integrals
- **Why needed:** The micro-game replaces a continuous path with a grid. Understanding the Riemann sum limit (Theorem 2) is crucial for relating finite-m attributions to Integrated Gradients and for choosing m.
- **Quick check question:** In the Riemann sum representation of Sᵢ→ᵤ, what does the term ∂rᵤ/∂tᵢ(τ1ₖ) intuitively capture? How does increasing m refine the approximation?

## Architecture Onboarding
### Component map
Cube Constructor -> Grid Discretizer -> Micro-game Builder -> Attribution Engine -> (optional) Convergence Monitor

### Critical path
Input (x₀, x₁, g) → identify changed features u → define cube xᵤ(t) → discretize with m → evaluate grid points gₚ → build residual table rₚ → define micro-game vᵤ(A)=rₚ(A) → compute φ(vᵤ) via LES closed form (Prop 3) → aggregate micro-payoffs to Sᵢ → output attributions.

### Design tradeoffs
- **Resolution m vs. cost:** Exact grid-state computation costs O(k(m+1)^k·2^{|u|}) but reduces to polynomial in m for fixed |u|. Higher m improves geometric fidelity but increases cost.
- **Smoothness assumption:** For smooth models (C¹), moderate m (5-10) suffices. For tree ensembles, m must be large to capture split thresholds; otherwise attributions may be unstable.
- **LES choice:** Shapley is principled but O(n²) in closed form; Equal Surplus (ES) is O(k) but discards higher-order state dependence; Solidarity offers a middle ground.
- **Scalability:** When |u| > 5-6, even moderate m becomes costly; Monte Carlo permutation sampling can approximate Shapley at lower cost.

### Failure signatures
- **Numerical instability:** If |ϕᵤ| is tiny, Δp(i) calculations amplify floating-point noise. Check magnitude of residuals.
- **Categorical mishandling:** If the mixture extension is not applied for categorical features, intermediate points may be invalid, yielding garbage gₚ.
- **High-order dominance:** If the transition is driven by a high-order pot, grid-state sums may be dominated by extreme states, making Sᵢ sensitive to m.
- **Non-local effects:** The local cube assumes model additivity outside; if changing key features shifts the model regime, rᵤ(t) may not represent the true interaction.
- **Oscillations for non-smooth models:** For tree ensembles, attributions can oscillate as m crosses split thresholds; monitor stability across m.

## Open Questions the Paper Calls Out
1. **Convergence for non‑smooth models:** What are the convergence properties and stability guarantees of Aumann‑SHAP as grid resolution increases for models like tree ensembles? The paper notes that attributions may change when refinement resolves new split thresholds and leaves convergence analysis outside the scope.
2. **Automatic grid resolution selection:** How can the grid resolution \( m \) be chosen automatically and optimally for a given model and counterfactual? The paper uses a heuristic saturation rule with tolerance \( \varepsilon \) but provides no theoretical foundation.
3. **Extension beyond counterfactual transitions:** Can the Aumann‑SHAP framework be generalized to other XAI settings, such as global feature importance or time‑series explanations? The current method is tied to the counterfactual transition; adapting it would require abstracting the "transition" concept.
4. **Choice of LES parameterization:** For the Aumann‑LES family, which b(s) yields the most robust and actionable explanations across different data types and models? The paper compares Shapley (b(s)=1) and Equal Surplus (b(1)=n-1, b(s)=0 for s≥2) but does not evaluate others like Solidarity.

## Limitations
- Grid discretization may fail to capture interactions in non-smooth models (e.g., tree ensembles), leading to noisy or unstable attributions.
- Handling of multiple categorical features is only defined for a single categorical; extensions to many categoricals are unspecified and can introduce bias.
- Computational cost grows exponentially with the number of changed features |u|, limiting use for high-dimensional counterfactuals.
- Convergence to Integrated Gradients requires C¹ smoothness, which is violated by piecewise-linear models; convergence is not guaranteed in that case.

## Confidence
- **Micro-game construction (smooth models):** Medium confidence; the mechanism is well-defined but for non-smooth models confidence is Low.
- **Geometry-aware pot allocation:** High confidence; the theoretical derivation of within‑pot contributions is rigorous.
- **Convergence to Integrated Gradients:** High under the C¹ smoothness assumption; Low otherwise.
- **Empirical superiority (patch tests):** Medium confidence; demonstrated on two datasets but needs broader validation.
