# HT-GNN: Hyper-Temporal Graph Neural Network for Customer Lifetime Value Prediction in Baidu Ads

## Quick Facts
- **arXiv ID:** 2601.13013  
- **Source URL:** https://arxiv.org/abs/2601.13013  
- **Reference count:** 40  
- **Primary result:** Achieves over 75% relative improvement (NRMSE 0.1109 vs. 0.4712) on short-term LTV (LT30) prediction versus state-of-the-art baseline.

## Executive Summary
Predicting customer lifetime value (LTV) in online advertising is challenging due to heterogeneous user segments and noisy, irregular behavior sequences influenced by dynamic marketing. The HT-GNN model introduces a three-part architecture: (1) a hypergraph learning module with Jensen-Shannon divergence supervision to capture inter-segment relationships, (2) a transformer-based temporal encoder with adaptive masking to handle irregular sequences, and (3) a task-adaptive mixture-of-experts (MoE) with dynamic prediction towers for multi-horizon forecasting. Evaluated on 15 million Baidu Ads users, HT-GNN substantially outperforms baselines across all horizons (30, 180, 365 days) and metrics (NRMSE, NMAE, GINI, AUC). Ablation studies confirm the contribution of each core component.

## Method Summary
The method integrates three innovations. First, it constructs a *k*-NN hypergraph from user static features and applies hypergraph convolution, supervised by a Jensen-Shannon divergence loss that aligns learned embedding similarities with LTV label similarities (using pseudo-labels for unobserved horizons). Second, it processes 35 behavior types with a Transformer encoder; sequences are randomly masked, and the mask pattern is embedded to generate adaptive weights for the final representation, addressing irregularity. Third, a task-adaptive MoE combines task-specific and shared experts, with gating controlled by the mask embedding. Each prediction horizon (short/medium/long-term) uses separate dynamic regression and classification towers whose linear layer weights are functions of the mask embedding. The total loss combines JS divergence, cross-entropy for zero-LTV classification, and a dynamic Huber loss for robust regression.

## Key Results
- HT-GNN reduces NRMSE for LT30 (30-day LTV) by over 75% relative to the best baseline (MDME), from 0.4712 to 0.1109.
- Consistent performance gains hold across all prediction horizons (30, 180, 365 days) and metrics (NRMSE, NMAE, GINI, AUC).
- Ablation studies show removing the hypergraph module, dynamic weighting, or dynamic towers each causes significant performance drops, validating all three components.

## Why This Works (Mechanism)

### Mechanism 1: Hypergraph Learning with JS Supervision
**Claim:** Hypergraph learning captures inter-segment user relationships, improving predictions by leveraging population-level regularities.  
**Mechanism:** A hypergraph connects each user to its *k*-nearest neighbors via hyperedges. Hypergraph convolution propagates information across these group structures. A Jensen-Shannon (JS) divergence loss supervises this process by aligning the similarity structure of user embeddings with the similarity structure of LTV labels (or pseudo-labels), ensuring representations preserve value-relevant groupings.  
**Core assumption:** Users with similar static features have similar LTV patterns, and modeling higher-order group interactions (beyond pairwise) is beneficial.  
**Evidence anchors:** Empirical analysis (Section III, Fig. 2) shows LTV variance decreases with feature similarity; Section IV.B details hypergraph construction, convolution, and JS loss (Eqs. 5–10).  
**Break condition:** If user segments are homogeneous (low inter-group variance), hypergraph complexity is unjustified. Performance degrades if *k*-NN grouping incorrectly clusters users with divergent LTVs.

### Mechanism 2: Transformer with Adaptive Mask-Based Weighting
**Claim:** A transformer-based temporal encoder with adaptive weighting based on sequence mask patterns handles irregular, noisy behavior sequences.  
**Mechanism:** For each of 35 behavior types, sequences are embedded and randomly masked before a Transformer encoder. The mask pattern itself is embedded (*u*<sup>mask</sup><sub>i</sub>) and used to compute dynamic weights for the aggregated temporal representation, allowing the model to weigh information based on observed availability patterns rather than assuming regular intervals.  
**Core assumption:** The pattern of missing/available observations contains information about user engagement or marketing influence and should modulate the representation.  
**Evidence anchors:** Abstract and Section IV.C describe masking, positional encoding, and dynamic weighting via *u*<sup>mask</sup><sub>i</sub>.  
**Break condition:** If sequences are predominantly regular (e.g., daily logs), adaptive weighting may add unnecessary complexity or noise, and simpler positional encodings might suffice.

### Mechanism 3: Task-Adaptive MoE with Dynamic Towers
**Claim:** A mixture-of-experts (MoE) with dynamic prediction towers enables robust multi-horizon forecasting by specializing experts and output layers for heterogeneous user patterns and task-specific requirements.  
**Mechanism:** For each prediction horizon, separate task-specific experts and shared experts are maintained. A gating function (Eq. 13) uses the sequence mask embedding to weight expert contributions per task. Separate dynamic regression and classification towers per task use mask-based dynamic linear layers (Eq. 18) to adapt the final prediction head.  
**Core assumption:** Different horizons (short vs. long-term) require different combinations of static and temporal features, and this requirement correlates with the behavior sequence availability pattern.  
**Evidence anchors:** Abstract and Sections IV.D–E detail MoE, gating, and dynamic towers. Ablation (Table II) shows removing dynamic weighting (“w/o DW”) or dynamic towers (“w/o DT”) significantly harms performance.  
**Break condition:** If all horizons rely on similar feature combinations (e.g., only recent behavior), MoE complexity is unnecessary and could cause overfitting or expert collapse.

## Foundational Learning

- **Concept:** Hypergraph Neural Networks (HyperGNNs)  
  **Why needed:** To model non-pairwise, group-level relationships among users beyond standard graph convolutions.  
  **Quick check:** How does the incidence matrix *H* in a hypergraph differ from an adjacency matrix in a standard graph, and why does this allow modeling of "higher-order correlations"?

- **Concept:** Transformer Architecture for Temporal Sequences  
  **Why needed:** To process variable-length, irregular behavior sequences; self-attention weighs importance without recurrent dependencies, extended here with mask-based adaptive weighting.  
  **Quick check:** What is the role of the special "[cls]" token appended to each behavior sequence, and how is its final state used?

- **Concept:** Mixture-of-Experts (MoE) with Task-Adaptive Gating  
  **Why needed:** To handle heterogeneity in predictive features across different LTV horizons by specializing experts and combining them dynamically per task.  
  **Quick check:** What is the key difference between the task-specific experts {E<sup>t</sup><sub>j</sub>} and the shared experts {E<sup>s</sup><sub>j</sub>} in the HT-GNN MoE design?

## Architecture Onboarding

- **Component map:**  
  Input Features → Hypergraph Module (JS supervision) → ↳ Combined with ↳ Temporal Encoder (Transformer + mask weighting) → Task-Adaptive MoE (mask-gated experts) → Dynamic Towers (per-task regression/classification) → Outputs  
- **Critical path:** Static features → Hypergraph learning → Temporal encoder → Task-adaptive MoE → Dynamic task towers. The mask embedding *u*<sup>mask</sup><sub>i</sub> influences MoE gating and dynamic weights at two points.
- **Design tradeoffs:**  
  - Hypergraph complexity vs. group modeling fidelity: heavier computation justified by variance reduction (Fig. 2).  
  - Transformer cost vs. irregular sequence handling: expensive but enables long-range dependencies and adaptive weighting.  
  - MoE parameter explosion vs. specialization: separate experts/towers per task increase parameters; shared experts mitigate this.  
  - Multi-loss tuning vs. robustness: balancing JS, classification, and Huber losses (β parameters) requires careful tuning.
- **Failure signatures:**  
  - Hypergraph failure: JS loss remains high, indicating inability to align embedding and label similarities.  
  - Temporal encoder failure: poor performance on sparse sequences vs. simple average baseline.  
  - MoE/Dynamic tower failure: gating weights near uniform (no specialization) or some experts never activated.  
  - Generalization failure: strong short-term but weak long-term performance, indicating inadequate temporal modeling for long horizons.
- **First 3 experiments:**  
  1. Ablation study: remove hypergraph (HG), dynamic weighting (DW), and dynamic towers (DT) to validate each component’s contribution (as in Table II).  
  2. Loss function comparison: train with only MSE, only Huber, and the proposed multi-loss to confirm necessity of combined strategy (as in Table III).  
  3. GNN architecture comparison: replace hypergraph layer with standard GCN, GraphSAGE, or GAT to test hypergraph superiority (as in Table IV).

## Open Questions the Paper Calls Out

- **Open Question 1:** How does pseudo-labeling for unlabeled samples in JS supervision affect reliability and bias of user segment representations?  
  **Basis:** Pseudo-labels are used for horizons without ground truth; impact not isolated or analyzed.  
  **Why unresolved:** Ablation removes entire hypergraph module, not pseudo-labeling strategies.

- **Open Question 2:** To what extent does the adaptive weighting mechanism for irregular sequences outperform other irregular time-series methods (e.g., GRU-D), and what specific irregularity patterns does it best address?  
  **Basis:** Motivates handling “irregular behavioral sequences” but no direct comparison to other irregular sequence models.  
  **Why unresolved:** Baselines lack advanced irregular handling; ablation replaces DW with simpler fixed approach, not state-of-the-art alternatives.

- **Open Question 3:** Is the sequence-length mask *u*<sup>mask</sup><sub>i</sub> sufficient as sole gating input, or are other signals (e.g., behavior entropy, feature missingness) needed?  
  **Basis:** Gating network (Eq. 13) uses only mask embedding; paper posits “data availability” drives selection but doesn’t validate mask sufficiency.  
  **Why unresolved:** No ablation adding other availability signals; mask reflects length but not richness or type of behaviors.

- **Open Question 4:** What is the trade-off between loss components (JS, classification, Huber) during joint optimization, and do they converge at compatible rates?  
  **Basis:** Combined loss defined (Eq. 21) and multi-loss outperforms single losses (Table III), but dynamics unexplored.  
  **Why unresolved:** β weights selected empirically without sensitivity analysis; gradient interactions and convergence dynamics not monitored.

## Limitations
- Critical hyperparameters (embedding dimensions, expert counts, dropout) unreported, hindering exact replication.
- Pseudo-labeling strategy for JS loss on unobserved horizons is conceptually unclear and lacks implementation details.
- Scalability claims unverified; constructing *k*-NN hypergraphs for 15M users may require approximations not discussed.

## Confidence
- **Hypergraph + JS supervision:** Medium. Empirical variance reduction (Fig. 2) motivates grouping, but JS-supervised hypergraph formulation lacks prior validation.
- **Transformer adaptive weighting:** Low. Novel mask-to-weight mechanism; no ablation isolating its contribution from other temporal components.
- **MoE + dynamic towers:** Medium. Ablation (Table II) shows gains, but integrated design untested in isolation.

## Next Checks
1. **Isolate temporal adaptive weighting:** Implement Transformer without mask-based dynamic weighting (use standard positional encoding); compare NRMSE on LT30 to full model.
2. **Hypergraph necessity test:** Replace hypergraph convolution with pairwise *k*-NN graph + GCN; evaluate if hypergraph’s higher-order modeling yields significant gains.
3. **JS loss correctness verification:** On a synthetic dataset with predefined LTV-based clusters, confirm JS loss decreases during training and that embeddings preserve cluster similarities.
