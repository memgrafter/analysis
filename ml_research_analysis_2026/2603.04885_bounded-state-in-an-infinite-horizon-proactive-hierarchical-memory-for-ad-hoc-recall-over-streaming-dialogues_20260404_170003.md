# Bounded State in an Infinite Horizon: Proactive Hierarchical Memory for Ad-Hoc Recall over Streaming Dialogues

## Quick Facts
- **arXiv ID:** 2603.04885
- **Source URL:** https://arxiv.org/abs/2603.04885
- **Reference count:** 38
- **Primary result:** ProStream achieves state-of-the-art accuracy on streaming dialogue QA (STEM-Bench) with constant inference latency, resolving the fidelity-efficiency dilemma via proactive hierarchical memory.

## Executive Summary
This paper tackles the core challenge of maintaining an accurate, bounded memory state for ad-hoc question answering over infinite-horizon dialogue streams. Existing approaches either fragment context via retrieval or suffer unbounded latency by processing full history. The proposed ProStream framework introduces a proactive hierarchical memory system that distills dialogues into a multi-granular knowledge tree (scenes, events, atomic units) and employs an adaptive spatiotemporal optimization to enforce a strict memory budget. On the new STEM-Bench dataset (14,938 QA pairs), ProStream demonstrably outperforms all baselines in reasoning fidelity metrics while guaranteeing constant-time complexity, proving that a structured, optimized memory state can surpass raw context in both accuracy and efficiency for streaming scenarios.

## Method Summary
ProStream operates in four stages: (1) **Proactive Perception** uses a Short-Term Sensing Buffer (STSB) to accumulate utterances, detecting semantic drift via embedding similarity to segment the stream. (2) **Hierarchical Distillation** transforms each flushed block into a three-layer tree: a scene label, an event summary (using LaMini-T5), and atomic memory units (AMUs) as relational triplets (using GLiNER). AMUs are attached to events only if their embedding novelty is below a threshold. (3) **Adaptive Optimization** continuously maintains a bounded memory by assigning each node a utility score combining frequency and time-decayed recency; when a token budget is exceeded, a greedy policy prunes low-utility nodes, merges similar ones, and cascades abstractions. (4) **Evidence-Grounded Generation** retrieves relevant memory paths via top-down tree traversal with a composite score (cosine similarity × utility), merges them with recent STSB content and pending distillations, and generates answers with a frozen LLM (e.g., Qwen).

## Key Results
- **SOTA Accuracy:** ProStream significantly outperforms all retrieval-based and full-context baselines across BLEU-4, ROUGE-L, BERTScore, Evidence Similarity, Key Entity Matching, and Gemini scores on STEM-Bench.
- **Constant Latency:** Inference time remains bounded and independent of stream length, beating even the full-context oracle in wall-clock efficiency for long streams.
- **Ablation Strength:** Ablating any core component (STSB, tree structure, pending buffer) causes catastrophic performance drops, validating the synergistic design.

## Why This Works (Mechanism)

### Mechanism 1: Proactive Hierarchical Distillation for Bounded Semantics
- **Claim:** Transforming the infinite stream into a bounded, multi-granular knowledge tree (scenes, events, atomic units) enables efficient ad-hoc recall without scanning raw context.
- **Mechanism:** Incoming utterances are segmented by semantic drift detection. Each block is recursively distilled: coarse scene classification, mid-level event summarization, and fine-grained AMU extraction as triplets. This creates a query-friendly topology organized by semantic granularity.
- **Evidence:** §5.2 details the dual-path generation (summarization) and structuring (triplet extraction). The abstract explicitly states this creates a "bounded knowledge tree."
- **Break condition:** Failed semantic segmentation (e.g., rapid topic shifts) degrades tree coherence and retrieval.

### Mechanism 2: Adaptive Spatiotemporal Optimization for Budget Enforcement
- **Claim:** Dynamic pruning and merging based on time-decaying utility guarantees a bounded memory state and constant inference latency.
- **Mechanism:** Nodes have utility `u_v,t = α·log(f_v,t + 1) + β·exp(−Δt_v/τ)`. When cost exceeds `T_max`, a greedy policy removes nodes with lowest marginal utility density (`u_v,t / c_v`), merges nodes below a similarity threshold `θ_sim`, and cascades abstractions.
- **Evidence:** §5.3 defines the online knapsack formulation and greedy policy with a (1−1/e) approximation guarantee under submodular utility.
- **Break condition:** Utility misestimation may prematurely discard critical but low-frequency nodes, harming fidelity.

### Mechanism 3: Probabilistic Evidence-Grounded Synthesis
- **Claim:** Combining immediate context with utility-weighted hierarchical memory paths yields coherent, factually grounded answers.
- **Mechanism:** For a query, the system traverses the tree top-down (scenes → events → AMUs), scoring each AMU as `S(o) = cos(v_q, v_o) · u_o,t`. Retrieved paths are merged with STSB and pending distillations to form context `K` for LLM generation.
- **Evidence:** §5.4 describes the hierarchical retrieval scoring and context composition `K = {B, M_pend, M_tree}`.
- **Break condition:** Missing a critical low-utility node or STSB contradictions can cause hallucination or inconsistency.

## Architecture Onboarding
- **Component map:** STSB -> Distillation Engine -> Memory Tree (H) <- Optimization Manager; Retrieval & Generation uses H, STSB, and M_pend.
- **Critical path:** New utterance -> STSB accumulation -> (on flush) Distillation -> Tree update -> Optimization -> (on query) Hierarchical retrieval -> Generation. Optimization triggers on flushes or queries; retrieval is per-query.
- **Design tradeoffs:** 
  - Fidelity vs. Efficiency: Distillation loses lexical detail for semantic abstraction; aggressive pruning risks discarding long-tail facts.
  - Granularity: Coarser trees increase efficiency but may merge distinct entities; finer trees preserve detail but increase overhead.
  - Utility weights (`α`, `β`): Balance persistent topics vs. recency; domain-dependent.
- **Failure signatures:** 
  - Catastrophic drop without STSB (`-w/o B`): vague/ inconsistent short-term references.
  - Poor multi-hop/comparative reasoning (SLR tasks): broken tree hierarchy or failed cross-event path retrieval.
  - High latency despite pruning: overly fine granularity or inefficient vector search; unenforced `T_max`.
  - Hallucination on premise-compliance errors: generation stage overrides memory evidence to align with query framing.
- **First 3 experiments:**
  1. **Unit Test: Flush & Distill.** Feed a block with known entities/events; verify correct tree structure, labels, AMU extraction, and novelty threshold behavior.
  2. **Stress Test: Optimization Boundary.** Stream long dialogue (e.g., 10k tokens); log memory size and query latency. Confirm size never exceeds `T_max` and latency plateaus.
  3. **Retrieval Sanity Check.** For a query with known evidence, trace retrieval paths; verify composite score `S(o)` prioritizes correct evidence over high-similarity distractors.

## Open Questions the Paper Calls Out
- **OQ1:** How can ProStream integrate explicit conflict detection to resolve the compliance legitimacy bias where it validates fallacious user claims contradicting stored memory? The current framework lacks a contradiction detection module, leading to hallucinations on false premises.
- **OQ2:** How can activity-aware attention mechanisms be incorporated to improve implicit context disentanglement in dense dialogues? The model's attention is captured by high-density monologues, missing fragmented critical cues (e.g., crossword puzzle references).
- **OQ3:** How can hierarchical distillation be adapted for smaller language models (<7B)? The observed U-shaped efficiency profile suggests distillation overhead outweighs gains for smaller backbones that cannot parse structured topologies effectively.
- **OQ4:** To what extent do results on synthesized audio (ChatTTS) generalize to real-world streaming audio with noise, accents, and disfluencies? The controlled benchmark may overestimate ASR robustness.
- **OQ5:** Can the Adaptive Spatiotemporal Optimization policy be enhanced beyond greedy marginal-utility pruning for infinite-horizon streams? The handcrafted utility function may not fit non-stationary patterns; a learned policy could reduce regret.

## Limitations
- STEM-Bench dataset is not public; exact construction pipeline details (prompts, clustering) are missing.
- Key hyperparameters (temporal decay τ, merging threshold θ_sim) are unspecified.
- Baseline implementations and configurations are not detailed, compromising fair comparison.
- Reliance on LLM-based metrics (Gemini score) may introduce evaluator bias.

## Confidence
- **Bounded hierarchical distillation:** Medium – algorithm described but depends on external modules (LLM, GLiNER); no external validation.
- **Adaptive spatiotemporal optimization:** Medium – theoretical guarantee holds under assumptions; empirical support rests on proprietary dataset.
- **Evidence-grounded generation:** Medium – ablations show contribution, but dataset-specific effects unruled out.
- **Overall claim (SOTA accuracy + constant latency):** Medium – strong reported results, but reproducibility gaps temper certainty.
