# Ca-MCF: Category-level Multi-label Causal Feature selection

## Quick Facts
- **arXiv ID:** 2602.12961
- **Source URL:** https://arxiv.org/abs/2602.12961
- **Reference count:** 36
- **Primary result:** Significantly outperforms seven state-of-the-art methods on seven real-world datasets, achieving the best average rank in six out of seven evaluation metrics while selecting more compact feature subsets.

## Executive Summary
Multi-label causal feature selection (MLCFS) traditionally treats each label as a monolithic entity, obscuring fine-grained category-specific causal mechanisms. Ca-MCF introduces *label-category flattening* to decompose labels into individual binary category nodes, enabling precise causal modeling within the label space. It employs information-theoretic metrics—Specific and Distinct Category-Specific Mutual Information (SCSMI & DCSMI)—to discover Markov Blankets, coupled with an explanatory competition-based recovery mechanism that salvages features suppressed by label correlations. Evaluated on seven datasets, Ca-MCF reduces Hamming Loss and increases Macro-F1, with statistically significant gains confirmed by Friedman and Bonferroni-Dunn tests.

## Method Summary
Ca-MCF transforms multi-label data by flattening each label into a set of binary category nodes (e.g., label *L* with categories {A,B} becomes nodes *C_A* and *C_B*). A four-phase pipeline then identifies the Markov Blanket (MB) for each category: (1) **Label Skeleton Builder** constructs a sparse graph of category-category dependencies using DCSMI; (2) **Local MB Discoverer** finds parents/children (PC set) and spouses (SP) via conditional SCSMI tests; (3) **Feature Recovery Engine** re-evaluates discarded features by competing their conditional explanatory power against blocking label categories; (4) **Symmetry & Redundancy Filter** enforces bidirectional associations and removes features overly predictive of other categories. The union of all category-specific MBs yields the final feature subset. Performance is measured by training ML-kNN (k=10) on selected features and computing seven standard multi-label metrics.

## Key Results
- Achieves best average rank in 6 of 7 metrics across 7 datasets.
- Reduces Hamming Loss and increases Macro-F1 compared to 7 baselines.
- Selects more compact feature subsets.
- Statistical tests (Friedman, Bonferroni-Dunn) confirm significance.

## Why This Works (Mechanism)
The method's success rests on three interlocking mechanisms:

**1. Label-category flattening uncovers hidden causal heterogeneity.**  
*Claim:* Decomposing monolithic multi-label variables into fine-grained category nodes enables discovery of causal relationships obscured by aggregate label representations.  
*Mechanism:* Each distinct value within a label becomes a separate binary target (e.g., *L_i={A,B}* → *C_iA*, *C_iB*), allowing direct dependencies between features and specific label states to be modeled.  
*Core assumption:* Causal mechanisms for predicting a specific category (e.g., "image contains a *dog*") differ from those for another category in the same label (e.g., "image contains a *cat*").  
*Evidence anchors:* Formal definition in Definition 1; abstract statement about precise modeling of causal structures.

**2. SCSMI/DCSMI enable robust conditional independence testing.**  
*Claim:* These metrics quantify feature-to-category and category-to-category dependencies in the flattened space, providing a stable foundation for MB discovery.  
*Mechanism:* SCSMI measures *X → C_ic* associations; DCSMI measures *C_ic ↔ C_jd* associations. Conditional forms ( Eqs. 1–2) are used for PC-set refinement and spouse identification.  
*Core assumption:* Mutual information estimated on the flattened space sufficiently captures direct causal associations for non-linear relationships.  
*Evidence anchors:* Used in Algorithms 2–3; formal definitions in Definition 2.

**3. Explanatory competition recovers features blocked by label correlations.**  
*Claim:* The recovery mechanism restores causal features that are statistically suppressed (blocked) by strong correlations between label categories ("label blocking").  
*Mechanism:* For discarded features *f_miss* with moderate SCSMI, compete against each potential blocking category *Y_block*: if *SCSMI(f_miss; C_ic | S_base) > DCSMI(Y_block; C_ic | S_base)*, add *f_miss* and remove *Y_block*.  
*Core assumption:* A true causal parent/child will, when conditioned appropriately, have stronger residual association with *C_ic* than a correlated but non-causal label category.  
*Evidence anchors:* Theorem 1 and Definition 5 formalize causal blocking; Algorithm 4 implements the competition.

## Foundational Learning
- **Markov Blanket (MB):** The set of a node’s parents, children, and spouses. *Why needed:* Ca-MCF aims to identify the MB of each flattened category; understanding MB composition is key to interpreting outputs. *Quick check:* What three types of features constitute a target category’s MB, and how are they identified in Phase 2?
- **Conditional Independence via Mutual Information:** Using MI (SCSMI/DCSMI) to test conditional independence for structural discovery. *Why needed:* All phases rely on these tests; thresholds and conditioning sets affect reliability. *Quick check:* In spouse identification (Eq. 11), why are both *SCSMI(z; C_ic | R_ic) ≤ δ1* and *SCSMI(z; C_ic | {x} ∪ R_ic) > δ1* required?
- **Label Blocking Effect:** Strong correlations between label categories can suppress the statistical signal of true causal features. *Why needed:* This is the core problem Phase 3 solves; understanding it justifies the recovery mechanism. *Quick check:* Describe a scenario where a true parent *X* of *C_ic* is incorrectly deemed independent due to correlation with *C_jd*.

## Architecture Onboarding
**Component map:**  
Input Processor -> Phase 1: Label Skeleton Builder (Alg 2) -> Phase 2: Local MB Discoverer (Alg 3) -> Phase 3: Feature Recovery Engine (Alg 4) -> Phase 4: Symmetry & Redundancy Filter (Alg 5) -> Aggregator

**Critical path:** Phase 2 establishes the initial PC and SP sets, making it the most structurally determining and computationally intensive phase (O(m² l)). Phase 3 is the key differentiator from prior label-level MB methods.

**Design tradeoffs:**
- Granularity vs. cost: Flattening increases target nodes, raising O(m² l) complexity for labels with many categories.
- Threshold sensitivity: Performance hinges on δ1 (feature-category strength) and δ2 (label-category strength); poor settings cause over/under-selection.
- Recovery aggressiveness: The competition heuristic (Eq. 12) may restore spurious features if conditioning sets are weak or metrics noisy.

**Failure signatures:**
- Performance degrades on datasets with high label cardinality and many rare categories (e.g., Yeast, Enron) due to unstable MI estimates from data sparsity.
- Oversized feature subsets result from ineffective redundancy removal (e.g., multiplier γ=1.2 unsuitable for noise level) or incomplete label skeletons.
- No improvement over MI baselines if k1 pruning in Phase 2 is too aggressive, eliminating true PC candidates before rescue.

**First 3 experiments:**
1. **Reproducibility sanity check:** Run Ca-MCF on Flags dataset; verify output feature count and top features align with domain knowledge; check metric trends (HL/Macro-F1) match Figure 1.
2. **Ablation - Recovery mechanism:** Disable Phase 3; compare performance on Enron (high label correlations); expect significant drop confirming recovery’s role.
3. **Threshold stress test:** Systematically vary δ1 and δ2 on VirusGO; plot performance cliffs; validate adaptive tuning robustness, especially for sparse data.

## Limitations
- Discretization method for continuous features is unspecified, affecting mutual information stability.
- Adaptive threshold procedures (δ1, δ2) and fraction-to-integer conversion for k1/k2 are ambiguous.
- High computational complexity O(m² l) may be prohibitive for many categories (e.g., Enron’s 53 labels → ~100 flattened nodes).
- Rare categories cause sparse data issues, leading to unreliable MI estimates and potential false independence.

## Confidence
- Label-category flattening reveals hidden mechanisms: **Medium** (empirical gains but lacking synthetic control).
- SCSMI/DCSMI provide reliable conditional independence: **Medium** (nonparametric but biased with limited data; bias correction not discussed).
- Competition recovery salvages suppressed features: **Low** (theoretical basis but weak empirical isolation; risk of false positives).
- Overall performance gains are statistically significant: **High** (consistent improvements across datasets and metrics with statistical tests).

## Next Checks
1. **Synthetic ablation:** Simulate multi-label data with known category-specific Markov Blankets; compare Ca-MCF’s precision/recall against label-level methods.
2. **Discretization robustness:** Replace binned MI with continuous estimators (e.g., KSG) on real datasets; evaluate stability of selected features and classification metrics.
3. **Scalability & parameter profiling:** Measure runtime/memory vs. number of categories and features; perform systematic grid search over δ1, δ2, k1, k2 to map performance cliffs; validate adaptive tuning robustness.
