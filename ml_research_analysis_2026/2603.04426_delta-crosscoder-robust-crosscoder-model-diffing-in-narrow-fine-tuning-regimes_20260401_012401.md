# Delta-Crosscoder: Robust Crosscoder Model Diffing in Narrow Fine-Tuning Regimes
## Quick Facts
*   **arXiv ID:** 2603.04426
*   **Source URL:** https://arxiv.org/abs/2603.04426
*   **Reference Count:** 23
*   **Primary Result:** Delta-Crosscoder successfully recovered causally valid, fine-tuning-specific latents across all 10 tested narrow fine-tuning scenarios, achieving perfect coverage where prior SAE-based baselines failed.

## Executive Summary
Standard crosscoders, which learn a shared sparse feature dictionary between a base and fine-tuned model, struggle to isolate sparse, localized representation changes caused by narrow fine-tuning. Such changes are often dwarfed by shared, high-frequency features and fail to receive a strong training signal. Delta-Crosscoder addresses this by introducing a dual-component latent space (shared vs. delta-specific), a delta loss that directly targets activation differences, and the use of contrastive data pairs to amplify fine-tuning signals. This enables robust identification of causally implicated features across diverse model organisms and failure modes, facilitating model steering and mitigation without requiring interactive probing.

## Method Summary
Delta-Crosscoder modifies the standard crosscoder architecture with three key components. First, it employs **Dual-K sparsity**, partitioning the latent space into a shared subspace (20%) and a non-shared "delta" subspace (80%), each with its own activation budget. Second, it adds a **delta loss** (`L_Δ`) that explicitly penalizes the mismatch between the observed activation difference (`Δ`) and the difference in model-specific decoders, but crucially **masks out** the shared latents, forcing `Δ` to be explained solely by the non-shared latents. Third, it trains on a mixture of general data and **contrastive pairs**—activations from the same prompt but with different model generations—to ensure `Δ` concentrates on layers involved in the fine-tuned behavioral response. Post-training, features are ranked by their relative decoder norm in the fine-tuned model; top-ranked non-shared features are validated for causal effect via steering.

## Key Results
*   **Causal Coverage:** Recovered valid latents in 10/10 narrow fine-tuning test cases (emergent misalignment, taboo guessing, false facts, subliminal learning), outperforming SAE baselines (best: 6/10) and matching the non-SAE Activation Difference Lens.
*   **Reconstruction & Efficiency:** Maintained high reconstruction fidelity (~80% explained variance, within 1-2% of baselines) with comparable or lower dead feature rates.
*   **Robustness:** Ablations confirmed the necessity of the delta loss, Dual-K partition, and contrastive data; performance was stable regardless of access to the fine-tuning dataset itself.

## Why This Works (Mechanism)
### Mechanism 1: Dual-K Sparsity Partition
*   **Claim:** Reserving separate latent budgets for shared and delta-specific features isolates fine-tuning signals by preventing dominant shared features from absorbing the weak `Δ` signal.
*   **Mechanism:** The latent space is split: first 20% of features use a larger `K_shared` budget to model common structure; remaining 80% use a smaller `K_Δ` budget and are the only ones allowed to contribute to the delta loss via masking. This constrains capacity for `Δ`, enforcing sparsity and preventing it from being modeled by shared features.
*   **Core assumption:** Fine-tuning-induced behavioral changes manifest as sparse, localized shifts in a subspace distinct from the high-frequency features shared by both models.
*   **Evidence anchors:** Spatial partitioning and masking defined in section 3.3; causal validation selects top non-shared features by relative norm (section 4.3).
*   **Break condition:** If fine-tuning effects are distributed symmetrically across many features, the partition unnecessarily restricts capacity and could harm reconstruction without improving isolation.

### Mechanism 2: Delta Loss with Shared Feature Masking
*   **Claim:** Directly optimizing for prediction of `Δ` creates a gradient signal that pulls fine-tuning-specific directions into the non-shared latent subspace.
*   **Mechanism:** The auxiliary loss `L_Δ = ||Δ - (W_ft - W_base)[0; z_Δ]||²` ensures only the non-shared component `z_Δ` is used to predict `Δ`. This tunes the decoder difference `(W_ft - W_base)` for the non-shared features to match the observed activation differences.
*   **Core assumption:** `Δ` contains a structured, learnable signal about fine-tuning effects that is orthogonal to the majority of shared activation variance.
*   **Evidence anchors:** Delta loss formulation and integration in Equation 10 (section 3.3); successful recovery in all 10 test cases (section 4.1).
*   **Break condition:** If `Δ` is dominated by noise or spurious correlations (e.g., seed differences), the delta loss could learn false directions. The null test (identical models) suggests this is mitigated in practice.

### Mechanism 3: Contrastive Pair Data Construction
*   **Claim:** Activations from paired model responses (`x || y_base` vs. `x || y_ft`) induce an asymmetry that amplifies fine-tuning-specific signals in `Δ`.
*   **Mechanism:** For a shared prompt `x`, the two models generate different continuations (`y_base`, `y_ft`). Extracting activations across the full sequence ensures `Δ` captures differences during the *generation* of the fine-tuned-style response, not just early prompt processing.
*   **Core assumption:** Narrow fine-tuning alters generative behavior; this alteration is most evident in activations during the production of the finetuned continuation.
*   **Evidence anchors:** Data mixture includes 100k contrastive pairs (20M tokens) (section 4.2); steering efficacy on task-agnostic prompts (section 5) shows latents capture behavioral dispositions.
*   **Break condition:** If the fine-tuning effect is purely in-context or only modifies earliest layers, the contrastive construction might not sufficiently amplify the signal.

## Foundational Learning
*   **Sparse Autoencoders (SAEs) & Linear Representation Hypothesis**
    *   **Why needed here:** Delta-Crosscoder extends the SAE framework to a cross-model setting. Understanding how SAEs use overcomplete dictionaries and sparsity to disentangle superposition is prerequisite.
    *   **Quick check:** If a single-model SAE learns features as linear combinations due to superposition, what must be true of a crosscoder's shared dictionary to enable meaningful comparison between models?

*   **Crosscoders for Model Diffing**
    *   **Why needed here:** The paper directly modifies the standard crosscoder objective. The baseline—shared latents, model-specific decoders, and post-hoc exclusivity via relative decoder norm—is the target of improvement.
    *   **Quick check:** In a standard crosscoder, why do small, sparse differences between models tend to be ignored during training?

*   **Narrow Fine-Tuning & Model Organisms**
    *   **Why needed here:** The problem scope is defined by narrow fine-tuning (small datasets, specific objectives) that causes unpredictable, large behavioral shifts ("emergent misalignment") from minimal representation changes.
    *   **Quick check:** Why might a model finetuned on a narrow task (e.g., taboo word guessing) exhibit a broad behavioral shift (e.g., deception) despite a minimal training distribution change?

## Architecture Onboarding
*   **Component map:**
    `x_base, x_ft` (activation streams) -> `W_base_e, W_ft_e` (encoders) -> `u = (ubase+uft)/2` (fused latents) -> **BatchTopK (Dual-K)** -> `z = [z_shared, z_Δ]` (sparse code) -> `W_base_d, W_ft_d` (decoders) -> reconstructions; `L_Δ` computes `||Δ - (W_ft - W_base)[0; z_Δ]||²`

*   **Critical path:**
    1.  **Data Prep:** Extract activations from base/finetuned models on general corpora, instruction data, and crucially, contrastive pairs (`x || y_base` and `x || y_ft`).
    2.  **Training Loop:** For each batch, compute sparse `z` via Dual-K BatchTopK. Calculate reconstruction losses for both models. Compute `L_Δ` using only `z_Δ` against `Δ = x_ft - x_base`. Sum losses and backpropagate.
    3.  **Post-Training Analysis:** Compute relative decoder norms (`R_i`) for all features. Select top non-shared features (right tail) for causal validation via steering and max-activation.

*   **Design tradeoffs:**
    *   **Shared Fraction (20%):** Heuristically fixed. Smaller fractions increase `Δ` capacity but risk dead shared features; larger fractions reduce `Δ` capacity.
    *   **`K_shared` vs `K_Δ`:** `K_Δ` is a fraction (α) of `K_shared` (e.g., α=1/5). Too small α starves `Δ` features; too large blurs the partition.
    *   **`λ_Δ` Weight:** Tuned (0.005). Too high destabilizes reconstruction; too low renders delta loss ineffective.
    *   **Contrastive Data Ratio:** 10% of total tokens (20M/200M). More may amplify signal but risk overfitting to contrastive distribution.

*   **Failure signatures:**
    *   **Null Test Failure:** Applied to identical models, relative decoder norm distribution should collapse near 0.5; a long right tail indicates spurious discovery.
    *   **High Dead Feature Rate in `z_Δ`:** If `K_Δ` is too low or delta signal too weak, non-shared features may die.
    *   **Steering Invalidation:** Top-ranked non-shared latents must induce causal behavioral changes; failure implies false positives.
    *   **Reconstruction Collapse:** Explained variance dropping >2-3% below baselines indicates delta constraint harms core learning.

*   **First 3 experiments:**
    1.  **Reproduce Null Test:** Train on two identical unfinetuned models (e.g., two seeds of Llama 3.1 8B Instruct). Confirm tight relative norm distribution (~0.5) and no latents pass causal validation.
    2.  **Ablate Contrastive Data:** Retrain without contrastive pairs (`D_C`). Expect significant drop in coverage/steering efficacy on a known organism (e.g., EM-Risky Finance).
    3.  **Ablate Dual-K Partition:** Train variant with a single shared K budget for all features (but still apply masked `L_Δ` with a random 80% feature selection). Expect degradation vs. partitioned version.

## Limitations
*   The fixed 20%/80% Dual-K split is heuristic; optimal partitioning likely varies with model scale and tuning type.
*   Method relies on contrastive data construction; may not generalize if finetuning data is unavailable or changes manifest in early, non-contrastive layers.
*   Causal validation focuses on top-ranked, individual latents; higher-order interactions or distributed changes could be missed.

## Next Checks
1.  **Dual-K Sensitivity Sweep:** Vary shared feature fraction (0%, 10%, 20%, 30%) and `K_Δ`/`K_shared` ratio. Measure trade-offs in reconstruction, dead features, and causal coverage.
2.  **Contrastive-Data Ablation:** Retrain replacing contrastive pairs with (a) plain text from finetuning corpus and (b) random non-paired responses. Expect severe coverage drop if asymmetry is essential.
3.  **Out-of-Distribution Task Test:** Apply a Delta-Crosscoder trained on one organism (e.g., EM-Risky Finance) to a qualitatively different narrow tuning case (e.g., coding-style shift). Failure would indicate overfitting.
