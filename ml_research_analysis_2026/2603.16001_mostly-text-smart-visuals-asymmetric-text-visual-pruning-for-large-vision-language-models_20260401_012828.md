# Mostly Text, Smart Visuals: Asymmetric Text-Visual Pruning for Large Vision-Language Models

## Quick Facts
*   **arXiv ID:** 2603.16001
*   **Source URL:** https://arxiv.org/abs/2603.16001
*   **Reference count:** 40
*   **Primary result:** Achieves 77.01% average retention at 60% unstructured sparsity on LLaVA-NeXT, setting a new state-of-the-art for LVLM pruning.

## Executive Summary
This paper identifies a fundamental asymmetry in the sensitivity of Large Vision-Language Models (LVLMs) to weight pruning: textual components are highly sensitive and require text-specific calibration, while visual components are robustly redundant. Motivated by this, the authors propose ATV-Pruning, an unstructured pruning method that constructs a calibration pool from all text tokens and a minimal, layer-adaptive set of informative visual tokens. The visual tokens are selected per layer using a "representation drift" metric. Evaluations on LLaVA-NeXT and Qwen2-VL across nine multimodal benchmarks show significant improvements over prior modality-agnostic pruning methods, establishing the principle that text and visual pathways in LVLMs must be handled differently for efficient compression.

## Method Summary
ATV-Pruning modifies the Wanda pruning framework. Instead of using all tokens from a calibration batch to compute activation norms (`||X_j||2`), it builds an asymmetric calibration set `S_cal`. This set is the union of two subsets: (1) **all text token positions** (`T`) from every calibration sample, and (2) a **layer-specific subset of visual token positions** (`V_sub`) selected from each image. The size of `V_sub` is determined per Transformer block by a budget `K`, which scales with the average "representation drift" of visual tokens within that block—a measure of how much a token's representation changes as it passes through the layer. This design focuses the importance scoring on linguistically critical signals while efficiently capturing essential visual information.

## Key Results
*   Achieves state-of-the-art performance at 60% sparsity, e.g., 77.01% average retention on LLaVA-NeXT (vs. 72.74% for the best prior method).
*   Outperforms modality-agnostic baselines (Wanda, LORRA) by a clear margin (>4% absolute) on average across nine benchmarks.
*   Maintains competitive efficiency, with only a 1.35× slowdown compared to the fast Wanda baseline, due to the low overhead of the drift-based selection.

## Why This Works (Mechanism)

### Mechanism 1
*   **Claim:** Textual weights in LVLMs are highly sensitive to the calibration pool composition, while visual weights are robust and redundant.
*   **Mechanism:** Using a Mixture-of-Transformer (MoT) probe, the authors independently prune textual and visual pathways within shared Transformer blocks. Performance of the textual pathway catastrophically degrades when calibrated with non-text tokens, while the visual pathway retains >99% performance even under text-only calibration at 60% sparsity.
*   **Core assumption:** Modality-specific parameters within a shared Transformer block can be functionally separated for analysis.
*   **Evidence anchors:**
    *   [abstract]: "...textual weights are highly sensitive and require text-only calibration, while visual weights are highly redundant..."
    *   [section 3.2]: Finding A & B on calibration sensitivity and weight redundancy.
    *   [section 2, Table 1]: Quantitative ablation showing pathway-specific sensitivity.

### Mechanism 2
*   **Claim:** An effective calibration pool must be text-anchored (include all text tokens) and augmented with only a small, informative subset of visual tokens.
*   **Mechanism:** ATV-Pruning constructs `S_cal = T ∪ V_sub`. Retaining all text tokens preserves the signal for sensitive linguistic weights. A limited `V_sub` prevents the dilution of this signal by less relevant visual tokens, while still providing sufficient context for the redundant visual weights.
*   **Core assumption:** Activation statistics from tokens most relevant to linguistic/reasoning capabilities yield more protective weight importance scores.
*   **Evidence anchors:**
    *   [abstract]: "constructing a calibration pool using all text tokens and a layer-adaptive subset of informative visual tokens."
    *   [section 3.3.1]: Two design principles outlined.
    *   [section 4.4, Figure 5]: Ablation showing performance drops when text tokens are removed from calibration.

### Mechanism 3
*   **Claim:** Visual token saliency for calibration can be estimated per-layer via "visual drift"—the cosine distance between a token's input and output representations—and used for layer-adaptive budget allocation.
*   **Mechanism:** For each visual token `v` in block `b`, compute `s_v = 1 - cos(X_in,v, X_out,v)`. The block-average `¯s` scales the per-sample token budget `K = floor(α * ¯s * n_text)`. Top-K tokens by `s_v` are selected. Layers with higher average drift (often mid- and late-layers) retain more visual tokens.
*   **Core assumption:** Large representation drift indicates a layer actively processes that token's information, making it more important for weight importance estimation in that layer.
*   **Evidence anchors:**
    *   [section 3.3.2]: Formal definition of drift and budget allocation.
    *   [section 4.3.2, Table 3]: Adaptive drift ("Drift, ✓") outperforms non-adaptive ("Drift, ✗").
    *   [section A6, Figure A6]: Visualization of non-uniform drift and resulting token allocation across blocks.

## Foundational Learning
*   **Concept: Activation-aware pruning (e.g., Wanda)**
    *   *Why needed here:* ATV-Pruning is a direct extension of Wanda. The core importance score `I_ij = |W_ij| * ||X_j||2` is fundamental; the paper's innovation is *which activations* `X_j` to include.
    *   *Quick check question:* In Wanda's formula, what do the weight magnitude and activation norm independently represent, and why is their product a heuristic for importance?
*   **Concept: Modality decoupling in LVLMs**
    *   *Why needed here:* The motivation experiment relies on separating "textual" and "visual" pathways within a shared Transformer block to test pruning sensitivity.
    *   *Quick check question:* How can you isolate the effect of pruning on text-associated vs. vision-associated weights when both flow through the same weight matrix `W`?
*   **Concept: Token saliency vs. token pruning**
    *   *Why needed here:* ATV-Pruning prunes *weights*, not tokens. It uses a saliency metric (drift) to select a *calibration subset* of visual tokens, which is distinct from removing tokens from the input sequence.
    *   *Quick check question:* What is the key difference between selecting tokens for *calibration data* (as in ATV-Pruning) and selecting tokens to *remove from the input sequence* during inference?

## Architecture Onboarding
*   **Component map:** Base Pruner (Wanda scoring) -> Modality Router (identifies T/V positions) -> Saliency Computer (computes per-token drift `s_v` and block-avg `¯s`) -> Budget Allocator (computes per-block `K` from `α`, `¯s`, `n_text`) -> Token Selector (TopK on `s_v` to get `V_sub`) -> Calibration Pool Aggregator (forms `S_cal = T ∪ V_sub` across samples) -> back to Base Pruner (computes `||X_j||2` only for `j ∈ S_cal` and prunes).
*   **Critical path:** Load model & calibration data. For each Transformer block: (a) Forward pass on calibration batch to collect input/output features for visual tokens, compute `s_v` and `¯s`. (b) For each sample, identify `T` and `V`, compute `K`, select `V_sub`, form `S_cal`. (c) Aggregate `S_cal` across all samples. (d) Compute activation norms *only* for columns in `S_cal`. (e) Calculate importance scores `I_ij` and prune weights. Repeat for all blocks.
*   **Design tradeoffs:**
    *   *Text token retention:* All vs. selective. Evidence (Fig. 5) strongly favors retaining all.
    *   *Visual saliency signal:* Drift (representation change) vs. Attention (cross-attention scores) vs. Diversity. Paper finds drift most stable (Tab. 3).
    *   *Adaptivity:* Fixed per-block visual token budget vs. `K ∝ ¯s`. Adaptivity improves performance (Tab. 3).
    *   *Scaling factor α:* Controls total visual token inclusion. Moderate `α` (0.5-2) best; too high dilutes text signal (Fig. 4).
*   **Failure signatures:**
    *   Performance collapses on text-heavy/reasoning benchmarks if text tokens are excluded from calibration (Fig. 5).
    *   Performance approaches modality-agnostic baseline if `α` is too large, indicating text signal dilution (Fig. 4).
    *   Degradation if `TopK` selection is replaced by random selection for visual tokens (Tab. 3, "Random").
*   **First 3 experiments:**
    1.  Replicate the motivation experiment (Table 1). Implement the MoT probe to independently prune textual/visual pathways with text-only, image-only, and mixed calibration. Verify Finding A (text pathway sensitive) & B (visual pathway redundant).
    2.  Validate the block-adaptive budget (Table 3). Compare ATV-Pruning with (a) adaptive drift, (b) non-adaptive drift (fixed `K`), and (c) random selection. Confirm adaptive drift yields highest average retention.
    3.  Ablate text token inclusion (Figure 5). Systematically vary the ratio of text tokens retained in `S_cal` (0% to 100%). Observe monotonic performance degradation, validating the necessity of all text tokens.

## Open Questions the Paper Calls Out
*   **Open Question 1:** What underlying architectural or training factors cause the textual pathway in LVLMs to exhibit higher pruning sensitivity than the visual pathway?
    *   *Basis:* [inferred] The paper shows the asymmetry via MoT probe but does not investigate root causes (e.g., gradient flow, loss landscape).
    *   *Why unresolved:* Without identifying the cause, it is unclear if the asymmetry is universal or setup-dependent, limiting theoretical generalization.
    *   *What evidence would resolve it:* Controlled ablations (e.g., frozen vision encoder), analysis of activation/gradient distributions per modality, comparative studies across training objectives.
*   **Open Question 2:** Can the global scaling factor α in ATV-Pruning be determined automatically rather than through per-model tuning?
    *   *Basis:* [explicit] The method requires manual α selection (e.g., 1.0 for LLaVA-NeXT), with no automatic mechanism.
    *   *Why unresolved:* Empirical tuning hinders plug-and-play usability; a data-driven or architecture-based rule is needed.
    *   *What evidence would resolve it:* Correlate optimal α with model characteristics (layers, hidden size, avg visual drift) or derive it from calibration stats to meet a target.
*   **Open Question 3:** Is the representation drift metric the most effective saliency signal for selecting visual tokens during pruning?
    *   *Basis:* [explicit] Drift outperformed ABS and DBS in tests, but without explanation of why.
    *   *Why unresolved:* The empirical advantage may not generalize; understanding the theory could lead to better metrics.
    *   *What evidence would resolve it:* Evaluate a broader set of metrics (gradient-based, predictive confidence) across multiple LVLM families; statistically link metric values to pruning impact.
*   **Open Question 4:** Are all text tokens equally necessary for calibration, or can a selective subset maintain performance?
    *   *Basis:* [inferred] The paper retains all text tokens, supported by Fig. 5's random removal ablation. Token informativeness was not considered.
    *   *Why unresolved:* If many text tokens are redundant, calibration could be more efficient. Necessity of all tokens remains open.
    *   *What evidence would resolve it:* Apply text token selection strategies (attention entropy, token type) and evaluate pruning accuracy with subsets; measure contribution of individual text tokens to importance scores.

## Limitations
*   **Architectural Generalizability:** Findings are validated only on late-fusion LVLMs (LLaVA-NeXT, Qwen2-VL). Asymmetry may not hold for models with earlier/denser fusion (e.g., BLIP-2, Kosmos-2).
*   **Calibration Data Distribution:** The "text-anchored" principle's effectiveness likely depends on calibration data distribution. Results may not transfer to domains with extreme modality biases (e.g., pure OCR) without re-tuning `α`.
*   **Drift Metric Specificity:** The cosine drift metric's correlation with true weight importance is assumed, not proven. It may not universally capture saliency across all architectures or tasks.
*   **Efficiency Claims:** The reported 1.35× slowdown versus Wanda includes drift computation overhead. Its scaling with model size, batch size, or long contexts is not deeply analyzed.

## Confidence
*   **Asymmetry Exists (Finding A & B):** **High**. Strong, consistent evidence via MoT probe across models/sparsity levels.
*   **All Text Tokens Needed (Principle 1):** **High**. Clear, monotonic degradation in Fig. 5 when removing text tokens.
*   **Layer-Adaptive Visual Token Budget via Drift (Principle 2):** **Medium**. Validated against baselines, but drift's universality and optimality vs. other metrics are partially unexplored.
*   **State-of-the-Art Performance:** **High** (for tested models/benchmarks). Results are clear and reproducible.
*   **General Efficiency Benefit:** **Medium**. Speedup over prior LVLM pruners shown, but absolute latency and scalability not extensively benchmarked.

## Next Checks
1.  **Test on a Differently Fused Architecture:** Replicate the motivation experiment and full ATV-Pruning on a model with **early or dense cross-modal fusion** (e.g., BLIP-2 style Q-Former, Kosmos-2). This tests if asymmetry is architecture-dependent.
2.  **Ablate Calibration Data Distribution:** Run ATV-Pruning using **calibration datasets with extreme modality biases** (100% text-heavy instructions vs. 100% image-captions). Measure shift in optimal `α` and final performance to test robustness of the "text-anchored" principle.
3.  **Direct Probe of Pathway Separability:** Validate the MoT probe's core assumption. Implement a **strict ablation where weights are zeroed/replaced independently per pathway** and measure output change, versus random weight zeroing. This confirms the probe identifies meaningful subnetworks.
