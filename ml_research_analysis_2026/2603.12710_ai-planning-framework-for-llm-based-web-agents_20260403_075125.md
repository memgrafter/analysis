# AI Planning Framework for LLM-Based Web Agents
## Quick Facts
- arXiv ID: 2603.12710
- Source URL: https://arxiv.org/abs/2603.12710
- Reference count: 40
- Primary result: Introduces a planning taxonomy for LLM-based web agents, showing Step-by-Step agents align better with human trajectories while Full-Plan-in-Advance agents achieve higher element accuracy.

## Executive Summary
This paper tackles the lack of transparency in LLM-based web agents by framing web interaction as a sequential decision problem. It proposes a taxonomy that categorizes agent architectures according to classical planning paradigms: Step-by-Step (BFS-like), Tree Search (Best-First), and Full-Plan-in-Advance (DFS-like). To assess planning behavior, the authors define five new trajectory-level metrics and compile a dataset of 794 human-annotated WebArena trajectories. Experiments contrasting a Step-by-Step baseline with a novel Full-Plan-in-Advance implementation uncover a trade-off: Step-by-Step better matches human decision patterns (82% step success, 36% recovery), whereas Full-Plan-in-Advance yields superior technical precision (89% element accuracy). The findings emphasize that metric selection must align with application-specific constraints when choosing an architecture.

## Method Summary
The study frames web interaction as a sequential decision problem. It introduces a taxonomy that maps LLM-based web agent architectures to three classical planning paradigms: Step-by-Step (resembling breadth-first search), Tree Search (resembling best-first search), and Full-Plan-in-Advance (resembling depth-first search). To evaluate these agents, the authors define five novel trajectory-level metrics: Step Success Rate, Element Accuracy, Repetitiveness Rate, Recovery Rate, and Partial Success Rate. They compile a dataset of 794 human-annotated trajectories from the WebArena environment. The experimental evaluation focuses on comparing a Step-by-Step baseline with a novel Full-Plan-in-Advance implementation, measuring their performance on the defined metrics.

## Key Results
- The taxonomy maps modern LLM web agent designs to three classical planning paradigms.
- Five novel trajectory-level metrics are introduced: Step Success Rate, Element Accuracy, Repetitiveness Rate, Recovery Rate, Partial Success Rate.
- Step-by-Step agents demonstrate higher human alignment (82% step success, 36% recovery), while Full-Plan-in-Advance agents achieve higher element accuracy (89%).

## Why This Works (Mechanism)
The observed trade-off between human alignment and element accuracy is hypothesized to stem from the planning paradigms. Step-by-Step agents (BFS-like) make incremental decisions based on the current state, allowing dynamic adaptation and error recovery, which aligns with human decision patterns. Full-Plan-in-Advance agents (DFS-like) commit to a complete plan upfront, reducing exploration and backtracking, which may improve precision in element selection but sacrifices flexibility. The paper does not provide a detailed mechanistic analysis; this explanation is inferred from the classical analogies and empirical results.

## Foundational Learning
The work builds on classical planning algorithms (BFS, DFS, best-first search) and adapts them to LLM-based web agents. It assumes that pre-trained LLMs can function as effective planners without additional training, relying on their inherent reasoning capabilities. The evaluation uses the WebArena benchmark, a simulated web environment designed for agent evaluation. The study contributes a taxonomy and metrics but does not introduce new learning methods; instead, it explores architectural choices for planning.

## Architecture Onboarding
The paper details two main architectures:
- **Step-by-Step**: At each timestep, the agent uses the LLM to decide the next action based on the current observation, akin to BFS exploration.
- **Full-Plan-in-Advance**: The agent first uses the LLM to generate a complete plan (sequence of actions) from the initial state, then executes it sequentially, akin to DFS.

The critical path for Step-by-Step involves iterative perception-planning cycles; for Full-Plan-in-Advance, it involves a single planning phase followed by execution. Design tradeoffs: Step-by-Step achieved 82% step success and 36% recovery in experiments, indicating better human alignment and error recovery, while Full-Plan-in-Advance achieved 89% element accuracy, indicating higher precision. Failure signatures: Step-by-Step may suffer from inefficiency or repetitiveness (though repetitiveness rates were not reported); Full-Plan-in-Advance is brittle to initial planning errors due to lack of recovery mechanisms. The paper does not elaborate on extensive initial experiments beyond the main comparison.

## Limitations
- The taxonomy mapping lacks empirical validation across diverse agent architectures and tasks.
- The newly introduced trajectory metrics have unknown reliability and correlation with user satisfaction.
- The human-labeled WebArena dataset may have limited inter-annotator agreement and generalizability.
