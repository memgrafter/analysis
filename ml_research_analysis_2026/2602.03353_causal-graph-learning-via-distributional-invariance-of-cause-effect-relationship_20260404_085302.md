# Causal Graph Learning via Distributional Invariance of Cause-Effect Relationship

## Quick Facts
- **arXiv ID:** 2602.03353  
- **Source URL:** https://arxiv.org/abs/2602.03353  
- **Reference count:** 40  
- **Primary result:** Matches or outperforms state-of-the-art causal discovery methods in accuracy (SHD) while achieving up to 25× reduction in runtime and up to 73.3% lower spurious edge rate.

## Executive Summary
Recovering causal Directed Acyclic Graphs (DAGs) from purely observational data is a fundamental yet computationally intensive task, often relying on heuristic assumptions that limit scalability and reliability. This paper introduces GLIDE, an invariance‑based framework that exploits a core causal principle: the conditional distribution of an effect given its causes remains invariant when the prior distribution over source (basis) variables changes. GLIDE creates multiple augmented datasets by downsampling the original data to induce different source priors while preserving conditional distributions of non‑source variables. It then tests candidate parent sets for stability of the conditional $P(\text{effect}\mid\text{causes})$ across these datasets. To keep the search feasible, parent candidates are restricted to cliques in an augmented bidirectional graph derived from Markov blankets, leveraging empirical sparsity to achieve quadratic‑time complexity. Extensive experiments on synthetic and real‑world benchmarks show that GLIDE achieves state‑of‑the‑art structural accuracy (SHD) with up to 25× faster runtime and up to 73.3% fewer spurious edges compared to existing methods.

## Method Summary
GLIDE proceeds in several stages. First, it identifies a maximum‑sized basis set $\mathbf{B}$ of mutually independent source variables via a greedy procedure that uses pairwise independence tests. Using $\mathbf{B}$, it samples $m$ diverse source priors $P^i(\mathbf{B})$ within a convex region defined by a minimum downsampling ratio $\gamma_o$ (default 0.5). For each prior, the original dataset $\mathcal{D}$ is downsampled exactly as prescribed by Theorems 4 and 5, producing augmented datasets $\mathcal{D}_i$ that share the same conditional $P(\mathbf{X}\setminus\mathbf{B}\mid\mathbf{B})$ but have different $P(\mathbf{B})$.  

For each target variable $X$, GLIDE recovers its Markov blanket $\mathcal{M}(X)$ using an $O(d^2)$ algorithm (Edera et al., 2014). From this, it builds a bidirectional graph on $\mathcal{M}^*(X)=\mathcal{M}(X)\setminus\mathrm{Sp}[X]$, where edges indicate mutual Markov blanket membership. Under empirical sparsity, the number of maximal cliques in this graph is near‑linear in $d$; these cliques enumerate all plausible parent sets for $X$.  

For each candidate parent set $Z_j$, GLIDE estimates the conditional distribution $P_i(X\mid Z_j)$ in every augmented dataset $\mathcal{D}_i$ and computes the sample variance across $i$. The true parent set exhibits near‑zero variance; if multiple sets satisfy the threshold $\epsilon\approx10^{-3}$, the one with smallest variance is chosen. Finally, the selected parent sets are assembled into a DAG.

The overall complexity is $O(m d^2 + m|\mathcal{D}|)$, which is quadratic in the number of variables and linear in the number of augmentations and data size. This, combined with the empirical sparsity of real‑world graphs, yields substantial speedups over traditional constraint‑based or score‑based methods.

## Key Results
- **Accuracy:** GLIDE matches or exceeds state‑of‑the‑art methods (e.g., PC, FCI, NOTEARS) in Structural Hamming Distance (SHD) on both synthetic and real‑world benchmarks.  
- **Scalability:** It achieves up to **25×** reduction in runtime compared to PC/FCI, scaling quadratically with the number of variables.  
- **Reliability:** The spurious edge rate is reduced by up to **73.3%** relative to competing approaches, demonstrating higher precision in edge recovery.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** GLIDE identifies true parent‑child relationships by testing the invariance of the effect‑cause conditional distribution $P(X\mid \mathrm{Pa}[X])$ across datasets with different source priors.  
- **Mechanism:** For a candidate parent set $Z$, GLIDE constructs several augmented datasets $\{\mathcal{D}_i\}$ via downsampling that alter $P(\mathbf{B})$ while preserving $P(\mathbf{X}\setminus\mathbf{B}\mid\mathbf{B})$. The variance of the estimated $P_i(X\mid Z)$ over $\{\mathcal{D}_i\}$ is computed; a near‑zero variance indicates that $Z$ is the true parent set (Theorem 1, Section 4.2). This leverages Observation 1: causal conditionals are invariant to interventions on upstream sources.  
- **Core assumption:** The conditional $P(X\mid \mathrm{Pa}[X])$ is stable under interventions on ancestors/sources (causal invariance). The downsampling procedure correctly generates $\mathcal{D}_i\sim P_i(\mathbf{X})$ (Theorem 5).  
- **Evidence anchors:**  
  - Abstract: “exploits that the conditional distribution of an effect given its causes remains invariant under changes to the prior over source variables.”  
  - Section 4.2: Formalism of the downsampling scheme and invariance test (Equation 2).  
  - Corpus: Related work on invariance‑based causal discovery (e.g., IRM for graphs) supports the principle; GLIDE’s specific downsampling test is novel.  
- **Break condition:** The invariance test fails if the estimated variance exceeds threshold $\epsilon\sim10^{-3}$ for all candidates, implying either no true parent set is present or the augmentations did not adequately vary source priors.

### Mechanism 2
- **Claim:** GLIDE reduces parent set candidates from exponential to $O(d)$ by restricting the search to cliques in an augmented bidirectional graph derived from Markov blankets.  
- **Mechanism:** It uses the Local Markov Condition: $\mathrm{Pa}[X]\subseteq\mathcal{M}^*(X)=\mathrm{MarkovBlanket}(X)\setminus\mathrm{Sp}[X]$ (Theorem 7). The algorithm first finds all Markov blankets using a prior $O(d^2)$ method (Edera et al., 2014). Then it constructs a bidirectional graph on $\mathcal{M}^*(X)$ where edges indicate mutual Markov blanket membership. Maximal cliques in this (empirically sparse) graph correspond to plausible parent sets. A modified Bron‑Kerbosch DFS enumerates these cliques in time $O(p d\cdot 3^{p/3})$ where $p$ is graph degeneracy (typically a small constant).  
- **Core assumption:** Causal sufficiency (no unmeasured confounders) so Markov blankets are identifiable from observational data. Empirical sparsity: the augmented graph is $p$‑degenerate with small $p$ (Definition 4, Section 4.3).  
- **Evidence anchors:**  
  - Section 3: Definitions of Markov blanket and local Markov condition.  
  - Section 4.3: Theorem 7 states $\mathrm{Pa}[X]$ belongs to a clique in $G'(X)$; Theorem 3 provides basis for source identification.  
  - Corpus: Markov blanket discovery is standard; sparsity assumption is empirically validated (Appendix C.4.3 shows $p\le13$ even for large graphs).  
- **Break condition:** If the augmented bidirectional graph is not sparse (large $p$), clique enumeration becomes expensive. If Markov blanket recovery fails (due to small sample size or violations of causal sufficiency), candidate parent sets may exclude the true parents.

### Mechanism 3
- **Claim:** GLIDE generates valid augmented datasets by downsampling the original data with rates derived from target source priors, ensuring $\mathcal{D}_i\sim P_i(\mathbf{X})$ while preserving $P(\mathbf{X}\setminus\mathbf{B}\mid\mathbf{B})$.  
- **Mechanism:** Given a target prior $P_i(\mathbf{B})$ and original dataset $\mathcal{D}\sim P(\mathbf{X})$, Theorem 4 gives the minimum downsampling rate $|\mathcal{D}|/|\mathcal{D}_i|=\gamma_i^{-1}$ where $\gamma_i=\min_b P(\mathbf{B}=b)/P_i(\mathbf{B}=b)$. Theorem 5 specifies achieving this rate by sampling $P_i(\mathbf{B}=b)\cdot|\mathcal{D}|\cdot\gamma_i$ points without replacement from the subset of $\mathcal{D}$ with $\mathbf{B}=b$. This respects the factorization $P(\mathbf{X})=P(\mathbf{B})\cdot P(\mathbf{X}\setminus\mathbf{B}\mid\mathbf{B})$.  
- **Core assumption:** The source/basis variables $\mathbf{B}$ are correctly identified (Algorithm 2). The downsampling operation does not introduce selection bias that alters $P(\mathbf{X}\setminus\mathbf{B}\mid\mathbf{B})$. For continuous data, discretization for $\mathbf{B}$ is sufficiently granular.  
- **Evidence anchors:**  
  - Section 4.2.2: Theorems 4 and 5 define the optimal downsampling rate and procedure.  
  - Section 4.2.3: Theorem 6 describes the convex set of valid $P_i(\mathbf{B})$ with $\gamma_i\ge\gamma_o$ and how to sample them.  
  - Corpus: The idea of simulating interventions via resampling appears in invariant causal prediction; GLIDE’s precise link between downsampling rate and prior ratio is novel.  
- **Break condition:** If $\mathbf{B}$ is not a valid basis/surrogate for sources, changing $P(\mathbf{B})$ may not properly simulate interventions. If $\gamma_i$ is too low, $|\mathcal{D}_i|$ becomes too small, increasing estimation variance for $P_i(X\mid Z)$. If $\gamma_i$ is too high (near 1), $\mathcal{D}_i\approx\mathcal{D}$ and fails to test invariance.

## Foundational Learning
- **Concept: Causal Markov Condition & d‑separation**  
  *Why needed here:* GLIDE assumes the causal graph is a Bayesian Network where each node is independent of its non‑descendants given its parents. This justifies the factorization $P(\mathbf{X})=\prod_i P(X_i\mid\mathrm{Pa}[X_i])$ and underlies Theorem 1’s invariance statement. d‑separation is used to define Markov blankets and basis sets.  
  *Quick check:* In a DAG where $A\rightarrow B\rightarrow C$, what is $\mathrm{Pa}[C]$ and what set $Z$ makes $C\perp A\mid Z$ according to d‑separation?

- **Concept: Markov Blanket**  
  *Why needed here:* GLIDE restricts candidate parent sets $Z$ to subsets of $\mathcal{M}^*(X)=\mathcal{M}(X)\setminus\mathrm{Sp}[X]$ (Theorem 7). Identifying Markov blankets for all nodes ($O(d^2)$ complexity) is the first step to limiting the search space from exponential to quadratic.  
  *Quick check:* Given a node $X$, what three types of nodes constitute its Markov blanket $\mathcal{M}(X)$ in a causal DAG?

- **Concept: Empirical Sparsity / Graph Degeneracy**  
  *Why needed here:* The quadratic‑time guarantee for finding plausible parent sets (via maximal cliques) relies on the augmented bidirectional graph being $p$‑degenerate with small constant $p$. This is an empirical observation about benchmark causal graphs (Section 4.3, Appendix C.4.3).  
  *Quick check:* What does $p$‑degenerate mean for a graph, and why does a small $p$ make maximal clique enumeration efficient?

## Architecture Onboarding
- **Component map:** Basis Finder -> Prior Sampler -> Dataset Augmenter -> Markov Blanket Finder -> Plausible Parent Enumerator -> Invariance Tester -> Graph Builder  
- **Critical path:** Basis identification ($O(d^2)$) → Prior sampling (complexity reduced to $O(m c |B|)$ via K‑means) → Dataset augmentation ($O(m|\mathcal{D}|)$) → Markov blanket recovery ($O(d^2)$) → Plausible parent enumeration (per‑variable cost $\sim O(d)$ due to sparsity) → Invariance test per variable ($O(m \cdot |\text{candidate\_sets}|)$). Overall complexity: $O(m d^2 + m|\mathcal{D}|)$.  
- **Design tradeoffs:**  
  - $m$ (number of augmentations): Higher $m$ improves test reliability but linearly increases runtime; default set as high as budget allows.  
  - $\gamma_o$ (minimum downsampling rate): Higher $\gamma_o$ preserves more data per $\mathcal{D}_i$ (better estimation) but reduces prior diversity; recommended $\gamma_o=0.5$.  
  - Basis size $|\mathbf{B}|$: Affects prior sampling complexity; Algorithm 2 aims for max‑size basis (equal to number of sources); non‑uniqueness is empirically stable.  
  - Discretization bins for continuous $\mathbf{B}$: More bins increase cost; fixed at 4 in implementation.  
- **Failure signatures:**  
  - High spurious edge rate: Invariance threshold $\epsilon$ too loose, or Markov blanket recovery missed true parents (too many candidates). Check $\mathcal{M}(X)$ completeness.  
  - Low recall (missing true edges): Invariance test too strict ($\epsilon$ too small), or $\gamma_i$ too aggressive. Increase $m$ or $\gamma_o$.  
  - Runtime blowup: Degeneracy $p$ large (graph dense) → maximal clique enumeration expensive. Check $p$ on $G'(X)$. If $|\mathbf{B}|$ large, prior sampling may explode; use per‑variable resampling.  
  - Failure to find any parent set: All candidates fail invariance test. Possible causes: wrong basis $\mathbf{B}$, insufficient $m$, or data not following causal model (e.g., cyclic, selection bias).  
- **First 3 experiments:**  
  1. **Invariance Test Sanity Check:** On a known 5‑node DAG with linear Gaussian mechanism, generate $\mathcal{D}$. Run GLIDE with $m=20$, $\gamma_o=0.5$. Verify that for a node $X$ with true parent $Z_0$, $\mathrm{Var}[P_i(X\mid Z_0)]\approx0$ while $\mathrm{Var}[P_i(X\mid Z_\text{other})]\gg0$. Confirm $\epsilon=10^{-3}$ is sensible.  
  2. **Markov Blanket Recovery Validation:** Using the same DAG, run only the GSMB step. Check if $\mathcal{M}(X)$ contains $\mathrm{Pa}[X]$, $\mathrm{Ch}[X]$, and $\mathrm{Sp}[X]$. Measure recall/precision of $\mathcal{M}^*(X)$ containing $\mathrm{Pa}[X]$.  
  3. **Scalability Stress Test:** Generate Erdős‑Rényi DAG with $d=500$, $E=500$. Measure total runtime vs $m$ (e.g., $m=\{10,50,100\}$). Confirm near‑quadratic scaling with $d$ and linear with $m$ and $|\mathcal{D}|$. Compare against PC/FCI runtime explosion.

## Open Questions the Paper Calls Out
1. **Handling latent confounders:** How can GLIDE be extended to handle latent confounders, relaxing the causal sufficiency assumption? The paper assumes no unobserved confounders, an implicit limitation not discussed. Without such an extension, GLIDE may produce spurious edges when latent variables exist. Evidence to resolve this would involve integrating FCI‑style conditional independence tests into the framework or empirically validating on datasets with known latent structures.  
2. **Sparsity guarantees for parent search:** Under what structural conditions does the augmented bidirectional graph remain $p$‑degenerate, guaranteeing the quadratic‑time parent search? The paper observes low $p$ empirically but offers no theoretical analysis. Without guarantees, the runtime advantage might vanish for graphs that do not exhibit the observed low degeneracy. A proof linking graph properties (e.g., edge density, degree distribution) to $p$ would be needed.  
3. **Sensitivity of disjointness assumptions:** The invariance test relies on assumptions $\mathrm{Pa}[X]\cap\mathrm{Sp}[X]=\emptyset$ and $\mathrm{Sp}[X]\cap\mathbf{B}=\emptyset$ (Theorem 1). The paper notes these hold “with relatively high probability” (e.g., $>$75% on real graphs) but not universally. When violated, the test may fail to uniquely identify the true parent set, reducing accuracy. A systematic analysis of violation frequency and impact, plus relaxed invariance criteria, would address this.  
4. **Hyperparameter and discretization effects:** How do the choices of $m$, $\gamma$, and the number of discretization bins for continuous data affect the reliability of the invariance test? The paper offers practical defaults ($m$ as high as runtime permits, $\gamma=0.5$, 4 bins) but no theoretical guidance. Poor choices may lead to inaccurate variance estimates or discretization artifacts. Finite‑sample bounds on conditional estimation error and investigation of continuous alternatives (e.g., kernel methods) are needed.  
5. **Improving basis identification:** The greedy basis‑finding procedure (Algorithm 2) is not guaranteed to recover all true source variables, especially in dense graphs or with limited data. Errors in the basis propagate to the invariance test, potentially degrading overall accuracy. A provably correct or higher‑accuracy basis identification algorithm under weaker assumptions would enhance GLIDE’s robustness.

## Limitations
- **Missing implementation details:** The paper does not provide full specifications for GSMB Markov blanket recovery, the conditional density estimator, nor the modified Bron‑Kerbosch algorithm, hindering exact replication.  
- **Discretization bias:** Fixed 4‑bin discretization for continuous source variables may bias source prior manipulations and affect the invariance test’s stability.  
- **Strong assumptions:** Causal sufficiency, accurate basis discovery, and empirical sparsity (small graph degeneracy $p$) are required; violations could compromise correctness or the claimed quadratic‑time guarantee.
