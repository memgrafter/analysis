# FreeAct: Freeing Activations for LLM Quantization

## Quick Facts
- **arXiv ID:** 2603.01776
- **Source URL:** https://arxiv.org/abs/2603.01776
- **Reference count:** 40
- **Primary result:** FreeAct enables token-type-specific activation quantization while sharing weight transforms, achieving SOTA W4A4 performance (up to 5.3% relative improvement) on diffusion and multimodal LLMs.

## Executive Summary
LLM quantization traditionally enforces a static one-to-one relationship between activation and weight transformations, which fails under dynamic activation disparities in diffusion LLMs (dLLMs) and multimodal LLMs (MLLMs). FreeAct resolves this by decoupling the transformations, allowing distinct activation transforms for different token types (e.g., masked vs. unmasked, vision vs. text) while maintaining a shared weight transform. The method exploits the rank-deficient nature of activations to construct a solution space beyond simple matrix inverses, using subspace decomposition with zero padding to prevent interference. Optimized during calibration by minimizing token-specific quantization error, FreeAct matches or exceeds 8-bit and even 16-bit accuracy across multiple architectures.

## Method Summary
FreeAct constructs transformation matrices from a shared orthogonal basis `U` and distinct, zero-padded components `UX`, `UX'` for different token types, ensuring disjoint subspaces. The weight transform `eP` unifies these via concatenation. During calibration, it minimizes the mean squared error between full-precision and quantized outputs separately for each token type, learning clipping thresholds and the transformation parameters. At inference, token-type indices slice the appropriate sub-matrix from `eP` on-the-fly for each activation, requiring minimal code modification. This design separates the concerns of handling diverse activation distributions (via type-specific activation transforms) from preserving weight compatibility (via a common weight transform).

## Key Results
- Achieves SOTA W4A4 quantization on LLaDA, Dream, Qwen2.5-VL, and InternVL2.5.
- Improves accuracy by up to 5.3% relative to prior methods (e.g., QuaRot, FlatQuant).
- Often matches the performance of W8A8 and even 16-bit full-precision models.

## Why This Works (Mechanism)
**Rank-deficiency enables decoupling:** When activation matrices are rank-deficient (typical in LLMs), the constraint `XP·eP·W⊺ = XW⊺` admits non-unique solutions beyond the trivial `P·eP = I`. This allows distinct activation transforms `P`, `P'` for different token types while sharing a single weight transform `eP`. The paper theorizes this solution space exists for diffusion and multimodal activations, though empirical rank verification for these domains is not provided. If activations become full-rank, the flexibility collapses.

**Subspace decomposition with zero-padding:** FreeAct builds `eP = [U, UX, UX']⊺`, where `U` is shared across token types and `UX`, `UX'` are distinct, zero-padded to ensure orthogonality. This projects different token-type activations into disjoint subspaces (`XUX' ≈ 0`, `X'UX ≈ 0`), preventing interference. Theoretical guarantees rely on these orthogonality conditions, which are approximated in practice. Overlapping subspaces increase quantization error; thus, performance is sensitive to the rank parameters `r1`, `r2` governing subspace sizes.

**Token-specific error minimization:** Calibration optimizes `eP` and clipping thresholds by minimizing the MSE between original and quantized outputs *separately* for each token type. This tailors the activation transforms to disparate distributions while keeping the weight transform consistent. Successful optimization requires calibration data that adequately represents all token types; deficient calibration data degrades generalization.

## Foundational Learning
- **Post-training quantization (PTQ):** Quantizes pre-trained models without gradient-based retraining, using calibration data to determine scaling factors and clipping thresholds. *Why needed:* FreeAct is a PTQ method; understanding error sources and activation clipping is key to appreciating its improvements over static transforms. *Quick check:* Why does directly quantizing LLM activations to 4-bit fail catastrophically, while quantization-aware training (QAT) might succeed?
- **Transformation-based quantization:** Applies a linear transformation (e.g., rotation) to activations/weights before quantization to reduce outliers and improve range. *Why needed:* FreeAct extends this paradigm; the one-to-one constraint `YP = XP·P⁻¹W⊺` ensures computational equivalence but limits handling dynamic activations. *Quick check:* How does a one-to-one transformation maintain numerical equivalence, and why does it prevent token-specific adaptations?
- **Rank-deficient matrices and subspace decomposition:** A matrix `X` with `rank(X) < d` lies in a lower-dimensional subspace, enabling multiple solutions to `X·M = X·N`. *Why needed:* FreeAct's theory hinges on non-unique solutions to the transformation constraint when activations are rank-deficient. *Quick check:* If `X` is rank-deficient, why does `X(P·eP - I)W⊺ = 0` have infinitely many solutions beyond `P·eP = I`?

## Architecture Onboarding
**Component map:**
Token Indexer -> Subspace Constructor -> Quantization Engine -> Error Optimizer -> Inference Module

**Critical path:**
- *Training:* Input sequence -> Token Indexer groups activations by type -> Subspace Constructor builds `P`, `P'` from `eP` -> Quantization Engine transforms and quantizes -> Error Optimizer computes type-specific MSE -> Backpropagation updates `eP` and thresholds.
- *Inference:* For each token, Token Indexer determines type -> slice relevant sub-matrix from `eP` -> Quantization Engine applies transform and quantizes -> compute with quantized weights.

**Design tradeoffs:**
- Flexibility vs. memory: Larger distinct subspaces (`r1`, `r2`) handle more token-type diversity but shrink the shared subspace `U`, potentially reducing generalization. Default `r1 = r2 = d/32` balances this.
- All layers vs. selective: Applying FreeAct to every layer can degrade performance on some models; selective layer application is preferred.
- Theory vs. practice: Theorem 2 requires exact orthogonality (`XUX' = 0`), but practical optimization via error minimization allows relaxed conditions; enforcing hard constraints may hinder learning.

**Failure signatures:**
- High layer-wise performance variance: Indicates token-type activation subspaces overlap significantly, causing interference despite zero padding.
- Calibration data mismatch: Missing or under-represented token types (e.g., no masked tokens in dLLM calibration) leads to suboptimal transforms and large train-test gaps.
- Numerical instability: Without orthogonal initialization or gradient clipping, optimization of `eP` may collapse to degenerate solutions.

**First 3 experiments:**
1. **Rank-sensitivity test:** Vary `r1 = r2` from `d/2` to `d/64` and measure accuracy. Expect peak performance at intermediate values (e.g., `d/32`), confirming that both full-rank (inflexible) and very low-rank (too restrictive) are suboptimal.
2. **Token-type separation validation:** Visualize pre- and post-transformation activation distributions (range, outliers) per token type. Expect reduced outliers and maintained separation, similar to Figures 7, 11–14.
3. **Component ablation:** Remove zero-padding (allow `UX`, `UX'` overlap) or remove shared component `U`. Expect both degrade performance, validating the subspace design's necessity.

## Limitations
- Rank-deficiency of activations in dLLMs/MLLMs is assumed based on general LLM properties but not empirically verified for these models.
- Orthogonality of token-type subspaces is theoretically required but only approximated in practice; overlapping activations may cause interference.
- Calibration data must represent all token types; the paper does not analyze sensitivity to incomplete or skewed token-type distributions.
- Subspace rank hyperparameters (`r1`, `r2`) are chosen via grid search without theoretical guidelines; optimal values likely vary by model and layer.
- Optimization stability under orthogonal constraints is not thoroughly examined; no explicit regularization (e.g., weight decay) is reported.

## Confidence
- **Rank-deficiency enabling decoupling:** Medium (theory relies on an unverified assumption for target domains).
- **Subspace decomposition with zero-padding:** Medium (orthogonality condition is approximated and not guaranteed in real activations).
- **Token-specific error minimization during calibration:** High (empirically validated by decreasing MSE in calibration).
- **Overall SOTA performance:** High (consistent gains across four diverse models).

## Next Checks
1. **Activation rank measurement:** Compute empirical ranks of activation matrices across layers and token types for dLLMs/MLLMs; verify ranks are significantly below dimensionality.
2. **Subspace overlap quantification:** For each layer, compute cosine similarity between mean activations of different token types before/after transformation; correlate with quantization error to test orthogonality assumption.
3. **Calibration data ablation:** Systematically vary the proportion of masked/unmasked and vision/text tokens in the calibration set and measure performance drop to establish representativeness requirements.
