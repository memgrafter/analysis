# Visual Memory Injection Attacks for Multi-Turn Conversations

## Quick Facts
- **arXiv ID**: 2602.15927
- **Source URL**: https://arxiv.org/abs/2602.15927
- **Reference count**: 40
- **Primary result**: VMI achieves combined success rates (SR∧) up to ~100% on anchor+trigger prompts and ~80-100% on held-out context prompt sets, persisting across over 27 turns.

## Executive Summary
The paper uncovers a critical vulnerability in large vision-language models (LVLMs) used for multi-turn conversations: an adversary can embed a persistent, stealthy influence via a single perturbed image. They introduce Visual Memory Injection (VMI), which combines benign anchoring (ensuring normal responses on non-trigger prompts) and context-cycling (optimizing across varying conversation lengths) to craft adversarial images. These images cause the LVLM to emit a specific target message only when a designated trigger topic appears, even after many unrelated turns, thereby avoiding user suspicion.

Extensive evaluation on Qwen2.5-VL, Qwen3-VL, and LLaVA-OneVision shows VMI attaining near-perfect combined success (SR∧) on anchor+trigger prompts and 80–100% on held-out diverse context sets, with effectiveness lasting beyond 27 turns. Ablations confirm that context-cycling is essential for maintaining success as context grows. The attack also transfers, with reduced rates, to fine-tuned model variants and paraphrased prompts, but fails on thematically coherent “Holiday” contexts.

## Method Summary
VMI formulates multi-turn attack as an optimization problem over an ℓ∞‑bounded perturbation δ added to a source image x. The loss has two terms: (1) a clean anchoring term that encourages the model to output a benign response (its original clean answer) on the anchor prompt, and (2) a trigger activation term that maximizes the probability of the attacker‑chosen target when the full context (including many intervening prompts) ends with the trigger prompt. Optimization uses APGD (2000 iterations) with ε = 8/255.

To make the perturbation robust to arbitrary context lengths, context‑cycling is employed: during optimization, the dialogue length before the trigger is randomly sampled from 2 to n (n=8) every τ = 5 steps. Pre‑computing the model’s clean outputs on the unperturbed image for all context prompts is required. After training, the adversarial image is evaluated by simulating the full conversation: feeding the image with the anchor prompt, then sequentially generating responses for each context prompt, and finally the trigger prompt. Success is measured via keyword matching: the target must appear only on the trigger turn (SR_target) and never leak earlier (SR_context); their conjunction is SR∧.

## Key Results
- VMI achieves SR∧ close to 100% on anchor+trigger prompts and 80–100% on held‑out diverse context sets for some models, with persistence beyond 27 turns.
- Removing context‑cycling causes attack success to degrade rapidly as context length increases, highlighting the importance of multi‑length optimization.
- Transfer to fine‑tuned variants and paraphrased prompts is possible, but success rates drop significantly in thematically coherent “Holiday” contexts, indicating sensitivity to semantic consistency.

## Why This Works (Mechanism)
VMI exploits the persistent memory state of LVLMs across dialogue turns. A carefully crafted perturbation biases the model’s internal representations so that when a specific trigger topic later enters the context, the model consistently generates the attacker’s target message. Benign anchoring guarantees that on all other turns the model’s output matches its clean behavior, preventing anomalies that might alert a user. Context‑cycling forces the perturbation to generalize across conversation lengths, enabling the attack to remain effective even after many intervening interactions.

## Foundational Learning
- **Large Vision‑Language Models (LVLMs)**: Multi‑modal architectures that combine visual and textual inputs. *Why needed*: VMI targets these models in multi‑turn settings. *Quick check*: Understand how models like Qwen‑VL or LLaVA process an image and a sequence of text prompts.
- **Adversarial Perturbations**: Minimal, often ℓ∞‑bounded changes to inputs that cause model misbehavior. *Why needed*: VMI uses them to embed the attack. *Quick check*: Implement a basic PGD attack on a classifier.
- **Multi‑turn Context Memory**: LVLMs maintain a rolling context that influences future outputs. *Why needed*: The attack relies on persistent memory to inject a long‑term effect. *Quick check*: Have a conversation with an LVLM and show that earlier messages affect later responses.
- **Stealth via Benign Anchoring**: Maintaining normal outputs on non‑trigger turns to avoid detection. *Why needed*: Ensures the attack remains invisible during the conversation. *Quick check*: Compare model responses on clean and adversarial images for prompts unrelated to the trigger.
- **Context‑Cycling**: Optimizing against a distribution of context lengths during attack generation. *Why needed*: Provides robustness to the number of intervening turns at test time. *Quick check*: Train a VMI perturbation with and without context‑cycling and test on longer dialogues than seen during optimization.

## Architecture Onboarding
**Component map:**  
Adversarial Perturbation Generator (APGD) → Perturbed Image (x+δ) → LVLM (multi‑turn memory) → Output

**Critical path:**
1. Load a clean image and run the LVLM on all context prompts to log clean responses.
2. Optimize δ with APGD using the combined loss and context‑cycling; each cycle samples a random context length and computes the loss on that dialogue.
3. Freeze δ and simulate the full conversation: present the adversarial image with the anchor prompt, then sequentially feed each context prompt and record the model’s response, finally the trigger prompt.
4. Evaluate success by checking that the target string appears only on the trigger turn (using keyword lists).

**Design tradeoffs:**
- ε (perturbation radius): Larger values may boost success but increase visual detectability.
- Context‑cycling parameters (n and τ): Higher n and longer τ improve generalisation but increase optimization time.
- APGD iterations: More iterations improve convergence but cost more compute.

**Failure signatures:**
- SR∧ drops sharply when conversation length exceeds the max used during optimization (n).
- Target message appears in early context turns (low SR_context).
- Perturbed image shows noticeable noise or artifacts.

**First experiments:**
1. Baseline replication: Run the clean LVLM on a sample image with a 5‑turn conversation to confirm expected behavior.
2. Attack reproduction: Apply VMI with default hyperparameters (ε=8/255, n=8, τ=5) on a single image; measure SR∧ on the anchor+trigger and a short context (≤5 turns).
3. Generalization validation: Take the resulting adversarial image and evaluate it with increasing context lengths up to 27 turns; plot SR∧ versus turns to verify persistence.

## Open Questions the Paper Calls Out
1. **Defense strategies**: What defense strategies can mitigate Visual Memory Injection attacks in multi‑turn LVLM conversations? The paper explicitly calls for “better robustness of LVLMs against these attacks” and safety evaluations that account for long‑context interactions.
2. **Black‑box feasibility**: Can VMI be executed without gradient access to the target LVLM? The limitations state that “developing attacks against models available only via API remains an open challenge.”
3. **Multiple images**: How do multiple images in a multi‑turn conversation affect VMI persistence and stealth? The study restricts to a single image per dialogue, whereas real interactions often include several.
4. **Real‑world distortions**: Are VMI attacks robust to typical image transformations (e.g., printing, compression) before LVLM input? The threat model assumes pristine digital images, but dissemination may introduce distortions that degrade the perturbation.

## Limitations
- Full prompt lists for the Diverse and Holiday contexts are missing, preventing exact replication of held‑out evaluations.
- The attack assumes white‑box gradient access; its effectiveness in black‑box settings (e.g., APIs) is unknown.
- Evaluation is limited to three open‑source LVLMs, and stealthiness is inferred from small perturbations without human validation, so generalizability and detectability remain uncertain.

## Confidence
- **Attack success (SR∧) on optimized lengths**: Medium confidence (strong reported numbers but missing full prompt lists limit reproducibility).
- **Persistence over long contexts (27+ turns)**: Medium confidence (ablation supports context‑cycling necessity, but generalization beyond n=8 is under‑validated).
- **Transferability to fine‑tuned/paraphrased inputs**: Low–Medium confidence (transfer shown on limited variants with degraded performance; robustness to free‑form paraphrasing uncertain).
- **Stealthiness (benign anchoring and perturbation invisibility)**: Low confidence (no human study; automated metrics may not capture subtle anomalies).
