# PEANUT: Perturbations by Eigenvector Alignment for Attacking Graph Neural Networks Under Topology-Driven Message Passing

## Quick Facts
- **ArXiv ID:** 2603.26136
- **Source URL:** https://arxiv.org/abs/2603.26136
- **Reference count:** 40
- **Primary result:** A black-box attack on GNNs via virtual node injection achieves over 52% accuracy drop on Cora with only 5% added nodes, even when those nodes have zero features.

## Executive Summary
PEANUT introduces a practical black-box evasion attack against Graph Neural Networks (GNNs) by injecting virtual nodes whose connectivity is crafted via eigenvector alignment of clean node embeddings. Without requiring model access or gradients, the attack maximizes the Frobenius norm difference between original and perturbed node representations under a strict budget. Experiments demonstrate severe performance degradation across node classification, graph classification, and graph regression tasks. Notably, on the Cora dataset with a GCN, it causes over a 52% accuracy drop and over 74% F1 drop at a mere 5% injection rate. The attack remains effective even with zero-feature injected nodes, underscoring a fundamental vulnerability in topology-driven message passing.

## Method Summary
PEANUT operates as a purely black-box attack. It first obtains node embeddings from the clean graph, potentially using a shadow model or pre-trained embeddings. It then computes the eigenvectors of these embeddings and strategically aligns the topology of virtual nodes to maximize the Frobenius norm difference between the original and perturbed node representations, subject to an injection budget. The virtual nodes are added to the graph, optionally with zero features to enhance stealth, and the perturbed graph is fed to the target GNN, causing significant misclassification.

## Key Results
- On Cora with GCN, >52% accuracy drop and >74% F1 drop at only 5% virtual node injection rate.
- Attack effectiveness persists even when injected nodes have zero features.
- Outperforms existing baseline attacks across node classification, graph classification, and graph regression tasks.

## Why This Works (Mechanism)
PEANUT exploits the inherent sensitivity of GNN message passing to topological perturbations. By aligning the connectivity pattern of injected virtual nodes with the dominant eigenvectors of clean node embeddings, the attack ensures that the introduced nodes maximally distort the aggregated representations during message passing. This eigenvector alignment leverages the spectral properties of the graph to efficiently propagate disruptive signals with minimal modifications, thereby causing large representation shifts without needing gradient access or model-specific knowledge.

## Foundational Learning
- **GNN Message Passing:** The core process where nodes iteratively aggregate information from neighbors. *Why needed:* Attack directly targets this aggregation mechanism. *Quick check:* Visualize how a single neighbor's features influence a node's representation after one layer.
- **Node Embeddings:** Continuous vector representations learned by GNNs to encode node structure and features. *Why needed:* PEANUT uses these embeddings to compute eigenvectors for alignment. *Quick check:* Apply t-SNE to node embeddings and verify cluster separation for known labels.
- **Eigenvector Alignment:** A method to match a graph's topology (adjacency) with the eigenvectors of a target matrix. *Why needed:* Optimizes placement of virtual nodes to maximize representation disruption. *Quick check:* Compare attack success when virtual node connections follow principal eigenvectors vs. random connections.
- **Black-Box Attacks:** Adversarial attacks that do not rely on model gradients or internal parameters. *Why needed:* PEANUT's stealth and practicality stem from this assumption. *Quick check:* Execute the attack while withholding all model details except inference API.
- **Frobenius Norm:** A matrix norm measuring overall element magnitude. *Why needed:* Used as the objective to quantify representation difference between clean and perturbed graphs. *Quick check:* Compute Frobenius norm between identity and scaled noise matrices to understand its sensitivity.
- **Virtual Node Injection:** Adding dummy nodes to a graph to alter message passing dynamics. *Why needed:* Primary perturbation mechanism in PEANUT. *Quick check:* Inject a few random nodes into a small graph and observe changes in node embeddings after one GCN layer.

## Architecture Onboarding
- **Component Map:** Clean graph -> Extract node embeddings -> Eigen decomposition -> Align eigenvectors -> Design virtual node topology -> Inject virtual nodes -> Perturbed graph -> Target GNN inference.
- **Critical Path:** The sequence from embedding extraction to eigenvector alignment is critical; errors in eigenvector computation or alignment directly determine injection topology and thus attack efficacy.
- **Design Tradeoffs:** Injection rate vs. attack strength (higher rate increases damage but reduces stealth); zero virtual node features vs. effectiveness (enhances stealth but may lower impact, though paper claims minimal drop).
- **Failure Signatures:** Target GNN employs robust aggregation (e.g., median instead of mean); graph noise obscures eigenvector structure; injection budget too low to meaningfully alter spectral properties.
- **First Three Experiments:** 1. Replicate the Cora + GCN experiment with exactly 5% injection rate and measure accuracy/F1 drops. 2. Test PEANUT on a different GNN architecture (e.g., GAT) on the same dataset to check transferability. 3. Perform an ablation where virtual node features are set to zero, random, and learned to isolate the contribution of topology.
