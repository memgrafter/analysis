# Spatial PDE-aware Selective State-space with Nested Memory for Mobile Traffic Grid Forecasting

## Quick Facts
- arXiv ID: 2603.12353
- Source URL: https://arxiv.org/abs/2603.12353
- Reference count: 13
- Primary result: NeST-S6 reduces one-step MAE/RMSE and 6-step rollout error vs. Mamba baseline; under drift, nested memory lowers MAE by 48–65%; for full-grid reconstruction, it achieves 32× speedup and 4.3× lower MACs than per-pixel scanning while attaining 61% lower per-pixel RMSE.

## Executive Summary
NeST-S6 introduces a convolutional selective state-space model (SSM) with a spatial PDE-aware core and a nested learning paradigm for mobile traffic grid forecasting. It processes the grid in non-overlapping patches, using a Fast Learner that applies local spatial mixing followed by a recurrence that mimics a discretized PDE, regularized for spatial smoothness. A Slow Learner maintains a memory tensor that is updated only when prediction error (surprise) indicates unmodeled dynamics, and this memory is injected into the Fast Learner’s context to improve long-term rollout robustness. Evaluated on the Milan dataset across multiple resolutions, NeST-S6 achieves lower one-step and 6-step errors compared to a Mamba-family baseline, significantly reduces error under synthetic distribution drift, and outperforms per-pixel models in efficiency and accuracy for full-grid reconstruction.

## Method Summary
The method formulates forecasting as a patch-wise next-step prediction. Input grids are tiled into H_p×W_p patches. Each patch sequence is processed by a Fast Learner: a convolutional stem followed by a stack of Conv-SSM blocks. Each block first applies depthwise convolution and windowed attention for local spatial mixing, then a selective SSM core with input-conditioned parameters (Δ, B, C, A) that vary across space, designed to model PDE-like dynamics; a Laplacian penalty enforces output smoothness. Nested learning runs alongside: the Fast Learner generates one-step predictions; the error is used to compute a surprise signal S_t. A Slow Learner (Deep Optimizer 2D) takes the current context z_t and S_t to produce an update for a persistent memory tensor M_t via a learned optimizer. During training, memory updates are applied; during autoregressive rollout, S_t is unavailable so M_t only decays and is injected into the Fast Learner’s context via a gated additive mechanism. The output head maps the final context to a patch prediction.

## Key Results
- NeST-S6 reduces one-step MAE/RMSE and 6-step rollout error accumulation relative to a Mamba-family baseline (VMRNN-D) on Milan across resolutions (20², 50², 100²).
- Under synthetic drift stress tests (scale/shift, spatial shift, volatility), its nested memory lowers MAE by 48–65% compared to a no-memory ablation.
- For full-grid reconstruction at 100² resolution, NeST-S6 achieves a 32× speedup and 4.3× lower MACs than the per-pixel scanning model HiSTM, while also lowering per-pixel RMSE by 61%.

## Why This Works (Mechanism)
### Mechanism 1: Convolutional SSM with PDE-aware core
**Claim:** A convolutional selective state-space model with a spatial PDE-aware core efficiently captures local spatiotemporal dependencies in grid data.  
**Mechanism:** Input patches undergo local spatial mixing via depthwise convolution and windowed attention before entering a spatial SSM core. The core implements a per-pixel recurrence (Eq.1) where input-conditioned, spatially varying parameters (Δ, B_eff, C_eff, A_eff) model dynamics analogous to a discretized PDE. A Laplacian penalty regularizes outputs to be spatially smooth.  
**Core assumption:** Traffic dynamics within a local patch follow a stable, spatially coherent process that can be approximated by PDE-like interactions, where changes depend on neighboring states and inputs.  
**Evidence anchors:** Abstract mentions the core; Section II.B defines the recurrence and regularization; related work acknowledges PDE-inspired parameterization as distinguishing.  
**Break condition:** Abrupt, non-smooth spatial transitions (e.g., sharp cell boundaries) may violate the smoothness prior, causing the Laplacian term to suppress valid sharp features or the SSM to misrepresent heterogeneous couplings.

### Mechanism 2: Nested learning with error-driven memory
**Claim:** A nested learning paradigm that updates a slow memory via a learned optimizer triggered by one-step prediction error improves robustness to distribution drift during long rollouts.  
**Mechanism:** A Fast Learner produces one-step predictions. A Slow Learner (Deep Optimizer 2D) maintains a persistent spatial memory tensor M_t. When a surprise signal S_t (based on one-step error) indicates unmodeled dynamics, M_t is updated using a learned optimizer (Eq.3). During free-running rollout, M_t is injected into the Fast Learner’s context (Eq.4) to correct accumulated error; without surprise, M_t only decays.  
**Core assumption:** One-step prediction error reliably signals long-term, unmodeled spatial-temporal dynamics (drift) that will affect future rollouts, and a slowly updated memory can compensate.  
**Evidence anchors:** Abstract and Section II.B describe nested learning and equations; it is novel compared to other SSM-based traffic models (HiSTM, ST-Mamba).  
**Break condition:** If one-step error uncorrelated with multi-step drift (e.g., noise vs. systematic bias), memory updates could amplify errors or inject irrelevant corrections, destabilizing rollouts.

### Mechanism 3: Patch-based forecasting for efficiency
**Claim:** Predicting non-overlapping grid patches in parallel yields efficient full-grid reconstruction with lower computational cost and error than per-pixel scanning models.  
**Mechanism:** The input grid is tiled into patches; the model predicts each patch’s next frame independently but in parallel, leveraging its local spatial mixing. The full grid is reconstructed by stitching predictions. This avoids the sequential autoregressive per-pixel processing of scalar predictors.  
**Core assumption:** Primary spatial dependencies for predicting a patch’s next state are contained within the patch and its immediate history; long-range dependencies are weak or can be handled by the model’s internal state without cross-pixel recurrence.  
**Evidence anchors:** Abstract and Section II.A formalize the patch-wise problem; Section III.E shows 32× speedup, 4.3× lower MACs, and 61% lower per-pixel RMSE vs. HiSTM.  
**Break condition:** If key predictive signals require context larger than a patch (e.g., city-wide events), patch boundaries could create artifacts or force approximate long-range interactions within limited capacity.

**Why needed:** The “PDE-aware” core is justified by analogy to spatial dynamical systems. The Laplacian penalty explicitly enforces spatial smoothness, a common property in physical PDEs.

## Architecture Onboarding
**Component map:**  
Input Tiling Module -> Fast Learner (convolutional stem -> stack of Conv-SSM blocks) -> Memory Injection Gate -> Output Head; Slow Learner (Deep Optimizer 2D) maintains memory M_t and updates it in parallel based on prediction error.

**Critical path:**  
1. Input grid tiled into non-overlapping patches.  
2. Convolutional stem processes each patch to extract features.  
3. Features propagate through Conv-SSM blocks, each performing local spatial mixing and a PDE-aware SSM recurrence; memory M_t is injected via a gated additive modulation at a designated layer.  
4. The final context is mapped by the output head to predict the next patch.  
5. Prediction error is computed to derive surprise signal S_t.  
6. Deep Optimizer 2D (Slow Learner) takes current context z_t and S_t, produces an update for M_t, which is combined with the previous memory using decay λ.  
7. During autoregressive rollout, steps 5–6 are disabled (S_t unavailable); M_t evolves only by decay but still gets injected.

**Design tradeoffs:**  
- **Patch size:** Larger patches capture more local context but increase per-patch compute and may dilute intra-patch dependencies; smaller patches increase total patches and risk boundary effects.  
- **Memory injection strength:** High injection improves drift adaptation but risks destabilizing training if memory becomes noisy; low injection reduces robustness.  
- **PDE regularization weight:** Stronger Laplacian penalty enforces smoothness (good for stable trends) but may suppress sharp, localized spikes (e.g., stadium events).

**Failure signatures:**  
- **Rollout error accumulation:** ∆MAE (6-step minus 1-step) grows rapidly, indicating memory fails to compensate for error propagation.  
- **Patch boundary artifacts:** Visible seams in stitched grid suggest dependencies cross patch boundaries or local mixing insufficient.  
- **Memory divergence:** In drift tests, no-memory ablation performs similarly or better, indicating memory updates are harmful (likely S_t not indicative of drift).

**First 3 experiments:**  
1. **Baseline comparison:** Train/evaluate NeST-S6 vs. VMRNN-D (Mamba-family) on Milan at all resolutions; report one-step MAE/RMSE and 6-step rollout accumulation.  
2. **Drift robustness ablation:** Introduce controlled drifts (scale/offset, spatial shift, volatility); compare NeST-S6 with its no-memory ablation; measure MAE degradation; expect memory to reduce degradation by ~48-65%.  
3. **Efficiency & full-grid validation:** At 100² resolution, compare per-grid-patch inference latency and MACs of NeST-S6 against HiSTM (per-pixel); also compute per-pixel RMSE across grid cells to validate patch reconstruction quality.

## Limitations
- **Implementation gaps:** Missing details of SSM parameterization (A_eff rank, Δ init) and Deep Optimizer 2D architecture hinder exact reproduction.
- **Break conditions:** PDE smoothness prior may over-regularize sharp spikes; memory triggered by one-step error may not correlate with long-term drift, potentially injecting corrections.
- **Generalization:** Evaluation limited to a single dataset; patch locality assumption untested beyond Milan; efficiency comparison against only one per-pixel baseline.

## Confidence
- **PDE-aware SSM:** Medium (supported by Laplacian ablation and baseline comparisons, but missing SSM config and possible over-smoothing).
- **Nested memory:** Medium (drift tests show 48–65% MAE reduction, but surprise design and update rule lack transparency).
- **Patch-based efficiency:** High (32× speedup, 4.3× lower MACs, 61% lower RMSE vs. HiSTM; plausible but needs broader validation).

## Next Checks
