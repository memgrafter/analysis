# MB-DSMIL-CL-PL: Scalable Weakly Supervised Ovarian Cancer Subtype Classification and Localisation Using Contrastive and Prototype Learning with Frozen Patch Features
## Quick Facts
- arXiv ID: 2602.15138
- Source URL: https://arxiv.org/abs/2602.15138
- Reference count: 9
- Primary result: MB-DSMIL-CL-PL improves instance macro F1 by 70.4% and instance OvR AUC by 16.9% over DSMIL on DROV dataset (137 WSIs), with better localisation and slide-level metrics.

## Executive Summary
Ovarian cancer subtyping from whole-slide images demands accurate classification and localisation under weak slide-level supervision. This paper introduces MB-DSMIL-CL-PL, a framework that enhances the DSMIL multiple instance learning architecture through three synergistic components: class-specific attention branches (MB-DSMIL), contrastive learning on frozen UNI patch features (CL), and prototype learning for stable pseudo-labeling (PL). Evaluated on the DROV dataset, the method yields substantial gains over DSMIL across instance and slide classification as well as attention-based localisation, while preserving the scalability benefits of frozen features.

## Method Summary
MB-DSMIL-CL-PL modifies the DSMIL MIL pipeline by replacing the shared query projection with class-specific queries, enabling each ovarian cancer subtype to define its own relevance metric for patches. Contrastive learning operates directly on precomputed UNI features via SimCL-inspired augmentations in feature space and a momentum encoder, adapting representations without end-to-end image training. Prototype learning introduces per-class centroids (including normal) updated by exponential moving average; soft pseudo-labels derived from these centroids guide instance-level training with temporal stability, reducing noise from early predictions. Slide predictions are derived from class-specific aggregated bag vectors, with the overall loss combining slide-level cross-entropy and instance-level contrastive and pseudo-label losses.

## Key Results
- Instance macro F1 ↑70.4% (0.301→0.513) versus DSMIL.
- Slide macro F1 ↑15.3% (0.672→0.775).
- Attention-based localisation AUC ↑15.9% (0.756→0.876).

## Why This Works (Mechanism)
### Multi-Branch Attention (MB-DSMIL)
DSMIL uses a shared query projection to compute attention scores; MB-DSMIL replaces this with class-specific queries (`ϕ_c`). For each class `c`, instance features are mapped to query space, and attention weights are computed between all queries and the critical instance query for that class. The resulting weighted sum yields a class-specific bag vector, which is fed to a dedicated linear classifier. This allows each ovarian cancer subtype (e.g., HGSC vs. CCC) to define its own relevance metric, better capturing subtype-specific morphological patterns.

*Evidence:* The abstract and Section 2.5.1 detail the formulation. Ablation results (Tables 2–4) show improved per-class F1, particularly for rare subtypes, confirming the benefit of class-specific branches.

*Break condition:* If minority-class F1 (e.g., MA, MBT) drops compared to shared-query DSMIL, it would indicate that class-specific branches may overfit or fail to Learn discriminative queries for rare subtypes.

### Contrastive Learning on Frozen Features (CL)
Instead of end-to-end training, CL adapts frozen precomputed patch features from UNI. Weak and strong feature-space augmentations (SimCL noise and dropout) are applied, and embeddings are projected via MLPs (`g_q`, `g_k`). `g_k` is updated by exponential moving average. Initially a MoCo loss aligns the two views; later a supervised contrastive loss (using pseudo-labels from PL) pulls together embeddings of the same class and pushes apart those from different classes. This reshapes the embedding geometry for the ovarian subtyping task while keeping the encoder frozen for scalability.

*Evidence:* Section 2.5.2 describes the adaptation. Instance OvR AUC improves when CL is added (Table 3), supporting its contribution to feature discriminativity.

*Break condition:* If instance OvR AUC decreases when CL is ablated but improves with end-to-end fine-tuning, it would suggest that frozen features lack sufficient representational capacity for such adaptation.

### Prototype Learning for Stable Pseudo-Labeling (PL)
Prototype learning provides temporally stable pseudo-labels for instance classification. A prototype `µ_c` for each class (including normal) is initialized randomly and updated via EMA of weakly augmented instance features assigned to that class. Soft pseudo-labels `s_ij` are computed via similarity to relevant prototypes (restricted to the slide-level label class plus normal). A momentum parameter `α` smooths `s_ij` over time, and the instance classifier is trained with KL divergence against `s_ij`. This mitigates noise from unstable early predictions (e.g., attention or confidence scores), especially for rare subtypes.

*Evidence:* Section 2.5.3 and qualitative improvements in attention maps (Figures 3–5) show more coherent localisation. The use of `m=0.9` and `α=0.8` (Section 2.6.4) and ablation gains confirm effectiveness.

*Break condition:* If instance macro F1 variance across CV folds increases with PL, or per-class performance for rare subtypes does not improve, it could indicate prototype collapse or poor initialization.

## Foundational Learning
- **Multiple Instance Learning (MIL):** Framework where a whole-slide image (bag) is represented by a set of patches (instances); only bag-level labels are available during training.  
  *Why needed here:* MB-DSMIL-CL-PL is built atop DSMIL/CLAM, which are MIL architectures. Understanding bag/instance separation and attention-based aggregation is essential to grasp how slide predictions emerge from patch features.  
  *Quick check:* In DSMIL, what is the role of the "critical instance" in the attention mechanism?

- **Contrastive Learning (CL):** Technique that learns representations by maximizing agreement between differently augmented views of the same sample and minimizing agreement between views from different samples.  
  *Why needed here:* CL adapts frozen UNI features to the ovarian subtype task without end-to-end image training. The loss function (MoCo then supervised) reshapes the embedding space.  
  *Quick check:* Why use a momentum encoder (`g_k`) instead of a synchronously updated one for the strong view?

- **Prototype Learning (PL):** Method that represents each class by a learned centroid (prototype); instance labels are derived from similarity to these centroids.  
  *Why needed here:* PL generates stable pseudo-labels for instance supervision, mitigating noise from attention/confidence. The momentum update of both prototypes and soft labels ensures temporal stability.  
  *Quick check:* How does the soft pseudo-label `s_ij` differ from a hard one-hot label, and why is momentum (`α`) applied to it?

## Architecture Onboarding
### Component map
Precomputed patch features (UNI) → MB-DSMIL core (class-specific query projections and attention) → Slide classifier (linear per class).  
Simultaneously, Contrastive Learning module (SimCL augmentations, MLP projections, MoCo/supervised contrastive loss) operates on the frozen features, and Prototype Learning module (class prototypes with EMA, soft pseudo-labels) provides instance-level supervision. These streams converge in a joint loss that combines slide-level cross-entropy and instance-level losses.

### Critical path
1. Precomputed patches are fed into the MB-DSMIL core, where each class computes attention weights and aggregates a class-specific bag vector.
2. The bag vectors are passed through class-specific linear layers to produce slide-level predictions, optimized by cross-entropy loss.
3. In parallel, augmented versions of the same instance features are processed by the CL module to compute contrastive loss, and by the PL module to update prototypes and generate soft pseudo-labels that supervise the instance-level classification objective.
4. The overall loss is a weighted sum (exact λ values not detailed) of the slide and instance losses.

### Design tradeoffs
- **Frozen vs. end-to-end features:** Using frozen UNI features offers speed and scalability but limits adaptability; contrastive learning aims to mitigate this but may not fully match end-to-end fine-tuning.
- **Class-specific vs. shared queries:** Multi-branch attention increases expressive power for diverse subtypes but risks overfitting on rare classes and higher memory usage.
- **Prototype stability:** High momentum values (`m=0.9` for prototypes, `α=0.8` for labels) smooth updates but may delay adaptation to new patterns, especially in early training.

### Failure signatures
- Sudden drop in per-class F1 for rare ovarian subtypes (e.g., MucA, SBT) suggests either class-specific branches or prototype mechanism failing to capture minority patterns.
- Extremely sparse attention distributions indicate the model relies on very few instances; the proposed method should exhibit denser, more coherent heatmaps.
- High variance in metrics across cross-validation folds signals instability in pseudo-labeling or contrastive learning; investigate PL momentum and CL warm-up schedule.
- Poor separation between tumor subtypes and normal tissue (low "GT vs. Normal" AUC) indicates insufficient differentiation between malignant and normal prototypes.

### First 3 experiments
1. **Ablation study:** Train DSMIL, MB-DSMIL, MB-DSMIL-CL, MB-DSMIL-PL, and the full MB-DSMIL-CL-PL. Expected: CL boosts instance OvR AUC; PL stabilizes training (reduced variance); combination yields best overall.
2. **SimCL augmentation sweep:** Vary the strength of noise augmentations (`η_w`, `η_s`). Too low yields insufficient feature adaptation; too high causes semantic drift. Monitor instance macro F1 and slide F1; paper uses `η_w=0.05`, `η_s=0.4`.
3. **Prototype momentum sensitivity:** Vary PL EMA momentum `m` (default 0.9) and label momentum `α` (default 0.8). Lower values increase noise; higher values risk sluggish adaptation. Track instance F1 consistency across epochs and per-class performance for rare subtypes.

## Open Questions the Paper Calls Out
1. **Multi-resolution integration:** How does incorporating patch features from multiple magnifications affect performance and computational cost? The authors suggest extending the current single-resolution (10×) approach with a multi-resolution framework like Li et al. (2020).  
   *Resolution:* Train and test with patches at e.g., 10× and 20×, comparing slide/instance metrics and resource usage.

2. **Regularisation for instance reliance:** Can random instance dropout or hard-positive mining further improve generalisation by reducing dependence on a small subset of instances? The paper proposes these as future directions.  
   *Resolution:* Implement such techniques, measure attention weight diversity (e.g., entropy), and compare classification performance.

3. **Generalisation to binary benchmarks:** Does the method transfer to standard binary classification tasks (e.g., CAMELYON) while maintaining efficiency? The authors note this could be easily adapted.  
   *Resolution:* Adapt MB-DSMIL-CL-PL for binary slide classification on CAMELYON, report instance localisation AUC and slide AUC, and compare to state-of-the-art MIL methods.

## Limitations
- **Dataset scope:** Evaluation restricted to the DROV dataset (137 WSIs) limits claims of generalisability; external validation on other cancer types or larger cohorts is lacking.
- **Contributions entangled:** Ablation shows combined benefits, but isolating the precise additive or synergistic effects of MB-DSMIL, CL, and PL remains difficult.
- **Scalability evidence:** The claim of scalability from frozen features is not supported by a direct benchmark of training time or memory versus end-to-end fine-tuning.

## Confidence
- Overall improvement over DSMIL: **High** (consistent gains across multiple metrics).
- Multi-branch attention (MB-DSMIL): **Medium** (internal evidence via per-class F1, but lacking independent replication).
- Feature-space contrastive learning (CL): **Low to Medium** (novel assumption not directly corroborated by external work; evidence mainly from ablation).
- Prototype learning (PL): **Medium** (supported by improved localisation and qualitative maps, but stability claim inferred from performance).

## Next Checks
1. **External validation:** Replicate MB-DSMIL-CL-CL on at least two independent, publicly available histopathology WSI datasets (e.g., a different cancer type or a larger ovarian cohort) to test generalizability beyond DROV.
2. **Frozen vs. end-to-end trade-off:** Conduct a controlled benchmark comparing (a) the proposed frozen-feature method and (b) a version with the UNI encoder fine-tuned end-to-end, measuring training time, GPU memory, and final performance to directly assess scalability claims.
3. **Prototype robustness under shift:** Systematically vary PL momentum parameters (`m` for prototypes, `α` for labels) and evaluate the variance of instance-level pseudo-label quality (e.g., using manually annotated patches as ground truth) over training, specifically for the rarest subtype, to stress-test the stability claim.
