# Fine-Tuning Without Forgetting In-Context Learning: A Theoretical Analysis of Linear Attention Models

## Quick Facts
- **arXiv ID**: 2602.23197  
- **Source URL**: https://arxiv.org/abs/2602.23197  
- **Reference count**: 40  
- **Primary result**: Value-matrix fine-tuning improves zero-shot performance while preserving in-context learning across tasks.

## Executive Summary
Fine-tuning large language models for improved zero-shot performance can degrade in-context learning (ICL) on unseen tasks. This paper uses linear attention models to theoretically analyze how different fine-tuning objectives alter attention parameters and affect few-shot performance. The authors derive closed-form solutions for optimal parameters under three regimes: full fine-tuning, value-matrix-only updates, and adding an auxiliary few-shot loss. Full fine-tuning minimizes zero-shot error to the irreducible noise level but causes asymptotic few-shot error to rise, even on the target task. Value-matrix fine-tuning achieves near-optimal zero-shot error while preserving few-shot performance for all tasks. However, combining zero-shot fine-tuning with an auxiliary few-shot loss optimizes few-shot performance on the target task at the cost of degraded out-of-distribution performance, with excess error scaling quadratically with task dissimilarity. Empirical validation on synthetic linear regression and the MMLU benchmark (Qwen2.5-3B-Instruct) confirms these predictions.

## Method Summary
The study employs a linear attention transformer with prediction function \(f(Z;V,Q) = Z + \frac{1}{n} V Z Z^\top Q Z\), where \(Z\) is the context matrix. Pretraining minimizes expected \(m\)-shot error over a distribution of linear regression tasks. Fine-tuning regimes include: (i) full fine-tuning on zero-shot loss; (ii) value-matrix fine-tuning (freezing \(Q\) and most \(V\) blocks except \(v_{21}\)) on zero-shot loss; (iii) value-matrix fine-tuning with an auxiliary \(n\)-shot loss that is annealed to zero. For MMLU, LoRA (rank 128) is applied either to all Q/K/V or only to V, with and without the auxiliary loss. The humanities subset (1k examples) with chain-of-thought rationales is used for fine-tuning; zero-shot and 7-shot accuracy are evaluated across four categories.

## Key Results
- Full fine-tuning drives zero-shot error to \(\sigma^2\) but asymptotic few-shot error increases to \(\sigma^2 + \theta_0^\top \Sigma \theta_0\).
- Value-matrix fine-tuning yields zero-shot error \(\sigma^2 + \frac{2}{d+4}\theta_0^\top \Sigma \theta_0\) and preserves few-shot error near \(\sigma^2 + \frac{1}{(d+4)^2}\theta_0^\top \Sigma \theta_0\).
- Adding an auxiliary few-shot loss attains target-task few-shot error \(\sigma^2\) but OOD excess error scales as \((1-\rho(\theta,\theta_0))^2\), with \(\rho\) the \(\Sigma\)-induced cosine similarity.
- MMLU: Updating all LoRA modules harms 7-shot performance on other categories; V-only LoRA maintains it. Auxiliary few-shot loss boosts in-domain few-shot but hurts out-of-domain.

## Why This Works (Mechanism)
The linear attention model separates the roles of \(Q\) (query) and \(V\) (value). Pretraining shapes \(Q\) to approximate \(\Sigma^{-1}\), encoding a robust in-context learning algorithm for any task under the data distribution. Full fine-tuning updates both \(Q\) and \(V\) to fit the target task’s zero-shot loss, thereby overwriting the pretrained \(Q\) and disrupting the ICL mechanism. In contrast, value-matrix fine-tuning updates only specific entries of \(V\), leaving \(Q\) untouched; this adjusts the zero‑shot bias while preserving the ICL algorithm. The auxiliary few‑shot loss directly optimizes the few‑shot objective on the target task, but its gradient modifies \(V\) in a direction that depends on \(\theta_0\), making the resulting parameter specialized and thus less effective for dissimilar tasks.

## Foundational Learning
1. **Linear Attention Model**  
   *Why needed*: Enables closed-form analysis, avoiding softmax nonlinearities.  
   *Quick check*: Forward pass with random \(V,Q\) yields \(Z' = Z + \frac{1}{n} V Z Z^\top Q Z\); check dimensions and linearity.

2. **Task Distribution & Covariance \(\Sigma\)**  
   *Why needed*: Theoretical expectations are taken over \(\theta \sim \mathcal{N}(0,\Sigma)\); \(\Sigma\) defines the natural inner product for task similarity.  
   *Quick check*: Sample many \(\theta\) and compute empirical average of \(\theta\theta^\top\); it should approximate \(\Sigma\).

3. **Zero‑Shot vs. Few‑Shot Error**  
   *Why needed*: Different objectives; fine‑tuning may improve one while harming the other.  
   *Quick check*: For a pretrained model, compute error with \(n=0\) (zero‑shot) and \(n=20\) (few‑shot) on a held‑out task.

4. **Value‑Matrix Fine‑Tuning (PEFT)**  
   *Why needed*: Demonstrates that updating only a subset of parameters can preserve ICL.  
   *Quick check*: After value‑only fine‑tuning, compare \(Q\) to its pretrained copy; it should be unchanged.

## Architecture Onboarding
- **Component map**:  
  Task distribution → Sample context → Build \(Z\) → \(f(Z)=Z+\frac{1}{n}VZZ^\top QZ\) → Extract prediction (query token) → Loss → Parameter update.
- **Critical path**:  
  (1) Pretraining minimizes expected \(m\)-shot error → yields \(Q^* \approx \Sigma^{-1}\) and structured \(V\).  
  (2) Full fine‑tuning on zero‑shot loss updates both \(V\) and \(Q\) → alters \(Q\) → ICL breaks.  
  (3) Value‑only fine‑tuning updates only \(v_{21}\) (and scaling) → \(Q\) unchanged → ICL preserved.  
  (4) Auxiliary few‑shot loss adds a term that forces \(V\) to specialize on target task → OOD degradation.
- **Design tradeoffs**: Zero‑shot improvement vs. few‑shot retention; in‑domain vs. out‑of‑domain few‑shot performance.
- **Failure signatures**:  
  - Full fine‑tuning leads to increased few‑shot error on held‑out tasks.  
  - Value‑only fine‑tuning harms few‑shot if \(Q\) was inadvertently updated or pretraining converged poorly.  
  - Auxiliary loss fails to improve target few‑shot if annealing is too fast or context length too small.
- **Three first experiments**:  
  1. Verify that a pretrained model performs accurate few‑shot learning on random tasks.  
  2. Apply full fine‑tuning to a fixed target task; measure zero‑shot and few‑shot errors on both the target and a held‑out task; expect few‑shot on held‑out to degrade.  
  3. Apply value‑matrix‑only fine‑tuning to the same target task; confirm that few‑shot on held‑out tasks remains unchanged.

## Open Questions the Paper Calls Out
1. Does the analysis extend to softmax attention and multi‑head architectures?  
2. How do other parameter‑efficient fine‑tuning methods (LoRA, adapters, prefix‑tuning) relate to these findings?  
3. How robust are the results to finite or varied pretraining context lengths?  
4. Is the \(\Sigma\)-induced cosine similarity a reliable predictor of out‑of‑distribution degradation when using auxiliary few‑shot losses?

## Limitations
- Hyperparameters for synthetic and MMLU experiments are not fully specified, hindering exact replication.
- Theory assumes linear attention; real LLMs include nonlinearities that may alter the derived trade‑offs.
- Empirical validation is restricted to a single model (Qwen2.5‑3B) and a single MMLU subset; generalizability is uncertain.

## Confidence
- Linear‑attention theory: Medium  
- Value‑matrix fine‑tuning preserves few‑shot: Medium  
- Auxiliary few‑shot loss degrades OOD: Low  
- Overall recommendation of value‑matrix fine‑tuning: Low‑Medium
