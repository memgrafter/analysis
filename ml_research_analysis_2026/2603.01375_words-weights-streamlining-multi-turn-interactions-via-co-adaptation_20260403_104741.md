# Words & Weights: Streamlining Multi-Turn Interactions via Co-Adaptation

## Quick Facts
- ArXiv ID: 2603.01375
- Source URL: https://arxiv.org/abs/2603.01375
- Reference count: 21
- Primary result: ROSA2 jointly optimizes textual gradients and weight updates, achieving up to 30.8% absolute accuracy gain on MATH and a 40% reduction in average interaction turns.

## Executive Summary
Test-time policy adaptation for multi-turn interactions remains challenging because existing methods optimize either instructions (words) or model weights in isolation. This separation fails to address the coupled nature of context ambiguity and model incapacity. ROSA2 introduces a co-adaptation framework that simultaneously refines user intent through textual gradients and improves execution via parameter updates, with semantic clarity pre-conditioning the weight updates. Theoretically, ROSA2 proves that joint optimization strictly reduces the required parameter shift and accelerates convergence. Empirically, across models from 0.5B to 8B and several benchmarks, ROSA2 yields up to 30.8% absolute accuracy improvements on MATH and reduces average interaction turns by 40% (e.g., from 7.2 to 4.4 on Qwen3-8B). On sparse-reward UI agent tasks, it achieves over 10% improvement with minimal memory overhead, demonstrating the synergy of co-adapting context and parameters.

## Method Summary
At test time, for each turn in a multi-turn interaction, ROSA2 first computes a textual gradient—a natural language instruction that indicates how to modify the current context (user query and prior responses) to reduce ambiguity. This textual gradient is applied to rewrite the context, producing a semantically clearer version. The refined context then guides a small number of gradient-based weight updates on the model, targeting the current turn’s objective. The pre-conditioning of weight updates by textual refinement leads to more targeted parameter changes and a smaller overall shift. This loop of textual refinement followed by weight adjustment repeats across turns, enabling the model to adapt both its understanding and behavior in concert.

## Key Results
- Up to 30.8% absolute accuracy improvement on the MATH benchmark.
- Average interaction turns reduced by 40% (e.g., Qwen3-8B: 7.2 → 4.4 turns).
- Over 10% improvement on sparse-reward UI agent tasks, with minimal memory overhead across models 0.5B–8B.

## Why This Works (Mechanism)
Separate optimization of words and weights fails because ambiguous context yields noisy or misdirected weight updates, while weight updates alone cannot resolve inherent ambiguity in the instruction. ROSA2’s co-adaptation directly tackles this coupling: textual gradients first clarify the user’s intent, producing a context that yields a cleaner learning signal for parameter updates. Theoretically, this ordering bounds the necessary parameter shift, implying faster convergence. Empirically, the synergy manifests as both higher accuracy (better execution) and fewer turns (faster resolution), confirming that the two adaptations reinforce each other.

## Foundational Learning
- **Test-Time Adaptation (TTA)**: Adapting model parameters during inference without altering training data.  
  *Why needed*: ROSA2 extends TTA to dynamic multi-turn settings where context evolves.  
  *Quick check*: How does TTA differ from traditional fine-tuning?
- **Textual Gradients**: Natural language descriptions that specify how to modify an input context.  
  *Why needed*: To disambiguate user intent before weight updates.  
  *Quick check*: How would you design a textual gradient for a vague user query?
- **Parameter Shift**: The Euclidean distance between a model’s original and updated weights.  
  *Why needed*: Smaller shifts indicate more efficient, stable adaptation, crucial for multi-turn continuity.  
  *Quick check*: Why is minimizing parameter shift beneficial in test-time adaptation?
- **Multi-Turn Interactions**: Dialogues or task sequences requiring sustained context awareness.  
  *Why needed*: The core problem domain; ambiguity accumulates across turns.  
  *Quick check*: What unique challenges do multi-turn interactions pose compared to single-turn?
- **Semantic Clarity**: The degree to which the context is precise and unambiguous.  
  *Why needed*: Clear context ensures accurate gradient signals for weight updates.  
  *Quick check*: How does semantic clarity affect the quality of parameter updates?

## Architecture Onboarding
**Component Map**: User Input → Textual Gradient Generator → Context Refinement → Parameter Updater → Adapted Model → Response Generation

**Critical Path**:
1. Receive user turn with accumulated context.
2. Compute textual gradient (e.g., via a critic model or loss signal).
3. Apply textual gradient to refine the context (e.g., rewrite ambiguous parts).
4. Perform weight updates using the refined context (few gradient steps).
5. Generate model response.
6. Append response to context and repeat for the next turn.

**Design Tradeoffs**:
- *Coupling timing*: ROSA2’s fixed order (textual then weight) reduces parameter shift but adds a per-turn step; simultaneous or reversed ordering may trade stability for speed.
- *Computational cost*: Textual gradient generation is cheap (single prompt), while weight updates involve backpropagation, which is costly for large models. Balancing the number of update steps is key.
- *Stability vs. adaptability*: Aggressive weight updates quickly adapt to the current turn but risk overfitting and harming future turns; textual refinement can mitigate but may not fully correct.

**Failure Signatures**:
- Accuracy degrades after several turns, indicating weight updates are diverging due to poor textual gradients.
- Context becomes more verbose or confusing after refinement, suggesting a mis-specified textual gradient generator.
- Memory usage grows with each turn (if context is not truncated), leading to out-of-memory errors.
- Interaction turns do not decrease or even increase, implying co-adaptation is ineffective.

**First Three Experiments**:
1. **Reproduce baseline results**: Run ROSA2 on MATH with a 0.5B model, reporting accuracy and average turns.
2. **Ablation study**: Compare full ROSA2 against (a) only textual gradients (no weight updates) and (b) only weight updates (no textual gradients) to isolate the synergy of co-adaptation.
3. **Adaptation step sensitivity**: Vary the number of weight update steps per turn (e.g., 0, 1, 5, 10) and measure impact on accuracy and turn count to determine optimal schedule.

## Limitations
- Theoretical assumptions (convexity, smoothness) are unrealistic for LLMs; it is unclear whether guarantees hold empirically.
- Large reported gains may be hyperparameter-sensitive; lack of reproducibility details (e.g., learning rates, prompts) hinders verification.
- Evaluation limited to models ≤8B and few benchmarks; scalability, generalization, and memory overhead require further study.

## Confidence
- Theoretical guarantee: Low
- Empirical gains: Medium
- Efficiency/synergy: Medium

## Next Checks
