# Efficient Analysis of the Distilled Neural Tangent Kernel

## Quick Facts
- **arXiv ID**: 2602.11320
- **Source URL**: https://arxiv.org/abs/2602.11320
- **Reference count**: 40
- **Primary result**: DNTK reduces NTK computation cost by up to five orders of magnitude while preserving predictive fidelity; with only five synthetic gradients (100× compression) it attains 76% test accuracy on ImageNette (ResNet‑18), matching full NTK performance.

## Executive Summary
The paper introduces the Distilled Neural Tangent Kernel (DNTK), a pipeline that dramatically reduces the computational and storage costs of neural tangent kernel (NTK) evaluation by combining three orthogonal compression techniques: NTK‑tuned dataset distillation, Johnson‑Lindenstrauss random projection, and local‑global gradient distillation. By exploiting the low effective rank of class‑wise NTK matrices, DNTK achieves compressions of up to 100× within each stage, leading to overall reductions of up to 10^5× relative to the naive O(n²P) approach. On the ImageNette dataset with ResNet‑18, DNTK attains 76% test accuracy using only five synthetic gradients, matching the performance of the full NTK. Theoretical analysis shows that dataset distillation selects a tangent subspace aligned with the principal components of the gradient covariance, while the local‑global algorithm captures hierarchical spectral structure. Extensive experiments confirm that the compressed NTK preserves the predictive fidelity of the original kernel.

## Method Summary
The DNTK pipeline consists of four stages. First, dataset distillation (specifically WMDD) is applied to the original training set to synthesize a small set of *m* examples (e.g., 500) and their soft labels. These distilled points are chosen to match the intermediate feature distribution of the full data, thereby inducing gradient vectors that span the dominant subspace of the tangent space. Second, for each distilled example and each class, the logit gradient with respect to the network parameters (size *P*) is computed. A random orthonormal projection (Johnson‑Lindenstrauss) reduces the gradient dimension from *P* to *k* (e.g., 200), yielding per‑class projected gradient matrices Φ̃^c ∈ ℝ^{m×k}. Third, the local‑global gradient distillation algorithm (Algorithm 1) processes the average class kernel and clusters it into *H* groups; it then synthesizes a minimal set of *s* gradient vectors that cover both the local cluster subspaces and any global "gap" directions that are not captured by the union of local subspaces. The resulting synthetic set (Φ̂, Ŷ) is orders of magnitude smaller than *m*. Finally, kernel ridge regression is performed on the synthetic set by directly using the inner products of projected gradients as kernel entries. At test time, the network is not evaluated; instead, the projected gradient of the test example is computed and compared to the synthetic gradients via inner products, and the learned coefficients produce the class scores. This entire pipeline avoids ever constructing the full *n*×*n* kernel and reduces both computational and storage demands significantly.

## Key Results
- DNTK reduces computational and storage costs by up to **five orders of magnitude** compared to the naive O(n²P) NTK construction.
- With only **five synthetic gradients** (100× compression), it achieves **76% test accuracy** on ImageNette (ResNet‑18), matching the full NTK baseline.
- Spectral analysis reveals that class‑wise NTK matrices have **effective ranks of 31–41**, enabling aggressive compression with minimal error.

## Why This Works (Mechanism)

### NTK‑tuned dataset distillation
Dataset distillation reduces the number of data points needed for NTK computation by synthesizing a small set of examples whose gradient features span the dominant subspace of the full dataset's tangent space. In the lazy training regime (fixed reference parameters θ), the NTK for a class *c* is *K*^c = Φ^c (Φ^c)^⊤, where Φ^c contains per‑example logit gradients. Lemma C.1 shows that for any distilled dataset (X̃, Ỹ), the loss gradients lie in the span of the logit gradients at X̃. Theorem 3.3 reveals that one‑step outer progress when training with the distilled set is governed by the projection residual ∥(I−Π_{X̃})g_t∥², where Π_{X̃} projects onto the tangent subspace induced by X̃. The optimal (relaxed) subspace minimizing this residual is the principal component subspace of the gradient covariance *G* = 𝔼_t[g_t g_t^⊤] (Corollary 3.5). Distillation methods like WMDD optimize a feature‑matching objective that encourages the distilled set’s gradients to align with those principal directions (Section 4.1). Consequently, a small distilled set *m ≪ n* captures most of the variance, yielding a 20–100× reduction in Jacobian evaluations. Core assumption: the network operates near a lazy linearization around a fixed θ, and the bilevel distillation objective succeeds in producing inputs whose gradient span approximates the top eigenmodes of *G*. Evidence anchors: the abstract and Sections 3.3–4.1 confirm the mechanism. Break condition: if the distilled data fail to capture the principal directions (e.g., due to optimization failure or non‑lazy parameters), the projection residual grows and the approximation error may become unacceptable.

### Johnson‑Lindenstrauss random projection
A Johnson‑Lindenstrauss (JL) random projection reduces the parameter dimension *P* to *k ≪ P* while approximately preserving the inner products that define NTK entries, enabling a further 10–100× compression with bounded error. Let Φ ∈ ℝ^{n×P} be the matrix of gradient features. Apply a random orthonormal map *g*: ℝ^P → ℝ^k (scaled by √(P/k)) to obtain Φ̃ = Φ Q, where Q ∈ ℝ^{P×k}. The JL lemma guarantees that for any pair *u, v* ∈ ℝ^P, ∥*g*(u)−*g*(v)∥² ≈ ∥u−v∥² up to (1±ε_JL). Since ⟨u,v⟩ = ½(∥u∥²+∥v∥²−∥u−v∥²), inner products are also preserved. Thus the approximated kernel K̃ = Φ̃ Φ̃^⊤ is close to the original *K* = Φ Φ^⊤. The required *k* scales as Ω(log n / ε_JL²), which is independent of *P* (Section 4.2). Error bounds (Section B.3) indicate that if the kernel has effective rank *r*, the error depends on *r* rather than *n*, making the projection particularly effective for low‑rank kernels. Core assumption: the gradient vectors reside in a high‑dimensional ambient space and the random projection preserves pairwise distances uniformly; the introduced JL error is acceptable for downstream KRR. Evidence anchors: abstract and Section 4.2. Break condition: if *k* is too small relative to the effective rank of Φ, or if the eigenvectors of *K* are highly non‑uniform, the JL guarantee may degrade; also the random matrix must be independent of the data.

### Local‑global gradient distillation
Per‑class NTK matrices exhibit a hierarchical spectral structure: within‑cluster variance concentrates in a few global principal components, but some global variance lies outside the union of cluster subspaces. Exploiting this structure by synthesizing gradients for both *cluster modes* (local) and *gap modes* (global) yields an additional 10–100× compression beyond the distilled dataset alone. After dataset distillation and JL projection, we have a set of *m* gradient vectors per class. Algorithm 1 computes a class‑averaged kernel K̄ and partitions the data into *H* clusters via spectral clustering. It then finds the global truncation rank *r_g* (at variance threshold τ_v) and identifies “gap” directions—global principal components not well covered by any cluster (coverage *c_j* < τ_g). For each cluster, it synthesizes *r_h* gradients by taking linear combinations of the projected gradients in that cluster using the local eigenvectors as weights (Remark 4.2). For each gap direction, it synthesizes one gradient from the full set using the global eigenvector as weights. After orthogonalization to remove redundancy, the final set size *s* is much smaller than *m*. These synthetic gradients collectively span the subspace needed for accurate KRR, as verified by higher variance coverage and lower reconstruction error compared to sampling baselines (Figure 6). Core assumption: the per‑class NTK matrices satisfy properties (A) and (B) from Section 3.4—the local eigenspaces are contained in the global truncation space, but their union does not span it—and the effective ranks *r_h* and *r_g* are modest. Evidence anchors: abstract, Sections 3.4–4.3, and Figure 4. Break condition: if the kernel lacks a significant gap, the gap synthesis may be unnecessary but harmless; if the gap is large but too many directions are flagged, the synthetic set size may approach *m*, reducing compression. The method also relies on accurate estimation of local and global eigenvectors, which can be noisy if *m* is small.

## Architecture Onboarding

**Component map**  
- Input: Full dataset *X* (n examples) and pretrained network parameters θ.  
- Stage 1 (Dataset distillation): WMDD → distilled set (X̃, Ỹ) of size *m*.  
- Stage 2 (Gradient extraction & projection): Compute per‑class logit gradients Φ^c for X̃; apply random projection *Q* → Φ̃^c ∈ ℝ^{m×k}.  
- Stage 3 (Local‑global gradient distillation): Algorithm 1 operates on the average class kernel K̄ derived from Φ̃ to produce a synthetic gradient set (Φ̂, Ŷ) of size *s*.  
- Stage 4 (KRR): Train coefficients α from (Φ̂, Ŷ); at test time, compute projected gradient for *x*⁎ and predict via inner products with Φ̂.

**Critical path**  
The most expensive steps are: (1) WMDD optimization (many inner/outer iterations), (2) computing full Jacobians for *m* examples (O(mP)), (3) SVD in Algorithm 1 (O(m³)), and (4) solving the KRR system (O(s³)). Gradient projection and kernel evaluations are comparatively cheap.

**Design tradeoffs**  
- *Distilled set size m*: Larger *m* improves subspace coverage but increases later costs.  
- *Projection dimension k*: Smaller *k* reduces storage and inner‑product cost but may increase JL error.  
- *Cluster count H and thresholds τ_v, τ_g*: Larger *H* captures finer cluster structure but may increase synthetic set size *s*; thresholds control how many directions are considered gaps.  
- *Synthetic set size s*: Directly impacts KRR cost and accuracy; *s* should be as small as possible while maintaining fidelity.

**Failure signatures**  
- *Poor subspace coverage*: Low fidelity between DNTK and full NTK on a held‑out set (<90%) suggests Stage 1 failed.  
- *Ill‑conditioned kernel*: Condition number of K̂ exceeding 1e10 indicates over‑compression or numerical instability.  
- *Excessive gap directions*: If the gap set *G* becomes large (comparable to *m*), the intended compression is lost.  
- *Random projection collapse*: Projected gradients with near‑zero variance in many dimensions imply *k* is too small.

**First 3 experiments**  
1. Quantify data redundancy by computing singular values of a class‑wise NTK for a subset and reporting truncation rank at a 5% variance threshold.  
2. Validate the local‑global structure by replicating Figure 4: for each cluster, plot fraction of local variance captured by the first *r* global PCs, and plot global variance uncovered by any cluster.  
3. Perform an end‑to‑end accuracy vs. compression study: vary *m*, *k*, and thresholds, record test accuracy, MSE, and fidelity relative to full NTK, and compare against random and leverage baselines.

## Limitations
- The underlying lazy training assumption (fixed reference parameters) may not hold for networks that have moved far from initialization, invalidating the tangent subspace approximation.  
- Dataset distillation quality is highly dependent on the bilevel optimization succeeding; failure to produce a distilled set that spans the principal gradient directions leads to substantial approximation error.  
- The observed low effective rank of NTK (31–41) on ImageNette/ResNet‑18 might not extend to other architectures or datasets, limiting the achievable compression gains.
