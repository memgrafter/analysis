# Fully Kolmogorov-Arnold Deep Model in Medical Image Segmentation

## Quick Facts
- **arXiv ID:** 2602.03156
- **Source URL:** https://arxiv.org/abs/2602.03156
- **Reference count:** 29
- **Primary result:** Introduces ALL U-KAN, the first fully Kolmogorov-Arnold-based deep model for medical segmentation, which outperforms partial KAN and traditional models while reducing parameters by 10× and memory by over 20× versus directly stacked KANs.

## Executive Summary
Deep Kolmogorov-Arnold networks (KANs) have been limited to shallow architectures due to prohibitive parameter counts and memory consumption during training. This paper presents ALL U-KAN, the first fully KA-based deep model capable of replacing every fully connected and convolutional layer in a U-Net architecture. Two key innovations enable this: Share-activation KAN (SaKAN), which simplifies parameterization and increases training samples per function using Sprecher’s KA variant; and Grad-Free Spline, which detaches spline basis gradients to drastically reduce memory without harming accuracy. Evaluated on three medical segmentation datasets (BUSI, GlaS, CVC), ALL U-KAN achieves superior Intersection-over-Union (IoU) and F1-scores compared to partial KAN baselines and conventional models, demonstrating that KA-inspired layers can be scaled to deep, practical vision models.

## Method Summary
The core innovations are SaKAN and Grad-Free Spline. SaKAN reparameterizes the KA representation by sharing a single univariate spline activation function across all input dimensions for each output, reducing parameters from O(n_in · n_out · n_spline) to O(n_out · n_spline) and increasing the number of training samples contributing to each function’s gradient. Grad-Free Spline modifies the backward pass: the spline basis values are computed normally in the forward pass, but their gradients are detached during backpropagation. This avoids storing the computational graph for the de Boor-Cox algorithm, cutting memory use while relying on the dominant gradient signal from the linear residual connection. These components are embodied in two layer types: the KA layer (fully connected replacement) and the KAonv layer (convolutional replacement, which unfolds patches and applies a KA layer). All layers in a U-Net-style encoder-decoder are replaced with KA/KAonv blocks, forming ALL U-KAN, trained with Adam, a combined BCE-Dice loss, and cosine learning rate decay.

## Key Results
- **IoU improvements on medical segmentation datasets:** BUSI 66.14% vs. 63.38% (U-KAN), GlaS 88.72% vs. 87.64%, CVC 85.37% vs. 85.05%.
- **Efficiency gains:** Compared to naively stacked KANs, ALL U-KAN reduces parameter count by 10× and GPU memory consumption by over 20×.
- **Superiority over partial KANs:** Outperforms U-KAN, ProKAN, and KM-UNet across all three benchmarks.

## Why This Works (Mechanism)
### Mechanism 1: SaKAN Simplifies Deep KAN Training
SaKAN, based on Sprecher’s KA variant, shares one activation function ϕ_i across all input dimensions for each output, reducing the number of learnable univariate functions from n_in · n_out to n_out. Each shared ϕ_i is evaluated on all n_in inputs per sample, increasing training samples per function from 1 to n_in. This simplified parameterization and denser gradient signal ease optimization. Theoretically, Sprecher’s variant supports this sharing without loss of representational power if certain coefficients (λ_j) are set to 1. Evidence: The paper derives the parameter reduction in Section 3.1.1–3.1.2 and notes better optimization in the abstract. The break condition is if shared activations cannot capture dimension-specific interactions, causing underfitting.

### Mechanism 2: Grad-Free Spline Slashes Memory
Grad-Free Spline detaches the computational graph of spline basis functions B_k(x) during backpropagation. The forward pass computes B_k(x) normally, but the backward pass ignores gradients through B_k(x), computing updates for spline coefficients using only forward-pass values. This avoids storing intermediate states of the de Boor-Cox algorithm, which otherwise scales poorly with depth. The approach assumes spline gradients are negligible compared to those from the linear residual term b(x), justified by local support, sparsity, and cancellation effects. Evidence: Theorem 1 proves detachment does not affect optimization; Figure 3b shows spline gradient magnitudes are much smaller than residual gradients. Break condition: Tasks relying on high-order derivative information through splines may degrade.

### Mechanism 3: Combined Innovations Enable Fully KA Deep Networks
SaKAN reduces per-layer parameters to be comparable to a standard FC layer (O(n_in·n_out + n_out·n_spline)), while Grad-Free Spline prevents memory from scaling with depth by eliminating spline gradient storage. Together, they make deep KA architectures feasible, allowing replacement of all FC and Conv layers. The ALL U-KAN architecture (31 KAonv + 12 KA layers) leverages the expressive univariate functions in every layer. Evidence: The paper’s Table 2 shows parameter counts (~3.17M) and memory use, and Section 4 reports consistent IoU/F1 gains over partial-KAN and traditional baselines. Break condition: If the KA inductive bias is mismatched to the data (e.g., insufficient translational invariance), or if spline evaluation overhead becomes prohibitive at scale.

## Architecture Onboarding
Component map: SaKAN Layer (FC replacement) -> KAonv Layer (Conv replacement via patch unfolding) -> ALL U-KAN (U-Net assembly of KA/KAonv blocks)

Critical path:
1. Implement a vanilla KAN layer following the original equations to establish a baseline.
2. Modify to SaKAN by changing activation application from per-input-output pairs (ϕ_i,j) to shared per-output (ϕ_i) across all inputs.
3. Add Grad-Free Spline by detaching spline basis gradients during the backward pass; verify peak memory drops.
4. Implement KAonv by applying a convolution to unfold spatial patches into a feature dimension, then processing with a SaKAN layer.
5. Assemble ALL U-KAN by replacing every FC and Conv in a reference U-Net with KA/KAonv blocks, matching channel dimensions.

Design tradeoffs:
- Parameter count vs. sample efficiency: SaKAN’s sharing reduces parameters but may lose dimension-specific interactions.
- Memory vs. potential gradient information: Grad-Free Spline saves memory but discards spline derivative signals assumed negligible.
- Theoretical purity vs. engineering practicality: SaKAN simplifies Sprecher’s variant (e.g., λ_j=1), possibly reducing theoretical coverage but improving generalization and memory.

Failure signatures:
- Out-of-memory (OOM) at low depth: Indicates Grad-Free Spline not applied correctly; spline gradients still stored.
- NaNs or unstable early loss: SaKAN’s shared activation may fail to converge; check learning rate or add residual connections.
- Performance worse than MLP/U-Net baseline: KA inductive bias mismatch or incorrect implementation; verify partial-KAN (U-KAN) performs better to isolate the “fully replaced” issue.
- Extremely slow training: Spline operations (even without gradients) are slower than matmuls; profile time in spline basis computation.

First 3 experiments:
1. **Synthetic validation:** Train a 2-layer network (e.g., [256,128,1]) on a simple bivariate function (e.g., f(x1,x2)=sin(x1)+cos(x2)). Compare vanilla KAN, SaKAN, and a parameter-matched MLP. Monitor final loss and gradient norms per parameter to confirm stable training and adequate capacity.
2. **Memory benchmark:** On MNIST, train a 5-layer KAN model with standard backpropagation and with Grad-Free Spline. Record peak GPU memory (torch.cuda.max_memory_allocated()) and test accuracy; expect >10× memory reduction and <0.5% accuracy drop.
3. **Smoke test:** Using 10% of the BUSI dataset, build a tiny ALL U-KAN (e.g., 2 encoder/decoder blocks) with inferred channel dimensions. Train for 50 epochs; verify no OOM, decreasing loss, parameter count near 3M, and ability to overfit the small subset.

## Open Questions the Paper Calls Out
1. **Accelerating spline computations:** Future work may speed up spline operations, which remain a training bottleneck even with Grad-Free Spline, via precomputation or parallelization.
2. **Representational capacity of SaKAN:** Does SaKAN’s shared activation preserve the full expressiveness of vanilla KANs when scaled to deep networks and applied to diverse vision tasks beyond medical segmentation?
3. **Depth scalability of ALL U-KAN:** How does network depth affect accuracy, memory, and training stability? Is there an optimal depth for medical segmentation, or a point of diminishing returns or degradation?

## Limitations
- **Incomplete architectural details:** Exact channel dimensions and precise layer ordering in ALL U-KAN’s 43 layers are not fully specified beyond a high-level diagram.
- **Missing spline hyperparameters:** Details of grid size beyond 5, order beyond 3, and the algorithmic implementation of chunk-wise computation are unclear.
- **Unstated training regimen:** Potential use of weight decay, dropout, or data augmentation is not documented, hindering exact replication.
- **Limited external validation:** SaKAN and Grad-Free Spline lack independent corroboration; corpus shows prior work focused on partial KAN models.
- **Generalizability concerns:** The assumption that spline gradients are negligible may not hold for all tasks or deeper architectures.

## Confidence
- **ALL U-KAN achieves superior segmentation accuracy** (IoU/F1 improvements on BUSI, GlaS, CVC): *Medium* – results are reported but not independently verified; baseline comparisons may lack statistical rigor.
- **SaKAN reduces parameters and increases training samples per function** via Sprecher-based sharing: *Medium* – theoretical derivation appears sound, but empirical support is limited to the paper’s own experiments.
- **Grad-Free Spline drastically reduces memory with negligible accuracy impact**: *Medium* – memory savings are demonstrated and gradient magnitudes shown small, yet cross-task generalizability is unproven.
- **ALL U-KAN is the first fully KA-based deep model**: *High* – literature search reveals no prior work replacing all FC and Conv layers with KA components.
