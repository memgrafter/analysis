# Invariance-Based Dynamic Regret Minimization

## Quick Facts
- **arXiv ID:** 2603.03843  
- **Source URL:** https://arxiv.org/abs/2603.03843  
- **Reference count:** 40  
- **Primary result:** Regret scales with residual subspace dimension \(p_{\text{res}}\) rather than full dimension \(p\) through invariant subspace decomposition.

## Executive Summary
The paper tackles stochastic non-stationary linear bandits where the reward parameter drifts over time. Instead of discarding old data, the authors propose ISD-linUCB, which decomposes the feature space into an invariant subspace (where the parameter is stationary) and a residual subspace (where it varies). Using all offline data, they estimate the stationary component and its confidence set, while online data adapt only to the residual component. The theoretical analysis shows that regret scales with the residual dimension \(p_{\text{res}}\), yielding significant improvements when a large invariant subspace exists and sufficient offline data is available. Empirical results confirm sublinear regret and near-oracle performance as offline data grows.

## Method Summary
ISD-linUCB operates in two phases. First, an offline phase processes \(T_0\) logged trajectories to estimate an invariant subspace \(\mathcal{S}_{\text{inv}}\) via joint block diagonalization of windowed covariance matrices. It also obtains a ridge regression estimate \(\hat{\beta}_{\text{inv}}\) of the stationary parameter using all offline data projected onto \(\mathcal{S}_{\text{inv}}\). Second, during the online phase, the algorithm maintains a confidence set \(\hat{\mathcal{C}}_\beta\) around \(\hat{\beta}_{\text{inv}}\) and, at each round, estimates a residual parameter \(\hat{\delta}^{\text{res}}_t\) in the complementary subspace \(\mathcal{S}_{\text{res}}\) using recent data. Action selection maximizes the upper confidence bound over the combined parameter set \(\hat{\mathcal{C}}_\beta \oplus \hat{\mathcal{C}}_{\delta,t}\). This separation reduces the effective dimensionality for exploration from \(p\) to \(p_{\text{res}}\).

## Key Results
- Regret bound: \(\tilde{O}(p_{\text{res}} \sqrt{T})\) under invariant subspace decomposition assumptions and sufficient offline data.
- Empirical cumulative regret grows sublinearly and depends on \(p_{\text{res}}\), approaching the oracle lower bound as \(T_0\) increases.
- The method outperforms standard LinUCB, especially when the invariant subspace dimension \(p_{\text{inv}} = p - p_{\text{res}}\) is large.

## Why This Works (Mechanism)

**Mechanism 1: Invariant Subspace Decomposition (ISD)**  
The reward parameter \(\gamma_{0,t}\) is decomposed into a stationary component \(\beta_{\text{inv}}\) and a time-varying residual \(\delta^{\text{res}}_t\). The feature space is partitioned into orthogonal subspaces \(\mathcal{S}_{\text{inv}}\) and \(\mathcal{S}_{\text{res}}\). This allows using all offline data to learn \(\beta_{\text{inv}}\) (since it is constant) while only recent online data is needed for \(\delta^{\text{res}}_t\). The decomposition relies on Assumption 1: there exists a non-degenerate partition such that \(\gamma_{0,t} = \beta_{\text{inv}} + \delta^{\text{res}}_t\) and the projected features are uncorrelated.

**Mechanism 2: Dual Confidence Sets**  
Separate confidence sets are constructed: \(\hat{\mathcal{C}}_\beta\) around \(\hat{\beta}_{\text{inv}}\) using all \(T_0\) observations, and \(\hat{\mathcal{C}}_{\delta,t}\) around \(\hat{\delta}^{\text{res}}_t\) using data since the last subspace update. The combined set \(\hat{\mathcal{C}}_\beta \oplus \hat{\mathcal{C}}_{\delta,t}\) yields an uncertainty quantification that leverages the precision from abundant offline data for the invariant part. Assumption 2 ensures the offline covariance matrix is well-conditioned, guaranteeing a tight \(\hat{\mathcal{C}}_\beta\).

**Mechanism 3: Dimensionality Reduction in Exploration**  
The LinUCB UCB bonus depends on \(\|\phi_t\|_{\Sigma^{-1}}\), where \(\Sigma\) is the aggregated covariance of the parameter estimates. Because uncertainty in \(\hat{\beta}_{\text{inv}}\) becomes negligible with large \(T_0\), the effective dimension in \(\Sigma\) reduces to \(p_{\text{res}}\). This is reflected in the regret bound, which replaces the full dimension \(p\) with \(p_{\text{res}}\). However, the benefit is contingent on accurate subspace estimation; subspace estimation error incurs an extra term \(\sqrt{p_{\text{res}} T / (\lambda_0 T_0)}\) (Assumption 3), so \(T_0\) must be large enough for the gains to dominate.

## Architecture Onboarding

**Component map**  
Offline Manager → Subspace Estimator → Invariant Learner → (Online loop: Residual Learner ↔ Policy Selector). More precisely:
- Offline Manager ingests \(T_0\) trajectories and computes windowed covariance matrices.
- Subspace Estimator applies joint block diagonalization to output \(\hat{\mathcal{S}}_{\text{inv}}, \hat{\mathcal{S}}_{\text{res}}\).
- Invariant Learner regresses \(\hat{\beta}_{\text{inv}}\) on all offline data projected onto \(\hat{\mathcal{S}}_{\text{inv}}\) and constructs \(\hat{\mathcal{C}}_\beta\).
- Residual Learner updates \(\hat{\delta}^{\text{res}}_t\) using recent online data projected onto \(\hat{\mathcal{S}}_{\text{res}}\) and constructs \(\hat{\mathcal{C}}_{\delta,t}\).
- Policy Selector computes UCB for each action by maximizing over \(\hat{\mathcal{C}}_\beta \oplus \hat{\mathcal{C}}_{\delta,t}\) and selects the action.

**Critical path**  
Offline preprocessing → Subspace estimation → Invariant parameter learning → (Online: Residual update → Dual confidence set construction → UCB maximization) repeated each round.

**Design tradeoffs**
- *Offline data size \(T_0\) vs. computational cost*: Larger \(T_0\) improves subspace estimation and tightens \(\hat{\mathcal{C}}_\beta\) but increases memory and computation (covariance and diagonalization cost \(O(p^2 T_0)\)).
- *Recomputation frequency*: Subspaces could be re-estimated periodically to adapt to slow changes in invariance structure, but this adds overhead and may destabilize learning.
- *Regularization \(\lambda\)*: Too small leads to overfitting in residual space; too large blurs distinctions between subspaces and may over-shrink \(\hat{\beta}_{\text{inv}}\).

**Failure signatures**
1. **High misalignment error**: \(\|\Pi_{\mathcal{S}_{\text{inv}}} - \Pi_{\hat{\mathcal{S}}_{\text{inv}}}\|\) remains large even with large \(T_0\). Indicates poor offline exploration or violation of Assumption 2.
2. **Invariant confidence set inflation**: \(\hat{\mathcal{C}}_\beta\) does not shrink as \(T_0\) increases. Suggests \(\beta_{\text{inv}}\) is not stationary (Assumption 1 violation) or numerical instability in matrix inversion.
3. **Residual regret comparable to LinUCB**: Cumulative regret scales with \(p\) rather than \(p_{\text{res}}\), implying \(p_{\text{inv}} \approx 0\) (subspace estimation failed to detect invariance) or that the residual component dominates.

**First 3 experiments**
1. *Oracle S_inv/S_res benchmark*: Fix true subspaces, vary \(p_{\text{res}}\) while holding \(p\) and \(p_{\text{inv}}\) constant. Validate that cumulative regret of oracle ISD-linUCB scales ~\(p_{\text{res}}\sqrt{T}\) and is independent of \(p\) for fixed \(p_{\text{res}}\).
2. *Estimated subspaces convergence*: For fixed \(p_{\text{inv}}, p_{\text{res}}\), increase offline data \(T_0\). Measure projection error \(\|\Pi - \Pi_{\text{hat}}\|\) and the regret gap between full ISD-linUCB and oracle. Verify error decays as \(1/\sqrt{T_0}\) and regret approaches oracle lower bound.
3. *Sensitivity to change in S_inv*: Introduce a small perturbation to \(\beta_{\text{inv}}\) after time \(\tau_{\text{break}} > T_0\). Compare regret of ISD-linUCB (fixed \(\hat{\beta}_{\text{inv}}\)) vs. a variant that re-learns \(\beta_{\text{inv}}\). Tests robustness to violation of stationarity (Assumption 1).

## Open Questions the Paper Calls Out
1. **How can one test for the existence of an invariant subspace decomposition in real-world non-stationary bandit problems?**  
   The algorithm assumes such a decomposition but gives no method to verify it. Without confirmation, applying ISD-linUCB risks poor performance if the assumption fails. Developing statistical diagnostics (e.g., tests for orthogonality of time-averaged feature projections or model selection criteria for \(p_{\text{inv}}\)) using offline data would be valuable.

2. **What is the impact on regret if the offline data collection policy does not satisfy Assumption 2's exploration requirement?**  
   Assumption 2 demands that the offline policy ensures the regularized covariance matrix is strictly positive definite. However, many practical offline datasets come from arbitrary, possibly non-exploratory policies, which may violate this condition. Understanding the robustness and analyzing performance under such weak exploration (possibly via importance sampling) is an open problem.

3. **Can the theoretical regret analysis be extended to cases where the reward parameter changes during the online phase?**  
   The paper’s regret bound (Setting 1) assumes the reward parameter \(\gamma_{0,t}\) is constant for \(t \in [T]\). In reality, non-stationarity may persist online. Extending the analysis to handle dynamic changes (e.g., via sliding windows or discounting) while retaining the \(p_{\text{res}}\) scaling remains unresolved.

4. **Is the invariance-based decomposition concept applicable to non-linear contextual bandits or general function approximation settings?**  
   The current work is restricted to linear models and finite-dimensional parameters. The linear algebraic tools (orthogonal projections, joint diagonalization) may not generalize to non-linear settings. Investigating kernelized or representation-learning extensions where invariances are captured in latent spaces is an open direction.

## Limitations
- **Joint diagonalization opacity**: The method (Lazzaretto et al., 2025) for estimating subspaces is not described, making implementation uncertain and sample complexity unclear.
- **Feature mapping ambiguity**: The mapping from context \(X_t\) to arm features \(\phi(X_t, a)\) for multi-arm settings is unspecified; our simplified orthogonal construction may not replicate the paper’s experiments.
- **Hyperparameter sensitivity**: Confidence parameters (\(\lambda, \eta, L, M, \lambda_0\)) are not provided; improper tuning could invalidate theoretical guarantees.
- **Assumption fragility**: The core ISD assumptions (stationary \(\beta_{\text{inv}}\), uncorrelated projections, sufficient offline exploration) may not hold in practice, potentially causing the algorithm to underperform or fail.

## Confidence
- **Regret scales with \(p_{\text{res}}\)**: *Medium*. The proof relies on accurate subspace decomposition and bounded errors; if assumptions fail, the bound may not hold.
- **Oracle convergence with \(T_0\)**: *Medium*. Empirical evidence suggests convergence, but exact reproduction requires precise implementation of subspace estimation.
- **Subspace estimability via joint diagonalization**: *Low–Medium*. The method’s details are missing; error behavior and noise sensitivity are uncertain.
