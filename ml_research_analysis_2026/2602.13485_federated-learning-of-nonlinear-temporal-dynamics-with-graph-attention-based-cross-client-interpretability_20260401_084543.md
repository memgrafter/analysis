# Federated Learning of Nonlinear Temporal Dynamics with Graph Attention-based Cross-Client Interpretability

## Quick Facts
- **arXiv ID:** 2602.13485
- **Source URL:** https://arxiv.org/abs/2602.13485
- **Reference count:** 40
- **Primary result:** The proposed federated framework attains server loss 0.0024 on the HAI industrial dataset, reduces average client prediction loss by 40.67% over proprietary models, and achieves Jacobian cosine similarity of 0.7277 with a centralized baseline, all while preserving client privacy and model fixedness.

## Executive Summary
This paper tackles the problem of learning cross-client temporal interdependencies in federated nonlinear dynamical systems where each client possesses a fixed proprietary model (e.g., an Extended Kalman Filter) and heterogeneous observations. The framework lets clients compute low-dimensional latent states locally; these are augmented with learnable functions and sent to a central server. The server models the system-wide state transition as a Graph Attention Network (GAT) over the communicated latent states, using a known graph skeleton. The Jacobian of the learned transition function is analytically linked to the attention coefficients, providing interpretability of directed temporal influence. Theoretical analysis shows convergence to a centralized oracle. Experiments on synthetic data confirm that the server recovers ground-truth dependencies and that attention aligns with Jacobian-based influence. On a real-world industrial dataset (HAI), the method significantly improves client prediction performance while maintaining privacy and without altering proprietary models.

## Method Summary
The method operates in alternating federated rounds. Each client first runs its fixed proprietary dynamics model (e.g., EKF or LSTM) to obtain predicted and estimated latent states. A learnable augmentation Δₘ is applied to these states to produce augmented latent states, which are then propagated by the client’s fixed local transition function fₘ. The client sends its corrected latent states (from the EKF) and its propagated augmented states to the server. The server aggregates the received latent states from all clients using a Graph Attention Network with a predefined adjacency matrix, producing server-predicted states for each client. A mean-squared error loss between the server predictions and the clients’ augmented propagated states drives updates. The server backpropagates the loss to obtain gradients with respect to the augmented states and sends them to the corresponding clients. Each client uses these gradients together with its local reconstruction loss to update the parameters of Δₘ, while keeping its proprietary model fixed. The server updates its GAT parameters via Adam. This process allows the server to learn a global state-transition model that captures cross-client temporal dependencies without requiring clients to share raw data or modify their core models.

## Key Results
- Server loss on HAI dataset: **0.0024**.
- Average client prediction loss reduced by **40.67%** compared to using only proprietary models.
- Jacobian cosine similarity between learned server model and a centralized baseline: **0.7277**, indicating strong alignment with ground truth influence.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Clients can incorporate cross-client temporal dependencies without altering their fixed proprietary EKF models by learning a local augmentation function on top of the EKF’s latent states.
- **Mechanism:** Each client uses its proprietary EKF to produce corrected state estimates. A learnable nonlinear mapping Δₘ is applied to these states, yielding augmented states that evolve under a separate transition. The server computes gradients of its loss with respect to the augmented states and sends them to clients, which update Δₘ’s parameters.
- **Core assumption:** The EKF’s latent states are sufficiently accurate to serve as a foundation and the client can compute gradients for Δₘ.
- **Evidence anchors:** Abstract: "Each client maps high-dimensional local observations to low-dimensional latent states using a nonlinear state-space model." Section 5.1: Eq. (12)–(16) and Assumption 5.1 describe augmentation and updates.
- **Break condition:** If the EKF produces poor latent estimates or Δₘ lacks capacity, augmented states fail to capture cross-client effects.

### Mechanism 2
- **Claim:** A central server can learn a global state-transition model that captures cross-client temporal interdependencies by representing the clients as a graph and using a Graph Attention Network, despite heterogeneous observations and fixed client models.
- **Mechanism:** The server aggregates communicated latent states from clients and applies a GAT with a predefined adjacency matrix to compute predicted states. The server loss (MSE between its predictions and clients’ augmented predictions) drives GAT parameter updates via backpropagation.
- **Core assumption:** The graph skeleton (adjacency) is known a priori and the server-side transition can be expressed as a GAT.
- **Evidence anchors:** Abstract: "A central server learns a graph structured neural state-transition model over the communicated latent states using a Graph Attention Network." Section 5.2: Eq. (17) and note on known adjacency.
- **Break condition:** Incorrect adjacency or distribution shift in latent states leads to spurious dependencies.

### Mechanism 3
- **Claim:** In the learned nonlinear server model, directed temporal interdependencies between clients are interpretable via the Jacobian of the transition function, which is analytically tied to attention coefficients.
- **Mechanism:** For each client pair (m,n), the Jacobian block Jₘₙ(t) = ∂(ℎ̃ˢₘ,ₜ)/∂(ĥᶜₙ,ₜ₋₁) quantifies influence. Proposition 6.1 derives a closed-form expression linking Jₘₙ to attention coefficients αₘₙ, weight matrices, and derivatives of attention scores.
- **Core assumption:** Activation σ and attention mechanism are differentiable; Jacobians are bounded in operating regime.
- **Evidence anchors:** Abstract: "For interpretability we relate the Jacobian of the learned server-side transition model to the attention coefficients..." Section 6: Proposition 6.1.
- **Break condition:** Saturated attention scores (near 0/1) cause vanishing derivatives, making Jacobian unstable or uninformative.

## Architecture Onboarding

**Component map**

Client side: Proprietary EKF (fixed) → latent states (ĥᶜ, ℎ̃ᶜ) → Augmentation Δₘ (learnable) → ĥᵃ → local transition fₘ (fixed) → ℎ̃ᵃ → send (ĥᶜ, ℎ̃ᵃ) to server.

Server side: Receive (ĥᶜ, ℎ̃ᵃ) from all clients → compute ℎ̃ˢ via GAT over neighbors’ ĥᶜ → compute loss Lₛ = (1/T) Σₜ Σₘ ||ℎ̃ˢₘ,ₜ − ℎ̃ᵃₘ,ₜ||² → backpropagate to get ∇_{ℎ̃ᵃ} Lₛ → send gradients to clients. Server updates GAT parameters (α, W).

**Critical path**

1. Client runs EKF on local observations to get (ĥᶜ).  
2. Client computes ĥᵃ = ĥᶜ + Δₘ(yₜ₋₁; θₘ).  
3. Client evolves ℎ̃ᵃ = fₘ(ĥᵃₜ₋₁).  
4. Client sends (ĥᶜ, ℎ̃ᵃ) to server.  
5. Server computes ℎ̃ˢ for each client using GAT on neighbors’ (ĥᶜ).  
6. Server computes Lₛ across time and clients.  
7. Server sends ∇_{ℎ̃ᵃ} Lₛ to each client.  
8. Client updates θₘ using local and server gradients.  
9. Repeat.

**Design tradeoffs**
- Fixed EKF limits expressiveness but preserves privacy/IP; augmentation adds minimal overhead.
- GAT requires known adjacency; incorrect skeleton forces wrong dependencies.
- Communication cost scales with number of clients and latent dimension; experiments show manageable overhead.
- Privacy-utility trade-off: noise injection yields robustness at low noise but sharp degradation at high noise.

**Failure signatures**
- Server loss fails to converge → check GAT initialization, learning rate, or adjacency.
- Attention coefficients remain uniform or Jacobian norms explode → nonlinear dynamics unstable or saturation.
- Client augmentation does not reduce local loss → cross-client learning not benefiting local task.
- High attention residuals on synthetic data → server not recovering ground truth structure.

**First 3 experiments**
1. **Synthetic validation:** Uses ground-truth GAT to show server learns attention close to oracle, Jacobian aligns, and attention-Jacobian correlation holds.
2. **Real-world HAI dataset:** Compares against proprietary, centralized, pre-trained, and NOTEARS-ADMM baselines; demonstrates loss reduction and Jacobian similarity to centralized.
3. **Privacy analysis:** Adds Gaussian noise to communications and measures server loss, illustrating trade-off.

## Open Questions the Paper Calls Out

1. **Graph skeleton discovery:** How can the unknown graph skeleton (adjacency matrix) be learned in a federated setting for nonlinear temporal dynamics without prior structural knowledge? The framework assumes a known skeleton, which may be unavailable in practice. Resolving this would require integration with causal or structure discovery methods.
2. **Robust Jacobian interpretability:** How can Jacobian-based interpretability be made robust for highly nonlinear dynamics where first-order approximations become unreliable? Under strong nonlinearities, Jacobians can vary dramatically across states, weakening the empirical correlation between attention coefficients and influence magnitude. Higher-order or alternative interpretability measures are needed.
3. **Differential privacy guarantees:** Can formal differential privacy (DP) guarantees be incorporated into the federated learning of temporal dynamics without severely compromising utility? The paper uses Gaussian noise injection but provides no formal privacy accounting, limiting deployment in sensitive domains.

## Limitations
- The method requires a predefined graph adjacency matrix, which may be unknown or need to be learned; the paper does not address how to discover it in a federated manner.
- There is a discrepancy between the synthetic experiments (using EKF-based clients) and the real-world HAI experiments (using pretrained LSTMs as proprietary models), which hampers direct comparison and generalizability.
- Real-world validation is limited to a single industrial dataset; the framework’s performance across diverse domains remains unproven.

## Confidence
- **Cross-client learning with fixed client models:** High (theoretical convergence proof, strong synthetic alignment, 40.67% loss reduction).
- **Interpretability via Jacobian-attention relation:** Medium (cosine similarity 0.7277 on HAI, moderate synthetic correlation, but no multi-domain verification).
- **Scalability and privacy-utility trade-off:** Medium (shown for small latent dimensions; privacy analysis limited to additive Gaussian noise without formal guarantees).

## Next Checks
1. **Adjacency sensitivity:** Evaluate server GAT performance with varying adjacency configurations (learned, fully connected, sparse true) on synthetic and HAI data to quantify effects on loss and attention-Jacobian correlation.
2. **Cross-dataset generalization:** Replicate the entire pipeline on at least two additional federated dynamical datasets (e.g., smart grid, IoT sensor networks) to test robustness of the reported utility gains.
3. **Jacobian stability analysis:** Systematically sweep activation nonlinearities and attention temperature on synthetic data; measure Jacobian-attention correlation to define safe operating regimes and identify failure modes.
