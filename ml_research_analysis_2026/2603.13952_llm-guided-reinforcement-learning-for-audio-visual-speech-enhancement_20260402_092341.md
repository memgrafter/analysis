# LLM-Guided Reinforcement Learning for Audio-Visual Speech Enhancement

## Quick Facts
- **ArXiv ID:** 2603.13952
- **Source URL:** https://arxiv.org/abs/2603.13952
- **Reference count:** 0
- **Primary result:** LLM-guided RL improves perceptual quality in AVSE, achieving PESQ 1.57 and NISQA MOS 1.29 on AVSEC-4, with 96.7% subjective preference over baseline.

## Executive Summary
Audio-visual speech enhancement (AVSE) typically optimizes for metrics like SI-SNR or MSE, which poorly align with human perception. This work introduces a reinforcement learning (RL) framework where a frozen large language model (LLM) generates natural language assessments of enhanced speech, which a sentiment analysis model converts into a 1-5 rating score. This score serves as the reward for proximal policy optimization (PPO) to fine-tune a pretrained AVSE model, using relative improvement over the base. On the AVSEC-4 test set, the approach outperforms supervised and DNSMOS-based RL baselines on objective metrics (PESQ 1.57, NISQA MOS 1.29) and achieves strong subjective preference (96.7% vs. baseline, 67.6% vs. DNSMOS RL). The LLM-generated textual feedback additionally provides interpretable explanations for quality changes.

## Method Summary
The method builds upon a pretrained AVSE model treated as the base policy. During RL fine-tuning, the current policy generates enhanced speech from noisy audio-visual inputs. A frozen LLM is prompted with the enhanced speech to produce a textual quality assessment. A sentiment analysis module maps this text to a scalar reward between 1 and 5. PPO updates the AVSE policy to maximize this reward, but the training signal is defined as the relative improvement of the reward compared to the base policy’s reward, mitigating absolute reward biases. This loop iterates, gradually improving the model’s perceptual output as judged by the LLM.

## Key Results
- **Objective metrics on AVSEC-4:** PESQ 1.57 (vs. 1.45 supervised baseline, 1.54 DNSMOS RL), NISQA MOS 1.29.
- **Subjective preference:** 96.7% preferred over the supervised baseline, 67.6% preferred over the DNSMOS RL method in A/B tests.
- **Interpretability:** LLM outputs include natural language explanations (e.g., reduced noise, less distortion) that highlight specific improvements.

## Why This Works (Mechanism)
The core mechanism leverages the LLM’s ability to understand and articulate nuanced aspects of speech quality that traditional metrics ignore. By generating free-text evaluations, the LLM acts as a surrogate for human perception, capturing factors like naturalness, artifact presence, and clarity. The sentiment analysis step condenses this into a numeric reward while preserving the LLM’s judgment. Using relative improvement (current policy reward minus base policy reward) focuses learning on perceptual gains rather than absolute scores, making the reward more robust to LLM biases. The RL framework (PPO) then directly optimizes the AVSE model for this perceptual objective, leading to measurable improvements in both objective metrics and human preference. The frozen LLM avoids costly retraining and provides interpretable feedback, making the system both effective and explainable.

## Architecture Onboarding
### Component Map
Noisy Audio + Video -> Pretrained AVSE Model (base policy) -> Enhanced Speech -> LLM (text assessment) -> Sentiment Analyzer (score 1-5) -> Reward (relative improvement vs. base) -> PPO Update -> Updated AVSE Model

### Critical Path
The critical path involves: (1) current AVSE model producing enhanced speech; (2) LLM generating textual evaluation; (3) sentiment analysis producing reward; (4) PPO computing relative improvement; (5) updating AVSE model weights. Disruption at any stage (e.g., LLM failure, sentiment misclassification) directly impacts learning.

### Design Tradeoffs
- **Frozen LLM vs. Fine-tuned LLM:** Frozen reduces compute and preserves general knowledge, but may not adapt to speech-specific nuances; fine-tuning could improve relevance but increases cost and risk of overfitting.
- **Sentiment Analysis Simplification:** Mapping free text to a 1-5 score is efficient but discards nuanced feedback, potentially losing information that could guide learning.
- **Relative Improvement Reward:** Using difference from base policy stabilizes training by mitigating absolute reward bias, but the base policy must be reasonably good; a poor base could mislead.
- **Computational Cost:** LLM inference at every PPO step is expensive, limiting scalability and real-time applicability.

### Failure Signatures
- **LLM bias/inconsistency:** Rewards fluctuate widely for similar quality changes, causing unstable PPO updates.
- **Sentiment mapping errors:** Text that is objectively positive receives low scores, or vice versa, misguiding the policy.
- **Reward saturation:** The LLM may give similar scores for all enhanced samples, leading to vanishing gradient signals.
- **Base policy collapse:** If the RL policy diverges too far, relative rewards become meaningless or negative.

### First Three Experiments
1. **Baseline reward correlation:** Compute correlation between LLM+ sentiment scores and human MOS on a held-out set of enhanced samples to establish validity of the reward signal.
2. **Ablation - remove RL:** Apply supervised fine-tuning with the same reward (e.g., using MSE on predicted scores) to see if RL is necessary for the observed gains.
3. **Sensitivity to LLM prompt variation:** Test multiple prompt formulations to the LLM and measure variance in resulting rewards and final AVSE performance, assessing robustness to prompt design.

## Limitations
- LLM reward may be biased toward generic language understanding and not specialized for subtle speech quality distortions.
- The sentiment analysis step’s simplification to a 1-5 score can lose discriminative information and introduce noise.
- High computational cost due to LLM inference at every training step, hindering deployment and scalability.
- Evaluation limited to a single dataset (AVSEC-4), raising questions about generalization to other AVSE scenarios.

2. **Ablation of LLM and sentiment components** – Replace the LLM with a non-LLM quality estimator (e.g., DNSMOS) while keeping the RL pipeline, and vary the sentiment model to measure each component’s contribution.
3. **Reward-human alignment study** – Collect human MOS for a diverse set of enhanced samples and compute correlation with the LLM-derived reward; analyze error cases to understand misalignments.
