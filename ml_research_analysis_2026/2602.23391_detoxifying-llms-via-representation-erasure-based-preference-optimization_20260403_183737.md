# Detoxifying LLMs via Representation Erasure-Based Preference Optimization

## Quick Facts
- arXiv ID: 2602.23391
- Source URL: https://arxiv.org/abs/2602.23391
- Reference count: 37
- Primary result: REPO achieves state-of-the-art robustness in LLM detoxification, maintaining significantly lower toxicity under relearning and jailbreak attacks while preserving language modeling utility.

## Executive Summary
Large language models (LLMs) can still generate toxic content even after standard detoxification methods like DPO or NPO. These methods only superficially suppress toxicity, leaving harmful “directions” in the model’s internal representations that can be revived by fine-tuning or adversarial attacks. This paper introduces Representation Erasure-based Preference Optimization (REPO), which treats detoxification as a token-level preference problem. REPO combines a token-wise KL loss to preserve benign fluency on retained continuations with an adversarial loss that aligns the representations of toxic and non‑toxic tokens, using a discriminator with a gradient reversal layer. Evaluations on GPT‑2 and Gemma‑2B show that REPO not only reduces toxicity more effectively but also remains robust against relearning attacks, enhanced GCG jailbreaks, and orthogonalization attacks, all while keeping perplexity close to the original model. Mechanistic analysis reveals that REPO induces deep, localized edits to toxicity‑encoding neurons, unlike the diffuse changes caused by sequence‑level methods.

## Method Summary
REPO operates on paired data consisting of prompts, non‑toxic continuations (retain), and toxic continuations (forget). For each pair, the model processes both full sequences. The training objective has two token‑level components: (1) a KL anchoring loss between the edited model and a frozen reference model, computed only on retain sequences to preserve benign behavior; (2) an adversarial domain loss where a discriminator (a small MLP attached to a transformer layer) tries to classify each token representation as belonging to a retain or forget sequence, while the language model updates its parameters to fool the discriminator via a gradient reversal layer. This minimax game forces the model’s token representations to become indistinguishable between toxic and benign content, effectively erasing toxic features. The overall loss is a weighted sum: α·L_retain + (1−α)·L_dom, with α tuned to balance erasure and utility. Training uses full fine‑tuning for smaller models and LoRA for larger ones.

## Key Results
- REPO dramatically reduces toxicity after relearning: on GPT‑2 Medium, forget‑set toxicity after fine‑tuning on 10 forget samples is 0.169, versus 0.202 for NPO and 0.200 for DPO.
- Resists enhanced GCG jailbreaks: toxicity 0.208 (REPO) vs. 0.347 (NPO).
- Resists orthogonalization attacks: toxicity 0.308 (REPO) vs. 0.335 (NPO).
- Mechanistic analysis shows REPO produces localized edits to toxicity‑encoding neurons in later layers, while maintaining utility (perplexity near reference, comparable F1).

## Why This Works (Mechanism)
### Mechanism 1: Token‑level preference formulation
REPO defines a token‑wise objective that separately treats each token’s representation. The retain loss (token‑wise KL between the edited model and a frozen reference) preserves fluent, non‑toxic generation. The adversarial loss operates on the same granularity, aligning representations of toxic and non‑toxic tokens. This fine‑grained control allows the model to erase toxic features without affecting benign parts of the sequence.

### Mechanism 2: Adversarial representation alignment
A discriminator attached to a transformer layer receives token representations. Through a gradient reversal layer, the discriminator is trained to minimize binary cross‑entropy on domain labels (retain vs. forget), while the language model is trained to maximize that loss. This domain‑adversarial setup pushes the token representations toward a domain‑invariant space where toxic and benign tokens are indistinguishable, effectively removing the “toxic direction” from the internal states.

### Mechanism 3: Localized edits preserving utility
Because the discriminator processes each token independently, the resulting gradient signal is confined to positions that actually carry toxic content. Combined with the KL anchoring on retain sequences, this yields highly localized changes: mechanistic probes (cosine similarity drift) show that REPO modifies later layers only for toxic tokens, whereas baseline methods (DPO, NPO) make diffuse, lower‑magnitude edits across the network. This sparsity protects general language capabilities.

## Architecture Onboarding
#### Component map
Reference model (frozen) -> KL anchoring loss; LLM backbone (Gf feature extractor + Gy LM head) -> token representations at layer ℓ -> Gradient reversal layer (R) -> Discriminator (Gd) -> domain loss; Combined loss (αL_retain + (1−α)L_dom) updates LLM (via reversed gradients) and discriminator separately.

#### Critical path
1. Prepare triples (x_p, x_r, x_f); construct full sequences s_r=[x_p;x_r] and s_f=[x_p;x_f].
2. Forward pass both sequences through LLM; extract token representations h_t at chosen layer ℓ.
3. Compute L_retain: token‑wise KL(π_ref(s_r) || π_θ(s_r)).
4. Compute L_dom: pass h_t through R and Gd; binary cross‑entropy against domain labels (0 for s_r, 1 for s_f).
5. Backward pass: update discriminator parameters to minimize L_dom; update LLM parameters to minimize combined loss, with gradients from L_dom flipped by R (effectively maximizing L_dom w.r.t. LLM).
6. Repeat until convergence.

#### Design tradeoffs
- Granularity: Token‑level discrimination yields precise localization but can be noisy; segment‑level (pooled) is smoother but risks erasing useful features.
- Discriminator capacity: A small nonlinear MLP (e.g., hidden 16) balances expressivity and stability; too large may overfit or cause oscillations.
- Hyperparameter α: Higher α preserves utility; lower α strengthens erasure. Requires validation tuning.
- Layer ℓ selection: Using the final block maximizes influence on logits; shallower layers affect more generic features and may reduce erasure effectiveness.
- Reference model: Must be identical and frozen to anchor benign behavior; using a toxic reference could hinder preservation.

#### Failure signatures
- Discriminator accuracy remains high (>80%) on held‑out token representations, indicating insufficient alignment.
- Utility collapse: perplexity on retain set or WikiText‑2 increases substantially (e.g., >1.5× reference) or F1 drops sharply.
- Relearning vulnerability: After fine‑tuning on a few forget examples, toxicity returns to pre‑unlearning levels.
- Localization loss: Mechanistic heatmaps show broad drift across many tokens/layers instead of concentration on toxic tokens.
- Training instability: Losses diverge or oscillate; often due to mismatched learning rates between discriminator and LLM.

#### First 3 experiments
1. **Discriminator sanity check**: With the LLM frozen, train Gd alone on a small set of token representations. Verify it achieves >90% accuracy in distinguishing retain vs. forget tokens, confirming capacity.
2. **Localization visualization**: For a known toxic prompt, compute 1−cosine similarity between reference and REPO representations across layers and tokens. Expect high drift only in deeper layers and on toxic token positions.
3. **Utility‑unlearning Pareto sweep**: Vary α over a range (e.g., 0.05, 0.1, 0.2, 0.5). Measure toxicity on forget set and perplexity on retain. REPO should lie near the lower‑left frontier compared to baselines.

## Open Questions the Paper Calls Out
1. **Scalability to larger models**: Does REPO remain effective and efficient on 7B+ or instruction‑tuned models? The current evaluation is limited to GPT‑2 and Gemma‑2B due to computational constraints.
2. **Sensitivity to toxicity evaluator**: Would alternative toxicity detectors (Detoxify, human judgment) alter the reported performance? The paper uses Perspective API for comparability but acknowledges this limitation.
3. **Synthetic training data bias**: The pairwise dataset is generated with PPLM (toxic) and greedy (non‑toxic). Does this synthetic bias limit generalization to natural toxic language?
4. **Robustness under black‑box attacks**: The enhanced GCG attack assumes white‑box access to the reference model. It is unclear if REPO resists realistic black‑box jailbreaks.

## Limitations
- **Dataset unknowns**: Construction details of PairToxicity (prompts, sampling parameters) are not fully described, hindering exact reproduction.
- **Attack specifications**: The enhanced GCG and orthogonalization attacks lack precise hyperparameters and loss formulations, requiring assumptions.
- **Model scale**: Experiments are confined to small models (GPT‑2, Gemma‑2B); applicability to larger architectures remains untested.
