# Confounding Robust Continuous Control via Automatic Reward Shaping

## Quick Facts
- **ArXiv ID**: 2602.10305
- **Source URL**: https://arxiv.org/abs/2602.10305
- **Reference count**: 40  
- **Primary result**: Achieves normalized IQM return of 1.09 on confounded benchmarks, outperforming baselines (0.81–0.96); normalized mean return 1.29.

## Executive Summary
This paper introduces an automatic reward shaping method for continuous control reinforcement learning that remains robust in the presence of unobserved confounders in offline datasets. The core technique employs a causal Bellman equation to derive a tight upper bound on optimal state values from confounded data, then uses this bound as a potential function in potential-based reward shaping (PBRS). By construction, PBRS preserves optimal policies while the causal bound ensures robustness to confounding. Evaluations with Soft-Actor-Critic on MuJoCo and Adroit benchmarks under confounding show consistent improvements over unshaped and causally unaware baselines (CQL-Shaping, T-REX-Shaping), with normalized IQM return of 1.09 compared to baseline ranges of 0.81–0.96 and a normalized mean of 1.29.

## Method Summary
The method begins by learning an upper bound on the optimal state value function from a confounded offline dataset. This is achieved by solving a causal Bellman equation that accounts for unobserved confounders, yielding a conservative yet valid value estimate. This estimated bound serves directly as the potential function Φ in potential-based reward shaping, where the shaping reward is defined as F(s,s') = γΦ(s') – Φ(s). The shaped rewards are then used to train a policy (e.g., with Soft-Actor-Critic) in an offline RL setting. Because the potential function is derived from an upper bound that respects the causal structure, the shaping is robust to confounding yet retains the policy invariance property of PBRS, meaning any optimal policy under the shaped rewards is also optimal for the original MDP.

## Key Results
- Normalized interquartile mean (IQM) return of **1.09** vs baseline range **0.81–0.96**.
- Normalized mean return of **1.29**.
- Consistent outperformance of unshaped and causally unaware baselines (CQL-Shaping, T-REX-Shaping) across confounded MuJoCo and Adroit benchmarks.

## Why This Works (Mechanism)
The method works because it combines two key properties: (1) The causal Bellman equation provides an upper bound on optimal values that remains valid even when offline data is corrupted by unobserved confounders. This bound is learned in a way that accounts for the confounding structure, avoiding bias that would plague standard value estimation. (2) Using this bound as the potential function in potential-based reward shaping guarantees that any policy optimal under the shaped rewards is also optimal for the original MDP, provided the bound is indeed an upper bound. Thus the shaping improves learning (by providing more informative rewards) without altering the set of optimal policies. The overall approach thus achieves robustness to confounding while preserving the fundamental goal of policy invariance.

## Foundational Learning
- **Confounding**: Unobserved variables that influence both actions and rewards, causing bias in standard offline RL. *Why needed*: Offline datasets often contain such biases, leading to poor policy performance if ignored. *Quick check*: In a dataset of robot movements, if a hidden obstacle influences both the chosen action and the received reward, that obstacle is a confounder.
- **Causal Bellman equation**: Extension of the Bellman equation to causal graphical models that incorporate confounding. *Why needed*: Enables computation of value estimates that are resilient to confounders. *Quick check*: Can you write the standard Bellman equation and identify how a confounder would alter its terms?
- **Potential-Based Reward Shaping (PBRS)**: Technique that adds a shaping term F(s,s') = γΦ(s') – Φ(s) to rewards, preserving optimal policies if Φ is bounded. *Why needed*: Improves learning efficiency without changing the optimal solution. *Quick check*: If Φ(s) = V(s) (true value function), what is the effect on Q-learning updates?
- **Offline RL**: Reinforcement learning from a fixed dataset without additional environment interaction. *Why needed*: Essential for safety-critical or sample-limited applications. *Quick check*: What are the main challenges of offline RL compared to online RL? (e.g., distribution shift)
- **Continuous control**: Tasks with high-dimensional, continuous action spaces (e.g., MuJoCo). *Why needed*: Many real-world control problems require fine-grained continuous actions. *Quick check*: Why might discrete-action RL algorithms struggle on MuJoCo?
- **Upper bound on value**: A guaranteed conservative estimate of the maximum achievable return. *Why needed*: Serves as a robust potential function that respects the optimality preservation condition of PBRS. *Quick check*: How does using an upper bound (instead of exact value) affect the shaping term’s properties?

## Architecture Onboarding
**Component map**:  
Offline Dataset (confounded) → Causal Bellman Bound Estimator → Upper Bound V^ → Potential Function Φ = V^ → Potential-Based Reward Shaping → Shaped Rewards → Policy Training (SAC)

**Critical path**:  
1. Learn a tight upper bound V^ on the optimal value function from confounded offline data via the causal Bellman equation.  
2. Construct potential Φ from the bound.  
3. Apply PBRS to the dataset, generating shaped rewards.  
4. Train the policy (e.g., SAC) on the shaped rewards using offline RL.

**Design tradeoffs**:  
- Bound tightness vs. computational cost: Tighter bounds require more expressive models or iterative optimization, increasing compute.  
- Conservative vs. informative shaping: Overly loose bounds yield weak shaping signals; too tight bounds risk violating the upper bound property if misestimated, breaking invariance.  
- Causal model generality: The method assumes a specific confounding structure (e.g., additive noise); more general causal models may be needed for complex confounders.

**Failure signatures**:  
- The learned bound is excessively high (infinitely loose) → shaping provides no useful gradient.  
- Policy performance collapses when bound is not a valid upper bound (e.g., due to function approximation errors) → invariance guarantee breaks.  
- Offline dataset lacks adequate coverage of state-action distributions → bound becomes uninformative or overly optimistic, leading to poor policies.

**First experiments**:

2. Ablate bound quality by varying model capacity (e.g., network width) or regularization strength to assess sensitivity to bound tightness.  
3. Inject confounders of varying magnitudes (e.g., different noise levels) to evaluate robustness across confounding strengths.

## Limitations
- Bound tightness is sensitive to causal assumptions and function approximation; practical bounds may be loose.  
- Requires sufficient coverage in the offline dataset; severe confounding can render the bound uninformative or overly optimistic.  
- Evaluation limited to simulated MuJoCo and Adroit benchmarks; real-world confounding may introduce additional challenges.

## Confidence
- **Causal Bellman bound tightness**: Medium (theory solid but empirical tightness not fully verified)  
- **Policy invariance guarantee of PBRS**: High (standard RL result)  
- **Consistency of benchmark improvements**: Medium (evidence strong but limited by baseline selection and environment diversity)
