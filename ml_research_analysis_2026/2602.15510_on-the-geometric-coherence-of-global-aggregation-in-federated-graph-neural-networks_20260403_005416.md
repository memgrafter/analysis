# On the Geometric Coherence of Global Aggregation in Federated Graph Neural Networks

## Quick Facts
- arXiv ID: 2602.15510  
- Source URL: https://arxiv.org/abs/2602.15510  
- Reference count: 20  
- Primary result: GGRS improves mean accuracy by up to 0.022 and restores geometric coherence across six real‑world graph benchmarks.

## Executive Summary
Federated averaging of GNN parameters fails because GNNs define graph‑dependent message‑passing operators, not Euclidean vectors. Heterogeneous client graphs produce updates in incompatible operator tangent spaces, causing destructive interference and operator degeneration that standard accuracy metrics miss. We propose GGRS, a server‑side aggregation wrapper that uses a data‑free proxy (normalized parameter updates) to enforce geometric admissibility: directional consistency via soft attenuation of anti‑aligned updates, subspace compatibility by projecting onto a consensus subspace from recent proxies, and sensitivity stability via norm clipping. On six real‑world graph benchmarks, GGRS improves mean accuracy (e.g., +0.019 on GCN‑2, +0.022 on GraphSAGE), flips pairwise alignment from negative to positive, speeds convergence, and reduces per‑client variance. The method works across GCN and GraphSAGE and combines additively with SCAFFOLD.

## Method Summary
GGRS is a server‑side wrapper that regulates client updates before aggregation without requiring access to client data. It starts from a normalized parameter update direction proxy `z_k = Δθ_k / ||Δθ_k||₂`. The server maintains an exponential moving average reference direction `r(t)` and a sliding buffer of recent proxies. After a warm‑up period, each client’s proxy is evaluated: if its alignment `γ_k` with the reference is negative, a soft attenuation `β_k` (sigmoid gate) reduces its contribution. Next, the (possibly attenuated) proxy is projected onto a consensus subspace spanned by the top‑`q` right singular vectors of the buffer, enforcing geometric compatibility. The projected vector’s norm is then clipped to a threshold `ε`, and the resulting norm yields a scale factor `s_k`. Scales are normalized to preserve average magnitude and used to reweight the original updates: `Δθ_global = Σ_k w_k s'_k Δθ_k`. The global model is updated by this regulated aggregate. The wrapper is agnostic to the base federated optimizer (FedAvg, FedSGD, FedProx, SCAFFOLD) and GNN architecture.

## Key Results
- Mean accuracy gains: +0.019 (GCN‑2), +0.022 (GraphSAGE) over FedAvg.  
- Pairwise alignment (PA) flips from negative (−0.013) to positive (+0.009).  
- Faster convergence: 16 fewer rounds to reach 70% accuracy on GCN‑2; per‑client accuracy variance reduced.

## Why This Works (Mechanism)
**Mechanism 1: Directional Consistency via Reference Attenuation**  
Misaligned client updates cause destructive interference in operator space; attenuating anti‑aligned updates preserves directional coherence. The server computes a proxy direction `z_k = Δθ_k / ||Δθ_k||` and maintains an EMA reference `r(t)`. Alignment `γ_k = ⟨z_k, r̂(t)⟩`. After warm‑up, for `γ_k < 0` a soft attenuation `β_k = β (1 - γ_k)` is applied, yielding `z'_k = β_k z_k`. The identity Jacobian approximation (`Ψ`) justifies using normalized parameters as a proxy for operator perturbation directions.

**Mechanism 2: Subspace Compatibility via Consensus Projection**  
Client updates inhabit distinct operator tangent spaces; projecting onto a consensus subspace enforces geometric compatibility. A sliding buffer `B` of admitted proxies (those with `γ_k ≥ γ_min`) is maintained. The top‑`q` right singular vectors `S` from SVD on `B` span the consensus subspace. Each attenuated proxy is orthogonally projected: `z''_k = Sᵀ(S z'_k)`. This assumes the dominant left singular subspace of the graph‑specific modulation `P_k` is approximately shared across clients.

**Mechanism 3: Sensitivity Stability via Norm Clipping**  
Unbounded update norms destabilize aggregation; clipping ensures no single client dominates the operator perturbation. After projection, the norm is clamped: `z'''_k = z''_k * min(1, ε / ||z''_k||)`. The resulting norm `s_k` reweights the original update. This prevents extreme sensitivity changes that could distort the global message‑passing operator.

## Architecture Onboarding
**Component map**  
Client → `Δθ_k` → Server computes proxy `z_k` → EMA reference `r(t)` updated → Buffer `B` stores recent `z_k` → Every `ν` rounds compute consensus subspace `S` via SVD → Per‑client regulation (alignment `γ_k`, attenuation `β_k`, projection onto `S`, norm clipping) → obtain scale `s_k` → normalize to `s'_k` → aggregate `Δθ_global = Σ w_k s'_k Δθ_k` → broadcast updated `θ`.

**Critical path**  
1. Receive all `Δθ_k`.  
2. Compute each `z_k = Δθ_k / ||Δθ_k||₂`.  
3. Update EMA reference `r(t)` and normalize to `r̂(t)`.  
4. Append `z_k` to buffer `B`; trim to window size.  
5. Every `ν` rounds, recompute `S` (top‑`q` right singular vectors) from `B`.  
6. For each client after warm‑up: compute `γ_k = ⟨z_k, r̂(t‑1)⟩`, derive `β_k` via sigmoid, attenuate `z_k`, project onto `S`, clip norm `ε`, extract `s_k`.  
7. Normalize scales: `s'_k = s_k / mean(s)` so mean scale = 1.  
8. Aggregate regulated updates: `Δθ_global = Σ w_k s'_k Δθ_k`.  
9. Update global model: `θ(t+1) = θ(t) + Δθ_global`.

**Design tradeoffs**  
- `α` (EMA decay): smaller → more adaptive but noisy; larger → smoother but slower.  
- `τ` (sigmoid temperature): higher → harder attenuation threshold.  
- `ε` (clip norm): low → over‑regularization; high → weak clipping.  
- `q` (subspace dimension): larger → more variance captured, more compute; smaller → less adaptive.  
- `w` (warm‑up rounds): longer → more stable reference before regulation.  
- `ν` (SVD frequency): higher → fresher subspace, more cost.  
- Buffer size: balances subspace stability vs. adaptability.

**Failure signatures**  
- High aggregate attenuation `̄β(t)`: persistent geometric conflict → consider increasing `α` or `q`.  
- Empty buffer: no admitted proxies → check `γ_min` or extreme heterogeneity.  
- Norms consistently at `ε`: clipping too aggressive → increase `ε`.  
- Rising `σ_acc`: over‑penalizing some clients → review `β` and `γ_min`.  
- Slow convergence despite high `Γ`: possible over‑projection → adjust `q` or buffer size.

**First 3 experiments**  
1. **Main benchmark**: Evaluate FedAvg/FedSGD/FedProx/SCAFFOLD ± GGRS on six datasets. Metrics: accuracy, `Γ`, `PA`, `σ_acc`, convergence rounds.  
2. **Heterogeneity sweep**: Vary Dirichlet `α ∈ {0.05,…,1.0}`. Measure `ΔAcc` with vs. without GGRS.  
3. **SBM mechanistic proof**: Use Stochastic Block Model graphs with 3 Smooth vs. 3 Sharp communities. Compare attenuation rates per group.

## Open Questions the Paper Calls Out
1. **Convergence of regulated dynamics** – The paper does not provide a theoretical convergence guarantee for the GGRS aggregation operator. Proving convergence under standard FL assumptions (smooth losses, bounded variance, client similarity) remains an open problem.  
2. **Better data‑free proxy** – The current identity proxy `Ψ(Δθ)=Δθ/‖Δθ‖` ignores curvature. A Fisher‑weighted proxy could be tighter; its design and impact need investigation.  
3. **Robustness to subspace assumption violations** – GGRS relies on the approximate shared dominant subspace of client Jacobians. Under extreme heterogeneity this may fail; controlled experiments with orthogonal (or deliberately misaligned) Jacobian subspaces are needed to assess robustness.  
4. **Extension to graph transformers** – It is unclear whether geometric regulation benefits attention‑based message passing. Applying GGRS to graph transformer architectures (e.g., Graphormer) and evaluating on cross‑domain benchmarks is a key future direction.

## Limitations
- Data split specification: details of client graph partitioning beyond Dirichlet label‑skew (e.g., edge handling, train/test splits) are underspecified, potentially affecting observed heterogeneity and geometric conflict.  
- Simulation‑based estimates: some results (FedProx+GGRS, full GraphSAGE) are estimates; final numbers may differ, weakening cross‑baseline comparisons.  
- Core approximations: the identity Jacobian approximation and the shared‑subspace assumption lack validation under extreme heterogeneity, limiting theoretical guarantees and generalizability.
