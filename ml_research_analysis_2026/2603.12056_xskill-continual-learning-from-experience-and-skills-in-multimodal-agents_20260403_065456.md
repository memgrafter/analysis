# XSkill: Continual Learning from Experience and Skills in Multimodal Agents
## Quick Facts
- **arXiv ID**: 2603.12056
- **Source URL**: https://arxiv.org/abs/2603.12056
- **Reference count**: 40
- **Primary result**: XSkill improves Average@4 by 2.58–6.71 points over tool-only baselines and reduces tool execution errors by nearly half, with strong zero-shot transfer.

## Executive Summary
Multimodal agents often struggle with inefficient tool use and rigid orchestration, and they lack mechanisms to learn from past interactions without retraining. XSkill introduces a dual-stream framework that extracts two complementary forms of knowledge—experiences (action-level guidance) and skills (task-level workflows)—from trajectories using visually grounded summarization and cross-rollout critique. At inference, the system retrieves and adapts these knowledge forms to guide tool selection and execution. Evaluated on five benchmarks with four different backbone models, XSkill achieves consistent improvements in task completion (Average@4 gains of 2.58–6.71 points) and significantly reduces tool execution errors. The approach also demonstrates robust zero-shot transfer to out-of-distribution tasks, highlighting its flexibility and effectiveness.

## Method Summary
XSkill is a training-free framework that enables continual learning from experience and skills in multimodal agents. It processes past trajectories to extract two types of knowledge: experiences, which provide fine-grained action-level guidance, and skills, which capture reusable task-level workflows. Experience extraction employs visually grounded summarization to condense trajectories while preserving visual context. Skill extraction uses cross-rollout critique to distill robust skills by comparing multiple attempts. Both knowledge forms are stored in separate memory banks. During inference, given a new task, the system retrieves relevant experiences and skills, adapts them to the current context, and uses the combined knowledge to orchestrate tool calls. This dual-stream design allows the agent to leverage both detailed and high-level prior knowledge, leading to more efficient and accurate tool usage.

## Key Results
- Average@4 improves by 2.58–6.71 points over tool-only baselines and up to 11.13 points over the strongest prior method.
- Tool execution errors are nearly halved (e.g., syntax errors drop from 114 to 71).
- Zero-shot transfer on out-of-distribution benchmarks outperforms baselines by 2–3 points.

## Why This Works (Mechanism)
The effectiveness of XSkill stems from its dual-stream knowledge decomposition. Experiences offer immediate, context-specific action suggestions, while skills provide reusable procedural templates. Visually grounded summarization ensures that experiences remain tied to the visual state, making them directly applicable. Cross-rollout critique filters out noisy or failed attempts, yielding reliable skills. At inference, retrieval selects the most relevant pieces from both streams, and adaptation aligns them with the current task and visual context. This combination allows the agent to avoid common tool errors (e.g., syntax mistakes) and adopt more targeted strategies (e.g., increased use of code interpreter when appropriate).

## Foundational Learning
- **Multimodal agents**: Need to process both visual and linguistic inputs to interact with tool-augmented environments; quick check: can interpret images and text to generate tool calls.
- **Tool orchestration**: Efficient sequencing and use of external tools is essential for complex tasks; quick check: correctly invokes tools and handles their outputs.
- **Continual learning from trajectories**: Agents should improve from past interactions without full retraining; quick check: stores and reuses past episodes for future tasks.
- **Experience vs. skill decomposition**: Separating action-level and task-level knowledge supports flexible adaptation; quick check: retrieves appropriate granularity for given situation.
- **Visually grounded summarization**: Summaries must reflect the visual context to be useful; quick check: generated summaries include references to visual elements.
- **Cross-rollout critique**: Comparing multiple trajectories extracts robust skills; quick check: skills are derived from multiple successful rollouts.

## Architecture Onboarding
Component map:
- Experience pipeline: trajectories -> visually grounded summarization -> experience storage.
- Skill pipeline: trajectories -> cross-rollout critique -> skill storage.
- Inference pipeline: new task -> retriever (queries both storages) -> adapter -> tool orchestration -> execution.

Critical path: During inference, the system retrieves relevant experiences and skills from storage, adapts them to the current visual and linguistic context, and then uses the adapted knowledge to guide the agent's tool selection and execution sequence.

Design tradeoffs:
- Separating experiences and skills increases storage and retrieval complexity but enables finer-grained knowledge reuse.
- Visually grounded summarization adds computational overhead but ensures context awareness.
- Cross-rollout critique requires multiple trajectories but yields more reliable skills.
- Adaptation introduces latency but improves relevance to the current task.

Failure signatures:
- Retrieval of irrelevant knowledge leads to inappropriate tool calls or syntax errors.
- Poor adaptation misaligns past knowledge with the current visual state, causing execution failures.
- Over-reliance on stored data may reduce flexibility on novel tasks not covered by past experiences.

## Limitations

- Potential confounding from using multiple backbone models without fully disentangling their effects.
