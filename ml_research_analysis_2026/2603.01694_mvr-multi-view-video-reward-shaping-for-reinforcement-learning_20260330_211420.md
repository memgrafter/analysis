# MVR: Multi-view Video Reward Shaping for Reinforcement Learning
## Quick Facts
- **arXiv ID**: 2603.01694
- **Source URL**: https://arxiv.org/abs/2603.01694
- **Reference count**: 39
- **Key outcome**: MVR consistently outperforms VLM-based methods on 19 HumanoidBench and MetaWorld tasks

## Executive Summary
MVR (Multi-View Video Reward Shaping) addresses the challenge of providing visual guidance for reinforcement learning agents when reward functions are difficult to specify. The method leverages videos from multiple viewpoints and vision-language models to generate rewards that guide agents toward desired behaviors. Unlike single-image similarity approaches, MVR learns a state relevance function from video-text comparisons and applies state-dependent reward shaping that automatically decays as the agent's behavior improves. This approach enables more effective learning, particularly for tasks requiring dynamic motions and fine-grained interactions.

## Method Summary
MVR processes multi-view demonstration videos alongside reference text descriptions to create a reward shaping framework. The method extracts features from videos using a video-text alignment model, learns a state relevance function that identifies important frames, and computes similarity scores between agent states and demonstrations. A key innovation is the state-dependent reward shaping formulation where shaping intensity automatically decays as the agent approaches the desired behavior. The framework is evaluated across 19 tasks from HumanoidBench and MetaWorld, showing consistent improvements over existing VLM-based reward methods like VLM-RM and RoboCLIP.

## Key Results
- MVR consistently outperforms VLM-RM and RoboCLIP across all 19 evaluated tasks
- Ablation studies confirm the importance of multi-view videos, matching objectives, and regularization
- Visual guidance through MVR helps prevent suboptimal behaviors by reshaping the reward landscape
- The state-dependent shaping formulation provides automatic decay as agent behavior improves

## Why This Works (Mechanism)
MVR works by learning what aspects of demonstration videos are most relevant to the task through multi-view video-text alignment. By comparing agent states to multiple video perspectives rather than single images, the method captures temporal dynamics and spatial relationships more effectively. The state relevance function identifies which frames matter most for the task, while the matching objective ensures the agent's behavior aligns with demonstration semantics. The regularization component prevents overfitting to specific video features, and the state-dependent shaping ensures rewards guide rather than dominate the learning process.

## Foundational Learning
**Vision-Language Models (VLMs)**: VLMs provide the foundation for understanding visual content through natural language descriptions, enabling reward generation from demonstrations. *Why needed*: Traditional reward engineering is difficult for complex behaviors; VLMs bridge this gap by interpreting visual demonstrations semantically. *Quick check*: Verify VLM can accurately describe key actions in your demonstration videos.

**Video-Text Alignment**: Learning correspondence between video frames and textual descriptions is crucial for identifying task-relevant visual features. *Why needed*: Single images miss temporal dynamics; video-text alignment captures the full behavior sequence. *Quick check*: Ensure alignment model correctly matches critical frames to their textual descriptions.

**State Relevance Learning**: The ability to identify which video frames are most important for a given task. *Why needed*: Not all video content is equally relevant; focusing on important frames improves reward quality. *Quick check*: Validate that relevance scores highlight frames corresponding to key task milestones.

**Reward Shaping Theory**: Understanding how shaped rewards affect the optimal policy and learning dynamics. *Why needed*: Poorly designed shaping can mislead agents or slow convergence; theoretical grounding ensures effectiveness. *Quick check*: Confirm shaping preserves optimal policies while accelerating learning.

## Architecture Onboarding
**Component Map**: Video Encoder -> Text Encoder -> Alignment Model -> State Relevance Function -> Reward Generator -> RL Agent

**Critical Path**: Demonstration videos → Multi-view feature extraction → State relevance learning → Reward computation → Agent policy update

**Design Tradeoffs**: Multi-view videos provide better context but increase data collection burden versus single-view approaches. Learned state relevance reduces computational cost during training versus using all frames equally, but requires additional pretraining. Automatic decay simplifies hyperparameter tuning versus manual shaping schedules, but may need task-specific adjustment of the shaping intensity parameter.

**Failure Signatures**: 
- Poor reward signals: Check video-text alignment quality and state relevance function accuracy
- Slow learning: Verify shaping intensity is appropriate and demonstration videos capture the full task
- Agent ignoring guidance: Ensure VLM can recognize the demonstrated behavior in agent observations

**First Experiments**:
1. Test reward generation on held-out demonstration videos to verify VLM alignment quality
2. Evaluate state relevance function on validation frames to ensure it identifies key moments
3. Run short RL training with shaping disabled to establish baseline performance

## Limitations
- Performance depends on demonstration video quality and viewpoint diversity
- VLM limitations in understanding complex physical dynamics may affect reward accuracy
- Multi-view video requirement increases data collection burden compared to single-view methods
- The shaping intensity parameter λ may need task-specific tuning despite automatic decay
