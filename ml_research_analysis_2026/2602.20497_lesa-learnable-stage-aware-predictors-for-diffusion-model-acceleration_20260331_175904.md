# LESA: Learnable Stage-Aware Predictors for Diffusion Model Acceleration

## Quick Facts
- arXiv ID: 2602.20497
- Source URL: https://arxiv.org/abs/2602.20497
- Reference count: 40
- Primary result: LESA achieves 5.00x speedup on FLUX.1-dev with only 1.0% quality drop, 6.25x on Qwen-Image with 20.2% improvement over TaylorSeer, and 5.00x on HunyuanVideo with 24.7% PSNR improvement.

## Executive Summary
LESA addresses the high inference cost of diffusion models by introducing a learnable, stage-aware predictor framework that overcomes limitations of existing feature caching methods. It partitions the diffusion process into discrete noise-level stages (e.g., high-noise, mid-noise, low-noise), each with a dedicated expert predictor based on a parameter-efficient Kolmogorov-Arnold Network (KAN). A two-stage training strategy—first ground-truth guided, then closed-loop autoregressive—ensures robustness against prediction drift during multi-step inference. This approach yields state-of-the-art acceleration across image and video synthesis models with minimal quality degradation.

## Method Summary
LESA caches intermediate features from DiT blocks and predicts missing features during accelerated inference. For a given cache skip interval, the system identifies the current noise stage and uses the corresponding expert predictor. The predictor inputs concatenated cached features from the past K steps and a relative timestep vector, processed via a linear projection and a KAN module to produce a scalar modulation α. The predicted feature is computed as ŷ = hₜ + α·z, where z is the projected feature representation. Training proceeds in two stages: first, the predictor learns from ground-truth features to model denoising dynamics; second, closed-loop autoregressive training exposes it to its own past predictions, building resilience to accumulated errors. This design adapts to stage-dependent feature evolution while maintaining efficiency.

## Key Results
- 5.00× speedup on FLUX.1-dev with only 1.0% drop in ImageReward.
- 6.25× speedup on Qwen-Image, achieving 20.2% quality improvement over TaylorSeer.
- 5.00× speedup on HunyuanVideo, with 24.7% PSNR improvement over TaylorSeer.
- Consistent outperformance of training-free forecasting methods across image and video benchmarks.

## Why This Works (Mechanism)
### Mechanism 1: Stage Partitioning for Non-Uniform Dynamics
LESA partitions the diffusion trajectory into noise-level stages (e.g., high-noise, mid-noise, low-noise), assigning each a dedicated expert predictor. This adapts to the fundamentally different feature dynamics across regimes: high-noise involves coarse feature formation, mid-noise shows smoother evolution, and low-noise focuses on fine detail refinement. A unified predictor cannot capture these distinct behaviors, as evidenced by the paper's analysis in Section 2 showing stage-dependent feature trajectories. If feature evolution were globally smooth, this multi-expert design would add unnecessary complexity.

### Mechanism 2: Two-Stage Training for Drift Robustness
The training strategy first uses ground-truth (GT) guided learning to model clean denoising dynamics, then transitions to closed-loop autoregressive (CL-AR) training where the predictor's own past outputs are fed back as inputs. This exposes it to accumulated prediction errors, teaching correction mechanisms. As described in Section 3.2, this mirrors real inference conditions and prevents catastrophic drift. Without CL-AR, performance degrades sharply at high acceleration, as prediction errors compound.

### Mechanism 3: KAN Backbone for Efficient Nonlinear Modeling
LESA employs a Kolmogorov-Arnold Network (KAN) with learnable univariate spline functions per neuron, replacing fixed activations in MLPs. This allows flexible approximation of complex, high-frequency temporal mappings between cached features and targets, with fewer parameters than equally expressive MLPs. The paper notes in Section 6.2 that KAN's theoretical expressiveness per parameter suits the non-smooth dynamics. If the temporal mapping were inherently low-complexity and smooth, simpler polynomial or MLP forecasters would suffice.

## Architecture Onboarding
- **Component map**: Stage Scheduler maps timestep t to stage index s → Feature Buffer stores last K features for stage s → LESA Predictor (stage-specific KAN) computes predicted feature → Caching Controller decides cache hit/miss based on skip interval N.
- **Critical path**: During cache skip from t to t-K: (1) Stage Scheduler identifies stage s for t; (2) Feature Buffer provides {hₜ, hₜ₋₁, ..., hₜ₋ₖ₊₁}; (3) LESA Predictor (s) outputs ĥₜ₋ₖ; (4) ĥₜ₋ₖ feeds to next DiT block, skipping computation of hₜ₋ₖ.
- **Design tradeoffs**: Stage granularity vs. complexity (more stages better model dynamics but increase predictors); predictor capacity (KAN size) vs. efficiency (larger KAN adds latency); training data diversity vs. cost (paper uses 100 prompts, saturates ~10).
- **Failure signatures**: Spatial/structural drift (blurring, distortions); temporal inconsistency (flickering in video); metric collapse at high acceleration; net negative speedup due to predictor overhead.
- **First 3 experiments**:
  1. Baseline Replication & Stage Validation: Run base DiT, extract features, plot PCA/cosine similarity to confirm stage-dependent dynamics.
  2. GT-Guided Training Sanity Check: Train only GT stage for one epoch, evaluate L1 error; expect low error on held-out but high error in autoregressive rollout.
  3. Closed-Loop Training Ablation: Compare full LESA (GT+CL-AR) vs. GT-only at target N; expect GT-only fails at high N, CL-AR recovers quality.

## Open Questions the Paper Calls Out
1. How do learned stage boundaries correspond to intrinsic diffusion phases, and are they consistent across models and datasets?
2. To what extent does two-stage training mitigate prediction drift, and what is each stage's quantitative contribution?
3. Why does KAN outperform MLP for timestep modulation, and what dynamics do learned splines capture?
4. How transferable is a LESA predictor across different diffusion architectures without retraining?
5. What is the theoretical relationship between LESA's scalar modulation α and optimal multi-step predictors from diffusion ODEs?

## Limitations
- Exact feature extraction layers and tensor shapes are unreported, causing ambiguity in predictor input design.
- Stage partitioning thresholds (timestep or sigma ranges) are not quantitatively specified.
- Mapping from cache interval N to reported acceleration ratios is implicit and model-dependent.
- KAN hyperparameters (spline components, grid size) are unspecified, affecting reproducibility.
- Predictor scope per DiT block (weight sharing vs. per-block) is unclear.

## Confidence
- Staged partitioning claim: Medium (qualitative support but lacks explicit thresholds).
- Two-stage training robustness: High (clear ablation rationale and described failure without it).
- KAN efficiency advantage: Medium (theoretical basis but no direct capacity-matched MLP ablation).

## Next Checks
1. Empirical stage boundary discovery: Use change-point detection on feature trajectories to find natural splits and compare with LESA's assumed stages.
2. Latency-acceleration curve audit: Measure end-to-end latency across N values to derive actual skip pattern and validate reported speedups.
3. KAN vs. MLP capacity-efficiency ablation: Train predictors with identical parameter counts but different backbones; compare drift and final metrics at fixed acceleration.
